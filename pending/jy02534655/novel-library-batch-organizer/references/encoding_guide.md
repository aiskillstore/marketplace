# 中文文本编码处理指南

## 常见编码

| 编码 | 典型场景 | 检测优先级 |
|------|----------|-----------|
| UTF-8 | 现代文本、网络下载 | 1 |
| GBK | 国内早期Windows文本 | 2 |
| GB18030 | GBK超集，覆盖全部中文字符 | 3 |
| Big5 | 台湾/香港繁体 | 4 |

## 检测策略

1. 使用 chardet 检测前 10KB
2. 若置信度 > 0.9，使用检测结果
3. 否则依次尝试：UTF-8 -> GBK -> GB18030 -> Big5
4. 全部失败则标记为 encoding_error

## 转换策略

所有文件统一输出为 UTF-8（无BOM）
繁体中文保留，不做转换
检测到混合编码时，按出现频率最高的编码处理

## 异常处理

无法解码字符：替换为 � 并记录位置
乱码检测关键词：锟斤拷、烫烫烫、屯屯屯
若乱码比例 > 5%，标记为 heavy_pollution
