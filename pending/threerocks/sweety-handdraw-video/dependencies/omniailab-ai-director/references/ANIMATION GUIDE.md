# 动画与混合媒介制作层（三维预演 ＋ 生成式 AI）

**核心结论：动画不是"换一种画风"，而是换一套运动逻辑与管理方式。** 写实管线里"物理正确"是目标；动画管线里**动画原理优先于物理正确**——角色可以看起来写实，但运动必须服从挤压、拉伸、预备动作与弧形轨迹，否则出来的东西是"会动的人偶"，不是动画。

**本层的存在意义**：把主流水线从"只做真人实拍质感"解放为**任意媒介**，并补上动画独有的四件事——**分工判据、混合美学、运动逻辑、资产验证方式**。

## 在本流水线中的定位与边界

- **只管媒介与运动**：媒介判定、三维／生成的活怎么分、混合美学怎么写、角色资产用什么格式、会动的资产怎么验、运动服从哪一套原理。**画风词汇仍归 `STYLE`，成片级配方仍归 `AESTHETICS`，提示词块序与铁律仍归 `PROMPT-DOCTRINE`。**
- **它是覆盖层，不是替代层**：本流水线各阶段文档里的"真人实拍质感"是**默认模板文本**。媒介一旦被设定为动画，**以 P1「全片风格锁定」里的媒介声明为唯一准绳**，各阶段模板中的实拍字样按其覆盖——不必逐条改写模板。
- **不单独计为一个子技能**。

## 何时调用 · 怎么调用

| 时机 | 怎么用 |
|---|---|
| **P1 定基准前** | 先做**媒介判定**（第一节）：写实／风格化三维／二维／混合。判定结果写进「全片风格锁定」，成为全片唯一媒介口径 |
| **P1 定基准时** | 用第三节定**一条全片光线措辞**，写进风格锁定并逐镜复用；用第二节定**混合美学的分权写法** |
| **P2 建角色资产时** | 用第四节决定角色主参考是**静态角色表**还是**360° 转身视频**（动画线默认后者） |
| **P2／P3 资产验收时** | 按第五节：**会动的资产一律用视频测**，并在与成片相同的条件下测 |
| **P4 分镜时** | 按第一节判据决定**哪些镜头转三维预演**、哪些留给生成；分镜板上把三维镜头**显式标出** |
| **P5 写提示词时** | 按第六节补动画运动口径（挤压拉伸、预备、跟随、弧形、夸张）；光线措辞全片复用不逐镜改写 |
| **P6 生成与组装时** | 按第九节组织分幕目录；**先拼一版全片，再回头重生单镜** |

## 一、媒介判定与分工：什么时候用三维，什么时候用生成

### 1.1 分工判据（一句话）

> **"这个动作能不能用一段话让模型复现？"能 → 交给生成；不能、或者试错代价太高 → 转三维预演。**

三维预演优先的典型场景：

- **动作本身复杂或高度特定**：多关节同时运动、精确的接触与穿插、物体的挤压与拉伸必须被保住的镜头；
- **剧烈动作**：追逐、翻越、载具机动、多人交错——生成很容易把它拍碎或糊掉；
- **描述成本高的镜头**：要用很长的提示词才能说清、而且说清了模型也不一定照做的；
- **需要精确复现的镜头**：后续镜头必须严格接上本镜的空间与朝向。

生成优先的场景：环境、背景、氛围元素、群像填充、道具与载具的静态呈现、以及"能用几句话讲清"的常规动作。

### 1.2 三维预演的真正价值是"把动作定死"

三维预演不只是"更好看"，而是**在生成之前把动作、时间与机位锁死**——生成环节只负责质感、光与风格。代价是前期更重，收益是**试错次数大幅下降**。

### 1.3 判定的落点

判定结果必须写进「全片风格锁定」，并且**逐镜标注本镜走哪条路**：分镜表里给每个镜头加一列「实现路径：三维预演／生成／三维＋生成」。**分镜板上把三维镜头显式高亮**（例如统一用一种颜色标出），团队一眼就能看出分工与工作量。

## 二、混合美学：风格化角色 ＋ 手绘背景

### 2.1 最重要的一条规则

> **干净的立体质感给会动的物件；厚笔触留给不会动的世界。**

原因很具体：**模型很难逐帧稳定保住密集的手绘笔触**。当运动物件和背景**都是**厚笔触时，模型顾不过来，表面会开始"像一张平面图被贴到几何体上"——边缘发死、笔触不动、体积感消失。

**定型写法**：`干净的立体质感 ＋ 手绘质感的环境`。重点运动道具（载具、主要兵器、会飞的物件）走干净路线；世界（背景、远景建筑、天空、植被）走厚笔触。

### 2.2 混合美学必须"分权声明"

两种美学同时出现时，必须在提示词里**分开写清谁走哪一路**，并各自给锚点；否则模型会在两者之间来回摇摆，出来的画面一半干净一半糊。

```text
【媒介与风格分权】角色走风格化立体造型：干净的表面、明确的体积转折、轮廓清晰，
鼻、耳等部位保留夸张比例；环境走手绘水彩质感：可见笔触、纸纹、颜料堆积与晕染，
远景比近景笔触更松。两者共存，角色不被水彩化，环境不被打磨成塑料。
```

### 2.3 不要一次全手绘

纯手绘路线在早期测试里极容易变成"脏、糊、没性格"。**中间路线（立体骨架 ＋ 手绘环境）几乎总是更快出效果**。只有在团队本身有成熟的手绘产能时，才考虑全手绘。

## 三、光决定风格：全片只用一条光线措辞

### 3.1 关键发现

**正午光会让手绘环境发平、发闷、失去体积。** 同一批资产、同一套笔触，**只把光改成傍晚**，画面立刻变暖、层次与体积都出来了。

> **结论：在确立视觉身份这件事上，光比表面处理更重要。**

### 3.2 定型公式

```text
手绘地点 ＋ 金色时刻侧逆光 ＋ 长而清晰的投影
```

### 3.3 全片复用同一条光线措辞（硬规则）

金色时刻一旦测试成立，**整部片逐镜复用同一条光线表述**，**不得逐镜重新描述光线**。理由：重复一条稳定的光线公式，是让不同镜头"看起来属于同一部片"最便宜、最可靠的手段。

**可直接复用的光线风格前缀**（写进 P1「全片风格锁定」后逐镜原样沿用）：

```text
【光线公式】傍晚金色时刻，低角度暖阳斜射，长而明确的投影，暖色高光，
强体积感与层次，环境暗部保留手绘笔触细节。
```

```text
[LIGHTING] late-afternoon golden-hour lighting, low warm sun, long dramatic
shadows, warm highlights, strong depth and dimensionality.
```

> 与本流水线既有口径的关系：`PROMPT-DOCTRINE` 第五节已有「光线七项必定义」与「风格由光决定」。**本条是它在动画线上的强化版——动画线对光线措辞的"全片复用"要求比写实线更严。**

## 四、角色资产：360° 转身视频取代静态角色表

### 4.1 为什么

静态角色表**管不住跨代一致性**：模型看到的是几个离散角度，一旦要求它在运动、表情、说话状态下复现，就开始漂。

**动画线的解法**：用**一段 360° 转身视频**作为角色的主参考资产——一次给全**全部角度 ＋ 表情 ＋ 声音**。

### 4.2 规格（作为 `@char_` 资产制作）

| 段 | 内容 | 作用 |
|---|---|---|
| 转身段 | 完整 360° 缓慢转身，角色保持中性表情与放松站姿 | 锁定轮廓、比例、服装四面细节 |
| 表情段 | 依次给出本片需要的关键表情（笑／不笑／惊讶／怒／惧） | 防止"第一次笑时用了别人的嘴" |
| 声音段 | 说一句本片台词或短句 | 与声音资产（VOICE LOCK）对齐，供唇形与音色参考 |

### 4.3 与 `ASSET-SYSTEM` 的分工

- **`ASSET-SYSTEM`** 定"资产怎么建、怎么命名、怎么不漂"（成对资产、`@char_` 命名、新状态＝新资产、三格角色表、图片不过两遍模型）；
- **本层** 定"动画线的角色主参考**优先用转身视频**"。
- 两者不冲突：**转身视频是 `@char_` 资产的一种形态**，静态角色表仍用于身份定格与快速比对。

### 4.4 参考必须齐全——否则模型替你发明

**已实测的教训**：某批测试在角色表完成前就出图，参考里的载具是**空的**；模型于是**自己往车里塞了随机乘客**。角色参考补齐后，这个问题立刻消失。

> **规则：模型会为缺失的信息编内容。每个应当出现在画面里的常驻角色，都必须在输入里被清楚代表。**（与 `ASSET-SYSTEM` 的"资产前置闸门"同源，动画线上尤其容易触发。）

## 五、会动的资产必须先过视频测试

### 5.1 硬规则

> **静帧好看不等于能用。** 一个"看起来很完成"的资产，必须在**视频状态下、在与成片相同的条件里**被验证过，才算通过。

### 5.2 三条测试要求

1. **用视频测，不用静帧测**；
2. **在与成片相同的条件下测**：同样的光线、同样的镜头、同样的运动幅度；
3. **与它的地点、以及会同框的其它资产一起测**——单件好看的资产和地点放一起可能立刻崩。

### 5.3 崩了怎么办

- **先改措辞**（换材质描述、简化笔触、调整光线表述）；
- **同一处再崩一次 → 直接重建该资产**，不要在措辞上无限打转。（与长片工程层的"迭代纪律"一致。）

### 5.4 测试量本身就是预算

资产测试不是"顺手做两下"。一个 4 分半的动画短片，光是**美术方向的测试就有一千五百多条**。做排期时，**测试量与正式生成量要一起算进去**；把测试压到最低，代价会在正式生成阶段以更高的返工倍数还回来。

## 六、动画运动：动画原理优先于物理正确

写实管线追求"像真实摄影机拍到的"；**动画管线追求"运动本身好看、可信、有意图"**。两者在运动层的优先级不同。

动画线必须逐镜检查的五件事：

| 原理 | 在提示词里怎么写 |
|---|---|
| **挤压与拉伸** | 明确写出"受冲击时物体沿运动方向被压扁／拉长，随后回弹"；载具、软体、布料尤其要写 |
| **预备动作** | 大动作前先写一个反方向的短促蓄力（后撤、下沉、吸气），不要直接给结果 |
| **跟随与重叠** | 主体停下后，附属物（头发、衣摆、尾巴、天线）延迟几拍才停 |
| **弧形轨迹** | 肢体与投掷物走弧线，不走直线；写出弧的起、顶、落三点 |
| **夸张** | 幅度比现实更大：起跳更高、停顿更长、形变更明显——**夸张要写出来，模型默认给的是平均值** |

**写实元素与动画运动的配比**：角色造型可以保留写实质感，但**运动一律按动画原理**。这是本层与写实线最大的分野，必须在「全片风格锁定」里显式声明：

```text
【运动口径】造型保留写实质感与干净的立体表面；运动按动画原理执行——挤压与拉伸、
预备动作、跟随与重叠、弧形轨迹、适度夸张。物理正确让位于运动表现力。
```

## 七、角色设计：幽默与"酷"的配比

动画角色设计最容易走错的一步是**只冲"好笑"去做**——第一版往往更滑稽、更好笑，但一放进设计好的动作里，角色会显得**更可笑**，整部片的调性就塌了。

**正确目标**：在设计里维持**幽默与"酷"之间的平衡**。

**做法**：把喜剧感**局部化**——只放在**脸与个别部位**（夸张的耳形、略笨拙的五官比例），**身体保持可信、舒适、日常的造型**。

**判据句（写进角色设计说明）**：

> **"她看起来像那个真的会把护照落在家里的人。"**

——设计要**为性格服务**，不为好笑服务。

**迭代要点**：
- 第一版觉得"太好笑"就是信号，不要因为好看就保留；
- 每一轮设计都要问："这个造型放进**已经设计好的动作**里，会变丑还是变帅？"
- 手绘／风格化比例（细腿、长颈、圆头）可以留，但**比例夸张要服从角色可信度**。

## 八、人工精修层（不可省）

生成只做到 80–90%。动画线尤其如此，最后一段必须由人推：

- **调色**：全片统一，不逐镜调（与长片工程层"颜色做统一而非逐镜调色"一致）；
- **补细节**：把生成吃掉的结构、转折、眼神处理回来；
- **修生成瑕疵**：穿模、抖动、糊边、笔触断裂；
- **加轮廓线**：在关键镜头给角色补**铅笔式描线**，强化形体与剪影——这是动画线与写实线在后期上最明显的差别。

> **原则：每一处人工痕迹都必须有"逻辑与意图"。** 手工的正确用法是**让画面更清楚**，不是"补得像手工"。

## 九、工程组织：分幕 · 分段 · 先拼全片再重生单镜

### 9.1 两条主目录

| 主目录 | 装什么 |
|---|---|
| **美术方向（Art Direction）** | 全部资产（角色／地点／道具）＋ **早期测试**（用于筛掉 AI 味道、验证风格） |
| **视频生成** | 按幕、按场景组织的全部镜次 |

### 9.2 按幕分文件夹

把片子切成**若干幕**（本例五幕：机场／出租车／警察／忍者／回家），每幕再按场景分子文件夹（如 `Ninja / 19–25`）。

### 9.3 先拼全片，再回头重生单镜

> **流程是：先按分幕拼出一版完整成片 → 再回头逐镜／逐场重生不满意的部分。**

因此同一幕的文件夹**可能会出现两次**（一次是初版、一次是重生版）——这是**正常的**，不是命名错误。做目录规范时要把这条写进去，否则半年后没人看得懂。

### 9.4 资产账目用来定位成本

**按幕统计资产数**，找出最重的那一幕，预算与人力按此分配：

- 典型分布极端不均：本例里最重的忍者一幕占全部故事镜次资产的 **44.3%**，最重的两幕合计 **70.1%**；
- 资产数还受**镜头区间**影响（一个文件夹覆盖多镜，总数不能直接等同于最难的单个镜头）——排期要**看文件夹粒度，不能只看总数**。

### 9.5 早期测试要专门用来筛"AI 味道"

美术方向阶段必须有一步**专门筛 AI 味道的测试**（手部、牙齿、纹理糊化、对称感、无意义文字）。**这一步是主动做的，不是等成片再发现。**

## 十、与其它层的接口

| 层 | 接口 |
|---|---|
| `ASSET-SYSTEM` | 转身视频作为 `@char_` 资产形态；参考必须齐全；会动的资产按 §5 过视频压力测试；**动画线素材不过两遍模型**尤其重要 |
| `PROMPT-DOCTRINE` | 块序与铁律**照常适用**；动画的**动作节拍链**要比写实线更细（挤压／预备／跟随／弧形各写一拍）；光线措辞全片复用 |
| `BLOCKING` | 三维预演镜头同样要站位数据——坐标从站位基线**直接搬进三维场景**，不要再翻译成文字 |
| `COMBAT` | 动画打斗同样要帧链与物理节拍链，但**允许动画原理夸张**（详见 `COMBAT GUIDE.md` 的媒介语法） |
| `OPTICS` | 视场角锚点在三维里**可直接换算成虚拟镜头**，比写实线更好控；内容—视场对齐规则照常适用 |
| `AESTHETICS`／`STYLE` | 画风与成片级配方照常适用；**混合媒介片要按"角色／环境"分别指定**，不能只给一套 |
| `FEATURE-PRODUCTION` | 多幕、几十场以上的动画项目按其制度执行（开启仪式、压力测试、迭代纪律、法条） |
| `SCENE-ENGINE`／`MUSIC-SCENE` | 剧本体检与音乐场景照常适用，音乐段落对动画线尤其常用 |

## 十一、问题 → 解法

| 现象 | 原因 | 解法 |
|---|---|---|
| 运动物件表面像"一张平面图贴在几何体上" | 运动物件用了厚重手绘笔触，模型逐帧保不住 | **运动物件走干净立体质感**，厚笔触只留给环境 |
| 画面一半干净一半糊 | 混合美学没有分权声明，模型在两种处理之间摇摆 | 用 §2.2 的**分权声明**块，分开写清谁走哪一路并各给锚点 |
| 手绘环境发平、发闷、没体积 | 正午光 | 改**傍晚金色时刻侧逆光 ＋ 长投影**；把这条光写入全片锁定逐镜复用 |
| 不同镜头看着不像同一部片 | 每镜各自描述光线 | **全片复用同一条光线措辞**，不逐镜改写 |
| 参考里没有的角色出现在画面里 | 参考不全，模型自己发明 | **常驻角色必须全部进参考**（典型：车里被凭空塞进乘客） |
| 静帧好看，一动就崩 | 只做了静帧验收 | **会动的资产一律用视频测**，并与地点、同框资产一起测 |
| 同一处修了十几次还是崩 | 在措辞上打转 | **同一处再崩一次 → 重建资产**，不再改措辞 |
| 动作像"会动的人偶"，没有节奏 | 只给了结果，没给动画原理 | 逐镜补**挤压拉伸／预备动作／跟随重叠／弧形轨迹／夸张**五件套 |
| 角色好笑但不可爱、整片调性塌 | 设计只冲"好笑" | 喜剧感**局部化到脸与个别部位**，身体保持可信；用 §7 的判据句自检 |
| 跨代角色一致性差 | 只给了静态角色表 | 改用 **360° 转身视频**（转身＋表情＋声音三段）作主参考 |
| 成片一看就是 AI | 没做 AI 味道筛查 | 美术方向阶段**主动做筛查测试**（手、牙、糊化、对称感、乱码文字） |
| 后期调不齐、颜色两段分明 | 逐镜调色 | **全片统一调色**，再补轮廓线与细节 |
| 半年后看不懂目录 | "先拼全片再重生单镜"留下的重复幕目录没有说明 | 目录规范里写明：**同一幕出现两次＝初版＋重生版** |

## 十二、交付前质检

- [ ] 媒介判定写进「全片风格锁定」了吗？（写实／风格化三维／二维／混合）
- [ ] 每个镜头都标了**实现路径**（三维预演／生成／两者），分镜板上三维镜头已**显式标出**？
- [ ] **运动物件**用的是干净立体质感，厚笔触只在环境？
- [ ] 混合美学有**分权声明**块（角色一路、环境一路，各带锚点）？
- [ ] 全片只有**一条光线措辞**，且逐镜**原样复用**？
- [ ] 主要角色有 **360° 转身视频**资产（转身＋表情＋声音三段）？
- [ ] **会动的资产全部过了视频测试**，且是与地点、同框资产一起测的？
- [ ] 每个镜头都给了**动画原理五件套**（挤压拉伸／预备／跟随重叠／弧形／夸张）中适用的项？
- [ ] 角色设计用 §7 的判据句自检过（放进设计好的动作里会变丑还是变帅）？
- [ ] 美术方向阶段做过 **AI 味道筛查**？
- [ ] 后期做过**统一调色 ＋ 轮廓线**，且每处人工痕迹都有意图？
- [ ] 目录规范写明了**分幕结构**与"重复幕目录＝初版＋重生版"？
