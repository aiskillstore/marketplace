# 广告文案与艺术字体包装参考

当广告需要 LLM 编译屏幕文案、CTA、旁白关键词或艺术字体包装时按需读取。本卡支持的是品牌信息层，不等同于逐字字幕：旁白负责完整表达，文案单元在语义重音、卖点证明或品牌收束处成为视觉事件。

## 输入锁定

生成前确认以下内容，并只把已确认文本写入最终 H3 Prompt：

- 旁白逐字稿、语言、声线身份、语气、语速和必要的停顿。
- 用户已提供或官方确认的品牌名、产品名、卖点句、关键词、CTA、免责声明，以及它们对应的产品证据 / 画面事件。
- 用户没有给出精确文案时，LLM 基于已核验事实提出短的 `creative_proposal`；在用户确认前不得把提案当作事实或写入最终 H3 Prompt。
- 每个文案单元的字体角色、字形骨架 / 字重、材质与颜色、空间平面、对比度、可读安全区、出现 / 消失方式和 Logo / CTA 资产来源。
- 用户要求的字幕、广告文案、旁白、关键词包装是否同时存在；没有明确要求时不擅自增加整句字幕，但产品广告默认应提出一组广告文案和字体方向供确认。

旁白文案、关键词、Logo、CTA 和法律信息只能来自用户输入、已分析素材或官方来源。未经确认的卖点、数字、承诺和品牌标语不得因为包装需要被补写。

## 旁白执行

1. 旁白由 MiniMax H3 随画面原生生成：Prompt 写入精确文案、语言、声线、语气、语速、停顿和对应视觉事件；不另建独立 TTS，不为同一内容叠加第二条旁白。
2. H3 Prompt 必须逐字写入已确认创意文案 / 关键词，要求画面在对应节拍直接生成清晰、稳定、符合品牌调性的艺术字体；禁止改写、翻译、打乱、遗漏、乱码或随机替代，并写清构图、负空间、透视、材质、遮挡和运动方式。真实 Logo、字标、包装文字和法律标签不得重绘，只能保留输入素材中已核验的原有内容；可保留与声音同步的环境声和动作声。
3. 旁白是完整叙事；文案单元只承担当前卖点或品牌节拍，不把每句话压成大字，也不让字体盖住产品身份或主要动作。

## 文案与关键词包装结构

按旁白语义和画面节拍组织信息层：

```text
广告意图 / 旁白句段 -> 文案角色 -> 语义重音 -> 字体艺术行为 -> 视觉出现动作 -> 停留与退出 -> 对应产品证据
```

- 每个视觉事件通常只强调一个短文案单元；优先短、可读、能被画面证明的词组，避免整句字幕化或信息墙。
- 文案出现应由语音重音、动作触发、产品特写、材质变化、空间揭示或品牌收束驱动；不要按固定秒表机械铺字。
- LLM 为每个单元选择与当前视觉母题相称的字体艺术行为：文字可以成为平面、体块、投影、反射、材质表面或镜头路径的一部分，也可以在品牌方向明确支持线性扫描时成为光带的一部分，并通过遮挡、透视、景深、形状匹配或材质响应与产品发生关系。
- 进场、停留、退场只选能服务当前事件的主运动；先让文案完整可读，再允许轻微位移、缩放、局部遮挡或材质变化。不要用持续抖动、无意义弹跳或过多装饰遮盖主体。
- 文字层与旁白使用同一语义节拍，但允许根据实际视频与语音时长微调；最终时长仍由视频片段完整拼接结果决定。

## 字体与品牌包装

- 默认使用用户 / 官方确认的字体与品牌色；没有字体资产时使用中性、可读的替代字体，并说明概念性质。
- LLM 根据当前品牌方向和画面媒介决定字形骨架、字重、材质、颜色、空间深度和层级；主文案负责记忆点，辅助词只补充必要语义，不把画面变成信息海报。
- 预留产品、人物和 Logo 的安全区；包装不遮挡产品识别面、人物脸部、动作路径或关键材质证据。
- 当文字落在暗色或高纹理材质上时，为整句保留最低局部对比度；优先用克制的边缘高光、明度抬升或干净留白保持可读性，同时不破坏材质隐喻。不要用字幕框或后期叠字补救。
- 文案包装可以承接品牌方向的材质、光色、形状和运动语法，但不能把参考图中的字体、Logo 或完整版式直接复制过来；精确 CTA 和身份文字仍以 `Copy Lock` 为准。

## Typography Treatment Card

为每个创意文案单元写一张可直接转译到 H3 Prompt 的字体处理卡，至少包含：

```text
Typography Treatment Card
- exact_text: <逐字文本>
- role: <hook | benefit | proof | product | brand close | cta>
- brand_reason: <为什么这种字体气质属于当前品牌方向>
- letterform: <轮廓、字宽、字重、笔画与字距>
- material_edge: <字面、边缘、高光/反射/透明度反馈>
- spatial_anchor: <空间中的平面/体块/表面/路径>
- depth_order: <与产品、环境、前景的前后关系>
- motion: <入场触发 -> 完整读字停留 -> 退场触发>
- product_trigger: <绑定的产品动作或卖点证据>
- safe_area: <可读区域与禁止遮挡对象>
- primary_mechanism: <只选一种主要物理机制>
- secondary_response: <最多一种辅助材质反馈>
```

- `primary_mechanism` 必须来自当前视觉母题，例如投影、蚀刻、透明薄膜、纸张体积、折射、结构展开或克制的空间字块；光带仅在 brief 或 `Brand Direction Lock` 明确需要线性扫描时可用，不能作为默认机制。`secondary_response` 只能增强材质或运动，不能变成装饰堆叠。不要让 H3 把字体处理退化为普通平面标题、底部字幕框或无关的 UI 标签。
- 选择机制前至少比较三种可用方案，并记录品牌理由、产品触发点和排除的默认模板；未明确选择线性扫描时，在最终 Prompt 中加入“禁止通用横向扫光、扫描线揭示、镜头光晕擦屏或光带写字”。多 sequence 任务还要避免多个文字事件重复相同的方向性扫光或擦镜。
- 未明确选择线性扫描时，光带、扫光、扫描线或镜头光晕擦屏不能承担文字入场、转场或产品触发，即使作为辅助反馈也不行；受控高光只能留在已有产品表面，不能让文字出现、写入、擦屏或横向带过画面。优先使用材质显现、实体遮挡、焦点 / 形状匹配、投影、结构展开、折射、阴影几何或静止揭示。
- 先保证整句准确且稳定可读，再让字形轻微响应动作、材质、透视或景深。字体可以被产品或前景短暂遮挡，但必须先有完整读字停留，并且不得遮挡产品识别面、主要动作或受保护身份资产。
- 若暗色或纹理背景让整句对比度跌破可读下限，必须在 H3 Prompt 中指定受控的边缘高光、明度分离或负空间位移；不得改成字幕框，也不得留到后期处理。
- 字体门验收分为三项：逐字准确、停留期间跨帧稳定、品牌调性与产品动作有可见关系。任一项失败都要标记本次 H3 生成失败，基于同一份完整 Prompt 准备只修正字体处理的方案；取得新的生成授权后才能提交，严禁用后期合成掩盖失败。

## 生成与验收

1. 视频按所选路线生成，保留 H3 原生旁白、环境声和动作音效；创意文案文字由 H3 使用 `Copy Lock` 与 `Typography Lock` 在生成阶段直接渲染。禁止用 `ffmpeg`、OmniAiLab 画布 原生合成或其它后期步骤加字、补字、换字、修字或覆盖文字。
2. 以实际旁白波形 / 语音转写和画面事件校准文案出现与退出，不为凑目标秒数裁切、补帧、循环或变速。
3. 检查旁白清晰、文案与重音 / 卖点证据对应、逐字内容正确、字形跨帧稳定、艺术字体与品牌方向一致、品牌色与产品不冲突、文字与产品动作存在可见因果、完整读字停留成立、没有未被选择的横向扫光 / 扫描线 / 光晕擦屏模板、文字没有事实扩写、声音没有重复叠加。H3 艺术字体不合格时标记当前生成失败，提出修正或调整方案并重新请求生成授权，不能以后期文字覆盖掩盖失败。
4. 独立 BGM 是否生成由用户确认的声音方案决定；旁白、环境声、动作声和艺术字体包装均可保留。最终交付报告实际成片时长和文字 / 声音来源。
