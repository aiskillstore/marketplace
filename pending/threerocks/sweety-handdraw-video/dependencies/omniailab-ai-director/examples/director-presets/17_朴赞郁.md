# 朴赞郁｜Park Chan-wook

> **一句话**：把画面塞满花纹，让摄影机做一件物理上不可能的事，然后礼貌地伤害一个人。
> **触发词**：朴赞郁、复仇、巴洛克、反讽、形式感、装饰

## 一、适用与不适用

**适用**
- 复仇、家族秘密、阶级伪装、囚禁与交换、**道德账目型**犯罪叙事。
- 需要"美"与"残酷"**同时在场**的段落：一次伤害发生在一个非常好看的房间里。
- 有美术预算或有**真实纹样环境**的项目：壁纸、地砖、刺绣、木雕、庭院植栽、旧式旅馆。
- 需要一次让观众"**看见摄影机**"的形式高潮：一个镜头做完一次不可能的位移。

**不适用（改用谁）**
- 自然主义生活流 → 用 **侯孝贤**（16）。
- 纯净的道德结局 → 用 **斯皮尔伯格**（01）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| **张艺谋** | 也高饱和、正面对称、画面填满。张氏填的是**一种颜色**（占画幅 60%–80%）＋ 等距同动作的 30–200 个单元 ＋ 只用眼平与顶俯两档机位；这里填的是**多种图案**（一帧里至少三种互不相同的大母题同时可读）＋ 一两个人 ＋ **每场必做一次穿过中间高度的运动**——那正是张氏参数明令禁止的。 |
| **雷弗恩** | 也风格化暴力与装饰。雷弗恩的画面是**空的**（对称、单一色温、一个人被供在中央、摄影机几乎不动、暴力没有后账）；这里画面**被纹样填满**，摄影机每场做一次夸张运动，而且**暴力必须留下要处理的东西**：一个证人、一笔债、一具需要搬走的身体。 |
| **芬奇** | 也控制与程序。芬奇的控制是**隐形的**，摄影机永远不承认自己存在；这里的摄影机是**表演者**——一场戏里明目张胆地做一次超现实运动（穿墙、穿地板、从俯视转成正面），而且你就是要观众注意到。 |
| **库布里克** | 也对称形式主义。库氏的对称是空的、广角的、单点透视的、冷的白；这里的对称是**被装饰过的**——中焦段、画面各层塞满织物与木纹、色调是酒红橄榄绿芥末金的**暖**。 |
| **维伦纽瓦** | 也讲几何。维氏靠**清空与去饱和**把人压小；这里靠**填满与高饱和**把人围住——压迫感来自"这个房间太好看了，而你正要在里面做一件很脏的事"。 |
| 通用复仇爽片 | **复仇不提供宣泄**。结构要求复仇者被这件事**变得更坏**——先写清代价（他会失去哪一项做人的资格），再写怎么杀。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 先写这场戏的**账本**：谁欠谁什么，以及**复仇者最后会失去哪一项具体的做人资格**。
- 给人物**一句过度礼貌的台词**，用它说出最狠的那件事。
- 暴力段落**只拍三颗**：起手、发生（顶俯或严格正面）、**后果（在收拾东西）**。

**2｜空间与机位**
- 为这场戏设计**唯一那一次不可能运动**，写成"起点 → 路径 → 终点"三句话；**其余镜头全部锁定**。
- **清点画面里的图案**：至少三种，且最小重复单元不小于画幅高的四十分之一（否则读不出）。
- 画面被填满：一帧里同时可读的母题不少于三种。

**3｜光学与景深**
- 中广只给那一次不可能运动；标准做正面对称；中长焦给装饰性插入。
- **中等景深**：画面是**锐的**，每一处花纹都要可读（与大光圈虚化相反）。
- 主光走**掠射角**，确认花纹在画面里有浮雕感而不是被拍平。

**4｜光影与色彩**
- 常规段落光比 3:1；**暴力发生的那一颗拉到 8:1**——做法是**关掉补光**，不是加硬光。
- 酒红、橄榄绿、芥末金、胡桃木褐**四色并置**（不是一色统治）。
- 颜色是"被装饰的暖"，与库布里克的临床白正好相反。

**5｜时间与剪辑**
- 平均镜头 3–8 秒，**含一次 40–90 秒的形式长镜**（那一次不可能运动）。
- 设计一次**形状匹配转场**：上一颗画面里的某个图形，在下一颗的同一位置变成另一样东西。
- 让每个演员练"**晚一拍**"：表情保持到不合理为止，再变——反讽由节奏产生。

**6｜声音与表演**
- 古典乐或巴洛克；音乐与画面的残酷形成对照。
- 对白**过度礼貌**、语速平稳；威胁藏在教养里。
- 表演分两层：表面的礼貌与底下的恶意，两者之间的落差就是风格。

## 六、与其它层的对接

- **接管**：纹样密度与最小重复单元、每场一次的不可能运动、掠射光与浮雕感、四色并置、形状匹配转场、"晚一拍"表演节奏。
- **保持全片默认**：布光可取 `CAMERA-LIGHT` 的"影棚遮旗塑形"或"伦勃朗光"；打斗动作归 `COMBAT`；块序与铁律归 `PROMPT-DOCTRINE`。
- **硬约束**：正文不写光圈值；"中等景深、画面锐"要写成"从前景的刺绣到背景的壁纸，每一处纹样都清晰可辨"。
