# Prompts behind the kept samples — variant contrast (速写本 · 粗细对比)

Every sample: Qwen-Image 2.1 Q6 on ComfyUI, euler / simple, 20 steps, CFG 1.0, 1024×1024, then `scripts/inkpost.py` with the options shown.

Iterations: Post-only test on round-1/2 raws: --vgrow 3.5 gave ratio 1.9–2.0, but handwriting got thick and unreadable → big-form mask (filled silhouettes eroded ~40 px) so notes and small marks stay thin. --thin first version broke fine lines and --rough 0.5 speckled 1 px lines on a scatter page → thin only strokes ≥ 5 px, no --rough. v1 prompt pilot (two pens, weight follows busyness): thick/thin mix appeared but every big surface stayed white (solid ~0.1), ratio 3–5 → prompt asks for one or two flat black areas; --vgrow lowered to 2.5, --thin to 0.85. v2: full set with the final prompt and preset.
