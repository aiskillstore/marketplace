# Documentation map

## ADRs

- Match the existing file naming, for example `docs/adr/0003-short-title.md`, using the next free number.
- If `docs/adr/` does not exist, create it only for a durable decision that has real alternatives.
- Minimum sections: Status, Context, Decision, Consequences.
- Never rewrite an accepted ADR; supersede it with a new one and update the old record's status.
- When an ADR skill is installed in `.agents/skills/`, load it for the format.

## Edge cases

- `CLAUDE.md` that only points to `AGENTS.md`: edit `AGENTS.md`, not the pointer.
- A decision that only affects one feature belongs next to that feature, not in top-level docs.
- Docs regenerated by a tool are edited at their source, not in the output.
