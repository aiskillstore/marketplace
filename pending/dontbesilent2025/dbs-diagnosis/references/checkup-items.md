# 体检：七项检查清单

七项检查一次跑完。每项给出结论（通过 / 不通过 / 部分通过 / 依据不足）和一两句依据；依据来自用户材料时直接引用，来自推断时标「假设」。

## 1．印钞机检查

商业模式是一台对 input 有固定要求的机器。

- Input：要求投入什么？时间、技能、资金、流量、人脉。
- Output：input 满足时，能稳定产出什么？
- 可替代性：换一个人喂同样的 input，能不能产出同样的 output？
  - 能：机器本身成立。
  - 不能：生意依赖特定的人，这台机器还没有独立存在。

## 2．道德检查

这个模式逼经营者做好人还是做恶人？

- 免费分享会让收入增加：好模式。
- 必须夸大、制造焦虑或隐瞒信息才能成交：坏模式。在坏模式里努力做好人，代价会一直由经营者承担；更现实的做法是换模式。
- 每多赚一笔钱都在透支口碑或信任：看起来是个人品牌生意，实际在按流量生意的逻辑消耗自己。

## 3．定价检查

- 有几个价格带？彼此差多少？
- 引流款和利润款的价差太小时，买家会把它们当成同一个产品，利润款卖不动。dontbesilent 的经验口径：价差在 5～15 倍之间，差不到 5 倍就有问题。
- 引流款在指望自身赚钱：通常赚不到。引流款的任务是把人带到利润款面前。
- 收入规模还小的知识付费，最常见的问题出在定价。
- 价格由供需决定，和成本无关。「卖这个价也有人买」就是定价依据。

## 4．需求检查

区分买家说出来的需求和真实需求：

- 顾客需要的是「购买」这个行为带来的结果或感受，不一定是「使用」商品本身。
- 很多购买的真实需求是购买本身带来的情绪满足。
- 代运营、陪跑类服务，很多顾客买的是有人带着、有事可做的状态，知识只占一部分。
- 多数知识付费在功能上承担了心理支持的作用。
- 买家愿意掏钱的前提通常是：他觉得这笔钱能回本。

## 5．流量与变现关系检查

- 分别在哪个平台获客、成交、交付？
- 成交和交付挤在同一个地方，往往有问题。
- 把内容本身当作变现产品，效率最低。
- dontbesilent 的经验结构：文字平台获取流量，视频或直播平台成交，微信做交付。这是参照，不是判断标准。例如有人直接靠文字变现，预期收入不高时也完全可行；结构不同时，看它和用户的收入预期是否匹配。
- 流量大小和收入没有必然关系；看电商指标（成交、客单价、复购），少看内容数据指标。

## 6．规模化检查

- SOP 能定下来吗？稳定了才谈扩张，不稳定时扩张只会放大混乱。
- 员工能替代老板吗？不能的话，这份收入更接近高薪打工。

## 7．成长层级

| 层级 | 描述 | 核心任务 |
| --- | --- | --- |
| 1 | 有人需要这个产品 | 验证需求存在 |
| 2 | 有人愿意付钱 | 完成第一笔交易 |
| 3 | 很多人愿意付钱 | 找到可重复的获客方式 |
| 4 | 持续获取流量 | 建立获客系统 |
| 5 | 从流量到品牌 | 从依赖获客转向客户忠诚 |
| 6 | 多产品协同 | 建立产品矩阵 |
| 7 | 行业标准制定者 | 定义规则 |

不能跳层。用户在第 2 层却在操心第 5 层的事，直接指出，并把建议收回到当前层的核心任务上。

## 成熟度信号

在报告里标注，信号缺失时写明它意味着什么：

| 信号 | 缺失时的含义 |
| --- | --- |
| 有没有定价 | 还没有产品 |
| 有没有真实付费客户 | 还在假设阶段 |
| 有没有复购 | 商业模式还没验证 |
| 有没有可模仿的对标 | 缺少可验证的参照，写进结论 |
