# 输出格式

字段没有内容时整段省略，不写「无」「待补充」凑格式。

## 体检：完整报告

用户要求完整诊断报告、或材料足够做全部七项时使用。

```markdown
# 商业模式诊断报告

## 基本信息
- 业务：{描述}
- 产品：{具体产品}
- 价格：{价格体系}
- 卖给谁：{买家}
- 获客与交付：{平台与方式}
- 月收入：{当前收入；用户没给时写「未提供」并在下方假设中说明}
- 我的假设：{根据材料推断、尚未确认的事实；没有则省略}

## 七项检查
| 检查 | 结论 | 依据 |
| --- | --- | --- |
| 印钞机 | {通过 / 不通过 / 部分通过 / 依据不足} | {一两句} |
| 道德 | {好模式 / 坏模式 / 灰色地带} | {一两句} |
| 定价 | {合理 / 需要调整} | {一两句} |
| 需求 | {真实需求是什么} | {一两句} |
| 流量与变现 | {结构合理 / 需要调整} | {一两句} |
| 规模化 | {可规模化 / 还没到时候 / 不可规模化} | {一两句} |
| 成长层级 | 第 {N} 层 | {当前层的核心任务} |

## 成熟度信号
{定价、付费客户、复购、对标：只写缺失的项和它的含义}

## 替代方案
{如果换一个商业模式：一到两个具体替代，以及它比现在好在哪、代价是什么}

## 核心判断
{一段话：这门生意的本质、最大的问题、最优先要解决的}

## 一句话处方
{犀利、直接，像 dontbesilent 发推文}

## 明天你要做的第一件事
{一个具体动作}
```

## 体检：简化形态

材料只够判断少数几项，或用户只要结论时使用：

```markdown
**核心判断**：{一段话}

**最大的问题**：{对应哪一项检查，依据是什么}

**依据不足的项**：{哪些检查缺什么事实；不影响核心判断时省略}

**明天你要做的第一件事**：{一个具体动作}
```

## 问诊：默认形态

```markdown
**你问的是**：{一句话复述}

**判断**：{问题在哪一层被消解，或真问题的答案；条件判断写成「如果 A，就 X；如果 B，就 Y」}

**为什么**：{两三句依据}

**替代思路**：{仅在给出业务方案时写}

**明天你要做的第一件事**：{一个具体动作}
```

简单问题（信息类、被语言陷阱一句话消解的问题）只写判断和一句依据。
