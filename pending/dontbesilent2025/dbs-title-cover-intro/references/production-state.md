# 生产状态与工作模式

文字标题、封面标题和视频开头共享同一个内容入口，但最终发布形式与生产状态会改变可以修改的范围。先使用当前对话判断；缺少的信息会改变交付时必须追问。

文件格式、材料标签和输入形态只能说明用户提供了什么。`#推文`、文章、Markdown、字幕或逐字稿等字样不能证明用户最终只发布文字，也不能证明视频尚未拍摄。最终用途和视频进度没有明确说明时，在普通聊天消息里列出 1～5 项并让用户手动回复数字；不调用弹框或表单工具，不声称已经弹出选项。

制作状态与角度开发是两条判断线：先明确当前可修改范围，再按主 Skill 选择快速扫描或深挖；角度产生后用状态筛选可兑现内容。深挖的各组先独立提出命题，再判断实现条件。只处理已拍视频的现有冷开场、未要求重做整条方向时，快捷路径优先。不要按不同状态增删深挖的组，也不要把「当前不方便拍」等同于「没有值得讲的方向」。已确定角度或只改措辞时无需重新运行 12 视角。

## Mode 1：还在整理素材，稿子没有形成

适用于只有素材、母题、事件、案例或模糊想法，稿件尚未形成、视频尚未拍摄的任务。

先挖掘值得讲的事实、经历、结果、冲突和受众处境，再形成入口简报。角度确定后写清目标受众、核心命题、可用锚点和最小补充材料；此时的文字标题、封面标题和开头属于生产假设，需要同时写清正文必须提供的证据、过程或解释。材料无法支持入口时，提出最小补充问题或建议暂缓生产。

## Mode 2：已经有稿子，视频还没拍

适用于已有草稿或完整文稿，视频尚未拍摄、文章仍可修改的任务。

通读内容，检查选定角度最有价值的信息是否真正进入正文。角度确定后，先交简短角度简报和必要的正文最小改动：哪些段落保留、前移、压缩或补充，以及需要什么事实或案例；再生成所需平台的文字标题、封面标题和可直接口播的开头，附接入正文的下一句。发现标题需要正文没有提供的信息时，优先建议修改可改的稿件；用户只允许改标题时收窄承诺。完整逐字稿只在用户明确要求整稿改写时交付。

## Mode 3：视频已经拍了，用户还愿意再拍一些内容

适用于视频已经拍过一版，用户还愿意重新拍几句话、旁白、镜头或证明材料的任务。

先给出仅使用现有素材的可行版本，再列出采用更强角度时最值得重新拍摄的少量内容。新增口播、旁白、字幕大字和现有原话必须分别标记，让用户知道哪些内容需要重新制作。若补拍事实尚未提供，增强版标题只能标为暂定。

## Mode 4：视频已经拍完，不方便再拍

适用于无法再拍、无法复现场景、只能使用现有视频、字幕或逐字稿的任务。

从现有原话和画面中选择、前移、删减和组合，两种标题只能承诺成片能够兑现的内容。角度扫描可能发现更广的命题，但缺案例、解释或画面的方向应单列为未来内容，不与当前成片的可用主线混排。找不到足够强的入口时，说明当前素材上限；不得用虚构成果、扩大因果或新写引语填补缺口。

## Mode 5：从已录好的较长内容中制作一条短视频

适用于课程、访谈、直播、会议或数十分钟以上的连续素材，其中可能存在多个可独立发布的内容。

先确定当前要剪出的一个具体切片或选题，再围绕同一个切片做主 Skill 选定的角度分析；形成原话结构、回接方式和入口简报，最后生成文字标题、封面标题与开头。用户已经给出明确切片时直接处理；不要让不同成员从互不相干的片段各取一句，再拼出原素材没有的连续论证。使用非连续片段时保留说话人、语义和声画连续性检查。

## 矩阵批量生产：可以叠加在其他情况上

矩阵生产可以叠加在 Mode 2 至 Mode 5 上。方向确定后，按用户要求批量生成不同平台、账号或素材版本，并保持事实口径稳定。批量版本需要有实际的信息顺序、受众或展示条件差异，不能依靠近义改写凑数量。

## 快捷路径

下列请求可以直接处理：

- 用户只改一句文字标题、封面标题或开头，并已给出完整上下文；
- 用户只要求从已拍素材中选择或重排冷开场，没有要求改变整条成片主线；
- 用户已经锁定方向，只要求压缩字数、调整口语或适配平台字段；
- 用户已经明确最终用途时跳过用途提问；是否需要角度开发仍按主 Skill 路由，纯文字本身不构成跳过角度开发的理由；
- 用户明确要求沿用现有角度，不接受上游重做。

快捷路径仍需遵守事实、兑现、素材来源和实际使用位置的限制。

## 怎样向用户确认情况

Mode 名称只供 Skill 内部判断。需要用户补充信息时，先用一两句话说明为什么要问，例如「同一段文字可以直接发，也可以拍成视频；拍没拍、能不能补拍，决定我能改多少。」再在普通聊天消息里给出连续编号的 1～5 项（措辞见主 Skill），结尾写「请直接回复数字」。选项本身已经说明各种情况，前面不再逐项展开解释。用户用文字说明时也应接受；不得要求用户点击弹框。

第 5 项向用户解释时直接说「已经录好一段较长的视频或音频，准备从中选一部分做短视频」，不使用「长素材」「切片」「剪出一条」等制作术语。

用户已经明确说明最终用途和制作进度时，直接进入对应处理方式，不重复解释和追问。
