# 用色决策

`aesthetics/default.json` 提供色值；本文件只决定何时使用。

| 色板 | 条件 | 数量 |
|---|---|---|
| Categorical | 类别无顺序 | 2–7 最佳；8–10 慎用；>10 合并或分面 |
| Sequential | 自然低到高 | 单色相用于普通强度；Viridis 用于精确、色盲、打印 |
| Diverging | 围绕 0/均值/目标双向变化 | 中性色严格对齐中点 |

禁忌：

- 红绿、蓝黄不得作为唯一区分。
- 禁用彩虹色板。
- 高饱和色 ≤3/图。
- 白底不用浅黄；小字不用蓝色。

语义：蓝=主数据/稳定；绿=增长/达标；红=下降/警告；橙=预警；灰=中性/其他；紫=特殊/高亮。

背景：浅色 `#FFFFFF` + 网格 `#E8E8E8`；深色 `#1A1A1A` + 网格 `#333333`。正文对比 ≥4.5:1；大字与数据元素 ≥3:1。
