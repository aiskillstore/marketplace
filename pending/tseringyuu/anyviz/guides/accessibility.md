# 无障碍

关键区分至少使用两种通道：颜色 + 形状/线型/标签/纹理/位置。

## 对比与色觉

| 内容 | 最低对比度 |
|---|---:|
| 正文 | 4.5:1 |
| 大字 | 3:1 |
| 数据元素、焦点、UI 边界 | 3:1 |

- `#888888` 白底约 3.5:1，只用于非关键脚注。
- 白底不用浅黄；<10px 小字不用蓝色。
- 红/绿涨跌加 ▲▼ 或 +/−；也可换蓝橙发散。
- Viridis 用于连续值与打印；最终检查灰度。

## 图表冗余编码

| 图表 | 第二编码 |
|---|---|
| 多折线 | dash + 终点直标 |
| 柱/堆叠 | 白描边 + 标签/纹理 |
| 饼/环 | 名称 + 百分比直标 |
| 分类散点 | 圆/三角/方/十字 |
| 热力 | 单元格值 + Viridis |
| 烛台/瀑布 | ▲▼、实虚边框、数值 |
| 等值地图 | 数值/清晰分级图例 + Viridis |
| 桑基/冲积/弦 | 完整标签 + Tooltip/数据表 |

形状优先：圆、三角、方、菱、十字、星。线型优先：实线、`6,3`、`3,3`、`1,2`、`6,3,1,3`。

## Alt text 与数据出口

每图提供：

1. 类型与主题。
2. 关键趋势、极值或结论。
3. 精确数据出口：HTML 表、CSV 或可访问列表。

禁用“图表”“图片”等空 alt。模板：

```
{chart_type} 图表，展示 {data_description}。X 轴：{x_axis_label}，Y 轴：{y_axis_label}。
```

## 交互

- 图形可聚焦；方向键浏览数据；Enter/空格触发。
- 焦点描边 ≥2px、对比 ≥3:1；触摸热区 ≥44×44px。
- Tooltip 同时支持 hover、焦点、点击。
- 状态除颜色外使用边框、图标、透明度或文字。
- 尊重 `prefers-reduced-motion`；提供静态版；禁止 >3 次/秒闪烁。
- Canvas 图必须提供等价 DOM/表格入口。

## 字号

- 关键标签 ≥9px；屏幕建议 ≥11px；移动端缩放后仍 ≥9px。
- 行高 ≥1.3；空间不足先减标签，不继续缩字。

## 检查

- 文本 ≥4.5:1；大字、数据、焦点 ≥3:1。
- 每个关键区分有第二编码；红绿语义有符号。
- Alt text 含类型、结论、数据出口；复杂图附表/CSV。
- 键盘路径完整；焦点可见；触摸目标 ≥44px。
- 动画可关闭；关键标签 ≥9px；灰度可辨。
