# 图表选择

先识别数据结构，再按意图选图；选定后读对应 `templates/` 文件。

## 选择矩阵

| 数据结构 | 意图 | 首选 | 备选/条件 |
|---|---|---|---|
| 1 数值 | 分布 | 直方图 | 密度、箱线 |
| 1 数值 | 组成 | 饼/环 | ≤5 类；否则华夫/柱状 |
| 类别 + 数值 | 精确比较 | 柱状 | 排名用横条；点图/棒棒糖 |
| 类别 + 数值 | 多系列 | 分组柱 | 系列多用小倍数 |
| 时间 + 数值 | 趋势 | 折线 | ≤3 系列可用面积 |
| 时间 + 数值 | 周期 | 折线 + 周期标记 | 日历热力 |
| 时间 + 数值 | 累计/组成 | 堆叠面积 | 瀑布 |
| 时间 + 数值 | 波动/OHLC | 折线/烛台 | 参考线、波动带 |
| 两数值 | 相关 | 散点 | 第 3 变量用气泡 |
| 两数值，大样本 | 分布+关系 | 六边形分箱 | 2D 密度/等高线 |
| 3+ 数值 | 多维对比 | 雷达 | ≤10 维；否则平行坐标 |
| 3+ 数值 | 概览/相关 | 热力/矩阵散点 | 降维后散点 |
| 类别×类别，值 | 交叉/相关 | 热力 | 分组柱、网络 |
| 地理区域，值 | 空间分布 | 等值区域 | 面量图 |
| 经纬度点，值 | 位置/规模 | 气泡地图 | 符号地图 |
| 地理起终点，值 | 流动 | 流向地图 | 弧线地图 |
| 层次，值 | 比例 | 树图 | 旭日 |
| 层次 | 结构 | 树形/冰柱 | 旭日 |
| 节点/边 | 网络 | 力导向 | 稠密时邻接矩阵/弧形 |
| 源/目标/流量 | 流量 | 桑基 | 时间流动用冲积；双向用弦图 |

## 上限与异常

- 普通图 ≤7 系列；饼/环 ≤5 扇区；面积 ≤3 系列，堆叠 ≤5；热力 ≤30×30；雷达 ≤10 维。
- `>10,000` 散点：六边形分箱或 2D 密度；长折线用 LTTB 降采样。
- 长尾：对数尺度或截断轴，并明确标注。
- 负值：双向柱、正负分区面积；禁用饼图。
- 缺失：折线断开或虚线跨越并标记；柱位留空或灰色标注。
