# 排版规则

以 `default.json` 为真值。保持角色层级、数字格式、标签可读性与跨平台字体一致。

## 基线

| 角色 | 字号/字重 | 用途 |
|---|---|---|
| H1 | 16px/600 | 主标题 |
| H2 | 13px/400 | 副标题 |
| H3 | 11px/400 | 轴标题 |
| H4 | 10px/400 | 刻度 |
| H5 | 10px/400 | 图例 |
| H6 | 9px/400 | 数据标签、脚注、来源 |

- 相邻层级差 1–2px；行高 1.3。
- 屏幕默认无衬线；印刷可用衬线；等宽字体只用于代码和数值表。
- 中文回退：`PingFang SC`、`Microsoft YaHei`、`Noto Sans CJK SC`。
- 标题水平；Y 轴标题优先水平；X 轴标签拥挤时旋转 30–45°；图例水平。

## 自然语言映射

| 指令 | 调整 |
|---|---|
| 字体大/小 | 全层级 ×1.15 / ×0.85 |
| 标题突出 | H1 +2px；字重 700 |
| 紧凑 | 行高 ×0.85；间距 ×0.8 |
| 正式/学术 | serif；全层级 +1px |
| 现代/科技 | sans-serif；字距 `-0.02em` |

## 数字

表格、仪表盘、轴刻度、数据标签使用等宽数字：

```css
/* CSS 示例 */
.data-label {
  font-variant-numeric: tabular-nums;  /* 或 font-feature-settings: "tnum"; */
}
```

- `≥1,000` 用逗号千分位。
- 默认数值/百分比 1 位小数；货币 2 位；计数 0 位；比率按需求 2–3 位。同类全图一致。
- 大数优先可读缩写，不用科学计数法：中文 `万/亿`；国际 `K/M/B`；保留 1–2 位小数。
- 单位、日期格式、小数位、分隔符跨图一致。

## 标签防重叠

按序处理，前项有效即停：

1. 旋转 X 轴标签 30°，必要时 45°；不超过 45°。
2. 抽稀刻度；保留首、中、末与至少 4–5 个主刻度。
3. 截断并加 `…`；约 15–20 个西文字符或 7–10 个汉字；Tooltip/表格给全称。
4. 自由标签 <50 个时用碰撞避让与引线；静态打印避免大量引线。
5. 直接标注 ≤5；5–10 混合；>10 用图例、交互或小倍数。

自由标签避让参考：

```javascript
// D3 示例（伪代码）
d3.forceSimulation(labels)
  .force("collide", d3.forceCollide(labelWidth/2 + padding))
  .force("x", d3.forceX(label.x))
  .force("y", d3.forceY(label.y))
```

| 图表 | 优先处理 |
|---|---|
| 柱状 | 旋转/抽稀；长标签改横条 |
| 折线 | 只标终点/异常点 |
| 散点 | 碰撞避让或只标异常点 |
| 饼/环 | 外置标签；仍拥挤则换图 |
| 面积 | 只标关键时点 |

## 字重与强调

- 最多 3 种字重：400 辅助、500 支持、600–700 焦点。
- 强调优先级：字重、颜色、字号、斜体。通常只用 1–2 种手段。
- KPI 可用 20px/700；标题与重点 600–700；轴、图例、脚注 400–500。
- 颜色已编码系列时，不再同时放大字号。

## 检查

- 角色规格、字体回退、数字格式一致。
- 标签无重叠、无裁切；完整文本可访问。
- 字重 ≤3；屏幕核心标签建议 ≥11px，任何关键标签 ≥9px。
- 打印后层级、灰度、对比仍清晰。
