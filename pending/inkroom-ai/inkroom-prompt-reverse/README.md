# InkRoom Prompt Reverse 1.0.8

Official MCP-only marketplace adaptation for image-to-prompt reconstruction. Use an already configured InkRoom MCP connection exposing `reverse_prompt`. This package contains no executable, no credential and no guest fallback.

- Website: https://inkroom.ai/
- Setup and actual prices: https://inkroom.ai/skill-server
- Existing MCP connection: https://inkroom.ai/mcp-server
- Official standalone installation: https://inkroom.ai/skills/INSTALL.md
- Standalone artifact manifest: https://inkroom.ai/skills/manifest.json

The standalone Skill and this MCP-only adaptation share the 1.0.8 functional baseline. Host adaptation is recorded separately from the app version and marketplace review status. The hosted service's current configuration controls availability. A directory entry or installed instruction file does not itself authorize paid calls or prove complete native-host acceptance.

Analysis requires the user's existing account and MCP Token. Preview supplies the actual per-image model and price; the administrator-configurable default is 2 credits per image. Chinese and English prompts belong to the same analysis. Optional recreation is a separately authorized image generation, not part of the analysis charge.

See SKILL.md for authorization, original-receipt recovery and unsettled outcomes. This is visual reconstruction, not extraction of an exact hidden original prompt.

The local LICENSE.md applies only to the new documentation adapter. It does not grant a license to InkRoom server/client code or brand assets.
