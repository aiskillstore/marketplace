# Логика показа и маршруты

**Собирает ветвление так, чтобы ни один респондент не упёрся в тупик**

| Навык | Версия | Инструментов | Скачать |
|---|---|---|---|
| `webask-quiz-logic` | 1.0.0 | 2 | [ZIP](https://github.com/WebAskio/webask-mcp/releases/download/skills-latest/webask-quiz-logic.zip) · [страница навыка](https://webask.io/skills/quiz-logic) |

## Что делает

1. **Сначала читает структуру.** Идентификаторы вопросов не угадываются. Запись логики поверх несуществующего вопроса даёт опрос, который просто не открывается.
2. **Строит нужный вид перехода.** Ветка по ответу, пропуск блока, отсев неподходящих на отдельный экран, квота на группу — под задачу, а не одним способом на всё.
3. **Знает, обо что спотыкаются.** «Другое» срабатывает по варианту, а не по вписанному тексту. «Больше» не работает на тексте. Порядок условий решает: сработает первое подошедшее.
4. **Проходит маршрут после правки.** От первого вопроса по каждой ветке до завершения. Если веток больше трёх-четырёх, ассистент опишет схему словами.

## Что на выходе

| Веток | Тупиков | Недостижимых | Возвратов назад |
|:-:|:-:|:-:|:-:|
| **4** | **0** | **0** | **0** |
| <sub></sub> | <sub>проверено по каждой</sub> | <sub></sub> | <sub>респондент не зациклится</sub> |

| | | |
|---|---|---|
| **Оценка ниже 4 → «Что было не так?»** | ветка по ответу · вопрос 2 | есть выход |
| **Оценка 4 и выше → пропуск вопроса 3** | пропуск блока | есть выход |
| **«Не пользовался услугой» → экран отсева** | screenout · вопрос 4 | завершение |
| **Набрано 200 ответов в группе → дальше не пускать** | квота | завершение |

> **Условие «Другое» работает по варианту, а не по тексту**  
> Частая ошибка: ждут, что переход сработает от слова, вписанного респондентом в поле «Другое». Он сработает от самого выбора этого варианта — текст в условии не участвует.

<sub>Переходы на схеме — пример. Логика собирается по вашим вопросам и их идентификаторам.</sub>

## Как попросить

> Если поставили оценку ниже четырёх — спроси почему

> Настрой пропуск блока для тех, кто не пользовался услугой

> Проверь логику опроса, нет ли там тупиков

|---|---|---|
