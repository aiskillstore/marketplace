# Хронология опроса

**Отвечает на «почему перестали приходить ответы», сопоставляя сбор с историей правок**

## Что делает

1. **Строит две линии.** Ответы по дням и снимки публикаций. По отдельности каждая мало что объясняет, вместе — почти всё.
2. **Ищет совпадения по датам.** Провал сразу после публикации — сломали правкой. Провал без правок — дело снаружи: закончилась рассылка, сняли баннер, прошло мероприятие.
3. **Проверяет очевидное отдельно.** Резкий провал до нуля — повод посмотреть, не сняли ли опрос с публикации: по ссылке он перестаёт открываться мгновенно.
4. **Не выдаёт совпадение за причину.** Если правка не могла повлиять на сбор, так и говорится. Придуманная связь хуже, чем честное «не нашли».
