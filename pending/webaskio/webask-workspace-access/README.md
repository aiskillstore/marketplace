# Участники и доступы

**Разбирается, почему участник не видит опросы, и выдаёт ровно те права, что нужны**

## Что делает

1. **Сначала показывает, как есть.** Кто в аккаунте, с какой ролью и что конкретно видит. «Дай Пете доступ» без этой картины обычно заканчивается лишними правами у Пети.
2. **Знает две главные причины «он не видит».** Приглашение не принято — человек в списке есть, доступа нет. Или роль дана, но папки не открыты, и список опросов у него пустой.
3. **Спрашивает про задачу, а не про роль.** Смотреть результаты, собирать опросы, настраивать интеграции — разные наборы прав. Полный доступ нужен только тем, кто администрирует аккаунт.
4. **Не отзывает доступ по своей инициативе.** Исключение участника обратно не откатывается — только новым приглашением. Поэтому только по явной просьбе.

> **Обе жалобы «я его добавил, а он не видит» — отсюда**  
> У Петра непринятое приглашение: нужно повторить его. У Марии роль есть, но папки не открыты — она заходит и видит пустой список. Ни то ни другое не похоже на ошибку системы.

## Как попросить

> Добавь коллегу с доступом только к результатам

> Почему участник не видит опросы

> Покажи, у кого какие права в аккаунте

## Какие инструменты вызывает

| Инструмент | Что делает | Тип |
|---|---|---|
| `delete_workspace_role` | Удаление роли участника | необратимо |
| `get_folder_list` | Список папок | чтение |
| `get_workspace_list` | Список аккаунтов | чтение |
| `get_workspace_member_access` | Доступы участника | чтение |
| `get_workspace_members` | Участники аккаунта | чтение |
| `get_workspace_roles` | Роли участников | чтение |
| `invite_workspace_member` | Приглашение участника | запись |
| `manage_folder_access` | Доступ участников к папке | необратимо |
| `remove_workspace_member` | Исключение участника | необратимо |
| `resend_workspace_member_invite` | Повторное приглашение участника | запись |
| `save_workspace_role` | Роль участника | запись |
| `set_workspace_member_folders` | Папки, доступные участнику | запись |
| `set_workspace_member_role` | Смена роли участника | запись |
