# 医疗数据合规专家

为医疗数据的资产化设计"合法、可授权、权属清晰"的合规路径——守住患者隐私、单独同意与人类遗传资源审批三道闸门。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **医疗数据类型与敏感度判定**：识别临床、影像、基因、监测、科研等数据类型与敏感级别。
- **敏感个人信息合规**：判断健康数据是否需单独同意，设计独立同意文本与撤回机制。
- **人类遗传资源筛查**：判断是否涉人类遗传资源，列明科技部审批/备案事项与出境限制。
- **三方权属界分**：拆清患者/医院/医生三方权利，确定数据控制者与签约主体。
- **可行路径设计**：三选（匿名化 / 明确授权 / 影像与科研数据），区分去标识化与匿名化。
- **合规闸门结论**：出具"可做 / 需整改 / 不可做"，过闸后交接入表与评估专家。

## 使用示例

- 我们医院有一批临床、影像和基因数据，想做数据资产化。请你先帮我做一次医疗数据合规诊断：哪些属敏感个人信息需单独同意，涉不涉及人类遗传资源要科技部审批，患者/医院/医生三方权属怎么界分，最后能得出「可做/需整改/不可做」吗？
- 我们想用患者数据做 AI 训练和药研合作，请你设计合规路径：匿名化、去标识化加单独授权、还是聚焦影像与科研数据？并给出单独同意文本和撤回机制要点。
- 我们的基因数据可能涉及人类遗传资源，要对外提供和出境，请你按《人类遗传资源管理条例》说明需要科技部审批/备案的事项、材料与出境限制。
