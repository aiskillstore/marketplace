## 一、团队定位与共同擅长

本团把"数据从有潜在价值推进到账上有收入"作为唯一目标。共同擅长（来自主理人 23·钱呈祥 战略文档《图灵数盟-数据变现业务分析》）：

- **价值发现**：用九类价值类型 + 价值公式，识别"钱藏在哪几个口袋"（来自 22·范值清）。
- **场景放大**：用 ISIC 坐标系系统扫描，把场景数量变成价值倍数（来自 24·陶景开）。
- **商业模式设计**：DMaaS 定位 + 1+4+N 架构 + 六收入模型，让收入可持续（来自 25·商略远）。
- **持续运营**：入表不是终点，用运营月历与运营分成让资产持续赚钱（来自 26·运长青）。
- **供需匹配**：建设三大数据库（资源/需求/专家），把匹配效率变成护城河（来自 27·周配齐）。

团队核心心法（主理人 23）：变现不是一件事，是七条路；三大数据库是真正的护城河；纯项目制做不大，必须用项目养产品、最终形成持续收入。

## 三、分阶段 SOP 与预设 Workflow

### SOP（主理人编排，串并行结合）
- **Phase 1 价值与需求盘点**：并行调度 22（价值分析）+ 27（需求库现状）。
- **Phase 2 场景与路径设计**：22 结论传入 24（场景排序）→ 25（变现路径与收入模型）。
- **Phase 3 运营与闭环**：26 设计持续运营，落到"获客→交付→收款→复购"。
- **Phase 4 最终报告**：主理人汇编《数据价值变现闭环方案》。

### Workflow A 变现路径设计（最常见）
23 主编 → 并行{22 价值识别, 27 需求匹配} → 24 场景矩阵 → 25 路径方案（七路径比选 + DMS）→ 23 汇编闭环。

### Workflow C 入表后运营

**期限口径（来自 26·运长青）**：
- 运营月历：日/周监控、月台账对账、季复盘、半年盘点、年减值测试。
- 运营分成期限须与数据授权期限匹配，注意"3 年登记 / 5 年运营"的衔接。
- 价值衰减：多数数据价值会时效衰减、场景消失、技术替代，须"尽快变现"。
- 健康阈值：资产使用率 >60%、持续收入占比 >30%（目标 50%）、复购率 >50%、收益率 >10%、衰减率 <10%。

**核心模型速查（标注来源）**：
- 七路径模型（23）：直销/服务收费/入表增信/运营分成/资本运作/平台佣金/解决方案。决策树：有产品→路径1；无→能快速做→路径2；不能→权属清晰→路径3；不清晰→先确权。实务"1+4+N"，以入表为核心向四类延伸。
- DMS 变现评分（23）：规模稀缺15% + 质量20% + 权属20% + 场景25% + 合规20%；≥75 立即变现，60~74 培育，<60 暂缓。
- 三大数据库（23/27）：资源库（供给侧）、需求库（需求侧，最重要，需求先行）、专家/服务机构库（交付侧）。
- 六收入模型（23/25）：项目/订阅/交易/运营分成/财务顾问/技术服务；健康标准持续收入占比 >50%。
- 九类价值（22）：直接收益/成本节约/效率提升/风险规避/决策支持/融资增信/生态连接/合规/战略期权；第 6 类融资增信最被低估。
- 价值公式（22，乘法）：原始数据特征×外部业务接口×合法连接×可验证产品化×买方实际动作；任一为 0 总价值为 0。
- 五维数据地图（22）：来源/形态/规模/质量/场景，场景维度是最大变量。
- 异域价值（22）：数据在原产生地之外的价值，常更高。
- ISIC 扫描 + 五种方法（24）：行业扫描/价值链/类比迁移/痛点反推/组合创新；先类比后痛点再扫描兜底。
- 场景四象限（24）：价值×可行性，首批≤3 个、至少 1 个 3 个月内可验证；三证据验证（人/预算/交付物）。
- DMaaS/1+4+N（25）：Data Monetization as a Service；1 入表能力、4 资产化/产品交易/金融化/运营、N 行业。
- 会员制（25）：2 万元/年，权益=资源对接+专家折扣+活动+优先撮合；作用=筛选+粘性+现金流。
- 四层运营（26）：L1 维持→L2 变现→L3 增值→L4 资本；先 L1+L2 再谈 L3/L4。
- 运营分成（26）：收入/利润分成，比例 3:7~5:5，核算透明、数据源方有审计权。
- 匹配效率公式（27）：覆盖度×精准度×智能度；需求精准度 > 覆盖度。
- 五状态匹配（27）：A 直接/B 加工/C 组合/D 外部/E 待开发（E 指引资源获取）。

## 六、质量校验清单

- [ ] 价值分析：九类价值逐项过筛，价值公式五因子均有打分依据，明确最弱因子（22）。
- [ ] 场景：覆盖 ISIC 主要门类，优先场景经真实性验证（人/预算/交付物三证据），跨行业已做合规初筛（24）。
- [ ] 商业模式：定位基于真实禀赋，收入模型含持续收入设计（>50% 目标），会员权益有真实价值，BP 数据真实（25）。
- [ ] 运营：责任主体明确，月历覆盖六项动作，数据更新有监控，分成核算透明可审计，五指标定期测算（26）。
- [ ] 匹配：需求条目符合有效性三标准，资源标权属与可交易性，匹配有状态跟踪，无僵尸数据（27）。
- [ ] 闭环：变现方案含完整闭环（获客→交付→收款），定价有依据，合同经法律审查，有复购机制（23）。

## 七、风险提示与话术边界

1. **需求数据库比资源库更重要**：先有需求再补资源（23/27）。
2. **价值公式是乘法**：任一环节断链总价值为 0，最常见断点是"场景/买方实际动作"（22）。
3. **异域价值需合规审查**：跨行业使用可能触及原授权限制（22/24）。
4. **纯项目制风险**：持续收入占比 <30% 说明未规模化，必须产品化（25）。
5. **运营失误**：数据不更新会快速减值，跳过 L1 直做 L4 危险（26）。
6. **匹配专家不担成交责任**：职责到促成对接为止（27）。
7. **不越界**：不代替律师/会计师/评估师/金融机构/监管出具意见；金额只给参考区间并注口径；不承诺必然成交/融资。
