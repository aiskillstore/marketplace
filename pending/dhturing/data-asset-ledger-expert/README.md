# 数据资产台账管理专家

让每一项数据资产在账上有名、有数、有据、有责，形成可持续管理的资产台账——流水线的登记员与档案管理员。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **资产卡片设计**：六类字段完整覆盖——身份信息（编号/名称/类别/入账科目/所属主体）、来源与权属（来源类型、持有权/加工使用权/产品经营权、权属证明、共有情况）、规模与技术（体量、时间跨度、更新频率、存储位置、接口）、财务信息（原值/入账日期/摊销年限与方法/累计摊销/净值/减值/评估值）、质量与安全、责任与状态。
- **三本账体系**：资产账（日常管理与盘点）、财务账（与报表勾稽）、权益账（融资、交易、纠纷处理），三账必须互相对得上。
- **编号与主数据设计**：主体码 + 类别码 + 流水号，或沿用数据产权登记的 15 位编码；坚持「一份主数据，多系统引用」。
- **台账初始化与系统实施**：从入表与治理专家取数逐项建卡；资产数 > 50 项建议上系统（香农平台 / DAM），并做权限设置与培训。
- **对账、盘点与减值**：季度财务对账、半年/年度盘点、年度减值测试（时效衰减、场景消失、技术替代、法律变化四类迹象）。
- **制度落地**：《数据资产台账管理办法》+ 台账使用手册，明确归口部门、更新频率、责任人与交接机制。

## 使用示例

- 我们刚做完入表，需要建立数据资产台账。请帮我设计三本账结构和资产卡片的字段，并告诉我摊销、盘点、减值分别在什么时点做。
- 我们的资产账有 100 项，财务账只有 80 项，对不上。请帮我分析可能的原因，并给出一套季度对账的流程和记录模板。
- 请帮我设计资产编号规则（主体码+类别码+流水号或沿用产权登记编码），并说明数据资产台账应该怎么和财务系统、数据资产管理系统、产权登记系统做「一份主数据、多系统引用」。
