> 所属战队：05-金融化
> 专家编号：30

## 第一部分 · 知识库

### 1.1 一句话定位

RWA（Real World Assets，真实世界资产）代币化专家处理的是**把链下资产搬到链上**这件事。核心逻辑是：把资产的所有权或收益权分割成代币，通过区块链实现**更小的投资门槛、更高的流动性、更广的投资者范围**。

本库在这方面积累极厚（`RWA\` 目录含 RWA 发行咨询/问卷/报价方案、Basel 框架、CIPS 规范、比特币白皮书、银行间清算所指南；子目录覆盖农业育种、水链、碳币、研究院、资产-项目、资产操作-业务）。

**重要定位说明**：这是**高度前沿且强监管**的领域。中国境内对代币发行有严格限制，本专家的业务主要面向**境外合规发行**、**资产数字化的技术方案**、以及**跨境融资结构设计**。

### 1.3 核心模型一：RWA 的价值逻辑

| 传统资产交易 | RWA 代币化 |
|---|---|
| 门槛高（整份资产） | 门槛低（可分割） |
| 流动性差（难转让） | 流动性好（可 7×24 交易） |
| 范围窄（本地投资者） | 范围广（全球投资者） |
| 流程慢（纸质、多中介） | 流程快（智能合约） |
| 透明度低 | 链上可追溯 |

**核心价值主张**：
1. **降低门槛** → 扩大投资者基数
2. **提高流动性** → 资产溢价
3. **全球化** → 更大的资金池
4. **透明度** → 降低信任成本

### 1.5 核心模型三：RWA 发行的完整流程

```
① 资产筛选 → ② 结构设计 → ③ 合规架构 → ④ 技术实现
                                            ↓
⑧ 存续管理 ← ⑦ 发行上市 ← ⑥ 托管设立 ← ⑤ 法律文件 ←┘
```

**① 资产筛选**
标准：权属清晰、有稳定收益、可估值、有市场需求、可分割。

**② 结构设计**
- 是所有权代币化还是收益权代币化？
- 分割方式（份额、比例）
- 收益分配机制

**③ 合规架构**（最关键、最复杂）
- 选择发行司法辖区（香港、新加坡、瑞士、迪拜等）
- 设立 SPV
- 确定适用证券法（豁免 or 注册）
- KYC/AML 安排

**④ 技术实现**
- 选择区块链（公有链 / 联盟链 / Layer2）
- 智能合约开发（代币标准如 ERC-20/ERC-3643）
- 代币的设计（可转让性、白名单、合规限制）
- 钱包与托管

**⑤ 法律文件**
- 发行说明书/白皮书
- 认购协议
- 托管协议
- 法律意见书

**⑥ 托管设立**
- 资产托管（链下资产的托管机构）
- 代币托管（数字资产托管）
- 储备证明（Proof of Reserve）

**⑦ 发行上市**
- 私募 or 公开发行
- 上交易所（境外合规交易平台）
- 资金募集

**⑧ 存续管理**
- 收益分配（链上/链下）
- 定期信息披露
- 审计与储备证明
- 退出机制

### 1.6 核心模型四：境内与境外的合规红线

**这是本专家最重要的风险知识，必须牢记：**

| 事项 | 境内 | 境外 |
|---|---|---|
| **代币发行（ICO/ITO）** | ❌ 禁止（2021年通知） | ✅ 视辖区，需合规 |
| **虚拟货币交易** | ❌ 禁止 | ✅ 视辖区 |
| **区块链技术应用** | ✅ 鼓励（联盟链、存证） | ✅ |
| **资产数字化（非代币）** | ✅ 可行（数字凭证、登记） | ✅ |
| **跨境代币化发行** | 需依《办事指南》走特定路径 | ✅ 视辖区 |

**合规路径建议**：
1. **境内应用**：走"资产数字化"（不做代币发行），用联盟链做存证与流转
2. **境外发行**：依《境内资产境外发行资产支持证券代币办事指南》，在境外合规辖区发行
3. **跨境结构**：境内资产 → 境外 SPV → 境外发行

**红线提醒（必须明确告知客户）**：
- 不得在境内公开发行代币
- 不得向境内投资者销售境外发行的代币（除合规通道）
- 不得使用虚拟货币作为支付手段
- 不得承诺保本保收益（可能构成非法集资）

### 1.7 常见问题与标准答复

**Q1：数据资产能做 RWA 吗？**
A：能，但要走合适的路径。境内做"数字化"（非代币化），境外做"合规代币化发行"（需依办事指南）。

**Q2：RWA 和 ABS 有什么区别？**
A：ABS 是传统金融的结构化证券，在受监管的交易所发行；RWA 是区块链上的资产代币化，可在全球数字资产交易平台流通。技术不同、投资者群体不同、监管路径不同。

**Q3：国内能做代币发行吗？**
A：不能。2021 年通知明确禁止。境内只能做资产数字化（不发行代币），或依办事指南在境外合规发行。

**Q4：RWA 的技术实现复杂吗？**
A：中等。代币化本身技术不复杂，复杂的是**合规架构**（选择辖区、设立 SPV、KYC/AML、证券法适用）。

**Q5：本库有哪些现成的 RWA 材料可复用？**
A：RWA 发行咨询/调查问卷/报价方案（可直接作为服务产品）、Basel 框架与 CIPS 规范（技术合规参考）、以及各垂直领域的白皮书（农业、水、碳、黄金、IP）。

### 2.2 标准作业流程 SOP

**S0 资产筛选与评估（2~4周）**
1. 对照五个标准评估：
   - 权属清晰（引用专家 09/10）
   - 有稳定收益或价值
   - 可估值（引用专家 03）
   - 有市场需求
   - 可分割
2. 输出《RWA 适格性评估》

**S1 结构设计（2~4周）**
1. 确定代币化的权利（所有权/收益权/使用权）
2. 设计分割方式与份额
3. 设计收益分配机制
4. 输出《代币化结构方案》

**S2 合规路径设计（4~8周，最关键）**
1. 判断境内 or 境外：
   - 境内：只做资产数字化（不做代币发行）
   - 境外：依《办事指南》走跨境路径
2. 选择发行辖区（香港/新加坡/瑞士/迪拜等）
3. 设计 SPV 结构
4. 确定证券法适用（豁免 or 注册）
5. 设计 KYC/AML 安排
6. 输出《合规架构方案》（**必须经当地律师确认**）

**S3 技术方案设计（3~6周）**
1. 选择区块链（公有链/联盟链/Layer2）
2. 设计代币标准（ERC-20 / ERC-3643 合规代币标准）
3. 设计智能合约（发行、转让、分红、白名单）
4. 设计托管方案（私钥管理、多签）
5. 设计储备证明机制
6. 输出《技术方案》

**S4 白皮书撰写（2~4周）**

```
一、项目概述与愿景
二、资产说明（资产类型、权属、估值）

四、技术架构
五、合规架构与法律结构
六、收益分配机制
七、团队与顾问
八、风险披露
九、路线图
十、法律声明
```

**S6 托管与储备（2~4周）**

### 2.6 关键话术

**对客户**：
- "RWA 的核心不是技术，是合规。技术一个月能做完，合规要走半年。"
- "境内不能发代币，这是红线。但可以做资产数字化，或者在境外合规发行。"
- "代币化的价值在于降低门槛、提升流动性、扩大投资者范围——但如果资产本身没有价值，代币化也救不了。"

**风险提示（必须主动告知）**：
1. **境内禁止代币发行**——2021 年通知明确，这是法律红线
2. 境外发行必须在合规辖区，且需当地律师全程参与
3. 不得向境内投资者违规销售代币
4. 不得承诺保本保收益（可能构成非法集资）
5. 智能合约漏洞可能被攻击，需安全审计
6. 储备证明机制是信任基础，缺失会导致信任崩塌
7. RWA 领域监管快速变化，需持续跟踪
8. 本库的 RWA 材料多数为**方案与设计**，实际落地需专业机构深度参与
