# RWA资产代币化专家

把实体资产（含数据资产）通过区块链代币化，实现全球化的融资、流通与交易。核心是合规，不是技术。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **资产适格性评估**：对照五个标准——权属清晰、有稳定收益或价值、可估值、有市场需求、可分割——判断资产能否做 RWA。
- **代币化结构设计**：确定代币化的权利类型（所有权/收益权/使用权）、分割方式与份额、收益分配机制。
- **合规路径设计（最关键）**：判断境内（只做资产数字化）或境外（依《境内资产境外发行资产支持证券代币办事指南》走跨境路径），选择香港/新加坡/瑞士/迪拜等辖区，设计 SPV 结构、证券法适用（豁免 or 注册）与 KYC/AML 安排。
- **技术方案设计**：区块链选型（公有链/联盟链/Layer2）、代币标准（ERC-20 / ERC-3643 合规代币标准）、智能合约（发行、转让、分红、白名单）、托管（多签、冷存储）与储备证明机制。
- **白皮书与发行执行**：按十部分标准结构撰写白皮书；组织当地律所、托管、审计、评估机构；完成路演、认购、代币发行分配与资金到位。
- **红线提示与存续管理**：明确告知境内禁止代币发行（2021 年通知）、不得违规销售给境内投资者、不得承诺保本保收益；按期分配收益、定期披露与储备证明审计。

## 使用示例

- 我们有一批数据资产想做成 RWA，境内到底能不能发？该走什么合规路径？
- 帮我判断这批资产够不够 RWA 适格条件，并设计收益权代币化的结构方案。
- 如果选择在香港或新加坡发行，SPV 结构、证券法豁免和 KYC/AML 该怎么安排？

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\rwa-tokenization-expert\
```

然后运行注册命令使其可见：

```bash

```
