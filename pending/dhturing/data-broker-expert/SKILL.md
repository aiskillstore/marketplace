## 内容索引

- **1.1 一句话定位**：中间人角色，知道谁有数据、谁需要数据，并让双方信任地成交；收入来自撮合佣金、服务费与保荐溢价
- **1.2 政策与标准依据**：国数政策〔2026〕6号（核心依据）、数据二十条（2022-12）、各交易所数据商/经纪制度、深数所数据商认证材料、深数所保荐函、《数据产品交易标准化白皮书》（2022）、《数据安全法》《个人信息保护法》
- **1.3 核心模型一**：数据经纪人三种角色（撮合型/代理型/保荐担保型）与收入、责任对照
- **1.4 核心模型二**：数商服务矩阵十类服务与收费模式（含入表服务 20-60 万）
- **1.5 核心模型三**：撮合五步法（需求捕获→资源匹配→双向验证→促成交易→履约跟进）各步要点
- **1.6 核心模型四**：经纪人价值公式 = 信息不对称程度 × 信任缺失程度 × 交易复杂度
- **1.7 常见问题与标准答复**：Q1 经纪人与中介的区别 / Q2 佣金区间（1%~10%）/ Q3 对合规性负责吗 / Q4 没有数据能否做数据生意 / Q5 客户跳单怎么办
- **1.8 源材料索引**：培育数据流通服务机构意见、深数所数据商认证材料、深数所保荐函、福建数商证书、商业模式设计、市场合作伙伴计划、会员费 2 万/年模式
- **2.1 能力清单**：C1-C9（需求捕获与管理、资源池建设、双向验证、撮合促成、保荐服务、交易结构建议、居间协议设计、生态网络维护、复购与延伸）
- **2.2 SOP**：S0 经纪定位 / S1 资源池建设 / S2 资质取得 / S3 需求捕获 / S4 匹配与验证 / S5 撮合谈判 / S6 保荐服务 / S7 促成签约与交付 / S8 履约跟进 / S9 生态维护
- **2.3 交付物**：12 项（经纪业务定位说明、数据资源池、需求清单、数商认证/保荐资格、双向验证报告、撮合方案、居间协议、保荐函、成交记录、佣金结算单、客户档案、合作伙伴名录）
- **2.4 质量校验**：10 条勾选项（含未越界成为实质交易主体）
