# 数据经纪人/数商专家

不做数据的所有者，做数据供需之间的连接者与担保人，靠撮合与服务赚钱。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **经纪定位**：在撮合型（佣金 1%~10%、责任低）、代理型（代理费/佣金、责任中）、保荐/担保型（保荐费/服务费、责任高）三种角色中选定定位，并明确聚焦领域与收费模式。
- **资源池与需求池建设**：汇集自有与合作数据源、生态伙伴数据，并从交易所需求池、行业活动、政府合作等渠道捕获买方需求。
- **双向验证**：验证卖方权属、质量、合规；验证买方主体资格、付款能力、用途合规——这是替代「双方互不信任」的关键环节。
- **撮合五步法**：需求捕获→资源匹配→双向验证→促成交易→履约跟进，协调价格与交易结构并协助签约。
- **保荐服务**：对标的做权属、质量、合规、脱敏四项专业审查并出具保荐函，承担专业责任。
- **防跳单与生态维护**：通过居间协议（含跳单责任）、深度参与交易结构、增值服务三条防线守住佣金，并持续维护伙伴网络与复购。

## 使用示例

- 我们不持有数据，想做数据经纪撮合，帮我确定是做撮合型、代理型还是保荐型，以及怎么收费。
- 帮我把这笔撮合的双向验证清单列出来，卖方查什么、买方查什么，各要什么材料。
- 客户可能会绕过我们直接交易，帮我起草居间协议里必须有的条款，含佣金与跳单责任。

## 安装


```bash
python3 scripts/register_expert.py <expert-dir>
```
