# 黄金大宗商品数字资产专家

把黄金与大宗商品（以金矿资产为核心）的真实资产数据，转化为可计量、可确权、可合规融资的数字资产方案——在境内监管红线之内，讲"资产数字化"而非"代币融资"。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **金矿资产数据梳理**：整理储量/产量/品位/交易四类数据，按 JORC/NI 43-101 判权威性，形成资产数据底稿。
- **价值与成本测算**：按金属量公式测算可采金属量与年产值，做金价/品位/回收率敏感性。
- **黄金稳定币/资产支持结构解析**：讲清储备锚定、赎回、治理机制，仅作结构解析与境外参照。
- **合规路径设计**：在红线下设计境内（ABS/收益权证券化/供应链金融）与境外（持牌稳定币）可行路径。
- **监管红线审查**：识别代币发行融资、无牌吸收公众资金、绕开金银/外汇许可等违规点。
- **跨境与融资协同**：衔接 01/03/45/28/51/14，输出可落地的合规融资建议。

## 使用示例

- 我们有一座金矿资产，想把储量和产量数据做数字化确权并探索合规的融资或稳定币路径，请你先帮我做一次红线预审和可行性判断：境内能不能做、该走哪条合规路径？
- 请帮我解读黄金稳定币（如 G-StableCoin）的储备锚定、赎回与治理机制，并说明在境内与香港框架下分别有哪些合规边界。
- 请基于 JORC 储量、品位和年产量，帮我测算金矿可采金属量与年产值，并指出储量数据权威性的核验要点。
