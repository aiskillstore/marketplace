# 数据产品定价专家

> 所属战队：03-流通与交易
> 专家编号：18
> 核心使命：让数据产品的价格既卖得出去、又不贱卖资产，且能在谈判桌上守得住

---

## 第一部分 · 知识库

### 1.1 一句话定位

数据产品定价专家解决一个看似简单实则极难的问题：**这份数据产品该卖多少钱？**

难点在于数据产品有三个"反常识"特征：
1. **边际成本趋近于零**——多卖一份几乎不增加成本，所以成本定价法会严重低估
2. **价值高度依赖买方场景**——同一份数据给不同买方价值差异可达 100 倍
3. **无活跃可比市场**——找不到"隔壁同类数据卖多少钱"的参考

所以定价必须**复合使用多种方法**，并且把定价当作**谈判工具**而非精确计算。

### 1.3 核心模型一：定价三法

**方法一 · 成本定价法（底线）**

```
价格 ≥ 数据成本 + 合理利润
```

- 成本 = 采集 + 加工 + 维护 + 机会成本
- 利润 = 行业平均利润率
- **作用**：确定价格下限，防止亏本
- **局限**：数据边际成本低，成本定价会低估价值

**方法二 · 价值定价法（天花板）**

```
价格 = 买方获得的价值 × 分成率
```

买方价值包括：
- **收入增量**：用了这个数据能多赚多少
- **成本节约**：能省多少
- **风险降低**：能减少多少损失
- **效率提升**：能节省多少时间

分成率通常 5%~30%（视数据关键程度），复杂场景可用"价值阶梯"（递减分成）。

- **作用**：确定价格上限
- **局限**：买方价值难量化，且买方会低估

**方法三 · 市场定价法（参考）**

```
价格 = 可比产品价格 × 修正系数
```

- 修正维度：数据规模、覆盖度、质量、稀缺性、时效性
- **作用**：市场验证
- **局限**：可比案例少，尤其新品类

**三法使用规则：**
```
成本定价 = 价格底线
价值定价 = 价格上限
市场定价 = 校准参考

最终价格落在 [底线, 上限] 区间内，
通过市场参考与谈判确定具体点位。
```

### 1.4 核心模型二：价值量化四法

价值定价的难点是量化买方价值。四种实用方法：

| 方法 | 做法 | 适用 |
|---|---|---|
| **替代成本法** | 买方自己搞这份数据要花多少钱 | 买方有自建能力的场景 |
| **收益增量法** | 用数据后收入增加多少 | 营销、销售类数据 |
| **成本节约法** | 用数据后成本降低多少 | 风控、运营类数据 |
| **损失规避法** | 不用数据可能损失多少 | 风控、合规类数据 |

**实务技巧**：跟买方一起算账——"您用我们的数据做精准营销，转化率从 2% 提到 3%，一年多赚 100 万，我们收 15 万，您净赚 85 万。"

这个算法让定价变成**价值分配**而非"要钱"，买方更容易接受。

### 1.5 核心模型三：定价结构设计

价格不只是一个数字，而是一套结构：

| 结构类型 | 设计 | 适用 |
|---|---|---|
| **一次性买断** | 固定总价 | 标准化数据集、一次性交付 |
| **按量计费** | 单价 × 调用量（阶梯价） | API 类、用量可测 |
| **订阅制** | 年费/月费 | 持续更新类 |
| **基础费 + 用量费** | 底价 + 超量加价 | 兼顾稳定性与弹性 |
| **许可费 + 分成** | 固定许可 + 收益分成 | 高价值深度合作 |
| **阶梯定价** | 用量越大单价越低 | 鼓励规模化使用 |

**阶梯定价示例：**

| 调用量 | 单价 |
|---|---|
| 0~10 万次 | 0.5 元/次 |
| 10~50 万次 | 0.35 元/次 |
| 50 万次以上 | 0.25 元/次 |

### 1.6 核心模型四：谈判空间设计

定价的最后一步是**设计谈判空间**，这一步决定了能不能谈成。

**关键概念：**

| 概念 | 含义 | 作用 |
|---|---|---|
| **锚点价** | 首次报价 | 设置谈判起点（通常高于目标价 20%~40%） |
| **目标价** | 期望成交价 | 理想结果 |
| **底线价** | 最低可接受价 | 不可突破 |
| **让步策略** | 分步让步计划 | 引导成交 |

**谈判技巧：**
1. **先谈价值再谈价格**——让买方认可价值后再报数
2. **非价格让步优先**——用交付周期、数据范围、服务支持等换价格空间
3. **捆绑销售**——单产品价高，组合更易接受
4. **阶梯引入**——首期优惠建立关系，后续正常定价
5. **守住底线**——低于成本价成交会破坏市场价格体系

### 1.7 常见问题与标准答复

**Q1：我们的数据值多少钱？**
A：这个问题没法一句话答。需要先明确：卖给谁、用来干什么、能带来多少价值。**定价的前提是场景明确**。

**Q2：为什么同样的数据，卖 A 客户 10 万，卖 B 客户 50 万？**
A：因为价值不同。B 客户用它能多赚更多，或者 A 客户是长期合作价。这在数据交易中是正常且合理的——**差异化定价**是数据产品的特性（边际成本低）。

**Q3：客户嫌贵怎么办？**
A：不要急着降价。先问："您觉得贵在哪里？"常见回答是"不确定有没有用"。这时应提供**小规模试用**或**按效果付费**方案，把风险转移。

**Q4：定价太高卖不掉，太低又亏，怎么找平衡？**
A：从目标客户数量反推。如果是独家数据且客户少，高价；如果是大众化数据，低价走量。

**Q5：价格能随便改吗？**
A：对新客户可以调整；对已成交客户随意改价会损害信任。建议设置价格有效期（如 6 个月~1 年）。

### 2.2 标准作业流程 SOP

**S0 定价准备（3~5天）**
1. 明确定价对象（产品、服务、组合）
2. 明确定价目的（快速占领/利润最大化/建立关系）
3. 明确目标客户群
4. 输出《定价策略说明》

**S1 成本测算（1周）**
1. 归集成本：数据成本（引用专家06）、运营成本、销售成本
2. 加目标利润率
3. 得出价格底线
4. 输出《成本测算表》

**S2 价值量化（1~2周，核心）**
1. 与买方或内部业务专家一起测算：
   - 用替代成本法？收益增量法？成本节约法？损失规避法？
2. 得出买方年度收益（这是价格上限的锚）
3. 设定合理分成率
4. 输出《价值量化报告》

**S3 市场比对（1周）**
1. 搜集同类产品价格（交易所、公开信息、行业渠道）
2. 逐项修正（规模、质量、范围）
3. 输出《市场比价表》

**S4 价格区间确定（3~5天）**
1. 整合三法：底线（成本）、上限（价值）、参考（市场）
2. 形成价格区间
3. 确定建议价格
4. 输出《价格区间分析》

**S5 定价结构设计（1周）**
1. 选择计价方式（一次性/按量/订阅/分成）
2. 设计阶梯与套餐
3. 设计优惠条件（首单折扣、年度预付折扣、多产品捆绑）
4. 输出《定价结构方案》

**S6 谈判方案设计（3~5天）**
1. 设定锚点价（高于目标价 20%~40%）
2. 设定目标价
3. 设定底线价
4. 设计让步阶梯（每次让步幅度递减）
5. 预备非价格让步项
6. 输出《谈判方案》

**S7 报价与谈判（执行）**
1. 正式报价（书面，含有效期）
2. 谈判（先价值后价格）
3. 记录谈判进展
4. 输出报价单与谈判纪要

**S8 成交与归档（1周）**
1. 确定成交价
2. 归档定价依据（对审计、融资、复购都有用）
3. 沉淀为定价案例库

**S9 价格复核（每 6~12 个月）**
1. 复核成本、市场、客户价值变化
2. 提出调价建议（对老客户有过渡期）
3. 输出调价建议

### 2.6 关键话术

**对内部（定价决策）**：
- "成本法给您底线，价值法给您上限，市场法给您校准。三者定区间，谈判定点位。"
- "数据边际成本近乎零，所以不能用成本加成了事。"

**对买方**：
- "我给您算笔账：这份数据帮您一年省 100 万，我们收 15 万，投资回报率 6 倍多。"
- "您可以先小规模试用，觉得有价值再扩大。"
- "这个价格在 3 个月内有效，之后会根据数据更新情况调整。"

**风险提示**：
1. 定价过低会拉低整个市场对数据资产的价值认知，也会被审计质疑资产减值
2. 定价过高会导致长期卖不出去，产品被清退
3. 差异化定价需注意合规（不得构成价格歧视违法情形）
4. 分成定价需建立可信的收益核算机制，否则易生争议
5. 价格有效期与调价机制必须提前约定
