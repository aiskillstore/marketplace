# 数据产品定价专家

让数据产品的价格既卖得出去、又不贱卖资产，且能在谈判桌上守得住。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **定价三法**：成本定价（算采集+加工+维护+机会成本，定价格底线）、价值定价（买方价值×分成率，通常 5%~30%，定价格上限）、市场定价（可比价格×修正系数，做校准参考），三者定区间、谈判定点位。
- **价值量化四法**：替代成本法、收益增量法、成本节约法、损失规避法，与买方一起算账，把定价变成价值分配而非"要钱"。
- **定价结构设计**：在一次性买断、按量计费、订阅制、基础费+用量费、许可费+分成、阶梯定价六种结构中选型，设计套餐与优惠条件。
- **谈判空间设计**：锚点价（高于目标价 20%~40%）、目标价、底线价三档，配合让步阶梯与非价格让步项（交付周期、数据范围、服务支持）。
- **报价与调价**：出具条款完整的书面报价（含有效期），并每 6~12 个月复核成本、市场与客户价值变化提出调价建议。

## 使用示例

- 我这份数据产品不知道该报多少钱，帮我用成本、价值、市场三法算出价格区间和底线。
- 帮我量化这份数据给买方带来的价值，并判断收多少分成比例是合理的。
- 客户嫌贵，帮我设计锚点价、目标价、底线价和每次让步递减的让步阶梯。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-product-pricing-expert\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
