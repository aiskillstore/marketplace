# ABS现金流建模专家

> 所属战队：08-细分方向（原附录·可细分方向，从 29 拆出）
> 专家编号：45
> 核心使命：把数据资产未来产生的现金流，量化成可验证、可承压、可定价的证券化模型——让"有没有钱、够不够还、崩不崩得住"有数可查

## 第一部分 · 知识库

### 1.1 一句话定位

ABS（资产支持证券）的本质不是"卖资产"，而是"卖资产未来产生的现金流"。本专家是 29 号（数据资产 ABS/REITs 专家）拆出的**建模与压力测试专项**，只做一件事做到底：把基础资产的现金流，从原始收入数据，一步步算成覆盖证券本息的**覆盖率、覆盖倍数、压力情景与敏感性结论**，并给出优先/劣后分层与超额覆盖的**量化配比**。

发行申报、交易谈判、监管沟通归 29 号；本专家交付的是发行前最硬的那张"算账底稿"——没有它，任何证券化方案都是空中楼阁。

### 1.3 核心模型一：基础资产现金流归集与可归集性判定

现金流建模的第一步不是算数，是**确认这笔钱能不能被算**。很多数据资产"有收入"但"归集不了"，根本原因是收入与基础资产之间没有清晰的映射关系。

**可归集性四问（任一不过即不具备建模前提）：**

| 判定项 | 通过标准 | 不过的后果 |
|---|---|---|
| 收入可识别 | 单笔数据产品/服务收入能对应到具体基础资产 | 无法真实出售，破产隔离失效 |
| 收入可计量 | 有系统台账/合同/账单，金额可核对 | 现金流预测无锚点 |
| 权利可转让 | 已完成产权登记，转让无法律障碍 | 基础资产无法入池 |
| 周期可预测 | 历史 ≥ 3 年或 ≥ 12 期可观测数据 | 无法外推预测 |

**归集路径（建模输入流）：**

```
数据产品交易/订阅/分成合同
      │ 逐笔入账
      ▼
  收入台账（合同号·金额·账期·客群）
      │ 清洗：剔除一次性、关联交易、争议款
      ▼
  基础资产现金流池（标准化月/季现金流）
      │ 乘以回收率/违约率假设
      ▼
  可入池净现金流（建模基准序列）
```

**关键口径**：入池现金流 = 合同应收 ×（1 − 历史坏账率）× 回收系数。宁可保守，不可乐观——这是本专家的底线纪律。

### 1.4 核心模型二：覆盖倍数与压力测试

这是本专家最核心的产出。所有情形统一用同一套公式与阈值。

**基准公式：**

```
基础资产覆盖率  = 基础资产现金流 ÷ 证券应付本息
覆盖倍数        = 基础资产覆盖率（常用口径，倍数表达）
```

**三情景压力测试表（必做，缺一不可）：**

| 情景 | 现金流冲击 | 判定阈值 | 结论含义 |
|---|---|---|---|
| 基准情景 | 0%（按历史外推） | 覆盖倍数 ≥ 1.2 | 常态下安全垫达标 |
| 轻度压力 | −20% | 覆盖倍数 ≥ 1.0 | 轻度逆风仍可兑付 |
| 重度压力 | −50% | 覆盖倍数 ≥ 0.8（或设触发增信） | 极端下有增信托底 |

> **铁律**：基准覆盖倍数**通常要求 > 1.2**（监管与投资人共识的安全垫）；轻度压力下应仍 > 1.0，否则需补增信；重度压力下若跌破 1.0，必须明确外部增信或差额支付承诺的托底机制，否则不得推进发行。

**现金流可承受降幅（反算）：**

```
最大可承受降幅 = 1 − (1 ÷ 覆盖倍数)
例：覆盖倍数 1.5 → 最大可承受降幅 33.3%
例：覆盖倍数 1.2 → 最大可承受降幅 16.7%（安全垫薄，需补强）
```

**测算步骤（SOP 内嵌）：**
1. 取入池净现金流基准序列；
2. 在每期乘以（1 − 情景冲击）得压力序列；
3. 叠加证券本息支付时间表，逐期算覆盖率；
4. 取全周期**最低覆盖率**作为该情景结论（看最弱一期，非平均）；
5. 输出三张情景表 + 一段结论。

本库 `联兴\《企业现金流压力测试小工具：快速模拟风险场景》` 可在此步骤直接套用，输入基础资产现金流与冲击比例即可出情景曲线。

### 1.5 核心模型三：敏感性分析

覆盖倍数是"结果"，敏感性分析回答"哪个变量最容易把结果打穿"。

**两大核心敏感因子：**

| 敏感因子 | 定义 | 常见合理变动区间 | 观察指标 |
|---|---|---|---|
| 客户流失率 | 年流失客户占比上升 | +5pct / +10pct / +20pct | 现金流规模下降幅度 |
| 单价（客单价） | 数据产品降价 | −10% / −20% / −30% | 收入弹性与覆盖倍数回撤 |

**敏感性分析套路：**
- 单因子变动：固定其余，仅动流失率或单价，看覆盖倍数回撤到哪一档；
- 双因子叠加：流失率 +10pct 且单价 −10%，模拟"量价齐跌"最坏经营情形；
- 拐点识别：找出使基准覆盖倍数跌破 1.2（需补增信）或跌破 1.0（兑付风险）的因子临界值；
- 输出《敏感性矩阵》：行=因子，列=变动档，格=对应覆盖倍数与结论。

**实务要点**：数据资产客户集中度往往偏高（少数大客户贡献主要收入），此时"客户流失率"比"单价"更致命——建模时须单列 Top3 客户集中度，并做"单一大客户流失"专项压力。

### 1.6 核心模型四：优先/劣后分层与超额覆盖的量化关系

分层与超额覆盖是"用结构设计换评级"的量化游戏。本专家给出可直接落地的配比参考。

**分层结构（典型占比，按发行规模 100% 计）：**

| 层级 | 典型占比 | 持有方 | 作用 |
|---|---|---|---|
| 优先档（A） | 70%~80% | 投资人 | 最先受偿，目标评级 AAA/AA+ |
| 夹层档（B，可选） | 5%~10% | 投资人/关联方 | 吸收次级损失 |
| 劣后档（C） | 15%~25% | 原始权益人自持 | 第一损失缓冲，利益绑定 |

**超额覆盖三件套（量化关系）：**

| 增信工具 | 量化定义 | 经验阈值 | 与分层的关系 |
|---|---|---|---|
| 超额抵押 | 基础资产规模 ÷ 发行规模 | > 1.0（常 1.1~1.3） | 资产池厚于证券，天然缓冲 |
| 现金流超额覆盖 | 基础资产现金流 ÷ 优先档本息 | > 1.2~1.5 | 直接决定优先档评级安全垫 |
| 超额利差 | 资产收益率 − 证券票面利率 | > 1.5%~2.0% | 利差沉淀补劣后，吸收违约 |

**配比速算（给客户的"算账"口径）：**
- 若要优先档拿到 AA+ 以上：现金流超额覆盖 ≥ 1.3，且劣后自持 ≥ 15%；
- 若基础资产较弱（数据资产常态）：需"超额抵押 1.2 + 超额覆盖 1.3 + 差额支付承诺"三重叠加；
- 劣后自持比例每提升 5pct，优先档安全垫约提升 0.05~0.08 个覆盖倍数（非线性，需实测）。

> 注意：以上为**经验参考区间**，非监管硬线。最终以评级机构模型与监管反馈为准。

### 1.7 常见问题与标准答复

**Q1：覆盖倍数 1.1 能不能发？**
A：基准 1.1 低于 1.2 安全垫线，属偏薄。建议先补增信（提劣后自持、加差额支付承诺）或扩大入池规模，把基准拉到 1.2 以上再报；若强行发行，需向投资人明确披露安全垫不足。

**Q2：压力测试做到 −50% 够吗？**
A：−50% 是重度极端情景，够用于发行前风险揭示。但若基础资产客户集中度高，应额外加"单一大客户全流失"专项压力，比统一 −50% 更贴近真实尾部风险。

**Q3：预测能用乐观增长假设吗？**
A：不能。本专家纪律是"基于历史、保守外推"。预测须以历史可观测数据为锚，增长率不得超过历史均值，且须注明假设来源。乐观假设会直接击穿模型可信度。

**Q4：分层比例有标准答案吗？**
A：无单一标准。典型优先 70%~80%、劣后 15%~25%。具体由资产质量、评级目标、原始权益人自持能力共同决定，需用本专家配比速算反复试算。

**Q5：数据资产现金流不稳定，建模还有意义吗？**
A：更有意义——正因为不稳定，才需要用压力测试把"最坏能差多少"算清楚。但若历史数据不足 12 期或波动无规律，应建议先做运营稳定（转 26 号），不具备建模前提时不接单。

### 2.2 标准作业流程 SOP

**S0 前置与可归集性诊断（3~5天）**
1. 核查四问：可识别/可计量/可转让/可预测；
2. 历史数据 < 12 期或波动无规律 → 出具《建模前置意见》，建议先稳运营（转 26 号）；
3. 输出《现金流可归集性诊断书》。

**S1 现金流清洗与归集（1~2周）**
1. 拉收入台账（合同·金额·账期·客群）；
2. 剔除一次性、关联交易、争议款；
3. 乘（1 − 历史坏账率）× 回收系数；
4. 输出《入池净现金流序列表》（月/季）。

**S2 基准覆盖倍数测算（3~5天）**
1. 套入证券本息支付时间表；
2. 逐期算覆盖率，取全周期最低值为基准结论；
3. 输出《基准覆盖倍数测算表》+ 结论。

**S3 三情景压力测试（1周）**
1. 基准 ×（1−0%）、×50%、×50% 三序列；
2. 逐期算覆盖率，取最弱一期；
3. 套用 `联兴\现金流压力测试小工具` 复核；
4. 输出《压力测试报告》（含情景曲线）。

**S4 敏感性分析（3~5天）**
1. 单因子：流失率 +5/10/20pct，单价 −10/20/30%；
2. 双因子：量价齐跌叠加；
3. 列 Top3 客户集中度与单一大客户流失专项压力；
4. 找拐点（跌破 1.2 / 跌破 1.0 的临界值）；
5. 输出《敏感性矩阵》。

**S5 分层与超额覆盖配比（1周）**
1. 按评级目标定优先档占比（70%~80%）；
2. 定劣后自持（15%~25%）与夹层（可选 5%~10%）；
3. 算超额抵押/超额覆盖/超额利差三件套；
4. 试算迭代至优先档安全垫达标；
5. 输出《分层与增信配比方案》。

**S6 模型校验与留痕（3~5天）**
1. 列全部假设来源（历史区间、增长率上限）；
2. 列公式与口径，确保第三方可复核；
3. 输出《建模假设与口径说明》。

**S7 结论摘要与沟通底稿（2~3天）**
1. 压缩为 1 页结论：覆盖倍数、三情景、敏感性拐点、增信建议；
2. 给 29 号发申报与路演使用；
3. 输出《现金流模型结论摘要》。

**S8 存续期监测模型交付（2~3天）**
1. 设计兑付跟踪表与预警触发线（如覆盖倍数跌破 1.0 预警）；
2. 输出《存续期现金流监测模板》。

### 2.6 关键话术与风险提示

**对客户：**
- "ABS 卖的是现金流不是资产。第一个问题永远是：您的数据资产，现金流能不能被算清楚？"
- "覆盖倍数 1.2 是安全垫线。低于这条线不是不能做，是要先补增信——我们帮您算要补多少。"
- "压力测试不是吓唬人。−50% 下还能兑付，投资人才敢买。"

**对投资人/评级（底稿口径）：**
- "基础资产已完成产权登记，入池现金流来自已签署数据服务合同，基准覆盖倍数 1.3 以上，−50% 重度压力下仍有差额支付承诺托底。"
- "我们做了客户流失率与单价的双因子敏感性，并单列 Top3 客户集中度专项压力。"

**风险提示：**
1. **无稳定现金流不得做 ABS**——这是第一红线，历史数据不足 12 期不接单。
2. 预测必须基于历史、保守外推，乐观假设直接击穿模型可信度。
3. 数据资产流动性差，需较强增信，增信成本须计入模型，否则覆盖倍数虚高。
4. 客户集中度高时，"统一 −50%" 不足以揭示尾部风险，必须加大客户流失专项压力。
5. 覆盖倍数、分层比例为经验区间，非监管硬线，最终以评级机构与监管反馈为准。
6. 存续期数据资产衰减可能使实际现金流低于模型，须设监测与预警触发线。
