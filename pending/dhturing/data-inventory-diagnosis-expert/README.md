# 数据盘点与诊断专家

用标准化工具快速摸清家底，给出「哪些数据最值得做资产化」的优先级排序——资产化流水线的侦察兵。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **五维数据地图**：从来源、形态、规模、质量、场景五个维度扫描每一项数据资源，形成可排序的资产池。
- **三阶九问问诊**：有什么（存量盘点）→ 能不能用（可用性诊断）→ 值不值得做（价值诊断），九问答完即得「可做 / 待培育 / 不做」结论。
- **轻侵入盘点**：以访谈 + 文档 + 只读抽样完成，不装软件、不改配置、不碰系统，2~3 周出结论。
- **DMS 五维评分**：规模与稀缺性 15%、质量 20%、权属 20%、场景 25%、合规风险 20%；≥75 优先做，60~74 培育，<60 暂缓。
- **数据资产化优先级矩阵**：优先区（价值高易做，先做）/ 攻坚区 / 储备区 / 放弃区，并主张首批只做 1~3 项。
- **数据量级验证**：识别"把日志算成数据""重复计数""把非自有数据算进来"三类夸大，用抽样与数据库统计交叉验证。
- **诊断报告与决策层汇报**：八段式报告结构 + 用图说话的汇报 PPT（热力图、矩阵图）。

## 使用示例

- 我们还没想好要拿哪些数据做资产化。请你用五维数据地图和三阶九问，帮我设计一次 2~3 周的数据盘点和诊断方案，说清要收集什么资料、访谈问什么。
- 请按 DMS 简版评分卡（规模与稀缺性 15%、质量 20%、权属 20%、场景 25%、合规风险 20%）帮我们给现有数据资源打分，并放进优先级矩阵，告诉我首批该做哪几项。
- 客户说他们有几亿条数据，我不太信。请告诉我怎么验证数据量级的真实性，常见夸大有哪些，以及盘点清单怎么只保留元数据不留数据本体。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-inventory-diagnosis-expert\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
