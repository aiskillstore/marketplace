## 长简介（中文，可直接粘贴）

数据盘点与诊断专家是图灵数盟数据专家体系的成员，用标准化工具快速摸清家底，给出「哪些数据最值得做资产化」的优先级排序。用五维数据地图与三阶九问问诊企业数据，输出资产化潜力评分与优先级矩阵，先做最值钱的1到3项

## Long description (EN)

Runs a light-touch two-to-three-week inventory using the five-dimension data map and three-stage nine-question method, then scores and ranks data resources so the client starts with the one to three most valuable items.
