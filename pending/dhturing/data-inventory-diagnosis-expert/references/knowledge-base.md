# 数据盘点与诊断专家

> 所属战队：01-资产化流水线
> 专家编号：05
> 核心使命：用标准化工具快速摸清家底，给出「哪些数据最值得做资产化」的优先级排序

---

## 第一部分 · 知识库

### 1.1 一句话定位

数据盘点与诊断专家是流水线的**侦察兵**。在企业还没决定要做什么之前，他先用一套工具和方法，把企业所有数据资源过一遍，输出一张「数据资产热力图」，标出哪些是金矿、哪些是废矿。

与专家 02（治理专家）的区别：**02 是深度治理（要动手改造），05 是快速诊断（只看不动）**。05 通常先于 02 进场，2~3 周出结论。

### 1.3 核心模型一：五维数据地图

这是本专家自有的诊断框架，来自本库 `数据变现场景及业务路径研究.md`：

| 维度 | 探查什么 | 关键问题 |
|---|---|---|
| **来源维度** | 数据从哪来 | 自有产生？授权获取？公开采集？交易取得？ |
| **形态维度** | 数据长什么样 | 结构化/半结构化/非结构化？实时/批量？ |
| **规模维度** | 有多少 | 记录数、字段数、时间跨度、覆盖范围 |
| **质量维度** | 好不好 | 六维快速扫描 |
| **场景维度** | 能干什么 | 内部已有场景？潜在场景？外部需求？ |

**输出形式**：一张表，每行一个数据资源，五列打分，形成可排序的资产池。

### 1.4 核心模型二：数据盘点「三阶九问」

**第一阶：有什么（存量盘点）**
1. 有哪些业务系统？各产生什么数据？
2. 每个系统的数据量级、更新频率？
3. 有没有没进系统的线下数据（纸质、Excel、个人电脑）？

**第二阶：能不能用（可用性诊断）**
4. 数据是否可被技术手段取出（有无接口/导出）？
5. 数据权属是否清晰？
6. 数据质量是否达标（快速扫描）？

**第三阶：值不值得做（价值诊断）**
7. 有没有明确的内部使用场景？
8. 有没有潜在的外部需求方？
9. 是否符合政策鼓励方向（是否在"数据要素×"12个行业场景内）？

九问全部回答完，就能给每个数据资源一个「可做/待培育/不做」的结论。

### 1.5 核心模型三：数据资产化优先级矩阵

```
            高价值
              │
   ② 攻坚区   │   ① 优先区
  (价值高难做)│  (价值高易做)  ← 先做这些
 ─────────────┼─────────────  实施难度
   ④ 放弃区   │   ③ 储备区
  (价值低难做)│  (价值低易做)
              │
            低价值
```

- **① 优先区**：立即启动，这是最快见效的
- **② 攻坚区**：需要投入，但值得，作为第二阶段
- **③ 储备区**：低成本做掉，作为资产储备
- **④ 放弃区**：明确不做，节约资源

**实战建议**：一个客户的资产化项目，**首批只做 1~3 项优先区**，做出样板后再扩展。切忌一次铺开 10 项。

### 1.6 诊断评分卡（本库 DMS 模型简化版）

| 评分项 | 权重 | 评分要点 |
|---|---|---|
| 数据规模与稀缺性 | 15% | 量级大、独家性强得分高 |
| 数据质量 | 20% | 六维快速扫描 |
| 权属清晰度 | 20% | 无瑕疵得分高 |
| 场景明确度 | 25% | 有明确付费场景得分高 |
| 合规风险 | 20% | 无个人信息/无涉密得分高（扣分项） |

总分 100，≥75 优先做，60~74 培育，<60 暂缓。

### 1.7 常见问题与标准答复

**Q1：盘点要不要动客户的系统？**
A：不需要。以访谈 + 文档 + 只读抽样的方式完成，不装软件、不改配置。这是本专家相比治理专家的优势——**轻侵入，快交付**。

**Q2：盘点结果会不会泄露客户商业机密？**
A：所有材料签保密协议，盘点清单只保留元数据（表名、字段名、量级），不留存数据本体。

**Q3：客户自己说数据很多，可信吗？**
A：不可信，必须验证。常见夸大有：把日志算成数据、把重复数据重复计数、把非自有数据算进来。验证方法是抽样查、看系统截图、比对数据库统计。

**Q4：盘点做完，客户不想继续怎么办？**
A：这是正常的。盘点报告本身就是交付物，客户可以自己拿着往前走。同时报告中的优先级建议天然指向我们的服务，是良好的转化钩子。

### 2.2 标准作业流程 SOP

**S0 项目启动（2~3天）**
1. 与客户决策层沟通，明确盘点目的
2. 确定盘点范围（全公司 / 某业务线）
3. 组建盘点小组，指定客户侧对接人
4. 签保密协议
5. 输出《数据盘点方案》

**S1 资料收集（3~5天）**
1. 收集：系统清单、数据库清单、数据字典（如有）、组织架构、业务流程图
2. 与 IT 部门确认可访问的数据源
3. 输出《资料收集清单》

**S2 访谈调研（1周）**
1. 访谈对象：业务负责人、IT 负责人、数据团队、财务
2. 按「三阶九问」逐项访谈
3. 关键问法：
   - "你们部门每天产生什么数据？存在哪？"
   - "这些数据有没有对外提供过？有没有人问你们要过？"
   - "这些数据如果明天没了，业务会怎样？"
4. 输出访谈记录

**S3 数据验证（3~5天）**
1. 抽样查询数据库，验证访谈中的数据量级
2. 查看系统截图、报表，交叉验证
3. 剔除夸大部分
4. 输出《数据资源清单（经核实）》

**S4 快速质量扫描（3~5天）**
1. 每个资源抽 1000~10000 条抽样
2. 六维快扫（不用做到专家 04 那么细）
3. 给出质量初判等级
4. 输出质量快扫结果

**S5 权属与合规快诊（2~3天）**
1. 判断数据来源类型
2. 标记含个人信息、涉密、第三方权利的数据
3. 标记高风险项
4. 输出《权属与合规风险清单》

**S6 DMS 评分与排序（2~3天）**
1. 按五维评分卡逐项打分
2. 计算总分
3. 放入优先级矩阵
4. 输出《数据资产化潜力评分表》《优先级矩阵》

**S7 诊断报告撰写（3~5天）**
报告结构：
```
一、盘点背景与目的
二、盘点范围与方法
三、企业数据资源全景（清单 + 地图）
四、数据资源质量快扫结果
五、权属与合规风险提示
六、数据资产化潜力评分与优先级排序
七、首批建议项目（1~3项）+ 预期投入与产出
八、后续路径建议
附件：数据资源清单、评分明细
```

**S8 决策层汇报（1天）**
1. 用图说话：热力图、矩阵图
2. 重点讲「首批做什么、为什么、要多少钱、能换来什么」
3. 输出汇报 PPT

**S9 转化衔接（持续）**
1. 首批项目转 01 入表专家 / 17 产品孵化专家 / 23 变现专家
2. 治理需求转 02 专家

### 2.6 关键话术

**对客户决策层**：
- "我们只花两三周，就能告诉您公司数据里哪块最值钱、先做哪块最划算。"
- "盘点不动您的系统，不装软件、不改配置，只看不碰。"
- "我们不建议一次全做。先做 1~2 项做出样板，再复制。"

**风险提示**：
1. 盘点结论是初步诊断，不等于评估结论
2. 质量快扫不能替代正式质量评价
3. 权属快诊不能替代法律意见书
4. 客户可能高估自身数据价值，需数据说话
