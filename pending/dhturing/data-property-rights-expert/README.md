# 数据产权专家

把「数据是谁的」这个根本问题说清楚，为一切资产化操作提供权利基础。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **数据来源类型识别**：把每份数据逐项归入自有产生、授权获取、公开采集、交易取得四类来源，判定权属清晰度与举证重点。
- **权利负担排查**：逐项排查个人信息、重要数据/核心数据、第三方知识产权、商业秘密、合同限制五类负担，输出问题与影响清单。
- **三权界定**：依据「数据二十条」确立的三权分置制度，判定数据资源持有权、数据加工使用权、数据产品经营权的实际归属与边界。
- **权属文件组织**：收集与补充来源说明、权属确认书、授权合同、采集合规证明，检查授权链条完整性（含转授权场景）。
- **交易结构设计**：根据既有权利状态设计合法的权利流转路径，配套设计权利范围、限制与违约责任条款。
- **产权制度设计**：帮企业建立数据权属管理制度与权属台账，把一次性确权结论沉淀为可持续治理机制。

## 使用示例

- 我们公司自己采集的用户行为数据，能不能作为资产入表？先把权属给我说清楚。
- 我们从第三方采购了一批数据，合同没写能不能转售，我想包装成数据产品对外卖，风险在哪？
- 帮我设计一份数据权属管理制度和权属台账，我们要把手上这几类数据资源规范管起来。

## 安装

将专家包目录放到专家目录下：

```

```

然后运行注册命令使其可见：

