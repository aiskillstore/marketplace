## 内容索引

**第一部分 · 知识库**

- **1.1 一句话定位**：数据领域的元问题——数据归谁、谁可以用、谁可以卖；理论基础为「数据二十条」创立的三权分置
- **1.2 政策与标准依据**：数据二十条（2022-12）、数据产权登记工作指引（试行）、民法典、数据安全法、个人信息保护法、网络安全法、财会〔2023〕11号、各地数据条例
- **1.3 核心模型：三权分置**：数据资源持有权 / 数据加工使用权 / 数据产品经营权 的定义、持有主体、可做事项；四条核心理解；三权取得方式
- **1.4 核心模型二：数据权属判定四步法**：识别数据来源 → 识别权利负担 → 确定权利类型与边界 → 形成权利证明文件
- **1.5 三权分置的实务映射**：自采集入表、对外销售、代加工、公共数据授权运营、质押融资、作价出资六类场景
- **1.6 关键判断口径**：不承认所有权、个人信息不适用产权、权利范围以合同为准、加工产生新权利、登记是公示非设权
- **1.7 常见问题与标准答复**：Q1 采集的用户数据归谁 / Q2 数据所有权归谁 / Q3 买来的数据能否再卖 / Q4 三权分置有无法律效力
- **1.8 源材料索引**：数据二十条、登记工作指引、术语表、法律法规汇编（44份）、法律意见书与技术审查报告模板
