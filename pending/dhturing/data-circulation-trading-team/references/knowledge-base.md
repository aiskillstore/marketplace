> 本底座由团 3 六位成员（15/16/17/18/19/20）的《知识与技能.md》按团队视角重组而成。
> 整理基准日：2026-09-23。

## 一、团队定位与共同擅长

**共同擅长**：把原始数据孵化为数据产品、定得住价、挂牌撮合并建成可信流通基础设施。

**团队心智模型**：流通交易是一条**业务链**——
```
孵化（17，闸门）→ 定价（18，依据）→ 撮合（19，成交）
                                    ↑
        身份与场所（16：交易所/平台/数商三层）
        基础设施（20：可信数据空间，高敏感数据专用）
```
**先有产品，再谈定价，然后撮合。** 价格不是算出来的，是谈出来的——但谈判桌上要有依据。

## 三、分阶段 SOP 与预设 Workflow

**SOP 五阶段**：
- **Phase 1 资源与场景诊断**：盘点数据资源、场景与买方画像。
- **Phase 2 产品化（闸门）**：17 完成 MVP 与种子客户验证——**没有验证不进入定价**。
- **Phase 3 定价与身份**：18 出定价方案；16 同步确认流通身份与场所。
- **Phase 4 撮合与成交**：19 撮合谈判，主理人把控交易结构合规。
- **Phase 5 最终报告**：汇编交付包（产品说明书 + 定价依据 + 撮合记录 + 合同 + 成交凭证）。

**三个预设 Workflow**：
- **Workflow A 数据产品从 0 到挂牌成交**（最高频）：并行（17 潜力评估 + 16 身份判断）→ 串行（17 产品定型 → 18 定价）→ 串行（19 撮合 + 18 价格支撑）→ 主理人汇编。
- **Workflow B 数商身份与流通资质布局**：并行（16 资质路线 + 19 经纪定位）→ 串行（18 服务定价 → 16 申报材料）→ 主理人汇编。
- **Workflow C 高敏感数据可信流通方案**：并行（20 空间判断 + 17 产品形态设计）→ 串行（20 规则与技术选型 → 18 空间服务定价）→ 主理人汇编。

## 六、质量校验清单

- [ ] 产品化潜力评估有买方画像与场景依据，不是自嗨式规划
- [ ] MVP 已做种子客户验证，验证报告在档（闸门）
- [ ] 定价有三法依据与市场比价，报价单带定价依据页
- [ ] 谈判方案有三档（锚点/目标/底线），且底线经过主理人确认
- [ ] 数商/会员身份与所选交易所匹配，认证材料齐全
- [ ] 交易合同载明授权范围、使用限制、交付方式与违约责任
- [ ] 涉个人信息与重要数据的交易已过合规闸门（与合规团衔接）
- [ ] 高敏感数据方案优先考虑可信数据空间而非直接交易
- [ ] 居间与保荐角色界定清晰，佣金结算有单据
- [ ] 未向客户承诺必然成交、必然挂牌、必然卖到某个价格

## 七、风险提示与话术边界

1. **没有需求的数据产品卖不动**——先验证买方，再投入产品化（最常见的失败原因）。
2. **低价成交毁掉整个市场认知**——首单价格是锚，贱卖会让后续所有产品难以定价。
3. **数商不是中介这么简单**——有合规审核与保荐责任，撮合前必须」先验真」。
4. **可信数据空间的难点在规则不在技术**——五类规则体系（准入/授权/使用/分配/治理）谈不拢，技术再好也落不了地。
5. **场外交易风险高**——优先走有监管的场所；场外交易必须有完备合同与交付凭证。
6. **不越界**：交易合规审核意见不替代法律意见书；定价结论不替代资产评估报告。
7. **话术**：」数据产品的价格不是算出来的，是谈出来的——但谈判桌上要有依据。"
