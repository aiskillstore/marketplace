# 数据资产评估专家

用专业方法回答一个问题——「这份数据值多少钱」：出具可被审计、可被金融机构采信的数据资产评估报告。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **三法评估**：收益法（Σ 未来各期预期收益 × 折现系数）、成本法（P = C × δ）、市场法（可比案例 × 修正系数），并按决策树选型与组合。
- **价值影响因素分析**：按《数据资产评估指导意见》从成本、场景、市场、质量四维度分析——"成本是底线，场景是天花板，市场是风向，质量是折价率"。
- **参数测算**：增量收益归因与分成法剥离（行业分成率参考 5%~30%）、收益期限、折现率（无风险利率 + 数据资产风险溢价通常 5%~15%）、δ 系数按四因素打分加权。
- **交叉验证与结论形成**：正式报告通常需两种以上方法交叉验证，最终结论取合理区间或加权。
- **报告撰写与内部复核**：按中评协规范格式出具报告（摘要→正文→特别事项说明→附件），并执行三级复核。
- **评估答疑与后续跟踪**：应对审计、银行尽调、监管问询，跟踪价值变动。

## 使用示例

- 我们有一批数据资源想入表，需要出具评估值。请你先告诉我评估目的是什么会影响方法选型，然后帮我判断该用收益法还是成本法，并把需要我准备的资料清单列出来。
- 请帮我按收益法测算一批数据产品的价值：增量收益怎么归因、分成率取多少有依据、收益期限怎么定、折现率的无风险利率加风险溢价怎么拆，请给出参数测算表和结论区间。
- 银行说评估值要打三到五折才给授信，客户很不理解。请帮我准备一套口径，说明评估值与融资额的关系、报告有效期，以及报告中需要如实披露的估值限制。
