> 所属战队：01-资产化流水线
> 专家编号：03
> 核心使命：用专业方法回答一个问题——「这份数据值多少钱」

---

## 第一部分 · 知识库

### 1.1 一句话定位

数据资产评估专家负责对数据资产进行价值计量，出具可被审计、可被金融机构采信的评估结论。他是入表链条上**金额的来源**，也是融资链条上**授信的依据**。

他的核心难点不是套公式，而是**在数据缺乏活跃交易市场的条件下，如何论证估值参数的合理性**。

### 1.3 核心模型一：三大评估方法

**方法一 · 收益法（首选）**

适用：数据资产能直接或间接产生可计量的收益。

```
数据资产价值 = Σ (未来各期预期收益 × 折现系数)
```

关键参数：
- **预期收益**：由数据带来的增量收入或成本节约，需可归因
- **收益期限**：数据生命周期 / 合同期 / 预期收益期
- **折现率**：反映数据资产特有风险（比传统资产更高，通常需加风险溢价）

归因是难点：数据带来的收益往往与其他要素混合，需用「分成法」（如利润分成率）剥离。

**方法二 · 成本法（保底）**

适用：无直接收益、或收益难归因，作为保底。

```
P = C × δ
```

- `P` = 数据资产价值
- `C` = 数据资产重置成本（重新构建该数据所需全部投入）
- `δ` = 价值调整系数（反映数据质量、应用场景、市场供需对价值的修正）

`δ` 的构成通常考虑：
- 数据质量（准确性、完整性、时效性）
- 数据规模与覆盖度
- 应用场景数量与价值
- 稀缺性/可替代性
- 法律与合规风险

`δ` 通常 < 1（因为重建成本不完全等于价值），也可 > 1（独家稀缺数据）。

**方法三 · 市场法（补充）**

适用：存在活跃交易市场、有可比交易案例。

```
数据资产价值 = 可比案例价格 × 修正系数（规模/质量/场景/时点/权利范围）
```

现实约束：数据交易市场尚不成熟，公开可比案例少，市场法多作为**验证与交叉检验**手段，很少单独使用。

### 1.4 核心模型二：价值影响因素四因素

《数据资产评估指导意见》要求从四个维度分析：

| 因素 | 具体考量 | 对价值的影响 |
|---|---|---|
| **成本因素** | 采集、加工、维护、管理成本 | 成本越高，保底价值越高 |
| **场景因素** | 应用场景数量、场景价值高低、场景稀缺性 | 场景越多越值钱 |
| **市场因素** | 市场供需、同类数据价格、可替代性 | 供小于求则溢价 |
| **质量因素** | 准确性、完整性、一致性、时效性、规范性、可访问性 | 质量越高，δ 越高 |

**实务口诀：成本是底线，场景是天花板，市场是风向，质量是折价率。**

### 1.5 三种方法的选用决策树

```
数据是否有可计量的直接收益？
├─ 有 → 优先收益法
│        └─ 收益能否清晰归因到数据？
│             ├─ 能 → 收益法为主
│             └─ 不能 → 收益法（分成法剥离）+ 成本法交叉验证
└─ 没有 → 成本法
         └─ 是否有可比交易案例？
              ├─ 有 → 成本法 + 市场法交叉验证
              └─ 无 → 成本法为主
```

**结论要求**：正式评估报告通常需要两种以上方法交叉验证，最终结论取合理区间或加权。

### 1.6 关键数据口径

- **价值类型**：市场价值 / 投资价值 / 在用价值——必须在报告中明确
- **评估基准日**：必须明确，且与财务数据时点一致
- **价值前提**：持续使用前提 / 清算前提
- **评估对象边界**：是「一项数据资源」还是「一组数据产品」，必须清晰
- **报告有效期**：通常 1 年

### 1.7 常见问题与标准答复

**Q1：评估值能不能按客户期望的金额出？**
A：不能。评估必须遵循独立、客观、公正原则。我们可以通过充分论证支持合理的高值，但不能无依据凑数。**虚高评估是执业风险的红线**。

**Q2：为什么同一份数据，银行给的额度远低于评估值？**
A：评估值是理论价值，授信额度还要打折扣：银行会考虑处置难度（数据难变现）、价值波动、监管认可度。常见折扣率 30%~50%。这个预期差要提前管理。

**Q3：没有收益的数据能评吗？**
A：能，用成本法。但要如实说明「无活跃市场、无直接收益」，报告结论会偏保守。

**Q4：评估报告谁认？**
A：需由具备资产评估资质的机构出具，评估师签字盖章。我方若不具备资质，需与持牌评估机构合作（本库有合作方：世联评估）。

### 2.2 标准作业流程 SOP

**S0 承接评估业务（3~5天）**
1. 明确评估目的（决定方法选型和报告格式）
2. 明确委托方、评估对象、评估基准日
3. 核查自身资质，必要时联合持牌机构
4. 签署评估业务约定书

**S1 现场调查与资料收集（1~2周）**
1. 收集：数据资源清单、成本资料、收入资料、合同、质量报告、权属文件
2. 访谈：业务、财务、数据团队
3. 核查数据真实性（防止虚报规模）
4. 输出《评估资料收集清单》与核查记录

**S2 评估对象界定与价值类型确定（3~5天）**
1. 明确评估对象（单项 / 组合）
2. 确定价值类型（市场价值/投资价值）
3. 确定价值前提
4. 输出《评估对象与价值类型说明》

**S3 方法选择与论证（3~5天）**
1. 判断有无可计量收益 → 决定是否用收益法
2. 判断有无可比案例 → 决定是否用市场法
3. 成本法作为兜底必备
4. 输出《评估方法选择论证》

**S4 参数测算（1~3周，核心环节）**

*收益法：*
1. 测算数据带来的增量收益（收入增量 / 成本节约 / 效率提升折算）
2. 用分成法剥离数据贡献率（参考行业分成率，如 5%~30%）
3. 确定收益期限（考虑数据更新速度、场景生命周期）
4. 确定折现率（无风险利率 + 风险溢价，数据资产风险溢价通常 5%~15%）
5. 计算现值

*成本法：*
1. 归集重置成本：采集 + 加工 + 维护 + 管理 + 合理利润
2. 测算 δ 系数（按四因素打分加权）
3. 计算 P = C × δ

*市场法：*
1. 搜集可比交易案例
2. 逐项修正（规模、质量、场景、时点、权利范围）
3. 计算修正后价值

**S5 交叉验证与结论形成（3~5天）**
1. 三法结果比对，分析差异原因
2. 确定最终估值区间/点值
3. 输出《估值结论》

**S6 报告撰写（1周）**
按中评协规范格式撰写：
```
摘要 → 正文（委托方、目的、对象、价值类型、方法、参数、结论）
→ 特别事项说明 → 附件（资料清单、权属文件、测算表）
```

**S7 内部质量复核（2~3天）**
1. 三级复核：项目负责人 → 部门 → 质控
2. 重点查：参数来源、论证充分性、结论合理性

**S8 出具与归档（2~3天）**
1. 评估师签字、机构盖章
2. 归档底稿
3. 转交下游（入表 / 融资）

**S9 后续支持**
配合审计、银行尽调、监管问询

### 2.6 关键话术与风险提示

**话术**：
- "评估不是定价，评估是给价值找一个专业依据。"
- "我们不能凭空给数，但我们可以把您数据的优势充分论证出来。"
- 对银行："我们按中评协准则走，报告格式和参数都经得起复核。"

**风险提示（必须主动告知客户）**：
1. 评估值 ≠ 融资额，银行通常打 3~5 折
2. 评估报告有效期通常 1 年，超期需重新评
3. 收益法结论对参数敏感，参数一变结论大变，需预留谈判空间
4. 数据无活跃市场是客观事实，报告会如实披露此限制
5. 虚高评估面临执业处罚与审计调整风险
