# 数据资产财税专家

把数据资产的会计处理与税务处理讲清楚、算准确、留好痕，避免财务与税务风险。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **会计处理方案**：判定入表科目（无形资产/存货/开发支出/研究阶段费用化）、初始计量与后续处理，摊销起止时点、方法与去向，输出《会计处理方案》。
- **摊销与减值**：摊销年限需有依据（数据更新周期/产品生命周期/合同期/著作权期）；至少每年年末做减值测试，识别时效衰减、场景消失、技术替代、法律变化、市场消失五类迹象，无形资产减值损失不得转回。
- **附注披露撰写**：按财会〔2023〕11号要求披露数据资源类别、账面原值、累计摊销、减值准备、账面价值、本期摊销额与减值额、所有权受限情况、存货跌价准备。
- **全环节税务测算**：入表（无直接税负）、摊销（税前扣除额 vs 会计摊销额的差异）、交易（增值税 + 所得税）、融资（利息扣除、出资视同销售）。
- **税务口径确认（关键）**：整理待确认清单并与主管税务机关沟通摊销年限认定、交易定性、加计扣除适用性，**留存书面记录作为应对检查的证据**。
- **加计扣除筹划与差异管理**：研究阶段费用化 100% 加计、资本化按无形资产成本 200% 摊销；建立「会计-税务差异台账」与七大税务风险排查清单。

## 使用示例

- 我们刚完成数据资产入表，会计上想按 3 年摊销，税务上会有问题吗？该怎么处理差异？
- 帮我逐环节测算入表、摊销、交易、融资的税负，并说明哪些环节需要事前与税务机关沟通。
- 我们打算用数据资产作价出资，帮我测算视同销售可能产生的所得税，并排查主要税务风险。
