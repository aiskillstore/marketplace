# 行业垂直数据专家团

把通用数据资产化方法论，落到碳、种业、电力储能、公共数据等具体行业，先过监管闸门再谈资产化。

## 类型

专家团（多角色协作团队，expertType: team）

## 团队构成

| 角色 | 花名 | 职业头衔 | 职责 |
|---|---|---|---|
| 主理人 | 毕落地 | 行业垂直数据专家 | 行业适配五步法编排、跨行业调度、总成报告 |
| 团员 | 谭核查 | 碳数据资产专家 | 碳 MRV、CCER 登记交易、碳核算/碳金融/ESG 披露 |
| 团员 | 钟穗 | 种业数据资产专家 | 种质资源合规闸门、重要数据边界、多方权属、种业 RWA |
| 团员 | 楚能 | 电力储能数据资产专家 | 能源数据分类分级、CII/重要数据筛查、现金流可计量性、充电桩 RWA |
| 团员 | 龚运 | 公共数据授权运营专家 | 授权模式/五步程序、期限衔接（授权≤5年/登记3年）、收益分配 |

## 共同擅长

- 行业数据特性分析与行业合规闸门识别（碳 MRV、种质资源审批、电网 CII/重要数据、公共数据授权期限）
- 行业价值场景挖掘与买方结构分析
- 行业资产化路径设计：入表（五步法）、RWA（收益权/品种权益上链）、公共数据授权运营拿权
- 区分官方规则与商业 RWA，防"漂绿"与合规风险

## 使用示例

- 梳理某行业的行业数据特性、合规闸门与价值场景，并给出可落地资产化路径。
- 碳、种业、电力储能、公共数据四类行业数据，分别该走什么合规资产化路径？
- 我们这行（充电网络/种业/碳/公共数据）的数据能产生可计量现金流、可以做资产化吗？

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\vertical-industry-data-team\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r vertical-industry-data-team.zip vertical-industry-data-team/
```
