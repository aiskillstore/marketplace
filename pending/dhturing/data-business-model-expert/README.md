# 数据商业模式设计专家

设计「怎么把数据能力变成可持续赚钱的生意」，而不只是接一单做一单——战略定位、业务架构、收入组合、壁垒与进化路线。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **定位设计**：在数据提供商 / 技术服务商 / 咨询顾问 / DMaaS 运营商之间比选，结合自身禀赋论证
- **1+4+N 业务架构**：以数据资产入表为切入点（1），向资产化服务、产品与交易、金融化、资产运营四类业务延伸（4），复制到 N 个行业场景
- **六类收入模型**：设计项目/订阅/交易/分成/顾问/技术收入组合，把持续收入占比推向 50% 以上
- **产品体系设计**：把能力打包为引流款、利润款、战略款的标准化产品矩阵
- **会员与伙伴模式**：会员分档与权益设计、城市合伙人/渠道商分润机制
- **三层壁垒分析**：能力、生态（15 家数商认证、交易所关系、专家网络）、数据（三大数据库，尤其需求数据库）
- **五阶段进化路线**：项目制 → 复制期 → 产品化 → 平台化 → 生态化，含阶段目标与可量化指标
- **对外表达**：BP、公司介绍、路演材料与统一对外话术

## 使用示例

- 帮我把数据业务的商业模式整体设计出来：定位怎么选、业务架构怎么搭、收入怎么组合。
- 我们做了三年全定制项目，帮我规划从项目制走到产品化、平台化的分阶段目标和量化指标。
- 帮我设计会员分档与城市合伙人分润机制，并把持续收入占比的目标算清楚。
