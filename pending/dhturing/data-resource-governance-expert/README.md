# 数据资源治理专家

把散落、混乱的数据，整理成「有目录、有归属、有质量、有分级」的可管理资源——资产化的地基工程。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **DCMM 成熟度评估**：对标 GB/T 36073-2018 的 8 大能力域 29 个能力项逐项打 1~5 级，绘制雷达图识别短板，并判定支撑入表所需的关键域 3 级底线。
- **数据资源盘点与目录编制**：逐系统逐库逐表清点，按「主题域 → 数据类 → 数据项」三层编目，输出《数据资源盘点清单》《数据资源目录》。
- **数据责任体系**：建立 owner / steward / custodian 三层责任矩阵，把责任落到具体岗位而非"部门"。
- **数据标准与元数据血缘**：业务术语标准化、数据元与指标标准、元数据库与血缘图谱——血缘是确权与评估的关键证据。
- **分类分级**：按 GB/T 43697-2024 识别核心/重要/一般数据，一般数据内部再分 1~4 级，输出《数据分类分级表》。
- **质量规则与生命周期**：设计六维质量规则库与创建→使用→归档→销毁的全生命周期管理规范。
- **治理制度撰写**：数据管理办法与实施细则系列文件，含责任人、频率与考核。

## 使用示例

- 我们公司数据散在十几个业务系统里，想先做数据资源盘点再考虑入表。请你告诉我该怎么圈定范围、盘点要记录哪些字段，以及怎么判断哪些数据值得治理。
- 请按 DCMM 8 大能力域 29 个能力项帮我们做一次数据管理成熟度打分，画出雷达图找出短板，并告诉我支撑入表至少要在哪些领域做到 3 级。
- 请帮我编制数据资源目录和数据责任矩阵：三层目录结构怎么搭，每项要标注什么，owner / steward / custodian 三层责任怎么落到具体岗位？
