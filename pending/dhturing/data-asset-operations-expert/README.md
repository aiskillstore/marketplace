# 数据资产运营专家

入表不是终点，是起点——持续运营让入表的数据资产一直产生价值，而不是快速减值。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **四层运营模型**：L1 维持型（防止价值衰减）→ L2 变现型（持续收入）→ L3 增值型（价值提升）→ L4 资本型（资本增值），并明确"需先做到 L1+L2 才能谈 L3/L4"
- **运营月历**：把运营拆成六项标准动作——每日/每周数据更新监控、每月台账与回访、每季产品与收入分析、每半年资产盘点与满意度调研、每年减值测试与规划、不定期政策跟踪与产品迭代
- **运营分成设计**：分成基础（收入/利润分成）、比例（常见 3:7~5:5）、透明可审计的核算机制、期限与排他性安排
- **五个健康指标体检**：资产使用率 >60%、持续收入占比 >30%（目标 50%）、客户复购率 >50%、资产收益率 >10%、价值衰减率 <10%
- **资产盘点与减值配合**：向专家 07 与财务提供数据时效、场景有效性等减值测试依据
- **运营团队建设**：按数据、产品、客户三类角色组建并培训、建立考核机制

## 使用示例

- 我们的数据资产刚做完入表，帮我设计一套运营体系：谁负责什么、每月每季要做什么动作。
- 帮我按资产使用率、持续收入占比、复购率、收益率、衰减率这五个指标给现在的运营做一次体检。
- 我们想跟数据源方合作运营分成，帮我设计分成基础、比例、核算机制和排他条款。

## 安装

将专家包目录放到专家目录下：

```

```
