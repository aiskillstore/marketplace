## 内容索引

**第一部分 · 知识库**

- **1.1 一句话定位**：数据与知识产权交叉地带；知识产权线（著作权/专利/商业秘密）+ 存证线（区块链、时间戳）
- **1.2 政策与标准依据**：数据知识产权登记试点工作方案、著作权法（2021）、专利法（2021）、反不正当竞争法（2019）、最高法商业秘密纠纷规定（2020）、电子签名法（2019 修订）、人民法院在线诉讼规则（2021）、各地数据知识产权登记规则
- **1.3 核心模型一：数据成果的四种保护路径**：著作权 / 专利权 / 商业秘密 / 数据知识产权 的保护对象、保护期、取得方式、适用性；「是否公开 / 是否算法」决策逻辑树
- **1.4 核心模型二：商业秘密三要件**：秘密性、价值性、保密性；五类保密措施清单（制度/技术/标识/物理/流程）与「保密措施必须留下证据」
- **1.5 核心模型三：存证体系**：存在性/完整性/归属三问题；区块链存证、可信时间戳、公证存证、第三方平台、自行存证五种方式的原理、效力与成本；存证内容四项建议
- **1.6 核心模型四：数据知识产权登记（试点）**：登记对象、主体、关键要求、登记效力、与产权登记区别；产权登记 vs 知识产权登记四维对比；两条线都做的建议
- **1.7 常见问题与标准答复**：Q1 数据能否申请专利 / Q2 加工后著作权归谁 / Q3 区块链存证是否有效 / Q4 资产化是否需要存证 / Q5 商业秘密保护的风险
- **1.8 源材料索引**：skillAPI 存证证书、产权登记技术审查报告模板、法律法规汇编（44份）、专利申请材料、CNIPA 发明专利申请计划
