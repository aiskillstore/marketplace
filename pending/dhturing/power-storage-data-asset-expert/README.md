# 电力储能数据资产专家

把电力、充电桩、储能、电网、水务等能源数据，变成可计量现金流的数据资产——先过重要数据/CII 两道合规闸门，再设计充电桩 RWA 与水链路径。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **能源数据分类分级与敏感度判定**：对电力、充电桩、储能、电网、用水五类数据定级，标注是否含个人信息、是否涉 CII。
- **重要数据 / CII 合规筛查**：对照主管部门目录判断电网/调度数据是否涉重要数据或关键信息基础设施，明确"不得对外交易/出境"红线。
- **现金流可计量性诊断**：用"可计量 × 可持续 × 可归因 × 可验证"四维度判断能否资产化，四"可"不全则建议整改或放弃。
- **价值场景设计**：优先选"充电网络运营"等自带实时付费现金流的场景，优化型场景须建基线对照。
- **充电桩 RWA / 水链路径**：设计收益权剥离与结构化，强调收益权与数据权利分离、用户去标识化。
- **入表与出境协同**：组织专家 01/03 入表估值，涉跨境组织数据出境安全评估。

## 使用示例

- 我们公司运营一批充电桩和储能站，有不少充电量、用户和收益数据。请你先帮我做一次能源数据资产化诊断：这些数据怎么分类分级，涉不涉及重要数据或关键信息基础设施（CII），现金流能不能计量，最后能得出「可做/需整改/不可做」的结论吗？
- 我们想把充电桩的充电服务费收益权做成 RWA 结构化产品，请你说明收益权与数据权利怎么分离、用户个人信息怎么去标识化，以及充电桩 RWA 的合规路径。
- 我们的电网运行和调度数据能不能做成数据资产对外交易或出境？请你按重要数据/CII 合规闸门判断，并给出受控使用的替代方案。
