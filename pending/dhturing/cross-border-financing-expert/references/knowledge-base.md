# 境外发行与跨境融资专家

> 所属战队：05-金融化
> 专家编号：33
> 核心使命：设计并执行「境内资产 → 境外资本」的合规通路，把数据资产卖到全球资本市场

## 第一部分 · 知识库

### 1.1 一句话定位

境外发行与跨境融资专家处理**跨越关境**的资本运作。核心命题是：境内企业持有数据资产，如何从境外资本市场融资（包括传统路径与代币化新路径）。

这条线的难点有三：
1. **外汇与跨境资金流动**的监管
2. **数据出境**的合规（与专家 37 交叉）
3. **境外法律与监管**的适用

**政策依据的关键突破**：《境内资产境外发行资产支持证券代币办事指南》与《监管指引》为"境内资产 + 境外发行 + 代币化"提供了明确路径。这是本专家最重要的政策依据。

### 1.4 核心模型二：跨境代币化发行的合规流程

这是本专家最核心的新知识（依《办事指南》）：

```
① 资产准备 → ② 境内备案 → ③ 境外SPV设立 → ④ 数据出境合规
                                                    ↓
⑧ 存续管理 ← ⑦ 发行上市 ← ⑥ 境外合规发行 ← ⑤ 法律架构 ←┘
```

**① 资产准备**
- 境内资产权属清晰（已登记）
- 有稳定现金流（ABS 属性）
- 完成评估

**② 境内备案**
- 依《监管指引》向境内监管机构备案
- 材料：资产情况、发行方案、法律意见
- 这是**前置条件**，未经备案不得开展

**③ 境外 SPV 设立**
- 在合规辖区设立 SPV（香港、新加坡等）
- 由 SPV 持有境内资产（通过合规的跨境结构）

**④ 数据出境合规**
- 如涉及数据出境，需完成安全评估/备案/认证
- 依《数据出境安全评估办法》
- 这是**最容易被忽视但最关键的环节**（与专家 37 紧密协作）

**⑤ 法律架构**
- 境内外法律意见书
- 确定证券法适用与豁免
- KYC/AML 安排

**⑥ 境外合规发行**
- 在境外合规平台发行
- 面向合格投资者

**⑦ 发行上市**
- 募集资金

**⑧ 存续管理**
- 收益分配（跨境支付，用 CIPS 等）
- 定期披露
- 储备证明

### 1.6 核心模型四：跨境融资的四重合规门

这是本专家最重要的风险框架。跨境项目必须同时过四道门：

| 门 | 依据 | 要点 | 主管 |
|---|---|---|---|
| **门一：外汇门** | 《外汇管理条例》 | 跨境资金流动合规、外债登记 | 外汇局 |
| **门二：数据门** | 数据出境相关法规 | 数据出境安全评估/备案/认证 | 网信办 |
| **门三：证券门** | 境外发行监管规则 | 境内备案 + 境外合规 | 证监会 + 境外监管 |
| **门四：境外法门** | 辖区法律 | 证券法、AML、税务 | 境外监管 |

**重要提示**：四道门**缺一不可**。常见的失败案例是"只关注境外发行合规，忽略了数据出境和外汇"。

### 1.7 常见问题与标准答复

**Q1：数据资产能拿到境外融资吗？**
A：可以，但目前路径较窄。最明确的是《境内资产境外发行资产支持证券代币办事指南》确立的路径。另有跨境担保、境外上市等传统路径。

**Q2：数据出境是必须的吗？**
A：如果境外发行涉及数据出境（如把数据本身或数据产品转移到境外），是的。如果只是**资产权利**的跨境安排而不涉及数据本体出境，可能不涉及——需专业判断。

**Q3：跨境代币化发行要多久？**
A：前置备案 + 境外设立 + 合规审查，通常 6~12 个月甚至更长。

**Q4：熊猫债是什么？**
A：境外主体在境内发行的人民币债券。对境内企业来说是反向参照——理解跨境结构的一种方式。

**Q5：新加坡上市借壳可行吗？**
A：是常见路径之一（本库有方案）。但借壳上市有严格监管，需评估壳公司质量与合规性。

### 2.2 标准作业流程 SOP

**S0 路径比选（2~4周）**
1. 评估客户资产与需求
2. 五条路径逐项比选：
   - 境外发债：看信用评级
   - 境外上市：看规模与合规
   - 跨境 ABS/代币化：看现金流与备案可行性（**推荐优先评估**）
   - 跨境担保：看是否有境外主体
   - QFLP/QDLP：看投资需求
3. 输出《跨境融资路径方案》

**S1 资产适格性评估（2~4周）**
1. 核查：
   - 资产权属清晰（已登记）
   - 有稳定现金流
   - 估值合理
   - 规模足够
2. 输出《跨境适格性评估》

**S2 境内备案（4~8周，前置关键）**
1. 依《监管指引》准备备案材料：
   - 资产情况说明
   - 发行方案
   - 法律意见书
   - 风险评估
3. 提交境内监管备案
4. 取得备案回执
5. 输出备案材料与回执

**S3 境外 SPV 设立（4~8周）**
1. 选择辖区（香港/新加坡等）
2. 设立 SPV
3. 设计跨境持股/持有结构
4. 办理境外公司注册
5. 输出《境外架构方案》与注册文件

**S4 数据出境合规（4~12周，关键）**
1. 判断是否涉及数据出境
2. 如需：
   - 数据出境安全评估（涉重要数据/大量个人信息）
   - 或标准合同备案
   - 或保护认证
3. 完成出境合规手续（与专家 37 协作）
4. 输出出境合规文件

**S5 外汇合规（2~4周）**
1. 办理外债登记（如涉及外债）
2. 或办理跨境担保登记
3. 或办理境外发行登记
4. 输出外汇登记文件

**S6 法律架构（4~8周）**
1. 境内法律意见书（专家 14）
2. 境外法律意见书（境外律所）
3. 确定证券法适用与豁免
4. KYC/AML 方案
5. 输出法律意见与架构文件

**S7 中介组织（4~8周）**
1. 境内：券商、律所、会所、评估
2. 境外：当地律所、承销商、托管、审计
3. 组织跨境尽调
4. 输出中介机构清单

**S8 发行执行（8~16周）**
1. 编制发行文件
2. 境外路演
3. 发行认购
4. 资金到位（跨境结算，用 CIPS 等）
5. 输出发行结果

**S9 跨境结算设计（2~4周）**
1. 设计资金回流路径
2. 选择结算工具（CIPS/SWIFT/信用证）
3. 办理结算手续
4. 输出《跨境结算方案》

**S10 存续管理（持续）**
1. 跨境收益分配
2. 定期披露
3. 应对境内外监管检查
4. 输出存续报告

### 2.6 关键话术

**对客户**：
- "跨境融资有四道门：外汇、数据、证券、境外法。任何一道没过，项目就停。"
- "《办事指南》给了明确路径，但流程长（6~12 个月），要提前规划。"
- "最容易漏的是数据出境合规——很多人只盯着境外发行规则。"

**风险提示（必须充分告知）**：
1. **数据出境是最容易遗漏的合规门**——很多项目在此卡住
2. 外汇登记不可省略，否则资金无法合规进出
3. 境内备案是前置条件，未备案不得开展
4. 境内禁止代币公开发行（红线）
5. 境外法律管辖复杂，必须聘请境外律师
6. 政策快速变化（尤其代币化方向），需持续跟踪
7. 流程周期长（6~12 个月+），客户预期需管理
8. 本库材料多为方案与设计，实际落地需专业机构深度参与
