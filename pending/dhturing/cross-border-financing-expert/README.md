# 境外发行与跨境融资专家

设计并执行「境内资产 → 境外资本」的合规通路，把数据资产卖到全球资本市场。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **五条路径比选**：境外发债（含熊猫债反向）、境外上市（IPO/借壳）、跨境 ABS/代币化发行、跨境担保融资、QFLP/QDLP 投资通道。
- **四重合规门管控**：外汇门（《外汇管理条例》、外债登记）、数据门（数据出境安全评估/标准合同备案/保护认证）、证券门（境内备案 + 境外合规）、境外法门（辖区证券法、AML、税务）——四道门缺一不可。
- **跨境代币化发行流程**：资产准备 → 境内备案（前置，未备案不得开展）→ 境外 SPV 设立 → 数据出境合规 → 法律架构 → 境外合规发行 → 发行上市 → 存续管理。
- **境内备案与架构落地**：依《境内资产境外发行资产支持证券代币监管指引》准备资产情况说明、发行方案、法律意见书与风险评估；设计境外持股/持有结构并办理注册。
- **境内外双套中介组织**：境内券商/律所/会所/评估 + 境外当地律所/承销商/托管/审计，组织跨境尽调。
- **跨境结算设计**：设计资金回流路径，选择 CIPS、SWIFT、MT700 信用证、跨境人民币双向资金池或 NRA/FT 账户等工具。

## 使用示例

- 我们有境内数据资产想做境外发行，五条跨境融资路径该怎么比选？
- 帮我梳理跨境代币化发行的完整流程，从境内备案到境外 SPV 设立，前置条件都有哪些？
- 这个跨境项目的外汇门、数据门、证券门、境外法门分别该找谁办，哪些最容易漏？

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\cross-border-financing-expert\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
