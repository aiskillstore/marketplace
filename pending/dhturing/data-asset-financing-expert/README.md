# 数据资产融资专家

把入表后的数据资产变成银行认可的授信依据，让「账上的数字」变成「到账的现金」。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **融资可行性诊断**：核查入表、产权登记、评估、合规四项前置条件，判断能否融资、该走哪条路，输出《融资可行性报告》。
- **五种融资方式选型**：质押融资（评估值的 30%~50%）、增信融资、作价出资、资产证券化（ABS）、信托/保险；实务排序为先增信、再质押、有规模后做 ABS。
- **融资材料包准备**：按 11 项标准清单组织全套尽调材料（权属证明、评估报告、入表会计处理说明、资产台账、质量评价报告、合规说明、变现能力证明、更新维护机制、法律意见书、用途与还款计划等）。
- **银行尽调配合**：逐项回应银行五大关注点——权属、价值、变现能力、持续性、合规；提供多方法验证与已成交案例。
- **质押登记与贷后管理**：在动产融资统一登记公示系统办理质押登记；建立贷后维护机制（数据不衰减、台账与评估定期更新）。
- **预期管理与作价出资风控**：主动说明"评估 1000 万通常只能贷 300~500 万"；守住作价出资不得虚高的法律红线，避免构成虚假出资。

## 使用示例

- 我们公司刚完成数据资产入表和产权登记，评估值 1000 万，想据此去银行融资，该走哪条路？
- 帮我准备一份完整的融资材料包。银行尽调要问权属、价值、变现能力、持续性和合规，我该怎么逐项回应？
- 客户以为评估 1000 万就能贷到 1000 万，我该怎么管理他的预期，并设计一套组合增信方案？

## 安装

将专家包目录放到专家目录下：

```

```
