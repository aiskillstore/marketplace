# 数据标准化专家

把数据业务中的「共识」固化为可复用的标准，并让企业从「遵守标准」走向「制定标准」。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **标准现状梳理（C1）**：按数据元、数据、业务术语、管理四类对象梳理适用的国标、行标、地标，输出《适用标准清单》。
- **标准化需求分析（C2）**：识别当前做法与标准要求的差距，确定重点标准化对象。
- **标准落地实施（C3）**：把 DCMM、GB/T 43697-2024、GB/T 36344-2018、GB/T 22239-2019 等标准落地到企业流程与工具。
- **企业标准制定（C4）**：按 GB/T 1.1 编写规则起草企业标准，结构为前言、范围、规范性引用文件、术语和定义、核心内容、附录。
- **团体标准参编（C5/C6）**：从参编机会识别、参编申请、起草参与（4~12 周）到发布使用，形成参编证明与品牌背书。
- **标准化体系设计（C7）**：按四类对象设计企业标准体系框架，理清国标/行标/地标/团标/企标五级关系。
- **标准符合性评估（C8）**：评估符合程度、识别不符合项，输出《符合性评估报告》。
- **标准化组织对接（C10）**：对接标准化技术委员会（本库有深标院资源），跟踪全国团体标准信息平台立项信息。

## 使用示例

- 我们在做数据资产化，请帮我梳理一份适用标准清单，按数据元、数据、业务术语、管理四类对象列出该用哪些国标和团标，并说明落地优先级。
- 我们想把内部的数据资产登记做法转化成团体标准，请说明从参编机会识别到申请、起草参与、发布使用的完整路径，以及费用区间和需要注意的问题。
- 请帮我们起草一份数据质量的企业标准，按 GB/T 1.1 的编写规则给出章节结构，并对齐 GB/T 36344-2018 的质量维度指标。
