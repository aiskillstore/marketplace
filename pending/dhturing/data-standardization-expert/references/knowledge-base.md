# 数据标准化专家

> 所属战队：06-合规安全与政策
> 专家编号：39
> 核心使命：把数据业务中的「共识」固化为可复用的标准，并让企业从「遵守标准」走向「制定标准」

---

## 第一部分 · 知识库

### 1.1 一句话定位

数据标准化专家处理数据领域**从国标到团标到企标**的三层标准化工作。他的价值有两层：

1. **用标准**：把国家标准、行业标准落地到企业的数据资产化工作中（提高规范性、可审计性）
2. **定标准**：参与标准制定（团体标准、行业标准），把企业的实践变成行业规则——**这是最高级的竞争壁垒**

本库有相关基础材料：`深标院\`（标准化技术委员会）、`同步合作资料\团体标准参编`、`学习资料\标准与规范`（7份）、`最新政策\` 中的《资产管理 数据资产登记指南》《资产管理 数据资产分类与代码》。

**标准层级：**
```
国家标准（GB/T）    ← 全国适用，强制或推荐
    ↓
行业标准（YD/T 等） ← 行业适用
    ↓
地方标准（DB）      ← 地方适用
    ↓
团体标准（T/）      ← 社会团体制定，市场自愿采用
    ↓
企业标准（Q/）      ← 企业自定
```

### 1.3 核心模型一：数据标准化四类对象

数据标准化不是一件事，涉及四类对象：

| 类型 | 内容 | 示例 |
|---|---|---|
| **数据元标准** | 字段级定义（名称、类型、长度、值域） | "企业统一社会信用代码"的规范定义 |
| **数据标准** | 数据的分类、编码、格式 | 数据资产分类与代码 |
| **业务术语标准** | 统一业务概念（消除同名异义） | "活跃用户"的准确定义 |
| **管理标准** | 流程、职责、方法的标准 | 数据资产登记流程标准 |

### 1.4 核心模型二：标准化工作的五步法

```
① 需求识别 → ② 现状调研 → ③ 标准起草 → ④ 征求意见 → ⑤ 发布实施
```

**① 需求识别**
明确要标准化什么（哪个数据、哪个流程）、为什么（解决什么问题）。

**② 现状调研**
了解现有做法、行业惯例、上级标准要求。避免重复造轮子。

**③ 标准起草**
按标准编写规则（GB/T 1.1）起草文本。结构通常为：
```
前言 → 范围 → 规范性引用文件 → 术语和定义
→ 核心内容（分类/要求/方法）→ 附录
```

**④ 征求意见**
向相关方征求意见，修改完善。团标/行标/国标有严格的征求意见程序。

**⑤ 发布实施**
- 企标：企业发文
- 团标：团体发布（在全国团体标准信息平台公示）
- 行标/国标：主管部门发布

### 1.5 核心模型三：参与标准制定的价值

这是本专家**最高价值**的知识点。为什么企业要参与标准制定？

| 价值 | 说明 |
|---|---|
| **话语权** | 标准是行业规则，参与制定=参与定规则 |
| **壁垒** | 标准倾向采用制定者的技术路线，形成天然优势 |
| **品牌** | "某某标准起草单位"是强力的品牌背书 |
| **客户信任** | 政府/国企客户非常看重标准参与经历 |
| **前置优势** | 提前知道标准方向，可以提前布局 |
| **资质加分** | 招投标、政策申报中标准参与常是加分项 |

**参与方式（由易到难）：**
1. **参编团体标准**（门槛最低，本库已有材料）
2. **参与行业标准**（需行业影响力）
3. **参与国家标准**（需较强实力）
4. **主导制定**（需权威地位）

**实务建议**：从**团体标准参编**切入。很多标准化技术委员会欢迎企业参编，成本不高，收益明显。

### 1.6 核心模型四：标准化与数据资产化的关系

标准化是数据资产化的**隐形基础设施**：

| 资产化环节 | 需要什么标准 | 相关标准 |
|---|---|---|
| 数据治理 | 数据元、术语、质量 | GB/T 36344、DCMM |
| 权属登记 | 资产分类、登记规则 | 《资产管理 数据资产分类与代码》《登记指南》 |
| 质量评价 | 质量指标 | GB/T 36344 |
| 安全管控 | 分类分级、等保 | GB/T 43697、GB/T 22239 |
| 产品交易 | 产品描述、标的规范 | 数据产品交易标准化白皮书 |
| 资产评估 | 评估方法 | 数据资产评估指导意见 |
| 台账管理 | 台账规范 | 登记指南 |

**核心洞察**：**没有标准，数据资产就难以被可比、可验证、可流通**。标准是"共识的固化"，而资产交易的前提是共识。

### 1.7 常见问题与标准答复

**Q1：我们小企业需要做标准化吗？**
A：需要，但不必自己造标准。**采用现有标准**即可（如 GB/T 36344 做质量、GB/T 43697 做分级）。只有行业领先者才需要制定标准。

**Q2：团体标准有什么用？**
A：三个作用——① 市场自愿采用，可成为事实标准；② 参与成本低，是进入标准化领域的入口；③ 品牌背书（"XX 标准起草单位"）。

**Q3：参与标准制定要花多少钱？**
A：团体标准参编费用通常几万到十几万（含参编费、会议费）。国标/行标成本更高但门槛也更高。

**Q4：我们的内部标准能变成团标吗？**
A：可以。如果企业的实践有普适性，可以通过行业协会/学会转化为团体标准。本库的 `同步合作资料\团体标准参编` 就是这个路径的材料。

**Q5：标准一定要遵守吗？**
A：GB 强制性国家标准必须遵守；GB/T 推荐性标准、团标、行标是自愿采用，但**一旦在合同/声明中引用，就成为约束**。

### 2.2 标准作业流程 SOP

**【标准应用流程】**

**S0 适用标准梳理（1~2周）**
1. 按四类对象（数据元/数据/术语/管理）梳理
2. 列出适用的国标、行标、地标
3. 输出《适用标准清单》

**S1 标准化需求分析（1~2周）**
1. 识别当前做法与标准要求的差距
2. 确定需要标准化的重点对象
3. 输出《标准化需求报告》

**S2 标准落地实施（2~4周）**
1. 选择优先落地项（如先做数据元标准、分类分级）
2. 制定实施计划
3. 组织落地（工具、流程、培训）
4. 输出《标准实施方案》与落地证据

**S3 企业标准制定（按需，3~6周）**
1. 起草企业标准（按 GB/T 1.1 规则）
2. 内部评审
3. 发布实施
4. 输出企业标准文本

**【标准参编流程】**

**S4 参编机会识别（1~2周）**
1. 关注团体标准立项信息（全国团体标准信息平台）
2. 对接标准化技术委员会（本库有 `深标院` 资源）
3. 评估价值与成本
4. 输出参编机会清单

**S5 参编申请（2~4周）**
1. 提交参编申请（单位资质、技术能力、参编人）
2. 缴纳参编费用
3. 确认参编单位/参编人身份
4. 输出参编确认文件

**S6 标准起草参与（4~12周）**
1. 参加起草工作组会议
2. 提交技术建议
3. 参与征求意见稿讨论
4. 参与标准文本修订
5. 输出参编工作记录

**S7 标准发布与使用（持续）**
1. 标准发布后获得参编证明
2. 用于品牌宣传（"XX 标准起草单位"）
3. 用于客户沟通与招投标
4. 输出标准文本与参编证明

**【标准化体系流程】**

**S8 企业标准体系设计（2~4周）**
1. 按四类对象设计标准体系框架
2. 明确各级标准的关系
3. 输出《企业标准体系》

**S9 符合性评估（2~3周）**
1. 评估对适用标准的符合程度
2. 识别不符合项
3. 输出《符合性评估报告》

### 2.6 关键话术

**对客户（标准应用）**：
- "国家标准是'共用语言'。按国标做，您的数据资产才能被别人看懂、认可、接受。"
- "比如质量评价按 GB/T 36344、分类分级按 GB/T 43697，这是行业通用语言。"

**对客户（标准参编）**：
- "参与标准制定是从'遵守规则'变成'制定规则'。这是最高级的竞争壁垒。"
- "建议先从团体标准参编切入，成本不高、收益明显，还能用于招投标加分。"

**对内部**：
- "我们把最好的实践沉淀成标准，既能服务客户，也能占据行业话语权。"

**风险提示**：
1. 标准引用前必须**核实现行有效性**（标准会被修订或废止）
2. 强制性国标（GB）必须遵守，不得以推荐性标准替代
3. 参编要**有实际技术贡献**，纯挂名在专业圈子里会损害声誉
4. 标准一旦被合同引用即具约束力
5. 制定团体标准需符合《标准化法》要求，避免与国标冲突
6. 标准参编费用需评估性价比，不必盲目参与
