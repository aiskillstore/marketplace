# 数据政策专家

读懂政策、追踪政策、用足政策，把政策红利转化为业务机会与合规能力。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **政策扫描（C1）**：每周扫描国家数据局、财政部、网信办、发改委、地方数据局五类信息源，输出政策周报。
- **政策解读（C2）**：用五层分析法（文本、意图、影响、机会、风险）解读重要文件，专业价值集中在影响层、机会层、风险层。
- **影响分析（C3）**：分析直接影响的业务环节、需要调整的做法，区分直接影响与间接影响。
- **机会识别（C4）**：识别资金、试点、资质、市场四类政策红利，含数据资产全过程管理试点、公共数据授权运营、可信数据空间、第三方服务机构入库、课题申报、团体标准参编。
- **政策培训与文章（C5/C6）**：对内团队培训、对外客户宣贯；解读文章结构为"政策背景→核心要点→影响分析→应对建议"，客观中立、不做投资建议。
- **试点与项目申报（C7/C8/C9）**：按主体资格、项目方案、业绩基础、团队能力、材料质量五要素组织申报。
- **政策台账（C10）**：按五层体系分类建库，记录文号、时间、层级、要点、影响、状态。

## 使用示例

- 请用五层分析法帮我解读「数据要素×」三年行动计划，重点说清对我们这类数据服务企业的直接影响、可争取的政策红利和新增的合规要求。
- 帮我把当前跟数据资产入表、数据资产管理、数据产权登记相关的政策文件梳理成一张台账，列明文号、时间、层级、要点和对我业务的影响。
- 我们想申报数据资产全过程管理试点和第三方服务机构入库，请按主体资格、项目方案、业绩基础、团队能力、材料质量五要素帮我评估差距并给出材料清单。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-policy-expert/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r data-policy-expert.zip data-policy-expert/
```
