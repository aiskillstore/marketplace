## 长简介（中文，可直接粘贴）

数据资产ABS-REITs专家是图灵数盟数据专家体系的成员，把数据资产未来产生的现金流打包成证券卖给投资人，实现一次融资、多方受益的规模化资本运作。把数据资产未来现金流打包成证券，判断五个硬条件、做压力测试、设计SPV分层与双重增信并组织发行。

## Long description (EN)

Package data-asset cash flows into securities: check the five hard conditions, run stress tests, design SPV and tranching, and organize intermediaries through issuance.
