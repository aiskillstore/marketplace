## 内容索引

- **1.1 一句话定位**：给数据「体检」，结论决定能否入表、δ 折扣系数怎么打、数据产品能否卖出好价；最容易被低估但最不该省略的环节
- **1.2 政策与标准依据**：GB/T 36344-2018（核心标准）、DCMM GB/T 36073-2018 质量域、工信部实施指南、中评协〔2023〕17号、财会〔2023〕11号、行业数据质量规范
- **1.3 核心模型 · 数据质量六维**：准确性 / 一致性 / 完整性 / 规范性 / 时效性 / 可访问性，每维的定义、关键指标、常见问题
- **1.4 六维打分方法**：百分制 + 等级制双轨；通用 / 交易 / 入表三套权重表；A（90~100）/ B（75~89）/ C（60~74）/ D（<60）等级划分与对应结论
- **1.5 质量与价值的量化桥梁**：δ 系数 = 质量维度加权得分映射；A 0.9~1.2 / B 0.7~0.9 / C 0.5~0.7 / D <0.5 或不做
- **1.6 关键数据口径**：抽样 vs 全量（含抽样方法、样本量、置信度）、检测基准日、规则表达式化、缺陷三级分级
- **1.7 常见问题与标准答复**：Q1 测多细 / Q2 分数能否改高 / Q3 D 级怎么办 / Q4 报告谁出
- **1.8 源材料索引**：数据质量评价系统代码、六维质量指标、燕然数据资产系统白皮书、标准与规范、DCMM 质量域
- **2.1 能力清单**：C1 质量指标体系设计 ~ C8 质量监控设计
- **2.2 标准作业流程 SOP**：S0 需求确认 ~ S8 复检与移交（含 S5 九段式报告结构）
- **2.3 交付物清单**：01 需求说明书 ~ 09 质量监控方案
- **2.4 质量校验清单**：10 项交付前必查
- **2.5 协作接口**：上游 02；下游 03/01/17/15；平行 35/07
- **2.6 关键话术与风险提示**：3 条话术 + 3 条风险（保密协议与只读权限、不得留存数据本体、虚高连锁风险）
