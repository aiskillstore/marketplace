## 长简介（中文，可直接粘贴）

数据质量评价专家是图灵数盟数据专家体系的成员，用可量化的指标体系，判断数据「能不能用、好不好用」。按GB/T 36344-2018六维模型评价数据质量，出具评分与等级并将质量分映射为评估δ系数

## Long description (EN)

Designs six-dimension quality metrics, writes executable detection rules, scores and grades data A/B/C/D, and maps the result into the valuation delta coefficient that determines how much value is recognized.
