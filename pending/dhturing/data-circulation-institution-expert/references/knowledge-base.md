## 第一部分 · 知识库

### 1.1 一句话定位

数据流通服务机构专家处理的不是"卖一份数据"，而是**"如何以机构身份参与数据流通生态"**。他服务的对象通常是：

- 想做数商认证、加入生态的企业
- 想建设/运营数据交易平台的主体
- 想申请成为数据流通服务平台的企业

这个方向的政策依据是**国数政策〔2026〕6号《培育数据流通服务机构 加快推进数据要素市场化价值化的意见》**——这是把数据流通服务体系正式确立的最新标志性文件，也直接框定了本专家的知识范围。

### 1.3 核心模型一：三类机构分工

国数政策〔2026〕6号确立了数据流通服务机构的三类构成：

| 类型 | 定位 | 核心功能 | 典型主体 |
|---|---|---|---|
| **数据交易所** | 基础设施/枢纽 | 提供交易场所、规则、撮合、结算、合规审核、凭证 | 深数所、上数所、北数所 |
| **数据流通服务平台企业** | 区域性/行业性服务 | 提供流通服务、区域或行业聚焦、灵活机制 | 各地数据交易中心、行业平台 |
| **数据商** | 市场服务主体 | 数据产品开发、数据经纪、数据评估、数据合规等专业服务 | 图灵数盟及同类企业 |

**关键理解**：
- 交易所是"场地"，提供规则与公信力
- 平台企业是"区域/行业的中介"
- 数据商是"产业链上的专业服务者"——**这是大多数企业可切入的位置**

### 1.4 核心模型二：数据商的业务类型

数据商不是单一角色，按业务类型可分：

| 类型 | 业务内容 | 图灵数盟是否具备 |
|---|---|---|
| **数据产品开发商** | 开发数据产品供交易 | ✅ 强 |
| **数据经纪商** | 撮合供需、代理交易 | ✅ 有（专家19） |
| **数据评估服务商** | 质量评价、价值评估 | ✅ 有（专家03、04） |
| **数据合规服务商** | 合规咨询、合规审查 | ✅ 有（专家34） |
| **数据治理服务商** | 治理、盘点、标准化 | ✅ 有（专家02、05） |
| **数据资产入表服务商** | 入表全流程服务 | ✅ 核心（专家01） |
| **数据技术提供商** | 提供技术平台工具 | ✅ 有（专家41） |
| **数据金融服务商** | 融资、ABS、RWA | ✅ 有（专家28-33） |

**图灵数盟的定位判断**：不是单一数据商，而是**综合型数据商 / 数据流通服务机构**——本库的 15 家数交所数商认证、福建大数据交易平台数商证书都印证了这一点。

### 1.5 核心模型三：资质体系全景

| 层级 | 资质 | 获取方式 | 作用 |

| **数商资质** | 数商认证/证书 | 申请+审核 | 可提供数商服务 |
| **专业资质** | 资产评估资质 | 财政部/中评协备案 | 可出具评估报告 |
| **专业资质** | 律师执业资质 | 司法部 | 可出具法律意见书 |

### 1.6 核心模型四：机构建设四要素

如果一个主体要建设数据流通服务机构，需要四要素齐备：

| 要素 | 内容 | 门槛 |
|---|---|---|
| **资质** | 主体资格 + 数商认证 + 专业资质 | 中 |
| **能力** | 数据产品开发、评估、合规、技术 | 高 |
| **生态** | 交易所关系、买方资源、专家网络 | 高 |
| **合规** | 数据安全制度、等保、审计 | 中 |

**判断**：资质是入场券（可快速取得），能力是内核（需长期积累），生态是壁垒（最难复制）。图灵数盟的优势在**能力 + 生态**，这是本库资料反复体现的核心竞争力。

### 1.7 常见问题与标准答复

**Q1：数据商认证有什么用？**
A：三个实际作用：① 可以合规承接交易所撮合的业务；② 对外是能力背书（尤其政府、国企客户看重）；③ 进入生态网络，获得撮合机会。

**Q2：我们要不要自己建交易所？**
A：不建议。交易所是重资产、强监管、需要政府背书的业务。多数企业的合理定位是**数据商**，或参与**平台企业**的运营。

**Q3：数商认证好拿吗？**
A：相对好拿。通常提交主体材料、能力证明、合规承诺，通过审核即可。门槛在"持续经营"而不是"取得"。

**Q4：数商是"卖数据的"吗？**
A：不全是。数商更多是**服务提供者**——帮别人把数据变成资产、把资产变成交易，不一定自己持有数据。

**Q5：国数政策〔2026〕6号对我们意味着什么？**
A：把数据流通服务确立为**受政策支持的正式业态**，意味着：① 有了明确身份认定；② 有政策支持（可能含资金、税收、项目）；③ 有了规范要求（需合规经营）。

### 2.2 标准作业流程 SOP

**S0 定位诊断（1~2周）**
1. 评估自身资源禀赋（能力、资质、资金、生态）
2. 判断适合的角色（交易所/平台企业/数商）
3. 输出《机构定位方案》

**S1 资质规划（1周）**
1. 列出目标角色所需资质
2. 评估现状差距
3. 制定获取顺序（先易后难、先必需后增强）
4. 输出《资质获取路线图》

**S2 数商/会员申请（2~6周）**
1. 准备材料：主体资格、能力证明、合规承诺、案例
2. 提交目标交易所
3. 配合审核
4. 取得证书
5. 输出数商认证/会员证书

**S3 政府入库申请（2~4周，可选）**
1. 填写第三方服务机构入库申请表
2. 提交能力与业绩证明
3. 取得入库资格
4. 输出入库通知

**S4 合规体系建设（4~8周）**
1. 建立数据安全管理制度（含等保）
2. 建立服务合规流程（尽调、审核、留痕）
3. 建立内部风控与审计
4. 输出《合规管理制度》系列

**S5 服务产品化（2~4周）**
1. 把专业能力打包为标准化服务产品
2. 明确服务内容、交付物、价格、周期
3. 输出《服务产品目录》

**S6 生态网络建设（持续）**
1. 建立交易所合作关系
2. 发展买方网络
3. 建立专家/机构合作伙伴网络
4. 输出《合作伙伴名录》

**S7 政策申报（按需）**
1. 跟踪政策支持方向
2. 组织申报材料
3. 提交申报
4. 输出申报材料

**S8 持续经营（常态化）**
1. 维持资质有效（年审、续期）
2. 积累业绩案例
3. 提升机构等级/扩大覆盖

### 2.6 关键话术

- "数据流通服务体系里，交易所是场地，平台是中介，数商是专业服务者。多数企业的合理位置是数商。"
- "数商认证门槛不高，难的是持续有业务。"
- "国数政策〔2026〕6号把数据流通服务确立为正式业态，这是政策红利的窗口期。"

**风险提示**：
1. 数商认证不等于有业务，需真实的获客能力
2. 多地数商认证存在重复认证成本，需评估性价比
3. 交易所会员有年费与业务量要求
4. 合规经营是持续要求，违规可能被清退
5. 政策处于快速演进期，需持续跟踪调整定位
