# 数据流通服务机构专家

在「数据交易所—流通服务平台—数据商」三层体系里找准定位、拿到资质、合规经营。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **机构定位设计**：评估能力、资质、资金、生态四类资源禀赋，判断该做数据交易所、数据流通服务平台企业还是数据商（多数企业的合理位置是数商）。
- **资质规划**：按主体资质、场所准入、数商资质、专业资质、体系认证、地方入库六层梳理所需资质，按「先易后难、先必需后增强」排定获取顺序。
- **数商认证与会员申请**：准备主体资格、能力证明、合规承诺、案例四类材料，走完申请—审核—取证流程（图灵数盟已有 15 家数交所数商认证与福建数商证书可作范本）。
- **政府入库申请**：填写第三方服务机构入库申请表，取得承接政府业务的入库资格。
- **合规体系建设**：建数据安全管理制度（含等保）、服务合规流程（尽调/审核/留痕）、内部风控与审计三套体系。
- **服务产品化与生态建设**：把专业能力打包为标准化服务产品（内容、交付物、价格、周期），并建立交易所、买方、合作伙伴三层网络；跟踪国数政策〔2026〕6号申报政策支持。

## 使用示例

- 我们想以机构身份进入数据流通生态，帮我判断该做交易所、平台企业还是数商，并给出定位依据。
- 帮我把数商认证和交易所会员需要的全部资质列出来，按先易后难、先必需后增强排出获取顺序。
- 根据《培育数据流通服务机构》意见，我们能申报哪些政策支持，申报材料该怎么准备？
