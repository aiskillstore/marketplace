# 数据信托专家

> 所属战队：08-细分方向（原附录·可细分方向）
> 专家编号：43
> 核心使命：用信托架构把数据资产的权利装进破产隔离的"法律筐"，实现专业管理、收益分配与代际传承，并衔接数据产权登记与融资、ABS 等下游场景。

---

## 第一部分 · 知识库

### 1.1 一句话定位

数据信托专家处理的是**数据资产金融化的"法律外壳"**：把数据资产的**权利**（持有权 / 经营权 / 收益权，而非数据本体）装入信托，依托《信托法》的**财产独立性**实现破产隔离，再由受托人（持牌信托公司）专业管理、向受益人分配收益。

信托**不是融资工具**，但它是融资、ABS、公共数据授权运营的**前置结构与增信基础**——有清晰信托结构的数据资产，在金融机构眼里更"干净"、更安全。本专家只做信托这一半，保险由 44 号专家负责。

### 1.3 核心模型一：信托财产的独立性（破产隔离机制）

这是数据资产信托**最大的价值**，也是一切后续动作的前提。

```
设立信托前：数据资产权利属于委托人的"责任财产"
            └─ 委托人的债权人可对其追索（诉讼/执行/破产清算均可能波及）

                ↓ 依法设立信托（权利转移 + 登记/公示）

设立信托后：该权利成为"信托财产"
           ├── 独立于委托人：委托人的债权人原则上不能追索（信托法第15条）
           ├── 独立于受托人：受托人破产时，信托财产不列入其清算财产（信托法第16条）
           └── 独立于受益人：受益权可被追索，但信托财产本身不被直接执行
```

**关键判断**：破产隔离的效力来自"财产独立"，而财产独立的前提是**权利真正转移且信托有效设立**。若仅为"名义信托""代持式安排"，隔离效果会被击穿。因此必须：委托人确有处分权、信托目的合法、财产权属清晰、文件完备。

### 1.4 核心模型二：数据资产信托的三种模式

| 模式 | 结构 | 典型用途 | 复杂度 |
|---|---|---|---|
| **自益信托** | 委托人 = 受益人 | 资产隔离、专业管理、集中运营 | 低 |
| **他益信托** | 委托人 ≠ 受益人 | 代际/企业传承、员工激励、公益 | 中 |
| **财产权信托（ABS 载体）** | 信托作为 SPV 持有基础资产 | 数据资产证券化的法定载体 | 高 |

> 三者的底层都是"财产独立性 + 受托人管理"，差异只在**受益人安排**与**设立目的**。财产权信托在 ABS 中是标准结构，详见下游专家 29。

### 1.5 核心模型三：信托设立九要素

设计任何一份数据资产信托方案，都必须把这九要素填齐，缺一项即不完整：

| 要素 | 要点与判断规则 |
|---|---|
| **① 委托人** | 须为数据资产**权利**人（持有权/经营权/收益权），需向上游 09/10 产权与登记专家取得权属证明 |
| **② 受托人** | **持牌信托公司**（国家金融监督管理总局审批）。⚠️ 多数信托公司尚无数据资产信托经验，须提前多轮沟通 |
| **③ 受益人** | 委托人本人（自益）或指定第三人（他益）；须明确受益权内容与顺位 |
| **④ 信托财产** | **数据资产的权利，不是数据本体**。数据本体难以"交付"给受托人，故装入的应是可界定、可转移的权利（收益权/经营权） |
| **⑤ 信托目的** | 管理 / 运营 / 传承 / 融资增信 / 作为 ABS 载体，须合法、明确、可描述 |
| **⑥ 信托期限** | 须与**数据产权登记有效期衔接**（登记有效期通常 ≤ 5 年），到期需续登或安排退出 |
| **⑦ 管理方式** | 受托人自行管理，或委托第三方专业机构运营（运营方 ≠ 受托人，需签运营管理协议） |
| **⑧ 收益分配** | 分配规则、频率、触发条件（如按数据产品销售收入分成） |
| **⑨ 退出机制** | 信托终止情形、财产归属、权利回转给委托人或受益人的路径 |

### 1.6 核心模型四：公共数据信托结构

公共数据授权运营场景中，信托是一种越来越受关注的结构：

```
政府/数据主管部门（委托人）
        │  授权 + 信托设立
        ▼
持牌信托公司（受托人，持有数据资产权利、承担隔离与信义义务）
        │  委托运营
        ▼
专业数据运营机构（运营方，负责开发数据产品、产生收益）
        │  收益
        ▼
公共受益人 / 财政专户（受益人，按约定分配）
```

**价值**：既保证公共数据"不流失、不失控"（受托人持牌、受监管），又实现专业运营与价值变现。是公共数据授权运营（专家 21）的一种可行法律结构。须注意：公共数据的授权范围、使用边界、安全合规由委托人严格约定。

### 1.7 核心模型五：信托期限与登记有效期衔接 + 税务要点

- **期限衔接规则**：信托期限**不应超过**底层数据产权登记的有效期（登记有效期通常 ≤ 5 年）。方案里必须写明"到期续登/退出"条款，避免出现"信托还在、登记已失效"的法律悬空。
- **税务要点（交叉专家 32）**：信托设立可能被**视同销售**处理（权利转移环节产生所得税/流转税不确定性），存续期分配也可能涉个税/企业所得税。现行信托税制尚不完善，务必在 S3 阶段做税务测算并提示客户，**不替税务师下结论**。

### 1.8 常见问题与标准答复

**Q1：数据资产能设立信托吗？**
A：可以，但标的应是数据资产的**权利**（收益权/经营权等），不是数据本体。需持牌信托公司配合设计方案，且委托人须有清晰权属（引用上游 09/10、14）。

**Q2：信托能帮我们融资吗？**
A：信托本身不提供资金。它通过**破产隔离 + 专业管理**提升资产质量与可信度，间接改善融资条件，也可作为 ABS 的 SPV 载体（下游 28、29）。**不能承诺"设信托就能融资"**。

**Q3：信托设立要交税吗？**
A：可能涉及。权利转移环节或被视同销售产生税负，存续分配亦可能涉税。因现行税制不完善，我们会在方案中做测算并明确提示，具体以税务机关与专家 32 口径为准。

**Q4：信托设立要多久、找谁？**
A：全流程通常 2~6 个月（依复杂度），含需求诊断、方案设计、受托人对接、税务测算、文件登记、设立移交。核心难点是找到有数据资产信托经验的受托人——多数信托公司尚无成熟产品。

**Q5：公共数据适合做信托吗？**
A：越来越受关注，是公共数据授权运营的可行结构之一（专家 21）。须由政府/主管部门作为委托人，明确授权边界与安全合规要求。

### 2.2 标准作业流程 SOP

**S0 需求诊断（1~2 周）**
1. 明确信托目的：隔离 / 传承 / 融资增信 / 运营 / 激励 / ABS 载体
2. 评估数据资产权利是否清晰、是否适合入信托
3. 输出《数据资产信托可行性诊断》

**S1 模式与九要素设计（2~4 周）**
1. 选定模式（自益/他益/财产权信托）
2. 填齐九要素：委托人、受托人、受益人、信托财产（权利）、目的、期限、管理方式、收益分配、退出机制
3. 输出《数据资产信托方案》+《信托模式选择说明》

**S2 受托人对接（2~4 周）**
1. 筛选有数据资产信托经验的持牌信托公司
2. 多轮沟通可行性（**关键**：多数信托公司尚无经验，需耐心教育式沟通）
3. 确定合作意向与费率区间
4. 输出《受托人对接记录》

**S3 税务测算（1~2 周）**
1. 测算权利转移环节的视同销售税负
2. 测算存续分配环节的税务
3. 输出《信托税务测算表》（与专家 32 交叉确认）

**S4 期限与登记衔接（1~2 周）**
1. 对齐数据产权登记有效期（通常 ≤ 5 年）
2. 设计续登/退出条款
3. 输出《期限衔接与续登方案》

**S5 文件起草与登记（2~4 周）**
1. 起草信托合同、权利转移文件、运营管理协议
2. 办理信托登记/公示（如适用）
3. 输出《信托合同及附件》

**S6 设立与移交（1~2 周）**
1. 签署信托合同
2. 数据资产权利移交受托人（非数据本体）
3. 信托生效
4. 输出《信托设立确认》

**S7 存续与退出管理（持续）**
1. 协助受托人履行管理职责、监督收益分配
2. 到期续登或启动退出，权利回转
3. 输出《信托存续/终止报告》

### 2.6 关键话术与风险提示

**关键话术（对客户）：**
- "信托最大的价值是**破产隔离**。装入信托的数据资产权利，原则上不会被您的债权人追索。"
- "但请注意：信托标的应该是数据资产的**权利**，不是数据本身——数据本体很难真正'交付'给受托人。"
- "设立信托可能涉及税务成本（权利转移或被视同销售），我们会先算给您看，再决定怎么设。"

**风险提示（必须主动说）：**
1. **数据资产信托是新领域**，多数信托公司缺乏经验，对接周期长、沟通成本高。
2. 信托设立可能涉及税务成本（视同销售），必须提前测算并提示，不可隐瞒。
3. 信托标的应是权利不是数据本体，避免"无法交付"导致信托效力存疑。
4. **信托不是融资工具**——不可向客户承诺"设信托就能融资"。
5. 信托期限须与数据产权登记有效期（通常 ≤ 5 年）衔接，否则会出现法律悬空。
6. 公共数据信托须由政府/主管部门作为委托人，授权边界与安全合规须严格约定。
