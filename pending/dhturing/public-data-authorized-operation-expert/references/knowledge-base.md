# 公共数据授权运营专家

> 所属战队：03-流通与交易
> 专家编号：21
> 核心使命：帮企业拿到公共数据的授权运营权，把政府手里的数据价值释放出来并合规变现

---

## 第一部分 · 知识库

### 1.1 一句话定位

公共数据授权运营专家处理的是**政府数据与企业能力之间的对接**。他的核心工作有两面：

- **政府侧**：帮政府设计授权运营方案、选择运营主体
- **企业侧**：帮企业申请授权运营资格、设计运营模式、合规运营

这是当前数据要素领域**政策红利最集中、门槛也最明确**的方向。《公共数据资源授权运营实施规范（试行）》（2025-03-01 施行）是这个方向的操作手册。

### 1.3 核心模型一：三种授权模式

《实施规范》明确三种授权模式：

| 模式 | 内容 | 适用 | 运营主体数量 |
|---|---|---|---|
| **整体授权** | 将公共数据整体授权给一个运营主体 | 数据量小、领域单一的地区 | 1 家 |
| **分领域授权** | 按领域（如交通、医疗、金融）分别授权 | 数据量大、领域清晰的地区 | 多家 |
| **依场景授权** | 按具体应用场景授权 | 场景明确、需求导向 | 多家（可重复授权不同场景） |

**模式选择逻辑：**
```
数据领域是否清晰可分？
├─ 是 → 领域数据量大吗？
│        ├─ 是 → 分领域授权（多主体竞争）
│        └─ 否 → 整体授权（单一主体）
└─ 否 → 依场景授权（按需求切）
```

**对企业的启示**：整体授权门槛最高收益也最大；分领域授权是主力机会；依场景授权是中小企业的切入机会（门槛低）。

### 1.4 核心模型二：授权运营五步程序

```
① 目录编制 → ② 方案制定 → ③ 主体选择 → ④ 协议签订 → ⑤ 运营监督
```

**① 目录编制**
政府编制公共数据资源目录，明确哪些数据可授权运营（涉及安全的要剔除）。

**② 方案制定**
制定授权运营实施方案，明确：
- 授权范围（哪些数据）
- 授权模式（整体/分领域/依场景）
- 授权期限（**最长 5 年**）
- 收益分配（政府与运营主体的分成）
- 安全要求
- 退出机制

**③ 主体选择**
公开遴选或指定（视地区规则），评估运营主体的：
- 技术能力
- 资金实力
- 数据安全能力
- 运营经验
- 合规记录

**④ 协议签订**
签订授权运营协议，明确双方权利义务。**核心条款**：
- 授权范围与期限（最长 5 年）
- 收益分配比例
- 数据安全责任
- 禁止行为（不得转授权、不得泄露、不得违规使用）
- 退出与终止

**⑤ 运营监督**
政府监督运营主体合规运营，定期评估，违规可终止授权。

### 1.5 核心模型三：授权运营期限与登记期限的衔接

这是本专家的一个**关键实操知识点**（易踩坑）：

| 事项 | 期限 | 起算 |
|---|---|---|
| 公共数据资源登记 | 原则 **3 年** | 登记之日 |
| 公共数据授权运营 | 最长 **5 年** | 协议生效日 |

**衔接要点**：
- 运营期限 5 年，但登记有效期只有 3 年 → **必须在中途续展登记**
- 建议在协议中明确登记续展的责任方（通常为运营主体）
- 建立双到期提醒机制

### 1.6 核心模型四：收益分配机制

收益分配是授权运营最敏感、最容易谈崩的环节。常见模式：

| 模式 | 内容 | 适用 |
|---|---|---|
| **固定费用** | 运营主体向政府支付固定年费 | 初期、收益不确定 |
| **收入分成** | 按运营收入比例分成（如 7:3、8:2） | 收益可计量 |
| **保底+分成** | 保底费用 + 超额分成 | 兼顾稳定与激励 |
| **利润分成** | 按利润分成 | 成本可核算 |

**实务建议**：
- 初期用"保底 + 分成"，降低政府风险也保住企业空间
- 分成比例需考虑运营主体的合理回报（数据加工、技术投入、市场推广成本高）
- 分成核算机制必须透明（政府通常要求审计权）

### 1.7 常见问题与标准答复

**Q1：企业怎么拿到公共数据授权运营权？**
A：三条路——① 政府公开遴选时投标；② 主动对接地方政府，参与方案设计（**推荐**，早期介入更容易拿到）；③ 通过分领域/依场景授权切入。

**Q2：拿到授权后数据能直接卖吗？**
A：不能。公共数据原始数据不交易。必须加工形成**数据产品**后经营（转专家11、17）。这是制度红线。

**Q3：授权期限到了怎么办？**
A：需重新申请或续期。所以要在运营期内建立不可替代性（数据积累、客户关系、技术壁垒），提高续约概率。

**Q4：收益怎么和政府分？**
A：没有统一标准，各地不同，需逐地谈判。常见 5:5 到 8:2 之间。

**Q5：企业和政府谁承担数据安全责任？**
A：运营主体承担运营过程中的安全责任。协议中要明确责任边界，尤其是数据从政府到运营环境的传输与存储环节。

**Q6：能不能转授权给第三方？**
A：一般**禁止**。转授权需政府明确许可，否则构成违约。

### 2.2 标准作业流程 SOP

**S0 区域选择与政策分析（2~4周）**
1. 分析各地公共数据政策开放程度
2. 识别有真实需求、政策积极的地区
3. 评估自身能力与地方需求的匹配度
4. 输出《区域政策与机会分析》

**S1 政府对接与早期介入（4~8周，关键）**
1. 拜访数据局/大数据中心
2. 了解当地数据资源状况与规划
3. **争取参与授权运营方案的设计**（早期介入的最大价值）
4. 输出对接纪要与合作意向

**S2 目录梳理协助（4~8周）**
1. 协助政府梳理可授权运营的数据资源
2. 识别哪些数据有市场价值、哪些涉及安全需剔除
3. 输出《可授权数据目录建议》

**S3 授权方案设计（4~6周）**
1. 设计授权模式（整体/分领域/依场景）
2. 设计授权范围与期限（最长 5 年）
3. 设计收益分配
4. 设计安全与退出机制
5. 输出《授权运营方案》

**S4 主体申报（2~4周）**
1. 准备申报材料：主体资格、技术能力、资金实力、安全能力、运营经验、合规记录
2. 突出差异化优势
3. 提交申报
4. 输出《运营主体申报材料》

**S5 遴选与答辩（2~4周）**
1. 准备答辩材料（方案 + 演示）
2. 参与遴选
3. 应对评审问询
4. 输出答辩材料

**S6 协议谈判与签订（4~8周）**
1. 谈判核心条款：
   - 授权范围（明确数据清单）
   - 授权期限（≤5 年）
   - 收益分配（比例 + 核算机制）
   - 安全责任（边界清晰）
   - 禁止行为（不得转授权）
   - 退出与终止条件
2. 签订协议
3. 输出《授权运营协议》

**S7 登记与备案（2~4周）**
1. 办理公共数据资源运营登记（引用专家 12）
2. 办理运营主体备案
3. 输出登记/备案凭证

**S8 运营体系搭建（4~8周）**
1. 建立数据接收、存储、加工、输出的安全环境
2. 建立合规制度与流程
3. 建立审计与追溯机制
4. 输出《合规运营手册》

**S9 产品开发与变现（持续）**
1. 基于授权数据开发数据产品（转专家 17）
2. 完成产品登记（转专家 11）
3. 开展交易与运营（转专家 15、26）
4. 输出产品与收入

**S10 期限与续约管理（常态化）**
1. 建立双到期提醒（登记 3 年 / 授权 5 年）
2. 登记到期前 3 个月续展
3. 授权到期前 6 个月启动续约
4. 输出续期材料

### 2.6 关键话术

**对地方政府**：
- "公共数据不授权运营就是沉没资产。授权运营能让数据产生财政收益，还能带动本地产业。"
- "我们建议分领域授权，让多家主体竞争，效果更好。"

**对政府部门内部（争取支持）**：
- "安全责任我们承担，收益分成给政府，我们还要投入技术和团队。"
- "我们可以在方案设计阶段就参与，帮您把方案做扎实。"

**风险提示**：
1. 授权期限最长 5 年，登记 3 年，需中途续展（易踩坑）
2. 公共数据原始数据不得交易，只能经营加工后的产品
3. 禁止转授权，违规可能被终止授权
4. 收益分配谈判周期长，需预留时间
5. 地方政府换届可能影响政策连续性，需在协议中约定稳定性条款
6. 涉个人信息的公共数据需特别注意合规
