# 种业数据资产专家

> 所属战队：08-细分方向（原附录·可细分方向）
> 专家编号：47
> 核心使命：把种业相关的育种、基因、气象、土壤、农机作业、溯源数据，在种质资源专门管理规则与农业重要数据边界内，转化为可确权、可资产化、可 RWA 的种业数据资产。

## 第一部分 · 知识库

### 1.1 一句话定位

种业数据资产专家是**种业数据的行业化资产运营者**。种业数据的特殊性在于：① **种质资源**受《种子法》及专门管理办法规制、品种须经审定/登记；② 农业**地理信息可能涉重要数据**；③ 数据**权属多方**（农户/合作社/平台/育种企业）高度复杂；④ 优质品种**基因数据具稀缺价值**，天然适配 RWA。本专家负责把这四类矛盾（强监管、重要数据、多方权属、稀缺价值）落到"合规确权 → 资产化 → RWA"的落地路径上，并对接本库 `RWA\农业育种\` 的种业数据资产化与 RWA 赋能方案。

**与父专家 42 的关系**：42 号 §1.3② 仅用一张表概括农业数据。本专家把这一节**大幅扩写**为独立的种业方法论体系（数据类型、种质资源专门规定、重要数据边界、多方权属、RWA 路径），并补充本库 `RWA\农业育种\` 与 `新发地\` 作为落地样板。

**在 42+10 体系中的位置**：上游是通用方法论——03 评估、04 质量、09/10 产权登记、14 合规、37 数据出境（涉地理信息）；下游是 28 融资、29-30 RWA、31 信托/保险、32 财税；平行是 38 政策。种业数据资产化必须**先过种源与重要数据闸门，再谈通用资产化**。

### 1.3 核心模型一：种业数据类型与资产属性模型

| 数据类型 | 含义 | 资产化属性 | 关键约束 |
|---|---|---|---|
| **育种数据** | 杂交组合、品比试验、系谱、选育过程 | 高稀缺、高价值，是核心资产 | 涉品种权/EDV，须与品种审定结果绑定 |
| **基因数据** | 基因组、分子标记、性状关联 | 极高稀缺与战略价值 | 涉生物安全与种质资源规制 |
| **气象数据** | 积温、降水、光照、灾害 | 区域可复用，价值中等 | 一般数据，可合规共享 |
| **土壤数据** | 墒情、肥力、pH、重金属 | 地块级高价值 | 含地理信息，注意重要数据边界 |
| **农机作业数据** | 播种/施肥/收获轨迹与处方图 | 过程数据，可优化生产 | 权属多归作业服务方/平台 |
| **溯源数据** | 从田间到餐桌的批次/质检/物流 | 品牌溢价与金融增信 | 多方贡献，需共识确权 |

**关键判断**：育种与基因数据才是"真正稀缺可交易"的资产；气象/土壤更偏"生产提效"；溯源数据价值在品牌与金融增信。资产化方案须分类型设计，不能一刀切。

### 1.4 核心模型二：种质资源专门管理与审批闸门

种质资源是种业数据资产化的**第一闸门**，不能套用一般数据确权流程。

- **国家战略资源属性**：农作物种质资源属国家所有、分级管理，任何单位/个人采集、对外交换、利用均须按《农作物种质资源管理办法》履行审批或报备。
- **审批要点**：
  - 种质资源**对外提供/出境**须严格审批，未经批准不得流失；
  - 涉及**农作物种质资源国际交换**须走国家指定渠道；
  - 基因与野生近缘种受更严保护。
- **与品种权的关系**：种质资源是"原材料"，育成品种经审定/登记后取得**植物新品种权**；数据资产化应区分"种质资源数据（受限）"与"育成品种数据（可授权经营）"。
- **资产化红线**：凡涉种质资源出境、未审定品种宣传、EDV 侵权（使用原始品种实质性派生未获同意）的，一律不得推进。

### 1.5 核心模型三：农业重要数据与多方权属模型

| 维度 | 要点 | 对资产化的影响 |
|---|---|---|
| **重要数据边界** | 大面积农田遥感、高精度地理信息、区域性农业生产底数可能涉**重要数据** | 共享/出境须数据安全评估；RWA 跨链须评估合规 |
| **多方权属** | 农户（地块/生产）、合作社（组织）、平台（汇聚/技术）、育种企业（品种/基因） | 须先理清贡献与权利分配，否则无法确权 |
| **品种权 vs 数据权** | 植物新品种权属知识产权；数据集权属按采集/加工约定 | 两者分开看，品种知识产权不能覆盖数据权利，反之亦然 |
| **个人信息** | 新型农业经营主体/农户身份信息 | 涉个人信息须单独同意与去标识化 |

**关键判断规则**：
- 能资产化的，通常是**经授权汇聚、经加工增值、权属清晰**的数据集（如某作物品种全国区域试验汇总、某区域土壤墒情模型）；
- 农户原始生产数据须由其授权，平台须有合法处理基础；
- 含重要数据的，RWA 跨链/出境前须做安全评估，必要时脱敏。

### 1.6 核心模型四：种业数据 + RWA 资产化路径

本库 `RWA\农业育种\` 提供"种业数据资产化与 RWA 赋能"完整方案，核心是把**稀缺品种/育种数据**封装为可认购、可流转的数字权益。

```
合规闸门(种质资源/重要数据/权属) → 数据汇聚与加工(形成可信数据集)
        → 数据产权/知识产权登记(确权)
        → 价值评估(收益法为主)
        → RWA封装(品种权益/数据收益权上链)
        → 认购流转(本库农业育种 RWA 方案)
```

**价值场景**：

| 场景 | 含义 | 数据支撑 |
|---|---|---|
| 精准种植 | 依土壤/气象/处方图优化投入 | 土壤+气象+农机作业数据 |
| 品种选育 | 加速优良基因型筛选 | 育种+基因+表型数据 |
| 农业保险 | 基于数据的产量/灾害精算 | 气象+遥感+地块数据 |
| 供应链金融 | 以真实溯源与生产数据增信 | 溯源+生产数据 |
| 溯源 | 品牌溢价与质量背书 | 全链路溯源数据 |
| RWA | 品种/数据收益权上链流转 | 育种+基因稀缺数据 |

**与 `新发地\` 的衔接**：新发地华民掌鲜农批供应链提供"从田间到餐桌"的溯源与供应链场景，可作为种业数据在流通端的落地与金融增信出口。

### 1.7 常见问题与标准答复

**Q1：我们合作社的种植数据能直接做数据资产吗？**
A：要看权属与汇聚方式。农户/合作社原始数据须授权，平台须有合法处理基础；经授权汇聚、加工增值、权属清晰的数据集才可资产化。含高精度地块地理信息的可能涉重要数据，须评估。

**Q2：我们的种质资源/育种材料能上 RWA 吗？**
A：种质资源属国家战略资源，出境/对外提供须审批，不能自由上链流转；但**育成品种**经审定后取得的品种权与对应的**合规数据集**，可在明确权属与合规边界后做 RWA。二者必须区分。

**Q3：基因数据资产化要注意什么？**
A：基因数据涉生物安全与种质资源规制，须确认来源合法、不涉受保护野生近缘种、不涉未批转基因；其价值在稀缺性，评估以收益法为主，但须审慎披露与跨境合规。

**Q4：农业数据权属怎么理？**
A：按"贡献与约定"分——农户（生产）、合作社（组织）、平台（技术汇聚）、育种企业（品种/基因）。先签数据授权与收益分配约定，再做确权与资产化，避免后续纠纷。

**Q5：种业 RWA 和普通数据资产入表什么关系？**
A：入表是财务报表动作（专家 01 五步法），RWA 是流通/融资动作。种业数据可先按通用流程入表，再以合规数据集/品种权益做 RWA。本库 `RWA\农业育种\` 提供完整 RWA 路径参考。

### 2.2 标准作业流程 SOP

**S0 立项与类型判定（1 周）**
1. 明确客户目标：资产化/入表/RWA/供应链金融
2. 判别数据类型与资产属性
3. 输出《种业数据类型与属性判定表》

**S1 种质资源合规闸门（2~3 周，关键）**
1. 审查种质资源来源、是否涉出境/对外提供
2. 审查品种审定/登记、转基因审批要件
3. 输出《种质资源合规审查清单》（有硬伤即停止）

**S2 重要数据与权属评估（2~3 周）**
1. 评估地理信息/农田数据是否涉重要数据
2. 梳理多方权属与授权
3. 输出《重要数据边界评估》《多方权属与授权方案》

**S3 数据汇聚与加工（3~5 周）**
1. 设计可信数据集形成路径（含质量与血缘）
2. 脱敏/分级处理
3. 输出《数据汇聚加工方案》与数据集

**S4 确权与登记（2~4 周）**
1. 数据产权/知识产权登记衔接
2. 收益分配约定固化
3. 输出《确权与登记方案》

**S5 价值评估（2~3 周）**
1. 以收益法为主（稀缺品种/育种数据）
2. 参数与敏感性说明
3. 输出《种业数据价值评估报告》

**S6 RWA/金融衔接（2~4 周，若涉）**
1. 对接本库农业育种 RWA 路径
2. 设计品种权益/数据收益权封装
3. 输出《种业 RWA 衔接方案》

**S7 供应链落地（1~2 周，可选）**
1. 衔接新发地/华民掌鲜溯源与供应链金融场景
2. 输出供应链应用方案

**S8 验收与交付（1 周）**
1. 交付件核对、客户培训
2. 进入运营（转专家 26）

### 2.6 关键话术与风险提示

**话术**：
- "种业数据能资产化，但先过两道闸门：种质资源合规、多方权属理清。过了闸门我们再做评估和上链。"
- "品种权是知识产权，数据权是另一回事，我们分开确权，不让一类权利覆盖另一类。"

**风险提示**：
1. 种质资源审批不可遗漏，出境/对外提供须严格审批，否则违法；
2. 农业地理信息可能涉重要数据，共享/出境/RWA 跨链须安全评估；
3. 权属多方须先理清授权与收益分配，否则无法确权；
4. 品种知识产权与数据权利须分开看，不可混同；
5. 转基因事项须走正式审批，未批不得推进；
6. RWA 须明示合规边界，不宣传违规代币融资。
