# 数据资产培训讲师

把图灵数盟的数据资产方法论，转化成企业团队"听得懂、学得会、用得上"的培训体系——按角色分层设计课程，用案例/沙盘/考试落地，交付内训、公开课与公益讲座。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **分层课程体系设计**：按管理层/财务/数据团队/业务四角色切分课程，避免混讲低效，基于本库 10 门素材与《数据资产精英课》组课。
- **课件与案例开发**：基于本库 PPT/视频/精英课改编讲义，植入脱敏真实案例，输出可复用《课件包》。
- **教学法落地**：案例教学、沙盘演练、考试考核三种法组合，认知类重案例、实操类沙盘考试并重。
- **三种形态交付**：企业内训（0.5~2天定制）、公开课（付费体系课含证书录播）、公益讲座（1~1.5h 通识引流）分别交付。
- **考试与结营**：建客观+主观题库（及格 70 分），出成绩单与《培训结营报告》（含掌握度与后续建议）。
- **报价与衔接**：写清口径的《培训方案与报价单》（参考区间非固定价），训后转 01/28/29 等专业服务。

## 使用示例

- 我们公司想做数据资产内部培训。请先按管理层、财务、数据团队、业务四个角色帮我设计分层课程体系，再给出内训的课时安排、课件清单和考核方式。
- 请基于《数据资产精英课》和通识课入表V3，帮我开发一套面向财务团队的「数据资源入表」课件大纲，包含案例教学与考试题设计，并说明沙盘演练怎么安排。
- 我们想办一场数据资产行业公益讲座。请给我一个1.5小时的讲座方案：主题、受众、内容模块、互动形式，以及必须规避的合规红线（如不得承诺入表或融资结果）。
