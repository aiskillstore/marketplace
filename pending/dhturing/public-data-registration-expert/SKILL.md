## 内容索引

**第一部分 · 知识库**

- **1.1 一句话定位**：处理政府与公共机构掌握的数据；与企业数据登记制度平行但规则完全不同
- **1.2 政策与标准依据**：公共数据资源登记管理暂行办法（核心依据）、公共数据资源授权运营实施规范（试行）（2025-03-01 施行）、数据二十条（2022-12）、关于加快公共数据资源开发利用的意见（2024-10）、政务数据共享条例、数据安全法（2021）、GB/T 43697-2024
- **1.3 核心模型一：公共数据的范围**：政务数据 / 公共服务数据 / 公共资源数据 / 财政资金数据四类；三个「不等于」（≠公开数据、≠无主数据、≠免费数据）
- **1.4 核心模型二：公共数据登记的三种形态**：目录登记 / 使用登记 / 运营登记及各自登记对象、登记人与用途
- **1.5 核心模型三：登记结果有效期**：原则上 3 年、自登记之日起算、期满前申请续展；与企业产权登记 ≤5 年、授权运营最长 5 年的对比记忆
- **1.6 核心模型四：登记与授权运营的关系**：目录登记 → 编制公示目录 → 选择运营模式 → 授权运营协议 → 运营登记 → 产品登记 → 交易
- **1.7 关键数据口径**：登记主体、登记范围、公示要求、安全要求、收益分配
- **1.8 常见问题与标准答复**：Q1 企业能否登记公共数据 / Q2 是否收费 / Q3 公共数据能否卖 / Q4 3年太短怎么办 / Q5 地方与国家平台关系
- **1.9 源材料索引**：登记管理暂行办法、授权运营实施规范、政务数据共享条例、国家公共数据登记系统、国数局登记全套、数据要素公共服务基地

**第二部分 · 操作技能**

- **2.1 能力清单**：C1 公共数据范围界定 / C2 目录梳理与登记 / C3 登记类型选择 / C4 安全评估组织 / C5 授权运营对接 / C6 运营登记办理 / C7 续展管理 / C8 合规咨询
