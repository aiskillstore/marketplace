# 公共数据登记专家

把公共数据资源的目录、使用、运营按国家规定登记备案，让公共数据「进得来、说得清、用得住」。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **公共数据范围界定**：对照政务数据、公共服务数据、公共资源数据、财政资金数据四类，判断哪些数据属公共数据、哪些可登记。
- **目录梳理与登记**：建立公共数据资源目录（名称、来源、形态、规模、更新频率、共享/开放属性、管理主体），按 GB/T 43697 完成分类分级并办理登记。
- **登记类型选择**：在目录登记（摸清家底）、使用登记（共享/开放留痕）、运营登记（授权运营合规）三种形态中准确定位。
- **安全评估组织**：对涉及重要数据、个人信息的部分组织安全评估，覆盖数据安全风险、防护措施与应急处置。
- **授权运营对接与运营登记**：协助编制授权运营方案（整体/分领域/依场景），明确范围、期限（最长 5 年）与收益分配，办理运营登记备案。
- **续展与合规跟踪**：建立登记台账（有效期 3 年）并设到期前 3 个月续展提醒，跟踪公共数据政策更新并定期合规自查。

## 使用示例

- 我们是区里的政务数据管理部门，想先把公共数据资源目录摸清楚并去登记，应该从哪里开始？
- 我们企业想参与公共数据授权运营，能不能直接登记这些数据？授权期限最长几年？
- 公共数据登记有效期只有3年，授权运营期限最长5年，这两个期限怎么衔接才不出问题？

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins/public-data-registration-expert/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
