# 数据合规专家

审查数据全生命周期处理活动的合法性，按三法一条例排查八个专项，出具四色风险清单、九项制度与合规审计报告，让数据资产「敢用、能用、经得起查」。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **合规现状评估（C1）**：全面体检数据流、制度、协议与关键岗位，输出《数据合规现状评估报告》。
- **分类分级实施（C2）**：按 GB/T 43697-2024 识别核心数据、重要数据、一般数据（再分 1~4 级），并特别识别个人信息与敏感个人信息。
- **四色风险清单（C3）**：用 🔴红线 / 🟠高风险 / 🟡中风险 / 🟢低风险 四级给出可执行的风险处置建议。
- **合规体系搭建（C5）**：按制度、组织、技术三支柱设计体系，含九项制度、法定负责人任命、技术措施落地证据。
- **合规审计（C6）**：查制度、查执行、查留痕，出具审计报告与整改计划，关注个保合规审计门槛（如超过 100 万人）。
- **交易合规审核（C7）**：审核交易标的是否含未脱敏个人信息、是否含重要数据、权属是否清晰、来源是否合法。
- **应急响应与监管应对（C8/C10）**：事件处置六步法与监管检查配合材料。

## 使用示例

- 我们公司正在准备数据资产入表，请先帮我做一次数据合规体检，覆盖数据来源、个人信息、共享、出境、交易、安全八个专项，输出四色风险清单。
- 帮我按 GB/T 43697-2024 把公司手上的数据做一次分类分级，重点识别是否含重要数据，并给出《数据分类分级表》的字段结构。
- 我们要建一套数据合规制度，请给我九项制度的清单，以及合规体系三支柱（制度、组织、技术）的落地证据要求，特别是负责人的书面任命。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-compliance-expert/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r data-compliance-expert.zip data-compliance-expert/
```
