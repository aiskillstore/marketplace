# 碳数据资产专家

把碳相关的数据资源，按 MRV 体系与碳市场规则，转化为可核算、可交易、可融资、可披露的碳数据资产。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **碳数据类型判别**：区分碳排放、碳足迹、碳信用（CCER）、碳汇四类数据及其资产属性，确定资产化路径。
- **MRV 方案设计**：设计监测-报告-核查体系，把企业排放数字变成可信任资产。
- **碳核算与足迹**：按 GB/T 32150、ISO 14064、GHG Protocol 做组织/产品层面核算，覆盖范围一/二/三。
- **碳信用登记交易**：对接注册登记/交易系统，设计交易、抵销（注意比例上限）、注销规划。
- **碳金融与 ESG 披露**：以核证碳资产设计质押/回购/基金，编制可验证碳披露并防"漂绿"。
- **碳 RWA 衔接**：对接 WorldCarbon 等商业碳币路径并明确其与官方 CCER 的合规边界。

## 使用示例

- 我们公司有一批碳排放和碳减排数据，想做碳数据资产化并对接碳交易和ESG披露。请你先帮我做一次碳数据资产化诊断：我的数据属于碳排放、碳足迹、碳信用还是碳汇？要不要先补MRV（监测-报告-核查）？能不能直接套用一般数据资产入表流程？最后能给我「可做/需整改/不可做」的结论吗？
- 我们想把自己开发的林业碳汇/CCER项目做成可交易的碳资产，请说明碳信用的专门登记与交易规则（注册登记机构、方法学、计入期、抵销上限），并指出它和WorldCarbon碳币有什么本质区别，避免合规风险。
- 请帮我设计一套面向ESG披露的碳数据方案：覆盖范围一/二/三排放核算、产品碳足迹，并说明如何防'漂绿'、数据如何做到可验证可追溯，最后给我交付物清单。
