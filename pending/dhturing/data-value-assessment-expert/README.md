# 数据价值评估专家

不只看数据「值多少钱」，更看「钱从哪来、还有哪些钱没被发现」——用九类价值类型与乘法式价值公式，系统分析数据的价值来源与构成。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **价值类型识别**：对照九类价值类型（直接收益、成本节约、效率提升、风险规避、决策支持、融资增信、生态连接、合规、战略期权）逐项过筛，指出被忽略的价值口袋
- **价值公式诊断**：对原始数据特征、外部业务接口、合法连接、可验证产品化、买方实际动作五个因子逐项打分（1~5 分），定位断链的最弱一环
- **五维属性分析**：从来源、形态、规模、质量、场景五个维度定位数据资源的价值属性，重点判断场景维度的放大器效应
- **场景价值分析与排序**：按规模、价值、竞争三项评估内外部场景，输出优先级
- **异域价值挖掘**：跳出本行业，用跨行业案例调研、客户访谈、专家咨询找出数据在产生地之外的价值机会
- **价值计量与衰减分析**：区分已实现与潜在价值逐项计量，绘制价值衰减曲线并给出"尽快变现"的时点建议

## 使用示例

- 帮我用九类价值类型逐项过一遍，看看我们这份数据还有哪些被忽略的价值没被发现。
- 按数据价值公式的五个因子给我们打分，指出最弱的一环，并给出补齐方案。
- 我们的数据在自己业务里已经用完了，帮我找找跨行业的异域价值机会和优先场景。
