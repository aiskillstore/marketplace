# 数据价值评估专家

> 所属战队：04-价值与变现
> 专家编号：22
> 核心使命：不只看数据「值多少钱」（那是评估专家的事），而是系统分析数据「价值在哪里、值在哪几方面」

## 第一部分 · 知识库

### 1.1 一句话定位

数据价值评估专家与数据资产评估专家（专家 03）的区别必须讲清楚：

| 维度 | 03 数据资产评估专家 | 22 数据价值评估专家 |
|---|---|---|
| 目的 | 出具可入表/融资的**估值金额** | 分析价值的**来源与构成** |
| 依据 | 中评协准则 | 价值理论 + 场景分析 |
| 输出 | 《评估报告》（有金额） | 《价值分析报告》（多维分析） |
| 用途 | 会计处理、授信 | 战略决策、产品设计、变现路径选择 |

**简单说**：03 回答"多少钱"，22 回答"钱从哪来、还有哪些钱没被发现"。

22 是 **23 数据变现专家**的理论供方——变现路径的选择依赖于价值类型的识别。

### 1.3 核心模型一：价值公式

这是本库理论的精华，必须完整掌握：

```
数据价值 = 原始数据特征 × 外部业务接口 × 合法连接 × 可验证产品化 × 买方实际动作
```

**逐项解读：**

| 因子 | 含义 | 为什么重要 |
|---|---|---|
| **原始数据特征** | 数据的规模、维度、独特性、时效性 | 决定价值的**基础**（0 乘任何数都是 0） |
| **外部业务接口** | 数据能接入哪些业务场景 | 没有场景接口 = 价值无法释放 |
| **合法连接** | 数据与场景的连接是否合规可行 | 不合规的连接价值等于 0 |
| **可验证产品化** | 能否形成可被验证的产品 | 不能产品化 = 无法定价交付 |
| **买方实际动作** | 买方是否真的会采取行动 | 潜在需求 ≠ 实际付费 |

**核心洞察**：这是**乘法**关系不是加法。任何一项为 0，总价值就是 0。这解释了为什么"很多数据看起来有价值但卖不出去"——某一项断链了。

**实务用法**：诊断数据资产时逐项打分（1~5 分），找出最弱的一环，那就是改进的方向。

### 1.4 核心模型二：九类价值类型

数据对一个主体的价值可以从九个维度体现：

| 价值类型 | 含义 | 变现方式 | 计量方式 |
|---|---|---|---|
| **1. 直接收益价值** | 数据本身可以卖钱 | 直接销售 | 成交额 |
| **2. 成本节约价值** | 用数据降低运营成本 | 内部应用 | 成本降低额 |
| **3. 效率提升价值** | 用数据提升效率 | 内部应用 | 时间/人力节省 |
| **4. 风险规避价值** | 用数据降低风险损失 | 内部应用 | 减少的损失 |
| **5. 决策支持价值** | 用数据优化决策 | 内部应用 | 决策改善的收益 |
| **6. 融资增信价值** | 数据资产可用于融资 | 质押/ABS | 融资额 |
| **7. 生态连接价值** | 数据带来合作机会 | 合作 | 合作收益 |
| **8. 合规价值** | 满足合规要求避免处罚 | 内部 | 避免的罚款 |
| **9. 战略期权价值** | 未来可能的场景价值 | 预留 | 期权价值 |

**关键理解**：
- 大多数企业只看到第 1 类（直接收益），忽略了 2~9 类
- **第 6 类（融资增信）是当前最被低估的价值**——本库的 ABS/RWA 业务正是围绕它
- 第 9 类是"看涨期权"，不能计入当期估值，但影响战略决策

### 1.5 核心模型三：五维数据地图

用于**定位**数据资源的价值属性（来自本库理论）：

| 维度 | 探查内容 | 价值含义 |
|---|---|---|
| **来源维度** | 自有/授权/公开/交易 | 决定权利完整度 |
| **形态维度** | 结构化/半结构化/非结构化 | 决定加工难度 |
| **规模维度** | 记录数、字段数、时间跨度、覆盖度 | 决定稀缺性与代表性 |
| **质量维度** | 六维质量 | 决定可用性 |
| **场景维度** | 现有场景、潜在场景 | **决定价值的最大变量** |

**场景维度是价值放大器**：同一份数据，只有 1 个场景 vs 有 10 个场景，价值差异可能是 10 倍。

### 1.6 核心模型四：数据异域价值

本库理论中的独特概念：**数据在其产生地之外的价值**。

| 价值类型 | 说明 | 例子 |
|---|---|---|
| **原生价值** | 在数据产生的业务中的价值 | 电商平台的交易数据用于自身推荐 |
| **异域价值** | 在完全不同的业务中的价值 | 同样的交易数据用于宏观经济预测 |

**异域价值常被忽略，但往往更高**。因为：
1. 原生场景已被充分开发，边际收益低
2. 异域场景需求方多，竞争少
3. 跨行业数据组合可产生新价值

**实务方法**：拿着数据问"除了我们自己的业务，还有谁会要？"——这个问题的答案就是异域价值。

### 1.7 常见问题与标准答复

**Q1：价值评估和资产评估有什么区别？**
A：价值评估看"价值构成与来源"，往往没有具体金额；资产评估出"金额"，是对外出具的报告。前者用于内部决策，后者用于对外。

**Q2：我们怎么知道数据还有没有没被发现的价值？**
A：用九类价值类型逐项对照。多数企业只看第 1 类，逐项过一遍通常能发现 3~5 个被忽略的价值点。

**Q3：价值公式里的"买方实际动作"怎么理解？**
A：买方说"这个数据挺有用"但从不付钱，价值就是 0。只有真正产生付费/使用行为，价值才成立。这是与"潜在需求"的关键区别。

**Q4：异域价值怎么找？**
A：三个方法：① 参加跨行业会议；② 问现有客户"您还想知道什么"；③ 分析数据在其他行业的应用案例。

**Q5：数据价值会衰减吗？**
A：会。时效性衰减、场景消失、技术替代都会导致价值下降。所以有价值的数据要**尽快变现**。

### 2.2 标准作业流程 SOP

**S0 对象确认（3~5天）**
1. 明确分析对象（数据资源/数据产品/数据资产）
2. 明确分析目的（内部决策/产品设计/变现路径/融资）
3. 输出《分析对象说明书》

**S1 价值类型识别（1~2周）**
1. 对照九类价值类型逐项分析
2. 每类给出：是否存在、强度如何、依据是什么
3. 输出《价值类型识别表》

**S2 价值公式诊断（1周）**
1. 对五个因子逐项打分（1~5 分）：
   - 原始数据特征：规模、维度、独特性
   - 外部业务接口：可用场景数量
   - 合法连接：合规可行性
   - 可验证产品化：产品化程度
   - 买方实际动作：真实付费证据
2. 计算总分，识别最弱因子
3. 输出《价值公式诊断报告》（含短板分析）

**S3 五维属性分析（1周）**
1. 五维逐维分析
2. 特别深入场景维度（这是最大变量）
3. 输出《数据价值属性分析》

**S4 场景价值分析（2~3周）**
1. 列举所有可行场景（内部 + 外部）
2. 对每个场景评估：
   - 场景的规模（有多少潜在买方）
   - 场景的价值（能给买方带来多少）
   - 场景的竞争（有多少替代品）
3. 排序得出优先级
4. 输出《场景价值排序》

**S5 异域价值挖掘（2~3周）**
1. 跳出本行业思考
2. 方法：跨行业案例调研、客户访谈、专家咨询
3. 列出异域价值机会
4. 输出《异域价值机会清单》

**S6 价值计量（1~2周）**
1. 对识别出的价值逐项计量：
   - 直接收益：估算成交额
   - 成本节约：测算节约额
   - 融资增信：估算可融资额
2. 区分"已实现"与"潜在"
3. 输出《价值计量表》

**S7 价值衰减分析（3~5天）**
1. 分析数据的时效特征
2. 绘制价值衰减曲线（何时价值减半）
3. 提出"尽快变现"的建议时点
4. 输出《价值衰减分析》

**S8 价值提升建议（1周）**
1. 针对价值公式中最弱的因子，给出提升方案
2. 例：场景太少 → 挖掘新场景；产品化不足 → 产品化改造
3. 输出《价值提升方案》

**S9 报告整合（3~5天）**
整合为《数据价值分析报告》，移交变现专家（23）与产品孵化专家（17）。

### 2.6 关键话术

- "我们不看『数据值多少钱』，我们看『价值的钱藏在哪几个口袋里』。"
- "价值公式是乘法不是加法——只要有一环断了，整条价值链就是 0。"
- "大多数企业只看到『卖数据』这一种价值。实际上还有八种，其中『融资增信』最被低估。"
- "同一份数据，在您自己的业务里值 100 万，换个行业可能值 1000 万——这就是异域价值。"

**风险提示**：
1. 潜在价值不能当作已实现价值对外宣称
2. 场景价值评估依赖假设，需标注不确定性
3. 异域价值需要合规审查（跨行业使用可能触及授权限制）
4. 价值衰减分析是"尽快变现"的依据，不能忽略
