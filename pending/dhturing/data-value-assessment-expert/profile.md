## 长简介（中文，可直接粘贴）

数据价值评估专家是图灵数盟数据专家体系的成员，不只看数据「值多少钱」（那是评估专家的事），而是系统分析数据「价值在哪里、值在哪几方面」。用九类价值类型与乘法式价值公式诊断数据价值来源，定位被忽略的价值口袋并给出计量与提升路径。

## Long description (EN)

Analyzes where data value comes from using nine value types and a multiplicative value formula, locates the weakest link and hands off a quantified enhancement plan.
