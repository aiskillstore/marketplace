# 数据产权登记专家

把「数据是谁的」通过官方登记程序固定下来，拿到一张可对抗第三人、可用于融资交易的产权凭证。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **登记可行性判断**：核查登记主体（法人或其他组织）、登记对象（数据资源）与权利类型，判断能否登记、该登记哪一类。
- **登记类型选择**：在初次登记、转让登记、变更登记、续期登记、注销登记五类中准确定位并给出登记方案。
- **登记材料编制**：按初次登记 12 项标准材料清单组织全套申请材料，确保材料齐全、来源证明充分、数据范围界定清晰。
- **技术审查报告编制**：围绕数据真实性、技术可行性、安全性、可追溯性组织技术审查，套用标准模板出具报告。
- **法律意见书对接**：组织律师或法务出具，覆盖主体适格、来源合法、权属清晰、无重大权利瑕疵四项核心内容。
- **登记台账与续期管理**：建立产权登记台账（编码、名称、类型、权利、登记日、到期日），设到期前 3 个月提醒，办理续期与变更登记。

## 使用示例

- 我们想把手上这批数据资源去官方登记，拿到产权登记凭证，需要准备哪些材料、大概要多久？
- 登记机构发来问询，说我们的数据来源证明不足、数据范围界定模糊，帮我逐项组织答复材料。
- 我们三年前登记的数据产权凭证快到期了，帮我建一份产权登记台账，把续期和变更的提醒机制设起来。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins/data-rights-registration-expert/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
