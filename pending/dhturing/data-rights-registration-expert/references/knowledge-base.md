# 数据产权登记专家

> 所属战队：02-确权与登记
> 专家编号：10
> 核心使命：把「数据是谁的」通过官方登记程序固定下来，拿到一张可对抗第三人、可用于融资交易的产权凭证

---

## 第一部分 · 知识库

### 1.1 一句话定位

数据产权登记专家负责把权利判断（专家 09 的产出）变成一张**官方凭证**。登记是数据资产从"企业自己说"到"有官方背书"的关键跳跃——没有登记，银行不认、买方不认、审计也未必认。

本专家的核心工作对象是《数据产权登记工作指引（试行）》，这是一套非常具体的操作规范，包括登记类型、材料清单、编码规则、审查标准。

### 1.3 核心模型一：五类登记

《数据产权登记工作指引（试行）》规定五类登记：

| 登记类型 | 触发情形 | 关键要求 |
|---|---|---|
| **初次登记** | 首次确认数据产权 | 需完整材料、技术审查、法律审查 |
| **转让登记** | 权利发生转让 | 需转让合同，登记机构审核后变更权利人 |
| **变更登记** | 权利人信息、数据范围等变更 | 需变更证明材料 |
| **续期登记** | 有效期届满续展 | 需在有效期届满前申请 |
| **注销登记** | 权利消灭/放弃 | 需注销申请与理由 |

**实务重点**：初次登记是绝大多数项目的主战场，转让和变更登记是运营期的常态化需求，续期登记最容易被遗忘（有效期一般不超过 5 年）。

### 1.4 核心模型二：登记凭证编码规则

这是本专家的标志性知识点。凭证编码共 **15 位**：

```
SJ + [地域2位] + [机构1位] + [日期6位] + [流水4位]
│     │          │           │            │
│     │          │           │            └─ 当日流水号（0001-9999）
│     │          │           └─ 登记日期（YYMMDD）
│     │          └─ 登记机构代码（1位）
│     └─ 地域代码（2位，省级行政区）
└─ 固定前缀 "SJ"（数据）
```

总计：2 + 2 + 1 + 6 + 4 = **15 位**

**示例结构**：`SJ4401A2509220001`
- SJ = 数据
- 44 = 广东
- 01 = 机构
- 250922 = 2025-09-22
- 0001 = 当日第 1 件

**实务要点**：编码是唯一的，是企业数据资产的"身份证号"，建议与内部资产台账编号建立映射关系（见专家 07）。

### 1.5 核心模型三：登记有效期

| 事项 | 规则 |
|---|---|
| 有效期 | 一般**不超过 5 年** |
| 起算 | 自登记之日起 |
| 续期 | 有效期届满前申请续期 |
| 逾期后果 | 权利公示效力受影响；融资/交易材料失效 |

**管理建议**：建立登记台账，设到期前 3 个月提醒机制。这是一个常被忽略但会造成实际损失的细节。

### 1.7 关键数据口径

- **登记主体**：必须是法人或其他组织（自然人一般不作登记主体）
- **登记对象**：数据资源（非数据产品——产品走专家11）
- **权利类型**：明确登记持有权/加工使用权/产品经营权中的哪一项或多项
- **登记范围**：必须明确边界（数据集名称、字段范围、时间跨度）
- **公示性**：登记结果通常公示，涉及商业秘密的需注意披露范围

### 1.8 常见问题与标准答复

**Q1：登记是不是必须的？**
A：法律上不是强制。但实务上，不登记的资产：银行不认可质押、买方不敢交易、审计可能质疑权属。**要资产化，登记是事实上的必需**。

**Q2：登记要多久？**
A：材料齐全情况下，初次登记通常 20~45 个工作日（视机构效率）。

**Q3：登记了就等于权利确定了吗？**
A：登记是**公示**，产生对抗第三人效力，但不是"设权"。如果实质权利有瑕疵（如来源不合法），登记也可能被撤销。所以前置的产权分析（专家09）不能省。

**Q4：登记要花多少钱？**
A：官方登记费通常不高（部分免费），主要成本在**技术审查报告 + 法律意见书**（这两份是主要成本项，通常合计数万元）。

**Q5：有效期 5 年到了怎么办？**
A：申请续期。建议建立到期提醒机制，不要等到过期。

**Q6：同一份数据能登记几次？**
A：不同权利可分别登记（如 A 登记持有权，B 登记使用权）。同一权利重复登记会被驳回或产生争议。

### 2.2 标准作业流程 SOP

**S0 登记需求确认（3~5天）**
1. 明确登记目的（入表/融资/交易/资质）
2. 明确登记对象（数据资源清单）
3. 明确登记的权利类型
4. 选择登记机构（地域、行业）
5. 输出《登记可行性意见》

**S1 前置条件核查（1周）**
1. 权属是否清晰（引用专家 09 结论）
2. 是否含个人信息（是否已处理）
3. 是否属重要数据/核心数据（是否已履行义务）
4. 是否已完成分类分级
5. 前置条件不满足的，先补正

**S2 材料准备（2~4周，核心）**
1. 填写申请表
2. 准备主体资格证明
3. 撰写数据来源说明（附证据）
4. 整理权属证明文件
5. 撰写数据处理与合规说明
6. 撰写数据资源描述（含规模、形态、更新频率）
7. 出具分类分级说明
8. 撰写安全保障措施说明
9. 签署承诺书

**S3 技术审查报告（1~2周）**
1. 编制技术审查报告：数据真实性、技术可行性、安全性、可追溯性
2. 可由第三方技术服务机构出具
3. 本库有标准模板可直接套用
4. 输出《数据产权登记技术审查报告》

**S4 法律意见书（1~2周）**
1. 委托律师或法务出具
2. 核心内容：主体适格、来源合法、权属清晰、无重大权利瑕疵
3. 本库有标准模板
4. 输出《数据产权登记法律意见书》

**S5 提交与受理（1周）**
1. 全套材料整理成册
2. 线上（国家公共数据登记系统/地方系统）或线下提交
3. 取得受理凭证
4. 建立跟踪记录

**S6 审查问询应对（2~4周）**
1. 登记机构审查，可能发出问询
2. 常见问询：来源证明不足、个人信息处理说明不清晰、数据范围界定模糊
3. 逐项答复并补充材料
4. 输出答复文件

**S7 登记完成与凭证获取（1~2周）**
1. 取得登记凭证（含 15 位编码）
2. 将编码录入资产台账（对接专家 07）
3. 归档全部材料

**S8 台账与续期管理（常态化）**
1. 建立《产权登记台账》：编码、名称、类型、权利、登记日、到期日
2. 设置到期前 3 个月提醒
3. 到期前发起续期
4. 权属变更时发起变更/转让登记

### 2.6 关键话术

- "登记凭证就是您数据资产的『房产证』，15 位编码就是『门牌号』。"
- "技术审查报告和法律意见书是两份关键文件，也是主要成本所在。"
- "有效期一般不超过 5 年，我们会帮您设好到期提醒，不会让它失效。"

**风险提示**：
1. 登记有效期 5 年，逾期需续期，遗忘会造成融资材料失效
2. 登记是公示非设权，实质权利有瑕疵仍可能被撤销
3. 登记公示涉及信息披露，商业秘密需提前脱敏
4. 不同登记机构要求可能不同，需提前确认
5. 含个人信息或重要数据未合规处理的，登记可能被拒
