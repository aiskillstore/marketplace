# Five messages (optional test arm)
Note (premise, only with a real fact), first message (premise and offer), follow-up 1 (one real peer), follow-up 2
(offer and way out), follow-up 3 only if the user picks it: a two-sentence breakup. Run it over 2 to 6
weeks. More messages lowered total replies in every dataset (vendor, observational). It differs from the baseline only by follow-up 3.
