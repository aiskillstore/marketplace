# 语音复刻模型检查

平台记录中的`selection`保存用户听选的模型、语速、音色登记表引用与升级偏好。调用该平台时先运行`voice_review.py --provider <平台>`读取听选；本次显式模型优先于已存选择。周期更新保留`selection`，不能用官方候选覆盖个人选择。未具备通用供应商适配器时，沿用记录指向的已验证项目调用方式，不把查询工具说成合成工具。

用于复刻前检查与用户已授权的周期巡检。记录放在`capabilities.py`实际用户配置同目录的`voice-model-review.json`，不提交私人配置。

每个平台独立保存：
```json
{"providers":{"qwen":{"checked_at":"2026-10-15T12:00:00+08:00","models":[],"sources":[],"findings":"官方清单与账户实际可调用性分开记录"}}}
```

`checked_at`只在本次成功读取并核对官方资料后更新。失败用`last_attempt_at`、`last_error`记录，保留旧成功时间。`sources`保留来源URL、访问日期和相关事实；`models`记录准确ID、用途、官方支持情况与实测状态，不把普通TTS、声音设计、实时对话混为声音复刻。

豆包优先查火山豆包语音的声音复刻与合成文档；Qwen优先查百炼语音合成模型清单、声音复刻指南与API文档。榜单用作候选线索，不能充当公开API ID或账号可用性的证据。确认新旧接口是否迁移、参考音频要求、价格和模型弃用情况；搜索不到不等于没有更新。

每周检查只读官方资料和本地配置，更新记录并报告新增、弃用或限制变化。不得擅自充值、重新训练、切换默认或重复发起付费测试。用户授权测试后另记请求模型、回执、音频验收和听选反馈；只有实际试听与可靠调用证据足够时才建议改默认。

来源：2026-10-15用户要求每周检查豆包/Qwen更新，并在每次复刻时报告当前模型和上次检查时间。若官方资料与旧记录冲突，修改旧结论并保留更正依据；个人听选与公共能力分开。
