# Vibe 知识短视频导演

把用户的主题直接制作成可播放成片。延续《二向箔》案例的视觉语言与制作质量，为新主题重新设计内容、物体与解释动画。

## 环境与首次配置

本技能不绑定模型厂商。由所在代理的文件、终端、联网研究和图片查看工具执行；无需 Codex 专属工具。宿主安装与调用见 [兼容说明](references/compatibility.md)。先运行 scripts/doctor.py 检查依赖。没有图像查看能力时可以渲染，但应将视觉验收交给可看图的工具或人工，不能声称已审片。

首次设置配乐：将 assets/local-profile.example.json 复制为技能目录 local-profile.json（仅本地保留）并填入音乐路径，或设置 VIBE_MUSIC，或给 prepare.py 传 --music。首次配置后可只提交主题。公开包不含歌曲、商用字体或个人路径。

## 输入与默认成片

唯一必需输入是主题。用户新要求优先于默认值；没有指定时直接执行，不重复询问时长、颜色、音乐、分辨率或是否开始。

- 中文；60 秒；9:16；1440×2560 原生渲染；恒定 30fps；MP4 / H.264 / yuv420p / BT.709；AAC 48kHz 双声道。
- 无配音、无解说旁白；用运动过程、对照和短文字讲清楚。
- 前 3 秒有与主题相关的视觉冲击或悬念；第一秒已有主体和钩子文字。
- 深黑背景、冰蓝与香槟金、精细线框与粒子、克制辉光、留白、大字号中文。
- 默认使用用户已配置的配乐；案例使用《千年之后（氛围版）》60 秒片段，不代表已获得公开分发或商用授权。用户选择新曲后，分析真实音轨；公共技能不捆绑歌曲。
- 以成片为完成标准。只交文案、分镜、网页或静音动画不算完成；用户明确只要其中一项时按其范围执行。

## 执行流程

1. **独立项目。** 运行 `scripts/prepare.py --topic '主题' --project 'work/vibe-短名'`。脚本复制案例、节奏资料和默认配置，生成 brief.json；它不生成新主题动画。不要覆盖既有成片。临时文件放 work/，交付放当前任务规定的 outputs/。
2. **核查与叙事。** 对关键结论查阅可靠一手来源；将主张、来源、事实/假说/类比/虚构的区分写入项目 sources.md。提取一个主问题、两到三个解释步骤和一个收束。科幻不能包装成已证实物理；不能为反转编造事实。
3. **导演分镜。** 读取 [视觉与叙事标准](references/direction.md)。先设计开场变化，再确定每镜要让观众看懂什么。把文字、起止帧、动作、事实属性、音乐事件写入 storyboard.json。60 秒通常约 7–9 段，按内容调整。
4. **配乐卡点。** 读取项目 brief.json 的 music 与 beat_analysis_status。只有哈希、起点和长度吻合的案例片段才复用分析；其余配乐运行 scripts/analyze_music.py，并重写动作时间映射。BPM 只是辅助，转场与动作对齐真实音频事件，按 30fps 量化，不能凭空填节拍。轻音效服务于动作。
5. **新主题动画。** 读取 [渲染说明](references/rendering.md)，以项目 film.js 为可运行案例。保留排版与底层绘图方法，重写场景、主体动画、标签和事件映射。不能仅替换文字而留下二向箔物体或旧论证。可按主题选 Canvas、Three.js 或其他本地代码渲染方式。
6. **预览再渲染。** 查看开场 0 / 0.8 / 1.6 / 3 秒、各段中点、转场前后及结尾的实际图片，修复缺字、遮挡、太暗和字小问题。同步更新案例的预览时间点。渲染真正的 1440×2560、30fps 视频。
7. **混音导出。** 用 `scripts/finish.py --silent 静音成片 --music 音轨 --output 输出路径 --duration 60`，可选 `--sfx 音效.wav`、`--music-start 秒数`。助手负责生成与本片动作一致的音效。工具完成混音、编码、全片解码、规格校验、抽帧和技术报告。
8. **验收交付。** 查看 contact.jpg，复杂运动另看连续帧；检查字形、阅读时间、开场事件、图形因果和结尾。读取响度报告，确认非静音且无削波。能试听时试听；只有信号检查时不声称已试听。修复后使用宿主支持的文件附件或本地文件链接交付 MP4，具备预览工具时打开预览，简短注明时长与规格。

## 缺失信息与范围

没有参考片时使用已保存案例，不再次要求参考文件。默认音乐缺失时，检查已提供素材及 本地配置中的路径，继续脚本和画面工作，并只询问实际缺失的音轨。不得把自制临时音轨冒充原曲或完成版。

不自动发布、不建立定时任务、不购买素材或调用付费渲染服务；这些不属于“主题出片”的默认范围。

## 资源

- assets/reference-film.js：已交付二向箔动画代码，用于复用绘图方法与视觉样式。
- assets/music-analysis.json、assets/beat-edit.json：该版真实音轨的分析与事件时间，不是所有歌曲通用节拍。
- assets/local-profile.example.json：一次性配乐配置示例；scripts/doctor.py 检查渲染环境。
- scripts/prepare.py、analyze_music.py、finish.py：建项目、音轨分析、混音导出与技术检查。
