# Template Methods

The `Template` domain contains LynxView-specific extensions. These methods may return `method not found` for WebView targets.

## Methods

- [Template.getTemplateJs](Template.getTemplateJs.md) - Read a base64-encoded range of saved template bytes
- [Template.templateApi](Template.templateApi.md) - Get template data-processor API information
- [Template.templateConfigInfo](Template.templateConfigInfo.md) - Compatibility response for removed config info support
- [Template.templateData](Template.templateData.md) - Get the current initial template data
