# CSS.getMatchedStylesForNode

- `CSS.getMatchedStylesForNode` - Get matched styles for node
- Input: `{nodeId: NodeId}`
- Output: `{cssKeyframesRules: Array<CSSKeyframesRule>, inlineStyle: CSSStyle, matchedCSSRules: Array<CSSRule>, pseudoElements: Array<CSSPseudoElementMatches>}`
- Description: Returns CSS rules matching the specified node
