# WhiteBoard.enable

Scope: This is a LynxView-specific CDP extension. For WebView targets, use standard Chrome DevTools Protocol storage/runtime APIs instead; this method may return `method not found`.

- `WhiteBoard.enable` - Enable WhiteBoard domain
- Input: None
- Output: `{}`
- Description: Enables the WhiteBoard domain so the client can send `WhiteBoard.*` requests and receive shared data change events.
