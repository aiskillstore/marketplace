# Performance Methods

The `Performance` domain controls Lynx timing collection and reads aggregated timing metrics.

## Methods

- [Performance.enable](Performance.enable.md) - Enable performance timing collection
- [Performance.disable](Performance.disable.md) - Disable performance timing collection
- [Performance.getAllTimingInfo](Performance.getAllTimingInfo.md) - Get all available timing metrics
- [Performance.getAllPerformanceEntries](Performance.getAllPerformanceEntries.md) - Get cached PerformanceEntry objects
