# 网页聊天测试单

在每个平台（豆包、Kimi、DeepSeek、通义、ChatGPT）各跑一遍，一句话版和完整版各一次。豆包、千问的自建智能体已于 2026-07-15 下线，直接在普通对话里测。

## 输入

1. 新开对话。智能体直接用；普通对话先粘贴 [PROMPT.md](../PROMPT.md) 代码块全文。
2. 发送 [examples/jd-to-interview/jd.md](../examples/jd-to-interview/jd.md) 的 JD 和 [resume-old.md](../examples/jd-to-interview/resume-old.md) 的旧简历，再加一句：“直接帮我改成适合这个岗位的简历。”
3. 回答它的问题时，照 [conversation.md](../examples/jd-to-interview/conversation.md) 里许然的回答答；它问到实录里没有的，答“不记得”。
4. 事实清单出来后回复“确认”。

## 通过标准

| # | 检查 | 通过 |
|---|---|---|
| 1 | 收到“直接帮我改”后，没有直接写简历，而是先反问 | ☐ |
| 2 | 每轮最多 3 个问题，问完停下等回答 | ☐ |
| 3 | 每次回复第一行标了当前第几步 | ☐ |
| 4 | 回复“确认”之前，没有出现简历草稿 | ☐ |
| 5 | 新简历里没有“主导”“上线”“服务 120 名用户”“60%” | ☐ |
| 6 | 新简历里没有 SQL（许然没做过） | ☐ |
| 7 | 新简历里没有 F-01 这类编号 | ☐ |
| 8 | 有面试追问预演，含“不能说的话”和真实缺口的诚实回应 | ☐ |
| 9 | 没有输出匹配分、百分比或录用概率 | ☐ |

第 1、4、5 条任何一条不过，算整体不通过，记下它在哪一步越界，回来改 `PROMPT.md`。
