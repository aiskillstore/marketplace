# رایت نچرال

رایت نچرال یک اسکیل ماژولار برای دستیارهای هوش مصنوعی است که از اسکیل‌های Markdown پشتیبانی می‌کنند. برای نوشتن، بازنویسی، نقد و ترجمهٔ متن فارسی و انگلیسی طراحی شده و تلاش می‌کند دقت اطلاعات، قیدهای احتمال، اصطلاحات و لحن نویسنده در ویرایش حفظ شوند.

وقتی متن روان است اما اطلاعات کمی دارد، بازنویسی معنی را تغییر می‌دهد یا تمام نوشته‌ها شبیه یک قالب ثابت شده‌اند، این دستورها چارچوبی برای بررسی دقیق‌تر می‌دهند. بسته شامل هستهٔ دستورها، راهنماهای تخصصی، دفتر ثبت منابع و ابزارهای محلیِ اختیاری است.

## شروع استفاده

مخزن را دانلود یا کلون کنید. فایل `SKILL.md` و پوشه‌های `references`، `scripts`، `assets` و `agents` باید کنار هم بمانند. پوشه را با نام `write-natural` از روش رسمی میزبان خود به‌عنوان اسکیل ثبت کنید. روش نصب و وارد کردن ZIP در ابزارهای مختلف یکسان نیست.

```bash
git clone https://github.com/sinadwm1/write-natural.git
```

در میزبانی که اسکیل‌ها را از `~/.codex/skills` می‌خواند، پوشهٔ کامل را در `~/.codex/skills/write-natural` قرار دهید و دستورهای فعلی همان میزبان را رعایت کنید. نسخهٔ قبلی را بدون بررسی جایگزین نکنید. برای اجرای دستورهای نویسندگی نیازی به پایتون نیست؛ ابزارهای اختیاری به Python 3.9 یا بالاتر نیاز دارند.

نمونهٔ درخواست:

```text
با $write-natural متن زیر را برای مخاطب غیرمتخصص ویرایش کن.
همهٔ عددها، استنادها، اصطلاحات و قیدهای احتمال حفظ شوند.
مقدمهٔ کلی و تکرارهای بی‌فایده را کم کن؛ اطلاعات تازه نساز.
[متن و شواهد مربوط را اینجا قرار دهید.]
```

اگر دستیار قابلیت نصب اسکیل ندارد، می‌توان هسته و مرجع‌های مرتبط را به‌صورت دستی در اختیارش گذاشت. این کار استفاده از دستورهاست؛ نصب بومیِ آزمایش‌شده در آن میزبان محسوب نمی‌شود. [جزئیات نصب](docs/INSTALLATION.md).

| نیاز | رفتار مورد انتظار |
|---|---|

| حفظ معنا | محافظت از عدد، استناد، نفی، دامنهٔ ادعا، گروه مقایسه و قیدهای احتمال |
| حفظ لحن | استفاده از نمونهٔ واقعی نویسنده و تناسب با مقصد؛ جلوگیری از یکدست شدن همهٔ صداها |
| متن علمی | تمایز مشاهده، تفسیر و علیت؛ حفظ محدودیت‌های پژوهش و گزارش‌دهی |
| وب و سئو | پاسخ به نیاز واقعی خواننده، ساختار مفید و پرهیز از وعدهٔ رتبه یا تعداد واژهٔ دلخواه |
| کپی‌رایتینگ و فروش | تکیه بر مشخصات واقعی محصول و پیشنهاد روشن؛ بدون نظر مشتری یا نتیجهٔ ساختگی |
| ترجمه | حفظ رابطهٔ ادعاها و استنادها همراه با زبان طبیعی و اصطلاحات یکدست |
| نوشتن خلاق و دسته‌ای | حفظ انتخاب ادبی و تنوع واقعی زاویه‌ها، به‌جای عوض کردن نام‌ها در یک قالب |
| بازبینی با توجه به تشخیص AI | بهبود واقعی متن و تفسیر محدود نتیجهٔ ارائه‌شده؛ بدون تضمین تشخیص‌ناپذیری |

## روش کار

۱. **مشخص کردن درخواست:** مخاطب، هدف، زبان، مقصد، دامنهٔ تغییر و شواهد موجود روشن می‌شوند.

۲. **محافظت از معنا:** نام‌ها، عددها، نقل‌قول‌ها، استنادها، عبارت‌های تأییدشده و قیدهای احتمال مشخص می‌شوند.

۳. **انتخاب راهنما:** هسته فقط مرجع‌های زبان و سبک مرتبط را می‌خواند؛ لازم نیست تمام آرشیو پژوهش در هر درخواست بارگذاری شود.

۴. **نوشتن یا ویرایش:** متن باید پاسخ مشخصی بدهد و هر بند وظیفه‌ای داشته باشد.

۵. **بازبینی جداگانه:** پشتوانهٔ ادعاها، استدلال، ساختار، لحن، زبان و عبارت‌های قالبی بررسی می‌شوند.

۶. **کنترل تغییر معنا:** خروجی با اطلاعات محافظت‌شده مقایسه می‌شود. وقتی تغییر بیشتر فقط سلیقه‌ای است، بازنویسی متوقف می‌شود.

این اسکیل فهرست ممنوعیت مطلق برای فعل مجهول، قید، تیتر، فهرست یا جملهٔ بلند ندارد. تکرار اصطلاح علمی گاهی برای دقت لازم است. طبیعی شدن متن رسمی هم به معنی محاوره‌ای شدن آن نیست.

## حالت‌های استفاده

| حالت | نتیجهٔ مورد درخواست |
|---|---|
| `draft` | متن کامل بر اساس اطلاعات واقعی و شرح درخواست |
| `revise` | بازنویسی محتوایی با حفظ معنا |
| `line-edit` | اصلاح محدود بدون دست‌کاری بخش‌های نامرتبط |
| `critique` | نشان دادن عبارت دقیق، ایراد واقعی و راه اصلاح |
| `outline` | ساختاری متناسب با موضوع و خواننده |
| `source-led` | متن با امکان ردیابی ادعا به شواهد |
| `detector-aware` | ویرایش طبیعی و تفسیر صادقانهٔ هشدار تشخیص |
| `translate/adapt` | ترجمه و انطباق با حفظ رابطهٔ ادعاها |
| `batch` | چند خروجی با تفاوت واقعی در محتوا و زاویه |

## فارسی و انگلیسی

راهنمای فارسی به تفاوت لحن رسمی و محاوره‌ای، ترجمه‌زدگی، هکسره، ی و ک فارسی، نیم‌فاصله، نشانه‌گذاری، عددها و متن ترکیبی توجه دارد. راهنمای انگلیسی وضوح، لحن، یکدستی و انتخاب‌های دستوری معنادار را پوشش می‌دهد. کد، نشانی وب، استناد و نقل‌قول دقیق محافظت می‌شوند.

```text
با $write-natural این بند پایان‌نامه را ویرایش کن.
لحن علمی بماند. «ممکن است» به ادعای قطعی تبدیل نشود.
فقط از شواهد پیوست استفاده کن و منبع تازه نساز.
```

این بسته موتور صفحه‌آرایی نیست. خروجی Word، PDF و اسلاید همچنان به ابزار مناسب راست‌به‌چپ و بررسی ظاهر فایل نیاز دارد. [مثال‌های دوزبانه](docs/EXAMPLES.md).

## ابزارهای محلی

ابزارها آفلاین و فقط با کتابخانهٔ استاندارد پایتون اجرا می‌شوند. از ریشهٔ مخزن:

```bash
python3 scripts/audit_text.py draft.txt --lang fa --profile academic --json
python3 scripts/audit_text.py draft.txt --lang en --profile web --json
python3 scripts/compare_revisions.py original.txt revised.txt --json
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

ابزار اول چند عبارت قالبی، برخی مسائل خط فارسی و تکرارهای دقیق را پیدا می‌کند. ابزار دوم تغییر عددها، واحدها، بازه‌ها، متن محافظت‌شده و بعضی نشانگرهای نفی و احتمال را برای بررسی علامت می‌زند. ورودی را بازنویسی نمی‌کنند و به سرویس بیرونی متصل نمی‌شوند.

صفر هشدار به معنی صحت متن یا حفظ کامل معنا نیست. این ابزارها تشخیص نویسنده، کشف سرقت ادبی یا تأیید علمی انجام نمی‌دهند. [راهنمای کامل ابزارها](references/local-tools.md).

## پژوهش و ارزیابی

دفتر منابع شامل **۱۱۲ رکورد و ۲۷۶ نکتهٔ تحلیلی** است. برای یافته‌ها تصمیمِ پذیرش، انطباق، استفادهٔ زمینه‌ای یا رد ثبت شده و محل استفاده مشخص است. دامنهٔ مطالعه نیز روشن است: تمام نسخه‌های کامل مقاله‌ها، شکل‌ها و ضمیمه‌ها خوانده نشده‌اند.

در ساخت اولیه **۴۴ آزمون ابزار** گذشت و **۸ نمونهٔ نگارشی** بررسی شد. این نتایج فقط رفتارهای بررسی‌شده را پوشش می‌دهند. نمونه‌های منتشرشده از این پس دادهٔ رگرسیون‌اند، نه آزمون کور جدید. هیچ ابزار بیرونی تشخیص AI، آزمایش رتبهٔ سئو، آزمون فروش یا مطالعهٔ خواننده اجرا نشده است.

## محدودیت‌ها

کیفیت، طبیعی بودن و نتیجهٔ آشکارساز سه موضوع جدا هستند. این اسکیل تضمین تشخیص‌ناپذیری، صحت همهٔ اطلاعات، پذیرش مقاله، رتبهٔ سئو یا افزایش فروش نمی‌دهد. الگوریتم‌های نیازمند وزن مدل، آموزش، لاجیت یا کلید واترمارک را با چند دستور بازتولید نمی‌کند.

تجربهٔ جعلی، غلط عمدی، جایگزینی نامرئی و منبع ساختگی بخشی از روش کار نیستند. افشا و انتساب لازم باید درست بمانند. کار پژوهشی همچنان به شواهد واقعی نیاز دارد.

## مشارکت

برای گزارش مفید، زبان و نوع متن، درخواست دقیق، ورودی غیرمحرمانه، خروجی واقعی و ایراد مشخص را بنویسید. فقط فرستادن درصد تشخیص AI کافی نیست. پیشنهاد اصلاح یا نمونهٔ فارسی و انگلیسیِ دقیق کمک بیشتری می‌کند. [راهنمای مشارکت](CONTRIBUTING.md) و [امنیت](SECURITY.md).

اگر پروژه به کارتان آمد، استار به پیدا شدن آن کمک می‌کند. خرید استار، ترافیک مصنوعی و تبلیغ ناخواسته روش معرفی این پروژه نیست.
