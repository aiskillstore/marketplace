# Birdview 0.2.1

[English](release-notes-0.2.1.md)

用更清晰的约束帮助 AI 写出更好的代码：本次小版本优化了 Birdview 对模型理解架构、澄清决策和实施前评估修改的要求。

- 规划时先查清源码能回答的问题，仅询问实质影响方案的未决选择，并提供建议及取舍。
- 按需架构评审结合源码证据、迁移成本和风险，检查职责、耦合与验证困难。普通建图不自动启动重构，提案与现有架构保持区分。
- 官网提供 Codex、Claude Code 和 DeepSeek Harness 安装选择，以及中英文复制命令、依赖自检和试用提示词。
- README 示例更易理解，并增加简短使用反馈表，方便分享成功使用、模块遗漏、错误关系和安装问题。

这些改进旨在减少盲目编辑和缺乏依据的重构，从而提升编码质量。目前未进行代码生成质量的对照评测；仓库检查通过不代表已证明生成代码更好，也不保证 Agent 必然遵循指令。

按[安装指南](installation.zh.md)安装完整发行版源码，在技能目录运行 `npm ci` 和 `node scripts/birdview.mjs doctor`。更新时保留本地定制，项目显式按需设置仍然有效。仅通过 GitHub 分发，不发布到 npm。

验证包括仓库测试、示例校验、doctor、可复现示例构建和浏览器检查；双语文档与链接已检查。Claude Code 和 DeepSeek Harness 实际会话触发仍未验证；Birdview 展示声明的活动，不独立观测编辑。
