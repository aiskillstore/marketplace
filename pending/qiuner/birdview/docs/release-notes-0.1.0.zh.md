# Birdview 0.1.0 发布说明

[English](release-notes-0.1.0.md)

**用 Birdview 来改变开发的流程！真正地从关注代码到关注架构！解决 AI coding 的黑盒！**

已发布为 [v0.1.0](https://github.com/Qiuner/birdview/releases/tag/v0.1.0)。

Birdview 在 AI 编辑前，将计划中的代码更改展示在带源码证据的架构地图上。

## 包含功能

- 独立 HTML，提供完整架构、更改和并排对照视图。
- 模块证据、依赖、活动历史、缩放、分步指引和一屏工作区。
- 中英文控件和配套双语文档。
- Schema 与语义校验、稳定模块标识、职责颜色及通用分类的明确理由。
- 自动与按需两种触发模式。分发版本默认自动，项目显式设置优先。
- MIT 许可证和 GitHub 贡献模板。

## 安装

需要 Node.js 18 或更高版本。技能放置、依赖、验证和模式选择见[安装指南](installation.zh.md)。包尚未发布到 npm。

## 发布前验证

对实际发布候选版本执行[发布检查清单](releasing.zh.md)。在正式发布说明中记录实际测试结果和跳过的浏览器检查；CI 状态本身不能验证 Agent 触发。

## 已知限制

活动由 Agent 声明，不是独立观测。模式指令不能强制模型遵守。地图更新需要重新生成 HTML 并刷新浏览器；未实现实时传输或显示回执。完成事件不能证明验证成功。内置示例为虚构内容，不是本仓库或生产系统的证据。
