# Birdview 查看器设计

[English](viewer-design.md)

状态：唯一演示入口为 `examples/harness-activity.html`。共享查看器支持架构、更改和对照模式、可折叠活动详情、面板导航联动、可关闭检查器和单层分组。活动是 Agent 声明的文件快照，实时集成仍未实现。

## 目标

让系统和 Agent 预期变更一目了然。画布是主要区域，模块证据用于检查但不占据首屏。保留独立 HTML 交付和现有语言支持。

## 架构含义

Birdview 的 local/external 类型描述代码归属。外部数据库仍可能在产品部署内部。不要仅根据类型、目录名或屏幕位置推导系统或信任边界。

提出可选的作者声明分组，包含稳定 ID、名称、成员模块 ID 和源码证据。系统或子系统先使用一层分组，在真实用例支持前不引入部署/信任边界。分组标签采用模块相同的翻译约定。无分组时渲染原始平面地图，不要为美观编造成员关系。

## 页面组织

- 紧凑页头：Birdview、项目名称、语言和主题。地图版本移到次要元数据中，移除重复的大项目标题区域。
- 画布工具栏：架构/更改/对照、适配、缩放和流向开关。无活动记录时只展示架构，不放不可用的视图控件。
- 让图占用可用宽度。检查器初始关闭，点击节点打开 300–340 px 检查器，关闭后恢复画布宽度。移动端详情在图下展开，仅自动适配模式重新适配。
- 全图适配保持可读的编写间距，保留原始尺寸缩放用于细看。模块增多不应只增加空白边距。
- 分组框使用轻微底色、清晰标题和预留标题空间。仅在成员数据如此定义时把外部依赖放在框外。

## 视觉语言

- 保留黑白主题。画布与面板使用中性色，青、绿、暖黄仅作克制强调，避免所有节点都泛绿。
- 节点名称居中、职责简短、圆角 8 px。只有角色数据存在时使用对应图标或小强调，不能仅根据外部归属推断数据库角色。完整说明放在检查器。
- 分组框表示成员关系，不应与任务范围轮廓混淆。
- 悬浮高亮相邻关系并预览方向，点击选择详情，两者都不能暗示模块正在修改。
- 最强光晕留给当前 AI 修改目标。计划范围使用轮廓，仅明确活动视图弱化无关模块。
- 检查时显示关系标签，空间允许时在画布上显示可读的选中标签。保留方向箭头与减少动态效果支持。

## 交付顺序

查看器通过无障碍的正交通道布线，与模块保持 10 px 间距，转角最大圆角 6 px。共享端口沿选定边分散。路径成本偏好短路径和少转弯，对与既有路径交叉或重叠施加惩罚。这是局部启发式，不保证无交叉。斜向连接优先使用占用端口较少的垂直端点边。额外通道位于障碍通道外 8 px，按并行重叠长度惩罚过近路径，避免成本依赖网格细分。这可能以更长路径换取分离，不保证硬性最小间距。
分组边框与标题不是布线障碍。布线保留作者指定的节点位置，不使用网络资源或额外运行时依赖。

保留网格轨道顺序，但屏幕间距随关系密度变化。每个内部轨道边界，跨越关系超过两条后，每多一条增加 12 px，上限 96 px。分组地图只统计各组内部关系，无分组时统计全图。所有关系都计入，包括 detail 边，因此悬浮和可见性改变不触发布局变化。布线可以使用通道中间轨道和底部两条外围通道，它们是候选而非强制路径。较大画布在窄屏可能需要缩放。

1. 基于当前数据实现紧凑页头与可关闭检查器。
2. 同步为 Schema、校验、编写指引和渲染器增加可选分组，拒绝未知/重复成员和同层重叠。排列时不包入无关节点，不遮挡节点文字。
3. 建立有代表性的 8–12 节点测试数据，包含应用分组和明确外部依赖。双节点双语数据保留用于语言测试，不作为主要视觉基准。
4. 在同图上渲染声明的计划/当前活动，对照模式旁边显示完整概览，两侧使用相同位置和共享导航。

## 验收

页头显示项目名称，不另设模块总数。页面不设独立页脚，现有图例保留规模与关系可见性信息。

关系、流向与缩放控件直接显示在地图工具栏，不另设更多工具菜单。

更改视图在历史控件旁持续显示所选步骤的完整原因，下方提供可展开的文件与检查记录，并明确标记模拟或 Agent 声明来源。关闭检查器后仍能访问摘要。窄屏控件换行，较长的展开详情在活动面板内滚动。架构与并排对照视图隐藏这些历史控件及详情。

在 1440x900、1280x720、390x844 下检查深浅主题和中英文。验证分组包含关系、标签无碰撞、检查器开关、适配/手动缩放保留、悬浮恢复与键盘选择。渲染无分组的旧地图。所有图文本保持转义，HTML 无网络资源。长证据可访问，且不强制画布始终保持大片纵向空白。
