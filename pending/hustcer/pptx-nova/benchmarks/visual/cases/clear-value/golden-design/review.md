# Clear Value golden review

Accepted on 2026-10-22 with xdoc 0.13.0 (ea2c8e58), frozen field date 2026-10-22.

The final public-kit sample contains twelve native editable pages. Every canonical PNG was
individually reviewed; stacked values, ring labels, area circles and table-note clearance were
also inspected as crops of those same PNGs. Zero hard defects. The eight supplied reference roles
are covered; four additional pages exercise line, forecast, ring/area and argument signatures.

The same source also passed four same-content layout variants, five density/boundary pages,
twelve CJK pages, three unrelated ecology pages and three chart-boundary pages, all individually reviewed. The local review
ledger binds each page to its PNG hash and candidate PPTX. Standard Create finalization published
the same reviewed bytes for all seven groups (41 pages), including both native matrix density variants.

The golden sample has seven native charts, four native tables and data-derived editable circles.
Readback checked every native series/category/value and literal table cell. No reference bitmap,
embedded font or financial policy is shipped. Serif fonts were substituted with Georgia/Songti SC;
body fonts are Arial/Arial Unicode MS. Line endpoint values appear in the figure head because the
tested classic chart runtime lacks selective endpoint value visibility. Pixel-area restraint and
cross-platform font appearance remain visual checks, not machine-proof claims.
