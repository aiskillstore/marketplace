# Clear Value

A white research report with black rules, serif assertions and restrained teal evidence. Gray is
history or reference, dark teal is supporting evidence, terracotta is reserved for conclusions and
small decision marks. Large current marks use outlines to avoid a teal blanket. Exact tokens,
registered regions and capacities live in `design.json`.

Start with the claim, then select its evidence: comparison, native table, trajectory, composition,
area comparison, phases or a bounded argument. All headings, values, units, sources, dates,
assumptions and controls come from content. The skin adds no financial policy. Bundled business
figures are synthetic test observations, not forecasts or default recommendations.

Evidence supports one to four native figures. Rail/wide changes the same single figure's geometry;
paired, lead and quad reflect the authored figure count. Argument column/split and matrix
full/compact provide additional density choices. Selection is deterministic from content fit and
recent geometry. Explicit layouts must fit too. A capacity failure requires shorter authored text,
another supported composition or splitting the page; never silently drop fields or shrink type.

Tables have two to seven weighted columns and bounded row counts. Cells retain literal source
strings, alignment and semantic emphasis. Use one paragraph per cell; automatic wrapping is
allowed. Timeline widths encode positive durations, not capital or task counts. Table notes have
a reserved region below the bottom rule.

Charts retain raw series, categories and names. Bar/column values are directly labeled; stacks use
light fills and dark labels. `focus` selects one category in a single bar, column or ring series;
unsupported focus combinations fail explicitly. A forecast boundary is the last observed zero-based category index in
a single-series column chart; subsequent columns use dashed outlines. Ring charts represent parts
of one nonnegative total. Editable comparison circles encode area, so diameter follows the square
root of value; zero omits the circle but retains its label. Regenerate from content after data edits
to synchronize shapes and captions with native plots.

Line values are not labeled at every point. First/last category and value appear in the chart head:
the tested runtime does not expose selective endpoint value visibility for classic line charts.
This is an explicit adaptation, not attached endpoint labels. Tiny and negative values remain exact
in native series; a common linear scale cannot make every tiny value separately visible.

The supplied composite has eight landscape pages. The accompanying prose also includes portrait
guidance; the actual reference aspect and the user's permission to improve design govern this
landscape adaptation. Secondary text is enlarged, table spacing made explicit, and dark stack fills
replaced with outlines where their internal numbers were unreadable. Georgia/Songti SC replace the
unavailable reference serif faces; Arial/Arial Unicode MS carry body text. Fonts are not embedded.
Latin/CJK regular and bold were actually rendered on the validation machine. Other systems require
fresh font and visual checks; font lookup alone does not prove appearance or PowerPoint parity.

Use `meta.designScope: "excerpt"` for standalone evidence. Full decks alternate opening, summary,
evidence and decision. This adapter creates native editable decks; it does not establish arbitrary
source-PPTX refurbishment or animation fidelity. Contract/readback checks and machine findings do
not replace actual every-page PNG review, including dense labels and bottom-note clearance.
