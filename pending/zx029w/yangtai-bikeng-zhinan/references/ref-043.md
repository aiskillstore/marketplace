# 看，别人阳台这样做吊顶12.4

阳台吊顶的种类不外乎以下几种：
1.桑拿板，原木材质厚度太多差异了，各位业主选择的时候不光看价格，需要关注厚度，否则只比较单价吃亏的还是你

▲看见了吗，同样桑拿板厚度不一样，价格相差很大，你只看价位，你家质量能好才怪

2.绿可木，档次太多，烂板子轻轻手捏就碎了，颜色也做不到原木效果，还是一分价钱一分货，业主一定得明白，只盯价位只能给你用最烂的

3.石膏板，阳台也可以用石膏板，做法和其他区域都一样，各种造型都可以做

4.铝扣板，阳台也可以用铝扣板，但是不是目前厨卫用的300*300的，而是长条形铝扣板600*150的

下面看看各种类型阳台吊顶的效果

▲阳台如果与区域打通，或者客厅，或卧室，此时阳台吊顶最好和区域统一起来，做同样材质的吊顶，比如石膏板吊顶

▲阳台如果做书房使用的话，不用铺贴瓷砖，直接涂刷乳胶漆即可，吊顶同样可以不吊直接涂刷乳胶漆，或者直接用石膏板平面吊顶，隐藏筒灯安装即可

▲阳台做单独书房使用，也可以用石膏板做造型灯带吊顶，更富有情调，这个看个人喜好决定

▲阳台做书房使用，不做吊顶，直接刷白，安装吊灯即可

▲阳台与卧室打通设置，中间有梁，单独做了四周实心吊顶，中间隐藏筒灯安装

▲阳台与卧室打通，中间没有梁，刚好阳台做了石膏板吊顶，隐藏中央空调室内机，合理利用位置，也区分了空间

▲阳台与客厅打通，做了榻榻米休闲空间，吊顶采用白色木质扣板装饰，区分空间，同时隐藏大梁

▲卧室与阳台打通设置，阳台作为休闲空间，吊顶做了石膏板假梁设置，提升阳台空间氛围

▲阳台单独空间，一侧设置储物柜，没有晾衣架，做了白色绿可木吊顶

▲阳台放置洗衣机，晾衣服，原木格栅吊顶，其实完全可以不做晾衣架，直接使用格栅晾衣服就行

▲当然可以不吊顶，直接顶面刷白，直接安装固定晾衣架

▲生活阳台放置洗衣机，墙面瓷砖，照样可以做石膏板吊顶，安装吸顶灯或者隐藏筒灯即可

▲生活阳台放置洗衣机晾衣服，墙面瓷砖，不吊顶直接刷白，升降晾衣架钢丝外露，如果能接受完全可以，省钱了
