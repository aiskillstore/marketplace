# 无吊顶，不要石膏线，120m²三室绿意家

过去装修家家户户都有木头吊顶，感觉没有吊顶就不是装修，而且家家户户复杂的电视墙，哪怕没有钱买家具，电视墙都得做得像模像样，一切都是为了面子。并不是吊顶不好，而是和自己的喜好和经济情况匹配。不做吊顶和电视墙照样可以有品味。

▲门厅空间，进门就是清新的浅绿。左手一部分通顶鞋柜收纳，局部楼空可以满足进门放置物品，同时也可以摆上精美的装饰，进门心情都好了。门口的电箱装饰画装饰遮挡，同时下方挂衣钩功能，简单皮质的换鞋凳配置，方便换鞋，同时视觉也非常灵活
▲反过来看一下门厅，局部墙面的浅绿色点缀，与客厅局部绿色呼应协调，营造清新极简的家居环境
▲门厅进来客餐厅全景，统一无造型吊顶，甚至连石膏线都没有，墙面绿色与淡黄色变色处理。视觉非常清新干净

▲餐厅与门厅，绿色墙面互相连贯呼应，非常清爽自然
▲摆上水果花瓶，营造气氛的蜡烛，这样的就餐环境实在太温馨了
▲门厅进来餐厅对面的过道，简单穿衣镜布置，旁边斗柜收纳兼顾装饰，摆上精美的物件，就是进门最好的端景了
▲紧挨斗柜的地方就是沙发区，浅色布艺L型布局搭配两个木质方几，彩色清雅的抱枕装饰，背景是组合照片墙，非常简单舒适
