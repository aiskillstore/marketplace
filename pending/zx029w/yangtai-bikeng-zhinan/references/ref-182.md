# 地漏不是为好看，不防臭有啥用？8.6

关于地漏的文章大家可以公众号直接回复“地漏”即可。

今天重点谈一下地漏的选择，经常有业主咨询：地漏该选铜质的还是不锈钢的。实在不知道怎么回答。因为出发点是错的。因为地漏是排水用的，其主要目的是排水并且关键防臭。

不问防臭性能，只问材质，和装修一样，只为面子，却失去了功能意义。所以，选择地漏先看功能，其次再看样子是否美观。如果要用，建议不锈钢，别问为什么。最耐用，性价比最好。好吧有的人喜欢铜质的，感觉很土豪，好吧，你不看满世界的锌合金山寨铜质地漏，你敢用吗？全铜地漏有，价格是最贵的，如果你买的价格低，肯定不是全铜或者压根就是锌合金。所以，与其买铜质最后买个山寨，不如直接买普通不锈钢。

好了，重点来了。家里能用什么地漏是楼盘原始下水管决定的，如下图：

▲北方大部分卫生间收房的时候就是这个样子，所以你的地漏取决于头顶管路做法。注意上图的S弯，除过马桶下水，所有地漏处都做了S 弯处理，这就是标准做法，可以存水防臭。如果你家是这个样子，你就可以买普通地漏即可。如下图：

▲有S弯的话，普通地漏就可以满足使用了

▲注意上图，所有地漏排水管没有S弯，全部直管，此处就得注意，下水管没有存水，是不会防臭的，此时你不知道，随便买个普通地漏，入住就会有异味。所以碰到没有S弯的下水，必须用深水封地漏，如下图

▲上图就是深水封地漏，这样即使你家下水管没有S弯，后期入住就不会有异味了。

如果这些措施你都做好了，家里还有异味，可以参考这篇《新房刚刚入住，卫生间异味很大》
