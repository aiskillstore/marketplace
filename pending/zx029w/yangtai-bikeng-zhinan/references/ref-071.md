# 阳台必须贴墙砖？这个得综合考虑12.3

作为一般老百姓，刚需房子，只有一个阳台，而且阳台还得放洗衣机，放洗手池，不言而喻，这样的阳台必须铺瓷砖。想省钱也不行。瓷砖要好打理，而且不怕日晒雨淋。

▲上图几乎是北方所有生活阳台的做法，一边放洗衣机洗衣池，全部瓷砖铺贴，上方吊顶做晾衣架。没有办法阳台要晾衣服，还得洗衣机，有情调的还得养花，水汽和潮湿是避免不了的，所以瓷砖是必须做的

▲像过去的老房子，一是装修没有经验，二是也为了省钱，阳台墙面全部做了乳胶漆，时间久了后果就是到处潮湿发霉，严重的大面积墙皮脱落。其中一部分是自家潮湿所致，一部分是外墙年久失修漏水导致。如果全部贴瓷砖就不会有这种后果，所以该贴瓷砖的地方必须贴

▲阳台不晾衣服，只放洗衣机和洗手池，如上图，还兼顾休闲地方，可以只铺地砖，墙面乳胶漆处理，或者只在洗衣机洗衣池和吊柜之间墙面做个瓷砖背景即可。不晾衣服，平时就是洗衣机和洗个小件，这样完全可以的

▲如果客厅带的阳台纯粹就是休闲之用，像上图做了地台休闲，墙面完全可以做乳胶漆处理，这样能更温馨，而不是直接铺瓷砖看起来很冰冷

▲如果是客厅和阳台打通成一个空间，为了拓展客厅区域，这样就完全和客厅一致的做法，不需要单独处理阳台

▲像上图虽然阳台和客厅打通设计，阳台作为地台休闲区域，同样做了局部墙砖处理，这里只是为了迎合风格需求，做了局部文化石背景处理而已

阳台如果不铺瓷砖，也可以同样用防腐木或者各种木质处理装饰，同样也是可行的。但是如果是露台空间，直接铺瓷砖吧，尽管防腐木也可以用于室外，但是长期日晒雨淋会变色，而且质量次的防腐木会短时间内腐烂坏掉的。

总结一下：如果你家晾衣服和洗衣服都在阳台，墙砖是必须贴的，后期避免潮湿，如果作为休闲处理可以不贴墙砖，做乳胶漆完全可以。如果阳台只放洗衣机，但是不晾衣服，或者直接烘干机处理，同样也可以不贴瓷砖。
