# 跟风把阳台改成了书房，入住半年，谁在哭谁在笑？！

向往的人：阳台作为光线最好的地方，直接改成书房，在这里办公不仅明亮，而且还能欣赏窗户无线风光。心里排斥的人：夏热冬冷，光线刺眼到电脑屏幕看不进，拉上纱帘不遮光，拉上厚厚的布帘不仅空间累赘，无限风光尽泡汤！北方的话阳台靠窗灰尘非常大，一个小时桌上一层尘土；如果楼层低，楼下噪音非常大，压根不可能安心办公。第一、阳台改书房后悔又无奈！网友@快乐的涂：天亮的越来越早，夏日的阳光也越发的刺眼，早上的阳台书房已经看不清屏幕，立夏过后，得时刻拉好窗帘，保护设备和书籍，想要阳台放书桌一定要想清楚，偶尔使用是可以，长期使用光线太刺眼了。网友@未屋：以前觉得这样的阳光书房真好、现在呀、稍微出点太阳热死了，冬天冷死了，窗帘遮阳又无法欣赏到外头的美景，其实有利有弊，介意的人最好谨慎。网友@胖师傅：想象中，阳光是温暖的拥抱，现实中，它却是刺眼的折磨。强光下工作，不仅效率低下，还伤眼睛！客厅的欢声笑语、厨房的锅碗瓢盆，都在考验你的专注力。噪音，成了学习的天敌！偶尔用一下可以，作为专门的办公和学习地方，除非是单身，否则有时候感觉鸡肋！网友@小飞侠：靠窗户灰尘多书桌靠近阳台窗户，灰尘容易堆积，一天不打扫就厚厚一层灰，开放式书架更是加重家务量。第二、阳台放书桌，又有风景又有光。自然光充足：再也不用担心眼睛疲劳，自然光下工作学习，效率都翻倍！通风良好：新鲜空气环绕，头脑更清醒，学习效率蹭蹭上涨。 风景优美：抬头就是蓝天白云，绿意盎然，心情都变好了呢~网友@丽丽：阳台不只是是晾衣场，更是生活诗意的延伸呀！「早咖晚酒」模式：早晨被阳光唤醒做手冲，夜晚开氛围灯加班都变享受～  娃的学习角神器：配了可升降学习椅+坐姿矫正器，老母亲终于不用吼“背挺直”。网友@宅家吧：把书桌移动到了阳台这边，在阳台办公学习真的太棒了，工作之余还可以看看风景是多么惬意。网友@兰亭：大落地窗让窗外的景色尽收眼底 新入的电脑椅让办公的同时拥有舒适与享受 万向轮的旋转、丝滑的升降、细腻的手感…… 无一处细节不精致。网友@家的鹿：每天都在这样的窗前写作业，大概是近视眼宝宝麻麻内心最大的安慰了。阳台光线充足且自然，避免了室内灯光的局限。孩子在这学习，眼睛能充分接受自然光的滋养，减少视疲劳。学习间隙眺望远方，让眼睛得到放松和调节。网友@愿如初：考虑到女儿房间比较小，就把这个阳台打通连接到她的卧室了，这样她的活动空间也大了很多，现在的卧室集睡觉、学习、娱乐于一体，真的很方便 - 4平米阳台一侧做成了她的书桌，另一侧则是她的休闲区啦。网友@还得是你：在阳台给自己布置了一个氛围感的办公区！累了就可以抬头看看窗外，坐累了也可以把桌面升高，只要轻轻一按就能调整到适合的高度，站起来活动活动筋骨，缓解久坐对腰椎的伤害，到这个治愈的角落，干活的劲也是满满后记：阳台适不适合做书房因人而异！你如果是家里人少或者单身，完全可以，没有家里其他噪音的干扰，真的想要办公或者学习，光线都不是问题，窗帘可以控制，如果嫌布帘累赘，其实百叶帘最适合阳台。如果是一家三口，其实这里更适合大人偶尔办公，孩子学习的最佳地方，因为光线好，就不用担心孩子视力问题，而且还可以时常远眺远方，能更好缓解孩子视力的疲劳。如果家里人多还想要安静独立的办公地方，此时就得谨慎了。公共阳台作为办公的话，家里人有多，各种干扰就多，此时就不适合作为专门办公的地方，即使做了会发现压根无法使用。至于冬冷夏热完全可以忽略，窗帘和空调都可以解决，除非你生活在极寒和极热地方，否则大可放心！
