# 踢脚线，装修的时候哪地方不做？12.23

今天不谈哪地方用踢脚线，谈一下家里不用踢脚线的地方。
 1
▲家里成品家具后面是必须有踢脚线的，因为成品家具生产的时候已经考虑好这一点，后面预留了空隙，专门有踢脚线位置。而且一般购买成品家具肯定是装修已经完成了，所以所有成品家具都是直接靠着踢脚线放置的。

▲所有定制衣柜后面都不需要踢脚线，否则安装以后，与墙会有很大缝隙。所以在安装踢脚线的顺序一定要明白：你家有定制衣柜，一定是衣柜先安装，然后安装木门和踢脚线。因为木门和踢脚线需要一样的颜色，一般是一家，先装衣柜，避免踢脚线多跑一次，还有避免和门套的冲突无法安装。
▲彻底开放的厨房，橱柜包括木质的岛台等，下方都是不要踢脚线的，否则视觉更凌乱难看。一定是橱柜或者岛台的材质一通到底的做法
▲飘窗柜也是一样的，定制安装不需要有踢脚线。
▲同样定制榻榻米的地方也是不需要任何踢脚线的，后期踢脚线只要挨着榻榻米收口即可
▲阳台区域一定注意，同时有墙地砖的情况下是不需要踢脚线的，如果有乳胶漆墙面是也要踢脚线的，否则墙体和地砖会有很大的伸缩缝盖不住
▲石材背景落地做法，是不需要踢脚线的，视觉上更干净
▲护墙板与石材结合的背景，石材地方同样可以不做踢脚线，这样电视柜更能与石材严丝合缝放置，视觉上层次分明
▲家里有大量KD板饰面的情况下，也是不需要踢脚线的，木质饰面直接落地即可，视觉上更统一
▲衣柜外面按照常规也是不需要踢脚线的，但是如上图所示，踢脚线没有直接挨着衣柜，在墙体与衣柜平齐的情况下，也是可以不做踢脚线的，也可以踢脚线直接通过去的做法

▲如上图，定制衣柜后面没有踢脚线，做好衣柜以后，踢脚线直接做到了衣柜下方与其他踢脚线是一个完整的整体。这样做的话唯一好处就是家里视觉上一个整体，但是仅限于衣柜颜色与踢脚线颜色相近的做法，否则太难看，再一个就是比价浪费，踢脚线米数多了，花的钱更多了。还有需要定制衣柜的时候就要知道踢脚线高度，提前预留挡板高度，非常麻烦。不建议，但是也不反对。
总结，踢脚线是为了保护墙体，有别的材质保护墙体是不需要踢脚线的。衣柜后面要不要踢脚线？
