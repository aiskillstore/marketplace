# 厨卫瓷砖怎么买？纠结的都是钱3.29

关于瓷砖方面的知识说的也很多，需要了解后台回复“瓷砖”看专题。

今天主要谈一下厨卫瓷砖的购买和选择。

一、厨房主要是为了好打理，也没有长期的水泡。所以相对于卫生间瓷砖，厨房瓷砖只要满足你的颜色喜好，好打理，质量只要保证平整即可。这样可以节省一部分费用。

二、比如卫生间成品瓷砖300*600，一般控制价位20元左右，是不会有问题的。这里的20元不是标价，而是你能拿到手的价格。比如标价四五十，你能20元左右拿到，质量不会有问题。

三、如果卫生间瓷砖你拿20元左右的，厨房就可以考虑10元左右的成品瓷砖，也不会有什么问题。因为厨房不用考虑长期水泡的问题。

四、关于半瓷或者全瓷没有必要纠结，这个是瓷砖的特性，决定不了质量。举例：同等规格瓷砖，半瓷20元，全瓷10元，你说哪个好呢？

五、全瓷砖比较坚硬，吸水率低，但是容易崩瓷。半瓷砖容易切割，不易崩瓷，但是吸水率高。从这个特性来看，为了省钱，你可以卫生间购买吸水率低的全瓷，厨房选择半瓷。

六、半瓷砖水泥砂浆可以直接铺贴，全瓷砖需要配合粘贴剂，不能纯用水泥砂浆直接铺贴，容易脱落。同等价格的瓷砖，全瓷成本要高。甚至有的工人你用全瓷会比半瓷的工费高，这个一定考虑进去。

七、怎么辨别厨卫瓷砖的好坏。这个没有任何办法，除非卖瓷砖的是你的熟人。用的人多了，卖砖的当然知道这个瓷砖质量的好坏。

八、不要指望在店里看几个样品砖，就能看出好坏。这就不是你家的瓷砖，你看的是样品，你家瓷砖还在库房，甚至没有出生呢。你能看出什么来？

九、人不识货，钱识货。低价风险要高于高价。这是必然的。

十、大商城要比外面小店保险。不论出现什么质量问题，商城会出面解决。而你在小店买的瓷砖扯皮只能打官司。

十一、如果是装修公司全包包含瓷砖，只要人品正的装修公司，出现任何问题，都会给你负责。

十二、有没有掏了高价瓷砖反而出问题的？当然有，报废的兰博基尼都有，何况瓷砖呢。只要商家人品正有售后，这就是前提。

十三、大地砖上墙费用就高了。因为一块大砖的单价本身就高，加工以后用到厨卫，比成品的厨卫瓷砖要高很多了。但是颜值高，这个成本需要考虑。
