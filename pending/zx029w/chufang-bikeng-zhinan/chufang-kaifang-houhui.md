# 开放厨房不做饭都是优点，其他就剩后悔了……

开放厨房对没真正用过的人非常有诱惑力，撇开做饭功能，就只剩优点了。但中式家庭天天做饭，几乎都会后悔。

1. 油烟飘满屋：六千多的大吸力烟机也控不住，爆炒肉菜味散满客厅甚至卧室。老陕爱油泼，更忍不了。
2. 噪音矛盾：破壁机豆浆不敢用，看电视听不见；三代同堂噪音成了家庭矛盾导火索，厨房有点动静全家人别想安静。
3. 凌乱一览无遗：未收拾餐具、待洗锅具、油盐酱醋、烧黑锅底全暴露。餐边柜不装门，看着乱还容易被油烟熏油腻。
4. 水蒸气凝结：冬天做饭水蒸气凝在玻璃上成水滴，影响客厅美观。
5. 自问三题再决定：
   - 是否几乎每天爆炒？是就三思，再好的烟机也难保油烟不到处飘。
   - 是否一家三口或三代同堂？噪音比油烟更烦人。
   - 是否单身或两人、基本不做饭？那随意，大胆做开放式，剩下只有优点。

想通透又怕油烟，走半开放（玻璃+联动门）才是大多数中国家庭的答案。
