# 小户型没有餐厅，茶几怎么兼顾餐桌5.30

太多小户型压根没有餐桌，此时客厅要兼顾就餐功能，所以茶几就得兼顾多重功能，既要作为会客办公，同时还得兼顾孩子的学习，最重要的还得兼顾一日三餐的餐桌功能。
▲对于小户型来说，压根没有餐桌位置，此时茶几显得尤为重要，同时兼顾会客、书桌学习办公功能，这个是没有办法的办法。▲如图采用茶几餐桌两用的家具，可以兼顾餐桌以及茶几功能▲这种家具可以满足平时书桌和茶几功能，同时也可以兼顾就餐功能▲当然如果单身一个人的话，这种可以移动的轻巧边几都可以兼顾所有功能了，可以放笔记本办公，可以就餐，也可以作为平时会客的茶几使用▲木质的轻便茶几，高度可以稍高一点，同时可以兼顾茶几和餐桌，平时不用的时候可以随意挪动，搭配两个小圆凳可以满足平时会客和就餐▲小户型没有餐厅，可以采用这种可以升降的茶几，同时兼顾茶几和餐桌两种功能▲还有一种办法就是去客厅化，不要沙发，直接餐桌居中代替沙发，此时餐桌就兼顾了客厅会客、学习办公，以及日常就餐功能《有娃更应该去掉传统客厅，一个区域供一家人活动，叫啥无所谓》▲还有上图这种可以升降的茶几，同时可以兼顾会客，读书、和就餐功能▲还有这种可以遥控的升降桌，也是可以兼顾餐桌的，只不过需要带电源，家里有小孩不太安全▲原木高茶几，阅读就餐以及会客，小户型一件家具搞定功能▲带轮的折叠茶几，同时兼顾茶几和餐桌功能，还可以随意移动▲类似的这种原木高腿茶几非常多，而且样子都轻巧，非常适合小户型没有餐桌的家庭。
