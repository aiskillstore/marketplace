# 全屋 WiFi 覆盖：4 种落地方案，大小户型都能用

家里总有几个房间 WiFi 信号弱？网速卡顿、卧室刷视频掉线，大多都是装修前期没规划。水电阶段不留网线、不提前布局，后期再多放大器、信号增强器都是治标不治本。今天整理 4 种主流全屋 WiFi 方案，优缺点、布线逻辑讲透彻，装修照着选，再也不被网络公司套路推销。方案一：单路由模式（最基础，适合小户型）
此种方案适合普通刚需房，几乎适合大部分户型的做法，可以满足平时网络全覆盖。连接顺序：光猫 → AC/一体化路由器（通常放在客厅或弱电箱）优点：造价最低，安装简单，后期维护省事，刚需小户型、出租房、简单自住完全够用。做法：原有开发商弱电箱放电信猫即可，记着留电源；客厅电视位置放置路由器，记着两根网线从光猫到路由器：一根是给路由器，一根是看IPTV用。如果家里电视不看IPTV可以只给路由一根网线。此种做法非常简单，前期水电改造成本也是最低的。如果开发商从电信猫到电视墙路由本身就有网线，位置也合适，都可以不做任何改动，水电改造费用更低。除非你介意开发商原有是5类线需要更换。缺点：穿墙能力差，墙体一多、距离一远，信号直接衰减。所以不适合大户型以及家里混凝土墙多的家庭。延伸解决：此类做法如果有独立书房需要有线上网也可以稍作改动即可。例如从路由单独走网线到书房，可以实现书房的有线上网。如果电信猫原有网线有一根到书房，此时可以直接连接电信猫进行单独有线上网。
此类方式只是简单解决少走网线的问题，简单一间房需要有线，其他无线WiFi 满足时候可以做。
常犯错误：电信猫和路由器位置错误，很多家庭走水电不考虑光猫和路由放置位置，随意走线，导致后期无法上网。所以水电改造第一步确定家里上网方式和需求，确定光猫和路由的位置。
方案二：AC+AP面板模式（适合较大户型）
连接顺序：光猫 → AC 一体化主路由（弱电箱 / 客厅居中摆放）→ 全屋预埋超五类 / 六类网线 → 各个房间 AP 面板。
优点：全屋信号均匀无死角，每个房间自动无缝切换网络，网速稳定、延迟低。适合长期自住、大平层、多卧室、墙体复杂的家庭，也是装修行业公认最耐用的全屋网络方案。
做法：例如光猫放弱电箱，网线到电视墙路由器，此时从路由器走网线到各个房间的AP面板即可，不用单独电源，此类PoE面板是网线直供电源的，不需要单独供电。
缺点：前期需要水电阶段全屋预埋网线，水电造价偏高，后期不能随意改动布局，属于一步到位的做法。
常犯错误：①前期水电改造费用高，让好多人望而却步，入住又后悔，此时已经没法解决了。②网线错误从光猫连接导致后期无法上网。
方案三：Mesh组网模式，最灵活的搭配
此类做法分为有线组网、无线组网、混合组网三种，适配所有已装修或者新装修的家庭。
连接顺序：光猫 → 主Mesh路由 → 子Mesh路由（通过有线或无线连接）。适用场景：复式楼、别墅、大户型，或者装修时网线没布好的家庭。1.无线组网
新装修或已入住家庭：例如弱电箱放光猫，走网线到客厅电视墙放主路由器，其他房间可以放置子路由器，保证无线WiFi 全屋覆盖。
优点：组网自由，可以解决已经入住家庭网络信号问题，不需要走线，只要购置新的子母路由器即可解决信号差的问题。
缺点：主路由器与子路由器靠无线连接，超大面积户型，网络信号不是很稳定。
2.有线组网
两种走线方式：①全部从主路由到子路由器，这样所有子路由器都是第一个层级，网络信号更佳；②从主路由器到第一个子路由器，后面子路由器接到第一个子路由器，属于串联形式，适合户型比较狭长的方式，这样做子路由器的层级属于递减形式，网络信号会有延迟。
只适合新房装修家庭：例如光猫放弱电箱，走网线到客厅电视墙主路由器，走网线到各个房间或者最远的房间，然后加子路由器。
优点：有线走网，网络更稳定，而且更自由；新装修的可以给每个房间都从主路由器接网线以后，入住可以先用一个子路由器，后期信号不好，可以随时添加子路由器即可。理论上只要有网线可以无限拓展。
缺点：装修的时候大量布网线，造价也是最高的一种，但是后续不会有后悔的余地。
3.混合组网
顾名思义，就是有线Mesh和无线Mesh混搭的形式，可以首先做一个重要的有线Mesh，后期不够了可以添加无线Mesh。
方案四：AC+吸顶AP+面板AP其实就是第一种AC+AP的另外一种做法，采用吸顶的AP和房间AP互相弥补，来满足无线信号的稳定。
优点：吸顶AP的体积要大于普通的墙面AP，信号的覆盖面更广，适合公共区域很大的家庭首选公共过道顶部安装。
缺点：吸顶AP的体积大，需要顶部安装美观，同时又不能隐藏，会遮挡信号，所以要从实用和美观之间取舍。
陈工总结避坑提醒：
①不要盲目跟风AP 面板，小户型方案一完全够用，避免花冤枉钱。②如果是大户型拿不定主意，预算充足的话，水电阶段一定要全屋预留网线，不管后期选哪种方案，有网线就有选择权
③拒绝劣质信号放大器，延迟更高④大户型优先 AC+AP 或有线 Mesh，自住长远用，稳定才是关键。
