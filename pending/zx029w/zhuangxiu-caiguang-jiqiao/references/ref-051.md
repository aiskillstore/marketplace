# 卫生间做好5点，暗卫也不会臭气熏天12.27

卫生间异味或者有臭味，的确非常让人头疼。但其实这些在装修的时候是可以避免的，只是大部分人在装修的时候，只把重点放在了颜值和功能上，而忽视了入住以后要面临的防臭细节。
第一、人为排风功能必不可少。
▲卫生间大部分都有单独风道口，如图右上角所示，此时排气扇是必不可少，这里一定注意购买的时候大功率最好，功率小了排气能力不行；噪音与排气是成正比的，你家如果排气扇无声静音，排气能力是肯定不行的，这一点与油烟机相似，想要排气能力好，噪音必然大，所以这一点做好也是人为排除异味的最好办法
▲并不是所有的卫生间都有单独风道，有的是没有的，需要从外墙直接打孔，满足后期排气扇的安装。一定要做，有好多人感觉明卫有窗户不做排气扇，这个是错误的，冬季洗澡你不可能直接开窗的，必须用到排气功能的。除此最重要的是排气扇止逆阀一定要安装稳固和密封。第二、防水以及美缝基础一定要做好。▲湿区防水一定是做到吊顶位置，防潮气才是重点，那些为了低价切入连工艺都做不到位的防水，多半是侥幸而已；因为防水做不好后期只能砸掉重做了；▲卫生间瓷缝是继防水之后的第二大重要工艺，一定要做，否则过去的勾缝剂时间久了全部脱落，导致水进入瓷缝缝隙，长时间以后，就会导致你家瓷砖与防水层之间长期潮湿，必然会有发霉异味，更严重会导致潮气四周蔓延，外墙发霉脱皮等后果。第三、地漏一定要用对，而非用好。
▲北方和南方不同但是类似，例如上图就是典型的北方隔层排水，抬头看你家地漏管道，如果有左图的存水弯，你用任何地漏都不会有异味；如果是右边的没有存水弯，你地漏随心所欲必然后期有异味；▲如图就是没有存水弯用普通地漏，压根不会防止异味，而且高层都是共用管道，卫生间肯定始终都是臭烘烘。▲而采用深水封地漏，因为地漏有存水功能，此时任何异味不会通过水到室内，所以没有存水弯的地漏必须采用深水封地漏，而非只关注地漏怎么好看或者材质。有存水弯最好不用深水封，会导致下水过慢的。▲如果已经入住，发现地漏买错了，可以买一个深水封地漏芯更换一下，解决这个问题。但是前提是管径一致，下水管深浅以及地漏芯可以更换。注意：以上只是北方隔层排水的问题，如果是南方下沉式卫生间呢，注意最好不要自己做存水弯埋到地下，会增加隐患，而且一旦堵塞不好清理，所以采用深水封的后期做法最保险。第四、洗手盆下水异味根治。
▲肯定有人说了，洗手盆的按压器需要更换。其实这个和异味没有任何关系，充其量就是有个过滤网可以挡住杂物或者头发而已，和防臭没有任何关系，下水器的样式无法隔绝任何洗手盆的异味的。▲还有人说更换上图的下水管就可以，没用，只是让你家下水速度更慢而已。▲注意洗手盆还得看存水弯，如果你家洗手盆下水管有这个存水弯，是不会有任何异味的，即使你下水器用的是普通的，也不用花里胡哨的下水管设施，也不用手动折S弯，压根就不会有异味。▲如果你家洗手盆下水管没有存水弯，就需要下功夫了，这个需要自己入住自己动手操作了；如上图下水软管与下水口的密封一定要做好，在家动手没有材料最简单的办法就是，用家里的保鲜膜缠绕，多缠绕直至密封，然后保鲜膜外面采用透明胶带密封固定，保证这个接缝不会出现异味。虽然方法古老但是对于异味的隔绝是最管用的。
▲当然上图就是懒人自认为的高级做法，购买成品硅胶密封接头。不推荐，因为这玩意短时间管用，时间久了下方的硅胶会随着使用以及温度污水侵蚀的而变化，就会失效产生缝隙，等于白做。▲洗手盆下水管没有存水弯的第二道重点，如图所示，左图就是下水软管没有存水的做法，这种压根不会防臭和蚊虫；如右图，自己动手一定折一个S弯存水，这个才是杜绝异味和蚊虫爬出的正确做法。▲当然购买成品的不锈钢金属下水管，自带S存水弯也是可以的。▲墙排下水管也是同样的道理，一定要有存水弯，自己动手折或者成品都是可以的。注意：洗手盆下水本身没有存水弯，一定要第一做好软管与下水口的密封；第二下水软管一定要有存水弯；如果你家下水管本身带有存水弯，以上照做，如果发现下水过慢可以去掉你人为的存水弯，这样下水会更快。第五、马桶异味。
▲马桶异味的几率很小，马桶内部都是自带防臭的，唯一有异味就是安装问题；如图法兰圈移位或者错位，有缝隙必然会有异味；如果家里有异味一个一个按照上面的做法排除，依然有异味，就需要检查马桶重新安装法兰即可。▲马桶除过法兰做好，同时下方的密封胶也得保证密封，安装完以后缝隙采用瓷缝做，第三道密封同时不会变脏，这样做即使法兰有错位问题，有密封胶也不会出现异味。以上方法你都做到位以后，卫生间不论是暗卫也好明卫也好，是不会有任何异味的。
