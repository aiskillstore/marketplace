# 装修新房，阳台刷漆还是瓷砖？4.15

首先搞清楚阳台的作用是什么？
1.晾衣服，这是普通老百姓阳台的最大用处

2.储物，也就是放一些杂物，还得兼晾衣服

3.休闲空间，比如放个桌子阅读或者品茶的地方，这个前提是家里有两个或者两个以上的阳台，有一个专门晾衣服的阳台

一，如果你家就一个阳台，还得晾衣服，不论是朝向何方，必须贴砖，否则就是下面的后果。

阳台乳胶漆长期晾衣服会使墙面潮湿发霉甚至脱落，当然有人会抬杠：我家就没有事。

是的，这就和过马路闯红灯一样，告诉你不要闯红灯会死人的，可是你就非得说闯了这么多年了，不是还活得好好的。可是却把那些因为闯红灯而送上性命的灵魂不放在眼里。

不要存在侥幸心理，只是说如果只有一个阳台最好直接贴瓷砖，否则晾衣服时间长了，有问题出来再后悔又有什么意义？直接贴砖好看耐用而且一劳永逸。

二.如果你家有两个或者两个以上的阳台，此时当然可以选择一个贴砖一个乳胶漆，例如晾衣服的贴砖，不晾衣服的可以直接乳胶漆就可以，作为休闲空间使用了
三.阳台的几大功能

晾衣服，老百姓过日子必备用处

休闲空间，喝茶聊天，当然得有另一处晾衣服的地方

阳台放杂物，作为储藏室使用

阳台和客厅融为一体使用，当然最好有另外地方晾衣服

阳台和卧室融为一体使用，当然还得有别的地方晾衣服
