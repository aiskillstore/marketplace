# 镶嵌洗碗机，水电路一定要做对5.16

现在装修年轻人厨房标配洗碗机，是生活便利，也能节省更多时间。但是自己装修的时候，往往在洗碗机是否能做上，犯了好多错误。今天就看看洗碗机水电路设计注意的地方。

▲金辉世界城实景图▲▲如上图厨房，L型布局，需要洗碗机，首先装修之初就得定好方案，看厨房是否具备做镶嵌洗碗机的条件。
1.下水，必须具备的条件，一般现在的厨房很少有地漏，都是悬空的水槽下水，所以只能和水槽共用下水，三通下水。
2.空间，必须保证水槽左右有足够的洗碗机的空间，这个需要做洗碗机的时候，在网上看上产品，把详细尺寸发给装修公司设计师，或者发给你找的定制橱柜商，这样就会给你规划空间。
如果空间允许才可以决定做，千万不要没有空间直接做水电了。这个错误一般犯在自己装修的业主家里。自己不懂规划，也不知道空间够用不，直接跟着别人让水电工随便预留洗碗机水电，散工才不管你能放不能放，水电做的越多手工费越高而已。
▲注意看上图的做法，竖管位置是水槽，上方留了电源，应该是后期给净水器留的。右边两个插座和上水明显是错误的。如果按照这样竖管和上水之间可以放洗碗机，但是洗碗机放了以后，水槽的上水怎么能绕过洗碗机接上？正确的做法必须把插座电源和上水放到水槽下方，然后隔板打孔即可安装。

▲如上图，电源和上水必须放在水槽下方，隔板打孔就可以接洗碗机。
3.洗碗机柜门。购买洗碗机的时候，有自带柜门，有的没有柜门，需要做橱柜的做柜门，这个需要协调好，要不要柜门，洗碗机的价格是不一样的。像第一张金辉的做法就是用的自带洗衣机门。洗碗机后面不能有任何管道或者障碍物。
▲如上图,洗碗机不带柜门，橱柜定制的时候做柜门，这样关上门颜色能统一一点，视觉美观一点，不过见仁见智，看自己喜欢哪一种。洗碗机，你家适合哪种？
