# 瓷砖铺贴翻车，这些错误不该犯4.16

瓷砖铺贴肯定会有各种各样的问题，能整改的问题不算问题，但是有些问题是完全可以避免的，前期没有考虑成熟，或者说没有按照原则办事，就会出现一些无法改变的遗憾。

▲如图所示，窄边全留在了不该出现的地方。

原因有两种可能：
第一自己装修，找瓦工直接施工，而且不懂排砖，买瓷砖图便宜，商家压根只管卖砖，从来不管你怎么铺，最终是两道把关，没有一个管用，就会出现这个结果，后悔已经来不及了，除非你砸了重铺。

第二找装修机构，瓷砖自己购买的话，需要商家出具铺贴图纸，但是商家一般只顾卖瓷砖，至于铺贴是否完美，边角在哪，几乎百分之八十都不操心，随便给你张图纸，然后作为装修机构是按照图纸施工，最终出来边角全部外露。

所以你家铺贴什么瓷砖，规格多大，不是想当然，必须是出具合理的铺贴图纸以后，然后决定用多大瓷砖，怎么铺贴，起点在哪里，从哪里能最大化避免窄条外露，说简单也简单，但是往往就是没有人操心才造成严重后果。

▲学别人通铺瓷砖，然而连个图纸都没有，找个工人自由发挥，这也叫通铺？算是通铺，但是零分的通铺；其实掏钱的装修贵那是有道理的，操心费才是最贵的，而不是你看到表面数字那么简单。

▲不用说都知道问题在哪。一个是瓷砖选购颜色的问题，有壁龛的话就得想到不能用两色瓷砖和腰线；第二工人完全是随心所欲，这手艺出来挣钱也够糊弄的

▲看了上图大部分人可能不知道真正的问题出在哪里，其实就是早已淘汰的工艺：墙压地还是地压墙。

已经到了2022年了，瓷缝工艺都炉火纯青了，但是还有人执着过去老一辈的观念，一定要墙压地，否则就是朝天缝，非得把一个简单的铺砖复杂化，导致不该发生的失误。

好吧，你以为墙压地是那么好实现吗？右图，最后铺贴最下方的瓷砖，因为你家卫生间小，有地漏就得有坡度，这个坡度瓷砖手艺再高都会出现问题，缝隙不一样，尤其是越小的卫生间，就会导致最下方瓷砖完全是斜的；左图是没有坡度的地方，缝隙倒是小了，但是美缝没法填实导致美缝时间久了就得脱落。所以，已经有美缝了，不要纠结朝天缝了。

▲左图是没有动脑，右图是动脑以后，你们说哪个美观？小面积铺贴瓷砖一定要注意灵活变通，当有第二种铺贴方法的时候，暂且停止，看哪一种能达到完美，然后去做，而不是低头蛮干。装修能做长久绝对不是蛮干出来的。

▲同一个户型，同一个阳台，三种效果，显然最右边是最佳方案。取决于是否愿意去动脑，愿意把细节做到完美而已；普通工人干一家是一家钱，给你多想要钱的话不好要。装修机构吧，碰到不是良心干事的，别人怎么做自己也怎么做，凭啥多想，多想费用多了咋办？这就考验装修机构的眼光了，看眼前利益还是长远发展了。

▲瓷砖墙面地面规格不一样，最好不要去强行对缝，顾此失彼的事情肯定会发生，其中利弊在铺贴之前一定知悉，等铺完了后悔就来不及了

▲淋浴地漏不是什么太高深的工艺，这是属于职业道德的问题，如果连个淋浴地漏安装基本规范都不知道，或者不懂的话，要不是故意的，要不等着全房瓷砖脱落吧，不懂这个工艺的瓦工怎么可能把大面积瓷砖铺好

▲没有生活经验，也不多问问人，让卖砖的忽悠，把大客厅的亮光瓷砖直接通铺卫生间，而且又不做淋浴房，地漏也无法做任何坡度。以后洗澡水没法流，而且洗澡滑到连站立都是问题。

▲卫生间小规格瓷砖做壁龛，最好根据瓷砖规格进行分割对缝处理，视觉比较好看，而且放置洗漱用品并没有这么高；比例失调空间是大了，但是不实用而且影响美观

▲干区采用400*800瓷砖上墙，背景不贴单独花砖，就会出现以上4种的铺贴方式，如果是你你喜欢哪种呢？第一个，墙面是90公分，多了一个10公分的窄条；第二个裁割成对称大小铺贴；第三直接裁割成300的铺贴，瓷砖呈现竖向排列了；第四个错位对缝处理，不用花砖但是有了更多的灵动

▲学别人做无主灯的品位，但是其他地方也得跟上，地面通铺亮光瓷砖，这是老一辈人的认知，总认为亮光就能光线好，但是毫无质感，很难打理，然后无主灯的反射全部到顶面；太阳照射地面以后，家里到处都是光影。

总结一下：
瓷砖铺贴失误一般不外乎四种原因：
1.瓷砖商家问题，一般业主自购瓷砖，铺贴图商家负责出具，然而商家只顾卖砖，才不管你铺贴好坏，随便出具一张图纸应付，如果不幸业主找的是散工的话，散工才不管你怎么铺贴好看，根据图纸施工，赶紧完工干下一家，最终是铺完了才发现，各种问题，已经迟了；如果你找的是装修机构，你的铺贴图纸发过来，会有审核这一关，如果有明显瑕疵马上会告知你，最终会让你选择更完美的铺贴方式，这就是区别。

2.设计师的问题。如果你找的装修机构就是纯粹赚钱坑你的，那你即使拿他们的瓷砖，设计师应付或者压根不懂排砖，最终效果倒霉的还是你。

3.瓦工问题。这里如果找装修机构的话，就不是瓦工问题了，其实怎么铺，那是设计师说了算，并不是让瓦工自由发挥的，所以一旦设计师排砖图错了，那肯定瓦工就铺错了，当然好一点的公司，瓦工比较负责的话，这一关就制止了，然后与设计师沟通，哪一种会更好。

4.最后一个业主买砖的问题。这里有一定的审美基础，毕竟业主是第一次接触装修，对于什么瓷砖铺贴出来效果好，哪种瓷砖该用到什么地方，压根不知道。如果是自己装修的话，只能听天由命，不求有功但求无过，这就是最好的结果了。但是现实往往是会给你警示的，要不瓷砖花纹买错，要不规格买错，要不被卖瓷砖的忽悠。审美是没有办法的，但是功能性错误就没救了，例如上头提到的卫生间地面全部采用大规格亮光瓷砖，这是审美和常识都错误的做法了。
