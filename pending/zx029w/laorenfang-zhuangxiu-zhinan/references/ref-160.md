# 55㎡公寓一人住，为了收纳做了错层

小户型公寓的装修一个人住，只要满足基本的功能，差不多都可以顺利入住；但是本套公寓虽然一个人住，但是卧室与客厅如果不做独立分割，就显得拥挤；而且卧室和客厅都想要很好的采光，所以大胆把卧室做了错层上铺处理，这样既保证了各自的光线，还能满足更多收纳，总花费12万。

▲原始户型结构没有做任何改造，唯一在进门口新砌了一堵墙，一是为了满足橱柜的延伸，二是满足鞋柜的定制。进门右手是卫生间，左手过道就是开放式厨房；卫生间拐角地方刚好做了错层卧室上铺，下铺可以满足收纳储物，同时下铺还满足了一个办公区域；借用超大的落地窗下方还布局了小的餐桌空间，可以满足平时的就餐，同时也是光线最好的休闲角落

▲整体不大，几乎是全景了。进门过道就是厨房空间，同时新砌墙分割出一个过道衣柜收纳，满足衣物的存放。中性色的搭配能看出来业主是一位帅锅。
▲衣柜与阳台柜之间刚好布局两人位沙发，背景借用墙体做了一个壁龛收纳，灯光布局，可以随时放置各种零碎，极简轻巧的落地灯以及筒灯，灯带可以营造温馨的客厅氛围
▲电视墙整体收纳柜布局，也不要电视，黑白配，黑色元素的镂空可以让视觉更有层次，下方壁龛以及落地黑色的石材地台，可以摆一些养眼小饰品作为展示，让空间更温馨
▲超大的落地窗让光线一览无余，刚好利用落地窗下布局一个小的餐桌，吊灯搭配，这里可以作为偶尔就餐的区域，大部分时间这里也是最好的喝茶阅读的地方
▲虽然一个人住，灯光布局上一点都不含糊，冷暖结合，即使一个人，晚上也能让空间更温馨舒适
▲落地窗的柱子处定制木质的收纳柜，兼顾收纳同时兼顾餐边柜的功能
▲铺上格子桌布能让视觉更温馨，花卉装饰，泡一壶茶，看外面夜晚的万家灯火
▲极简的吊灯，与餐边柜的暖色灯带同时烘托气氛，这里喝下午茶再好不过，窗外风景尽收眼底
▲原来卧室的位置为了满足收纳和成就一个书桌空间，同时不影响采光，采用错层方式，把卧室做成上铺空间，这样既不影响卧室采光，还成就更多下方收纳功能，同时也能避免公寓房卧室和客厅在一块的视觉凌乱
▲上铺空间，也不影响光线，四周铁艺的护栏保证安全；背景采用软木背景舒适而且温馨
▲卧室上铺的楼梯同样采用收纳定制，储物量超级强大
▲抽屉收纳和柜体收纳同时满足，满足所有杂物的存放了
▲门口的过道是开放式厨房，为了满足更多收纳，做了L型布局，一个人住满足偶尔的烹饪绰绰有余
▲卫生间采用浅色爵士白瓷砖，能让暗卫光线好一点
▲淋浴房一边是定制木质浴柜，镜柜满足收纳，另一边放置洗烘一体机END
