# 卧室有个落地窗，能怎么利用？8.11

以前谈过各种窗户，唯独没有说过落地窗，今天这一期谈一下卧室落地窗，给大家装修带一点新的思路。

▲如果功能收纳都有了，落地窗可以作为本来面目存在，无需改造，让光线和空间的都得到提升
▲放个小书柜，不至于挡光，加一把休闲椅，落地窗可以作为独处阅读的最佳场所，累了还可以赏尽窗外风景；落地窗还可以加上吊顶局部灯具照明，同时满足窗帘盒的功能
▲超大落地窗，上方局部吊顶满足局部照明，同时满足窗帘盒布局，下方放置书桌，刚好满足办公和学习功能
▲落地窗下可以满足化妆台的布局，自然光下美更自然；添加一个懒人沙发，这里也可以是休闲角落
▲上方吊顶满足窗帘盒需求，一把单椅+一盏落地灯，这里就是休闲阅读的地方
▲落地窗上方吊顶实现窗帘盒功能，利用隔板延伸，刚好在落地窗位置实现小的化妆台功能
▲空间小的卧室，可以借用落地窗拓展空间，同时满足一边的化妆台功能
▲小的落地窗下方刚好满足化妆台的布局，功能最大化
▲放一把休闲单椅，可以作为平时休息角落
▲木质装饰一下，懒人沙发与圆几搭配，这里休闲阅读最好不过
▲空间小，最好留空，满足空间的基本通畅
▲落地窗的空间合理利用，化妆台满足了
▲儿童房落地窗刚好利用起来，定制书桌，满足一个学习空间
▲刚好借用落地窗满足书桌学习功能
▲原有落地窗位置，打造收纳柜，实现一个兼顾收纳，同时休闲的飘窗功能
▲如果是老人房的话，落地窗可以放置休闲椅子，供老人随时坐下来休息
▲落地窗下方定制收纳柜，兼顾收纳和休闲两用
▲落地窗下方满足书桌的布局，刚好延伸功能
▲落地窗位置定制书桌书柜，满足基本的学习和收纳
▲很大的落地窗，一部分满足书桌学习，一部分满足收纳和休闲
▲弧形落地窗下刚好满足按摩椅的布置，利用空间增加功能性
▲落地窗利用隔板，布置一个简易的吧台，可以满足休闲功能
▲落地窗实现拐角书桌的定制，衣帽间兼顾书房完美实现
