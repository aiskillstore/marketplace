# 160m²美式四房，父母装修也不含糊

建面160平的四室户型，因为实在没有时间，只有父母在照顾装修，从装修开始规划都是父母在操心。并不想着父母能装出什么样子，关键他们喜欢就行。完工以后，实在意外，父母竟然时髦的装修成了美式风格，这点想一想父母应该是为了照顾我们年轻人了。美式风耐看且稳重。

▲这是入户花园，也不知道做什么用。铺仿古砖，美式休闲家具搭配。角落因为有个下水，父母还专门定制了小水景，对面做了非常时髦的洗手台。已经很让人意外了，父母的眼光不错

▲入户花园进来右手就是客厅，深红色的木地板，这是预料之中，几乎小区父母辈装修都是这个颜色，也不知道是不是一起团购的。家具倒是可以，真皮美式沙发，还搭配了田园风的单椅。灯光以及吊顶就有点千篇一律了，灯带+筒灯而已

▲电视墙听说父母绞尽脑汁想出来的，咋不是很相信呢，几乎有百分之三十小区住户都是这个电视墙，应该都是互相抄袭的吧。不过，电视柜还是蛮配套的

▲看个电视墙整体，旁边就是入户花园进来的门了。因为是电梯入户的，所以这里必须装防盗门

▲来个客餐厅全景，这样看来光线还是可以的，木地板还不是很深。南北通透的房子光线还是不错的

▲另一边的餐厅空间，厨房和防盗门之间刚好有个凹陷区，就做了收纳柜，且镶嵌冰箱，几乎小区都是这样做的。中国结是父母的杰作

▲不同的设备拍出来的感觉天地之差呀

▲餐厅全景，家具是统一一家购买，挺奢华的吊顶，父母的退休金应该所剩无几了

▲餐厅看客厅空间，进门碰大象，不知道是什么寓意，第一次进来有点害怕。按照父母的说法，这里挂大象头是有讲究的，至于什么讲究到现在也无从知晓，应该又被团购忽悠了吧

▲这是儿童房，虽然孙子还是孙女都不知道，父母都能装修好。从这个布置看，肯定想要孙子呀

▲这是主卧，父母的房子，搭配不错吧。唯一就是主卧真的没有什么意见。颜色包括灯光都非常满意

▲超级大的飘窗，可以当座椅休闲使用了
