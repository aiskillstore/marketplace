# 给老人装修，其实要求很简单1.27

每一家都有老人，今天谈的是给老人单独装修一套房子需要注意什么，并不是三代人同住注意什么。因为三代人同住，装修基本老人没法插嘴，除非是老人出钱；只要有住的都不错了，能把带卫生间的主卧留给老人的寥寥无几。

▲鞋柜不鞋柜其实不重要，但是门口的换鞋凳必须有，老人回家或者出门，可以坐着换鞋，穿鞋，非常方便；只要实用就行，哪怕没有鞋柜，常穿的鞋子直接放到换鞋凳的下方，要好拿好取多了；
▲下沉门厅禁止出现在老人装修中。千万不要用年轻人的思想装修老人房，做这个的人居心不善呀，老人每天回家都是一趟危险的旅途
▲进门暖色灯光明亮为主。切勿采用傻白的光线，进门没有温馨感；同时尽量不做门厅的复杂吊灯，采用暗藏筒灯布局，减少老人怕灰尘爬高打扫卫生的危险
▲进门处不能采用玻璃做玄关，更不能采用透明大块玻璃。这个和下沉门厅有一拼，都是非常危险的存在；玻璃制品老人进门容易用手扶，甚至是磕碰，非常危险，而且透明大块的玻璃，老人视力本身就不好，更容易碰到。老人房不要做玄关，让所有空间互通，尽量减少迂回拐弯的空间，更利于老人平时的通行
▲北方地区采用柔光或者哑光瓷砖通铺。如果使用木地板请用纯实木，否则禁用亮光瓷砖，柔光哑光防滑，同时减少老人打扫卫生的次数；而且地暖房子，减少使用加湿器的次数，采用拖地等安全物理加湿的方式，对老人身体更好；拖地的同时既锻炼身体，又能让冬季干燥的房间添加湿度
▲如果夏天因身体原因无法使用空调，客厅采用风扇灯。既满足了平时的照明，又能给老人炎热的夏季带来安全的清凉
▲如果可以餐厅也可以布局风扇灯，厨房最好用木质的推拉门，减少大面积玻璃的存在。安全实用为主要原则，餐桌餐椅适合木质的材质，圆角处理，避免磕碰，最好铺上柔软的垫子，让老人更舒适的就坐
▲餐边柜不宜通顶，采用矮柜最好。老人不需要爬高拿东西，减少危险；同时矮柜可以让老人随手放置物品，更实用方便
▲冰箱最好放厨房，同时冰箱尽量够用，小一点。厨房小一点不怕，最好冰箱放厨房，减少动线的距离，老人拿取操作更方便，同时最好采用单开门冰箱，减少食物的存储量，这样老人每天散步都可以捎回来新鲜的果蔬，否则太大的冰箱反而不利于健康，老人省吃俭用惯了，怕浪费，会导致放置冰箱的食物久了反而不利于健康。
▲厨房收纳如果够用，能不做吊柜尽量不做，采用低的隔板代替。因为吊柜太高老人登高取东西危险，可以采用隔板的形式，满足老人随时放置和拿取东西，更便捷；如果要做吊柜，最好给老人添加升降拉篮，增加拿取的便利性
▲如果要做吊柜，最好给老人添加升降拉篮，增加拿取的便利性
▲厨房电器征求老人意见后购买，不要盲目配置洗碗机等懒人电器。好多老人不愿意使用，一是不相信机器能比自己洗得更干净，最大原因是电器比较复杂，而且成本高，所以最好购买前依据老人需求购买，防止买回家不使用，老人看着浪费反而影响心情
▲厨房最好给老人做高低台。根据老人身高定制，避免老人弯腰，尽量让使用舒适，同时尽量用地柜满足收纳。
▲家具方面多征求老人意见，多以木色温馨为主；灯具最好不要用吊灯系列，可以采用无主灯布局，减少视觉的凌乱，同时减少老人不停想清洁的冲动，这样就可以减少好多危险隐患
▲老人居住电视墙不要做造型，也不要做收纳柜，太高收纳够不到，登高取物反而危险；简单的悬空电视柜摆放，打扫卫生方便，绿植摆放，简单也耐看
▲卧室电视是必不可少，可以让老人平时躺床上就可以看电视，同时最好给卧室配单人沙发，老人可以随时就坐
▲老人房颜色素雅为主，床头可以采用布艺的高靠背，方便老人倚靠；床头灯必须有，方便老人起夜使用，同时收纳床头柜必须有，老人随手放杯子，随手物品都方便
▲如果老人居住的房子能有一方花园，这是最好不过了，给老人一点田园地，平时可以养花，晒太阳，都是非常不错的。
▲如果没有露台，有个朝阳的阳台也是不错的，除过平时晾衣服，老人也可以养一些花草，备一个躺椅，平时晒太阳休闲的好去处
▲老人房如果带阳台，一定给装上门，最好不要采用大面积透明玻璃，减少安全隐患的同时，冬季利于卧室保暖。
▲老人房洗衣柜定制，最好不要做吊柜，登高取物危险有隐患。
▲老人卫生间坚决不要浴缸，这个是非常危险的；淋浴配上淋浴凳，老人可以坐着洗澡，降低手持花洒的高度，老人坐着方便拿取。同时马桶跟前配备扶手，方便老人随时有扶的地方。
▲老人卫生间不要做任何挡水或者淋浴房或者淋浴隔断，减少危险因素的存在；瓷砖一定要防滑，而且淋浴地方一定配备防滑垫。

▲老人居住卫生间尽量采用木门，坏了再换，不要心疼说木门腐烂了，让玻璃占据面积越小越好，减少危险因素，同时木门一定朝外开，这样有突发情况，老人自己可以推门而出，切记不要朝内开，情急之下老人无法推开的。
