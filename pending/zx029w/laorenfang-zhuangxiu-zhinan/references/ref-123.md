# 收纳柜靠窗户，有哪些更好的定制样式？3.17

很多户型都存在衣柜与窗户的问题，虽然是缺点，但是懂得设计的话，缺点有时候可以变成优点。今天看看这类专题，在自己的装修中可以作为参考。

▲电视墙满墙柜定制，延伸至窗户位置，而且与飘窗柜一体衔接，飘窗柜上靠近窗户位置采用镂空书架形式，满足另外一种收纳功能，视觉上刚好让满墙柜与书柜卡座有了区域划分，不会产生突兀感

▲书房区域一边书架，另一边是窗户，靠窗户位置延伸一个书桌出来，避免影响光线，同时延伸合理功能

▲如图榻榻米衣柜延伸至飘窗位置，刚好有墙体遮挡，直接延伸定制，满足收纳的更多功能

▲书房就比较简单，窗户跟前延伸书桌或者化妆台，如图所示，既能保证不遮挡光线，还延伸功能，还满足上头风口的布局

▲如果是推拉窗不影响窗户的正常开启，但是为了最大限度保证采光需求，靠窗户位置采用超薄的书柜布局，这样就可以避免厚重收纳柜遮挡光线了

▲靠近窗户延伸隔板充当一个小的书桌，隔板简单置物，可以满足功能，同时又能避免影响光线和窗户的开启

▲如果是衣帽间，为了保证最大的储物量的话，可以直接留出窗户，这样就可以实现一个卡座空间，还能保证窗户的正常开启

▲如图所示衣柜延伸的话会影响采光，而且会影响空调风口的布局，刚好预留一段距离，下方用来满足成品化妆台的放置，上方也能保证风口的布局，同时并不影响窗户的采光需要

▲如图电视墙满墙柜如果延伸到头会遮挡窗户，刚好利用窗户跟前布局一个小的书桌，用来满足平时的办公，轻松解决遮挡窗户的问题，而且也满足了另外一个功能

▲如图书房空间靠近窗户，采用延伸书桌以及超薄书柜的做法，同时保证不影响采光和满足上方空调风口的需求
▲阳台区域往往也存在收纳柜与窗户窗帘的问题，如图故意留出距离，用来满足窗帘的布局，同时保证最大的采光面
▲如图L型的做法，可以最大限度保证采光需求，同时如果是平开窗的话，可以保证窗户的正常开启
▲床尾衣柜与窗户位置的问题，可以采用镂空书桌的做法，上方超薄书柜，这样既可以延伸功能，而且不影响采光以及窗户的位置
▲床尾衣柜靠近窗户化妆台延伸，留出窗帘位置，满足功能，同时保证了采光和窗帘的正常使用
▲书房兼顾衣帽间，如果衣柜延伸可能会遮挡窗户，采用两边超薄书柜的形式，刚好满足双人位的书架功能，同时保证不会遮挡窗户的光线
▲在不影响采光以及窗户开启的情况下，可以衣柜做到头，留出合理窗帘空间即可
▲像这种空间小的儿童房，做了小的衣柜以后，靠近窗户延伸一个书桌，简单隔板放装饰品，可以避免遮挡光线，同时还能满足自然光下布局书桌的功能
▲平开窗的话，衣柜直接断开，做高低定制，抽屉还能满足分类收纳，不影响平开窗的开启以及光线
▲榻榻米房子墙厚满足不了做衣柜，可以把书柜与衣柜调换位置即可，超薄书柜避免与窗户的冲突，衣柜放角落刚好与书桌同厚度
