# 卧室无主灯，怎么去做？9.3

无主灯其实不算太复杂的做法，视觉可以让空间更加简洁，空间更清爽。灯光的层次感更好；像卧室如果做无主灯，见光不见灯的话，更温馨柔和

▲卧室不要主灯都是可以的，床头半截背景灯带营造氛围和照明，搭配一盏台灯即可，只有夜晚才进来的卧室，永远都是温馨的

▲局部平面吊顶，暗藏灯带的做法更符合见光不见灯的无主灯设计，筒灯照明，床头以及悬浮的床下灯带围绕，两边吊线灯点缀，这样的卧室灯光，既满足基本照明，又有了氛围的营造，同时大面积见光不见灯的做法不刺眼，整体柔和温馨

▲灯带+暗藏筒灯以及吊线灯局部点缀，无主灯的卧室照明就可以满足，而且肯定比一个主灯要更有氛围感

▲灯带作为主要照明，见光不见灯，也不会造成刺眼和光污染，局部筒射灯点缀，不要主灯空间更显得简洁

▲不要主灯，全部采用暗藏灯带满足照明和营造氛围，一般的卧室完全是可以的，见光不见灯才是无主灯的精髓所在

▲卧室做无主灯最忌全部采用筒射灯，如图的明装和安装，防眩光的还好一点，否则相当于把一个灯换成N个灯的做法，不仅满足不了柔和的光线，说不定会更刺眼，造成光污染

▲灯带作为主要照明，暗藏筒灯作为点缀或者作为正常照明，此时灯带可以作为主要光源使用，氛围更好，更符合无主灯的布局

▲其实如果卧室不大，想要无主灯的话，如图的做法灯带营造氛围，两边吊线灯补充照明，这样做完全满足卧室无主灯的做法，视觉空间上也能更加简洁

▲像这种大面积做灯带的照明，见光不见灯做法最好，局部配合筒灯以及吊线灯，实现无主灯的做法

▲如果非得用平面吊顶，暗藏筒灯以及射灯的形式做无主灯，一定要购买放眩光的产品，否则这种做法必然会造成刺眼或者光污染。

▲卧室无主灯最完美做法，其实就是灯带，光线更柔和温馨

▲卧室无主灯的大忌就是这种磁吸轨道灯，非常刺眼，搞不好会造成光污染，特别是儿童房，严禁使用这种没有任何健康标准的光源

▲虽然没有那么高级，但其实上图这种用灯带作为主要照明的做法，才是卧室真正的无主灯设计
