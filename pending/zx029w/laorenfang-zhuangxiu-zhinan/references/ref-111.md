# 家里没老人，千万别学别人抬高洗衣机！折腾一圈钱花了…最后发现，腰还得弯！

洗烘机抬高肯定是好的做法，不需要弯腰，当然是好事情。有很多人想不通为什么要折腾？这个是对生活品质追求不同而已；最重要的是，家里人如果腰椎有问题，这样做就可以避免弯腰；特别是家里有老人的话，洗烘机抬高最好不过。想要抬高洗烘机并不是那么简单，不要模仿和跟风，需要有专业人员的全程参与，否则多半钱花了，最后翻车了，还得继续弯腰。01.盲目抬高洗衣机，结果各种翻车。真是见识了，学别人抬高洗烘机，人家是并排抬高，这个都叠放了，你把洗衣机抬高，烘干机咋能够得着？结果是洗衣机抬高白做了，还得弯腰，烘干机家里个子低的人都够不到，需要踩板凳。洗烘机抬高不仅仅是抬高放上去那么简单，和你的产品质量有很大关系，有的品牌质量好一点振动小，有的振动非常大，需要根据产品做加固处理，否则不同的衣服放进去就会导致偏心振动，掉下来还好没有伤到人，要不真的要后悔死了。仔细看图就会发现，只是做了模仿，把洗烘机放上去了，结果振动直接掉下来了。钢架+木板+岩板+挡条。钢架上放木板，木板上垫岩板，三明治叠放，前部再钉上挡条防止机器前移。晃动的确轻了点，但每次洗衣烘衣都会担心岩板有破裂风险！奉劝各位想抬高洗衣机的：机器设计时考虑了放置稳定性，强行架高真的容易踩坑，费钱费力还有安全隐患，不是必须最好不要跟风和模仿。不信邪不撞南墙不回头，结果自己不懂把网图给了全屋定制，定制只管赚钱不管风险，结果不出意料洗衣机掉下来了。光顾着抬高了，结果没有考虑家里人上身高，洗涤盒过高，每次使用费劲。02.抬高洗衣机，正确做法。洗烘机抬高最好的做法就是水泥台面，非常稳固；只要你的洗衣机平地不会振动移位，放上头绝对没有问题。一定注意和洗衣机品牌质量有关系。如果你家购买的洗衣机平地振动都乱跑，就算了，不敢抬高，即使抬高必然会掉落。千万不要很自信的把洗衣机抬高就是平放，如此振动，很有可能掉落下来。上图采用L型金属固定做了遮挡，否则洗衣机百分百会移位。任何洗衣机你都无法保证洗衣时候振动，而且洗不同衣服振动频率不一样，所以不仅仅是底座坚固，一定要采用办法保证洗衣机振动时候不会移位。现浇台子和地面一样的稳固，绝对可以满足抬高的设计。总结一下：抬高设计肯定好，如果是为了老人使用方便可以考虑，但一定把细节做到位；如果不是老人使用，奉劝最好不做，非常麻烦；第二洗烘机抬高需要经过商家同意，否则一旦抬高没有任何售后，后果自负；而市面上大部分商家压根不允许抬高，即使你退货威胁也没有用，所以一定三思后行。
