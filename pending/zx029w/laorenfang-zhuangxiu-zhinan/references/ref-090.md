# 家有老人，装修没有那么简单4.26

▲谁家没有老人，如果老人身体尚且可以，一般不愿意和年轻人同住，所以一般选择在同一个小区或者临近小区生活。但是现实生活中，这样的条件老百姓又有几家能达到？年轻人买房首付是老人一辈子省吃俭用出来的，到了身体不行了，只能和孩子们在一个屋檐下安度晚年。这几乎是大部分家庭的组成方式。于是，在有老人的时候，装修房子就得仔细考虑，让老人晚年能生活的便利和顺心。

▲不论是和年轻人同住，还是老人单独住，家里大面积地面必须防滑设置，比如仿古砖，这个瓷砖简直就是老少通吃。按照北方的情况，几乎都是地暖房子，冬天的时候仿古砖本身就是温热的，而且空气干燥的时候，完全可以用湿拖把拖地来缓解，对于老人来说比加湿器更加健康和环保。《38家美式装修，都用了仿古砖》

同时具备防滑和健康的还有仿木纹瓷砖，这个一定注意，木纹瓷砖可以选择大规格的，这样缝隙比较少。

▲相较于仿木地板瓷砖，木纹砖的规格相对大一点，看起来不是那么凌乱，也能起到防滑作用。《怕污染，用木纹瓷砖，效果看这里》

▲卧室床头柜对于老人来说非常重要，必须选择结实耐用，收纳储物相对多一点的。可以随时放置老花镜，水杯，而且老人始终愿意把对自己重要的东西放在身边。同时床头柜有时候老人会当扶手使用，所以必须注重结实和储物

▲如果卫生间过小，老人居住除过地面防滑，一定要注意收纳。空间小没有台面储物，尽可能做镜柜收纳，方便放置生活用品

▲有能力和空间做洗手台面的，一定要大，可以放置很多物品，同时一定要结实，老人可以随时手扶

▲餐厅能做西厨尽量做西厨，方便老人放置物品，同时冰箱如果和西厨在一起更好，老人买菜或者食品都可以方便取拿和随时放置

▲老人房厨房其实不宜太大，老人活动不便，尽量缩小动线长度，方便老人随时转身操作，台面尽可能宽，适合老人安全放置物品，不至于不小心跌落。光线一定够明亮，老人视力不好，便于晚上在厨房操作

▲老人居住进门鞋柜其实很重要，最好不要下方镂空放鞋，因为老人身体不便利，很难不停低头放鞋，所以最好做成成品或者定制的矮柜，旁边最好有个可以随时坐下休息换鞋的换鞋凳《装修新房，想过放一个换鞋凳吗？3.8》

▲关于客厅沙发颜色上必须深色，耐脏，减少老人的打理时间，同时注意尽量不使用带腿的高沙发，一是便于老人随时落座，而是避免有小零碎掉入沙发下方，老人拿取不方便

▲老人居住家里的插座尽量以方便实用为主，这里就不需要考虑美观，或者家里插座统一高度了，一切以方便老人使用为目的

▲储物抽屉以不过腰为高度，衣柜高度以不超过头为目的，否则太高，老人踩高去拿容易出现意外

▲老人卧室尽量选择带卫生间的，老人起夜方便，同时注意有可能在卫生间做一小块玻璃，便于内外观察，因为老人身体不便利，两个老人随时可以发现发现对方情况，及时照顾

▲卫生间是重中之重，往往老人一个人独处时间最长，有可能注意座便的高低，两边的扶手，以及洗手盆附近尽可能安排扶手

▲洗澡淋浴区注意地面防滑《浴室要防滑，都有哪些办法？3.1》同时墙面设置扶手便于老人随时手扶

▲淋浴区最好给老人备一把椅子，便于老人洗澡时休息就坐

▲如果是浴缸，尽量做好周边扶手设置，同时可以在浴缸设置就坐区域，方便老人坐下来洗

最重要一点：一般老人不愿意让儿女做这些准备，自己不服老，有时候儿女这样做老人还不愿意，认为儿女嫌自己老了。其实这个心里人皆有之，你可以给老人讲解，该做的还得做，老人打心底是高兴的。
