# 为娃上学购买50㎡老破小，这届父母太拼了

非常老旧的小区，总楼层6层，房子位于5楼，非常破旧，破旧到第一次看见被震撼到了。

户型：一室一厅一厨一卫一阳台
造价：拆墙垃圾运输8千；全包7万；
▲未拆改之前的样子，老旧破败，没有一个地方是完好的，完好的地方也非常脏，而且长期不住人，房子里头到处发霉，有一股难闻的气味。
▲原始的结构图。一间客厅，一间卧室带阳台，一厨一卫就是全部，而且客厅居中，整体光线也不是很好，加上过去的老旧房子，问了物业，任何墙体都最好不要动，只能在原有的格局基础上翻新布局
▲设计后的布局图纸，格局没有任何变化，只是把原来的旧的拆除，重新翻新而已。卫生间太小了，为了能满足洗澡功能，只能采用蹲便器，如果采用马桶的话，人都站不进去
▲新改造的入户门厅，更换了老旧的防盗门，包了门套，视觉好看，也避免进门磕碰；左手墙面上是强电箱，孩子手画的龟背竹画，刚好遮挡，简洁也美观
▲入户门右手墙面是网购的鞋柜，非常实惠，几百元搞定，平时收纳鞋子是完全够用；鞋柜上方是照片墙，全家人的照片展示，也算是温馨的一角
▲入户进来就是客厅空间，光线问题，大白墙和灰色的柔光瓷砖搭配，视觉素雅，也能整体提高亮度；布艺沙发搭配粉色抱枕，视觉温馨活泼；小窗户成品的罗马卷帘，不贵实惠；茶几是大理石台面的看起来更精致一点
▲沙发背后一个很小的窗户，在每一天的特定时间总能有太阳进来，这也是客厅唯一采光的地方
▲经济原因，极简装修，不做造型，不要石膏线；跨度太小，网购的悬空收纳柜，满足基本的电器放置；沙发角落还得放置冰箱，因为实在没有地方容纳了
▲白色与灰色为主色调，让空间更简单素雅
▲唯一的卧室带个生活阳台，为了利用率更大一点，把阳台两边的窗户封堵了，这样阳台可以布置一个收纳柜和小小的书桌，孩子平时可以学习。阳台放了沙发床，平时可以睡觉作为单独一张床使用。
▲卧室背景蓝色变色，成品的衣柜，为了空间能大一点，一个床头柜布置，床头精美的挂画与颜值的吊线灯搭配，时尚温馨
▲成品衣柜和床也是网购的，价格比较实惠，床尾是大人的电脑桌
▲床头温馨一角，摆上了好看的花瓶，灯光点缀更温馨
▲孩子平时在阳台沙发床休息，男业主一年四季基本是夜班居多，所以晚上基本是母女两再住
▲改造之后的厨房，没有地方放洗衣机，只能放到厨房，然后需要操作台大一点，就将就把水槽挤到洗衣机旁边，勉强能操作吧，因为实在需要一个大的操作台面
▲洗衣机上方可以收纳小家电，做了一组吊柜收纳，同时微波炉架子方便收纳
▲角落勉强能容纳烟机的位置，小白砖与蓝色搭配空间倒是明亮清新
▲卫生间很小，为了节省地方，角落定制三角的浴柜，节省更多地方；另一边是蹲便和洗澡位置。没有办法如果是座便器，剩下的洗澡地方太难受，所以索性蹲便空间更大，而且洗澡也宽敞一点；还有一个重要原因是原来卫生间本身就高，为了节省费用，索性地台保留，也能节省一部分费用
▲这里是最好看的角落，定制三角浴柜和镜柜，旁边墙上黑色的五金挂杆，简洁有质感，上方很有颜值的壁灯搭配，其实挺好看
▲其实最开始方案是这样的，可以有两个卧室，这个方案真的不错，满足一家三口的入住，但是花费超多；所以最终根据三口人的入住习惯，加上男业主基本都是上夜班，所以不做改造，这样节省更多费用，也达到入住的条件。END
