# 无障碍淋浴区，到底好不好？9.20

淋浴独立设计的话，必须做分区处理，但是过去的做法都是突出地面的挡水条，可不可以不用挡水条，没有障碍的做法。
▲如图所示，传统的淋浴做法，下方必须预埋挡水条，因为预埋才能让挡水条上方保持水平，不影响上方玻璃隔断的安装，然后淋浴可以独立做下水坡度。这样传统的做法施工简单，而且使用寿命也长，好维修好打理，唯一有一点就是地面有挡水的突出，家里有老人或者小孩的话，有时候会有一定的安全隐患，但是毕竟是自己家长期使用，一般习惯了以后，这种障碍基本可以忽略
▲为了解决传统的挡水条做法，好多人想到了这种高低台处理，如图所示，淋浴区低于其他区域两三公分的做法，然后淋浴隔断分割，这样就可以避免传统挡水条的突兀和安全隐患了。缺点是这样做的必须有高低落差，就会导致除过淋浴区其他地面的人为抬高，间接导致家庭公共区域的地面高度更高，会牺牲整体层高，而且防盗门本身的门槛也会受到影响，甚至有时候满足不了高度，需要重新更换防盗门。▲其次这种下沉式高低落差的做法，在费用上会有所增加，瓷砖损耗加大，人工费相应的也会高出不少，而且看起来走入淋浴区没有障碍，但是走出淋浴区还是有个障碍高台，如果有安全隐患和传统挡水条几乎没有什么区别▲如图就是淋浴高低台的做法，比起通铺，这种做法瓦工需要更细致，更浪费时间，所以工费自然会高▲所以为了解决这种生硬的落差，又出现了这种斜坡的挡水条，落差不会太生硬，解决容易绊倒的问题▲如图所示，其实就是把生硬的落差变缓一点，但是落差还在，与传统的挡水条只有异曲同工之妙，并没有彻底解决障碍问题。▲于是乎，这种隐形的长条地漏就排上了用场，直接提前预埋，满足下水以及地面平整的功能，此时完全实现了无障碍的淋浴房了▲当然还有这种极窄的长条地漏，作为分区以及下水使用，表面看似完美实现了无障碍的淋浴区▲如图还有这种隐形地漏，视觉上比长条地漏更美观，完全实现了无障碍的淋浴房区设计，然而……▲如图所示，这个就是长条地漏的致命缺点，你以为的下水快只是错觉而已，除非你勤快，否则越是面积大的地漏，藏污纳垢的越多，越是恶心，一旦你懒到一定地步，夏季卫生间温度过高，用不了几天这种地漏下方很有可能生蛆，除非你始终需要保证地漏下方的干净和整洁。总结：有些事情可以解决，但绝对不能模仿，脱离生活实际的诗和远方，那始终是诗和远方，生活是实实在在的鸡零狗碎，一地鸡毛而已。以上是各种淋浴无障碍的做法，视情况决定，普通家庭不建议采用后者的长条地漏。
