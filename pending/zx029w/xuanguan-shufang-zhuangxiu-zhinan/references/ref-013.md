# 玄关不是进门障碍，不是每家都能做的

玄关，大家都不陌生。但是具体到每一户都无法真正的理解。好多人认识的玄关就是进门必须有的遮挡。这种理解是错误的。玄关只是一个概念，具体到实际中，可能是鞋柜、屏风、绿植、挂画……

玄关并不是非得是进门直对去做，好多户型压根不允许这样做。而且大部分商品房高层，如果直对做玄关，能毁掉整个格局。所以丢掉过去陈腐的观念吧，玄关其实就是进门的一景，不是一个障碍物。以下用实际装修案例举例，大家看看从中能学到什么。

▲美式装修，有单独的入户门厅，收纳鞋柜都可以随意做。所以直对的墙面放置美式的玄关柜和挂画。这个做法是无可厚非，空间绰绰有余，完全可以把进门直对做成装饰性的玄关。没有什么作用，就是一种装饰。缺它，门厅就失去了家的感觉。

▲旧房改造，虽有单独门厅，但是无法直对做玄关，直对做玄关堵住了整个过道。左手是厨房入口，右手放上简单的椅子，墙面挂钩挂衣服包包。请问玄关是什么？其实就是右手的功能性布置而已。

▲如上图户型，没有门厅，玄关怎么做？当然是不做。保持空间通畅即可，但是好多人认为进门直对客餐厅不好，非得在进门直对设计鞋柜或者遮挡物，活生生把一个敞亮的空间堵死分割，毁了整个户型。

▲有单独门厅，右手墙面设计功能性鞋柜，玄关在哪？其实就是右手的鞋柜，功能兼进门一景而已。并不是进门直对的障碍物

▲此户型是门厅和厨房融为一体，所以利用直对空间做了鞋柜，分割单独门厅和厨房，这直对的鞋柜就是玄关。

▲像这种户型，无门厅，进门是无法做直对玄关的，否则适得其反，整个空间非常堵。所以进门右手的鞋柜和换鞋凳功能，也可以叫做入门玄关。其实不论是具象的家具还是装饰品，只要进门起到缓冲作用，分割区域的作用，你都可以称之为玄关，而非必须直对大门的障碍物。

▲如上图户型，左手是衣帽间镶嵌鞋柜，难道非得进门做个遮挡物吗？当然不是，直对的玄关是不需要的，会毁掉空间的通畅的。左手的鞋柜你也可以叫做玄关，因为是进门一景和功能，完全可以起到进门缓冲的效果

▲像上图户型，虽然有单独门厅，但是无法做直对玄关的，不可能为了不直接看到客厅，横个玄关？所以玄关并不是挡住入户门就叫做玄关，门口的换鞋凳挂衣板位置就是进门玄关

▲单独门厅，左手鞋柜，右手软木背景装饰，此户型直接看到客厅沙发，难道非得把沙发挡住做个玄关？这样不是毁了整个格局了，所以玄关并不是必须做的，而是看格局布置

▲像这种小户型，进门就是客餐厅，如果玄关就是挡住入户门的话，整个格局就全破坏掉了。所以进门右手的斗柜和挂画其实就是玄关空间。玄关并不是非得堵住防盗门才叫做玄关

▲像上图户型，进门无门厅，左手做了玄关鞋柜，刚好成就门厅，同时满足鞋柜收纳，这就叫做进门玄关。但是绝对不是直对入户门才叫玄关
