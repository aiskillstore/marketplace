# 邻居装修侵权怎么办（漏水泡了自家、破坏承重、遮挡采光），维权路径是什么？

**核心法律依据：相邻权。** 《民法典》第288条规定不动产的相邻权利人应当按照有利生产、方便生活、团结互助、公平合理的原则正确处理相邻关系。第293条建造建筑物不得违反国家有关工程建设标准妨碍相邻建筑物的通风、采光和日照。第295条不动产权利人不得违反国家规定弃置有害物质。第296条不动产权利人不得危及相邻不动产的安全。漏水可视为有害物质侵入，砸承重墙直接违反第296条。

**三大侵权情形分别处理。** 漏水泡了自家：拍照录像保留证据，找物业或居委会出具现场证明。第一时间通知邻居停止漏水并协商赔偿。装修公司保修期内可要求装修公司修复，已入住的找楼上业主赔偿。损失包括墙面修复、家具更换、不能居住的临时安置费等。破坏承重墙：这是最严重的侵权。立即固定证据，通知物业发整改通知，要求恢复原状。向城管执法部门或建设局投诉，行政主管部门可责令改正并处罚款。情节严重构成危害公共安全罪的可追究刑事责任。同时可起诉要求恢复原状并赔偿损失。遮挡采光：根据住宅建筑日照标准，如果大寒日日照时数低于国家标准，可主张采光权受侵害，要求侵权方停止侵害或协商赔偿。收集日照受影响前后对比的证据。

**维权四步走。** 第一步固定证据：发现损害第一时间拍照录像，最好拍下损害源，找物业出具现场证明，严重的可委托公证处保全证据。第二步书面沟通：向侵权方发出书面通知留存邮寄凭证或微信记录，明确告知侵权事实要求停止侵害限期修复或赔偿。第三步第三方调解：找物业、居委会、街道人民调解委员会介入，调解笔录或协议具有法律效力。第四步诉讼：起诉到房产所在地法院，诉讼中前期收集的证据链和评估报告就是最有力的武器。

**关键原则。** 先礼后兵理性沟通，专业评估定损失别自己估个数，委托有资质的评估机构出具损失报告。必要时咨询律师少走弯路。既要依法据理力争维护自身权益，也要避免矛盾激化影响日后相处。

**装修自家也别侵权别人。** 装修自家时同样要注意不破坏承重墙，做好防水避免漏水影响邻居，噪音施工避开休息时段，否则别人也可以用同样的方法维权你。
