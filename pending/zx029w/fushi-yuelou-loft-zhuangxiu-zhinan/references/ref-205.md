# 跃层北欧，160m²满足5口之家居住

因为要满足5口之家的基本入住，所以在选择房源的时候，就想好了两层空间，这样可以互不打扰，而且空间设计更灵活一点。

▲一楼设计图纸，一个卧室刚好是父母房，一厨一卫，餐客厅阳台，基本满足我们的所有需要

▲二楼的设计图，三个卧室分别是我们的主卧、女儿房，还有一个单独的书房。而且二楼还有两个卫生间，三代人居住，完全满足所需

▲一楼空间通铺鱼骨地板，极简质感咖色皮质沙发搭配大理石双圆几，保证空间宽敞，同时颜值还得高。沙发背景就是简单的石膏线条勾勒，经济环保还有颜值

▲咖色皮质沙发，搭配黑白配大理石圆几，蓝色的单椅休闲配置与窗帘呼应。非常喜欢这个人头挂画，靠近侧边放置，空间很有艺术感。沙发旁边就是餐厅以及西厨空间

▲喜欢客厅的角落，挂画惊艳，百看不厌

▲来个特写，也不知道这个画的是哪位美女

▲电视墙就是大白墙，什么都没有。灰色的悬空电视柜定制，与白色形成对比质感。旁边突出来的其实是父母房的隐形门，看起来是收纳柜的样子，而且与楼梯另一边木质饰面对称协调

▲餐厅以及西厨空间，西厨颜色与电视柜呼应协调。原木色餐桌极简配置，白色吊灯清爽简洁。厨房全景移门空间通透

▲楼梯下方是很小的储藏间，平时不怎么打开，所以隐形门设计。楼梯下方整体灰色石材地台设计，放一个简易的挂衣架，平时可以兼顾放置进门衣服也是很实用的

▲楼梯下方的夹角简易衣帽间放置，平时进门的衣服可以随手放置。木质玻璃扶手简洁温润

▲白色与木质搭配，玻璃通透扶手，视觉上更干净清爽，而且温馨自然

▲白色与木质整体温馨清爽

▲颜值非常高的西厨柜子，流行的高级灰与木色设计，局部镂空可以放置精致的杯子和饮品

▲西厨刚装上拍的，灯光打开颜值更高

▲一楼的父母房，落地的窗户采光非常好，所以比较深色的搭配，也能稳重一点

▲深灰色背景调色安静稳重，极简的壁灯使用功能。侧墙镶嵌白色衣柜，满足收纳

▲原木的极简温馨，灰色主色调空间安静素雅

▲一楼厨房，原来带的阳台彻底打通，光线更好，同时阳台可以放置平时不用的杂物，收纳容量更大

▲一楼卫生间干湿分离，干区小白砖搭配圆镜，精致又高级。灰色与木质定制浴柜，干净清爽

▲金边圆镜与金色置物架，高级轻奢感

▲一楼湿区统一灰色瓷砖搭配黑色五金以及淋浴房，非常有质感还耐脏，淋浴地面单独的石材拉槽防滑设计

▲二楼楼梯上来的过道，对面抽象挂画充当楼梯端景。过道尽头就是小书房空间

▲二楼我们的主卧，超大的飘窗光线非常好，背景灰色质感硬包处理，整体无主灯，辅助光以及吊线灯照明，极简又有质感

▲床对面是白色的顶天立地的衣柜，白色隐形把手，简洁清爽

▲侧墙移门后面就是衣帽间兼主卫空间，同样白色极简设计

▲女儿房的颜值是最高的，背景是粉色和草绿色乳胶漆几何形状，女儿太喜欢这个背景了。小阳台刚好作为休闲空间

▲侧墙同样颜色的衣柜与背景延伸，几何形状，非常有创意。床对面超大的原木书柜，完全满足孩子的书籍放置

▲粉绿色背景，极简的圆几代替床头柜，非常清爽，非常有颜值

▲平板皮质把手衣柜与墙面融合一体，很有创意和趣味性

▲儿童房阳台暂时一把休闲椅，这里以后是书桌位置，作为学习空间使用，前期插座已经设计好了

▲衣帽间和主卫空间，定制浴柜兼顾化妆台。爵士白瓷砖与深灰色瓷砖对比质感，功能非常强大

▲二楼的书房相对较小，一侧书架收纳，很小的书桌布置满足功能，同样简洁不要主灯，百叶帘通透光线更通透

▲二楼的干区兼顾水吧台区域，木质灰色搭配，经典小白砖，延续风格

▲二楼湿区空间灰色瓷砖，地面采用六边形网红砖铺贴，高柜镶嵌洗衣机和烘干机，满足功能
