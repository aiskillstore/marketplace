# 小户型装修，怎么做能放大空间？10.18

房价越高，户型越小，这是有目共睹的，现在什么户型最吃香？不到一百的小三室销量最好。为什么？总价低，而且还能满足三代人居住，虽然挤点，功能够了。全当是掏了两室的钱买了三室的房子了。但是，这样的房子装修就是难点，如果不规划，还是按照传统做法，不拥挤才怪。

▲首先风格决定，如果是刚需，风格第一步非常重要。千万不要看了两张图片就想做人家的样子。比如欧式、美式、中式风。一是颜色普遍厚重，会让小空间更小，二是类似于此种风格的家具都非常贵。否则强行模仿只能东施效颦。如果你非常中意的话，先去同等户型装修成这种风格的家里看看，顺便问问家具都花了多少钱，然后再做决定。

▲颜色上，不要一味认为深色就是稳重。过去的大红门黑色踢脚线早都淘汰N年了，你如果还在延续老一辈的装修风格，花钱再多都会压抑陈旧的。

▲整体色调一定是浅色为主，暖色协调，彩色点缀。千万不要尝试大面积深色去做，再大的空间都会显小的。

▲空间极小的话能开放尽量开放，否则视觉空间更显局促

▲家具配置上，一定注意轻巧再轻巧，家具就是满足功能就行，大不一定好看，一定占地方。为什么非得把小空间做成了库房。特别是家里有小孩的，连孩子活动空间都没有

▲能用玻璃尽量采用玻璃，让空间整体通透开放，同时视觉上绝对可以放大空间。
