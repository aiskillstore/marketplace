# 80㎡两室二手房改造精致家，厨卫互借空间成就功能

刚需两室户型，小夫妻的首套新家。因为空间太小，所以总会出现理想与现实的冲突，通过设计以及颜色搭配，这套小户型实现了功能和颜值的双重效果。

▲房子原始状态，虽然没有太多破损，但是格局上完全和自己想要的冲突，需要有砸墙改造，索性不如彻底恢复原始毛坯，重新来说

▲纯南两室常见的户型，只不过空间相对很小，建面80平实际套内不到60，在如此紧凑的空间里头，还想要实现小夫妻的各种要求，难度不小；
首先共用客餐厅很小，而且与阳台门联窗分割，显得空间光线也不好。怎么能在实现基本功能的前提下，让空间看起来更开阔，而且还不能损失颜值；
厨卫紧凑，女主对厨房要求很高，想要更多空间收纳以及操作，而且还得让光线敞亮，但现实是连冰箱都没有地方布局；两个卧室没有什么办法，只能尽量在色彩上满足颜值需求

▲设计后的布局图，首先入门很小的空间无法满足鞋柜收纳，为了获得更大的空间感，右手角落采用极简换鞋凳和全身镜的方式，满足两人平时的鞋子放置，达到功能而且让空间更宽敞；同时利用左手拐角与共用客厅背景打造矮柜收纳，用来满足进门换季鞋子以及杂物收纳；
转换思路是装修里头非常有价值的做法，例如调换传统意义的沙发与电视的位置，会出现出其不意的效果，同时可以满足收纳以及空间的完整；砸掉原有阳台的门联窗以及墙体，让阳台引光入室，放大空间和光线
为了成就厨房的最大化，采用砸掉墙体的办法，做了开放式布局，这样不仅让光线明亮，空间开阔，同时提升了收纳以及操作空间；砸掉厨房对面卫生间墙体，利用空间实现冰箱的最近距离放置，同时利用橱柜的定制满足了干区的布局，互借空间互相成就，设计非常惊艳
两个卧室一间作为主卧使用，满足基本功能，另一间因为空间太小，打造榻榻米满足空间和收纳
▲入户右手有个拐角很小的地方，本来想要定制收纳鞋柜，但是又担心门口显得拥挤压抑，考虑到就是放鞋而已，索性成品的换鞋凳，带镂空两层置物架，刚好能满足基本的进门收纳；上方还可以布置颜值全身镜，搭配简单挂钩，满足衣服包包的随手悬挂，最重要的是功能达到了，进门不会压抑，颜值也有了
▲入户左手利用拐角位置，打造顶天立地鞋柜，这里才是真正的收纳地方，因为内部空间较大，利用旋转鞋架，让收纳翻倍
▲门口视角看全景，客餐厅共用空间，打通阳台不不做窗帘累赘，尽可能轻巧的家具搭配；不要任何造型，挂机以及无主灯搭配，让空间每一个角落能能感受到宽敞明亮
▲转换思路，改变传统的沙发电视布局，把最长的墙让给餐厅以及电视墙，这样拉伸定制收纳柜，同时满足餐边柜以及电视柜的需求，让空间互相分离又能连接一体；蓝色的变色与白色悬空柜搭配，拉伸空间又提升了层次感
▲共用空间，蓝色变色提升视觉层次，矮柜延伸定制，而且采用悬空设计，餐桌刚好满足布局，滑轨灯延伸补光，满足收纳，同时拉伸空间，又能提升颜值
▲入户左手通顶鞋柜与矮柜的无限延伸，白色平板搭配皮质的把手，干净又有档次
▲入户以及餐厅空间，干净素雅，轻巧实用的颜值
▲不仅砸掉朝向过道的厨房墙体，沙发墙也做了缩短处理，这样就可以腾出L型橱柜的定制空间
▲通向卧室的过道，原始户型厨房是封闭空间，导致过道窄而且昏暗；砸掉厨房做了开放式以后，让光线豁然开朗，同时满足L型橱柜的定制，增加了收纳，提升操作空间；对面牺牲卫生间空间镶嵌冰箱，最短距离实现功能性
▲开放厨房全景，经典小白砖搭配白色平板定制橱柜，视觉上更明亮，局部黑色的对比，让空间更富有层次；利用拐角橱柜延伸一个洗手池朝向过道，吊镜布局，这里满足了卫生间干湿分离的功能
▲站卫生间可以看到厨房全景，L型地柜朝向过道，这里其实就是卫生间干区，下方专门预留镂空，可以随手放置牙刷牙杯，不至于台面太凌乱
▲主卧延续客厅的经典蓝白对比，白色的衣柜定制，橘色床品点缀提升空间亮度
▲衣柜定制利用折叠门，让开启空间更大，使用更方便
▲床头柜专门选择轻巧的可移动款式，不会影响衣柜门的开合
▲客厅生活阳台采用户外专用地板铺设，有自然气息，定制了小的洗衣池，洗烘机叠放以后，上方吊柜满足杂物收纳，洞洞板搁架还可以摆放一些绿植，提升颜值
▲牺牲卫生间局部空间实现冰箱的镶嵌以后，卫生间采用了非常有质感的黑色谷仓门布局，与整体颜色颜值呼应
▲干湿分离以后，卫生间内部空间宽大很多，刚好布局淋浴隔断做了分区，墙排马桶干净整洁；利用上方空间打造收纳柜，灯条的点缀，让卫生间也成就了温馨舒适
