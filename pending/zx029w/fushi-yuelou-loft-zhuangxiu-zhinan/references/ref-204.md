# 160㎡复式婚房，小两口的完美居

顶层复式可能在普通认知中，认为非常麻烦，而且大部分信息中漏水风险让太多人望而却步。但毕竟是少部分，今天的顶层复式是新人婚房，因为只有两人入住，要求和功能基本都能实现。
▲一楼原始结构，入门直对楼梯，这一点业主接受不了，而且一楼公共区域的格局也被破坏了；所以首先需要移动楼梯位置，让一楼格局更规整；而且两人都有养宠物，所以一楼空间需要满足洗衣生活，同时还得满足宠物的居所；厨房进门狭小而且不规则，一楼三间卧室，又小又感觉逼仄，导致空间不通畅▲二楼原始格局，因为客厅区域属于挑空，所以为楼梯的位置改变满足了条件，而且二楼空间可以实现一间大卧室，而且有露台空间，可以满足休闲布局▲一楼重新布局以后，改变了楼梯位置，放大空间，实现了横厅的布局，而且利用楼梯下方满足收纳以及宠物窝，楼梯直对阳台刚好满足生活刚需；改变厨房门洞以后，利用厨房空间实现门口鞋柜收纳，朝向客厅厨房新开窗户，砸掉小卧室实现独立餐厅，满足了空间的南北通透；一楼规划了两间卧室，客卫做了干湿分离▲二楼空间搭建以后，实现了一间大卧室布局，同时满足衣帽间需求；而且露台空间做了休闲阳光房设计▲一楼改变厨房门洞位置，新开窗户满足南北采光和通透，同时利用厨房空间实现门口镶嵌鞋柜的定制，满足刚需收纳▲改变楼梯位置，让公共区域格局更方正，拆除小卧室实现独立餐厅，空间更开阔，而且实现了横厅的布局，整体更通畅更明亮▲拆除小卧室，实现独立餐厅，改变厨房门洞，实现餐厨动线合理，而且实现了户型的南北通透▲沙发居中布局，刚好与后面楼梯实现了横厅设计，中间无法砸掉的承重墙采用定制隐藏，延伸一个镂空的书架以及展示柜作用；利用楼梯下方满足收纳的同时实现了家里宠物的窝▲蓝色的布艺沙发撞色搭配，提亮视觉感受▲大面积木色搭配大白墙，简洁温馨；蓝色沙发与餐椅呼应协调，朴素又温馨▲无法拆除的承重墙利用定制，木色装饰，延伸出来一个书架收纳，也可以作为展示作用▲楼梯下方刚好作为宠物的乐园，利用收纳存放一些宠物用品▲横厅布局，刚好利用沙发后面书桌布局，满足一个开放书房办公空间▲书房后面楼梯，石材踏步搭配玻璃扶手，楼梯阳台玻璃移门分割，满足基本的生活晾衣需求▲餐厅隔壁的房间砸掉墙体，玻璃移门设计，这里作为多功能房备用，一面墙的玻璃柜是业主展示品的收藏区▲一楼厨房通透玻璃移门以及窗户，放大空间视觉更加通透▲改变厨房门，砸掉小卧室，实现餐厨最合理动线，也实现了格局的南北通透▲厨房统一木色定制，U型布局，满足基本需求和收纳▲餐厅利用窗户下方实现了西厨定制，弥补厨房收纳的布局，兼顾平时的水吧台功能柜▲一楼客卫门口实现了干湿分离布局，刚好多功能房玻璃移门设计，满足过道采光通透▲楼上卧室，本身是斜顶格局，所以空间更显开阔▲楼梯上来独立木门封闭，利用楼梯休息平台实现一个衣帽间收纳▲楼上最大的书房空间，定制柜根据斜顶造型设计，书桌刚好在天窗下方▲楼上卫生间以斜顶设计，配置浴缸，粉色瓷砖点缀▲楼上露台搭建了阳光房，纳入室内，作为平时的休闲空间
