# 好的价格+好的设计，25平也能打造豪宅LOFT

25平的房子，层高3.4米，一个人住，咋装修？碰到一般人恐怕真的头疼，这么小怎么做？而且层高又很高，怎么装都感觉廉价。但是碰到单身贵族可不这么想。虽然一个人，也得装的超前，而且必须方便舒服。下来就来看看单身豪宅LOFT的故事。

▲一楼空间，除过一个固定卫生间的位置，其他自己分割。进门利用储物柜分割空间，后面是一个客厅兼工作室的区域。厨房开放式在门厅的另一端。一楼很轻松分割出门厅、厨房、客厅兼工作室、卫生间，四大区域。

▲二楼空间轻松设计一个卧室，虽小但是功能齐全

▲从厨房角度看进门门厅，过道以及厨房地面灰色的哑光瓷砖通铺。入户进来直对的超级收纳柜，分割区域，腾出后面的客厅兼顾工作室。这一端就是一个狭小的开放式厨房

▲入户进来过道看后面的客厅，内部木地板通铺能温暖一点。收纳柜分割区域，上二楼的楼梯把空间一分为二

▲厨房全景，虽小也是双一字型布局，同时洗衣机镶嵌

▲因为小又是窄条，所以利用白色面包砖半截墙铺贴，上方局部水泥墙对比，有时尚的工业风感觉，同时空间有比较清新

▲空间狭小，无法用传统吊柜收纳，所以简单隔板布置，增加收纳的同时，保证空间的宽敞

▲为了增加收纳，3.4米挑空厨房，在紧挨吊顶做了吊柜储物，平时就放些不常用的杂物，因为太高的缘故，所以全当是增加储物了

▲空间虽小，懂得取舍，完全可以杂而不乱，一人住同样品味十足

▲进门收纳柜后面的客厅兼工作室区域，定制的实木沙发床以及矮柜收纳，楼梯跟前就是小的卫生间，同样采用收纳柜的形式进行处理，增加储物能力。白色与木色的协调搭配能让空间温暖又保持明亮

▲站楼上卧室看全景，非常小的空间，但是规划合理，平时就是休闲看书或者作为工作区使用，一个人已经足够了

▲来看看小空间超强收纳是怎么做到的，卫生间墙体也是利用收纳柜分割。沙发床代替沙发，对面还有一个可以折叠的书桌，可以作为书桌使用。就连上楼梯的第一个踏步下方也做了可以拉开的收纳空间

▲站卫生间看客厅区域，平时一人看书或者躺下来休息，都是可以的

▲沙发床对面是一个超薄的收纳柜，侧板可以直接拉起来充当书桌使用的，小空间需要很强的设计支撑

▲折叠的超薄收纳柜，分开两块板子操作，这样可以随意那一块都可以，可以随时改变书桌的大小，不用的时候放下，一点都不占地方

▲空间虽小，但是兼顾客厅、书房工作室的职能，这就是一人一家的好处

▲卫生间有单独窗户，光线没有问题，与厨房相比，卫生间还要大一些，所以一定要有舒服的浴缸泡澡

▲灰地白墙，同样需要干净清爽。长虹玻璃移门是入户门。后面的镜面柜门是门后的收纳壁龛门，而且拉开以后可以充当全身镜，功能确实不错

▲白色清爽瓷砖加上超大的百叶帘窗户，光线非常好

▲楼梯拾级而上就是小小的楼上主卧了，楼梯整体就是木质结构的储物，这也是小户型必须利用的收纳点

▲因为只有一人住，所以楼梯非常小，只要满足功能即可，铁艺的单面扶手白色清新简单

▲木质与白色搭配，小空间温暖又能保持清新

▲楼上很小的主卧，床尾设计了小的收纳以及隔板书桌，晚上看书或者放置物品都是可以的

▲空间小做卧室是足够了，床头还做了隐形储物柜，侧面做了半高护栏保证安全

▲卧室看下方的客厅，光线如此明亮，确实美好。
