# 新家9个必不可少的家电，必须装修前规划2.11

新家装修有些电器是必不可少的，固定件，而且必须配合装修，否则后期无法使用，有些是个性小家电，甚至有的家庭大小家电上百件都有。今天看一下一些新家必不可少，必须与装修相配套的家电。
第一、电视机/激光电视/投影仪
很普遍，家家必备的家电，但是安装样式各异，此时必须在装修前规划线路的隐藏以及电视尺寸的大小。

▲如图所示挂墙电视，悬空的电视柜，必须规划位置，保证线路刚好隐藏在电视柜，否则前期不考虑，后期线路杂乱不堪

▲全镶嵌收纳式隐藏电视，此时必须提前规划电视大小，根据电视大小来安排线路位置以及定制的样式。

▲全镶嵌造型隐藏电视，必须提前设计电视尺寸以及造型的整体比例，一步错了，整体就毁掉了

▲不要电视柜，需要提前根据电视大小以及线路情况，在电视后面隐藏
▲电视伸缩架的选择，需要提前规划，后期保证各个方位看电视以及电视后面空间的合理利用▲支架放电视，需要提前规划地方以及线路的规划隐藏▲好多年轻人喜欢激光电视，同样需要提前根据尺寸以及线路进行规划，同时还得隐藏信号盒的位置，这样才能保证后期装修完毕空间的美观和整洁▲如上图提前规划设计，把信号盒子采用抽拉设计，平时可以隐藏起来，让空间更美观整洁▲当然你也可以把激光电视的信号盒子放到电视柜上，就是后期电视柜上头比较乱而已▲除过激光电视，还有年轻人钟爱的投影幕布，同样需要在装修之前规划距离尺寸以及电源位置，同时保证合理隐藏▲前期不规划，后期不仅没有电源，而且投影幕布还得明装，视觉上不好看▲收纳柜前方做投影幕布，不仅要计算位置尺寸，同时满足收纳柜以及吊顶的宽度协调▲有的是电视和投影共存，此时必须提前规划位置以及尺寸大小，电源的合理规划隐藏第二、洗烘机/晾衣架推荐洗烘机分体单独配置，省去了晾衣服的麻烦，空间更整洁，更能提高生活品质。▲洗烘机单独分体布局，几乎是家里的标配，不需要平时晾衣服空间显得更乱。▲空间够的话并排布局更好，提前规划电源以及上下水的位置，同时上方可以侧装晾衣架，平时小件衣服可以晾晒，阳台也不会显得凌乱▲不论是洗烘机都有，还是只有洗衣机，晾衣架推荐这种隐藏设计，平时不晾衣服的时候阳台更整洁，这些都需要装修之前规划考虑成熟。▲洗烘机的位置不止于阳台，家里任何地方只要满足上下水电源的位置都可以放置，必须装修前规划《5个常用家电，上下水电源提前预留》第三、冰箱大小根据家里空间和生活习惯需求决定，必须装修前提前规划好位置▲厨房放冰箱，不论大小，一定选择下散热严丝合缝的产品《冰箱功能大同小异，散热方式和预留空隙却天地之差》，需要提前规划电源以及全屋定制的细节设计▲冰箱也不是必须放厨房，只要使用方便，根据空间都可以放置，但是想要做到使用方便，同时弱化冰箱的存在感，并不容易，必须装修之初规划好位置，并不是后期随便买放上那么简单第四、蒸烤箱普通家庭其实只要配备蒸烤箱一体即可，基本家里需要蒸烤的烹饪都可以实现▲厨房没有高柜，地柜有空间都可以镶嵌，需要装修之前规划位置以及电源位置▲厨房空间够大，当然高柜镶嵌冰箱以及蒸烤箱的方式是首选，普通家庭蒸烤箱一体即可，不需要独立分体的，不仅不常用而且还占地方▲蒸烤箱第二首选地肯定是餐边柜了，可以和冰箱同时镶嵌设计，必须在装修之处就得规划电器位置和大小尺寸第五、内嵌洗碗机。这个几乎是年轻人装修的标配，房子是为了提高生活品质，何不让自己更轻松？▲洗碗机肯定是最小13套的镶嵌洗碗机最实用了，千万不要用水槽洗碗机，除非家里最多就两人使用▲洗碗机不光是可以放到厨房，如果空间不够，西厨有水槽下水也可以满足洗碗机的布局，必须保证上下水电源的位置，同时装修前规划空间，与装修紧密衔接，并不是单独购买那么简单《镶嵌洗碗机，水电路一定要做对》▲注意上图的就是水槽洗碗机，不仅水槽缩小了，同时洗碗机也非常鸡肋，家里最多两人入住可以用，否则坚决不要这种电器第六、燃气热水器/壁挂炉燃气热水器相比较与电热水器更方便实惠，同时也更安全。当然北方有的不是集中供暖需要自己烧暖气，需要的就是燃气壁挂炉。▲如图所示燃气热水器是必备的家电，但是位置至关重要，合理的位置可以影响厨房整体的布局▲如图想要更美观隐藏的话，需要提前规划尺寸以及全屋定制的设计▲想要彻底隐藏也是可以的，这一切必须装修之初规划设计，否则水电改造第一步就得错误百出第七、净水器家家必备，水槽下方隐藏即可。推荐有加热功能的净水器。▲如图所示，一般厨房单槽下方放置净水器，上头小龙头就是净水龙头，这里一定注意，推荐使用可以加热的净水器，这样平时就没有必要使用管线机和暖水壶了，随时可以喝上热水▲净水器的位置肯定在水槽下方，需要规划上下水以及电源位置。推荐使用有加热功能的净水器，完全兼顾了管线机的加热功能，否则厨房没有地方放管线机，好多人放到餐边柜，导致PE管预埋加长，不仅不健康，时间久了管路无法更换。第八、扫地机器人这个是现代家居装修必备的电器，当然不是过去的半自动的，全自动吸扫拖一体机才是标配。▲你以为上图的做法就是合格了？当然不是，能有这种做法基本是装修没有规划。如果是先装修好才有这个产品还情有可原，如果是装修的时候明明就有这个产品，但是自己不规划，装修完了随便放置，这个就是装修价值高低的不同了▲全自动云鲸首选阳台位置，刚好借用上下水电源的规划，隐藏起来，这才是装修要考虑的价值▲除过阳台，干区也是首选之地，因为要有上下水，所以必须提前规划和根据房间原始的下水位置决定▲实在没有地方，只要和厨卫下水隔壁的空间都可以实现，但是必须装修前规划好，也就是电器和装修是紧密衔接的，脱离要不位置不对，要不压根实现不了第九、空调/新风空调家家必备，北方只是夏季使用，有地暖，对于南方没有地暖的话，空调还得用来制热，所以也是非常重要的电器。▲北方地区，刚需空间又不大，如果为了省钱和省空间，当然挂机都可以搞定▲北方地区，柜机还是不推荐购买，这个价钱可以搞风管机了，而且不占地更美观了▲有钱直接中央空调了，这个完全就是空间和金钱说了算的电器。《风管机、挂机、柜机，客厅用哪个好？》至于新风系统刚需房子就不用考虑了，开窗通风来得更实在，除非是为了隔音没有办法搞一个壁挂新风满足基本功能才用《房子隔音不好，更换窗户就万事大吉了？》总结：以上九个是目前新家装修必不可少的家电，而且任何一个都和装修息息相关，想要完美和成就装修价值，就必须让专业人士来规划。当然除过这些家电，家里家电很多，例如空气净化器，消毒柜、各种厨房家电电饭煲之类，还有智能家居一类的，就太多了，这些不是必要的，大部分普通家庭可有可无的。只有上头九个家电规划好，到位了，剩下的家电后期购买基本都可以满足使用。
