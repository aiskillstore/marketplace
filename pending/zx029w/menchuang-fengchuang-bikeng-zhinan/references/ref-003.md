# 断桥铝门窗怎么选，怎么避免花了大价钱还是漏风、漏水、隔音差？

**断桥铝门窗，型材宽度越宽越好。** 型材宽度越宽越好，国标壁厚最低1.4mm。外窗宜选断桥铝，内窗可选塑钢。看小区同户型已装的，考察同户型实例避免选购失误。

**玻璃按噪音分贝选。** 依噪音环境选夹胶中空或双层中空。夹层玻璃两层玻璃中间加一层隔音膜，效果要好于开发商的中空玻璃；真空玻璃两层玻璃中间接近真空。临街房选夹层或真空玻璃的专业隔音窗。注意钢化玻璃的3C认证与防爆膜、LOW-E玻璃特性。

**五金单独收费要问清。** 五金是门窗的灵魂，是否单独收费、什么品牌、是否包含在总价里都要问清楚。开启方式受物业限制，推荐内开内倒等安全形式。高楼层选2.0mm加厚型材。

**开发商窗户的问题。** 一般开发商的窗户玻璃是中空玻璃，两层玻璃中间是空气，有一定的隔音效果，但是对于在路边的小区，基本不起什么作用。开发商的窗户大部分就是塑钢或者断桥铝，最好的也就是两层中空玻璃。如果是平开窗户还能好一点，推拉方式那隔音效果更差。

**换窗要配新风。** 更换了更好的、更隔音的窗户玻璃，难道入住你不开窗户？如果要开窗户通风，请问更换窗户的意义在哪？那和不更换一个效果，这就是冲动消费。当你家不幸在噪音区，需要更换更好的窗户，这个是基础改造，更重要的是这种窗户关上才能起到效果，如何能关闭窗户隔绝噪音的同时保证呼吸顺畅呢？只有一条路可走：安装新风。一般卧室需要处理噪音，采用成本最低的壁挂新风满足换气功能，壁挂新风要选双向流且带热交换功能的。

**选购注意。** 关注型材正品授权、明确面积与配件计价，优先考察同户型实例，并根据实际需求与环境条件匹配材料与配置。隔音膜贴窗户没有任何作用，噱头而已。专业隔音窗造价不菲，一平方可能在七八百甚至上千元。

**记住。** 断桥铝选型材宽度越宽越好，壁厚国标1.4mm，玻璃按噪音分贝选夹胶中空或双层中空，五金单独收费问清品牌，换窗必须配新风。看同户型已装的实例，比听导购吹靠谱。
