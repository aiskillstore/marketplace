# 飘窗窗帘别乱装！10种安装形式利弊实测，第4种最实用！

后台经常有业主问：飘窗窗帘该怎么装不出错？好多装修业主飘窗窗帘安装错误，后期导致漏光，功能都没法实现；有的是颜色搭配尺寸比例错误，降低了整体装修价值。今天就把飘窗窗帘最常见的10种安装形式，一一拆解，优缺点一次性说明白，大家装修前看看，根据自身实际情况对号入座，选择最适合自己家的做法。01｜布帘纱帘靠窗安装。
做法：U型玻璃｜明装轨道，折弯处理。
优点：节省空间，相对节省了费用，随时闭合窗帘，不会牺牲飘窗台面空间，更适合小户型空间或者飘窗超级大空间。
缺点：没有窗帘盒，轨道厚重突兀；两侧为了避免漏光的轨道折弯处理厚重，视觉累赘。空间大，窗户小的时候显得小气。
避坑提醒：尽量选择超薄轨道弱化突兀；能实现嵌入式轨道更好。
避坑提醒：尽采用帘头遮挡轨道或者避免漏光，尽量采用极简款式，造型款式会加重窗帘的厚重感。
避坑提醒：极简帘头更好看，适合明装轨道以及窗帘盒浅的情况。
L型飘窗：靠窗挂帘是最佳方式，否则满墙做窗帘盒和窗帘无法靠墙停止，视觉更突兀。
避坑提醒：窗帘盒能实现尽量实现，根据窗户大小比例选择平吊以及单独窗帘盒。单独窗帘盒深度不会影响整体窗户的比例。
避坑提醒：上图一字型平吊实现窗帘盒，适合满足深度窗户高的做法，否则窗帘盒太浅，最容易漏光。
缺点：很明显上图左右没有墙体以及留槽，后期最容易漏光。需要采用磁吸扣或者魔力扣弥补。
飘窗非常大的卧室，更适合靠窗安装。也顺道解决了有定制占用飘窗无法满墙安装的问题。而且上图嵌入式蛇形轨道弱化轨道厚重感，更美观。
纱帘+木百叶都靠窗安装，氛围有了，睡眠空间光线敏感谨慎，完全不遮光。
陈工提醒：满足4种情况（1.飘窗很大；2.转角飘窗；3.有定制冲突；4.床靠飘窗）双层帘可以靠窗安装，其他情况慎选！
02｜布帘纱帘满墙外装。
做法：布帘纱帘统一外装，加窗帘盒防止漏光优点：视觉空间大气，更有氛围感，两层帘叠加，弥补布帘遮光不足；休闲就坐空间不受纱帘干扰。
缺点：相对于纱帘内装面积大了，增加费用；白天拉上纱帘台面利用不便；
避坑提醒：双层外装窗帘盒宽度至少20cm宽，具体施工之前必须根据窗帘商家的要求去做，避免返工。

03｜布帘纱帘满墙外装+靠窗帘。
与『布帘纱帘满墙外装』仅仅多了一个靠窗的纱帘，优点是内窗纱帘拉上不会牺牲台面的利用，但是预算增加了，得不偿失，刚需房完全不推荐！
类似的还有靠窗换成百叶的形式，如果纯粹为了氛围感可行，但是上图远远没有达到效果，增加预算多花冤枉钱而已。
如图的做法虽然多花了预算，木质的百叶确实增加了氛围感，适合自己的需求还值得多花钱。
如图同样类似的做法，只不过飘窗作为茶室兼阅读角，想要更好的氛围。而且外开窗满足了极简罗马帘的安装，遮阳和氛围都有了。对于刚需来说，外装纱帘就有点多余了。
陈工提醒：刚需房不推荐，如果为了营造氛围，就去掉外装纱帘，费钱不说，空间小视觉更会累赘。
04｜布帘落地外装+靠窗纱帘（卧室推荐做法）
做法：布帘外装，纱帘直接靠窗安装，最常见的做法，也是最推荐的做法。优点：布帘满足了大气效果以及晚上的隐私和安全；纱帘满足白天的以及晚上开灯的隐私，也兼顾了氛围；纱帘靠窗也便于台面的利用。
缺点：相对于都靠窗安装，增加费用；
避坑提醒：纱帘注意预留飘窗垫高度，内开窗注意上方是否满足轨道高度安装。
刚需布帘可以不要窗帘盒，明装轨道首选，尽量超薄。
内罗马帘，外装纱帘，睡眠空间谨慎，透光太严重。
05｜只装布帘（内装/外装）。
做法：只布帘靠窗安装，窗帘盒/明装轨道/内嵌轨道，看现场实际决定。优点：省钱！布料面积很小。随时都便于台面利用，放大空间。
缺点：只能满足晚上睡觉的隐私，伴随局部漏光的风险；白天想要隐私就得开灯，否则空间昏暗。
避坑提醒：高层外头没有其他临楼可行，一楼隐私重点最不推荐，否则白天遮挡室内昏暗压抑。看似省钱，但最不推荐。
不论是内装还是外装，只要一层布帘，需要看外头隐私，不能只图省钱。
06｜只装纱帘/百叶（内装/外装）。
做法：只装百叶帘，内开窗竖百叶不影响窗户开启，外开或者推拉可以用横百叶。优点：省钱！视觉放大空间，采光和空间都通透。
缺点：对光线敏感的人来说，无法满足遮光需求，为了美最终还得眼罩解决。
避坑提醒：卧室睡眠空间对光线敏感的谨慎！书房以及衣帽间可以随意。
非卧室睡眠空间，只内装木质百叶，营造氛围，实现光影效果，是可行的做法，空间更通透简洁放大空间。
飘窗靠窗日夜蜂巢帘，还是会漏光，光线敏感者慎用。
客厅飘窗肯定不能装布帘，视觉累赘，完全不需要百分百遮光，所以各种百叶才是首选，其次罗马帘，最后纱帘。既保证隐私，同时营造氛围感，还得满足时刻光线通透。
书房空间同样不能用布帘，也不推荐纱帘，空间小形状臃肿，视觉显得累赘。轻巧通透百叶罗马帘更适合。
只用了日夜蜂巢帘，上方有窗帘盒，左右有防止漏光的留槽，完全可以，隐私也没有问题，颜值高，视觉轻巧简洁。一定要满足条件才能保证隐私和遮光。
只外装一层纱帘，看似氛围有了，但睡眠空间光线敏感慎用，透光严重。
07｜窗帘两层都在飘窗（内沿+外沿）。
都装飘窗上，内竖百叶，外罗马卷帘，卧室空间谨慎，无法遮光，透光严重。
外沿纱帘，靠窗百叶，氛围有了，卧室空间慎用，严重透光。
内开窗飘窗顶部没有空间，可以选择外沿安装各种卷帘，条件限制无奈之举。
靠窗竖百叶内开窗不影响开启，外沿布艺罗马帘满足隐私。
楼梯转角飘窗完全休闲，纱帘靠窗营造氛围，外延布帘重点为装饰功能。
靠窗纱帘氛围，外沿蜂巢帘遮光，两侧缝隙多少都会漏光，需要考虑清楚。
08｜纱帘+百叶靠窗安装
做法：纱帘和百叶都靠窗安装，需要注意窗户外开推拉才能满足横百叶，内开只能采用分段横百叶或者竖百叶。『谁说内开窗没法装百叶帘？操作非常简单』
优点：视觉极简，超级有氛围感
缺点：没有遮光效果，透光厉害，睡眠卧室空间慎选。
避坑提醒：氛围感至少满足窗帘盒隐藏，反之显得凌乱和廉价。光线敏感者慎选。
正确做法：想要氛围和遮光的卧室空间，应该三道帘同时布局，白天不用布帘，可以满足氛围，晚上布帘满足隐私和遮光，折中做法平衡氛围与遮光的矛盾。
09｜纱帘满墙+百叶靠窗
靠窗木质百叶+满墙纱帘，确实很有氛围感，但是透光厉害，不适合卧室对光线敏感的家庭。
罗马帘+纱帘一样可以营造氛围感，缺点透光厉害。
正确做法：纱帘与布帘同时满墙，氛围和功能兼顾。
