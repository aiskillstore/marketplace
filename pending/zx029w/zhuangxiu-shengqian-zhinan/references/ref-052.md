# 厨卫装修，怎么能省钱？12.23

金厨银卫，想要绝对的省钱不太有可能，是不可能！除非你的房子是出租，那钱是绝对能省，自己住，只是在互相比较中，能做到更实惠，更物有所值，这就是最大的省钱了。

一、厨房基础格局，这个要省钱的话是不会完美的。例如厨房可以做到更好，但是为了省钱不去做，这个省钱的意义不大。

▲如图所示，改变厨房格局以后，不仅让采光更通透，同时空间更敞亮，而且改变了厨卫对门的尴尬，成就了干区空间。如果不做改动是省钱了，但是同时也省掉了格局的完美和入住品质的提升

所以厨房装修布局想要省钱是没有可能的，同时省去的还有空间的完美和格局的实用。

▲如图所示，卫生间也是一样的，别人家做了干湿分离，你家不做，省钱了，也省掉了全家人的健康。所以卫生间格局的改动并不能省钱。

二，厨卫基础施工。这里的基础施工包括防水、水电改造、包管道、贴瓷砖、吊顶。

1.防水，这里完全可以省钱的，因为大部分新房交付厨房是没有地漏的，所以是可以不做防水的，但是大部分人不懂，还是认为厨卫防水必做，多此一举给厨房做了防水，其实不仅费钱而且适得其反《没有地漏的厨房做防水，就等着破产吧！》

卫生间防水那是重中之重，是一点都不能节省的。这个毋庸置疑。

▲如图所示是两个不同的做法，左图明显是不懂行的省钱做法，就会导致后期墙体发霉，因为防水的根本是防潮气，并不是说是只防止地面漏水，但是大部分人不懂，装修公司为了低价签单，只能这样做，虽然地面不漏了，但是潮气压根没有解决；再看右图直接全部做到吊顶位置，面积大了，但是不仅防止了漏水，而且还保证了潮气问题。所以防水你要省钱完全是自己坑自己。

2.水电改造。厨房的水电改造是一点都不能省的，如果在这里纠结节省费用，那你后期的电器以及使用必然会出问题。必备的烟机电源、水槽下方净水器水电、如果有洗碗机还有洗碗机的水电、镶嵌洗衣机有洗衣机水电，冰箱电源、剩下的就是多余台面上的电器电源，能多做就多做，后面的电器多少只会增加不会减少。
厨房最重要的还有灯具位置，品质生活需要至少三个地方有灯具，第一是主灯，第二是吊柜下方手扫灯，第三水槽上方吊灯。
厨房凉霸需要不？不要，这就是个简易风扇而已，有条件还是装一个挂机，预留电源和孔位《夏天厨房做饭太热，空调+凉霸+开放式》
卫生间水电同样是不能节省的，浴柜下方的厨宝电源、上方的吹风机各种电源，至少上下各需要预留一个五孔；马桶跟前一定一定留个电源，后期想要更换智能马桶盖的话非常方便。
3.包管道。这里指的是水管和烟道。水管必须用红砖包了以后铺砖，烟道必须用红砖包了以后铺砖，你要省钱，烟道不包的后果就是后期，瓷砖裂缝，甚至跑烟脱落，得不偿失。卫生间管道同样是要包的，但是你省钱你家仅仅就是包个管道而已。
▲如图所示，同样是包管道，你家就是包个管道，人家做了壁龛，你家省钱了同时也省去了收纳和方便；同样马桶，你家是普通的，人家是墙排移位，让格局更好，同时打理更方便，还成就了上方壁龛，省钱到底省掉了什么，一目了然。
4.贴瓷砖。不论厨卫铺瓷砖是压根不可能有省钱的做法，除非你找手艺不好的工人，费用低了，品质质量降低了；唯一能省钱的就是主材。例如瓷砖，厨卫可以有别，可以卫生间采用全瓷砖，厨房采用半瓷砖，价位相对能低一点，因为厨房只有油烟，而且大部分被橱柜挡着了，半瓷完全可以达到目的。
5.吊顶。厨卫吊顶最基础的常用的就是铝扣板而已。但是这里有个省钱的办法，就是不要连铝扣板都做品牌，这个又烧钱质量又差。完全可以采用本地制造的铝扣板，厚度质量都没有问题，而且价位要低很多。否则品牌的吊顶，薄如纸价位还死贵，完全没有必要，图个虚名全成了智商税了。
6.瓷缝。这个是可以选择省钱的，也就是家里哪地方都可以不做，但是卫生间瓷缝必须做，这个看个人需求，如果真的没有钱，先做卫生间，其他地方瓷砖按照美缝留缝，但是做普通勾缝，以后有钱了可以把露在外面的重新做美缝也是可以的。
7.成品定制。厨房的橱柜，这里当然可以省钱，但是大部分人不懂，还是看品牌定制，这个东西不是手机，哪来的什么品牌，就是定制而已，重要的是设计和定制，而非广告里头的品牌《全屋定制问品牌，你问的是什么？》，所以你如果只图品牌还得省钱，这个是不可能的。
浴柜定制也是一样的道理，当然是和家里定制一家去做，而不是每个空间找一个定制商，不仅难以协调，而且价位都得高很多了。
综上所述，冲着省钱进来的就会失望了，这个也没有什么可以省钱的，完全是费钱的做法。是的，装修的省钱都是相对的，并不是真的省钱，而是同样价格可以做到物有所值本身就是省钱。例如有人找品牌花了几万，你自己定制几千搞定，而且设计和功能比品牌要实用多了，这才是省钱的做法。而不是前期只看低价，让低价钓鱼害惨，后期不断加钱，这个就是自欺欺人而已。
