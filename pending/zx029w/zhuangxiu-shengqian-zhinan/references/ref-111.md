# 剖析装修预算，详解公共区域3.25

今天来个超级详解装修预算，让业主根据实际预算，看看一般预算都包含什么，里头每一步都会隐藏哪种陷阱，知己知彼，才能让装修更顺利，节省费用还能达到目的。

一般家装预算最简单也是最合理的一定是详单式预算。这种预算每一个区域，每一个项目都单独分开计算，非常傻瓜式的预算，对于不懂装修的业主来说，这种预算才是能让业主短时间看懂。

能让业主短时间看懂的预算，出发点才是好的，否则专门故弄玄虚，预算故意设计非常复杂，这种装修机构出发点就不善，目的就是让你看不懂，才能瞒天过海。

第一部分：公共区域预算

▲如图，这是一般家庭公共区域的基础预算，也就是大家所说的半包预算。

第一项：墙固，这是必须有的，和过去的界面剂、108胶的作用是一样的，为了腻子更好的附着。这个项目家家户户必须有。
第二项：地固，这个完全就是智商税了。封闭尘土，固化地面松散颗粒，有一定的防潮作用。
如果你家地面铺瓷砖已经用大量水泥砂浆了，防什么尘？固什么沙？同时水泥砂浆本身就有水分，防哪门子潮湿？所以这个几乎是大部分装修公司用来表演的材料。一平方动辄3-5元，一家一两桶一个人一个小时搞定，这就是纯利润而已。
▲如图，你们肯定非常熟悉，然而没有一个人告诉你，开工刷这些是错误的。如果开工这样干，水电进场墙面开槽不破坏吗？拆除不破坏吗？如果破坏了刷这个又有什么用呢？
所以开工刷墙固地固，完全就是表演性质。地固是多余的，墙固必须是批腻子之前的工艺，否则没有一点用。《黄墙绿地，你付钱，我负责表演》
第三项：基层处理，这个是重中之重，也是最容易出问题和忽悠人的地方。注意成品腻子是没有问题。但是家里的墙面不仅仅是批腻子，只不过批腻子占的面积大而已，重点是腻子前的基层处理，基层处理不好，腻子做得再好，后期还会出现开裂问题。
▲如图施工就是腻子之前的基层处理，包括贴布挂网，找平，这个才是最重要的工艺。
注意在看预算的时候一定问清，基层处理是否包含贴布、挂网、石膏找平，否则就会出现备注后面的单独计费。这个单独计费不要小看，一旦墙面基础差，后期的加钱费用比你家全房的腻子费用都高。所以不要自欺欺人以为报价很低，后期加钱不断，比谁家都贵。
此预算，第三项基层处理备注里头就隐藏陷阱，看起来不计费，合同价位低，实则进房子这是必然增项的地方。
第四项：乳胶漆，这个也是重中之重，注意项目里头只有多乐士品牌，而没有具体型号，这个就是最大的坑。坑的就是大部分只认品牌的错误认知。
一个乳胶漆品牌有N个型号，每个型号价位天地之差，有一大桶100元的，有一大桶三四千的。预算里头不写型号，后期百分之百拿的是最低价格，这个就是预算的漏洞，如果你不知道，那就赚了，你以为你用的品牌，其实是用的最垃圾的乳胶漆；你如果后面发现了，已经迟了，你要多钱的都行，必须加钱补差价，但是低价切入已经签订合同了，目的已经达到了。《乳胶漆什么档次适合家用？多钱一桶合适？》
乳胶漆的施工方法也得注意，一般是顶面可以喷涂，墙面不能喷涂，有颜色的墙面更不能喷涂，否则后期维修没有办法去做了。
第五项：地面贴砖，这里也是隐藏最大坑的地方，前期一定要把规格和贴法弄清楚，然后做预算，不同的瓷砖以及规格的话价位是不一样的，如果明明知道你有个性要求，或者个性的瓷砖，而按照最简单报价，那后期增项是必须的，而且可以坐地起价，说多少是多少了。
注意备注里头的高度，这个几乎是大部分装修公司故意挖坑的地方，贴砖途中因为厚度问题而无故加钱，但是薄的地方从来不会给你减钱。这样的话量房的意义何在？
第六项：石膏板吊顶，这里简单，注意龙骨是木龙骨还是轻钢龙骨，价位应该是不一样的，自己拿定主意即可。
以上是家里公共区域的预算，注意除过这个预算，其中还有一个漏项，你家地面是瓷砖，但是入户过门石呢？这里必须采用单独过门石去做，所以预算里头已经漏算了一块过门石，虽然费用不多，但是后期还得增加。
装修费用就是一点一点累计而来的，所谓的《偷项漏项》就是一点一点增加的，这个就是装修的大忌，但是却是大部分装修公司乐此不疲使用的勾当。
