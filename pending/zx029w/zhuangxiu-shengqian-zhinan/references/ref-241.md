# 自己装修翻车，有时候真的没有省钱4.14

好多人喊着装修机构存在没有意义，其实这个需要思考着看，如果你找卖活的套餐装修机构，那就不是做装修的，和自己装修没有区别，要不设计感没有，要不纯粹就是廉价建材的堆积。所以，当你需要找装修机构的时候，远离套餐。装修机构的存在并不是赚取差价，而是服务费，把控所有美感和细节，保证装修有价值，这才是装修机构存在的意义。你自己装修除非你自己懂装修，否则装修完了也就是施工而已，谈不上任何效果，甚至花费比机构更高。只是你没有比较损失的大小而已。▲如图所示，自己装修不懂审美，看一片瓷砖好看，结果就成了这样，比精装修瓷砖还丑，为了省钱自己装修缺少专业人士把关，损失更大。▲既然不找装修机构就是为了省钱，那做电视墙干啥？是不是本末倒置了？而且没有专业人士指导，照抄同小区的做法，图便宜买同花纹的瓷砖，不翻车都难，如果砸掉重新做，那成本要更多了。也就是你自己做装修的效果损失以及材料浪费，甚至远远大于你找装修机构的费用。▲装修真不是多用岩板，多用金色就显得高级，这种做法非常轻浮，甚至廉价，审美真的需要专业把控，要不钱比谁都花得多，没有任何价值。▲乳胶漆变色真的不能东施效颦，你自己装修没有审美支撑，没有专业人士指导，学别人最后只能不伦不类▲自己装修什么都图便宜，那便宜的瓷砖商压根不给你出排砖图，散工更不会给你出排砖图，你让从哪开始贴是你自己决定，结果就是如图的结果，省钱省到哪了？▲你自己不懂装修，也压根把控不了审美，散工才会不管你用什么瓷砖，贴上你就得付费，所以自己装修到底省掉了什么？▲自己装修没有审美，这个瓷砖到底是要还是不要呢？▲左图自己装修，不懂审美采用亮光瓷砖，各种配色厚重又难看，定制图便宜也没有审美，而且还学别人做了吊顶；而右图刷墙铺地有专业人士把控，不仅省钱而且美观。▲价格没有少花一分钱，你以为只要做定制的都有审美？没有专业人士的把关，任何东西都有可能翻车。钱没有省砸掉的冲动都有了，但是装修房子真的没有后悔药。▲稍微有审美，有专业人士把关，都不会让你贴这么深的亮光瓷砖，你以为光线是靠亮光决定，这个是误区；吸顶灯不好吗？非得东施效颦学别人弄一些花里胡哨的灯具，结果是互相翻车▲自己装修很大几率成了运气，但是你的钱决定了几率大小，所以一般就只能这种水平的工人了，因为市面上手艺好的工人基本都被专业机构收走了，只有手艺不行没人要的工人才做散工的。▲自己装修连个图纸都没有，你以为让工人看个图，工人就能给你做成一模一样，照这样任何行业都不需要经验和专业支撑了，想简单了，自己装修省不了钱的▲人家的长虹玻璃是一层长虹，一层磨砂的，你没有专业人把控，用单层长虹，甚至两层长虹，不翻车也难，到底钱是白花了还是节省了呢？▲自己装修或者半包多半会出现以上的情况，因为自己装修压根不规划，东西随便购买；而你半包的话，木门和马桶是你自己的，马桶位置是固定的，这怪谁？自己装修以为价格低，半包找机构也找价格低的，那没有操心费，谁也不会操心了。▲自己装修，后果只能自己承受，同样瓷砖价格也一样，缺的其实就是专业人士的把控和基本的审美▲如图装修，甚至有的装修机构也犯这样的错误，这就是完全没有生活常识而已▲自己没有审美，没有专业人士指导，充其量其实就是做了装修，一分钱没有少花，只不过没有比较，自己以为自己没有找装修机构省钱了，其实只不过是自己一厢情愿的想法而已。▲装修的过程有了，而且钱比别人花的更多，但是几乎所有东西没有一个是不翻车的▲你说没钱吧，一个娃整一个实木上下铺，但是这个配色呀，真的不适合孩子住，适合爷爷住。▲投影计价，上图可能低价切后期让你加的更多，其实并不会省钱，可能更费钱而没有任何效果▲都2023年了，还有人给小的电视墙贴壁纸，而且还是贴一坨的做法，掏钱是为了把房子缩小吗？▲自己装修学别人找独立设计师，花了好几万，然后找个施工队，造价承受不了，结果自己还是刷墙铺地，几万设计费打水漂《装修找个独立设计师省钱？坑到哭》最后是完全达不到设计标准，这就是定位问题。▲真的不是省钱那么简单，人家可以用比这个少的价钱做出更好的效果。
