# 多做吊顶，你家定制就省钱了5.2

如果就想极简的话，那无需吊顶，如果你只是单纯想节省费用的话，有定制，其实最好做吊顶，这样并不是费钱，而且还会省钱。

▲如图所示，电视满墙柜没有做吊顶，定制高度就高了，而且与空调吊顶形成了难看的刀把结构，此时定制的费用肯定高了，如图净层高如果是2.7米，此时定制必然要算吊顶位置

▲如图所示，电视满墙柜上方做了吊顶，定制层高到2.5米，是不是定制就少了。很简单的比较一下，定制不论你用多钱的，肯定要比吊顶贵很多了。而且比较下来以后，做了吊顶是可以压低定制，在公共区域视觉效果更好。
▲如图所示，鞋柜和餐边柜转角定制，不做任何吊顶处理，此时柜子很高，定制价位肯定高了，在公共区域的话，视觉就会显得压抑▲如图所示，同样是鞋柜和餐边柜转角设计，做了吊顶，而且独立门厅也能更好的区域划分，此时所有定制高度降低，费用自然就低了▲如图同理阳台也是一个道理，左图是没有吊顶的阳台，定制通顶，窗帘只能用明装轨道以及明装的晾衣架；而右图是做了吊顶的，柜子下压视觉更好看，而且成就了窗帘轨道以及晾衣架的隐藏，整体效果好很多。虽然比较下来右图要花费多一点，但是效果上要更出彩，这里自己就得权衡自己的实力和效果了。▲如图所示卧室也是一个道理，上图不做吊顶，柜子通顶，自然定制费用就会高▲如图所示衣柜上头做了吊顶，而且还做了石膏板隔墙，此时不仅衣柜高度变矮，宽度也变窄了，其实最后定制是省钱了，石膏板要比定制便宜多了。▲如图榻榻米定制，衣柜和书柜上头没有吊顶，直接通顶定制的，此时定制费用肯定要好，因为面积增加了▲再看看上图所示是做了吊顶的，这样整体定制高度下压，后期定制总价就低了。总结一下：其实大部分定制上方采用吊顶方式去做，装修反而更省钱，另外的好处是上方吊顶的话，定制的平整度更好，误差更小，而且压低定制，视觉反而不会显得压抑。建议公共区域定制通顶最好吊顶处理，如果卧室不想吊顶空间小也是可以的，这个根据自己的经济实力和审美决定。
