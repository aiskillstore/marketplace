# 我很善良，从不占便宜，装修照样被坑1.2

装修被坑再正常不过，放眼看，是人，谁没有被坑过？所以不稀奇。

稀奇的是，一次次被坑，被低智商坑；更稀奇的是坑了不知道被坑，傻人自有傻福。

善良人人都有，人之初性本善。但是善良绝对是要分对象的，你对你家人好，不代表你就是善良之人，充其量叫做护犊子而已。你对陌生的外界善良才叫真的善良。

善良 ≠老实。你如果把这个分不清，那只能是愚蠢的善良。

农夫与蛇大家都熟悉吧？这就是愚蠢的善良，好听一点叫做老实，实则愚昧而已。

装修中也是一样的，好多现实中老实之人常常这样想：我不骗人，不害人，老天会保佑我不受欺辱。这是典型的奴性思维。农夫也是这样想的，可是还是被蛇咬。

我不做坏事，不害人，还得有一双慧眼，识别外界的假善和真恶，这才叫正常人的生存之道。

说到这，想起来昨天都市快报报道的一则新闻：一位老实的姑娘听信诈骗电话，人家声称是公安局，说她涉嫌洗黑钱，现在需要冻结她的资产，让把所有的钱汇到指定账号，于是就有了报道中的几万元轻松汇给骗子，警察来了劝都劝不住，还要继续汇款，坚信自己涉嫌洗黑钱。

报道中的姑娘绝对称得上是善良，从面相都能看出来。但是太愚昧无知了。从中陈工不仅看到愚昧，还看到了不自知。假如有骗子打电话说陈工洗黑钱，陈工首先低头撒泡尿照一下，自己这个德行想洗也没钱呀。

生存之道不分行业，不存在隔行如隔山之说，万事离不开做人，做事，这个是相通的。比如装修行业的最基本识别方法。

这是百度图片搜索到的某装修公司的宣传广告，类似于这样的宣传西安装修公司太多了，举例说明一下。

1.恶意增项全额退款。什么叫做恶意增项？你即使恶意，你也可以用善良的面孔来掩盖，笑里藏刀才可怕---你做就交钱，不交钱就不做，反正我没有恶意。这种能对付被教育洗脑的一大批人了《装修偷项漏项竟然没有加钱？这个更恐怖了！9.2》

2.工程不达标全额退款。遇到这种脑残的宣传，你还屁颠屁颠去公司咨询，你百分百被坑。第一条作假还能想得通，这个达标不达标再笨的人也知道，这就是靠一张嘴说而已。

3.环保不达标全额退款。和第二条一样，如果这种脑残营销都分辨不清，不坑你对不起你的智商。《装修不环保全款退，撒弥天大谎，要脸不？》

4.材料不一致全额退款。同样叫做多乐士乳胶漆，型号上百种，可惜几人想过。《装修乳胶漆的真相，明白了就不纠结了4.15》

5.工程转包分包全额退款。这个隔壁老王都笑了，西安地区十家有9.9家都是转包，这个说说而已。《装修被转包给隔壁老王了，你还蒙在鼓里？4.30》

好了，现在回到标题：我很善良，从不占便宜，为什么照样被坑？

因为你没有分辨好坏的能力，因为你一直生生的活着，而从未思考，上面5项宣传如果你看不出是在挑战业主的智商，那你被坑的几率很大。不是你善良别人就对你善良，善良的人得有起码的生存之道，最起码的慧眼识人，而不是不思考，只想着别人对自己善良。

不要做愚昧的农夫了，蛇是冷血的，你为什么不躲？不要做不思考的业主了，从任何蛛丝马迹都可以判断出一个公司的好坏，可惜，大家都被洗脑了而已，一个清醒的人反而被认作神经病。
