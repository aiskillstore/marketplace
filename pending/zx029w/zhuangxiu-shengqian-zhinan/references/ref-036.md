# 装修找施工队，真的能省钱？4.10

大部分业主在目前装修市场的影响下，总认为不找装修公司都能省钱。其实很简单的道理，你住宿的话以为不住酒店就能省钱？不一定，只不过是心里暗示自以为省了钱，搞不好是钱并没有省掉，而且还损失了品质。

以前有专门说过这种情况，今天用汽车保养来举个例子。

曾经在家门口有家汽车维修的小哥，感觉小伙不错，而且好几年的车了，也不想再去4S店保养。于是每一次都放到门口保养，时间久了发现问题所在。

第一，很少去检查全车其他情况，一般就是最最基本的保养，发现有几次连基本的螺丝松了不管；第二从来不愿意多发现问题，导致刹车片已经完全不能用，而且口头禅永远都是：这个还能用，不用换。

后来因为种种问题太多没有发现，就不去了，整天低头不见抬头见，终于有一天小伙可能感觉好久不来主动来询问，直接说明理由。小伙子倒是坦诚：哥呀，你咋不早说，你早说，兄弟每次给你全盘检查，这个不是费用高吗，能到咱店里消费的，肯定都是害怕4S店的高消费，所以不敢检查呀，如果检查多了负责任了，车主保养一次那么贵，肯定不来了。

听出什么门道没有？作为和4S店竞争的马路小店，你能去找他们，不可能给你保养什么，这是行业所迫，如果给你尽心了，费用比4s店还高很多，相信大部分人都不会去了。

其实在家门口保养并不是为了省钱，命和钱哪个重要这个不用纠结，但是这种故意低价或者手艺不行压根检查不出来问题的做法，作为安全首要的汽车来说不啻为生命开玩笑。

以上举例不是很准确，其实和装修施工队是一样的，你能找施工队，不找装修公司，作为施工队来说难道不知道你为了省钱？就会出现两种情况：

第一，你能找施工队，施工队不会给你费用很高，但是装修的工艺繁杂，不可能不做，只能靠偷减工艺和降低所有材料档次来解决；

第二、你会发现好多施工队不做全包，甚至不愿意带任何材料，只愿意让你出工钱，你以为便宜，其实不是，纯工费和全包比起来当然永远都是低的，哪怕工费已经翻倍，和装修公司的全包比起来，永远都是低的，这就造成一个低价的假象而已。甚至给你高于装修公司的工费，作为业主也很难把装修公司的工费和材料剥离开来和施工队比较。

这样的现象其实就会出现，施工队只出工费甚至利润高于装修公司带部分材料的做法。如果不信，你可以用心去比较一下就知道了。

找施工队唯一便宜的机会，是你找了一个家族式施工队，这样的施工队非常灵活。例如常见的一大家子组成一个施工队，都是自己家人干活，而且都是靠手艺吃饭，任何一个工种都可以降低费用，来打价格战。

但是所有找施工队都忽略掉了一个协调能力，以及装修与时俱进的做法。如果你就是出租房可以找施工队，没有什么技术细节难度，如果是自住还是谨慎。

甚至有的人刚需房子掏了几万的单独设计费，然后找施工队施工，认为这样投机取巧不找装修公司设计，可以省一笔可观的费用，而且还能达到效果。其实真的大错特错，装修不是泥腿子干活，每一个细节都需要有经验和美感支撑。这就好比你拿到了汽车的设计图纸，到路边汽车维修店给你组装一个道理，这样的汽车能保证安全才怪。

一个不争的事实是，装修公司把你坑了，你会在网上声讨，因为有名有姓，但是一个施工队把你坑了，你连人都找不到，甚至都不知道全名叫什么。所以只能自己吃个哑巴亏而已，这就是为什么你在网上很难找到指名道姓骂施工队的原因。

最后说一句，你只知道装修公司卖活，其实施工队也是一样的，一个施工队接你家活以后，如果因为太忙或者你不好说话，这个活很有可能转卖给别的工头，给你说的肯定是他家人，一回事，其实暗地里倒卖而已，中间拿个好处费。

不要说你碰到的施工队多么优秀，干装修这一行，如果施工队优秀了，有了口碑，立马成立自己专业的施工队伍，组建自己的公司了，何必整天在小区靠低价接活呢？嫌麻烦？还是嫌成本太高？装修公司何来成本？房租？那是让业主过来看方案可以有个遮风避雨的地方；业主没有时间可以在公司直接选购建材方便而已；至于人员配备，一个好的装修公司绝对不会像政府部门那样，各个部门都有，否则离倒闭就不远了，除非有坑人赚钱的高明手段。
