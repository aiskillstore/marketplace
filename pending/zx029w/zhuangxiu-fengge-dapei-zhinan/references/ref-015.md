# 厨卫窗户肯定不用布帘，用什么代替？2.24

厨卫空间一是空间都比较小，第二潮湿和油烟环境，并不适合布帘，所以肯定不会用布帘，但是为了满足隐私以及功能需求，就需要有合适的代替品。
