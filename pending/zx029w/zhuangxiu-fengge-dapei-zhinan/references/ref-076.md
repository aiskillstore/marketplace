# 橱柜门板无好坏，只有喜好和适合10.5

橱柜方面的文章很多，大家可以公众号直接回复“橱柜”看专题

今天详细谈一下橱柜门板选择，陈工经验之谈，不足之处请专家文后留言。

1吸塑模压门板
▲上图就是吸塑模压，吸塑和模压只是不同工艺而已，叫做吸塑或者模压都是可以的，分别使用模压机或者吸塑机，所以工艺统称为模压吸塑门，严格来说两者是有区别的，这个就不是业主需要知道的了。基材用的是密度板，外面主要是PVC贴面，好坏在于贴面的压制技术和水平，同样颜色也很重要，质量越好，颜色越正。

一般装修风格没有太大限制，美式，北欧，简约，或者是欧式都可以采用模压柜门，只不过颜色和款式有所不同罢了。好处是可以做出实木造型，也可以叫做仿实木。如果要说不足，那就是时间久了，门板会附着不同程度的油烟，甚至时间久了，烟机上头吊柜门板会有黄色的油渍。不过这个无需担心，任何东西你使用都是有损耗和磨损的，不可能历久弥新，所以吸附油烟方面可以忽略，业主只需要看是否喜欢和自己家风格搭配即可。

是门板都有厚度，一般模压门厚度有18mm，20mm,22mm，不同厚度价格是不同的，当然并不是越厚越好，要根据柜体风格选择，如果你柜体板材就是15的，用22的门板也不好看。

2实木门+半实木门
▲平时所说的实木门分为两种，一种就是纯实木，也就是原木门做出造型喷漆工艺，价格很贵，老百姓一般消费不起。半实木，一般就是所说的实木复合门，一般是外框纯实木，内心填充实木指接板，这是好的，次一点的，内心填充密度板，外面实木贴皮而已。一分价钱一分货，纯实木当然好，但是维护较难，实木复合虽然不是纯实木，外表完全可以做出纯实木的纹理，拼接做法更能保证门板的稳定性，不易变形，价格实惠，老百姓也消费得起。所以业主在购买的时候一定问清是什么实木，怎么做法，不能掏了高价买了实木复合门。

至于选择实木门还是其他看个人喜好和风格搭配，比如模压门完全可以做出实木的效果，价格还要便宜很多。这个就没有好坏之分了，同样都是厨房，外表如果用实木和模压，普通人还真的难以分辨，所以经济情况和风格决定需求。

3双饰面板
▲双饰面板和平时所说的三聚氰胺板差不多，基材一般有颗粒板，密度板，细木工板，表面面漆哑光沾合而成。有木头的质感，一般用到北欧风，或者仿原木色也是不错的，至于耐擦洗程度也是见仁见智了。一般双饰面板最害怕潮湿，一般潮湿或者泡水封边会有脱落。与模压和实木相比较，无法做造型处理，只能是平板门，不过可以隐形封边处理

4亚克力板

▲亚克力门板，单面高光，基材一般是密度板。颜色较于双饰面板类似，不过亮度高，颜色鲜艳。表面有机玻璃制作在耐擦洗方面相对要好于哑光的双饰面板。这个就看个人喜好了，与模压和实木相比较也是无法做造型的，只能是平板柜门，可以做隐形封边

5UV烤漆
▲密度板基材Uv烤漆加工，表面亮光，颜色鲜艳。相较于其他柜门，UV不耐磕碰，也是使用很多的柜门。一般简约风格多搭配

6玻璃门板
▲上图就是玻璃橱柜门，做的隐形边处理，颜色有各种各样。这里注意，一般橱柜厂叫做晶刚门或者什么钛金门，各位业主只要记住玻璃门就行。分两种，一种是普通玻璃，背板是实木多层；一种是无背板，玻璃是钢化玻璃，钢化玻璃的颜色是贴膜上去的。这两种玻璃橱柜是最耐擦洗的，同时因为是玻璃也是亮光的，怎么搭配厨房都显得亮堂。相较于其他材质，玻璃更不怕潮湿和水泡，同时不怕油烟附着，抹布随时可以擦洗。
