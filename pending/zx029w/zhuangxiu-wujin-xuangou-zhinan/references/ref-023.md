# 柜门铰链别乱买！一段力二段力三段力区别讲透，选错柜门用半年就坏

定制柜子，你盯着板材、比着价格，铰链呢？商家配啥用啥，从不过问。
入住半年，柜门关不严、回弹无力、磕碰异响、还夹手——这就是铰链随便配的下场。
市面上铰链分一段力、二段力、三段力，价格不一样，体验差距更大。今天一次性讲透，看完不会再被商家糊弄
01｜一段力：便宜是便宜，关个门跟摔门一样
一段力是最早的基础款，开合全程力度一致，关门没有缓冲，直接猛撞柜体，砰砰作响。
结构简单，用料少，造价最低——所以低价全屋定制最爱标配这种。
优点只有一个：便宜。缺点一堆：夜里开关柜子吵死人，大力关门震松螺丝，柜门边角磕碰掉漆，老人小孩容易夹手。
你家全屋用好板材，铰链配一段力，等于好柜子配了个垃圾心脏。
一段力只有一个用途：储物间、阳台杂物柜，极少开关、不在意噪音的地方。自住家用一段力，就是给自己找罪受。
02｜二段力：家用主流，性价比最高二段力是目前家装主流，也是陈工最推荐大多数家庭用的。
开合分两个阶段：大开角度轻松顺畅没有阻力，闭合到最后25度左右，内置液压阻尼开始发力，自动缓慢缓冲闭合，轻轻一推就关严，不猛撞不夹手。
开关顺滑静音，关门自带缓冲减震，厨房橱柜、卧室衣柜、餐边柜都通用。承重稳定、防锈好，正常家用十几年不容易出故障。
唯一的小缺点：全开状态没有阻力，柜门开到最大会贴紧侧板，大风或轻微外力可能晃动。但完全不影响日常使用。
自住家用，全屋统一二段力就够了，别听商家忽悠升级。
03｜三段力：顶配，但不是谁都需要三段力把开关过程分成三个力度区间：大开轻松推拉，中段平稳匀速，闭合缓慢缓冲减速。柜门开到任何角度都能直接停住，支持任意角度悬停。
窄空间柜子、厨房转角柜、儿童房衣柜——拿取东西不用手扶柜门，体验确实好。
但价格比二段力贵不少。预算充足、追求极致体验的可以上，普通人没必要全屋标配。
三段力是锦上添花，不是雪中送炭。你家预算有限，先把二段力配齐了再说。
04｜选铰链，别迷信品牌很多人一上来就问：铰链用海蒂诗还是百隆？
先想想你家柜子用的什么板材。
你家用颗粒板，投影500一平，非要配200块一个的百隆铰链——这叫本末倒置。人造板柜门轻，国产DTC铰链或者悍高足够完全匹配档次。
你家用进口实木做柜子，柜门重，那用百隆200一个的铰链才叫匹配。
铰链的选择和板材档次要匹配。用品牌最烂的不如用大众品牌最好的。
商家给你推大牌铰链，先看看你柜子的档次值不值得配那个价位的五金。没有那个板材档次，配再贵的铰链也是浪费。反过来，好板材配一段力垃圾铰链，一样是浪费。
05｜选购记住这四条1. 看场景选档次，不盲目追最贵
出租房、杂物柜省钱选一段力；自住全屋二段力；儿童房、窄空间、高端定制上三段力。
2. 看材质，别被忽悠
优质铰链加厚冷轧钢，表面防锈电镀处理，摸着厚实有分量，晃动柜门没松动间隙。薄铁皮铰链轻飘飘，用一年就生锈变形，柜门直接歪斜下垂。
3. 现场试缓冲
反复开关柜门，缓冲匀速顺滑、没有卡顿、没有忽快忽慢就是好的。劣质缓冲铰链用半年阻尼就失效，变回硬碰硬。
4. 分清弯数，别装错
直弯（全盖）=侧板贴平柜门，中弯（半盖）=两门相邻共用侧板，大弯（不盖）=内嵌柜门。装错了柜门关不严，还怪铰链不好。
陈工总结：
铰链看着不起眼，每天开关几十次，是柜子最累的零件。
全屋统一二段力，够用好用性价比最高。一段力别用在自住房，三段力看预算上。
别迷信品牌，铰链和板材档次匹配才是正经事。好板材配垃圾铰链是浪费钱，差板材配顶级铰链也是浪费钱——匹配，比品牌重要。
