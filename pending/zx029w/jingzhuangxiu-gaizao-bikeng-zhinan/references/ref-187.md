# 卫生间门联窗，满足采光和空间价值9.12

一说起门联窗，可能大部分人就想到过去年代的做法，但其实不论哪个年代的做法，只要有价值，总是经典不落伍的。第一可以放大视觉空间，对于小户型来说非常实惠；第二可以提升采光面，对于光线不好的户型非常有价值。今天看看门联窗，在实际卫生间装修里头的运用。
.01
不做干湿分离的门联窗

▲即使卫生间没有干湿分离，也可以采用门联窗的设计，提升采光，同时放大视觉空间▲无法实现干湿分离的卫生间，也可以采用门联窗的形式，满足采光的最大化提升▲没有干湿分离的主卫空间，同样可以直接采用门联窗的形式满足空间的光线的通透▲复古风格客卫采用复古的黑色门联窗，既保证了风格的协调，同时又能解决视觉拓展和采光的问题▲无法实现干湿分离的客卫，直接采用复古白色的门联窗满足空间和视觉的放大.02
干湿分离门联窗

▲干湿分离解决空间小以及光线不好的常见做法。湿区门联窗设计，增加空间的视觉面积，同时提升了整体空间的光线，让小空间也能有通透感▲如图所示，原本昏暗的干区因为增加了采光面，让干区不再逼仄，瞬间通透，而且视觉上有放大空间的作用▲狭小的空间既能放大空间不压抑，玻璃的选择也可以保证湿区的隐私性，同时利用湿区的窗户采光面更通透▲门联窗并不是只有现代的做法，像这种复古的款式，搭配风格更协调，同时艺术玻璃的加入，空间上更丰富▲干区在过道，彻底与过道打通空间，本身就是用来放大空间的，然后再结合湿区的门联窗满足采光的通透，实现空间和光线的双重价值▲打通干区放大空间，同时门联窗成就光线，装修的每一步其实都是创造空间的价值的做法▲款式和颜色是为了协调风格，但是功能都是为了空间和采光▲复古的白色门联窗加上打通空间的干区布局，不仅风格完美协调，同时空间和光线的价值最大化满足▲湿区空间比较大，此时可以采用门联窗形式，但是采用子母门的做法，满足了视觉光线的提升▲如图一样的门联窗形式满足湿区隔断的功能，同时采用子母门的形式，实现平开门的密封效果.03
