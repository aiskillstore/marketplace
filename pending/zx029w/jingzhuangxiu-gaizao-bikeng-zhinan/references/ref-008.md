# 厨房吊柜是刚需？还是多此一举？

厨房吊柜是刚需还是多此一举？一句话：**只要你不是豪宅，吊柜基本就是刚需。** 跟风不做吊柜，入住基本都后悔了。

**先看事实。** 只要不是豪宅，几乎所有人家厨房收纳都不够，即使做满柜子，时间久了就会发现收纳是远远不够的。老百姓装修想要更整洁，唯一就是充足的收纳，否则连收纳都保证不了，正常生活都受影响。

**那为什么有人不做吊柜？** 不做饭，地柜收纳够而已；不要模仿，收纳都不够再好也得是仓库。不做吊柜空间是看起来更大，但是收纳百分百不足，除非不经常做饭或者压根不做饭。不做吊柜前提是你地柜收纳充足，而不是不做吊柜乱成仓库。你一家三代人顿顿烹饪一大桌，你羡慕单身的厨房，生活方式不一样，是没法跟风模仿的。

**隔板能替代吊柜吗？** 隔板是代替吊柜的神器，只能满足常用小物品的随手放置，无法满足太多杂物的收纳，不频繁做饭的家庭是可以满足。但要注意，隔板越多后期越乱，油烟重地就得不停的擦洗，要不油污太多了。开放厨房不做吊柜，采用局部的小吊柜与隔板搭配，美图看着都漂亮，但是如果频繁做饭，用不了多久就会乱成仓库，这个还得考虑清楚，不敢只看摆拍美图。

**不做吊柜还有个麻烦。** 不做吊柜首先考虑的就是烟管的外露，烟机必须采用伸缩挡板或者直接定制挡板，否则露出来烟管非常难看。

**很直观比较一下有没有吊柜的区别。** 显然有吊柜空间更整洁，杂物都可以藏起来，而不做吊柜没有地方收纳，东西是越来越乱，除非不做饭，可以实现空无一物。

**什么情况下可以选隔板？** 隔板的最大功能就是不占空间，同时方便拿取东西，而且在整体厨房装修中，还可以起到装饰作用。厨房拐角的隔板比吊柜更加实用，同时视觉上减少压抑。水槽上方空间有限无法做吊柜，隔板收纳利用空间。窗户两边的小空间做隔板收纳，利用率更高。对于小户型厨房来说很实用，不妨结合实际用隔板代替吊柜。

**最后送你一句大实话。** 千万别信不做吊柜生活多么爽的鬼话了，这就好比一夜暴富的神话一样，你信了你就输了；这就好比不工作肯定爽，但得饿死；没有吊柜肯定爽，那得乱死而已。别跟风，看自己家的生活，天天开火做饭的，老老实实把吊柜做满。
