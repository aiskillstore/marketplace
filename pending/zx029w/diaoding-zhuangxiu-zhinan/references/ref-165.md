# 装修客厅吊顶好还是不吊顶好？12.21

这个问题对于我这种人来说，真不该专门开辟一篇来讨论，感觉好浪费资源。但是从早上到下午最起码有五六个业主咨询吊顶问题，让人不思考都不行。

这个问题如果放到土豪圈里压根不存在，之所以有这个问题，是因为我们都是普通大众，我们的房子几乎都是刚需房，我们得权衡利弊，细心算计才能用尽量少的钱装修出理想中的效果。

西安地区那些动不动几十万半包或者几百万的所谓高端装修人士，肯定不屑回答这个问题。问他们几乎也是白问，你不吊顶，人家只能白眼相向，连吊顶都不想做怎么能称之为高端呢。

呵呵，苦逼的现实，吊不吊顶也能分出个高低端，林子太大……

按我自己的想法，客厅吊顶不吊顶这就不是问题，这个问题好比你问别人：我家老婆漂亮吗，一样让人不敢回答。我说吊顶好呀，有档次，但是不喜欢吊顶的业主心里一阵鄙夷：什么年代了，都是以轻装修为主，你说吊顶好还不是想多做项目多赚钱，而且吊顶造型繁琐经不起热胀冷缩的考验，往往会有不同程度的裂缝问题，积灰难打理等问题；我如果说没有必要吊顶，直接压个顶角线就行，或者什么都不做，吊顶就得费钱，而且还有质量隐患，牺牲层高等等问题。喜欢吊顶的业主有一阵鄙夷：我装修房子就是为了档次，找你们就是为了好看，设计一下，你连个吊顶都不做，哪找你们干什么，直接找工人刷墙铺地就行。

万能的主，你说我该怎么回答？回答不回答都得罪人，还显得我是故意内行骗外行了。

装修房子如果为了住，有吊顶也行；没有吊顶照样睡觉。

人活着，一日三餐，有肉也行，没肉日子还是一样的过。不见得吃肉就有好的身体，自然界纯肉食动物一般都命短，而从不吃肉的和尚才终成佛，长命永远。

如果你就是投资房，用来出租，那就算了，吊那个顶也不能多收一分钱房租；你如果是自己住那就是你自己喜好问题，喜欢就吊，不喜欢就不吊。

如果你要做中央空调，这是必须吊顶的。

如果你的净层高已经低于2.6米了，就得谨慎了，用红外线找一下高低，看你房子最低点层高有多少，如果过低了最好放弃吊顶，如果还想吊顶，那只能想办法牺牲灯带，做假灯带以增加层高，或者直接有吊顶取消灯带也是可以的。

最后一点，如果是为了经济考虑，那我劝你不要吊了。吊顶和钱是人都知道怎么选。
