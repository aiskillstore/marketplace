# 装修要不要请独立设计师？免费设计和付费设计到底差在哪？

**先下结论：免费设计不一定是坑，付费设计不一定靠谱。** 那些把免费设计是坑整天挂在嘴边的人，不一定是对你好，要不人云亦云，要不就是对业主最严重的PUA。如果是独立设计师，那免费100%是坑，因为独立设计不施工，靠的就是设计。但一般的装修公司自带设计师，如果免费设计，你认为是坑那就草率了，因为施工本身就有利润，设计如果简单，再收设计费只不过是不收白不收而已。

**装修设计没那么高大上。** 大部分老百姓装修几乎都是刚需和功能，谈不上所谓高级，充其量就是功能的布局和颜色喜好的搭配，再加上对装修的整体协调安排，也就是所谓的装修服务。以上所谓服务的费用已经完全包含在装修施工费用里头了，完全没有必要为了报答装修群体的PUA而白白付出金钱。

**两种现实对比。** 没有一分钱设计费，装修踏踏实实，从来不低价切入，合同多钱完工依然多钱，从来不会故意增加项目和费用，事无巨细任何细节都做到尽量完美。另一种收了几千元甚至上万元的设计费，花里胡哨的图纸复制打印成册，效果图精美绝伦，结果装修途中各种增项和加钱，最后发现设计效果要不与装修效果天地之差，要不毫无关系。装修坑不坑你，和设计收费不收费没有半毛钱关系。真正的坑，是那些打着免费设计幌子前期报价故意漏报，钓鱼式装修，途中不断给你疯狂加钱和增项的公司；是那些收了高额设计费结果完全不负责，中途还是疯狂加钱，效果完全无法落地的公司。

**独立设计师该请吗？** 独立设计师当然必须收设计费，就靠这吃饭。你如果真的想找独立设计师或者好的设计，请找设计经验10年以上的，否则都不要找。干了两三年设计师，工地加起来都没有超过一百家，连施工工艺都不懂，怎么设计？图纸画的花里胡哨，效果图外面掏钱做得很漂亮，施工的时候全傻眼，全是常识性错误。而装修机构的设计师都是底薪加提成的方式，你真以为收了设计费能到设计师的包里？公司给设计师一部分其他还得拿走，给多给少设计师给你家操心不操心没有任何关系。

**普通老百姓怎么办。** 刚需房刷墙铺地要什么设计费？咱普通老百姓买个马桶一千以上的都不考虑，就不要掏所谓设计费了。别再被免费设计是坑PUA了，别认为花了设计费就一定高端就一定靠谱。清醒思考理性看待，多比较，多看看细节。服务到位细节到位，免费设计不仅不是坑，反而是老百姓装修实实在在的福利。低头看钱包，抬头看效果。
