# 装修里头不对称设计，有意想不到的效果4.8

装修设计和多高的学历，或者艺术院校毕业，压根没有半毛钱关系。通俗讲，就是经验和审美，缺一不可。有经验都是老旧年代的做法，自己不思考，没有基本审美也不行；但是有了审美没有经验，连基本的错误都避不开，更不行。今天看看这些里头的一些不对称设计，从中能给自己家装修汲取点灵感。

▲现代装修中，沙发以及旁边搭配，其实都是不对称的做法。如图一边是落地灯，一边是壁灯呼应，这种不对称的做法不仅满足了不同功能，同时空间视觉上会更有层次，也更有高级感

▲如图的沙发两边，一边是边几，另一边就采用轻巧的烛台，另一边吊线灯布局，视觉上更显得灵动，同时功能性也得到延伸

▲像沙发背景的挂画，如果中规中矩，就显得死板，但是如果错位布局，视觉上立马有了高级艺术感

▲卧室也是一个道理，一边吊线灯，另一边采用壁灯，满足不同功能，同时视觉上更显得灵动，并没有采用一样的对称做法，会显得更中规中矩

▲不对称做法还有卧室背景的局部涂刷，错位的做法，更能有艺术感和高级感

▲电视柜满墙柜的延伸做法，套色设计采用不对称延伸，空间视觉满足延伸感的同时，更显得高级生动

▲满墙柜套色有时候采用不对称的做法，人为把电视居中，如图就是标准做法，满足了电视的套色的居中，同时视觉上还显得高级

▲如图的竖向镂空同样采用不对称的布局，既满足电视的视觉上的居中，又能让空间更显的生动，同时还有拉伸层高的作用

▲甚至常见的拱形门洞，同样可以采用不对称的做法，让视觉上更有新意，更有高级感

▲背景乳胶漆和线条同时采用非对称的设计，让空间更有高级艺术感

▲不同的餐椅搭配，其实也是利用不对称的视觉差异，显得更灵动

▲餐椅与条凳的搭配，满足空间的基础上，不对称搭配视觉更灵活

▲家里卧室两边也可以采用不对称的功能搭配，让视觉更灵活，而且延伸功能性

▲即使放床头柜，同样也可以采用非对称的布局，采用不同形式的床头柜，也能有意想不到的作用

▲非对称设计在定制里头以及家庭装修中，用到的非常多，而且恰到好处的话，可以让空间更出彩
