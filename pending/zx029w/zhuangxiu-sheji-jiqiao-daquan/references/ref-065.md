# 主卫对床，L型衣帽间布局以及注意事项10.10

大部分主卧带主卫格局基本类似，而且国内户型的布局方式一般就是固定的几种《主卧床对卫生间，6种解决办法》，今天重点看看L型布局的注意事项以及做法。

▲这种格局几乎占据了主卧布局的一半以上，因为对主卫对床比较介意，同时又得满足小空间的收纳，所以这种既能实现收纳，又能遮挡卫生间的做法，是大部分这种户型的设计。

第一、空间尺寸以及见光板

▲需要注意尺寸的控制，如果主卧放大床，尺寸1.8*2米的话，横向跨度床铺位置加上床头柜的话，大概1.9+1米，也就是需要三米左右的空间，除非牺牲床头柜，但是空间就显得压抑；
而L型衣帽间为了不至于压抑，横向需要80公分，加上衣柜进深60公分，至少需要1.4米的空间，如果做隔墙的话还得有10公分的墙体厚度，这样算下来如果主卧横向跨度有4.5米左右的话，才是刚需尺寸，再小就得牺牲功能性，空间会显得压抑。

▲如图格局，采用定制L型衣帽间，满足主卧衣物的收纳，同时遮挡一下主卫对床的问题；

▲封闭式L型衣柜的定制，好处是收纳居多，视觉上不显得凌乱，卫生间可以根据空间采用平开或者移门作为隐私需求，缺点是衣帽间的灯光设计，必须保证时刻光线的通透

▲如图所示，空间够的情况下，为了让主卧背后不露出衣柜的背板，可以采用石膏板墙镶嵌的方式，这样主卧内部不会看到衣柜的背板，而是统一的颜色，前提是空间一定够用，满足这样的需求。一般轻钢龙骨石膏板隔墙做完10公分，所以只要空间允许可以这样做

▲如图如果刚好衣帽间有窗户或者是缩小卫生间实现的L型衣帽间，此时可以窗户下布局化妆台，满足一组衣柜的收纳也是可以的

▲L型衣帽间定制注意见光板的设计，注意上图，左图侧面就是做了见光板和柜门一致，而右图没有做见光板，柜体露出，而且封板也是柜体露出，明显视觉空间要乱很多，这也是全屋定制设计低价切的做法。《定制柜子不做见光板？有价格无价值》

▲侧面如果不想做见光板，也不想进门直对一个呆板的柜体，可以采用侧面镂空的形式，玻璃门布局，专门用来收纳平时的包包，也可以当做展示区使用

▲还可以利用侧面，下方抽屉收纳，上方局部玻璃平开柜门，作为平时的随手挂衣需求，比如晚上脱下的衣服，可以随手悬挂；注意上图衣柜的背面为了颜色统一，做了整面的见光板设计，这样可以保证衣柜整体是统一颜色，而不是出现柜门与柜体颜色不一致的问题
第二、光线通透问题

▲衣帽间开放或者封闭根据地域以及家里配置不同决定；如果是南方地区可以采用开放布局，或者北方地区有新风的家庭可以采用开放布局，否则还是封闭减少打理的麻烦。

▲考虑到L型衣帽间会让睡眠区变小显得空间压抑，同时衣帽间没有光线，可以采用上图的做法，一字型衣柜镂空设计，这样既能起到遮挡作用，同时成就光线和空间的通透

▲还有类似但是不同的做法，如图同样是L型布局，但是作为洗漱区以及化妆区使用，卫生间采用玻璃封闭，一般很少有人能接受这种做法，多见于酒店民宿的做法，可以让视觉上与众不同，放大空间

▲一般这种做法最好主卫采用玻璃门，如果是明卫的话，可以引光入室，平时给衣帽间带来采光需求，视觉上让狭小空间也不至于压抑

▲如果家里有别的地方衣帽间，此时主卧可以不采用牺牲空间的方式，可以局部做收纳柜，然后采用玻璃屏风解决主卫对床的问题，节省空间，光线也变得通透，当然前提是家里的收纳够用

▲如图就是不做衣帽间，不会牺牲主卧的空间，同时采用局部的收纳柜与玻璃屏风，遮挡主卫门问题，空间变大，光线通透，唯一需要解决的是家里的收纳问题

▲为了成就空间和光线，家里有其他地方满足收纳，可以采用如图的做法，卫生间门口化妆台布局，采用镂空隔断遮挡一下主卫门的尴尬

▲如图也可以加入玻璃的设计，来解决视觉压抑以及光线通透问题，但是前提是必须牺牲局部的收纳

▲做玻璃柜体的衣柜当然能解决光线问题，但是付出代价是惨重的，普通家庭如果这样做，后果就是主卧永远的都是凌乱不堪，谨慎大面积使用这种玻璃衣柜，过日子不是样板间，很难永远保持高级感的摆拍

▲当然还有更高级的做法，局部收纳柜，中间采用悬空化妆台满足视觉的通透，成就光线，前提是这样的收纳足够使用

▲如果地方更大，收纳足够的时候，可以采用局部玻璃屏风的做法，满足视觉通透和光线的明亮

▲定制颜值更高的玻璃屏风，一组衣柜满足收纳；或者空间够大屏风后面实现一个化妆台功能，实现空间的通透和光线的明亮

▲高级感的定制以及高级感的灯光布局，除过造价比较高以外，几乎没有什么太大缺点
