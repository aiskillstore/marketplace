# 不要仓促找纯设计，理想与现实太远4.5

相信看了标题都知道今天要说什么。

纯设计对于大部分业主都不陌生，为什么要找纯设计？

第一，自己有施工团队，例如亲朋好友有做装修的，但是没有或者不会高大上的设计，于是就可以自己找单独的设计做好方案，根据方案施工即可。

第二，不相信装修公司的设计师能力，认为必须掏钱或者高价请的设计师，才能达到自己的要求，然后拿着设计方案让装修公司协调施工即可。

以上两种不谈论对错，但是又有几个人，在找纯设计之前想过自己的钱包？或者说找纯设计的时候专门强调造价？几乎没有！

这简直就是装修设计的天灾+人祸；

天灾是业主压根不懂装修，不知道该如何下手，更不懂的装修里头的专业常识，盲目只追求设计效果，压根忽略了设计和钱包挂钩的现实问题；

人祸是什么？普天之下，只要做单独设计的，除非昧着良心，否则无法存活。这一行就是这么残酷，你如果想要牌坊，只能走投无路；否则别人怎么干，你也得怎么干。

单独设计靠设计存活，效果就是第一大目的；只有效果好了，业主能看上了，高兴了，这设计费才掏得爽快。而效果的前提是不可能考虑造价的，否则设计师当时就会给你说：你做的这个预算你承受不了。

如果要立牌坊的话，更加寸步难行，因为家里有小孩，如果有点人性的话，设计师就会给你说，壁纸、木地板一切含有甲醛的都不敢用，请问设计里头所有花里胡哨的设计哪样不是以污染为代价的？

如果真的这样，设计师给你设计一个刷墙铺地的效果，你愿意掏两万设计费吗？肯定不愿意，因为这样的出租房效果压根你看不上。而且设计师能这样干不啻为自断财路，有设计师这样干吗？现实中有，但是已经改行！

能让你看上效果的只能忽略污染，昧着良心赚你的设计费，间接害你全家的健康，这就是现实。只有这样，单独的设计才能存活，可悲不？

举个例子，西安的刚需100平三室房子，单独设计费一平方在200元左右，设计费大概在两万左右。对于好多业主盲目追求高大上来说，感觉非常值！

但是记住，设计师能收你两万的设计费，效果不可能差，但是设计师永远闭口不谈这样的设计要落地你需要付出的金钱以及你全家付出的健康代价。

如果实话实说，这个效果施工要30万，你还会继续吗？肯定是越低越好，承诺这个设计施工费用不会太高，以促成设计的完成，目的是赚到钱就行，至于你后期是否花这么多钱施工，那是业主自己的事情。

然而这样的后果是什么？碰到N个找单独设计的，然后过来让施工，大部分是预算完全超支，如果按照设计效果还原，预算远远高于业主的承受力。最终导致几万元的设计沦为一堆废纸，不仅没有任何效果的体现，反而加大了刚需装修的成本。

还有一部分纯粹追求效果，自己有身孕或者家里有小孩，只追求装修的效果，完全不顾设计落地的污染，设计出来告知风险以后，悔不当初，原来的设计全部推翻，设计费打了水漂。

以上两点对于家庭刚需装修来说不啻为雪上加霜。所以在你准备找单独设计的时候，钱包比效果重要多了；同时一定和单独设计师签订违约责任，因为为了能出效果最快时间拿到设计费，会在你不懂行情的时候故意压低预算，导致后期施工预算超支，设计沦为废纸。

此时一定要告知设计师你的预算，然后设计后的效果一定要与当地的施工费用行情匹配，超出多少算违约，可以追讨当时的设计费，这个一定要有合同为据，除此之外，除非你有钱，也压根不在乎装修污染。

装修需要落地，不要做帽子比头都贵的事情。找设计师的前提是一定知道自己钱包里头有多少钱，同时考虑设计师一定是人性第一，工作第二。《好的设计师都有哪些标准？对号入座》《设计只图效果不看环保，花业主的钱要业主的命》
