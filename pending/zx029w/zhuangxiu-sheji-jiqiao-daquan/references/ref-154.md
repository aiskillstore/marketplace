# 入住才懂被坑惨！电视柜藏路由器，反人类设计的抽屉，砸了重装的心都有了

装修设计真的不是建材堆积，更不是用来炫技的，碰到这种情况当时不明白，等你真正入住就会发现：一些反人类的设计，除过炫技以外，结果都是坑人！例如，好多人路由器在电视柜隐藏，结果设计师不懂生活，为了炫技，设计了好多反人类的抽屉，业主当时以为很高级、很专业，入住以后才发现，都是坑人的做法！网友@脑子丢了：当初真的是鬼迷了心了，设计师信誓旦旦高级设计，做了一个电视柜抽屉，说是隐藏路由器，而且关闭以后美观；现在入住半年，才发现这个是反人类设计，只要电源有问题，必须趴到地上，艰难操作，真悔呀曾几何时，家家户户流行下翻柜门，以为这样更好开启，而且省了一个抽屉的费用，结果是安装插座趴地上，后期路由器电源有问题趴地上，不就是典型的反人类设计？与下翻柜门有异曲同工之处的就是上翻柜门，这个更加鸡肋，即使你趴地上，柜门更加碍事，同样是反人类的做法。当然有更“高级”设计师，很聪明给业主设计师以上的抽屉，倒装抽屉，没有毛病，功能实现了，即使里头放路由器，上头关闭以后还有个散热口，同时维修电源安装电源也方便。但是有没有人问一句：如果要实现功能，为啥要做一个复杂的倒装抽屉呢？又能上翻，又能抽拉，值得骄傲吗？不感觉把简单的事情复杂化了？弄个下翻柜门，上头弄个局部的活动板，最终你会发现，上头没法维修插座，下翻柜门你得趴着维修，复杂化以后没有目的，不是炫技就是完全不懂生活！有人看到抽屉需要趴着维修了，干脆做了对开柜门，但是这么低的电视柜，一样不得趴着干活？一样的鸡肋和反人类！其实电视柜隐藏插座和路由器，最简单的做法，就是最有价值的，也是最方便的，而且造价也是最低的。如果电视柜上方背后有空间的话，做成整体上翻柜门，直接靠墙也是可以的，柜门上翻留有散热口，也方便维修和拿取的。其实最简单的最不花钱的，就是上图的做法，一个活动板即可，随时可以拿起来，又达到目的又能不多花一分钱，不炫技，最朴实的做法才是价值。后记：其实真的不需要炫技，不需要复杂，更不需要单独去买什么五金，多收个抽屉钱，一个活动板就可以搞定，方便拿取。
