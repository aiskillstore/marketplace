# 给刚入行家装设计师的信

旧文重发，看过略过

一份简单预算并不简单，首先它代表公司形象，如果一份预算第一眼看起来了了草草，那么不用看工程也一样，不会好到哪去；
一份预算代表一个设计师日常为人处世，预算的整个版面好比设计师的衣服一样可以看出一个人的品味，预算的每一行每一个条条框框则好比是设计师的内心，一个内心成熟胸有成竹的设计师做出来的预算是清爽的，自信的，当客户第一眼看到一份这样的预算，基本上你的为人和品位已经一览无余了。
预算虽然简单，但条理分明，每一行文字占满每一行表格空间，项目适当用底色区分，不要用太艳的颜色；目前最大的问题就是预算一行字占多行字的空间，当客户第一次在一个陌生的空间（装修公司）看时，本身在短时间里心静不下来，看到如此的预算，表格多余的部分更加让人心空落落的---可怕的是设计师不知道第一印象就输了！！！
细节决定成败，一花看世界，相信每个人都是人才，每个人都想着干好每一件事，为什么干不好？？----静下心来，从内心每一个角落开始审视，从生活中每一个小细节去汲取营养，事情发展总会有一个过程，不是一朝一夕的事情，不要急于求成，好事多磨，好的过程才会有好的结果，相信没有风风雨雨万物怎能生长。
每一个人都会追问：为什么这么多年总也找不到自己的路，总也看不到前方的目标，好像每一天不是自己愿意这样过下去，而是无奈的一天一天又一天。时间是最好的老师，也是最不负责任的老师，时间教会你去生活，而你却不会珍惜生活；每一位业主都是设计师的老师，教你去怎么揣摩人心，教你去怎么设计别人房子和自己的内心，也教会你更清晰的看清自己前方的目标。可是，自己到底做到没有。
量房做预算做设计谈方案，改设计，反反复复，头昏脑胀，甚至恼羞成怒，静下心来想一想，这有什么用吗？设计就是设计师的职责，在日复一日年复一年的重复（暂且称为重复）的劳动中，难道只得到了厌烦，只得到了对业主的怨恨，细细想一下，如果真的这样是不是该考虑改行算了，这样的生活对自己就是折磨。
没有一次的方案是相同的，不要以为都一摸一样，怎么可能一样，每一设计方案都有不同业主，不同的业主都有不同的爱好和品位，你每天要面对如此复杂社会下如此不同的人，要谈方案，要讲预算，多好的人际环境，这么好的人际条件还激不起你的设计欲望和灵感，这么多的设计做下来，一年两年，三年，你还是平平庸庸只能去做简单预算，是不是该反思一下：小学生能从1+1=2总结出100+100=200，设计师难道只是在重复枯燥乏味的设计？
设计好比做人，每一次设计都要融入自己做人的因素，每一次设计的完结都要伴随个人心智和内力的提升，生活就是这样才显得有意义，每一天都是新的，每一天都表示你比前一天更成熟更有力量。一年做小户型，两年做大户型，三年，五年……还有什么能阻挡自己。
设计不是设计师的衣服，不是设计师的门面，不是设计师的招牌，设计是设计师的内涵，是设计师的为人；不是扛着这个招牌你就高人一等，不是有了这一身衣服你就沾沾自喜，不要在如此光鲜的名号下昏庸的数日子；设计是一门没有学科类别的科学，面对客户，不是说两张预算两张图纸就是交代，你递交的不仅仅是两张数据和图纸，最最重要的是你递交的一个人的内涵，一个设计师的价值，一个在如今如此喧嚣社会上的一份冷静和自信，靠着它才能打动每一位业主。
每一个人都会成功，成功就在眼前，只要脚踏实地走好每一步，过好每一天，成功就会越来越近。失败并不代表成功不存在而是你在不经意间放弃了追寻，同时也放弃了自己。
