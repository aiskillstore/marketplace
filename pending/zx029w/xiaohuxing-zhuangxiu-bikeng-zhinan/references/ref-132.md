# 装修神奇改造：丑陋管道变艺术品，邻居都羡慕不已！

家里装修总避免不了难看的各种管道，有的采用简单方法就可以轻松化解，但是有的管道属于“前不着村后不着店”的类型，此时无法采用普通做法化解，就需要用到创意做法。今天就盘点一下那些“前不着村后不着店”管道的创意做法，不仅化解丑陋，同时还可以成就家里的亮点！阳台纳入客厅以后，阳台下水可以封堵，但是下水管大家共用，此时采用石膏板封闭太突兀了。所以定制了金属板直接隐藏装饰，然后采用顶天立地的柱子搭配隔板，实现一个巧妙的展示架，不仅化解了丑陋的管道，同时成了家里最亮的装饰。拆除阳台墙体以后幸运的是下水管在空调外机位置，不幸的是上头弯管在室内，直接包盒子非常突兀而且还难看。采用饰面板隐藏装饰一下，同时加入电源，安装了一个射灯，墙面做了造型，让难堪的管道成了家里最亮的端景造型。如图所示，拆除阳台墙体以后，管道采用白色定制以及结合木色隔板，实现一个收纳展示柜的样式，隐藏了管道，成就角落一个展示功能，一举两得！想要开放厨房，砸墙以后下水管裸露，采用木质定制洞洞板实现隐藏，同时洞洞板可以满足悬挂置物，同时岛台围绕定制，不仅不难看，反而成了创意的亮点。移动厨房墙体以后，导致天然气管道外露，采用木质包裹，天然气表藏到后面，前方做成了酒架，既隐藏了管道，同时实现了酒架，又提高了颜值。卧室阳台有下水管以及突兀的墙垛，结合设计采用木质饰面与背景护墙板结合延伸，实现了完美隐藏。阳台纳入室内，导致下水管外露，为了更美观，采用木质饰面定制，与旁边墙体木质协调，同时采用金属隔板的做法，实现了一个创意的展示空间，原有丑陋的管道反而成就了家里最亮的角落。为了扩大厨房做开放式，砸墙就露出难看的下水管道，采用石膏板直接做成了圆形，后期刷上防水乳胶漆，管道反而成了难得的装饰亮点，或许这就是设计的意义吧。同样的做法开放厨房以后，下水管你外露，采用定制石膏造型加以装饰，后期采用防水漆涂刷，让管道成为开放厨房的陪衬亮点。厨房开放以后水管外露，又无法移动主管道，采用160的下水管裁口套进去然后用胶水粘牢，最后采用木纹贴纸贴上，让颜色融入厨房，实现丑陋水管的最大化弱化。阳台原有是分割两个阳台，为了扩大空间砸掉中间的隔墙，但是难看的下水管就裸露出来，网购乐高积木自己动手装饰一下，同时也实现了乐趣，装饰效果简直独一无二。露台难看的下水管，影响露台的观瞻，采用麻绳装饰，然后采用仿真椰子树装饰一下，视觉上好看多了封闭厨房改造开放厨房以后，天然气管道就到了餐厅位置，采用定制烤漆板造型，让燃气师傅把表改到了地柜里头隐藏，这样视觉上完美解决问题。开放厨房以后水管外露而且到了岛台位置，采用定制造型隐藏起来，融合整体设计，让视觉上更美观。阳台纳入室内以后导致下水管裸露，定制木纹板装饰一下，变成了家里最亮的装饰，同时还融入了整体风格。封闭作为开放厨房以后，下水管就完全裸露外头了，采用石膏板圆形包裹隐形，然后批腻子刷漆，隐藏管道同时实现了颜值需求裸露的两根下水管，上方做了一个穹顶，下方定制石材罗马柱装饰，最后惊艳成了全房的亮点。厨房开放以后天然气管道裸露，采用定制一体隐藏，刚好与岛台融为一体，弱化了存在感，同时空间整体反而更出彩。开放厨房以后，下水管裸露难看，采用枯树造型加以隐藏，不仅与侘寂风整体融合，而且视觉上还成了空间的亮点。
