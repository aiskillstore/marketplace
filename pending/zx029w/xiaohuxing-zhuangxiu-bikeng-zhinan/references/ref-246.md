# 90㎡两室老房改造，成就小两口婚房

一套过去的两室二手房，两室空间并不大，但是公摊小，得房率非常高，作为婚房来说，而且不准备要小孩，空间完全满足。
▲原始图纸。存在的问题以及业主要求：
1.得房率高但只有两室空间，不准备要小孩，刚需是完全满足
2.入门是厅，进门的收纳很难满足
3.厨房狭小，朝外窗户居多，收纳定制以及空间都比较局促
4.唯一的卫生间很小而且没有干湿分离
5.餐厅处狭小，进门视觉比较拥堵
▲设计后的布局图。改动如下：
1.砸掉厨房开放布局，延伸岛台弥补厨房收纳不足
2.改变次卧门洞方向，作为书房使用，推拉门设计，让进门空间豁然开朗
3.改变次卧门洞以后，实现了进门的玄关收纳，同时满足卫生间干湿分离
4.餐厅卡座布局，利用鞋柜满足卡座的遮挡，一举两得
▲改变次卧门洞以后，推拉门朝向餐厅，让进门视觉豁然开朗，同时利用空间，实现了进门直对的玄关柜收纳▲砸掉厨房开放布局，延伸岛台弥补厨房收纳不足，同时作为餐厅卡座的区域分割；利用卡座侧面实现了进门口的鞋柜收纳，不突兀，空间反而整齐整洁▲卡座布局节省空间弥补收纳，小圆桌布局，满足了平时两人的就餐需求，旁边岛台随手置物非常方便▲保持合理动线，餐厅鞋柜与岛台让就餐区围合设计，白色与木色搭配，温馨舒适▲岛台作为餐厨区域划分，同时延伸收纳，抽屉布局满足更多小零碎分类收纳▲客厅阳台打通布局，满足空间以及采光的通透；电视墙镶嵌定制满墙柜，满足家里的杂物收纳▲空间不大，充足的收纳可以让家里长久整洁▲轻巧布艺沙发搭配小巧圆几，休闲椅布局，地毯满足提升温馨层次▲午后的阳光透光百叶帘斑驳温暖，坐在休闲椅上享受短暂的温暖时光▲客厅看餐厅空间，书房改变门洞位置，推拉门布局，让原有狭小的就餐空间豁然开朗；沙发拐角位置局部草绿色乳胶漆清新变色，原木斗柜弥补收纳，也可以让客厅空间更丰满▲一抹绿色提升视觉层次，空间显得更温馨丰满▲客厅阳台一侧做了小的洗衣池，因为墙体太短，防止洗烘机遮挡阳光，把洗烘机移至卫生间布局▲主卧光线最好，采用业主喜欢的暗色调搭配，稳重而且更有层次感▲主卧落地窗定制飘窗柜满足收纳和休闲，轻巧化妆台靠墙布局，满足女主爱美需求▲床尾原木斗柜布局，满足收纳的同时可以满足台面的随手置物，空间上更显温馨▲书房折叠门布局，可以随时让空间豁然开朗▲书房利用落地窗位置打造了一个兼顾收纳休闲，同时可以随时拉出来满足一间次卧的功能▲靠最里头定制双人书桌，满足两人的同时办公学习▲开放厨房为了通燃气，同时为了必要时满足空间的封闭，采用立川门，随时保证空间的封闭和开放▲厨房空间不足，为了满足烟机的位置，采用异形设计，保证基本的功能满足▲异形处理满足了灶具的布局，满足了合理的动线▲另一边高柜满足冰箱的放置，吊柜满足一部分收纳▲改变次卧门洞实现了唯一卫生间的干湿分离，背景草绿色与客厅呼应，视觉清新简洁▲湿区空间，独立淋浴隔断分区，左手区域高柜满足洗烘机的镶嵌▲湿区空间全景，满足收纳的同时弥补部分收纳的不足▲马桶角落悬空杂物柜定制，可以满足一些杂物的收纳
