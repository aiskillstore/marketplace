# 115㎡有限空间创造无限可能，紧凑小横厅三口之家

横厅户型虽小但是光线一览无余，风格上没有固定模式，现代加入其它混搭，在具体设计中步步为营，最终呈现出来完整的效果。

▲原始的结构，入门小横厅，只不过被客厅阳台分割，进门显得零碎拥堵；入门右手的窗户也因为电箱的原因，人为墙体分割，进门收纳无法实现，好处是防盗门外空间挺大，可以放置临时鞋柜；厨房被阳台分割很小；客卫狭长空间小，而且没有干湿分离；朝北两间卧室格局都小，一间直对客厅，一间被阳台分割；主卧门直对客卫门，而且主卫也是狭长细小。
所以需要重新规划，让格局更完美，上图红色的区域都是需要拆除掉重新规划的地方

▲设计以后，防盗门外安排临时鞋柜，解决放鞋问题，进门原有的强电箱墙体改造成了收纳柜；
砸掉客卫重新布局，外移墙体实现了干湿分离，同时利用干区突出墙体实现了过道收纳，同时解决了客厅直对次卧入门的问题；
移动次卧墙体实现衣柜的收纳；改变主卧入门方向，拓展主卫空间，实现了衣帽间的收纳；客厅阳台砸掉墙体，放大客厅空间；厨房与阳台打通布局，不装门，采用吧台延伸空间，半开放设计

▲入门左手墙体砸掉实现了一个小的鞋柜，同时原有窗户保留，透光百叶满足采光需求

▲进门口看客厅局部以及过道空间，尽头的电视墙微水泥电视墙，加入工业元素，突出空间层次

▲入门口看横厅全景，阳台多余墙体砸掉，纳入客厅，放大视觉空间，同时提升光线；小横厅采用餐桌沙发后布局，与半开放式厨房一体通透，有更多互通

▲模块轻巧沙发与餐椅暖色呼应，与局部的灰色以及微水泥冷暖协调；整体无主灯让小空间视觉更简单

▲新作干区墙体，采用局部镂空通透设计，让空间更有呼吸感，微水泥的延伸与电视墙完美呼应

▲客厅阳台功能性沙发布局，这里休闲的角落

▲客厅阳台看全景，干区的延伸成就了过道内嵌收纳柜，同时遮挡了次卧的隐私需要；电视墙局部收纳柜木色的温润又与沙发地毯色块完美呼应

▲大面积白色作为主色，焦糖色作为温馨点缀，剩余的黑灰色作为陪衬，层次分明，冷暖恰到好处

▲进门的全景空间，虽是横厅但是空间并不大，所以需要在家具以及规划上，留出更多空间，满足功能和空间的双重价值

▲主卧大面积白色，背景半高木质饰面，延伸焦糖色的床品，在空间明亮的底色中又层次分明，视觉温暖

▲延伸利用飘窗满足收纳以及一个床头柜的功能，玻璃吊灯营造氛围；衣帽间收纳柜延伸一个小的化妆台，同时兼顾另一边床头柜功能

▲改变主卧入门方向，拓展主卫以后实现了双一字的衣帽间收纳，局部墙体微水泥点缀，刚好与外面微水泥完美呼应

▲衣帽间看主卧空间，一边衣柜延伸化妆台同时兼顾床头柜功能

▲客卫紧邻的次卧空间，拓展空间以后，背景蓝色层次，满足基本的功能

▲棕色皮革的床头柜与蓝色背景对比，非常有层次感，冷暖对比协调

▲半开放式的厨房，门口采用延伸吧台进行空间的衔接，橱柜内部黑白配色简洁

▲U型布局的厨房，右手满足冰箱布局，集成灶满足更多收纳定制；大面积白色搭配黑色台面，层次简洁

▲新砌墙拓展干区，满足干湿分离，同时满足了次卧直对客厅的隐私需求

▲干区新砌墙，采用断开式悬浮设计，局部的镂空悬浮空间更多互通，创意新颖

▲主卫浅色石材瓷砖与水磨石地砖搭配，局部玻璃隔断满足空间分区，整体清新简洁
