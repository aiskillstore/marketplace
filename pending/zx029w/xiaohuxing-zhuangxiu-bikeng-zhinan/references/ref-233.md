# 95m²三室混搭，两孩十年老房改造记

原房子已经装修入住10年了，房东孩子大了，就准备出手。就成了我们的学区房了，大家都懂。小学到初中就在家门口，铁打的学校，流水的娃，房子轮流转。我们不仅仅是为了两个孩子上学，同时地段也不错，就准备长期入住，决定砸掉这入住十年之久的房子，彻底改造。

▲设计后的布局图纸，刚需小三房，空间很紧凑。定位现代混搭，暖色系装修。

▲没有拆除之前的样子，没有地方放鞋柜，进门口朝客厅做了个鞋柜加玄关，不大的空间更显得有点堵

▲这是新装修的样子，进门口右手放了白色的成品鞋柜，满足进门收纳。电箱处挂画装饰遮挡。砸掉原来厨房的墙体镶嵌了餐边柜，同时餐厅侧墙也做了餐边柜，而且还镶嵌了一个水景鱼缸。简洁的大理石瓷砖搭配清爽的颜色，整体简洁。只不过餐厅灯采用了欧式的吊灯，加入一点混搭元素，整体还是挺协调的

▲餐厅全景，两边都有收纳柜，储物更多。白色与木色结合的餐桌椅，空间更有质感

▲全景空间，这就是为什么选择白门的原因，整体要明亮很多。所以小户型最好不用深色木门，让空间更压抑

▲进门看全景，去掉原来的玄关，空间更加通畅。奶咖色墙面搭配区域分割的白色灯带点缀，整体还是现代感十足的

▲原来的客厅电视墙，旁边就是主卧的门

▲装修后的电视墙，用了很小的电视柜来搭配，角落为了放置钢琴空间，为了这个功能区确实费了劲了

▲客餐厅全景，灯带吊顶区域划分更明确。皮质的咖色沙发搭配黑金家具，现代中还有那么一点轻奢之感

▲客厅全景，与阳台整体打通，空间更通透。沙发背景是手绘的世界地图，好像颜色有点突兀了

▲装修前的主卧空间，空间本身很小，而且光线也不是很好，老房子老小区，大家都把平窗延伸做了飘窗，我们也决定这样做

▲装修后的主卧，比较简单，石膏线搭配墙面的变色。唯一是背景用了混搭的壁布，还有整体定制软包床头。看起来更温馨一点。原来的平窗延伸出去后改做了飘窗空间，有了休闲场地了

▲侧墙的玻璃衣柜门，进门右手全身镜功能，床尾墙面还有挂衣钩，可以随手挂衣服了

▲飘窗跟前搭配一个中式的鼓凳，平时飘窗可以当做书桌使用了

▲这是装修前的小孩房子，过去的木质装修，显得非常陈旧

▲新装修的儿童房，粉色墙面变色，原来的平窗同样改造成了飘窗，因为需要放床，所以做高了窗台，不会与床冲突。大面积白色设计空间更亮堂

▲空间紧张，刚好设计上下铺，白色与木色搭配。楼梯也是收纳式的抽屉设计，收纳更多

▲第二个儿童房，同样非常小的空间，过去深色的家具让空间更压抑

▲这是第二个儿童房新装修的，蓝色的墙面变色，顶面还做了蓝色的星空顶装饰。空间有限，所以定制榻榻米以及衣柜一体布置。同样原来的平窗改作了飘窗空间，为了放床窗台抬高了一点

▲榻榻米一体的粉色套色衣柜，非常清新

▲原来没有装修的客厅生活阳台

▲装修以后的阳台空间，客厅之间的门拆除，用白色纱帘平时遮挡即可，空间能大一点。一边高柜镶嵌洗衣机，最大可能满足功能性

▲阳台的另一边，平时就养个花花草草，光线非常好

▲没有拆除之前的厨房空间

▲新装修以后灰地白墙，搭配白色模压橱柜，非常干净清爽

▲U型布局，右手冰箱放置

▲卫生间未拆除之前的样子，本身就是干湿分离，但是原来房东竟然放个洗衣机

▲装修后的样子，浅色的石材瓷砖搭配定制浴柜，镜柜收纳，干净整洁

▲吊柜的收纳功能非常强大

▲未装修之前的湿区空间，原来就是老式的平窗

▲装修之后，湿区空间很大，同样做了成品浴柜，原来的平窗直接延伸出去做了飘窗，这样平时就可以放置物品了。浅色瓷砖一体铺贴，空间干净清爽
