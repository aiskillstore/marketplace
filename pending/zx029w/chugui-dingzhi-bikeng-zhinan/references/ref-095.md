# 业主让看预算，这报价太坑6.14

因为提供的是全国性的装修咨询，所以每天都会收到来自各地方的装修咨询。发过来的报价预算也是五花八门。一般不看单价，因为不是一个地方，成本是不一样的。即使同一个城市大家的运营成本不一样，也是无法比较的。所以关注点一般都在工艺和做法，看项目是否齐全，是否有隐藏后期加钱的坑。今天就看看其中一个预算，每一处都会有详细标注，单价也可以参考一下。声明一下，别看单价，单价是公司成本决定的。

❶接下来是客厅餐厅公共区域的预算。第一项基层处理第4条：不含原墙贴布等处理。这是什么神奇的操作？难道这家的基层处理就是批腻子？但是你不挂网，不贴布，不石膏找平，直接批腻子，这是公开耍流氓呀，真的把业主当傻子看了。

❷看第二项乳胶漆工费10元，备注后面是空白。但是很明显，这10元只是工费，不含乳胶漆。这里人家说的是半包施工，所以含不含乳胶漆谁也没有严格规定。但是显然这个坑比较大，后期油漆都是业主提供，调色也是业主的事情，即使后面有售后同样需要调色乳胶漆，业主自己跑吧

❸看第三条铺砖，地面高低超过4公分加钱，呵呵呵，难道这预算是不量房做出来的？既然量房了，专业人士上门，难道不知道是否高出4公分，如果高出，那你就老实算进预算，为什么留这个后期加钱的借口呢？

❹当然可能有所谓专业人士会说，你用肉眼能看出高低吗？当然看不出，既然看不出，直接按照正常计算就行，你超过四公分加钱，请问低于四公分，你是否愿意减钱呢？

❺此外除过这些，发现铺地砖，入户门竟然没有过门石铺贴的费用，难道业主买回来过门石免费给铺吗？显然不是，只不过后期再加罢了。
