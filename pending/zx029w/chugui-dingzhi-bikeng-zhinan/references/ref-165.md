# 110㎡三室两卫，开放式厨房+吧台+定制柜

三室刚需，本身空间就不大，需要满足业主更多要求，就需要更多细致的设计。

▲房子原始的样子，进门是个狭窄的过道，通过过道朝南向分别是客餐厅以及主卧，而且主卧和客厅共用阳台；入门左侧分别是另外两个小卧室以及客卫空间。
缺点：进门过道狭窄无法满足收纳，封闭厨房太小，冰箱无法满足布局；客厅主卧共用阳台，隐私不好，浪费空间；两个北向卧室极其小，无法满足基本的收纳

▲设计后的样子，砸掉原来封闭厨房以及干区的墙体，用进门的收纳柜兼顾门口收纳以及进门玄关，厨房开放布局提升整体光线以及收纳；
客厅与主卧共用阳台分割作为单独阳台，主卧与阳台打通拓展整体空间，增加收纳；牺牲主卫空间满足冰箱的镶嵌；客卫隔壁卧室很小，利用客卫局部空间实现收纳的定制；另一间卧室打掉设备阳台拓展空间

▲进门的玄关柜，矮柜满足进门的收纳，同时兼顾进门的置物玄关柜；干区长虹玻璃通透布局，视觉更加灵活

▲进门的全景空间，砸掉封闭厨房开放式布局，满足吧台以及更多收纳；进门的矮柜满足门口收纳以及玄关背景

▲开放布局增加了吧台功能，平时简餐随时置物更方便

▲开放厨房以后，橱柜与餐边柜一体定制，四人位餐桌满足基本功能；牺牲主卫空间实现了冰箱的镶嵌

▲餐边柜白色与木色结合，兼顾水吧台以及少量酒柜功能

▲全景空间，岩板餐桌与岩板电视柜呼应统一

▲客厅全景，皮质的灰色沙发搭配白色岩板电视柜，两个圆几代替传统茶几，视觉和空间更灵活

▲角落空余小的边几搭配时尚吊灯搭配，一副有纵深感的挂画斜靠更有高级感

▲大面积白色提亮空间，灰色调可以让视觉更柔和干净

▲全景空间，白色为主，利用大面积灰色搭配，素雅极简，少量的饱和度低的色彩点缀，提升温馨

▲利用主卫局部空间，实现了双开门冰箱的镶嵌，上方吊柜定制，还满足了少量杂物的收纳

▲主卧与阳台打通以后，拓展空间，背景深灰色涂刷提升层次感

▲打通阳台拓展空间，阳台实现了收纳柜以及书桌的布局；化妆台角落布局，背景壁灯吊线灯以及错落的挂画，视觉上增加高级感和艺术感

▲床尾顶天立地的衣柜满足基本收纳，与阳台打通以后，套色设计满足了一个书桌功能

▲衣柜平时满足基本的衣物收纳，完全足够

▲阳台套色书桌满足平时偶尔办公的需求

▲阳台另一边同样衣柜定制，局部镂空套色作为展示作用，视觉更生动，可以做为局部展示使用

▲距离满足，衣柜内部伸缩镜布局，刚好满足平时的臭美需求

▲一边床头柜，一边化妆台满足功能；背景壁灯吊线灯以及空白挂画搭配，空间简单高级

▲次卧空间大白墙简单装修，搭配一米五的床铺，满足基本的功能即可

▲客卫隔壁的次卧空间，定制榻榻米以及书桌，满足一间次卧以及书房的功能

▲榻榻米下方以及衣柜满足衣物以及杂物的收纳

▲客厅与主卧共用的阳台分割以后，一边实现了生活阳台功能

▲干区定制白色的浴柜，因为空间太小，所以采用台上盆满足功能，拱形的镜子搭配，视觉上更显高级

▲湿区空间小，单独做了淋浴区，为了节省空间以及不与马桶冲突，采用移门的形式满足功能

▲主卫空间，统一灰色调布局，单独淋浴区域分割
