# 客厅不要电视柜行不？当然可以10.13

一般家庭装修还是过去传统的思维，也是固定模式，比如客厅一定是沙发墙与电视墙的摆设，无可厚非，但是随着生活的演变，大家追求的不仅仅是一个入住的房子，更多朝品质，朝宽敞靠近。于是，好多家庭都有一个要求，客厅能不能不放电视柜，本来空间就小，显得更加拥挤，而且也没有什么大的用途。

这里一定得考虑清楚，电视柜其实并不仅仅是储物那么简单。你如果需要电视，就牵扯到看电视的功能上。比如你家用电信的IPTV，那么就必须有光猫还有电信的信号盒子，这个不可能直接放地上吧？所以，这里就得解决看电视问题，才能决定放不放电视柜。

前提条件：
1.不看IPTV，路由器和光猫就放在弱电箱附近或者里头，电视墙挂电视，电视后面只要提前放一个电源插座，然后利用电视的内置WIFI功能直接看网络电视，这样就可以不需要电视柜。满足所需，而且现在看电视的时间明显减少了，这样就可以实现不放电视柜的宽敞效果。

2.还有一个办法，就是在挂电视的高度位置直接做好网线和电源，后期在电视后面做个超薄支架，把光猫和路由器隐藏在电视后面，这样也可以丢弃电视柜的功能，从而让空间更宽敞。

▲客厅跨度小，双圆几满足基本功能，去掉电视柜，空间更加通畅，非常简洁，更适合有小孩的家庭，活动空间更大

▲还是同样的做法，小圆几代替过去笨重的收纳式茶几，舍弃电视柜功能，是不是客厅又大又宽敞，其实还是那个空间，只不过丢弃了电视柜而已

▲丢弃电视柜，电视墙干挂石材，镶嵌电视机，这里就有两种办法，一种就是利用内置WIFI看网络电视，还有一种办法就是，干挂石材的时候背后留出空间，隐藏光猫和路由，等于是藏在电视后面，也是可以实现不需要电视柜的

▲当然更直接的办法就是，电视墙整体隐形柜，镶嵌电视，下方就是隐形的抽屉，里头隐藏光猫，同时隐藏各种线路，实现不要电视柜，同样可以看有线IPTV的办法。

▲家有小孩的话，丢弃电视柜让空间更宽敞，也更简洁，值得推荐。
