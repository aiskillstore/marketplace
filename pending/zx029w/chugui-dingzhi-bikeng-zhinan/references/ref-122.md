# 岩板用到哪都行，慎选一体盆11.8

陶瓷岩板，其实就是大板瓷砖，比瓷砖更硬，工艺不一样，所以可以达到更坚硬，防渗防污的效果，作为台面来说，远远好于目前主流的石英石，只是因为其价格现在居高不下，所以很难普及。

▲岩板比较坚硬，所以一般做法是不需要和石英石一样翻边处理，线条感更强，看起来更简洁大气。硬说岩板有什么缺点，就是太坚硬，就会导致冷硬的刀具不能使劲磕碰，容易掉块绷瓷。安装风险也大，返工的成本比较高
▲相反石英石一般需要做外面的翻边处理，视觉上无形中厚重，而且防污防渗能力远远低于岩板。
▲岩板餐桌面大气，好打理，非常不错
▲岩板大气茶几，好打理，更有质感
▲岩板一体盆慎选，因为本身就是岩板一块一块沾起来的，时间久了要不漏水，维修的方法就是不断不断打胶
▲因为是粘贴起来的岩板，就会出现时间久了或者长期压力下，盆底脱落的风险。

▲因为没有办法像陶瓷盆有弧度，四周都是直角，所以打扫卫生太难了，时间久了，直角清理不到的地方都是污渍，这简直就是岩板一体盆致命的地方，所以懒人慎选。
▲更不要提隐藏下水，价格贵不说，时间久了隐藏下水的缝隙压根不可能清理，而且成了藏污纳垢的场所，时间长了里头竟然爬出莫名的虫子，太可怕了，唯一的办法就是拆除不要了。
▲虽然有的为了解决下水问题，直接做成了斜坡处理，但是无法解决直角污垢的问题，同时溅水严重压根弊大于利。
▲任何岩板形式的一体盆，都无法解决根本问题，不能因为网红式流行自己也跟着入坑
▲如果真的喜欢岩板，可以采用成品陶瓷盆的形式，既利用了岩板的防污防渗能力，又能解决了防水溅好打理的问题
▲哪怕只用岩板做台面，做个方形台上盆，甚至解决了台下盆缝隙藏污纳垢的问题
