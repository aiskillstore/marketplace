# 除甲醛公司和甲醛检测有哪些套路（假检测、假治理、低价引流加价）？

**90%甲醛治理是智商税。** 治理公司通过治理前关窗测、治理后开窗测的文字游戏造假达标，治理公司短期效果不可持续，化学除醛产品作用微弱。甲醛释放周期长达3-15年，任何治理都管不了一辈子。生物酶、光触媒、纳米矿晶等所谓高科技基本都是心理安慰，智商税。

**假检测三大套路。** 第一关窗开窗文字游戏：治理前关窗测污染严重超标，治理后开窗测达标数字漂亮。第二低价检测加价治理：免费或几十块检测完就说你家超标，然后推销几千元治理。第三检测时间造假：检测要在密闭空间关窗12小时以上，不是随便测测。私人检测机构几十块就上门，准确性可想；真正有资质的CMA认证检测一次几百上千。

**送检报告的真相。** 环保检测并非零污染，而是单位面积没超过国家标准。单独板材合格不等于全家合格，单位面积环保不等于100平米堆积后环保。你家用100平方的人造板，每一块单独测都达标，叠加在一起总量就超标N倍。你去维权法院的做法是取你家一块板子检测，结果百分百符合标准，但你家整体超标这个官司你永远打不赢。

**低价引流加价套路。** 免费检测是私人机构为推销治理的引流手段，引导后续消费。先用低价免费吸引你上门，测出严重超标后推销几千上万的治理套餐，治理前报价低，治理中以各种理由加价：点位加密、加喷光触媒、复检费、保证金等层层叠加。零甲醛是商家卖货的话术，不存在零甲醛的装修建材。

**治理公司真相。** 甲醛治理属于智商税，控制装修源头甲醛比后续治理更有效。强化复合木地板、壁纸壁布、全屋定制柜子为最致命的前3类。事后治理多属无效甚至误导，真正有效方式是装修前预防并依靠持续通风及合理选材。

**通风才是唯一真正有效的除醛方式。** 装修完直接开窗，配合工业风扇对着窗口吹效率翻3倍。春秋全天通风，夏冬每天开窗≥4小时，甲醛释放温度大于19℃。窗帘沙发套先过水洗再装，甲醛溶于水。温度25℃+湿度70%时加速通风，甲醛释放最快。你家窗户才是除醛神器，开发商免费送的。

**预防大于治理。** 装修前独立思考用合理花费优先控制关键污染源，公共区域因常通风可降低影响，婴幼儿房用金属衣柜。墙面用乳胶漆最环保，地面有矿纯实木刚需木纹砖或柔光瓷砖。装修需要的不是治理，是从源头控制。

**记住两句话。** 环保不等于零污染，叠加后必然超标。甲醛只能预防不能治理。检测报告那是样品不是你家用的板材，治理公司管不了一辈子的甲醛释放周期。免费检测是套路，通风是免费解药。
