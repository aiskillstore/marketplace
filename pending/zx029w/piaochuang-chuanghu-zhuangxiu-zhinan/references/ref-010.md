# 家里有小孩，装修安全需要注意什么？

装修应保障孩子安全与健康。 孩子的安全与健康是第一优先级，成人的审美喜好需为此让步。

十防建议是孩子安全核心。 防玻璃伤：室内不要使用大面积玻璃和镜子。防磕碰伤：家具边角和把手不留棱角锐利的边。防倒压伤：玩具架书架不易太高要放稳。防门夹伤：低矮的玻璃门和平开门很危险。防坠落伤：窗口落地窗和阳台窗口要安装安全栅栏。防滑摔伤：地面材料注意防滑地毯固定。防缠绕伤：窗帘绳的长度注意。防窒息伤：封闭衣柜橱柜书柜设计通风口。防电击伤：电源插座选用带插座罩的。防污染伤：注意装修材料造成的室内环境污染。

家具地面防滑。 沙发四周茶几电视前最易滑倒，尽量选柔软无尖角家具。家具边缘尖角加装圆弧角防护棉垫。防滑倒地板不要打蜡，铺设材质避免石材选弹性塑胶地砖。孩子活动区地毯下面加止滑垫。床缘床尾放附止滑垫踏脚垫。玩具衣物收拾整齐以免绊倒。

卧室厨房安全。 不要让孩子单独留高床上睡觉以免醒来慌张跌落。床边床尾放止滑垫踏脚垫，被单裙摆不要过长。厨房门锁作好安全措施以免孩子乘家长不注意进入，随时擦水渍油渍保持干燥，锅碗瓢盆用完归位。餐桌料理台加装圆弧角防护棉垫。

电源插座和窗户安全。 电源插座选安全的那种，孩子能够着的都装防护套。装修时一米五以下设施注意牢固。窗户边不能放置家具，窗户需锁上。不能在窗边放床椅子等孩子可爬上去家具，业主平时一定要将窗户锁好不能让孩子轻易打开。有娃家庭优先考虑封窗避免暴雨台风和安全隐患。

环保健康放第一。 有小孩装修千万不能以大人喜好来，小孩子免疫力低下对装修污染没有抗拒力。地面优选瓷砖或纯实木警惕大品牌包装控制全屋定制污染，墙面用乳胶漆别用硅藻泥壁纸。备孕或婴幼儿入住卧室用金属衣柜加PP抽屉替代甲醛少90%，小孩即将分房的主卧和儿童房用实木其他人造板。窗套哑口套入户门套能不做就不做减少建材堆积。装修前独立思考用合理花费优先控制关键污染源。

施工安全不能马虎。 严禁未成年人进入工地，高风险施工亲自监工，每日撤场关闭水电总阀。

记住。 装修从空间布局到材料选择均优先考虑儿童特殊需求，环保健康放第一安全防护放第二颜值放第三。孩子不是缩小版的成人，他们有独特需求和风险，装修需要为他们让路。
