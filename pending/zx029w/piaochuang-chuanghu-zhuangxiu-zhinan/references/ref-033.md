# 水电改造两个绝招，照着做，想被坑都难！

网友@超能猫：建面160平的房子自装的，外面散工电工，因为不懂行情，也因为自己没有时间，让工人包工包料，当时口头承诺一万左右水电没有问题，结果水电完了单子出来直接傻眼，甚至比小区装修公司贵很多。
装修肯定是有捷径的，任何行业都会有不为人知的秘密，只不过因为利益原因或者其他不可告人的原因，内行人不愿意透漏而已。掌握这些捷径或者利用这些方法，往往就会让装修事半功倍。
北方水电是按照米数计算的，你以为随口给你说的几千搞定，真的就能搞定？你如果太过于自信，自己预算不足，还不想独立思考，多半水电第一步会坑到怀疑人生！
北方水电按照米数计算，也无法直接计算到预算里头。除非双方以大概的价格直接包死，但是这样的方式不公平，因为压根不知道实际要求的包死做法，施工方只能尽最大能力去压低成本。而业主会尽最大能力加大施工量，这就是两个不可调和的矛盾，一般都会存在中途扯皮和停工的风险！
包死费用的做法，必须两方详细交底，确定了所要做的项目以后，在不增加不减少项目的情况下，谈一个双方都能认可接受的价位，这才是水电费用包死的前提。
风险规避①：不要把水电签到合同里头。
因为签合同之前是不会现场交底的，不如直接把水电提出来，反正预算里头又不包含水电费用，为什么要用装修合同制约水电呢？
一旦忽视把水电签进合同，后期交底估价过高（前提是会给你估价）业主无法承受，此时无法单方面毁约，等于自己把自己绑死了；如果没有签进合同的话，估价过高会有第二条退路，哪怕单独找人做水电，都是自由的。
风险规避②：交底一定估价谈实际出入。
水电交底，实地说清楚你要改造的位置，同时结合方案把水电位置现场做标记。最后让水电工根据标记位置测量尺寸要求估价。
例如水电工根据双方交底的要求估价9000元，此时一定切记谈实际出入，例如上下五百差。也就是水电按照交底的要求，施工完毕实际测量，如果测量总价比9000少，按照少的支付，如果测量比9000多，以上下伍佰元差为标准，哪怕测量总价是两万，业主只需要付9500元。
一定要注意，在签订合同之初，必须把水电估价谈实际出入写进合同里头，而且不要把水电签进合同，一定注明：水电实际交底估价，估价过高，甲方可以自行水电施工，而不产生违约。
不要相信谈方案时候的随便估价，一定要交底以后知道做的项目，专业水电工现场准确估价谈实际出入。
这个事情一定是你找装修公司咨询必须问的事情，如果水电不给你估价，就会导致：你以为几千搞定，完了成了几万，你不得不乖乖掏钱，而且毫无办法！这样的装修机构坚决不要找。
总结：不论你是找装修机构还是散工自装，都一样做法。散工虽然不签订合同，但是一定要估价谈实际出入，否则过路客做法，能宰一家是一家，比装修机构更离谱。
