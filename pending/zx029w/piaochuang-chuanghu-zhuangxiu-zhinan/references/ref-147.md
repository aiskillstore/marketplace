# 平窗的四种改造，你家都浪费了11.16

家有飘窗当然是好事情，但是得会改造，否则就浪费了。今天看看一些比较实用好看的飘窗改造案例，给装修提供一些灵感。

一、落地窗/平窗造飘窗
家里没有飘窗，但是有落地窗和平窗
完全可以改造成飘窗兼收纳

▲上图其实就是一个平窗，但是卧室空间大，于是造平窗下方做了飘窗柜收纳，右边实墙高柜收纳，左边侧墙隔板收纳，同时上头局部造型顶，营造一个惬意的休闲空间。美观而且实用

▲这个就是凹陷落地窗，下方直接做成飘窗地柜，成就飘窗和收纳。同时做了白色的飘窗窗套。注意上头铺什么得考虑好《飘窗铺什么，看你做什么用，否则全错了6.9》

▲同样是落地窗，不包窗套，做了飘窗收纳柜，石材铺贴，成就休闲区，同时飘窗上方辅助光照明《飘窗配灯，飘窗更漂亮了11.8》

▲这个就是超大的平窗，直接拉通做了飘窗地柜，上方做上舒服的垫子，就是一个完美的休闲飘窗了。头顶局部吊顶，辅助光照明

二、飘窗成就衣柜
平窗/落地窗可以成就飘窗
不仅仅是做地柜，还可以做成衣柜收纳

▲落地窗凹陷区，矮柜成就飘窗，旁边实墙位置刚好衣柜收纳。L型收纳柜成就飘窗和衣柜，一举两得。

▲卧室中间是平窗，两边实墙做成收纳衣柜，中间矮柜成就休闲飘窗，不仅美观还能满足储物

▲跟上一图类似，只不过做了平板的隐形把手柜门，窗帘只需要在飘窗制作，还节省了费用

▲落地窗居于一侧，利用墙面多的一边做衣柜收纳，矮柜成就飘窗，侧墙少的地方做镂空书架。有一点需要格外注意：做飘窗衣柜最好局部吊顶，否则通顶太显得压抑。

三、平窗/落地窗，成就L飘窗书桌
这个很好理解，就是原来的平窗或者落地窗
不仅可以改造成飘窗，还能成就书桌功能
休闲和学习都有了

▲本来是平窗，下方做矮柜成就飘窗休闲，侧墙与矮柜垂直放置书桌，小型书架收纳，学习休闲两不误，合理利用了空间。同时书桌可以代替床头柜功能。改造成就三种功能。

▲同样是平窗空间，矮柜成就飘窗，侧墙书桌书柜一体与矮柜一体定制，学习和休闲都有了

▲平窗居中，矮柜成就飘窗，一边高柜衣柜收纳，另一边侧墙横向成就书桌，同时兼顾床头柜功能

▲平窗下方矮柜实现飘窗功能，侧墙横向小书桌一体定制，书桌背后小隔板壁龛充当书架，空间更合理，功能更多

▲凹陷区平窗，矮柜成就飘窗功能，侧墙横向制作小书桌，成就学习空间，同时兼顾床头柜功能，上方小吊柜书架

▲卧室阳台窗户下方地柜成就飘窗，侧墙书桌以及书架成就学习空间

▲平窗下方飘窗柜收纳，侧墙高柜收纳。另一边横向书桌设计，吊柜储物

▲平窗下方矮柜以及高柜收纳，平板隐形柜门，侧墙小书桌书架学习空间，且兼顾床头柜功能

四、平窗/落地窗，成就一字型飘窗书桌
这个也是飘窗书桌，只不过是一字型排列

▲平窗一半矮柜成就飘窗，一半与矮柜一体定制成书桌，两个功能都有了

▲平窗居于一侧，下方矮柜成就飘窗，右边书桌连体定制，成就两种功能

▲凹陷区平窗，一半飘窗柜，一半书桌，侧墙还做了壁橱收纳，同时折叠隐藏镜子功能

▲凹陷区平窗，一半矮柜一半书桌，休闲和学习都有了

▲平窗下方一半矮柜一半书桌，成就两种功能

▲平窗下方书桌矮柜成就两种功能

▲平窗下方矮柜书桌或者梳妆台，成就各种功能

▲平窗下方成就飘窗书桌，同时侧墙高柜收纳

▲平窗下方成就矮柜飘窗和书桌，同时侧墙收纳壁橱

▲平窗下方隔板书桌，旁边侧墙书柜一体，两种功能，整体木色温润

▲平窗做矮柜成就飘窗，旁边书桌书架设计。不同的是局部做了吊顶，拱形造型整体设计，浑然一体
