# 阳台非落地窗，窗帘到底怎么做？

你家阳台有半截墙吧？窗帘做了一半，拉也不是，不拉也不是。花了钱，住进去总觉得哪里别扭，又说不上来。我帮你看过了，九成业主都做错了——不是你不会选，是没人告诉你该怎么选。

半截墙配半截纱帘，窗帘不浪费，听着好像挺搭？其实最别扭。纱帘天生就该落地，那种轻飘飘的飘逸感，截一半就没了，说不上错，但就是不好看。半截墙想做半截窗帘？百叶帘才是它的朋友，透光、隐私、颜值，一个不落。

百叶帘、香格里拉帘、罗马卷帘，随便挑一个，都比半截纱帘高级。想要自然感→木百叶，光影温馨到你想坐一下午。想要轻巧感→分段式百叶帘，内开窗也不影响通风。想要收纳+颜值→半截墙下方做矮柜，上方明装百叶帘，功能颜值全拿走。

有人客厅不装布帘，搬到阳台装了——拉上以后光线昏暗，这不是给自己添堵吗。厚布帘一挂，阳台变小、变暗、变沉，钱花出去换来一堵墙。还有窗户很小也做满布帘的，又费钱又压缩空间。阳台的窗帘，轻、透、够用就好。

半截墙配窗帘，记住三句话就够了：纱帘要落地，百叶配半截，布帘别上阳台。窗帘选对了，你家阳台才是真的通透又好看。装修避坑的更多内容，可以去看看「从学到装｜装修课堂」知识库。
