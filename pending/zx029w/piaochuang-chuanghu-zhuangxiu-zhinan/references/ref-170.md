# 飘窗铺什么，看你做什么用，否则全错了6.9

前面写过一篇飘窗窗台的文章，可以参考《装修房子，窗台铺什么材料好？5.22》

飘窗铺什么，这个在于个人爱好，你喜欢哪个都是可以的。
比如铺石材：

▲飘窗铺石材的目的是什么？首先是美观，其次是为了避免忘记关窗户雨水进来，还有为了入住以后养点绿植方便。

▲铺马赛克也是可以的，和石材一样道理，花样更加丰富

这里就注意了，你家能不能铺石材就得考虑清楚了，如果是为了怕雨水侵入，养花需要，不用说直接用石材或者马赛克就可以。

▲铺木地板，首先肯定不是为了防止雨水侵入，否则谁敢用木地板，当然也不是为了养花需要，此处只是为了木地板的温暖感，后期入住可以随时坐卧，眼观八方，为了一种生活情调而已。所以你如果是为了休闲坐卧，就不要铺石材或者马赛克了，那么冰冷，冬天你坐得下去吗？夏天看起来也是冷冰冰。

▲注意上图，大部分家里都这样做了，好看又实用。关于飘窗垫子可以参考《家有飘窗绝对不能太丑，学问都在这3.3》

此处注意了，如果你家后期准备做飘窗垫子，那你做石材有什么用？谁看得见你家高档的石材？那你做那么好的石材不是浪费吗？如果你装修本身经济紧张，此处更不应该铺高档石材，然后做个垫子盖上，有什么意义？

所以，如果打算后期入住做飘窗垫子的，直接用你家客厅的大地砖随便铺上就行，后期做好垫子盖上了，谁知道你家飘窗铺的是瓷砖？这就是装修中该省钱的省，不该省钱的不省。

还有千万不要飘窗铺了木地板了，后期再做个垫子，木地板本来就是温暖的木质，已经足够让你一年四季放心的坐上去了，你再做个垫子，等于把木地板浪费掉了。

所以总结一下，飘窗不要纠结铺什么，你应该先搞清楚自己后期需要做什么，是养花？休闲坐卧？这个搞清楚了，铺什么的问题迎刃而解了。
