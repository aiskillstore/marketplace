# 87m²老房改造，几乎砸掉所有墙体，开放简洁通透设计

是套老房，格局不好，而且过去的装修方式导致光线更差。小两口喜欢明亮简洁，而且尽量开放通透的效果。

▲这是原始的结构。门厅有单独的入户门厅还带一个小的生活阳台。门口的厨房很突兀，导致过道很窄，进门感觉非常不舒服。卫生间很小，没有单独淋浴地方，浴柜也很小。红色的区域就是准备彻底砸掉的墙体，让空间大变样

▲设计后的布局图纸，把所有能砸掉的厚重墙体都砸掉了。入户门厅和生活阳台打通，采光和视觉都通透了，而且做成了一个很小的书房空间。原来的景观阳台作为生活阳台使用。厨房墙体彻底砸掉，全部用玻璃代替，进门空间和视觉都不会压抑。而且成就了过道超大收纳柜。牺牲次卧一部分，成就卫生间单独淋浴空间。餐厅和次卧之间墙体改用薄墙新砌，成就冰箱的合理放置

▲未拆除之前的样子，因为装修老旧导致光线和收纳都无法满足使用

▲进门右手的入户门厅和原来的小生活阳台打通，空间和光线都好了。定制鞋柜以及换鞋凳收纳，最里头镶嵌小的书桌，成就一个单独的小书房空间。牺牲厨房墙体镶嵌小的书架布置，整体木色和白色套色，满足业主的清新需求。而且厨房和入户厅玻璃窗整体开放通透

▲一个人在书房，一个人在厨房，两边玻璃窗户通透，视觉光线都做到了通透

▲原来的厨房墙体砸掉全部做了玻璃墙体，视觉和光线都通透敞亮。而且墙体变薄以后，过道定制了超大的收纳柜，满足更多收纳。餐桌背景牺牲次卧墙体实现了镶嵌冰箱，旁边同样地柜西厨收纳

▲玻璃墙体让厨房开放，同时又解决了油烟问题，一举两得

▲也可以把餐桌靠近玻璃墙放置，腾出更多过道空间

▲过道上超大收纳柜，局部镂空做展示柜使用，灯光点缀，颜值非常高。

▲整面墙的收纳柜，白色与木色套色清新，局部镂空玻璃门展示区，放上精美摆件，可以当做进门的端景了

▲很小的餐厅，餐桌刚好满足四人同时就餐。斗柜收纳，冰箱放置，功能非常齐全

▲L型厨房布局，白色的瓷砖清新简洁，木质地柜与白色吊柜清新对比，黑色移门窗户质感搭配，视觉上不仅清新而且质感十足

▲厨房的玻璃墙体移门打开以后，就是一个彻底的开放式厨房，空间和视觉立马敞亮无比
