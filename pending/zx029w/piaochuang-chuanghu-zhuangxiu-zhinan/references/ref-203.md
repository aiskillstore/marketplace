# 145m²现代原木风，通铺大木纹砖，全屋没有一张床，全部打造榻榻米

经典竖厅户型。南向客厅，北向厨房南北通透明亮。全屋现代原木风设计，全屋通铺大规格木纹砖。入户门门窗都没换，质量一般但是我用几十年也没问题～ 入户门换了智能锁；洞洞板全身镜应有尽有入户只有120cm，进门左手边果断挪墙，定制了35cm深的鞋柜～客厅铺了大片木纹砖，是原木风没有翻车的关键，大片砖也省下了很多美缝的钱⚪️🟠⚫️的色彩搭配，大面积的白色，大面积木色和小面积黑色，有原木风的温馨温润，也有现代风的大气。木纹砖通铺并打通阳台，开阔视野，即使采光差，也看起来很温馨。电视背景墙做了造型，阳台角做了弧形，给家里增添点设计感。搭配黑色线条，有了现代原木风的感觉。搭配双层纱窗帘和弧形门洞有了轻法式的感觉。全屋木门有了日式原木风的感觉全屋定制做满，能打柜子的地方都打了，实用又高级。客厅很宽敞，阳台我做了抬高12公分，给客厅做了分区，以后在这里摆个茶桌，晒着太阳喝茶吃果子不要太惬意～选浅色，浅色沙发反色后使整个空间明亮不压抑，选的是治愈米，家里还多了些温馨感；经典豆腐块造型沙发，客厅就看起来干干净净，很是耐看选拼接款，房子只有一套，软装容错率很低，沙发也不可能频繁换。选个拼接款，随时可以变换格局～常换常新餐厅很小，选择了可伸缩的岛台餐桌，可大可小，人多人少皆宜。对于低楼层而言，墙顶通刷这个颜色
并不会让光线变暗，
反而增加了温柔感
略带灰度的奶油米白色，上墙高级有格调阳台地台是抬高了12公分，里面是红砖+水泥，没有留灯带。榻榻米做了两层台阶，有公主回房的仪式感，榻榻米是可以上翻打开储物的，不常用的杂物可以放进去，收纳满满。女儿房墙顶通刷了乳胶漆。很温柔～做了两个弧形门洞，给睡眠和学习做了分区，有了轻法式风格的高级感，也有安全感。拱形门和飘窗阳角，都用了可弯曲弧形阳角条，提前买好，油工给做上。防碰撞，又好看。衣柜做了折叠门➕金属衣架。环保又好用。金属架我买的成品，和主卧一起买了六米才不到1000块，还可以定制。书桌宽60，长1.5米。桌角也做了圆弧，保证美观的同时防磕碰。卧室都很小，都做了榻榻米，北方不怕生虫，做出来的效果又美又实用，摆个床垫子就能睡小书房比较简单，空间很小，做了双人位的书桌，书房外面就是生活阳台，安排晾衣洗衣功能用了比较贵的实木做了折叠门，但是认为虽不上档次，但是巨实用的金属衣柜值得推荐，柜子总长4.2米，衣架要用4.05米。两头需要预留空间方便安装厨房的瓷砖很随意的选了个浅色。但是，橱柜跟特意的选择了上浅下深的配色。加上黑色线条，太好看了！
