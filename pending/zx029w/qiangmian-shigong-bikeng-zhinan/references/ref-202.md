# ✅西安装修课堂每日一讯【装修关键词之腻子】7.8

相比“耐水腻子”来说，“防水腻子”更有噱头：“耐水”有什么用啊，墙又不是在水里泡着；“防水”多容易理解啊，还容易博取业主好感。可是您知道吗，这“防水腻子”压根就是个商业陷阱，啥叫误导消费者，“防水腻子”就是个典型！
先讲正确的、不容易被奸商利用的叫法，“耐水腻子”。
“耐水腻子”这个词是从哪来的呢？从国家制定的行业标准！《建筑室内用腻子》（JG/T3049-1998）中明确规定了达到那些指标的腻子才能称作“耐水腻子”。
那么“耐水腻子”具有什么特点，为什么要叫“耐水”呢？应该说，“耐水”是一个集合了专家们的智慧，并准确表达了这种腻子特点的称呼。“耐水腻子”的两大特点——“粘得结实”、“寿命超长”都可以从“耐水”一词中体现出来。
“耐水腻子”配方和普通腻子完全不同，正常情况下，它的粘接强度（衡量粘得是否结实的指标）可以达到0.5兆帕以上，是普通腻子的2倍；在水中浸泡48小时后，耐水腻子得拉拔强度依然高于0.3兆帕，而普通腻子为0兆帕（已经脱落了）。主要是防治发霉，提高墙体防水性能，比一般的腻子耐水侵蚀，减少脱落。主要是防治发霉，提高墙体防水性能，比一般的腻子耐水侵蚀，减少脱落。
水汽无处不在，空气中有，墙体里也有，如果腻子遇水就会溶解，粘得怎么会结实呢？使用寿命怎么可能长得了呢？
耐水腻子又有什么缺点呢？一是造价高。二是耐水腻子上墙未干透存在碱性。耐水腻子要利用灰钙（主要成分有CaO，生石灰）遇水及二氧化碳的一系列复杂反应使自身的强度提高，这其中会产生有一定碱性的氢氧化钙，而且这种碱性一般要持续5-7天才会消失。这种碱性如果控制不好，会令施工者有灼烧得感觉，三是用耐水腻子必须用抗碱底漆，而且还可能会使面层乳胶漆的色浆分解，导致颜色不均。
返回来，再说说靠蒙人起家的“防水腻子”！
有很多“专家”都说，“防水腻子”就是“耐水腻子”，一样的——错！大错特错！
“防水腻子”是一种流传在“民间”的叫法，到底是个什么东西完全没有任何书面的定义。最早的时候，“防水腻子”指的是“仿瓷”（也叫刮瓷、瓷膏），现在有很多地区仍然说“仿瓷”就是“防水腻子”。“仿瓷”的确能“防水”，空气中的水汽是不怕了，可墙体里的水汽也出不来啊，久而久之，“仿瓷”就会被墙里的水汽拱起来，造成空鼓。除了“仿瓷”之外，一些达不到“耐水腻子”标准的普通腻子，为了抬高身价，也宣称自己是“防水腻子”，无据可凭，肆意自封，滥竽充数，鱼目混珠啊！
很多人都觉得“防”是个很好的概念，殊不知“水可疏而不可堵”，只会“防”是不行的，“防不胜防”啊！那应该怎么办呢，要“耐”！“耐水腻子”并不阻挡水汽的进出，它的结构很特殊，表面虽然致密，但却留有很多可供水汽出入的孔道，墙体可以自由的和空气进行水汽交换，可谓“呼吸通畅”！
如果以后再有“专家”在你面前提起“防水腻子”，那你要注意了，这个“专家”说不定就是个冒牌货，至少他没你想象的那么专，可能是“砖”家！
