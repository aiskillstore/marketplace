# Editing decision guide

Use this guide only when a request leaves the editing boundary unclear.

## Choose the mode

| Request | Mode | Return |
|---|---|---|
| "Clean this up" | Edit | Corrected draft only, unless the change is substantial. |
| "What feels off?" | Detect | Brief findings with quoted evidence. Do not rewrite. |
| "Keep this casual" | Edit, light touch | Correct only clear mechanical patterns. |
| "Prepare this for publication" | Edit, full check | Corrected draft, then a concise revision note if requested. |

## Keep the boundary

- Preserve the writer's facts, stance, and intended level of directness.
- Flag a factual error instead of silently repairing it when verification is missing.
- Keep deliberate fragments, slang, and rough edges when they belong to the voice.
- Do not make a draft longer merely to sound more complete.

## Decide what to report

- For a post, reply, or short email: return the corrected text only.
- For a longer document: add one plain sentence stating the categories corrected.
- For an unresolved choice: quote the line and explain the concern in one sentence.
