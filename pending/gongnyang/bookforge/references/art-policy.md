# 생성 아트 정책 — 표지·도비라 이미지 규칙

## 무텍스트 절대 원칙

생성 이미지 안에 문자·숫자·로고·워터마크·간판 글자가 있으면 폐기하고 재생성한다. 프롬프트에 항상 다음을 포함한다:

```
no text, no lettering, no typography, no logo, no watermark, no signage
```

글자는 언제나 조판 레이어(테마)가 벡터로 얹는다. 생성 이미지 위에 코드로 글자를 후처리 합성하는 것도 금지 — 텍스트가 필요하면 프롬프트를 고쳐 재생성한다.

## 스타일별 아트 사용처

| 스타일 | 표지 | 본문 |
|---|---|---|
| practical | 벡터 타이포(아트 불필요) | 도해는 SVG만 |
| insight | 벡터 회로 그래픽(아트 불필요) | 장 전환부 감성 컷(블루 단색조·저채도) 선택 |
| academic | 타이포 전용, 아트 금지 | 벡터 도해만 |
| essay | 소형 정물 오브제 1점(선화·수채·콜라주 중 택1), 폭 = 지면의 38~52% | 원칙적으로 무이미지 |
| business | 벡터 기하 패턴 기본, 추상 아트 선택 | 벡터 차트만, 사진 금지 |
| magazine | 풀블리드 아트 필수 | 스프레드당 1컷 권장, 룩(조명·색온도) 이슈 단위 통일 |

## 배치 방법

- 표지 아트 파일명: `<book_dir>/assets/cover.png` (HTML 트랙은 자동 인식) / essay는 `assets/cover-art.png`
- 해상도: 풀블리드 표지는 긴 변 3,000px 이상, 본문 컷은 배치 폭 기준 300dpi
- 인물은 실존 인물 유사성 금지, 브랜드 로고·실제 제품 형태 모사 금지
- 생성 이미지가 실린 책은 판권면·캡션에 생성 이미지 사용을 표기한다 (예: `AI 생성 이미지`)

## 생성 수단

환경에 있는 이미지 생성 수단을 쓴다. Codex 환경이면 `$imagegen`, Claude Code면 사용 가능한 생성 도구 또는 codex-imagegen 스킬. 후보 3컷을 생성해 가장 나은 1컷을 고르고, 3컷 모두 무텍스트 원칙을 어기면 프롬프트를 수정해 재생성한다. 수단이 없으면 벡터 폴백(각 테마의 기본 표지)으로 진행한다 — 아트 없이도 모든 표지는 성립한다.
