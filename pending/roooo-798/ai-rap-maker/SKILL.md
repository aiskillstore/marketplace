# AI Rap Maker

## Songs and instrumentals

1. Turn the user's idea into a short brief with a narrator, a concrete scene, and the feeling the track should convey. For supplied lyrics, preserve their wording unless asked to edit it. Use `[Verse]` and `[Hook]` labels where they help establish structure, and respect any language or content preferences.
2. Open the [AI rap generator](https://airapmaker.app/) and find **Create a rap song**. Choose **An idea** for a brief (up to 3,000 characters) or **My lyrics** for existing bars (up to 5,000 characters). The [AI rap lyrics generator](https://airapmaker.app/ai-rap-lyrics-generator) has examples for writing from a brief.
3. Pick the requested style, mood, and energy. The style options are Trap, Boom Bap, Drill, and Melodic Rap. Select **Instrumental only, no vocals** for a beat. Use **Export draft** if the user wants the setup without audio.
4. Use the visible site flow for generation. Let the user handle sign-in and confirm any credit spend or checkout before submission. Check the quote shown in the current session. After submitting, check **Your tracks** for the requested job. Play or download a completed take if requested. Check the existing job before retrying a pending or interrupted request.

Example brief: “A night-shift cook taking the last train home, proud to have paid rent on time. Mention the grease on their sleeves and the empty platform. Boom bap, focused mood, balanced energy.”

## Short rap videos

1. Open the [AI rap video generator](https://airapmaker.app/ai-rap-video-generator). Choose a hot template or **Song to video** with a track from the official library or the user's saved songs.
2. Prepare a short excerpt and the number of performer photos requested by the selected mode. Use photos of consenting adults and audio the user has permission to use. Let the user handle sign-in and confirm the site's permission statement and current quote.
3. Submit through the visible site flow after authorization. Check **Your videos** for the job and use the site's MP4 download when ready.

If only text is requested, return the lyrics or brief in chat. If browsing or generation is unavailable, return the prepared inputs, link to the matching official page, and report the last verified status. Report a generated file only after the site shows an actual result.
