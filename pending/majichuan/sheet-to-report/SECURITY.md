# Security Policy

## Supported version

Security fixes are applied to the latest public release.

## Reporting a vulnerability

Do not put credentials, private workbooks, personal data, internal paths, or confidential business figures in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Otherwise, open a minimal public issue that contains no exploit details or sensitive data and asks the maintainer to provide a private contact channel.

## Data handling boundary

The bundled scripts do not call an external model API. The AI tool that hosts this Skill may still read files supplied by the user, so users must review that tool's data-processing policy before using private data.
