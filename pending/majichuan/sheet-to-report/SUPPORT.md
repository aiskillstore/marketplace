# Support

## Where to ask for help

Use [GitHub Issues](https://github.com/majichuan/sheet-to-report/issues) for installation problems, reproducible defects, documentation questions, and feature requests.

For security vulnerabilities, follow the private reporting guidance in [SECURITY.md](SECURITY.md) instead of opening a public issue.

## What to include

Please include:

- The goal you were trying to complete
- Operating system and Python version
- Whether you requested HTML, standard PPT, or optional presentation refinement
- The command used and the full error message
- A minimal synthetic or de-identified sample when data is needed to reproduce the issue

Do not attach real customer records, employee data, credentials, API keys, or other confidential information. Replace sensitive values with synthetic examples.

## Support scope

Community support is provided on a best-effort basis. The publisher does not provide an availability guarantee or emergency response service.
