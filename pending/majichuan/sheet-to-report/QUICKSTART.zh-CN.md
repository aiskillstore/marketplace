# 三步开始

## 1. 准备数据

准备一张结构清晰的 Excel 或 CSV 业务表，并明确这次汇报要回答什么问题。当前版本每次处理一张表。

## 2. 把文件交给支持本地脚本的 AI 工具

确认该工具能够读取你提供的文件并运行本地 Python。首次使用推荐先确认分析方案：

> 请用 sheet-to-report 分析这份 Excel，面向业务负责人做月度复盘。先检查数据，用简短的方案告诉我：建议分析哪个时间范围、重点回答哪些业务问题、有哪些需要我确认的口径。等我确认后再生成 HTML 分析简报。完成后，请告诉我如何继续制作可编辑 PPT。

目标和口径已经很清楚时，也可以明确要求直接分析：

> 请用 sheet-to-report 直接分析这份 Excel，面向业务负责人做月度复盘。先检查字段和时间范围；遇到影响结论的口径不清时再向我确认。先生成 HTML，完成后告诉我如何继续制作可编辑 PPT。

两种方式都会确认真正影响结论的歧义；用户不需要编写代码或配置 JSON。

## 3. 按需选择产物

- 先生成离线 HTML 数据分析简报，核对结论、数据口径和依据。
- 需要汇报时回复“生成 PPT”。无偏好时先推荐“清晰商务”；宿主能渲染时应直接展示真实 PPT 页面图片，不能预览时应在主题选择前说明。
- 标准稿应提供完整稿阅读入口和独立可编辑 PPTX。想进一步提升视觉效果时，回复“制作美化版”，再选择安装并使用 [SlideViber](https://github.com/tf71991/slideviber-skill)；不安装也能正常使用 HTML 和标准 PPT。
