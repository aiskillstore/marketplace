# 换装机制库

优先偏好机制：M1、M2、M5、M8、M10。若用户明确说这些方案不错，推荐和改写脚本时应优先从这 5 种中选用。

仅在需要选择、替换或推荐换装方式时读取。

## M1｜鼠标点击 + 完整人物飞入重合

适合：拼贴图、悬浮人物贴纸、社交媒体互动。
动作：点击 → 复制完整人物作为飞入副本 → 原位置目标贴图立即移除并留空 → 副本斜向飞入中央并放大 → 与中央人物头肩腰和动作重合 → 换装后副本与虚线消失。
优点：因果最清楚，与“中央大人物 + 四周小人物”版式兼容性最高。
注意：飞入必须是完整人物抠像副本，不是衣服或矩形卡片；原位置贴图不得保留、弹回或再次出现。

## M2｜长袖 / 袖摆遮镜

适合：汉服、大袖袍、宽袖、披帛。
动作：挥袖或旋身 → 袖摆短暂遮挡主身体 → 遮挡峰值换装 → 袖摆离开后继续同一动作。
优点：最自然的古风换装之一，服装本身就是转场介质。
注意：不要让袖摆永久盖住脸。

## M3｜旋身接力

适合：汉服、礼服、优雅角色。
动作：目标小人物轻微高亮 → 主角同方向旋身 → 侧身/半背身时换装 → 转回正面。
优点：动作连续性最好，不依赖强特效。
注意：换装前后旋转方向和重心必须一致。

## M4｜披帛 / 丝带缠绕

适合：神女、仙侠、飘逸长裙。
动作：披帛从目标方向飞入 → 环绕肩、腰、裙摆 → 短暂遮挡 → 散开后完成变装。
优点：东方幻想感强。
注意：丝带必须有重力和惯性，不能像硬塑料。

## M5｜团扇 / 折扇遮挡

适合：古风贵女、雅致汉服。
动作：扇面掠过面部或上身 + 轻转身 → 遮挡峰值换装 → 放下扇面展示新造型。
优点：古典、克制、易控制。
注意：扇子不应凭空出现；若首帧无扇，可作为系统补全道具前先说明。

## M6｜花瓣 / 云纹 / 水墨扩散

适合：东方幻想、国风视觉、神女。
动作：对应小人物触发 → 花瓣/云纹/墨纹从该方向蔓延 → 覆盖服装主体 → 散去后换装。
优点：画面表现力强，不需要人物飞行。
注意：特效不能遮住人物脸太久。

## M7｜镜面 / 倒影同步

适合：清冷、高级时尚、镜面空间。
动作：倒影先出现下一套服装 → 主角与倒影动作同步 → 对齐点真实人物换装。
优点：高级、概念化。
注意：无镜面环境时不要强行使用。

## M8｜贴纸翻页 / 人物剪影翻转

适合：lookbook、拼贴、小红书式视觉。
动作：目标完整人物贴纸从边缘掀起/翻转 → 向中央贴合 → 贴合瞬间换装。
优点：强化平面设计与真实人物的混合感。
注意：贴纸仍必须是人体轮廓，不要变成矩形卡片。

## M9｜分身归位融合

适合：角色概念短片、多人格衣橱。
动作：对应分身向中央滑近或走近 → 与主角姿态重合 → 融合后服装切换。
优点：叙事感强。
注意：融合阶段要短，避免出现长期双重人物。

## M10｜步伐 / 跺脚 / 手势卡点

适合：现代穿搭、强节奏、灵动角色。
动作：脚步落地、手掌拍合、转身回正或抬手落下的动作峰值换装。
优点：节奏直接、适合快速变装。
注意：需要动作峰值清楚，不能无因果瞬切。

## M11｜发簪 / 耳饰 / 配饰触发

适合：古风人物、饰品识别度高的角色。
动作：人物轻触发簪、耳坠、腰佩 → 配饰发出短暂高光 → 光沿服装边缘扩散 → 换装。
优点：细腻、有角色感。
注意：核心发型和头饰如果要求始终一致，只改变“触发”，不要替换配饰本身。

## M12｜衣纹生长 / 刺绣蔓延

适合：汉服、金线刺绣、东方美学。
动作：从腰封或袖口出现纹样 → 刺绣沿衣料快速蔓延 → 原服装颜色/结构逐层变化 → 完成新造型。
优点：不是遮挡式，能突出服装本身。
注意：8 秒 4 次换装时要简化纹样动画，避免每次太长。

## 组合限制

短视频里不要一次混用超过 2 种主换装机制。
若 8 秒内需要 4 次变装：

* 最稳：统一一种机制
* 次稳：两种机制交替
* 不建议：四次都用不同机制

## 用户偏好方案（高优先级）

如果用户点名偏好以下方案，则按高优先级处理：

* M1｜鼠标点击 + 完整人物飞入重合
* M2｜长袖 / 袖摆遮镜
* M5｜团扇 / 折扇遮挡
* M8｜贴纸翻页 / 人物剪影翻转
* M10｜步伐 / 跺脚 / 手势卡点

### 推荐使用场景

* M1：最适合“中央大人物 + 四周小人物贴纸”的拼贴联动视频
* M2：最适合大袖汉服、宽袖袍、披帛感较强的古风换装
* M5：最适合清冷贵女、雅致闺阁、需要更克制古典感的变装
* M8：最适合平面设计感强、贴纸感强、lookbook 式内容
* M10：最适合节奏明显、动作爽点明确、平台传播感强的换装短视频

### 默认组合建议

* 稳定古风汉服：M1 + M2
* 古典贵女：M2 + M5
* 拼贴互动感：M1 + M8
* 节奏爽感：M1 + M10 或 M8 + M10
