Roboto Condensed
================

    RobotoCondensed-Regular.ttf
    RobotoCondensed-Bold.ttf

Modified files generated by un-editorial-check
----------------------------------------------

Apache License 2.0 section 4(b) requires modified files to carry prominent
notices stating that they were changed. This notice covers those changes.

A report generated by un-editorial-check embeds a **subset** of
RobotoCondensed-Regular.ttf and RobotoCondensed-Bold.ttf into a Portable
Document Format (PDF) file. The embedded subset is a modified copy of the
font above. The modification is made by `lib/ttf.mjs` and consists only of:

  * removal of every glyph that cannot be reached from a character in the
    WinAnsi range `U+0020`-`U+00FF` (192 of 1031 glyphs are kept, `.notdef`
    included), and the remapping that follows;
  * removal of the OpenType shaping tables `GPOS`, `GSUB`, `GDEF` and `STAT`,
    which a portable document format file using `WinAnsiEncoding` never reads,
    because no shaper runs on its text;
  * the rewriting of `cmap`, `loca`, `hmtx`, `head`, `maxp` and the table
    directory that the two removals above require.

No glyph outline is altered. Nothing is added. The subset is produced
deterministically from the source file: the same source bytes always yield the
same subset bytes.

The two source files in `fonts/` are distributed unmodified.

The font itself is not required for a report to be read - a viewer needs only
the embedded subset - but the source files and this notice are retained here
so that the embedded copy remains traceable to its origin.
