# D3.js 适配器

## 用途
- 像素级定制、特殊图形/投影、动态更新、数据艺术。

## 映射

### 颜色
```javascript
const colorPalette = ['#4269d0', '#3ca951', '#ff725c', '#a463f2', '#efb118',
                       '#6cc5b0', '#9696a0', '#f5a623', '#ca5bb8', '#ff8ab7'];

// 分类色板比例尺
const colorScale = d3.scaleOrdinal(colorPalette);

// 顺序色板
const sequentialScale = d3.scaleSequential(d3.interpolateBlues)
  .domain([minValue, maxValue]);
```

### SVG 画布设置
```javascript
const margin = { top: 48, right: 36, bottom: 56, left: 56 };
const width = 800 - margin.left - margin.right;
const height = 500 - margin.top - margin.bottom;

const svg = d3.select('#chart')
  .append('svg')
  .attr('width', width + margin.left + margin.right)
  .attr('height', height + margin.top + margin.bottom)
  .style('background-color', '#FFFFFF')
  .style('font-family', "'Helvetica Neue', Helvetica, Arial, 'PingFang SC', 'Microsoft YaHei', sans-serif")
  .attr('viewBox', `0 0 ${width + margin.left + margin.right} ${height + margin.top + margin.bottom}`);

const plot = svg.append('g')
  .attr('transform', `translate(${margin.left},${margin.top})`);
```

### 排版
```javascript
// 标题：以完整 viewBox 居中
svg.append('text')
  .attr('class', 'chart-title')
  .attr('x', (width + margin.left + margin.right) / 2)
  .attr('y', 24)
  .attr('text-anchor', 'middle')
  .attr('font-size', 16)     // h1
  .attr('font-weight', 600)
  .attr('fill', '#1A1A1A')
  .text('Chart Title');

// 轴标题
svg.append('text')
  .attr('class', 'axis-label')
  .attr('font-size', 11)     // h3
  .attr('fill', '#333333')
  .attr('text-anchor', 'middle');

// 刻度标签
plot.append('g')
  .attr('font-size', 10)     // h4
  .attr('fill', '#666666')
  .call(d3.axisBottom(xScale));
```

### 顶部图例安全带

图例独占标题与绘图区之间区域，按完整 viewBox 居中，距绘图区 ≥20px。

### 线条
```javascript
// 折线
const line = d3.line()
  .x(d => xScale(d.x))
  .y(d => yScale(d.y))
  .curve(d3.curveMonotoneX);   // 平滑曲线

plot.append('path')
  .datum(data)
  .attr('fill', 'none')
  .attr('stroke', colorScale(0))
  .attr('stroke-width', 2)     // line width
  .attr('stroke-linecap', 'round')
  .attr('stroke-linejoin', 'round')
  .attr('d', line);

// 网格线
d3.axisBottom(xScale)
  .tickSize(-height)
  .tickFormat('');

plot.append('g')
  .call(/* ... */)
  .attr('stroke', '#E0E0E0')
  .attr('stroke-width', 0.5)
  .attr('stroke-dasharray', '2,2');
```

### 散点
```javascript
plot.selectAll('.dot')
  .data(points)
  .enter()
  .append('circle')
  .attr('r', 4)               // scatter radius
  .attr('fill', d => colorScale(d.category))
  .attr('fill-opacity', 0.8)   // scatter opacity
  .attr('stroke', '#FFFFFF')
  .attr('stroke-width', 0.5);
```

### 柱状图
```javascript
const barWidth = xScale.bandwidth() * 0.7;  // width_ratio

plot.selectAll('.bar')
  .data(data)
  .enter()
  .append('rect')
  .attr('x', d => xScale(d.category) + xScale.bandwidth() * 0.15)
  .attr('width', barWidth)
  .attr('fill', colorScale(0));
```

## 约束

1. 数据绑定用 `.join()`，覆盖 enter/update/exit。
2. 过渡默认 `transition().duration(800).ease(d3.easeCubicOut)`；支持低动态模式。
3. 响应用 `viewBox` 或 resize 重绘。
4. SVG 加 `<title>`、`aria-label` 与键盘入口。
5. 数据点 >5,000 时考虑 Canvas。
