# 布局规则

优先数据，弱化轴/网格/装饰；以完整画布校准标题、图例、主体与导出边界。

## 基线

| 项目 | 规则 |
|---|---|
| 数据墨水 | 无背景色块；网格最浅最细；去无用边框 |
| 视觉层级 | 数据、轴/刻度、标题/标签、网格/参考线 |
| 宽高比 | 默认 1.6；时间序列 2.0；小倍数 1.0；地图保投影比例 |
| 内容占比 | 绘图区 65–75%；标题/标签 15–20%；图例 5–10% |
| 标准边距 | 上/右/下/左 = 48/36/56/56px |
| 紧凑边距 | 32/24/40/48px |
| 多图间距 | 28px |

### 画布居中硬约束

- 主标题 `anchor = canvas`，x = 完整画布 50%。
- 图例按完整画布水平居中；标题、图例、绘图区、外置标签留安全距离。
- 紧裁切后检查可见内容边界；补齐不对称留白。
- Word/PDF/论文优先视觉居中，不追求最小边界。

## 自然语言映射

| 指令 | 调整 |
|---|---|
| 留白多 | 边距 ×1.3；间距 ×1.2 |
| 紧凑 | 边距 ×0.75；间距 ×0.8 |
| 宽屏/正方形 | 宽高比 2.0 / 1.0 |
| 移动端 | 应用 mobile 字体与边距缩放 |
| 图表/标题居中 | `title.anchor = canvas`；导出后查视觉中心 |
| 图例离远 | 图例到绘图区 ≥20px；必要时增上边距 |

## 网格与多图

| 宽度 | 列数 |
|---|---|
| ≤640px | 1 |
| 641–1024px | 2 |
| >1024px | 3–4；不得超过 4 |

- CSS Grid/Flex 使用 `align-items: start`；卡片 padding、margin、高度与标题基线一致。
- 共享 Y 轴时范围一致，只保留外侧轴标签；同排图宽度一致。
- 共享图例适合 ≤4 个相关图；更多时分组或局部图例。
- 间距按 4/8px 网格；常用 24、28、32、40px。

## 响应式

| 断点 | font_scale | margin_scale |
|---|---:|---:|
| ≤640px | 0.85 | 0.70 |
| 641–1024px | 0.92 | 0.85 |
| >1024px | 1.00 | 1.00 |

```json
"spacing": {
  "chart_margin": { "top": 48, "right": 36, "bottom": 56, "left": 56 },
  "chart_margin_small": { "top": 32, "right": 24, "bottom": 40, "left": 48 }
},
"responsive": {
  "breakpoints": {
    "mobile": { "max_width_px": 640, "font_scale": 0.85, "margin_scale": 0.7 },
    "tablet": { "max_width_px": 1024, "font_scale": 0.92, "margin_scale": 0.85 },
    "desktop": { "max_width_px": 999999, "font_scale": 1.0, "margin_scale": 1.0 }
  }
}
```

- 单图可用宽度 `<400px`、移动端、侧栏或 3 列紧凑卡片：用 `chart_margin_small`。
- 缩放后关键文字不得 <9px；空间不足先减标签密度。
- 每个图表容器初始化前必须有非零显式高度。

```css
/* 桌面 */
.chart-container {
  font-size: 16px;
  padding: 48px 36px 56px 56px;
}

/* 平板 */
@media (max-width: 1024px) {
  .chart-container {
    font-size: 14.7px;  /* 16 × 0.92 */
    padding: 41px 31px 48px 48px;
  }
}

/* 移动端 */
@media (max-width: 640px) {
  .chart-container {
    font-size: 13.6px;  /* 16 × 0.85 */
    padding: 33px 25px 39px 39px;
    column: 1;  /* 单列布局 */
  }
}
```

## 焦点

- 关键数据大小不超过次要数据约 1.5 倍；高饱和色 ≤3。
- 焦点用 `highlight`；非焦点灰化或 opacity 0.2–0.3；参考线 opacity <0.5。
- 重要信息放左上/上方；排名降序；终点、极值靠近数据直接标注。
- 单一 KPI 可组合 20px/700、主题色、独立留白、目标参考线；动画必须尊重 `prefers-reduced-motion`。

## 检查

- 标题、图例、绘图区基线与卡片样式一致。
- 无竞争焦点；高饱和色 ≤3；辅助元素低权重。
- 移动端无裁切/重叠；共享轴尺度正确。
- 灰度/打印可辨；静态导出可见内容居中。
