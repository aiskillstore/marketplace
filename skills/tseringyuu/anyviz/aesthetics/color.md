# 色彩规则

以 `default.json` 为真值；先按数据类型选色板，再处理语义、对比、主题与品牌色。

## 选色

| 数据 | 色板 | 条件 |
|---|---|---|
| 分类 | `categorical` | 无顺序；单图 ≤7 类，硬上限 10 |
| 顺序 | `sequential` | 有高低；精确、色盲、打印优先 Viridis |
| 发散 | `diverging` | 围绕 0、均值或目标双向变化 |
| 高亮 | `highlight` | 目标、预警、基准、焦点 |

- 饼/环图 ≤5 色；高饱和色 ≤3 种/图。
- 类别 >10：保留前 8–9 类并合并“其他”；有层级时用同色相明度梯度；必须保留时叠加线型、点型或纹理。总数仍应 ≤12，否则分组或小倍数。
- 顺序色板至少 5 级；禁止彩虹色板。

## 语义与无障碍

| 语义 | 颜色 |
|---|---|
| 主数据、稳定 | 蓝 |
| 增长、达标 | 绿 |
| 下降、亏损、警告 | 红/橙 |
| 中性、参考、“其他” | 灰 |
| 特殊、高亮 | 紫 |

- 不以红/绿或蓝/黄作为唯一区分；叠加符号、形状、线型、标签或纹理。
- 文本/背景 ≥4.5:1；大字与数据元素/背景 ≥3:1。
- 白底不用浅黄；小字不用蓝色。
- 灰度输出仍须可分辨。

## 自然语言映射

| 指令 | 调整 |
|---|---|
| 活泼/鲜艳 | 饱和度 ×1.3；顺序色改多色相 |
| 素雅/低调 | 饱和度 ×0.7；亮度 +10% |
| 深色 | 背景 `#1A1A1A`；文字 `#E8E8E8`；数据色亮度 +15% |
| 公司品牌色 | `categorical[0]` = 品牌色；其余生成协调色 |
| 暖色/冷色 | 色相限制 0–60° / 180–270° |
| 对比更强 | 相邻色相差 ≥30° |
| 柔和 | 相邻色相差 ≤15°；降低饱和度 |
| 突出 X | X 用 `highlight.primary`；其他 opacity 0.3 |

## 品牌色扩展

只变色相，尽量保持饱和度与亮度一致；生成后验证对比度和色盲可读性。

| 方案 | 角度 | 用途 |
|---|---|---|
| 类比 | ±30° | 相近、递进、层级数据 |
| 互补 | 180°；可加 ±90° | 强对比、两级对立 |
| 三分 | ±120° | 三类等权对比 |

品牌蓝 `#4269d0` 示例：橙 `#F5A623`、紫 `#A463F2`、青 `#6CC5B0`。

## 透明度

| 场景 | opacity |
|---|---|
| 单层面积 | 0.12 |
| 堆叠面积 | 0.65 |
| 面积渐变 | 0.25 到 0 |
| 散点 | 0.75；高密度 0.3–0.5 |
| 非焦点 | 0.25 |
| 趋势/参考线 | 0.6–0.8 |

- 3 层以上改堆叠，避免半透明混色。
- 用 `rgba()` 显式设置；检查叠加结果。浅黄易消失；中性底色可用 `#999999`。

## 深色主题

| 元素 | 值 |
|---|---|
| 图表/页面 | `#1A1A1A` / `#0F0F0F` |
| 主/次/三级/弱文字 | `#E8E8E8` / `#AAAAAA` / `#999999` / `#777777` |
| 网格/边框 | `#333333` / `#444444` |
| Tooltip 背景/文字 | `#2A2A2A` / `#F0F0F0` |
| 参考线 | `#FF9999`，opacity 0.5 |

- 数据色 HSL Lightness +15%；刺眼时饱和度 -10% 或降 opacity。
- 高亮区域 opacity 0.12。
- 再验文本 ≥4.5:1、数据 ≥3:1、灰度可辨。

### 深色主题配置

```json
{
  "background": {
    "chart": "#1A1A1A",
    "page": "#0F0F0F",
    "grid": "#333333",
    "border": "#444444"
  },
  "color": {
    "categorical": [
      "#5B8DE6",  // 蓝 +15% lightness
      "#4FC15D",  // 绿 +15% lightness
      "#FF8976",  // 红橙 +15% lightness
      // ... 其余颜色同样处理
    ]
  },
  "text": {
    "primary": "#E8E8E8",
    "secondary": "#AAAAAA",
    "tertiary": "#999999",
    "muted": "#777777"
  },
  "annotation": {
    "tooltip_background": "#2A2A2A",
    "tooltip_border": "#555555"
  }
}
```
