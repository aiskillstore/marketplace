# 自然语言定制

用户明确值优先；主题次之；`aesthetics/default.json` 兜底。所有覆盖项传递到同一输出全部图表。

## 风格

| 指令 | 设置 |
|---|---|
| 深色/暗色 | 背景 `#1A1A1A`；文字 `#E8E8E8`；色板亮度 +15% |
| 学术/论文 | serif；灰度安全；少网格；保留必要边框 |
| 极简 | 去网格和装饰边框；保留轴与数据 |
| 商务 | `analytics`；预留 logo 空间 |
| 彩色/活泼 | 多色相；分类色饱和度 +20% |
| 黑白/灰度 | 灰阶 + dash/点型冗余 |
| 现代/科技 | 圆角柱 4px；细字；克制渐变 |
| 手绘 | xkcd/rough.js |

## 颜色与排版

| 指令 | 设置 |
|---|---|
| 主色 X | `categorical[0] = X`；其余生成协调色 |
| 暖/冷 | 色相 0–60° / 180–270° |
| 对比强/柔和 | 相邻色相 ≥30° / 饱和度 -20% |
| 渐变蓝 | Sequential Blues |
| 正绿负红 | 正 `#3ca951`；负 `#ff725c`；加符号 |
| 字体大 | 全层级 ×1.15 |
| 标题突出 | H1 +2px、700 |
| 衬线/等宽 | serif / monospace |
| 中文优先 | 加 `PingFang SC`、`Microsoft YaHei` 回退 |
| 紧凑/宽松 | 行高与间距 ×0.85/×0.8；或 ×1.15/×1.2 |

## 布局与元素

| 指令 | 设置 |
|---|---|
| 手机 | mobile 断点；宽高比 1.0 |
| 大屏/宽屏 | 宽高比 2.0；字号 +10% |
| 正方形 | 宽高比 1.0 |
| 空间有限/留白多 | 边距 ×0.75 / ×1.3 |
| 显示标签 | H6 9px；防重叠 |
| 隐藏图例/去网格 | `legend.show=false` / `grid.show=false` |
| 加粗线 | `line.width ×1.5` |
| 圆角柱 | `bar.corner_radius=4` |
| 不要动画 | `animation=false` |
| 标注数据点 | point marker + data label |

复合指令同时应用全部映射；冲突时以更具体、更新的用户指令为准。
