# 多图一致性

生成前建立共享设计令牌；生成后逐项核验。

## 共享令牌

| 项目 | 规则 |
|---|---|
| 排版 | 同角色同规格：H1 16/600、H2 13/400、H3 11/400、H4/H5 10/400、H6 9/400 |
| 标题 | 按完整画布居中；同排标题基线一致 |
| 实体颜色 | 先建 `entity: color` 映射；跨图复用 |
| 间距 | 同边距、卡片 padding、图间距、标题/图例安全带 |
| 线点 | 同角色同线宽、dash、点型、透明度 |
| 数值 | 同单位、小数位、百分比、日期、千分位 |
| 标注 | 同字体、颜色、引线、高亮与 Tooltip |
| 交互 | 同延迟、动画、筛选、缩放、高亮、禁用语义 |

默认值以 `aesthetics/default.json` 为准。图例间距：标题到图例 ≥16px；图例到绘图区 ≥20px，出版 ≥24px。紧裁切导出后补齐不对称留白。

## 图表语义

相同数据角色保持相同图表类型。仅当数据角色、单位或分析意图不同且标题/说明能解释时混用；一份报告通常不超过 2–3 种主图类型。

允许示例：销售额用柱状，利润率用折线；月度值用柱状，累计值用面积。仅为“好看”换图不允许。

## 交互

- Tooltip：样式、格式、延迟统一；信息可通过 hover、聚焦或点击获取。
- 高亮：同一焦点策略；非焦点 opacity 统一。
- 点击/筛选/钻取：所有可点击元素反馈一致；联动规则写明。
- 缩放：同类图支持能力一致；不支持时明确。
- 动画：统一时长；尊重 `prefers-reduced-motion`。
- 键盘与触摸：Tab/Enter/方向键；焦点 ≥2px；触摸目标 ≥44×44px。

## 冲突优先级

1. 用户明确要求。
2. 图表类型硬约束。
3. 主题。
4. `aesthetics/default.json`。

## 核验清单

- 字体角色、标题锚点、卡片基线一致。
- 同实体同色；同角色同线型/点型。
- 边距、图间距、宽高逻辑、图例安全带一致。
- 单位、小数、日期、标签、Tooltip 一致。
- 同数据角色图表类型稳定；混用理由明确。
- 联动、筛选、缩放、动画、禁用反馈可预测。
- 静态导出视觉居中。
- 独立完成 `guides/accessibility.md` 核验。
