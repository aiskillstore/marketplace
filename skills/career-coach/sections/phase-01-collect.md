# Phase 1: 信息收集

## 目标
通过 3 轮结构化对话收集用户全部基线信息。**严禁一次性倒出所有问题**——每轮 5-8 个问题。每轮结束后保存到 `.state.json`。

## Round 1 — 基础事实（5-8 题）
自然对话中穿插询问：
1. 年龄、性别、所在城市
2. 学历（大专/本科/硕士/博士）、专业、毕业院校、是否全日制
3. 工作年限、当前岗位、当前行业
4. 目前薪资（税前/税后）、目标薪资

**本轮结束：** 写入 `.state.json`。确认理解正确后再进入下一轮。

## Round 2 — 约束与工作经历（5-8 题）
### 约束
婚姻、孩子、家庭经济压力（低/中/高）、月固定支出、房贷、车贷、赡养老人压力、英语水平、计算机水平、健康（仅限影响职业的）

### 工作经历
每段经历：公司、岗位、年限、职责、项目、管理经验、离职原因。职业成就与失败经历。

**本轮结束：** 更新 `.state.json`。

## Round 3 — 价值观、偏好与能力（5-8 题）
### 接受度确认
加班 / 出差 / 倒班 / 换城市 / 出国 / 创业

### 价值观排序
从以下选最重要的 3 项并排序：收入 / 稳定 / 成长 / 自由 / 兴趣 / 社会地位 / 生活平衡 / 工作环境 / 职业成就感 / 企业文化

### 能力自评（1-5 分）
硬技能 | 软技能 | 沟通 | 表达 | 学习 | 执行 | 管理 | 销售 | 逻辑 | 商业思维 | 创造 | 技术 | 领导 | 抗压 | 数据分析 | AI工具

### 性格
- 有测试结果（MBTI/DISC/霍兰德/大五人格）→ 记录
- 没有 → 用户用 3-5 个词自述 + 一段描述
- 性格推断必须标 `【推断】`，不得假装已完成专业测试

## Round 3 结束后
1. 更新 `.state.json`，标记 Phase 1 完成
2. 写 `~/.claude/career/01-profile.md`，结构：基础信息 → 家庭与约束 → 工作经历 → 能力自评 → 职业价值观 → 性格 → 信息完整度评估
3. 询问：进入 Phase 2 / 补充信息 / 暂停

## 注意事项
- 用户不适 → 允许跳过，标注"未提供"
- 信息矛盾（如"目标 100 万但高中学历"）→ 先记录，Phase 5 再分析
- 用户疲劳 → 主动提议暂停，告知 `/career resume` 恢复
