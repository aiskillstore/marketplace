# Phase 9: 面试准备

## 目标
基于 Phase 4 推荐方向和 Phase 7 能力缺口，为用户准备完整的面试策略。

## 前置条件
Phase 4、7、8 完成

## 面试准备内容

### 1. HR 高频问题（10 题）
每道题配 STAR 框架回答建议：

1. "请做一下自我介绍" → 30-60 秒，突出与岗位最相关的 3 个卖点
2. "为什么离职/想看新机会？" → 避免贬低前司，强调成长诉求
3. "你的职业规划是什么？" → 结合 Phase 12 给出可信回答
4. "你的优缺点是什么？" → 缺点要真实但非致命，附改进计划
5. "你期望的薪资是多少？" → 给区间不谈具体数字
6. "为什么选择我们公司？" → 展现了解，体现匹配
7. "你最大的成就是什么？" → STAR + 量化
8. "你遇到过最大的挑战是什么？" → STAR，重点是"怎么解决的"
9. "你对加班的看法？" → 基于 Phase 1 接受度给策略
10. "你还有什么要问我的？" → 3 个聪明的问题

### 2. 业务面试问题
针对 Phase 4 第一推荐方向，列出 5-8 个专业问题：行业理解 / 岗位专业 / 案例分析 / 情景模拟。

### 3. 技术面试问题（如适用）
核心技能考察点 + 常见算法/系统设计题 + 项目深挖方向。

### 4. 优势表达策略
- 核心卖点提炼（3 个，每个配一句话 + 一个例子）
- 如何把 Phase 7 的短板转化为"正在学习"的故事

### 5. 薪资谈判策略
- 第一次被问薪资期望：给区间不给具体数
- 收到 Offer 后如何谈判
- 除了薪资还可以谈什么（期权/假期/弹性工作/培训预算）
- 常见压价话术和应对

### 6. Offer 谈判技巧
- 拿到 Offer 后不要立刻答应
- 如何用 B 公司 Offer 谈 A 公司
- 什么时候该接受，什么时候该拒绝
