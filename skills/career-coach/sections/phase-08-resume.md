# Phase 8: 简历优化

## 目标
诊断用户简历问题，提供具体优化建议。**对话为主，文件读取为辅。**

## 简历获取方式
1. **首选：对话收集。** 让用户分段粘贴简历内容，或口头描述简历结构（教育背景 → 工作经历 → 项目经验 → 技能 → 其他）。
2. **备选：文件读取。** 如果用户提供 `.md` 或 `.txt` 格式简历文件，可以 Read 分析。
3. **文件限制提醒：** PDF 限制 20 页且可能无法读取中文图片简历。DOCX 不支持直接读取。如果用户只有 PDF/DOCX，引导用户粘贴文本。

## 分析维度

### 1. 简历整体诊断
- 结构是否清晰（HR 平均只看 6 秒）
- 篇幅是否合理（1-2 页为佳）
- 视觉层次是否分明
- ATS（Applicant Tracking System）通过率预估

### 2. 逐段分析
- **个人信息：** 是否简洁、是否有多余信息（如年龄/性别在部分外企不应出现）
- **自我评价/Summary：** 是否量化、是否有记忆点、是否与目标岗位匹配
- **工作经历：**
  - 是否用 STAR 法则（Situation-Task-Action-Result）
  - 成果是否量化（数字 > 描述）
  - 是否突出与目标岗位相关的经验
- **项目经验：**
  - 是否展示了具体贡献（不是"参与"而是"负责""主导"）
  - 技术栈/工具是否清晰
- **技能：** 是否与目标岗位 JD 关键词匹配
- **教育背景：** 位置是否合理（社招放后面）

### 3. 关键词优化
- 基于 Phase 4 推荐方向，提取目标岗位 JD 高频关键词
- 对比用户简历现有关键词
- 给出需要补充/强化的关键词列表

### 4. 具体修改建议（逐条列出）
每条建议格式：
```
问题：xxx
修改后：xxx
原因：xxx
```

### 5. 简历竞争力评分
| 维度 | 得分 | 满分 | 说明 |
|------|------|------|------|
| 结构清晰度 | X | 20 | ... |
| 成果量化度 | X | 25 | ... |
| 关键词匹配 | X | 20 | ... |
| 可读性/HR体验 | X | 15 | ... |
| 差异化/记忆点 | X | 10 | ... |
| ATS 友好度 | X | 10 | ... |
| **总分** | **XX** | **100** | ... |

### 6. 针对不同岗位的简历变体
如果 Phase 4 有多个推荐方向，给 1-2 个方向的简历调整建议（不需要完整重写）。
