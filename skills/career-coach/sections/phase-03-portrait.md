# Phase 3: 用户画像分析

## 目标
基于 Phase 1 收集的信息和 Phase 2 的市场数据，输出用户的三维画像。

## 前置条件
- Phase 1 完成
- Phase 2 完成（推荐）

## 三维画像

### 维度一：基础画像
- **年龄阶段分析：** 用户在职业生涯中所处阶段（探索期/成长期/成熟期/转型期）。分析该年龄段的典型机会和限制。
- **学历竞争力：** 学历在当前行业中的位置——高于/等于/低于平均水平。是否需要提升学历。
- **家庭责任：** 婚姻、子女、赡养老人对职业选择的影响权重。
- **经济压力：** 基于月支出、负债推算最低月收入要求。卡死这个底线，后续所有推荐必须高于此线。
- **职业阶段：** 初级执行者 / 独立贡献者 / 团队管理者 / 部门负责人 / 高管。当前阶段是否与工作年限匹配。
- **职业成熟度：** 自我认知清晰度、职业规划意识、市场敏感度。

### 维度二：能力画像
基于用户自评（1-5 分）：
- **优势：** 自评 4-5 分的能力项 → 是否真的是市场需要的优势？扫描岗位 JD 交叉验证。
- **短板：** 自评 1-2 分的能力项 → 哪些是致命短板（目标岗位必须的），哪些可以忽略。
- **核心竞争力：** 优势中独特且高市场价值的 2-3 项组合。
- **可迁移能力：** 沟通、逻辑、管理、数据分析等跨行业通用的能力。
- **未来可培养能力：** 短板中哪些值得投入时间培养，哪些不值得。
