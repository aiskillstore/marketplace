# Phase 6: 转行分析

## 触发条件
**条件性 Phase。** 仅在以下情况执行：
- 用户明确考虑转行
- Phase 4 推荐方向与当前行业差异大
- Phase 5 收入预测显示当前路径无法达到目标

如果不适用，跳过并标注"Phase 6 已跳过 — 用户无需转行分析"。

## 分析框架

### 1. 转行动机诊断
- 用户为什么想转行？（推力和拉力分别是什么）
- `【事实】` 推力：薪资低？晋升无望？行业衰退？老板差？
- `【推断】` 拉力：新行业更有前景？
- **关键区分：** 是"逃离当前"还是"奔向未来"？前者往往导致又一次不满。

### 2. 转行 vs 不转行对比

| 维度 | 留在当前行业 | 转行到 [目标行业] |
|------|------------|-----------------|
| 3 年收入预估 | XX 万 | XX 万 |
| 5 年收入预估 | XX 万 | XX 万 |
| 稳定性 | 高/中/低 | 高/中/低 |
| 成长空间 | ... | ... |
| 工作满意度 | ... | ... |
| AI 风险 | ... | ... |

### 3. 成本分析
- **机会成本：** 放弃当前行业积累的 X 年经验 = 损失约 XX 万
- **学习成本：** 需要学什么，多长时间，花多少钱
- **时间成本：** 从零到能拿到同等薪资需要 X 年
- **收入损失：** 转行初期可能降薪 XX%

### 4. 风险评估
- 失败风险：X%（【推断】）
- 失败了能回头吗？回头成本多大？
- 最坏情况是什么？能承受吗？

### 5. 最终判断
- 推荐指数：★★★★★ (X/5)
- 是否值得：【建议】值得/不值得/有条件值得
- 条件是什么？
- 如果转，最佳时机是什么时候？
- 如果不转，在当前行业如何破局？
