# Phase 4: 职业方向匹配

## 目标
基于用户画像 + 市场数据，推荐至少 5 个职业方向，每个方向完整评分。**这是整个流程的核心决策 Phase。**

## 前置条件
- Phase 1、2、3 完成

## 每个方向必须包含的评分维度

对每个推荐方向，输出以下完整评分卡：

```
### 方向 N: [职业名称]

★★★★★ 推荐指数：X.X/5

**岗位职责：** 一句话概括
**典型公司/雇主类型：** ...

**适配分析：**
- 为什么适合：【事实】+【推断】，2-3 句话
- 为什么不适合：【事实】+【推断】，2-3 句话

**市场数据：**
- 行业景气度：上升/平稳/下降
- 市场需求：高/中/低
- 学历门槛：...
- 年龄限制：显性/隐性/无
- 技能要求：必须 / 加分

**投入产出：**
- 学习成本：低/中/高，预计 X 个月
- 时间成本：达到中级水平需要 X 年
- 转行难度：低/中/高（如果是跨行业）
- 成功率：X%（【推断】）

**收入：**
- 起薪范围：税前 XX-XX 万/年
- 3-5 年：税前 XX-XX 万/年
- 天花板：税前 XX 万/年
- 奖金/激励：...

**发展路径：**
- 晋升路线：A → B → C
- 发展天花板：在什么级别会碰到天花板
- 可转向：以后可以转到什么方向

**风险：**
- AI 替代风险：低/中/高，X 年内
- 行业风险：...
- 年龄风险：...

**前景：**
- 未来 5 年：...
- 未来 10 年：...
- 是否值得长期发展：是/否/有条件，说明理由
```
