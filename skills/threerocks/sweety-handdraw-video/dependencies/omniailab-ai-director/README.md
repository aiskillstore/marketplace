## 一句话

把一份定稿剧本交给它，它会按影视工业标准从剧本解析一路带你做到成片；你在每个阶段末尾只需回答"确认"或"要改哪里"。

- **适用 · 媒介不限** —— 真人写实的影视级管线，与纯动画／2D 卡通／3D 游戏引擎渲染风格／三维＋手绘混合，都在范围内。
- **适用 · 体量不限** —— 30 秒短片、短剧单集、品牌宣传片、MV 叙事片段，到几十场甚至上百场、数十分钟至两小时以上的长片（**长片不再要求拆成多集**）。
- **默认媒介** —— 真人实拍影视级写实质感（不指定时按此执行）。动画／混合媒介项目由 P1 先做「媒介判定」并写进「全片风格锁定」，此后以该声明为全片唯一媒介口径：造型、笔触、运动与光线按**动画与混合媒介层**执行——运动遵守**动画原理**（挤压拉伸／预备动作／跟随重叠／弧形轨迹／夸张），物理正确让位于运动表现力。

## 能力一览

**它不是"一个跑流程的模板"，而是一套会提问、会提案、会把形容词翻译成参数的创作系统。**

| 层面 | 具体有什么 |
|---|---|
| **① 入口会引导，不等你懂** | 开工先判定**作品形态**：剧情片／短剧／动画片／纪录片／宣传片／片头／MV／游戏 PV／UI 动效／达人视频／教育——每种形态走不同的线。你说不清时**只问三个问题**收敛（放哪放、里面的人是真实的还是演出来的、核心要交付什么），三问定不下来**不硬猜**，给"最短可交付"的建议让你拍板。 |
| **② 创作决策可点菜，也可托付** | **20 位导演预设**（单选或混搭：一位主导演决定全片基准，另可借 1–2 位指定维度）· **五维机位坐标**（6 机型格式 × 11 镜头性格 × 6 焦段 × 3 景深 × 20 运动）· **33 套布光 × 5 种色温变体** · **7 套成片级美学配方**（A01–A07）· **D／P／C／R／S 画风词汇**。全部可以由你点，也可以交给它判断——你说不清时，它按作品类型先给 2–3 个候选和理由。 |
| **③ 专业在机制，不在形容词** | **导演式推理**：选一位导演＝加载他处理空间／机位／光影／时间／潜文本的底层机制；每位都写明**「反例」**——与最容易混的相邻导演的**机制差异**（例如库布里克用广角把人压进建筑、芬奇用长焦把人切成样本，**两者的背景要求正好相反**）。**调度反查表**：按**作品类型 16 类／场景 22 类／人物 16 类／剧情节点 18 个**直接给机位与布光方案。**提示词 16 段固定块序 ＋ 十一条铁律**（"否定即召唤""几何绑画框不绑物件""把难的东西放进静帧"）。**资产体系**：成对资产、统一命名、状态管理、声音锁定。 |
| **④ 有真实项目背书** | **6 个商业级实战案例**（写实短片／长片／动画，含成品提示词块与「问题 → 解法」清单）· **49 张方法配图**（关键词反查索引，最难讲清的部分直接给图）· **7 条真实成片样例**（逐字原文 ＋ 拆解）· **14 个宣传片方向细则**（品牌广告／片头／动态视觉／游戏 PV／UI 动效／MV／达人视频／教育／视频拆解／音色克隆等）。拿不准怎么写，直接照抄成品块。 |
| **⑤ 全链路到成片** | P0 项目接收 → P0A 十项剧本解析与全片情绪曲线 → P1 摄影色彩与声音创作基准 → P2 角色与关键道具母板 → P3 场景资产与环境色卡 → P4 分镜设计与首帧 → P5 视频提示词与画布参数 → P6 在 **OmniAiLab 无限画布**中生成、剪辑、导出成片。**每阶段末尾一次确认门**，你只需回答"确认"或"第 X 处要改"。 |
| **⑥ 宣传片类会先帮你选通道** | 同一支宣传片／产品片／发布视频／功能演示，有两条路：**生成通道**（画面由模型生成，在 OmniAiLab 画布选 **MiniMax H3**）与**代码渲染通道**（真实页面截图 ＋ 代码逐帧渲染，画面 100% 可控，还能回交可编辑工程）。两条**并列且可接力**。它**先给判断、再给选项**：按**五个判据**（画面主角是真人实景还是界面数据／要不要分毫不差／有没有可截图的真实界面／要不要逐帧可控／时长与投放）报出倾向，并**说清代价**；**定形态时只报倾向、不展开**，**素材核完后、进分镜前正式确认并锁定**。场景覆盖**按画面主角分四类**（人为主体／物为主体／屏为主体／混合），含企业形象／TVC／公益／城市／招聘／产品广告／软件发布／功能演示／数据可视化／电视包装／大屏循环，并给出**混合接力分工**（会动的真人实物走生成、屏幕上的一切走代码渲染）。代码渲染侧自带 **157 张动效镜头配方卡**、七份规则文档、可跑工程模板与 **154 份音效素材**；**不适用的片子会明确说不，并给你替代路线**。 |
| **⑦ 判断有出处，不靠形容词** | **电影艺术知识层**：由电影艺术领域著作系统梳理成的**判断与来源层**——**15 个能力域**（读本到讲戏／剧本与叙事／选角与讲戏／视听语言／场面调度／分镜／剪辑／声音／光线／美术造型／类型／制片／方法与心法／类型实操／国别流派）＋ **39 张能力卡**（框架／原则／案例／反例，逐条可溯源）＋ **118 本著作的书库索引**。它管的是**"该想什么、为什么、判准在哪"**：spine 与支点、戏剧块与叙述拍、**关系线与三角形原理**（越轴与"看不懂"的根）、走位动机、切点判准与判停、**声音设计六框架**（听觉层级／声画三位置／听音视角／静默／音桥）、类型契约与分镜级参照片单、资源反推与导演权限边界、**分镜级拉片法**。它**只产出判断、依据与清单**，提示词写法仍归各专项层；**在 P0A／P1／P4 三个节点主动给出判断**、P5 用发布级清单收口——并附**「拥抱经典、欢迎创新」的三档借法**（同域借惯例／跨域借手段／跨媒介与跨国别借流派）与融合纪律。 |

> **形容词会被翻译成参数。** 你说"高级一点""电影感"，它会先翻成可执行的档位（曲线柔、光比 3:1、中长焦压缩、平均镜头 6 秒）报给你确认——**形容词不可执行，档位才可执行**。

## 快速开始

### 一、装到哪：按你用的工具

把**整个 `omniailab-ai-director` 文件夹**（含 `GUIDE.md`、`VERSION`、`openai.yaml`、`references/`、`examples/`）放进下面对应的目录，重开一个新会话即可生效。

| 工具 | 放哪里 | 怎么调起 |
|---|---|---|
| **Codex**（推荐主用） | 没有原生 skill 目录：把文件夹放进项目，例如 `<你的项目>/skills/omniailab-ai-director/`，再在项目根目录的 `AGENTS.md` 里加一行：<br>`影视制作任务：先读 skills/omniailab-ai-director/GUIDE.md，并按其流程执行。` | 说"按 GUIDE.md 开始做片子"。它读 `AGENTS.md` 后会加载这个 skill。 |

| **WorkBuddy** | 用户级（全局可用）：`~/.workbuddy/skills/omniailab-ai-director/`<br><br>项目级（只在该项目可用）：`<你的项目>/.workbuddy/skills/omniailab-ai-director/` | 新开会话后它出现在技能列表里；直接说 **`$omniailab-ai-director 开始`**。 |
| **OmniAiLab**（omniailabx） | [官网下载](https://www.omniailabx.com/plugin)（Windows 本地版 v0.8.16），或[网盘备用](https://pan.baidu.com/s/12Wtj8pAKmXOGgWN-M07v7A?pwd=2gff)（提取码 `2gff`）；安装后把整个文件夹放进它的 **技能目录**（客户端内可查看技能目录位置） | 新开会话后它出现在技能列表里；直接说 **`$omniailab-ai-director 开始`**。 |

> **必须整个文件夹一起复制，不能只拷 GUIDE.md。** 四个子技能（ACTING / EMOTION / LIRA / CINEDANCE）、全部专项层（COMBAT 打斗 / BLOCKING 站位 / AESTHETICS 美学 / PROMPT-DOCTRINE 提示词教义 / ASSET-SYSTEM 资产体系 / SCENE-ENGINE 剧本引擎 / OPTICS 光学 / FEATURE-PRODUCTION 长片工程 / MUSIC-SCENE 音乐场景 / ANIMATION 动画 / DOCUMENTARY 纪实 / PROMO 宣传片线 / ONBOARDING 入门引导 / MOTION-STUDIO 动效工作室）、视觉语言库、7 套现成提示词、纪实模板、**宣传片 14 个方向的完整细则**、**7 条宣传片成品样例**、**机位与布光索引**与 **49 张案例配图**，全都放在 `references/` 与 `examples/` 里；少拷一个目录，运行时就会断链。

**克隆安装（推荐）**


仓库是**公开仓库**，始终与最新版 skill 同步；以后更新只需在该目录执行 `git pull`。发现问题也可以在仓库里提 issue。

### 二、剧本从哪来（三选一）

1. **你直接上传定稿剧本** —— 它读取后直接进入 P0。
2. **什么都不给，直接说"开始"** —— 它会先问一句"手上是已有剧本，还是只有一句创意？"，**不会自动载入内置剧本**；只有你明确说"跑默认项目"时，才用内置样例剧本《17楼》（30 秒悬疑短片）。
3. **只给一句话创意或标题**（例如"做一个太空惊悚短片"）—— 它先自动写出一版定稿剧本给你确认，确认后才进 P0。剧本时长控制在 30 秒 – 5 分钟。

### 三、启动指令

```text
$omniailab-ai-director 开始
```

直接说"开始"即可，它**不会**反问"请问你的剧本是什么"，而是直接问"你手上有剧本，还是只有一句创意？"。

**默认不会自动跑内置剧本**；只有当你说下面这类话时，才使用内置样例剧本（30 秒悬疑短片《17楼》）：

```text
跑默认项目
做《17楼》
```

### 四、启动前必须想清楚的两件事

- **剧情必须是定稿。** 它只处理已定稿剧情，不改戏、不加角色、不加台词、不改结局。中途大改剧情（尤其涉及角色或场景增删）会让前面已生成的资产全部作废。
- **交付规格先定好。** 默认 1080p / 16:9 / 24fps / MP4。要做竖屏或方屏（手机端、产品包装图等），请在 P1 就提出来——P1 之后改规格同样会导致资产返工。

### 五、全程你只需要回答两种话

1. **放行到下一阶段** —— 必须是这四个词之一，其它说法它不开门：

```text
确认 / 通过 / 定稿 / 继续
```

2. **要改就指出位置** —— 它停在当前阶段就地重做，不会往下走：

```text
第 3 处的光线改成侧逆光
把镜 07 的景别从远景改成中近景
```

**只想用其中一项能力时**，直接点名即可，不必走全流程：

| 你想要什么 | 复制这句话直接说 | 它会给你什么 |
|---|---|---|
| 图像提示词 | `只做图像，给我这张图的提示词` | 可直接投喂的生图提示词，含画风档位、构图与光位 |
| 视频提示词 | `只做视频提示词，这个镜头怎么拍` | 16 段固定块序的完整视频提示词，附十一条铁律自检 |
| 表演设计 | `只做表演，这个角色这段戏怎么演` | 表演任务块：动机／目标／障碍／战术，逐拍写清 |
| 情绪控制 | `只处理情绪，这场哭戏怎么演` | 全片情绪曲线或单镜情绪引擎的输出 |
| 画风选择 | `给我画风菜单` ／ `用 D01 + C04 + R01 + S2` | 视觉语言库档位说明与成句，直接进提示词 |
| 美学推荐 | `这场戏该用哪种电影美学` | 2–3 套成片级配方候选，各附一句理由 |
| 打斗编排 | `这段对打怎么打，给我高燃打斗动作提示词` | 打斗帧链、动作命名与矢量、钱镜头时间轴 |
| 站位 / 场面调度 | `这段多人戏怎么站` ／ `下一镜人物位置又变了` | 站位基线数据与跨镜锁定方案，多人镜头必用 |
| 机位与布光 | `这镜用什么镜头和光` ／ `全片怎么打光` | 按作品类型／场景／人物／剧情节点反查出的机位与布光方案 |
| 导演风格 | `这片适合谁拍` ／ `王家卫＋芬奇行不行` | 2–3 位导演候选与理由，或混搭方案与不可混清单 |

> **提要求越具体，返工越少。** 最有效的三样：① 定稿剧本全文；② 交付规格（画幅、分辨率、帧率、时长）；③ 硬性限制（不能出现什么、必须出现什么）。这三样在第一步就给它，比后面补要省得多。

## 全流程总览

八个阶段串成一条**串行链**：**P0 → P0A → P1 → P2 角色 → P2 道具 → P3 → P4 → P5 → P6**。链上每一段末尾都有一道**确认门**——你不明确说"确认 / 通过 / 定稿 / 继续"，它就锁在原阶段不动。

| 阶段 | 它做什么 | 你会拿到 |
|---|---|---|
| **P0 ＋ P0A** | 接收剧本 ＋ 十项剧本解析 ＋ 全片情绪曲线图 | 项目接收摘要、十项解析、一张 16:9 黑色情绪曲线图 |
| **P1** | 锁定全片摄影风格、环境色彩策略、声音圣经；并主动提案 2–3 个美学配方 | 「全片风格锁定」文本——后续所有提示词的固定前缀 |
| **P2 角色** | 角色 / 状态母板生产清单 → 按依赖批次出 9:16 角色图 → 批量出 16:9 角色设定板 | 角色母板、角色设定板、表演主档案 |
| **P2 道具** | 关键道具清单 → 3:4 单件产品档案照 | 道具母板 |
| **P3** | 场景清单 → 16:9 空场景母板 → 5 色环境色卡 | 场景母板、环境色卡（含 HEX）、空间方向链 |

| **P6** | 在 OmniAiLab 画布批量生成、配音、BGM、剪辑、导出 | 成片 MP4、全部素材、质检报告 |

> **宣传片类项目在进入这条链之前，先过一道「通道选择」**：同一支宣传片有**生成通道**（画面由模型生成，OmniAiLab 画布选 MiniMax H3）与**代码渲染通道**（真实界面截图 ＋ 代码逐帧渲染）两条路，选错要整支重做。它会在**定形态时先给一句倾向**、在**素材核完后、进分镜前正式确认并锁定**。判据、时机、场景全表与混合分工见 `references/CHANNEL-SELECT GUIDE.md`。

> **门禁是硬规则。** P0 与 P0A 必须在同一回合连做，P0 不单独确认；从 P0A 起，每阶段末尾它都会给出固定话术，你回复"确认"才解锁下一步。想改就停在原地改，改完再确认——**不要试图一句话让它把后面几阶段一起做完。**

## 逐阶段操作细则

### P0 ＋ P0A｜项目接收与剧本解析

完整读取剧本，先输出 P0 项目接收摘要，并在**同一回复里**继续做完 P0A 前 9 项（国家年代、世界规则、人物小传、空间链、状态链等）；随后自动计算情绪节点，生成第 10 项——16:9 黑色情绪曲线图。

**你要做的**：基本不用动手，等它一次性给完。重点检查两处——情绪曲线的**节点数**与**呼吸区**。

**产出**：项目接收摘要 ＋ 十项剧本解析 ＋ 全片情绪曲线图。

**它给出的确认话术**（可整段复制）：

```text
【请确认】以上 P0A 剧本解析与创作基准（包含全片情绪曲线图）是否确认？需要修改请指出具体项目。
【确认后下一步】建立 P1 全片摄影风格、环境色彩策略与声音圣经。
```

**避坑**

| 坑 | 正确做法 |
|---|---|
| 等 P0 单独确认 | **它不会**——P0 与 P0A 在同一回复里连做，只在情绪曲线图展示后统一确认 |
| 情绪曲线一路高能没有低谷，或凭空冒出一个释放点 | 应为 **8–14 个节点（最多 16）**，且至少有 **1 个真实呼吸区**；不符当场退回去改 |
| 把情绪曲线图当装饰 | 它是 P6 的 BGM 进出点、P4 节奏检查的依据——**这张图错了，后面全歪** |

### P1｜创作基准（全流程最关键的一次确认）

读完剧本判定类型后，**先主动向你提案 2–3 个美学配方候选**（编号 ＋ 名称 ＋ 适合原因 ＋ 建议落点 ＋ 代价）；你选定后，它再给出 1 套完整推荐——1 部主要影视参考（必要时最多 1 部补充参考）、摄影介质与镜头家族、画幅与帧率、光源与材质、环境色彩策略、全片环境声原则与音乐圣经。

**你要做的**：在提案里选 1 个作主美学、最多再选 1 个作补充；或直接说"不用"，它会回到常规取型。然后确认风格锁定文本。

**产出**：「全片风格锁定」文本——**后面每一张图、每一段视频的提示词开头都必须原样带上它。**

**它给出的确认话术**（可整段复制）：

```text
【请确认】以上 P1 摄影风格、环境色彩策略与声音圣经是否确认？需要修改请直接指出。
【确认后下一步】先列出 9:16 角色 / 状态母板生产清单，确认范围与依赖批次后再生成。
```

**避坑**

| 坑 | 正确做法 |
|---|---|
| 期待它在 P1 出图或出音频 | 这一阶段**不生成任何图片与音频**（没有色卡图、没有声音文件、没有 BGM）；在这里要图，说明走错了阶段 |
| 锁定后又想改风格 | 风格锁定**一旦确认即冻结**，只能回 P1 重来，而那会让后面所有资产重做——**这是全流程最需要认真看的一次确认** |
| 硬套美学配方 | "不用"是合法选项；剧本没有配方级需求时它会明说"本片无配方级美学需求" |
| 把光学性格、夜戏的暗、画面内文字留到视频阶段解决 | **把"难的"提前到 plate 决定**——这三件事都要在**场景 plate / 首帧**解决，并写进「全片风格锁定」一起冻结；留到视频提示词只会逐镜漂 |
| 想靠后期调色、或写"不要黄"来定调 | **颜色在提示词里定调**：全片风格前缀逐镜粘贴（含色板、曝光与反差、颗粒、运动性格）；用正向**「颜色宪法句」**；选胶片／印片型号的判据是"**暗部往哪个颜色偏**"，不是选"更贵"的；参考图里裁不掉的发光物写成"**在本片是关着的**" |
| 动画／混合媒介项目不先做媒介判定就出图 | P1 必须先做**「媒介判定」**（写实／风格化三维／二维／混合）并写进「全片风格锁定」，同时锁定**全片光线公式**与**风格分权**（会动的物件走干净立体质感、厚笔触只留给环境） |

### P2 角色资产

先出一张 9:16 角色 / 状态母板生产清单（资产类型、上游依赖、建议批次、必要性、出图理由）；你确认范围后，**第 1 批只做无依赖或基础角色**；基础角色定稿后，才做血缘亲属、变异、换装、受伤、年龄状态；全部确认后，一次性为所有已确认角色生成 16:9 角色设定板。同时为每个主要角色建立表演主档案。

**你要做的**：确认或删改清单；按批次认真验收每一张图。

**产出**：9:16 角色母板、16:9 角色设定板、角色表演主档案。

**它给出的确认话术**（可整段复制）：

```text
【请确认】以上角色资产是否全部定稿？需要修改请指出具体角色和位置。
【确认后下一步】提取关键道具清单并生成关键道具母板。
```

**避坑**

| 坑 | 正确做法 |
|---|---|
| 催它单独出角色设定板 | 设定板**不单独立项、不输出第二张清单**——只在所有 9:16 角色确认后一次性生成 |
| 跳批次（上游没确认就写下游） | 按依赖批次解锁：基础角色定稿后才做血亲／变异／换装／受伤／年龄；**上游一改，下游全废** |
| 角色图验收不认真 | 一致性靠"**真实确认图**"往下游继承——**放行一张错的，后面全盘皆错** |

### P2 关键道具

先用一张**无批次**表格列出最终候选道具（剧情作用、识别 / 连续性锚点、必要性、出图理由）；你确认或删改后，生成 3:4 竖构图的单件产品档案照。不生成三视图，不出现人物或手。

**你要做的**：确认道具清单；验收每件母板。

**产出**：道具母板（每件附对应提示词）。

**避坑**

| 坑 | 正确做法 |
|---|---|
| 以为道具也分批 | 道具**没有批次概念**（这点和角色不同），但**清单必须先确认再出图**，别让它直接开画 |
| 拿有手／有人的图当道具母板 | 道具图必须是"**产品档案照**"规格——干净单件、可识别细节；**出现人物或手的图不能用作道具母板** |

### P3 场景资产

从剧本空间链提取场景，输出生产清单（场景名、剧情作用、光线状态、交互点、必要性）；你确认后为每个必须场景生成 16:9 **空场景母板（无人物）**，同一空间的不同光线状态分别出图；全部确认后，为每个主要场景提取 5 色环境色卡（主色 / 暗部 / 中间调 / 光源色 / 强调色，标注 HEX），并输出空间方向链与场景-角色-道具交互点。

**你要做的**：确认场景清单；验收每张母板与色卡。

**产出**：场景母板、5 色环境色卡（含 HEX）、空间方向链。

**避坑**

| 坑 | 正确做法 |
|---|---|
| 空场景母板里出现人物 | 必须**无人物**——这是后面站位与首帧能叠加的基础；有人物就得重出，否则站位无从叠加 |
| 同一空间只出一张图 | 同一空间的**不同光线状态**（日 / 夜 / 雨 / 不同光源）**要分别出图**，别指望一张图打天下 |
| 色卡不标 HEX | 必须**标 HEX**（主色 / 暗部 / 中间调 / 光源色 / 强调色 五色齐全），否则后面无法引用，等于白做 |

### P4｜分镜设计与首帧生成

按戏剧节拍拆镜头（30 秒短片 6–10 镜；1–3 分钟 15–30 镜），输出完整分镜表（镜号、时长、景别、角度、运镜、画面内容、角色 / 道具、场景、声音、情绪强度）；**多人或多物镜头先建立「站位基线」**，再让每镜从基线取数；为每镜生成 16:9 首帧图，并把角色主档案改写成逐镜表演段落、写出情绪命题与节拍。

**你要做的**：确认分镜表与**全部**首帧图。

**产出**：分镜表、站位数据、全部首帧图、镜头表演段落、情绪节拍。

**它给出的确认话术**（可整段复制）：

```text
【请确认】以上分镜表与全部首帧图是否定稿？需要修改请指出具体镜号。
【确认后下一步】进入 P5，为每个镜头生成视频提示词和 OmniAiLab 参数。
```

**避坑（这一阶段坑最多）**

| 坑 | 正确做法 |
|---|---|
| 多人镜头跨镜站位漂移（上一镜在左、下一镜跑右） | 一场景先建「**站位基线**」，所有镜头从它取数、**只改本镜真正变化的字段**，未变化角色继承并冻结；**没有坐标变化证据，不许改站位／朝向／姿势**。发现漂了就说 `检查站位，按跨镜连续性协议排查` |
| 打斗镜头直接说"两人打起来" | 先填**「镜头契约」**（叙事目的 → 景别 → 机位／观察轴 → A/B 画面位置 → 主运镜 → 触发点 → 终点 → 交接状态），再定 A/B 左右与三个空间锚点，最后才排动作 |
| 首帧提示词没带风格前缀；参考图顺序乱 | 必须带 **P1 风格前缀**；参考图按优先级上传：**角色确认稿 > 场景母板 > 道具母板**（单节点最多 6 张） |
| 画面有中文却用了默认生图模型 | 出现**中文文字**（招牌、路牌、包装、屏幕字）或产出整板故事板时，生图**改用 image2.5**——否则中文字形与排版会崩 |
| 想在视频阶段补救曝光、光学与画面内文字 | **首帧就是最终曝光与光学**：别指望视频阶段压暗；构图里**不要有天空**（有天空一定往蓝调时刻漂），窗户取景成被对面墙面填满；字在这一步定稿。另：**本镜用到的资产必须都已命名、已锁定**，临场改描述词会破坏一致性 |

### P5｜视频提示词与 OmniAiLab 参数

每镜先做**两层强制前置**——① 用 ACTING 把角色主档案改写为「本镜头表演段落」（目标、障碍、策略、节拍、倾听、潜台词、身体与声音）；② 用 EMOTION 写出「情绪命题 ＋ 情绪节拍 ＋ 眼神落点 ＋ 声音包络」，并完成角色权限隔离与视觉词汇净化。**两层齐备后**，连同本镜站位 / 机位坐标、参考标签、分镜需求，交 CINEDANCE 合成最终视频提示词。最后输出参数表。

**你要做的**：确认全部视频提示词与参数表。

**产出**：逐镜视频提示词 ＋ 参数表（镜号、模型、时长、比例、输入方式、参考图清单）。

**它给出的确认话术**（可整段复制）：

```text
【请确认】以上全部视频提示词和 OmniAiLab 参数是否确认？需要修改请指出具体镜号。
【确认后下一步】进入 P6，在 OmniAiLab 画布中批量生成视频、制作音频、剪辑导出成片。
```

**避坑**

| 坑 | 正确做法 |
|---|---|
| 跳过 ACTING 与 EMOTION，直接写视频提示词；或把情绪当"补充"事后加 | **这是硬前置**：先用 ACTING 出「本镜表演段落」、用 EMOTION 出情绪层，**两层齐备后**才交 CINEDANCE 合成；跳了就等于放弃表演与情绪控制 |
| 直接文生视频 | **必须图生视频**（纯黑场／纯文字镜头除外）——每镜先出首帧，再生成视频 |
| 选错视频模型 | 人物镜头 → **Seedance 2.5**；特效／形变 → **Kling O3**；道具特写 → **Vidu**；备选／试水 → **Wan 2.6 / Seedance 2.0 Fast** |
| 把宽高比、分辨率、时长、模型名写进提示词正文 | 一律放平台 UI，**不进提示词正文** |
| 打斗镜头动作链不完整 | 完整动作链：攻击目的 → 身体与武器动作 → 对手响应 → 接触反馈 → 位移结果 → 环境余波；攻防成对、物理闭环、不越轴、一阶段一主运镜、**终结不以摆 pose 收尾** |
| 不按固定块序写、不按十一条铁律自检 | 见下方「**16 段固定块序**」与「**十一条铁律**」——台词只写在「声音与对白」段，动作段一个字都不许有 |
| 物理与连续性没写下来 | 门／窗／开口几何**逐镜重复写全**；道具尺度写"**数值＋关系**"；走路写**步态锁**、并排写"肩并肩同一纵深线"、跨镜写**机速一致**；打斗走**帧链＋一镜到底秒级时间轴** |
| 动画项目漏了动画原理 | 逐镜补「**动画原理五件套**」——**要写出来，模型默认给的是平均值**；全片光线措辞逐镜原样复用、不重写 |

**16 段固定块序**（视频提示词按此顺序写，可整段复制）：

```text
1  场景语境
2  启用参考
3  全片锁定
4  地点图（GEO 空间图）
5  视线与眼线
6  首帧状态与空间占用
7  格式模式
8  镜头（光学）
9  摄影机
10 动作计时
11 表演任务
12 物理
13 光线
14 声音与对白
15 风格与画质
16 正向锁定
```

> **台词只写在「声音与对白」段，动作段一个字都不许有。所有约束一律写进末段的「正向锁定」，不写否定式。**

**十一条铁律**（逐镜自检，可整段复制）：

```text
1  只说"有什么"，不说"不要什么"（写"不要旗子"会把旗子召回来）
2  几何绑画框，不绑物件（"枪的左侧"会被读成画面左侧）
3  一节拍只给一次反应
4  规模用线索，不用米数（道具尺度写"数值＋关系"）
5  可数事件要给出视觉证据（一个闪光＝一发火箭）
6  动作写成物理节拍链
7  相邻镜的景别与角度必须不同
8  可数部位要点检（"只有两只手，都在同一只袖子里"）
9  参考里不想要的东西要"关掉"
10 绝不写年龄（内容过滤器读到未成年会突然变严）
11 维护禁用词字典（"暗"→"低调"、"颠簸"→"快速运动"）
```

### P6｜生成、剪辑与成片导出

指导你在 OmniAiLab（omniailabx.com）建项目、上传全部前期资产到素材库；按"脚本 → 图片 → 视频 → 音频 → 剪辑 → 导出"搭画布；**先全部首帧确认，再批量排队生成视频**，逐镜检查重试；AI 配音（匹配角色音色）、BGM（按情绪曲线进入退出）、音效分层（环境 / 动作 / 强调）；按分镜拼接、叠加音轨、加字幕；导出 1080p / 16:9 / 24fps / MP4 / H.264；最后逐项质检。

**你要做的**：按指引在平台操作；批量生成前确认首帧全过。

**产出**：成片 MP4 ＋ 全部素材包 ＋ 质检报告。

**避坑**

| 坑 | 正确做法 |
|---|---|
| 首帧没全确认就批量生成 | **批量生成前一定先把首帧全部确认**——首帧错一张就白生成一条，**返工成本最高** |
| BGM 凭感觉铺 | 进出点要**对着 P0A 的情绪曲线**，只标注需要推动／反转／积蓄／释放的节点 |
| 剪辑与声音不按阶段走 | 粗排 → 粗剪 → 生成监督 → 精剪 → **定剪**；定剪后除紧急修复不再新增生成。转场按**运动方向 ＋ 声音**匹配，每片段头尾各留 **8 帧**余量，切点落在覆盖元素**填满画面 ≥90%** 的那一帧；颜色做**统一**而非逐镜调色 |

以下为全片唯一口径，**不得混用其它平台的模型名**。

## 避坑总表

这 **29** 条按"踩中概率 × 后果严重度"排。建议在 P1、P4、P5 三处确认前各扫一眼。

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | 多人镜头跨镜站位漂移：上一镜在这边，下一镜就跑了 | 一场景一份「站位基线」，逐镜取数、只改变化字段，未变化角色冻结；没有坐标变化证据不许改站位 |
| 2 | 写视频提示词时跳过表演与情绪 | 必须先 ACTING 出「本镜表演段落」＋ EMOTION 出情绪层，再交 CINEDANCE 合成 |
| 3 | 画面里有中文，却用了默认生图模型 | 有中文文字 / 封面 / 海报 / 故事板 → 一律优先 image2.5 |
| 4 | 把 16:9、10 秒、模型名写进了提示词正文 | 比例、分辨率、时长、模型名一律放平台 UI，正文不出现 |
| 5 | 提示词里堆"不要 XX""排除 XX" | 一律正向表达（"排除数字感" → "光化学胶片质感"） |
| 6 | 把胶片写成真实拍摄（"用 70mm 胶片拍摄"） | 写"70 毫米胶片**模拟**质感"，不伪装成实体胶片 |
| 7 | 提示词里写导演姓名（"某某导演风格"） | 姓名只作内部检索标签；对外交付拆成具体视觉特征 |
| 8 | 引用了不存在的参考图（写了 `{{Image 3}}` 但没上传） | 没有真实参考图就删掉全部素材编号与继承措辞 |
| 9 | 风格锁定之后还想改风格 | 锁定即冻结，不能改；要改只能回 P1 重来 |
| 10 | 情绪曲线一路高能，没有呼吸区 | 8–14 节点，至少 1 个真实呼吸区，不凭空造释放 |
| 11 | 角色跳批次：上游没确认就写下游状态 | 按依赖批次解锁，基础角色定稿后才做血亲 / 变异 / 换装 / 受伤 / 年龄 |
| 12 | 打斗镜头直接写"两人打起来" | 先填镜头契约、定 A/B 左右与三空间锚点，再排动作脊柱与物理闭环 |
| 13 | 一口气提 5 个确认，想一次做完 | 每轮只展示当前需要确认的一步；确认真实有效才解锁下一步 |
| 14 | 把已确认的图当草稿反复重生成 | 确认即冻结，下游依赖它；重生成等于让下游全部失效 |
| 15 | 把"镜头性格"写进视频提示词（想要变形宽银幕质感），结果镜头逐镜漂 | 光学性格做进**场景 plate**；视频提示词里连"不要光晕"都不能写——点名光晕就召来光晕 |
| 16 | 夜戏压不暗，模型总给你黄昏 | 把暗**烤进 plate**（低 2–3 档、黑位压实、只留一道冷边缘光）＋ **把天空裁出构图** |
| 17 | 在旧资产上直接覆盖新状态（同一角色换装 / 受伤就改那张图） | **新状态＝新资产＋新名字**，旧资产保留；覆盖会让此前所有镜头失去参照 |
| 18 | 冷调画面被模型拉成暖黄，写"不要黄"完全没用 | 用**正向"颜色宪法句"**；参考图里裁不掉的发光物，写成"**在本片是关着的**"；选胶片型号看"暗部往哪个色偏" |
| 19 | 楼梯口消失、人物一次跳上去；普通走路滑行或双脚离地 | 上升写成物理＋把开口**命名为必须存在的物件**；走路加**步态锁**；并排写"肩并肩同一纵深线"；跨镜写**机速一致** |
| 20 | 打斗拆成多段生成必然发顿，剪辑救不回来 | **帧链**（第 N 段末帧＝第 N+1 段首帧）＋钱镜头**一镜到底、秒级时间轴、点名禁掉慢动作**；动作**命名并给出矢量** |
| 21 | 剧本没体检就开生成，做到一半才发现某场戏不成立 | 先过**五要素引擎**，产出**唯一最弱点**与三层修法；重点揪**惰性反转**。**只诊断、不改戏** |
| 22 | 同一间屋子跨几十个镜头，脸、声音、座位、视线全在漂 | **声音圣经**（每角色一块 VOICE LOCK，逐字粘贴）＋资产**加场景后缀**＋分段计时节拍＋视线独立成块 |
| 23 | 镜头景别与透视逐镜漂（广角感时有时无） | 按**内容类型**选镜头（视场角锚点 8/18/29/47/84/107°）；同节拍绝不混不兼容内容类别；写**镜头一致性声明** |
| 24 | 英雄瞬移、换位、摄影机跳到房间另一边 | 每场戏先做**开启仪式**：一秒固定站位宽景主镜 ＋ **GEO 空间图** ＋ **罗盘句**（绝不跨 180° 线） |
| 25 | 镜头卡了十几版还不出、越改越坏 | **十到十五次规则**：过线就不是措辞问题——**去改镜头**；迭代**一次只改一件事**，并**全部进日志** |
| 26 | 唱 / 说唱段落口型对不上、或生成被版权检查拦掉 | 先歌后演：终混**切 12 秒块**、做成**黑画面视频文件**、**在设置里关掉生成的音频**；再写**硬唇形锁**与**嘴的所有权** |
| 27 | 运动物件一动就像"贴图"、表面发死，笔触像被抹平 | 会动的物件走**干净的立体质感**，厚笔触只留给环境；混合美学必须做**「分权声明」** |
| 28 | 手绘／风格化环境发平、发闷、没体积；换个镜头就不像同一部片 | 换**金色时刻侧逆光 ＋ 长而清晰的投影**；且**全片只用一条光线措辞、逐镜原样复用** |
| 29 | 静态角色表管不住跨代一致性；画面里的角色被模型凭空发明 | 动画线用 **360° 转身视频**（转身＋表情＋声音三段）作角色主参考；**会动的资产一律先过视频测试** |

## 常见问题

**问：中途想换风格怎么办？**
答：回 P1 重做。后面的资产会连带作废，所以风格要尽量在 P1 一次定准。

**问：它一直要我确认，能不能让它一口气做完？**
答：门禁是防返工的机制，不是流程装饰。每个确认点后面都挂着一批依赖产物——跳过确认去往下走，等于把错误放大到下一阶段。

**问：我能只用其中一段吗？**
答：能。直接说"只做图像""只做站位""只做打斗编排"，见上文调度速查表，它不进全流程。

**问：生成平台必须用 OmniAiLab 吗？**
答：子技能负责"怎么描述"（提示词构建与选型），实际生成在 OmniAiLab 执行；模型口径按上文模型口径表。你也可以只在外部平台生成，但模型名要按这套口径对齐。

**问：剧本能中途改吗？**
答：只能改**不改变资产**的细节。一旦动到角色、场景或结局，前面已生成的资产就要重做。

**问：美学提案我不想要，可以直接跳过吗？**
答：可以。回"不用"即可，它会按常规取型继续；无命中时它自己也会明说不硬套。

## 推荐工具与模型

这个 skill 是纯文本规范，不绑定任何一家模型——换工具、换模型都能跑。但流程很长（P0→P6 八段、几十次生成指令），**模型越强，越不容易在中途丢上下文或漏掉门禁**。

| 工具 | 适合拿来干什么 |
|---|---|
| **Codex**（推荐） | 完整跑 P0→P6：工程能力强，可直接操作项目文件、批量处理资产清单、脚本化整理各阶段产物 |
| **Claude** | 剧本解析、提示词打磨、长篇文档产出（原生支持 skills，长文本改写稳定） |
| **WorkBuddy** | 完整跑 P0→P6：会话内可读写文件、跑脚本，每阶段产物直接落盘 |
| **OmniAiLab**（omniailabx） | 完整跑 P0→P6：与 WorkBuddy 同类的对话客户端，[官网下载](https://www.omniailabx.com/plugin)（Windows 本地版 v0.8.16；[网盘备用](https://pan.baidu.com/s/12Wtj8pAKmXOGgWN-M07v7A?pwd=2gff) 提取码 `2gff`）；会话内可读写文件、跑脚本，生成统一在 OmniAiLab 画布完成 |

**模型建议**

- **首选**：GPT-5.6、DeepSeek V4 这类最新一代模型——长上下文与指令跟随更稳，跑长链路不容易中途"失忆"或漏门禁。
- **可用**：任何上下文 ≥ 64K 的推理型模型都能跑通，但要在每个门禁处多核一遍产物。
- **不建议**：用轻量模型跑全流程（P0A 十项解析最容易漏项）。

> 具体能选哪些模型以你账号里实际可用的为准；模型换代很快，这个 skill 本身不用改——它规定"怎么做"，不规定"用谁做"。

## 基础设备要求

本 Skill 是**流程规范与提示词体系**，不在本地部署服务、不占用本地算力——**图像与视频生成全部在 OmniAiLab 画布中完成**。门槛主要在"运行对话的客户端"与"素材存放"两侧。

| 项目 | 最低要求 | 推荐配置 | 用途 |
|---|---|---|---|
| 对话客户端 | 能读取本地文件的 AI 编程助手（Codex / Claude / WorkBuddy / OmniAiLab 任一） | 同上；**Codex** 在长链路下的稳定性最好 | 加载 Skill、逐阶段产出提示词与工程文件 |
| 本地磁盘 | 1 GB 可用空间 | 5 GB 以上 | Skill 本体约 3 MB；成片、首帧与资产图按项目另行存放 |
| 网络 | 可访问 OmniAiLab 与所用对话服务 | 稳定宽带 | 生成、下载素材、同步仓库 |
| 浏览器 | Chrome 或 Edge 近两年版本 | 最新版 | 使用 OmniAiLab 画布进行生成 |
| 生成算力 | **不需要本地 GPU** | — | 生成全部在 OmniAiLab 云端完成 |
| 可选本地软件 | — | 三维预演、合成与动效、位图精修、程序化与实时视觉工具 | 仅当项目需要时使用；本 Skill 只产出规范与提示词，软件操作由本地工具链承接 |

**不需要准备的东西**：本地模型、向量数据库、任何 API Key、专业显卡。生成参数在 OmniAiLab 画布中选择，可选模型以平台在架为准。
