# 配图索引（案例库插图）

**这套图是干什么用的**：`references/` 是**文字规范**，`examples/case-studies/` 是**可照抄的成品提示词**，**这里是"看得见的样子"**——把最难用文字说清的那几件事（角色表怎么排、状态怎么分、站位示意图长什么样、颜色被拉跑是什么样、运动物件"像贴图"是什么样）直接给图。

**共 49 张，约 2.4 MB。** 全部来自各案例公开的制作复盘，已按本 skill 的中文口径重新命名与压缩，无第三方标识。

## 一、调用规则（硬规则）

> **凡在回答里引用了本索引里的某条规范，必须同时给出对应的图片路径，并说明"对照看这张"。**
>
> 图像是这套方法里最容易被误解的部分——"三格角色表""站位示意图""像贴图"这些说法，光靠文字描述十有八九会被理解错。**不要让用户靠想象**。

触发时机：

| 情形 | 动作 |
|---|---|
| 用户问"XX 长什么样 / 怎么排 / 怎么做的" | **先给图**，再讲规范 |
| 用户说"不明白 / 不清楚 / 没概念 / 能不能举个例子" | **先给图** |
| 你在讲某条规范 | 顺手带上对应图（查下面的反查表） |
| 用户在 P2／P3／P4／P5 做资产或提示词 | 主动报出该阶段相关图的路径 |

路径写法：`examples/images/CHB-03_三格角色表.jpg`（相对 skill 根目录）。

## 四、使用纪律

- 图只作**说明**用，不替代 `references/` 的规范；引用时要**同时给出图与规范条款**。
- 图中出现的片名、人物、标识一律未随图收录；文件名为本 skill 自拟的中文说明。
- 全部图已压缩到宽 ≤ 900px、单张 ≤ 180KB，**整个目录约 2.4 MB**；不要再往这里加原始大图。
- 新增案例配图时：同样只取**正文里的方法示意图**（跳过海报、头像、推荐位、资产缩略图），按 `<案例代码>-<序号>_<中文说明>.jpg` 命名，并回填本文件的两张表。
