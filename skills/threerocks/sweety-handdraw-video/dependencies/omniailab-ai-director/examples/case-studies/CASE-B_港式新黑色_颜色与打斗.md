# CASE-B · 港式新黑色短片（颜色与打斗）

**一句话**：一支约两分钟的写实 AI 短片，1990 年代中国香港新黑色气质，全部发生在一个雨夜的同一间公寓里，方言对白、极少台词。

**它的两块硬骨头是剧本自己决定的**：
1. **把九十年代黑色片的 look 稳定地压在每一镜上**——模型会反复把冷调拉回暖调；
2. **让一场真实的三招擒拿打斗成立**——AI 视频模型默认会把它打碎、打慢、打到别的地方去。

其余篇幅都在处理"中间的几何"：门、楼梯、走廊、一串珠帘，**它们必须待在原地**。

---

## 1. 全片风格锁定前缀（示例）

```text
风格：一九九〇年代港式霓虹黑色电影，按九十年代实拍方式拍摄。
阿莱 35 毫米机身，蔡司高速定焦球面镜，1.85:1 球面画幅。
富士 ETERNA 500T 冷加工——粗颗粒有机噪点，实用光源上有光晕，
浅景深。低照度夜景，暗部压实、气氛沉郁。
```

> **选胶片型号的判据：看它的暗部往哪个颜色偏。** 本片先试了柯达 VISION3 500T，最后换成 ETERNA 500T——原因只有一个：**它的暗部偏绿，而这部片就活在绿色里**。选型不是选"更贵"，是选"暗部偏向你整片的主色"。

---

## 2. 颜色偏色战（本案例最实用的一段）

**现象**：模型反复把原本冷青绿的走廊翻成暖黄。**根源不在提示词，在参考图**——参考里有一扇亮着的窗、有暖色球形壁灯，模型会**放大**这些暖源。**否定清单（"不要黄"）完全无效。**

**正解：换成正向的颜色宪法句。**

```text
画面的主导色必须是冷青绿。黄色只存在于灯泡内部
与灯泡下方一个手掌大小的光晕里。
如果画面变黄，这一帧就是错的。
```

**参考图里有你裁不掉、又不想要的东西**（例如一张参考照片里有一扇发光的红窗）——**不要裁，也不要写"不要"，把它"关掉"**：

```text
参考图里那扇发着光的窗，在我们这部片里是关着的。
```

> 一句话就让模型相信了。这是本案例里性价比最高的一句。

---

## 3. 参考图的分工与排序（决定"画面长成什么样"）

**关键认知**：一旦附上场景照片，模型会把它当作**取景与机位的参考**。所以必须把角色拆开：

| 参考 | 只负责 |
|---|---|
| **平面轮廓示意图**（正面视角，用字母/颜色代替人） | **构图与机位**（谁在哪、什么角度、什么景别） |
| **场景照片** | **表面与光**（材质、陈设、光的方向与色温），**不负责构图** |

**并且要在提示词里把这件事说出来**：

```text
构图与机位 = 以示意图为准，不以场景照片为准。
```

**示意图最后附**（排在场景与角色参考之后），让实拍参考主导风格投票。

**最狠的一招：少锚点胜过好说明。** 当模型还是抓错了参考，**直接把那张参考从这一镜里删掉**。

### 3.1 用锚点把世界钉住（解决"动作飞到别的房间"）

本片的钱镜头反复**瞬移**：主角一会儿飞进走廊、一会儿飞出窗户——**远景镜头锁在场景参考的角度上，把动作拖进了它的地理**。

解法三步：
1. 把场景**降级**为"地点、陈设与光"（不再充当机位依据）；
2. **禁止镜头落在场景参考的轴线上**；
3. **用锚点把世界钉死**：

```text
摄影机只看着厨房；红色珠帘在前景；他头朝前穿过珠帘。
```

## 4. 物理与连续性必须写下来

### 4.1 门是最难缠的"演员"

铰链在哪一侧、往内开还是往外开、老虎图案只画在门的外侧面——**每一镜都要重复写完整的门的几何**，因为模型每次都自己重新发明一遍。

### 4.2 尺度要用"数值 + 与人体或已知物的关系"

```text
栏杆高 110 厘米；在 185 厘米高的人身上，顶端扶手落在他腰带上方一点。
```

不这么写，扶手就会漂到他胸口。（注意：单写米数对"高度感"没用——那要靠线索；但**道具的具体尺度**要靠"数值＋关系"钉住。）

### 4.3 数量要点检

出现过"第三只手在开锁"之后，所有特写都带上这一句：

```text
画面里只有两只手，都属于同一个人，从同一只袖子里伸出来。
```

### 4.4 连续性冲突时，再建一个状态的资产

开着的窗反复"自己关上"：**模型相信参考图，不相信故事**——资产里窗是关的，它就当窗是关的。
**正解不是跟模型商量，而是再建一个"窗开着"的独立资产**。之后这类连续性失误基本消失。

> 这条与 `references/ASSET-SYSTEM GUIDE.md` 的「新状态＝新资产」是同一条原则的两个应用面。

---

## 5. 走路是最难的特技

### 5.1 从楼梯口升起

两位女性要**缓缓从楼梯井里升起**——先头、再肩、再腿，被观众看不见的台阶一级级抬上来。模型的表现是：要么一次跳上去，要么把楼梯口删掉砌成一堵实墙。

修法两条：
```text
被抬起进入画面，一次一级看不见的台阶，历时两到三秒。
```
```text
楼梯口是一个被命名、必须存在的物件。
```

### 5.2 普通走路也要上锁

```text
脚跟先落地，左右严格交替，始终有一只脚在地面上。
```

不写就会：滑行、双脚同时离地、同一只脚连踏两次。

### 5.3 两人并排

```text
肩并肩，在同一条纵深线上，两个头一样大。
```

不写，年长的那位就会走到前面去。

### 5.4 机速一致（跨镜连续性里最隐蔽的一条）

两条同一次行走的跟拍镜头出来速度不同（"脚快、背影慢"）。修法：**在提示词里写明"第 9 镜的摄影机速度与第 10 镜完全一致"**。

## 6. 打斗不能靠剪辑救

**现象**：三招擒拿拆成独立片段生成后**必然发顿**——每个片段都重新猜姿势和节奏，每一刀里都渗出停顿。**剪辑救不回来。**

修法四件套：

1. **帧链**：第 N 段视频的**最后一帧**作为第 N+1 段的**第一帧**，动作**跨切点在中途交接**。
2. **钱镜头用一镜到底**：整套组合写成**单条秒级时间轴**、**实时速度**，并**点名禁掉慢动作**——视频模型很喜欢自己把打斗放慢。
3. **动作写成武术指导的笔记，不是情绪**：
   - **风格即人物**：她的动作柔、走圆、擒拿引带、推手——冠军只用最小力；他的动作直、重、慢半拍。
   - **每个动作都要命名并给出矢量**，否则模型每次都翻物理：
   ```text
   她用脚把他从自己身上翻过去；他落地时脸朝她，头朝向窗户。
   ```
   （原文没有矢量时，他每一条的身体落法都不一样。）
4. **打斗关键帧配自己的站位示意图**——手脚的火柴人图，作为**首帧几何**附着。

**当全身连续性太贵**：**切进身体**——手、腰、脚的快速插入镜头。跳切能藏住过渡、增加冲击力，而且**脚的特写比两人全身远景难崩得多**。

**一个运镜干了最多的活**：**一个从她脚部向上摇起的单镜头，摇到一半时她把他扫倒在地。**

## 7. 问题 → 解法（本案例复盘）

| 问题 | 根因 | 解法 |
|---|---|---|
| 冷调走廊被拉成暖黄 | 参考图里的暖色光源被模型放大；**否定清单无效** | 正向颜色宪法句；参考里不要的发光物**写"在本片是关着的"** |
| 模型抓错了参考 | 场景照片同时承担了"构图"和"表面"两个角色 | 分工：**几何与机位＝示意图，表面与光＝场景照片**；在提示词里说出来；示意图最后附 |
| 说了还是抓错 | 锚点太多 | **删掉那张抢戏的参考**——少锚点胜过好说明 |
| 动作飞到走廊／窗外 | 远景锁在场景参考的角度上，被拖进它的地理 | 场景降级为"地点/陈设/光"；禁止镜头落在参考轴线上；用锚点钉死 |
| 门每镜长得不一样 | 模型的默认重造 | **每镜重复写完整的门的几何**（铰链侧、开向、图案在哪一面） |
| 扶手漂到胸口 | 只写词不写尺度 | 写"**数值 + 与人体或已知物的关系**" |
| 出现了第三只手 | 模型不数数 | 特写统一加**数量点检句** |
| 开着的窗自己关上 | 模型相信参考图胜过故事 | **再建一个"窗开着"的状态资产** |
| 楼梯上升变成一次跳／楼梯口消失 | 没写成物理，开口不是必须物件 | 写"一次一级看不见的台阶、历时 2–3 秒"；把开口命名为**必须存在的物件** |
| 走路滑行／双脚离地 | 没有步态锁 | "脚跟先落地、左右严格交替、始终一只脚在地面" |
| 并排两人走散 | 没有纵深约束 | "肩并肩、同一纵深线、两个头一样大" |
| 两段同一次行走速度不同 | 机速没锁 | 写明"第 9 镜与第 10 镜的摄影机速度完全一致" |
| 打斗发顿、有停顿 | 逐段独立生成，每段重新猜节奏 | **帧链**（末帧接首帧）＋ 钱镜头**一镜到底秒级时间轴**＋**点名禁慢动作** |
| 打斗动作每次落法不同 | 动作没有矢量 | 每个动作**命名并给矢量** |
| 全身连续性太贵 | 信息量过大 | **切进身体**（手/腰/脚的特写）；脚部特写最扛崩 |
