# CASE-A · 写实犯罪短片（夜戏与光学）

**一句话**：一支全流程生成的写实犯罪短片，两条互不相通的时间线（雨夜都市 / 沙漠白昼），人物只作为参考资产存在，每一镜都由"参考资产 + 文本"生成。

**它的硬骨头**：90% 的夜景画面是黑的、几乎没有细节；表演只活在一只眼睛、一道肩上的边缘光、一只按在开关上的手。而视频模型天生跟你作对——它会抬黑位、会凭空给你一片黄昏天空、会"好心"把你没打光的脸照亮、会逐帧重画印刷文字。**这支片子大半的工艺，都是在解决这一件事。**

---

## 1. 全片风格锁定前缀（示例，逐镜粘贴）

一条时间线一段，P1 定稿后**永不改写**，每个提示词开头原样带上。

**时间线 A · 雨夜都市**

```text
风格：九十年代都市夜雨犯罪片质感，以九十年代实拍方式拍摄。
35 毫米变形宽银幕，浅景深，暗部极深、黑位压实，无干净白点。
主色为青绿暗部与钠灯琥珀色的实用光源，被雨水打湿的路面反光。
画面里最亮的东西只能是实用光源本身。
```

**时间线 B · 沙漠白昼**

```text
风格：沙漠白昼战争片质感，以实拍方式拍摄。
35 毫米，低反差，黑位发灰提亮，高光柔和溢出。
主色为蜜色与沙色，奶油金阳光，尘土与卡其。
```

> 写法要点：**风格前缀是"全片唯一口径"**，任何一镜想要例外的质感，都要回 P1 处理，不得在单镜提示词里改。

## 2. 把难的东西放进静帧（本案例的核心解法）

### 2.1 光学块 —— 整块粘到**场景 plate 提示词末尾**

不要在视频提示词里要镜头性格；把它做进 plate，plate 本身就成为那支镜头。

```text
强烈的变形宽银幕镜头性格：水平方向的挤压与压缩，椭圆形散景，
高光被水平拉伸，画面边缘出现猫眼形变，向边缘渐增的轻微色差。
无镜头光晕，无横向光条，无漂浮的散景圈。
```

**注意**：这一整块只出现在 **plate 的生成提示词**里。在**视频提示词**里这些词一个都不出现——连"无镜头光晕"这种否定式也不能写，因为**点名光晕就会召来光晕**。

### 2.2 夜戏两句（曝光与天空）

```text
（plate 生成时写）
曝光比目标低两到三档，黑位压实到没有细节，只保留一道冷色边缘光。
```

```text
（取景时写）
画面被对面的砖墙填满到边缘——没有天际线，没有屋脊线，没有云。
```

- **原理一**：视频的曝光跟的是**首帧的曝光**，不是文字里的形容词。写"很暗"，模型照样给你黄昏。
- **原理二**：画面里只要有天空，就一定会往蓝调时刻漂。**把天空裁出构图**，夜就不再跟你争。

## 3. 完整视频提示词骨架（对照 13 段块序）

```text
【场景语境】本场是主人公确认旧身份的一刻，本镜是他发现的那一刻，全程不动。
【参考（按优先级）】角色 A 参考 ＞ 场景母板 ＞ 关键道具 ＞ 站位示意图
【锁定】〔粘贴 P1 时间线 A 的全片风格锁定原文〕
【地理 / 站位】他从画面右侧入画，停在窗左一米处，正对窗；身体朝向镜头 3/4 侧。
【首帧状态】与已定稿首帧一致：手在开关上，窗内黑，窗外三扇亮着的窗。
【时间轴】第 0–1 秒：静止；第 1–2 秒：头部抬起约五度；第 2–3 秒：转身、起步。
【对白】（本镜无对白）
【表演任务】〔粘贴本镜表演任务块，见第 4 节〕
【物理】转身时重心先移到右脚，外套下摆滞后半拍；起步的第一步脚跟先着地。
【光线】室内唯一光源是窗外的街灯冷光，从左侧打来，右侧为暗部；无补光。
【调色 / 镜头 / 画幅】时间线 A 配方；镜头性格来自 plate；宽幅横幅画面。
【声音】雨声持续，室内极安静；本镜无需重配音。
【禁止项】（仅填本镜已实测翻车的具体词）
```

> 第 13 段"禁止项"**只在实测翻车后逐条追加**，不预先堆叠——堆否定式本身就会招来那些东西。

## 4. 表演任务块（示例）

```text
表演任务 —— [角色名]（完全投入于他的战术；工作在眼睛里发生）：
场戏方向（共享、不点破）：让这一刻像一次普通的例行检查。
动机（他的燃料）：他必须先确认自己没看错，才允许自己害怕。
目标：认清对街那扇窗后面的东西。
障碍：他已经知道答案，而承认答案就等于承认自己还是当年那个人。
战术：他只在测量一个他早就知道的距离——测量本身是他的抵抗。
逐拍：
—（无对白）—— 视线一次抬到位，不来回扫；呼吸停在半口。
—（无对白）—— 瞳孔不再移动，眼睛完成"确认"这个动作。
— 断点：呼吸重新开始的那一下，他人已经在转身。
（安全：视线始终投入任务，绝不呆滞或放空；自然眨眼节奏。）
```

> 自检：**没有人演情绪，所有人演方向**；面部不编排，情绪从压力里漏出来。详见 `references/ACTING GUIDE.md` 附录。

## 5. 站位示意图 · 连接器块（示例）

**第一步（示意图生成提示词）**——把目标画面作为**构图专用参考**：只取取景、机位、裁切、人物位置姿势与比例，不取摄影质感；**不得添加画面里没有的东西**；**被画框切掉的身体不许补全**。产出：一张白底、极淡网格、**细线轮廓不填色**的示意图。

**第二步（粘进视频提示词参考区）**

```text
@staging_[代号]_[场次]_[版本] —— 仅作位置参考
本参考只用来读取每个图形在 @loc_[代号]_[场景名]_[场次]_[版本] 里的位置、姿势与朝向。
本镜的一切视觉品质——风格、光线、调色、脸、服装、环境、道具——
全部且仅来自 @loc_[代号]_[场景名]_[场次]_[版本] 与角色参考。本镜是完全写实的真人实拍画面。

字母对照（字母只存在于本段文字中，不出现于参考图上）
@A = 图上【蓝色】图形 = [角色资产标签] → 窗口左侧，正面朝窗，右手在开关上
@B = 图上【橙色】图形 = [角色资产标签] → 画面左侧，背对镜头

渲染规则：把真实的、写实的角色（用他们各自的参考）放进场景 @loc_... 中
由本参考定义的位置，除此之外不取本参考的任何东西。

锁定：所有风格、光线、质感仅来自 @loc_... 与角色参考；@staging_... 只定义位置。
所有人保持被锁定的站位，直到剧本规定的动作发生。
```

**附着顺序：场景参考与角色参考在前，示意图在最后。**

**本案例的补充变体（几何/机位锁定型）**：当示意图**只用来锁构图与机位**、风格全部来自场景参考时，也可以用**俯视平面图**、并在图上**用字母代替人物**——但渗色与字母渲染的风险随之升高，只在"确有必要且场景参考足够强"时使用。详见 `references/BLOCKING GUIDE.md` 附录 C。

## 6. 声音锁定块（示例）

一次定稿、存盘，**逐字粘贴进每一次生成，连一个同义词都不换**。

```text
[角色名] —— 声音：偏低的干哑男中音，磨损感、不慌不忙，
底部带轻微沙哑，动态范围极小；说话音量低于房间需要的音量，
贴得很近，一次只说一个短句，句子之间留真实空隙；即便不在无线电上也保持通联纪律。
无戏剧化色彩，句尾不上扬。美式。
```

**跨镜同音的正解**：画面先行，再用**单一声音参考做一次专门的重配音**——只动音频、画面不动，逐帧对上已经在画面上的口型。

## 7. 问题 → 解法（本案例复盘）

| 问题 | 模型为什么会这样 | 解法 |
|---|---|---|
| 夜戏怎么压都不够暗，总给黄昏感 | 曝光跟的是首帧，不是形容词；画面里有天空就会往蓝调漂 | 把暗**烤进 plate**（低 2–3 档、黑位压实）＋**把天空裁出构图** |
| 镜头质感逐镜漂（这一镜有变形宽银幕味、下一镜没有） | 视频提示词里的光学词汇不稳定 | 光学性格做进 **plate**；视频提示词里连否定式都不提 |
| 模型"好心"把没打光的脸照亮 | 模型默认把脸当主体 | 在 plate 阶段就把曝光与光比恒定；首帧决定后续 |
| 印刷文字（招牌、包装、屏幕）逐帧乱变 | 文生视频不会保持同一行字 | 画面内文字**在静帧定稿**；中文文字画面一律优先 `image2.5` |
| 写"不要出现旗子"，旗子反而出现了 | 写在"不要"里的词也会被召唤 | 改成正向表述（"素净无标识的布料"） |
| 写"枪的左侧"，弹药带出现在两边 | "左侧"被读成**画面左侧** | 几何一律绑画框："朝向镜头的这一侧" |
| 一节拍里出现"反应—瞥开—再反应" | 这是模型的默认动作 | 明确只给**一次**反应，然后直接给动作 |
| 高度写"三米"没用 | 米数对模型无意义 | 用线索：俯看车顶、台阶顶端、被透视压缩的人形 |
| 一发火箭打出九发 | 数量没有视觉证据 | 一次闪光＝一发火箭，且**空管要可见** |
| 中弹倒下像"摆姿势" | 写了一串状态形容词 | 写成**物理节拍链**：头部先落→双肩不对称→单膝内折→手套拖地 |
| 所有镜头都居中、同一个高度 | 模型的默认取景 | 每一镜**必须**变景别与角度 |
