# 案例库 · 索引（AI 影视实战复盘）

> **配套配图**：`examples/images/`（49 张，约 2.4 MB）——把最难用文字说清的那几件事直接给图（角色表怎么排、状态怎么分、站位示意图长什么样、颜色被拉跑是什么样、运动物件「像贴图」是什么样）。**索引与关键词反查表见 [`../images/INDEX.md`](../images/INDEX.md)。****硬规则：凡引用案例里的某条规范，必须同时把对应图给用户看。**

## 使用纪律

- **块可以整段复制，但必须换成你自己的资产标签与项目事实**（`@char_`／`@loc_` 等按 `ASSET-SYSTEM GUIDE.md` 命名）。
- **风格前缀、光学块、颜色句都是"正向表述"**——本库不提供否定式模板，因为模型对否定很弱（见 `PROMPT-DOCTRINE GUIDE.md` 铁律一）。
- 案例里的**比例、时长、模型名不进提示词正文**，只作说明；实际参数在平台 UI 设置。
- 原文为英文，本库按本 skill 的**中文正向提示词**口径重写，去掉了原项目与作者标识；**方法取自公开的制作复盘**。
