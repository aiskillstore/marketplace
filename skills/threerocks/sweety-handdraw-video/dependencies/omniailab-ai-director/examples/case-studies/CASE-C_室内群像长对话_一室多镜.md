# CASE-C · 室内群像长对话（一室多镜的稳定性）

**一句话**：一支约二十分钟的全流程生成写实短片。全片的脊梁是**一场发生在同一间房间里的长对话**（四个朋友讨论一台能把你送进任何世界的机器），中途三次**猛切**进入各自幻想的类型世界（古战场／太空巡洋舰／童话山谷），最后一个镜头把前面全部重新框定。

**它的硬骨头**：幻想世界是短促而壮观的，难在**设计与规模**；而那间屋子恰恰相反——**四个角色、同一个空间、被几十个镜头锁住**：同样的脸、同样的声音、同样的座位、同样的视线，占全片大部分时长。而视频模型**没有记忆**：它会在镜头之间忘掉一张脸、会在机位移动时重画房间、会给同一个角色在每一条里换一个新声音。**把那间屋子稳住，是这部片最难的技术活**，下面大半的工艺都是为它服务的。

---

## 1. 光学配方（整块粘到场景 plate 提示词末尾）

**变形宽银幕那套配方与 CASE-A 相同**，本案例补充两个要点：

```text
强烈的变形宽银幕镜头性格：水平方向的挤压与压缩，椭圆形散景，
高光被水平拉伸，画面桶形边缘形变，向边缘渐增的色差。
无镜头光晕，无横向光条，无漂浮的散景圈。
```

- **强度要分级**：用「轻微／柔和／中等」或「强烈／极强」**调节**镜头性格的量——不要只会写一种强度。
- **在静帧阶段就要顺手禁掉那三样垃圾**（光晕、光条、漂浮散景球）；**到了视频提示词里，这些词一个都不出现——连作为禁止项也不出现**（点名它们就会召来它们）。
- 视频提示词里只写"**干净的玻璃与受控的光斑**"，镜头性格由 plate 带进来。

## 2. 剧本压力测试（生成之前的第一步）

**在生成任何镜头之前**，让每一场戏过一遍五要素引擎（详见 `references/SCENE-ENGINE GUIDE.md`）：**目标 · 障碍 · 战术 · 反转 · 价值转变**。

**输出样例**（真实用法）：

```text
场次/序列：实验室夜班 · 三人查房（序列 4）

链条检查
• 目标 —— 通过：这场戏是"今晚照常过去"这条因果链上的一环，删掉它，主角"证明自己还配穿这身白大褂"就断了。
• 障碍 —— 通过 / 局部+全局：床上那个病人是全局威胁（他让"照常"变得不可能），两小时一次的指标是局部威胁。
• 战术 —— 通过但有一次空转：老医生用"把流程做到无可挑剔"来抵抗；年轻护工用"多看一眼病人本身"来抵抗。第二次量指标时的一次空转（他重复核对同一栏）不交回信息，建议去掉或改成一次有新发现的核对。
• 反转 —— 通过：年轻人最后那句低声的自语，把"这是例行公事"翻成"这是三个不能原谅自己的人在同一间屋子里"。
• 价值转变 —— 通过：老医生「冷漠的老油条」→「早就放弃了希望、正在观察这个年轻人会不会走到自己没走出的地方」；护工「新手」→「在用照顾病人当赎罪」。

唯一最弱点：战术那次零信息空转。

如果……会怎样
1.（最小改动）把"重复核对同一栏"改成"他核对了一栏不该由他核对的记录，于是发现了新东西"——其余照旧成立。
2.（干净修法）把空转整段删掉，让他的第二次动作直接撞上病人的一个反应（监护仪的一次跳变），信息与威胁同时到位。
```

**同一个阶段还要产出「导演解读」**：每场戏**所有人共同经历的那一个事件**，以及**每个人自己那条可见的物理通道**。

- 示例：事件 =「寻找自我原谅」。甲在梦里重历它；乙用无可挑剔的流程躲进去；丙用超越清单的照护去赎它。**表面（例行查房）只是这个事件流经的地形。** 丙最后那句台词，在不知情的情况下把三个人同时点了名。

## 3. 一室多镜怎么稳住（本案例的核心工程）

### 3.1 命名：加上"场景后缀"

```text
@loc_[项目]_[房间名]_[机位朝向]_s[场次]     地点 + 项目 + 名称 + 场次
@char_[项目]_[角色]_s[场次]_v[版本]         角色 + 项目 + 场次 + 版本
@prop_[项目]_[道具]                          道具 + 项目 + 名称
```

- **场景后缀把每个资产绑到它所在的地方**——同一个房间的"正面机位"和"反打机位"是两个资产。
- **版本后缀出现在状态变化时**：新状态＝新资产＋新名字，绝不覆盖。同一个人在不同场的座位/服装/状态，各自是独立资产。

### 3.2 声音圣经（VOICE LOCK）——一室多镜的隐形杀手

同一角色在每一条里会换一个新声音，除非把它**写成条件**。做法：每个角色写一个声音块（**音区 · 音色 · 语速 · 说话方式**），一次定稿存进**声音圣经**，之后**逐字粘贴进每一次生成，连一个同义词都不换**。

```text
【角色甲】声音（画外）：低、深、有共鸣的胸腔男声，顺滑扎实，平静而有底气的自信——与锁定音色一致。
【角色乙】声音：明亮、偏高的小号男声，带芦苇般的鼻音与粗粝边缘——紧绷、有攻击性，
          音高跳动大、语速快而咬字过度、嘲讽的锋刃明显——与锁定音色一致。
【角色丙】声音：温暖喧闹的男中音，带一点砂砾边缘，动态范围大——戏剧化、顽皮、
          昂扬而愉悦，关键词重音带着善意——与锁定音色一致。
```

每一条视频提示词的音频块都写一句「**与锁定音色一致**」，并补"安静的室内底噪、沙发与扶手椅的轻微吱呀"。

### 3.3 参考的分工（沿用 CASE-B）

**几何与机位归站位示意图；场景照片只供表面与光。** 并在提示词里说出来：`构图与机位 = 以示意图为准，不以场景照片为准。`

**【块 7 · 分段（计时节拍）】**

```text
本镜为受控三段，硬切，实时速度，对白以同期人声呈现。

分段 1 —— 无声建立全景，无对白（约 0.0–0.5 秒）
四种人在上述精确位置，与前面各镜一致。平视全景，保持约半秒，所有人放松而活跃。
这一段**没有任何对白**：所有人的嘴保持闭合、房间完全安静整半秒。对白只发生在后面的中景里。
镜头：平视宽银幕全景，柔和的椭圆散景，干净清透的玻璃配哑光质感；
窗户与实用光源只呈现为各自光源内部的柔和、圆形、受控光斑。

分段 2 —— 中景，乙（约 0.5–5.5 秒）
硬切到画面右的乙。他咬一口披萨、嚼着，听画外的丙说话，眼睛看向画面左。
【动作任务】乙对这项技术持怀疑，想打掉丙说的话；他用一句平的、带刺的挖苦打断丙，
确定自己是对的——只说剧本给他的那一句，不多加一个字。他含着披萨说话，但字要清楚。
镜头：宽银幕中景，画面透过**柔焦的前景杂物**取景（茶几上的杯子、笔筒、玻璃杯、披萨盒边缘）；
柔和的椭圆散景，干净清透的玻璃配哑光质感，光源保持柔和、圆形、受控的光斑。

分段 3 —— 中景，甲（约 5.5–11 秒）
硬切到画面左的甲。他亮起来，转向画面右的乙。
【动作任务】甲是个好笑、心热的极客，充满正向兴奋——他真心相信这项技术，
在用顽皮而善意的方式争取大家。他那句"不，是**你**才是彻底没用的垃圾"是**温暖的打趣，不是敌意**：
他咧嘴笑、用汽水罐做手势，愉快而真诚，满身好意。他说完自己的台词。
镜头：宽银幕中景，同样透过柔焦前景杂物与近处椅背边缘取景；柔和椭圆散景，
干净清透的玻璃配哑光质感，光源保持柔和、圆形、受控的光斑。
```

**【块 8 · 对白】**（逐字＋时间码，只说剧本写下的）

```text
对白只发生在分段 2 与分段 3。分段 1（全景，0.0–0.5 秒）完全静默。
丙（画外）：1.0–3.6 秒："人工智能是围着你在实时搭建整件事的。"
乙：3.8–5.3 秒："哥，那就是彻底没用的垃圾。"
甲：5.8–10.8 秒："不，是你才彻底没用。我看过演示，老兄——是真的。它是真的。"

每个角色只说自己的那一句、逐字；不说话时嘴保持闭合。
```

## 5. 问题 → 解法（本案例复盘）

| 问题 | 根因 | 解法 |
|---|---|---|
| 同一个角色在每条里换一个新声音 | 模型没有记忆，声音没被写成条件 | **声音圣经**：每个角色一个 VOICE LOCK 块，逐字粘贴进每一次生成；每条音频块补一句"与锁定音色一致" |
| 机位一移动，房间就被重画 | 场景没有按机位拆资产 | 命名加**场景后缀**，同一房间的不同机位各自是独立资产 |
| 无对白的嘴在动 / 对白发生在不该发生的分段 | 没有分段与嘴部纪律 | **分段（计时节拍）**＋"不说话时嘴保持闭合"＋"对白只发生在 XX 分段" |
| 一个镜头里塞了太多事，动作与台词对不上 | 没有时间码 | 对白**带时间码**，每个分段给"约 X–Y 秒"，动作任务写进对应分段 |
| 画面偏平、没有纵深 | 中景没有前景层 | 中景统一**透过柔焦的前景杂物**取景（杯、笔筒、玻璃杯、盒边），造出前后层次 |
| 一段时间的对白被背景声淹没 | 环境声没有回落到台词之下 | 写明"环境声在台词之下回落；人声近、干净、情绪受控" |
| 场景照片把机位咬死、动作被拖进参考地理 | 参考越权 | 参考分工＋`构图与机位 = 以示意图为准`；抢戏的参考**直接删掉** |
| 一室多镜的站位不稳 | 缺少空间数据 | 站位示意图 + 连接器块；有了它，"下一镜怎么拍"变成一句话（"给蓝色那位一个中近景"） |
| 剧本到生成完才发现某场戏不成立 | 没有前置结构体检 | **剧本压力测试**（五要素）＋"唯一最弱点"＋三层修法，在生成之前解决 |
| 角色在镜头之间忘掉脸 | 没有身份锚点 | 特写定身份 → 底片原样保留、**永不再过模型**；状态用遮罩逐点合成 |
