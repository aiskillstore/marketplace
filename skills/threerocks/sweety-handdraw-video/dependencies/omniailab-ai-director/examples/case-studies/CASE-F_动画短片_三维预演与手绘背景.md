# CASE-F｜动画短片：三维预演 ＋ 生成，风格化角色与手绘背景

> **一句话**：一部 4 分半的**手绘感动画动作短片**——风格化立体角色跑过水彩世界，公路追逐、警察追捕、忍者群战、古代战车接连撞进来。它的制作复盘把"动画线怎么做才不糊"这件事讲得最透：**混合美学怎么分权、会动的资产怎么验、光怎么统一全片、以及"先拼全片再重生单镜"的工程组织**。
>
> **素材规模**：约 1 万 4 千条资产，其中美术方向（角色／地点／道具／测试）约 6 千 3 百条、故事镜次约 8 千 5 百条。全片切成五幕。

**取用规则**：本文件所有成品块**可直接复制**。取用时把 `[...]` 换成你的项目值，并把 P1 的「全片风格锁定」接在最前面。**所有块都不得原样投喂给视频模型**——必须先经 `ACTING → EMOTION → CINEDANCE` 合成（与 `PROMPT-DOCTRINE` 的块序一致）。

**规范出处**：`references/ANIMATION GUIDE.md`（动画与混合媒介制作层）、`references/PROMPT-DOCTRINE GUIDE.md`、`references/ASSET-SYSTEM GUIDE.md`。

## 1. 可整段复制的成品块

### 1.1 媒介与风格分权块（→ P1 定，P4／P5 逐镜复用）

混合美学的核心写法：**角色一路、环境一路，各自带锚点，并声明两者共存。**

```text
【媒介与风格分权】角色走风格化立体造型：干净的表面、明确的体积转折、轮廓清晰，
鼻、耳等部位保留夸张比例；环境走手绘水彩质感：可见笔触、纸纹、颜料堆积与晕染，
远景比近景笔触更松。两者共存，角色不被水彩化，环境不被打磨成塑料。
```

### 1.2 光线公式（→ P1 锁定，全片逐镜原样复用，不得逐镜改写）

```text
【光线公式】傍晚金色时刻，低角度暖阳斜射，长而明确的投影，暖色高光，
强体积感与层次，环境暗部保留手绘笔触细节。
```

```text
[LIGHTING] late-afternoon golden-hour lighting, low warm sun, long dramatic
shadows, warm highlights, strong depth and dimensionality.
```

### 1.3 运动口径块（→ P1 锁定；写实造型 ＋ 动画运动的分界声明）

```text
【运动口径】造型保留写实质感与干净的立体表面；运动按动画原理执行——挤压与拉伸、
预备动作、跟随与重叠、弧形轨迹、适度夸张。物理正确让位于运动表现力。
```

### 1.4 动画原理五件套（→ P5 逐镜按需拆入「动作计时」段）

```text
【挤压与拉伸】[物件] 受冲击瞬间沿运动方向被压扁约 [1/4]，随后回弹并轻微过冲。
【预备动作】动作前 [角色] 先向 [反方向] 短促蓄力 [约 4 帧]，再发力。
【跟随与重叠】主体停止后，[头发／衣摆／天线] 延迟 [约 5 帧] 才停，并有一次回摆。
【弧形轨迹】[肢体／投掷物] 走弧线，起点 [左下方]、顶点 [过顶]、落点 [右前方]。
【夸张】[起跳高度／停顿长度／形变量] 比现实放大 [约 1/3]，保持可信但明显超出日常。
```

### 1.5 角色设计说明（→ P2 角色资产；用判据句自检）

```text
【角色设计定位】[角色名]，[年龄区间不写]，[职业／处境]。
造型：身体保持可信、舒适、日常的立体造型；喜剧感只放在 [脸／耳形／五官比例]。
自检句：TA 看起来像那个真的会 [核心失误行为] 的人。
本轮自检：把本造型放进已设计好的动作里，会变丑还是变帅？→ [结论]
```

### 1.6 360° 转身视频资产规格（→ P2 建 `@char_` 主参考）

```text
【资产形态】@char_[代号]_[角色名]_[版本] — 360° 转身视频
段 1｜转身：缓慢完整 360° 旋转，中性表情、放松站姿、双臂自然下垂；
      要求四面服装与轮廓细节全程可辨、比例不漂。
段 2｜表情：依次给出 [中性 → 笑 → 收笑 → 惊讶 → 不悦]，每个停 [约 0.8 秒]；
      要求同一张脸、眉与嘴角变化清楚。
段 3｜声音：说一句 [本片台词]，用于音色与唇形参考。
用途：全片该角色的唯一主参考；任何镜头出图前先挂本资产。
```

### 1.7 会动资产的视频测试卡（→ P2／P3 验收用）

```text
【资产压力测试】
被测资产：@[资产标签]
测试条件（须与成片一致）：地点 [@loc_...]、光线 [1.2 光线公式]、镜头 [视场角／机位]、
运动幅度 [本片实际幅度]。
同框资产：[列出会与它同时出现的资产]
通过标准：在 10 次生成中 ≥ 10 次可清楚辨认，且表面质感不塌、边缘不糊、笔触不被磨平。
不通过处置：先改措辞（[具体改法]）；同一处第二次仍崩 → 重建该资产。
```

## 2. 五条"先做错才换来"的风格规则

| # | 规则 | 为什么 | 一句话写法 |
|---|---|---|---|
| 1 | **会动的物件简化纹理** | 运动物件和背景都是厚笔触时，模型逐帧保不住，表面会像"平面图贴在几何体上" | `干净的立体质感 ＋ 手绘环境` |
| 2 | **资产要先在运动状态下测试** | 静帧好看 ≠ 动起来能用；早期视频测试才暴露出运动物件的材质问题 | `关键资产尽早做运动测试` |
| 3 | **从一开始就用完整的角色参考** | 角色表没做好就出图，参考里载具是空的 → 模型**自己往车里塞了随机乘客** | `把需要的角色参考全部附上，不留空` |
| 4 | **用光统一视觉风格** | 正午光让手绘环境发平发闷；只改成傍晚光，画面立刻变暖、有体积 | `手绘地点 ＋ 金色时刻光` |
| 5 | **把光线语言在全片锁死** | 逐镜各写各的光，做出来的像好几部片拼的 | `全片复用同一条光线措辞` |

> 规则 2、3 与 `FEATURE-PRODUCTION` 的"资产压力测试"、`ASSET-SYSTEM` 的"资产前置闸门"同源——**动画线对这两条的敏感度更高**，因为它们更容易被"静帧观感"骗过去。

## 3. 五幕结构（可直接照搬的分幕法）

| 幕 | 内容 | 资产量占比（本例） |
|---|---|---|
| 幕一 | 开场：把故事推起来（机场．误机前的最后几分钟） | — |
| 幕二 | 概念验证段：公路与载具追逐（**最重的一场动作测试**） | 25.8% |
| 幕三 | 追捕段：执法方介入 | 10.7% |
| 幕四 | 群战段：忍者群战（**全场最重**） | **44.3%** |
| 幕五 | 收束：回到起点取物再返回 | 4.3% |

**读法**：**不要平均排期。** 本例最重的两幕合计 **70.1%** 的镜次资产。分幕统计做完，先把人力与生成预算压到最重那两幕上。

**目录结构**：

```text
美术方向 / 资产
    角色        [条数]
    地点        [条数]
    道具        [条数]
    视频测试 / 早期测试   [条数]   ← 专门用来筛 AI 味道
故事镜次
    幕一  [n] 个子文件夹
    幕二  [n] 个子文件夹
    幕三  [n] 个子文件夹
    幕四  [n] 个子文件夹
    幕五  [n] 个子文件夹
```

> **同一幕的文件夹可能出现两次**——那是"先拼全片、再回头重生单镜"留下的初版与重生版。这是**正常结构**，写进目录说明，否则后来的人会以为是重名事故。

## 4. 剧本到成片的实际路径（本例自述）

1. **前期**：创意 → 剧本 → **分镜（传统分镜板，三维镜头在板上高亮标出）** → 资产；
2. **资产**：角色（**转身视频**，含表情与声音）＋ 地点（**手绘感，反复试错才定型**）＋ 道具（**运动道具走干净立体质感**）；同步做**早期测试筛 AI 味道**；
3. **三维与生成分工**：**复杂或高度特定的动作、剧烈动作、描述成本高的镜头 → 三维预演**；其余交给生成；
4. **生产**：分幕分场景出镜次 → **先拼出一版完整成片** → **再回头逐镜重生不满意的部分**；
5. **后期**：**统一调色（人工逐镜精修）** → 原创配乐 → **声音设计（逐条清理、加音效）** → 交付。

**值得抄的一条团队做法**：**全组一起过一遍"什么才够视觉爽、能加什么动作"**——忍者群战这一场就是在画分镜时被提出来的。**增量的爽点常常诞生在画板前，不在剧本里。**

## 5. 问题 → 解法（本例实录）

| 现象 | 原因 | 解法 |
|---|---|---|
| 运动物件一动就"平"了，像贴图 | 运动物件用了密集手绘笔触 | **运动物件走干净立体质感**，笔触只留在环境 |
| 手绘环境试了几十版还是"脏、糊、没性格" | 纯手绘路线 ＋ 正午光 | 改**立体骨架 ＋ 手绘环境**的中间路线，并把光改成金色时刻 |
| 一度想放弃手绘全改立体 | 试错成本压住了判断 | **两条路线并行试到找到平衡**——"错误的选择本身会指出对的方向" |
| 画面里凭空出现乘客 | 参考里载具是空的，模型自己发明 | **把常驻角色参考全部附上**，不留空 |
| 角色第一版太好笑，整片调性要塌 | 设计只冲"好笑" | 喜剧感**局部化到脸与耳**，身体回到可信造型；用判据句自检 |
| 手绘环境没体积 | 正午光 | 换**傍晚金色时刻侧逆光 ＋ 长投影** |
| 各镜不像同一部片 | 逐镜各写光线 | 全片**复用同一条光线措辞** |
| 角色跨代一致性差 | 只用静态角色表 | 改用 **360° 转身视频**（转身＋表情＋声音） |
| 成片一看就是 AI | 没主动筛 | 美术方向阶段**专门做 AI 味道筛查**（手、牙、糊化、对称感、乱码字） |
| 排期严重误判 | 按平均分布排 | 按幕统计资产，**最重的两幕吃掉 70%** |
| 生成卡在同一处十几次 | 在措辞上打转 | 先改措辞，**同一处第二次崩就重建资产** |
| 半年后看不懂目录 | 重复幕目录没写说明 | 目录规范写明"**重复＝初版＋重生版**" |
