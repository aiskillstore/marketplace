# 王家卫｜Wong Kar-wai

> **一句话**：摄影机贴得太近、挡得太多、又晚了一步——正好是这段关系的形状。
> **触发词**：王家卫、暧昧、错过、霓虹、怀旧、都市爱情

## 一、适用与不适用

**适用**
- 都市爱情与**错过**、暧昧未成形的关系、记忆叙事、夜景与狭窄室内、人物独白、怀旧年代空间、情绪向短片与音乐段落。
- **空间越小越好**：走廊、楼梯、单间、面摊、后座。

**不适用（改用谁）**
- 需要清楚交代地理关系的场景、群戏调度 → 用 **斯皮尔伯格**（01）或 **黑泽明**（04）。
- 观众必须看懂"谁在哪里"的动作段落 → 用 **迈克尔曼**（19）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| **雷弗恩** | 也用霓虹。雷弗恩把霓虹当**填充色块**，机位锁死、正面对称、人物摆在画幅正中；这里霓虹是**穿过镜头的污染**，机位手持、构图偏心，前景永远有东西挡住（门框、栏杆、水壶、别人的后脑）。 |
| **芬奇** | 也拍低照度城市夜。芬奇每一帧都是精算的稳定构图、干净的空气；这里要**故意的不稳、错误的取景、被切掉一半的脸、发生在画框外的动作**。 |
| **斯科塞斯** | 也有运动的摄影机＋流行乐＋旁白。斯科塞斯用稳定器与推轨**推进**（慢起、中段快、硬停）；这里是**小幅手持在原地犹豫**，微调、后退、重新构图，整镜位移不到 1 米，哪儿也到不了。 |
| **伯格曼** | 也拍脸。伯格曼要正面全脸和眼睛；这里拍**侧脸、后颈、下颌线和被遮住的半张脸**——正脸是舍不得给的东西。 |
| **毕赣** | 也有怀旧流行乐与旁白。毕赣的旁白是诗、人称模糊、画面是连续长镜；这里的旁白是**第一人称自述，带具体日期、编号、次数**，画面是碎片跳接。 |
| 通用 MV | **慢动作不是为了好看**：一个段落只用一次，且必须落在"人物克制住自己"的那一秒；其余时间是正常速度甚至偏快。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 写出这两个人"**差一点**"的具体形式：错开多少秒，或共享哪一件物。
- 给场景指定一个**可数的时间标记**（日期、编号、班次、第几次），且必须是为这个故事**新造**的。
- 写一段旁白，让它**至少有一处与画面事实不符**（记忆是被重写的）。
- 让一个小动作在**三个场景里重复**，第三次给出含义。
- 结尾停在**离开、错过或未说出口**，删掉任何解释性台词。

**2｜空间与机位**
- **每镜指定一样前景遮挡物**，并写明它挡住身体的哪一部分。
- 摄影机贴身（距离常在 1 米以内），构图偏心，人物常被挤在画框边缘。
- 动作常常**发生在画框外**——观众听见／猜到，却看不到。

**3｜光学与景深**
- 广角**贴身拍变形的亲密**；中长焦**隔街压缩人流**；**中焦段刻意回避**（不给人"客观"的视点）。
- 极浅景深为主：焦点只保住一个细节（手、耳朵、烟）。

**4｜光影与色彩**
- 光比 **6:1 到 10:1**。
- 选定**两种互补的霓虹色，一种打人、一种打墙**；颜色是"漏进画面"的，不是设计出来的。
- 霓虹绿、深红、钨丝琥珀为主。

**5｜时间与剪辑**
- 平均镜头 **1.5–4 秒**——靠碎片累积，不靠长镜。
- 每段允许**一个 6–12 秒的慢动作长挂**，且只落在"克制住自己"那一秒。
- 允许"错误"的取景与延迟的切点（晚一步）。

**6｜声音与表演**
- 怀旧流行乐来自**场景内的来源**（收音机、点唱机、邻店的喇叭）。
- 旁白是第一人称、自述式、带具体数字。
- 表演**内向、克制**：情绪由手、烟、背影与停顿承担；哭与笑都只给一半。

## 五、可执行清单

1. 写出这两人"**差一点**"的具体形式：错开多少秒，或共享哪一件物。
2. 给场景指定一个**可数的时间标记**（日期、编号、班次、第几次），且是你为这个故事新造的。
3. 为每个镜头指定**一样前景遮挡物**，并写明它挡住身体的哪一部分。
4. 选定**两种互补霓虹色**，一种打人、一种打墙。
5. 只安排**一次慢动作**，写清它落在哪一秒的哪个克制动作上。
6. 写一段旁白，让它**至少有一处与画面事实不符**。
7. 让一个小动作在**三个场景里重复**，第三次给出含义。
8. 结尾停在离开、错过或未说出口，删掉解释性台词。

## 六、与其它层的对接

- **接管**：前景遮挡的强制要求、手持微动的幅度上限、霓虹色彩的两种分工、旁白的不可靠性、慢动作的唯一性、碎片化短镜节奏。
- **保持全片默认**：布光可取 `CAMERA-LIGHT` 的"霓虹都市夜"；情绪命题归 `EMOTION`；块 13 七项必定义归 `PROMPT-DOCTRINE`。
- **硬约束**：正文不写焦段数字；"极浅景深"要写成"只有她指间那支烟是清晰的，其余全部化开"。
