# 黑泽明｜Akira Kurosawa

> **一句话**：用长焦把队列压成横向的带，让风雨作用在身体上——等待比爆发更长。
> **触发词**：黑泽明、史诗、武士、群像、恶劣天气、战争与冲突

## 一、适用与不适用

**适用**
- 武士片、史诗、群像、战争与社会冲突、阶级压迫、英雄牺牲、权力崩塌。
- 需要在**恶劣自然环境**（雨、风、雪、尘、泥）中完成情绪的段落。
- 需要 5 人以上同框且每人有明确功能与位置；需要动作方向绝对清楚的战斗。

**不适用（改用谁）**
- 室内心理剧、亲密两人对话 → 用 **伯格曼**（07）或 **侯孝贤**（16）。
- 需要浅景深与柔光的当代都市题材 → 用 **王家卫**（09）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| 通用史诗动作 | 主流做法用广角贴身拍冲撞与混乱；这里用**长焦从侧面拍**，把队列压成横向的带、运动横穿画面——观众读到的是**阵型**，不是混乱。 |
| **斯皮尔伯格** | 斯氏的空间清晰是为了让观众**替主角害怕**；这里的空间清晰是为了标明**社会位置**——谁站在高处的干地上、谁在低处的泥里，这是阶级信息，不是安全感。 |
| 流媒体战场剧 | 战斗前的等待（准备、观察、沉默、雨里站着）必须占段落时长的 **50–60%**；压到 10% 就变成另一种类型片。 |
| 只在后期加的天气层 | 风雨尘泥必须**作用在身体与织物上**：湿透的布贴在背上、泥浆改变步态、风把发绳吹到脸上。只叠一层雨而人物干燥挺拔，就是失败。 |
| 慢动作英雄化 | 暴力是**极短的一击（0.3–1 秒）**，之后接 3–8 秒的静止收尾。用慢动作延展杀戮属于另一套体系。 |
| 单机位覆盖 | 同一动作用**不同焦段的多台机位同时记录**，剪辑在同一动作的不同压缩度之间切换，因此每一刀都能看清方向。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 群像里**每个人写一行"社会位置 ＋ 一个道德选择"**；超过 8 人就合并（观众记不住更多）。
- 胜利必须有代价：结尾写下**胜利者失去的那样东西**。
- 人道主义底色：镜头对弱者与失败者保持同等尊严。

**2｜空间与机位**
- 战前画**阵型图**：标出顶点方向、高地与低地、包围与突破口。
- **横向运动**是主语法：队列横穿画面，压缩感由长焦提供。
- 屏幕运动方向**全段一致**，除非插入一个明确的转身镜头来交代转向。
- 机位多在**眼平或略低**，与人物同高——不俯视弱者。

**3｜光学与景深**
- 标准焦段交代空间关系；中长焦拍身体与阵型；**长焦把人群压成一堵墙**，并让正面冲来的人几乎看不出在推进。
- **深焦**为主：群像里每个人的状态都要可读。

**4｜光影与色彩**
- 光比 **6:1 或更高**：阳光、火光、雨中的反差本来就是戏剧性的，不要压平。
- **天气是角色**：写出它对织物、步态、视线、声音四件的具体影响。
- 土黄、泥褐、湿布墨黑、雨天灰白为主；色彩克制，情绪由天气与姿态承担。

**5｜时间与剪辑**
- 等待段平均镜头 8–20 秒；战斗段 2–5 秒。**等待段时长 ≥ 战斗段时长**。
- 决定性一击写成 0.3–1 秒，后面接 3–8 秒的**静止收尾**（不是升格）。
- 剪辑在**同一动作的不同焦段覆盖**之间切换。

**6｜声音与表演**
- 自然声是主角：雨、风、泥、织物摩擦、呼吸、兵器的金属声。
- 音乐克制，多用于等待段与结尾，不用于杀戮瞬间。
- 表演走**身体姿态**：站姿、握持、转身的幅度承担人物；不靠面部特写。

## 五、可执行清单

1. 给群像里每个人写一行"**社会位置 ＋ 一个道德选择**"，超过 8 人就合并。
2. 战前画一张**阵型图**，标出顶点方向、高地与低地、包围与突破口。
3. 把等待段时长写成秒数，并确认它 **≥ 战斗段时长**。
4. 为段落选一种天气，写出它对**织物、步态、视线、声音**四项的具体影响。
5. 每个动作节拍同时列出**三个焦段的三条覆盖**，剪辑只在这三条之间切。
6. 检查屏幕运动方向：全段一致，除非插入明确的转身镜头。
7. 决定性一击写成 0.3–1 秒，后面接 3–8 秒静止收尾。
8. 结尾写下胜利者失去的那样东西。

## 六、与其它层的对接

- **接管**：群像阵型纪律、横向运动与屏幕方向、天气的作用方式、等待／爆发时长比、多焦段覆盖规则。
- **保持全片默认**：布光可取 `CAMERA-LIGHT` 的"正午硬光"或"烟雾逆光体积光"方案；打斗编排归 `COMBAT`（帧链与矢量）；站位落坐标归 `BLOCKING`。
- **硬约束**：正文不写焦段数字；"长焦压缩"要写成"人群被压成一道横向密实的带，前后层几乎贴在一起"。
