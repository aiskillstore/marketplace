# 侯孝贤｜Hou Hsiao-hsien

> **一句话**：摄影机提前到场，坐在门外，不走近也不离开，让一屋子人把时间过完。
> **触发词**：侯孝贤、家庭、日常、远观、时代、事件在画外

## 一、适用与不适用

**适用**
- 家庭史、时代变迁下的日常生活、代际沉默、离开与返乡、小城与街屋空间。
- 需要"**事件发生在画外**"的叙事：变故已经发生，我们只看见之后的一顿饭。
- 极低成本高完成度的项目：一个真实房间、一扇门、一个下午的自然光就能拍一场。
- 需要观众**自己在长时间里发现信息**的段落——他必须扫描画面，而不是被剪辑喂。

**不适用（改用谁）**
- 需要在 30 秒内交代三条信息的商业片 → 用 **诺兰**（10）或 **芬奇**（12）。
- 靠特写推动的情绪片 → 用 **斯皮尔伯格**（01）或 **伯格曼**（07）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| **塔可夫斯基** | 也固定长镜。塔氏让水、火、雾**替人物表演**，人常被清出画面，压力是垂直与形而上的；这里画面里**必须有人在过日常生活**——盛饭、点钱、修东西、吵一件很小的事，机位在 6–12 米外，**任何象征性元素都不允许进来**。 |
| **毕赣** | 也华语长镜。毕赣的长镜**持续位移**，穿门、过桥、换地理；这里的长镜**一步不走，也绝不跨过门槛**——地理永远是这一个房间，换地方必须靠切点，而切点同时跳掉一段时间。 |
| **伯格曼** | 也处理人的内部。伯格曼把危机压进面部特写（脸占画幅 60% 以上）；这里**全片可以没有一个特写**，情绪要从 9 米外的坐姿、停顿长度和一次背过身去读出来。 |
| **芬奇** | 也精确静止。芬奇的静止是**监视**（长焦隔离、每帧被工程化、光是被设计过的）；这里的静止是一个**提前到场的目击者**——机位是现场唯一合理的位置，光是窗户给的，没人补光。 |
| 纪录片手持 | **观察不等于晃**。摄影机在三脚架上锁死，构图是预先决定的；"纪录感"来自**时长与距离**，不来自机器不稳。 |
| 空镜头式慢电影 | **画面不是空的**。一颗镜头里通常有 3–6 个人在做互不相干的事，**前中后三层都要有事情发生**，观众才会去扫描。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 写下这场戏**之前和之后各发生了什么大事**，然后**确认两件都不拍**。
- 信息由**观众自己扫描画面**获得，不由台词与特写交付。
- 结尾：**在人物离开画面之后，让镜头继续拍 8–20 秒空房间**，并想清楚这段时间观众该看见什么。

**2｜空间与机位**
- 为这场戏找出**唯一那个机位**：距离 6–12 米、坐姿眼高，**最好在另一个房间里，透过门框拍**。
- 列出画面**前中后三层各有什么在持续发生**——三层都要有内容才能开机。
- 摄影机提前到场：它比人物先进入这个空间，并在人物走后留下。

**3｜光学与景深**
- 从中长焦在 6–12 米外拍全景——**远，但清楚**。不用广角贴近。
- **深焦**：一屋子人的关系必须同时可读（座次与动作分配承担关系）。
- 门框作为画中框：空间被切出一层"门里／门外"。

**4｜光影与色彩**
- 光比 2:1 到 4:1。
- **关掉所有补光**，只留门窗的自然光和现场的灯，**接受人脸在暗部**。
- 老木褐、白灰、门外绿、洗旧的靛布为主；色彩来自年代与材料，不刻意调。

**5｜时间与剪辑**
- 平均镜头 **40–120 秒**。
- **实时，不做时间压缩**：把这场戏的真实时长写下来，然后决定拍其中连续的哪 1–3 分钟。
- **删掉所有特写和反打**；确认没有特写时观众仍能读懂关系（靠座次与动作分配）。
- 切点同时**跳掉一段时间**（省略，而不是衔接）。

**6｜声音与表演**
- 录一条 **60 秒以上的完整现场声床**，确保**全片没有一秒是真正的静音**。
- 环境声是主体：碗筷、收音机、脚步、远处市声、风扇。
- 表演是**非表演**：人物在过日子，不在演情绪；变化体现在停顿的长度与身体的朝向。

2. 为这场戏找出**唯一那个机位**：距离 6–12 米，坐姿眼高，最好在另一个房间里，透过门框拍。

## 六、与其它层的对接

- **接管**：唯一机位与距离纪律、无特写／无反打、实时时长、三层都要有事、现场声床、省略式切点。
- **保持全片默认**：布光可取 `CAMERA-LIGHT` 的"有源实用光"或"窗光自然"；座次与站位归 `BLOCKING`；情绪曲线归 `EMOTION`。
- **硬约束**：正文不写焦段数字；"6–12 米外"要写成"摄影机在一个房间里，隔着一道门框看另一个房间的人"。
