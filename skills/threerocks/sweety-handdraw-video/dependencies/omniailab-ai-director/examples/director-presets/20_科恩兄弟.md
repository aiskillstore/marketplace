# 科恩兄弟｜Coen Brothers

> **一句话**：把画面摆得一丝不苟，让演员绝对认真地演，然后比该切的时候多留一秒。
> **触发词**：科恩兄弟、黑色幽默、荒诞、命运、地域、冷面

## 一、适用与不适用

**适用**
- 黑色喜剧、犯罪失控、绑架与勒索、**小人物执行大计划**、官僚与流程荒诞。
- 强地域性题材：某个具体的县、某种口音、某种天气、某种连锁店——**具体到能说出品类名称**。
- 需要观众"**笑得不确定**"的段落：同一颗镜头里既有滑稽也有真实的伤害。
- 低成本可行：一条走廊、一间办公室、一片空地加一个正面对称机位就能成段。

**不适用（改用谁）**
- 需要观众情绪代入并被安慰的题材 → 用 **斯皮尔伯格**（01）。
- 浪漫、英雄叙事 → 用 **黑泽明**（04）或 **诺兰**（10）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| **库布里克** | 也广角对称与冷峻形式。库氏的对称意味着"**制度正在碾碎人**"，镜头持续凝视直到观众不适；这里的对称意味着"**宇宙对你毫无兴趣，而你正在被一件小事绊住**"——笑点靠的是**切点比自然出点晚 0.5–1.5 秒**，不是靠长时间凝视。 |
| **雷弗恩** | 也静止、对称、突发暴力。雷弗恩把暴力**美学化、仪式化、无后账**；这里的暴力**笨拙、光打得难看、结束得太快**，而且紧接着就是一个**后勤问题**——一摊要擦的东西、一个看见了的人、一张需要处理的单据。 |
| **芬奇** | 也程序化犯罪。芬奇的专业者**确实专业**，影片尊重那套流程；这里流程被**一个不该做这件事的人**正确地执行了，然后计划自身的逻辑把他杀死——**失败不是因为疏忽，恰恰是因为他很称职**。 |
| **斯科塞斯** | 也犯罪与方言。斯科塞斯的人抢着说话、语速高、摄影机跟着能量走；这里的对白**慢、过分客气、把对方的话原样复述一遍**，一个问题之后留 2–3 秒死寂是常规操作。 |
| **费里尼** | 也有一整廊怪人。费里尼的怪诞是**庆典式、漂移**的；这里每个怪人都被**精确地钉在对称画面的正中**，功能是"情节机器里的一个障碍"——出场、造成延误、退场。 |
| 通用喜剧 | **不给反应镜头收笑点，不给喜剧配乐，不许挤眉弄眼**。喜剧由**几何与时长**产生。演员一旦示意"这句好笑"，这个镜头就废了。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 写出主角的 **5–8 步计划书**，圈出那一步"**因为执行正确才引发灾难**"的动作。
- 每次暴力之后**立刻安排一颗善后镜头**：擦、搬、填表、赔钱。
- 全片保留**唯一一次不开玩笑的镜头**（中焦单人），并把它**放在观众已经笑过之后**。

**2｜空间与机位**
- 给每个正面镜头找一个**正好落在人物头后的东西**（门、窗、牌子），**把它当光环用**。
- **低机位**：广角低机位是这套语法的基础。
- 给每个配角安排**一件与情节无关但必须做完的事**，并规定**主角要等多久**。

**3｜光学与景深**
- 超广到广角做低机位运动与怪诞近景；标准做**冷面正面对称**；中焦是全片**唯一一次不开玩笑**的单人。
- 平衡景深：荒诞来自"画面里所有东西都在正确的位置"，不是来自虚化。

**4｜光影与色彩**
- 3:1 室内；8:1 夜外景。
- **主光改成顶光**，检查每个人眼窝里是否都有阴影；**没有就再抬高灯位**（"难看的顶光"是这套语法的识别特征）。
- 机构米色、汽车旅馆褐、雪白、荧光绿白为主；**地域具体性**要写进美术。

**5｜时间与剪辑**
- 平均镜头 4–9 秒。
- **每颗对话镜头的出点后拖 0.5–1.5 秒**。
- 至少留**一次 2–3 秒的死寂**。
- 慢是策略：对白慢、停顿长，荒诞由节奏产生。

**6｜声音与表演**
- **无喜剧配乐**。音乐若有，只用于环境或片头片尾。
- 地域性写进声音：口音、天气、店铺的招牌与广播。
- 表演是**绝对的认真**：演员必须完全相信自己在做一件重要的事。**任何示意"这句好笑"的表演都会毁掉镜头**。

## 五、可执行清单

1. 写出主角的 **5–8 步计划书**，圈出那一步"**因为执行正确才引发灾难**"的动作。
2. **指定地域**：一个具体的地貌、一种口音、一种天气、一类店铺；写进美术、声音和台词。
3. 给每个正面镜头找一个**正好落在人物头后的东西**（门、窗、牌子），把它当光环用。
4. 把主光改成**顶光**，检查每个人眼窝里是否都有阴影；没有就再抬高灯位。
5. 给每个配角安排**一件与情节无关但必须做完的事**，并规定主角要等多久。
6. 在剪辑里给每颗对话镜头的出点**加 0.5–1.5 秒**，并至少留**一次 2–3 秒的死寂**。
7. 每次暴力之后**立刻安排一颗善后镜头**：擦、搬、填表、赔钱。
8. 全片保留**唯一一次不开玩笑的镜头**（中焦单人），并把它放在观众已经笑过之后。

## 六、与其它层的对接

- **接管**：对称与低机位纪律、顶光要求、切点延后规则、死寂的使用、暴力后的善后镜头、地域具体性、"绝对认真"的表演档位。
- **保持全片默认**：布光可取 `CAMERA-LIGHT` 的"荧光灯工业感"；地域性资产归 `ASSET-SYSTEM`；块序与铁律归 `PROMPT-DOCTRINE`。
- **硬约束**：正文不写焦段数字；"顶光留下眼窝阴影"要写成"光从正上方下来，两只眼窝都落进阴影里，鼻下也有一道暗"。
