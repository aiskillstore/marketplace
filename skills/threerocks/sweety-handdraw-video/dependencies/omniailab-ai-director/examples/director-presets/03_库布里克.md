# 库布里克｜Stanley Kubrick

> **一句话**：让建筑比人更有权力——广角、单点透视、匀速推进，人被压进几何里。
> **触发词**：库布里克、冷峻、对称、制度、理性失控、仪式场面

## 一、适用与不适用

**适用**
- 心理恐怖、科幻寓言、战争讽刺、制度与权力机制、失控的理性、封闭空间。
- 需要观众保持**分析距离**而非情感认同的段落；需要荒诞感与庄严感同时成立的仪式场面。
- 有长走廊、大厅、舱体、机房、营房这类**具备强消失点**的实景或生成场景。

**不适用（改用谁）**
- 需要观众共情主角 → 用 **斯皮尔伯格**（01）；需要手持临场感 → 用 **迈克尔曼**（19）或 **斯科塞斯**（05）。
- 需要柔和情绪转折 → 用 **伯格曼**（07）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| **芬奇** | 同样冷、同样控制，但**背景处理正好相反**：芬奇用长焦把人物从背景里切出来变成样本，背景被压扁成失焦色块；这里用广角单点透视**把人物压进建筑**，背景必须完整清晰，并在构图权重上压过人。 |
| **维伦纽瓦** | 维氏的巨大空间制造**敬畏与渺小**（柔散射、雾做纵深梯度、人只占画幅 5%）；这里的空间制造**秩序与荒诞**（成排硬光源打出的均匀照明、空气里没有梯度、人物骑在中轴上），观众被要求分析而不是仰望。 |
| 对称美学（如娃娃屋式平面构图） | 那种对称是平面化、浅纵深、平移；这里**必须有强消失点和真实纵深**，摄影机沿消失点轴线匀速推轨，纵深本身就是压力。 |
| 恐怖片的黑 | 恐惧来自**高照度、无处可藏**：整体曝光比常规恐怖片亮 2–3 档，让观众看清一切却依然不安。 |
| 手持不安 | 不安来自**摄影机绝对不动或严格匀速直线运动**，而人的行为逐渐反常。任何抖动、任何加减速都会消解风格。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 先写一句"**这个空间代表什么制度或机器**"，再写人物在里面做什么。
- 观众被要求**分析**：特写用于展示人物的僵住、机械化、不合时宜的微笑，**不是让观众替他难过**。
- 结局开放而冷：不给和解，也不给惩罚的满足。

**2｜空间与机位**
- 每个镜头标出**消失点的画面坐标**；不在中央就重新布机位。
- 建筑是第二主角：走廊、舱体、房门阵列本身承担压迫。
- 人物**骑在中轴线上**，不是被缩小；构图权重上建筑压过人。

**3｜光学与景深**
- 广角制造单点透视与轻微脸部变形，让走廊两壁在画面里收拢；标准焦段只在**需要一个"正常"参照镜头**时使用，用量不超过全段的五分之一。
- **深焦**：背景必须完整清晰——背景模糊就等于取消了这套机制。

**4｜光影与色彩**
- **成排硬光源打出的均匀照明**，空气里没有体积光梯度。光比偏平（约 2:1，压迫最强处可到 1.5:1）。
- 冷白、灰、纯黑为主；**每个空间分配一个饱和色块**，墙与地保持低饱和。
- 检查照度：如果观众需要眯眼才能看清角落，就**打亮两档**。

**5｜时间与剪辑**
- 平均镜头长度 **12–40 秒，极少低于 6 秒**。长凝视是主体语法。
- 摄影机运动写成数值：方向、速度（约 0.1–0.25 米/秒）、时长，并注明**无加减速**。
- 挑一个动作在段落里**重复 2–3 次，每次只改一个细节**（仪式化重复）。
- 结尾用**与开场相同的构图，只换内容，不换机位**。

**6｜声音与表演**
- 音乐从段落头**覆盖到尾**，不跟随画面情绪起伏（不去"配"情绪）。
- 表演要求**克制与机械化**：情绪外露被压制，反常藏在微小处。
- 环境声要干净、空间感明确（走廊回声、舱体低频）。

## 四、风格参数（选型台）

```yaml
style_id: kubrick
lens_character: 临床锐利定焦        # 无光学性格、畸变可控
focal_bands: [超广, 广角]           # 标准焦段仅作"正常"参照，用量 < 20%
aperture_band: 深焦
camera_prefer: [固定, 沿消失点匀速推轨（0.1–0.25 m/s、无加减速）]
camera_avoid: [手持, 抖动, 斜角, 变速, 绕主体旋转, 无动机摇摄]
motion_budget: 极低但恒定
lighting: {ratio: 2:1（最强处 1.5:1）, style: 成排硬光源均匀照明, gradient: 无体积光梯度, exposure: 比常规恐怖片亮 2–3 档}
palette: {dominant: 冷白、灰、纯黑, accent: 每空间一个饱和色块, walls_floor: 低饱和}
editing: {asl_s: 12–40（极少 < 6）, transitions: [硬切], ending: 与开场同构图只换内容}
sound: {music: 覆盖整段、不配情绪起伏, ambience: 空间感明确、干净}
performance: {register: 克制、机械化, close_up: 展示僵住与不合时宜的微笑}
aspect: 1.85:1 / 1.66:1（避免过宽画幅，会削弱建筑的垂直压迫）
clip_s: 8–12（推轨需行程；短于 6 秒看不出匀速）；12–40 秒长凝视用同参数分段续接拼出
negative: [手持抖动, 斜角, 广角扭曲人脸, 体积光雾, 情绪化配乐, 浅景深, 快速剪辑]
```

## 五、可执行清单

1. 先写一句"**这个空间代表什么制度或机器**"，再写人物在里面做什么。
2. 为每个镜头标出**消失点的画面坐标**；不在中央就重新布机位。
3. 把摄影机运动写成数值：方向、速度、时长，并注明**无加减速**。
4. 检查照度：若要眯眼才看清角落，就打亮两档。
5. 挑一个动作，让它在段落里**重复 2–3 次**，每次只改一个细节。
6. 给每个空间分配一个**饱和色块**，墙地保持低饱和。
7. 音乐从段落头覆盖到尾，不跟随画面情绪起伏。
8. 结尾用与开场相同的构图，只换内容。

## 六、与其它层的对接

- **接管**：机位与消失点纪律、摄影机速度规范、照度与反差策略（高照度恐惧）、长凝视节奏、仪式化重复、结尾构图回环。
- **保持全片默认**：布光方案可从 `CAMERA-LIGHT` 的"荧光灯工业感"取三灯结构；站位的中轴纪律交 `BLOCKING` 执行；块序与铁律归 `PROMPT-DOCTRINE`。
- **硬约束**：正文不写焦段数字与速度数值；"匀速推轨"要写成"摄影机保持恒定速度沿走廊轴线前进，全程不加不减"。
