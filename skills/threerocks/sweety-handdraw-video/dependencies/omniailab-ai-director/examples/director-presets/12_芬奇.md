# 芬奇｜David Fincher

> **一句话**：用长焦把人从背景里切下来，再从他不知道的位置上看着他。
> **触发词**：芬奇、冷静、精确、调查、程序、职场操纵

## 一、适用与不适用

**适用**
- 犯罪悬疑与连环案、调查与程序叙事、技术行业与媒体操纵、心理冷酷的家庭暴力、职业流程剧、阴冷都市夜景。
- 特别适合"**信息不对称**"驱动的段落：谁知道什么、何时知道、怎么被揭穿。

**不适用（改用谁）**
- 需要观众与人物的共情到失控的段落 → 用 **斯皮尔伯格**（01）。
- 手持纪实 → 用 **迈克尔曼**（19）；温暖家庭剧 → 用 **侯孝贤**（16）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| **库布里克** | 也冷、也几何、也控制。库氏用广角单点透视把人**压进建筑**（走廊本身是第二主角）；这里用长焦把人从背景里**抠出来变成样本**，背景被压扁成失焦色块，建筑退化为环境噪音。 |
| **维伦纽瓦** | 也低饱和。维氏一个段落只有一个主导色相、用雾做纵深梯度；这里**同时保住青绿阴影与琥珀实用光两级**，而且**空气必须干净**——没有雾、没有丁达尔光柱、没有灰尘。 |
| **雷弗恩** | 也是精确的静止构图。雷弗恩的静止是**仪式**，画面可以不给信息；这里的静止是**监视**，每一帧都必须传递可读的事实。 |
| 手持惊悚 | **不许抖**。紧张来自剪辑点的精确和信息的不对称，不来自晃动；镜头呼吸幅度为零。 |
| **诺兰** | 也冷调理性。诺兰给观众规则和倒计时；这里**刻意不给规则**——观众和调查者一样只能靠积累的证据推断，且推断可能是错的。 |
| **王家卫** | 也拍城市夜、也用实用光。王氏要色彩污染、前景遮挡、错误的取景；这里要**通透、可读、无遮挡**——观众必须看清每一个细节才会不安。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 画**信息流动表**：谁在第几分钟知道什么，观众领先或落后多少。
- 规则永远不被完整交出——**观众与调查者同步推断，且可能推断错**。
- 结尾**删掉清算式高潮**，留一个未闭合的事实。

**2｜空间与机位**
- 机位放在**人物不知道的位置**：门外、玻璃后、走廊尽头、天花板角落。
- 每个镜头写出机位三要素（高度、距离、角度），确保**可精确复现**（复现性是这套语法的核心）。
- 静止但不空：画面里必须有可读的证据物件。

**3｜光学与景深**
- **中长焦为主**：把人从背景里抠出来，背景被压成不可读的色块；广角只用于一次性交代几何。
- 极浅但**可控**：焦点精确落在眼睛与手，不做情绪化虚化。
- 画幅宽——用横向排列证据与空间关系。

**4｜光影与色彩**
- **同时保住青绿阴影与琥珀实用光两级**；黑位要**抬起**——阴影里能看见纹理，不是死黑。
- **空气必须干净**：没有雾、没有光柱、没有灰尘。**灯是可数的**：每个场景点名实用光源实体，并确认它在画面里可见或其方向可推断。
- 光比 4:1 到 6:1。

**5｜时间与剪辑**
- 平均镜头 **4–9 秒**；场景内的信息蒙太奇可降到 **0.5–1.5 秒**。
- 运动写成**画幅百分比＋秒数**（例如"8 秒内推 4%"）——运动必须可度量。
- 给一场戏安排一次 **2–3 秒的静默长挂**，写明观众该在这段时间里发现什么。

**6｜声音与表演**
- 配乐极少或为低频电子；环境声精确（键盘、空调、远处电梯）。
- 对白少而准：每一句都推动信息，没有寒暄。
- 表演**压抑、专业、几乎无表情**；情绪从流程与效率的冷静里渗出。

```yaml
camera_height: 人物不知道的位置（门外／玻璃后／走廊尽头／天花板角落）
camera_prefer: [固定, 可度量的缓慢推进（画幅百分比＋秒数）]
camera_avoid: [手持, 抖动, 呼吸式晃动, 无度量的漂移]
motion_budget: 极低
lighting: {ratio: 4:1–6:1, palette_two_tier: 青绿阴影 ＋ 琥珀实用光, black_lift: 阴影里可见纹理, air: 干净（无雾、无光柱、无尘）}

aspect: 2.39:1
clip_s: 4–8

```

## 五、可执行清单

1. 画出**信息流动表**：谁在第几分钟知道什么，观众领先或落后多少。
2. 为每个镜头写出**机位三要素**（高度、距离、角度），确认可精确复现。
3. 选定长焦焦段，确认**背景被压成不可读的色块**。
4. 点名每个场景的**实用光源实体**，并确认它在画面里可见或其方向可推断。
5. 检查阴影：**黑位必须抬起**，阴影里能看见纹理。
6. 把镜头推进写成**画幅百分比和秒数**（例如 8 秒内推 4%）。
7. 给一场戏安排一次 **2–3 秒的静默长挂**，写明观众该发现什么。
8. 结尾**删掉清算式高潮**，留一个未闭合的事实。

## 六、与其它层的对接

- **接管**：机位可复现纪律、长焦样本化与背景处理、两级色彩与黑位抬起、空气洁净要求、可度量运动、信息流动表。
- **保持全片默认**：布光可取 `CAMERA-LIGHT` 的"荧光灯工业感"或"黑色电影"；站位归 `BLOCKING`；块序与铁律归 `PROMPT-DOCTRINE`。
- **硬约束**：正文不写光圈与焦段数字；"极浅景深"要写成"只有桌面上那份文件是清晰的，他身后整片街道化成一团冷色"。
