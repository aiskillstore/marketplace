# 希区柯克｜Alfred Hitchcock

> **一句话**：把秘密先交给观众，再让角色慢慢走进去——等待本身就是段落。
> **触发词**：希区柯克、悬念、紧张、跟踪、身份错置、单场戏锁人

## 一、适用与不适用

**适用**
- 悬疑、惊悚、犯罪、心理恐怖；跟踪戏、误认与身份错置、密室段落。
- 需要在**日常空间**（楼梯、厨房、办公室、车厢、洗手间）里制造威胁的段落。
- 短片与广告中需要用 20–60 秒把观众按在座位上的单场戏。

**不适用（改用谁）**
- 需要观众与角色**同步无知**的鬼屋式恐怖 → 用 **雷弗恩**（13）或 **朴赞郁**（17）。
- 需要开放式意象的作者电影 → 用 **塔可夫斯基**（08）或 **马力克**（18）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| **芬奇** | 芬奇用**系统视角**（监控位、玻璃后、走廊尽头）做客观观察；这里摄影机是**有身体的偷窥者**，"看—所见—反应"三镜结构应占镜头数一半以上，观众被指认为共犯。 |
| 现代跳吓惊悚 | 跳吓靠观众**不知道**；这里必须观众**先知道**。从"危险被揭示给观众"到"抵达角色"之间要**撑满 20–60 秒**——跳吓风格里这个间隔是 0 秒。 |
| 恐怖片的黑 | 威胁发生在**明亮、整洁、正在被使用**的空间里。降的是**杂乱度**不是照度，反差照旧硬 4:1；但**阴影必须是可辨认的几何形状**，不是吞掉细节的大块黑。 |
| 分屏与炫技并置 | 信息不对称由**剪辑顺序与画外空间**承担，不由画面分割承担。观众必须"记住"另一个空间，而不是同时看见它。 |
| 血浆片 | 暴力用**碎片化插入＋声音**完成：平均镜头长度可从 4–9 秒骤降到 0.4–1.5 秒，但**完整动作永远不在一个镜头里出现**。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 核心是一句话能写出的信息差：**"观众知道 X，角色不知道 X"**。写不出这句，说明这个段落不该用本风格。
- **麦高芬只负责让人物移动**；摄影机的注意力必须始终落在罪感、欲望与观众的共谋感上。拿掉麦高芬段落就垮 → 说明写错了。

**2｜空间与机位**
- 段落开始时用广角**一次性交代房间地图**，此后所有镜头都在这张地图内成立。
- 摄影机是**偷窥者**：机位常被家具、门框、窗帘"挡住一部分"，观众通过缝隙看。
- 三个可数节拍：危险被观众看见 → 角色向危险靠近 → 危险抵达。每个节拍有自己的时长。

**3｜光学与景深**
- 广角交代地图；标准焦段做客观中性眼；**中长焦做"凝视的选择性"**——把远处的危险压缩到观众眼前，让角色与危险同框而互不知情。
- 承载秘密的物件给一个中长焦特写，**此后每次出现都用同一景别**（同一景别＝同一心理标记）。

**4｜光影与色彩**
- 光比 4:1，阴影保留可辨几何。中性冷灰、米白、家具木色为主——**画面越干净，观众越要替角色去扫每个角落**。
- 光源多为日常（台灯、走廊灯、窗外光），但**阴影形状要刻意**：百叶、栏杆、门缝形成的条纹是好用的语法。

**5｜时间与剪辑**
- 基线平均镜头长度 4–9 秒；暴力瞬间骤降到 0.4–1.5 秒。
- **延迟是主体**：把等待切成 3–5 个可数节拍，而不是让一个长镜头等。
- 每次收紧之后放**一句轻台词或一个日常动作**，为下一次收紧做准备（松—紧交替，不是一路紧）。
- 单人主观段落可用更方的画幅压缩两侧的逃逸空间。

**6｜声音与表演**
- 为段落指定一个**"时钟"声音**（滴水、钟摆、远处施工、心跳式低频），写进声音表。
- **反派要优雅**：礼貌、有条理、语速平稳——威胁来自教养与冷静的落差。
- 表演要求克制：恐惧由**呼吸、手部小动作与目光的晚一步**承担，不靠尖叫。

## 四、风格参数（选型台）

```yaml
style_id: hitchcock
lens_character: 旗舰现代定焦
focal_bands: [广角, 标准, 中长焦]      # 宽交代地图 / 标准客观眼 / 中长焦做凝视压缩
aperture_band: 平衡景深
camera_prefer: [固定, 缓慢横移跟随, 越过遮挡物的推近, 主观视线三镜]
camera_avoid: [手持抖动, 环绕, 无动机升降, 高速推拉]
motion_budget: 低
lighting: {ratio: 4:1, shadow: 形状可辨、保留细节, source: 日常实用光}
palette: {dominant: 中性冷灰、米白、家具木色, saturation: 低, contrast: 中}
editing: {asl_s: 4–9 基线 / 0.4–1.5 仅暴力瞬间, delay_beats: 3–5 可数节拍, rhythm: 松紧交替}
sound: {clock: 指定一个时钟声贯穿段落, violence: 声音在前、碎片在后}
performance: {villain: 优雅、礼貌、语速平稳, fear: 由呼吸与手部小动作承担}
aspect: 1.85:1；单人主观段可收到 1.66:1
clip_s: 3–6 延迟节拍 / 1–2 碎片插入
negative: [血浆特写, 完整暴力动作, 镜头抖动, 分屏, 大块无细节黑, 无动机炫技运镜]
```

## 五、可执行清单

1. 写一行"**观众知道 X，角色不知道 X**"；写不出就换风格。
2. 把危险抵达时间定成秒数（20–60 秒），并切成 3–5 个可数节拍。
3. 选一个**承载秘密的物件**，给它一个中长焦特写，之后每次出现都用同一景别。
4. 用广角给房间**画一次地图**，此后所有镜头都在这张地图内成立。
5. 每个主观段落凑齐"**看—所见—反应**"三镜，并检查三镜共享同一条视线轴。
6. 为段落指定一个**时钟声音**，写进声音表。
7. 暴力只给碎片：列出 3 个局部镜头，永远不拍完整动作。
8. 最紧的节拍之后放一句轻台词或一个日常动作。

## 六、与其它层的对接

- **接管**：信息节奏（何时让谁知道什么）、偷窥机位语法、延迟节拍划分、暴力碎片化规则、时钟声音。
- **保持全片默认**：光比细则可参考 `CAMERA-LIGHT` 的布光方案（推荐"高对比三点"）；站位与遮挡关系归 `BLOCKING`；块序与铁律归 `PROMPT-DOCTRINE`。
- **硬约束**：正文不写焦段数字；"阴影是可辨认的几何形状"要写成可见描述（百叶条纹、栏杆投影）。
