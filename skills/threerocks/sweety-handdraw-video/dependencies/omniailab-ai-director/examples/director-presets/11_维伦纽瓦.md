# 维伦纽瓦｜Denis Villeneuve

> **一句话**：把人缩到画面高度的百分之五，然后给他二十秒，什么也不解释。
> **触发词**：维伦纽瓦、宏大、雾、渺小、肃穆、缓慢恐惧

## 一、适用与不适用

**适用**
- 科幻寓言、第一接触、缓慢恐惧、犯罪程序剧、**巨型建筑与荒漠地貌**、人在系统性力量前的渺小感。
- 需要"**看不清也听不清**"作为主题的段落。
- 低成本也可成立：一堵大墙、一台雾机、一个逆光窗。

**不适用（改用谁）**
- 需要密集信息交付的段落 → 用 **诺兰**（10）或 **芬奇**（12）。
- 喜剧、群戏对白 → 用 **费里尼**（06）或 **科恩兄弟**（20）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| **诺兰** | 也大尺度、也低频。诺兰在巨物**旁边工作**，三条线交叉，平均单镜 3 秒，人物永远在**赶时间**；这里镜头**停下来看**，单镜 12–18 秒，一个人穿过画面就是全部事件，倒计时不存在。 |
| **库布里克** | 也巨大空间。库氏靠**填满秩序**（成排硬光源的均匀照明、人物骑在中轴）制造荒诞；这里靠**清空**（负空间、单一色相、柔散射、人物只占 5%）制造敬畏。 |
| **塔可夫斯基** | 也慢、也有精神性。塔氏贴到一米内看湿木头的纹理，**质地是主题**；这里退到几十米外，**距离本身是主题**，画面的信息量被刻意抽空。 |
| **雷弗恩** | 也对称、也慢。雷弗恩的对称是**舞台仪式**（纯色块、硬边界、高饱和）；这里的对称是**建筑测量**（单一低饱和色调、柔散射、无硬边阴影），人物小到读不出表情。 |
| 通用科幻 | **禁止发光全息 UI、悬浮蓝色数据、拥挤的赛博霓虹街**。未来是巨大的、素净的、几乎没有装饰的混凝土、石材与雾——**表面越空，尺度越可信**。 |
| 恐怖片 | 威胁不靠跳吓。**低频先到、画面后到**，观众在听见之后才看见，中间隔 2–4 秒。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 先写**形而上问题一句话**，再设计奇观；**奇观必须是这个问题的物证**。
- 人物不说话也成立：事件由环境与比例承担。
- 结尾是**一个动作**，不是一个答案。

**2｜空间与机位**
- 给出人物占画面高度的**百分比（5%–15%）**，以及画面里的**已知尺寸参照物**（门、车、人、梯）。
- 写出雾／沙／雨**从第几米开始起作用**，以及远处比近处淡几档。
- 镜头运动只用**三选一**：锁死、恒速横移、恒速推进，并写出**总位移米数**。

**3｜光学与景深**
- 中广给纪念碑尺度；标准给程序化中景；中长焦压缩疲惫的脸。**不用超广也不用超长**（两者都会破坏"丈量"的冷静）。
- **深焦**为主：建筑的几何要完整可读。

**4｜光影与色彩**
- 光比 **5:1 到 8:1**，且是**逆光面对正面补光**（不是常规的主光对补光）。
- **一个段落只有一个主导色相**；写出什么事件会触发换色。
- **空气必须有可见的雾或沙**作为纵深梯度——没有介质的低饱和会变成"脏"。

**5｜时间与剪辑**
- 平均镜头 **8–18 秒**。
- 安排一次**低频先于画面 2–4 秒**进入的时刻。
- 计划一个 **5–8 秒的余波镜头**：事件结束后观众该看什么。
- 宽画幅强化水平线与"横向丈量"。

**6｜声音与表演**
- 低频轰鸣与寂静是主语法；音乐少而大，不做情绪跟随。
- 表演**内敛到近乎无表情**：人物小到读不出情绪时，情绪转由姿态与环境承担。
- 环境声（风、沙、金属共振）要有空间感。

## 五、可执行清单

1. 先写**形而上问题一句话**，再设计奇观；奇观必须是这个问题的物证。
2. 指定本段**唯一主导色相**，并写明什么事件会触发换色。
3. 给出人物**占画面高度的百分比**（5%–15%），以及画面里的已知尺寸参照物。
4. 写出**雾／沙／雨从第几米开始起作用**，远处比近处淡几档。
5. 把镜头运动限制为**锁死、恒速横移、恒速推进**三选一，并写出总位移米数。
6. 安排一次**低频先于画面 2–4 秒**进入的时刻。
7. 计划一个 **5–8 秒的余波镜头**，写明事件结束后观众该看什么。
8. 让结尾是**一个动作**而不是一个答案。

## 六、与其它层的对接

- **接管**：主体占画幅比例、介质（雾／沙）的纵深规则、单色相纪律、逆光为主的曝光策略、恒速运动规范、低频前置。
- **保持全片默认**：布光可取 `CAMERA-LIGHT` 的"月光"或"蓝调时刻"；站位比例归 `BLOCKING`；块序与铁律归 `PROMPT-DOCTRINE`。
- **硬约束**：正文不写焦段数字与百分比术语；"占画面高度 5%"要写成"人只占画面很窄的一段高度，整面墙与天空压在他上方"。
