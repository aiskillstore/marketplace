# 雷弗恩｜Nicolas Winding Refn

> **一句话**：机位锁死、人在正中、什么都不动，让颜色替所有人做完这场仪式。
> **触发词**：雷弗恩、霓虹、对称、仪式、极简、风格化犯罪

## 一、适用与不适用

**适用**
- 风格化犯罪、寓言式短片、时尚惊悚、缓慢恐怖、宗教或仪式感空间、沉默角色与极端美学并存的段落。
- **这套语言对生成模型格外友好**：无位移、无复杂调度、单一光源、单一平面——能出错的地方比其他风格少一个数量级，你几乎只需要守住构图不塌。

**不适用（改用谁）**
- 需要交代因果的叙事段落、群戏对白 → 用 **芬奇**（12）或 **科恩兄弟**（20）。
- 依赖观众共情的情节 → 用 **斯皮尔伯格**（01）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| **王家卫** | 也霓虹夜。王氏是小幅手持、拖影、偏心构图、前景永远有东西挡住；这里是**锁死机位、绝对正面对称、人物在画幅正中**，画面里没有一件多余的物体，也没有一处遮挡。 |
| **芬奇** | 也精确控制。芬奇的控制**服务于信息传递**，每帧必须可读；这里的控制**服务于仪式**，一个镜头可以什么信息都不给，只给一个姿势和一片颜色。 |
| **维伦纽瓦** | 也对称、也慢。维氏的对称是**建筑测量**（单一低饱和、柔散射、无硬边）；这里的对称是**舞台**（纯色高饱和、灯光有硬边界、色与色之间可以直接切开，像展览而不像空间）。 |
| **库布里克** | 也中心对称。库氏靠广角单点透视的**纵深走廊**制造建筑压迫；这里**没有纵深**，用平面化的正面墙面把人物压成一张画。 |
| 恐怖片 | 不用渐强弦乐，不做跳吓。暴力是**一次性的、无预警的、发生在画面正中的**，且结束后**立刻回到与之前完全相同的静止构图**。 |
| 时尚广告 | 广告用慢动作展示物体质感；这里用**静止**让观众在一个不动的画面里**等到不舒服为止**（12 秒以上）。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 选定一个**寓言主题**（欲望／复仇／嫉妒／自毁），并**禁止为它写任何动机说明**。
- 只给一个**微动作**（眨眼一次、转头、把一样东西放到正中），其余交给灯光变化。
- 结尾**停在姿势上**，不给解释、不给反应镜头。

**2｜空间与机位**
- 找到空间的**中轴**，把摄影机放上去，**与墙面成 90 度**。
- 画面里**没有多余的物体、没有遮挡**——平面化，用正面墙把人物压成一张画。
- 人物居中，体态对称；空间像展台而非房间。

**3｜光学与景深**
- 中广把房间拍成**舞台**；标准拍仪式中景；中长焦拍锁死的脸。
- **避免长焦压缩与广角变形**——两者都会破坏正面平面感。（这也是它对生成模型友好的原因：单一平面，无压缩需求。）

**4｜光影与色彩**
- 光比 **8:1 到 12:1**；纯色高饱和、**灯光有硬边界**、色与色之间可以直接切开。
- 指定**两种颜色**和它们**分界线在画面里的位置**，并把分界线**钉在一条已有的竖直边上**（例如左半品红、右半电光蓝，分界线在画幅中线偏右，正好压在门框竖边上）。
- 颜色是"填充"而非"照明"：像色纸，不像环境光。

**5｜时间与剪辑**
- 平均镜头 **10–25 秒**；单镜定到 **12 秒以上**，并写明观众在这 12 秒里应该开始感到**不适**。
- 摄影机基本不动；唯一的变化来自灯光与微动作。
- 暴力或决断：**无预警、单镜完成、发生在画面正中**，前后各挂一个**完全相同的静止构图**。

**6｜声音与表演**
- **合成器音墙**贯穿；低频持续。对白极少或没有。
- 表演**催眠式缓慢**：体态不动，只有微小的表情变化；人物被物化为"被观看的对象"。
- 声音与画面的反差是语法的一部分（音墙在动，画面不动）。

## 五、可执行清单

1. 选定一个**寓言主题**（欲望／复仇／嫉妒／自毁），并**禁止为它写任何动机说明**。
2. 找到空间的**中轴**，把摄影机放上去，与墙面成 90 度。
3. 指定**两种颜色**和它们**分界线在画面里的位置**，把分界线钉在一条已有的竖直边上。
4. 设计一个**可重复的仪式动作**，并规定它出现的次数。
5. 把单镜时长定到 **12 秒以上**，写明观众在这 12 秒里应该开始感到不适。
6. 只给**一个微动作**，其余交给灯光变化。
7. 安排一次暴力或决断：**无预警、单镜完成、发生在画面正中**，前后各挂一个完全相同的静止构图。
8. 结尾**停在姿势上**，不给解释、不给反应镜头。

## 六、与其它层的对接

- **接管**：机位锁死纪律、正面平面构图、纯色硬边界与分界线位置、极长单镜、仪式动作重复、暴力的一次性处理。
- **保持全片默认**：布光可取 `CAMERA-LIGHT` 的"霓虹都市夜"或"MV 戏剧光"；站位只在"中轴居中"这一项上服从本层；块序与铁律归 `PROMPT-DOCTRINE`。
- **硬约束**：正文不写焦段数字；"纯色硬边界"要写成"左半画面被一片浓品红占据，右半是电光蓝，两者之间是一条笔直的分界，正好压在门框的竖边上"。
