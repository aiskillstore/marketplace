# 毕赣｜Bi Gan

> **一句话**：摄影机像一个没睡醒的人，沿一条能画在地图上的路，一直走进梦里。
> **触发词**：毕赣、小镇、长镜、梦、潮湿、路径式长镜

## 一、适用与不适用

**适用**
- 华语小镇叙事、诗电影、梦与现实交叠、寻人与寻记忆、潮湿西南地貌、低成本高氛围段落、长镜实验、魔幻现实主义。
- 适合**有真实场地但没有预算做复杂分镜**的项目：一条路线就是一场戏。

**不适用（改用谁）**
- 需要多机位覆盖的对白戏 → 用 **伯格曼**（07）或 **侯孝贤**（16）。
- 剪辑驱动的类型片、需要观众看懂因果的段落 → 用 **诺兰**（10）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| **塔可夫斯基** | 也长镜头、也水。塔式镜头几乎不位移，压力是**垂直**的（滴落、下沉、仰望）；这里镜头**持续水平漂移**，穿台球室、桥洞、楼梯、雨街，靠**地理的连续性**把梦缝在一起——**位移本身就是叙事**。 |
| **王家卫** | 也有怀旧流行乐与旁白。王氏的旁白是第一人称自述、带具体日期与编号，画面是**碎片跳接**；这里的旁白是**诗**，人称模糊，与眼前画面刻意错位（说的是另一个人、另一场雨），而**剪辑几乎不存在**。 |
| **雷弗恩** | 也霓虹。雷弗恩是干净的纯色块舞台光、硬边界；这里的霓虹是**脏的**、被雨和雾散开，混着白炽灯泡、荧光管和电视屏，**色与色互相污染**，没有边界。 |
| **维伦纽瓦** | 也雾。维氏的雾是几何空间的**纵深梯度**，人物极小；这里的雾是**气候和皮肤的湿度**，摄影机贴着人走，距离常在 1–3 米。 |
| 通用文艺片 | **不是"长镜头＋空镜＋无对白"就成立**。长镜头必须有**一条能画在地图上的路径**，以及**至少一次穿越**（门／桥洞／隧道／水面／镜子）作为时空转场；没有路径的长镜头只是没剪好的素材。 |
| 悬疑或恐怖 | 不解释机制，也不制造威胁。**观众困惑的对象是时间，不是危险**。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 先确定**要找的人或记忆**，再画**路径**：起点、3–5 个途经点、终点。
- 选一件**重复物件**，写明它两次出现时的状态差别。
- 写一段**诗歌旁白**，确保它**谈论的对象不在画面里**。
- 不解释机制：时间会自己错位。

**2｜空间与机位**
- 路径上至少安排**一次穿越**（门／桥洞／隧道／雨帘／水面／镜子），并规定**穿越后什么改变了**。
- 摄影机速度 **0.8–1.2 米/秒**，**滞后人物 1–2 秒**（"晚一步"的感觉）。
- 广角为主：狭窄空间可通行、自然景深、湿反光铺满画面。

**3｜光学与景深**
- 广角为主（狭窄空间可通行）；**自然景深**，靠画面的层次而非虚化建立深度。
- 镜头贴人走（1–3 米），湿反光与雨幕承担光学趣味。

**4｜光影与色彩**
- 光比 **2.5:1 到 3.5:1**，柔和。
- **每个途经点指定一种主光源类型**（霓虹／荧光管／白炽／电视／火）。
- **先设计水，再设计灯**：哪里有积水、哪里在滴、谁穿雨衣。
- 潮湿青绿、暗紫、钨丝琥珀为主；霓虹是**脏的**，与乡镇光源混在一起。

**5｜时间与剪辑**
- 平均镜头 **45–600 秒**（极长）。
- **长镜靠首尾帧串联，不指望单条片段完成**（这对生成工具尤其重要）。
- **规定镜头在人物离开后继续拍什么、拍多久**（这是这套语法的收尾方式）。

**6｜声音与表演**
- 怀旧老歌（磁带质感）、诗旁白、环境声（雨、虫、水）。
- 表演**松弛、近似日常**：人物不为了镜头表演，走路的姿态比表情重要。
- 对白少，且常常听不清内容——信息由画面与旁白承担。

## 五、可执行清单

1. 先确定**要找的人或记忆**，再画出路径：起点、3–5 个途经点、终点。
2. 给每个途经点指定**一种主光源类型**（霓虹／荧光管／白炽／电视／火）。
3. 在路径上安排**至少一次穿越**（门／桥洞／隧道／雨帘／水面／镜子），并规定穿越后什么改变了。
4. **先设计水**：哪里有积水、哪里在滴、谁穿雨衣——再设计灯。
5. 设定摄影机**速度（0.8–1.2 米/秒）**和**滞后量（落后人物 1–2 秒）**。
6. 选一件**重复物件**，写明它两次出现时的状态差别。
7. 写一段**诗歌旁白**，确保它谈论的对象不在画面里。
8. 规定镜头在**人物离开后继续拍什么、拍多久**。

## 六、与其它层的对接

- **接管**：路径式长镜结构、穿越式转场、摄影机速度与滞后量、水先于灯的设计顺序、脏霓虹口径、长镜的收尾方式。
- **保持全片默认**：布光可取 `CAMERA-LIGHT` 的"雾中实用光源"；站位与路径坐标归 `BLOCKING`；块序与铁律归 `PROMPT-DOCTRINE`。
- **硬约束**：正文不写速度数值；"滞后 1–2 秒"要写成"摄影机总是比他晚半步到达，等他走出画面中心才跟上"。
