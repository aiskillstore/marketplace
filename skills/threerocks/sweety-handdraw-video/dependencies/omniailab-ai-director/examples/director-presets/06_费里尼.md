# 费里尼｜Federico Fellini

> **一句话**：怪异全部长在真人身上——脸、身体、服装、姿态；摄影机在人群里游动，不停下。
> **触发词**：费里尼、梦境、游行、荒诞、群像狂欢、自传

## 一、适用与不适用

**适用**
- 梦境段落、自传性叙事、艺术家困境、荒诞喜剧、回忆结构、城市漫游、**群像仪式**（游行、派对、集会、婚礼、葬礼）。
- 需要喜剧与悲伤同时在场的段落；需要主角**被一群人包围却更孤独**的段落。
- 时尚片、音乐录影、品牌短片里需要"**生命剧场**"感的群像调度。

**不适用（改用谁）**
- 需要严密因果的类型片情节 → 用 **芬奇**（12）或 **诺兰**（10）。
- 需要观众相信空间地图的动作戏 → 用 **斯皮尔伯格**（01）或 **黑泽明**（04）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| 通用超现实 | 超现实靠不可能的物件与视觉扭曲（漂浮、变形、拼贴）；这里的怪异**全部来自真实的人**——脸、体型、服装、姿态的奇观性。场景本身保持物理可信，重力不失效。 |
| **塔可夫斯基的梦** | 塔氏的梦缓慢、静默、物质性（水、火、尘、时间）；这里由**音乐驱动**，节拍接近圆舞曲或进行曲，人声嘈杂，**几乎没有静默**。 |
| 低频压迫式梦境 | 那类梦境是威胁性的、缓慢的、靠低频与声音设计压迫；这里喧闹、外向、由人群与游行推进，情绪是**滑稽与悲伤同时在场**，不是恐惧。 |
| 对称平面构图 | 那种做法用对称、平面正交、居中定格；这里摄影机**在人群中游动**（跟移＋摇摄），人物从画面边缘陆续进入，构图持续被打断和重组。 |
| 转场特效 | 现实滑入幻想**不靠溶解、变形或粒子**。方法是在**同一空间内让群众行为逐级升级**——先多出一个不合时宜的人，再多出五个，直到空间变成舞台，而观众说不清是哪一秒变的。 |
| 无结构漫游 | 离题必须**回旋**：同一意象在段落里至少出现两次，第二次带着第一次积累的情绪回来，否则只是散。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 选 **3 个意象**，规划它们各出现**两次**，第二次改变一个属性（颜色、方向、伴随的人）。
- 现实到幻想的**升级台阶**：多出 1 个不合时宜的人 → 多出 5 个 → 空间变成舞台。
- 允许 **15–25% 的镜头与情节无关**，用来撑世界的密度。

**2｜空间与机位**
- **游行式调度**：人群有队列感但不整齐，摄影机沿队列横向游动。
- 给场上每个群众角色写**一句话身份 ＋ 一个正在做的动作**；写不满就减少人数。
- 安排一次**垂直事件**（梯子、楼台、抛起、突然的高度），让平面人群突然有高度。

**3｜光学与景深**
- 广角装下整支队伍与前景穿行；标准焦段做**正面近景的漫画式透视夸张**（不要用长焦去"修正"脸）；中广做人群跟移的默认焦段。
- 平衡景深：人群的表演必须可读。

**4｜光影与色彩**
- 光比 4:1，**阴影保留细节**（不做纯黑，因为这是"白天的梦"）。
- 粉、金、酒红、天蓝为主；色彩可以艳，但光源要有来源（舞台灯、灯笼、窗光）。
- 黑白段落是合法的（回忆／梦境分层）。

**5｜时间与剪辑**
- 平均镜头 6–14 秒；**结尾段拉到 15–30 秒**。
- **先定音乐再定调度**，让人物的步速跟上乐句。
- 剪辑是"接"而非"切"：镜头之间常有重叠动作或音乐延续。

**6｜声音与表演**
- 音乐驱动（圆舞曲、进行曲），人声嘈杂，**几乎没有真正的静默**。
- 表演是**剧场式**：夸张的姿态与表情，但动机是真实的羞耻与欲望。
- 群众的声音要有层次：远处合唱、近处交谈、个别人在喊。

## 五、可执行清单

1. 选 **3 个意象**，规划它们各出现两次，第二次改变一个属性。
2. 给场上每个群众写**一句话身份 ＋ 一个正在做的动作**；写不满就减人。
3. 设计现实到幻想的**升级台阶**：多出 1 个不合时宜的人 → 多出 5 个 → 空间变成舞台。
4. **先定音乐再定调度**，让人物步速跟上乐句。
5. 摄影机全段游动，写出速度（约 0.4–0.8 米/秒）与每次交接给下一张脸的时间点。
6. 安排一次**垂直事件**，让平面人群突然有高度。
7. 允许 15–25% 的镜头与情节无关，用来撑世界密度。
8. 结尾让队列继续走，用一个 15–30 秒的长镜收，不给答案。

## 六、与其它层的对接

- **接管**：群像调度的人数与身份纪律、意象回旋结构、现实到幻想的升级方式、音乐先行的节奏规则。
- **保持全片默认**：布光可取 `CAMERA-LIGHT` 的"动画平光"或"蝴蝶光"；群众站位归 `BLOCKING`；情绪曲线归 `EMOTION`。
- **硬约束**：正文不写焦段数字；"漫画式透视夸张"要写成"靠近的脸被放大，鼻与颧骨的体积明显压向镜头"。
