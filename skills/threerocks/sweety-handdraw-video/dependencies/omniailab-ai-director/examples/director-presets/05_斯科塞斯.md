# 斯科塞斯｜Martin Scorsese

> **一句话**：让摄影机被欲望拖着走，用音乐把上升拍得好看，再用静默让代价落地。
> **触发词**：斯科塞斯、犯罪、旁白、都市、圈层、道德坠落

## 一、适用与不适用

**适用**
- 犯罪片、都市人物传记、道德坠落、亚文化圈层生态、男性友谊与暴力关系、宗教罪感。
- 需要"**进入一个世界**"的段落：从任何人都能进的公共入口，连续走到只有内部人能进的那个房间。
- 需要用 60–120 秒**压缩数年命运**的音乐蒙太奇。

**不适用（改用谁）**
- 需要观众保持冷静分析的题材 → 用 **芬奇**（12）。
- 极简室内心理剧 → 用 **伯格曼**（07）；无音乐的写实主义 → 用 **侯孝贤**（16）。

## 二、反例：最容易混的相邻导演

| 相邻 | 差别在机制上 |
|---|---|
| 通用手持犯罪片 | 手持**不是默认语法**。能量来自有目的的机器运动——稳定器长镜、推轨、急推。摄影机被**人物欲望**拖着走，不是被摄影师的呼吸拖着走。 |
| **王家卫** | 王氏是小幅手持**在原地犹豫**、整镜位移不到 1 米、哪儿也到不了；这里是稳定器长镜**持续推进**、慢起、中段快、硬停在一个预先指定的落幅上。 |
| **芬奇** | 芬奇的叙述是客观调查；这里有**不可靠的旁白**，摄影机与人物同谋，允许人物直视镜头说话、允许旁白与画面矛盾——**矛盾就是内容**。 |
| 剪辑花招型犯罪片 | 那种做法用分屏、定格图解、倒放来讲规则；这里靠**第一人称旁白 ＋ 一个不间断的长镜头**带观众走进去，规则由**空间路径**揭示：哪道门要有人放行、哪条通道只有自己人走、终点那张桌子谁能坐。 |
| 浪漫化犯罪 | 上升段用流行乐蒙太奇（1.5–3 秒）；**崩塌段必须抽掉音乐并把镜头拉长到 8–15 秒**。这两段的音画反差就是道德判断，缺一段就变成宣传片。 |
| 风格化长暴力 | 这里的暴力**短促（0.5–2 秒）、笨拙、有难看的生理后果**，并且专门用来**打断此前的音乐节奏**。 |

## 三、六维推理机制

**1｜叙事潜文本**
- 写下这个圈层的**三条规则**，并设计一次**违规**来让观众学会它们。
- 让人物用旁白讲自己的神话，**然后在同一画面里放一个证伪它的视觉细节**。
- 入场路径：**公共空间 → 三个关卡 → 私密空间**，用一个不间断长镜头走完。
- 结尾写出他**具体失去的那一样东西**，不写顿悟。

**2｜空间与机位**
- 摄影机运动必须写出**终点与停止构图**，并标出**速度曲线**（起步慢、中段快、停得干脆）。
- 稳定器长镜让背景始终贴着人物滑动——空间是被"穿过"的，不是被"看"的。
- 允许人物直视镜头（与观众建立同谋关系）。

**3｜光学与景深**
- 广角撑稳定器长镜（背景贴人、不飘）；标准拍自辩式的中近景；**中长焦是急推的落点**——由一支变焦在 0.5–1 秒内推完，机位不动。
- 平衡景深为主：空间信息必须一直可读（旁白在讲，画面要能对照）。

**4｜光影与色彩**
- 光比约 **5:1，方向混乱**——多个实用光源互相打架（这是都市圈层的视觉事实）。
- 主色：酒吧红、后厨绿、钠黄街灯、包厢金。 **饱和度可高**，因为这是"被欲望点亮的空间"。
- 光源都必须有场景内的来源。

**5｜时间与剪辑**
- 上升段：流行乐蒙太奇，平均镜头 **1.5–3 秒**，切点落在鼓点上。
- 崩塌段：**抽掉全部音乐**，平均镜头拉到 **8–15 秒**，饱和度降 30–40%。
- 在最快的音乐段里插一个 0.5–2 秒的暴力镜头，然后**让音乐继续**。

**6｜声音与表演**
- 上升段选一首**场景内有来源**的歌（车里的电台、酒吧的唱机、现场乐队）。
- 旁白是第一人称、自辩式、不可靠。
- 表演走**高能量、抢话**：语速高、互相打断；崩塌段转为停顿与沉默。

## 五、可执行清单

1. 写下这个圈层的**三条规则**，并设计一次违规来让观众学会它们。
2. 让人物用旁白讲自己的神话，**在同一画面里放一个证伪它的视觉细节**。
3. 设计一条入场路径：**公共 → 三关卡 → 私密**，用一个不间断长镜走完。
4. 给每个摄影机运动写**终点与停止构图**，并标出速度曲线。
5. 上升段选一首场景内有来源的歌，切点落在鼓点上，镜头 1.5–3 秒。
6. 在最快的音乐段里插一个 0.5–2 秒的暴力镜头，然后让音乐继续。
7. 坠落段抽掉全部音乐，镜头拉到 8–15 秒，饱和度降 30–40%。
8. 结尾写出他具体失去的那一样东西，不写顿悟。

## 六、与其它层的对接

- **接管**：运动的目的性与速度曲线、旁白与画面的矛盾关系、入场路径式长镜、上升／崩塌的音画反差策略、暴力插入规则。
- **保持全片默认**：布光可取 `CAMERA-LIGHT` 的"MV 戏剧光"或"霓虹都市夜"；表演的具体任务归 `ACTING`；站位归 `BLOCKING`。
- **硬约束**：正文不写焦段数字与光圈值；"急推"要写成"镜头在不到一秒内收紧到面部，机位不动"。
