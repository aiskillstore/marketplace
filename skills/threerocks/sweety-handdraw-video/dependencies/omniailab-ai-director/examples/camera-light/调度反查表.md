# 机位与布光调度反查表（类型 · 场景 · 人物 · 剧情）

**本文件的用途**：让"这一镜该用什么镜头、打什么光"**不需要从零推理**——四步查完即得组合。
**调用顺序**（逐级收窄，不要跳级）：

```text
A 作品类型 → 定全片基线（P1 用，一次）
B 场景     → 定这一场的机位与光（P4 用，每场一次）
C 人物     → 定这个角色在镜前怎么被拍（P4 用，每个角色一次）
D 剧情节点 → 定这一镜的光怎么变（P4／P5 用，每镜一次）
```

> 全部为中文重写、无任何硬件厂商与型号。**档位只用于选型**（分镜表的选型列、画布参数栏），
> **写进提示词的一律是"可见结果"**（见 `references/CAMERA-LIGHT GUIDE.md` 第六节）。
> 每组都给**主推 + 变体**，不是唯一解；与 P1 基线冲突时**以 P1 为准**。

## A. 作品类型 → 全片基线（P1 定一次）

| 类型 | 全片机位基线（机身档／镜头性格档／主力焦段） | 光照基调（方案／色温变体／光比） | 判断依据（为什么这么配） |
|---|---|---|---|
| **都市爱情／情感生活** | 全画幅电影数字／暖调电影定焦／35–50 标准段 | 有源实用光 或 窗光自然／暖钨丝或日光／2:1–3:1 | 观众要"像身边发生"，光必须来自画面内有理由的地方；标准焦段最不像摆拍 |
| **家庭伦理／现实题材** | 影棚级 S35／暖调电影定焦／35–50／平衡景深 | 有源实用光、窗光自然／暖钨丝或混合／3:1 | 张力来自被压抑的日常——光是"顺手开的灯"，不是"打的灯" |
| **悬疑犯罪／黑色** | 影棚级 S35／经典变形宽银幕 或 70 年代定焦／24–35／平衡景深 | 黑色电影（诺瓦）或 高对比三点、尘埃光束／冷调或混合／6:1 以上 | 黑暗本身是信息量；遮挡与大光比把"看不清"变成叙事手段 |
| **惊悚／恐怖** | 影棚级 S35／临床锐利定焦 或 柔光滤镜定焦／24–35／**深焦** | 恐怖底光、雾中实用光源、荧光灯工业感／冷调或偏绿／8:1 | 恐怖靠"视野里的不确定"——既不虚化也不美化；光源来自不合理的方向 |
| **科幻／未来** | 旗舰大片幅数字／现代紧凑变形宽银幕／35–50／极浅至平衡 | 科幻冷蓝主光、混合色温／冷调／4:1 | 未来感来自**环境自身发光**（屏幕、面板、舱灯），不是打上去的光 |
| **奇幻／古装／年代** | 大片幅（70mm 级）／黄金时代复古定焦 或 70 年代定焦／24–50／平衡至深焦 | 黄金时刻、烛光、火光／暖钨丝或烛光级／3:1 | 奇观需要"大画幅的物理真实"来抵消不可信；年代感来自光源的年代（烛、油灯、钨丝） |
| **战争／历史** | 大片幅（70mm 级）或 经典 16mm 胶片／70 年代定焦／35–85／平衡至深焦 | 正午硬光、烟雾逆光体积光、阴天柔光／日光或冷调／4:1–6:1 | 历史感来自"自然环境的不可控"；硬光与尘埃是"无法被安排"的证据 |
| **动作／警匪／追车** | 全画幅电影数字／经典变形宽银幕／24–35／平衡景深 | 高对比三点、霓虹都市夜／按场景／4:1 | 宽银幕畸变与拉丝眩光提供"速度的物理证据"；**必须深焦**（动作要可读，配合 COMBAT 帧链） |
| **青春／校园** | 全画幅数字／光晕柔化／35–50／极浅至平衡 | 黄金时刻、窗光自然／暖钨丝或日光／2:1 | 回忆质地靠高光柔化；光比要低——少年世界还没有阴影 |
| **文艺／作者电影** | 大片幅（70mm 级）或 经典 16mm 胶片／黄金时代复古定焦 或 光晕柔化／35–50／**深焦** | 蓝调时刻、尘埃光束、纪实可用光／冷调／3:1 | 环境先于人物；深焦与长镜保留完整时空 |
| **职场／商战／医疗／法律** | 全画幅数字／旗舰现代定焦／35–50／平衡 | 荧光灯工业感、企业干净光、经典三点／冷调／3:1 | 机构空间的光是"制度的光"——平、冷、无个性，正是压迫感的来源 |
| **纪录片／纪实** | 影棚级 S35 或 经典 16mm 胶片／35 标准广／平衡景深／轻微手持 | 纪实可用光、阴天柔光、窗光自然／日光／2:1 | **本类在纪实线生效时，叙事口径以 `references/DOCUMENTARY GUIDE.md` 为准**，本层只提供机位与光的取值 |
| **动画／风格化** | 按媒介判定（`references/ANIMATION GUIDE.md`）／按风格声明 | 动画平光、MV 戏剧光／按方案／按方案 | 动画的光服务于**风格声明与可读性**；混合媒介按"光决定风格"口径 |
| **音乐 MV／演出** | 全画幅数字／经典变形宽银幕 或 现代紧凑变形／24–50／极浅至平衡 | MV 戏剧光、霓虹都市夜、烟雾逆光体积光／按方案／6:1 | MV 允许"光不来自任何现实理由"；双色对冲是节奏的视觉等价物 |
| **宣传片／广告／TVC／产品** | 旗舰大片幅数字／旗舰现代定焦／50–85／极浅景深 | 商业产品光、影棚遮旗塑形、经典三点／日光／3:1 | 产品必须"无瑕可读"；光是可控的塑形，**每一处反光都必须是设计过的**（方向细则见 `references/PROMO GUIDE.md`） |
| **微短剧／竖屏叙事** | 全画幅数字／暖调电影定焦／35–50／平衡景深 | 有源实用光、窗光自然／暖钨丝／3:1 | 竖屏画框窄，靠"人近、环境少"；光要一次交代完，不做复杂层次游戏 |

**P1 怎么用**：选定类型后，从本表取**1 条主推基线 ＋ 1–2 条变体候选**，连同理由交给创作者拍板，再写进「全片风格锁定」。**不要逐镜现挑。**

## B. 场景 → 机位与光（每场一次）

| 场景 | 机位（焦段／光圈／运动／高度） | 布光（方案 ＋ 变体） | 一句要点 |
|---|---|---|---|
| 小面积室内（卧室、出租屋） | 35 标准广／平衡／轻微手持或固定／眼高略低 | 有源实用光（暖钨丝） | 空间小就要用光把墙"推远"——背景比主体低一档 |
| 大空间室内（厂房、礼堂） | 24 广角／深焦／稳定跟随 或 升 | 荧光灯工业感 或 尘埃光束 | 靠"区域照亮"；人物穿过明暗区本身就是叙事 |
| 餐厅／咖啡馆 | 35–50／平衡／固定或缓推／桌面高度略低 | 有源实用光（暖钨丝）＋窗光自然（混合） | 桌上那盏灯就是主光，别在外面再打一盏 |
| 办公室／会议室 | 35／平衡／固定 | 企业干净光 或 荧光灯工业感（冷调） | 顶光常在，用大柔光压低反差，别让它"脏" |
| 医院／机构走廊 | 24–35／深焦／稳定跟随 或 横移 | 荧光灯工业感（偏绿） | 走廊的光必须是连续平行光带，**不要补光** |
| 审讯室／密闭对峙 | 50–85／平衡／固定 | 分割光 或 高对比三点 | 桌面高度做光源或头顶单点，让眼睛陷在暗里 |
| 楼梯间 | 14–24／深焦／升 或 降 | 尘埃光束 或 窗光自然 | 楼梯的"层级"就是情绪的层级，光要有明确的上下方向 |
| 车内（白天） | 50–85／极浅／固定或轻微手持 | 窗光自然（侧窗） | 白天车内只有一扇主光，脸的一侧永远在暗处——这是它的真实 |
| 车内（夜晚） | 35–50／平衡／固定 | 霓虹都市夜 或 有源实用光（仪表盘） | 仪表盘与路灯交替扫过脸——**光源是运动的** |
| 雨夜街道 | 24–35／平衡／侧向横移 或 轻微手持 | 霓虹都市夜（湿地面反射）／冷调 | 湿地面是免费的第二个光源 |
| 霓虹夜街 | 24／平衡／稳定跟随 或 侧向横移 | 霓虹都市夜 | 彩色不是装饰——要让主体身上有两三种颜色在抢 |
| 白天城市街道 | 35–50／平衡／稳定跟随 | 阴天柔光 或 黄金时刻 | 避开正午顶光时段，走阴影侧 |
| 开阔自然（山、草原、海） | 14–24／深焦／固定 或 升 ／缓拉 | 黄金时刻 或 蓝调时刻 | 大景靠"时刻"，不靠灯 |
| 森林（雾中） | 35／平衡／缓推 | 烟雾逆光体积光 或 雾中实用光源 | 可见光束需要"逆光 ＋ 悬浮物"两件事同时成立 |
| 沙漠／荒野 | 14–35／深焦／固定 或 升 | 正午硬光 或 黄金时刻 | 正午的硬影本身就是"生存压力" |
| 废墟／废弃建筑 | 24–35／深焦／缓推 | 尘埃光束 或 轮廓边缘光 | 单束光 ＋ 大面积暗 ＝ 发现感 |
| 舞台／演播厅 | 24–50／平衡／缓慢环绕 或 侧向横移 | MV 戏剧光（双色对冲） | 台上的光是表演，后台的实用光才是"人味" |
| 地下空间／隧道 | 14–24／深焦／稳定跟随 或 轻微手持 | 荧光灯工业感 或 科幻冷蓝主光 | 没有天光——一切光都是人造且可疑的 |
| 庭院／屋顶／阳台 | 35–50／平衡／固定 或 缓推 | 蓝调时刻 或 月光 | 室内与外部世界之间的过渡空间，光要混合内外 |
| 客舱（飞机／列车／船） | 35／平衡／固定 或 轻微手持 | 窗光自然 ＋ 有源实用光（混合色温） | 移动空间的光在变，要写"**光在动**" |
| 教堂／宗教空间 | 24–50／平衡至深焦／缓推 或 升 | 尘埃光束 或 烟雾逆光体积光 | 高窗 ＋ 暗内部，是它唯一的光学性格 |
| 家庭客厅（夜晚） | 35–50／平衡／固定 | 有源实用光（暖钨丝）＋ 屏幕光 | 屏幕光在家庭戏里是"第四个人"，可用来只照亮一张脸 |

## C. 人物 / 角色功能 → 机位与光（每个角色一次）

| 角色／功能 | 机位 | 光 | 要点 |
|---|---|---|---|
| **主角（日常状态）** | 50／平衡景深／固定或缓推／眼高 | 经典三点 或 有源实用光 | 先给"和观众同一水平线"的视点，后面才有资格改变它 |
| **主角（内心挣扎）** | 35 或 85／极浅／呼吸式推拉 | 窄面光 或 高对比三点 | 光只留在一侧，另一侧交给暗 |
| **反派／威胁者** | 24 或 85／极浅／固定或缓变焦 | 分割光 或 恐怖底光 | 让他永远"少一半脸"——信息不对等就是威胁 |
| **权势者／上位者** | 24／平衡／升 或 缓拉 | 影棚遮旗塑形 或 高对比三点 | 低机位 ＋ 顶光在眼窝留下的阴影，是"位置感"的直接翻译 |
| **弱者／受害者** | 85／极浅／缓推 | 伦勃朗光 或 窗光自然 | 光是"被给予"的——要给到脸上，不是切在脸上 |
| **老人** | 85／极浅／固定或缓推 | 伦勃朗光 或 黄金时刻 | 侧光让皮肤纹理成为叙事；**用可见特征描述，绝不写年龄** |
| **儿童** | 50／平衡／固定或轻微手持／**降机位** | 阴天柔光 或 窗光自然（低光比） | 镜头降到他的高度、光要平；**绝不写年龄**（内容过滤器） |
| **女性主角（独立、掌控）** | 35–50／平衡／稳定跟随 | 窄面光 或 影棚遮旗塑形 | 用有结构的光，别用"柔到没有形状"的光把她的决定美化掉 |
| **群像／多人同框** | 24 或 35／**深焦**／稳定跟随 或 固定 | 经典三点（大面积统一）或 有源实用光 | 深焦 ＋ 统一底光，让"谁占画框更多"承担阵营关系（配合 BLOCKING） |
| **英雄出场** | 50–85／极浅／缓慢环绕 或 升 | 轮廓边缘光（剪影）→ 再补光揭示 | 先剪影、后照脸——**用光完成"揭示"这个动作** |
| **爱情两人** | 50／极浅／固定 或 呼吸式推拉 | 黄金时刻 或 烛光 | 让两人共享同一片光、中间没有暗带，才叫"在一起" |
| **决裂／对立两人** | 35／平衡／固定 | 分割光（各占一侧） | 一人一套光逻辑、中间一道暗缝——**光比就是关系比** |
| **父母与子女** | 50／平衡／缓推 | 窗光自然 或 有源实用光 | 窗光的高光在一侧脸上，"没说完的话"落在暗处 |
| **陌生人／过客** | 85／极浅／固定或甩摇 | 纪实可用光 或 阴天柔光 | 不给造型光，他就是环境的一部分 |
| **职业角色（医生／警察／律师）** | 35–50／平衡／固定 | 企业干净光 或 荧光灯工业感 | 职业的光是"制服性的"——平、可辨认、无个性 |
| **隐藏秘密的人** | 50／极浅／固定（拒绝靠近） | 窄面光 或 有源实用光（**背景留一处亮**） | 让他被"看见一半"；背景那点亮是观众看得见、他看不见的 |

## D. 剧情节点 → 布光（每镜一次）

| 剧情节点 | 布光方案 | 色温变体 | 光比 | 机位配合 |
|---|---|---|---|---|
| 日常铺垫 | 经典三点／有源实用光／窗光自然 | 日光 或 暖钨丝 | 2:1 | 固定机位、深焦，人物在环境里 |
| 初遇 | 窗光自然／黄金时刻 | 日光 | 2:1 | 50／平衡／缓推；**两人进同一片光** |
| 暗流／危险铺垫 | 高对比三点／窄面光 | 冷调 | 4:1 | 35／平衡／固定；背景开始出现暗区 |
| 摊牌／对峙 | 分割光／高对比三点 | 冷调 或 混合 | 6:1 | 35／固定；中间暗缝 |
| 揭露真相 | 尘埃光束／轮廓边缘光 | 冷调 | 6:1 | 24–50／缓推或固定；单束光打在关键物或人的一部分 |
| 背叛 | 黑色电影（诺瓦）／分割光 | 冷调 | 8:1 | 50／固定、缓变焦；暗侧占更多面积 |
| 反转 | 有源实用光（**光不变**） | 混合 | 4:1 | 24／**推拉变焦**——光不变、视角变，才是"世界没变、看法变了" |
| 追逐 | 霓虹都市夜／高对比三点 | 按场景 | 4:1 | 24／侧向横移 ＋ 甩摇；环境光在动 |
| 打斗 | MV 戏剧光／烟雾逆光体积光 | 按场景 | 6:1 | 见 `references/COMBAT GUIDE.md`；**光必须能让动作轮廓可读** |
| 牺牲 | 烟雾逆光体积光／轮廓边缘光 | 暖钨丝 或 烛光级 | 8:1 | 50／缓推或缓慢环绕；主体成为剪影 |
| 离别 | 蓝调时刻／雾中实用光源 | 冷调 | 4:1 | 35／缓拉；光是"退场的方向" |
| 重逢 | 黄金时刻／窗光自然 | 日光 | 2:1 | 50／缓推；**把光比降回起初的低值** |
| 和解 | 有源实用光／窗光自然 | 暖钨丝 | 3:1 | 50／固定或极慢推；一盏灯把两人收进同一个圆 |
| 崩溃／失控 | 恐怖底光／高对比三点 | 冷调 | 8:1 | 24–35／剧烈手持或推拉变焦；**光变得没有来源** |
| 觉醒／决心 | 轮廓边缘光 → 侧向硬光揭示／窄面光 | 暖 或 冷（按走向） | 6:1 | 85／固定；一半脸亮，一半决定留下 |
| 孤独时刻 | 月光／蓝调时刻／尘埃光束 | 冷调 | 4:1 | 50–85／固定或极慢缓拉；大面积空与一小块亮 |

## F. 冲突裁决（五条，按顺序适用）

1. **与 P1 冲突 → 以 P1 为准**。P1 写进「全片风格锁定」的机位基线与光照基调是全片唯一口径。
2. **纪实项目 → 以 `references/DOCUMENTARY GUIDE.md` 为准**（自然光逻辑、每镜空气感、不人工补光）；本层只供取值。
3. **动画／混合媒介 → 以 `references/ANIMATION GUIDE.md` 为准**（媒介判定、"光决定风格"、全片一条光线措辞）。
4. **宣传片 → 以 `references/PROMO GUIDE.md` 的方向细则为准**（方向硬规则优先于本层通用配法）。
5. **同一镜内不得混两套光源逻辑**——混合色温方案属专责方案，不算冲突。
