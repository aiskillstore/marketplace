# 摄影机预设索引（五维坐标 · 意图反查）

**怎么用**：先读「一」拿到五维字典（每个档位的**可见结果**），再到「二」按**意图**查候选组合，最后按「三」写进提示词。
**本文件不是让人从头读的**——是让你**查的**。

> 全部为中文重写、无任何硬件厂商与型号；**档位名只用于选型，写进提示词的一律是"可见结果"**（见 `references/CAMERA-LIGHT GUIDE.md` 第六节）。

## 一、五维字典

### ① 机身格式档（6 档 · 全片级，P1 定死）

| 档位 | 它带来的可见结果 | 适合 |
|---|---|---|
| **全画幅电影数字档** | 宽容度极高、高光过渡自然、肤色有机、高感下仍有细颗粒 | 通用写实、室内外兼顾 |
| **模块化高像素数字档** | 极高像素、临床级锐度、细节保留强、可后期裁切构图 | 需要大幅裁切或高细节画面 |
| **大片幅（70mm 级）档** | 大片幅、原生景深极浅、气象宏大、纵深夸张 | 史诗、风景、大场面 |
| **影棚级 S35 数字档** | 双基准感光度、低照表现出色、肤色自然、宽容稳定 | 夜景多、光线复杂 |
| **旗舰大片幅数字档** | 高像素大片幅、色彩科学成熟、可再构图 | 高完成度商业片 |
| **经典 16mm 胶片档** | 16mm 画门、机械质感、纪录式颗粒、手持生活感 | 复古、档案、纪录片 |

|---|---|---|

| **极限微距探针** | 极端微距、虫眼贴近透视、近距离深焦、非常规视角 | 产品细节、生物、器械 |
| **70 年代电影定焦** | 70 年代性格、暖调复古、大光圈、时代感 | 复古年代戏 |
| **现代紧凑变形宽银幕** | 紧凑变形、可控蓝／琥珀拉丝、椭圆焦外、中心锐边缘柔 | 现代商业、科幻 |

### ③ 焦段档（6 档，与 `OPTICS GUIDE.md` 的视场角锚点对齐）

| 档位 | 视角与压缩 | 典型用途 |
|---|---|---|
| **8 超广** | 极端畸变、沉浸视角、鱼眼感 | 极限 POV、狭窄空间 |
| **14 超广** | 戏剧透视、建筑尺度、环境交代 | 大景、空间压迫 |
| **24 广角** | 环境建立、主体与环境同框、畸变轻微 | 建立镜头、群像 |
| **35 标准广** | 自然视角、纪实感、环境肖像 | 纪录片、跟拍、对话 |
| **50 标准** | 经典自然视点、畸变极小 | 对话、肖像标准 |
| **85 中长焦** | 紧凑肖像、压缩感、主体隔离、浅景深 | 特写、情绪时刻 |

### ④ 光圈档（3 档）

| 档位 | 可见结果 |
|---|---|
| **极浅景深** | 焦外奶油般化开、主体强隔离、低照可用 |
| **平衡景深** | 主体锐、环境仍可辨、通用 |
| **深焦** | 前后皆清、适合风景与空间叙事（"深焦风格"） |

## 三、结果语言怎么写（把选型翻成句子）

**不要写**："85mm、f/1.4、某厂某型号镜头。"

**要写**（挑 2–3 项即可，不要堆满）：

| 维度 | 可写的结果短语 |
|---|---|
| 景深 | 焦点之外柔化成奶油状／前后景皆清晰可辨／主体从环境中强隔离 |
| 透视 | 环境被拉宽的纵深／背景被压缩、层次叠加／接近人眼所见 |
| 焦外 | 焦外光点呈椭圆／焦外呈漩涡状旋转／焦外化为柔和光团 |
| 眩光与光晕 | 光源拉出水平蓝色拉丝／高光周围有暖色光晕／光源泛出柔白辉光 |
| 锐度 | 全画面一致的精密锐度／画面带有细密胶片颗粒／轻微柔化、边缘不刺 |
| 畸变 | 边缘轻微桶形、中央平整／广角端轻微透视夸张 |

## 四、质检

- [ ] 每镜五维都有取值，且**机身格式档与镜头性格档落在该场戏基线上**；
- [ ] 同场戏**没有两处以上维度在跳**（跳了就是漂移）；
- [ ] 正文里**没有**焦段数字、光圈值、机器与镜头型号、平台参数；
- [ ] 选型与 P1 的镜头家族一致；不一致时以 P1 为准。
