# 布光方案索引（33 套 · 三灯结构 · 情绪反查）

每套布光都写同样的四件：**三灯结构（位置·性质·强度）→ 色温变体 → 情绪标签 → 典型用途**。
选取顺序：**先按戏型与情绪锁定一套 → 再按时段与色温选变体 → 最后翻成结果语言写进块 13**。

> 中文重写、无硬件与品牌名。**方案名只用于选型**；写进提示词的是**光源性质、方向、明暗关系、光比、色温**（见下表末列）。

## 四、结果语言怎么写（写进块 13 的样子）

**不要写**："某某方案灯位、某某柔光箱、某某色纸。"

**要写**（块 13 的七项必定义）：

| 七项 | 写法示例 |
|---|---|
| 主光源 | 单一暖色实用光源（桌上台灯／窗外日光／一排顶部荧光管） |
| 方向 | 从画面右侧略高于桌面／从人物左前方 45° 上方 |
| 摄影机在哪一侧 | 摄影机位于受光侧的对面／与主光同侧 |
| 主体是阴影还是轮廓 | 主体以受光面为主、阴影短／主体大半沉在暗部、仅余边缘轮廓 |
| 背景亮度 | 背景留有一片暗部与暖色实用光的小亮区／背景比主体低约一档半 |
| 曝光优先项 | 曝光优先保住皮肤／优先保住窗外高光不溢出 |
| 允许的高光 | 允许灯罩与玻璃器皿上的高光／允许逆光在尘埃中的可见光束 |
| 色温与光比（附加） | 整场偏暖、光比约 3:1／冷暖并存、光比约 6:1 |

## 五、质检

- [ ] 三灯结构完整（无辅光也要写明"无辅光、阴影完整"）；
- [ ] 色温变体与戏的时段、情绪一致；
- [ ] 块 13 的**七项必定义**齐全；

- [ ] 正文里没有灯位品牌、柔光箱型号等硬件名。
