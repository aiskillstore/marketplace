# 纪实／纪录片 · 现成提示词模板

**怎么用**：把 `[…]` 换成你的项目值即可。七套模板是**直接可抄的成品**，规则出处见 `references/DOCUMENTARY GUIDE.md`。

> **取用规则**：① 所有图像模板前**必须接上 P1 的「全片风格锁定」**；② **视频模板不得原样投喂给视频模型**——必须先经 `references/ACTING GUIDE.md`（表演段落）与 `references/EMOTION GUIDE.md`（情绪命题与节拍），再交 `references/CINEDANCE GUIDE.md` 合成；③ **画幅、分辨率、帧率、时长与模型名只进平台 UI 与数据文件，不写入提示词正文**；④ 人物三视图一经确认即全部镜头的统一锚点，**不得在后续镜头重新描述外貌**。

## 一、人物三视图（建立跨镜一致性锚点）

用途：角色外貌基线。路由：Seedream 5.0。竖向或横向排列均可，本模板为横排。

```text
[人物外貌详细描述：年龄感、脸型、五官特征、肤色与肤质、体型] ＋ [服装与配饰：材质、颜色、磨损程度] ＋ [发型与发质]
＋ 三视图横向排列：正面 / 四分之三侧面 / 侧面，人物等距居中，全身完整入画
＋ 纯净灰色无缝摄影棚背景，柔和均匀的顶侧光，无投影
＋ 皮肤质感：可见毛孔、绒毛、睫毛与碎发，真实皮肤油光与细纹
＋ 纪实定妆照质感，非艺术化处理，非海报感
```

**四视图版本**：把视图说明改为「正面 / 四分之三侧面 / 侧面 / 背面横向排列」，并在背面注明「展示发型背部走向、服装背面结构与完整背面轮廓」。

## 二、人物定妆参考板（竖幅，供创作者确认）

用途：独立资产输出，供人工确认人物形象；**不自动绑定分镜**。路由：Seedream 5.0。

```text
[人物外貌与身份描述] ＋ [服装细节与材质] ＋ [发型、配饰、随身物件]
＋ 版面：竖幅。上段占整体高度三分之一——两张面部特写并排，左为正脸、右为侧脸，取头部与肩颈，表现五官细节、骨相、发型与妆感；
  下段占整体高度三分之二——左为近距离放大的正面服装展示图，头部裁出画面外，人物占比明显大于普通全身照；
  右为标准站姿的完整背面全身图
＋ 布光：摄影棚三点布光，主光在正左、辅光在正右、轮廓光在后方偏右
＋ 背景：纯净无缝灰色摄影棚背景
＋ 皮肤质感：保留毛孔、绒毛、睫毛与碎发；真实皮肤层次
```

**核心口径**：这是**专业真人定妆参考**，不是海报、不是宣传片。

## 三、场景参考图（无人物、纯环境）

路由：Flux。用于建立地点资产。

```text
[地点与地理环境描述：地域、建筑材质、地面状态、周边物件] ＋ [时段：清晨 / 正午 / 黄昏 / 阴天 / 夜晚]
＋ [光线状态：自然光方向、色温、明暗层次] ＋ [空气质感：dusty air / morning mist / dampness / hot haze / wind blowing 任一]
＋ 画面内无人物，纯环境观察视角
＋ 生活痕迹：真实的使用磨损、堆放物、生活杂物，非布景感
＋ 纪实摄影质感：低饱和、高层次感、高光柔和、暗部保留细节
```

## 四、道具参考图（保留使用痕迹）

路由：香蕉Pro（Nano Banana Pro）。竖幅、纯净灰色无缝背景。

```text
[物品名称与用途] ＋ [展示构图：特写 / 多角度 / 三视图] ＋ [材质与外观细节]
＋ 真实使用痕迹：磨损、锈斑、褪色、磕碰、修补痕迹
＋ 纯净灰色摄影棚无缝背景
＋ 光线：柔和单侧自然光
＋ 色彩偏淡、对比柔和、带细微颗粒感
＋ 生活化的真实物品，非商业产品拍摄，非崭新出厂感
```

## 五、色卡参考图（纯 2D 扁平）

路由：image2.5（文字与排版最强）。**本图是设计稿，不是照片。**

```text
纯二维扁平色彩系统图，类似电影美术色彩圣经的设计稿，不是摄影、不是实物拍摄，画面内无任何立体效果
＋ 顶部居中标题：主标题「[项目名 · 场景 · 色彩系统名]」近黑色无衬线字体；副标题「[色彩气质描述] · [N] color system」更小的浅灰字
＋ 中部横向排列 [N] 个色块，均匀间距，完全一致的纯色矩形，无渐变、无阴影、无描边
＋ 每个色块下方两行文字：第一行 HEX 色值，第二行功能标签（如 暖光照射 / 皮肤中间调 / 阴影底色 / 材质色 / 强调色）
＋ 背景：低饱和中性纯色（米白 / 灰白 / 暖白 / 冷白），完全平面
```

**色值来源**：先按 `references/DOCUMENTARY GUIDE.md` 第七节从参考影像提取 10–13 个色彩＋功能标签，再填入本模板。

## 六、首帧提示词（决定性瞬间）

不含任何运镜与节奏词汇。取用前接 P1「全片风格锁定」。

```text
[画面主体与微小动作：手部劳作 / 背影 / 收拾工具 / 点烟 / 看窗外] ＋ [环境与空气感：dusty air / morning mist / dampness / wind blowing]
＋ [光线状态：自然光方向与时段，如 soft window light / overcast diffused light / golden hour side light]
＋ [摄影机语言与景别：中景 / 特写 / 远景，长焦观察，浅景深]
＋ [色彩体系与质感：low saturation、soft highlights、real skin tone，胶片质按模拟口径写]
＋ [核心精神关键词：humanist observational documentary、environmental portrait]
```

## 七、视频提示词（长镜观察感）

**必须先经 ACTING → EMOTION，再交 CINEDANCE 合成**；本模板只提供纪实运动与节奏口径。

```text
[极克制的镜头运动：fixed camera / slight handheld breathing / extremely slow push-in / extremely slow pan，四选一]
＋ [主体持续的微小动作：动作从头到尾连续，不切换]
＋ [环境与光线的微小变化：云影移动、炊烟飘动、光斑变化、尘埃浮动]
＋ [色彩体系：low saturation、cinematic documentary grading、real skin tone]
＋ [纪录节奏：long take、slow pacing、no fast cuts、breathing space]
＋ [核心精神关键词：observational、unhurried、真实在场]
```

**禁止出现**：旋转、快速推拉、无人机飞行、炫技运镜、切镜、音乐卡点节奏。

---

## 八、音频层口径

- **旁白**：按 P1 声音圣经锁定的音色与说话方式（`references/ASSET-SYSTEM GUIDE.md` 的声音锁定），一条参考定音，之后逐段落复用。
- **音乐**：极简器乐／环境音景；**不生成歌词类音乐**。
- **现场声**：市集噪声、风声、雨声、街道声、器物声优先；音乐音量**低于现场声**。
- **不做强制音画同步**，画面与声音各自自然流动。
