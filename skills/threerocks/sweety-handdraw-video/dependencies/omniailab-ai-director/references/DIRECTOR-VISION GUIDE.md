# 导演视界层（导演式推理 · 加载 · 混合 · 锁定）

**核心认知**：选一位导演**不是套一层视觉皮肤**，而是**加载他处理空间、机位、光影、时间与潜文本的底层机制**。
"赛博朋克感""电影感""高级灰"是形容词，**形容词不可执行**；一位导演的机制是**一串可写进提示词的取舍**——
镜头组怎么配、机位高度是多少、允许什么运动、光比多少、平均镜头多长、声音什么时候进。**这些才是能拍出来的东西。**

> **来源与口径**：本层吸收一个开源导演风格库的**组织方法**——**每位导演一个模块、统一结构、"反例"写明与相邻导演的机制差异、附机器可读参数块**。
> **只取方法与结构，不搬运其文本**；全部中文重写、去一切硬件厂商与型号、以结果语言落地。出处只记在内部 memory。

> **与电影艺术知识层的关系**：本层把「某位导演」变成**可推理的机制**并锁定全片。**工作方法与心法**——四位大师的判断原则、**分镜级拉片法**（逐镜记录景别／机位／构图／时长，建个人可调用视觉库）、对理论的正确用法——来自 `FILM-ART GUIDE.md`，见 `film-art/13-master-methods-and-mindset.md`。**风格机制与混合规则以本层为准，拉片方法与心法以电影艺术层为准**；两层的「反例」纪律同源（**互为反例者不得同镜混用**），**跨层融合的三档借法与纪律见电影艺术层第四节**。

## 在本流水线中的定位与边界

- **谁决定"怎么拍"**：本层决定**全片的摄影与视听取舍**（镜头组、机位语法、光比、剪辑节奏、声音策略、表演档位）。
- **谁决定"拍什么"**：剧本、人物、情绪分别归 `SCENE-ENGINE`（结构）、`ACTING`／`EMOTION`（表演与情绪）、`BLOCKING`（站位）。
- **与相邻层的分工**（不得越权）：

| 层 | 它管什么 | 本层与它的关系 |
|---|---|---|
| `STYLE GUIDE.md` | 画风字典（D/P/C/R/S 词汇）：图像的**表面质地** | 本层管**取景与取舍机制**；两者可叠加，冲突时**画风服从导演机制**（例：导演要"通透干净的空气"，就不选颗粒与雾的画风） |
| `AESTHETICS GUIDE.md` | 成片级美学配方（A01–A07） | 两者都是"成片级"。**导演预设优先**；若同时命中，先把导演的冻结维度写进声明，再从配方里取**不冲突的部分**（如色彩策略） |
| `OPTICS GUIDE.md` | 视场角锚点、多镜不漂 | 导演预设**引用**它的锚点，不重复定义 |
| `CAMERA-LIGHT GUIDE.md` | 五维机位坐标 ＋ 33 套布光 | **导演预设是它的上游约束**：先由导演冻结"镜头性格档与光照体系"，再由它逐镜取具体值 |
| `BLOCKING`／`ACTING`／`EMOTION`／`CINEDANCE`／`COMBAT` | 站位、表演、情绪、动作、打斗 | 本层只给**档位与规则**（如"机位距脸 3 米、不许逼近"），具体内容仍由各层产出 |
| `PROMPT-DOCTRINE GUIDE.md` | 16 段块序与十一条铁律 | 导演预射的参数**落在块 8／块 9／块 13／块 16**；铁律不可被导演风格推翻（见其第十一节） |
| `DOCUMENTARY`／`ANIMATION`／`PROMO` | 三条专线 | **专线优先于本层**：纪实、动画、宣传片各自的硬规则不可被导演风格覆盖 |

- **不单独计为一个子技能**，是按阶段接入的规范层。

## 何时调用 · 怎么调用

| 时机 | 怎么用 |
|---|---|
| **第 0 步之后、P0A 之前** | **先定导演**（与定形态同步）。导演决定全片基线，**越早越好**；用户不改就沿用，不反复问 |
| **没有点名** | 从 `examples/director-presets/README.md` 的**推荐表**给 **2–3 个候选**（各附一句理由与一个可见结果），让创作者挑；也可按"作品类型"直接推荐（见该表） |
| **点名了一位** | 只加载 `examples/director-presets/<NN>_<中文名>.md` 这一个文件，**不要一次读多个** |
| **点名了多位** | 走第五节的**混合规则**：定主导演 ＋ 借用维度，产出「导演声明」 |
| **P1 创作基准** | 把「导演声明」写进「全片风格锁定」；此后全片以它为准 |
| **P4 分镜与首帧** | 逐镜读声明：**冻结维度一律不动**，可变维度按 `CAMERA-LIGHT` 取具体值 |
| **P5 视频提示词** | 参数落块 8（光学结果）／块 9（机位）／块 13（光线）／块 16（正向锁定） |
| **P6 剪辑与声音** | 按声明的**剪辑节奏与声音策略**执行（平均镜头长度、切点落点、音乐进入时机） |

## 一、六维推理机制（一位导演＝六组取舍）

读一位导演，只读这六维。**每维都必须落到"可写进提示词的东西"上**，写不出来的就不算机制。

| 维 | 问什么 | 输出成什么 |
|---|---|---|
| **① 叙事潜文本** | 他的故事靠什么推进？观众该被要求做什么（共情／分析／等待／推理）？ | 结构规则（目标何时说清、反转在哪、结尾给什么） |
| **② 空间与调度** | 人物在空间里被放在什么位置？谁高谁低、谁在框内谁在框外？ | 调度规则（三层纵深／压进建筑／被缩小到画幅百分之几） |
| **③ 机位与光学** | 机位高度、距离、角度、允许与禁止的运动？镜头组怎么配？ | 块 9 ＋ 块 8 的取值与禁令 |
| **④ 光影与色彩** | 光比多少、光从哪里来、阴影里能不能看见细节？主色与色点是什么？ | 块 13 的取值 ＋ 调色方向 |
| **⑤ 时间与剪辑** | 平均镜头多长？切点落在哪一帧？镜头内必须有变化点吗？ | 分镜的时长与切点规则 |
| **⑥ 声音与表演** | 音乐何时进、何时撤？表演的档位是外放还是抑制？ | 声音策略 ＋ ACTING 的表演档位 |

## 二、"反例"是这一层最重要的纪律

**任何导演预设都必须写出"最容易与谁混淆"以及"机制上的差别在哪"**——这是它区别于形容词的唯一凭据。

- 例：**库布里克 vs 芬奇**——两者都冷、都几何、都控制。差别是机制：**库布里克用广角单点透视把人压进建筑**（背景必须完整清晰、纵深本身是压力）；
  **芬奇用长焦把人从背景里切出来变成样本**（背景被压扁成失焦色块、机位在人物不知道的位置）。
- 没有"反例"这一节，预设就会退化成"高级、冷峻、克制"这类没人能执行的词——**判定为不合格，退回重写。**

## 三、加载与优先级

```text
优先级（高 → 低）：
专线硬规则（纪实／动画／宣传片）  >  导演预设  >  CAMERA-LIGHT 类型基线  >  项目基调  >  各层默认
```

- **专线优先**：纪实项目不得因选了某位导演就改成人工布光；动画项目不得因此丢掉媒介声明。
- **一次只展开一位主导演**：允许混合，但混合的规则见第五节——**不是把两位导演的全文都读进来。**
- **默认值不是空**：用户没点名时，按作品类型从 `CAMERA-LIGHT` 的 A 表取基线（那里已有 16 类），**不要为了"有风格"硬塞一位导演**。

## 四、导演声明（唯一口径，写进「全片风格锁定」）

定下导演后，**必须输出这个块**（YAML，机器可读），后续所有阶段只认它：

```yaml
导演风格声明:
  主导演: <中文名>（预设文件：examples/director-presets/<NN>_<中文名>.md）
  借用: <若无写"无"；若有写：导演名 → 只借哪一维或哪两维>
  冻结维度:            # 全片不许变
    - 镜头性格档: <用 CAMERA-LIGHT 的档位名>
    - 光照体系: <方案名或编号>
    - 剪辑节奏: ASL <区间>，切点落在 <哪里>
    - 声音策略: <一句话>
  可变维度: [焦段, 光圈档, 运动档]     # 允许逐镜调
  本片禁用: [<从预设的 avoid／negative 里取 3–6 条>]
```

**四条纪律**：

1. **冻结维度一经写入，P4 之后不得改动**；要改就回到 P1 改声明，并同步通知已产出的资产与分镜。
2. **可变维度每镜只改一项**（与 `CAMERA-LIGHT` 第七节同源）。
3. **禁用清单必须真的执行**：写进块 16 的正向锁定，而不是只在口头上说"不要手持"。
4. **声明要能一句话说清**：创作者问"我们这片是什么味"，回答用一句预设里的话，不堆形容词。

## 五、混合规则（多选时怎么混）

用户选了多位导演是常见需求，**做法是"一位主 ＋ 少量借用"，不是把两套机制平均**。

**三档混合（按推荐度）**：

| 档 | 做法 | 何时用 |
|---|---|---|
| **主 ＋ 借一维／两维（首选）** | 选一位作主导演（决定冻结维度）；从另 1–2 位**只借指定维度**（如"主＝芬奇；借王家卫的**前景遮挡**与**霓虹污染**"） | 用户说"想要 A 的冷，但要 B 的那种都市味" |
| **分段主导演** | 不同段落／幕用不同主导演（如"前两幕维伦纽瓦、第三幕雷弗恩"），**每段各自冻结、段内不混** | 结构与情绪有明显分幕的片子 |
| **全片双主（不推荐）** | 两位导演共治同一维度 | 只在两位的机制**同向**时可用（如都要求"机位锁死"）；否则必然互相抵消 |

**混合硬规则三条**：

1. **同一维度只能有一个来源**。定不了就是主导演的。
2. **先查"反例"节**：若两位导演的预设里**互相把对方列为反例**（例如库布里克与芬奇、雷弗恩与王家卫、张艺谋与朴赞郁），说明他们靠**同一批手段达到不同目的**——**混用会同时废掉两边的机制**，此时必须二选一，或改成分段主导演。
3. **借来的维度要写出"改到什么程度"**：不写程度就会失控（"借王家卫的前景遮挡"应写成"每镜指定一样前景遮挡物，并写明挡住身体哪一部分"）。

## 六、用户可选项与引导话术

**用户能自己指定什么**（完整清单见 `references/ONBOARDING GUIDE.md` 第二节）：
导演（**单选／混选**）、机型格式档、镜头性格、焦段、光圈档、运动档、布光方案、色温与光比、美学配方、画风档位、画幅与时长。

**三条引导原则**：

1. **主动报菜单，不要等用户问**——定完形态与导演后，用一段话说清"这些你都能自己点，也能交给我判断"（照抄话术见 `references/ONBOARDING GUIDE.md` 第四节的"主动报一次菜单"）。
2. **用户说不清时先给判断，再给选项**：给 2–3 个候选，每个附**一句理由 ＋ 一个可见结果**（例："他会永远只露半张脸——信息不对等就是威胁"），**不要反问一长串问题**。
3. **把形容词翻译成档位再确认**：用户说"高级一点""电影感"，先翻成具体档位（曲线柔、光比 3:1、中长焦压缩、平均镜头 6 秒）报给他确认——**形容词不可执行，档位才可执行**。

## 七、组合示例：从一句话需求到可执行参数

**范例一｜"我要做一部悬疑短片，全片怎么打光？"**

```text
类型      → 悬疑犯罪（核心：黑暗本身是信息量）
导演      → 希区柯克（观众先知道）或 芬奇（系统视角、信息差）
机型档    → 影棚级 S35（低照表现出色）
镜头性格  → 经典变形宽银幕 或 临床锐利定焦
焦段      → 广角（一次性交代房间地图）＋ 中长焦（凝视的选择性）
光圈档    → 平衡景深（环境可读是悬念的前提）
运动      → 固定 ＋ 缓推
布光      → 高对比三点 或 黑色电影（诺瓦）    色温 → 冷调    光比 → 4:1（阴影保留可辨几何）
节奏      → ASL 4–9 秒；危险抵达前撑满 20–60 秒，切成 3–5 个可数节拍
禁用      → 手持抖动、跳吓、完整暴力动作、大块无细节黑
```

**范例二｜"都市爱情，要那种错过感"**

```text
类型      → 都市爱情（观众要"像身边发生"）
导演      → 王家卫（贴身／遮挡／永远晚一步）
机型档    → 全画幅电影数字
镜头性格  → 漩涡焦外肖像
焦段      → 广角贴身 ＋ 中长焦隔街（中焦段刻意回避）
光圈档    → 极浅
运动      → 轻微手持（原地犹豫，整镜位移不到 1 米）
布光      → 霓虹都市夜（脏霓虹、互相污染、没有边界）
色温      → 混色（一种打人、一种打墙）        光比 → 6:1–10:1
节奏      → ASL 1.5–4 秒；每段仅一次慢动作，落在"克制住自己"的那一秒
禁用      → 锁死对称、稳定器推进、正面全脸大特写、干净通透构图
```

**范例三｜"产品广告，要干净高级"**

```text
类型      → 宣传片／广告（每一处反光都必须被设计过）
导演      → 芬奇（外科精确）或 按 `references/PROMO GUIDE.md` 的方向细则
机型档    → 旗舰大片幅数字
镜头性格  → 旗舰现代定焦
焦段      → 中长焦（主体隔离）
光圈档    → 极浅（但焦点精确可控，不做情绪化虚化）
运动      → 固定 ＋ 缓慢环绕
布光      → 商业产品光 或 影棚遮旗塑形       色温 → 日光（中性干净）  光比 → 3:1
节奏      → ASL 4–8 秒；流程按步骤剪（一个步骤一个镜头）
禁用      → 多光源方向混乱、颗粒与雾、色彩污染、死黑阴影
```

> **三例的用法**：照第一行写类型，其余各行按顺序填；填不出的（例如"不知道机型档"）**留空交给本层按导演与类型取默认值**，不要硬填。

## 九、扩容：新增一位导演

**三步，不改主干**：

1. 按 `examples/director-presets/README.md` 的**统一结构**新建 `examples/director-presets/NN_<中文名>.md`（NN 为两位数序号，控制排序）；
2. 在该 README 的**总表**与**推荐表**各加一行；如涉及专线（纪实／动画／宣传片），在对应线的文件里加一句入口；
3. 升版（版本号进每个文件的 frontmatter）→ 同步飞书手册 → 提交推送（钩子自动）。

**质检三问**：① 六维是否都落到了可执行的取舍？② **"反例"节是否写出了与相邻导演的机制差异**？③ 参数块里是否**只在选型台出现档位与数字、正文只写结果**？

## 十、交付前质检

- [ ] 已产出「导演声明」并写入「全片风格锁定」；
- [ ] 声明的**冻结维度**在 P4／P5／P6 全程未被违反；
