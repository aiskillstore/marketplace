# P5 视频提示词生成与 OmniAiLab 参数

## 1. 阶段位置与目标
P5 位于分镜和首帧全部确认之后，视频生成之前。目标是为每个镜头生成可直接粘贴到 OmniAiLab 视频节点的提示词，并指定模型、时长、比例等参数。P5 不实际生成视频，只输出提示词和参数表，供 P6 阶段批量执行。

## 2. 视频提示词结构
每个镜头的视频提示词由以下部分组成，顺序不可变：

```
[P1风格前缀] + [首帧状态描述] + [动作描述] + [运镜描述] + [光线/氛围变化] + [严格约束]
```

### 2.1 P1 风格前缀（固定，每个提示词开头必须包含）
```
电影级真人实拍质感，ARRI Alexa Mini数字摄影机，Cooke S4i定焦镜头，16:9画幅24fps，实用光源，曝光偏暗，暗部沉，冷蓝灰色调，轻微数字噪点，哑光材质，禁用HDR光晕和无来源轮廓光，杜绝游戏CG感和精修滤镜。
```
> 实际使用时替换为该项目 P1 确认的「全片风格锁定」文本。

### 2.2 首帧状态描述
用一句话描述视频开始时的画面状态，必须与已确认的首帧图完全一致：
```
起始画面：[角色]在[场景]中[位置和姿态]，[光线状态]，[道具位置]。
```

### 2.3 动作描述
具体描述角色/物体在视频中的动作，必须是可执行的物理动作，不写抽象情绪：
- 好："林晚缓缓抬起头，目光从手机移向电梯内壁的镜面"
- 坏："林晚感到害怕"（不可执行）

动作描述规则：
- 一个镜头只描述 1-2 个主要动作
- 动作有明确的起始和结束状态
- 微表情要具体（眉头微皱、瞳孔放大、呼吸停顿）
- 多人镜头分别描述每人动作

### 2.4 运镜描述
```
摄影机[运镜方式]，[速度描述，如极缓慢/匀速/快速]，[起止构图变化]。
```
- 固定镜头："摄影机固定不动"
- 推进："摄影机极缓慢向前推进，从中景推到近景"
- 跟拍："摄影机侧面跟拍，保持角色在画面中央"
- 手持："手持摄影，轻微自然晃动"

### 2.5 光线/氛围变化
如果镜头中光线有变化，必须描述：
```
光线[变化描述，如日光灯突然闪烁一下/电梯门打开光线溢出/屏幕光照亮面部]。
```
无变化时写"光线保持稳定"。

### 2.6 严格约束
每个提示词结尾必须包含：
```
严格保持角色身份、脸型、发型、服装与参考图一致，不换脸，不增减道具，不改变场景结构。无文字，无水印，无字幕。
```

## 3. 完整提示词示例
```
电影级真人实拍质感，ARRI Alexa Mini数字摄影机，Cooke S4i定焦镜头，16:9画幅24fps，实用光源，曝光偏暗，暗部沉，冷蓝灰色调，轻微数字噪点，哑光材质，禁用HDR光晕和无来源轮廓光，杜绝游戏CG感和精修滤镜。
起始画面：林晚背对镜头站在电梯中央，面向关闭的电梯门，微微低头看手机，冷白色顶光，电梯不锈钢镜面内壁反射出她的背影。
林晚缓缓抬起头，目光从手机屏幕移向左侧电梯内壁的不锈钢镜面；镜面中她身后的深色风衣人影慢慢抬起头，长发从脸侧滑落。
摄影机极缓慢向前推进，从背面中景推到背面近景，始终保持林晚在画面中央。
光线保持稳定的冷白顶光，镜面反射逐渐清晰。
严格保持林晚和神秘人影的身份、脸型、发型、服装与参考图一致，不换脸，不增减道具，不改变电梯结构。无文字，无水印，无字幕。
```

## 4. OmniAiLab 视频节点参数表
每个镜头必须输出以下参数，直接对应 OmniAiLab 视频节点的设置项：

| 镜号 | 模型 | 时长 | 比例 | 输入方式 | 参考图 | 提示词 |
|---|---|---|---|---|---|---|
| 01 | Seedance 2.5 | 5s | 16:9 | 图生视频 | 首帧图+林晚确认稿 | [完整提示词] |
| 02 | Seedance 2.5 | 3s | 16:9 | 图生视频 | 首帧图+林晚确认稿 | [完整提示词] |
| 05 | Kling O3 | 5s | 16:9 | 图生视频 | 首帧图 | [完整提示词] |

### 4.1 模型选型规则
| 镜头类型 | 首选模型 | 备选模型 | 理由 |
|---|---|---|---|
| 人物表情、对话、微动作 | Seedance 2.5 | Seedance 2.0 | 人物面部和动作最自然 |
| 人物运镜、走路、转身 | Seedance 2.5 | Vidu | 运镜流畅，角色一致性好 |
| 特效、物体形变、环境破坏 | Kling O3 | Wan 2.6 | 物理模拟和特效表现力强 |
| 产品/道具特写 | Vidu | Kling O3 | 物体细节还原度高 |
| 快速试水/低成本 | Seedance 2.0 Fast | — | 速度快，成本低 |
| 纯环境/空镜 | Seedance 2.5 | Wan 2.6 | 氛围和光线还原好 |

### 4.2 时长设置
- 严格按分镜表设置，不擅自延长
- Seedance 2.5 支持 5-30 秒，Seedance 2.0 支持 5-15 秒
- 超过 15 秒的镜头拆为两个，在 P4 分镜阶段就拆好
-  OmniAiLab 视频节点时长以秒为单位，整数输入

### 4.3 比例
- 全片统一 16:9（横屏短片/电影感）
- 短视频平台（抖音/视频号）改用 9:16，需在 P1 阶段确认
- 同一项目不混用比例

### 4.4 输入方式
- **必须使用图生视频（image-to-video）**，首帧图作为输入
- 禁止使用文生视频（text-to-video），除非是纯黑场/纯文字镜头
- 首帧图 + 角色确认稿同时作为参考图上传

## 5. 角色一致性强化技巧
### 5.1 参考图策略
- 每个含角色的视频节点，除首帧图外，额外上传角色确认稿
- OmniAiLab 视频节点的参考图字段中，首帧图排第1，角色确认稿排第2
- 提示词中重复角色核心特征至少2次：开头风格前缀后一次，结尾约束中一次

### 5.2 提示词锚点
在动作描述中嵌入角色不可变特征：
```
林晚（黑色中长发，白色皱衬衫，蓝色工牌挂绳）缓缓抬起头...
```

### 5.3 漂移修正
如果生成的视频中角色漂移（换脸/换发型/换衣服）：
1. 不修改提示词，重新生成 1-2 次
2. 仍漂移则在提示词中增加角色特征描述的密度
3. 仍漂移则更换首帧图（重新生成首帧，确保首帧中角色清晰正面）
4. 最后手段：降低动作幅度，用更简单的动作

## 6. 常见问题与修正
| 问题 | 原因 | 修正方法 |
|---|---|---|
| 角色换脸 | 参考图权重不够 | 增加角色确认稿为参考图，提示词中重复特征 |
| 场景变形 | 首帧场景不清晰 | 重新生成首帧，确保空间结构明确 |
| 动作不自然 | 动作描述太复杂 | 简化为1个主要动作，延长时长 |
| 光线跳变 | 提示词未锁定光线 | 在风格前缀和光线变化段明确描述 |
| 出现多余人物 | 提示词未约束 | 增加"画面中只有X个角色" |
| 出现文字/水印 | 模型默认行为 | 提示词结尾增加"无文字无水印无字幕" |
| 运镜过猛 | 运镜描述太激进 | 改为"极缓慢"或"固定" |

## 7. 交付物
P5 阶段完成后必须交付：
1. 逐镜头视频提示词表（含模型、时长、比例、参考图清单）
2. 每个镜头的完整可复制提示词（纯文本，可直接粘贴到 OmniAiLab）
3. 模型选型说明（为什么这个镜头用这个模型）
4. 角色一致性检查清单

全部确认后进入 P6 生成与剪辑。
