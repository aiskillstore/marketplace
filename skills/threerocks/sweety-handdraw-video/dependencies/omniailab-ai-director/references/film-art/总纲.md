# 全球电影艺术知识库

> Global Film Art Knowledge Base —— 由电影艺术领域著作系统梳理成的**可调用知识库**，当前主入口是「影视导演全流程」。

这不是书摘合集，是一套**从剧本到成片的决策链**：15 个能力域 + 一条主线工序 + 每一步的判停点。
手艺来自对电影艺术与导演实践的**系统梳理**。**参考了哪些书、哪些书尚未收录**，见 `BOOKS.md`（附机器可查索引 `books.json` 与查询脚本 `find_book.py`）。

## 三条工序铁律（先记住这三条，其余都好办）

1. **顺序不可颠倒**：读本 → 演员走位 → 加摄影机 → 剪辑。
   跳过前面直接想机位，是新手最常见的死法。（FR-01）
2. **每一镜必须承担一个叙述拍**。说不出来的那一镜，就是白拍。（PR-02）
3. **剪辑是增益，不是抢救**。现场没解决的，剪辑台救不回来。（PR-01）

## 主线工作流（六步，每步都有完成标准）

### Step 0 · 定类型与预期（10 分钟，但决定后面全部基准）
- 做：明确"给谁看、在哪放、多长时间、什么类型"。类型＝与观众的预期契约（FR-13）。
- 完成标准：能用一句话说出"这是给 ___ 看的一部 ___ 片，观众期待看到 ___"。
- 判停点：**说不出来就别往下走**。手册 `11`。

### Step 1 · 剧本侦探（最容易被跳过，也最要命）
- 做：找出全片主动作（spine）、每个角色的贯穿欲望、每场戏的支点，再把每场戏切成戏剧块。
- 完成标准：一场戏能列出 2–5 个戏剧块，每块标出"谁想要什么／被什么挡住"，并标出支点位置。
- 判停点：**如果一个块说不出它推进了什么，那一块就是多余的**。手册 `01`。

### Step 2 · 调度与平面图（先人后机器）
- 做：在平面上把演员走位排完，**先不加摄影机**；在已有走位里找秩序与形状（PR-04）。
- 完成标准：有一张俯视平面图；每个戏剧块的走位能体现该块的叙述拍；支点处有明确动作转折。
- 判停点：走位表达不了叙述拍时，**改走位，不要靠机位去补**。手册 `05`。

### Step 3 · 加摄影机 + 分镜与镜头表
- 做：逐块加机位，遵守关系线／三角形原理；写文字分镜（每镜一句话说清承担哪个叙述拍），再出镜头表。
- 完成标准：镜头表每行都有"承担哪个叙述拍"；没有两镜承担同一个拍（除非刻意重复）；越轴处有补偿方案。
- 判停点：**发现缺拍就补，发现重复就删**——此时发现成本是 1，现场发现是 100。手册 `06`、`04`。

### Step 4 · 现场执行
- 做：按镜头表推进；保证主镜头/遮盖保底；记录已获素材与缺口；为声音留位置（PR-10）。
- 完成标准：当天通告完成；每个场景有可剪的最小素材集；缺口清单当场列出。
- 判停点：**素材不足时先补遮盖，不要指望后期**。手册 `12`、`08`。

### Step 5 · 后期
- 做：先按叙述拍粗剪，再调节奏；混录前反复完整看片（CX-08）。
- 完成标准：不看字幕也能看懂人物在做什么；每个叙述拍在成片里可被指认。
- 判停点：**剪到"只是在消耗时间"就停下**，设明确判停（CX-14）。手册 `07`。

## 最小交付物清单（任何项目都该有）

1. **读本备忘**：spine 一句话 ＋ 每场戏的"块-拍-支点"表
2. **平面图**：分块的走位（俯视）
3. **文字分镜**：逐镜一句话 ＋ 承担的叙述拍
4. **镜头表**：机位／景别／内容／顺序／备注（越轴补偿、特效需求）
5. **现场单**：通告顺序、器械、演员到场、声音预留项
6. **剪辑判停清单**：叙述拍核对表 ＋ 节奏检查点

## 发布级检查清单（交付前逐条过）

- [ ] 全片主动作能用一句话说清（spine）
- [ ] 每个角色的贯穿欲望能被主动作收容
- [ ] 每场戏有支点，且支点处有明确处理
- [ ] 每镜能指认它承担的叙述拍
- [ ] 无越轴、无方向不匹配（或已给补偿）
- [ ] 对话机位落在关系线同侧或三角形顶点上
- [ ] 远景非顺光，画面有层次而非"平"
- [ ] 构图上的站位变化与人物关系变化一致
- [ ] 声音在前期已被规划（不留到后期硬凑）
- [ ] 剪辑只做增益，没有"靠剪辑救场"的期望
- [ ] 拍摄周期与野心匹配；有缺口清单与补拍预案
- [ ] 不看字幕也能看懂人物在做什么

## 反模式（见到就停下纠正）

| 反模式 | 纠正 |
|---|---|
| 没定 spine 就开机 → 每场都对，整片散 | 回 Step 1 |
| 跳过调度直接想机位 | 回 Step 2，先排人 |
| 把演员的拍当叙述拍 → 观众收不到 | 用调度/摄影机外化 |
| 越轴 | 补中性镜头，或用移动镜头过线 |
| 滥用广角＋顺光"求全" | 侧光/侧逆光造层次 |
| 指望剪辑台救场 | 现场解决；剪辑只增益 |
| 成片前不完整看片 | 混录前至少完整看 3 次，间隔开 |
| 用理论代替可执行方案 | 理论用来选，不用来拍 |
| 低成本按大片组织 | 用资源反推镜头数与场景数 |

## 迁到 AI 短剧 / 虚拟制片

方法论不变，只换执行手段。三条映射：

1. **文字分镜 → 提示词分镜**：文字分镜天生适合当 AI 生成的镜头描述——"这镜承担哪个叙述拍"直接决定提示词写什么、不写什么。
2. **关系线与三角形原理 → 一致性锚点**：AI 生成最易崩的是空间连续。把机位限制在关系线同侧，等价于锁定角色朝向与左右关系，显著降低"跳轴式"穿帮。
3. **剪辑是增益 → 生成前定节奏**：AI 素材成本低但可控性差，**先定剪辑节奏再生成**（决定每镜时长与运动幅度），比生成后再找节奏省数倍返工。

## 书库怎么用

- **要读某本书的具体内容**：先看 `LIBRARY_STATUS.md` 的"状态"列。
  - `取文` = 已抽出文字层，可直接检索
  - `页面图` = 无文字层 PDF，已还原为可读页面图，按页码抽样阅读
  - `加密/未取` = 无法读取，**不得凭记忆引用其内容**
- **脚本**（本机无 PDF 库、无外网时也能用）：
  - `scripts/pdftxt.py` — 纯标准库抽取 PDF 文字层（含对象流、ToUnicode CMap）
  - `scripts/ccitt.py` — 把图片页还原成可阅读的 PNG（CCITT G4 → TIFF 技巧）
  - 用法：`python scripts/pdftxt.py <in.pdf> <out.txt>`；`python scripts/ccitt.py <in.pdf> <outdir> [起页] [止页] [宽度]`
- **引用规范**：正文锚点（FR-02 等）可在 `audit/verified.md` 与 `audit/candidates/` 逐条溯源（含淘汰项与理由 `audit/rejected/`、书库整体解读 `audit/BOOK_OVERVIEW.md`）。**未取文的书不得假装引用**。

## 边界（什么时候不该用这个技能）

- 纯理论问题（"巴赞的长镜头理论是什么"）→ 直接讲，不必套工作流。
- 只要文案/宣传语 → 转文案技能。
- 涉及**拍摄安全、劳动法、版权、保险、发行合同** → 库内无此内容，须另找专业依据，**不要从本技能推断**。
- 纪录片／实验片／非叙事影像 → 本技能基于古典叙事剧情片手艺（Proferes 明说限定 "classical sense"），只可部分借用。
