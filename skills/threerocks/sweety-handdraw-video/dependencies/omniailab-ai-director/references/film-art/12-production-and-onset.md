# 11 制片与现场（怎么在资源内做出来）

**这一域要解决**：**让野心与资源匹配**——这是导演最容易失手的地方，也是唯一"钱能直接买到"的能力。

---

## 核心原则

### 1. 资源反推，不是愿望正推（CX-12）
- 愿望正推："我想拍 300 个镜头、5 个场景、夜戏外景。"
- 资源反推："我有 6 天、2 个主场景、无夜戏灯光车 → 那就把戏压到 2 个场景、日戏、镜头表按机位归组。"

**铁律**：**先算天数 × 每机位可完成镜头数**，再回头改剧本与镜头表。顺序反了，最先崩的是周期。

### 2. 低成本不是缺陷，是约束下的取舍（PR-16）
芦苇谈低成本剧本：
> "这就是对预算有把握，他呈现出剧本的张力、细节、对白都非常好。"

低成本导演的核心竞争力不是"省"，是**在约束里把张力做足**——靠场景选择、对白、调度，而不是靠场面。

### 3. 导演权限是有边界的（CA-14 / CX-10）
《导演如何做电影》记录的制片厂体制：
> "总剪辑师甚至比导演更先看到电影的雏形……如果他认为这个或那个场景需要补拍，他就去找制片厂副厂长或厂长，坚持重拍。导演必须服从。"

**启示**：无论大小制作，先搞清**决策权在谁手上**。把力气花在可决定的范围内；越过权限的对抗只会消耗片子。

### 4. 分工要匹配工种，不是人格魅力
制片/DP/剪辑/美术各有专业判断。选 DP 有点像选演员（PR-07 同源逻辑）：**他是否尊重你的叙述概念**。
（Proferes："you should try to work only with DPs who respect that concept."）

### 5. 通告单是现场的宪法
按**资源不可替代性**排序：
1. 只租一天的场地/器材
2. 特殊天气/光线窗口（魔幻时刻、夜景、雨）
3. 高成本演员档期
4. 危险/特效镜头（要有充足时间余量）
5. 普通对话戏（可挪）

---

## 决策规则

| 情况 | 规则 |
|---|---|
| 天数不够 | 减场景数 > 减镜头数 > 减机位移动次数 |
| 场景太杂 | 合并场景（改剧本地点），一个主场景尽量用足 |
| 夜戏太多 | 改日戏，或集中一天拍完所有夜戏 |
| 演员档期紧 | 把他的戏集中排，先拍不可替代的 |
| 天气不可控 | 每场准备"雨天替代方案" |
| 特效镜 | 前期就锁死，避免后期返工 |
| 现场来不及 | **优先补遮盖**，不指望后期（PR-01） |
| 与制片冲突 | 回到"决策权在谁"，用可决定的范围内解决（CX-10） |

---

## 工作流

1. **资源盘点**：天数、场地、器材、演员档期、预算上限。
2. **算产能**：天数 × 每日可完成机位数（含布光/转场损耗）→ 得出可行镜头数。
3. **反推改本**：超出产能的，按"减场景 → 减镜头 → 减机位"顺序削减。
4. **按不可替代性排通告**（见上）。
5. **风险清单**：天气、器材、演员、场地、特效、动物/儿童，各写 Plan B。
6. **现场流程**：镜头表按机位归组；每场留"补遮盖"的时间窗。
7. **缺口记录**：每日收工记录"已获素材/缺口/补拍需求"。
8. 完成标准：通告单 + 风险清单 + 产能核算三者互相自洽。
9. 判停点：**产能核算与镜头表不一致 → 不准开机**。

---

## 检查清单

- [ ] 已有"天数 × 产能"的镜头数核算
- [ ] 镜头表数字与产能自洽
- [ ] 通告单按"不可替代性"排序
- [ ] 每场有雨天/意外替代方案
- [ ] 特效与危险镜头已锁死并有时间余量
- [ ] 每日有缺口记录机制
- [ ] 决策权归属明确（谁能否决什么）
- [ ] 每场留了补遮盖的时间

## 失败模式

| 失败 | 症状 | 纠正 |
|---|---|---|
| 愿望正推（CX-12） | 第 3 天开始通宵 | 用资源反推削减 |
| 场景过多 | 时间全耗在转场 | 合并场景 |
| 无 Plan B | 雨一来全组停工 | 每场准备替代方案 |
| 指望后期补料 | 缺拍无法挽回 | 每日记缺口，现场补 |
| 与制片硬碰（CX-10） | 片子被改得七零八落 | 先查决策权，在范围内优化 |
