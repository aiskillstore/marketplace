# rejected · 被淘汰的候选与原因

## 1. 只作素养、不进技能

| 类 | 代表书 | 剔除原因 |
|---|---|---|
| 电影史分期 | 《世界电影史》萨杜尔（上下）、《23 世界电影史》波德维尔、《电影通史》《中国电影史》系列 | V2 不过：史料提供参照系，推不出创作动作 |
| 理论范畴 | 《时间-影像》德勒兹、《电影是什么》巴赞、《蒙太奇论》爱森斯坦、《电影哲学概说》、《电影与方法：符号学文选》、《凝视的快感》 | V2 不过：范畴用于描述与判读，无法转成可判定指令 |
| 批评立场 | 《电影批评》戴锦华、《好莱坞批判》、《不宣而战》、《野调无腔》 | V2 不过：批评判断≠创作方法 |
| 影评合集 | 《1979-2005 最有价值影评》、《你的，大大的坏》 | V2 不过 |
| 名作清单 | 《一生要看的500电影》卷1/2 | 只作素材库（见 library map 的"参照"区） |

## 2. 常识（V3 不过）

- "要有主题" "要真诚" "要理解人物" —— 无作者特定含义时属常识
- "预算不足会拍砸" —— 常识
- "多看电影有好处" —— 常识（但"分镜级拉片法"是方法，已保留为 FR-14）

## 3. 单点/过时信息（V1 不过）

- 具体器材型号、价格、胶片规格
- 单次事件的年代细节（除非作为案例锚点）

## 4. 无法取文、未能验证

- **加密（AES-128，未解密）**：《电影艺术：形式与风格》波德维尔第8版、《电影镜头设计：从构思到银幕》卡茨第2版
- **JBIG2 编码（无解码器）**：《认识电影》贾内梯第11版
- 这些书的书名与主题已进 library map 的"书目在库（未取文）"区，**其内容未被本技能引用**，避免凭记忆冒充取文。

## 5. 边界声明

被淘汰 ≠ 无价值。**它们是本技能的"素养底座"**：不进操作指令，但决定使用者在"选择"时的品味与判断基准。凡引用被淘汰类目，技能中一律标注为"参照"，不作为执行依据。
