# candidates · 术语视角（关键概念词典）

| id | 术语 | 出处 | 作者用法 |
|---|---|---|---|
| GL-01 | 电影语言 / 视觉叙述 | 《电影语言的语法》第1章 | 用画面与声音而非文字完成叙述的整套表达系统 |
| GL-02 | 关系线（轴线/180°线） | 同上 第4章 | 连接两个演员的假想线；摄影机不得越过的基准 |
| GL-03 | 三角形原理 | 同上 | 以关系线为底、五个可落位机位构成的对话机位系统 |
| GL-04 | 视觉分句法 | 同上 第3章 | 镜头内部与镜头之间的"标点"组织方式 |
| GL-05 | 平行剪辑 | 同上 第2章 | 动作与反动作交替，制造高峰瞬间与理解力 |
| GL-06 | 建立镜头 | 《场面调度全解析》/《电影摄影入门》 | 大远景，为后续近镜提供空间参考架构 |
| GL-07 | 密闭/开放形式 | 《场面调度全解析》 | 画框自足 vs 暗示画外延续 |
| GL-08 | 纵深调度 | 同上 | 让人物在纵深层次间移动，强化三度空间与造型表现力 |
| GL-09 | 重复调度 | 同上 | 同一动作/形状反复出现以累积含义 |
| GL-10 | spine | 《电影导演方法》 | 全片或角色的贯穿动作 |
| GL-11 | 戏剧块 / 叙述拍 / 支点 | 同上 | 分块组织动作；由调度与摄影机说出的推进；戏的转向点 |
| GL-12 | 表演拍 vs 叙述拍 | 同上 | 演员心理层 vs 观众可感知层 |
| GL-13 | 客观 / 主观镜头 | 同上 | 叙述者声音的选择（谁在看） |
| GL-14 | 文字分镜（prose storyboard） | 同上 | 以文字逐镜描述，替代/先于绘图故事板 |
| GL-15 | 平面图（floor plan） | 同上 | 俯视走位图，先定调度再落机位 |
| GL-16 | 遮盖（coverage）/ 主镜头 | 《电影语言的语法》第14章"用主镜头拍摄画面中的动作" | 保底与可剪性 |
| GL-17 | 主观时长 vs 客观时长 | 《电影导演方法》 | 剪辑点由观众的心理时间决定，不由秒表 |
| GL-18 | 视觉重量 / 视觉张力 | 《电影构图经典入门》 | 由明暗、虚实、疏密、大小共同决定的注意力分配 |
| GL-19 | 视觉中心交替 | 《电影语言的语法》第3章 | 多人对话中把"注意中心"从一人交给另一人的手法 |
| GL-20 | 影调 / 层次 | 《苏牧讲视听语言》 | 明暗分布与中间层次；远景不靠顺光靠侧光 |
| GL-21 | 剪辑点 | 《电影电视剪辑学》傅正义 | 动作、情绪、节奏可切的那一瞬 |
| GL-22 | 蒙太奇 | 《蒙太奇论》爱森斯坦 | 镜头并置产生"第三意义" |
| GL-23 | 景深 | 《电影摄影入门知识总结》 | 清晰范围；全景深为王家卫式"最美画面"的偏好手段 |
| GL-24 | 移焦（rack focus） | 《王家卫作品拉片合辑》 | 用一个镜头内的焦点转移交代关系 |
