# GLOSSARY · 全包共享术语表

> 用法：读到不熟的词回来查。左列中文/常用英文，右列"在本包中的操作含义"——不是百科释义，而是**调用它时该做什么**。

## 叙事与结构

| 术语 | 操作含义 |
|---|---|
| **spine（脊椎）** | 全片主动作 / 角色贯穿欲望。**用它筛掉一切不相干的漂亮镜头**；角色 spine 必须能被全片 spine 收容 |
| **戏剧块 Dramatic Block** | 一场戏里"一个动作单元"。**先切块、再给每块不同的空间处理**，观众自然读出结构 |
| **叙述拍 Narrative Beat** | 观众可感知的一次推进。**必须由调度或摄影机外化**，否则等于没发生 |
| **表演拍 Acting Beat** | 演员心理层的一次推进。**它不等于叙述拍**；两者重合与否是风格选择 |
| **支点 Fulcrum** | 一场戏的转向点。**把最强处理押在这里；也可从它倒推整场调度** |
| **侦探工作 Detective Work** | 读本的正确姿态：找主动作、角色 spine、每场戏的支点。**不是读故事，是破案** |
| **主观时长** | 观众的心理时间。**剪辑点看它，不看秒表** |

## 视觉语言与机位

| 术语 | 操作含义 |
|---|---|
| **关系线（轴线）** | 连接两个主体的假想线。**摄影机不得越线**，除非用明确补偿（移动镜头过线、插入中性镜头） |
| **三角形原理** | 以关系线为底的五个可落位机位。**多人对话时所有机位必须落在三角形的顶点上** |
| **视觉分句法** | 用镜头充当"标点"。**段落读不通，先查分句** |
| **平行剪辑** | 动作/反动作交替。**用来制造高峰瞬间，也用来说明"两人在同一时刻"** |
| **建立镜头** | 大远景。**给后续近镜提供空间参考架构**；不给则观众会迷路 |
| **封闭形式 / 开放形式** | 画框自足 vs 暗示画外延续。**这是风格总开关，项目一开始就要定** |
| **视觉中心交替** | 多人戏中把注意力从一人交给另一人。**不交替，观众不知道该看谁** |
| **视觉重量 / 视觉张力** | 明暗、虚实、疏密、大小共同决定的注意力分配。**构图＝关系** |
| **景深 / 移焦** | 清晰范围；用焦点转移在一个镜头内交代关系。**全景深与浅景深是两种叙事态度** |

## 调度

| 术语 | 操作含义 |
|---|---|
| **纵深调度** | 人物在前后层次间移动。**加强三度空间感，用于"处境"类表达** |
| **重复调度** | 同一动作/形状反复出现以累积含义。**用于递进与呼应** |
| **移动调度** | 跟移把新信息带进画面。**一个镜头内完成时间/空间转换** |
| **平面图 floor plan** | 俯视走位图。**先定调度，再加机位** |
| **遮盖 coverage / 主镜头** | 保底素材。**主镜头是剪辑的退路，不是懒惰** |
| **客观 / 主观镜头** | 叙述者声音的选择（谁在看）。**别混用而不自觉** |

## 分镜与准备

| 术语 | 操作含义 |
|---|---|
| **文字分镜 prose storyboard** | 用文字逐镜写。**逼出"每镜承担哪个叙述拍"；漏拍一眼可见** |
| **故事板 storyboard** | 逐格图。**沟通工具，不是艺术作业** |
| **镜头表 shot list** | 机位/景别/内容/顺序。**现场效率取决于它** |

## 剪辑 / 声音 / 光线

| 术语 | 操作含义 |
|---|---|
| **剪辑点** | 动作、情绪、节奏可切的那一瞬 |
| **增益非抢救 enhancement not salvage** | 剪辑只能放大已拍到的，不能创造没拍到的 |
| **蒙太奇** | 镜头并置产生"第三意义" |
| **声音前置** | 前期就为声音留位置（"shoot for sound"）；后期补不出真实感 |
| **侧光 / 侧逆光** | 远景忌顺光；用侧光造层次 |
| **影调 / 层次** | 明暗分布与中间层次；画面"平"通常是层次问题 |

## 方法与协作

| 术语 | 操作含义 |
|---|---|
| **四段式工序** | 读本 → 演员走位 → 加摄影机 → 剪辑。**顺序不可颠倒** |
| **节奏统一律** | 摄影、造型、光影、说故事的方式统一到同一个节奏里 |
| **类型契约** | 类型＝与观众的预期约定。**先定类型，再定视觉与节奏基准** |
| **分镜级拉片** | 逐镜记录景别/机位/构图/时长。**建立个人可调用视觉库** |
