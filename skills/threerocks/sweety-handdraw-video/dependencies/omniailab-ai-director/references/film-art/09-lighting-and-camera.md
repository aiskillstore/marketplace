# 08 光线与摄影（光怎么打、镜头怎么选）

**这一域要解决**：画面是否"有层次"，以及摄影手段是否**服务于叙事**而不是炫技。

---

## 核心原则

### 1. 远景忌顺光（PR-11）
> "拍远景应尽量避免顺光，应采用侧光、或侧逆光，使景物具有层次感和表现力。" —— 《苏牧老师讲视听语言》

顺光的结果：**平**。没有明暗过渡，就没有三度空间，就没有层次。
**规则**：远景/全景用**侧光或侧逆光**；顺光留给需要"扁平、无深度、冷"的特定表达。

### 2. 布光要外化主题（CA-09）
《阳光灿烂的日子》：姜文用**高瓦数聚光灯**为主，把"环境与光的关系"的感受外化。
**判决标准**：你的布光方案能用一句话说出"这光表达了什么"——说不出就是照明，不是设计。

### 3. 光是人物处境的陈述（CA-10）
例：角色被推入黑暗，"几乎看不见了，这似乎象征着他在这个家庭中尴尬的地位"。
**用法**：人物的**能量与处境**用明暗与光位改写，不必靠台词解释。

### 4. 景深是叙事态度（GL-23 / CA-06）
- 全焦深（deep focus）：让前后景同时成立 → "一切都在场"，客观、复杂、多义。
- 浅景深/移焦（rack focus）：把注意力锁在一处 → 主观、强制、亲密或窥视。
《王家卫作品拉片合辑》记载其对**全景深**的偏爱："电影最美丽的画面，他总是用全景深来表达的。"

### 5. 技术为概念服务（CA-11）
《花样年华》为表现"香港在地球的另一端"，用**倒提摄影机**拍摄，制造失重感。
**启示**：非常规手段只有在概念需要时才成立——先有概念，才有异常。

### 6. 器材与参数服务于方案，不反过来
- 焦距：长焦压缩空间、强调人物关系；广角放大空间、制造变形与不安。
- 机位高度：平视（中性）、俯视（弱势/审视）、仰视（权威/崇高）。
- 曝光：宁可保留层次，不要"到死白/死黑"。

---

## 决策规则

| 情况 | 规则 |
|---|---|
| 画面"平" | 先改光位（顺光→侧光），再改景别，最后才加元素 |
| 需要权威感 | 仰角 + 侧光 + 稍低机位 |
| 需要弱势/压抑 | 俯角 + 顶部光 + 暗部占比大 |
| 需要亲密度/窥视 | 浅景深或移焦 |
| 需要"一切都在场" | 全焦深 + 纵深调度（与 `05` 联动） |
| 场景色彩冲突 | 用光位与曝光压统一，而非后期调色硬拉 |
| 反光/玻璃/水面 | 提前定偏振与机位，现场无法补救 |
| 昼夜外景 | 定"魔幻时刻"窗口，写进通告单 |

---

## 工作流

1. **定画面基准**：一句话写出这场戏的光线意图（可用"高对比/柔/冷/热/无影"等词）。
2. **定光位方案**：主光方向（顺/侧/侧逆/逆）、比数（明暗比）、是否需要底子光。
3. **定镜头方案**：焦距（空间态度）、景深（叙事态度）、机位高度（权力关系）。
4. **定特殊手段**：是否需要移焦、遮板、反射、非常规机位——**逐条写清"为表达什么"**。
5. **与调度对齐**：光位要允许走位（人走到暗处/光处本身就是叙事）。
6. **与美术对齐**：色彩与材质决定光的效果（回 `10`）。
7. 完成标准：每场有"光线意图一句话 + 光位方案 + 镜头方案"。
8. 判停点：**说不出光线意图 → 这场还没设计完**。

---

## 检查清单

- [ ] 每场戏有"光线意图"一句话
- [ ] 远景/全景用侧光或侧逆光，非顺光
- [ ] 光位方案允许并强化走位
- [ ] 焦距与景深的选择能说出叙事理由
- [ ] 机位高度与权力关系一致
- [ ] 特殊手段逐条写明"为表达什么"
- [ ] 昼夜外景的拍摄窗口已进通告单
- [ ] 与美术的色彩/材质已对齐

## 失败模式

| 失败 | 症状 | 纠正 |
|---|---|---|
| 顺光拍全景 | 画面平、无层次 | 改侧/侧逆光 |
| 为亮而亮 | 画面像电视广告 | 定光线意图 |
| 浅景深滥用 | 空间关系消失、观众迷路 | 需要"一切在场"时改全焦深 |
| 非常规手段无概念（CX-11 近亲） | 炫技、出戏 | 先有概念再用异常手段 |
| 光与走位打架 | 演员走进死黑 | 光位与走位一起设计 |
