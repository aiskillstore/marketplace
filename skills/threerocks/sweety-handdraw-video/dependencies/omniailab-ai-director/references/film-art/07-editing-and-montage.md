# 06 剪辑与蒙太奇（切在哪、为什么切）

**这一域要解决**：成片的时间与节奏。核心信条是——**剪辑只能放大你已经拍到的。**

---

## 核心原则

### 1. 剪辑是增益，不是抢救（PR-01）
> "the editing process should be one of enhancement, not salvage"
> "do not rely on the editing room to rescue you."

推论：
- 现场解决不了的问题，剪辑也解决不了；
- 因此**剪辑的判停点要在拍摄前就设好**（镜头表阶段就把缺拍补掉）；
- 剪辑出现"总觉得差一点"，通常是**拍的时候支点没处理好**（回 `01`）。

### 2. 剪辑点由"观众的心理时间"决定，不由秒表（GL-17）
Proferes：剪辑时可能发现"要去掉顾客走到第一个摊位的一两步"——**拿掉的是观众不需要的客观时间**。
- 判断标准：观众此刻**想知道什么**。他还没想知道 → 你切早了；他已经知道 → 你留长了。

### 3. 先按叙述拍粗剪，再调节奏
两遍法：
1. **结构遍**：只按"叙述拍"排顺序，让每个拍都在，时长不管。
2. **节奏遍**：调时长与切点，把节奏统一到一个基准上（FR-15 节奏统一律）。

### 4. 节奏统一律（FR-15）
> "你非得将摄影、造型、画面光影、所有细节，乃至说故事的方式，皆统一于这个节奏里。"

节奏不是剪辑阶段才定的——它从剧本、摄影、造型就开始统一。**剪辑只是最后一个确认者**。

### 5. 蒙太奇＝并置产生第三意义（GL-22）
两个镜头相接产生的含义，不等于两者之和（爱森斯坦《蒙太奇论》）。
- 用它来**省略时间**（并行、压缩）、**建立对比**、**制造因果错觉**。
- 注意：情感性并置要节制，滥用会让观众察觉"被操纵"。

### 6. 别在剪辑台上无限消耗（CX-14）
侯孝贤剪《悲情城市》与廖庆松磨了三个多月，最糟处几乎翻脸。
**教训**：必须有判停点。"总觉得还能更好"是剪辑台最贵的状态。

---

## 决策规则

| 情况 | 规则 |
|---|---|
| 观众"看不懂" | 先查**分句**（缺建立镜头）与**空间方向**（越轴），不是加旁白 |
| 节奏"拖" | 删客观时间的冗余（走路的步数、开门的过程） |
| 节奏"赶" | 不是回到长镜，而是在**情绪拍点**上给出停留 |
| 想知道切点位置 | 在**动作中间切**（动作切）比在动作完成后切更自然 |
| 需要时间压缩 | 用平行剪辑/重复镜头，而非加速 |
| 两镜接不上 | 检查运动方向与视线（`04`） |
| 剪了很久仍不满 | 停下，写"到底缺哪一拍"，指向补拍或改结构 |
| 素材不足 | 用遮盖不足的事实接受方案降级，别硬凑 |

---

## 工作流

1. **结构遍（不看时长）**：按叙述拍排顺序。
   - 完成标准：所有叙述拍在成片里能被指出位置。
2. **标记缺拍**：列出"应有但没有"的拍 → 决定补拍或改结构。
3. **节奏遍**：逐段定切点。
   - 完成标准：全片节奏基准统一（快/慢的切换是有意的）。
4. **空间遍**：逐段检查越轴与运动方向。
5. **完整看片 ×3**（混录前，间隔开）——这是 Proferes 点名的学生最大错误（CX-08）。
   - 完成标准：**不看字幕也能看懂人物在做什么**。
6. **设判停点**：明确"改到这个版本就停"的条件（时间/收益双条件）。
7. 判停点：**出现"只是消耗时间"就停**（CX-14）。

---

## 检查清单

- [ ] 每个叙述拍在成片里可指认
- [ ] 缺拍清单已清零或已接受降级
- [ ] 全片节奏有统一基准
- [ ] 无越轴、无方向不匹配
- [ ] 动作切多于"完成后再切"
- [ ] 混录前完整看片 ≥3 次，间隔开
- [ ] 不看字幕能看懂人物在做什么
- [ ] 有明确判停条件

## 失败模式

| 失败 | 症状 | 纠正 |
|---|---|---|
| 指望剪辑救场（CX-01） | 反复重剪仍不行 | 回现场/回结构 |
| 只看技术不看片（CX-08） | 混录后才发现整体不对 | 建立看片节律 |
| 幕布式节奏（全程一个速度） | 观众疲劳 | 定基准＋有意变速 |
| 用加速代替省略 | 观众察觉被糊弄 | 用平行剪辑/重复镜头 |
| 无限消耗（CX-14） | 工期崩 | 设判停条件 |
