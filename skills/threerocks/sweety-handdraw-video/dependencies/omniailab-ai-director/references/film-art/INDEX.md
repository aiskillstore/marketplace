## 三、推荐学习顺序

### 路线 A · 主线打通（第一次用，按工序走一遍）
1. `01-story-and-script.md` —— 先会读本（spine / 戏剧块 / 叙述拍 / 支点）
2. `05-staging-and-camera.md` —— 再把设计落到平面图与机位
3. `04-visual-language.md` —— 补关系线与视觉分句，避免"看不懂"
4. `06-storyboard-and-shotlist.md` —— 变成可执行的镜头表
5. `07-editing-and-montage.md` —— 收口：剪辑只做增益
6. `13-master-methods-and-mindset.md` —— 回头用大师方法校一遍自己的决策

### 路线 B · 按痛点补课
- 戏"平"没张力 → `05` → `04` → `09`
- 观众"看不懂" → `04`（分句/建立镜头）→ `05`（越轴）
- 剪辑救不了 → `07` → 回 `01` 查 spine 与缺拍
- 演员演不出来 → `02` → 回 `05` 查是否该用调度承载表演
- 资源不够 → `12`（资源反推镜头数与场景数）

### 路线 C · AI 短剧 / 虚拟制片专线
1. `01` 定 spine 与戏剧块 → 2. `06` 写文字分镜 → 3. `05` 用关系线锁一致性 → 4. `07` 先定节奏再生成
（映射说明见 `GUIDE.md` "迁到 AI 短剧 / 虚拟制片"）

## 四、跨域铁律（任何域卡住都回这里）

1. **顺序不可颠倒**：读本 → 演员走位 → 加摄影机 → 剪辑（FR-01）。
2. **每一镜一个叙述拍**：说不出来的那一镜就是白拍（PR-02）。
3. **剪辑是增益不是抢救**：现场没解决的，剪辑台救不回来（PR-01）。
4. **定不下 spine，后面全是空转**：跨域冲突一律回到域1（CX-02）。

## 五、能力域互链（依赖 / 对比 / 组合）

> 别把 12 个域当 12 个孤岛用。下面每条关系都是**实际会发生的调用顺序或替换选择**，不是凑数。

### 依赖（A 的前提是先想通 B —— 顺序错了会返工）

| 关系 | 为什么 |
|---|---|
| 域4 场面调度 ← 域1 剧本与叙事 | 没定 spine、没标支点，调度没有设计依据（CX-02：每场都对，整片散） |
| 域5 分镜与镜头表 ← 域4 场面调度 | **先有调度再加机位**（PR-03）。反过来做＝用机位补走位，戏不会变好 |
| 域2 人物选角表演 ← 域1 剧本与叙事 | 角色 spine 不清，讲戏就没有依据；也判不出是演员错还是设计错（PR-07） |
| 域6 剪辑 ← 域5 分镜与镜头表 | 镜头表的"承担哪个叙述拍"就是粗剪的判停清单；没有它，剪辑只能凭手感 |
| 域11 制片与现场 ← 域1 剧本与叙事 | 先有主动作与场次，才能反推镜头数、场景数与周期（PR-18） |
| 域8 光线与摄影 ← 域3 视听语言 | 画面"平"的一半是层次问题，属构图与视觉重量范畴（PR-11 / CX-05） |

### 对比（二选一，按情境挑 —— 不是优劣）

| 二选一 | 怎么选 |
|---|---|
| 域3 封闭形式 **vs** 开放形式（FR-08） | 风格总开关，项目一开始就定：要控制与风格化 → 封闭；要写实与画外延续 → 开放 |
| 域6 蒙太奇修辞（并置生第三意义） **vs** 连续剪辑（只服务读懂） | 想制造联想与冲击 → 蒙太奇；观众先得看懂 → 连续剪辑。**"看不懂"成灾时停用蒙太奇** |
| 域2 把表演交给演员 **vs** 把表演交给场景与节奏 | 演员可控 → 交给演员；演员不可控（非职业／儿童／动物）→ 用场景与节奏承载（CX-13 的正解） |
| 域4 纵深调度 **vs** 重复调度 **vs** 移动调度（FR-09） | 要三度空间的"处境"感 → 纵深；要递进与呼应 → 重复；要一镜内完成时空转换 → 移动 |

### 组合（经常一起调用）

| 组合 | 什么时候一起用 |
|---|---|
| 域1 + 域4 | 主线工序的 Step 1→2，读完本当场上平面图 |
| 域3 + 域4 | 关系线、越轴补偿、移动过线——**是同一张平面图上的事**，拆开做必出错 |
| 域4 + 域8 + 域3 | 治"戏平"的三连：走位找秩序 → 侧光造层次 → 构图承担关系 |
| 域9 + 域8 | 色彩方案与光线方案必须同定，否则两组人各打各的，成片颜色打架 |
| 域5 + 域6 | 镜头表的顺序列＝粗剪的叙述拍顺序，两件事共用一份表 |
| 域12 + 全部 | 拉片法为每个域提供参照；卡住时用大师方法校一遍自己的决策 |

## 六、能力卡六要素在各册中的落点
