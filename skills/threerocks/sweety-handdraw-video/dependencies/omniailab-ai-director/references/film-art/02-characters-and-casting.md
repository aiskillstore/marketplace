# 02 人物、选角与表演

> **域定位**：管「他是谁、他要什么、谁来演、怎么让他在镜头前做对」。人物是剧本的承重墙——**主题是动作和人物**，人物立不住，结构再巧也是空架子。
> 不管机位（04）、不管最终怎么剪（06）；只管**人物内核的判断、关系的可见化、以及给演员什么指示**（排练细节见 03）。
>
> **行号约定**：「《书名》行 N」的 N = 该书正文的**原始行号**（1 起），可复核。

## 一、核心框架

### 1. 每个角色先问「他的目的是什么」

- **原文**：「导演要对每个角色的目的动机有所了解，无论是在整个故事发展过程中，还是在其在故事中出现的具体时间内。每个角色在剧中的客观目的性可以是有意而为，也可以是无意识的举动。」——出处：《影视短片的制片与导演》行 2122。

- **自述**：读本时**逐个角色**问两遍——**他在整个故事里要什么**、**他在这一场里要什么**。两句都要能答。答不出的角色，在画面里必然"飘"（演员也不知道该怎么使劲）。注意"**无意识的举动**"也算目的——人物并不总知道自己要什么，但**他一直在要**，这才是活人。

- **用它做什么**：给每个角色写一行"目的卡"（全片目的 + 本场目的）。**这是给演员的第一份材料**，也是判断"这场戏该谁占上风"的依据。

- **什么时候别用**：① 纯状态/群像式作品（《茶馆》式群像）里有些角色就是**背景生态**，不需要个体目的；② 别把"目的"写成任务清单——目的要能驱动**动作**，不能是抽象形容词。

### 2. 对话的四条硬规则

- **原文**：「规则一，对话必须代表这个真实的角色，就是有**性格性的对话**。规则二，**尖锐而清晰**。规则三，要把这个人给他**转化、描述出来**。规则四，**推动情节**，移动、推动情节。」——出处：《知名编剧杰内特·内布里斯经验谈》行 1521。

- **自述**：这是**最快能用来判断台词好坏的四把尺**。① 换个人说这话还成立吗？成立＝没有性格性，废。② 一句话说的是不是那件事，糊不糊？③ 这句台词有没有让人物**多暴露一点**？④ 删掉它情节会不会不推进？四条都过，才是能用的台词。

- **用它做什么**：读本时逐句过筛。**改不动剧本也能用**：导演在现场至少能删掉不满足①②的台词，逼出可演的留白。

- **什么时候别用**：① 刻意的"废话戏"（安东尼奥尼式日常对话）有意违反②④，其价值在**氛围与空转**；② 类型喜剧的插科打诨不走这四条。

### 3. 用「语言状态」与「动作」把关系外化

- **原文**：「我们可以从人物之间语言状态方面去有效地表现人与人之间的关系…**人的动作同样可以展示人物关系的远近和亲疏**。父母对子女的动作是亲密无间的。恋人之间则可能是咆哮的，毫不留情的。」——出处：《剧本创作：人物塑造法》行 2020。

- **自述**：人物关系**不能靠台词说出来**，要靠两样东西让人看见：**说话的方式**（语速、口气、抢话还是让话）和**身体的对待方式**（距离、触碰、回避）。"我们是好朋友"这句台词谁都会写；**两个人站着说话时肩膀有没有对着对方**，才见功力。

- **用它做什么**：排一场关系戏，先定**两个动作/距离参数**（比如"谁先移开视线""两人的站位距离"），比给十句台词管用。

- **什么时候别用**：① 信息密度极高的戏（法庭陈述、交代前史）需要台词承载信息，此时关系外化退居其次；② 别为了"外化"硬加动作，会让表演变假。

### 4. 外表与性格的反差（用"误导"来刻画）

- **原文**：「虽然外表是判断人物性格特征的重要依据，但它也经常会误导我们。」——出处：《看电影的艺术》行 1745（《冰血暴》里怀孕戴软帽的玛吉掩盖了她的精明；《永不妥协》里穿紧身俗衣的女主角让人误以为缺乏智慧）。

- **自述**：观众**第一眼就会读外表**——这是天赐的刻画杠杆：**先给一个"看起来是×的人"，再让他做出"非×的事"**，反差立刻造出人物深度。反过来，如果人物的外表和内在完全一致，演员就只有"演类型"的空间。

- **用它做什么**：选角时把"外表像不像"往后放一放，先问**"外表能不能帮上忙"**——要么精确（一眼是人），要么**反向误导**（更有戏）。

- **什么时候别用**：① 需要观众**零成本代入**的角色（功能型配角）反而要一眼可读；② 反差用得太多就变成"故意反着来"，观众会失去信任。

### 5. 群像：性格要「越人而出」，脑子里要有标本

- **原文**：「同样是晚上出租汽车司机的故事，它就展示了群像，时间是整一的…但是**性格要越人而出**。我们看老舍先生写《茶馆》…你脑子里要有不同性格，**标本得多**。」——出处：《中国知名编剧经验谈》行 3509。

- **自述**：群像戏的病根是"几个人长得一样"。解法是**给每个人一个不可互换的标本特征**——不是标签（胖子、戴眼镜），而是**行为方式**（谁先开口、谁总是笑、谁从不坐下）。检验法：**把台词在几个人之间随机互换，如果毫无违和，说明这批人没立起来**。

- **用它做什么**：群像人物的"互换测试"。每个角色至少要有一个**只属于他的行为**。

- **什么时候别用**：① 群像戏仍要有**焦点人物**，不能让所有人一样重（观众会失去视角）；② 《茶馆》式群像适合舞台化处理，电影群像常需借助景别/焦点来分配注意力（接 03）。

### 6. 人物弧光可以是「他不变」

- **原文**：「仅仅因为伊萨克性格中没有发生任何根本的变化，并不意味着（整部影片）没有发生任何有重大意义的事情。」——出处：《作为文学的电影剧本》行 2298（瑞典《野草莓》）。

- **自述**：很多人把"人物必须成长"当铁律，其实**另一种更高级的设计是"人物不变，世界/关系变了"**——或者"他到最后也没能改变，但**我们看清了他为什么不能改变**"。这类片子不给你"成长的满足"，给你"看清的震动"。

- **用它做什么**：当剧本人物"没有弧光"时，先别急着加成长线，问一句：**这片子要的是成长，还是看清？** 后者是合法且常常更强的选择。

- **什么时候别用**：商业类型片（尤其主流叙事剧）观众**期待**主角变化，不给成长会有"没完成"感。别把艺术片的逻辑硬套到类型片上。

### 7. 正／反人物的「贯串动作」与「反贯串动作」

- **原文**：「表现好正面人物的动作及**贯串动作**，也要组织、寻找、表现好反面人物的**反动作及反贯串动作**。这样才能为展现…的戏剧性、塑造人物思想性格提供良好的平台。」——出处：《功夫片的秘密：动作导演艺术》行 1877。

- **自述**：**每个主要人物都有一条"从头贯到尾的动作线"**（贯穿动作，也就是他的终极目的），而**对手必须有与之针锋相对的"反贯串动作"**。两条线咬着走，戏才有持续的对抗；只有主角有目标、对手只是"障碍物"，戏就散。

- **用它做什么**：画一张**两条贯串动作线的对照图**。检查：反派的动作线是否**和主角一样明确**？如果反派的动机只有"他是坏人"，补动机。

- **什么时候别用**：① 非人对抗的戏（人 vs 自然/命运/自我）不需要反派贯串动作；② 群像/无明确正反的题材（如《一一》）不适用。

## 二、原则清单

- 「剧本的主题是**动作和人物**。」（《剧本创作：人物塑造法》675）
- 「一切角色毫无例外地都应该具有性格特征，**没有性格特征的角色是不存在的**。」（斯坦尼，转引《演员自我修养》16009）
- 每句对话都要过四把尺：性格性 / 尖锐清晰 / 转化人物 / 推动情节。（《知名编剧杰内特·内布里斯经验谈》1521）
- 人物关系靠**语言状态 + 动作**外化，不靠台词声明。（《剧本创作：人物塑造法》2020）
- 外表会**误导**对性格的判断——这是刻画杠杆。（《看电影的艺术》1745）
- 群像的性格要「**越人而出**」，脑子里要多备"标本"。（《中国知名编剧经验谈》3509）
- 人物"不变"也可以是有效的设计——重点是**看清**而非成长。（《作为文学的电影剧本》2298）
- 主要人物要有**贯串动作**，对手要有**反贯串动作**。（《功夫片的秘密》1877）
- 角色的目的分两层：**全片目的**与**本场目的**，两层都要答得出。（《影视短片的制片与导演》2122）
- 导演要理解**每个角色在剧中的目的**，这是排练与选角的前提。（《影视短片的制片与导演》2122）
- 人物必须具有**视觉造型性**——影视靠视觉形象作用于观众。（《电影编剧学》汪流 3851）
- 用**焦距/景别**描述人物关系：大广角可强调物理与心理的**距离感**。（《拍电影：现代影像制作教程》3137）
- 关系也能用**光影**说：不做台词阐述，用光影交代疏离。（《镜头在说话》4282）
- 演员按功能分层：主角 / 配角 / 客串（≤5 句台词）/ 群众 / 替身。（《拍电影：现代影像制作教程》852）

## 三、案例

**① 《冰血暴》玛吉 / 《永不妥协》艾琳——用"误导性外表"立人物**
怀孕戴软帽的玛吉掩盖了她的精明，穿紧身俗衣的艾琳被误以为缺乏智慧。（《看电影的艺术》行 1745）——**用法**：先让观众用外表给人归类，再用行为推翻它，人物立刻有了层次。**这也是选角的依据**：挑能承载这个反差的演员，而不是"最像"的演员。

**② 《公民凯恩》早餐戏——用广角拍"越坐越远"**
「先生和妻子被架构得看起来离得很远，以此来强调疏离感…威尔斯就以大量使用大广角镜头来强调剧中角色间物理和心理上的距离感而闻名。」（《拍电影：现代影像制作教程》行 3137）——**用法**：**关系变化可以用光学完成**，不必写台词。

**③ 基耶斯洛夫斯基《十诫·背叛篇》——用光影交代夫妻疏离**
「性功能障碍的男主人公回家却不想见隔阂已久的妻子，导演没有用大段的对白来阐述两人疏离的关系，而是**用光影来告诉观众**。」（《镜头在说话》行 4282）——**用法**：关系的最经济表达往往不在台词里。

**④ 《野草莓》——主角没变，但"看清"发生了**
「仅仅因为伊萨克性格中没有发生任何根本的变化，并不意味着（整部影片）没有发生任何有重大意义的事情。」（《作为文学的电影剧本》行 2298）——**用法**：为"无弧光"的人物找到另一种完成度。

## 四、反例 / 陷阱

- **群像人物可以互换**：把台词在几个角色间互换而毫不违和，就是没立起来。（《中国知名编剧经验谈》3509 的反面）
- **对话只有信息、没有性格**：违反"性格性对话"这条尺。（《知名编剧杰内特·内布里斯经验谈》1521）
- **反派只是"障碍物"**：没有反贯串动作，对抗就散。（《功夫片的秘密》1877）
- **用台词声明关系**：「我们是好朋友 / 我很恨你」——关系要靠动作与语言状态外化。（《剧本创作：人物塑造法》2020）
- **把"成长"当唯一合法弧光**：硬加成长线不如把"看清"做扎实。（《作为文学的电影剧本》2298）
- **演员功能不分层**：把群众演员当配角用（或反之），现场秩序与表演密度都会垮。（《拍电影：现代影像制作教程》852）
- **无意识的目的被忽略**：人物"不知道自己为什么要"时**仍然在要**，漏掉这层，演员就演不出挣扎。（《影视短片的制片与导演》2122）

## 五、术语

- **贯串动作** —— 一个主要人物从头贯到尾的终极目的线。（《功夫片的秘密》1877）
- **反贯串动作** —— 对手针对主角贯串动作而设的对抗线。（《功夫片的秘密》1877）
- **目的（objective）** —— 角色在某场/全片要达成的东西；可含无意识成分。（《影视短片的制片与导演》2122）
- **性格性对话** —— 换个人说就不成立、只属于这个角色的台词。（《知名编剧杰内特·内布里斯经验谈》1521）
- **人物弧光** —— 人物在片中的变化轨迹；也可以设计为"不变"。（《作为文学的电影剧本》2298）
- **视觉造型性** —— 影视人物必须能被"看见"，而非只被叙述。（《电影编剧学》汪流 3851）
- **主角 / 配角 / 客串 / 群众 / 替身** —— 按台词量与功能划分的演员分层。（《拍电影：现代影像制作教程》852）
- **性格特征（性格化）** —— 斯坦尼：一切角色都应有，不存在"没有性格特征的角色"。（《演员自我修养》16009）
- **群像** —— 无单一主角、以生态呈现多人的作品形态。（《中国知名编剧经验谈》3509）
