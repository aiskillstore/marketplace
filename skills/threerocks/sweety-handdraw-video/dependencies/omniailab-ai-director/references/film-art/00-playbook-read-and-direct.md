# 00 读本与讲戏 · 主线作业流程

> **这是把 15 个能力域串起来的主线工序。** 拿到一个剧本、故事梗概、甚至一句"我想拍个××"，从这里开始。
> 每个能力域负责回答它那一格问题（见 `GUIDE.md` 能力地图）；本页只负责**顺序、判停点和分派**。
> 三条铁律先记住：**顺序不可颠倒**（读本 → 演员走位 → 加摄影机 → 剪辑）；**每一镜必须承担一个叙述拍**；**剪辑是增益不是抢救**。

---

## 第一步：读本（不可跳过）

**产出：一份读本备忘。** 不做这一步就进第二步，后面全是补救。备忘至少要落这 8 项：

| # | 要落的项 | 判断标准 | 依据 |
|---|---|---|---|
| 1 | **线（结构）+ 点（主题）** | 能用**一句话**说出"这是个什么故事、讲什么"。说不出来＝没读懂，回去重读 | 01 |
| 2 | **人物目的卡** | 每个角色两行：**全片要什么** + **本场要什么**。答不出的角色必然"飘" | 02 |
| 3 | **两条贯串动作线** | 主角的贯串动作 vs 对手的**反贯串动作**。反派不能只是"障碍物" | 02 |
| 4 | **戏剧块切分** | 一场戏切几块？**每块一个主动作**？块数是手感，不是公式 | 01 |
| 5 | **叙述拍标注** | 逐拍问："观众**收到**变化了吗？"只有表演拍没有叙述拍的，要补手段 | 01 / 03 |
| 6 | **支点标注** | 每场戏最强的那一下押在哪一刻？说不出来＝这场没有重心 | 01 / 05 |
| 7 | **伏笔回收表** | 列「埋—收」对照。只埋不收 / 只收没埋，都是结构漏洞 | 01 |
| 8 | **诊断** | 哪一幕塌（多半第二幕对抗不足）？哪场戏**没有"变"**（删或补）？ | 01 |

**判停点**：第 1 项做不出来，**不要往下走**。第 5、6 项做不出来，说明这场戏还没想清楚，先别谈机位。

---

## 第二步：讲戏（把判断翻译成演员能执行的东西）

导演讲戏的句式只有一种：**动词 + 副词**，不是形容词。

| 别这么说 | 这么说 |
|---|---|
| "你要更悲伤一点" | "她开口的时候，你把杯子放回桌上" |
| "这里内心很复杂" | "他在等她先说话，但等了半秒就先开口了" |
| "演出爱恨交加" | "他把照片翻过去，又翻回来"（情绪交给剪辑） |

**每场戏写一行三段式**（马梅）：**主旨 → 动作 → 镜头**。
例：「这场戏的主旨＝获得撤销成绩；动作＝提早到达；镜头＝某人走到长廊一端 / 转动门把 / 坐下。」

**三条硬规矩**：
1. **情绪不是演员的职责**——要求演员"演出崩溃"，是把剪辑的活推给他（03 框架 2）。
2. **演员找不到感觉，先补「规定情境」**，不要在情绪上加压（03 框架 4）。
3. **台词念不好，先试"演得快点"**，比讲十分钟人物背景管用（03 框架 5）。

**判停点**：如果一段戏写不出"动作"（只有情绪形容词），说明这场戏**还没被想清楚**——回到第一步补戏剧块与叙述拍。

---

## 第三步：落实（把判断分派到各域）

按铁律的顺序往下走，**别跳步**：

```
读本判断（01/02） → 演员走位（05） → 加摄影机（04/05） → 切（07）
                        ↑                    ↑
                    表演指导（03）        声音/光线/美术（08/09/10）
```

| 你要解决的事 | 读哪个域 | 典型问题 |
|---|---|---|
| 这场戏该谁占上风、怎么转换 | 01（回合）+ 03（潜台词） | "对话戏平" |
| 人怎么走、机器放哪 | 05 | "人物在画面里像摆拍" |
| 两个人一对话就拍乱 | 04（关系线/三角形原理） | "看不懂谁在看谁" |
| 这一镜该给谁特写 | 04（景别＝注意力指派） | "观众没看到重点" |
| 这场戏太闷 | 08（声音先入）/ 07（节奏） | "平、拖" |
| 画面没质感 | 09（光线）10（美术造型） | "廉价感" |
| 类型片该怎么拍 | 14（类型实操） | "武侠/恐怖拍不出味" |
| 想借鉴某位大师 | 15（国别与流派） | "怎么拍出那种味道" |
| 资源不够怎么拍 | 12（制片与现场） | "只有一台机/很少钱" |

## 分诊速查：症状 → 先查哪本

| 症状 | 先查 | 常见根因 |
|---|---|---|
| "整片散，每场都对" | **01** | 没定**线（主动作）** |
| "戏太平，没张力" | **01 → 03** | 场景没有目标-障碍-转折；或只有表演拍没有叙述拍 |
| "看不懂谁在看谁" | **04** | 越轴 / 没画关系线 |
| "演员演到了观众没收到" | **03** | 表演拍≠叙述拍，缺外化手段 |
| "台词像念稿" | **03** | 演员在念字不在**要东西**；先"演得快点" |
| "人物立不住" | **02** | 角色没有明确目的；或群像可互换 |
| "反派太弱" | **02** | 缺**反贯串动作** |
| "中段塌" | **01** | 第二幕对抗不足（无加码） |
| "结尾无力" | **01** | 第三幕的解决与第一幕的缺口没对上 |
| "剪辑怎么切都不对" | **01/07** | 多半是**现场没解决**——剪辑是增益不是抢救 |
| "画面平" | **04/09** | 远景顺光、缺少前后景层次 |
| "风格不对/像学生作业" | **15/13** | 没有统一的机位伦理与风格约束 |

## 交付物清单（一部片子在"前期"该产出的东西）

1. **读本备忘**（本页第一步的 8 项）
2. **人物目的卡**（每角色全片目的 + 本场目的）
3. **两条贯串动作线对照图**
4. **戏剧块与支点表**（每场：切几块、支点在哪）
5. **伏笔回收表**
6. **每场的「主旨→动作→镜头」表**（讲戏用）
7. **平面图 + 机位图**（接 05）
8. **镜头表 / 故事板**（接 06）
9. **声音预留清单**（接 08）
10. **拍摄计划与风险单**（接 12）

## 与其他手册的关系

- **本页是入口**：判断"现在该做哪一步"，然后把具体问题交给对应域。
- **01/02/03 是内环**（故事、人物、讲戏）——**改动成本最低、收益最高**，优先在这里解决问题。
- **04~10 是中环**（视听落地）——读本对了，这一步才有意义。
- **11~15 是外环**（参照、类型、风格、制片）——用来找基准、定风格、控资源。

> 一句话：**先在剧本上解决问题，再在排练场上解决，最后才在监视器前解决。** 反过来做，代价是指数级的。
