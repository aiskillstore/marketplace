# 10 类型与参照（观众期待什么、基准在哪）

**这一域要解决**：**类型是与观众的预期契约**——定了类型，就定了"什么时候观众会猜中，什么时候要打破猜中"。

---

## 核心原则

### 1. 类型是契约，不是标签（FR-13）
《电影类型与类型电影》：类型是工业与观众之间的**预期约定**。观众买票时已经预付了期待。
导演的工作：
- 知道观众**期待什么**（必须给足）；
- 知道在哪个点**打破期待**（创新点/记忆点）；
- **两个都要有**：只给期待 = 平庸；只打破 = 观众流失。

### 2. 先定发行场景，再定商业元素（PR-18）
芦苇：
> "应该明白这个制片目的是什么……如果给院线做，我就得想一些商业元素。"

**操作**：先回答"在哪放、给谁看、多长"，再决定视觉强度、节奏、信息密度。
短剧/短视频的"类型契约"与院线完全不同——**别把长片的打法搬到 60 秒里**。

### 3. 参照片单要"分镜级"而不是"感觉级"（FR-14 / CA）
拉片的价值在于**具体到"这一镜为什么这么放"**：
- 景别、机位、时长、构图、光位、声画关系逐项记录；
- 记录的是**手段**，不是"氛围很好"。
建立个人可调用库：遇到"这场戏不知道怎么办"时，从库里找**手段**而不是找"感觉"。

### 4. 类型决定视觉基准
| 类型 | 常见视觉基准 | 常见风险 |
|---|---|---|
| 爱情/文艺 | 浅景深、移焦、暖调、留白 | 节奏过慢而信息不足 |
| 惊悚/恐怖 | 封闭构图、暗部占比大、主观镜头 | 滥用手持与跳吓 |
| 动作/武侠 | 快镜剪接、摄影变速、方向清晰 | 方向混乱、看不清楚 |
| 喜剧 | 全焦深、正面机位、信息给足 | 用景别藏笑点 |
| 犯罪/黑色 | 高对比、侧光、镜面与窗框 | 视觉压过叙事 |

---

## 决策规则

| 情况 | 规则 |
|---|---|
| 项目刚启动 | 先写"类型一句话 + 给足什么 + 打破什么" |
| 想创新 | 打破点要少而准（1–2 处），其余遵守契约 |
| 不确定风格 | 找 2–3 部**同类型**参考 + 1 部**非同类型**参考 |
| 找参考 | 用分镜级拉片法，记录手段而非氛围 |
| 平台受限（短剧/竖屏） | 契约不同：前 3 秒定注意力、信息密度更高、景别偏近 |
| 类型混搭 | 明确主类型，副类型只做调味 |

---

## 工作流

1. **定类型契约**：写一句"这是给___看的一部___片，观众期待___，我在___处打破"。
2. **找参照**：2–3 部同类型 + 1 部跨类型；每部写出"我取它的哪一点"。
3. **拉片建库**：对参照做分镜级拉片（镜号/景别/机位/时长/构图/光位/声画）。
   - 完成标准：每条记录都是**手段**，能直接抄进自己的镜头表。
4. **定视觉基准**：从类型基准表出发，写本片的光线/景深/色彩/节奏基准。
5. **标打破点**：明确 1–2 处"观众以为会这样，我们那样"。
6. 完成标准：类型契约 + 参照片单 + 视觉基准 + 打破点，四项齐。
7. 判停点：**做不到"打破点少而准"→ 说明还没想清类型**。

## 检查清单

- [ ] 类型契约一句话（给谁看/期待什么/在哪打破）
- [ ] 参照 2–3 部同类型 + 1 部跨类型，各写明"取哪一点"
- [ ] 参照已做分镜级拉片（记录的是手段）
- [ ] 视觉基准与类型匹配
- [ ] 打破点 1–2 处且明确
- [ ] 平台/时长契约已考虑

## 失败模式

| 失败 | 症状 | 纠正 |
|---|---|---|
| 只打破不给足 | 观众流失 | 先满足契约再打破 |
| 只给足不打破 | 平庸、无记忆点 | 加 1–2 处打破 |
| 参照停留"感觉级" | 抄不到手段 | 做分镜级拉片 |
| 长片打法搬进短剧 | 信息过疏、开头不抓人 | 按平台契约重设节奏与景别 |
| 类型冲突 | 观众不知在看什么 | 定主类型，副类型只调味 |
