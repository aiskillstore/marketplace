# 实拍动态图形合成型片头与单条预告

只在真实人物、城市、建筑和动作仍清楚可辨，但多窗口、动态字体、空间字幕、遮罩、折射、粒子与 AE 级多层合成承担主要节奏时读取。它不是普通真人卡司字幕，不是把字贴到墙上的环境字幕，也不是纯纸张拼贴；至少一半画面时间保留真实摄影的空间、人物和真实光线。

## 1. 目标与不可降级项

把实拍镜头和动态图形编成同一套高密度电影视觉识别：前景图形、中景人物、背景城市/建筑、准确文字和光学效果共享相机、透视、遮挡、景深与运动方向。

无论题材如何调整，以下五项必须保留：

1. 至少 5 类真实地点/plate，日光、室内或投影、夜景/特殊光色至少三种状态。
2. 每个主要状态 5–8 个可见层；一个 Hero 效果推进，2–4 个支撑层持续反馈。
3. 至少三种真正不同的动态字体过程、三种空间关系、三层字体角色。
4. 真实 plate 的相机跟踪、透视、遮挡、接触影/反射、景深和运动模糊至少完整展开两次。
5. 最终标题由前面已经建立的轴线、字形、窗口、反射或粒子轨迹合并而来，不突然切成普通 Logo 页。

用户纠正某个效果时，只替换那个效果的来源或形态，不能因此删除多窗口、动态字体、多层合成和空间绑定整条路线。

## 2. Motion Spine：一条主轴统领高密度效果

先选一个贯穿全片的运动母题：建筑竖向网格/道路消失点、人物关系线、玻璃与窗框切割、暖金或冷银光束、圆/斜切面板/胶片框、片名的一个字腔或笔画。

所有窗口、线条、字形、粒子、反射和转场都从该主轴生长、碰触、切分并回收。高密度不等于效果拼盘；相邻状态必须继承主轴的方向、形状、专色、速度或声音中的一项，同时换入新人物、新地点和新信息。

## 3. 已验证的 AE 视觉语言

以下不是抽象标签，而是已验证案例中能产生对应效果的通用描述。最终 Prompt 必须展开成可见过程：

```text
电影级 合成动效 影视包装与动态视觉设计，把实拍电影画面和复杂动态图形包装合成为同一个三维空间。前景图形、中景人物和背景城市/建筑形成多层景深；姓名、卖点和片名不是简单浮现，而是由线条、光点、几何块、受控碎片或标题自身笔画沿准确字形逐步构建，形成完整字组后稳定可读。

文字和真实环境做空间合成：共享建筑、玻璃、街道、室内或独立深度层的相机跟踪、透视和视差；人物、窗框、车辆与前景物体产生真实遮挡。多窗口切割、关系连线、半透明网格、坐标感非文字 Marks、遮罩动画、局部粒子流、光线扫描、镜头光斑、胶片曝光、玻璃折射、棱镜大面和有来源液态遮罩按主次接力。每个状态一个主效果，另有 2–4 个低速/中速支撑层；画面始终有信息密度但不让所有层同时高速乱动。

画面保留高级电影调色、真实皮肤和摄影质感、时尚杂志式层级与可控留白。浪漫成熟、科技冷峻、校园活力或动作高能由题材决定；不做普通短视频滤镜、廉价模板动画、PowerPoint 式字幕、悬浮粗黑字和伪 HUD 数字。
```

`cinematic motion graphics package / premium AE title sequence / kinetic typography / compositing / layered animation` 只能作为内部理解，最终必须写文字怎么构建、在哪个深度、被谁遮挡、如何继承镜头、何时完整可读和怎样转到下一场景。

## 4. 两种 OUTPUT_MODE

### `opening_title`

使用 5–8 个主要构图状态与 0–3 个短 plate。影片世界、人物群像、卡司和视觉识别优先；准确文字严格按 `TEXT_CONTENT_MODE`，可以通过地点与人物卡建立关系，但不硬塞商业预告文案。

建议状态：实拍大全景与主轴出现 → 第一人物 Hero 字体构建 → 穿玻璃/窗口扩张进入第二人物 → 多地点关系版面 → 第三人物或主题卡升级 → 光学/几何合并 → 最终片名海报。

### `single_clip_trailer`

使用 8–11 个主要状态与 1–3 个短 plate；准确文字严格按 `TEXT_CONTENT_MODE`。动态图形必须放大已确认的故事信息，而不是代替故事：

```text
人物/群像的正常城市状态 → 一个真实事件或关系变化触发 → 主角卡 → 同伴/对手/阻碍卡 → 人物采取行动 → 图形连接揭示隐藏关系/世界法则 → 事件在第二、第三地点升级 → 代价或选择 → 最大合成奇观 → 片名
```

每一张人物卡必须同时回答“是谁”和“在这件事中做什么”；每一张卖点卡必须对应画面里已经出现或正在发生的冲突、法则、代价或选择。不能用窗口切割和大字掩盖人物只是在走路、站立、喝咖啡或看镜头。

推荐密度：

- `0.0–1.2s` 城市/空间与人物状态立即建立，主轴开始分割画面。
- `1.2–2.6s` 触发事件；第一句命题文字完整可读。
- `2.6–4.1s` 主角 Hero 卡，文字过程一。
- `4.1–5.6s` 第二角色/阻碍卡，换地点与光色，文字过程二。
- `5.6–7.2s` 人物行动带动面板、连线或真实平面变化。
- `7.2–8.7s` 1–3 个短 plate 和新地点提供证据，不重复同一动作裁切。
- `8.7–10.4s` 世界/关系升级，卖点卡用第三种字体过程。
- `10.4–11.9s` 代价、选择或最大合成状态。
- `11.9–13.3s` 最后动作/悬念，图形开始回收而非静止。
- `13.3–15.0s` 最终片名完整落板约 1.4–1.7 秒。

## 5. 两条已验证效果链

### G1 城市实拍 AE

无身份素材时在文本方案阶段提出 3–5 名原创成年人物并经用户确认；最终使用 5–7 个真实 plate，至少覆盖外部城市大全景、街道运动、公共交通、生活/工作室内、文化/社交空间、屋顶/开阔终景中的 5 类。确认后不临时新增人物、关系或事件。

完整母体链：

```text
城市航拍或建筑轴线快速下降，2–3 个几何窗口从主轴切开并同时露出不同人物/地点 → 第一组宽体或高对比人物名由线条、光点、几何块、受控碎片沿轮廓构建，填成玻璃/浅金属/印刷实体后稳定 → 一个窗口扩张，摄影机穿过真实玻璃进入第二地点，人物名从反射或独立深度层显现并被人物遮挡 → 建筑线、道路或动作轨迹连接人物，网格和白名单文字形成关系版面 → 咖啡蒸汽、脚步、交通灯影、展厅投影、窗帘、镜面局部或交通工具加入 1–3 个短 plate → 完整字块按语义拆成 2–3 块并重新锁定，光线扫描、镜头光斑和一次胶片曝光在可读之后发生 → 斜切面板、棱镜大面、局部粒子流和由玻璃/雨水/饮品/真实液面驱动的遮罩连续交换前中后景 → 多地点人物、光学层、准确卖点和最终标题合并为完整电影海报。
```

这条链不是固定“都市爱情”。科幻、动作、剧情、时尚或校园只替换人物事件、色盘、字体方案和材质，不删除其多地点、多窗口、空间字、反射、遮挡和层级装配。

### G2 校园群像 AE

```text
阳光校园航拍快速建立 → 海报、笔记、拍立得或实拍窗口切出不同社团和人物 → 姓名通过黑板/课本/公告板/屏幕/球场的透视或独立深度层进入，但不退化成印在牌子上的静态字 → 高亮笔划、贴纸、涂鸦、胶片框、尘粒、光漏和镜头光斑围绕角色卡形成层级 → 照片撕裂、页面展开、胶片切换、动作匹配连接课堂、图书馆、排练室、工坊、球场和黄昏聚会至少 6 个 plate → 人物关系线断开/重连，卖点卡对应友情、竞争或选择 → 多人物照片墙、实拍运动与片名合并。
```

只承诺 2–4 组准确姓名，其余人物用动作、服装、社团和地点建立群像；禁止生成不可读的“完整 20 人卡司小字”。

## 6. 场景与合成负载

每个主要状态使用 5–8 个可见层：

```text
Foreground：真实遮挡物、玻璃边、完整 Hero 字或一个几何遮罩。
Midground：主要真人和动作，脸与手始终清楚，不错误复制。
Background：城市/建筑/房间或一个次级真实窗口。
Graphic carriers：1–3 个面板、连线、框架、网格、光学大面或受控粒子层。
Type：一组准确角色/卖点/片名和必要 Utility，不新增白名单外文字。
Atmosphere：与实拍光源一致的尘粒、反射、曝光、雾、颗粒或投影，只作支撑。
```

- 多窗口最多 3 个主窗口；每个必须展示不同人物、地点、动作或关系证据。
- 实拍 AE 预告至少 6 个 plate/地点状态；Opening Title 至少 5 个。
- 连续两个状态改变地点、主景别、光色、面板结构、字体过程中的至少三项。
- 复杂状态后不必清空所有图形，但必须给人物/空间一个清楚识别时刻；不能连续三段只见图形不见真实主体。

## 7. Hero effects 与支撑效果

全片选择 4–6 个观众能明显看出的 Hero effects，按照建立、升级、高潮排序；再选择 8–14 个支撑效果跨镜延续。不要用“5–7 类模板、18–26 项凑数”代替真正可见的重点。

可选 Hero effects：

1. **多窗口空间切割与扩张**：2–3 个不同 plate 在三维视差中切开，一块扩成下一空间。
2. **准确字形轮廓构建**：线、点、几何块、受控碎片沿真实轮廓聚合并填实。
3. **主体/字体景深交换**：人物、文字和反射层在不同深度先后清晰，最后共同稳定。
4. **穿玻璃/棱镜大面**：相机穿过真实玻璃，折射大面重新组织实拍，不做碎片风暴。
5. **有来源粒子轨迹**：来自灯光、金属高光、投影或动作路径，只沿 Motion Spine 汇聚/分流。
6. **字块语义重组**：完整可读词组分为 2–3 个语义块，滑移/旋转/压缩后恢复新排版。
7. **标题笔画转场**：一个真实笔画/字腔放大成窗口、道路、圆环或遮罩，进入新场景后恢复。
8. **体积字 Hero**：只有最重要的一组字成为有厚度的空间实体，具备接触影、环境反射、正确离轴透视和尺度。
9. **有来源液态遮罩**：只从雨水、玻璃凝结、饮品、水面或反射边缘扩张，0.2–0.45 秒后恢复清楚边界。
10. **胶片曝光/投影合页**：投影光、胶片燃烧边或页面式光学层切换地点，保留实拍材质。

支撑效果可选：网格生长、描边游走、边框装配、光点轨迹、扫描高光、低对比重复字阵、镜头光斑、胶片颗粒、局部光漏、反射位移、轻微色差、玻璃污迹、投影闪动、纸片/面板阴影。一个状态只允许一个或两个层高速运动，其余层中低速响应。

## 8. PLATE COMPOSITE LOCK

每个承载角色卡、卖点或片名的实拍状态，都在内部补齐并在最终 Prompt 中用自然中文写出：

```text
PLATE=[人物动作、环境、原相机方向、镜头运动、真实光源]
ATTACH_PLANE=[墙/地/玻璃/物体/独立深度层与角度]
CAMERA_TRACK=[位置、旋转、比例；三维字才写 X/Y/Z]
PERSPECTIVE=[基线、垂直线、消失方向、离轴缩短]
PARALLAX=[前/中/后景的相对速度]
OCCLUSION=[谁从字前经过、遮挡比例、何时恢复]
CONTACT=[接触影/投影/反射/玻璃内反射]
LIGHT_MATCH=[光色、黑位、高光方向、边缘包裹]
LENS_MATCH=[景深、焦点、运动模糊、畸变、机震、颗粒]
READABLE_HOLD=[完整时刻、稳定时长、相机减速点]
```

合成层必须继承真实摄影：背景失焦时，所在深度的文字同步失焦；横移时共享方向和运动模糊；人物遮挡边缘跟随轮廓；完整阅读时相机与高速图形减速。没有投影、反射或平面证据的“漂浮字”不合格。

## 9. 字体必须是主要视觉事件

按 `typography-and-credits.md` 从以下题材方案只选一套：都市/爱情/时尚、科幻/科技、动作/高能、校园群像。每套必须包含明显不同的 Display A、Display B、Utility；不能全片使用同一种超宽粗黑字。

至少三种动态字体过程，且后一次比前一次更复杂：

- 角色卡一：轮廓构建/线框填实。
- 角色卡二：主体与文字景深交换/反射揭示。
- 卖点卡：完整字块按语义拆分重组，或笔画扩成转场。
- 最终片名：吸收既有窗口、连线、光点和字形材质后锁定。

每组文字都要经历 `触发 → 构建/揭示 → 完整字组 → 可读停留 → 一次空间/材质响应 → 稳定或退出`。墙牌、地板贴字、路牌、屏幕文字只能是其中一种空间关系，不能承担全片全部字体效果。

## 10. 摄影、转场与节奏

- 实拍可使用城市航拍下降、建筑轴线快速推移、横向跟拍、穿玻璃推镜、人物中景、群像全景和 0.25–0.65 秒动作插入。
- 相机运动与图形运动交替：相机高速时文字/面板相对稳定；字体构建或重组时相机减速。
- 转场持续约 0.18–0.45 秒，优先级：实拍动作/前景遮挡 → 建筑/字形相似匹配 → 窗口扩张 → 玻璃/反射 → 受控图形切割。
- 预告开场不超过约 1.2–1.5 秒；普通状态约 0.8–1.8 秒，最大合成状态可到约 2.2 秒；最终片名约 1.4–2.0 秒。
- 所有快切不能在 9–10 秒前结束后只剩静止海报；最后 5 秒仍需至少一次人物行动、一次地点/尺度升级和最终合并。
- 不用持续虚拟飞行、无尽穿图层和相机绕字一周展示技术感。

## 11. 完整音乐与声音

沿用验证案例“简洁但有方向”的音乐写法，不锁死歌曲：

```text
Music direction：原创 15 秒高级电影片头/预告配乐，按题材从 mature urban neo-jazz、cinematic electronic、indie pop、时尚电影节奏或冷峻科技脉冲中选择一条主气质；只给 2–4 个音色锚和完整能量曲线，不规定 BPM、拍号、调性、和弦或逐秒编曲。开场立即出现可辨识节奏/旋律动机，中段随人物卡和图形装配增加推进，8–12 秒通过变奏、增层或短抽空制造对比，最终片名处完成短促高潮并以明确终止音或完整和声收束。具体旋律、鼓点、和声和配器由 H3 自主原创。
```

只绑定 2–3 个重要同步点，如触发事件、最大字体重组、最终标题。面板、字母、粒子不逐个配 whoosh；城市/室内环境声和动作声只在接触时突出，BGM 始终可辨。

## 12. 最低检查

- 是否保留实拍人物、至少 5 类真实场景、三种光色和一条贯穿 Motion Spine？
- 预告是否有 8–11 个状态和可见故事因果、片头是否有 5–8 个状态；文字是否严格匹配 `TEXT_CONTENT_MODE`？
- 是否选择 4–6 个可记忆 Hero effects、8–14 个支撑效果，并形成建立—升级—高潮，而非小效果凑数？
- 是否至少三种动态字体过程、三种空间关系和三层字形角色；不是一套粗黑字反复出现？
- 每个重要文字是否具有 plane/depth、相机跟踪、透视、视差、遮挡、接触、光线和镜头匹配？
- 每个窗口是否提供不同地点、动作或关系信息；没有复制同一人物和重复裁切？
- 用户纠正单个粒子、液体或体积字时，是否只替换该机制而没有删掉整条 AE 合成链？
- 最后 5 秒是否仍有行动与升级；最终标题是否由既有机制合并且只稳定约 1.4–2.0 秒？
- 音乐是否是有动机、推进、高潮和终止的完整短曲，而非零散音效或没头没尾的氛围床？
