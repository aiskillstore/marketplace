# MiniMax H3 片头与 15 秒预告生成合同

生成 `final_h3_prompt` 时读取。目标是让 H3 直接执行可见、可听、可计时的 15 秒成片，不输出创意提案、内部账本、效果名清单或下游待改写 brief。

## 1. 参数与一次成稿

- 默认：MiniMax H3、15 秒、16:9、2K、24fps、同步生成音乐与环境声。
- 只在 `TRAILER_FLOW_STATE=ready_to_compile` 且 `scope_confirmed=true / design_confirmed=true / reference_scope_confirmed=true / proposal_confirmed=true` 时编译；有参考图却未完成用途 Gate 时返回 Gate 3，不生成生成指令 Prompt。
- 合法画幅、时长和参考模式以当前能力摘要为准。
- Prompt 使用中文自然语言；屏幕文字按 `TITLE_BIBLE` 保持准确语言。
- 硬范围 `5000–7000` 字符，目标 `5600–6500`。
- 按稳定结构一次写完，首次成稿后计数一次；越界时只做一次静默修整，再计数并锁定。禁止第三轮试算、逐句替换凑字符和向用户直播计数。
- 不足时补“新场景中的可见行动、主效果、支撑反馈、字体过程、转场因果”；超出时删内部字段、重复形容词、重复身份、重复边界和过细音乐说明。不能压缩准确文字、故事因果、场景变化和主效果。
- 复用用户确认前已经展示并锁定的素材职责、海报扩展范围、场景条件、转场落点和主校准；编译时不临时改写，不新增问题、媒体分析、独立校验轮次或字符计数。

内部使用的 `TITLE_INPUT / STORY_SPINE / CAMERA SCORE / EFFECT MAP / TEXT LEDGER / TYPE PROGRAM SCORE / 字符数` 不进入最终生成 Prompt。最终 Prompt 只保留 H3 可直接看见、听见和执行的内容。

## 2. 唯一生成执行

无素材时使用当前合法的纯文字路径；有素材时按最新能力摘要选择参考方式并保留全部已确认素材。只有生成指令锁全部通过、状态进入 `ready_to_dispatch` 后，才展示 `final_h3_prompt` 并在同一 assistant turn 直接执行。

展示和执行必须读取同一个已锁定字符串。不得经第二个 writer、摘要文件或另一版“生成指令 Prompt”转交；不得摘要、缩短、翻译、润色、重排或序列化后再执行。

执行校验失败时只补齐缺失的能力信息，使用字符级相同的 Prompt、素材顺序和设置重发。运行期间明确告诉用户已经生成指令；完成但输出包含运行时错误时仍按失败处理。

生成指令锁：

```text
scope_confirmed=true
design_confirmed=true
proposal_confirmed=true
prompt_length=5000..7000
type_program_complete=true
camera_plan_complete=true
transition_plan_complete=true
TRAILER_FLOW_STATE=ready_to_dispatch
```

任一项为 false、unknown 或缺失时禁止调用 video generation。工具本身接受短 Prompt 不代表通过本合同。

生成指令前必须在本 Skill 内部写出同一批检查记录，不能只用一句“已检查”代替：七项确认/编译状态、唯一案例校准、参考范围与序列模式、参考场景及使用方式、可区分视觉条件和转场落点都必须逐项核对并为真。默认模式仍要求参考环境只落在一个场景、全片至少发散到两个新地点；严格原景模式只有在用户主动选择后才成立。

编排 Agent 必须按最终 Prompt 的真实字符数检查 5000–7000，不采信预估值。`identity_grade_one_scene` 必须使用 `multi_scene`：参考图环境只对应一个场景，另外至少两个不同地点，并有 2 次落向新条件的完整转场。`strict_same_scene_people` 只有用户在 Gate 3 主动选择时使用 `single_scene_locked_reference`，且同一地点仍须至少三个可区分动作/尺度/光线状态。任一项失败就停止在本 Skill 内，不启动生成。

## 3. 最终 Prompt 结构

无素材时删除参考段；没有某类署名时不创建空栏目：

```text
【项目设置与成片模式】
【参考素材与身份锁】（按需）
【影片命题与故事钩子】
【人物、世界与视觉系统】
【准确文字、字体与版式】
【完整 15 秒音乐与声音】
【镜头与成片过程】
【连续性与最终交付】
```

推荐分配，不做逐段字符验收：

| 部分 | 建议字符 | 重点 |
| --- | ---: | --- |
| 设置与素材 | 250–450 | 参数、OUTPUT_MODE、参考贡献 |
| 命题、人物与世界 | 900–1250 | 因果故事/卡司关系、身份、场景、摄影、色盘 |
| 文字与字体 | 750–1050 | 准确白名单、双语关系、三层字体角色、文字过程 |
| 音乐与声音 | 260–420 | 完整短曲结构、音色、推进、高潮、收束、混音 |
| 镜头过程 | 2800–3900 | 不同场景、动作、主效果、文字、转场、声音 |
| 连续性 | 150–300 | 只保留真正会漂移的身份、世界、文字和声音 |

## 4. 项目、素材与身份

开头直接写：

```text
MiniMax H3｜2K｜15 秒｜16:9｜24fps｜同步生成完整原创配乐、环境声与动作音｜OUTPUT_MODE=[opening_title 或 single_clip_trailer]｜主路由=[四类之一]｜屏幕语言=[中英双语或纯英语]。
```

逐项绑定素材，不写“参考全部”。每个素材只设一个主要职责，可补一个次要贡献：

```text
@图片1：REFERENCE_SCOPE_MODE=[已确认模式]。默认模式只锁定[人物身份、服装主特征、色盘、光线和电影质感]，把图中环境仅用于[唯一场景及时间段]，其余场景保持人物与影调但主动更换地点和行动条件，原图站位/构图不贯穿；严格模式锁定[人物与同一地点]但变化动作、景别、机位、前中后景、光线和有来源效果；自定义模式逐项写明锁定与可发散白名单。
@视频1：主要参考[动作/运镜/剪辑/风格]；提取[具体节奏或空间关系]。
@音频1：只参考[节拍、重音、停顿、能量曲线或已授权内容]。
```

身份锁写人物/主体数量、脸、年龄、发型、服装、道具、关系与时代一致性；每位人物只保留能在画面中辨认的 4–6 个锚点。场景锁写时代、地点、建筑/舞台、物理法则、主材质、前中后景与尺度证据。

静态图即使已经像完整海报，也不能自行升级为全片构图锁。默认模式只让人物、服装主特征和颜色影调贯穿，把原图环境放进已确认的唯一场景；另外至少两个场景主动发散新地点和行动条件。严格原景模式才允许全片停留同一地点，但仍须有动作、尺度、空间层次和光线变化；自定义模式只执行用户白名单。

## 5. 两种成片模式

### `single_clip_trailer`

命题必须包含可见因果：

```text
TRAILER STORY: [主体当前状态] → [触发事件] → [阻碍/对手/代价] → [主体行动] → [世界或关系升级] → [未解决问题/选择] → [片名]。
```

最终 Prompt 把用户确认的因果链写成一段自然中文，不保留字段名。每个主要镜头至少推进一项：新行动、新证据、新阻碍、新关系、新尺度或新悬念。只换景别、人物走路、人物看奇观、角色摆拍或片名淡入不算剧情推进。确认后不得临时增加人物关系、往事、秘密、地名、数字、灾难或时间跨度。

无声观看时必须能回答：主体是谁、发生了什么、阻碍是什么、结尾留下什么问题。题材可保持含蓄，但不能只靠 Prompt 内的文字说明剧情、画面却没有对应事件。

### `opening_title`

命题聚焦影片世界、人物关系、职业/旅程动作和视觉母题。卡司、字体和空间设计是主角，但每个人仍通过不同动作被认识；不能只换脸、换姓名和背景。

## 6. 场景、效果与摄影

内部先完成以下判断，再转成逐镜自然语言：

- `SCENE DIVERSITY`：默认参考图模式使用 `multi_scene`，至少形成 3 个已确认的不同地点/行动条件，参考图环境只占其中一个。实拍 AE、架空特效和编辑拼贴仍至少形成 5 个物理地点、尺度区域或版面状态。电影叙事不强制镜头数量；严格原景模式不新增地点，但同一地点至少形成 3 个有信息增长的动作/尺度/光线状态。
- `HERO EFFECTS`：全片 4–6 个会改变构图或世界状态、观众能明显感知的主效果。
- `SUPPORT EFFECTS`：围绕主效果分布 8–14 个材质、反射、光线、视差、粒子、纸边、环境反馈或动作细节。
- 胶片颗粒、基础调色、普通景深、常规阴影只算质感，不算主效果。
- 每个主效果写清可见来源、运动/变化路径、接触对象、画面结果和结束状态；不要单列 26 个技术名词让模型平均忽略。
- 每个镜头只用一种主相机运动；相机移动必须揭示人物反应、空间尺度、世界法则或文字平面。
- 全片使用一种基础摄影纪律、最多三种主运镜、三至四个转场家族；转场写来源、切点、继承项和下一镜落点。

复用确认稿之前已经从 `case-calibration-matrix.md` 选择的唯一主校准，继承该案例的完整媒介链、摄影、材质、字体关系、主效果、转场种子与音乐气质；替换项目人物、世界、文案与专属物件。局部借用第二案例时只借一个机制，不改变主媒介。

实拍动态图形还要至少两次完整写出：真实 plate 与光源 → 文字/图形所在平面 → 相机跟踪与透视 → 前中后景视差 → 人物/建筑遮挡 → 接触影/反射 → 景深、运动模糊和颗粒匹配 → 完整阅读时刻。最终 Prompt 用自然画面语言表达，不抄英文键名。

## 7. 准确文字与卡片结构

先内部建立：

```text
TITLE_BIBLE:
- master_title
- cast_or_character_cards
- narrative_or_selling_lines
- crew_cards
- language: bilingual_cn_en | english_only
- text_content_mode: basic_cast | basic_cast_plus_hook | user_exact
```

文字数量只由用户在 Gate 2 选择的模式决定，不为追求密度增加万能短句：

- `basic_cast`：片名 1、导演卡 1、主要角色姓名卡 2–3。
- `basic_cast_plus_hook`：在基础卡司之外只增加 1 句用户已确认、且与画面事件直接对应的剧情钩子。
- `user_exact`：只使用用户确认的白名单；信息不完整时回到文本方案补齐，不猜写。

每张角色卡必须是主副标题结构：姓名为主层；英文名、角色身份或 `STARRING` 为副层。导演卡以导演姓名为主层，以 `导演 / DIRECTED BY` 为副层。具体出现次数、组合和无文字段由剧情与路由决定，不设固定句子下限。每组完整可读约 0.65–1.35 秒；最终片名按成片模式稳定约 1.4–2.4 秒。

### 语言与校对

- 默认中英双语：中文主信息 + 英文副信息为同一组，分别指定字形、字重、字距、行高、颜色和尺度；英文不是中文的机械缩小复制。
- 纯英语：所有可读文字只使用英文。
- 所有 Agent 提出的片名、姓名、身份、导演与剧情钩子必须已出现在用户确认的普通文本方案中；确认后不得临时补字。
- 每个片名、姓名、角色身份和短句在白名单、逐镜与最终落版中逐字相同；大小写、标点、换行固定。
- 白名单外不生成可读日期、编号、地点、品牌、伪 UI、报纸正文、Logo 或水印；非语义 Marks 只能是线、点、边框、网点、纸边或不可读纹理。

## 8. TYPE PROGRAM 与动态版式

最终 Prompt 必须写出 2–4 个可区分的字体角色，并逐项展开为可见参数：

- `Display A`：最终片名/主 Hero；写骨架、字宽、字重、字距、端点/笔画、字腔、材质、颜色、尺度、空间位置和动态过程。
- `Display B`：角色姓名或第二标题；完整写出同样参数，并与 A 在衬线/无衬线、宽/窄、粗/细、实心/线框、静态/构建中至少形成两项明显对比。
- `Utility`：承载已确认的身份、英文名、`STARRING`、`导演 / DIRECTED BY`；指定稳定小字骨架、字重、字距、对齐边和载体，不得只是 Display A 等比缩小。
- `Marks`：不承担新文字的边框、线条、箭头、网点、胶片孔、纸边或图形碎片；写清颜色、来源和回收方式。

先建立逐卡映射：每一张已确认文字卡只能归属一个主字体角色，同时写主标题、副标题和 Utility 的关系。每组文字写清：触发 → 揭示/构建 → 完整字组 → 可读停留 → 一次材质或空间响应 → 稳定/退出。AE 路线至少使用三种不同字体过程并按先后排序，例如轮廓构建、主体/字体景深交换、字块重组或笔画转场；不能把“字体有特效”写成墙上牌子、地面贴字和普通淡入。

同时完整写出 `scale ladder / COLOR SCRIPT / GRAPHIC KIT / SPACE BINDING / motion cue`：至少有全屏/近全屏 Hero、中尺度人物卡、小尺度身份三档；基础色关系在中段只做一次有来源的反白/专色接管，最终回到统一落版；2–4 个框、线、面板、纸片、圆环、网点或字形部件持续复用并成为转场。预告/AE 的 Hero 不能只在最终片名出现，前 20%–40% 至少有一次已确认文字的大字接管。

若最终 Prompt 只写“高级字体、清爽字体、现代字体、电影感字体、粗黑体、优雅衬线”而没有上述参数，设置 `type_program_complete=false` 并停止生成指令。

## 9. 完整 15 秒音乐

音乐必须是一支自成起承转合的原创 15 秒短曲，不是环境氛围音床、零散低频、连续音效或无结尾长尾。只锁风格、情绪、2–4 个音色锚和四段能量作用，不规定 BPM、调性、具体和弦、音符或逐秒配器：

1. `0.0–2.0s`：立即建立一个可辨识的旋律、节奏或音色动机；环境声可以先入，但不能只有环境声。
2. `2.0–8.0s`：加入清楚推进力，让人物卡、图形装配或世界揭示形成节奏。
3. `8.0–12.0s`：通过抬升、变奏、密度增加或一次短暂抽空形成对比和高潮准备。
4. `12.0–15.0s`：在最终奇观/片名处完成高潮，并用明确终止音、短促定格或完整和声收束；若使用余韵，也必须先完成可感知的终止句。

设置 2–3 个重要同步点，其余旋律、鼓点、和声和配器由 H3 原创。环境声与动作声只在接触瞬间突出；BGM 始终可辨识，不能被雨声、风声、打斗、机械和 whoosh 完全盖住。片尾不默认淡到无声。

## 10. 镜头数量与节奏

不同路线使用不同密度，不再共用“5–7 个慢镜头”：

| 模式/路由 | 主要状态 | 可选短插入 | 节奏要求 |
| --- | ---: | ---: | --- |
| 预告 × 电影叙事 | 不设数量 | 按证据需要 | 以完整动作、人物反应和因果切点决定镜头；可把多个剧情节拍合并进连续表演，避免碎切 |
| 预告 × 实拍 AE | 8–11 | 1–3 | 图形/相机交替运动；多地点、角色卡、卖点卡连续升级 |
| 预告 × 架空特效 | 7–9 | 1–3 | 正常世界→异常→人物/代价→第二次升级→最大奇观→片名 |
| 预告 × 编辑拼贴 | 8–12 | 1–3 | 版面、载体、内容 plate 和已确认文字卡快速接力 |
| Opening Title × 电影叙事 | 不设数量 | 按动作需要 | 保留人物完整动作、卡司阅读与电影世界连续性；不为介绍每张姓名卡单独切镜 |
| Opening Title × 实拍 AE | 5–8 | 0–3 | 人物卡、动态字体、多地点和最终视觉识别逐级建立 |
| Opening Title × 架空特效 | 5–8 | 0–3 | 物理法则、尺度区域、角色/主题卡和最终奇观共同成立 |
| Opening Title × 编辑拼贴 | 6–9 | 0–3 | 载体、内容 plate、混排文字和材料装配连续接力 |

电影叙事不套用统一镜头时长：保持到人物完成一个动作阶段、环境产生结果、关系发生变化或文字完整可读后再切；连续镜头内部持续增加行动、构图或空间信息时，可以明显长于包装路线的状态镜头。实拍 AE、架空特效与编辑拼贴的普通状态约 0.8–2.2 秒，短插入 0.25–0.65 秒。所有路线都避免前半段用完事件后只剩长标题；最终片名段预告约 1.4–2.0 秒，Opening Title 约 1.8–2.4 秒。

逐镜先在内部确认 `camera_origin / size_and_lens / path_axis / foreground_pass / subject_action / endpoint / story_gain / transition_source / cut_point / inherited_item / next_landing`，再用以下自然中文结构展开：

```text
【镜头 N｜start–end｜新增信息】
景别与相机：[焦段/稳定方式]，从[起点]沿[唯一路径]到[终点]，用于揭示[新行动/关系/尺度/文字]；在[对象]稳定[时长]。
人物/主体与环境：[连续动作、前中后景、该镜推进的故事或卡司信息]。
画面效果：[主效果来源→路径→接触→结果→结束]；[2–3 个支撑反馈]。
文字与版式：[准确文字、字体角色、位置、构建、完整时刻、停留和一次响应]；无文字时明确写无文字。
转场：[可见来源]到达[切点]，下一镜继承[一个形状/方向/颜色/速度/声音]并落到[新主体]。
声音：[音乐阶段、同步点、环境/动作声与 BGM 混音优先级]。
```

每镜只选一个主运动；“横移或慢推”“可以使用”“可选”“建议”“例如”“等方式”均属于未决方案。最终 Prompt 出现未决运镜或缺少起点、路径、动作、终点、叙事增益、切点、继承项、落点中的任一项时，设置 `camera_plan_complete=false` 并停止生成指令。全片至少覆盖建立揭示、行动跟随、证据靠近、尺度释放中的三种摄影功能，并确定使用动作匹配、形状匹配、前景遮挡、声音桥中的 2–3 类。

## 11. 连续性与最终检查

最终 Prompt 只写一次必要边界：人物身份、时代、世界法则、主材质、色盘、字体角色、准确文字、运动母题和音乐音色保持一致；案例专属名称、现实 IP、白名单外文字、乱码、Logo、水印、无来源粒子和无因果转场不进入画面。

生成指令前一次性检查：

- `TRAILER_FLOW_STATE` 是否为 `ready_to_dispatch`，三次确认与两项编译检查是否全为 true？
- 有参考图时，是否逐字执行 Gate 3：默认模式只锁人物/服装/影调，原图环境只占一个场景并发散至少两个新地点；严格模式确由用户选择；自定义模式与用户白名单一致？
- `OUTPUT_MODE` 是否准确，预告是否有用户确认的因果故事？
- 默认中英双语或用户选择的纯英语是否贯穿所有文字？
- 文字是否严格匹配 `TEXT_CONTENT_MODE`，每张人物/导演卡是否具有主副标题，且没有确认稿之外的新词？
- 主校准、母体和风格 Reference 是否一致，没有题材词覆盖媒介路由？
- 电影叙事是否以完整表演和有意义的换景为准；另外三条路线是否至少 5 个可区分场景/尺度/版面？是否有 4–6 个主效果和 8–14 个支撑效果？
- 是否每个主效果、运镜和转场都增加新信息并有可见因果？
- 是否在编译运镜的同一次过程中落实 2–3 类转场，且至少两次跨镜转场完整写出可见来源、切点、继承项和新落点；同一背景只换景别、继续走路或继续对视不计入？
- 字体是否完整展开 TYPE PROGRAM、逐卡映射、三档尺度、颜色脚本、图形组件、空间绑定与运动 cue；AE 是否至少三种动态字体过程，拼贴是否保留材料与混排？
- 每镜是否只有一个确定运镜，且起点、路径、前景、动作、终点、叙事增益和转场落点齐全？
- 音乐是否是完整 15 秒短曲，开场有动机、中段推进、后段高潮、片尾明确收束且 BGM 可听？
- 是否没有无信息增长的长镜头、前半全切完或后半只剩长标题；电影叙事中的较长连续镜头是否始终有动作、关系、构图或空间变化？
- 所有准确文字是否逐字一致，没有同音异写、错误翻译或意外第三语言？
- 字符数是否最多计数两次并落在 5000–7000；展示与实际执行是否为同一字符串？
