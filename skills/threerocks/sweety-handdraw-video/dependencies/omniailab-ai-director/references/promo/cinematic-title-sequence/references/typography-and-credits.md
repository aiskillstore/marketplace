# 电影片头与预告字体系统

生成最终 Prompt 时读取。目标是让片名、角色卡、卖点短句和署名成为画面设计，而不是同一种粗黑字反复淡入。H3 不调用本机字体文件；用字形类别、骨架、粗细、字宽、字距、端点、材质、尺度、空间和运动描述可见结果。

## 1. 先按用户确认的文字模式分配文字

文字数量不由成片模式设固定下限，必须服从 Gate 2 的 `TEXT_CONTENT_MODE`：

- `basic_cast`：片名、导演卡、2–3 位主要角色姓名卡。
- `basic_cast_plus_hook`：基础卡司之外增加一句已确认、且与可见事件直接对应的剧情钩子。
- `user_exact`：只排用户确认的准确文字；缺项时回到方案确认，不补写。

每张姓名卡是一个完整主副标题组：姓名为主层；英文名、角色身份或 `STARRING` 为副层。导演卡以导演姓名为主层，以 `导演 / DIRECTED BY` 为副层。同一时刻最多两组准确文字，最终片名段不再新增姓名。每组完整可读约 0.65–1.35 秒；最终片名按成片模式稳定约 1.4–2.4 秒。电影叙事可保留无文字段；实拍 AE、架空特效和拼贴可更早让准确文字参与构图。

## 2. 默认双语与纯英语

新任务必须通过 Gate 2 在 `bilingual_cn_en` 与 `english_only` 中确认一个；固定选项只有中英双语和纯英语。Gate 失败或未返回结果时停止，不代选默认值。

### 中英双语

- 中文承担主信息，英文承担副信息；两者属于同一语义组和同一阅读时刻。
- 中文与英文分别指定骨架、字重、字宽、字距、行高和材质，不能把同一种几何粗黑字机械缩小两次。
- 中文主层通常占该卡视觉权重的 60%–75%，英文副层占 25%–40%；角色英文名可比中文姓名更宽，但层级仍清楚。
- 片名、角色身份和卖点短句必须有准确英文对应；姓名按项目采用准确英文名或一致的罗马字写法，不临时改拼写。
- 中英文可共享基线、左边线、圆弧、纸片或空间平面，但保留各自字腔和阅读顺序。

### 纯英语

所有片名、角色卡、卖点和署名只用英文；不自动加入中文、法语或第三种语言。

## 3. 准确文字账本

内部建立，不原样复制进 H3 Prompt：

```text
TEXT LEDGER:
- id | exact_cn | exact_en | source=user_exact|confirmed_original_proposal | role | main_or_sub | first_full_read | hold | occurrences=1
```

- 白名单、逐镜和最终落版必须逐字一致；大小写、标点、换行和罗马字固定。
- Agent 提出的文字必须先出现在普通文本方案中并被用户确认，再回指影片命题、人物身份、冲突或卖点；确认后不得临时增加文字。
- 每条原创提案文案在提交用户确认前执行“静态海报阅读测试”：脱离动画后仍像一个人在介绍具体人物、事件、世界法则、代价或选择；`命运开启 / 未来已来 / 进入未知 / 传奇归来 / REALITY RECONSTRUCTED / ENTER THE UNKNOWN` 等可套在任何片上的库存句必须重写。
- 换风格时硬锁 `user_exact`；原创提案中的卡司、短句、语言组合、字体和时间点按新风格重建后，必须重新提交文本方案确认。
- 描边、反射、低对比重复和裁切属于同一文字，不产生新词。
- 生成指令前把所有中文同音字、英文拼写和多处重复逐项对照一次，消除同一片名的异写。

## 4. 三层字体角色

每支片至少使用两个、通常使用三个明显不同但同属一个视觉系统的字体角色：

```text
TYPE SYSTEM:
- Display A / Hero: [片名；骨架、字宽、字重、字距、端点/笔画、字腔、材质、颜色、尺度、空间位置、主运动]
- Display B / Character: [角色姓名/第二标题；完整同类参数；与 A 至少形成两项明显对比]
- Utility / Identity: [英文名、角色身份、STARRING、导演/DIRECTED BY；稳定小字骨架、字重、字距、对齐边、载体和短运动]
- Marks: [无新语义的边框、线、点、网点、纸边、箭头、胶片孔或白名单字的低对比重复；颜色、来源和回收方式]
```

`Display A` 与 `Display B` 至少在以下六项中的两项形成强对比：衬线/无衬线、宽/窄、粗/细、高对比/等粗、实心/线框、静态/构建。Utility 不能只是 Display A 的等比缩小。

最终 Prompt 必须列出“准确文字卡 → Display/Utility 角色”的逐卡映射。缺映射，或只写“高级、清爽、现代、电影感、粗黑、优雅”而未展开骨架、字宽、字重、字距、端点/笔画、字腔、材质、颜色、尺度、空间和动态时，`type_program_complete=false`。

尺度阶梯：Hero 50%–95% 画宽；Character 18%–55%；Utility 5%–16%。同一画面只设一个最大文字焦点。

再建立一份不进入最终 Prompt 的 `TYPE DESIGN SCORE`，最终用自然语言展开：

```text
scale_ladder=[全屏/近全屏 Hero + 中尺度角色/卖点 + 小尺度身份]
color_script=[基础色关系 → 中段一次反白/专色接管 → 最终回收]
graphic_kit=[2–4 个持续复用的框、线、面板、纸片、圆环、网点或字形部件]
space_binding=[至少三种空间关系]
motion_cue=[每组文字的触发、完整、响应、继承]
```

颜色变化必须由光线、色块、纸面翻转、投影、窗口扩张或世界法则触发，不随机换滤镜。图形组件持续复用并进入转场，不能每镜换一套装饰。

## 5. 字体骨架库

最终 Prompt 不写编号，展开选中的可见特征：

- **E1 极窄重型无衬线**：字宽 55%–72%、字重 850–950、直端点、清楚字腔；适合动作、奇幻、校园 Hero。
- **E2 扩展几何无衬线**：宽字面、开放端口、字重 650–850、舒展字距；适合现代都市、道路、建筑和科技主标题。
- **E3 人文无衬线**：正常字宽、开放字腔、清楚标点、中等字重；适合角色姓名和身份。
- **E4 高对比编辑衬线**：细横粗竖、尖锐或针状衬线、高字面、宽字距；适合史诗、年代、时尚和艺术片 Hero。
- **E5 粗衬线 / Slab**：矩形脚、厚重块面、中紧字距；适合工业、复古印刷和建筑式角色卡。
- **E6 等宽工程无衬线**：中等字重、略宽字距；适合身份、任务、主创和准确技术小层。
- **E7 模块线框无衬线**：安全断口、字腔完整；适合第二标题、空间线框与主字响应，不承担长句。
- **E8 克制手写/记号笔**：起收笔清楚、轻倾斜、不连成难读草写；只用于日记、青春和编辑批注。
- **E9 圆润怪趣块面**：超粗不等宽、圆角与少量短尖角并存、字腔清楚、单词内高宽差约 8%–16%；适合青春、轻喜剧、校园与活泼人物姓名主层，可两行错位或首尾字放大，但完整词只回弹一次。
- **E10 情绪记号笔/短笔刷**：不等粗、明确起收笔、轻微倾斜，只承担语义不同的 Display B 或批注；可由一笔写出后延成长下划线/框，不承担长句、导演名或小号 Utility。
- **C1 超粗方黑**：方形重心、偏旁完整、等粗笔画；适合中文高冲击 Hero。
- **C2 现代宋体**：横细竖粗、楔形收笔、疏朗字面；适合中文院线、史诗、编辑片名。
- **C3 窄体黑**：横向压缩不超过 12%–15%、字重 700–850、偏旁比例稳定；适合动作、科技和纵向空间。
- **C4 粗宋/方黑对比系统**：只选一个作 Hero，另一个承担 1–3 字强调；适合复古海报和剪纸拼贴。
- **C5 几何线框黑体**：单/双线描边、内部留白清楚；适合史诗空心字、空间科技和第二标题。
- **C6 现代手写细字**：自然笔压、疏字距、轻倾斜；只作青春、日记和关系批注。
- **C7 几何圆黑**：方字面、圆角等粗、开放字腔和完整偏旁；适合温暖青春、轻喜剧和校园的姓名/片名主层，使用错位双行或圆角框，整组在 0.4 秒内完整并只回弹一次。
- **C8 怪趣粗黑**：粗细略不均、圆角与短尖角并存，局部偏旁可夸张但重心完整；适合轻松人物卡或 Hero，配稳定人文小字，不能每个汉字随机变形。
- **C9 情绪笔刷**：粗笔刷、不等粗、局部飞白但偏旁完整，倾斜受控；只作 2–5 字 Display B、关系批注或已确认剧情钩子，必须与稳定实心主标题形成对比。
- **C10 人文黑体/稳定小字**：自然笔画、开放字腔、中等字重、小尺寸清楚；专用于角色身份、英文名对应层、`STARRING`、`导演 / DIRECTED BY` 等 Utility，并固定对齐边与字距。

### G1 实拍 AE 的三套可选字体方案

根据题材只选一套，不能把三套混在一支片中：

1. **都市/爱情/时尚 AE**：E4 高对比编辑衬线 Hero + E2 扩展几何姓名 + E6 极细 Utility；材质为黑白/暖金/玻璃/银色编辑层。
2. **科幻/科技 AE**：E2 扩展几何 Hero + E1 窄重姓名 + E6 等宽 Utility + E7 线框响应；材质为冷银玻璃、扫描线和受控粒子。
3. **动作/高能 AE**：E1 窄重 Hero + E2 宽体角色卡 + E6 工程 Utility；字块切片、速度压缩和笔画转场服务动作方向。

这三套都属于 `G1_urban_live_action_ae`，但必须在最终 Prompt 中写明所选方案的三层差异。不得因为是 AE 就默认同一套超宽粗黑字。

## 7. 文字进入空间

每组文字选择一个主要空间关系，整片至少使用三种：

- `negative_space`：天空、墙面、道路、海面、黑场或纸面留白。
- `perspective_lock`：沿道路、建筑、地板、玻璃或版面消失方向贴合，完整时恢复准确比例。
- `foreground_occlusion`：人物、车辆、柱体、道具、巨物、纸页或照片从字前经过，离开后恢复完整。
- `reflection_reveal`：玻璃、水面、金属或投影中的真实反射揭示。
- `carrier_bound`：准确文字预先存在于纸条、卡片、档案、屏幕或面板，载体运动。
- `independent_depth_plane`：文字位于可解释的三维深度层，具有相机跟踪、视差、投影/反射和正确景深。

人物不读取、触碰或操控卡司文字，除非项目明确把实体字设为世界道具。

## 8. 字体运动语法

每组遵循：

```text
TRIGGER → BUILD/REVEAL → FULL WORD → READABLE HOLD → ONE RESPONSE → SETTLE/EXIT
```

可用机制：

1. **光学显影**：光线、焦点或阴影经过完整字形，0.25–0.6 秒显露。
2. **遮挡揭示**：前景物离开后整组已存在。
3. **空间锁定**：文字随相机共享透视和视差，停点恢复清楚比例。
4. **轮廓构建**：线、光点、几何块或受控碎片沿准确轮廓聚合，0.35–0.75 秒填成实心字。
5. **主体/字体景深交换**：主体清楚→文字深度层清楚→两者共同稳定。
6. **字块重组**：完整词组作为 2–3 个语义块滑移、旋转或换位，再恢复准确排版。
7. **字形变图形**：完整文字的一个真实笔画/字腔放大成分栏、框、道路、圆环或转场遮挡，下一状态恢复文字。
8. **材质经过**：水、光、粒子、纸边、投影或玻璃折射只改变经过区域，完成后稳定。
9. **载体装配**：印有准确文字的纸页、卡片、胶片或面板滑入、翻页、吸附。
10. **重复字阵**：同一白名单词用低对比轮廓重复，保留一个实心阅读焦点，随后回收到一个词。
11. **全屏 Hero 接管**：一组准确短句从约 30% 扩到 75%–110% 画宽，完整稳定后被人物/物件真实遮挡，随后退到后景或变成下一状态的结构面；不能只在片尾使用大字。
12. **三档尺度跳切**：同一白名单文字不同时重复，按中尺度→Hero→局部裁切 Hero 三档依次出现；前一档退出后再进入下一档，每档先完整可读，避免残影堆字。
13. **字体空间通道**：准确主字跨地面、后墙、玻璃或独立前景板共享一个消失点；相机沿笔画/字腔前进，在新平面恢复完整词，Display B 留在侧面深度层。
14. **多分栏动态海报**：2–4 个窗口分别承担人物、Display A、Display B/Utility 和色彩/材质；0.25–0.45 秒内吸附到一个网格，完整成立后由一个窗口扩张成下一场景。
15. **边框生态**：一个主框、一个局部角框和 2–5 个短 Marks 从人物动作、建筑边、纸缝或文字基线生长；Utility 锁定角部，框的一条边成为下一镜遮挡/切割边。

预告/AE 路线至少使用三种不同机制并形成递进：前 20%–40% 至少一次角色/命题 Hero 建立规则 → 中段人物/卖点卡升级尺度、深度或网格 → 最终片名回收已有结构。不能把唯一大字留到片尾，也不能所有文字只用淡入、贴墙或同一种扫描。

## 9. 四条路线的字体纪律

### 电影叙事

字体平整、优雅、与环境留白和真实透视结合；角色名 18%–35%，片名 32%–60%。动态来自人物/车辆/门窗/光线遮挡，不做持续字母飞舞。

人物卡与导演卡使用“克制型院线卡司双层结构”，不能把职位、身份或 `STARRING / DIRECTED BY` 做成姓名的同字体等比缩小版：

- 姓名是 Display B 主层，承担整组约 70%–80% 的视觉权重；职位、身份、英文对应层或 `STARRING / DIRECTED BY` 是 Utility，承担约 20%–30%。Utility 字高通常为姓名字高的 22%–38%，但必须保持清楚可读。
- 主副层至少在字号、字形类别、字重、字宽、字距六项中的两项形成区别。推荐“高对比衬线姓名 + 小号宽字距人文无衬线/斜体衬线身份”，或“中等字重宽体无衬线姓名 + 小号窄体/等宽身份”；不能只靠颜色深浅区分。
- 每支片只选一种主排法贯穿所有人物与导演卡：`上小下大`（小号身份在上、大号姓名在下）、`同边线错阶`（共享左边线，身份向内缩进半个字宽）、`侧签式`（短竖线或短横线连接小号身份与大号姓名）。主排法不变，只随场景留白切换左/右放置。
- 中文姓名为主时，可用完整、清楚的中文院线字形承重，英文名或身份以更窄、更轻、更疏的拉丁字形成副层；纯英语时，姓名可用大小写或宽窄对比，但不把职位和姓名排成相同全大写粗体。
- 主副层共享一条明确构图轴或光学边线；行间距紧而不挤，姓名可分两行形成轻微尺度差，但单卡只保留一个最大词。允许一条无语义细线、一个小圆点或环境阴影作为对齐标记，不增加新文字，不堆装饰框。
- 姓名先随遮挡、焦点或自然光完整揭示，Utility 可提前 0.08–0.18 秒建立排版锚点，或与姓名同步出现；完整后只允许一次轻微字距舒展、焦点交换或光影经过，随后稳定阅读。禁止逐字弹跳、连续旋转、故障拆字、巨大立体挤出和多层重复字阵。

最终 Prompt 必须明确写出所选主排法、姓名与 Utility 的字形组合、视觉权重、字号关系、对齐边和唯一一次动态响应；只写“姓名大、职位小”视为未完成电影叙事卡司设计。

### 实拍动态图形合成

字体是主要视觉事件。角色卡、卖点卡和片名至少使用三种动态机制、三种空间关系和三层字体角色；每次都写相机跟踪、透视、遮挡、反射/接触影、景深和运动模糊。空间字不能退化成墙牌、铭牌、地板贴纸或普通字幕。

### 架空世界特效

Hero 可占 45%–80%，使用空/实心、宽/窄或衬线/工程字对比。奇观、建筑、模型、星体、粒子或介质必须从字前后经过；巨型字承担世界尺度，但角色卡仍使用独立 Display B，不能全片只有一个巨字模板。

### 编辑拼贴

准确标题保持统一字形，周围允许大字、竖排、手写批注、打字机署名、几何字块和不可读剪报纹理形成混排。每个版面至少出现两种字号和两种字形角色；套印偏移、跨纸缝、裁切和纸边遮挡只短暂作用，随后恢复准确阅读。

## 10. 最终片名与检查

- 预告最终片名稳定 1.4–2.0 秒；Opening Title 稳定 1.8–2.4 秒。片名与世界/人物/媒介共同存在，不默认切纯黑 Logo 页。
- 最终片名继承前文已经出现的轴线、材质、纸边、粒子轨道、反射或字体笔画，不突然换第三套字体。
- 双语两层是否各自清楚、准确、层级明确？
- 是否严格执行用户选择的 `TEXT_CONTENT_MODE`，没有为凑节拍临时增加短句？
- 每张角色/导演卡是否具有清楚的主标题和副标题，并映射到固定字体角色？
- Display A、Display B、Utility 是否至少有两项明显差异？
- 是否逐角色展开骨架、字宽、字重、字距、端点/笔画、字腔、材质、颜色、尺度、空间和动态，而非只写抽象风格词？
- 是否同时具有全屏/近全屏、中尺度和小尺度三档文字；Hero 是否在中前段出现过一次而非只留片尾？
- COLOR SCRIPT、GRAPHIC KIT 和空间关系是否跨镜持续复用并进入转场，而非每镜换模板？
- AE 是否存在三种动态过程，而非静态牌子和淡入？
- 拼贴是否保留混排、印刷材质和准确主标题？
- 所有姓名、角色身份、片名、翻译、大小写和换行是否在白名单与逐镜中完全一致？
