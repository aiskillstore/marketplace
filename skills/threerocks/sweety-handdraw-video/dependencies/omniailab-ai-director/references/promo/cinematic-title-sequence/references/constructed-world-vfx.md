# 架空世界特效型片头与单条预告

只在不可能世界、巨型异象、真实微缩模型、太空/抽象舞台、粒子物理或空间变形本身是主要视觉事件时读取。科幻史诗、魔幻现实奇观、微缩奇幻世界、宇宙档案空间和架空舞台使用本路由。若人物连续行动比世界法则重要，改用电影叙事；若纸页、照片与印刷版面始终占主画面，改用编辑拼贴。

“写实特效”指材质、尺度、光影、接触和运动可信，不等于删掉科幻、粒子、巨构或超自然现象。奇观必须大胆，物理反馈必须具体。

## 1. 三种底盘只选一个

### V1 Photoreal Impossible World｜写实巨型异象

真实城市/自然环境、真实人物和自然光中出现一条不可能法则，如倒置介质、反重力水流、巨型天体、空间折叠或物质逆行。建筑、皮肤、布料、液体、阴影和介质保持真实重量；异象可宏大但不默认变成灾难、战争和怪物袭击。

### V2 Miniature Crafted World｜真实微缩模型世界

所有空间像被真实 35/50/70mm 微距电影镜头拍摄的精致手工模型：纸张、木头、石材、金属、胶水边、尘埃、接触影、焦外和材料磨损可见。模型从地图、书页、桌面或机械舞台被装配；不是动画游戏 CG，也不复刻已有奇幻 IP。

### V3 Abstract Spatial Archive｜复古硬科幻/抽象空间

深空黑场或架空舞台中由真实机械物件、星体照片、工程线、少量档案、人物剪影、粒子轨道与几何通道构成电影化三维空间。物件有接触影、纵深和尺度；不是平面素材堆桌面、不是伪 UI 数据墙、不是全息人物排队讲话。

路由边界：V3 中若相机进入照片、轨道、黑洞、几何通道并形成真实纵深，留在本路由；若始终是纸页、杂志跨页和照片排版翻动，改用 `editorial_collage`。

## 2. 一条物理法则与一条戏剧法则

先内部写清，不把字段原样塞入最终 Prompt：

```text
PHYSICAL LAW：现象从哪里来 → 沿什么路径作用 → 改变哪些物体/介质 → 哪些仍保持正常 → 最终汇聚/回收/停在哪里。
DRAMATIC LAW：谁最先受到影响 → 他/她想完成什么 → 法则造成什么阻碍或代价 → 采取什么行动 → 法则第二次升级 → 最后必须做何选择。
```

Opening Title 可以弱化戏剧法则，但仍需人物/物件/空间因果。Trailer 必须同时具备两条法则；不能只有普通人抬头、粒子聚集和最终大字。

禁止每镜增加新法则、粒子从空气随机出现、无边界流体漫溢、魔法爆炸、随机物件变形和“所有东西都漂浮”。同一法则第二次出现时必须扩大影响对象、尺度或代价，而不是换颜色重复。

### SINGLE_FRAME_SPECTACLE_GATE

V1 至少在三个相隔约 2 秒的定格画面中，无需对白就能看懂“不可能之处”；异常至少改变三类对象，例如建筑/地面、液体/光线、布料/尘埃/人群反应。每次完整揭示同时存在前景人物/建筑、中景法则作用和远景巨型尺度锚。

只发生在镜子、记忆、提前几秒动作或心理暗示中的异常更偏剧情悬念，应改走电影叙事。

## 3. 已验证视觉语言

### V1 写实巨型异象

```text
70 毫米大画幅电影质感、真实人物和真实城市布景，采用传统光学合成与高级实拍特效感。画面不能像游戏过场动画或 AI 奇幻壁纸；建筑、人物、衣服、液体、阴影和光线拥有真实重量。异常世界使用深海蓝、银白介质光和自然金色阳光，不使用霓虹科技光；介质在城市、人物和物体表面形成真实焦散、折射、阴影、反射、气流和触感反馈。奇观宏大、尺度清楚，普通人通过可观察的动作承接，不只站立凝视。
```

验证母体链：

```text
正常城市/自然环境与日常动作成立 → 巨型阴影、焦散、反射或气流先扫过道路、墙面、皮肤/布料三类表面 → 相机沿人物视线或环境轴线上仰/横移，第一次完整揭示巨型介质/天体/生物与城市比例 → 空/实心巨字横跨异象，建筑和巨物分别从字前后经过 → 法则作用到第二种介质/地点，连续液体、漂浮物、布料和人物触感共同反馈 → 人物采取行动并暴露代价 → 相机沿法则路径稳定穿越/升降，进入最大纵深 → 穿过介质表面、建筑空腔或巨物遮挡，最终片名、人物决定和奇观共同成立。
```

### V2 手工微缩奇幻

```text
微缩模型摄影 × 奇幻电影 Opening Title × 真实电影微距摄影；所有场景像被真实摄影机拍摄的精致手工世界，不是动画，不是 CG 游戏。使用深古铜、旧羊皮纸米色、灰石、深绿色玻璃和暖金色光；夜空、月光、雾为蓝灰冷光，蜡烛、壁灯和火光为暖光，形成自然冷暖分离。模型具有磨损石墙、木纹、尘埃、旧书、铜件和胶水边的使用痕迹，但不破败、不恐怖。粒子只从地图、书页或材料纹理升起，装配道路、建筑、轨道、人物模型和符号后回到可见材料。
```

验证母体链：

```text
俯视真实桌面/地图/书页 → 纸纹、墨线、木屑或金属粉从可见材料升起 → 60–160 个可辨粒子沿纹理聚成道路、书、建筑、轨道和人物模型 → 摄影机下降进入模型，浅景深从前景部件交换到后景建筑 → 书页翻转、羽毛笔划过、模型转台、光束切割或有来源烟雾完成硬转场 → 冷色夜空与暖烛光/机械光建立第二地点 → 主角模型沿明确路径行动，一片局部黑暗/能量改变任务并回收 → 模型内部、森林、桥梁或建筑出现更大尺度/代价 → 所有材料重组为完整模型海报，极窄重字或古典衬线从模型阴影显影并锁定。
```

每镜至少出现模型边缘、接触影、尘埃、浅景深、胶水/磨损、真实灯光中的三项。禁止完整全息真人、光滑游戏角色和无材质的数字城堡。

### V3 复古硬科幻空间

```text
70 年代航天机构极简档案海报、写实硬科幻片头、复古工程蓝图印刷、现代极简留白动态图形、宇宙粒子流和低噪胶片扫描质感。以深空纯黑大面积留白为基底，使用冰蓝冷调强调色和浅米泛黄牛皮纸薄纹理；星体观测照片、工程图、手绘引力轨道、少量任务档案、宇航剪影与真实机械物件分层出现。氛围宏大、硬核、空旷、静谧、克制，并保留一点航天纪实的人性温度；不做太空 MV、迪斯科、恐怖、伪控制面板和堆满画面的数据墙。
```

验证母体链：

```text
纯黑深空和 60% 左右留白 → 一个真实机械物件/唱片/观测装置进入，旋转或开合形成圆形/几何入口 → 工程图、星体照片和牛皮档案少量滑入并产生真实层间阴影 → 冰蓝粒子只沿既有轨道牵引照片和星图 → 纸面沿中线折叠、照片边缘粒子化或镜头穿入天体照片进入更深空间 → 几何通道、档案舱、引力网格或多维结构打开，人物剪影作为尺度锚并采取行动 → 一束粒子直线、仪器光阑或标题真实笔画切割空间 → 天体、通道、人物、档案和宽体工程字在巨大纵深中共同锁定。
```

V3 的人物以真实剪影、宇航服局部、头盔反射或单个完整真人为主；禁止批量生成透明全息人物站成一排，避免游戏 CG 和发布会大屏感。

## 4. 按 OUTPUT_MODE 安排 15 秒

### `opening_title`

使用 5–8 个主要状态、0–3 个短插入；文字严格按用户确认的 `TEXT_CONTENT_MODE`。

```text
材料/正常世界建立 → 法则前兆 → 第一次完整揭示与第一人物/主题卡 → 第二空间和第二卡 → 无文字最大穿越/装配 → 法则回收或世界重组 → 最终片名海报
```

卡司/署名可以主导结构，但每组文字仍需与一个新的尺度、材质和可见动作结合。

### `single_clip_trailer`

使用 7–9 个主要镜头、1–3 个短插入；文字严格按用户确认的 `TEXT_CONTENT_MODE`：

1. `0.0–1.3s｜正常规则`：具体人物/物件正在完成任务，不能只拍空世界。
2. `1.3–2.7s｜异常前兆`：法则先影响三类表面/物件；命题短句进入。
3. `2.7–4.4s｜首次揭示`：完整奇观与主角卡同框，建立尺度。
4. `4.4–6.0s｜阻碍/同伴`：人物行动受阻，第二角色或职责卡进入。
5. `6.0–7.8s｜法则第二作用`：换地点/介质/模型区域，影响扩大并出现代价。
6. `7.8–9.5s｜行动`：主角进入、启动、追随、修复、封闭、释放或保护某物；不是继续观看。
7. `9.5–11.5s｜最大穿越`：进入介质内部、模型深层或多维空间；用 1–3 个短证据插入提高节奏。
8. `11.5–13.2s｜选择/悬念`：奇观导致必须选择的结果，片名机制开始汇聚但仍有行动。
9. `13.2–15.0s｜最终片名`：片名稳定约 1.4–1.8 秒，人物、法则和世界仍自然运动。

基础卡司使用片名、导演卡和 2–3 张角色姓名+职责主副标题；只有 `basic_cast_plus_hook` 才加入一条与异常法则直接对应的已确认钩子。不能用伪坐标、伪任务编号或临时史诗短句填充。

## 5. 场景、尺度与材质证据

- 至少 5 个一眼不同的尺度/介质区域：正常世界、第一次揭示、第二作用地点、人物行动区域、介质/模型/通道内部、最终海报空间可按项目组合。
- 相邻区域在尺度、光色、介质、相机高度、前景锚、人物动作中改变至少三项。
- V1 同时保留前景人物/建筑、中景法则作用和远景尺度锚；影子、焦散、气流、反射、尘埃或接触证明影响。
- V2 用模型边缘、桌面/书页、浅景深、接触影和真实灯光证明尺度；不能每层同样锐利。
- V3 保留一个真实尺寸物件或人物作为尺度锚；留白通常不少于 35%，但预告关键状态可为冲突短暂提高信息密度。
- 只使用一套主材质和一套特效介质，例如石材+水光、羊皮纸+金粒、深空+冰蓝轨道；不混入无关霓虹 HUD、糖果色和梦幻滤镜。

## 6. Hero effects 与世界反馈

全片使用 4–6 个观众明显感知的主效果和 8–14 个支撑反馈；它们必须都服从同一物理法则。

可用主效果：

- 巨型阴影/焦散先行，随后揭示不可能介质或天体。
- 连续液体或物质逆重力汇聚，人物和建筑保持正常规则。
- 真实材料粒子沿纹理装配出模型道路/建筑/角色，再局部解体回收。
- 相机穿过水面、书页字腔、建筑空腔、照片视界、光阑或黑洞入口进入新尺度。
- 巨型生物/天体/机械结构以真实质量移动，产生遮挡、影子、气流和环境响应。
- 模型舞台/档案舱/多维通道机械打开，露出比外部更大的内部空间。
- 空/实心巨字与世界形成前后景，现象从字腔内部经过。
- 局部黑暗、能量、光束或粒子路径触发人物行动并在结果后回收。

支撑反馈：介质焦散、折射边缘、空气尘粒、布料/纸张受力、接触影、桌面震动、金属高光、浅景深交换、星尘拖尾、灯光扫过、机械联动、远景人群/模型反应、反射变化、真实运动模糊。

颗粒、调色、普通阴影和“史诗感”不算主效果。每个主镜头写一个主效果和 2–3 个与之接触的支撑反馈。

## 7. 相机与转场

- V1：低机位仰拍、广角横移、跟随人物/介质、受控升降和宏大航拍；运动必须揭示新尺度或人物行动。
- V2：35/50/70mm 微距感，俯视下降、贴地跟随、穿过书架/模型、焦点从前景部件交换到远处建筑。
- V3：沿粒子轨道横移、穿过圆形机械/照片/黑洞/档案舱、从二维工程面进入三维通道；不持续旋转和无尽虚拟飞行。
- 预告普通状态约 0.8–2.0 秒，短插入 0.25–0.65 秒；Opening Title 可略放宽阅读，但不连续慢推。
- 转场优先使用世界法则：水滴覆盖、书页翻转、机械光阑闭合、巨物遮挡、照片视界穿越、粒子直线切割、标题笔画扩张和形状匹配。
- 每个转场写来源、覆盖/切点、下一镜继承的方向/形状/颜色/速度/声音以及新落点；禁止粒子万能擦屏。

## 8. 巨型文字和角色卡

按 `typography-and-credits.md` 使用 Display A、Display B 和 Utility；巨型字不是唯一模板。

- Hero 文字可占 45%–80%，角色卡/身份卡约 18%–45%，最终片名按构图约 50%–80%。
- V1 可用高对比空心/实心衬线与较窄角色卡对比；V2 可用极窄重型 Hero、古典衬线角色卡与克制铭文小层；V3 可用宽体工程 Hero、粗衬线/线框卖点和等宽 Utility。
- 预告至少三种文字过程：空间遮挡显影/模型阴影显影、来源粒子沿准确轮廓构建、标题笔画/字腔进入新空间或空实心材质交换。
- 文字先完整可读，再允许巨物、建筑、水流、模型或星体短暂从前后经过；不能一出现就被大面积遮住。
- 人物不触碰、不观察、不操控卡司文字；标题不是魔法道具。字母不随机飞散、逐个乱转和变形。
- 白名单外不生成伪咒语、坐标、任务编号、档案正文、品牌和 UI。

## 9. 特效因果句式

```text
可见来源 → 可数/可辨材料、液体、光或机械 → 单一路径 → 接触世界/人物/准确文字 → 一个可见结果 → 回收/吸收/停稳。
```

- 粒子给出大致规模如 60–160 个，并写聚合完成和稳定状态；不要密到像噪声。
- 液体写连续流向、重力规则、折射、重量和落点；液体不是“粒子流”。
- 烟雾、黑暗或能量只覆盖局部，结束时恢复主体、世界和文字清楚。
- 巨型生物/天体运动有质量，以遮挡、影子和气流证明；不攻击、不瞬移、不复制。

## 10. 完整 15 秒音乐与声音

保留案例验证过的音色，只要求完整短曲，不锁死编曲：

```text
Music direction：原创 15 秒电影配乐，只选一套气质和 2–4 个音色锚，不规定 BPM、拍号、调性、和弦或逐秒音符。V1 使用低弦、克制铜管、宽阔和声与自然介质声；V2 使用大提琴、木管、钟声和纸木/微型机械质感；V3 使用低沉管风琴、稀疏钢琴、冷弦、微量模拟合成器和唱针/机械质感。开场立即建立可辨识动机，中段随法则第一次与第二次作用形成节奏推进，最大穿越处通过增层或短抽空形成高潮准备，最终片名完成一次清楚高潮并以明确终止音/完整和声收束。具体旋律、节奏、和声和配器由 H3 原创。
Diegetic layer：从水压、风、石材共鸣、翻页、模型机械、投影/唱片或深空低噪中选 2–4 类，只在可见动作发生时突出，不能盖住 BGM。
```

只绑定触发、最大穿越、片名中的 2–3 个同步点；不用连续 trailer boom，也不能只留“清楚余韵”而没有终止句。

## 11. 最低检查

- 是否只选一个底盘、一条物理法则；预告是否还有一条清楚戏剧法则？
- 写实异象是否通过三个定格的奇观 Gate，并影响至少三类对象？
- 是否完整继承所选 V1/V2/V3 母体链，而不是只写“史诗、粒子、电影感”？
- 预告是否有 7–9 个镜头、人物行动、代价和未解决选择；片头是否有 5–8 个状态；文字是否严格匹配 `TEXT_CONTENT_MODE`？
- 是否有至少 5 个尺度/介质区域、4–6 个 Hero effects 和 8–14 个支撑反馈？
- 写实要求是否增强奇观的材质和反馈，而没有误删科幻、巨构、粒子与空间穿越？
