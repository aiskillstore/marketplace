# 电影叙事型片头与单条预告

只在连续真人/写实电影世界、人物行动和真实空间承担主要叙事时读取。青春公路、年代职业、都市群像、现实主义、冒险、剧情或由普通人反应承接的魔幻现实题材可使用本路由。若动态图形、纸面拼贴或架空空间比人物行动更重要，改选对应路由。

本路由有两个不同结果：`opening_title` 是一段“电影已经开始”的卡司片头；`single_clip_trailer` 是一条能看懂事件因果、人物选择和未解决悬念的 15 秒预告。不得把两者写成同一套慢镜头模板。

## 1. 不变的电影底盘

- 人物、时代、空间和关系先可信；镜头中的动作必须真实完成，不摆卡司英雄姿势，不排队看镜头。
- 文字与天空、墙面、道路、门窗、玻璃、交通工具和自然留白共处，不退化成下三分之一字幕。
- 摄影、表演、光线、天气、道具和环境声共同讲述信息；胶片颗粒、调色和光晕只是质感，不算主效果。
- 复杂度来自地点、行动、关系和真实光学层次持续变化，不来自无来源粒子、故障、模板转场或广告式环绕。

## 2. 按 OUTPUT_MODE 建立结构

### `opening_title`

不规定主要镜头数量。先保证人物动作完整、卡司文字可读、空间关系连续，再决定切镜。以下是叙事功能链，不是六个镜头：

```text
无文字建立空间、共同目标或旅程方向 → 第一人物通过具体任务被认识并出现姓名卡 → 第二/第三人物通过行动与第一人物建立关系 → 无文字完成一次共同工作或真正出发 → 已建立的光、门、玻璃、尘土或运动母题揭示片名
```

相邻功能可以在同一条横移、跟随、固定框景或受控升降镜头中连续完成；只有人物完成动作、前景形成自然遮挡、关系发生变化或进入真正新空间时才切镜。最终片名完整稳定约 1.8–2.4 秒，世界继续运动。

文字严格按用户确认的 `TEXT_CONTENT_MODE`：基础模式使用片名、导演卡和 2–3 组姓名主副标题；只有选择加钩子或自定义文字时才增加对应白名单。保留必要的无文字电影段落。

### `single_clip_trailer`

不规定主要镜头数量。先写出因果链，再把相邻事件合并到能完整表演的最少必要镜头中；证据插入只在必须看清关键物件、动作结果或人物反应时使用：

```text
主体的正常状态 → 一个可见触发事件打破它 → 阻碍/对手/代价第一次出现 → 主体作出行动 → 行动引发更大升级 → 一个选择或未解决问题 → 片名
```

开场用一个完整动作同时交代主体、地点和目标，并让触发事件在同一连续表演或自然切点中真正发生。角色卡不单独制造切镜：相机在人物行动达到可读构图时减速，让姓名和身份稳定，再继续动作。阻碍、选择与升级优先通过人物改变路线、传递物件、启动、保护、交付、隐藏或反抗来推进；动作尚未完成时不为追求节奏强行切走。最大事件与人物决定可以在同一连续镜头中完成，随后由真实动作或光学遮挡交付最终片名；片名稳定约 1.4–2.0 秒。

文字仍严格按 `TEXT_CONTENT_MODE`：基础卡司以角色姓名主副标题、导演卡和片名帮助辨认人物；仅当用户确认剧情钩子时增加一句。画面必须独立完成触发、阻碍、行动、升级与悬念，不能靠临时补短句解释。

## 3. 已验证的四套电影语言

最终 Prompt 选择最匹配的一套为主校准，完整继承其媒介、色盘、摄影纪律、空间文字和声音气质；替换案例专属人物、道路、飞机、海洋、姓名和道具。不要把三套时代和色盘混在一条片中。

### N1 明亮青春公路

```text
真实 35 毫米电影质感，轻微胶片颗粒，自然肤色，柔和阳光，宽阔环境构图；天空蓝、阳光黄、砖橙、奶油白和少量钴蓝，色彩清晰但不过度饱和。以中远景和全景为主，避免连续人物特写；人物不看镜头，通过开车、擦玻璃、拍照、奔跑、传递物件和互相回应显示关系。文字沿屋檐、公路消失点、墙面基线或车窗反射进入真实空间，保持平整、清晰、优雅，不使用夸张立体字、故障或快速飞入。
```

已验证的视觉链：

```text
日出/自然光大全景建立旅程 → 交通工具或人物掠过前景形成真实遮挡 → 新地点以屋檐、建筑边或天空留白显露人物卡 → 侧面跟拍让道路/建筑消失线承托下一文字 → 空白路牌、车身或柱体经过镜头完成空间切换 → 第三地点用墙面/地面基线建立人物与关系 → 有来源相机闪光或曝光接入共同事件 → 固定在车内/门内/窗内形成前中后景 → 自然反射或移动阳光在玻璃上揭示最终片名。
```

`opening_title` 可保留这条卡司链；`single_clip_trailer` 必须在其中加入“旅程为何改变、人物要去哪里、被什么阻挡、结尾面临什么选择”，不能只拍快乐旅行蒙太奇。

### N2 厚重年代职业

```text
大画幅胶片电影质感，自然皮肤纹理、轻微颗粒、柔和高光和真实空气透视；高原沙土色、旧金属银、灰绿色、磨损皮革棕、清晨冷蓝与自然金色阳光。使用 40、50 和 75 毫米焦段感，轨道横移、稳定肩扛、低机位跟拍和克制升降按行动需要交替；禁止 MV 式无因快切、夸张速度变化和广告式英雄环绕。服装、工具、机械和交通工具具有真实年代质感，不出现现代设备、品牌或可读编号。
```

已验证的视觉链：

```text
昏暗大空间中的轮廓与工作动作 → 门体打开让晨光、尘埃和完整机械主体显露 → 沿结构表面横移并用大型部件前景遮挡人物卡 → 检查、合盖、擦拭、装载等有重量动作形成第二人物信息 → 工具箱、舱门或窗框合拢匹配到内部空间 → 航图/仪表/窗外天空建立行动证据 → 低机位贴近轮组或交通工具跟拍 → 尘土、蒸汽或气流覆盖后散开 → 大空间中的真正出发与最终片名共同成立。
```

`single_clip_trailer` 必须加入任务改变、资源不足、时间/天气/地形/制度限制、人物决定和结果未知；“准备工作—起飞/出发”本身只够 Opening Title，不自动构成预告。

### N3 写实魔幻现实

```text
70 毫米大画幅电影质感、真实人物、真实城市布景、传统光学合成与高级实拍特效感；建筑、人物、衣服、液体、阴影和光线拥有真实重量与物理质感，不像游戏过场或 AI 奇幻壁纸。使用石灰岩白、陶土橙、低饱和赭石、深海蓝、银白介质光和自然金色阳光；异常介质把真实焦散、投影、气流或反射落在墙体、道路、布料和皮肤上。使用低机位仰拍、广角横移、受控升降、稳定穿越介质和宏大航拍揭示尺度，具有力量但不炫技。
```

只有当普通人物的行动仍是叙事核心时留在本路由；如果不可能物理法则、微缩模型或抽象空间本身占据主要时长，改用 `constructed_world_vfx`。

### N4 明亮海岸爱情卡司

```text
真实 35 毫米爱情电影质感、自然肤色、柔和高光、轻微颗粒与稳定空气透视；奶油白、海水蓝、淡黄色和少量珊瑚色构成清楚但不过饱和的明亮色盘。以宽阔环境、全景和中远景建立海边小城、生活空间与人物关系，近景只用于书页、花束、车轮或手部动作的结果。爱情通过整理物件、传递书本、放入花束、共同推车和并肩前行等生活动作发生，不依赖连续凝视和摆拍。
```

已验证的视觉链：

```text
沿海交通工具或前景物体掠镜建立世界并形成遮挡 → 第一人物在书店、咖啡馆、住宅门口或其他真实生活空间完成动作，姓名卡利用墙面、天空或建筑留白稳定出现 → 布料、门框或行人前景切到第二人物所在的港口、街道或工作区域，姓名卡与桅杆、道路或建筑线形成空间关系 → Gate 3 默认参考环境只映射到上述一个场景，其余场景主动发散 → 车轮、花束、书页或相同运动方向连接两人会合 → 无文字完成一次物件传递和关系变化 → 在开阔海岸、天空或海面以完整片名收束，不要求复刻参考图站位。
```

参考图已经是带片名的完整海报时仍服从 Gate 3。默认只继承人物、服装主特征和颜色影调，原图环境只占一个场景，原站位和版式不自动负责收束；严格原景模式才把同一地点用于全片。`single_clip_trailer` 以一次可见的相遇、交付、错过或决定形成关系变化；`opening_title` 以人物分别被认识、共同事件和最终片名完成卡司链。

## 4. 人物、行动与场景密度

- 无身份素材时在文本方案阶段提出 2–4 个原创成年人物，并经用户确认；每位锁定脸、年龄、发型、服装主色、可见道具、职责和行为气质。确认后不临时新增人物或关系。
- 人物跨镜不换脸、不换发型、不换衣；多人通过传递物件、确认眼神、共同劳动、冲突动作、互相保护或朝同一目标推进建立关系。
- 每位人物至少有一个“动作—环境反馈—结果”：例如扣紧固定带后机械稳定、推门后光和尘进入、递出物件后另一人改变路线。
- 默认参考图模式把人物身份、服装主特征和颜色影调带入全片，但原图环境只作为一个已指明场景；另外至少两个地点通过人物行动、物件交换和会合动作发散，不在同一背景连续重复走路、回头、对视和停步。
- 不强制镜头数量。`multi_scene` 至少建立 3 个已在确认稿中展示的不同地点/行动条件；只有新地点带来新的行动条件、阻碍或结果时才换景，不为凑数量碎切。只有用户在 Gate 3 选择严格原景时才使用 `single_scene_locked_reference`，并在同一地点建立至少 3 个有信息增长的动作/尺度/光线状态。
- 单主角用不同动作结果、视角和环境反馈建立变化，不为凑场景切换房间，也不能在同一空间反复走路、回头和看窗外。
- 年代题材锁定建筑、车辆、机械、纸张、灯具和服装；魔幻现实只允许一个不可能法则，人物反应可敬畏但不能全片只抬头观看。

## 5. 电影效果与层次

电影叙事路线也要丰富，但效果必须有来源。全片选择 4–6 个观众能直接感知的主效果，并围绕它们安排 8–14 个支撑反馈。

可用主效果：大门/百叶打开形成体积光揭示、车辆或大型机械掠镜遮挡、真实玻璃反射揭字、尘土/蒸汽/水幕覆盖匹配、相机闪光进入记忆/新地点、从内部框景突然释放到大空间、自然异象的焦散/影子扫过、动作匹配跨地点、天气或光色在事件中突变。

支撑反馈：空气尘埃、衣料和头发受风、轮胎尘土、地面反光、窗面二次反射、金属高光、焦点交换、真实运动模糊、前景擦过、纸张/工具震动、机械振动、液体附着、远景人群反应、局部光学耀斑。

每镜写一个主动作或主效果，再写 2–3 个与它发生物理关系的反馈。颗粒、调色、普通阴影、景深和“电影感”不单独凑效果数量。

## 6. 摄影与剪辑纪律

- 以 35/40/50/75mm 焦段感建立一致摄影；大全景、中远景和动作中景为主，近景只在道具、表情或决定真正增加信息时使用。
- 每段只设一个主运动：横向轨道、跟随/领先、低机位跟拍、仰俯揭示、升降、受控推拉、车内固定或稳定肩扛。
- 开场尽快出现主体和正在完成的动作，触发事件可以在同一镜头内发展；普通镜头保持到动作结果、人物反应或角色卡完整可读后再切，避免连续 0.8–1.2 秒碎切。连续镜头只要内部持续增加行动、关系、前中后景或光线信息，可以明显长于包装路线的状态镜头。
- Opening Title 与 Trailer 都允许更长的完整表演和阅读窗口；但长镜头必须有动作阶段、构图变化或空间揭示，不能以“克制”为由只慢推和凝视。
- 景别形成对比：`大全景定位 → 中景行动 → 细节证据 → 反向/关系镜头 → 新尺度`。连续两镜不使用相同中景站位。
- 光线必须来自太阳、门窗、街灯、车灯、投影、海面、云层或真实灯具；不用持续橙蓝、无来源霓虹和全片过曝光晕。

## 7. 文字进入真实环境

按 `typography-and-credits.md` 建立 Display A、Display B 和 Utility。电影叙事可克制运动，但不能全片同一种字体。

- 每张人物卡和导演卡都使用克制的主副标题组合：姓名为 Display B 主层，角色身份、英文名、`STARRING` 或 `导演 / DIRECTED BY` 为 Utility 副层；主副层至少用字号、字形、字重、字宽、字距中的两项拉开层级，不能只是同一种字体一大一小。
- 从 `上小下大 / 同边线错阶 / 侧签式` 中选择一种主排法贯穿全片，并在 Prompt 中写清姓名约 70%–80%、Utility 约 20%–30% 的组内视觉权重、共享对齐轴、行距和一项克制的线/点标记。不同人物卡只因环境留白调整左右位置，不每卡更换字体方案。
- 角色卡占画面宽约 18%–35%；卖点文字约 24%–50%；最终片名约 32%–60%，巨型奇观可到 55%–75%。
- 文字置于天空、墙面、道路、机库门、窗外、玻璃、海面或建筑留白，不覆盖脸、手和关键动作。
- 使用负空间、真实透视锁定、前景遮挡、反射显影和焦点交换中的 2–4 种；不能所有文字只淡入。
- Utility 可比姓名提前 0.08–0.18 秒建立排版锚点，或与姓名同步被遮挡揭示；整组完整后只做一次轻微字距舒展、焦点交换或自然光影经过，不能为了“丰富”加入持续字母飞舞、故障拆分或夸张三维字。
- 字体可沿消失方向略缩短，镜头停点恢复准确比例；人物、车辆、门框、机械、尘土或光线从字前经过后必须恢复完整可读。
- `single_clip_trailer` 的角色卡、卖点卡和片名至少使用两种明显字形角色与三种揭示机制；`opening_title` 至少使用两种字形角色与两种空间关系。
- 最终片名与人物/主体共同构成电影画面，不默认切黑 Logo 页；预告片名约 1.4–2.0 秒，片头约 1.8–2.4 秒。

## 8. 连续转场

每个转场都写“来源—覆盖/切点—下一镜继承项—新信息”：

- 车辆、人物、螺旋桨、柱体或门框掠过前景，遮挡中切到方向一致的新空间。
- 关门、扣箱、翻纸、抬手、转头、奔跑、轮子旋转在下一地点延续动作速度和方向。
- 相似形状连接车轮/月亮、窗框/银幕、杯口/镜头、螺旋桨/钟面、地图线/道路；位置和尺寸先对齐再硬切。
- 相机闪光、阳光、高光、尘土、蒸汽、水滴或布料只有真实来源时覆盖画面，下一镜从相同亮度、颜色或运动方向恢复。
- 一段环境声可提前 0.2–0.6 秒进入下一空间，形成声音桥；不为每个切点添加 whoosh。

禁止无来源液态变形、连续白闪、预告片抖动、万能粒子擦屏、无因速度变化和广告英雄环绕。

## 9. 完整 15 秒音乐与声音

音乐描述保持和已验证案例一样“锁气质、不锁死编曲”，但必须要求一支有头有尾的完整短曲：

```text
Music direction：原创 15 秒电影配乐，只锁题材气质、2–4 个音色锚和完整能量弧，不规定 BPM、拍号、调性、和弦或逐秒音符。明亮成长可用清脆吉他、温暖鼓点、轻弦和自然风声；年代职业可用低弦、木管、克制铜管与机械质感；敬畏奇观可用宽阔和声、低弦与自然介质声。开场立即建立一个可辨识动机，中段加入清楚推进，事件升级处形成变奏或短暂抽空，片名处完成情绪高潮并以明确终止音/完整和声收束；可以有短余响，但不能只有长音自然消散。具体旋律、节奏、和声和配器由 H3 自主原创。
```

## 10. 最低检查

- OUTPUT_MODE 是否正确：片头是卡司世界，预告是否真正有触发、阻碍、行动、升级和悬念？
- 镜头是否由完整动作、关系变化和自然切点决定，而不是为了达到固定数量快速切碎？文字是否严格匹配 `TEXT_CONTENT_MODE`？
- 无声观看是否看得懂谁在做什么、发生何种变化、代价为何、结尾问题是什么？
- 每次换景是否都带来新的行动条件、阻碍或结果；人物是否通过完整动作结果被认识，而非只换脸和姓名？
- 是否继承所选 N1/N2/N3/N4 的完整视觉链，而不是只复制“35mm/大画幅/电影感”标签？
- 参考图是否按 Gate 3 执行：默认只占一个场景并发散至少两个新地点，严格原景时是否仍有三个动作/尺度/光线状态，而不是把静态图做成十五秒轻微运动？
- 是否有 4–6 个有来源的主效果、8–14 个物理支撑反馈，且每个效果服务行动？
- 字体是否至少两种角色、空间关系和揭示机制明确；预告文字是否不再只有导演和片名？
- 是否没有前半快切完、后半停留长标题；最终片名是否只占合理收束时长？
- 音乐是否开场有动机、中段推进、后段高潮并明确结束，而非环境音床或无头无尾长音？
