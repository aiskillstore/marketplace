# 已验证案例校准矩阵

每次生成只选择一个 `primary_calibration`。矩阵保存用户案例中已经生成出目标画面的方法：媒介公式、摄影/版面、材质、字体关系、效果链、转场种子和音乐气质。它不保存案例专有片名、演员、现实作品、品牌或完整故事。

校准不是“照抄案例 Prompt”，也不是按爱情、科幻、校园等题材词选。先确定 `OUTPUT_MODE` 和四条主路由，再在该路由内部选择案例；用户认可的写实叙事成片只校准 `cinematic_narrative`，不能成为另外三条路线的统一审美标准。

## 2. 固定选择顺序

```text
OUTPUT_MODE → 主路由 → primary_calibration → calibration_base → 项目变量 → 镜头/版面/字体/音乐编译
```

1. 用户说“片头/卡司/Opening Title”选 `opening_title`；说“一条 15 秒预告/teaser/trailer”选 `single_clip_trailer`。
2. 按主画面载体选择四路由：连续真人行动、实拍+AE、架空世界/模型/空间、纸张/照片/杂志。
3. 只在选中路由内选一个最接近的案例。
4. 题材只修改人物、事件、地点、物件和准确文案，不反向改主媒介。
5. 允许从第二案例借一个局部机制，例如 N1 借 C4 的有来源放映光；不得借第二套完整色盘、字体、版面、音乐和落版结构。

### 常见歧义

- “科幻史诗”不是一个路由：真实城市巨型异象→V1；手工模型/微缩舞台→V2；深空机械、粒子轨道和三维通道→V3；纸质太空档案跨页→编辑拼贴，重新在 C1/C4 中选母体。
- “复古”不是一个路由：连续年代实拍→N2；实拍+高级动态图形→G1/G2；纸张/照片/杂志→C1/C3/C4；二维动漫复印杂志→C2。
- “爱情/校园”不是拼贴同义词：连续表演选电影叙事，实拍人物+动态包装选 G1/G2，纸张照片成为主要画面才选 C1/C3/C4。

## 4. OUTPUT_MODE_ADAPTATION

同一个案例因模式不同而采用不同信息密度：

| 主路由 | Opening Title | Single-clip Trailer |
| --- | --- | --- |
| 电影叙事 N1/N2/N4 | 不设镜头数量；文字按 `TEXT_CONTENT_MODE`；完整动作、卡司阅读、世界与出发优先 | 不设镜头数量；文字按 `TEXT_CONTENT_MODE`；把触发、阻碍、行动、升级和选择合并进最少必要的完整表演与自然切点 |
| 实拍 AE G1/G2 | 5–8 状态；文字按 `TEXT_CONTENT_MODE`；人物卡和视觉识别优先 | 8–11 状态；文字按 `TEXT_CONTENT_MODE`；人物、图形与故事事件连续升级 |
| 架空 V1/V2/V3 | 5–8 状态；文字按 `TEXT_CONTENT_MODE`；物理法则和奇观展示优先 | 7–9 镜头；文字按 `TEXT_CONTENT_MODE`；补受影响人物、代价、行动和未解决选择 |
| 拼贴 C1–C4 | 6–9 状态；文字按 `TEXT_CONTENT_MODE`；卡司/版面装配优先 | 8–12 状态；文字按 `TEXT_CONTENT_MODE`；触发材料、关系变化、行动、代价和海报收束 |

不能以案例原本是 Opening Title 为由，把用户要求的 trailer 仍写成只有署名和片名；也不能以 trailer 为由破坏案例已经验证的媒介链。

## 5. VISUAL_PAYLOAD_LOCK

每个主校准都必须从对应风格 Reference 继承完整验证链，再具体化到逐镜：

```text
CASE CALIBRATION
primary=[唯一 id]
calibration_base=[唯一母体]
output_mode=[opening_title 或 single_clip_trailer]
inherit=[媒介公式、摄影/空间、材质/色彩、字体关系、转场种子、音乐气质]
scene_or_state_density=[按 OUTPUT_MODE_ADAPTATION]
text_content_mode=[basic_cast / basic_cast_plus_hook / user_exact；逐卡使用用户确认的准确文字]
hero_effects=[4–6 个有来源、可记忆的主效果]
support_effects=[8–14 个物理/材料/合成反馈]
replace=[项目人物/主体、事件、世界、准确文字、项目色盘变量]
exclude=[案例专有实体、现有 IP、第二套完整视觉系统]
```

电影叙事不强制镜头数量，以完整表演和因果可读性为准；`multi_scene` 至少建立 3 个一眼可区分的地点/行动条件，可由较长连续表演或自然切镜承载，不为凑数碎切。实拍 AE、架空特效和编辑拼贴至少形成 5 个一眼可区分的环境/尺度/版面，并按各自 Reference 使用状态密度。相邻两段改变地点/载体、景别/视角、光色、人物行动、材质、字体过程中的至少三项。

每个 Hero effect 写可见来源、路径、接触对象、结果和结束状态；每个主要镜头再配 2–3 个支撑反馈。胶片颗粒、调色、普通阴影、景深和“高级感”不能充当 Hero effect。

## 6. TYPOGRAPHY_CALIBRATION

案例只锁“字体关系”，不锁所有文字使用同一家族：

- N1/N2/N4：环境卡司字克制，但 Display A、人物卡 Display B 和 Utility 仍需明显层级。
- G1/G2：从 `typography-and-credits.md` 选择一套三层方案；至少三种字体过程和三种空间关系。金色空间字只是可选材质，不是默认答案。
- V1/V2/V3：巨型 Hero 与角色/卖点卡必须使用不同宽度、粗细、实/空心或衬线关系；不全片只用一个巨字。
- C1–C4：准确片名稳定，周围可有大字、竖排、手写、打字机、编辑衬线和 Marks 混排；不得随机剪报拼准确片名。

语言只采用 Gate 2 的确认结果：中英双语时中文主层与英文副层分别设计骨架、字重、字距和尺度；纯英语时只保留英文。案例中的英语/日语只属于案例内容，不能覆盖语言 Gate，也不能在 Gate 失败时替用户代选。

## 7. 已验证运镜与转场种子

先继承主校准种子，再用 `cinematography-and-transitions.md` 补齐起点、路径、终点、切点、继承项和声音桥：

- `N1`：低机位横移/侧面跟拍 → 车辆前景遮挡 → 路牌/建筑遮挡 → 快门或阳光曝光 → 车内/门内框景 → 玻璃反射揭题。
- `N2`：沿机械结构横移 → 大型部件遮挡 → 工具箱/舱门合拢 → 轮组低位跟拍 → 尘土/蒸汽散开 → 大空间真正出发。
- `N4`：沿海交通/前景遮挡建立 → 人物分别在生活空间完成动作与姓名卡 → Gate 3 默认参考环境只在其中一个场景出现 → 布料/门框/桅杆/车轮遮挡换入至少两个发散地点/行动条件 → 物件传递与会合 → 开阔空间以片名收束，不强制复刻参考图构图。
- `V1`：贴地推进 → 异常影子/焦散先行 → 跟随视线上仰 → 沿介质升降/穿越 → 巨物/水面遮挡 → 介质内或新尺度稳定揭题。
- `G1`：城市下降/建筑轴线 → 多窗口切割与扩张 → 穿玻璃 → 反射/景深交换揭字 → 字块重组/笔画转场 → 多 plate 光学合并。
- `V2`：俯视真实材料 → 下降进入模型 → 书页/地图硬转场 → 粒子沿材料装配 → 模型内部穿越 → 拉远成模型海报。
- `C1`：地图折信封 → 照片碰撞成拍立得 → 照片堆扩张 → 红线成为遮罩/基线 → 材料汇入海报。
- `V3`：机械/唱片圆形入口 → 工程面/照片产生纵深 → 轨道粒子牵引 → 穿入照片/通道 → 粒子直线或标题笔画切割 → 天体/人物/文字空间落版。
- `C2`：撕纸/照片滑入 → 墨迹/扫描条 → 杂志翻页/胶片掠过 → 大字混排与套印 → 动画海报冻结。
- `C3`：树叶/纸片遮罩 → 课本合上 → 推入照片/眼睛/树纹 → 相册翻页与阳光曝光 → 记忆海报冻结。
- `G2`：校园航拍定位 → 多窗口/纸条人物卡 → 动作匹配切换社团与地点 → 高亮笔/贴纸/空间字升级 → 群像照片墙与标题合并。
- `C4`：放映光建立 → 胶片盘圆形光擦 → 城市诗硬切 → 杂志页面覆盖 → 红黑银几何对齐 → 摄影与字体冻结成艺术海报。

允许在一个种子上增加一次图形相似、动作匹配、因果切或声音桥；不能替换主媒介、整条转场链和最终落版方式。

## 8. 音乐继承边界

只继承案例的主气质与 2–4 个音色锚，不复制已有旋律，不锁 BPM、拍号、调性、和弦和逐秒配器。无论案例原写法是否偏氛围，最终都要编译成完整 15 秒短曲：开场动机 → 中段推进 → 后段变奏/增层/短抽空 → 标题高潮和明确终止。环境声、翻页、机械、风、水和 whoosh 只作同步层，不能替代 BGM。

## 9. 生成指令前校准检查

- 是否先定 OUTPUT_MODE 和主路由，再选唯一案例；没有被“科幻/爱情/校园/复古”题材词带错路由？
- 是否只继承一个完整母体；第二案例最多贡献一个局部机制？
- 用户认可的 N1/N2/N4 写实结果是否只影响电影叙事，没有把 AE、架空和拼贴都改成克制实拍？
- 是否完整读取对应风格 Reference 的验证链，而不是只复制矩阵里的概括词？
- 镜头/状态是否匹配成片模式；文字是否严格匹配 `TEXT_CONTENT_MODE`；预告是否用画面补足因果故事而不破坏媒介？
- 电影叙事是否只在行动条件、阻碍或结果变化时换景；其他三条路线是否至少 5 个不同环境/尺度/版面？是否有 4–6 个 Hero effects、8–14 个支撑反馈？
- 字体是否继承案例关系但仍有 2–4 个不同角色；默认语言是否为中英双语？
- 转场种子是否保留，并补齐起点、路径、切点、继承项和新落点？
- 音乐是否保留案例气质但成为有起承转合和明确结束的原创 15 秒短曲？
