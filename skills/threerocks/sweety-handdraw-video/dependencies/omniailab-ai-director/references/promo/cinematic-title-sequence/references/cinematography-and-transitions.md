# 电影运镜、预告剪辑与连续转场生成指令库

生成最终 H3 Prompt 时读取。本文件不讲理论，只把摄影和剪辑方法转成可执行句子。任何运镜都必须揭示人物行动、关系、空间尺度、世界法则或准确文字；任何转场都必须有前镜来源、切点、后镜继承项和新落点。

## 1. 先写两个内部 Score

最终 Prompt 不保留字段名，但逐镜必须覆盖这些关系：

```text
CAMERA SCORE
shot_id | start-end | new_information | size_and_lens | camera_origin | path_axis | foreground_pass | subject_action | endpoint | readable_hold

TRANSITION SCORE
from-to | visible_source | coverage_or_cut_point | inherited_shape_direction_color_speed_sound | next_landing | story_gain
```

硬规则：

- `new_information` 不能只写“更有电影感”；必须是新行动、新关系、新阻碍、新尺度、新地点、新材质或新文字。
- 一镜只用一种主运动；起点和终点必须不同，除非选择固定镜头。
- 转场不能只写“无缝切换”；写清什么覆盖画面、何时切、下一镜保留什么，并落到什么主体。
- 同一转场机制最多连续使用两次；第三次必须换真实来源或改变叙事功能。
- 每个主要镜头必须同时填满 `camera_origin / size_and_lens / path_axis / foreground_pass / subject_action / endpoint / story_gain / transition_source / cut_point / inherited_item / next_landing`。最终 Prompt 可转成自然中文，但不能省字段。
- “横移或慢推”“推近/升降二选一”“可以使用”“可选”“建议”“例如”“等方式”都是未决方案；出现任一未决表达时先做唯一选择，未选择前 `camera_plan_complete=false`，禁止生成指令。
- 全片至少覆盖建立揭示、行动跟随、证据靠近、尺度释放中的三种摄影功能；从动作匹配、形状匹配、前景遮挡、声音桥中确定 2–3 类并真正写入逐镜，不能只列手法名称。
- `TRANSITION SCORE` 与逐镜运镜一次写完，不增加问题、工具调用或第二轮检查。至少两次跨镜转场必须完整填写 `visible_source / coverage_or_cut_point / inherited_item / next_landing / story_gain`，且 `next_landing` 进入新地点、新行动条件、新主体或最终片名空间；同一背景只换景别、继续走路或继续对视不计入。全部成立才设置 `transition_plan_complete=true`。

## 2. 按叙事目的选运镜

### 固定镜头 / locked frame

用途：让人物决定、复杂层级、最大异象或最终片名自己产生力量。

生成指令句式：

```text
相机固定在[具体高度/位置]，使用[景别/焦段感]，不做推拉和环绕；前景[门框/玻璃/纸边]、中景[人物动作]、远景[世界/建筑]分别运动。到[时间]人物完成[决定/动作]，片名在[负空间]完整稳定[时长]，只保留环境的自然运动。
```

限制：预告中固定段通常 0.7–1.8 秒；最终片名外不以“胶片呼吸”代替内容。

### 推近 / push-in

用途：强调人物意识到变化、靠近关键物件、进入文字/照片/模型入口。

```text
从[大全景/中远景起点]沿[道路/桌面/视线/建筑轴]向[主体]推进，先经过[前景层]产生视差，再让[动作/异常证据]进入清楚焦点；推进到[中景终点]立即停稳[0.6–1.2 秒]，使[人物反应/准确文字]完整可读。
```

预告不要默认“缓慢推近”；触发、追赶和 AE 段可快速而稳定，片头卡司段才可更从容。

### 拉远 / pull-out

用途：从人物/物件揭示群像、城市、巨构、微缩世界或未被注意的代价。

```text
从[人物/物件近中景]沿原轴稳定后移，依次揭示[前景边框—中景关系—远景世界]；每增加一层都出现新的[人物/障碍/尺度证据]，最终在[大全景]停住，让片名落在刚出现的负空间。
```

限制：不能只是人物逐渐变小；至少揭示两层此前不可见的新信息。

### 横向轨道 / truck / side tracking

用途：比较人物、沿建筑/道路/模型建立空间，利用柱体和前景遮挡自然分段。

```text
相机在[人物/车辆/建筑]侧面以匹配速度横向移动，前景[柱体/窗框/树/机械部件]依次掠过，中景人物持续完成[动作]，远景消失线承托[准确文字]；在第[几次]遮挡占满画面时切到方向一致的新地点。
```

### 跟随 / 领先 tracking

用途：把观众带入行动，让“人物为什么移动”可见。

```text
相机以[低机位/肩高/背后]跟随或领先[人物/交通工具]，保持[中景/全景]和前进方向；主体边移动边完成[寻找/递交/启动/追赶/保护]，背景视差证明速度。到达[门/转角/目标物]时动作结果触发下一镜。
```

限制：只走路不算行动；必须写目标、动作和结果。

### 仰俯揭示 / tilt

用途：从人物/地面证据揭示建筑、飞行器、巨型异象、垂直水流或模型高塔。

```text
从[地面变化/人物手部/抬头反应]开始沿[建筑边/水流/光柱/模型塔身]向上仰拍，沿途让[焦散/影子/结构/粒子路径]连续可见；到完整奇观和负空间同时成立时停住，前景人物仍保留作尺度锚。
```

俯拍反向用于从天体/标题/地图下压到人物行动；不能无理由上下扫一遍。

### 升降 / boom / crane

用途：跨越遮挡、从个体升到群像、从桌面进入模型、从街道揭示城市异常。

```text
相机从[低位起点]随[人物/介质/建筑边]平稳升至[高位终点]，越过[真实遮挡]后才显露[第二空间/群像/规模]；运动末端减速，让[新关系/卖点文字]稳定。
```

### 受控弧线 / arc

用途：揭示人物关系、空间字厚度或物件背后的新信息。

```text
以[人物/物件/空间字]为中心只移动约[15–35 度]，从正侧面到斜侧面，途中出现[第二人物/投影/后方入口]；到新信息可见时停止，不完成英雄式一整圈环绕。
```

### 穿越 / pass-through

用途：进入玻璃、门、纸缝、字腔、模型、照片、液体表面或机械光阑后的新空间。

```text
相机沿[可见入口]轴线推进，入口边缘逐渐占满前景；在边缘完全遮挡/折射画面的准确帧切入下一空间，后一镜继承相同方向和速度，先落到[具体主体]再继续运动。
```

限制：一次穿越只跨一层入口；禁止无尽穿过多个世界展示技术。

### 稳定肩扛

用途：靠近职业行动、冲突现场和人物即时决定，同时保持电影真实感。

```text
相机在人物肩高以克制手持跟随[具体行动]，只有呼吸级微振，不做预告抖动；焦点在[人物—道具—结果]之间按事件交换，切点落在动作加速或前景遮挡处。
```

### 受限特殊运镜

- `whip pan`：只在前后镜都有同方向快速运动时使用一次；摇动模糊覆盖 3–8 帧感，后一镜保持同速度后迅速落稳。
- `dolly zoom`：只在世界尺度/认知突然改变时使用一次；人物大小近似稳定，背景透视显著改变，不作常规炫技。
- `roll`：只在物理法则明确旋转、失重或穿越界面时使用；通常不超过约 90–180 度并明确恢复方向。
- `drone descent`：从城市/建筑大全景下降到具体人物或入口，必须在 1–1.5 秒内找到主体；不作空旅游航拍。

## 3. 景别、焦段与视线落点

- `24–35mm`：空间、群像、城市、巨构和前中后景；人物置于边缘时避免脸部夸张变形。
- `40–50mm`：最稳定的人物行动、职业空间和环境卡司。
- `65–85mm`：压缩层次、隔窗观察、细节/反应和模型景深；不要连续多个只拍脸的近景。
- 微缩世界使用“35/50/70mm 微距感 + 浅景深 + 真实焦点平面”，而非整张均匀锐利。

预告至少形成一次：`大全景定位 → 中景行动 → 细节证据 → 反向/关系镜头 → 更大尺度或不同地点`。相邻两镜在景别、相机高度、方向或焦段感中至少改变两项。

保持 eye trace：前镜观众注意力落在画面左/中/右某处，后镜的重要人物、物件或文字尽量在相近区域出现；若故意跳到对侧，必须用于冲突或惊讶。这样可快切但仍易读。

保持运动方向：人物/车辆向右运动，动作匹配后的下一镜继续向右；要反转方向，先用正面、静止或明确转向镜头建立。

## 4. 连续转场库

### 图形相似切 / graphic match

匹配形状、构图位置、颜色或负空间中的至少两项，最好同时匹配运动方向。

```text
前镜[圆形/矩形/斜线/空洞]位于画面[位置]并占[比例]，在轮廓最完整时硬切到同位置、同尺寸的[天体/车轮/唱片/镜头/窗/字腔]；后一物体继承旋转/移动方向，再揭示新空间。
```

可执行配对：车轮→天体、杯口→镜头、窗框→杂志跨页、太阳→放映机光斑、道路线→关系线/粒子轨道、眼睛→黑洞、标题 O 字腔→圆形入口。

### 动作匹配切 / match on action

```text
前镜人物开始[抬手/关门/翻页/奔跑落脚/转头/递物/拉杆]，在动作速度最大或物体遮挡主体的中间帧切换；后一镜用相同屏幕方向和相近速度完成动作，并让结果落在新地点/新时间。
```

动作必须在后镜完成，不让 H3 生成两次起手。

### 前景遮挡 / invisible cut

```text
[车辆/柱体/人物背部/门框/巨物/纸页]从[方向]靠近镜头并覆盖 80%–100% 画面；在纹理最满、运动最清楚时切入下一镜，后一镜由同色/同方向前景离开，露出[新主体]。
```

避免用纯黑遮挡所有转场；材质与方向必须变化并服务场景。

### 视线匹配 / eyeline reveal

```text
先拍人物在[位置]看向画外[方向]，眼神或头部动作完整；硬切到该方向上的[异常/目标/人物/文字]，保持高度和左右关系一致；后镜立即给出被看的新信息。
```

禁止连续三个人抬头再切同一奇观；第二次必须增加行动或代价。

### 因果切 / cause-and-effect cut

```text
前镜[按钮/门/光束/水滴/线条/机械]完成可见触发，切到不同地点的直接结果[灯熄灭/道路改变/介质上升/照片裂开/人物停下]；声音可提前或延后连接，但结果不能只是相同光闪。
```

### 光色匹配 / light-color bridge

```text
前镜有来源的[阳光/相机闪光/投影/车灯/胶片曝光]从[方向]覆盖画面，在接近同一亮度和专色的帧切到后镜；后镜从相同光色中恢复，0.2–0.5 秒内露出新地点。
```

全片白闪通常不超过一次；其余使用阴影、专色或材质遮挡。

### 介质匹配

```text
前镜[水滴/玻璃反射/尘土/蒸汽/烟/纸纤维/粒子]由真实来源覆盖镜头；在纹理最清晰处切到性质相近但地点不同的[海面/玻璃/云/纸面/星尘]，保持流向后迅速落到具体主体。
```

液体不等于粒子，烟雾不等于光；后镜继承同一物理性质。

### 平面/入口衔接

```text
相机靠近[玻璃/屏幕/照片/书页/墙面/标题字腔]直到边缘成为全屏；在穿越平面的准确帧切到该平面内部/背后的世界，后一镜先保持相同网格或消失点，再释放成新空间。
```

### 反差硬切 / contrast cut

用于强化剧情升级：安静→运动、暖→冷、近景→大全景、拥挤→空旷、正常→异常。至少保留声音、构图位置或动作方向中的一个连续项，防止像随机换片。

### 插入镜头桥 / cutaway bridge

```text
在主动作两个阶段之间插入 0.25–0.65 秒的[手/工具/轮胎/信件/眼睛/仪表/纸边/环境反应]，插入镜头提供一个新证据；回到主动作时直接进入结果阶段，不重复前一动作。
```

一个主要段落最多连续 3 个短插入；插入不承担长文字。

## 5. 声音桥与音乐切点

声音用于连空间和预告节奏，不给每个转场配 whoosh。

### 下一空间声音提前进入（J-cut）

```text
在前镜画面结束前约 0.2–0.6 秒，先让下一地点的[列车/海浪/机械/人群/投影/风]低声进入；视觉切换后声音变清楚，观众自然被带到新空间。
```

### 前一空间声音延后退出（L-cut）

```text
画面已经切到[新地点/人物]，前镜的[引擎/钟声/一句呼吸/纸张声]再延续约 0.2–0.5 秒后结束，用于连接因果或留下情绪，不覆盖新的关键动作声。
```

### 音乐重音

全片只预设 2–3 个重要同步点：触发事件、最大升级/字体重组、最终片名。其他剪辑由原创音乐自然组织。声音桥不能代替完整短曲；BGM 必须从开场动机、中段推进走到片尾明确终止。

## 6. 按 OUTPUT_MODE 分配节奏

### `opening_title`

- 电影叙事不规定镜头数量，按完整动作、人物关系、卡司阅读和自然遮挡决定切镜；实拍 AE、架空特效与编辑拼贴继续遵循各自风格 Reference 的状态密度。
- 开场可用 1.4–2.0 秒建立影片世界；人物卡/卡司通常 1.2–2.2 秒。
- 允许 1–2 段无文字电影呼吸，但每段仍有行动、材质或空间变化。
- 最终片名完整稳定约 1.8–2.4 秒；此前一次转场必须自然交付片名空间。
- 不强迫所有路线快切：电影叙事允许完整动作，AE/拼贴可更密，架空特效允许最大奇观有较长阅读。

### `single_clip_trailer`

- 开场约 1.2–1.6 秒内出现主体和当前状态，约 2.5–3 秒内发生触发事件。
- 电影叙事不规定镜头数量，把正常状态、触发、反应、行动和阻碍按连续表演合并；实拍 AE 8–11 个状态、架空特效 7–9 个状态、编辑拼贴 8–12 个状态。
- 电影叙事保持到动作阶段完成、关系变化或文字读完再切，不套用统一时长；其他三条路线普通状态约 0.8–2.0 秒，短插入约 0.25–0.65 秒，最大奇观/人物决定可接近 2.2–2.6 秒。
- 已确认的文字卡按 `TEXT_CONTENT_MODE` 分散进入人物、行动和片名段；不能把全部文字挤到最后，也不能为填空临时补短句。
- 最后 5 秒仍须有至少两次新信息：一次人物行动/法则升级/版面重组，一次选择/悬念/最大奇观，然后才进入片名。
- 最终片名约 1.4–2.0 秒。禁止 7–8 秒进入最后一镜并停到 15 秒，也禁止 10 秒前结束所有快切后只剩长标题。

### 预告能量弧

```text
0–20% Hook：主体+触发，不绕场。
20–45% Identify：角色/任务/世界法则，文字卡帮助辨认。
45–70% Escalate：阻碍、地点和效果同时升级，加入短证据镜头。
70–88% Turn：代价、选择或最大奇观；可短暂抽空声音形成对比。
88–100% Land：最后一次物理/图形转场交付片名与音乐终止。
```

这是信息功能，不要求机械按百分比切段；不得覆盖所选案例母体的有效镜头种子。

## 7. 四条路线的摄影与转场预算

- `cinematic_narrative`：主要使用真实遮挡、动作匹配、视线/因果切、光色匹配和 1 个声音桥；无来源特效转场为零。
- `live_action_graphics`：实拍相机运动与图形运动交替；至少两次真实平面/透视继承、一次人物/建筑遮挡、一次玻璃/光学入口、一次标题笔画/窗口合并；纯图形擦屏不超过三次。
- `constructed_world_vfx`：所有转场服从同一物理法则；至少一次尺度揭示、一次介质/模型/通道穿越、两次形状/因果匹配；禁止粒子万能擦屏和连续虚拟飞行。
- `editorial_collage`：翻页/折叠、照片扩张、撕纸、轨迹线、放映/扫描、标题/几何遮挡中选择 5–8 个；每个动作有纸边、接触影与下一版面落点。

## 8. 文字阅读与相机配合

- 文字正在构建、拆分或重组时，相机减速或固定；相机快速移动时，完整文字固定在环境/深度层。
- 角色/卖点卡完整后通常保留约 0.65–1.35 秒；最终片名按模式保留约 1.4–2.4 秒。
- 人物或前景遮挡文字通常不超过约 35%，遮挡结束后恢复完整；不得用“层次感”长期盖住字。
- 快切状态的准确文字不能逐字打完才离开；应整组构建、整组揭示或完整载体进入。
- 一个镜头只有一个最大阅读焦点；中英双语属于同一信息组，而不是两张竞争卡。

## 9. 最终 Prompt 的逐镜自然语言模板

```text
【镜头 N｜start–end｜这一镜新增的信息】
景别与相机：使用[景别/焦段感/稳定方式]，从[具体起点]沿[运动轴]到[具体终点]；经过[前景]形成视差/遮挡，用于揭示[新行动/关系/尺度/文字]；到[时间]减速或停稳。
人物/主体与环境：[人物连续动作和结果]；前景[什么]、中景[什么]、远景[什么]；该镜如何推进故事/卡司/法则。
画面效果：[有来源主效果→路径→接触→可见结果→回收]；[2–3 个支撑反馈]。
文字与版式：[准确文字、字体角色、空间关系、构建、完整时刻、停留、一次响应]；无文字则明确写“本镜无文字”。
转场：[来源]在[切点]覆盖/完成动作，下一镜继承[形状/方向/颜色/速度/声音]并落到[新主体]。
声音：[音乐所处阶段]；[一个必要同步点或声音桥]；环境声不盖住 BGM。
```

逐镜写完后做一次确定性收敛：删掉所有备选连词，把每个镜头收敛为一个起点、一个主运动、一条运动轴、一个人物动作结果和一个终点；把每个转场收敛为一个可见来源、一个切点、一个继承项和一个下一镜落点。镜头字段齐全时设置 `camera_plan_complete=true`；2–3 类转场已经实际进入逐镜、至少两次跨镜转场落到新信息时，同时设置 `transition_plan_complete=true`。两项在同一次收敛中完成。

## 10. 失败边界

- 连续三镜只用慢推、连续三镜只拍人物走路/回头/凝视。
- 没有起点终点的“电影级运镜”、没有切点落点的“无缝转场”。
- 把多个运镜、地点、动作或文字用“或/可以/例如/可选”留给 H3 自己决定。
- 空旅游航拍、广告式 360 度环绕、无因预告抖动、随机变焦和无限穿越。
- 所有转场都是白闪、粒子、液体或光线扫屏。
- 前半段用完全部事件和特效，后半段静止大字或同一个人物慢动作。
- 快切只换裁切/景别，地点、人物动作和故事信息没有变化。
- 声音桥、whoosh 和 boom 堆满，但音乐没有旋律/节奏动机和片尾终止。
