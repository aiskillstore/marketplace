# 真人实拍 × 手绘融合

把简短创意转化为一份可直接复制给视频模型的 prompt，遵循用户原始风格。核心风格：真实生活空间、手机追拍、粗粝二维手绘、连续变形、真实物理接触；在保留手绘实拍融合逻辑的基础上，主动增强镜头位移、空间覆盖和背景变化，让镜头更灵动、更像拍摄者临时追着手绘实体观察。

## 处理流程

1. 解析并保留用户明确的模型、时长、画幅、主体、场景和变形路线；`15s/15 秒`、`16：9` 等写法统一为标准格式。
2. 未指定模型时用 MiniMax H3；时长或画幅缺失且会影响结果时，只使用一次 confirmation card，其他内容自行补全。不得改写用户明确的参数（例如 16:9 不得变成 9:16）。
3. 写 Prompt 前，先读取并遵循以下五类要求：
   - Prompt 结构规范：若用户没有完整变形路线，规划同一手绘实体的连续变形；每次变形都要有中间态，不得瞬移或突然换角色。按时长分成 4—5 个连续时间段，每段只安排一个主要动作或变形；至少 2 个时间段包含拍摄者真实手的好奇互动，结尾留下自然收束或小巧笑点。15 秒可用 `0-3 / 3-6 / 6-10 / 10-13 / 13-15`；12 秒可用 `0-3 / 3-6 / 6-9 / 9-12`。
   - 空间：补足光线/天气、空间质感、至少 4 个真实道具、动画可接触的表面和环境声音；空间范围从局部扩展到整个场景，保留自然凌乱、使用痕迹、轻微污渍、划痕、灰尘和水渍，不要广告式布置或过度整洁。手绘实体必须遵守接触、遮挡、反射、折射、碰撞、透视和光线关系，不能像贴纸一样悬浮。
   - 角色：统一蜡笔/粉笔/彩铅/粉彩/粗笔刷的粗粝二维手绘质感，保留逐帧重绘感、轻微抖动和局部柔和微光；颜色、尾迹和运动方向在变形中继承。手绘实体应在整个空间里移动、跳跃、攀爬、滑行、绕行和躲藏，而不是只在单一物体上变形。真人手保持未经修饰的真实质感；每次真人互动都形成“一方动作 → 另一方反馈 → 镜头跟随”的连续闭环。
   - 镜头：默认保持连续追拍；如采用剪辑或多镜头，必须明确景别、机位、主体动作、转场和时间段，不得只写“分镜剪辑”。镜头使用单手手机临场追拍，而非稳定展示；可加入横向晃动、身体移动、靠近/拉开、突然甩镜、绕物半圈、从物体后方探出、抬升和下压。主体不必始终居中，可位于画面边缘、前景后方或焦点外，并在前景、中景、远景之间持续游走。保留手抖、追拍滞后、自动对焦犹豫、白平衡漂移、曝光波动、局部过曝、运动模糊、暗部噪点和手机压缩感；不用稳定云台或摄影棚补光。
   - 声音：使用真实环境声、物体摩擦/碰撞/震动声、拍摄者脚步/衣物/呼吸声，以及与变形同步的轻微手绘音效；声音要随镜头距离、遮挡和空间区域变化，默认无背景音乐、旁白和对白。

## 输出格式

先输出一行：`模型，时长，画幅。`
随后只输出一份完整可执行 prompt，按以下顺序组织：

```text
整体影像与场景 → 手机拍摄质感 → 分段动作/变形（同时写镜头位移、空间覆盖、背景变化、遮挡、焦点和绕拍/俯仰反应） → 手绘统一规则 → 真人物理关系 → 负面限制 → 声音设计
```

## 必须避免

3D 卡通、玩偶感、平滑矢量线、均匀霓虹、精致广告布光、稳定云台、跨场景硬切、字幕、标识、巨大眼睛、裂口、尖牙、恐怖威吓、扑袭、突然黑屏、跳吓、物体穿模。

不要解释创作过程，不要重复用户原文；除非存在参数冲突，否则直接给出成稿。
