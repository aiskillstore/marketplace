# 产品广告 H3 动态编译

仅在“产品主角广告”路线准备生成视频时读取。先确认当前模型、单次时长与参考素材限制；用户可以指定任意目标时长，最终时长以实际片段完整拼接为准。本卡只定义产品广告的素材职责、动态结构和质量门槛。

## 素材职责

只上传承担明确职责的素材，并在 Prompt 中逐一声明：

- `@图片1` 产品锚图：锁定产品外观、包装、Logo、标签、材质、比例和识别点。
- `@图片2..N` 已选方向参考集合（执行 Research 或用户已给有效参考时必传）：逐张锁定已声明的成像、光影、色彩结构、构图、材质语言或品类氛围，不提供产品、人物、Logo 或文字身份。
- `@图片N+1` 额外场景锚点（非默认）：只在用户已提供/明确要求，或已选方向参考集合无法承担必要空间/首帧时使用；不在同一风格 Research 问题上重复增加一轮选图。
- `@图片N+2` 故事板（按需）：锁定镜头顺序、构图、卖点事件、转场节点和 Hero 定版。
- `@图片N+3` Logo/标准字（按需）：用于片尾准确合成或品牌锁定。
- `@视频1` 节奏参考（按需）：只迁移运镜、节拍、转场和运动结构。
- `@音频1` 声音参考（按需）：只迁移节拍、氛围和声音质感。

冲突时遵循：用户明确指令 > 产品锚图 > 已确认故事板 > 已选方向参考 > 额外场景锚点 > 节奏参考 > 风格词。弱相关素材直接剔除。

## Research 图传递约束

1. 先确认 MiniMax H3 当前支持所需的参考图片数量和组合方式；不能依赖旧会话能力或静默丢图。
2. 生成视频时把产品锚图和全部已选方向图按 Prompt 声明顺序附加。已选 Research 图不得只改写成风格词；未选候选不得传入。
3. Prompt 开头逐一声明 `@图片N` 的正向贡献和禁止迁移内容；后续镜头共同继承 `Brand Direction Lock` 的成像、光色、材质、空间、运镜和节奏。
4. 若当前能力无法同时接收产品锚图和全部已选方向图，停止生成并说明能力限制，请用户缩减参考图或调整生成方案；不得默认丢掉任一张。

## 三段式高信息密度 Prompt

三段式只规定组织顺序，不代表把创意压缩成摘要。最终 Prompt 必须同时回答“拍什么、在哪里拍、怎么运动、何时变化、如何接下一镜、声音如何同步”。以下是信息覆盖要求，不固定镜头数量、镜头型号、色板或创意答案；未被用户锁定的维度由 LLM 自主选择。

### 一、参考素材与全局视觉 Bible

先逐项写清素材贡献与边界，明确产品身份始终以产品锚图为准；场景锚点不改变包装，故事板不覆盖产品事实，参考视频不带入原品牌。随后建立一段可被所有镜头继承的全局锁定：

- **产品身份**：外形、比例、颜色、材质、Logo 位置、关键部件和不可改变的识别点。
- **空间关系**：背景、地面关系、空间尺度、前景 / 中景 / 后景层次，以及产品与环境的相对位置。
- **光色与材质**：主光方向、阴影逻辑、高光和反射表现、粒子 / 液体 / 纸张 / 玻璃等材质的可见反馈。
- **影像语法**：景别与机位变化、焦点 / 景深规则、镜头运动速度、主运动方向和节奏曲线。
- **创意脊柱**：开场观看理由、产品证明、视觉高潮和 Hero 收束；每个卖点对应一个可观察事件。
- **声音基线**：旁白、环境声、动作音效是否存在，各自的时间关系、层级和情绪功能。
- **连续性红线**：禁止产品变形、部件漂移、颜色漂移、随机文字、无关主体，以及参考素材中的品牌身份迁移。屏幕可读文字采用白名单：只允许已确认创意文案和已核验输入素材中的原有文字；环境招牌、UI、伪 Logo、微文案和旁白额外词必须不可读或不存在。
- 对概念产品或未核验表面文字，额外禁止表盘、标签、包装和 UI 表面出现可读微文案、伪 Logo 或装饰性字串；只保留核验设计中的抽象标记或刻度。

### AdsQA 目标答案与证据映射（按需）

当 brief 模糊或需要加强说服力时，读取 [adsqa-target-answers.md](adsqa-target-answers.md)，在全局锁定之后补充五维目标答案：视觉概念、情绪、主题 / 核心信息、说服策略、受众。每一维写清 `required_evidence`、`failure_if_missing`、`priority`，再映射到具体产品动作、材质反馈、镜头事件、声音节点或逐字创意文案。每个 sequence 至少承担一个主答案和一条可观察证据；没有证据的答案不能进入 H3 Prompt。此表用于解决歧义和校验创意，不得编造产品主张、复制参考广告身份，也不能替代产品事实与素材来源核验。

### 二、核心创意与视觉脊柱

写明目标时长、画幅、产品重点、成片形态和一句视觉母题，并补充：

- 视觉母题如何转译成可见的空间、材质或动作事件；
- 产品卖点由什么物理证据、结构变化或环境反应来证明；
- 事件如何从铺垫进入加速、高潮，再减速回到 Hero 定版；
- 全片的镜头运动如何形成方向、速度或形状匹配；
- 旁白、关键词字体和声音如何服务事件，而不是填充空白。

视觉母题必须能统领镜头、材质、卖点和转场，例如“透明水膜逐层修护干燥材质，最终凝成稳定产品屏障”，但不得把这个例子当成固定答案。

### 三、逐镜头可执行描述

按时间推进写独立镜头块。镜头数量和时间分配由 LLM 根据卖点、节奏和模型能力决定；每个镜头至少覆盖以下维度：

1. **时间范围 / 叙事目的**：说明本镜头带来的新信息，不只写“展示产品”。
2. **Scene**：环境、主体状态、空间层次和产品摆位。
3. **Framing**：景别、机位、视角、焦点、景深和主体在画面中的占比。
4. **Camera**：起点 → 运动路径 → 终点，包含方向、速度、加速度、停顿或焦点转移。
5. **Action**：主体的旋转、位移、展开、受力、交互或材质动作；同时写清动作方向和结束状态。
6. **Material / Light**：材质如何变化，光线、高光、反射、粒子或环境如何对动作做出可见反馈。
7. **Transition**：入镜承接、出镜触发，以及与下一镜头的形状、运动、遮挡、光线或材质匹配关系；禁止只写“流畅转场”。
8. **Audio**：对应的旁白精确片段、环境声、动作音效和相对混音层级；没有旁白时明确写纯声音设计。
9. **Typography**：引用已确认的广告文案单元或 `Copy Lock` 文本，写明 `copy_id`、角色、艺术字体方向、空间位置、入场、停留、退场、透视和遮挡关系；文字要参与当前镜头的视觉事件，不能退化为底部字幕。逐字创意文案必须交给 H3 在生成阶段直接渲染；真实 Logo、字标、包装文字和法律标签只保留输入素材中已有的核验内容。
10. **End State**：镜头结束时产品、镜头和运动处于什么稳定状态，供下一个镜头匹配或供该 sequence 独立收束。

镜头之间必须显式写出承接关系。上一镜头的出镜动作、遮挡物、光斑、形状、焦点或运动惯性，应成为下一镜头的入场理由；不能只在全局写一个“自然衔接”。每个 sequence 继承全局锁定，但最终送给 H3 的 Prompt 必须自包含地重复共享锁定与本段完整事件，不依赖上一段输出或另一段 Prompt。

## H3 单通道与防压缩检查

屏幕文字只允许一个渲染通道：

- **H3 视觉 / 原生声音 Prompt**：参考素材贡献、全局锁定、当前镜头块、`Typography Lock` 的逐字创意文案与艺术字体渲染指令、旁白 / 环境声 / 动作声和针对性负向约束。创意文案 / 关键词必须在 H3 生成阶段直接以清晰、稳定、符合品牌调性的字形出现；Prompt 必须明确禁止改写、翻译、打乱、遗漏、乱码或随机替代，并写出文字与主体的构图、材质、透视、遮挡、安全区和运动关系。真实 Logo、字标、包装文字和法律标签属于受保护身份资产，不能要求 H3 重绘，只能保留输入素材中已经存在且经过核验的内容。
- 禁止使用 `ffmpeg`、OmniAiLab 画布 原生合成或其它后期步骤加字、补字、换字、修字或覆盖 H3 生成的文字。H3 艺术字体失败时必须标记当前生成失败，提出定向修正或创意调整，并在用户重新授权后才生成，不能以合成结果冒充生成结果。

## 广告文案与艺术字体包装编译

在逐镜编译前先完成一次广告文案与字体艺术指导。目标是让成片具备广告成品的信息层和视觉层，而不是把 CTA 作为最后一行字幕补上。

### LLM 文案分析

- LLM 读取已核验产品事实、用户 brief、受众、投放平台、旁白意图和 `Brand Direction Lock`，判断当前广告真正需要哪些信息角色；按创意选择 hook、benefit / proof、product name、brand close、CTA、legal 等单元，不固定数量，也不要求每条广告都塞满全部角色。
- 用户或官方提供的精确文本保持原文；没有精确文本时，LLM 只能基于已核验事实写出短、可读、可视化的创意提案，并标记 `creative_proposal`，在生成前确认中让用户确认后才进入 `Copy Lock`。
- 每个文案单元都必须绑定一个产品证据、动作结果、材质变化、空间揭示或品牌收束；如果一句话无法对应可见事件，就删掉或改写，不用文案填充空镜头。

### 艺术字体方向

- 为每个已确认文案单元编译字体角色、字形骨架 / 字重、材质与颜色、空间平面、尺度、透视、与产品的前后层级、遮挡方式、入场—停留—退场和转场承接。
- 文字优先作为场景中的平面、体块、投影、反射、轨道、纸张 / 玻璃或其它与当前视觉母题一致的载体；光带只有在品牌方向明确支持线性扫描时才可选。只在用户明确要求字幕时才使用底部字幕排版。一个文字事件只选一种主要揭示机制，先完整可读，再允许局部遮挡、缩放或材质响应。若材质或背景偏暗、纹理复杂，必须用受控边缘高光、明度分离或干净留白维持整句最低局部对比度，不得用字幕框或后期叠字补救。
- H3 Prompt 必须写入 `Typography Lock` 的逐字文本，并要求 H3 在视频生成阶段完成准确、稳定、可读且符合品牌调性的字形渲染；同时写清背景明度、负空间和镜头如何穿过 / 环绕 / 遮挡文字。不得只写文字 staging 后再把创意文案交给后期。
- CTA 通常在最后一个 Hero / end card 完整可读，也可在中段作为空间文字参与卖点证明；不让 CTA 只在最后一帧闪现，不让产品或特效完全遮住 CTA。

### Typography Treatment Card 转译

将每张字体处理卡逐项展开到对应镜头，而不是把它压成“艺术字体”一个形容词：

1. 先写逐字文本、角色和品牌理由，再决定字形轮廓、字宽 / 字重 / 字距和笔画对比；品牌调性要能从这些选择中被看见。
2. 指定一个主要物理机制（投影、蚀刻、透明薄膜、纸张体积、空间字块、折射或结构展开；光带仅在明确选择线性扫描时可用）和最多一个辅助材质反馈，并说明它如何由产品动作触发。禁止无关的字幕框、UI 标签、辉光、粒子、贴纸或装饰堆叠。
3. 写清入场触发、完整读字停留、退场触发、透视 / 景深 / 遮挡关系和安全区。完整词组先稳定可读，再允许轻微运动或局部遮挡；不以闪现、持续抖动或复杂变形替代可读停留。
4. 若逐字准确、跨帧稳定、品牌调性或产品动作关联任一项不成立，判定字体门失败。准备只针对字体处理的修正，复用完全相同的产品、镜头、声音和其它 Prompt 字段，并在用户重新授权后生成；不可用后期合成补救。

### 运动机制选择与反模板

在写入每个镜头的转场和文字动作前，至少比较三种可用的运动机制，依据产品动作、材质证据、品牌方向和镜头空间选择一种，并记录选择理由与产品触发点。光带、横向扫光、扫描线揭示和镜头光晕擦屏都是条件机制，不得默认；如果 brief 或 `Brand Direction Lock` 没有明确支持线性扫描，就排除这些机制，改用投影、蚀刻、折射、结构展开、阴影几何、前景实体遮挡或材质表面显现。未明确选择线性扫描时，最终 Prompt 必须加入针对性约束：禁止通用横向扫光、扫描线写字、镜头光晕擦屏和光带写字。

未明确选择线性扫描时，光带、扫光、扫描线和镜头光晕擦屏不得被写成文字的入场、转场或产品触发，即使被列为辅助反馈也不得例外。高光只能作为已有产品表面的材质反馈，不能让文字出现、写入、擦屏或横向带过画面；文字应由材质显现、实体遮挡、焦点 / 形状匹配、投影、结构展开、折射、阴影几何或静止揭示承担。

多 sequence 广告为每个 sequence 记录一个运动机制，并在产品节拍变化时切换机制；不要让多个文字事件重复相同的方向性扫光、擦镜或扫描。若同一机制确实贯穿全片，必须说明它是品牌核心视觉语法，而不是默认模板。

### Copy Lock

文案是广告交付的一等信息层。创意文案必须随 H3 Prompt 在生成阶段直接渲染；不存在后期文字通道：

```text
Copy Lock
- brand_mark: <exact text | source | language | role>
- product_name: <exact text | source | language | role>
- benefit_line: <exact text | source | language | role>
- keyword: <exact text | source | language | related visual beat>
- cta: <exact text | source | language | placement | time window | mandatory=true>
- legal: <exact text | source | language | readable area | optional/mandatory>
- status: <source_verified | user_confirmed | creative_proposal_pending>
- render_channel: h3_native_typography
- typography_lock: <exact text | brand-tone rationale | glyph skeleton / weight | material / color | plane / depth | entrance -> dwell -> exit | occlusion | safe area>
```

- 文案角色可以按项目取舍，但已确认创意文案必须在 H3 Prompt 中逐字出现并在生成视频中渲染。Logo / 标准字和法律信息只能保留输入素材中已核验的原有内容，不能重绘，也不能后期添加。“无字幕”只表示不生成未经确认的整句字幕，不得把已确认创意文案静默改成后期文字。
- 若用户确认“不要文字”，在 `Copy Lock` 中显式记录 `copy_mode: none`，避免下游再次猜测；否则产品主角广告默认至少提出一组广告文案与字体方向供确认。

## Prompt 完整性与防缩写检查

- 每个最终视频产物只允许一条自包含 Prompt；送给 H3 的字符串必须与生成前记录的编译稿逐字一致。不得缩短、摘要、改写、翻译、调序或在调用工具前静默润色。
- 禁止使用“同上”“同 Sequence 1”“沿用前文”“等等”、省略号、未解析占位符、隐藏 reference 指针或只有风格形容词的摘要。每个 sequence 都必须重复产品身份、Brand Direction Lock、Typography Lock、声音基线、连续性红线和本段完整时间码。
- 逐字核对：Prompt 中每一条创意文案都必须与 `Copy Lock` 一致；每个镜头必须具备 Scene、Framing、Camera 起点→路径→终点、Action、Material / Light、Transition、Audio、Typography、End State。缺任一项就不得调用 H3。
- 生成后禁止用任何后期叠字替代创意文案的 H3 渲染结果，也不得以受保护资产为理由恢复 `ffmpeg` 文字合成。

## LLM 视觉质量语言编译

高收益词汇不作为固定枚举表或套用清单。LLM 必须从当前 brief、已选参考、产品材质和品牌方向中分析“为什么案例画面有效”，再把分析结果写成当前 Prompt 的自然语言。

1. 先识别本案最需要增强的可观察机制：例如主体的材质证据、空间层次、光线反馈、镜头的速度 / 焦点、文字与主体的关系或声音与动作的同步；不要从抽象形容词直接跳到关键词。
2. 对每个机制完成“来源观察 → 可见 / 可听行为 → Prompt 表述”的转译。Prompt 表述要写明发生在哪里、由什么触发、如何变化、镜头如何看见以及结束时稳定到什么状态。
3. 只把真正服务创意的表述放入全局 Visual Bible、对应镜头和转场；同一个词如果无法对应产品动作、材质反应、摄影行为或声音事件，就删掉或重写。
4. 从案例中学习信息密度、光材质反馈、微距与远景反差、前景遮挡、运动匹配、空间字体和声音卡点等方法，但不复制案例的品牌、主体、固定色板、镜头顺序或整句 Prompt。
5. 负向约束也由 LLM 根据当前产品和视觉方向推导，只保留会破坏身份、材质、可读性、空间层级或广告质感的失败模式；不能用长串通用 negative prompt 替代正向的主体、动作、材质和转场描述。

执行前检查最终 Prompt 是否具备：

- 全局产品、空间、光色、材质和连续性锁定；
- 每个镜头的景别 / 机位、起点 / 路径 / 终点和主体动作；
- 每个镜头至少一个可观察的材质、光线或环境反馈；
- 镜头之间具体的转场触发和运动 / 形状承接；
- 声音层与画面事件的同步关系；
- 需要文字时，广告文案单元与 `Typography Lock` 已绑定到具体镜头，逐字创意文案和品牌调性渲染指令已写入 H3 Prompt；不存在后期文字说明。明确无文字时记录 `copy_mode: none`。
- 视觉质量语言是否来自当前案例 / brief 的机制分析，并已写入对应的画面、光材质、运镜或转场，而不是孤立关键词。

如果最终 Prompt 只剩“风格形容词 + 产品慢慢旋转 + 几个特写”，或出现任何缩写 / 占位 / “同上”，必须回写缺失字段后才能启动 H3 生成。字段是质量底线，不是限制 LLM 发散的固定分镜模板。

## 长片分段编译

- 单次能力足够且能完整承载已确认节拍时按完整目标时长生成；不足时依据完整动作、转场和稳定承接状态划分有序 `sequence`，调用数量服从成片质量与连续性。
- 每个 sequence 都使用同一产品锚图、已选方向参考和品牌约束；`sequence: 1` 负责开场，其余 sequence 只写自己的局部 beat，不重新定义品牌/产品身份或无依据引入新主体。
- 多 sequence 成片的 `sequence: 1` 要在前 1.5 秒以足够比例给出实体且可识别的产品身份或已核验锚点，并在 3–4 秒内保持可见或有明确因果存在；倒影、剪影、手机、人物或抽象光线不能单独算作开场证明。抽象氛围只能在这次实体证明之后作为压力展开。
- 独立 sequence 通过共享产品外观、Logo 位置、包装结构、光色、镜头方向和创意脊柱保持可拼接性，并可并发提交；连续性敏感 sequence 只在方案已声明时使用上一段已批准的边界帧或锚点，并保持顺序。
- 每段末尾写成支持已确认剪辑或连续性衔接的状态，完成后按批准的镜头顺序与转场组装终剪。不得只为对齐目标秒数而裁切、补帧、循环或变速；任何失败或主体漂移只把对应片段列为重生成候选，不回滚整条链，也不在用户重新授权前提交。
- H3 Prompt 排除独立 BGM 和未经确认的整句字幕，但必须包含已确认创意文案的逐字文本、`Typography Lock`、品牌调性、透视、材质、遮挡和运动关系，并在生成阶段直接渲染艺术字体；真实 Logo、字标、包装文字和法律信息只保留输入素材中已核验的原有内容，不做后期文字合成。按确认的声音方案保留 H3 原生旁白、环境声和动作音效；需要广告文案、旁白关键词或艺术字体包装时，读取 [voice-keyword-typography.md](voice-keyword-typography.md)。独立 BGM 只能在用户确认后生成和混音。

## 并发批次编译

当一次请求包含多个视频 work items 时，先区分独立镜头与连续性依赖镜头。独立镜头可并发、互不消费同批输出，并由共享产品锚点和品牌方向锁保持连续性；执行窗口以当前能力上限为准，结果仍按已确认顺序进入终剪。

- 所有共享产品/品牌 refs 已就绪后，独立 sequence 才进入并发批次；连续性敏感 sequence 按依赖顺序单独编排。
- 只有连续性方案明确要求时才提取和使用前序边界帧；不得为本可独立的镜头制造串行依赖。
- 执行器按能力窗口滑动补位，结果落盘后按 `sequence` 与已确认剪辑方案排序；只在失败会改变后续连续性时追加用户确认。

## 节奏与转场

| 成片形态 | 事件密度 | 主要转场机制 |
| --- | --- | --- |
| 高端品牌定版 | 5–7 个事件 | 透明介质遮挡、焦点转移、材质显现、结构展开、定版减速；光扫仅在品牌方向明确支持线性扫描时使用 |
| 材质氛围 | 5–7 个事件 | 液体慢流、水膜、丝绸、折射、微距焦点变化 |
| 新品发布揭示 | 5–8 个事件 | 暗场显现、结构展开、形状匹配、局部折射、逐步加速；扫描仅限明确的系统视觉方向 |
| 卖点视觉解释 | 每个卖点一个事件 | 功能光环、成分流动、细线标注、结构层切换 |
| 社媒快节奏 | 8–10 个事件 | 前景擦镜、液体 wipe、包装弹跳、图案闪切、冲击硬切 |

转场必须由产品、材质、成分、光线、文字或图形自然触发。动作曲线与节拍一致；快切瞬间短促明确，最终 Hero 定版突然减速并稳定。

### 常用转场语义

- **液体遮挡**：液体或水膜掠过镜头并从纹理中揭示下一事件。
- **前景擦镜**：与产品相关的结构件、配料或包装高速掠过前景完成遮挡。
- **形状匹配**：前一事件的几何形态精确衔接产品轮廓、部件或包装图案。
- **结构展开**：产品部件沿清晰轴线拆解，再在下一事件回收到完整结构。
- **图形冲击**：一次短标题、色块或图案在节拍点形成记忆点，并让产品从信息层穿出。
- **材质呼吸**：光线、水膜、丝绸、玻璃或焦外高光完成柔性过渡。

## 文字记忆点

中段记忆点不等于固定大花字：

- 高端定版和材质氛围使用材质高潮、留白或极短品牌词组。
- 新品揭示可用克制的空间文字或半透明无衬线字。
- 卖点解释使用一个短标题、轻量标注或图形符号。
- 社媒快节奏可使用一次大字冲击，但不得遮挡产品识别面或生成额外随机文字。

广告成品的文字包装由 LLM 根据当前创意决定：可将文案嵌入真实平面、透明介质、材质表面、空间体块或镜头运动路径，让文字参与揭示、遮挡、匹配切换和 Hero 收束；若品牌方向明确支持线性扫描，才可把光带作为文字载体，否则不使用，不默认套用某一种字体、颜色、位置或动效模板。

精确 Logo、包装文字、CTA 和法律信息只保留输入素材中已核验的原有内容；不得通过 OmniAiLab 画布 原生合成或其它后期步骤新增文字。创意文案和艺术字体统一由 H3 在视频生成阶段完成。

## 声音方向

以下音乐类描述只作为节奏或音色启发；独立 BGM 仅在用户确认后生成，最终声音按确认方案包含旁白、环境声、动作音效和音乐。

- 食品饮料：节拍音乐、液体/气泡/酥脆声、包装动作声和短促品牌收束音。
- 护肤香氛：轻柔音乐、水滴、玻璃/水膜、织物轻响和克制品牌提示音。
- 科技硬件：低频脉冲、金属触感、能量流与精准提示音；扫描仅在品牌方向明确支持线性系统语法时使用。
- 生活方式：自然环境、轻柔触碰和温和背景音乐。

声音与画面事件同步。旁白由视频生成承接：存在已确认旁白时，把精确文案、语言、旁白身份与声线、语气语速和起止时间写入对应 MiniMax H3 Prompt，与画面、环境声和动作声同步生成；不另建独立 TTS 或重复旁白声轨。独立 BGM 按确认的声音方案决定；用户未指定旁白时，在创意确认中提出旁白或纯声音设计方案，不静默按无旁白处理；用户明确静音时不生成声音。

### Voice Continuity Lock（多段旁白）

多段分段使用同一份 Voice Continuity Lock：

- `narrator_identity`：同一语言、年龄感、音色、性别呈现和表演关系；
- `recording_perspective`：同一收音距离、空间反射和近远层级，不在片段边界突然换房间；
- `delivery`：语速范围、停顿、呼吸位置、重音和情绪弧线；旁白完整表达，不把每句变成屏幕字幕；
- `sequence_handoff`：每段精确的开头句 / 结尾句、承接动作和环境声尾音；前段不得截断，后段不得重复、自我介绍或换声；
- `mix`：旁白相对环境声与动作声的稳定响度关系，禁止段间突然压低、爆音或加入未确认音乐床。

每个 sequence 的 Prompt 都要完整展开这份锁定与本段精确旁白片段；生成后检查声线、语速、呼吸、响度和句子边界是否跨段连续。失败时只为受影响的旁白 / sequence 准备修正，不改写产品、镜头、艺术字或其它 Prompt 字段；取得新的生成授权后才提交。

### 生成设置稳态校验

提交前把模型、时长、画幅、参考素材、声音和其它设置与当前能力摘要逐项比对，只发送当前支持的设置。若模型拒绝某项设置，只有系统明确确认任务未受理且未扣积分时才可删除该项后自动重提；否则先重新请求生成授权。完整编译 Prompt、时长意图、画幅、声音、旁白、文案和艺术字体字段必须逐字保留，不得借机缩写或改写创意。

## 生成前检查

1. 产品锚图是否足以锁定身份，所有参考素材职责是否明确？
2. 视觉母题是否围绕产品和一个核心卖点展开？
3. 每个事件是否只有一个主要变化，并有明确转场机制？
4. 产品、包装、Logo、标签、比例和材质是否保持一致？
5. `Copy Lock` 是否完整，创意文案是否逐字写入 H3 Prompt 并在生成阶段渲染，CTA / Logo / 法律信息是否仅来自输入素材且未被后期新增？
6. 声音是否与动作和节拍同步，没有重复声轨？
7. 最后两秒是否回到完整、清晰、稳定的 Hero 定版？
8. 复杂度、参考数量和时长是否符合当前能力摘要？
9. 每张 `Typography Treatment Card` 是否已展开到对应镜头，且通过逐字准确、跨帧稳定、品牌关联和完整读字停留四项检查？
10. 开场抽样帧是否在 1.5 秒内展示足够比例的真实产品 / 已核验锚点，并且整个成片没有白名单之外的可读文字？
