# 产品广告视觉技法

仅在“产品主角广告”路线需要生成场景锚点、关键帧或故事板时读取。一次选择 2–4 项与产品卖点直接相关的技法，并转译成空间、材质、光影或画面事件；不要把整库复制进 Prompt。

## 选择方法

| 产品方向 | 优先技法 |
| --- | --- |
| 食品、零食、饮料、酒饮 | 成分与流体、材质微距、冻结运动、口味色彩 |
| 护肤、美妆、香氛、珠宝 | 透明介质、折射、材质证据、克制留白 |
| 科技硬件、耳机、手表、智能设备 | 产品构图、结构拆解、功能光环、精密轮廓光 |
| 多 SKU、多口味、多颜色 | 序列构图、色块分区、包装矩阵、图形信息层 |
| 家居、日用品、生活方式产品 | 真实使用空间、触感微距、自然光影、产品纪念碑化 |

视觉锚点只负责审美时，保持无产品包装、无品牌 Logo、无可读文字；产品身份始终由产品锚图提供。

## 技法库

### 透明介质与折射

使用透明玻璃、亚克力、水膜、棱镜、焦散光或内部微泡建立空间层次。适合护肤、香氛、珠宝与轻奢科技；将折射设计成掠过、包裹或揭示动作，而不是静态装饰。

### 产品构图与摆位

按卖点选择中心 Hero、低角度纪念碑、对角悬浮、三位一体 packshot、扇形多 SKU、俯视矩阵或零重力序列。构图必须持续保留产品完整轮廓和识别面。

### 科技解构与功能可视化

通过横向/纵向爆炸图、半透明剖切、发光部件、信号轨迹、气流、声波或轻量技术标注解释一个功能。每次拆解必须能回收到原产品结构，不引入第二产品身份。

### 成分、口味与流体

使用高速液体冻结、配料轨道、微距截面、泡沫、冰块、碎屑或能量流把成分和口感转成可见事件。配料从产品卖点出发，并在高潮后向包装或 Hero 定版收束。

### 材质证据微距

选择真正能证明产品价值的局部：金属切边、玻璃反射、镜片镀膜、皮革缝线、磨砂/镜面对比、冷凝水珠、凹凸字或包装肌理。微距后必须回到完整产品，避免只剩抽象材质。

### 光影与背景空间

可使用暗场轮廓光、圆形背光、高调柔光、窗影、体积光、镜面空间、工业混凝土或丝绸褶皱。光线承担揭示、聚焦或转场功能，背景只服务产品层级。

### 图形与文字信息层

按成片形态选择色块、短标题、轻量技术标注、半透明空间文字或包装图案。高端定版保持极简；卖点解释使用短标注；社媒快节奏才使用一次高冲击大字记忆点。

### 色彩结构

从产品与品牌事实提取主色、辅助色和一次点睛色。科技产品可用冷暗底与精准亮色；快消可用口味色块；轻奢可用低饱和同色域与高光材质。不要用风格色覆盖真实包装色。

## 广告审美放大器

从以下概念中选择 1–2 个作为构图和运动原则：

- **Product as Monument**：低视角、稳定轮廓与可控留白，让产品具有纪念碑感。
- **Material Proof Macro**：用微距材质作为卖点证据，并回切完整产品。
- **Functional Aura**：将功能转成环绕产品的光、流体、声波或保护层。
- **Product-World Portal**：让产品结构或屏幕成为进入视觉世界的入口。
- **Ingredient Orbit**：让成分沿产品轨道运动并最终收束。
- **Motion-Freeze Composition**：在高速事件的清晰冻结瞬间建立记忆点。
- **Packshot Trinity**：产品、包装和关键配件形成三点稳定定版。
- **Controlled Negative Space**：通过克制留白强化高端感与文字可读区。

## 晶体仿生奢华

适用于高端护肤、香氛、珠宝、轻奢美妆、柔性科技或生物科技概念；不作为食品、强促销或工业硬件的默认方向。

使用透明晶体外壳、液态金属边缘、内部微泡、晶体颗粒、星芒高光和羽毛/蝴蝶/水母般的轻盈仿生结构，构成暗场负空间与高折射焦散。动态编译时让晶体结构缓慢环绕产品，微泡和颗粒沿轮廓漂浮，前景水膜或仿生结构完成柔性遮挡，最终所有元素向产品收束形成 Hero 定版。

## 故事板落位

把选定技法分配到 5–9 个视觉事件：开场钩子 → 产品局部 → 完整出现 → 材质/成分/功能证明 → 中段记忆点 → 高潮 → Hero 定版。相邻事件预留可执行的遮挡物、形状、光线或材质变化，供视频阶段编译转场。
