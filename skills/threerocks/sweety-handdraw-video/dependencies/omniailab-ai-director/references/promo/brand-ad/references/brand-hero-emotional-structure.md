# 品牌 Hero 情绪结构参考

在 `brand-ad` 承接品牌 Hero Film、剧情 TVC、宏观前置设定、情绪推进或高密度镜头提案时按需读取。本卡是可选的创意组织参考；简单广告保持短链路，复杂 TVC 可把脚本、分镜、连续性锚点和终剪设为用户可见的评审里程碑。

## 三条创作红线

1. 除非用户明确要求产品直出，否则不要在第 1 秒就让产品孤立旋转占满画面；先用环境、状态或动作建立观看理由。
2. 不用满屏解释性促销字幕替代视觉表达；精确 Logo、包装文字、CTA 和法律信息仍只来自用户 / 官方来源，并按主 Skill 规则处理。
3. 不安排没有剧情支撑的夸张表演、喊叫或生硬笑脸；动作应服务人物状态、产品卖点或品牌情绪。

以上是可选的创意质量门槛，不覆盖用户已锁定的脚本、分镜或产品直拍意图。

## 五阶段情绪骨架（可变）

中等时长创意提案可参考以下推进关系：

1. **环境铺垫**：先建立空间、气候、声音或陌生感。
2. **人物 / 使用状态**：通过姿态、微表情或操作建立观看者的身份想象。
3. **精神图腾 / 可见隐喻**：用自然力量、动物、材质或空间变化承载抽象卖点。
4. **产品暗示**：先让材质、局部结构、色彩或动作露出产品线索。
5. **正式亮相与收束**：产品完整出现，完成 Hero 定版和品牌情绪回收。

这只是情绪曲线，不是固定时间码、固定产品露出时间或必须执行的五段结构。目标时长用于规划；多段生成时按主 Skill 判断独立镜头与连续性依赖，完成已确认终剪，不为凑名义时长裁切、补帧、循环或变速。

## 镜头密度与反差

- 需要 TVC 提案感时，可按目标时长先估算视觉事件，再根据卖点、H3 能力和实际生成结果调整；不把镜头数量写成硬约束。
- 交替使用环境远景、人物状态、中景、产品微距和极近特写，避免一个景别或一个场景从头拍到尾。
- 由极端景别反差、焦点切换、材质转化、遮挡或运动方向变化制造张力；不要用随机快切遮盖主体不稳定。
- 每个镜头 / 事件写清景别、运镜、主体动作、环境细节、光影、材质、起止状态和同步声音。落到 H3 Prompt 时按所选路线的单段主要变化原则装箱。

## 宏观前置设定

在生成首张图或首段视频前，先形成两段可复用设定：

- **整体氛围**：影像媒介、主色关系、打光逻辑、材质质感和现实 / 幻想边界。
- **主角 / 产品连续性**：外观、轮廓、包装结构、品牌识别、材质、人物服装 / 配饰与情绪气场。

后续事件只追加当前动作和局部变化，不重复改写身份事实；同一长片的所有 `sequence` 共享产品锚图、品牌方向、连续性圣经和创意脊柱。独立镜头不消费同批其它片段的输出，连续性敏感镜头只使用方案中已批准的前序边界帧或锚点。

## 交付前检查

1. **产品高潮**：完整产品是否在后段或用户指定位置出现，前期铺垫是否服务它？
2. **一致性**：产品 / 包装、人物、风格、天气、光线和运动方向是否连续？
3. **镜头语言**：是否有有效的远近景反差、角度变化和明确运动，而非随机炫技？
4. **去套路**：是否删掉无意义的促销字、陈词滥调和没有动机的夸张表演？
5. **商业识别**：创意概念、产品卖点和品牌收束是否能被看懂，但没有扩写未经证实的品牌事实？

主体 / 产品、复杂多场景连续性、脚本评审或系列交付成为核心需求时，继续由 `brand-ad` 的剧情 / 系列 TVC 路线承接，并启用连续性圣经、评审里程碑和终剪质量门。
