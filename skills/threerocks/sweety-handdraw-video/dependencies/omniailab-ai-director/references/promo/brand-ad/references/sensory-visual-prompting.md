# 通感视觉与提示词架构参考

仅在 `brand-ad` 需要把简短 brief 扩写为更具电影感、可执行的视觉概念和视频 Prompt 时按需读取。本卡是创意发散与 Prompt 质检参考，不是新的用户可见路线、Stage 或固定输出模板；最终视频字段、素材职责、模型能力和声音规则仍以主 Skill 及所选路线为准。

## 适用边界

- 适合把味觉、触感、性能、情绪或品牌态度转译为可见的环境、物理现象、材质反应或空间隐喻。
- 适合 brief 过于抽象、需要建立镜头反差或需要把创意概念编译成可拍摄提示词的任务。
- 不替代 `product-motion.md` 的路线选择，不把电影感术语强行塞进每条广告；简单单条广告仍可直接生成。
- 不改写产品、品牌、受众、核心卖点、已确认文案、Logo、包装文字或用户明确的画幅 / 时长。

## 创意转译方法

1. **内核剥离**：先写清产品、核心卖点、受众欲望、隐含冲突和情绪终点。
2. **视觉化卖点**：把抽象卖点转成具体可见的环境变化、物理反馈、材质细节或空间关系，不停留在“震撼 / 唯美 / 高级”等形容词。
3. **动态叙事张力**：有意识地比较小与大、静与动、现实与幻想、局部与整体等反差，但只保留服务品牌表达的一到两种。
4. **镜头推演**：为每个事件写清主体起点、动作路径、终点、镜头运动、光线变化、材质反馈、转场触发和同步声音。
5. **可执行性检查**：确认主体身份、包装结构、品牌文字、动作方向、时序和声音规则没有互相冲突。

## 视觉词汇的使用原则

可从下列方向选择少量真正服务创意的描述：

- 镜头：微距探针、超广角、浅景深、移轴或分视场等具体成像方式。
- 运镜：低机位跟拍、机械臂推进、FPV 穿越、甩镜或焦点转移等可见运动。
- 光影：体积光、硬调侧逆光、轮廓光、遮片光或局部反射等明确光源关系。
- 材质与媒介：纸纤维、包装膜、液体、玻璃、金属、织物、颗粒、胶片颗粒等触觉证据。

不要堆砌设备名、镜头型号、调色预设或渲染参数。它们只作为 Prompt 的描述词，不得替代执行前的能力核验或产品身份锁。

## Prompt 架构检查表

在编译视频 Prompt 前，可用以下顺序组织一段完整描述：

```text
主体与产品事实 + 环境与空间关系 + 光影与材质 + 景别与运镜 + 主体动作与起止状态 + 转场触发 + 同步声音 + 必须保留 / 禁止迁移的内容
```

- 每段只突出一个主要变化，避免同一 Prompt 同时要求多个互相竞争的高潮。
- 产品锚图、Logo、包装和已确认故事板的事实优先；参考图只贡献已经声明的光影、构图、材质或氛围。
- 文字、旁白、CTA 和片尾信息只有在用户需要或已确认时写入；不凭空增加促销信息。
- 不在 Prompt 正文写“生成 N 个结果”等执行数量要求；每个最终交付物对应一个独立的可执行描述。
- 需要落到 H3 时，继续遵循 `product-h3-compile.md` 的三段式 Prompt、真实参考顺序和原生声音约束。

## 导演自检

- 核心卖点是否被一个清晰、可见的物理或空间事件表达？
- 镜头是否有足够的景别 / 动静反差，但没有为炫技牺牲产品可读性？
- 产品和包装在动作前后是否仍保持同一身份与比例？
- 光线、材质、声音和动作是否共同服务情绪终点？
- 是否误把参考图的品牌、人物、文字、剧情或具体构图迁移进了创意？
