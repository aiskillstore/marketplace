# 产品事实与 Reference 路由

> **触发**：收到产品图、模特图、网页截图或其它来源素材后，任何生成之前必读。

本阶段只回答三件事：什么是可靠事实；现有素材分别能锁定什么；还缺什么会导致废片。它不负责设计 Hook、人设或生活方式场景。

## 1. 建立事实边界

对每个来源 ref 做一次完整的画面与质量检查，内部记录：

- 产品类别、主体数量、可见状态和技术质量。
- 清楚可见的整体轮廓、结构、文字、logo 与使用关系。
- 是否存在可靠的人体、手、桌面或空间尺度参照。
- 哪些部分被遮挡、模糊、无法确认或只是一种推测。
- 该素材适合承担产品身份、结构细节、人物身份、穿戴比例、场景气质中的哪些职责。

用户输入与来源素材是事实来源。看图分析用于判断风险和路由，不把它改写成下游 prompt 的产品外观清单，也不推断价格、容量、功效、销量、口碑或购买入口。

## 2. 原图优先承担产品事实

清晰、单主体、无遮挡的产品图即使是白底图，也可以直接进入 image 或 video refs 锁定产品外观。白底只说明拍摄背景，不说明产品图不可用。

只有满足以下任一条件时才生成额外锚：

- 需要建立可信的人体穿戴、手持或空间尺度关系，且已有足够尺度证据。
- 原图的角度、遮挡或清晰度不足以支持本条视频需要展示的关系。
- 内容确实需要一张经用户确认的人物锚或试穿创作者锚来保持跨 clip 一致。

需要生成时，KOC 默认使用 image-generation model 并传 `quality: medium`；用户明确指定图片模型、质量或参数时覆盖这一默认值。

不要为了“生活化”把清晰产品图先改成一张 AI 场景图。生成图不能反向证明产品真实结构和尺寸，也不替代原始产品 ref。

## 3. 按风险补最小证据

结构、尺寸或穿戴关系会明显影响可信度时，检查现有素材是否已有对应证据：

- 结构复杂：需要能看清本条内容涉及的角度、开合或连接关系。
- 尺度敏感：需要 verified 尺寸，或产品与手、身体、家具、房间之间的真实参照。
- 穿戴敏感：需要佩戴位置、垂坠、松紧或身体占比的可靠依据。
- 准确文字重要：原图承担文字与 logo 的真相；视频模型不负责生成可读文字。

证据不足且会改变画面时，在第一次 Question 中只问最小缺口：优先请用户补真实上身、手持或使用图；其次问实际尺寸、尺码或迷你 / 标准 / 大号等相对关系。低风险产品不额外追问。

没有尺度证据时，不生成试穿图、产品资料卡或多视角板来猜真实大小。拿到数字后，将它转成当前画面需要的相对关系，不把厘米数机械塞进 prompt。

## 4. Reference 职责

每张 ref 只承担它能可靠提供的职责：

| Ref | 主要职责 |
|---|---|
| 清晰产品原图 | 产品身份、整体轮廓、可见结构、logo 与包装 |
| 真实上身 / 使用图 | 人体关系、尺度、佩戴或使用状态 |
| 已确认创作者锚 | 人物身份、造型、拍摄关系 |
| 已确认试穿创作者锚 | 同一人物身份 + 已证实的穿戴关系 |
| 结构 / 多视角参考 | 补充特定角度或结构；仅作 reference，不复现参考板布局 |

多视角、三视图或 sheet 只有在当前能力明确支持时才能作为真实参考加入，不能冒充首帧素材。提示词说明它只用于保持结构、比例或身份，不复现多宫格。

## 5. 阶段出口

进入创意阶段前，内部必须能回答：

1. 哪些产品事实可以说、可以演示。
2. 哪些信息未知，不能进入脚本。
3. 每张 ref 在后续承担什么职责。
4. 是否需要补问尺度或补充一张有明确用途的锚。

如果现有素材足够，直接推进；不要把完整分析过程念给用户。
