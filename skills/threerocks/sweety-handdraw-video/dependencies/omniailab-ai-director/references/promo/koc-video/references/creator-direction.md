# 创作者方向与角色资产

> **触发**：开场确认后，确定角色资产、拍摄关系并生成身份锚。

人物不是产品旁边的模特。每个角色资产都需要像一个在具体生活处境中有理由使用、评价、提问或回应产品的人。

## 0. 建立角色资产表

角色资产表是本条内容中需要保持身份的角色清单。每个角色资产有稳定 id、在内容中的关系和一张独立身份锚；分镜和 video prompt 只引用该表中的角色资产，不临时生成另一张脸，也不让一个资产承担两个身份。

## 1. 判断内容身份

- **UGC** 首先让人相信这是用户自己的记录：使用处境熟悉，拍摄介入较低，反应和动作可信。真实不等于故意拍土、拍乱或降低画质。
- **KOC / creator content** 在可信基础上，还能看出创作者在选品、造型、空间或拍摄视角上的选择。精致可以成立，但不能变成品牌替通用模特拍的广告。

两者共享同一生产流程，只在人物美术指导和拍摄关系上形成差异。

## 2. 把人设翻译成可见选择

不要停在“华裔妈妈、ins 博主、男生 KOC、职场女性、真实用户”等标签。结合产品、受众、城市与生活阶段、使用场景和内容主题，确定：

- 造型轮廓与色彩关系。
- 发型、妆容、配件或个人习惯中与本条人设有关的部分。
- 人物所在的具体空间，以及这一刻为何会被记录。
- 人物与镜头、拍摄者之间的关系。
- 能体现人物生活阶段和内容风格的自然状态。

不把族裔、性别、年龄或家庭身份直接绑定到固定服装和审美。人物具体性来自相互一致的生活选择，不来自人口标签堆叠。

以上内容共同构成角色方向，用于人设选择和后续分镜；它们不会全部进入人物锚。人物锚只提取各角色资产跨 clip 必须保持的视觉信息。

用 confirmation card 给用户 3 个能产生不同观看体验的人设候选，每个用 1–2 行写清角色关系、谁在什么情境表达、可见的画面气质和为什么可信。差异要与产品和受众有关，并落到不同的内容行为与记录关系；不能只换人物标签，却让三项共享同一套拍摄者、机位和动作逻辑。用户反馈或修改方向时重新收敛候选，选定后才生成角色资产的身份锚。

## 3. 选择拍摄关系

先确定观众需要看到什么证据，再确定谁最自然地拿相机、为什么此刻开始拍，最后写镜头质感。自拍、镜前记录、朋友跟拍、固定机位、桌面 POV、街访或其它方式都可以；选择来自当前内容行为和证明需要，不从产品品类或“UGC 感”直接套用。

自拍由拍摄者与镜头的关系决定，人物拿着手机不等于对镜自拍。镜面只有在人物通过反射完成检查、比较或表达，且这个行为对当前内容有意义时，才构成拍摄关系；展示人物或产品本身不需要自动借助镜面。

相机行为由拍摄关系自然推出。临时手持记录可以有轻微晃动、取景修正或曝光变化；朋友跟拍可以保留移动中的跟随感；固定机位不需要为了“真实”强行加入晃动。不要把同一组相机效果复制到所有人物锚和视频 prompt。

## 4. 生成身份锚

每张身份锚对应一个角色资产，不是故事首帧。从已确认的角色方向中，只提取后续每个 clip 都必须保持的视觉信息：该角色身份、稳定造型、内容气质和拍摄媒介。

生成该锚时默认使用 image-generation model 并传 `quality: medium`；用户明确指定图片模型、质量或参数时覆盖这一默认值。

画面可以处于与角色相符的自然环境，但保持低叙事状态，不承担当前 Hook、剧情事件或镜头起始状态。判断一个元素是否进入身份锚时，只问：换到另一个 clip 后，它是否仍必须完全相同？必须相同才进入锚图；当前动作、即时表情、产品关系、角色互动、可变道具状态、精确机位和构图留给具体分镜。

非穿戴产品生成身份锚时不传产品 ref。产品从具体视频 clip 开始进入，由产品原图传递外观。

只有穿戴产品需要锁定上身关系，或当前产品与人体关系必须跨 clip 保持时，才生成人物与产品合一的交互锚。只服务某个镜头的动作和场景属于当前 clip，不作为全片人物锚复用。产品外观由产品 ref 传递，不把看图分析改写成部件清单。

人物面部是清晰主体且存在过度精修风险时，可按画面需要使用 `natural skin texture with visible pores`、`subtle facial asymmetry` 等具体描述；它们是可调用的生成语言，不是每张图的固定尾缀。人物锚出现均匀磨皮、蜡像质感、广告模特站姿，或去掉标题后看不出生活阶段和内容风格时，不进入确认，先重生成。

角色资产的身份锚经用户认可后，在该角色出现的 clip 中复用。用户上传了适合的真人图且已明确它对应的角色资产时，直接使用，不再为该角色生成另一个人。

## 5. 穿戴类合一

服装、鞋、包、眼镜、首饰和穿戴设备需要同时建立人物身份与产品上身关系：

- Persona Question 直接给“人设 + 使用场景”，不先选抽象人设再另造试穿场景。
- 尺度证据不足时，先按 `source-routing.md` 补最小信息。
- 生成一张单一真人自然穿、背或佩戴产品的试穿创作者锚；它同时是后续唯一人物锚。
- Prompt 以人物、场景、姿态、穿戴关系和已确认尺度为主，产品结构由原始产品 ref 传递。
- 如果已有可用真人试穿图，优先把它作为人物锚，不再生成不同脸的博主。

锚图落画布后，用 confirmation card 提供“使用这组角色资产”“调整造型 / 拍摄方式”“更换人设 / 场景”等可行动选项。修改意见不是确认；改图后再次确认。

## 完成条件

- 去掉标题后，仍能识别每个角色资产的身份、生活阶段和内容风格。
- 每个角色资产有且只有一张身份锚；一张身份锚不承担多个角色资产。
- 锚图没有提前表演当前 Hook，也没有把某个镜头的动作、情绪、配角关系或场景状态变成跨 clip 必须复现的内容。
- UGC 可信但不故意粗糙；KOC 有选择但不成为品牌 campaign。
- 人物面部没有明显磨皮或蜡像感。
- 穿戴类只有一个真人锚，产品关系建立在已有尺度证据上。
