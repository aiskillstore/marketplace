# 规整生成蓝图

最终提示词按“项目 → 参考 → 创意 → 音乐/歌词/表演 → 视觉/字体 → 镜头 → 全局负面”排序。执行说明使用 `working_language`；生成的屏幕文案默认 English-only 英语包装，准确用户原文和必要术语保持原样。不在最终 prompt 中写白名单元数据。有人物的项目在写镜头前必须读取 `performance-and-space.md`，先完成动作族选择和空间路线，不能边写边重复临时动作。

编排 Agent 必须先完成并展示整段 prompt，不能把写作职责交给执行层。随后只进行一次视频生成，并把已展示的同一字符串原样交给执行层；只发送角色、风格、歌词和动作摘要属于失败。不要在编排层展开底层实现细节。

## 长度预算

H3 输入上限为 7000 字符；本 Skill 的业务硬范围是 5200–6800，安全目标 5700–6500。所有汉字、英文、路径、空格、标点和换行都计入。低于 5200 通常意味着执行层把完整提示词压成了摘要，必须拦截。

| 区块 | 目标上限 |
|---|---:|
| 项目、参考、核心创意 | 650 |
| 音乐、歌词、表演 | 1300 |
| 视觉与动态字体系统 | 1050 |
| 8–10 个镜头合计 | 3200 |
| 全局与负面约束 | 550 |

单镜控制在 270–350 字符，不逐镜重复全局材质、完整字体定义和角色锁定。增加信息时优先加入动作起点/发力/落点、镜头反馈、字体层运动和音乐节点；不要堆抽象形容词。草稿超限时先删除重复形容词，再合并全局规则和相邻镜头说明；不得删除真实参考、实际歌词、准确英文词、人物动作、TYPE LAYER STACK、节拍与角色一致性。无法精确计数时写 8 镜并以 5600 字符为目标。

## 固定结构

```text
【项目设置】
MiniMax H3，15 秒，16:9，复古潮流拼贴音乐短片，音乐与画面同步生成。

【参考素材说明】
真实素材路径与各自用途；缺失维度写 AI 原创。

【核心创意】
1–3 句写人物、空间冲突、音乐动作和拼贴主视觉。

【音乐、歌词与表演】
Music Prompt：曲风、BPM、拍号、groove、鼓组、3–4 音 808 走向、4–6 音问答 motif、声线或 instrumental only、rap flow/cadence、vocal layering、0–15 秒段落结构和明确结尾。
Vocal / lyric：原创 rap/K-pop hip-hop 按 Rap A1、Rap A2、Pre-hook、Hook 1、Hook 2、可选 Response/ad-lib、Final tag 写 5–7 行实际歌词；写清内押、尾押和 cadence 变化。BGM 写 no vocals, no lyrics。
人物表演：概括 5–7 个动作族、至少 4 个空间区段、空间借力/服装动作、静点和嘴型/呼吸/眼神与节拍关系。

【视觉与动态字体系统】
色盘、成像、主/辅字体、四种以上版式、TYPE LAYER STACK、空间深度、4–6 种已落镜方法和硬切规则。

【画面过程描述】
Shot N — 时间｜景别/镜头｜空间
场景与人物：动作族：[本镜动作族]；空间区段：[本镜区段]；进入路径 → 重心/发力 → 空间或服装接触 → 惯性/落点 → 镜头反馈。
Typography: "EXACT ENGLISH TEXT"；字骨架/尺度/材质/颜色；Layer A/B/C（可选 D）的深度、透视、遮挡与可读时刻。
Rhythm / Cut：声音触发与硬切方式。

【全局要求与负面约束】
角色、肤质、英文准确性、静动冲突；禁止换脸换装、普通字幕、单层贴字、乱码、Logo 和柔和转场。
```

## 规整原则

- 默认 8–10 镜，按“建立 → Hook → 变化/抽空 → Hook 回归 → 最终收束”分组；镜头内部可安排 1–2 次短促节拍变化。每个硬切改变景别、空间、朝向或文字深度中的至少两项。
- 逐镜显式填写 `动作族` 和 `空间区段`：全片使用 5–7 个不同动作族、至少 4 个连贯空间区段；相邻镜头不重复动作族，并在身体轴线、运动方向、空间支点、镜头关系中再改变至少两项。
- 至少 3 镜为大幅度动作、2 镜发生真实空间借力、1 镜利用服装惯性、2 镜为承上启下的静点。手掌触摸/覆盖镜头最多一次，不能让所有转场都靠冲镜头或伸手。
- 动作必须写完整链条：进入路径、重心、发力、接触、惯性/落点和镜头反馈；避免“扭动身体、酷炫手势、自由舞动”等不可执行的空话。
- 15 秒音乐要有头有尾：原创歌曲未指定曲风时默认 K-pop hip-hop / trap-rap，按 Intro tag → Rap A → Pre-hook → melodic/chant Hook → Beat switch → Final tag 推进；最后一拍留下明确重音、尾音或干净停止，不要从头到尾同一循环或无意义淡出。
- 演唱歌词与屏幕词分离：歌曲可有 5–7 行连续歌词，画面仍只提取 3–6 个英文视觉关键词，不把全部歌词变成字幕。
- 至少两镜为设计主导静点，至少三镜有人物大动作；画面节奏与包装节奏共同成立。
- 每镜一个语义主词，同词拆成 Hero base、Print plate、Action/foreground，必要时增加 Occlusion/recovery。
- 屏幕文字先完整可读，再变形、遮挡、撕裂或退场，不生成随机伪英文。
- 聊天中展示的完整提示词就是实际生成输入；边界标签、说明文字和摘要都不得一同发送。
- 完整 prompt 必须至少包含 8 个 `Shot`，并在每个 Shot 中分别写 `Layer A`、`Layer B`、`Layer C` 和 `Rhythm / Cut`；不能只在全局段落说一次“有三层字体”。
