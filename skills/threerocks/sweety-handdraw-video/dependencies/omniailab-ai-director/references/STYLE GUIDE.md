# 视觉语言库（导演 / 摄影 / 胶片 / 印片）

把用户的自然语言画面需求，转换为一条模型无关、中文、可直接复制的文生图正向提示词。保持原意，合理补全视觉信息，让所有描述服务于同一个画面意图。

画风由一套可检索的代码体系承载：`Dxx` 导演视觉语言、`Pxx` 通用摄影风格、`Cxx` 拍摄胶片、`Rxx` 印片风格、`S1–S3` 风格强度。成品把代码展开为自然视觉语言，代码本身不进提示词。

## 在本流水线中的定位与边界

本库是 **LIRA 的风格来源层**，只负责"选什么视觉语言、怎么落到画面描述"。

- **只管图像**。文生图与图像编辑提示词归本库；视频提示词由 `CINEDANCE GUIDE.md` 处理，表演与情绪由 `ACTING GUIDE.md` / `EMOTION GUIDE.md` 处理。本库不生成运镜、时间轴、首尾帧或动作分段内容。
- **不覆盖 P1**。全片画幅、帧率、摄影机与镜头家族、环境色彩策略由 P1 锁定；本库的画幅建议只在脱离流水线单独出图时生效。
- **胶片与印片一律以"模拟"口径表达**。写"Kodak 2383 电影印片质感""35mm Kodak Vision3 500T 胶片模拟颗粒"，不得表述为实体胶片拍摄；数字摄影机与实体胶片不得并列（与 P1 第 4 节一致）。
- **比例与分辨率不进提示词正文**。这是平台参数，在 UI 里设置。构图措辞（"宽幅横幅画面""竖向全身构图"）可以写；`16:9`、`--ar`、`4K` 不可出现在散文里。
- **导演姓名只作检索标签**。默认稳定模式：姓名只用于定位条目，成品展开为具体视觉语言。锚点模式（"受某导演影像语言启发"）仅在用户明确要求时使用，对外交付物中默认不用——它与"提示词中不出现真实人物姓名"的既有口径存在张力。
- **静态空间调度是单图概念**。它描述最终定格瞬间的空间组织，不与 CINEDANCE 的镜头运动混用。
- **不承担美学选型**。"这场戏该用哪套电影美学"由 `AESTHETICS GUIDE.md` 主动提案并确定；本库只负责把已确定的配方／风格展开为画面参数（配方参数见 `aesthetic-recipes.md`，现成提示词见 `examples/aesthetics/`）。

## 工作流程

1. 提取用户明确给出的主体、数量、动作、环境、时代、风格、色彩、画幅和镜头要求，并将其作为最高优先级约束。
2. 判断画面类型：人物、产品、场景、插画、概念设计或混合类型。
3. 根据画面意图补全景别、观察角度、构图、空间关系、环境层次、光色和材质。
4. 将"高级、震撼、孤独、浪漫"等抽象感受翻译成可见、可拍、可渲染的视觉特征。
5. 按固定顺序组织成品：
   `画面类型 → 景别与机位 → 构图 → 主体 → 动作与表情 → 空间调度 → 环境层次 → 光影与色彩 → 美学与材质 → 画幅与质量`
6. 输出前核对角色数量、随身物件、职业装备、品牌、标签、文字、核心道具和叙事事件，确保这些实体均来自用户输入。
7. 直接输出一条完成度最高的提示词。

## 补全原则

- 完整保留用户明确的信息，不改变角色数量、身份、核心动作、环境、时代、道具和叙事事件。
- 随身物件、职业装备、品牌、标签、包装文字和知识产权元素仅在用户明确提及时加入。
- 人物与产品信息缺省时，仅补充完成画面所需的姿态、基础外形、材质和光影。例如将"独行者"写为"一名穿着御寒服装的独行者"，将"香水"写为"一瓶造型精致的透明玻璃香水瓶"。
- 情绪依据用户原话呈现；没有明确情绪时，采用与动作和环境一致的自然表情。
- 情绪与表情画面优先近景，人物动作优先中景或全景，产品质感优先特写，环境叙事优先大全景。
- 单主体明确位置与留白；双主体明确左右、高低、朝向和视线；多主体明确主次、遮挡和深度顺序。
- 环境按照前景、中景、背景建立空间层次。
- 画幅缺省时，人物与海报优先竖幅，环境与叙事场景优先横幅，产品静物依据陈列方式选择方幅或竖幅（流水线内画幅以 P1 为准）。
- 两个核心要求无法同时成立时，只询问一个最关键的问题，确认后再生成成品。

## 静态空间调度

"调度"专指单张图片中的静态空间组织：

- 主体在画面左、中、右或上下区域的位置。
- 身体朝向、头部朝向和视线落点。
- 主体之间的距离、相对高低、主次和遮挡关系。
- 前景、中景、背景的内容与深度顺序。
- 动作冻结在最具辨识度的瞬间，并呈现衣物、头发、液体、烟尘等受力结果。

使用静态画面语言描述最终定格瞬间，不加入视频运镜、时间轴、首尾帧或动作分段。

## 画风系统

画风由五类代码组成：

- `Dxx`：导演／摄影师视觉语言，控制构图、镜头、调度、光线、色彩、场景、材质和后期气质。需要导演风格或画风菜单时读取 `director-styles.md`。
- `Pxx`：通用摄影风格。需要自然纪实、黄金时刻、商业静物、美妆、硬闪、黑色电影、暖金贵妃夜宴风 01/02 等摄影风格时读取 `photo-styles.md`。
- `Cxx`：拍摄胶片模拟，控制光源倾向、宽容度观感、颗粒、肤色和基础色彩响应。需要胶片模拟或指定胶片时读取 `capture-films.md`。
- `Rxx`：电影正片／印片风格，控制最终对比、黑位、高光、色彩分离和影院拷贝质感。需要 Kodak 2383、Fujifilm 3513 或印片风格时读取 `print-films.md`。
- `S1–S3`：风格强度。`S1` 轻度体现，`S2` 平衡内容与风格（默认），`S3` 让风格成为主要视觉表现。

组合规则：

- `Dxx` 与 `Pxx` 作为主视觉语言，默认选择其中一项。
- `Cxx` 与 `Rxx` 可独立使用，也可叠加在主视觉语言上。
- 支持 `D01+C04+R01+S2` 等代码输入；成品把代码展开成自然视觉语言。
- 用户说"画风菜单"或"帮我选画风"时，针对当前画面提供最多三组适配组合及简短理由；用户选定后再按标准格式输出成品。
- 普通提示词转换直接根据用户意图完成画面，无需主动展示菜单。

## 导演姓名规则

- 默认采用稳定模式：导演或摄影师姓名仅用于检索对应预设，成品将姓名转换为具体的构图、调度、光色和材质描述。
- 用户明确要求锚点模式时，在【画面类型】开头使用"受某导演／摄影师相关影像语言启发"，随后继续展开完整视觉特征。
- 用户明确指定姓名呈现方式时，采用用户要求。
- 导演预设只控制视觉形式，主体、环境和事件继续以用户输入为中心。

## 冲突处理

- 优先寻找能够同时满足要求的静态构图。
- 两个核心要求无法在同一画面成立时，先询问一个决定性问题，确认后再生成成品。
- "面部特写且完整展示全身""纯俯视且完整呈现正面五官"等组合属于需要确认的高影响冲突。

## 输出格式

两种模式，默认使用模式 A。

**模式 A — 自然散文（默认）**

与 LIRA 口径一致：连贯散文，紧凑，不堆砌关键词，不使用大写分块，篇幅 ≤1500 字符。

**模式 B — 十段式结构化（需要精确控图时）**

用于首帧图、道具特写、产品与菜单图，以及其他需要严格限定构图与调度的画面。按固定顺序输出：

`画面类型 → 景别与机位 → 构图 → 主体 → 动作与表情 → 空间调度 → 环境层次 → 光影与色彩 → 美学与材质 → 画幅与质量`

- 从提示词正文直接开始，用【画面类型】【景别与机位】等短标签区分模块。
- 各模块用分号自然衔接，形成一条完整提示词。
- 【画幅与质量】只写构图倾向与质量描述（"宽幅横幅画面、主体清晰、背景具有自然景深"），不写比例数字与分辨率。
- 篇幅仍需控制，不因分模块而膨胀。

两种模式的共同要求：

- 内容聚焦于正向、可见、可执行的画面描述，不使用负面提示词。
- 事实描述采用肯定句式，直接呈现画面中实际可见的主体、环境、材质和光线。
- 使用中文和通用图像生成语言。
- 每次只提供一个完成度最高的版本，不解释创作思路，不提供备选版本。
- 不附加自动补全说明、英文版、参考图说明、模型名称、采样器、权重或其他模型专用参数。
- 排他性需求改写为"画面仅呈现……""背景保持纯净""主体独立置于……"等正向结果。
- 用户要求简短时压缩措辞，同时保留主体、镜头、构图、调度、环境、光色、美学和画幅。
- 用户需求存在关键冲突时，先询问一个最关键的问题，确认后再输出成品提示词。

## 示例

输入：`雨夜，一个女孩等公交。`

输出（模式 B）：

```text
【画面类型】电影感都市人物场景；【景别与机位】中远景，平视视角；【构图】三分法构图，女孩位于画面右侧，左侧保留街道与公交驶入方向的空间；【主体】一名独自等车的年轻女孩；【动作与表情】安静站在站牌下，双手自然收拢，神情平静专注；【空间调度】女孩朝向道路，视线望向画面左侧远处，前景是被雨水打亮的路面，中景是女孩与站牌，背景是虚化的城市灯光；【环境层次】持续细雨，路面积水反射灯光，远处建筑与车灯被雨幕柔化；【光影与色彩】冷蓝雨夜为主色，暖黄色站台灯从侧上方照亮人物面部与肩部，形成冷暖对比；【美学与材质】写实电影摄影质感，真实湿润织物、皮肤与路面反光，克制细腻；【画幅与质量】宽幅横幅画面，高细节，主体清晰，背景具有自然景深。
```

输入：`D01+C04+R01+S2，深夜便利店门口等人的男人。`

输出（模式 A）：按 D01 展开霓虹都市的构图偏置、潮湿反光与红绿琥珀色，叠加 C04 的钨丝灯平衡与城市混合光细颗粒、R01 的浓郁黑位与清晰色彩分离，强度为标准，产出连贯散文式提示词。代码本身不出现在成品里。

## 在本流水线中的调用点

| 阶段 | 用法 |
|---|---|
| P1 | 从 D 库选取主要影视参考，把参考展开为四维视觉特征，写进「全片风格锁定」 |
| P2 | 角色母板、设定板出图时，引用已锁定的 D/P/C/R 组合 |
| P3 | 场景母板出图时，引用已锁定的 D/P/C/R 组合 |
| P4 | 首帧图出图时引用同一组合；需要精确控图时切换到模式 B |

画风菜单只在用户主动要求时提供，最多三组组合加简短理由；风格强度默认 `S2`。

全片／整场美学由 `AESTHETICS GUIDE.md` 在 P1 主动提案、P4 二次触发；选定后仍由本库把该配方展开为 D/P/C/R 语义与具体画面参数。
