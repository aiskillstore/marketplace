# 光学层（视场角锚点 · 镜头决策树 · 多镜一致性）

**核心认知**：视频模型对**可观察到的镜头结果**的反应，远好于对**摄影机元数据**的反应。不要拿毫米数、光圈、感光度、镜头品牌或老镜头型号当主要控制手段。

> **与电影艺术知识层的关系**：本层管**以可观察结果选镜组**（视场角锚点、镜头决策树、多镜一致性）。**景别与角度在叙事上意味着什么**——景别体现创作者与观众的关系、角度决定权力与情绪、视点决定观众认同谁、构图改变＝关系改变——来自 `FILM-ART GUIDE.md`，见 `film-art/04-visual-language.md`。**选型与一致性的口径以本层为准，叙事含义与关系线约束以电影艺术层为准**。

## 在本流水线中的定位与边界

- **只管"这支镜头怎么被描述"**，不管画面内容：内容归 `ACTING`／`EMOTION`／`BLOCKING`／`COMBAT`，画风归 `STYLE`／`AESTHETICS`，块序归 `PROMPT-DOCTRINE`。
- **不覆盖 P1**。全片镜头家族由 P1 锁定；本层的角度选择**必须落在 P1 已锁定的镜头家族之内**，不得自行引入新镜头。
- **度数怎么用（重要边界）**：视场角是**内部选取与对齐的工具**，也是平台镜头／FOV 字段的填法；**写进提示词正文的是"可观察的镜头结果"**（见第四、五节）。若平台没有对应字段，可把角度与结果一并写进正文，但**同一片必须保持同一口径**。
- **与"光学做进静帧"配合**：镜头性格的稳定性由 plate／首帧承担（见 `PROMPT-DOCTRINE GUIDE.md` 第 3.1 节）；本层负责**逐镜选对镜头、并让它在多镜之间不漂**。
- **与 `CAMERA-LIGHT GUIDE.md` 的分工**:本层管视场角与镜头家族、多镜不漂；**机位组合**（机身格式档·镜头性格·焦段·光圈·运动）与**光照方案**的选取与注入归该层。拿不准某类片子／某类场景／某类人物该配什么，先查它的调度反查表 `examples/camera-light/调度反查表.md`。
- **不单独计为一个子技能**。

## 何时调用 · 怎么调用

| 时机 | 怎么用 |
|---|---|
| **P1 锁镜头家族** | 用第二节的锚点与决策树，为全片定下 2–3 支镜头性格（如"环境用 84°、对话用 29°、观察用 8°"），写进「全片风格锁定」 |
| **P4 出首帧** | 逐镜按内容类型选角度 → 取第四节对应的语言块 → 接在首帧提示词的光学位置 |
| **P5 写视频提示词** | 逐镜带上一句镜头性格（可观察结果）；多镜（含内切）时必须写第六节的**多镜镜头一致性**声明与反漂移锁 |
| **画面里出现"广角感/长焦感"但老是漂** | 先查第三节有没有**在同一个镜头节拍里混了不兼容的内容类别**——这是镜头漂移的头号原因 |

## 一、总原则

**优先用这些来控制镜头**：对角视场角（度）· 摄影机与人物的物理距离 · 可见的光学结果 · 内容与视场的对齐。

**不要用这些当主要控制**：`85mm` / `35mm` / `f/1.4` / `ISO 800` / 各厂家镜头型号。

## 二、视场角锚点与镜头决策树

**七个锚点：`8° · 18° · 29° · 47° · 84° · 107°`**（另备 `135°` 用于极端环境沉浸，仅在整段都是环境动作时使用）。

**按内容类型静默选镜头（写提示词之前先选完）：**

| 内容类型 | 选什么 |
|---|---|
| 亲近的脸、且要看见环境 | **84°** 亲密广角 |
| 中景肖像 | **29°** 短焦人像 |
| 紧凑的情绪特写 | **18°** 经典长焦 |
| 远距离的隐藏观察 | **8°** 超长焦观察 + 前景遮挡 |
| 自然纪实的动作 | **47°** 标准视角 |
| 广环境动作 | **84°** 经典广角 |
| 大尺度环境地理 | **107°** 广角直线镜头 |
| 极端环境沉浸 | **135°** 广角环境语法（**仅当整段都是环境动作**） |
| 标准细节 | **29°** 或 **18°** |
| 广环境里的细节 | 仅在确有必要时使用专门技法 |
| 体育转播 / 偷拍 / 野生动物观察 | **8°** 超长焦观察 |
| 被压缩的监视感肖像 | **18°** 或 **8°** + 前景遮挡 + 大气雾霾 |

**不要在一个镜头节拍里混宏观细节与广环境动作**，除非使用已被命名的专门技法。

## 三、内容—视场对齐规则（防镜头漂移）

- **广角成立的条件**：内容是环境的、空间的、身体的、沉浸的、或身体贴近摄影机的。
- **长焦成立的条件**：内容是肖像的、观察的、孤立的、压缩的、远距离注视的。
- **微距／细节自成一段插入节拍。**

**铁则：不得在同一个镜头节拍里混入不兼容的内容类别。** "脸部肖像 + 大环境地理 + 微观细节"塞进同一个节拍，就会造成**镜头漂移**。若一场戏需要不同内容类别，用**受控的内切**，并给每个镜头分配各自的镜头性格。

## 四、角度语言块（可整块复制）

放在提示词的光学／摄影机位置。

**47° 标准视角**

```text
47° 对角视场，标准视角的镜头性格，摄影机距主体 3–5 米，自然人眼透视。
没有可察觉的畸变，面部与身体比例自然，景深舒适，背景可读但不夸张，经典扎实的电影取景。
```

**84° 经典广角**

```text
84° 对角视场，经典广角镜头性格，摄影机距主体 1–1.5 米，必要时略微低机位。
广角带来的强烈但自然的透视扩张，前景身体体积比自然更大、更贴近，
环境保持可见直到画面边缘，空间语境纵深可读，建筑的直线保持笔直，没有鱼眼弯曲。
```

**107° 广角直线**

```text
107° 对角视场，广角直线镜头性格，摄影机距前景主体 0.5–0.8 米。
最前景的物体变得巨大，周围环境向四边展开，
全画幅深焦，直线保持笔直，画面边缘有轻微色差，无暗角，无鱼眼球感。
```

**29° 短焦人像**

```text
29° 对角视场，短焦人像镜头性格，摄影机距主体 4–6 米。
靠镜头焦段取得紧凑取景，而不是靠身体靠近。
主体锐利，背景开始向主体身后压缩贴近，面部比例好看且稳定，
背景化成柔滑的柔和散景，主体从环境中清晰地跳出来。
```

**18° 经典长焦**

```text
18° 对角视场，经典长焦镜头性格，摄影机距主体 6–8 米。
强烈的背景压缩，远处元素在主体身后堆叠得更近，
极浅的焦点只把眼睛与关键面部特征留在焦内，前景背景都溶成柔和散景，画面像是从远处被观察到的。
```

**8° 超长焦观察**

```text
8° 对角视场，超长焦观察镜头性格，摄影机距主体 20–25 米。
极端的背景压缩，背景被压成一片柔和的色块，只有主体是锐的，其余全部溶成柔滑散景。
画面像远距离的偷拍、野生动物纪录或体育转播的观察感。
前景遮挡是必须的：模糊的前景物体占据画面下 30%–45%，形成巨大的深色散景形状，从远处把主体框住。
```

## 五、视觉结果栈（可观察短语配够）

**任何长焦镜头，至少带上其中 4 条**：背景完全化开成柔和的暖色块 · 主体上锐利的焦点 · 只有主体是锐的、其余全部柔软 · 主体身后柔滑的散景漫开 · 背景在主体身后被压平成一片 · 主体在溶开的背景上锐利地跳出来 · 紧凑取景靠镜头焦段而非身体靠近 · 摄影机在物理空间里离主体很远 · 摄影机与主体之间悬着大气雾霾 · 前景遮挡把主体框成柔和的深色散景。

**任何广角镜头，至少带上其中 3 条**：前景身体体积比自然更大 · 主体四周环境保持可见 · 全画幅深焦 · 直线保持笔直 · 空间语境可见到画面边缘 · 摄影机在物理上贴近主体 · 沉浸式近距透视 · 没有长焦压缩 · 除非明确要求，没有柔滑的人像散景。

## 六、多镜镜头一致性（含内切）

**同镜多镜**（同一支镜头性格内的多个镜头）：

```text
本段全部镜头均为 X°。不可协商。
每个镜头以「镜头锁定：本镜 = X°」开头。
每个镜头以「镜头检查：X° 保持，无漂移」结尾。
```

**混镜多镜**：**仅当内容类型改变时**，每个镜头才拥有各自的镜头性格。**不同镜头性格之间只用硬切。** 不做平滑的视场过渡，不允许单镜内随机漂移，不允许在没有新镜头开始的情况下更换镜头性格。

**每一次内切都必须延续**：在场角色 · 地点地理 · 画面方向 · 视线目标 · 身体朝向 · 光线方向 · 道具状态 · 伤口状态 · 血／雪／土／汗／水／火／烟的连续性 · 世界物理。

### 反漂移锁（按需使用）

**长焦**：

```text
本镜的任何部分都不会变成广角或标准镜头的覆盖。更宽的取景靠摄影机退得更远、
保持同样的长焦触及，而不是换镜头。背景在每一帧都保持被压缩、被溶开。
```

**广角**：

```text
本镜的任何部分都不会变成长焦人像的覆盖。环境始终在主体四周可见，
摄影机始终在物理上贴近，画面保持广角的空间扩张与可读的纵深语境。
```

**标准**：

```text
没有极端的广角畸变，没有长焦压缩。画面保持自然、扎实、人眼中性。
```

## 七、光学反模式（不要这么写）

不要写：极端／超广角镜头 · 用"广角镜头"当作镜头指令 · 用"建立镜头"当作镜头指令 · 变焦拉远＋广角 · 紧凑的广角取景 · 用光圈／感光度／镜头厂家元数据当主要控制 · 在同一个镜头里叠复合运镜 · 在同一个节拍里混不兼容的内容类别 · 纯否定的镜头控制。

## 八、交付前质检

- [ ] 每一镜都按**内容类型**选定了角度，并落在 **P1 锁定的镜头家族**之内？
- [ ] 没有在同一个镜头节拍里混入不兼容的内容类别？
- [ ] 长焦镜至少带了 **4 条**可观察结果短语；广角镜至少带了 **3 条**？
- [ ] 正文里没有出现毫米数／光圈／感光度／镜头厂家型号作为主要控制？
- [ ] 同一支镜头性格出现在多个镜头时，是否写了**镜头一致性声明**？
- [ ] 需要换镜头性格时，是否**只在内容类型改变处硬切**，且没有平滑过渡与随机漂移？
- [ ] 每次内切是否逐条延续了十二项连续性？
