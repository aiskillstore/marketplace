# 纪实／纪录片层（观察式纪实影像工作流）

本层把「真实的人」与「普通人的生活」做成**可执行的纪实影像工作流**。它**替换的是内容来源与美学口径**，不替换主干流程——**P0→P6 与全部确认门禁照旧**；图像生成、视频生成、资产体系、提示词工程等影视级方法**一律沿用既有层级**，全部在 **OmniAiLab** 内执行。

**它不是**城市宣传片模板，不服务宏大景观包装，也不把纪录片做成 AI 味、广告味或网红味。

## 一、何时启用（触发判定）

对话中出现以下任一情形，即判定为**纪实／纪录片项目**，全片改按本层执行：

- 明确说到「纪录片」「纪实」「非虚构」「观察式」「人文纪录」「口述实录」「真实的人」；
- 题材是**真实人物与日常生活**（劳作、手艺、营生、家庭、社区、迁徙、节庆），而不是虚构剧情；
- 创作者要求「不要演」「不要摆拍感」「不要戏剧化」「要像长期蹲点拍到的」。

判定后：**先在 P0 与本层之间做一次「纪实规格」确认**（见第三节），随后仍按 P0→P6 推进；**每一镜的生成方法不变**，变的只是叙事原则、光线口径与提示词词汇。

> 判定不是纪实时，本层不启用，一切按原流水线执行。**不得把纪实口径套到剧情片、广告片与 MV 上。**

## 二、定位与边界

| 维度 | 本层的规定 | 仍由既有层级决定 |
|---|---|---|
| 叙事 | **观察生活，不"拍故事"**；去戏剧化 | 剧本结构体检仍走 `references/SCENE-ENGINE GUIDE.md`（只诊断、不改戏） |
| 美学 | 自然光逻辑、低饱和高层次、允许不完美 | 全片风格锁定仍由 P1 定稿，落点走 `references/STYLE GUIDE.md` 的 `C`／`R` 库 |
| 资产 | 沿用「文本＋图像」成对资产与命名 | `references/ASSET-SYSTEM GUIDE.md`（`@char_`／`@loc_`／`@prop_`／`@staging_`） |
| 图像与视频提示词 | 补充纪实词汇与运镜三级 | `references/PROMPT-DOCTRINE GUIDE.md` 的块序与铁律、`references/CINEDANCE GUIDE.md` 的合成 |
| 光学 | 长焦观察、浅景深抓拍 | `references/OPTICS GUIDE.md` 的视场角锚点与决策树 |
| 生成与装配 | 长镜优先、呼吸感转场 | `references/omniailab_production.md`（P6） |

**冲突优先级**：本层与主干冲突时，**以主干 P1／P4／P5／P6 为准**；本层只在其描述范围内成立。

## 三、纪实规格（P0 阶段的一次确认）

在 P0 之后、P0A 之前（或并入 P0A 首个确认门），先与创作者确认一份**纪实规格**，至少写清：

1. **片名**：贴合人文纪实调性，避免商业化或浮夸命名。
2. **题材地域**：亚洲／非洲／中东／南美／东欧／东南亚／海岛地区／发展中地区（非都市生活现场）。
3. **题材核心**：必须聚焦**真实的人与日常生活**；拒绝以城市景观或宏大场面为主角。
4. **画幅与时长**：优先 16:9 横屏，或 2.35:1 宽银幕；目标时长与用途（展映／新媒体／品牌人文单元）。
5. **视觉风格**：锁定一种并写进「全片风格锁定」——如「真实摄影师长期驻扎的观察视角」「国际纪录片电影节的选片质感」「流媒体人文纪录片的观察式风格」「人文地理类观察影像」。
6. **明确「不像什么」**：不像 AI 生成、不像商业广告、不像强戏剧、不像网红风。**这四条以正向表述写进风格锁定**（"只写有什么、不写不要什么"）。
7. **画面质感要求**：空气感（灰尘／水汽／热浪／潮湿／风）、自然光时段（晨光／黄昏／阴天／窗边光）、保留不完美（轻微失焦、曝光波动、真实混乱感）。
8. **真实度声明**：人物是否为真人出镜、是否使用参考素材、对白与旁白的来源（现场声／后配旁白）。

**参数口径（硬约束）**：画幅、分辨率、帧率、时长与模型名**只进平台 UI 与数据文件，不写入提示词正文**。

## 四、叙事与分镜规范

### 4.1 核心叙事原则

- **观察生活，而不是"拍故事"**；重点是呈现真实世界中的人类生活状态，不是讲一个起承转合的完整故事。
- **永远先拍人，不先拍城**；不把城市面貌或宏大景观当作主角，通过普通人的真实生活折射其背后的文化与环境。
- 画面要像**摄像师长期驻扎时偶然观察到的东西**，而不是导演刻意安排的东西。
- 用户提供的参考素材**必须与文字描述一致**，不得互相矛盾。

### 4.2 优先拍摄的细节动作

- **劳作类**：做饭、缝纫、洗衣、写字、手工劳动、修补、搬运。
- **微小日常类**：点烟、喝茶、发呆、看窗外、收拾工具、哄孩子。

### 4.3 地域化场景库（选题参考）

- **亚洲**：清晨早餐摊／老茶馆闲谈／熙攘传统市场／原生态渔村／老旧铁路边
- **非洲**：黄昏尘土中的归途／热闹集市／奔跑的孩子／雨季日常／传统手工劳动
- **南美**：街头音乐表演／充满生活气息的老城区／海边日常／街头足球／夜市烟火气
- **中东**：阳光穿透的传统市场／专注的手工艺制作／虔诚的祈祷时刻／沙尘环境下的生活常态

### 4.4 镜头设计

**时长**：每镜 **6–12 秒**；**不做短于 5 秒的镜头**。

**运镜（三级，一个分镜只写一种）**：

1. 固定镜头（首选）
2. 微弱手持呼吸／轻微漂移
3. 极慢推近或极慢横移

**禁止**：旋转、快速推拉、无人机飞行、炫技运镜、切镜。

**每个镜头描述必须包含三项**：

- **场景**：引用场景元素 ID，说明时段与光线；
- **主体动作**：人物正在做的**微小动作**，以肢体与神态为主，**不写台词**；
- **摄影语言**：景别（特写／中景／远景）＋ 运镜类型 ＋ 焦点策略。

**构图倾向**：优先手部劳动、背影、微小日常动作；**避免正面表演式构图**。

## 五、画面质感与光线断言

- **自然光优先**：晨光、黄昏、阴天散射光、窗边侧光；**禁止人工补光感**（不写布光方案，改写"现场本来就有的光"）。
- **空气感必写**：灰尘、水汽、热浪、潮湿、轻雾——每镜任选其一写进镜头描述。
- **允许不完美**：轻微失焦、曝光轻微波动、人物短暂停顿，都可加分。
- **色调体系**：低饱和、高层次感；高光柔和不过曝、暗部有细节不死黑、肤色真实。胶片与印片一律按**模拟**口径表达（`references/capture-films.md`／`references/print-films.md`），常用落点为 `C` 库的电影负片与 `R` 库的自然印片。

## 六、参考资产（P2／P3 阶段）

**生成前必须先扫描上下文**：查找创作者已提供或此前已生成的、与分镜条目匹配的任何资产（人物参考图、场景图、道具图、音乐）。**匹配到的先绑定、不重复生成**——绑定一律走 `references/ASSET-SYSTEM GUIDE.md` 的命名与「资产前置闸门」。

| 资产 | 形态与规格 | 路由 |
|---|---|---|
| **人物三视图** | 正面／四分之三侧面／侧面，横向排列，纯净灰色无缝背景；多人时按同一排版 | **Seedream 5.0**（角色一致性、角色三视图） |
| **人物定妆参考板** | 竖幅；上段约 1/3 高度为两张面部特写并排（左正脸、右侧脸），下段约 2/3 为近距离正面服装展示＋标准站姿背面全身 | **Seedream 5.0** |
| **场景参考图** | 横屏；**无人物、纯环境**；严格遵循纪实规格的光线与空气质感 | **Flux**（地点路由） |
| **道具参考图** | 竖幅；纯净灰色无缝背景；**保留真实使用痕迹**（磨损、锈斑、褪色），避免崭新出厂感与商业静物感 | **香蕉Pro（Nano Banana Pro）**（道具路由） |
| **色卡参考图** | 横屏；纯 2D 扁平图形（见第七节） | **image2.5**（排版与文字最强） |

**人物一致性是硬要求**：三视图一经确认即为**全部后续生成的统一锚点**；定妆参考板**作为独立资产输出供创作者确认，不自动绑定分镜**。**确认前不得进入下一阶段。**

## 七、色卡提取与色卡图

### 7.1 从参考影像提取色彩系统

当创作者上传参考影像并要求提取色卡时：

- 只做**结构化描述**，不做主观评价、不添加创作建议；
- 默认提取 **10–13 个**核心颜色（必要时缩减到 5 个）；
- 每个颜色给出**近似 HEX 值**与**在画面中的功能角色**：暖光照射／皮肤中间调／阴影底色／材质色／强调色；
- 输出顺序：① 环境主色与光照色 → ② 中间调与阴影色 → ③ 材质色 → ④ 强调色／特殊功能色；
- 输出为**可直接复用的结构化列表**，供提示词与后续生成使用。

### 7.2 色卡参考图（纯 2D 扁平）

**必含结构**：

1. **顶部居中标题**：主标题（项目名·场景·色彩系统名，近黑色无衬线）＋ 副标题（色彩气质描述 ＋ `N color system`，更小的浅灰字）；
2. **中部横向色块**：均匀间距、完全一致的纯色矩形，**无渐变、无阴影、无描边、无立体效果**；
3. **每个色块下方两行**：第一行 HEX 色值，第二行功能标签（如"暖光照射""皮肤中间调""布料高光"）。

**背景**：低饱和中性纯色（米白／灰白／暖白／冷白），完全平面。

**禁止**：摄影渲染、纸张纹理、桌面、景深、胶片颗粒、写实材质、立体渲染、色块阴影、光泽表面、插画感、实物样机。

**本图是设计稿，不是照片**——提示词里必须把这一点写成正向断言。

## 八、提示词规范

本层只补充**纪实词汇与断言**；块序、铁律、正向锁定与首帧验收**一律按 `references/PROMPT-DOCTRINE GUIDE.md` 执行**，视频提示词由 `references/CINEDANCE GUIDE.md` 合成（表演层仍先经 ACTING，情绪层仍先经 EMOTION）。现成可抄模板见 `examples/documentary/纪实提示词模板.md`。

### 8.1 首帧提示词

**核心**：捕捉"决定性瞬间"的静态画面、胶片色彩质感、真实光影与空气感；**不出现任何运镜与节奏词汇**。

公式：`[画面主体与微小动作] ＋ [环境与空气感] ＋ [光线状态] ＋ [摄影机语言与景别] ＋ [色彩体系与质感] ＋ [核心精神关键词]`

### 8.2 视频提示词

**核心**：时间流动感、极慢的节奏与运镜、环境的微小变化、长镜头的观察感。

公式：`[极克制的镜头运动] ＋ [主体持续的微小动作] ＋ [环境与光线的微小变化] ＋ [色彩体系] ＋ [纪录节奏] ＋ [核心精神关键词]`

### 8.3 纪实词库（中英混写，可与既有块序同用）

- **空气感**：dusty air／morning mist／dampness／wind blowing
- **光线**：natural light／soft window light／overcast diffused light
- **色彩与质感**：low saturation／soft highlights／real skin tone／fine grain（胶片质感按 `C` 库模拟口径写）
- **风格参考（正向、去品牌化）**：long-form observational documentary／humanist still photography／environmental portrait

## 十、暂停点与失败处理

主干每个阶段末尾的确认门禁**照旧执行**；纪实项目在这五个位置**额外强调不得跳过**：

1. 分镜（故事板）完成后 → 等创作者确认；
2. 人物参考板确认后 → 等创作者确认；
3. 首帧完成后 → 等创作者确认；
4. 视频生成完成后 → 等创作者确认；
5. 音频生成完成后 → 等创作者确认。

**禁止一次性跑完整条流程。** 若某一步已暂停等待确认，**不得越过暂停点**。

**生成失败的处理**：先在**同一模型内重试**，**不要自动切换视频模型**；重试仍失败则停止并如实告知创作者，由其决定换模型或改镜。

## 十一、装配与声音

- 走主干 P6（`references/omniailab_production.md`）：**长镜优先**，保留完整的时间流动感。
- 镜头之间可用 **0.5–1 秒黑场或声音延续**做过渡，制造呼吸感。
- **禁止**快剪、音乐卡点、特效转场、短视频式强节奏。
- **音画关系**：音乐轨存在的，音量**低于现场声**，不抢画面；**不做强制音画同步**，画面与声音各自自然流动。
- 现场声优先：市集噪声、风声、雨声、街道声、器物声。

## 十三、交付前质检（纪实专用）

- [ ] 八项纪实规格齐备，且"不像什么"已改写为正向表述；
- [ ] 全部镜头发**自然光**、**无人工补光感**；
- [ ] **每镜都写了空气感**（灰尘／水汽／热浪／潮湿／轻雾任一）；
- [ ] 每镜 6–12 秒，**无短于 5 秒**的镜头；
- [ ] 一镜只用一种运镜，且落在三级之内；**无旋转／快速推拉／无人机／炫技／切镜**；
- [ ] 分镜里没有台词、没有正面表演式构图；
- [ ] 人物跨镜一致，且一致性锚点来自已确认的三视图；
