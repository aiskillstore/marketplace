# P6 OmniAiLab 生成、剪辑与成片质检

## 1. 阶段位置与目标
P6 是全流程最后阶段，位于视频提示词全部确认之后。目标是在 OmniAiLab 无限画布中完成视频生成、音频制作、剪辑拼接、字幕添加和成片导出，并通过质检清单确保交付质量。P6 是唯一实际调用 OmniAiLab 生成视频的阶段。

本文档为通用制作规范，文中出现的《17楼》及其资产仅为样例项目（`examples/floor17_script.md`）的示意；实际执行时，一律替换为当前项目 P0–P5 已确认的资产、编号与情绪曲线节点。

## 2. OmniAiLab 画布搭建
### 2.1 项目初始化
1. 浏览器访问 [omniailabx.com](https://www.omniailabx.com/)，登录账号
2. 点击「开始创作」进入无限画布
3. 项目命名：`《项目名》_版本号_日期`，如 `《17楼》_v1_20260905`
4. 画布比例设置为 16:9（与全片一致）

### 2.2 素材上传
在开始建节点前，先把所有前期资产上传到 OmniAiLab 素材库：
- 角色确认稿（R01、R02...）
- 角色设定板（备用，需要背面/侧面细节时用）
- 道具母板（P01、P02...）
- 场景母板（S01、S02...）
- 首帧图（Shot01、Shot02...）

命名规范：`类型_编号_名称.png`，如 `R01_角色名_确认稿.png`、`S01_场景名_光线状态.png`、`Shot07_镜头名.png`。

### 2.3 节点搭建顺序
按以下顺序在画布中创建节点，从左到右排列：

```
[素材区] → [脚本节点] → [图片节点×N] → [视频节点×N] → [音频节点×N] → [剪辑节点] → [导出]
```

**具体操作：**
1. **素材区**：将上传的素材拖入画布左侧，作为参考图库
2. **脚本节点**：双击画布空白处 → 选择「脚本节点」→ 粘贴定稿剧本 → 点击生成
3. **图片节点**：为每个镜头创建一个图片节点，输入 P4 的首帧提示词，上传对应参考图，生成首帧
4. **视频节点**：为每个镜头创建一个视频节点，将图片节点的输出连线到视频节点输入
5. **批量绑定**：框选全部图片节点和视频节点 → 右键「批量连线」，自动按顺序配对
6. **音频节点**：创建配音节点、BGM节点、音效节点
7. **剪辑节点**：将所有视频节点输出连线到剪辑节点，按顺序排列
8. **导出节点**：剪辑节点输出连线到导出节点

### 2.4 节点参数设置
**图片节点：**
- 模型：根据场景选择（人物多用 Seedream，场景多用 香蕉Pro/Flux）
- 比例：16:9
- 参考图：按 P4 规范上传（角色确认稿 > 场景母板 > 道具母板）
- 提示词：粘贴 P4 生成的首帧提示词

**视频节点（关键）：**
- 模型：按 P5 参数表设置（Seedance 2.5 / Kling O3 / Vidu）
- 时长：按分镜表设置（5s / 3s / 10s...）
- 比例：16:9
- 输入方式：图生视频，首帧图作为输入
- 参考图：首帧图 + 角色确认稿
- 提示词：粘贴 P5 生成的完整视频提示词

## 3. 批量生成流程
### 3.1 生成顺序
1. 先生成全部首帧图（图片节点），逐张确认
2. 首帧全部通过后，再批量生成视频
3. 视频生成按镜头顺序，先生成关键镜头（高潮、特效），再生成过渡镜头
4. 每个视频生成后立即检查，不合格的当场重生成，不要攒到最后

### 3.2 批量操作技巧
- 框选多个视频节点 → 右键「批量生成」，同时排队生成
- OmniAiLab 支持多任务并行，建议一次排队 3-5 个镜头
- 生成期间可以继续准备音频节点
- 失败的节点会显示错误，点击重试或修改提示词后重新生成

### 3.3 生成进度管理
用一张表格跟踪每个镜头的状态：

| 镜号 | 首帧状态 | 视频状态 | 重试次数 | 备注 |
|---|---|---|---|---|
| 01 | ✅通过 | ✅通过 | 0 | |
| 02 | ✅通过 | 🔄生成中 | 0 | |
| 05 | ✅通过 | ❌失败 | 1 | 角色漂移，已加参考图重生成 |

状态标记：⬜待生成 / 🔄生成中 / ✅通过 / ❌失败需重做

## 4. 音频制作
### 4.1 配音
- OmniAiLab 音频节点支持 AI 配音
- 为每个有台词的主要角色，按其年龄、身份与语气匹配音色（如疲惫紧张的女声选低沉音色、语速偏慢）
- 配音参数：按角色与场景设定语速、音调与情绪（如 0.9x 语速、偏低音调、疲惫/紧张）
- 配音生成后与画面对齐，确保口型大致匹配（不要求精确对口型）

### 4.2 BGM
- 全片 BGM 原则：遵循 P1 音乐圣经（如惊悚/剧情片用极简低频 drone、不铺满）
- 进入点 / 增强点 / 最高点 / 退出：对照 P0A 情绪曲线节点与分镜表设定，例如在第一个紧张升级镜头极弱进入、在全片最高峰达到最强、在结尾黑场戛然而止只留环境声
- OmniAiLab BGM 节点：输入 P1 确认的音乐语言描述（乐器、节奏材质、频率倾向、动态与留白），时长匹配全片

### 4.3 音效
按剧本空间链与分镜表逐条列出必须的环境声与音效（可从 OmniAiLab 音效库选择或上传），至少覆盖：
- 空间底噪（贯穿主要场景，作为环境声底层，音量压低）
- 场景特征音（如走廊日光灯电流声、密闭空间机械嗡鸣）
- 动作同步音效（脚步声、门/开关机械声、按键声等）
- 非语言人声（呼吸、喘息、叹息等，对应紧张镜头）
- 情绪强调音效（关键转折与惊吓点使用的短促强调声）

音效分层：环境声（底噪）→ 动作音效（同步事件）→ 强调音效（惊吓点），三层音量递减。

## 5. 剪辑与导出
### 5.1 剪辑节点操作
1. 将所有视频节点按镜号顺序拖入剪辑时间线
2. 调整每个镜头的入点和出点，确保动作衔接
3. 转场：默认硬切；特殊转场按分镜表设置（淡入淡出等）
4. 叠加音频轨道：配音轨 + BGM轨 + 音效轨，分别调节音量
5. 添加字幕：按分镜表在指定镜头叠加对白字幕与片尾字幕

### 5.2 节奏调整
- 对照 P0A 情绪曲线检查节奏：紧张点镜头是否足够短，呼吸区是否足够长
- 全片时长误差控制在 ±2 秒内
- 如果总时长偏长，优先压缩建立镜头（镜头1-3），不要压缩高潮
- 如果总时长偏短，延长呼吸区和高潮的停留时间

### 5.3 导出设置
- 分辨率：1080p（1920×1080）
- 格式：MP4（H.264 编码）
- 帧率：24fps（与 P1 一致）
- 音频：AAC，320kbps
- 色彩：Rec.709
- 导出前预览全片至少 2 遍

## 6. 成片质检清单
导出前必须逐项检查，任何一项不通过都要修正后重新导出：

### 6.1 角色一致性
- [ ] 每个主要角色在所有镜头中脸型、发型、服装、配饰和道具一致
- [ ] 配角、人影或变异状态在所有出现镜头中保持剧本规定的状态一致
- [ ] 没有出现换脸、换发型、换衣服的镜头
- [ ] 角色体型和身高比例在不同镜头中一致

### 6.2 场景与光线
- [ ] 同一场景的空间结构在不同镜头中一致
- [ ] 光线方向和色温在连续镜头中不跳变
- [ ] 曝光整体偏暗，没有某个镜头突然过亮
- [ ] 道具位置和状态连续（如手持道具的转移、落地或转手要有过渡）

### 6.3 镜头与节奏
- [ ] 所有镜头按分镜表顺序排列
- [ ] 每个镜头时长与分镜表一致（±0.5秒）
- [ ] 景别变化有节奏，不连续3个同景别
- [ ] 运镜不滥用，全片推进不超过3次
- [ ] 动作衔接自然，没有跳切或重复帧

### 6.4 音频
- [ ] 配音清晰，与画面同步
- [ ] BGM 进入/退出点正确，没有突然切断
- [ ] 音效与动作同步（按钮声对应按按钮动作）
- [ ] 没有爆音、底噪过大、音频缺失
- [ ] 黑屏后的环境声残留有氛围感

### 6.5 技术质量
- [ ] 导出分辨率 1080p，无模糊
- [ ] 无水印、无平台logo、无多余文字
- [ ] 视频播放流畅，无卡顿、无花屏
- [ ] 文件大小正常（30秒约 20-50MB）
- [ ] 首尾有足够黑场（开头0.5秒黑，结尾1秒黑）

## 7. 成本与效率优化
### 7.1 模型成本控制
- 先用 Seedance 2.0 Fast 快速试水全部镜头
- 筛选出关键镜头（高潮、特效、人物特写），再用 Seedance 2.5 / Kling O3 精修
- 过渡镜头（走路、空镜）用 Fast 版本即可
- 预计 30秒短片成本：8-12 次视频生成 + 8-12 次图片生成

### 7.2 时间估算
- 前期资产（P0-P3）：1-2 小时
- 分镜与首帧（P4）：1-2 小时
- 视频提示词（P5）：30 分钟
- OmniAiLab 生成（P6）：2-4 小时（含等待和重试）
- 剪辑与导出：30 分钟
- 总计：约 5-8 小时出第一版成片

### 7.3 版本管理
- 每次重大修改后导出新版本，命名 `项目名_v1.mp4`、`_v2.mp4`
- 保留所有首帧图和视频片段，不要删除
- 修改时只重生成受影响的镜头，不要全片重做
- 最终版确认后，将整个画布项目保存为模板，可复用工作流

## 8. 交付物
P6 完成后必须交付：
1. 最终成片 MP4（1080p / 16:9 / 24fps）
2. 全部分镜首帧图（打包）
3. 全部视频片段（未剪辑版，打包）
4. OmniAiLab 画布项目链接（可复用）
5. 成片质检报告（逐项勾选结果）
6. 项目资产包（角色/道具/场景图 + 提示词文档）

全流程结束。

## 9. 剪辑：五阶段到定剪（picture lock）

全片剪辑固定走五段，不跳步：

1. **粗排（Assembly）**——所有场次按剧本顺序接起来，**不管节奏**。目的：看见整部片，找出塌陷处与素材缺口。
2. **粗剪（Rough cut）**——开始处理节奏、修剪、重排。**需要重生成的镜头清单在这一步形成。**
3. **生成监督（Generation supervision）**——质检回炉：重生成坏镜头、清掉糊的、在精剪之前把不成立的东西抓出来。
4. **精剪（Fine cut）**——精确贴合；组织冷观众试映（不看人情的观众）。
5. **定剪（Picture lock）**——定剪之后**除紧急修复不再新增任何生成**，并且要通知调色与声音环节。

## 10. 转场是设计出来的，不是捡到的

因为每一镜都是单独生成的，**接点必须当成特技来设计**：

- 每个衔接点按**运动方向 + 声音**匹配：一个杯子的影子横扫画面，交给收款机抽屉拉开；雨刷划过镜头，接同一轴上的一缕烟划过。
- 每个片段在**头尾各多生成 8 帧**作余量（在 P6 批量生成时设置）。
- 切点落在覆盖元素**填满画面至少 90%** 的那一帧——**绝不等到它走完**。
- 转场清单随分镜在 P4／P5 一并产出（哪个接点、靠什么元素盖、盖到多少、配什么声音），不要留到剪辑台上现找。

## 11. 颜色统一与声音设计

- **调色**：每次生成都自带一套内置调色，所以调色的工作是**统一**——把相邻镜头拉到一个 look，并把夜戏素材压得比任何模型愿意给的都更暗。基准配方来自 P1 的逐时间线锁定（见 `PROMPT-DOCTRINE GUIDE.md` 第 3.4 节）。
- **声音以设计为主**：环境底噪、纸、金属、机械、城市；每次转场一次低频闷响，**同一电平、绝不加速**。
- **配乐口径（与 P1 的关系）**：默认以 P1 的声音圣经为准（含 BGM 的进出）。当项目定位为**写实克制型**（犯罪／悬疑／作者向写实短片）时，推荐采用**"场景内不放配乐、只做声音设计"**的口径——此时以本条为准：安静不是预算问题，是这部片就是这么安静。
