# 长片工程层（分解 · 空间图 · 世界 · 法条 · 监督）

短片靠手感，**长片靠制度**。这一层是把"上百场戏、几百个资产"跑完并保持一致的工程方法——每一条都是**因为某个镜头在没有它的时候失败了**才存在的。

## 在本流水线中的定位与边界

- **只管"怎么把长片组织起来"**：分解、排产、锁定、日志、质检、监督。画面内容归 `ACTING`／`EMOTION`／`BLOCKING`／`COMBAT`，提示词写法归 `PROMPT-DOCTRINE`，资产归属 `ASSET-SYSTEM`，镜头语言归 `OPTICS`，剧本结构归 `SCENE-ENGINE`。
- **它是一个"制度层"**：不替换任何一层，而是规定它们**在长片里的执行顺序与验收方式**。
- **短片也适用**：场次少的项目可以简化（只保留"资产先行＋一次只改一件事＋简化镜头而不是简化措辞"三条），但**不建议省略**。
- **不单独计为一个子技能**。

## 何时调用 · 怎么调用

| 时机 | 怎么用 |
|---|---|
| **P0／P1** | 按第一节把剧本转成**带导演意图的镜头表卡片**，先看"洞"在哪（没目标的镜头、没任务的角色、没有资产的场次）；按第三节先写**视觉圣经**（分世界调性） |
| **P3／P4** | 每场戏按第二节做完**开启仪式**（主镜／第一秒宽景／GEO 空间图／罗盘句）再动笔 |
| **P4 出首帧前** | 每个资产按第四节做**压力测试**（视频测试 10/10），没过不许出镜 |
| **P5 写提示词／生成** | 按第五节的**迭代纪律**（一次只改一件事、进日志）；按第六节把关键约束写成**法条** |
| **P6 生成中** | 按第八节**剪辑并行**＋设一个**生成监督**岗位 |
| **P6 后期** | 按第九节：清理 → 颜色统一 → 声音 |

## 一、分解：把剧本变成"带导演意图的镜头表"

**分解不是一张"要造的东西"的清单**，而是把剧本转成一份**已经装着导演意图的镜头表**。每一个镜头一张卡，卡片四组：

**① 材料**：地点＋内/外景＋覆盖它的资产；**时间（它就是"选哪个资产变体"）**；在场每一个人＋他们的状态变体；道具与车辆＋标签；动作 1–3 句；**逐字台词**；时长（秒）；**复杂度（简单／中等／复杂）**。

**② 导演**：本镜目标一句话；**任务**——他为拿到想要的东西做了什么，用一个**动词**（质问、揭穿、羞辱）；**戏剧性**——从开头到结尾之间**什么变了**；相对机位的站位；**表演**——脸与身体做什么，以及**角色在隐藏什么**。

**③ 摄影**：景别 · 运动 · 镜头 · 角度。**④ 剪辑**：切类型 · 节奏 · 本镜如何勾住下一镜。

**镜号带字母**（`50B`、`50C`），并且**这个编号要在卡片、版本日志、提示词文件上保持一致**——否则相邻两镜一定会搞混。

> 卡片列完，洞会自动浮出来：**一句没有目标的镜头、一个没有任务的角色、一场没有资产的戏。**

## 二、每场戏的开启仪式

**① 主镜（master shot）**：每场戏以一个**约一秒的固定站位宽景**开场，无台词、无动作。模型会把这份安排"拍下来"——谁站哪、什么躺在哪、光从哪来——并在**该场戏后续每一镜里保持它**。**去掉这一秒，英雄就开始换位。**

- **让它出点声**：让某人在这一秒里说一个短词（如"嗯"），模型更容易把宽景当成一个正式镜头。
- **让它接上一场**：如果这场戏是回答上一场的，把**上一段片尾那句的尾巴**喂进这一秒——演员就会用对的语气回答对的东西，两段在接缝处粘住。

**② GEO 空间图（纯地点，每场一份，不改）**：写在主镜之下，是**几行的平面图**。**只写地点，不写英雄，不写动作。**

```text
GEO 空间图（全场锁定，纯空间图）：
— 平台 = 悬崖边的圆形石台。
— 祭坛巨石：在悬崖边，相对平台的画面中右。
— 仪式中心：画面中左，距祭坛约 3 米。
— 180° 轴：摄影机始终在尸体场地这一侧——绝不跨过这条线。
— 逆光：深红的地平线辉光从平台后方来，从摄影机视角给剪影打轮廓光。
```

**③ 罗盘句**：写明**摄影机在哪一侧**、**它绝不跨越哪条线**。这一句让整场戏的每个切都落在同一根轴上。切镜之后**重新说一遍谁在哪、看向哪**（模型不记得上一镜）。

**④ 站位的写法**：**位置来自 plate 里能看见的东西，不是距离**。米数对模型毫无意义，"在英雄左边"更没有意义（它不知道英雄在哪）。把每个身体**系到一个它看得见的地标**（那盏灯、第二排椅、舞台边缘、那扇门），左右一律用**画面左／画面右**。

**⑤ 给静态对话一个"房间的角落"，不要整个房间**——空间越少，模型的选择越少。

> **当生成与真实地点矛盾时，重读参考，不要改提示词。**（有个足球场戏连着几版都在攻击错的那半场，因为提示词是凭记忆写的。）

## 三、世界与颜色：在资产阶段决定，不在后期

**看与颜色在准备与建资产时就定死**，后期只做统一。

- **分世界，每个世界一个调性**。例：庄园＝淹没的卡其绿＋湿沥青；街头场景＝混凝土＋一台 CRT 屏；母亲家＝暖白＋蜂蜜橡木；俱乐部＝牛血红＋桃花心木＋失泽金；XX 的世界＝漆红＋镜亮黄铜；河面＝黑水；警察的机器＝灰混凝土，一丝暖色都没有。
- **世界内部比例：80–85% 基础场 · 10–15% 一到两个强调 · 约 5% 反调。**
- **强调不是调出来的，而是"在画面里找到一个有真实光源的物件"**：一扇绿门、一盏钠灯、一个橙帐篷、显示器的辉光。
- **同一个色相，用做工与年代区分，而不是用深浅**：两个富人内景都是红与金——但**老的那个是锈蚀**（干牛血红、失泽金、一盏旧灯），**新的那个是抛光**（饱和绯红、镜亮黄铜、许多同款灯对称排列）。**写出来，两个内景才不像同一套景。**

## 四、资产压力测试（视频测试，不是看图）

**一张好看的角色表什么都不能证明。** 真正的问题是：**这个资产能不能扛住运动？**

- **十次生成**——不同动作、不同景别、不同地点——**10/10 都能认出来**。要按真实提示词跑：他跑、他说唱、他打电话、他哭、他笑。**"脸只在英雄冷静时才稳"这件事，就是这样发现的。**
- **角色和地点必须一起测**。两个资产互相拉扯；对着空无测角色等于什么都没测——**地点没准备好之前，绝不测英雄**。
- **还要测他会同框的资产**：单独站得住的主角，**在双人镜里经常就崩了**。
- **崩掉的时候，可能错在资产，不只是提示词**：糊掉的半身、中途溶解的主角，**和"描述太弱"一样常见的原因是"表太弱／plate 太弱"**。**先改词；同一处再崩，就重建资产。**

## 五、迭代纪律

- **一次只改一件事。** 每一次迭代都是**外科式**的：**改一行，其余逐字不动**。整段重写会**把已经成立的部分一起丢掉**。
- **一切进日志**：版本号、改了什么、判定。没有日志，你**无法复现一个好镜头**，也**无法判断这个修法是否已经试过**。日志还会告诉你**哪些镜头在顽强抵抗**（某个镜头走到 v15、另一个 v10）。
- **十到十五次规则**：如果一个镜头迭代了十到十五次还没成立（复杂镜头可放宽到十五至二十次），**问题不在措辞**。**去改镜头**：拆成两个、去掉一个动作、换个角度、用另一种方式拿到物理。**救回来的每一个失败镜头都是靠改镜头，从来不是靠改措辞。**
- **复杂动作绝不要放在计时的中段**。门砸不开的实况是：英雄在门边磨蹭，然后冻住。现在让**动作开篇**——"他已经在半挥，门已经在裂"——而**接近门的那一段另做一镜**。
- **如果模型一直画你没要的东西，就点名禁掉它**（点名写进正向锁定）。某个铁路 plate 老是变成火车站（站台、雨棚、成排泛光灯、停着的列车），一条把它们全部列为不存在的锁、加上**精确的轨道数**，就治好了。
- **描述词与每个世界的固定 look-and-camera 块要当常量维护**：一次编辑，同时更新所有镜头。

## 六、法条，而不是请求

**一条规则要成为"法"，需要三样东西：一个名字 · 画面里可见的证据 · 一句说明什么算废镜。**

提示词库里可以有两百条具名锁。常用的四条：

| 法条 | 怎么写 |
|---|---|
| **尺度** | **三件事同时设定**：真实世界的度量 ＋ 占画面的比例 ＋ 与画面里已有物体的比较 |
| **高度** | **给一个"失败方向"**："一厘米都不许更高；拿不准就渲染得略矮一点" |
| **物件计数** | **逐帧写**——模型会在运动中复制道具（从手里被打掉的三明治会变成两个） |
| **情绪夹持** | **从两侧夹住**，因为一个词写出的语气会变成漫画："在喜悦与攻击之间；一张愤怒扭曲的脸 = 废镜；一个柔和发亮的微笑 = 废镜；面无表情 = 废镜" |

**巨人靠尺度锚**：一个尺寸比较 ＋ **画面里要有一个人形作参照**，两样缺一，模型就会**悄悄把巨人缩回人身高**。

```text
尺度法——画面里要有可见证据：石像守卫高三十米——他的头消失在穹顶的黑暗里，
他摊开的手掌有一辆家用车那么宽，而站在他脚边的男主只到他脚踝稍上。
每一帧里，守卫的剪影都是他身边那个人形高度的至少五倍，
且画框装不下他的脚和头同时出现。
读起来像一个"个子很大的人"、或者能与站立的人舒适同框 = 废镜。
```

**群戏**：**群体是一个"角色"资产**（给一个身高与服装的范围）＋一到两个有自己资产的领队群演用于特写。**中景要直接说数字**（"20+"），否则模型这一条给你三个人、下一条给你一百个。**超过十五人，群体会塌成三到五个身形**——所以"满场"要写成"**身体挤在舞台边缘、手臂在前景**"，绝不要只写一个数字。

**群体就是年代**：2011 年的演出**没有手机、没有发光的屏**——黑的剪影、摇摆的手臂、偶尔一个打火机的火苗。

**两个空间之间的转场靠门槛**：把**两个地点资产放进同一条提示词**，接缝是一道**有光反差的门洞**（"温暖的琥珀色房间，拱门后是一条冷蓝的走廊"）。**光反差解释了色板的变化，也原谅了小的几何错误。**

## 七、年代：年份是一条规则，不是装饰

**画面里不许有新于设定年份的东西。** 模型会**把每一镜拖向今天**——于是：

- 年份写进**每一张 location plate**，并在**每一条提示词里重复**。
- **一个群演拿手机，这一镜就废了。**
- 车、招牌、屏幕、衣服的版型，全部按年检。

## 八、剪辑并行与生成监督

- **剪辑与生成并行**：剪辑师**随到随装配**场次，并**下单缺什么**——"需要一个切到手的插入镜头""需要一个更宽的"。**重拍只要几分钟，所以是剪辑在塑造生产**，而不是等生产结束才开始剪。
- **生成的节奏几乎总是偏慢**：**剪得比感觉上更狠**，并计划把**每一段的首尾各修掉半秒**——边缘会漂。
- **生成监督是一个专职岗位，不是一种期望**：有人专门看**装配好的剪辑**，找出那些"技术上存在但不成立"的镜头——**晚了一拍的眼神、读错的手、第三秒开始漂的脸**——并**带着具名修法**退回去。**活到银幕上的劣品花的是声誉；在装配里发现的劣品只花一条提示词。**

## 九、后期：清理 → 颜色统一 → 声音

1. **清理（定剪之后、调色之前）**：AI 素材几乎**总是带着"干活时看不见、上大屏就看见"的缺陷**——多出来的手指、"沸腾"的纹理、招牌上的假字。**小缺陷逐帧修**；**彻底坏掉的镜头用保存的最终提示词改一行重生成**（这只因提示词库完整且带版本才可行）。**第一优先：脸与手的特写。**
2. **颜色从"统一"开始**：每次生成都自带一套内置调色，所以调色师的第一件事是**把同一场戏的相邻镜头拉到一个 look**。**look 本身早在准备阶段就烤进了 location 资产**——所以调色师是**精修，不是发明**。
3. **声音：不重录**。台词直接从生成里清出来——**降噪、抹平片段之间的音色、把声音放进空间**；只有某一段出来完全没有可用人声时才用棚录。**声音设计与音乐建在"连续的环境声"之上**：一个共享的气氛**把生成的镜头粘进同一个空间**，即便画面在漂。**所以"只做音效、不要音乐"在每一条提示词里是强制的**（音乐属于后期，生成的配乐只会挡住剪辑）。

## 十、规模参考（让你知道长片是什么量级）

- 一部约 95 分钟的长片：**14 人左右、预算可控制在 50 万美元以内、资产准备完成后 14 天生成**。
- 一部 114 分钟的长片：**137 场戏、约 600 个已批准资产**（主角与反派 74 张、配角与动物 52 张、集数角色 90 张、道具 159 件、场景 plate 200 张以上、生成总量四十余万次）。
- **每次生成的参考预算是 9 张图 / 3 段视频 / 3 段音频**——**这个预算决定一镜能装几个具名英雄**。
- 提示词库可以沉淀到**两百条具名锁**，其中相当一部分以"= 废镜"结尾。

> **五条压舱石**：① 资产先行（**在每一个角色、地点、道具都锁定并压力测试之前，不生成任何一镜**——这一条省下的钱比其余全部加起来还多）；② 每次描述一切；③ 一次只改一件事；④ **给模型更少的自由**（一个角落而不是一个房间、一个地标而不是开阔空间、一张图而不是猜、每镜一支镜头、每拍一个动作；法条要有可见证据）；⑤ **凑不起来就简化镜头，而不是简化措辞**。

## 十一、交付前质检

- [ ] 每个镜头卡片四组齐全，且**镜号在卡片／日志／提示词文件三处一致**？
- [ ] 每场戏都有**主镜（第一秒宽景）＋ GEO 空间图 ＋ 罗盘句**？
- [ ] 每个资产都过了**视频压力测试**（同地点、同框资产，10/10 可辨认）？
- [ ] 有**版本日志**，且每次迭代只改一行？
- [ ] 关键约束写成了**法条**（有名字、有可见证据、有废镜判据）？
- [ ] 设定年份的物品纪律已写进 plate 与每条提示词？
- [ ] 是否已设**生成监督**岗位，并在装配阶段退回不成立的镜头？
- [ ] 定剪后按**清理 → 颜色统一 → 声音**的顺序走，且"只做音效"已写进每条提示词？
