# 美学配方库（成片级电影美学）

把剧本里的「戏型」翻译成一套**成片级美学配方**，并在创作基准阶段**主动提案**——不让创作者自己想"这场戏该长什么样"。

本库解决的不是"提示词怎么写"，而是"**这场戏应该拍成哪一种电影**"。配方最终仍展开为 `STYLE GUIDE.md` 的 `D/P/C/R/S` 语义。

## 一、与 STYLE 视觉语言库的分工（两者不可互替）

| | `STYLE GUIDE.md` 视觉语言库 | **本库 AESTHETICS 美学配方库** |
|---|---|---|
| 承载 | 可检索的视觉语言**词汇**：`D01–D14` 导演语言、`P01–P10` 摄影风格、`C01–C14` 胶片、`R01–R02` 印片、`S1–S3` 强度 | 7 套**成片级配方**：整片／整场的成套方案 |
| 粒度 | 四维抽象描述，可自由拆解组合 | 成套参数：胶片格式＋胶片型号＋光比＋构图法＋材质组合＋现成提示词 |
| 触发 | 需要"选画风条目"时**按需调用** | 剧本命中特定戏型时**主动提案**（P1 必做一次、P4 二次触发） |
| 产物 | 一条画面提示词 | 一套全片／单场美学，落进「全片风格锁定」 |
| 关系 | **底层词汇表** | **建立在其上**；配方最终展开为 D/P/C/R/S 语义 |

一句话区分：**STYLE 是字典，AESTHETICS 是菜谱。** 字典负责"这个词怎么写"，菜谱负责"这道菜整道怎么配"。

> **与导演预设（`references/DIRECTOR-VISION GUIDE.md`）的关系**：两者都是成片级，**导演预设优先**——先按「导演风格声明」冻结摄影与视听取舍，再从配方里取**不冲突的部分**（通常是色彩策略与氛围）；冲突时以导演声明为准。

## 四、主动引导规则（硬性）

1. **P1 必做一次。** 读完剧本、判定类型后，**先于**「全片风格锁定」提出候选。按 P1「1 部主参考＋最多 1 部补充参考」的既有口径：推荐 **2–3 个候选**，让创作者选 1 个作主美学、最多 1 个作补充，然后才写「全片风格锁定」。不得跳过、不得先锁定再补提案。
2. **P4 二次触发。** 当某个镜头命中匹配表、而全片主美学未覆盖时（典型：全片是现代都市，但有一场近身打斗；全片写实，但有一场太空闪回），**主动提案"本镜局部换配方"**，并说明它与全片锁定的关系。
3. **一次只提一组。** 与主流程"每轮只展示当前需要确认的一步"一致：推荐最多 3 个候选，选定后不再反复推销同一件事。
4. **不得静默执行。** 任何配方选定必须写进 P1「全片风格锁定」或 P4 分镜备注——可见、可追溯。
5. **无命中就明说。** 剧本没有配方级美学需求时，明确写"本片无配方级美学需求，按 `D/P/C/R` 常规取型"，**不得硬套**配方。
6. **提案必须引用剧本事实。** 理由要落到剧本里的具体元素（年代、地域、场次内容），禁止只写"这个风格很带感"。

### 提案话术模板

P1：

```text
【美学提案】剧本判定为〈类型／年代／地域〉，命中以下美学配方：
1. A0x〈名称〉｜适合原因：〈引用剧本具体事实〉｜建议落点：〈哪几场／哪几镜〉｜代价：〈风格强度，及与他场次的协调成本〉
2. A0y〈名称〉｜…
3. A0z〈名称〉｜…
【请选择】选 1 个作主美学，最多再选 1 个作补充参考；直接说"不用"则按 D/P/C/R 常规取型。
```

P4：

```text
【局部美学提案】第〈N〉镜命中 A0x〈名称〉；本片当前主美学为〈现有锁定〉。
【请决定】① 本镜局部采用（仅本镜，不改全片锁定）；② 全片改用 A0x；③ 保持现状。
```

## 五、输出与合规规范

- **只改视觉形式。** 配方只决定"怎么拍"，主体、数量、动作、环境、事件一律以剧本与 P1 为中心，不得因配方而改戏、加角色、加事件。
- **参数进画面描述，不进正文参数位。** 胶片格式、胶片型号、焦段、光比、色板一律展开为自然语言写进画面描述；**比例、分辨率、时长、模型名不得进入提示词正文**。
- **胶片与印片一律"模拟"口径。** 写"70 毫米大画幅胶片模拟质感""依士曼彩色负片模拟色彩"，**不得表述为实体胶片拍摄**；数字摄影机与实体胶片不得并列。
- **导演姓名只作检索标签。** 命中配方不等于可以写"某某导演作品"；对外交付默认稳定模式，姓名展开为具体视觉特征；锚点模式（"受某导演影像语言启发"）仅在创作者明确要求时使用。
- **一律正向表达。** 配方原文中若有"排除／禁止／不要 XX"的负面清单，**必须改写为正向替代**——例如"排除数字视频感"改写为"光化学胶片质感、真实有机颗粒"。**不得把负面块搬进提示词**（与 LIRA「严禁负面堆叠」一致）。
- **工具与平台字样不得出现。** 配方来源文章里提到的第三方生成工具名一律不出现在成品中，统一表述为"图像提示词／视频提示词"。
- **与 P1 冲突时以 P1 为准。** 配方是提案不是覆盖：全片画幅、帧率、摄影机镜头家族、环境色彩策略与声音口径仍由 P1 锁定；配方只在其自身作用范围内生效。

## 六、在本流水线中的调用点

| 阶段 | 用法 |
|---|---|
| P1 | **主动提案** 2–3 个候选（本文件第三节匹配表），选定后展开为具体视觉特征写入「全片风格锁定」 |
| P4 | 命中匹配表且主美学未覆盖的镜头，**二次提案**局部配方；配方同时决定首帧图的画风取向 |
| P5 | 不重复推荐；按 P4 已确定的配方把视觉特征写进视频提示词 |
| P2 / P3 | 沿用 P1 已选配方，不另行选美学 |

### 现成提示词的两类分工（`examples/aesthetics/`）

每套配方文件都分两节，**对应两个不同阶段，不得混用、不得跳过中间环节**：

| 现成提示词 | 环节 | 用法 | 强制中间环节 |
|---|---|---|---|
| **分镜级图像提示词**（生图） | **P4** | 作该镜首帧的**图像提示词基础** | 必须接 P1「全片风格锁定」前缀，经 `LIRA GUIDE.md` 润色 |
| **视频动效提示词**（生视频） | **P5** | 仅作**动效与运镜参考素材** | 必须经 `ACTING` → `EMOTION` → `CINEDANCE` 合成 |

> 图像提示词是静态关键帧用语（构图／光色／材质），不含动作时态与运镜；视频提示词是动作＋运镜用语，不含静态构图参数。**两者不得混用**——混用会同时污染出图与出视频。
