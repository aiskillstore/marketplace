# 资产体系（成对资产 · 命名约定 · 状态管理 · 声音锁定）

这一层解决的是 AI 影视最大的隐性成本：**同一个角色在不同镜头里变成不同的人，同一个房间在镜头移动后变成另一个房间**。解法只有一个——**资产先行**。

## 在本流水线中的定位与边界

- **只管资产的"结构与命名"**，不管怎么出图。出图的模型路由归 `LIRA GUIDE.md`，画风归 `STYLE GUIDE.md`，美学配方归 `AESTHETICS GUIDE.md`。
- **只管资产的"身份与状态"**，不管表演。角色的动机、战术、情绪归 `ACTING GUIDE.md` / `EMOTION GUIDE.md`。
- **不单独计为一个子技能**，是贯穿 P1–P5 的规范层。

## 何时调用 · 怎么调用

| 时机 | 怎么用 |
|---|---|
| **P1 起草** | 用「六、资产前置闸门」先列资产总表（角色 / 场景 / 道具 / 声音），确定命名前缀与项目代号 |
| **P2 角色资产** | 按「一」成对建资产、「四」两遍法出角色表；每个状态一个独立资产 |
| **P2 关键道具 / P3 场景资产** | 按「二」命名；同一空间的不同光线状态、同一道具的不同形态，各自独立命名 |
| **P4 / P5 引用资产** | 提示词里只引用**已存在、已命名、已锁定**的资产标签；引用顺序按 `PROMPT-DOCTRINE GUIDE.md` 的块 2 |
| **P5 声音** | 按「五」把每个主要角色的声音写成锁定块，逐镜原样粘贴 |

## 一、资产 = 文本 + 图像

**一个资产是一对：文本描述词 + 参考图。**

- **文本描述词**：逐字进入每一条用到它的提示词，**连同义词都不换**。
- **参考图**：模型用来锚定的那个像素基准。
- 两者合起来，才能让一个主角在几十个镜头里是同一个人、一个房间在镜头移动后还是同一个房间。

**推论**：角色/场景/道具的"文本描述词"必须在 P2/P3 定稿并冻结；P4/P5 只引用，不改写。

- **称呼纪律**：一旦某个元素成为资产，**后续所有提示词里只能用它唯一的 `@tag` 称呼它**，绝不写"那个男人""那扇门""那把钥匙"。散文式指代会让模型把它当成一个新东西重新发明。
- **规模认知**：一部两分钟、几乎只在一个室内发生、人物不超过三人的短片，资产表也会长到**约三十个标签**（两三个主要角色与一位长辈、门、花束、钥匙、手袋、购物袋、走廊、楼梯井、厨房、夜景天际线，再加**一整架站位示意图**）。别以为只有大制作才需要资产化——**片越短、镜头越密，越需要**。
- **剪影锁定**：如果某个角色有半部片子不露脸（例如"夜闯者"必须从背影就认得出来），**他的文本描述词必须把剪影写死**（服装的条纹走向、衬衫颜色、身上唯一的金属件）。脸不可用时，轮廓就是身份。
- **参考要标角色，地点参考要禁继承**：往提示词里喂资产时，**逐项写明它的角色**（"@某人 作角色参考""@某地 作地点参考"）——不写，模型就自己决定，而且会决定错：**抄了构图而不是脸，或者抄了脸而不是色板**。**地点参考要显式禁止继承**："不用作起始帧，不继承构图、角度与调色，只取空间与质感"。
- **每个 tag 只在"启用参考"那一段出现一次。** 在提示词末尾重复一个 tag，是**生成拒绝启动**最常见的原因。
- **每次生成的参考预算是 9 张图 / 3 段视频 / 3 段音频。** 这个预算**决定一镜能装几个具名英雄**——排分镜时就要按它倒推。
- **描述词是常量，不是草稿。** 建资产时用它、在提示词里用它、传到平台画布上还是用它——**同一份文本，三处一致**。

## 二、命名约定（一人一名，一物一名）

**全项目（包括人、场景、道具、站位示意图）用同一套标签约定。一个元素只有一个名字。**

| 前缀 | 用途 | 示例 |
|---|---|---|
| `@char_` | 角色 | `@char_代号_角色名` |
| `@loc_` | 场景 / 地点母板 | `@loc_代号_场景名_场次_版本` |
| `@prop_` | 关键道具 | `@prop_代号_道具名` |
| `@staging_` | 站位示意图（见 `BLOCKING GUIDE.md`） | `@staging_代号_场次_版本` |

- 命名里带上**场次与版本**（`_s01_v1`），重拍时递增版本（`_v2`、`_v3`），**每镜只引用当前有效版本**——否则会出现"鬼站位/鬼资产"。
- 不做这套约定的后果是可预期的：项目一大就长出重复资产，同一扇窗活在三个名字下，没人知道哪张参考才是真的。

## 三、新状态 = 新资产，绝不覆盖

**角色/场景/道具的每一个新状态，都新建一个资产、给一个新名字。**

- 同一个人：餐厅里的他是资产 A，屋顶上的他是资产 B，受伤后的他是资产 C。
- 同一扇窗：从室内看是一个资产，从街上看是另一个资产。
- 同一件道具：完好、破损、被手持，各自独立。

**反面做法**：在旧资产上直接覆盖新状态。它会让此前所有镜头失去参照，等于全片返工。

**状态资产用于连续性（高频用法）**：当剧情要求的状态与已有资产不符——故事里窗是开着的、资产里窗是关的——**模型相信参考图，不相信故事**，于是那扇窗会在下一镜"自己关上"。正解不是跟模型商量，而是**新建一个"窗开着"的独立资产**。这类"状态资产"是治连续性失误最省力的办法。

**做变体只有一种做法**：**拿原始表，只改变化的东西**（换衣服、伤口、湿透的布料），其余**保持不变**——**在图像编辑里对原表做点改动，再用遮罩把那一点点变化手动贴回原件**。这就是皮肤质感得以幸存的原因，因为**一张图永远不会整张过第二遍模型**：多过一遍，纹理就掉一层、颜色就漂一点；**过两遍之后脸会变对称、变塑料、没生气——而这种死掉的质感，之后会伤到视频里的表演。**

## 四、角色表两遍法

角色用**两个模型、两遍**做出来：

角色用**两个模型、两遍**做出来，最后合成**一张三格角色表**：

1. **第一遍：定身份。** 永远先生成**特写**——让模型在最大细节下把这张脸捕捉下来。这张特写是该角色**所有其它资产的校验基准**。
2. **第二遍：定造型。** 生成**全身图**（正面与背面），服装（剪裁、材质、轮廓）与已锁定的那张脸对齐。
3. **合成三格表**：正面全身 · 背面全身 · **大特写**——一张图里三格，提示词里直接写明"**同一个人，三格一致**"。
4. **把全身那两格的人头去掉。** 远景里那张又小又软的脸，**正是模型会抄进宽景的脸**；把头去掉，脸就只剩一个来源——大特写。**它扛得住得多。**
5. **特写用三分之四视角**（脸略微侧转，不是正对）——一张图同时给出正面与侧面两个角度，模型对这个人长什么样的把握更完整。
6. **特写做两版：笑与不笑。** 否则模型会在角色第一次笑的时候**自己发明牙齿与下巴的行为**，那个笑容会是别人的嘴。**每一个有台词的角色都值得做。**
7. 状态差异（尘、汗、伤口、兜帽）用**遮罩逐点合成**，绝不动底片。**原始特写底片原样保留，永不再经过任何模型。**

**选脸：要"最可信的"，不要"最好看的"。** 一个"漂亮但假"的脸会在后面的视频阶段暴露它的假——**那时已经太晚**。**并且一定要检查眼睛**：即便是深色的眼睛，瞳孔里也要有一点细小的反光（眼神光）；**没有它，这张脸是死的，而任何视频模型都演不了一个死掉的脸。**

**把表做得"无聊"是故意的**：中性灰背景、平光、真实皮肤与可见毛孔、**不修图**。**电影感不在角色表里**——它住在场景 plate 与视频提示词里。**把胶片颗粒和电影镜头烤进角色表，这个角色就会把这套 look 带进每一场戏，并且不再对新的光做出反应。**

**表上的四条禁令**（都是被打出来的）：

- **避开"摄影棚"这个词**——模型会真的在画面里画出摄影棚的灯架与灯具，并**把棚光烤进之后每一次视频生成**。改写为"**无摄影棚、无器材、无墙**"。
- **"头顶主光"会把那盏灯本身画出来。**
- **轮辐光（边缘光）也禁**——一张带着漂亮边缘光的表，**会把那道光拖进每一场戏**，角色就不再对真实的光做反应了。
- **手上的道具保持空**：**每一个物件都是它自己的资产**——**从一个角色表里长出来的道具，永远没办法被放下、扔出去或被人拿走。**

## 四·B、地点 plate 的六条纪律

1. **用三分之四视角拍，不要正对。** 一张正对的"漂亮照片"到了宽景就是**一张平壁纸**：模型读不出体积，**而且超出画框的每一侧，它都会自己发明新的环境**。三分之四给模型纵深，它能正确安放英雄，并且**从一张 plate 里给出近乎一整圈的机位**。
2. **每个地点留一个锚**——一根柱子、一盏灯、一张沙发、一把歪椅——**并把调度系在它上面**。"英雄在灯旁，面向门"成立；"英雄在房间里"是抽奖。
3. **保持一个光逻辑**：一个光源、一个阴影方向，**绝不出两个太阳**——否则每个新角度都会重新发明一次打光。
4. **plate 里没有人物、没有武器。**
5. **用真实表面的语言对抗渲染感**：锈、裂纹、胶带、指纹、油渍、水痕。
6. **反打有两条路**：
   - **路一**：在图像编辑里画同一房间的另一个角，**匹配原图的柔焦**。
   - **路二（更省）**：生成一段**空地点**的视频，让摄影机**缓慢穿行**这个空间——模型会**与你的 plate 一致地**画出房间的其它几面。**截图你需要的那一面**，拿进图像编辑，让它**提升质感与光**。**一张图换来一整套地点 kit。**

**一个对话地点需要这套 kit**（三分之四、正面、反打 ＋ 每个在场英雄一张背景 plate）；**一个过场地点只需要一个角度。**

## 四·C、动画线的角色主参考：360° 转身视频

**静态角色表管不住跨代一致性**——它给的是几个离散角度，一旦要求模型在运动、表情、说话状态下复现，就开始漂。**动画与混合媒介项目的角色主参考优先用一段 360° 转身视频。**（完整口径与调用时机见 `references/ANIMATION GUIDE.md` 第四节。）

| 段 | 内容 | 作用 |
|---|---|---|
| 转身段 | 完整 360° 缓慢转身，中性表情、放松站姿 | 锁定轮廓、比例、服装四面细节 |
| 表情段 | 本片需要的关键表情依次给出（笑／不笑／惊讶／不悦） | 防止「第一次笑时用了别人的嘴」 |
| 声音段 | 说一句本片台词 | 与第五节的声音锁定对齐，供音色与唇形参考 |

- 它仍是 `@char_` 资产的一种**形态**，命名规则与「新状态＝新资产」**照常适用**；
- 静态三格角色表**仍然要建**（用于身份定格与快速比对），两者不冲突；
- **参考必须齐全**：动画线上，参考里缺失的角色会被模型**凭空发明**（实测：参考里的载具是空的，模型自己往车里塞了随机乘客）。每个应当出镜的常驻角色，都必须在输入里被清楚代表；
- **会动的资产（含角色）在动画线上必须过视频测试**才允许出镜：**用视频测**、在与成片相同的光线与镜头条件下测、**与它的地点和将会同框的资产一起测**。

## 五、声音锁定（VOICE LOCK）与重配音

**声音是一个"写下来的条件"，不是一个感觉。**

- 每个主要角色写一个声音锁定块，把四件事定死：**音区（register）、音色（timbre）、语速与节奏（tempo）、说话方式（manner）**。
- 该块**一次定稿、存盘，之后逐字粘贴进每一次生成，连一个同义词都不换**——换词就会漂。
- **跨镜同音的正解**：当同一声音要在相隔数周的镜头里保持一致，不要跟模型硬碰。做法是**画面先行**：先出画面，再用**单一声音参考做一次专门的重配音**——只动音频、画面不动，逐帧对上已经在画面上的口型。
- 声音锁定块在 P1 与全片声音圣经一起锁定，属 P1 资产。
- **口音写成条件，不是标签**：口音属于声音块，写法是**"一个类别 + 一两个音标标记"**（例："南伦敦街头口音——掉 h、喉塞 t、-ing 变 -in'"）。**关键处在台词里把它拼出来。** 一个角色一个口音，永不漂。
- **一个片段只装一个说话人和一句短话。** 更长的对话写成**独立片段**，回答放在下一个里。
- **写混音**：人声干净、贴近麦克风；环境声在它之下；**有人说话时环境声下压**。
- **罕见名字要给标音**，否则模型会念坏。

## 六、资产前置闸门

**任何一个镜头，在它涉及的全部资产（角色、场景、道具、声音）都"已存在、已命名、已锁定"之前，不允许生成。**

这条闸门要在 P4 逐镜校验，在 P5 逐镜复查：

- 本镜出现的每一个角色，是否有对应的、已锁定版本的 `@char_` 资产？
- 场景是否有匹配**本镜光线状态**的 `@loc_` 资产？
- 道具是否存在且形态正确（完好/破损/被手持）？
- 有对白的角色，是否有已锁定的声音块？
- 有没有任何资产被"临场改写描述词"以凑合本镜？（有 → 停下，回到 P2/P3 补资产）

## 七、交付前质检清单

1. 全项目资产表是否与提示词里用到的标签**一一对应**，没有孤儿标签、没有重复命名？
2. 每个角色资产是否有"特写身份锚点 + 全身造型"两遍，且底片未被二次生成？
3. 每个新状态是否是独立资产，而不是覆盖？
4. 所有引用是否都带**有效版本号**，且每镜只引用一个版本？
5. 所有对白角色是否都有已锁定的声音块，且逐镜粘贴的是**原文**？
6. 是否存在"某镜所需的资产尚未建立"的情况？

- [ ] 动画／混合媒介项目：角色是否有 **360° 转身视频**主参考（转身＋表情＋声音三段）？会动的资产是否都过了**视频测试**（用视频测、与成片同条件、与地点和同框资产一起测）？
