## 1. 核心模型

情绪不是“脸做成什么样”，而是角色在某段关系里接受信息、保护自己并作出选择的过程。

### 情绪命题

```text
角色想要什么（欲望）
+ 害怕失去什么（代价）
+ 当下必须表现成什么样（社交面具）
+ 哪个刺激改变了理解（触发）
+ 身体先泄露什么（非自愿反应）
+ 角色怎样重新控制（策略）
+ 最终做了什么（决定）
+ 控制之后还剩什么（余韵）
```

例如“失恋”不是机制。机制可以是：她想体面接受拒绝，害怕显得可怜；听见确定答案后笑意晚半拍才消失，先礼貌点头，声音却变薄，最后说“我知道了”，视线停在对方肩旁而不再对视。

### 内外双线表

| 节拍 | 内在事件 | 主导外部信号 | 辅助信号 | 关系/环境回声 |
|---|---|---|---|---|
| 刺激 | 听到/看到新信息 | 视线停住 | 吸气未完成 | 手停在道具上 |
| 处理 | 尚未相信 | 焦点短暂游离 | 嘴角保留旧表情 | 环境声被静默凸显 |
| 控制 | 维持体面 | 重新对视 | 唇线收住 | 坐姿更端正 |
| 泄漏 | 控制变吃力 | 下眼睑湿润 | 拇指摩擦杯沿 | 杯子轻响 |
| 决定 | 接受/拒绝/反击 | 改变视线对象 | 声音落稳 | 推回或接过道具 |
| 余韵 | 情绪未消失 | 目光变冷/变软 | 呼吸仍不齐 | 动作停在半途 |

## 2. 八节拍算法

按场景选择，不要求全部出现。

1. **基线/面具**：建立角色原先的节奏与想让别人看到的状态。
2. **刺激**：一句话、一个人、一个物件或一个动作改变局面。
3. **认知延迟**：旧表情短暂滞留；眼神停顿或失焦，大脑仍在处理。
4. **身体先反应**：呼吸、吞咽、手指、重心等先于完整表情发生。
5. **控制**：角色整理呼吸、重新对视、摆正道具或挤出礼貌反应。
6. **微小泄漏**：单侧嘴角、下眼睑、尾音、手部习惯动作暴露真实情绪。
7. **选择/行动**：说出一句话、放下武器、接过碗、后退、留下或离开。
8. **情绪残留**：表情不回到中性；保留改变后的焦点、呼吸、泪光或距离。

## 3. 自然性的五个关键

### A. 延迟

信息先抵达，理解随后发生，情绪最后成形。噩耗后可先保留笑，背叛后可先短暂空白，危险后可先屏息再回避。不要把触发与最终表情写在同一瞬间。

### B. 错位

不同通道不必同步：嘴角维持礼貌，眼神先暗；语句说“没事”，尾音却轻；手仍执行日常动作，动作速度已变慢。错位体现隐藏和关系压力。

### C. 非对称

真实面部常有轻微左右差：单侧嘴角先动、一侧眉尾略抬、目光从对方眼睛移到肩旁。一次轻微非对称足够，不要每个节拍都指定。

### D. 稀疏

每个节拍只突出 1 个主信号。让一个视线停顿比“眉眼鼻口喉全部变化”更可信。细节必须服务认知变化，不为炫技。

### E. 残留

收情绪不是清零。控制成功后仍可有眼眶薄湿、唇线略紧、呼吸晚一拍恢复、握力未松、视线不再回到对方。

## 4. 时长缩放

- **3-5 秒**：刺激 → 身体先反应 → 一个决定或余韵。只做一个转折。
- **6-10 秒**：基线 → 刺激/延迟 → 控制或泄漏 → 余韵。
- **11-15 秒**：基线 → 刺激 → 延迟 → 控制 → 泄漏 → 决定 → 余韵。
- **超过 15 秒**：按关系或权力变化拆组，不把同一张脸的细节无限延长。

时间段是节奏容器，不是要求每秒换表情。允许保持、停顿和空白。

## 5. 常见情绪机制

### 悲伤/噩耗

旧状态滞留 → 听懂 → 焦点松动 → 呼吸变浅 → 维持体面 → 湿润/吞咽泄漏 → 接受或否认 → 空或软的余韵。不要默认落泪。

### 愤怒

受辱/越界 → 确认对方意图 → 身体变静、视线固定 → 声音降低 → 一个精准动作或重音 → 决定进攻/退出。危险的愤怒常更安静，不必先吼。

### 恐惧

察觉异常 → 屏息听/看 → 视线寻找出口或威胁 → 重心准备移动 → 压住声音 → 做出逃、藏、装作无事的选择。避免持续瞪眼和随机颤抖。

### 爱意/暧昧

注意对方 → 想靠近又怕暴露 → 视线接触后移开 → 小动作整理自己或道具 → 声音稍软 → 重新接触视线 → 留下未说出口的余韵。避免全程甜笑。

### 失望/拒绝

期待仍在 → 答案落下 → 表情晚一拍收回 → 挤出礼貌 → 眼神与话语分离 → 点头/收回动作 → 体面但变远。

### 喜悦/释然

先确认安全或答案 → 呼气释放 → 面部从眼周开始松开 → 笑意逐步扩散 → 一个靠近或接过的动作 → 笑容回收但身体更松。避免瞬间满脸大笑。

### 羞耻/愧疚

被看见或承认错误 → 视线难以停在对方身上 → 身体缩小或动作变得过分规整 → 话语绕开关键字 → 被迫说出事实 → 短暂对视 → 承担后果。不要把羞耻等同于一直低头。
