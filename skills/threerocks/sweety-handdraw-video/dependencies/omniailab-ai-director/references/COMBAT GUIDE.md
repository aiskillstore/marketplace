# COMBAT — 打斗专项层（高燃对抗动作导演）

把打斗创意转换为可执行的 Seedance 2.5 高密度对抗提示词契约。目标不是堆叠"电影级、顶级、震撼"等形容词，而是让镜头有明确观察位置和运动目的，让角色在清楚的空间内持续交战，每次攻击都有防守、受力、环境反馈和可见终点。

## 在本流水线中的定位与边界

本文件是 OmniAiLab AI导演 skill 的**打斗专项层**，挂在 CINEDANCE（视频提示词）体系下，与 ACTING（表演）、EMOTION（情绪）、LIRA（图像）、STYLE（画风）并列协作，**不单独计为一个子技能**。它只负责「这十秒怎么打」——攻防编排、空间锚点、镜头契约、物理反馈与终结处理。

六条边界规则（重要，优先于本文件内部的默认值）：

1. **条件触发。** 仅当剧本／分镜中确实存在近身对抗、兵器战、拳脚战或能力型终结战时，才接入本层。不含对抗的镜头不启用本层，避免把普通动作镜头过度编排成打斗。
2. **媒介口径从属主流程。** 本流水线的**默认媒介为真人实拍影视级写实质感**；P1 判定为动画／混合媒介时（见 `references/ANIMATION GUIDE.md`），以 P1「全片风格锁定」的媒介声明为唯一口径——此时本文件的二维水墨、赛璐璐、手绘动画语法按该声明启用，且**动画原理（挤压拉伸／预备动作／跟随重叠／弧形轨迹／夸张）优先于物理正确**。任何情况下都不得用本文件的媒介默认值覆盖 P1 的媒介、画幅与镜头家族。
3. **声音口径从属主流程。** 本文件的默认「同期音效、无配乐」是**单镜动作层**的描述口径，不等于全片声音方案。全片 BGM、字幕与音效分层仍按 P1 声音圣经与 P6 执行。
4. **镜头口径从属主流程。** 镜头契约中的景别、机位、观察轴与运镜必须服从 P4 已确认的分镜设计与 P1 摄影基准。本层负责把打斗镜头写清楚、写可执行，不覆盖 P4 的整体镜头设计，也不改变已确认的切镜结构。
5. **参数不进正文。** 比例、分辨率、时长、模型名一律放平台 UI（P5 参数表），不写入提示词正文。本文件中出现的"宽幅横幅""本镜时长"等均为语境描述，不是参数。
6. **只处理已定稿剧情。** 不得借本层新增角色、招式或改变胜负结局；对抗结果以剧本为准，本层只负责把它拍出来。

平台口径：文中 `Seedance` 统一指 **OmniAiLab** 视频节点在架模型 **Seedance 2.5**。署名统一为 `OmniAiLab`，不出现其它品牌。

与站位层的关系：站位的**坐标、朝向、姿势与武器 ID** 由 `BLOCKING GUIDE.md` 与 `blocking-weapon-library.md` 提供——本层负责"怎么打"，站位层负责"人站在哪、朝哪、手里是哪一件"。兵器一律取站位武器库的稳定 ID，不得另起名；站位约束先落到坐标，再交本层编排动作。

## 触发条件

**使用本层：**

- 4–15 秒的近身兵器战、拳脚战或能力型终结战。
- 单条高密度打斗，或长序列中的一个终结片段。
- 图生视频（I2V）为主，兼容文生视频（T2V）、参考生视频（R2V）、首尾帧（FLF2V）与视频延续。
- 写实电影为**默认媒介**；项目本身为二维动画、水墨、赛璐璐或三维时按其媒介语法执行（媒介判定与动画原理见 `references/ANIMATION GUIDE.md`）。

**不要使用本层：**

- 大规模战争全景、多人军团调度（超出本层三锚点与双人轴的控制范围）。
- 以对白、情绪表演或产品展示为主的镜头（应走 ACTING／EMOTION）。
- 需要一条提示词承载超过 15 秒的完整故事（应先拆为连续片段）。

## 与其他子技能的分工

| 层 | 管什么 | 在本层打斗镜头里的角色 |
|---|---|---|
| ACTING | 表演是否成立：目标、障碍、策略、节拍、身体任务、潜台词 | 提供角色在这一镜的**表演段落**（出手前的意图、吃亏后的反应） |
| EMOTION | 情绪怎么发生：情绪命题、内外双线、眼神落点、声音包络 | 提供被打断、被击中、被压制时的**情绪节拍**，避免"面无表情地打" |
| **COMBAT（本文件）** | **对抗怎么编排**：攻防成对、物理闭环、空间锚点、镜头契约、终结处理 | 把上面两层与分镜需求编排成可执行的十秒动作脊柱 |
| CINEDANCE | 镜头怎么拍得稳：第一帧、空间调度、视线、光学、光线、物理与连续性 | 承接本层产出的动作脊柱与镜头契约，合成为最终视频提示词 |
| LIRA／STYLE | 图像与画风 | 负责首帧与本层无关；画风一律由 P1 锁定与视觉语言库提供 |

## 1. 建立最小制作简报

从剧本与 P4 分镜中提取下列变量。已有信息不得重复询问；缺失项可采用默认值：

| 变量 | 含义 | 默认值 |
|---|---|---|
| `medium` | 媒介：写实／三维／二维动画 | 按 P1 全片锁定，写实默认 |
| `fighter_a` / `fighter_b` | 外形、武器、屏幕方向 | A 左→右，B 右→左 |
| `anchor_left` | 左侧空间锚点 | 环境中的大型固定物 |
| `anchor_center` | 中央交战锚点 | 开阔交锋区域 |
| `anchor_right` | 右侧空间锚点 | 高差、出口或障碍 |
| `shot_structure` | 单镜头／分阶段长镜头／多镜头 | 分阶段连续镜头 |
| `camera_axis` | A/B 交战轴与越轴规则 | A 左 B 右，不越轴 |
| `shot_scale_arc` | 景别变化 | 全景→双人中景→全景结果 |
| `camera_motion_arc` | 主运镜的起点、触发与终点 | 跟随→侧移→后撤 |
| `outcome` | 最终结果 | 胜负强烈暗示，不血腥 |
| `audio_policy` | 声音策略（单镜层） | 同期音效，无配乐（全片声音见边界规则 3） |

若三个锚点未给出，从场景中选择彼此可区分、不会移动的三个位置。锚点必须能用"左侧/中央/右侧"或"前景/中景/后景"清楚描述。

用户未指定镜头时，不可直接套用"推拉摇移环绕"。先根据动作任务选择景别和机位，再选择最少且最有效的运动。默认保持 A 在画面左侧、B 在画面右侧；只有通过正俯拍、中性正面或明确遮挡转场重新建立方向，才允许越轴。

## 2. 先选择生成模式

- **I2V（首选）**：首帧图拥有角色、构图和美术；只补充画面中看不到的运动、节奏、受力、声音和保持项，不重新描绘整张图片。
- **T2V**：提示词需包含角色、场景、美术和动作。
- **R2V**：逐个声明素材角色，例如"@视频1 只参考攻防节奏，不转移人物、服装、场景和美术"；若另有运镜参考，使用 `@视频2` 只负责景别、机位、运动节奏和镜头终点。
- **FLF2V**：首帧图与尾帧图分别锚定起点和终点；只描述从起点到终点的连续动作。
- **延续**：以已验收视频的**真实尾帧**和**真实运动方向**为起点，不以计划中的尾帧为起点。

一份参考素材只承担一个主要职责。动作参考与运镜参考优先拆成两个视频，不得让同一视频同时控制人物身份、动作、镜头、场景、美术和声音。

> 注意：本流水线**必须图生视频**，禁止直接文生视频（纯黑场／纯文字镜头除外）。T2V 仅在本层单独试水时使用，正式生产一律 I2V。

## 3. 锁定媒介语法

### 写实或三维（本流水线默认）

可以使用低机位追拍、侧向跟拍、快速后撤、短促甩镜等摄影语言。先选能读清攻防的景别和机位，再选运动方式；每个时间段只保留一个主要运镜。运动模糊只用于边缘和轨迹，人物轮廓与兵器接触点必须可读。复杂连击期间优先稳定侧向跟拍，不使用 360 度环绕；环绕只用于动作密度较低、地理关系已经建立的短阶段。

### 手绘二维、水墨或赛璐璐（仅当项目本身为二维媒介时启用）

第一句明确媒介，例如：

> 原创手绘二维国风水墨动作动画，宣纸底、焦墨干笔、飞白线条、有限色。

使用动画制作语言：

- 二拍一用于蓄势、步法和回收。
- 一拍一仅用于突进、连击和终结。
- 涂抹帧表现挥击弧线。
- 单张高反差冲击帧表现关键命中。
- 背景横向卷动、多层视差和速度线表现超高速。
- 身体停止后，头发、衣摆、尘沙和兵器继续回落或震颤。
- 用画稿横移、纵向摇移、布局推近、背景急拉和多层视差表达二维"运镜"；每个动作阶段只使用一种主要画面运动。

二维提示词可以使用全景、双人中景、近景、低位、侧面、俯视等构图词，但不得使用焦距、镜头型号、景深、光圈、传感器、真实快门等摄影参数，以免漂移成真人或伪 3D。

## 4. 编排动作脊柱

默认使用六段式脊柱。它是**因果结构**，不要求机械地逐秒写满；各段时长按本镜实际时长等比缩放：

1. **开场｜直接入战**
   两人已在中央锚点交战；用一次明确碰撞建立速度、方向和重量。

2. **压迫链**
   进攻方完成三招以内的短链；防守方贴身闪避／格挡并借环境反弹回中央。

3. **换位链**
   围绕中央与一个侧锚点高速换位。每次移动都由攻击导致，不做无目的跑位。

4. **环境反作用**
   一方被压至侧锚点，利用墙面、坡面、残骸或地形反蹬；回到中央完成升级碰撞。

5. **终结与反转**
   一方发动不超过四动作的终结链，另一方连续化解并抓住唯一空隙反击。

6. **交错结果**
   双方完成一次交错终击；用滑停、震颤、破损、碎屑和扩散冲击波暗示胜负，不停下摆 pose。

若本镜时长较短（约 4–6 秒），只保留"直接入战 → 压迫／反转 → 交错结果"三段；若较长（10–15 秒），把中段展开为完整六段。扩展时长时**不要通过增加招式填满**，而是把每段的物理反馈写得更细。

## 5. 编写动作链

每个时间段遵循：

`攻击目的 → 身体与武器动作 → 对手响应 → 接触反馈 → 位移结果 → 环境余波`

示例：

> A 贴地横切逼 B 离开右侧斜坡；B 竖刃格挡，前臂被震开后立即回收；两人脚下沙地向外爆裂，B 向后滑移半步但仍留在近身距离。

规则：

- 一条短链最多 3–4 个动作。
- 招式必须能由前一个动作的重心和惯性自然进入。
- 武器不得无原因脱手、变形或穿透。
- 角色受到冲击后必须出现手腕偏转、肩线下沉、脚步滑移、躯干回弹等至少一种反馈。
- 环境特效必须由动作触发，不可独立抢戏。
- 能量效果不得遮蔽人物超过关键接触瞬间。

## 6. 先建立镜头契约

镜头不是动作之后附加的装饰。每个阶段在写招式前先填写：

`叙事目的 → 景别 → 机位/观察角度 → A/B 画面位置 → 主运镜 → 动作触发点 → 镜头终点 → 下一阶段交接状态`

示例：

> 显示 B 把 A 逼离右侧锚点 → 双人中景 → 交战轴侧面低位 → A 左 B 右 → 向左平行跟随 → B 第一记横切时启动 → 在中央锚点停住并保留两人全身 → 下一阶段从 A 踩住残骸开始。

镜头契约必须包含：

- **观察轴**：明确 A/B 左右关系。默认不越过交战轴。
- **安全构图**：复杂动作保持双人中景或全景，并在运动方向前方保留空间。
- **启动原因**：人物冲刺、被击退、跃起或冲击波扩张触发镜头运动。
- **运动终点**：落在下一个锚点、关键接触构图或结果构图，不写无终点的"持续环绕"。
- **交接状态**：记录人物位置、运动方向、镜头高度和运动是否仍在继续。

## 7. 选择景别、机位和运动

| 动作任务 | 推荐景别 | 推荐机位 | 首选运动 | 目的 |
|---|---|---|---|---|
| 建立三锚点与屏幕方向 | 双人全景/大全景 | 侧面或低位三分之四 | 短跟随或二维背景平移 | 让观众先看懂空间 |
| 高速压迫链 | 双人中景 | 交战轴侧面 | 平行跟随 | 同时看清攻防与脚步 |
| 单次关键命中 | 双人中近景 | 接触点一侧 | 短促推近或保持构图 | 强调接触和受力 |
| 高低差、跃起或坠落 | 全景 | 低位仰视/高位俯视 | 垂直跟随或画稿纵移 | 交代高度和落点 |
| 环境反蹬与回中心 | 双人全景 | 侧后方三分之四 | 背后短追后转侧跟 | 显示借力路径 |
| 能量对撞与冲击扩张 | 全景 | 正面或斜侧 | 快速后撤/背景急拉 | 容纳冲击范围 |
| 终结交错与惯性结果 | 双人中景转全景 | 保持原轴 | 跟过交错点后减速 | 不以 pose 结束 |

执行规则：

1. **一阶段一主运镜**：一个阶段只允许一种主要运动；短促构图修正不算第二运镜。
2. **动作越复杂，镜头越简单**：三至四动作连击使用平行跟随或稳定双人构图，不叠加环绕、推拉和甩镜。
3. **先看见再加速**：开场先用 0.3–0.8 秒建立 A/B 方向和锚点，再进入高速；若首帧已经建立空间，可直接加速。
4. **接触时稳定**：关键命中前完成大幅运镜，碰撞瞬间保持接触点可读；冲击后再后撤或甩向结果。
5. **近景有时限**：近景只用于一个明确接触或表情反应，通常不超过 0.5 秒；复杂连招不得长期使用近景。
6. **剪切落在完成态**：多镜头结构在格挡完成、落地、撞击或遮挡后切，不在武器尚未接触时切断动作。

## 8. 观察轴与越轴重建

- 默认全程保持 A 左 B 右，不越轴。这是观众读懂攻防关系的前提。
- **越轴必须重建方向**：确需越轴时，只允许通过三种方式之一完成，且必须在提示词中写明——
  1. **正俯拍重建**：切至接近垂直的俯视，把 A/B 关系压成上下或对角，重新交代方位后再回到侧面。
  2. **中性正面重建**：切至完全正对交战轴的正面机位，让左右关系暂时消失，再从另一侧重新建立。
  3. **遮挡转场重建**：用角色身体、烟尘、残骸或前景物遮满画面完成转场，在遮挡解除的瞬间建立新的左右关系。
- 越轴不得通过"镜头绕到对面"这类连续环绕偷渡——那是丢失观察轴，不是重建观察轴。
- 每次重建后必须重新声明观察轴，并在下一阶段交接状态中记录新的左右关系。

见「附录 B：交付前质检清单」。自检不通过时先修正再交付，不把问题上交。

# 附录：打斗不能靠剪辑救（帧链 · 单条时间轴 · 切进身体）

本附录来自一场三招擒拿的实战复盘。**核心结论：打斗的连贯性必须在生成阶段解决，剪辑救不回来。**

## 一、为什么逐段生成必然发顿

拆成独立片段生成后，**每个片段都重新猜姿势与节奏**，于是每一刀里都渗出停顿。事后再剪，只会把停顿剪得更明显。

## 二、四件套

1. **帧链**：第 N 段视频的**最后一帧**作为第 N+1 段的**第一帧**；动作要**跨切点在中途交接**，不要在动作完成处切。
2. **钱镜头用一镜到底**：把整套组合写成**单条秒级时间轴**（第 0–0.6 秒……第 0.6–1.4 秒……），**实时速度**，并**点名禁掉慢动作**——视频模型很喜欢自己把打斗放慢。
3. **动作写成武术指导的笔记，不是情绪**：
   - **风格即人物**：她的动作柔、走圆、擒拿引带、推手——冠军只用最小力；他的动作直、重、慢半拍。打斗风格本身就是人物塑造。
   - **每个动作都要命名并给出矢量**，否则模型每次都翻物理：`她用脚把他从自己身上翻过去；他落地时脸朝她，头朝向窗户。`（不给矢量，他每一条的身体落法都不一样。）
4. **打斗关键帧配自己的站位示意图**：手脚的火柴人图，作为**首帧几何**附着（配合 `BLOCKING GUIDE.md` 附录 C）。

## 三、两条降本增效的做法

- **当全身连续性太贵，就切进身体**：手、腰、脚的快速插入镜头。跳切能藏住过渡、增加冲击力，而且**脚的特写比两人全身远景难崩得多**。
- **让一个运镜干最多的活**：例如"一个从她脚部向上摇起的单镜头，摇到一半时她把他扫倒在地"——一个镜头同时完成信息、节奏与力量。

## 四、质检追加项

- [ ] 相邻打斗片段之间是否构成**帧链**（末帧＝首帧）？
- [ ] 钱镜头是否**一镜到底**、是否写成**秒级时间轴**、是否**点名禁掉慢动作**？
- [ ] 每个动作是否**有名字、有矢量**？
- [ ] 是否给打斗关键帧配了**火柴人站位图**并作为首帧几何附着？
- [ ] 是否在必要时**切进身体**（手／腰／脚）来替代难以维持的全身连续性？
