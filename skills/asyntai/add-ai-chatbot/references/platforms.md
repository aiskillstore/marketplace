# Install guides for hosted platforms

On these platforms the user installs Asyntai in the platform admin, not in
code. Give the user the guide link for their platform. Most guides use one of
two routes: the Asyntai app or plugin from the platform's own store, or the
snippet pasted into the platform's custom code (footer or header) setting.

If the platform is not in this list, use the general guide:
https://asyntai.com/documentation/installation/html/
