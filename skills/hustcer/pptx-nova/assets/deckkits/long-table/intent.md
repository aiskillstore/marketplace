# Long Table 2.0

Long Table 是暖纸底与陶土红单墨的编辑语言：重无衬线标题、衬线斜体正文、圆形版号、
胶囊按钮、描边卡片、细实线/虚线、节目单与日程账簿。它承载用户提供的内容，
不自动插入餐饮政策、活动状态、日期、报价或参考项目文案。

## 标准使用

保留 `long-table` id 和八个 `longTable*Slide` 页型；通过标准 discovery → content →
validate/build/Create 使用。`design.json` 是颜色、字体、几何、容量的唯一事实源；
`long-table-editorial/v1` 负责逐实例编译组件计划，执行器消费该计划。用户无需手写坐标。
`layoutId: auto` 按容量和近期构图确定性选择；显式布局仍须通过容量检查。

| 职责      | 布局               | 变化                            |
| --------- | ------------------ | ------------------------------- |
| Cover     | split / verso      | 标题与版号左右交换              |
| Manifesto | letter / wide      | 左标题右信笺 / 横向标题与正文   |
| Index     | cards / register   | 描边卡片 / 编辑式条目           |
| Featured  | right / left       | 详情账簿左右交换                |
| Menu      | ledger / programme | 语义标题 / 居中节目单并突出副题 |
| Quote     | centered / reading | 居中大引文 / 阅读栏与侧署名     |
| Calendar  | ledger             | 五列表格与状态胶囊              |
| Closing   | left / centered    | 左排 / 居中收束                 |

完整长 deck 以封面开始、收尾结束；摘录使用 `meta.designScope: "excerpt"`。
正文、卡片、条目、单元格按真实内容检查；不存在可容纳的布局时须调整组织或拆页。
不删除字段、不静默截断数组、不把数据改成假值、不无限缩字。

## 字段迁移

八类页型及全部可见字段保留。数组容量允许稀疏内容，最大合理密度由合同投影到 schema；
空白字符串、未知字段、未知布局和超容量输入报错。封面的 `bigEdition`、`bigLabel`、
`bigMeta` 各自可选，各自有独立可见区域；不再因缺少版号而丢弃另外两个字段。
`details`、`items`、`rows`、`footer` 保留原 tuple 顺序和全部单元格。
标题大小写与手动换行由 content 决定；示例将展示标题写为大写，不自动改写用户专名。

源模板日程和旧版页脚有小字。新版提高最小字号、增高容器并保留分隔线间距。
圆形、胶囊和标签由原生形状持有文字，统一水平与垂直居中。
封面修复了旧版先写编号、后画实心圆导致编号隐藏的问题。

## 原生对象与同步边界

文字、圆、线、卡片和胶囊可编辑。胶囊是原生自由路径，保持真实半圆端点。
日程是原生五列表格，所有表头/单元格参与对象回读；状态轮廓是独立原生路径。
在 PowerPoint 手工调整表格行高/列宽不会同步胶囊轮廓，须从 content 重新生成。
没有图表或图片输入能力；清单的数字只是用户提供的展示文本，不推导为统计图。

## 设计裁决与环境

参考来自八页 HTML；键盘导航和网页控件不进入 PPTX。保留单墨身份和扁平层次，
以可读性修正原图的小字和旧实现的窄列。程序单变体保留源模板突出副题的构图。

本次环境缺少 Bricolage Grotesque / Fraunces，明确替换为 Arial Black / Georgia；
中文及中英混排使用 Arial Unicode MS，并保持 CJK 正体。字体不随套件打包。
Georgia 的衬线与字宽不同于 Fraunces，不能声称逐像素还原或跨平台字体一致。
原生 pattern 试验在 canonical 输出中丢失奶油纸底，因此保留纯色纸面近似，省略细点纹理。
这项限制与机器门禁分开记录；通过机器检查不能代替实际看图和原生宿主验证。

创建链的合同迁移不证明任意旧 PPTX 翻新无损。已有独立 `refurbishProfile` 保留，
不因为创建套件升级而扩写翻新能力或自动获得 production 资格。
