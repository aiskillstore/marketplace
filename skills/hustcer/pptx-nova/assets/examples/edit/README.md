# Existing-deck edit examples

- `edit-title.patch.json` illustrates text, run style and notes edits. Resolve selectors from the
  actual source; sample shape names do not identify your objects.
- `micro-edit-matrix.json` lists successful and rejected Micro Edit patterns, minimum evidence,
  quality checks and escalation conditions.

Inspect the source deck and follow the edit workflow. These patterns do not replace source binding,
selector evidence, dry-run or the required post-edit review.
