# Creation examples

- `qbr-outline.json` shows a quarterly business review outline with page kinds, content and branding.
  It is outline input, rather than a DeckKit content manifest or an xdoc patch.
- `quarterly-report.patch.json` shows an xdoc quarterly-report patch with slide recipes, chart data
  and table content. These files are separate input examples, not a generated source/output pair.

Prepare the outline or patch through the selected workflow, validate with the current xdoc schema,
and run the required dry-run and visual checks.
