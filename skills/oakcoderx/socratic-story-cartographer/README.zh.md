# Socratic Story Cartographer

## 概览

一个面向创作者的叙事诊断 Skill，用苏格拉底式提问支持小说、剧本、片段和多集大纲的初审。

版本：2.2
作者：Solopup.co

目标不是直接下“通过/不通过”结论，而是先找出最有杠杆作用的问题点，并定位最值得先改的方向。

## 来历

该版本受李飞飞“提问先于答案”这一思路启发：先通过有约束的提问降低不确定性，再做判断，通常比直接给结论更稳。

我在自己的创作流程中也在用，并用于小说与剧本的初步评估。

## 本版强化

- 输入自动分类：小说 / 剧本 / 大纲 / 场景 / 混合 / 不确定。
- 输出使用叙事语言：人物目标、阻碍、选择、代价、因果、后果。
- 固定化诊断循环，支持快速迭代复测。
- 长文本先建立来源清单和阅读覆盖账本，避免用局部证据替代整部作品。
- 全季或多集大纲可输出制片人拍板页、问题发生路线、硬错误和可执行修改任务卡。
- 明确权限边界：AI 初审、评分或测试通过，不等于人工批准、正典升级或制作就绪。

## 诊断循环（默认3轮）

每轮执行：

1. 观察
2. 提出2–3个竞争解释
3. 用两个测试验证当前最强解释：
   - 一次可证伪测试
   - 一次反事实测试
4. 选一个根因杠杆
5. 给修正方案
   - 小修优先方案
   - 可选替代方向
6. 预估后果
7. 仅在关键时提出1–2个高价值问题
8. 盲测后更新判断

## 输出内容

每轮固定返回：

- 当前判断
- 竞争解释
- 测试设计
- 根因杠杆点
- 方案建议
- 预期影响
- 回归风险
- 未闭合疑点
- 可选作者提问（仅在有实质影响时）

最终补充：

- 这轮故事的核心结论
- 做了什么变化、为什么这样做
- 剩余风险
- 下一步Top3修复优先级
- 继续/暂停建议

## 怎么提问（推荐输入结构）

建议用下面结构发起诊断，减少猜测和歧义：

1. `对象：小说 / 剧本 / 大纲 / 场景 / 混合`
2. `目标：初审 / 根因定位 / 最小修改 / 基准对标`
3. `轮数：3（可改）`
4. `范围：`（贴入文本）
5. `限制：先不改文 / 允许最小修 / 允许结构改`

### 提示词示例

- `跑3轮，先做这段小说初审，先给最有杠杆作用的问题和下一步最小修复方向。`
- `只看这一幕，先不改文，判断这个场景是否真的推进了状态变化。`
- `以制片人视角做基准评估，说清楚更像“可推进”还是“先暂停”。`
- `完整初审这份全季大纲，核验阅读覆盖，把主要问题追溯到首次出现，并编译成制片人拍板页和修改任务卡。`

### 输出你会得到什么

- 当前判断
- 证据锚点（文本依据）
- 竞争解释
- 测试逻辑（可证伪+反事实）
- 根因杠杆
- 小修方案 + 备选方向
- 收益预期 / 风险代价
- 未闭合不确定性
- 需要时的高价值追问（1-3个以内）

每次尽量按“对象—目标—范围—边界”来提问，便于后续版本可对比。

## 边界

- 不输出“绿灯/不绿灯”这类绝对判定。
- 不替代版权、法律、合规、制作流程决策。
- 不做完整重写流程。
- 不臆造未写明的人物信息、动机和剧情细节。
