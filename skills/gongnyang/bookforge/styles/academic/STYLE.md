# Academic — 학술·논문형

## 정체성
논거가 주인공이고 조판은 투명해야 한다. 장식을 걷어낸 대칭 판면 위에 번호 위계·표·수식·주석이 한 치 어긋남 없이 정렬된 한국어 학술 단행본.
NIPS/LaTeX 논문의 골격(이중 룰 표제·booktabs 3선표·각주 헤어라인·하단 중앙 쪽번호)을 국내 학술서 관행(신국판·명조 본문·「」『』·표 1-1)으로 번역한다.
독자는 통독하지 않고 참조한다 — 모든 요소는 번호로 지목 가능해야 하고, 어느 면을 펼쳐도 자기 위치를 안다.

## 판형·판면

**판형: 신국판 153 × 225mm** (선정 근거: 서지 실측으로 확인된 국내 학술 단행본 표준. 도서관 목록 형태사항 높이 집계에서 아카넷 23cm 58%, 한울아카데미·고려대출판부는 23cm 거의 단일, 나남 23cm 우세 — 23cm = 실제 221~230mm = 신국판. 인쇄 실무 표기는 152×225 또는 153×224, 제작 사이즈 155×231. 반면 46배판 188×257은 한국교육개발원 발간물 100%가 채택한 **연구보고서 판형**이고, KDI·KIEP·한국노동연구원은 24cm급(231~240mm) 변형판이라 단행본형 전자책 기본값으로 부적합 — 아래 variant로 분리)

| 항목 | 값 |
|---|---|
| 재단 크기 | 153 × 225mm |
| 여백 | 안(gutter) 25mm / 바깥 22mm / 위 26mm / 아래 34.9mm |
| 판면 | **106.0 × 164.1mm** (300.47 × 465.17pt) |
| 조판 격자 | **1행 31자 × 1면 27행 = 837자/면** |
| 행송(baseline-to-baseline) | **17.5pt** = 본문 10pt × 1.75 |
| 여백 비례 | 위:아래 = 1 : 1.34, 안:바깥 = 1 : 0.88 (좌우 대칭 미러) |
| 도련 | 3mm, 안전선 5mm |

**실측 검증(Typst 0.14.2 / Noto Serif KR)**: 한글 자폭 = 0.966em → 10pt에서 31자 = 299.46pt ≤ 판면 폭 300.47pt. 27행 소요 높이 = 10pt + 26×17.5pt = 465pt ≤ 판면 높이 465.17pt. 두 값 모두 실렌더 1면 = 정확히 27행으로 확인.

**행송을 결정론으로 고정하는 규칙(필수)**: 엔진의 leading은 줄 간격이지 행송이 아니다. `top-edge: 0.88em, bottom-edge: -0.12em`으로 em 박스를 1em에 고정하면 **행송 = 글자크기 + leading**이 성립한다(실측 확인: 10pt + 7.5pt = 17.5pt). 이 고정 없이는 문장에 따라 행송이 흔들려 격자가 깨진다.

**행송 17.5pt = 175%의 근거**: 국내 학술지 원고 규정은 줄간격 **160%**가 사실상 통일값(한국언론학보·역사교육·스토리콘텐츠·불교철학 모두 160%), 서울대 학위논문 지침은 **170% 이상**, 단행본 편집 실무는 본문 9.5~10.5pt에 행간 **16~21pt**(=160~200%). 학술 단행본은 정보밀도 때문에 소설류(180~200%)보다 낮게 잡되 원고 규정값(160%)보다는 열어야 읽힌다 → **175%**를 채택.

**variant — 보고서판(46배판 188 × 257mm)**: 여백 안 28 / 바깥 25 / 위 30 / 아래 38mm → 판면 135 × 189mm. 본문 10.5pt / 행송 18.5pt / 1행 37자 × 29행. 1단 조판 유지(2단 금지). 표·그림이 많은 연구보고서·통계 부록에만 사용. 이 모드에서는 캡션·번호·인용 규약도 아래 각 절의 "보고서 모드" 항을 따른다.

## 폰트 스택

| 역할 | 폰트 | 크기 / 행송 | 비고 |
|---|---|---|---|
| 본문 한글 | Noto Serif KR Regular | 10 / 17.5pt | 자폭 0.966em, 자간 0em |
| 본문 라틴·숫자 | Libertinus Serif Regular | 10pt | 폰트 배열 1순위(한글은 fallback) |
| 강조 | Noto Serif KR Bold / Libertinus Serif Italic | 10pt | 한글 이탤릭 금지, 볼드만 |
| 표제·러닝헤드·캡션 라벨·표 헤더 | Pretendard SemiBold / Medium | 8.5~28pt | 자간 -0.02em(14pt 이상) |
| 수식 | New Computer Modern Math | 10pt | 엔진 내장 보장 폰트 |
| 표 숫자 | Libertinus Serif, tabular lining | 9pt | 자릿수 정렬 필수 |

**폰트 배열**: `("Libertinus Serif", "Noto Serif KR")` — 라틴·숫자·문장부호를 라틴 세리프가 먼저 잡고 한글만 명조로 떨어뜨린다. 순서를 뒤집으면 숫자·괄호가 한글 폰트의 전각 글립으로 잡혀 표 정렬이 무너진다.

**장평·자간을 별도로 걸지 않는 이유**: 국내 학술 원고 규정의 사실상 표준은 **장평 93~95% / 자간 −5~−10**(한국언론학보·역사교육·스토리콘텐츠)이고 단행본 실무는 장평 95~98% / 자간 −50 안팎이다. Noto Serif KR은 **한글 자폭이 이미 0.966em**(=장평 96.6%)이라 이 관행 구간에 들어와 있으므로 장평 100%·자간 0em을 그대로 쓴다. 밀도를 더 높여야 하면 **자간은 −0.02em까지만** 내린다(그 아래는 한글 낱자가 붙어 보인다).

**fetch 후 승격 옵션**: KoPubWorld바탕체 Medium(본문) / KoPubWorld돋움체 Medium(표제). 출판 전용 설계라 본문 가독성은 상위. **단 교체 시 자폭을 반드시 재측정하고 판면 폭을 재계산한다** — 전각(1.0em) 설계라면 10pt에서 31자 = 310pt로 판면을 4pt 초과해 1행 30자로 내려가고 격자 전체가 바뀐다. 자폭 1.0em이면 자간 -0.02em을 걸어 31자를 유지하거나, 바깥 여백을 22 → 18.5mm로 조정한다.

**크기 표(전부 명시)**: 부 제목 24 / 장 제목 20 / 절 11.5 / 항 10.5 / 본문 10 / 인용블록 9.5 / 정의·정리 박스 9.5 / 캡션 9 / 표 본문 9 / 쪽번호 9 / 각주 8.5 / 러닝헤드 8.5 / 출처·주 8pt.
행송: 인용블록 16 / 캡션 14 / 표 본문 14 / 각주 12.5 / 출처 12pt.
(각주 크기 근거: 국내 학술지 규정 각주 = 본문 −1~−2pt(80~90%)가 일관되고, 각주 줄간격은 본문 160%보다 죈 **130%**를 쓰는 규정이 다수. 8.5pt × 147% = 12.5pt로 관행보다 약간만 열어 잡았다.)

## 표지 문법 (타이포 중심)

- 전면 `--paper`. 사진·일러스트·패턴·그라데이션 전면 금지.
- **이중 룰 표제 블록**(견본 계승): 판면 상단에서 48mm 지점에 굵은 룰 1.2pt `--accent` 폭 106mm → 아래 9mm 간격 → 표제 → 아래 9mm 간격 → 헤어라인 0.4pt `--rule` 폭 106mm.
- 표제: Pretendard SemiBold 28pt / 행송 36pt / 자간 -0.02em / 중앙 정렬 / 최대 2행. 3행이 되면 24pt·행송 31pt로 1단계만 내린다.
- 부제: Noto Serif KR Regular 13pt / 행송 19pt, 하단 룰에서 아래 7mm, 중앙 정렬, 최대 2행.
- 저자: Pretendard Medium 11.5pt, 부제에서 아래 16mm. 소속·직위는 다음 줄 Pretendard Regular 9pt `--muted`. 공저 3인 이하는 가로 나열(구분 `·`), 4인 이상은 2열 그리드(열 간 8mm).
- 발행처: 판면 하단에서 위로 0mm 지점(=아래 여백 상단선) Pretendard Medium 9.5pt 중앙, 로고 금지(문자만).
- 속표지: 표제 20pt·부제 11pt·저자 10pt로 축소한 동일 구조, 룰은 헤어라인 1개만.
- 판권면: 좌하단 정렬, Pretendard Regular 8.5pt / 행송 13pt, 서지·ISBN·판차·저작권 표시 순.

## 목차 문법

- 표제 `차 례`(글자 사이 1em 벌림) Pretendard SemiBold 16pt, 판면 상단에서 24mm 지점, 좌측 정렬. 아래 10mm에 헤어라인 0.4pt 전폭.
- 위계별: 부 12pt SemiBold(위 여백 7mm) / 장 10.5pt Medium / 절 10pt Regular / 항 이하 **미수록**.
- 번호 칼럼 폭 14mm 고정(좌측 정렬), 제목은 14mm 지점에서 시작. 절은 추가로 14mm 들여쓰기.
- **리더 점선 금지.** 제목과 쪽번호 사이는 공백(flex), 쪽번호는 우측 정렬 폭 9mm에 tabular lining 숫자.
- 행송 16pt, 장과 장 사이 2.5mm, 부와 부 사이 7mm.
- 표 차례·그림 차례는 본문 차례 뒤 별면. 표제 `표 차례` / `그림 차례` 동일 규격, 항목은 9.5pt·행송 15pt, 번호 칼럼 폭 16mm.
- 목차 면은 앞붙이 쪽번호(i, ii, iii…)를 **하단 중앙 드롭 폴리오**(산세리프 9 pt)로 **첫 면부터** 표시, 러닝헤드 없음. (실물 확정 — 예제 `academic-game-theory.pdf` p3가 `i`, p4가 `ii`를 찍는다. book-anatomy 「목차」의 "미표시 또는 드롭 폴리오" 허용 형식 중 드롭 폴리오를 택한 것이며, 같은 문서 러닝 시스템 절의 "목차 첫 면 표시 금지"는 러닝헤드·본문형 폴리오 기준이다.)

## 지면 템플릿

**제목 위계(4단 고정, 5단 이상 금지)**
`부 → 제N장 → N.N 절 → N.N.N 항 → 가. 목(런인)`
사회과학 보고서 모드 대안: `1. → 1) → (1) → 가.` (한국언론정보학회 논문작성규정 계열)

| 위계 | 조판 |
|---|---|
| 절 `1.1` | Pretendard SemiBold 11.5pt, 위 26.25pt(=행송 1.5배) / 아래 8.75pt, 번호와 제목 사이 1.5자 |
| 항 `1.1.1` | Pretendard Medium 10.5pt, 위 17.5pt / 아래 5pt |
| 목 `가.` | 본문 크기 Noto Serif KR Bold, 문단 첫 줄에 런인 + 전각 마침표 없이 `가.` 뒤 1자 공백 |

**문단**
- 첫 줄 들여쓰기 **1em(=10pt=3.53mm)**, klreq 권고대로 글자 폭 단위. **모든 문단에 적용**(제목 직후 첫 문단 포함 — 국내 학술서 관행).
- 문단 사이 추가 여백 0 (문단 간격 = 행간과 동일). **빈 줄로 문단을 나누지 않는다.**
- 양끝맞춤 on. 한글 하이픈 금지(`hyphenate: false`), 라틴 단어만 하이픈 허용.
- 줄바꿈은 **음절 단위**. klreq §7.1.1은 "한글로 끝나는 줄은 글자 단위 또는 어절 단위로 나누며, 어느 쪽을 쓸지는 문단별 또는 문서 전체 단위로 작성자가 정한다"고만 규정해 기본값을 강제하지 않는다. 본 팩은 **양끝맞춤을 지키기 위해 음절 단위를 택한다** — 어절 단위 강제(한글 덩어리 boxing)를 실렌더로 시험한 결과 어절 사이가 벌어져 판면이 파열됐다. 어절 단위가 반드시 필요한 원고라면 **양끝맞춤을 왼끝맞춤으로 함께 바꿔야** 한다. 둘을 동시에 쓰는 조합은 금지.
- 고아·과부 줄 2행 이상 확보. 제목 뒤 본문이 2행 미만으로 남으면 제목째 다음 면으로 넘긴다.

**한글–라틴 혼식 간격**: 엔진의 CJK-라틴 자동 간격은 한자·가나에만 적용되고 **한글에는 적용되지 않는다**(실측: `한글A한글` 폭이 `auto`/`none` 동일 45.59pt). 따라서 한글↔라틴 알파벳 경계에 **1/8em(1.25pt)** 를 삽입하는 치환 규칙을 렌더 직전에 건다. 단 `2020년`, `제3장`처럼 **숫자+한글 결합에는 넣지 않는다**(실측: 무차별 적용 시 `제 1장`, `2020 년`으로 오작동). 규칙 대상은 `한글 ↔ 라틴 알파벳` 경계 하나로 한정한다.
※ 근거 정확히: klreq §7.3.4가 1/8em을 권고하는 대상은 **기호·수학기호 ↔ 한글**이고, 기호 ↔ 숫자/라틴은 0으로 규정한다. 한글 ↔ 라틴에 대한 명시 권고는 klreq에 없으므로 위 1/8em은 **같은 문서의 최소 시각 간격값을 한글–라틴 경계에 확장 적용한 합성 규칙**이다. 그 밖의 klreq 명시 간격: 한글·한자·가나 상호 간 0, 닫는 괄호 → 여는 괄호 **반각(1/2em)**, 닫는 괄호 → 중점류 **사분각(1/4em)**.

**금칙(klreq §7.1.2~3)**: 행두 금칙 = 닫는 괄호(cl2) · 하이픈류(cl5) · 문장 구분 기호 `？！`(cl6) · 중점류 `· : ; ： ；`(cl7) · 온점류(cl8) · 쉼표류(cl9) · 반복 기호 `〃`(cl11) · 장음 기호 `ー`(cl12). 행말 금칙 = **여는 괄호(cl1) 하나뿐**(일본어 jlreq보다 단순). 분리 불가 문자 `— … ‥`(cl10)는 두 자를 쪼개지 않는다. 엔진의 UAX#14 기본 줄바꿈이 이 목록 대부분을 이미 만족하므로, 파일럿에서 `『「(` 로 끝나는 줄과 `。」』)·…` 로 시작하는 줄만 표본 검수한다.

**인용 블록**: 좌우 각 2자(7.06mm) 들여쓰기, 9.5pt / 행송 16pt, 위아래 각 5mm, 첫 줄 들여쓰기 없음, 좌측 세로 룰·따옴표 장식 없음. 출처는 다음 줄 우측 정렬 8.5pt `--muted`.

**정의·정리 박스**
- 배경 `--accent-tint`, 좌측 세로 룰 1.5pt `--accent`, 내부 여백 좌우 8pt / 상하 6pt, 위아래 바깥 여백 각 5mm.
- 라벨 `정의 1-1` `정리 1-1` `명제 1-1` `보조정리 1-1` `따름정리 1-1` — Pretendard SemiBold 9.5pt `--accent`, 본문과 같은 줄 런인, 라벨 뒤 1자 공백. 부제가 있으면 `정리 1-1 (베이즈 정리).`
- 본문 9.5pt / 행송 16pt.
- **증명은 박스 없음**: `증명.` Noto Serif KR Bold 런인 + 본문 9.5pt, 말미에 `□`를 우측 정렬로 붙인다.
- 번호는 장별 리셋, 정의·정리·명제가 **하나의 연번**을 공유한다(따로 매기면 참조가 흔들린다).

**수식**: 블록 수식 위아래 각 6pt, 중앙 정렬, 번호 `(1-1)` 우측 정렬, 장별 리셋(학술지·학위논문은 전편 연번 `(1)`, 장별 번호는 보고서·교재 계열 관행 — 본 팩은 장 단위 참조가 잦은 단행본이므로 장별을 택한다. 보고서 모드 대안 표기 `[식 1-1]`). 연산 기호는 **양쪽을 띄운다**: `a + b = c`(O) / `a+b=c`(X). 인라인 수식은 행송을 넘기지 않는 높이로 제한(분수는 `/` 인라인 형태). **상호참조 보정 필수** — 번호를 장 카운터로 만들면 참조가 "참조된 위치"의 장 번호를 집는 알려진 결함이 있으므로, 참조 시 대상 요소의 위치에서 카운터를 읽도록 참조 규칙을 재정의한다.

**목록**: 번호 목록 `1) 2) 3)`, 불릿은 `–`(en dash). 중점 `·`는 klreq 구분 부호와 충돌하므로 불릿으로 쓰지 않는다. 들여쓰기 1자, 항목 사이 0, 항목 내 되돌이 들여쓰기 정렬.

## 각주·인용·참고문헌 규약

**두 모드 — 원고 분야에 따라 하나를 골라 책 전체에 고정한다**

| 모드 | 해당 분야 | 출처를 어디에 |
|---|---|---|
| **내주식(기본)** | 언론학·사회과학·교육학·경제학 | 본문 괄호 내주. 각주는 부연 설명 전용 |
| **각주식** | 역사학·국문학·철학·불교학·법학 등 인문 | 출처를 각주에. `앞의 책`·`같은 글`·`Ibid.` 허용 |

내주식에서는 `앞의 책 / 상게서 / 전게서 / ibid. / op. cit.` 를 **전면 금지**한다(STEPI 규정과 동일). 두 모드를 한 책에서 섞지 않는다.
각주식의 각주 출처 서식: `홍길동, 『조판의 역사』(서울: 아카넷, 2019), 113쪽.` / 재출 시 `홍길동, 앞의 책, 120쪽.`

**각주**
- 지면 하단, 8.5pt / 행송 12.5pt. 본문 안 표시는 **상첨자 아라비아**(`1` `2`)를 문장부호 **뒤**에, 각주 항목의 머리 번호는 국내 관행대로 **`1)` 형식**(HWP 각주 기본 번호 모양)으로 단다.
- 구분선: 길이 33%, 굵기 0.4pt `--rule`, 좌측 정렬. 본문↔구분선 6mm, 구분선↔첫 각주 2mm, 각주 사이 3pt, 매달린 들여쓰기 2자. (HWP 기본값은 구분선 위 2mm / 아래 2mm / 각주 사이 3mm — 단행본은 본문과의 분리를 위해 위쪽만 6mm로 넓혔다.)
- 번호는 **장별 리셋**(학술지 논문은 전편 연번이 표준이나, 단행본은 장별 리셋이 관행).
- 내주식에서 **각주는 부연 설명 전용.** 단순 출처 표시는 각주로 내리지 않는다.
- **미주 금지**(기본값). 요청 시에만 장 말 `주(註)` 항으로 모으고, 이 경우 각주는 쓰지 않는다.

**본문 내 인용**
- 괄호형 `(홍길동, 2020: 15)` / 서술형 `홍길동(2020)은 …`
- 외국 저자는 성만 + 첫 등장 시 원어 병기: `웨버(Weber, 1922: 30)`
- 공저 2인 `(홍길동·김철수, 2020)`, 3인 이상 `(홍길동 외, 2020)`
- 재인용 `(Weber, 1922: 30; 홍길동, 2020: 15에서 재인용)`
- 직접 인용은 40단어(한글 200자) 이하면 겹따옴표 인라인, 초과하면 인용 블록.

**참고문헌**
- 책 말미 별면, 표제 `참고문헌` Pretendard SemiBold 14pt. 9.5pt / 행송 15.5pt, 매달린 들여쓰기 2자(7.06mm), 항목 사이 2pt.
- **배열: 국내 문헌(가나다) → 동양 문헌 → 서양 문헌(알파벳)**. 동일 저자는 연도 오름차순, 같은 연도는 `2020a, 2020b`.
- 서식(저자–연도, 인문사회 기본):
  - 국문 논문 — `홍길동. 2020. 「한국어 조판의 원리」. 『한국출판학연구』 46(2): 1~20.`
  - 국문 단행본 — `홍길동. 2019. 『조판의 역사』. 서울: 아카넷.`
  - 국문 편저 장 — `홍길동. 2018. 「활자와 지면」. 김철수 편. 『출판학 강의』, 45~78. 서울: 한울아카데미.`
  - 서양 논문 — `Smith, John. 2018. "Typesetting Korean." *Journal of Typography* 12(3): 210–235.`
  - 서양 단행본 — `Smith, John. 2015. *Grid Systems*. Cambridge: Cambridge University Press.`
- **쪽수 부호**: 국문 자료는 물결표 `1~20`, 서양 자료는 붙임표 `210-235`(KIEP 규정). 같은 저자가 이어지면 저자명 자리에 줄표 — 국문은 3글자, 영문은 6글자 길이.
- 매달린 들여쓰기의 관행 근거: 한국언론학보 "첫 줄 기준 세 칸 내어쓰기". 본 팩은 2자(7.06mm)로 고정한다.

- **엔진 주의**: 내장 인용 스타일 90여 종에 **한국 서식은 없다**(중국 gb-7714, 일본 sist02는 있음). 따라서 `styles/academic/kci-ko.csl`을 동봉해 커스텀 CSL로 로드한다(커스텀 CSL 파일 로드는 실측 확인). CSL 준비 전 임시 대체는 인문 `chicago-author-date`, 사회과학 `apa`. 어떤 경우든 **국문 3건·영문 3건 스모크 렌더로 「」『』·쪽수 구분자·배열 순서를 눈으로 검수**한 뒤 통과시킨다.

## 캡션·표·그림 규약

- **번호 체계: 장-일련** `표 1-1`, `그림 1-1`. 장별 리셋. 부록은 `표 A-1`. 표와 그림은 각각 독립 연번.
- **표 캡션은 표 위** — 조사한 모든 국내 규정이 예외 없이 일치. **그림 캡션은 그림 아래**(APA계 학술지·학위논문 규칙). **보고서 모드에서만 그림 캡션도 표와 같이 위 중앙**에 둔다(KIEP·정부보고서 관행).
- 라벨 Pretendard SemiBold 9pt + 1자 공백 + 제목 Noto Serif KR 9pt / 행송 14pt. **구분자로 콜론(`:`)을 쓰지 않는다.** 캡션·출처의 9pt는 본문 대비 90%로 국내 규정 관행값과 같다.
- 표 캡션은 표 폭 기준 좌측 정렬, 그림 캡션은 도판 폭 기준 중앙 정렬. 캡션↔대상 간격 3mm.
- **단위**: 표·그림 오른쪽 위에 `(단위: 백만 원, %)`. 캡션 다음 줄 우측 정렬, 8pt `--muted`. 큰 수는 백만·십억 등 한글로 적는다.
- 자료·주: 대상 바로 아래 좌측, 8pt / 행송 12pt `--muted`. 순서는 `주: …` → `자료: …`. 위 여백 2mm. 주가 여러 개면 `1) 2) 3)`을 행 바꿔 달고, 출처가 여럿이면 세미콜론으로 잇는다. 저자가 가공했으면 `자료: 홍길동(2020, 34쪽)을 참고하여 저자 작성.`
- 유의수준 별표는 표 아래 주에서 정의하고, 주 배열은 **일반주 → 개별주 `a) b)` → 확률주 `*p<.05.` → 자료** 순.
- 본문 언급은 단행본 모드에서 `표 1-1`, 보고서 모드에서 `<표 1-1>` `[그림 1-1]`(국내 최빈형). 두 표기를 한 책에서 섞지 않는다.
- **표는 booktabs 3선표 강제**: toprule 1.0pt / 헤더 아래 midrule 0.4pt / bottomrule 1.0pt. **세로선 절대 금지**, 얼룩말 줄무늬 금지, 셀 배경 금지(합계·평균 행만 `--accent-tint` 허용, 그 위에 0.4pt 룰 1개). 국내 보고서 관행(KIEP·별첨5)은 표두 아래를 **이중 실선**으로 긋지만, 본 팩은 견본의 booktabs 문법을 계승해 **0.4pt 단선**으로 통일한다. 좌우 세로선을 비우는 원칙은 국내 관행과 견본이 동일하다.
- 셀 여백 좌우 6pt / 상하 4pt. 숫자는 우측 정렬 + tabular lining, 문자는 좌측 정렬, 헤더는 데이터와 같은 정렬을 따른다(헤더만 중앙 정렬 금지).
- 소수 자릿수는 열 단위로 통일. 유의수준 별표는 표 아래 `주:`에서 정의. 결측은 `–`(en dash), `0`과 구별.
- 표 폭은 판면 폭 106mm 이하. 초과하면 본문 크기를 9 → 8pt까지만 줄이고, 그래도 넘치면 **가로 배치(landscape) 대신 표를 분할**한다.
- 표가 면을 넘기면 헤더를 반복하고, 이어지는 면 왼쪽 위에 `표 1-1 (계속)`을 붙인다.
- 표·그림은 본문에서 언급된 문단 **뒤**에 배치. 같은 면에 못 들어가면 다음 면 상단. 본문 언급 전 배치 금지.
- 본문 지시어는 반드시 번호로: `표 1-1에서 보듯` / `(그림 1-2 참고)`. **`아래 표는`·`다음 그림에서는` 같은 위치 지시는 금지**(조판 중 위치가 바뀐다).
- 표·그림 블록 위아래 바깥 여백 각 6mm.

## 러닝 시스템

| 요소 | 규격 |
|---|---|
| 짝수면(좌) 헤드 | `제N장 장 제목`, 판면 좌단 정렬, Pretendard Medium 8.5pt `--ink` |
| 홀수면(우) 헤드 | `N.N 절 제목`, 판면 우단 정렬, 동일 서식 |
| 헤드 룰 | 헤드 아래 2.5mm, 0.4pt `--rule`, 판면 전폭 |
| 헤드 위치 | 판면 상단에서 위로 9mm(헤더 어센트) |
| 쪽번호 | **하단 중앙**, Libertinus Serif 9pt tabular, 판면 하단에서 아래로 14mm |

- 제목이 길면 짝수면은 장 제목을 20자에서 자르고 `…`, 홀수면은 절 제목을 22자에서 자른다.
- 러닝헤드 생략: 장 도비라 면, 부 도비라 면, 목차·참고문헌·색인의 첫 면, 백면. 쪽번호는 백면과 부 도비라에서만 생략.
- 앞붙이(속표지~목차)는 소문자 로마자 `i, ii, iii…`, 본문 첫 장부터 아라비아 `1` 재시작.
- **경계 오류 주의**: 현재 위치 이전의 마지막 제목을 조회하는 단순 구현은 장이 바뀌는 면에서 이전 장 제목이 남는다. 도비라 면을 제외 조건으로 명시하거나 러닝헤드 전용 헬퍼(hydra 계열)를 쓴다. 파일럿에서 장 경계 앞뒤 4면을 눈으로 검수한다.

- 선 굵기 2단계만: 0.4pt(보조·격자) / 0.8pt(주선). 색은 `--ink` + `--accent` 1도 + 회색 3단계(`#1A1A1A / #6E6E6E / #C9C9C9`).
- 도해 내 문자: Pretendard Medium **8pt 이상**. 8pt 미만이 필요하면 도해를 분할한다.
- 도해 폭은 **판면 전폭 106mm**(`bf.width: full`) 또는 **2/3폭 70mm**(`twothirds`) 두 가지만. 임의 폭 금지.
  mm는 `tokens.json` `diagram.widths`가 유일한 진리원이며 `md2typ`가 `#bf-fig(width: Nmm)`로
  발행한다. 4종 typst 팩 중 유일하게 문서·선언·실렌더 3원이 처음부터 일치했다
  (`theme.typ` 판면폭 trim.w 153 − 좌 25 − 우 22 = 106, PDF 벡터 실측 106.000 mm).
- 도해 내 최대 글자 ≤ 본문 10pt × 1.20 = **12pt**(HARD, `diagram.labelBand.enforce: true`).
  위 8pt 하한과 한 쌍이다 — 폭을 바꾸면 두 끝이 함께 움직인다.
- 차트: 격자선은 가로만 0.25pt `#C9C9C9`, 축선 0.8pt. 계열 3개 이하면 범례 대신 직접 라벨링. 3D·그림자·그라데이션·원형 차트 금지.
- 래스터 예외: 원자료 스캔·현미경 사진·유물 도판 등 벡터로 대체 불가한 1차 자료만. 600dpi 이상, 그레이스케일, 캡션에 소장처·촬영자 명기.
- 도해 위에 글자를 사후 합성하지 않는다. 라벨은 도해 소스에서 생성한다.

## 금지 사항

1. 본문 글자에 별색 사용, 고채도·형광, `--accent-tint` 외 면 채색.
2. 표 세로선, 얼룩말 줄무늬, 셀 배경(합계행 제외), 표 테두리 박스.
3. 사진·스톡·장식 일러스트·아이콘 세트·이모지.
4. 목차 리더 점선.
5. 제목 위계 5단 이상.
6. 미주 기본 사용, 각주에 출처만 단독 표기.
7. 한글 이탤릭(기계적 기울임), 한글 밑줄, 자간 -0.03em 미만 또는 0em 초과.
8. 한 책 안에서 인용부호 체계(`「」『』` / `〈〉《》` / `< >`) 혼재, 각주식·내주식 출처 표기 혼용.
9. 문단 사이 빈 줄로 단락 구분(들여쓰기로만 구분).
10. 어절 단위 줄바꿈 강제(한글 덩어리 boxing)를 양끝맞춤과 병행 — 양끝맞춤 파열 확인됨.
11. 표·그림을 본문 언급보다 앞에 배치, 표를 가로 배치로 회전, `아래 표는`·`다음 그림에서는` 식 위치 지시어.
12. 내주식 모드에서 `앞의 책 / 상게서 / 전게서 / ibid. / op. cit.` 사용.
13. 제목 뒤 본문 1행만 남기고 면 넘김, 문단 첫/끝 1행 고아·과부.
14. 폰트 교체 후 판면 재계산 없이 릴리스(자폭이 바뀌면 격자가 전부 무효).
15. 참고문헌 CSL 스모크 검수 없이 자동 생성 결과를 그대로 신뢰.
16. 학술지 투고규정의 A4·여백 수치를 조판 사양으로 오인 — 그것은 **원고 제출 규격**이고 발간물은 신국판/46배판이다.
