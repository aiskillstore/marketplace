# Tracing Methods

The startup-tracing methods are Lynx extensions handled by the global DevTool mediator. They access tracing state stored by the app's trace controller.

## Methods

- [Tracing.getStartupTracingConfig](Tracing.getStartupTracingConfig.md) - Get the stored startup tracing configuration
- [Tracing.getStartupTracingFile](Tracing.getStartupTracingFile.md) - Get a completed startup trace through a stream
