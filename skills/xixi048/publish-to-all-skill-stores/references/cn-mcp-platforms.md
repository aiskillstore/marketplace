# 国内 MCP 平台：能不能提交、怎么提交、卡在哪

> 时间基准：2026-10-27，全部条目为当天实测（curl + 真机浏览器）。
> 生态变动快，**URL 先按本表试，失败就重新逆向一次**。
> 原版清单长期缺这一块（只在合规裁剪版里躺着），但它恰恰是国内 MCP 侧唯一能落地的一条。

## 一、先分清「登记」和「托管」

| | 元数据登记型（海外主流） | 平台托管型（**国内主流**） |
|---|---|---|
| 平台做什么 | 只存一条记录 | **接管部署，代码跑在它的容器里** |
| 你要交什么 | 一个 URL 或一份 `server.json` | 可容器化的完整代码 |
| 地址归属 | 你自己的域名 | 平台生成的地址（如 `mcp.api-inference.modelscope.net/...`） |
| 之后维护 | 一处 | **两套端点要同步** |

**这条差异决定了国内上架的成本。** 一个跑在你自己服务器上的 Streamable HTTP 服务，
在国内平台不是「填个 URL」，而是「把代码交出去让平台重新部署一遍」。

交付前先问用户一句：**愿不愿意把服务代码托管给平台？** 有些服务的计费、密钥、数据
不适合搬到平台侧，搬过去就是另一个产品。

## 二、逐站实测

| 平台 | 入口 | 提交形态 | 登录要求 | 实测结论 |
|---|---|---|---|---|
| **魔搭 ModelScope** | `modelscope.cn/mcp` | 「创建 MCP」→ **自定义创建**（GitHub 快速创建境内不可用） | 阿里账号（手机/扫码） | ✅ **已实测提交成功**，生态最大（9K+ 服务）。详见第三节 |

| **百度 MCP World** | `mcpworld.com` | 登录后进投稿 | 百度账号 | ⚠️ `/submit` 未登录回落首页；收录量最大（6 万+），但以聚合为主 |

## 三、魔搭：国内最值得走的一条（已实测走通）

**结论先说：「从 GitHub 仓库快速创建」在境内基本不可用，不要在这条路上耗时间。**

平台会返回「仓库根目录 `README.md` 不存在或缺少正确的服务配置信息」。实际仓库的 README
是正常的、也有 `mcpServers` 代码块——这是魔搭的解析服务在境内读不到 GitHub，**不是你的仓库有问题**。
识别特征：文案说「README 缺失」，但你 `curl` 一下 raw 地址是 200。遇到这个错误直接换路，别改 README。

**可靠路径：自定义创建。** 入口 `/mcp/servers/create?template=customize`，字段与填法：

| 字段 | 填什么 |
|---|---|
| 英文名 | 与包名一致，全小写连字符（如 `feeling-search`） |
| 中文名 | 面向中文搜索，带品类词 |
| 来源地址 | GitHub 仓库 HTTPS URL |
| **托管类型** | **必须选**（如「可托管部署」）。留空会静默失败，只弹一句「请选择托管类型」 |
| 是否公开 | 公开，否则不进广场、搜不到 |
| 类型 | 选最贴近的品类（决定落在哪个广场分类） |
| 服务描述 | 中文一句话卖点，**不写会随词库/数据变动的固定数量** |
| 配置 | Stdio 与 Streamable HTTP **都填**，两种用户都能用（见下方 JSON） |
| README | 服务介绍正文，也是详情页展示内容 |

配置两种各填一份 `mcpServers` JSON：

```json
{ "mcpServers": { "<server-name>": { "command": "npx", "args": ["-y", "<npm-package>"] } } }
```

```json
{ "mcpServers": { "<server-name>": { "type": "streamableHttp", "url": "https://<your-domain>/mcp" } } }
```

提交后服务详情页即可访问：`modelscope.cn/mcp/servers/<user>/<name>`。
**改文案不用重建成新服务**：进 `.../<name>/setting` → 点「编辑」，会回到同一张表单，改完保存。

### 魔搭表单的三个坑（都会搞坏结果，但只有第一个报错）

1. **托管类型漏选 → 静默失败。** 校验只提示一句「请选择托管类型」，页面不跳转，容易以为提交成功。
   提交后务必打开详情页确认。
2. **README 编辑器是 Monaco，脚本直写必坏。** 用 `textarea.fill()` 写进去是转义字符；
   用 `keyboard.insertText()` 会触发自动缩进，代码块后每行缩进递增，整篇 markdown 渲染成一团。
   **唯一可靠做法：写系统剪贴板 → 聚焦编辑器 → `Ctrl+V` 粘贴。**
3. **antd 按钮文本中间带空格。** 实际文本是「保 存」「创 建」（CJK 自动加间距），
   按「保存」精确匹配会点空。选择器用 `/保\s*存/`。

保存后必须**回详情页看渲染效果**，不要只信保存成功提示——第 2 条坑的表现就是「保存成功但排版全乱」。

## 四、表单型（MCP World / AIBase）

这两家的表单是**公开可填**的，但提交动作要账号：

- **AIBase** 的字段里有「服务配置」，格式是标准的 `mcpServers` JSON：

```json
{
  "type": "streamableHttp",
  "config": {
    "mcpServers": {
      "<server-name>": {
        "type": "streamableHttp",
        "url": "https://<your-domain>/mcp"
      }
    }
  }
}
```

- **MCP World** 未登录访问 `/submit` 会回落到首页，先登录再进。

这类站的价值是**中文搜索流量**，不是客户端分发。填写要点：中文名称 + 中文一句话 + 真实仓库地址。

## 五、跨平台通用：先把端点做成「能自检」

国内平台和目录站都会做一件事：**真的连一次你的服务**。所以先满足这几条，再去提交：

| 项 | 要求 |
|---|---|
| 端点 | HTTPS，支持 `initialize` + `tools/list`，无需鉴权就能握手 |
| 工具数 | 3–5 个为宜。50 个原子接口直译成 50 个工具，模型只会选错 |
| 返回 | 人话摘要，不要甩整行内部数据（UUID、status 码） |
| 报错 | 能自愈：说清哪里错、正确格式是什么，下一轮模型自己改对 |
| 版本声明 | 包内声明服务名（`mcpName` 一类字段），与服务端声明保持一致 |

**自检脚本要放进仓库**（`verify.js` / `smoke.mjs`）：评审和平台都会跑，
一个能跑通 `initialize` + `tools/list` + 一次真实工具调用的脚本，比任何文案都有说服力。

## 六、服务侧四条静默错误（不报错，只表现为结果为空）

1. **部署包漏了数据文件**（`includeFiles` 之类）→ 端点返回 `ok:true` 但 0 结果。
   必须写护栏：把代码里读数据文件的路径收集起来，与打包清单做集合比对。
2. **入口与依赖被压进同一作用域** → 导出名重复声明，构建期直接失败。
   库侧导出改 `handleXxx`，入口做适配层。
3. **构建目标过旧**（如 node14）不支持 top-level await → 自启动段从库文件拆到独立入口。
4. **本地默认 ≠ 云端默认** → 副本要显式改默认值，并把这个改动写进同步脚本，不靠人工。

护栏都要**反向验证**：故意制造一次错误，确认它真的会失败。没验证过的护栏等于没有。

## 七、能免登录取到的两条路

国内平台基本都要实名/手机号，**我替不了用户登录**。真正不需要登录的只有：

| 渠道 | 动作 | 长期价值 |
|---|---|---|
| **GitHub 中文榜 PR** | `yzfly/Awesome-MCP-ZH`（7.8K star，`pull_request_creation_policy: all`）加一行 | 高，被中文文章与教程反复引用 |
| **自建发现端点** | 仓库开 GitHub Pages，放 `.well-known/agent-skills/index.json` 与 MCP 说明页 | 中，但完全自主 |

中文榜的收录口径很硬（见它的 CONTRIBUTING）：真实实现、可安装可调用、文档清晰、
对中文用户有价值；**付费墙套壳、聚合导航站、营销文案**明确不收。
PR 只加一行，正文里逐条对上它的评审标准，比写得多漂亮更有用。

## 八、账号清单（一次登录把能做的做完）

国内平台的登录都是手机号/扫码，**必须用户本人操作**。开工前把这几件事问清：

1. 有哪些平台账号（阿里云 / 百度 / 讯飞 / 火山 / 站长之家）
2. 是否接受把服务代码托管到平台（决定能不能走魔搭、百炼）
3. 实名是否已完成（百炼、魔搭的部署都要）

用户登录后，一个会话内可以连续做完：魔搭创建 → 百炼创建 → MCP World 投稿 → AIBase 提交。
**先把物料备齐再让他登**，否则登录态过期又要重来。
