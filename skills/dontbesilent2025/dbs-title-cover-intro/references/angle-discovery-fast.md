# 快速角度扫描

[流量层级梯子](topic-ladder.md) 的辅助工具：梯子找不到下一层、需要换角度看同一件事，或用户要求换个方向时使用。由主 Agent 自己完成，不开子 Agent。第 0 步已并入梯子第 1 步，从梯子进入时可以跳过。事实与表达检查遵循主 Skill 的表达尺度；本文件只在内部产生角度候选，不单独设置确认关口，也不把扫描过程展示给用户。

## 0．先看整篇许诺了什么

拆材料之前，先回答：读者看完整篇能拿走什么。常见几种：

- **一套方法**：多条做法合起来解决一个问题，例如「我如何三个月学会剪辑」；
- **一份清单或合集**：几条并列的经验、工具、案例；
- **一个判断**：作者要证明一个观点；
- **一个故事或一次经历**：有过程、有结果；
- **一种体验**：好笑、好看、共情。

整篇许诺本身就是首要候选方向，经常也是原稿能火的原因。一套方法或一份清单类的内容，「有这套方法／有这份清单」就是方向；按摩店、咖啡这类具体技巧是这套方法的证据和钩子，放进标题、封面或开头里用，不单独拆成方向。只有某个部分明显比整体更强、并且正文能单独撑起时，才把它升为独立方向。

原稿已有标题时，原标题对应的方向必须进入候选，并进入方向菜单；内部比较认为它更弱时，也要在菜单里保留，由用户决定。

## 1．恢复输入内核

一句输入内核同时保留：发生了什么、用户准备解释什么、哪些事实负责制造注意力。压缩后如果只剩「AI」「商业」「成长」「赚钱」等宽泛概念，重新恢复具体事件、数字、行为和条件。

## 2．相关性扫描

生成 2～5 个真正不同的候选。每个候选写清：

```markdown
候选方向：
不可丢失的输入资产：
注意力理由：
有效受众：
具体处境：
共同后果／受众问题：
连接机制：
继续了解的价值：
受众范围：专业小众／跨群体／广泛共同处境
关切强度：弱／中／强
现实信号：已确认／有线索／未确认
证据状态：已确认／有依据的推断／待验证
```

每个候选都应能写成一句话：这份材料通过什么机制，在什么场景下，影响了哪类人的什么后果、选择或任务；他们看完能多理解、多判断或多做什么。写不出这句话的候选，只是关键词或情绪相近，不进入比较。

注意力理由与继续了解的价值分开判断。数字很大、人物知名或事件猎奇，只能证明受众可能先看一眼；还需要正文提供理解、判断、行动价值，或故事进展、幽默、情绪与审美体验，才能形成持续连接。

受众范围和关切强度分别判断。专业小众可以拥有强关切，广泛人群也可能只有概念联系。不要把行业词替换成「赚钱、成长、焦虑」后直接判为大众相关。

现实信号单独判断：逻辑上和很多人有关，只说明可能覆盖的人多；现在是否真有很多人在讨论、搜索或咨询，需要材料里的评论、提问、咨询、数据，或用户提供的平台反馈。没有这类信号时记为「未确认」，不能把「理论上人多」说成流量大。

## 3．争点扫描

输入包含已经发生的事件、冲突、公开回应或可评价行为时，扫描：

| 类型 | 核心问题 |
| --- | --- |
| 事实争点 | 到底发生了什么？原因是否成立？ |
| 定义争点 | 这件事应当被理解成什么？ |
| 价值争点 | 它是否合理、重要、可责或可原谅？ |
| 行动争点 | 谁应该怎么回应、选择或改变？ |

每个有效争点包含：

```markdown
争点问题：
立场 A：
立场 B：
观众为什么在意：
用户独有的位置：
已有证据：
缺失证据：
```

双方没有真实判断差异时，争点不成立。方法型、教程型和普通经验没有合格争点时，可以跳过，不得为了评论量制造对立。

## 4．选择抽象路径

分别检查 4 种变化：

```text
抽象：具体事实 → 重复模式 → 解释机制 → 条件性原则
人群：个人 → 同角色群体 → 跨群体 → 公共问题
时间：一次事件 → 重复处境 → 长期结果
价值：事物属性 → 使用后果 → 决策标准 → 价值冲突
```

标题通常需要一组「入口＋终点」：

- 入口使用低抽象的具体人物、行为、数字或异常事件；
- 终点说明受众点开后将得到的解释、判断或行动价值。

不能从单个案例直接跳到普遍原则、时代趋势或长期因果。抽象层提高时，同步提高证明责任。

## 5．用 12 视角清单补漏

前 4 步完成后，用下面三组问题各过一遍，只找前面漏掉的新受众或新命题。不逐视角写结论，没有新发现就跳过，不开子 Agent。

- **结构与抽象**（L01、L02、L03、L12）：个人经验背后有没有平台、组织或资源规则？同一事实能不能换一种问题定义，并改变受众的选择？能上升到哪一层而不丢具体素材？有没有因为表达代价而不说话的人？
- **争点与判断**（L04、L05、L11）：原文里有没有两种都站得住的判断，包括作者前后文之间的张力？谁此刻正要做相关选择？有没有可指出的旧判断被材料推翻？
- **受众与需要**（L06、L07、L08、L09、L10）：原领域之外谁能联系到自己的处境？观众能拿这条内容判断什么、尝试什么？谁想推进什么进展却卡住了？涉及哪些身份或情绪代价？

补出的候选同样经过下一步的硬门槛。各视角的边界见 [深挖：12 视角分 3 组](angle-development.md)。

## 6．硬门槛

先淘汰以下候选：

- 删除关键条件后才显得普遍；
- 只有关键词、情绪、身份标签或宏大价值；
- 只有猎奇注意，正文也没有可继续观看的过程或体验；
- 只有广泛相关，没有保留独家事实；
- 依赖未知动机、未经证实的因果或虚构公众反应；
- 超过材料的证据上限。

## 7．按「人多不多 × 在不在意」排序

通过门槛的候选先放进四格：

| | 在意（关切中或强） | 不太在意（关切弱） |
| --- | --- | --- |
| **人多**（跨群体或广泛） | 优先，再看现实信号和材料能否撑住 | 容易大而空，收窄到更具体的人群，收不窄就淘汰 |
| **人少**（专业小众） | 保留，作为垂直方向 | 降为素材或淘汰 |

同一格内依次比较：关切强度 → 受众范围 → 现实信号 → 看完能多得到什么 → 材料是否撑得住。不把这些合成一个总分；事实忠实、作者原意和材料上限是淘汰条件，人再多也不能抵消。

## 8．候选怎么配（不直接发给用户）

菜单最多 3 个方向，按下面的顺序填：

1. **整篇许诺方向**（第 0 步），原稿有标题时通常就是原标题方向；两者不同时都进菜单；
2. 剩下的位置再从以下几种里选，用来提供真正不同的讲法：
   - **人多又在意**的新人群或新问题；
   - **人少但很在意**、某个具体人群会对号入座的方向；
   - **从作者的成果或亲历切入**：材料里有作者自己的成绩、一手观察或异常数字时考虑。

所有进入菜单的方向都要先通过第 7 步四格：「人少也不太在意」的方向，包括作者亲历方向，不进菜单。不同方向必须改变讲给谁听或讲什么问题，只换一个技巧当入口不算新方向。没有合格的补充方向时，菜单只给 1～2 个也可以，不凑数。

通过门槛后保留 2～5 个真正不同的候选，不预先按单一偏好删掉方向。交给 [材料选择](material-selection.md) 与 [候选比较](candidate-selection.md) 共同验收、筛选，再交回梯子，作为新的一层或放进「其他方向」。只有一个有效候选时如实返回；无合格方向时说明缺少的最小材料。
