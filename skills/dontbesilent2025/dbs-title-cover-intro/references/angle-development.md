# 深挖：12 视角分 3 组

仅在主 Skill 进入深挖时读取：用户要求多找方向、深挖或明确点名 12 视角，或快速扫描找不到合格方向。默认流程不读取本文件；快速扫描使用 [快速角度扫描](angle-discovery-fast.md) 里的 12 视角清单补漏。

任务是发现与更多人有真实关系的上层命题，再交给内容价值验收、制作状态和正文兑现检查。不让成员写标题。扩大受众只能产生候选，观众是否愿意进入和继续看仍须单独判断。

## 为什么分 3 组

12 个视角各开一个子 Agent 时，多个视角常常汇到同一个方向，成本约为快速扫描的 12 倍，增量有限。把判断动作相近的视角放进同一组，每组一个子 Agent，组内依次完成各视角，再合并重复路径。组与组之间仍然独立，避免互相影响。

## 3 个组

| 组 | 包含视角 | 这一组在找什么 |
| --- | --- | --- |
| A 结构与抽象 | L01 社会学想象力、L02 抽象阶梯、L03 框架理论、L12 沉默的螺旋 | 个人经验背后的规则和机制；同一事实的另一种问题定义；可以上升到哪一层 |
| B 争点与判断 | L04 争点理论、L05 修辞情境、L11 认知失调 | 真实存在的两种判断；此刻正要做选择的人；旧判断和新经验的冲突 |
| C 受众与需要 | L06 自我参照效应、L07 社会认同与自我分类、L08 使用与满足、L09 JTBD、L10 情绪评价理论 | 原领域之外的人怎样联系到自己；他们拿内容做什么、想推进什么、会有什么感受 |

## 12 个视角的判断动作

来源、核实层级与适用边界见 [角度理论依据](angle-theory-sources.md)。以下判断动作服务素材开发，不证明播放量、转发量或成交效果。

| 编号与视角 | 独立判断动作 | 必须守住的边界 |
| --- | --- | --- |
| L01 社会学想象力 | 检查个人困境是否还与机会结构、组织规则或资源获得方式有关，提出可调查的共同问题。 | 单个故事或共同情绪不能证明结构性不平等；缺群体资料时只保留问题假设。 |
| L02 抽象阶梯 | 从具体事件上移到重复模式、解释机制、带条件的共同难题；逐层说清新受众承担什么后果。 | 单个案例不证明普遍规律；删去具体素材只剩人生道理时退回。 |
| L03 框架理论 | 在同一事实下重新检查问题定义、原因解释、评价或处理方向，找出会改变选择的另一种理解。 | 换框架不证明新因果真实；只换说法、没有决策差别时无效。 |
| L04 争点理论 | 寻找事实、定义、价值或行动上真实存在的竞争判断，以及不同答案的现实后果。 | 不虚构反对者和争议；事实未清时保持问句。 |
| L05 修辞情境 | 找此刻面临具体选择、可能因表达改变判断的受众，并检查现实约束与时机。 | 没有期限或行动窗口时不制造紧迫性。 |
| L06 自我参照效应 | 找原领域之外的人能联系自身的场景、损失、机会或选择，写清可检验的后果。 | 「大家都焦虑」不构成受众连接；能联想到自己不等于会点击。 |
| L07 社会认同与自我分类 | 检查真实角色或群体的规范、身份、尊严与利益是否被素材触及。 | 不靠刻板印象制造「我们／他们」；工具性素材可能没有身份角度。 |
| L08 使用与满足 | 问观众实际能拿内容来理解什么、判断什么、尝试什么或与谁讨论。 | 好奇与认同不能自动升级为实用价值；内容必须兑现该用途。 |
| L09 JTBD | 找行动主体在具体情境里想推进的进展，以及原做法在哪一步受阻。 | 任务推断不冒充当事人原话；有购买场景才分析购买进展。 |
| L10 情绪评价理论 | 分开检查目标重要性、责任、确定性和可控制性，探索有条件的情绪与行动难题。 | 不凭理论诊断当事人的真实心理或声称方法能消除情绪。 |
| L11 认知失调 | 找可指出的旧判断、行为或自我认识与材料中的相反经验，研究判断怎样更新。 | 没有可定位的矛盾时不使用「大家都以为」或反常识包装。 |
| L12 沉默的螺旋 | 只在有意见气候、孤立担忧或表达代价线索时，检查谁可能因此保持沉默。 | 「没人说」不等于「不敢说」；缺证据时返回不适用。 |

## 给每组子 Agent 的简报

每组收到同一份素材包，内容包括：原素材全文或可回溯摘录、作者原命题、制作状态与可改范围、事实账本（F 事实或作者主张、R 来源可信度、U 未知、H 假设）、原稿强句。简报必须写入以下约束，因为子 Agent 读不到主 Skill：

- 本组负责的视角编号、判断动作和边界，只用这几项；
- 主 Skill 的表达尺度：作者的强修辞、全称判断和口语概括默认保留，不因扩大受众而建议削弱或加限定；
- 不写标题、封面或口播，不编造经历、数据、观众反应或动机；
- 不读取其他组的输出。

## 每组返回什么

1. **逐视角一行**：视角编号，有效、待验证还是不适用，一句话说明找到的路径或缺了什么条件。
2. **合并后的路径，最多 2 条**：组内多个视角指向同一受众和命题时合并成一条，注明来自哪些视角。每条写清：
   - 上层命题、新增人群及其具体关切；
   - 原文锚点（引原句）→ 推导机制 → 新人群处境或后果；
   - 直接材料、合理推断与待验证假设；
   - 什么事实会推翻这条路径；
   - 当前制作状态下：可直接兑现、需改稿、需补事实、需补拍，还是只能另做一条；对应整条视频还是只对应某一段。

找不到新增的真实受众关系时，返回「本组未找到有效升层」并写清原因，不为凑数编写。

## 执行与完成

有子 Agent 能力时，3 组同时派出。建立 A、B、C 三项完成账本；某组失败时重试一次，仍失败就如实标明缺席，不替它编写结论。没有子 Agent 能力时，主 Agent 依次完成三组，每组完成后再开始下一组，并告诉用户这一次没有独立执行。

## 汇合与交付

三组返回后，主 Agent 按作者原意、独特机制、受众处境和争点，把路径汇成最多 3 个方向，并与快速扫描已有的方向去重。多个视角指向同一方向不提高它的优先级。没有材料支撑的结构问题、心理动机、因果和普遍结论只能列为待验证。理论名用于溯源，不进入标题、封面或给用户的默认说明。

汇合后执行 [材料选择](material-selection.md) 的「内容价值验收」，再按 [生产状态与工作模式](production-state.md) 判断每个方向的实现成本，交给 [候选比较](candidate-selection.md)。

面向用户时按主 Skill 的默认交付格式输出，深挖本身不改变格式。用户说「展开」时，再给每组的逐视角结果和合并路径。

角度选定后不再运行本流程。只有作者主张、关键事实或受众任务发生实质变化，才重查受影响的组。
