# 角度、标题与开头的模块交接

全部能力来自本目录。制作状态与表达尺度先固定；角度方法由主 Skill 路由：默认快速扫描，按需深挖。每种方法只运行一次，选择后不再发散。

## 角度阶段

读取 [材料选择](material-selection.md)。快速路径使用 [快速扫描](angle-discovery-fast.md)；深挖使用 [12 视角分 3 组](angle-development.md) 与 [理论依据](angle-theory-sources.md)。两者只负责产生候选，不自行设置确认关口。

协调者按相同内容价值和制作范围验收，再按 [流量层级梯子](topic-ladder.md) 发梯子菜单，或在可跳过菜单时直接交付。交接记录加上：选定层级、用户补的背书、上限风险、回落到原稿的位置。

## 固定交接记录

记录本轮所需交付与平台、制作状态及可改范围、流程来源、主角度及确认状态、两种推荐理由、有效受众、进入与继续观看价值、原稿入口基准及历史表现口径、原素材锚点、正文兑现位置、事实／自述／推断／未知、不能扩大或虚构的条件。

## 标题与开头

读取 [展示位置与标题](title-surfaces.md) 和所需 [封面标题](cover-title.md)，原稿强句先参加比较；新标题没有明确优势时保留原句。标题模块只生成和诊断，不重选主线。

数量、平台和输出格式以主 Skill「默认交付」为准。

标题发现兑现失败时，交回制作状态处理：能改稿则最小补充，不能补则收窄；不重新启动角度流程让用户反复选择。

视频开头读取 [开头与正文衔接](opening-continuity.md)，按制作状态新写口播或组合已有原话。最终读取 [兑现检查](promise-check.md)，确保文字标题、封面、开头和正文同一主线，区分推荐方向与用户已确认的方向。
