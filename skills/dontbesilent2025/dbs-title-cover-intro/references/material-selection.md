# 材料选择

生成文字标题、封面标题或开头前读取。内部完成判断，向用户只展示影响选择的结论。证据检查遵循主 Skill 的“表达尺度”：先判断偏差是否影响核心理解，不把口语概括、经验判断和次要例外自动列为改稿问题。

## 先形成入口简报

先在内部写清以下项目，再生成任何文案：

```markdown
主方向：这份内容准备讨论的问题、展示的事件或提供的体验
作者原意：作者在材料中已经表达的判断、行动意图或叙事设定
注意力资产：最值得保留的事件、数字、经历、行为或原话
原稿入口基准：已有标题、强判断或开场句的原文、来源、历史表现与证据口径
有效受众与处境：谁在什么情况下会关心
进入理由：当前材料里什么具体场景、异常、行为、人物或体验能让这类人停下
后续价值：继续观看能得到什么解释、方法、判断、故事进展、情绪体验、笑点或审美体验
证据边界：哪些是事实、用户自述、合理推断和未知
争点：确有分歧时，观众需要判断的事实、定义、价值或行动问题
解释框架：解释型内容用什么关系、机制或理论组织材料
抽象层级：需要升层时，停留在个人事件、一类人的共同处境，还是上升为一般命题
制作范围：当前是完整视频、独立切片还是文字；能改稿、补拍或只剪已有素材
```

同一任务同时生成文字标题、封面标题和开头时，三者沿用同一份入口简报。用户随后修改了方向或事实，再更新简报；不要让每个交付物各自重新选题。

解释框架可以是材料中已经出现的因果关系、能力边界、机会成本、身份选择或其他清楚机制，不要求每次匹配一个有名字的理论。使用外部理论时需要能够核实来源和适用边界。

抽象层级每上升一级，都要检查材料能否支撑。个人观察可以形成个人判断；只有材料能够覆盖一类人的共同处境时，才扩展到群体。一般命题内部检查成立条件和例外，成品只补充影响核心理解、且上下文尚未交代的必要条件，不要求穷尽例外。

## 从材料中选

记录最少够用的信息：用户提供了什么事实、最值得保留的细节、谁在什么处境下会关心、后续内容能提供什么。区分用户自述、可核对记录和推测；用户自述可以按原有身份表达，不自动升级成独立核实的事实。

优先保留能让这条内容区别于同类内容的事件、数字、经历、观察或具体问题。删掉这些后只剩「赚钱、成长、焦虑」等通用词时，重新恢复材料。无需把所有细节塞进每一句，但关键事实应在适合的入口发挥作用。

## 判断价值

分别判断：什么让人先注意，什么让人愿意继续了解。后续价值可以是证据、解释、方法、判断，也可以是故事进展、审美体验、幽默或情绪共鸣；应由当前内容真实提供，不强行改成教程。

相关性需要具体人群和处境。专业人群强烈关心的问题可以优先于大众泛泛关心的问题。扩展受众时保留成立条件，不以替换行业词代替判断。

用户已确定方向时不重做选题。素材自带标题不能代替用户本轮确认，但必须先作为入口基准接受事实、受众与兑现检查。角度未定且有具体材料时，默认快速扫描；用户要求或快速扫描无合格方向时深挖。再让入口基准与新方向一同参与比较。只有措辞不同的候选合并，不凑数量。

## 原稿入口基准

完整保留原稿中的现成标题、能独立成立的强判断和有辨识度的开场句。记录它们承诺什么、谁会关心、正文能否兑现，以及已有表现的来源：用户自述、可核对的发布数据或尚未发布。历史表现说明过去在特定平台和语境中的注意力，不能自动证明观点正确，也不能保证新版本同样受欢迎。

入口基准通过内容价值验收时，随对应主线进入角度确认与文字标题比较；不要因为新框架更完整、更抽象，就把原句降为只能出现在正文的素材。原句若夸大事实、偏离本轮内容或无法由正文兑现，写明具体失败点并收窄或撤下。用户没有明确锁定原句时，仍允许更强的新方向胜出。

## 内容价值验收

快速扫描与深挖都只生成可能成立的受众连接。汇合命题后、决定推荐方向前，让原稿入口基准和新增候选分别完成下面的检查；未通过的候选保留在分析中说明原因，不放进可选主线。用户已锁定方向时仍检查内容能否兑现，不重新选题。

1. **谁会进入**：指出一类人在什么具体场景中，会被素材里的哪项事实、人物、行为、冲突或体验吸引。仅称「更多人都有关」不足以成立。
2. **为什么继续**：说明观众继续观看能获得什么。可以是解释、方法、判断、故事进展、情绪共鸣、笑点或审美体验；由材料决定，不要求每条内容改变观众的理解。
3. **有什么独特增量**：保留素材中负责兑现收获的具体机制、经历或表现。解释型内容若只复述受众已经知道的现象，要指出新的原因、条件或判断；故事、幽默和审美内容检查过程与体验，不能用「谁不知道」淘汰。
4. **正文能否兑现**：指出正文中哪一段提供了所承诺的价值。只有扩大后的受众名称、没有对应内容时降级；拍摄前可通过最小补充兑现的方向标明所需材料。
5. **证据与表达尺度**：先区分核心举证、作者经验和修辞强调。只有缺口会改变核心理解、造成错误预期或让承诺无法兑现时，才核实或最小收窄措辞；不因比例未经统计、判断存在例外就机械削弱表达。创作者可能承受的情绪或观众可能进行的联想，可以作为有条件的受众问题继续比较；不得写成已发生的心理事实，也不能因暂缺心理自述自动删除有材料支撑的解释路径。

比较通过验收的候选时，分别记录受众范围与关切强度。范围扩大而收获变得空泛时，退回更具体的受众；多个理论指向同一方向不增加它的优先级。未经现实反馈验证时，只称「候选方向」，不声称它有更高播放量。

## 材料复杂时怎样选角度

角度方法由主 Skill 路由。深挖时三组各自完成发现后再汇合。对每个候选执行同样的内容价值验收，再按制作状态筛选；只有一个有效方向时不凑数。只覆盖某段的方向另列。候选差异应改变受众、观看理由、收获或体验、核心命题或正文结构，换句式不算新角度。

每个候选至少回答：

- 保留了哪项不可丢失的注意力资产；
- 哪类人在什么处境下会关心；
- 观众为什么会进入，以及继续看能获得什么具体收获或体验；
- 正文是否有足够内容兑现；
- 是否超过当前材料的证据边界；
- 如果确有争点，它属于事实、定义、价值还是行动；
- 如果主要提供解释，用什么框架组织材料；
- 如果发生升层，采用个人事件、一类人的处境还是一般命题这一抽象层级。
- 在当前制作状态下能直接兑现、需改稿／补拍，还是只能留待另一条内容。

材料涉及已经发生的冲突、争议或公开回应时，再检查事实、定义、评价和行动中哪一个问题真的存在两种判断。没有真实分歧的教程、经历和方法内容，不制造争议。

先淘汰依赖未知动机、未经证明的因果、虚构公众反应和删除关键条件后才成立的候选。证据暂缺但有潜力的命题可保留为待补内容，不能进入当前成片的可直接使用区。剩余候选交给 [候选比较](candidate-selection.md)，按吸引注意与正文兑现两种标准比较。不把某方向的理论数量或可能涉及的人群规模当成流量分数。

## 方向选择

按 [候选比较](candidate-selection.md) 去重、排序，角度未定时先发梯子菜单；已锁定、授权代选或只有一个方向时直接继续。辅助方向只能服务主线。

## 不凭空补齐

数据口径、人物身份、经历、引语和条件保持一致。未知动机和未经证明的因果不能写成事实；问句也不能暗含未经支持的前提。单次结果不等于任何人都能复制。

只有宽泛话题时索取一个具体材料；事实充分而细节不足时继续给方案，必要的未知单独标注。缺少戏剧性不等于没有内容价值。
