# 12 视角的理论依据与使用边界

本文件说明角度开发所用理论的来源和迁移限制。理论只帮助提出可检查的内容命题；理论名称、研究结论和未经核实的因果不能自动写进面向观众的标题、封面或口播。12 个视角的判断动作与分组见 [深挖：12 视角分 3 组](angle-development.md)。

「已核对原文」表示该来源的可访问原文或出版社节选已进入本项目的资料核对；「已有资料记录」表示记录了书目和理论边界，具体版本或页码仍需在对外引用时重新核对；JTBD 在这里作为操作框架使用，不主张单一学术首创者。

| 视角 | 来源与核对状态 | 迁移到内容角度时的限制 |
| --- | --- | --- |
| L01 社会学想象力 | C. Wright Mills，*The Sociological Imagination*，1959；[出版社收录的原文节选](https://cmn-cdn-001.sagepub.com/books/titles/283045/att_sb1_130400.pdf)，已核对原文。 | 个人困扰可引出对公共问题的调查；单个故事不证明结构性原因或群体分布。 |
| L02 抽象阶梯 | S. I. Hayakawa，*Language in Action*，1939，及后续 *Language in Thought and Action*；已有资料记录，指定版本未逐页复核。 | 从具体观察升到原则时，逐级保留事实、机制和成立条件；抽象程度不等于证据强度。 |
| L03 框架理论 | Robert M. Entman，*Framing: Toward Clarification of a Fractured Paradigm*，1993；[论文原文副本](https://fbaum.unc.edu/teaching/articles/J-Communication-1993-Entman.pdf)，已核对原文。 | 问题定义、原因解释、评价和处理建议可以改变；重新定义不证明新原因真实。 |
| L04 争点理论 | 西塞罗，*De Inventione*；昆体良，*Institutio Oratoria*，第三卷；已有资料记录，古典原文未逐页复核。 | 事实、定义、价值、行动是定位分歧的操作分类，分类本身不证明任何答案正确。 |
| L05 修辞情境 | Lloyd F. Bitzer，*The Rhetorical Situation*，1968；[论文原文副本](https://wac.gmu.edu/wp-content/uploads/bitzer.pdf)，已核对原文。 | 迫切问题、可受表达影响的受众和现实约束须同时检查；不能凭空制造时机。 |
| L06 自我参照效应 | Rogers、Kuiper、Kirker，*Self-reference and the Encoding of Personal Information*，1977；已有资料记录。 | 受众能把信息联系到自己，不自动意味着会点击、分享或购买。 |
| L07 社会认同与自我分类 | Tajfel、Turner，1979；Turner 等，1987；已有资料记录。 | 只有真实存在的角色、规范或利益才能形成身份角度，不凭刻板印象划分群体。 |
| L08 使用与满足 | Katz、Blumler、Gurevitch，*Uses and Gratifications Research*，1973；已有资料记录。 | 观众可能如何使用内容是待核的任务假设，不能代替受众行为证据。 |
| L09 JTBD | 用于描述具体情境、行动主体、受阻状态与期望进展的操作框架；不作单一学者首创归属。 | 无当事人原话或行为时，只能提出进展任务假设；购买任务仅在材料涉及购买时分析。 |
| L10 情绪评价理论 | Lazarus，*Emotion and Adaptation*，1991；Smith 与 Ellsworth，*Patterns of Cognitive Appraisal in Emotion*，1985；已有资料记录。 | 目标相关性、责任、确定性和控制感可帮助提出条件性解释，不能诊断真实心理。 |
| L11 认知失调 | Leon Festinger，*A Theory of Cognitive Dissonance*，1957；已有资料记录。 | 需要可指出的旧信念／行为与相矛盾的材料；「反常识」句式不构成证据。 |
| L12 沉默的螺旋 | Elisabeth Noelle-Neumann，1974 年相关研究；已有资料记录，原文版本待核。 | 需要意见气候、孤立担忧或表达成本的材料；「没人说」不证明「不敢说」。 |

理论来源和边界不会自动带来流量结果。新闻价值、信息缺口等方法可在命题选定后检查入口和表达，不担任首轮升层成员，也不能代替正文兑现检查。
