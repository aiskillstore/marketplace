# Other Identities / 其他身份

This folder is named `custom-identities/` for cross-platform compatibility. Its Chinese name is 其他身份.

本目录使用 ASCII 名称 `custom-identities/`，中文名称为“其他身份”。

Place custom role identity files here.

用户提供的自定义身份文件请放在这里。

When Commander Multi-Agent Mode is selected, the model must first show the built-in identity options or ask whether the user has another identity file. If the user provides one, the model must read it from this folder before adopting the role.

选择指挥官多 Agent 模式后，模型必须先出示内置身份选项，或询问用户是否有其他身份文件。如果用户提供了身份文件，模型必须先从本目录读取，再采用对应角色。

Do not put secrets, tokens, or private project files here unless the user explicitly asks.

除非用户明确要求，不要把密钥、Token 或私有项目文件放在这里。
