三大机制 · Three Mechanisms

实现前门禁 · Pre-Implementation Gate

建目录、写文件、跑实现命令之前，先输出 11 字段确认单并停下等待授权。宣布阶段序列不是确认；"开始"不是授权。

An 11-field confirmation, output and stopped before any file or command work. Announcing a stage sequence is not confirmation.

一条主干 + 两个按需扩展 · 1 Backbone + 2 Extensions

单 Agent 主干（默认）· 子 Agent 增强（能力门禁 + 6 字段迷你包）· 指挥官扩展（身份+通道确认 + 23 字段任务包 + 完成门）。

Backbone by default; Subagent with a capability gate; Commander with identity, channel, and a full task package.

证据与验收 · Evidence & Acceptance

对抗式审查、用户路径验收、实操体验闭环（默认 ≤3 轮）；未亲手验证的一律标 UNVERIFIED，不伪造。

Adversarial review, user-path acceptance, a hands-on loop — anything not personally exercised is UNVERIFIED.
