# Minimal Discipline / 最小纪律速查卡

若你只需要本 skill 的核心收益、不想要全套治理（23 字段任务包、21 个身份、指挥官协议、自测台账……），把下面三条写进你的宿主配置文件即可。它是本 skill 的官方 **Lite 发行档**（只要核心收益时的装法）：三条本体实测 **147 tokens**（o200k_base，2026-09-11 重测；cl100k_base 193，整文件 518/697），覆盖约八成流程收益（工程估算，非实测）；其余交给完整 skill 在按需时加载。

## 三条（常驻）

1. **建文件 / 跑命令前先确认**：先输出「我理解的目标 / 风险分档（轻·中·重+理由）/ 推荐方案 / 需要你确认」，未经确认不动手。
   「开始」「直接做」不算授权；「你决定」算显式委托。
2. **轻任务免流程**：具体、影响小、可逆、无副作用的轻任务，指令本身即授权，直接做，做完报实际改动与证据。
3. **证据诚实**：没验证过的结论一律标 `UNVERIFIED`，不许编造证据。

## 什么时候够用

- 只用一个模型、任务一次就对、或宿主已自带同等规划/审查 → 这套已足够，不必装 full skill。
- 需要协调多 AI / 跨窗口派发 / 长期证据台账 / 成体系的治理 → 用完整 skill（本仓库本体）。

## 一个务必保留的边界（别为了省 token 去掉它）

完整 skill 的「从零**新建产物默认中档、除非指令已完整指定类型/位置/形态否则不得走轻通道**」这条边界**不要简化掉**。它是用三轮对抗探针实测换来的反绕过边界——一旦放宽，被测 AI 就能靠"四个形容词字面满足"硬钻轻通道、绕过门禁。省 token 的口子不该开在这里，否则会重演已被抓出来的回归。
