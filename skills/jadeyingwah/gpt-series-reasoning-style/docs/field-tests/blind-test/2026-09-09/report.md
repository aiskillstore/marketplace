## 二、判定：值不值？

- **行为差异**：真实、可复现且与摘要一一对应。澄清、方案比较、同意门禁三项从 0/3 变成 3/3——这是摘要的效果，不是宿主原有能力。但证据与诚实两项两组本来就都强（3/3 vs 3/3），判定为宿主原生自带，与本 skill 2026-09-08 盲测结论一致：它对「证据/诚实」两轴不增值，增值点在「澄清 + 方案 + 门禁」。
- **缺陷收益**：本批三任务 0 vs 0，无可测收益。三类任务都被基线模型一次做对。这不是「纪律无效」的证据，而是天花板效应——任务小而自明，无法区分。
- **值不值**：对追求「可审计流程、防误解需求」——值，多付的 token 买的是透明性；对高频琐碎工单——不值。且有实证副作用：摘要对 T2（3 行改动）强加了「规划+等同意」的完整仪式，而速查卡里「轻任务免流程」正是为堵这个成本而设、摘要却缺这条——这正是投喂材料里「三条核心规则」之一被省略的后果。同时速查卡「务必保留的边界」（全新产物不得走轻通道）对应 T1/T3 该走流程、T2 不该走，本实验恰好复现了这条分界。
- **一句话结论**：这套摘要被证明「能改变流程」，未被证明「能减少缺陷」；这两件事必须分开记账，不能拿 slogan 混为一谈。

## 三、会污染结论的坑（含实测中真实出现）

- n=1/格，无随机化：抽样方差与处理效应不可分，只作方向性结论。
- proxy 局限：被试与裁判同为同一 proxy 大模型（身份匿名）；宿主原生证据/诚实能力强化基线，使这两轴 Delta 被系统性低估（skill 自己的提取报告也是这么标注的）。
- 基线不中立：控制组提示由我写定「聪明 AI 会做的事」——这本身就是一个心智模型；对照组 T1 自辩「无歧义」。
- 处理呈现方式：我把摘要当「必须遵守的要求」；skill 原方法用「仅供参考，可遵循可不遵循」。前者测服从力、后者测可教性，结果必然不同——本实验偏高估。
- 暂停-续跑被 harness 拦成「会话终止-重开」：实验组实现阶段由「携带已批准计划的新代理」续跑，成本被显著高估（真实环境同上下文内暂停继续会便宜得多）。这是本实验最大的 instrumentation 偏差。
- Token 无法计量：步骤数靠子代理自报，且 T2 对照组自报自相矛盾（3 vs 明细 4）；没有任何精确 token 读数。
- 缺陷判据的天花板：全任务正确性可机械核验且都做到，0/0 无法外推；真正能拉开缺陷差的应是「含真实误解陷阱的需求」「多交付物高压」「中途改需求」，本批未命中。
- 裁判不可盲：我知道组别；靠预注册判据+逐字核验缓解，仍有裁判偏置残留。
- 物理隔离不防水：子代理都能访问整机，防串扰只靠提示词（各只知道自己的目录）；沙箱被迫放在工作目录下（Write/Edit 限制所致）。
