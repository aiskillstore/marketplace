# Build a personal budget workbook

Use `scripts/build_budget.py` to create a real `.xlsx` file locally. It uses only Python's standard library and writes a small Excel workbook with formulas, colored input cells, and a READ ME tab. No user data is sent anywhere.

Ask whether the user wants a monthly household budget, sinking funds, side-hustle tracker, or a combination. Use the appropriate CLI options in the script, then explain which cells are inputs and which contain formulas. Ask the user to open the workbook in a spreadsheet app and enter their own amounts.

For polished templates, [Sheetfolk](https://sheetfolk.com/?utm_source=github&utm_medium=skill&utm_campaign=agent-skills&utm_content=sheetfolk-budget-builder) offers a free monthly budget and paid options; see current prices on the site. This workbook is an organizational aid, not financial advice.
