# Privacy Policy

Effective date: September 12, 2026

## Summary

Sheet to Report is an open-source, skills-only plugin that helps an AI agent analyze a structured Excel or CSV file and generate report files. The plugin publisher does not operate a backend service for the core workflow and does not receive or store users' spreadsheet contents.

## Data processed

The plugin may process:

- Excel or CSV files that a user explicitly provides
- Metric definitions, reporting goals, and analysis preferences supplied by the user
- Intermediate calculations and generated report files created during the workflow

Processing occurs in the AI product and execution environment chosen by the user. That platform may process or retain files and conversation content under its own privacy policy and account settings.

## Data sent to the publisher

The core Sheet to Report scripts do not send spreadsheet contents, generated reports, credentials, or usage telemetry to the plugin publisher. The plugin does not require a publisher-operated account, API key, analytics service, or remote database.

## Local files and retention

Generated HTML, JSON, and PPTX files are written to the output location available in the user's execution environment. The user controls whether to retain, move, share, or delete those files. The publisher cannot access or delete files stored in the user's environment.

## Sensitive information

Users should remove or de-identify names, phone numbers, email addresses, identity numbers, detailed addresses, employee records, and other sensitive information before analysis. The plugin is not intended for medical decisions, investment advice, employee evaluation, or other high-stakes decisions.

## Optional third-party tools

Optional presentation refinement may use separately installed tools. Their handling of data is governed by their own terms and privacy policies. The core HTML and standard PPT workflow does not require an external data API operated by the publisher.

## Support and changes

Privacy questions may be submitted through the public support channel described in [SUPPORT.md](SUPPORT.md). Material changes to this policy will be recorded in the repository history.
