# 常见问题

## 我不会写代码，也能用吗？

可以。把一张结构清晰的 Excel／CSV 和汇报目标交给支持本地文件与脚本执行的 AI 工具即可。命令由 Agent 执行；只有日期、指标口径或业务对象会改变结论时，才需要你确认。

## 最少需要安装什么？

- **只生成 HTML：** Python 3.10+ 与 `requirements.txt` 中的基础包。
- **继续生成标准 PPT：** 再需要 Node.js 18+ 与 `python-pptx`。
- **继续生成美化 PPT：** 再单独安装 SlideViber；这是可选项。

让 Agent 在 Skill 根目录运行：

```bash
python scripts/environment_check.py --target html
```

完整说明见[安装与使用说明](INSTALL.md)。

## 为什么 Agent 还要问我问题？

“直接分析”会自动识别高置信字段。多个日期字段、比率分母、客户／订单粒度或未完成周期会改变结论时，必须确认。Agent 应用业务语言解释选择的影响，不要求你填写技术配置。

## 一个文件有多个工作表怎么办？

当前一次分析一张表。Agent 会列出候选工作表，请你选择。多表联合、多层表头和合并单元格不属于当前版本。

## HTML 已完成，PPT 失败了怎么办？

保留 HTML，再运行标准 PPT 的环境预检。标准 PPT 失败不应让 HTML 失效；美化版失败也不应覆盖 HTML 和标准稿。

## 一定要安装 SlideViber 吗？

不需要。它只负责可选的视觉精修。HTML 与标准 PPT 可以独立交付。

## 平台提示模型账号、API、权限或额度错误，是 Skill 坏了吗？

不一定。这通常是宿主平台尚未成功调用模型。先确认平台模型能正常运行，再判断 Skill 是否已经开始读取文件；无需因此重复安装 Skill。

## 遇到问题时怎样描述最有效？

请提供：所处阶段、完整错误文字、操作系统与 AI 工具、是否已经生成 HTML／标准 PPT。提交公开问题前，删除或替换真实业务与个人数据。
