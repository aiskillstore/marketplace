# Agensi：网页 ZIP、发布表单与审核

资料核验：2026-11-07 的官方打包/网页提交/审核/更新文档；2026-11-08 已登录的正式发布表单、可选区域和文件选择器属性。本轮浏览器读取与可逆展开/收起成功，没有填写字段、上传文件或提交审核。之前部分 HTTP 客户端的证书/连接错误是各次请求的历史记录，不能据此断言整个平台不可用，也不能绕过 TLS 或浏览器安全提示。

目前已核对入口、文档和实际界面，未验证服务端接收 ZIP、审核结果或本次版本公开。历史上传或待审记录只作定位线索，不沿用为今天的成功证据。

## 选择单个 skill 的 ZIP

正式网页入口为 [提交页](https://www.agensi.io/dashboard/submit)。按 [准备与打包](prepare-and-package.md) 固定本次来源、作者版本和完整文件清单；只要求方法或本地准备时，完成材料而不上传。

官方当前规则会在 ZIP 的**任意深度**查找每个 SKILL.md：一个识别为单 skill，两个或更多识别为 skill pack。包外套一层目录也可接收，不要求所有 ZIP 都扁平到根目录。用户只选一个 skill 时仅打包该发布单元，不能上传包含其他 skill 或测试 fixture 的整仓 ZIP。

每个 SKILL.md 保留 name/description 与完整正文；平台还说明会从 frontmatter 读取 summary、version、tags、keywords、use_cases 和 docs_url 预填列表。检查实际预填结果，不假定任意宿主字段或 metadata.version 都被同样识别，也不为某个平台静默改写源格式。

| 接收或交付范围 | 当前官方说明 |
| --- | --- |
| 网页 ZIP | 最多 50 MB、1,000 个文件；每个 pack 最多 50 个 skill |
| 代理提交 | 100 个文件、5 MB、仅文本；不能套用网页 ZIP 限制 |
| 给买方代理的内容 | 每个 SKILL.md，加最多 200 个其他文本文件；每个 listing 最多 600 万字符 |

允许上传文本、代码、配置，以及图片/PDF；但当前代理交付仅含文本，图片/PDF 不供代理读取。可执行产物和安装包会触发文件类型检查；node_modules、site-packages、虚拟环境等依赖目录不允许。平台会移除 Git 目录、Python 缓存及部分系统文件。若过滤或交付方式会破坏必要资源，保留源码，说明缺项并确定适配方案，不靠删依赖宣称完整。

官方说明脚本会原样写入买方会话的临时文件、独立运行并移除，不能读取包中的其他文件。核对相对资源/模块依赖是否还能工作；需要的数据应按允许方式随脚本提供。文档建议每个脚本的逻辑小于 20 KB，数据不计入该建议；这是可审阅性指引，不能写成通用硬性文件大小上限。

## 网页字段与预览

以下字段在正式发布页核对，包括展开的 Categories、Agensi tools、Extra Details、FAQ 和 Documentation Link 区域；读取后恢复原展开状态。Name/Summary 的 HTML maxlength 分别为 60/300。必填按页面星号说明记录，不能因控件没有 HTML required 属性就判断服务端允许省略。名称唯一性、条件价格和未触发的自动行为仍按 2026-11-07 官方文档记录；表单观察不等于服务端上传实测。

| 字段 | 要求或限制 |
| --- | --- |
| ZIP | 必填，页面显示上限 50 MB，包含 SKILL.md |
| Logo | 方形，建议 512×512，上限 5 MB；页面未显示必填标记，选择器为 image/* |
| Name | 页面必填、最多 60 字符；平台内唯一性来自文档，未测试同名创建 |
| Summary | 必填，最多 300 字符 |
| Full Description | 必填，Markdown；说明功能、运行方式和边界 |
| See it in action / Compatibility | 实际输入输出示例、所需宿主和环境；页面建议结果 700 字符以上，不作为通用硬性最小长度 |
| Pricing Model | 页面必选，提供 Free、One-time、Subscription；保留用户价格方式，条件金额依当前文档与实际表单核对 |
| Categories | 当前 32 个类别中最多 3 个，首项决定类别页归属 |
| Tags / Use cases | 检索标签与用途；网页字段与代理提交的数量限制分别核对 |
| Permissions | 页面说明从包中检测，仍须核对工具、文件、网络及服务权限；Required tools & software 按行列出，控件 maxlength 为 3600 |
| Limitations / FAQ / Docs link | 可选；按材料提供，不编造运行效果 |
| Screenshots / Video | 最多 6 张、每张 10 MB；YouTube 或 Loom 视频链接 |

网页名称/摘要与 Agent Skills 的 name/description 约束不是同一组字段。单独准备合规的 listing 标题与摘要，审核自动填入内容；源 description 即使通过技能格式校验，也可能超过网页 Summary 的 300 字符。不要为了列表摘要而静默删改代理触发描述。

页面有可选的 Agensi tools，以及桌面/移动端实时预览；工具选择、搜索和实际调用没有运行。FAQ 区域提示留空时会在批准后自动生成，本轮未验证该自动行为。文档中的 AI helper 可补空字段、不会覆盖用户已填内容，文档限额为每小时 20 次、每天 100 次；没有运行该功能或验证生成质量。

**网页会随填自动保存远端草稿。** 没按 Submit for review 不代表操作仍在本地；输入、上传和使用补全功能都应在相应授权范围内。仅核对表单时保持只读，不填写测试值或上传样例来试探。

## 价格、许可与代理提交

保留用户选择的免费、一次性或订阅方式。当前文档说明付费至少 $1、订阅至少 $5/月，网页提交付费条目前须连接提现方式；不将免费或仅准备任务扩成收款、KYC、付费或商业条款操作。核对当前禁止外部结账/付费版本链接的要求。作者保留所有权，但平台分发条款与源许可证分别检查，不替作者改许可证。

用户选择代理提交时，读取 [官方代理提交文档](https://www.agensi.io/docs/submit-from-your-agent) 及当前工具参数。文档路线为 creator_status 检查 Creator Mode/必要的提现状态，submit_skill 先生成预览，再在既有授权内确认提交；update_skill、upload_skill_media、my_skills 分别用于更新、展示材料和状态查询。当前代理上传为 100 文件/5 MB/文本，最多 10 tags、10 keywords、8 use cases，Summary 300 字符。

代理预览会发送文件和列表资料到服务器，并保留 7 天；“尚未发布”不等于离线准备。当前宿主是否已连接、认证及具备工具须另外核对，不能凭文档声明已执行这条链路，也不擅自接入连接器或启用 Creator Mode。

## 审核、更新与成功证据

Submit for review 对应提交审核：新条目先做八项安全检查、AI 审查，再由人工批准。扫描可通过、警告或失败；人会判断误报，不能把扫描分数或单项结果直接写成最终批准/拒绝。文档中的几小时或 48 小时是时间说明，不保证固定审核时限。

保留本次身份、作者版本、平台版本、来源/包哈希和原始状态：Pending 是待审，Live 是公开及可供代理使用，Rejected 保留原因，Paused 是隐藏或暂停。按 [核验说明](verification-and-recovery.md) 和 [发布记录](submission-record.md) 关联本次版本，再查公开条目及正式授权交付证据；HTTP 200、草稿、预览或旧版 Live 都不证明目标新版成功。

新 ZIP 更新时，文档说明平台会自动递增版本；与作者版本分别记录。订阅更新的 changelog 至少 5 字符，当前 live 版本在新版本审核期间继续服务。文本与价格编辑会直接上线，不需要新 ZIP；免费改付费需要确认，不能把这些修改当作不会影响公开状态的草稿操作。

当前买方通过 Agensi 连接器按需获得技能，正式条款限制保存/导出/再分发所购内容。按平台允许的作者记录、公开详情及 MCP 版本/交付证据核验，不能把通用“下载整包到本地比对”强加到该渠道，或为核验导出受限的已购内容。脚本临时执行按上文的官方规则处理。

同名、同包、超时或拒绝时先关联原条目和原因；不靠重传相同包、改名或自动升版猜测恢复。保持本次授权、语言、许可及单 skill 范围。
