# VoltAgent 社区目录投稿

目录收录通常只新增指向源码的链接；它不托管一个新 ZIP 版本，也不保证用户安装到哪一版。记录目录条目与其目标 URL。

## VoltAgent / awesome-agent-skills

核验：2026-11-07，[官方 CONTRIBUTING](https://github.com/VoltAgent/awesome-agent-skills/blob/main/CONTRIBUTING.md)。

当前要求：有可工作的公开仓库及 README 或 SKILL.md，使用作者/组织前缀；在 README 对应类别末尾添加条目，英文简介不超过 10 个词，PR 标题按 `Add skill: author/skill-name`。先检查重复条目和现有 PR。

官方明确要求真实社区使用，**不接受刚创建的全新 skill**。新项目可以先准备链接和条目、完成实际发布与使用验证；不要编造采用情况或把“已建仓库”写成满足目录门槛。

条目格式：

```markdown
- **[author/skill-name](https://github.com/author/repo/path)** - Short description
```

用户明确授权向该目录投稿且满足要求后，再提交具体 README 改动和 PR。回执记录 PR URL/状态；最终核对默认分支 README 中确实有工作链接。`closed` 不等于 `merged`；关闭未合并时读取原因，不猜测拒绝理由，也不重复开相同 PR。
