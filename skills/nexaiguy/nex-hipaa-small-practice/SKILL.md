# Nex HIPAA Small Practice

> Free skill by [Nex AI](https://nex-ai.be). This file is the public guide from [Agensi](https://www.agensi.io/skills/nex-hipaa-small-practice). Scripts, extension source, and templates from the original package are not in this folder.

## What it does

- Runs the Security Rule risk analysis across administrative, physical and technical safeguards, scored and documented.
- Generates the core policy set: access control, workforce sanctions, device and media, contingency plan, audit controls.
- Produces Business Associate Agreement templates and a vendor inventory so every downstream processor is covered.
- Builds the breach risk assessment and 60-day notification workflow, including the HHS reporting thresholds.

## Use cases

- A small medical, dental or therapy practice building its first HIPAA file
- Preparing for an OCR audit or a payer security questionnaire
- Onboarding a new software vendor that touches PHI
- Documenting a suspected breach and deciding whether it is notifiable

## Known limitations

US HIPAA only, not GDPR or other regimes. Output is a working draft for review by counsel or a compliance officer, not a certified compliance program. State health privacy laws add requirements this skill does not cover.

## Example

**Request**

I need a HIPAA risk analysis and a basic policy set for my three-person dental practice using a cloud EHR.

**Result**

I have generated your HIPAA Compliance File:
1. Security Risk Analysis: Scored assets including cloud EHR and local workstations.
2. Policy Set: Access control, workstation security, and sanctions.
3. BAA Checklist: For your EHR and IT vendors.
4. Training Log: Initial staff template.

## Questions

### Does this include a security risk assessment?

It includes a full security risk analysis template with asset inventory, threat identification, and likelihood/impact scoring.

### Is the output legally certified for compliance?

No. It produces working drafts for review. US HIPAA requirements vary and final documents should be reviewed by counsel.

### What types of practices is this for?

It covers small practices including solo doctors, dental clinics, therapy offices, and small-group medical centers.

### How does it handle Business Associate Agreements?

It includes a BAA checklist with the required 45 CFR 164.504(e) clauses and a vendor inventory tracker.
