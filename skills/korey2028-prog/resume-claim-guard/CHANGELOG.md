# 改动记录

## v1.2（2026-10-26）

- 新增一句话版提示词，放在 README 最前面：复制一句话、接上 JD 和简历就能用，不用安装也不用建智能体。经 GLM-5.3 和 Claude Haiku 实测，第一轮都只问一段经历、3 个问题，确认前不写简历。

## v1.1（2026-10-26）

按跨模型测试（Claude Haiku、智谱 GLM-5.3）修正网页版提示词：

- 每轮最多 3 个问号，一个问号算一个问题；硬性条件合成一问；“不记得”不再追问。
- 投递建议四档写明判定标准，避免不同模型结论不一致。
- 面试预演四项必备；旧简历已投出时，给每处失实写法的统一口径；主动问旧简历是否投出。
- 发简历前提醒删除手机号、身份证号和住址。
- 新增豆包智能体、ChatGPT GPT 配置（`platforms/`）和网页测试单（`tests/web-chat.md`），记录首批测试结果。
- README 标题加中文名“简历事实守卫”，入口表加 WorkBuddy。

## v1.0（2026-10-25）

从“简历事实审计”扩展为“从 JD 到面试”的完整流程。

- 新增定向模式：拆 JD → 反问经历 → 要求—证据匹配与投递建议 → 写定向简历 → 体检与面试追问预演。
- 新增 `references/`：拆 JD、反问经历、写定向简历、逐句体检、面试预演、输出格式各一份细则；`SKILL.md` 只保留入口和流程。
- 新增 `templates/facts.md` 事实清单模板、`agents/openai.yaml`、`scripts/validate.py` 和 GitHub Actions 自检。
- 新增完整示例 `examples/jd-to-interview/`。
- `PROMPT.md` 改为网页版五步流程。
- 原有体检规则（五种证据状态、两条轴动词上限、底稿自检、PDF、跨版本对比、过期与作废、内部编号）不变，移入 `references/claim-audit.md`。
