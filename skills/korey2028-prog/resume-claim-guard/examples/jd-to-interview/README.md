# 示例：从 JD 到面试追问（定向模式）

这个示例用虚构的新闻学大三学生“许然”和虚构公司“青檬科技”的 AI 产品运营实习生 JD，完整演示定向模式的五步：拆 JD、反问经历、匹配、写定向简历、体检并预演面试。旧简历里故意放了四类 AI 注水（主导实为参与、上线实为原型、数字换对象、无来源百分比），体检会逐条查出。

建议阅读顺序：`jd.md`（岗位）→ `resume-old.md`（注水的旧简历）→ `conversation.md`（反问实录，含“没做过”“不记得”和主动更正）→ `facts.md`（确认后的事实底稿）→ `output.md`（完整 8 部分输出）→ `resume-targeted.md`（对外简历，文末“内部对照”才有事实编号）。
