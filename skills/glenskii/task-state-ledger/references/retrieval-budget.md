# Retrieval budget

Use a fixed, small retrieval budget when resuming work. Start with the current task state, then open only the evidence records that answer the next decision.

## Default budget

1. Read `task-state.md` first.
2. Select no more than three evidence records for the immediate question.
3. Read the summary before opening raw content.
4. Stop when the decision can be made or the missing evidence is clear.

Do not load every record at the start of a session. The ledger is useful only when it narrows the material being reviewed.

## When to expand

Expand the budget only when a release gate, security question, or unresolved conflict needs more proof. State why the extra evidence is needed and record that decision in `task-state.md`.
