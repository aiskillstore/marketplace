# Operating Model

## What changes mail

Inbox Guardian audits by default. A mailbox change requires all of the following:

1. A local review file generated by this installation.
2. A valid HMAC signature and an unexpired review window.
3. A fresh Gmail metadata read and a second classification check.
4. A final typed confirmation for Quarantine or Trash.

Quarantine removes the Inbox label and adds `Guardian/Quarantine`. Trash is an explicit, recoverable Gmail action. The skill does not use Gmail's permanent-delete endpoint.

## Sender learning

Learning remains local and automatic after reviewed actions, but it is narrow by design. A domain is promoted to the local blocklist only after two reviewed messages where the visible sender domain and return-path domain align. Shared relays, mismatched return paths, protected domains, and one-off messages are not promoted automatically.

An owner can still add any validated domain with `--block-domain`. Trusted contacts and configured allowlists take precedence over block rules.

## Local data

The review file stores only the Gmail message identifier, current classification, rule reason, and proposed action. The audit displays sender and subject information only in the local terminal. Execution re-fetches current metadata from Gmail instead of relying on stored message previews.

Keep the computer account protected. Local files are private where the operating system supports it, but they are not a substitute for device security.
