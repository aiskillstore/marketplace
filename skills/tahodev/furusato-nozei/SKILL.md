# furusato-nozei

ふるさと納税で「自己負担2,000円で済む寄附額の上限」の目安を計算するスキル。外部APIは使わず、公開されている計算式だけで求める。

## 上限額の計算式

```
上限額 = 個人住民税所得割額 × 20% ÷ (90% − 所得税率 × 1.021) + 2,000円
```

この式は総務省「ふるさと納税のしくみ - 税金の控除について」の控除計算(住民税の特例分の上限 = 住民税所得割額の20%)から導かれるもの。
根拠: https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/furusato/mechanism/deduction.html (2026年9月時点で確認)

- **個人住民税所得割額**: 課税所得 × 10% で概算できる(標準税率の場合)。正確な値は住民税の決定通知書に載っている。
- **所得税率**: 課税所得(所得税ベース)に応じて下表。

下表は **2026年9月時点の現行値** (令和7年4月1日現在の法令に基づく国税庁の公表値。平成27年分以降から変更なし)。
根拠: 国税庁 No.2260「所得税の税率」 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2260.htm

| 課税所得(所得税) | 所得税率 |
| --- | --- |
| 195万円以下 | 5% |
| 195万円超 330万円以下 | 10% |
| 330万円超 695万円以下 | 20% |
| 695万円超 900万円以下 | 23% |
| 900万円超 1,800万円以下 | 33% |
| 1,800万円超 4,000万円以下 | 40% |
| 4,000万円超 | 45% |

1.021 は復興特別所得税分。

## 給与収入から課税所得を概算する

利用者が課税所得を知らない場合は、給与収入から概算する。

1. **給与所得控除** を引く(下表は **2026年9月時点の現行値** = 令和7年分以降。令和7年度税制改正で最低保障額が55万円→65万円に引き上げられた):
   - 190万円以下: 65万円
   - 190万円超 360万円以下: 収入 × 30% + 8万円
   - 360万円超 660万円以下: 収入 × 20% + 44万円
   - 660万円超 850万円以下: 収入 × 10% + 110万円
   - 850万円超: 195万円(上限)

   根拠: 国税庁 No.1410「給与所得控除」 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1410.htm (2026年9月時点で確認)
2. 給与所得 = 給与収入 − 給与所得控除
3. 課税所得 ≈ 給与所得 − 所得控除(基礎控除、社会保険料控除、配偶者控除、扶養控除など)

   基礎控除は令和7年度税制改正で引き上げられた。**2026年9月時点**の国税庁公表値では、合計所得2,350万円以下の場合: 令和7年分は58万〜95万円(132万円以下: 95万円、132万超336万以下: 88万円、336万超489万以下: 68万円、489万超655万以下: 63万円、655万超2,350万以下: 58万円)、令和8年分と令和9年分以後は62万〜104万円(489万円以下: 104万円、489万超655万以下: 67万円、655万超2,350万以下: 62万円)、令和10年分以後は62万〜99万円(132万円以下: 99万円、132万超2,350万以下: 62万円)。概算では大きめの控除を使うほど課税所得が小さくなり、上限が高めに出すぎない(保守的な見積もりになる)。
   根拠: 国税庁 No.1199「基礎控除」 https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1199.htm (2026年9月時点で確認)

   なお**住民税の基礎控除は43万円のまま据え置き**(令和7年度改正の対象外)。上限額を左右するのは住民税所得割額なので、所得税の基礎控除の引上げ額を住民税側の計算に持ち込まないこと。

社会保険料は給与収入の約15%で概算できる。扶養の有無で控除が変わるので、利用者に家族構成を確認する。

## 計算の進め方

1. 利用者に聞く: 給与収入(額面)、家族構成(配偶者・扶養)、わかれば課税所得や住民税所得割額。
2. 課税所得と住民税所得割額を推定し、使った前提を明示する。
3. 上限額を計算して、式と中間値を見せる。

## 計算例(給与収入600万円・独身)

「年収600万円、独身です。いくらまで?」と聞かれた場合:

1. 給与所得控除: 600万 × 20% + 44万 = 164万円 → 給与所得 436万円
2. 社会保険料(約15% = 90万円)と所得税の基礎控除を引く。合計所得436万円(336万超489万以下の区分)なので、令和7年分の基礎控除は68万円 → 所得税の課税所得 ≈ 436 − 90 − 68 = 278万円
3. 所得税率は10%(195万超330万以下)。住民税側は基礎控除43万円(所得税と別物)なので課税所得 ≈ 436 − 90 − 43 = 303万円、住民税所得割 ≈ 303万 × 10% = 30.3万円
4. 上限 = 30.3万 × 20% ÷ (90% − 10% × 1.021) + 2,000 ≈ 77,900円

目安表の「600万円 → 約77,000円」とほぼ同水準になる。控除引上げは所得税側の基礎控除が中心で、上限を左右する住民税所得割の計算(基礎控除43万円)にはほぼ影響しないため、差は小さい。

## 目安表(総務省資料ベースのクイックリファレンス)

給与収入ごとの目安(独身または共働き、社会保険料控除のみの場合)。この表は総務省の公表資料に基づく概算で、令和7年の控除引上げ前の前提で作られている。引上げは所得税側の基礎控除が中心で住民税所得割への影響は小さいため現行制度でも大きくはずれないが、あくまで入口にして、必ず上の計算式で確認すること。
総務省ふるさと納税ポータル: https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/furusato/about/

| 給与収入 | 上限目安 |
| --- | --- |
| 300万円 | 約28,000円 |
| 400万円 | 約42,000円 |
| 500万円 | 約61,000円 |
| 600万円 | 約77,000円 |
| 700万円 | 約108,000円 |
| 800万円 | 約129,000円 |
| 1,000万円 | 約176,000円 |

家族構成で変わる(夫婦+子2人だと同じ収入でもかなり下がる)。目安表はあくまで入口にして、必ず計算式で確認する。

## 注意(必ず伝える)

- これは**目安**。住宅ローン控除・医療費控除・株式の譲渡所得などがあると上限は変わる。
- 正確な上限は総務省や各ポータルサイトの詳細シミュレーション、または税務署・税理士に確認する。
- ワンストップ特例は寄附先が5団体以内の給与所得者向け。確定申告をする場合はワンストップは無効になり、寄附金控除として申告する。
- 上限を超えた分は自己負担になる。

## エラー・迷った時の対応

共通の取得時チェックリストは [共通レスポンス契約](../docs/response-contract.md) の「取得時の落とし穴チェックリスト」を参照。

- このスキルは外部APIを使わないので通信エラーは起きない。失敗は「情報不足」「前提の不確かさ」の形で起きる。
- **情報が足りないときは推測で埋めない**: 給与収入、家族構成(配偶者・扶養)が分からないまま計算しない。利用者に聞く。
- **前提が不確かなときは明示する**: 社会保険料の約15%概算など、使った仮定を計算結果と一緒に必ず見せる。仮定を隠した数字を出さない。
- **複雑な所得がある場合は計算を降りる**: 住宅ローン控除、医療費控除、株式・副業の所得などがあると概算は崩れる。その場合は「この概算では正確に出せない」ことを伝え、総務省のシミュレーションや税務署・税理士への確認を案内する( https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/furusato/about/ )。
- **結果は必ず「目安」と伝える**: 正確な上限額のように見せない。

## English summary

Estimates the furusato nozei (hometown tax) donation cap - the amount you can donate with only a 2,000 yen out-of-pocket cost. Pure calculation, no API needed. Ask for gross salary and family composition first, show every assumption and intermediate value, and always present the result as an estimate. Tax tables are the current values as of September 2026 with NTA/Soumu source links; for cases with mortgage or medical deductions, defer to the official Soumu simulator or a tax professional.
