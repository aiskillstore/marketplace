# withholding-tax

月給から天引きされる源泉所得税(月額表の甲欄)の目安を計算するスキル。外部APIは使わず、国税庁が公表している計算式だけで求める。

**基準日: 2026-10-03。以下の式・金額は同日に国税庁の公開PDFで確認したもの。**

## 何が計算できるか

扶養控除等申告書を出している人の毎月の給与(月額表の甲欄)。入力は2つ:

- **社会保険料等控除後の給与等の金額**(額面ではない。額面から健康保険・厚生年金・雇用保険料などを引いた後)
- **源泉控除対象配偶者 + 源泉控除対象親族の人数**(本人が障害者・ひとり親などに当たる場合は該当ごとに1人加算)

```bash
python3 withholding-tax/lookup.py --salary 175000 --dependents 2              # 令和8年分(既定)
python3 withholding-tax/lookup.py --salary 300000 --dependents 0 --year 2027  # 令和9年分
```

## 計算式(財務省告示の特例、令和8年分)

1. 課税給与所得金額(B) = 給与等(A) − 給与所得控除 − 31,667円×人数 − 基礎控除
2. 給与所得控除: A≦158,333 → 54,167円 / ≦299,999 → A×30%+6,667 / ≦549,999 → A×20%+36,667 / ≦708,330 → A×10%+91,667 / それ以上 → 162,500円(1円未満切り上げ)
3. 基礎控除: A≦2,120,833 → 48,334円 / ≦2,162,499 → 40,000 / ≦2,204,166 → 26,667 / ≦2,245,833 → 13,334 / それ以上 → 0
4. 税額: B≦162,500 → B×5.105% / ≦275,000 → B×10.210%−8,296 / ≦579,166 → B×20.420%−36,374 / ≦750,000 → B×23.483%−54,113 / ≦1,500,000 → B×33.693%−130,688 / ≦3,333,333 → B×40.840%−237,893 / それ以上 → B×45.945%−408,061(10円未満四捨五入)

**令和9年分で変わるのは2か所だけ(2026-10-03実測):** 給与所得控除の下限が54,167円→57,500円(第1区分の上限も158,333→169,444)、基礎控除の最大が48,334円→51,667円。第2表(31,667円)と第4表の税率は同じ。

- 令和9年分: https://www.nta.go.jp/publication/pamph/gensen/zeigakuhyo2027/data/denshi_01.pdf
- 税額表(月額表、令和8年分): https://www.nta.go.jp/publication/pamph/gensen/zeigakuhyo2026/data/01-07.pdf
- 税額表(月額表、令和9年分): https://www.nta.go.jp/publication/pamph/gensen/zeigakuhyo2027/data/01-07.pdf

## 税額表(月額表甲欄)の抜粋 (2026-10-03確認)

税額表は給与を「以上〜未満」の区分にして、中間値で計算した固定額。

| 区分(社保控除後) | 年分 | 0人 | 1人 | 2人 |
| --- | --- | --- | --- | --- |
| 175,000円以上177,000円未満 | 令和8年分 | 3,480円 | 1,870円 | 250円 |
| 175,000円以上177,000円未満 | 令和9年分 | 3,310円 | 1,690円 | 0円 |
| 299,000円以上302,000円未満 | 令和8年分 | 7,930円 | 6,320円 | 4,700円 |
| 299,000円以上302,000円未満 | 令和9年分 | 7,760円 | 6,150円 | 4,530円 |

同じ月給でも年分が変わると税額が変わる(例: 30万円前後・扶養0人は月170円、年2,040円の差)。

## 実測で確認した罠

1. **特例の式と税額表は一致しないことがある。** 税額表は区分の中間値(例: 175,000〜177,000円なら176,000円)で計算した固定額、式は実際の金額で計算する。差は年末調整で精算される。令和8年分の月額表で、区分の中間値を式に入れて税額表と照合すると、1,848セル(231区分×扶養0〜7人、社保控除後の給与が88,000円以上740,000円以下)のうち1,473セル(約80%)が一致し、最大の差は100円だった(2026-10-03、自作の照合)。
2. **扶養が8人以上のとき。** 税額表は7人で計算して1人超えるごとに1,610円を引くが、式は常に1人31,667円を引く。ここでも差が出る。
3. **74万円超。** 税額表は扶養0人を基準に税率を切り替えて調整するが、式は同じ要領で計算する。
4. **令和7年分以前には使えない。** 令和7年度の税制改正(基礎控除の見直し)で算出方法が変わったため、公式PDFも「令和7年分以前の給与等には使用できません」と書いている。
5. **令和9年分の税額表はすでに公開されている。** 2026-10-03時点で令和9年分(2027年1月以降の支給分)のPDFが取れる。今月の給与の計算に使わない。年分の取り違えに注意。

## 注意(必ず伝える)

- 結果は**目安**。実際の源泉徴収額は会社が税額表(または同じ特例)で計算した金額で、住民税・社会保険料・手取りは別。
- 対象は甲欄の毎月の給与だけ。乙欄(扶養控除等申告書を出していない人)、賞与の算出率、日額表、退職金は対象外。
- 入力は**社会保険料等控除後**の金額。額面を入れると過大になる。
- 年の途中や年末の精算(年末調整)・確定申告の税額ではない。

## 失敗時の対応

- **年分が分からない:** 今月の給与なら令和8年分(2026年支給分)。2027年1月以降の支給分だけ令和9年分。2025年以前は対象外と伝える。
- **対応外の年分(2025・2028など):** `{"error": ...}` が返る。国税庁の該当年の税額表を案内する。
- **税額表と合わない:** 式は税額表を再現するものではない。正確な値は会社の給与明細または国税庁の月額表(上のURL)を見る。

## English summary

Estimates monthly income-tax withholding for salaried employees (monthly table, column A) using the formula the National Tax Agency publishes under the Ministry of Finance notice for computer-based calculation. Inputs: monthly pay after social insurance, and the number of withholding-eligible dependents. Supports the 2026 table (Reiwa 8) and the already-published 2027 table (Reiwa 9); only the employment-income-deduction floor (54,167 to 57,500 yen) and the maximum basic deduction (48,334 to 51,667 yen) differ. Measured on 2026-10-03: the formula reproduces the NTA's worked examples exactly (e.g. 175,000 yen with 2 dependents gives 210 yen) but differs from the printed tax table (250 yen), which is calculated from band midpoints; the gap is settled at year-end adjustment. Out of scope: column B, bonuses, daily table, retirement pay, resident tax. The result is a guide, not a payroll figure.
