# 衣柜加个书桌，何愁没有学习地方？7.8
今天看看衣柜和书桌的一体化设计，这些案例可以让你装修事半功倍。
注意
以下图片可以点击查看成套案例
▲做榻榻米房间这种很常见，一边衣柜收纳，旁边一体定制的书桌以及书架，小卧室空间非常实惠的做法。<更多榻榻米案例，回台回复“榻榻米”即可>
▲很小的房间，而且还是男孩房，衣服本身很少，所以完全可以缩小衣柜的收纳，来实现书桌学习空间，一举两得，而且视觉上更时尚好看
▲书房兼顾娱乐室，侧墙一半衣柜收纳，一半书桌书架布置，同时书架上方还隐藏投影，小空间功能非常强大
▲儿童房空间，一边上下铺，另一侧满墙衣柜收纳，套色局部书架设计，拐角延伸书桌刚好在窗户下方，非常完美的儿童房功能布局
▲与上图一样的做法，衣柜套色延伸拐角书桌，同时沙发床布置，次卧兼顾书房又能兼顾衣帽间功能
▲衣柜书桌以及榻榻米的连体定制，功能强大，还能让空间更加宽敞
▲卧室门后通顶衣柜收纳，局部套色书桌书柜一体，视觉上好看，同时功能一应俱全
▲衣柜靠窗的角落留出书桌书架的空间，不占地而且满足功能
▲当然如果不需要太多收纳，成品衣柜和书桌的摆放更好，不仅颜值高，而且能让小空间减少压抑。定制是实在没有空间才做的，有空间成品最好
▲门后一面墙刚好有窗户，一边衣柜，有窗户的地方延伸做书桌，空间合理利用，而且成就功能
▲卧室对面墙整体衣柜定制，局部黑色套色书柜，下方木色书桌台面，不仅成就功能，而且颜值非常高
▲卧室门后衣柜布局，局部木色套色镂空以及书桌书柜布置，视觉灵活，小空间不压抑
▲靠窗户牺牲一部分衣柜空间，定制镶嵌书桌，隔板书架，合理利用空间成就功能
▲卧室床对面通顶收纳柜，镶嵌电视，角落书桌定制，因为进深很小，单独把桌面延伸成就功能
▲利用拐角位置定制小的书桌，上方拐角隔板收纳各种零碎，小空间成就大功能
▲通顶衣柜，利用角落局部镂空，拐角简易书桌布置，镂空区域隔板刚好充当书柜
▲利用衣柜的角落空余，设计化妆台和书桌一体功能，合理利用角落。视觉上还能更灵活一点
▲衣柜局部镂空充当书架，延伸出很小的书桌，还能兼顾床头柜功能
▲整体衣柜角落镂空，腾出书桌空间，悬空设计，不用的时候下方刚好隐藏坐凳，镂空区域灯光局部照明，隔板兼顾书柜功能，同时还能兼顾化妆台功能
▲牺牲局部衣柜功能，成就完美的书桌以及化妆台空间，而且轻巧的坐凳搭配，不占地方，随时放下方隐藏
▲牺牲局部衣柜空间，成就悬空书桌，镜子布置，上方隔板还能收纳，书桌和梳妆台都有了
▲如果为了整体美观，也可以把书桌位置做成两扇开门，打开门就是书桌以及化妆台，关上门就是一个完整的衣柜
▲再小的空间都可以实现衣柜与书桌的完美结合，同时还能兼顾床头柜功能
▲书桌与衣柜的完美结合，同时视觉上更灵活，功能更多
