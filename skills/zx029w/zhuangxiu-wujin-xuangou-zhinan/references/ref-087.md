# 装电动晾衣架，得看阳台有几盏灯5.1

电动晾衣架大家都非常熟悉了。过去家家户户用的手动的一是容易坏，二是有难看的钢丝外露，导致不得不吊顶处理，这样的话成本已经高于电动晾衣架了，何必多花钱用手动呢？《阳台不吊顶，更换电动晾衣架，反而节省一大笔费用》

▲普通阳台如果不做吊顶，做手动晾衣架，就会存在钢丝外露的情况，而且还得有个满足手摇器的安装位置。
▲于是乎家家户户这样做，阳台做吊顶隐藏手动晾衣架的钢丝，但是是否计算过手动晾衣架加上吊顶的费用，已经远远高于普通电动晾衣架的费用了，这个是什么操作呢？
▲直接不吊顶提升层高，安装电动晾衣架最实惠。
▲如果你嫌晾衣架突兀，直接可以采用石膏板吊顶做隐形处理，比厚重感太大的绿可木和桑拿板要好看多了。
今天重点探讨的是电动晾衣架的安装问题，装修前期注意看阳台大小，有几盏灯。
第一种：阳台一盏灯。一般刚需房小阳台，开发商本身中间就留有电源，这里就是阳台以后装灯的地方，你家如果后期要用电动晾衣架是无需重新布线的，借用灯线即可安装，电动晾衣架都是遥控控制，这样更方便，而且电动晾衣机本身就带着照明。
第二种：阳台大有两盏或者更多灯。有的阳台比较大，本身就有好几盏灯，而且这几个灯都是一个开关控制，一个回路，此时一定不敢用其中的灯线接电动晾衣架，就会导致后期必须打开开关，晾衣架才能操作，而且白天还得打开其他灯具，造成浪费，而且不合理。所以阳台如果有电动晾衣架，而且有好几盏灯的话，一定是电动晾衣架单独做一个回路，灯具一个回路，各自控制。
