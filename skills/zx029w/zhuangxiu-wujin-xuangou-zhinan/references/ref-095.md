# 橱柜抽屉免费定制，还需要拉篮吗？6.19

先回答一下标题问题，哪个商家脑子不好使定制抽屉不限制数量？对，就是陈工自己，橱柜按照米数计价，抽屉你随便做，破不了产。当然，对业主来说是福利，对同行来说你这个纯粹砸别人饭碗。

声明一下免费不限数量，仅限于家庭装修，你做中药行业的勿扰，真会破产的
言归正传，如果定制商家，像某些大品牌，按照展开面积计算抽屉，一个抽屉有可能加价五六百，这种做法肯定不要抽屉，有这个费用买自己买拉篮不好吗？
第一点认准一个标准：抽屉如果不限制数量，随便做，不要拉篮；如果抽屉单独加价，看多钱，贵了直接自己买拉篮。
第二点看空间功能，抽屉办不到只能拉篮。
什么时候必须用拉篮？抽屉压根无法满足收纳的时候，如图的异形拉篮，抽屉不可能实现，此时为了尽可能利用空间，需要拉篮。也就是普通抽屉如果能满足功能，无需单独选购拉篮。

千万不要抽屉明明免费，自己却学别人买个普通拉篮，而家里无法利用的角落却被白白浪费掉。
比如抽屉免费的时候，地柜坚决不要拉篮，钱用到吊柜升降蓝上，解决吊柜太高取物不方便的问题；用到转角地方，解决转角无法合理利用空间的问题；用到窄边缝隙里头，合理利用每一寸空间，才是拉篮存在的意义。
拉篮的存在不是代替抽屉，而是两者同时存在，各负其责。用对两者的价值，才是装修的智者。
第三，需要购买拉篮的时候，一定购买质量上乘，一般多见304不锈钢，这是最低级别，同时注意厚度以及颜色上的搭配，宁缺毋滥才是选拉篮的标准。
第四，拉篮购买谁安装？一般网购的话商家是不会安装的。拉篮需要橱柜设计师根据空间设计大小，家里满足条件，采用设计师给的尺寸购买即可，橱柜谁做，拉篮谁免费安装。
第五，碗碟拉篮最好不要放在灶具下方，因为拉篮设计本身就是按照橱柜普通高度，灶具不能加高，放上以后灶具下方会占用空间，导致拉篮不能放大的碗碟，所以做的时候谨慎。
总结一下：抽屉如果免费做，坚决不要拉篮；拉篮是为了满足抽屉办不到的事情，而非代替抽屉存在，如果两者功能一样，抽屉还免费，要拉篮干啥？
