# 全屋隔音怎么做？怎么挡住邻居说话、楼上脚步、临街车流和下水管道噪音？

临街车流：换窗+新风，缺一不可。 开发商窗户是中空玻璃，两层玻璃中间是空气，对路边小区基本不起什么作用。两种玻璃隔音效果好：夹层玻璃两层中间加一层隔音膜，效果要好于中空玻璃；真空玻璃两层中间接近真空。专业隔音窗一平方七八百甚至上千元。所谓隔音膜贴窗户没有任何作用，噱头而已。但换窗只解决了隔音，关上才有效果，如何关闭窗户隔绝噪音的同时保证呼吸顺畅？只有一条路：安装新风。不可能家里每间房都靠近噪音区，一般是卧室需要处理噪音，采用成本最低的壁挂新风满足换气功能。壁挂新风要选双向流且带热交换功能的，这样关闭窗户也能享受新鲜空气。预算有限的话，隔音或厚实的窗帘也有一定作用。

楼上脚步：吊顶加保温棉。 可以给全房做平面吊顶，吊顶里头加上保温棉，冬季可以起到保温作用，同时也有隔热和隔音作用。家里室内门也是隔音重点，不能只图便宜，一分价钱一分货，定制品掏多钱做多好的门而已。更换断桥铝三层玻璃窗户，隔热保温性能好很多。西晒墙面做木板基层加保温层再做硬包处理，视觉美观又能隔热保温隔音。

下水管道：红砖包管就行，隔音棉没用。 红砖包管道外面贴瓷砖，这种做法是最结实最隔音的，已经把下水声音消灭到最小范围了。红砖包管道里头再用隔音棉，不是不可以而是多此一举，而且有隐患：高层下水管不同程度都有渗漏，渗透的水会聚集到隔音棉里头，长期潮湿。最重要的一点：隔音棉没有隔音作用，是吸音作用。你以为没声音是隔音棉的效果？那是红砖和瓷砖的功劳。真正能起到隔音效果的必须用专业隔音板，而不是叫隔音棉的吸音棉。家里装修红砖包完全可以起到作用。高层下水的声音取决于使用的情况，晚上睡觉的时候声音最大，大家回来洗漱人最多，再怎么用隔音棉都无法避免有声音。

邻居说话：门和窗是关键。 邻居说话这种空气传播噪音，跟临街噪音一样，靠窗户密封和室内门隔音解决。推拉窗户隔音效果更差，平开窗户好一点。密封条重新加固开发商窗户，效果不是很理想但经济。家里门选隔音木门，几百元的木门太多，看自己是需要隔音还是仅仅遮羞。
