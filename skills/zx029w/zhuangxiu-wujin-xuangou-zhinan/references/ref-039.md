# 水槽不起眼，但是很重要6.2

水槽家家都有，必不可少的厨房物件。但是会选不会选才是最重要的。

1.首先是材质，201和304不锈钢，304是最低标配，如果你不注意，只看价格，201不锈钢也是可以做出来的，价格肯定要低，但是对于家庭水槽使用，关乎全家的饮食健康问题，一点不敢马虎，宁愿家具买烂一点，最起码不会影响健康问题。

2.大小：双槽/单槽。水槽根据空间大小，越大越好，否则连锅都放不进去，要它何用？所以在装修的时候，需要有专业人士给你设计空间，最起码洗切炒的位置需要合理划分；如果你懒得操心，也不懂，就交给专业人去做，然后直接告诉你，你家是怎么安排的，水槽多大，切菜位置多大，你一定要考虑是否合适，不要等到入住了，发现水槽洗个锅都费劲，媳妇能把你骂死。
不要问单槽好还是双槽好，肯定单槽好；单槽带滤水蓝。放上滤水蓝就是双槽，拿掉滤水蓝就是单槽，双槽这种反人类的设计该淘汰了；当然有的人认为双槽好，问及原因：一个洗碗，一个洗菜，这样干净。难道你们洗碗和洗菜直接放到水槽里头？不嫌脏呀。洗碗肯定是放到锅里头洗，洗菜肯定在菜篮或者滤水蓝里头洗。千万不要直接把菜扔进水槽里头，太不卫生了。

3.机器槽/手工槽。功能上没有区别，都可以满足功能；不同的寿命和打理。机器一体成型的机器槽，一般最厚做到0.8mm-1mm，这已经是机器能够压制的最厚的了；而手工槽焊接款可以达到4mm厚度，单从结实度看，手工槽完胜；打理上，因为机器槽比较薄，而且成品都有一层镀膜，脏了以后很难清理，铁丝球打磨也影响涂层和寿命，时间长了都是划痕；但是手工槽因为是不锈钢的本色，厚度又厚，一旦脏了可以采用铁丝球无限制打磨，也不会影响质量和表面的光滑。
水槽三种安装方式

4.安装方式。机器槽尽量做台中或者台下，好打理，因为太薄有个弧形的翻边，藏污纳垢也不好打理；手工槽的话可以直接台上做法，因为其厚度非常厚，放上去非常有质感，也可以台下台中。《厨房水槽3种安装方式，各有利弊》

5.龙头的选择。什么颜色水槽搭配什么颜色的龙头，但是高弯龙头的样式各样，需要注意一点：高弯龙头的出水口不能太高，也不能太低；太高水溅，太低洗碗不方便；需要根据个人使用习惯去购买；
