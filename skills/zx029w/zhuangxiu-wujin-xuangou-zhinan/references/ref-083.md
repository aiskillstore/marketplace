# 阳台只有一个下水，洗衣池+洗衣机怎么做？1.14

看图说事，上图左边镶嵌洗衣机，左边是洗手池，整体定制的。建议业主装修的时候，阳台要放洗衣机一定这样做，功能齐全，美观，而且洗衣机上方也可以做吊柜储物，收纳也多了。

千万不要像上图这样放了，除非你是出租房，要不真的把房子浪费了

今天讨论如果阳台只有一个下水怎么办。

1.首先看一下下水位置，位置是否在洗手池的位置，如果在是不需要改动的，如果下水刚好在洗衣机的位置，一定注意了，自己做水电的时候，一定要水电工把下水移动到洗手池的位置，否则后期洗衣机无法放置了。

2.确定下水在洗衣池的位置以后，不论你是成品洗衣柜还是定制洗衣柜都可以共用一个下水了，需要加一个三通装置就行，如下图，这个淘宝都有

看上图，如果下水只有洗手池下面有，就可以加一个三通和洗衣机共用了。不需要在阳台设置两个下水，因为镶嵌洗衣机，洗衣机下方是无法设置下水的，否则洗衣机放不进去了。

3.下水分为竖管和地漏，这个一定要搞清楚，看下图：

地漏和竖管都是下水，这里一定自己想好，这两个的区别，和装修施工密切相关。

第一，如果用地漏，直接三通插入，洗手池和洗衣机共用下水，阳台必须做防水，优点是以后一旦阳台有水，这个地漏就可以防止水漫金山；缺点是地漏位置很低，和洗手池共用，一旦洗衣机脱水的时候，跟前没有人，地漏很有可能出现溢水现象。

第二，如果用竖管，也可以直接用一个三通直接共用下水，优点是洗衣机和洗手池再大的水流，都不会溢水，而且如果用竖管，阳台防水是不需要的，你如果做了就是多此一举了，竖管下水高于地面很多，阳台即使你做防水，水也无法流入地漏，所以如果下水是竖管，防水钱省了。

第三，不论你是地漏还是竖管，一定注意，洗衣机龙头，洗衣池龙头软管、角阀一定要买质量好的，这个绝对不能含糊，否则水漫金山那是迟早的事情。

4.镶嵌洗衣池和洗衣机需要注意，洗衣机的上水一定一定是在洗手池位置预留，一般洗手池不需要热水，如果需要洗手池下方墙面预留冷热水即可，洗衣机和洗手池加一个上水三通共用冷水即可，千万不要把洗衣机上水做到了洗手池台面的上方，太难看了，如下图的做法严重错误：

上水和电源都放到了上头，难看而且不实用，一定注意，上水和插座一定是在洗手池下方，是看不见的，看下图

上图你能看到电源插座和上水吗？美观多了，上水和插座一定必须在洗手池的下方，千万不要放到洗衣机下方，否则洗衣机后期无法靠墙放置了。
