# 家电选购水太深！这些“伪常识”千万别信，都是白扔钱！

信息大轰炸的时代，各种博人眼球的信息层出不穷，不乏为了流量而产生的一些人为错误引导。例如各种电器选购耸人听闻的信息，总是能站在流量至上的顶尖，误导消费者进入一个又一个误区，而且多花了冤枉钱。01.洗衣机洗净比1.08肯定比1.03好很多。洗衣机洗净比是衡量洗衣机洗净率非常重要的参数，表示衣物被洗干净的参数。国家最低标准为0.7，一级能效达到0.91以上。实际上1.03或者1.08完全达到一级能效的标准，相差0.05，这数值是国家标准实验室的数值，实际上现实生活中完全可以忽略，不存在熟好熟劣，也压根感知不到区别。所以一定在选购洗衣机的时候，注意洗净比细微差别的智商税，因为价格上高很多，不影响具体洗净率的数字，完全没有必要付出太多冤枉钱。02.滚筒洗衣机一定比波轮高级这种论调在过去多年一直被人固化，导致很多人购买洗衣机时候，认为波轮就是低端产品，就是淘汰的产品，而滚筒洗衣机就是高端产品，就是流行产品。殊不知两者各有优劣。滚筒洗衣机不占地，可以嵌入定制产品里头，比较节省地方；而波轮是上翻盖，不适合内嵌，不太节省地方，对于小户型不友好。滚筒洗衣机节水，对衣物磨损小，保护衣物方面擅长，洗涤时间长，价格高；波轮洗衣机洗净力强，对一些特殊行业脏污衣物非常有用，维修方便，价格实惠，只不过对于现代好多娇贵面料的衣物不是很友好，会有损坏可能。所以，两者完全没有谁高级谁低端之说，完全看自己的实际需求决定。03.鼓吹电视刷新率最低120Hz绝大多数电影、电视剧、综艺节目都是24/30fps，你为更高刷新率买单，压根没有用武之地，这就是让你不断花冤枉钱的地方。如果你不玩主机游戏，平时就是看电视，千万不要为了刷新率多花钱了，何况现在的电视观看机会本身就很少，有多余的钱可以投入到更需要的地方。04.电视非得要4K8K吗？电视当然越清晰越好，但是很多人忽略了一个重要问题：绝大多数的电视片源以及主流媒体视频依旧以1080P为主，你多花钱买的4K8K充其量就是个样子货。而且很多刚需业主家里沙发离电视都小于3m了，你即使用4K分辨率看4K电视其实和1080P几乎没有什么区别。与其在用不上的东西上花冤枉钱，不如多关注亮度、对比度以及电视系统的流畅度，这个要比遥不可及的4K8K实用得多。05.空调匹数越大越好，制冷更快更省电空调匹数小了，制冷一直超负荷运转，不仅制冷效果差，还费电；如果匹数过大频繁启停，室温波动大，一样的费电。所以不要过分相信空调匹数与面积的对应理论知识，需要结合房子朝向、密封效果以及所处的地域选择。特别是中央空调的内机数量选择上，如果按照理论知识，多一个内机就多很多费用。此时一定要结合自己的使用习惯，而不是理论知识的匹配值。一个习惯夏季只开17度的人和一个夏季只开26度的人，选择空调是完全不同的。06.净水器滤芯越贵越好
净水器滤芯的好坏并不是价格决定的，需要匹配当地水质和所需水量决定。如果水质硬度低，重金属污染小，普通的PP棉和活性炭就完全够用了。过度追求高过滤滤芯不仅导致费用高，还会导致水量变小。最重要的是如果为了省钱太贵的滤芯舍不得更换，还不如用便宜的滤芯勤更换来的健康和安全。07.线上产品一定要比线下差其实电器行业都有线上和线下的渠道，为了保证不同渠道不会互相砸价，一般同一个电器线上线下型号会有细微区别，但是质量参数是一模一样的。那线上为什么要线下要便宜？为了区分不同销售渠道，线上产品会去掉一些不影响质量的配置，例如外观颜色等，例如取消线下才用的赠品等。同一个产品，线上线下一个厂家和品牌，没有什么质量的差异。只要你细心对比参数就能轻而易举明白。08.洗碗机比手洗更费水费电用生活经验都能想通，洗碗机用的是高循环水，肯定要比手洗用水量少很多，并不费水。而洗碗机费电主要是加热水是产生，现在好多洗碗机都有自动匹配脏污程度，能最大化降低能耗。09.空气净化器CADR值越高越好CADR值指的是洁净空气输出比率，如果不匹配面积，而是盲目追求越大越好，结果是噪音越大，价格更高。高CADR + 高CCM才是需要重点关注的。CCM是累积净化量，如果CADR很高，而CCM很低，滤芯短时间饱和，不断需要更换，成本会更高。010.家里装个新风，还要空气净化器干啥？
新风主要是为了换气，过滤效果远远低于专业的空气净化器。如果正常天气新风完全够用。碰到室外恶劣雾霾天气，此时新风持续只会把大量污染物带进室内，反而导致滤网过载成本过高。此时应该是关闭门窗，打开空气净化器进行内循环，才是高效低成本的做法。新风和空气净化器不能相互代替，而是互相弥补的存在。011.家电新款肯定比老款好？一定要注意，很多家电老款和新款一起售卖，盲目追求新款而忽视了实用性反而多花钱。大部分家电技术成熟以后，为了营销策略，推出所谓新款产品，价格比老款贵很多，但其实性能以及主要部件一点没有变化，很有可能就加入了外观改变或者不痛不痒的智能技术，压根用不上。写在后面：其实家电购买的猫腻不止于此，你是否在实际购买中，交过类似的智商税？文后留言区说一说。
