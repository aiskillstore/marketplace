# 厨房避坑指南

厨房是“金厨银卫”里最核心的空间，也是装修遗憾出得最多的地方。本 Skill 把西安装修课堂知识库里厨房专题的精华按倒序（最新在前）整理成 24 篇参考，覆盖从格局、水电、橱柜、台面、水槽、收纳、砖墙、灯光、门、去家务化到选材与常见错误的全链路避坑。

## 核心原则（先记住这 5 条）

1. 功能满足是底线，别被颜值话术带偏：亮光柜门、不做吊柜、凉霸、双槽、石英石水槽……很多“高级感”做法是坑，过日子优先功能。
2. 干厨房别做防水、别留地漏：没地漏才是正解，做了防水水往客厅漫才是真灾难。
3. 装修前一次规划对，别靠入住后补：定制、尺寸、动线、插座、电器镶嵌，前期定好，后期补救又丑又贵。
4. 普通家庭别硬上全开放：玻璃代替墙体+联动门做半开放，既通透又隔绝油烟，大多数中国家庭的最优解。
5. 选材多留心：锅具、餐具、厨电先看材质和口碑，不盲目跟风网红款，照着清单排查。

## 使用方法

用户问厨房相关装修问题（无论是否已开工），先按上面主题定位参考文件，再结合具体户型/预算给建议。重点：

- 给结论要直接，先说“别怎么做”，再说“该怎么做”。
- 涉及改造（打通墙体、改门、开放改半开放），一定提醒先确认是否非承重墙、当地通气政策。
- 涉及安全（燃气、锅具、餐具），用自查表式清单，让用户能照着排查。
- 不去 AI 味，用西安装修课堂“过日子”的口吻，说人话、给干货。
