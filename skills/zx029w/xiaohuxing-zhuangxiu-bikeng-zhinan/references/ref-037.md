# 装修水电改造最难，也是最简单的1.25

一、家装水电改造是必须做吗？都做些什么？
不论你是毛坯房还是自建房，水电都是必须改动和规划的。自建房不用说，开发商的毛坯房交房的时候，水电都是简单规划的，也就是入户基本到位，各个区域随便放几个插座，至于开关那更是能放哪就放哪。这些做法和你入住的需求相差太远，所以必须改动，只不过每家需求不一样，改动多少不一样

二、水电改造多少有没有标准？怎么知道我家需要改哪些？
家是自己住，家里需要什么电器难道自己不知道？这个需要业主自己提出来，在装修之初就得考虑到位，而不是等着装修公司给你考虑。这是你以后生活的地方，用什么电器，只有你心里最清楚。

装修公司只能根据大部分人的做法给你建议，至于你做或者不做，需要你做主。否则入住的时候往往会出现：这里没有插座，装修公司没有给你说;哪里要放电器，装修公司没有给你做。这完全就是借口而已。家是你自己住，做水电的时候，是按照你的要求布线的，不是装修公司住，责任完全在你。做水电的时候你如果嫌这个费钱,哪个费钱,都去掉,自己心里一定要有准备,否则后面使用不便。

还有装修公司给你建议的时候是站在个人角度上考虑的，你得站在自己角度看自己是否需要。比如家里是否有投影、是否要消毒柜、洗碗机等等。这些人家是根据别家经验给你好心提意。你做与不做一定自己决定，不要压根不用，都做了。然后费用高了却嫌电工给你多嘴了。人家不说你嫌不操心，说多了责任全是人家，你说这理能说通吗？

还有好多业主问别人:我家需要放多少插座合适?千万别有这个疑问.这个得问你自己,你家都需要什么功能,然后水电工根据你的要求布线就行.谁也不知道你住进去都有什么需求,只有你自己知道.如果说前期说这里要放冰箱,电工忘记做了,那是电工的责任。但是你从未提及过的电器，后期入住才发现没有地方使用，这个只能怪你没有想到而已。

三、水电路里头国标非标做法有什么不同？
按照生活经验去理解，其实只是一个说法而已，压根没有什么国标或者非标之说。只不过不同做法的叫法不一样而已。

比如国标走法就是横平竖直，这样看起来整齐，后面维修也好找到点位。非标做法就是相反的一种做法，不遵循横平竖直的原则，就近铺设，以直线局部去布线。但是后期维修可能困难重重，如果要砸掉地面的话，范围就大很多。

为什么这两者会提出来，一个是和后期维修有关，一个是和装修公司结算方式有关。以西安地区为例，水电都是按照米数计费的，当然非标走法走直线，米数就少了，国标走法米数当然就多了。所以这个需要业主自己衡量。还有非标走法，可能有的装修公司不会提供售后，因为出问题维修难度增加。

四、装修水电费用多少算是合理的？
没有什么合理不合理。你有钱多贵都合理，你穷多钱都是不合理的。这个完全在于你怎么想。水电改造和养娃是一样的，谁家养娃的成本能一样吗？所以完全取决于你的接受和改造的多少。

五、可以自己做水电，后面工程交给装修公司吗？
当然可以，前提是你得多出一部分费用。这部分费用就是装修给你检查验收水电路的费用，否则你自己做的水电路，后期施工没有人敢直接施工，水电有问题就说不清楚了。所以为了双方公平，责任明确，装修公司就会进场对你的水电路进行验收，没有问题了再做后续工作。这就无形中给装修公司造成成本，这就是验收的费用。不过一般，你把水电做完，很难找到敢接手的公司的。因为首先会想：这个业主肯定没钱，否则怎么不找装修公司做水电，而是自己做呢？二这个业主肯定不好说话，否则怎么会水电做完，找另一个机构继续施工呢？

不论怎么说，业主都是吃亏的。首先你自己做水电本身就是为了费用低，当然就得承受费用低的后果。不可能你自己的水电售后让别人给你承担。所以怎么看，水电单独剔出去，都是不明智的选择。而且搞不好吃亏更大，这个以前的文章可以参考《水电三四千？别嫌贵，赶紧交给装修公司吧4.8》
