# 100㎡四室刚需，三代人同住很紧凑

百平户型四室两卫，想想都知道空间有多么拥挤，而且还得给三代人预留各自的空间。没有办法，条件限制，只能在现有情况下，最大化满足三代人的最大空间和功能。▲原始图纸，入门口有个小空间，其实可以放个简易鞋柜，这样可以节省室内空间，不过小区刚装修不允许放，以后入住久了应该可以的。进门左手是个小次卧，这里可以作为老人房使用，进门门厅一直到客厅，典型的纯南户型；厨房带洗衣间，无形中分割了厨房空间，餐厅放了餐桌几乎把厨房门堵住了；客卫小到无法布局，否则无法通行；客卫的对面房间朝南，这里作为儿童房备用；主卧稍大一点，带一个很小的卫生间

业主要求很简单，主要是功能和收纳，还得满足女主一个衣帽间和单独书房；老人房和儿童房必须有；餐厅小也得有三代人吃饭的地方。
▲设计后的布局图。首先为了满足三代人刚需收纳，进门右手打造鞋柜延伸至餐厅兼顾餐边柜，顶天立地满足公共区域的所有收纳；为了视觉有延伸，从餐边柜开始电视柜落地定制，一直延伸至阳台，这样不仅满足了收纳，同时可以拉伸小空间的纵深感
原来的厨房带洗衣间打通布局，同时满足收纳和洗衣间功能，为了满足冰箱的布局，新砌墙延伸了扩大了厨房，刚好门后就是冰箱位置，同时利用新砌墙位置放置小的餐桌，满足就餐，保留了进入厨房的最小通道；
客卫实在太小，无法满足基本布局，砸掉与书房的墙体，S型布局，卫生间一边容纳了小的浴柜，书房满足了衣柜的布局；同时为了满足女主的衣帽间需求，改变儿童房门的位置，把书房与主卧做了套间设计，这样书房兼顾衣帽间刚好满足了女主的愿望
为了同时满足主卧和儿童房的收纳，同样采用砸掉墙体，S型布局同时满足两边的收纳储物
▲入门右手定制收纳柜鞋柜一直延伸至餐厅空间，这是小户型难得的收纳场所，所以顶天立地最合适不过，虽然牺牲空间的通畅，但是这也是刚需没有办法的事情；局部的镂空放置包包钥匙，竖向镂空还加了灯光布局，可以作为展示，也可以作为随手放物的地方，视觉上减少拥堵感；进门左手老人房门口布局了全身镜，满足基本功能；门厅没有采用明装灯具，而是留槽保留了灯带，见光不见灯的做法，让灯光更均匀，空间更简洁
▲鞋柜一直延伸至餐厅空间，满足餐边柜的功能，同时落地电视柜与高柜衔接一直到客厅空间，为了视觉很好的过渡，两层隔板装饰，摆上好看的饰品 ，让收纳延伸有了过渡，视觉更丰富新颖
▲新砌墙延伸了厨房空间，满足了冰箱的内置，同时借用新砌墙位置安排四人位餐桌，平时可以满足三代人的就餐，厨房为了节省更多空间，采用极窄长虹玻璃移门布局，这样不占用内部空间
▲门厅进来看全景，因为刚需空间实在太紧凑，所以收纳柜没有延伸到电视墙，担心会让空间压抑逼仄；大面积白色空间，采用沙发背后蓝色变色，蓝白相间可以让小空间视觉上更清新；同时无主灯布局，以及灯带的点缀满足照明的层次
▲暂时没有挂电视，空间还能清爽一点；米色布艺沙发搭配小圆几，皮质的单椅和脚凳布局，不论是视觉上还是空间上，都能让小空间更灵活宽敞
▲蓝色背景视觉上空间更清新，一副抽象挂画点缀，提亮视觉空间
▲黑色铁艺的岩板小几，小巧有质感，空间灵活度更高
▲暖色的皮质小单椅，不占地，搭配斑点纹的抱枕，增加空间的视觉层次感
▲反过来看全景空间，除过必要的收纳，都是一些刚需配置，但是在有限的空间，每一件物品都经过深思熟虑，每一处空间都兼顾功能和颜值
▲主卧采用灰色与木色搭配，背景半截墙木质饰面与上方灰色造型变色对比，提升空间质感和层次
▲床对面的衣柜就是利用儿童房空间实现的基本收纳
▲客卫隔壁的小房间，作为主卧的套间，通过改造做了女主的衣帽间，虽小但是完全满足功能
▲门厅跟前的小房间，这是给老人预留的空间，基本放置床和衣柜刚好，一个床头柜都无法满足；抽象挂画以及供老人起夜用的壁灯配置；皮质靠背床头是为了老人使用更舒适一点
▲预留的儿童房空间，朝南光线不错，利用与主卧S型墙体布局，满足了一个小衣柜空间，以后落地窗下买张书桌即可
▲一米二的床铺满足功能，墙面是淡淡的绿色，可以让空间更清新
▲厨房空间，与洗衣间打通布局，L型地柜定制满足最基本的功能，颜色上采用灰色与白色，与浅色石材瓷砖搭配，视觉更清新干净
▲洗衣间方向看厨房，虽然空间不大，但是完全满足功能；浅色配置让光线更加简洁明亮
▲洗衣间打通以后，定制了高柜弥补厨房空间的不足，同时满足了蒸烤箱的镶嵌，下方刚好镶嵌洗烘机。
▲客卫跨度太小，满足不了基本的布局，所以砸掉墙体朝向衣帽间移动以后，满足了极窄浴柜以及半镶嵌台盆的布局，同时镜柜定制，满足了基本的功能；淋浴处单独的黑色隔断质感现代；水磨石与水泥砖素雅又能分开视觉层次
