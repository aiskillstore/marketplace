# 120㎡三室旧房翻新，进门是厅，砸掉厨房开放布局，超级收纳

一直住旧房，业主早都想改造，但是孩子太小，为了环保一点，一直忍受旧房的各种不便，现在孩子大了，终于可以下决心翻新，给孩子一个更好的居住环境。
户型：三室旧房翻新风格：北欧宜家造价：拆除垃圾清运1.2万；半包6万
▲原始结构图。进门是厅收纳本身就是一个问题，而且公共空间收纳太少，满足不了日常收纳；厨房狭小，厨房门口的餐厅更小，就餐和烹饪都比较憋屈；主卫直对床铺，这里一直忍受，借着这次改造一定要改变

原始图纸中标准1.2.3.的部位是这次重点改造地方。▲平面设计图。进门是厅鞋柜压根没有地方做，右手是沙发，左手是墙体，所以采用简单换鞋凳满足基本收纳；为了满足更多公共区域收纳，利用客厅窗户定制收纳书柜，满足一部分收纳，同时满足飘窗的休闲；为了满足餐厨的拓展，把原来封闭的厨房砸掉做了开放式布局，不仅成就了采光需求，同时成就餐厨一体化的空间开放，让视觉更加通透

▲拆除之前和施工时的样子。过去客餐厅不仅深色木地板，而且墙面都是壁纸，繁琐的花纹，整体比较老旧而且空间显得压抑

▲新装修后的客厅图。改变过去的老旧繁杂印象，取而代之采用极简冷色调，让视觉和空间都敞亮简洁；进门右手为了满足基本的鞋子收纳，采用简单换鞋凳靠近沙发布局，满足进门一家人鞋子的放置，换季的鞋子放到室内别的收纳柜，这样不至于鞋柜布置影响整体客厅的视觉感受；
▲原来平窗位置为了满足家里的书籍放置，借用平窗位置定制书柜以及侧柜收纳，满足了家里书籍的收纳，同时成就窗户下的假飘窗布局，休闲空间也有了，同时可以兼顾客厅沙发区域的不足；因为空间原因选择了挂机代替柜机，这个太明智了
▲铺上垫子，平时随手拿一本书，坐在窗下非常惬意；罗马布帘搭配，可以让视觉更简洁，视觉放大空间
▲这个角度可以看到进门口，非常尴尬，左手是墙没有空间，所以只能作为进门的挂衣区，右手是沙发，直接定制鞋柜的话会让小空间更拥堵，所以干脆采用简易的换鞋凳满足鞋子收纳；沙发进深将近1米，坐下来非常舒适，非常实用
▲电视墙蓝灰色变色，电视柜宜家的不到2000元电视柜，视觉和颜色非常搭配
▲浅灰色坐垫上深蓝色抱枕，一个色系视觉不凌乱；电视柜玻璃花器和小鸟饰品，简单温馨
▲飘窗柜的抽屉非常实用，各种零碎都可以收纳，还可以保证空间的整洁
▲从开放餐厨看客厅空间，整体打通以后，视觉更开阔，互动性更好，采光也的得到提升；不做多余吊顶，不做无用的石膏线，干净简洁，采用有颜值和品味的软配装饰，照样有档次；灯具统一黑色呼应一体，视觉层次不凌乱
▲门厅区域，深蓝色的黑板墙涂刷，门口挂钩可以满足进门挂衣服或者包包，而且黑板漆耐脏，不规则的拼色让视觉更生动，平时还可以随意涂鸦，给生活增添趣味
▲餐厨区域，打通封闭厨房开放布局，成就西厨吧台，刚好分割餐厅区域；餐厅西厨餐边柜蓝色与白色清新搭配，整洁又柔和，就餐区域非常完美.餐边柜石材台面，可以放置各种小家电，非常强大的功能
▲开放让空间一体化通透，视觉和光线一览无余，还可以放大整体效果
▲开放厨房以后，厨房没有做任何吊顶，而是和餐厅一样的白色原顶，采用黑色的明装筒灯照明，视觉极简舒适；吧台背景靠近餐厅采用清新花砖装饰，提升视觉亮度，营造更好的就餐氛围
▲小白砖与黑板漆之间采用金属条进行收口，视觉简单明亮
▲西厨吧台不仅满足空间的互动，同时可以满足厨房操作台的不足
▲蓝色吸塑柜门与小白砖的清新搭配，两个水槽布局，满足中西厨不同的需求，采用集成灶满足了吊柜的更多收纳
▲主卧背景淡淡天空蓝，宜家家具配置，局部粉色点缀，清新雅致
▲挂画错落悬挂视觉更新颖，与深蓝色壁灯和谐共处
▲一边吊线灯一边壁灯，错位的挂画，都能让视觉更生动，有高级感；角落是原木的化妆台也能兼顾书桌，粉色的镜子与挂画呼应一体，增加空间明度和温馨度
▲一灯、一镜、一桌一花瓶，非常简单但是温馨的角落
▲为了避免卫生间门直对床铺，特意定制收纳柜进行分割，成就一个很小的衣帽间，上头吊柜收纳各种被褥，下方收纳衣物，里头夹角位置太小，放置全身镜和衣帽架，合理利用空间，移门保证功能的实现
▲次卧和儿童房格局一样，面积一样，一样的搭配，统一宜家白色的家具配置
