# 85㎡二手房改造，三口之家黑白灰简宅

这一套二手房改造，目前入住三口之家，孩子在外工作不常住，基本入住是夫妻两人。
▲没有改造之前的样子，其实就是两室空间，只不过装修老旧，规划不好显得非常凌乱，收纳严重不足。▲原始户型图，入门是厅，门厅没有鞋柜的收纳，右手厨房带生活阳台导致空间无法满足布局以及冰箱的放置；因为两室高层空间，采光不受影响，光线比较好，加上业主自身喜欢灰色调装修，所以最终定位是黑白灰的现代风格▲设计后的布局图纸，移动进门右手的厨房墙体，实现了门口的鞋柜收纳，同时满足了厨房内部冰箱的布局；打通厨房与生活阳台，满足空间和光线的拓展，同时满足了洗烘机的布局入门直对电视墙位置实现了进门的迂回玄关功能；打通客厅与阳台，实现空间的拓展和光线的提升，利用阳台位置小巧吧台实现一个休闲的角落缩小次卧空间，移动主卧门位置，实现了过道以及主卧门口的收纳，增加收纳储物能力▲门厅空间，利用移动厨房墙体，实现进门右手的镶嵌鞋柜，对面墙体全身镜以及折叠换鞋凳满足功能▲入门直对电视墙位置做了迂回的玄关设计，让进门视觉有迂回空间，不至于一览无余。其实是可以不做的，但是业主执意需求▲玄关与电视墙收纳柜结合，同时满足了厨房门的隐形，局部的玻璃保证光线的通透▲餐厅空间，延伸墙体镶嵌餐边柜，四人位餐桌满足就餐需求，整体黑白灰的色调搭配▲门厅以及餐厅全景，因为高层整体光线非常好，刚好业主喜欢的黑白灰风格得以满足▲入户门厅以及餐边延伸灯带点缀，营造氛围，同时视觉空间更有层次▲客厅全景，与阳台打通布局，整体无主灯布局，电视墙局部收纳柜结合，同时满足电视以及投影的布局；客厅采用务实的挂机满足功能性▲利用客厅和阳台的转角实现了一个休闲吧台的布局，平时满足休闲以及临时办公的所需▲全景空间，整体无主灯布局，让视觉空间更加简洁；玄关的直角做了圆弧处理，视觉上更柔和一点▲电视墙高柜与悬空柜布局，同时结合了石材与格栅的做法，上方投影延伸娱乐功能▲移动次卧门洞实现门后的衣柜收纳，定制榻榻米满足收纳以及办公空间，这里作为孩子的卧室▲利用移动墙体实现了床头的壁龛收纳，兼顾了床头柜的功能▲移动主卧门洞，实现了门口的收纳柜以及斗柜布局，床尾角落L型的书桌定制，兼顾化妆台以及办公所需▲侧墙镶嵌衣柜满足衣物收纳，门后收纳柜与斗柜延伸一部分储物能力▲厨房延续灰色调布局，移动墙体实现了冰箱的布局▲厨房与洗衣阳台打通布局，满足洗烘机布局同时L型地柜满足一部分收纳▲卫生间独立淋浴区布局，同时利用门后空间镶嵌一组收纳柜，满足了家里清洁用品的收纳
