# 90㎡三室无厅，改造无敌婚房

原始户型进门是过道，不能称之为厅，号称三室空间，其实就是牺牲了客餐厅人为分割成了三室，整体格局不是很好。
▲原始格局，进门是过道，并不是厅；左手分别是开放厨房以及很小的卫生间；右手以及直对总共三间卧室，其实是人为把右手客餐厅分割成了卧室空间，导致看似三室空间，其实非常鸡肋的户型

▲设计布局，门厅空间过道比较浪费，采用鞋柜以及岛台的形式，既满足了卫生间的干湿分离，同时满足了鞋柜以及洗烘机的布局，让门厅看起来更整洁完整；同时开放厨房L型布局，把原有过道利用起来；为了餐厨的动线更近，利用进门的卧室分割餐厅和多功能房；把原有带阳台的卧室打造成了单独的客厅空间，这样既满足了两室的功能，同时又有了客餐厅
▲利用进门左手定制鞋柜以及延伸岛柜，实现进门鞋子的收纳以及洗烘机的镶嵌
▲鞋柜背后刚好实现卫生间的干湿分离，同时与开放厨房融为统一，放大空间以及光线；卫生间墨绿瓷砖与厨房白色瓷砖视觉分区，同时又有了对比层次感
▲原有开放厨房延伸定制橱柜，采用窄边柜实现U性布局，满足更多收纳
▲浅色平板定制与墨绿瓷砖形成对比，大抽屉满足分类收纳
▲进门右手分割的墙体无法拆除，为了让餐厨动线更合理，采用玻璃折叠门分割出来餐厅以及多功能房两用空间
▲餐厅卡座以及收纳柜定制，离厨房一门之隔，动线更合理
▲带阳台的卧室改造成了客厅空间，与阳台打通布局，满足平时的会客休闲
▲轻巧布艺沙发布局，背景采用深灰色实木格栅与蓝色乳胶漆对比装饰，让空间更有层次
▲利用客厅空余地方定制收纳书柜以及书桌空间，满足平时的办公需求；不要电视，便携式投影满足基本娱乐
▲与餐厅一门之隔的多功能房，定制榻榻米衣柜书桌，满足一间客房兼顾书房的功能
▲主卧空间，舍弃床铺，直接床垫放地上布局，这样连床头柜都不要，空间显得更简洁；同样爱马仕橙的窗帘撞色搭配
▲角落L型衣柜定制满足一个衣帽间收纳功能，背景采用矮墙与格栅搭配，更有层次感
▲充足收纳以及舍弃床铺的布局，视觉上空间更显开阔
▲客厅小阳台同样打造榻榻米储物收纳，同时兼顾一个休闲区域
▲鞋柜背后刚好满足干区布局，镜柜满足收纳
▲湿区白灰瓷砖简洁布局，墙排马桶更好打理
▲花洒对面利用隔板满足一个悬空洗手池，方便如厕洗手，同时多余隔板作为洗漱用品的随手放置
