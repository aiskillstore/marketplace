# 75平小户型简约，开放设计显得很大

▲折叠餐桌顺便充当茶几~白色的墙裙一直延续整体~《餐厅空间太小，折叠餐桌显身手2.28》

▲不同于公共部分缤纷色彩，简洁干净的卧室更能入眠

▲给床一个特写

▲客厅电视机，做了很大的一排柜子，小户型一定要做好收纳

▲面积不大储物根据需求考虑了很多~所以选了开放式

▲墙上色彩有减压放松的感觉~客厅内选了个很小的双人沙发

▲清爽的色彩留予极大的布置空间，家人可随心所欲装饰旅游留影，增加空间生活感

▲暖烘烘的气氛让人不由自主放松~

▲推拉门也可以只打开一扇的，这样另外的感觉起来就是一面墙，这样在客厅看电视也不会耽搁书房里的工作的

▲在客厅位置看向卧室，卧室内超大衣柜和电视柜是连在一起的

▲推拉门都推到一边，这样就是全开放的空间了

▲基本的生活功能经过美化后，即便空间面积不足，美观及实用性也能巧妙并存

▲书房和卧室，这个区域很清雅并简洁

▲门中藏着还是门~对面只看向厨房，消毒柜安在水槽右下侧

▲因生活格式需求，有限空间满足充分收纳~书房也不能缺少

▲小朋友都在排排坐，大家一起来玩游戏
