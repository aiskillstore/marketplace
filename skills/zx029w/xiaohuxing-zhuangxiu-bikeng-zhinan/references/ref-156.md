# 50㎡一室二手房，改造单身混搭公寓

此套房属于二手房，原来已经做过格局改造，导致无法恢复到原有格局，而美女业主又不想全部拆除重新做，必须在现有基础上，尽量做到明亮，时尚，适合一个人入住。因为是局部改造，能保留的原来东西尽量保留，最终花费4.5万左右。▲房子的原始图纸。也不是最初图纸，因为是二手房，原房东已经做过改造，把原来卧室隔壁的封闭厨房砸掉，移到了阳台位置；把原来的卫生间墙体拓展，做了镶嵌浴缸；把原来卧室拓展空间，导致烟道刚好在卧室里头；导致厨房烟管必须穿过阳台墙体，经过卧室柜子然后才能安装。

业主要求：尽量保持原状，不做结构大的改动，原来能保留的尽量保留；能让整体清新明亮，更适合女孩子入住。▲最终的定稿图纸。首先改变进门口的逼仄，把原有卫生间浴缸恢复成简单的淋浴，然后缩小卫生间，做了干湿分离，让进门口空间以及收纳得到满足；
门厅进来空间布置客厅，挨着鞋柜门厅位置布置投影满足偶尔娱乐；
原来厨房阳台的墙体砸掉，让光线更好，同时采用砖砌橱柜以及岛台的形式，朝外推移，增加厨房的使用空间；与岛台紧挨布置圆形餐桌，满足更多功能；原来的卧室因为一个人住，做成了拱形门洞，同时不装门，采用布帘形式遮挡，一个人住改作了地台床，节省更多空间
▲入户前后对比。原来的枣红色防盗门重新打磨，刷成了白色油漆，更换了功能更强的密码锁；把右手卫生间缩小，实现了干湿分离，为了视觉更加通透，干区采用半截墙，吊镜定制的做法，让视觉通透更时尚；入户左手的换鞋凳是砖砌橱柜的时候一同采用砖砌，与墙面统一白色涂刷，上方的木框位置作为挂衣区，旁边全身镜功能布局；壁灯与干区吊线灯暖色灯光让进门温馨明亮
▲砖砌的换鞋凳，下方镂空刚好放置进门的鞋子；门厅位置视觉分区，专门选择了绿色的花砖搭配出一块地毯区域，视觉新颖，绿色更自然温馨
▲门厅原来与新作的对比。原来的颜色混乱，而且虽然有收纳鞋柜，也杂物堆积。而且原来深色的木地板让小空间更压抑，新作后保留了原来的木地板，但是改变墙面为大白墙提升整体视觉亮度，门口区域做了拓展和更简约明亮的搭配，让空间整体明亮清爽；挨着门厅的上方隐藏投影，为了偶尔娱乐所需
▲客厅前后对比。原来房东把卫生间扩充出来，为了里头放置浴缸，为了采光采用玻璃封闭，导致客厅不规则凌乱；新作以后砸掉原来的玻璃墙体，下方的木地板重新找了颜色相近的进行修补，让客厅区域更加完整，同时保留了采光洞口，采用玻璃砖新作封闭，让视觉更加美观
▲保留采光洞，采用玻璃砖封闭，让卫生间满足一部分采光，同时颜值更高，下方半截墙木板台面布置，放上装饰品，也是非常养眼
▲客厅全景，把美女遮挡一下；灰色布艺沙发铺上了绿色的沙发布，视觉更清新，简单的编织圆毯搭配钢木茶几，非常简单
▲沙发背后利用非承重墙掏了一个壁龛，上头玻璃金色壁灯点缀，放上精美的饰品，很小的改动也能让眼前一亮
▲靠近阳台厨房，原木餐桌椅搭配，不仅满足就餐，平时办公也有了地方；直对面是卧室门洞，做了拱形造型，同时搭配绿色的布帘遮挡，视觉复古，颜值提升不少
▲白天的时候，布帘收起，让视觉和光线都互通有无，绿色又给空间带来自然活力
▲餐厨前后对比。原来厨房移动到封闭的阳台，导致客餐厅光线昏暗，砸掉以后做了开放布局，同时满足了吧台功能，视觉和光线豁然开朗
▲新作的岛台背面以及侧面，做了小的壁龛收纳，视觉更灵活，还能收纳零碎或者放置装饰品，让空间整体更精美
▲厨房统一砖砌橱柜，绿色的自然瓷砖视觉非常清新，半截墙原木自然铺贴，上方两盏玻璃吊顶晶莹剔透
▲阳台厨房全景，绿色的瓷砖铺贴砖砌橱柜，原木的柜门自然温馨；落地窗采光极好，这里烹饪一顿美食，视觉通透，可以让各个空间敞亮开放
