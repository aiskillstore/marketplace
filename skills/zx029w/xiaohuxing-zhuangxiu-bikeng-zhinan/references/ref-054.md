# 沙发旁边拐角墙体，怎么布局比较好？10.5

沙发旁边有墙的户型很许多，此时就可以很好的利用角落空间，打造与众不同的客厅视觉感受。

▲小户型装修，客餐厅以及厨房一体空间打造，沙发旁边墙体，刚好满足餐边柜的定制，用来满足家里水吧台的功能，同时满足客厅的收纳储物

▲如图就是这种标准的户型，沙发旁边有墙体，图上是直接放置边几，台灯布局

▲利用墙体直接镶嵌定制收纳柜，虚实结合设计，满足储物和展示，同时角落木质的衣帽间布局，可以满足临时挂衣服或者包包

▲上图户型虽然不是沙发带拐角位置，但是格局类似，此时就可以正面墙利用起来，定制收纳柜，因为整体是镶嵌，弱化了柜体的存在感，视觉上不会显得压抑突兀

▲客厅沙发带拐角，刚好利用起来满足收纳，同时镂空处兼顾随手置物，也能放置少量书籍

▲沙发拐角置物架布局，可以兼顾放置装饰品以及绿植

▲当然对于小户型来说，客厅沙发拐角也可以作为冰箱的布局场所

▲利用沙发拐角位置，定制玻璃柜门的收纳书柜，视觉有了层次，同时平时客厅拿取书籍更方便

▲沙发拐角定制通顶收纳柜，虚实结合，满足收纳同时满足展示，功能性和颜值兼顾

▲同样是利用拐角位置定制镶嵌收纳柜，弱化柜体存感，满足收纳照顾颜值
