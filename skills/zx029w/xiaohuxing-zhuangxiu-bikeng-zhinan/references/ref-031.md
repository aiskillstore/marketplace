# 阳台墙垛过短又不能砸？试试这几种改造方法！9.16

实际装修里头，常常有一种问题，就是阳台垛子无法砸掉，但是又太短，无法遮挡洗衣机或者无法遮挡收纳柜，此时如果直接补墙，又浪费空间和影响光线，今天看看有没有更好的做法。

▲如图所示阳台墙垛无法砸掉，但是为了满足书桌定制，进深又不够，如果直接补墙，不仅浪费空间而且影响光线，所以采用延伸书桌的形式，完美实现书桌的进深，而且还成就了功能，不会影响光线和空间感受

▲如图其实也是一样的做法，书桌延伸出来，满足一个矮柜的收纳，完美实现视觉和空间的价值

▲一样的情况，没有补墙，而是颜色延伸书桌，拓展一个收纳开放格，完美实现书桌的进深，而且书桌颜色延伸墙体，让视觉上更完整整洁

▲如图其实也是一样的，阳台垛子砸不掉，但是又很短，无法遮挡洗烘机，此时如果补墙，不仅厚重而且浪费空间，刚好采用木色定制书柜开放格布局，既与整体色调一致，又拓展了收纳，一举两得，同时完美实现遮挡洗烘机

▲如图其实也是因为墙体太窄，为了不做补墙遮挡光线，阳台一侧需要一个洗衣池，采用半镶嵌陶瓷盆的做法，就可以实现进深小也可以满足功能

▲还有一种做法，直接采用收纳柜隐藏过短的阳台墙体，达到视觉的完整

▲如图墙体过短，为了实现书桌的进深，直接切割斜面处理，成就开放格收纳，也是一种办法

▲卧室阳台有垛子，书桌直接延伸墙垛，不仅仅实现了书桌的进深，同时还满足了一个床头柜的功能

▲如图一样的问题，不需要补墙，延伸洗衣柜即可，石材下翻，实现功能，同时视觉空间都变得完整
▲如图其实一样的道理，直接延伸书桌，拐角定制，弱化阳角突兀▲阳台太小的墙垛无法砸掉，但是又短，直接采用高柜定制隐藏墙垛，延伸收纳的同时，满足书桌的空间▲如图同样是有很短但是又无法彻底砸掉的墙垛，采用定制直接隐藏起来，垛子前方刚好满足一部分收纳，同时让高柜洗烘机更完整整洁▲当然还有一种简单做法，洗衣机靠向外边布局，缩短靠近墙垛收纳柜的进深，这样就不会直接突出墙体，视觉和功能都得到满足▲如图所示，收纳柜超过墙垛无需补墙，直接延伸收纳柜，侧面镂空延伸收纳，弱化突兀感
