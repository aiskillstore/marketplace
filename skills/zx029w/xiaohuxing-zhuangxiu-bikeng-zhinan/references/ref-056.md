# 小户型，不要茶几客厅更宽敞10.24

特别是刚需房子，家里还有到处撒欢的小孩，更应该去掉茶几，让空间通畅，可以让孩子有更多的活动空间，视觉上看去也不是很繁琐。

▲如图所示，去掉茶几，让跨度本身很小的空间更宽敞，视觉上也不显得拥挤；沙发旁边边几布局，其实完全代替茶几的功能，如果人多的时候，可以直接边几拉出来充当茶几功能。

▲不要茶几并不是小户型的专属，超级豪宅同样适用，而且整体空间更加开阔
▲极简装修，在沙发与单椅之间搭配小的圆几，本身就可以代替茶几的功能，完全取代传统茶几，空间更开阔明亮
▲即使横厅户型，照样可以去掉茶几，满足空间的开阔；如果需要随手放置杯子书籍等物，可以在沙发角落配置小的圆几即可
▲非常小的公寓户型，更不需要茶几来拥挤空间，可以角落用小的圆几代替，尽量让居中空间开阔留白，不论是视觉和空间都可以得到提升
▲去掉茶几，去掉电视，让跨度很小的空间也能看起来开阔极简
▲刚需房去掉茶几布局，只保留必要的家具，让刚需能有大宅范
▲去掉传统茶几，利用沙发位置满足边几的布局，空间更显的开阔；如果入住人少的小户型可以借鉴
▲家里入住人少，甚至沙发茶几都不要，仅仅满足必要的布局，空间更开阔，而且更有个性
▲小的边几代替茶几，可以满足功能，平时可以放置沙发角落，让客厅整体开阔简洁
