# 95㎡老房改造婚房，原木简约家

老旧二手房改造，作为小两口的婚房使用，年限比较久，而且功能性也不是很好，所以需要全部推倒重来。

▲没有拆除之前的原始样子，装修比较老旧，卧室深色的木地板让空间显得压抑；唯一优点是光线一览无余
▲过去的老旧格局，户型都比较方正，而且南北通透，还有单独门厅；两间卧室分别一南一北，朝北是厨卫空间，格局非常完美；唯一不足是厨卫都比较小，卫生间没有干湿分离，厨房功能性收纳不足

▲重新布局以后的样子，因为户型本身缺点极少，所以改造格局的地方比较少，只是局部增加隔墙满足定制的美观改造；因为只有两人居住，所以满足一间主卧的同时，需要一间备用儿童房，平时可以兼顾办公书房空间；利用厨卫之间新建墙体，同时满足干区以及厨房收纳的延伸，从而满足餐厅远离卫生间的布局
▲入户有个小的单独门厅，利用新砌隔墙直对定制鞋柜，满足基本收纳；镂空处感应灯布局满足进门的第一眼温馨；原木的树桩换鞋凳以及挂衣钩满足进门的功能设计
▲门厅进来右手就是北向的厨卫空间，为了满足干湿分离以及厨房收纳的延伸，采用新砌隔墙的形式，第一延伸出来干区，同时满足干区背面的收纳柜定制。玻璃隔断延伸墙体，满足餐桌远离卫生间的布局形式
▲干区与厨房收纳柜背靠背满足功能，玻璃视觉通透同时延伸墙体，原木的餐桌椅布局，条凳以及餐椅的非对称设计空间更显得灵活
▲餐厅看门厅空间，整体简洁明亮的瓷砖铺贴，墙面淡灰色统一变色，原木家具的加入，自然环保
▲极简白色单头吊灯以及极简挂钟装饰，营造更干净的就餐氛围
▲沙发旁边多余的空间，布局一个原木斗柜，挂画以及拱形的全身镜装饰兼顾功能，合理利用空间并提升空间的层次感

▲客厅全景，无主灯布局，在明亮光线的加持下，整体更干净清爽
▲客厅延伸原木家具的搭配，同色系的沙发布局，颜色上简洁干净，空间更具高级感
▲沙发背景组合简洁挂画，营造温馨氛围，局部暖色系与整体原木呼应协调
▲客厅看全景空间，颜色上确保统一协调，功能上多采用轻巧家具搭配，满足空间的开阔以及整体的颜值高级感
▲全景空间，浅色的底色上，原木自然的层次感搭配，整体清爽宜人
▲卧室同样延续原木的自然，采用颜色的撞色床品以及圆几呼应，提亮空间的视觉亮度
▲侧墙衣柜满足收纳，原木与藤编结合的床头柜提升层次，金色台灯满足功能性
▲次卧备用儿童房，目前同时兼顾两人的书房空间；U型布局满足功能性最大化，可以让空间更显开阔
▲厨房L型布局，延续了原木与白色的定制，简洁干净

▲新砌墙实现的干区布局，同时延伸了厨房的收纳，空间布局更加合理
▲干区实现以后，原有湿区空间得到释放，满足了休闲浴缸的布局
