# 140㎡老旧复式改造，办公室变身小夫妻婚房

大家在看老房改造的案例的时候，是不是会惊讶于前后对比的天地之差？心里肯定有疑问，人家的改造为什么这样好呢？其实这个常识以前普及过，为了给大家展示最美的，老新对比拍摄设备是不一样的，老的让其更老，新的让其更美，这也是人爱美的天性。大家在看的时候自己一定要想，镜头中的世界和现实世界，隔着一颗不同的心。《装修后的家，宁愿永远活在相机里》

今天是一套老旧的复式办公室，原来一直作为办公室出租用，现在需要住家，所以进行的大改造。
▲一楼原始结构。进门右手厨房，再过去就是客餐厅空间，左手是卫生间以及楼梯空间，每一层各70平方，共140平。
▲二楼的原始结构图。楼梯上来是主卧，楼梯平台有个很小的储物间，储物间的另一边是次卧空间。楼上三个房间。
★原始层高5.5米，但是做完钢结构就显得压抑，本身空间很小，一楼公共区域显得很拥挤；二楼虽然有三个房间，但是都很小，而且楼上没有卫生间，生活一点都不便利。
▲未改造之前的样子。为了让前后对比更强烈，故意用手机拍摄，好和后面的单反拍摄做对比，这样的效果都是大家乐于见到的。老旧阴暗，家具破旧。
▲一楼改造后的布局图纸。打掉进门右手厨房做了开放式布局，同时把厨房朝向客厅推进，给门口增加收纳储物空间，同时增加吧台功能代替餐桌；缩小进门左手的卫生间，挨着楼梯增加收纳空间，满足一楼的储物需求；原来的客餐厅缩小以后，为了改变压抑状态，切割掉部分钢结构，让客厅局部空间挑空，让空间敞亮
▲二楼的设计布局图。首先缩小楼上的储物间，并且与主卧打通，储物间做了衣帽间，扩大了主卧面积；缩小次卧空间，在一楼卫生间上头借用管道新增加卫生间以及洗衣区。
▲原始的入户空间。钢结构下黑色的铝格栅吊顶，让光线更加压抑，同时杂物堆积，显得非常拥挤
▲装修后的门厅，打掉厨房内推以后，门厅形成单独的区域，利用烟道形成的凹陷区定制收纳鞋柜，满足进门的收纳，地面六边形网红瓷砖与局部脏粉色呼应，让空间明亮时尚；同时原来的格栅黑色吊顶取而代之是平面石膏板，暗藏筒灯，让光线更通透，视觉更简洁
▲打掉厨房向客厅推移，利用墙面尽可能收纳布局，高柜与地柜、吊柜的集中收纳，满足基本的生活需求；颜色以白色为主提亮视觉亮度，局部木色套色与拐角吧台呼应，增加温馨感；
▲一字布局橱柜，刚好满足洗切炒的合理顺序，因为是开放式，尽可能利用收纳，让空间整洁。
▲厨房与客厅之间新砌墙体做了分割，同时为了满足燃气热水器的悬挂。一般小区开放式布局，燃气热水器是无法安装的，这个大家做的时候一定打听清楚再做，因为本套房本身是商住两用，而且老旧小区。利用厨房拐角做了吧台功能，代替餐厅功能，同时又能合理分区，让视觉更完整，不会因为空间小，功能多，而显得凌乱
▲地方小就得极尽收纳，连热水器也做了简单挂钩，可以用来放置厨房清洁纸巾；水槽很小，滤水蓝多余，刚好可以作为收纳篮使用
▲乌漆墨黑的客厅空间，当然这个是手机拍摄，也没有开灯，就是为了和新装修进行对比

▲因为厨房的前移导致客厅就小了，所以为了增加视觉的通畅和明亮，把原来的钢结构切割了一部分，让局部挑空，形成原始的5.5米层高，空间豁然开朗。不论是光线还是通风都得到提升。这样的话就形成了超高的窗户，在窗帘改造的时候因为太高，没法手动拉动，只能采用电动窗帘的形式，非常方便《电动窗帘，会生活就做吧》一袭纱帘不仅透光好，而且视觉洁白清爽
▲为了弥补收纳不足，沙发前移，背后通顶收纳柜定制，刚好与厨房区域形成隔而不断的整体，同时利用落地窗飘窗柜定制，与电视柜连成一体，不仅满足了收纳，视觉上更完整，更有延伸感。
▲因为空间小，飘窗柜满足收纳的同时，兼顾一部分沙发功能，这样就不至于沙发太大导致空间拥挤《客厅有飘窗，连沙发都省了》电视柜下方镂空布局，一是为了方便放置随手物品，二是平时可以兼顾书柜的使用，虚实结合视觉更灵活。
▲蓝灰色布艺沙发，鲜亮的抱枕舒适搭配，背后是白色与木色套色的温馨收纳柜，采用无把手极简布局。茶几是大理石台面金属质感的轻奢款式，视觉极简同时让空间更大
▲这个是没改造的楼梯空间，原来办公采用极简的钢木楼梯，显得简陋不美观，镂空踏步也不安全

▲更换以后的实木楼梯，实木厚重的踏板，与其他家具木色呼应一体，钢化玻璃以及黑色的扶手极简明亮；楼梯下方可以利用起来收纳储物。楼梯上去就是卧室的私密空间
▲楼梯上来的过道空间，因为楼上没有厨房，晚上休息想要喝水非常不方便，所以刚好利用镂空过道空间，金属斗柜作为水吧台使用，《家里水吧台是什么？有什么功能？》安装净水机，平时晚上喝水不用下楼，非常方便。地面同样采用网红的六边形瓷砖，局部脏粉色点缀，视觉非常清新柔和
▲楼上的主卧空间，背景蓝灰色变色，因为墙体本身有柱子，干脆借着柱子做了造型处理，床头背后形成一个凹陷区壁龛，刚好灯光点缀，可以随手放物品，也算比较完美的做法；原来的储藏间打通以后做了衣帽间功能，谷仓门封闭，内部开放格局，满足衣物的收纳《衣帽间衣柜，封闭还是开放好？》
▲造型壁龛反而成了一个亮点，摆上挂画和装饰品，让卧室温馨很多，两边对称极简的吊线灯满足局部照明，视觉层次更温馨舒适
▲卧室的另一边靠近窗户位置布置化妆台区域，同时延续使用脏粉色涂刷，和床品呼应，卧室更温馨舒适
▲储物间增加衣帽间功能，可以腾出更多地方作为活动区域。布置化妆台的位置，靠窗户角落与客厅连通，护栏围挡
▲楼上过道，卫生间门口做了收纳柜以及干区空间，洗衣机烘干机刚好放置。这里也是借用楼上新作卫生间实现下水以及上水的布置，局部墙面脏粉色与六边形瓷砖的延伸点缀，搭配金色圆镜，非常清爽精致
▲一楼的卫生间，很小，黑色的定制浴柜和台上盆满足功能，镜柜收纳储物，采用白色面包瓷砖搭配变色乳胶漆，让视觉更明亮，层次分明。因为一楼卫生间缩小以后，空间实在太小，就没有安排淋浴，所以采用了彩色乳胶漆做法，视觉效果更美观《厨卫不贴砖，刷防水漆靠谱不？》
▲二楼卫生间的浴缸区域，背景六边形网红瓷砖背景装饰，视觉非常精致时尚END
