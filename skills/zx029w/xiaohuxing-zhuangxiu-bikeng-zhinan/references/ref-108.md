# 小户型客厅设计，一个比一个好看

客厅作为休闲活动区域，空间一定要有空余，千万不要心疼房价这么高，恨不能每一件家具都把客厅塞满，这样才对的起高昂的房价。

这是过去式的装修了，在我们没有解决温饱的时候，思想也是枯竭的。物质基础决定思想境界。所以现在装修一定要有更好的品味，不要只考虑吃饱穿暖了。这篇文章可以给大家一个借鉴《沙发怎么摆放好看？别把客厅当库房9.2》

好看吗？其实每一个普通老百姓都可以装出这个效果，只不过很多时候，业主不可能都听设计师的，导致设计师有心无力，只能顺着业主的意思，结果是每一家不伦不类，后期想有所挽回已经没有回天之力了，设计师也就放任业主自己操作了。房子是业主住，设计师干着急也是无用的。

再一个西安地区装修，好多业主犯了一个错误，就是该花钱的不花钱，不该花钱的使劲花钱，导致后期装修结果和实际生活脱节。

一个家里好看美观不仅仅是功能性，同时也得赏心悦目。好多业主是进门电视墙豪华加俗气，然而家具却买的一点档次都没有，家，完全就是只能远观，不能入住了。沙发不敢做，坐了就变形；更不要提金厨银卫了，马桶一千以上的都心疼钱，橱柜一米一千的都是天价了，如果是这个情况，何必做电视墙造型？何必做吊顶？

各种华丽花哨的造型是经济允许的前提下，保证基础质量的前提下做的，如果连基本生活品质都达不到，奉劝各位，面子算老几？装修是为了自己生活品质，而不是让朋友来了充个面子。假如朋友看到你豪华俗气的背景虚假的赞叹两声，上厕所发现你家已经变色的马桶，生锈的水龙头，不知道这个朋友会怎么想？

真的装修哪怕是刷墙铺地，但是自己用的东西件件品质，这才是真的装修，为了自己。
