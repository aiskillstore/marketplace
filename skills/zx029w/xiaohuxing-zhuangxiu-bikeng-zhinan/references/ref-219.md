# 105m²三室改造，打造三分离的紧凑美居1.24

三室紧凑户型，比较方正，未来最多三口之家，刚需都能满足，但是致命的缺点也有。
▲原始图三室刚需，入门是厅户型，右手厨房还通向一个小的阳台，导致厨房被过道挤压无法满足基本的操作；卫生间只有一个而且很小，以后很难满足三口之家的使用。▲改变厨卫格局，把原有小阳台分割成了淋浴区，缩小原有卫生间，成就单独马桶区和干区，三分离完美实现；厨房空间也得以拓展，砸掉原有厨房多余墙体，采用收纳柜代替，厨房不要门，进门收纳得到拓展，同时刚好遮挡干区和冰箱的功能；移动主卧入门成就门口衣柜的定制；电视墙满墙柜满足公共区域的收纳，利用餐边柜位置满足进门的收纳▲入门是厅，只能借用定制餐边柜，门口布局换鞋凳镂空，满足进门临时放鞋；上方洞洞板满足随手置物，弱化进门的压抑感；利用厨房墙体定制收纳柜，可以弥补门口鞋柜的不足，也可以满足进门随手置物▲原木色的换鞋凳三层布局，满足进门的临时放鞋，同时成就换鞋凳，上方是灵活的洞洞板进门随手置物▲餐厅以及沙发墙体统一薄荷绿变色，拉伸层次，空间视觉更清新▲电视墙满墙柜定制满足公共区域杂物收纳，利用厨房门口收纳柜代替墙体，弥补收纳不足；收纳柜左边过道进入主卧和三分离卫生间▲客厅打通阳台，阳台满足生活所需，绿色的布艺沙发搭配轻巧圆几和单椅，视觉更极简▲打通阳台拓展空间，提升了整体的采光▲墨绿布艺沙发，绿植点缀，抽象挂画错位布局，干净舒适▲客厅阳台一边高柜定制，满足洗烘机的布局▲客厅阳台另一边成品极简吧台布局，可以满足平时的阅读休闲；地面是清新花砖区域划分▲主卧鱼骨拼的木地板背景搭配，提升视觉层次▲整体木色的搭配与灰色的对比，自然舒适▲床头右边蘑菇吊线灯营造氛围感▲移动主卧入门满足床尾的衣柜定制，同时门口局部木色镂空满足夜晚的随手挂衣▲主卧门外的三分离卫生间干区空间▲次卧依然灰色的背景涂刷，搭配原木的床铺，素雅干净▲侧墙是白色的平板衣柜定制，满足基本的收纳储物▲很小的书房墙面蓝色涂刷，搭配蓝色的吊柜定制，原木隔板书桌布局，可以让空间更简洁，搭配复古的皮质单椅▲书房光线非常好，黑色的百叶轻巧布局，洒下斑驳光影，非常有美感▲厨房L型布局，深灰色地柜搭配白色吊柜，视觉更有层次；地面水磨石瓷砖搭配墙面局部花砖点缀，空间更有层次感▲三分离的干区空间，一边是厨房收纳柜，另一边高柜薄柜满足壁龛收纳，灰色的悬空浴柜定制，精致的双镜组合▲干区过道能看到另一边的马桶区，花砖与小白砖的清新搭配，半截墙铺贴，视觉上更有层次感▲左手独立的马桶区，直对是独立的淋浴区，三分离空间的布局，可以满足更多的方便实用
