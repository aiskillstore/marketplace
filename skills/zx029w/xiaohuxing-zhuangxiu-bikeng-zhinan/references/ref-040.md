# 小户型厨房的鸡肋角落，怎么合理利用？8.29

厨房不是豪宅一般都很小，所以每一家厨房收纳是重中之重。

在实际装修里头，一部分人会有误区，只考虑空间的宽敞，而完全忽略厨房的收纳储物，这个是错误的做法，后果就是入住一两年厨房完全杂物堆积，台面凌乱，因为没有地方收纳。

所以厨房满足基本的操作空间以外，剩下的都得满足收纳。特别是小厨房更应该利用各个角落满足收纳最大化，留出仅有不影响操作的空间即可。

第一、垂直空间的利用

▲所有不影响操作空间的墙面，都可以利用起来，例如切菜区或者备菜区的空白墙面，采用壁挂收纳架，满足厨房物品的随取随拿

▲隔板架，利用空白墙面做隔板架，也是墙面利用的极致做法，平时可以随时放一些经常用的物品，拿取方便，也不会视觉上造成压抑感。长度宽度可以根据空间的不同进行调整，任何角落都可以利用起来

▲隔板与挂钩的配合，上方隔板，下方挂钩，完美利用墙面空间，而且适应不同的物品收纳

▲垂直空间不仅仅是墙面，同样地柜门内部也可以借用各种挂件，用来满足杂物的归类收纳，真正把厨房寸土寸金利用极致

▲磁吸金属刀架，平时刀具放哪都觉得占地方，可以利用墙面磁吸刀架吸附，不占地，随手拿取也方便，同时只要是金属的材质都可以随时吸附上去

▲厨房洞洞板利用，这类洞洞板有打孔安装，也有免钉安装，根据大小以及收纳物品的重量，选择合适的墙面，可以收纳好多厨房经常用的零碎，不要嫌视觉上不好看，很乱，没有地方收纳，这个可以挽救厨房收纳的不足，此时就不要奢求什么好看了，功能要紧

▲厨房调料架，这也是常见的，在离灶具很近的墙面规划一处专门放置随手 调料的置物架，不占地而且烹饪时候随手拿去非常方便

▲厨房挂钩，如水槽上方横排挂钩，可以随手悬挂厨房的洗涤用具，随手拿取，也利于沥水通风

▲厨房备餐区或者切菜区的墙面，完全可以利用起来，利用挂钩，满足小型锅具，金属用具的悬挂，保证台面的干净同时，使用起来也非常方便

▲隔板挂钩以及墙面电器架，甚至利用集成灶的上方，都可以满足随手物品的收纳和摆放

▲如果你家厨房收纳不足，台面杂物堆积，看看上图，就知道该如何去做了，利用所有能利用的墙面，都可以让厨房变成收纳库，而且用的时候一目了然，再也不用到处寻找。当然有人会说这样都是油烟，你有收纳柜的话谁愿意利用墙面，这是刚需没有办法的事情

▲水槽与吊柜之间的墙面，全部采用挂钩满足收纳；甚至吊柜下方也可以利用免钉挂件，满足各种物品零碎的收纳

▲即使厨房再大，墙面都不能浪费，利用起来，让操作更方便，满足厨房无数个零碎的归类收纳

▲磁吸的调料盒，可以吸附到任何金属的表面，甚至冰箱的侧面，利用垂直空间满足调料的随手放置

▲冰箱垂直空间的利用，磁条吸附，可以放置调料，也可以挂毛巾纸巾，非常方便，而且各种颜色，可以提供搭配厨房整体的颜值

▲吊柜底部空间的利用，可以放置作为轻便的杯架，以及纸巾的收纳，承重安全，而且合理利用空间

▲靠近厨房角落的位置，垂直墙面更应该极尽利用，因为不会影响厨房动线，也不会影响正常的烹饪操作，这里完全可以作为收纳的静地利用起来
第二、台面空间的合理利用

▲木质的随手小型调料架，放置在灶具的附近，可以随时拿取随手放置，合理归类常用的调料用品，把台面的角落利用起来

▲免钉的垂直收纳架，利用台面和吊柜之间的空间，搭建一个小型的随手置物墙。
▲扇形收纳架，可以利用角落空间，分层利用台面位置放置厨具用品，可以根据空间的大小选择相应的层数，下方放置重物，上方放置轻便物品

▲这种耐擦洗的金属置物架，非常方便，家里有角落台面无法利用，可以利用起来，上方放置随手的杯子调料，下方可以放置经常使用的碗碟，甚至小的家电都可以放置

▲像水槽下方的收纳，每家情况不一样，所用电器不一样，能多放点杂物当然更好《厨房储物，挑战一下水槽下方的收纳》
因为都是刚需空间，所以对于厨房台面的收纳还是谨慎再谨慎，如果影响到正常的烹饪活动，可以舍弃台面收纳，保证基本的操作空间。
第三、厨房定制收纳厨房想要收纳具备，其实最重要的是后期的橱柜定制，一个合理的定制，完全省去了后期的各种置物架。但是如果一个完全不会设计，只会做盒子的定制商，厨房收纳就会失去最重要的机会了。

▲除过正常的满做地柜吊柜以外，其实可以利用的就是包管道剩余的空间，如图利用管道前方空间，作为超薄开放格使用，可以放置厨房的各种瓶瓶罐罐，也是合理利用空间的一种做法《只包管道就浪费了，做成收纳就有价值了》

▲如图地柜利用拐角空间，延伸一个斜面的柜体，满足橱柜的延伸收纳

▲高柜镶嵌冰箱，这是必备操作，千万不要刚需只是放置冰箱，空间全部浪费；如图不仅高柜满足视觉的美观，同时延伸收纳，而且烟道位置也利用起来做了超薄的开放格，放置小家电以及随手物品非常方便；拓展收纳提升颜值双重作用《冰箱放厨房最好，怎么放是个问题》，这样的定制完全不用后期各种杂乱的夹缝收纳。

▲燃气表柜，能包就包，视觉美观，而且可以满足一部分零碎物品的收纳。让很小的厨房视觉更美观

▲燃气表的定制装饰兼顾收纳，如果心疼钱就算了，金厨银卫，厨卫都能应付，遑论其他

▲即使吊柜有柱子，也可以利用起来，去掉柜门，超薄收纳，满足零碎的随手放置，而且视觉也更美观

▲能实现U型尽量去做，哪怕超薄地柜，本身就是刚需房子，又想收纳充足，还想厨房能骑自行车，这不现实，面对现实吧，不用逃避，本身就小，收纳都不足，心有豪宅是没用的。

▲甚至能实现超薄高柜的话，尽量去做，薄柜一面墙，也能满足超级收纳，让视觉上厨房更整洁。但是大部分人本末倒置，装修死爱面子，客厅花里胡哨电视墙做一大堆，到厨房了心疼定制的钱，这个几乎是一部分人对待家庭装修的弊病了。功能都实现不了，面子早都没有了。

▲烟机能包就包，你以为烟机是为了好看吗？是为了拓展收纳而已，不要说烟机后面不好拆卸，是你自己没有设计对而已，烟机镶嵌需要留出升降空间，保证没有缝隙，后期可以随时拆卸《烟机与吊柜有缝隙太难看，一招解决》

▲和管道类似，烟道的位置也可以利用起来，超薄收纳，为什么要牺牲地柜用调料蓝呢？

▲至于厨房拐角的空间，千万别信卖拉篮的弄什么转角拉篮了，多此一举还费钱，就是更换个大角度铰链，做成对开门就可以实现拐角的完美利用了《橱柜转角利用，没有那么复杂》
