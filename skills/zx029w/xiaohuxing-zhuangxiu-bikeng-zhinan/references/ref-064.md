# 电视墙线路，怎么隐藏起来？4.19

关于这个话题以前都说过，但是总感觉不够系统，今天重新谈一下，尽量系统起来，让大家能看懂。

一、电视墙需要隐藏什么线路？
1.电视电源线路，也就是插座线。
2.IPTV信号盒子出来的信号线。

普通家庭基本就是这两根线而已。那么怎么隐藏，需要结合实际需求。

二、实际案例来说明隐藏。
1.第一种：暗埋50/40管。注意：需要有一个前提条件，你家电视墙是非承重墙，否则无法实现。

▲如上图，采用暗埋50/40管，把电视柜下方电源与电视后面打通，这样就可以穿过电视线以及信号线了。
注意：左图一根管，右图两根管，右图的意思是弱电（网线）和强电（插座线）分开通过，但其实是错误的，网线无需通过管路的，如果是IPTV是信号线，而非网线，信号线和电源线放在一起，压根对电视或者网络产生不了任何影响。如果是看网络电视，更不要网线，直接内置WIFI即可。
▲这就是做出来的实际样子，下方电源和下方管口，刚好隐藏在电视柜的镂空区域
2.第二种：无法暗埋50/40管。这就是电视墙如果是混凝土墙的前提下，怎么去隐藏。
和第一种预埋50/40管一样，改作预埋20水管即可。因为混凝土墙无法预埋那么粗的管子，但是预埋20水管还是绰绰有余，并不会破坏钢筋。所以IPTV的信号线完全可以穿过20管实现隐藏。
这里就有一个问题，电视的电视源线怎么办呢？因为插头太大，20管根本过去不。
▲如图，20管预埋穿信号线，在电视机后面偏向两边安装一个五孔插座带开关，直接把电视电源插到五孔即可，偏向一边的原因是为了方便每次给电视断电。注意：有一个条件，你家电视是普通壁挂或者带伸缩架的壁挂电视。
▲如图如果家里是贴墙电视或者激光电视的话，第二种是无法实现的。

▲购买激光电视如果是混凝土墙，最好提前规划，可以如上图做法，做电视墙收纳柜，镶嵌电视，所有线路都可以方便隐藏起来。《电视墙套色收纳柜，清新还亮眼》
三、电视墙的插座怎么隐藏？其实就不存在的问题，不论装修前规划不规划都不会出现插座外露的情况，只不过你的电视柜买错了而已。
两种情况，一种是装修前你看好电视柜，根据你的电视柜的高低布局插座，就不会外露；第二，装修的时候没有看好电视柜，你后期根据插座高低购买电视柜即可。否则你随心所欲，当然外露。

▲如上图，不论是先购买电视柜还是后购买电视柜，插座都可以隐藏起来的。大部分人犯的错误就是，后期购买电视柜不看插座，随心购买；或者是能隐藏插座的电视柜都看不上，看上的都外露了而已。
四、电视墙需要几根网线？和你家宽带有关系，以西安为例，如果你家是300M的家用宽带，一根网线也是可以的，网线是8根线，四根路由器，四根IPTV就行；但是大部分人认为这样分线会影响网速，其实宽带达到300M，平时就是看个电视，玩个手机WIFI，是一点不受影响的。当然，如果嫌后期影响网速，记着电视墙上头穿两根网线就行，一根从猫到电视柜的路由器，一根从猫到IPTV信号盒即可。
