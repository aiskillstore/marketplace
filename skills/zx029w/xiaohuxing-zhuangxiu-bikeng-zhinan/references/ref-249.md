# 90m²老旧房改造婚房，4个月20万成果惊艳

结婚是人生大事，没有婚房发愁，有婚房照样发愁。小两口的婚房是现成的，但是是老旧小区的房子，以前一直出租，现在收回来才知道实在太破败不堪。年轻人有没有实力去单独购买新房，为了减轻父母的负担，决定重新改造，看着老房一天天完美，也是缔造幸福的过程。
户型：两室一厨一卫三阳台风格：北欧原木混搭造价：拆除+垃圾处理0.8万，半包基础5万，主材6万，入住20万左右
▲此套房因为是老旧小区，所以格局和目前的新房有所不同，单从格局看亮点多多，比如有大小三个阳台，实在是非常惊喜了，虽然纯南户型，因为两个大阳台朝南，所以光线是一点不受影响。
业主要求：在尽量节省预算的情况下，做到北欧的清爽，喜欢原木的感觉。所以原来的地面瓷砖能不处理就不处理，直接铺木地板，局部的电路采用墙面和顶面排线，这样虽然牺牲了部分层高，但是预算省下来了。原来的格局因为大部分承重墙，所以没有做任何改动，保持原来的格局
▲先看看未改动之前的客厅，其实朝南大的阳台，光线不错，晚上看不出光线，只不过以前出租房，所以比较陈旧而已。阳台黑色的移门完好，所以打算保留不动。客厅瓷砖虽然旧但是也是没有破损的地方，所以在上面直接铺木地板，阳台的瓷砖更换掉，这样成本能低一点
▲客厅的阳台，其实空间挺大，因为有单独的洗衣间，所以这里纯粹作为休闲空间，还是想保留露台的阳台，把老旧的瓷砖更换掉，墙面做处理即可
▲厨房空间，因为空间不大，过去的老旧搭配显得很暗，需要全部砸掉重新去做，为了光线通透，反正很少做饭，决定不要门，尽量把门洞扩大，半开放厨房和餐厅更好的互通开放
▲看看装修后的样子，因为原来的瓷砖不拆直接铺木地板，连找平的钱也省掉了。因为是老小区，丑陋的防盗门也更换掉。进门右手放了简易的换鞋凳兼顾鞋柜，反正只有两人平时鞋子不多，换季的鞋子有专门的收纳柜。进门左手区域就是餐厅，靠墙刚好布置冰箱以及斗柜，原木的餐桌搭配不同的餐椅，在满足原木的基础上，让颜色更跳跃丰富

▲转过来看餐厅全景，因为厨房很小，而且厨房只有一扇小窗户通向洗衣间，所以为了采光和放大空间，厨房半开放设计，不装门，而且把门洞尽量扩大，这样厨房的光线可以和餐厅互通，而且视觉空间更大。大面积墙面没有做颜色处理，全部大白墙，和木地板和原木家具呼应起来，非常亮堂清爽
▲这是门口的鞋柜，兼顾换鞋凳，平时两个人足够使用了，进门的包包直接可以放
▲站门口看全景，右手卫生间门口单独做了一组收纳柜，用来兼顾鞋柜的不足，同时为了把客厅和卫生间区域分割，因为光线超好，所以完全不影响进门的光线
▲收纳分割一是为了避免电视墙刚好挨着卫生间，二是可以弥补鞋柜的收纳不足，三是进门有了个遮挡，也可以起到玄关的作用，所以好处大于坏处
▲客厅沙发区域，背景不大，所以深灰色沙发搭配白色的铁艺圆几，浅灰色地毯以及亮黄色的抱枕可以冲淡一下沙发的颜色。角落利用卧室的墙体挖了一个壁龛，采用黑色定制，形成一个可以放书也可以展示的壁龛。平时坐沙发也可以随手拿书，非常方便。即使摆上精美的装饰品也是不错的。挂画是随便网购的，没有按照居中悬挂的形式，错位悬挂，效果意想不到的好看
▲原来阳台的门完好无损，所以就没有拆除，做了保留，只简单做了窗帘。电视墙因为刚好有收纳柜分割，比较完整，角落绿植摆放，搭配同样原木的电视柜，因为装修实在太费钱，目前电视还没有购置
▲客厅看餐厨区域，客厅灯具餐厅灯具以及金色的落地灯是一起购买，金色轻奢，能提升空间档次
▲进入主卧，面积比较大，而且带阳台，光线不错。背景做了蓝灰色的变色处理，侧墙定制白色与木色清新的衣柜，统一原木家具简单搭配
▲因为原来的瓷砖没有改动，直接铺木地板，后来的床头电源都是从墙面直接开槽布线的，加了双控的开关
▲转过来看一下主卧全景，原来的阳台门保留，把阳台做了封闭处理，做了单独的书房空间，这样主卧就形成了套间形式，非常完美
▲主卧单独的书房布局，同样没有拆除瓷砖，而是直接铺木地板，墙面大白墙是重新处理的。侧墙成品配套的原木书桌和书柜，放上简单休闲沙发，这里就是休闲兼顾书房的空间
▲因为就两个人居住，目前也没有想过要小孩，所以次卧就单独定制了榻榻米，万一父母过来，能暂时居住
▲原来客厅的露台保持原状，把瓷砖更换成了北欧流行的迷宫瓷砖，放上休闲藤椅，这里作为平时休闲喝茶的空间
▲厨房是全部砸掉重新做的，经典小白砖搭配白色与木色的厨房，视觉更清新。因为小窗户通向洗衣间，而且洗衣间非常小，所以把洗衣机放进厨房，这样洗衣间专门晾衣服还能大一点
▲L型布局对于两个很少做饭的人来说，算是奢侈的
▲卫生间全部拆除重新做的，地面灰色瓷砖搭配小白砖，光线视觉非常明亮。淋浴区域挡水+浴帘基本满足功能，浴柜是定制的同样木色和白色搭配。END
