# 家里酒柜别瞎做！高颜值又能 “藏酒” 的设计，内行人都抄作业

以前的酒柜现在都是餐边柜了，但是爱喝酒的人就不一样了，家里总有一个地方需要给酒留出单独空间。今天盘点一下家里酒柜的做法，看看爱喝酒的人都是如何存放酒的。第一、局部酒柜设计。网友@叮当：心爱的酒柜终于落地了，黑色柜体加上黑色边框玻璃门，内置灯条，因为单独区域只放酒，并不会显得凌乱。网友@y叶问：收藏了数十支酒和100多只酒杯，用2个煤黑色的宜家鲁德斯塔玻璃门柜做酒柜，加上灯光的修饰， 这个blingbling的小角落充满幸福感。傍晚饮一杯，微醺时徜徉在醉人的精神世界，无比放松。网友@有点乖：装修之前老公一直想要一个酒柜，考虑到实用性，没有全部做成玻璃柜门，酒柜只做了左侧的一门到顶，中间的隔层做了区域划分，整体更实用美观。网友@草上飞：酒柜是装修的时候木工打的，总共5层，上面四层是36cm，基本适合所有酒的高度，下面一层是45cm，个别酒、瓶子比较高就放下面。网友@宁静：酒柜不仅是收纳，更是家的装饰品。无论是欧式、中式还是现代风，都能让家更有质感网友@野智：平时很喜欢空闲时小酌一杯！可以嵌入式与家居色调统一 高级感满满，可以平行嵌入，定制化设计，满足多种存储需求。需要在定制前确定尺寸型号预留好尺寸空间，这样效果才可以严丝合缝，更美观。网友@不错的注意：因为中央空调回风口在下方，刚好餐边柜实现开放格的形式，选择了铝合金金属发光杯架，也作为酒柜使用，出来的效果连设计师都很震惊网友@皮国王：饮酒不多，还可以留出一部分空间放好看的酒杯，两排酒瓶绰绰有余，中间是水吧台，平常接热水和泡茶的空间，下面做了储物收纳 ，分别放调酒工具、茶叶、还有垃圾袋日用品网友@旭日东升：买花、买香水大概都是女生无法抗拒的事情，会被花香果香吸引，“威士忌”其实就像香水，琥珀色的酒液，富有浓浓的奶油香气 忙完一天 回到家最放松的是播放一首喜欢的音乐，城市的夜光点亮 ，从柜子里挑选心仪的威士忌， 小酌一小杯 ，买酒开心 ，喝酒也开心！干杯！网友@穷鬼：餐边柜右边双开门的玻璃柜，看起来更通透不沉闷～放了很多瓶子漂亮的酒，打开灯还是很美的～网友@下山的猴子：利用客餐厅原有的凹角设计了一个类似嵌入式的小餐边柜，和家里爸妈拼着用，是我爸的展示酒柜，也是我的小小咖啡角，黑白配色的柜子➕白色电力轨道➕不锈钢和黑色咖啡角 整体搭配很和谐。网友@宅宅宅：2㎡的正确打开方式｜是超级惊艳我的吧台角落，伸缩的设计对小户型太友好了～ 傍晚待在这感受晚风、小酌一杯、休息办公（其实并没有）都无比放松惬意。生活仪式感：早餐咖啡、深夜小酌、下午茶时光、随时切换“迷你咖啡馆”或“家庭酒吧”模式。吊灯、灯带或烛台聚焦吧台区域，营造温馨或摩登的光影层次，成为空间视觉焦点。原来不锈钢酒柜这么香，可以恒温就算了，竟然还能放雪茄进去，好朋友想小酌一会，都不用去酒吧了，可以在家享受美好时光网友@巧克力：餐厅里我最爱的一个角落 新置办的酒柜实现了每个微醺的夜晚 整个空间立体起来了 立马拥有法式小酒馆的氛围网友@隐隐：家庭酒吧-制造属于微醺的夜晚，一块木板+一个挂壁式酒架=按压即喝网友@诗莹：在设计房子的时候，被嫌弃的鸡肋飘窗，被改成了家庭迷你酒吧，深夜的飘窗台会变身，有时是摇晃着冰块的爵士酒吧，有时是浸泡在梅子酒里的日剧场景，1㎡的宇宙，足够盛放所有情绪，如果你家也有一个鸡肋飘窗，可以参考这种形式，把它变成自己的精神角落第二、酒窖设计。第一眼就被这酒窖吸引了，灯光一打，氛围感直接拉满！微醺的感觉刚刚好～走进酒窖，就像走进了另一个世界。昏暗的灯光，加上一排排精致的酒架，感觉自己在拍杂志封面！家里某个角落 3～4平的玻璃隔间，比买几个Bosch恒温酒柜经济实惠，美观得多。楼梯下的空间改造成一个定制家庭酒窖，对于两层住宅的朋友来说，是陈列和储藏葡萄酒最简单的方法，不需要占用单独的房间空间，并且储酒量能达到五六百瓶，所以一定要好好利用楼梯间《楼梯下酒窖，在家享受美酒时光》极简美学：小型极简酒窖，以简洁线条和纯净色调为主，搭配木质或金属酒架，营造出高级感。无需过多装饰，简约之中尽显奢华。后记：普通家庭如果少量酒品，就可以利用定制酒柜的形式满足，如果家里没有喝酒需求，也没有什么展示品，定制不要做玻璃门，得不偿失。
