# 厨房带阳台，这样做都合理7.10

很多户型都有厨房带阳台的格局，有的是带生活阳台，有的是专用洗衣间，不外乎两种做法，一种是保持两个空间各自独立，一种就是把两者合为一体。

如果是洗衣间不晾衣服，建议合二为一，这样厨房空间更大；如果是带生活阳台需要晾衣服，此时只能各自独立，要解决油烟的晾衣的冲突。

▲打通空间，增加采光和厨房面积，同时利用小阳台放置冰箱等厨房用品。

▲打通设计，扩大厨房面积以及采光，同时原来的阳台可以作为厨房功能的延伸

▲彻底打通，融为一体，厨房面积更大，光线更好

▲空间更通畅，功能更多

▲虽然空间狭长，但是光线更好，功能区更多
