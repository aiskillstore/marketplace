# 阳台晾衣服太难看，咋办？10.26

这个几乎是装修过程中北方业主最担心的地方。不论装修的怎么漂亮，客厅唯一阳台晾衣服，不论从哪方面看，都难看，影响空间美观，而且来个朋友，更显得尴尬。

第一、摒弃老传统，迎接新科技带来的生活便利。

▲如图，如果阳台小，可以满足一个洗衣机位置，上方就可以满足一个烘干机位置；如果阳台够大，不仅可以满足洗烘的功能，同时还有地方做一个洗手盆，洗个小件衣服更方便，同时还有空间安装一个小洗衣机，满足孩子衣物的单独清洗。你家再也不用担心晾衣服的难看了，而且再也不怕长时间天阴下雨衣服无法晾晒的问题了。

烘干机其实和洗碗机或者和家里的智能马桶一样，好多人都会问一句：这个到底实用不？用过以后没有人能离开了；科技是为人服务的，更多便利机器都可以搞定。而且烘干机有杀菌消毒功能，实际效果要远远好于太阳的晾晒的。
尽量选择洗衣机与烘干机分体，除非空间真的不够才用一体机；一体机用同一个空间，烘干过程中免不了各种污渍，分开的话不至于难清理。
第二，不用烘干机，直接用晾衣架，咋办？
▲如图，一般北方地区，大部分人会在阳台吊顶，隐藏手动晾衣架的钢丝，其实这里一定注意，用电动的更好，不要吊顶《阳台不吊顶，更换电动晾衣架，反而节省一大笔费用》
▲电动晾衣架，吊顶不吊顶都是可以安装的，而且没有外露的钢丝，美观性更好；而且伸缩性的晾衣杆比手动固定2.4米的更灵活。
▲但是以上的做法晾衣服，并不能避免晾衣服的难看，只能在不晾衣服的情况下，隐藏晾衣架而已。如图采用局部吊顶做凹槽处理，把衣架隐藏起来，这样在不晾衣服的时候看不到晾衣架；
▲有晾衣架，可以采用两种方式遮挡晾衣服。
第一种：安装移门。这里一定注意移门不要选择框架厚重或者粗犷的做法，一定选择极窄边框，不影响视觉通透和采光的移门。
▲可以采用颜值高的长虹玻璃移门，透光不透影，不会影响光线，同时还能遮挡晾衣服的难看。用这种玻璃就可以客厅不做窗帘，视觉更开阔；同时门的形式根据空间大小，有普通移门，折叠门，或者三联动，四联动移门，效果都是不同的。
▲第二种，不装门，直接用纱帘即可。这也是最实用，颜值最高的一种做法。既能遮挡难看的晾衣服，同时不影响客厅采光，还没有布艺窗帘的厚重感，而且颜值非常高。再不用的时候，即使放到客厅两边，也是一种清雅装饰，不会难看，而且客厅和阳台随时互通，放大空间感。
第三种：非传统晾衣架，也可以改变难看的晾衣服。
▲折叠晾衣架，这类晾衣架非常多，用的时候拿出来，不用的时候收起来，根据阳台空间大小，可以选择横向摆，也可以采用纵向摆放，刚好让阳台墙体遮挡起来，也是可以的。而且阳台如果有收纳柜，可以把不用时的晾衣架收纳起来。
▲固定一边晾衣架，这类晾衣架可以放到最边缘，让阳台墙体遮挡一下，但是晾衣服的数量就比较少。
▲顶天立地垂直晾衣架，这种晾衣架仅仅需要一个角落就可以满足，如果阳台与客厅有墙体遮挡，刚好隐藏难看的衣服。
