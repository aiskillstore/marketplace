# 装修挑刺之阳台，不信看不出问题6.23

装修没有百分百完美，尽力而为。即使没有施工问题，审美差异不同，彼之砒霜吾之蜜糖而已。

即使你们平时看的高大上的美图，可能大部分人看的时候，看不出问题，但是如果作为业内人士要较真的话，问题太多了。今天就以实例“挑挑刺”，看看这些问题你们在意不。
▲高大上吧，注意看阳台窗户与下方墙体有个几公分的台阶，这里是乳胶漆涂刷，后期入住一旦这里有灰尘压根不可能清理，而且越擦越脏，所以这就是问题了。
前期如果是自己封窗户就应该注意这个细节，做乳胶漆就需要与窗户做平齐处理，或者把台阶留大，后期容得下石材台面的装饰。如图的不大不小，而且乳胶漆处理，除非用的是艺术漆，否则后期打理非常麻烦。
▲看起来毫无问题的阳台定制。第一吊柜与吊顶留缝隙是为了藏灰尘吗？显然这是全屋定制的问题，业主不懂的话，上下照顾不到只能给你留缝隙，和厨房吊柜有一拼《吊柜不挨顶，低价和不懂的必然结果》
第二，注意洗衣机上方空隙，至少在5公分，为什么不能做到1公分以内？美观和严谨大打折扣
第三，与洗衣机高度平齐做台下盆一定自己先试一下是否好用，高度是否合适，否则这个盆子高度至少90公分以上的高度了
▲读书喝茶的阳台，真的非常休闲自在。注意后面的书柜，明显这个是购买的成品，所以才会有很大的缝隙，大局没有问题，细节就不是很完美。时间久了这个缝隙里头灰尘无法清理
▲没有大问题，就是定制的时候，洗衣机尺寸把握不是很严谨，导致上头缝隙过大，这样洗衣机上方台面就高了
▲看似没有问题其实隐藏一个失误，注意吊顶是全部平面吊顶的，有暗藏筒灯，但是吊顶的时候为什么不直接留出窗帘盒呢？非得让难看的窗帘轨道外露？
▲如上图所示，既然石膏板吊顶都做了，顺手窗帘盒就留出来了，后期隐藏窗帘杆或者轨道要美观多了

▲高大上的美图看似完美而已。注意阳台吊顶是四周实现框架造型，其实这个框架造型只需要做U型结构就行，降低整体吊顶高度与大梁平齐，大梁本身就是造型的一部分，一是可以扩大阳台视觉范围，二是没有了收纳柜的刀把定制
▲上图能看出问题吗？注意阳台的石材台面，既然阳台铺砖了，这个石材台面不是多此一举？而且还出头定制，视觉上更突兀了
▲上图一是洗衣机上方缝隙过大，第二注意上方石膏线位置，要不不要石膏线，要不要石膏线，定制完毕需要石膏线柜子上方围绕，而不是很突兀难看的顶着收纳柜。
▲其实和衣柜定制如出一辙，不影响使用但是美观度极差《衣柜通顶，上头石膏线怎么办？》
▲上图堪称灾难现场了。第一，成品洗衣柜导致尺寸无法严丝合缝，死角太多，难看而且难打理；第二明显阳台地面通铺没有过门石，留地漏跑味？而且即使备用地漏也留到角落看不到的位置；第三，吊柜上方挡板恨不得做一米，这样全屋定制可以成本更低，用电动晾衣架，做这么高的浪费挡板，难道不是全屋定制为了节省成本？第四，阳台用铝扣板吊顶，丑陋而且高调，更突出丑陋《厨卫吊顶，没有存在感就是最好的搭配》
▲上图是咋想的把洗衣机放右边？下水上水都是由人的，肯定洗衣机靠窗户，另一边做洗手盆，而且柜门还能做个整体，而不是如图留个卫生死角
▲道理很简单，洗衣间肯定放到没有柱子的另一边，有柱子的地方做洗衣池，柜门刚好隐藏柱子的突兀，两图对比立马知道问题出在哪里了
▲或者这样做，也不至于留出死角难看
▲能看出问题吗？很明显右边洗衣池盆子做错了，本来应该是台上盆的，但是错误的做成了台下盆，导致每次洗衣服腰累断了；洗衣机台面高度在90公分以上了，这个盆子高度顶多75公分，明显低于一般人的使用高度了。如果要做台下盆，这个台盆高度与洗衣机台面不会相差这么大
▲正确的做法应该是如上图做法，台上盆高度适中，而且台上盆可以让盆子最大化

▲如图，注意左右两边的镂空地方做法不一样，很明显左边要好看完美多了
▲很明显上图黑色套色定制翻车了，这难道是做的鬓角？
▲阳台定制吊柜翻车，这么大缝隙
▲如图看起来非常高大上，单反让你家看起来更高级。注意看窗台位置，这里应该是踢脚线通铺，然后台面做石材，踢脚线和台面之间正常乳胶漆即可，但是这样人为包裹导致踢脚线与石材两边都有刀把无法过渡
▲如图窗套以及窗台石都是多此一举，装修冤枉钱就是这样花掉了的
▲什么时候阳台窗台需要做石材？当阳台墙面不贴砖的时候，有窗台就必须做石材台面，后期打理方便
▲阳台纯休闲布置，不仅墙面满贴瓷砖而且做多余的做了哑口套和过门石，喊着装修费钱，怪谁？《客厅带阳台，肯定通铺不分割》
▲这明显就是翻车现场，吊柜上头用铝扣板？旁边有个弯管直接做个盒子就可以和吊柜严丝合缝，既然有吊顶晾衣架钢丝外露？
▲这个属于审美翻车，窗户是推拉，而且需要采光良好，做个厚重的布帘，露出难看的罗马杆
▲其实就是换个窗帘，不仅满足遮光，而且视觉轻巧不会有厚重感
