# 有共用阳台，该怎么装修？5.3

好多户型里头都会存在共用阳台的格局，但是往往有利有弊，需要改动，需要根据自己的需求布局，今天看看这些共用阳台的改动案例，你家是否也碰到过。<点击图片可以放大>

▲1.餐厅厨房共用阳台。有其他阳台，这个阳台就显得多余甚至浪费空间，所以采用把厨房移到阳台，原来的厨房和餐厅打通拓展餐厅面积，而且成就了西厨和光线。
▲装修后的实景，不仅拓展了餐厅面积，同时成就西厨功能，光线和空间都得到完美提升。

▲2.两个卧室共用阳台。像这种格局，如果卧室都是单独睡人，肯定毫无隐私可言，所以必须分割成单独空间。

▲装修后的实景，两个阳台分割以后，主卧可以做整排的衣柜；儿童房做了封闭阳台，做了书桌学习空间。
▲分割的材料，如果允许可以用红砖，这样隔音效果要好很多，但是目前高层为了减少承重，阳台不允许用红砖，可以用气块砖代替，或者用石膏板轻钢龙骨隔墙也是可以的。需要注意，隔墙需要与窗户的竖向窗框协调，否则会有缝隙。

▲3.客厅和儿童房共用阳台。如图，客厅和儿童房共用阳台，而且是家里唯一的生活阳台，无法扩充到儿童房，必须保留生活阳台满足基本的生活所需。所以只能把儿童房原来通向阳台的移门改成窗户，满足采光同时有独立隐私。

▲装修后的实景，客厅进入生活阳台，阳台作为单独空间；儿童房原来的移门更改成窗户，保证光线，有了独立空间和隐私。窗外刚好定制洗衣机收纳柜，满足生活所需，这样使用阳台的时候，也不会打扰到孩子。

▲4.两个卧室共用阳台。如图显然这样做等于没有一个点隐私，所以采用封闭的做法，把生活阳台给主卧空间，满足基本的生活所需，也能保证次卧的独立隐私。

▲5.客厅和儿童房共用阳台。如图客厅与儿童房共用一个阳台，空间浪费不说，儿童房没有隐私，同时儿童房空间小，无法满足功能需求。所以采用把阳台一分二的形式---客厅阳台与客厅打通，拓展客厅空间；儿童房与阳台打通拓展儿童房的学习空间。

▲装修后的实景，共用阳台一分为二，客厅打通与阳台拓展空间，同时只在阳台做窗帘，放大视觉空间；儿童房的阳台与儿童房打通，作为孩子的学习和活动空间。

▲6.客餐厅共用阳台。如图横厅布局，客餐厅共用阳台，导致客餐厅地方狭小，同时影响视觉光线；整体砸掉，让阳台空间整体融进客餐厅，整体放大，不仅空间拓展了，光线好了，也能满足更多公共区域收纳，而不显得压抑。▲7.横厅户型餐客厅共用阳台。像一般这种户型中间如果没有柱子分割，是不需要处理的，共用阳台可以让空间更大，光线更好

▲装修后的实景，共用阳台不做分割，因为空间够大，不需要把阳台扩充进室内，所以保留格局，采用全景移门分割，同时采用透光百叶代替臃肿的布帘，让光线和视觉空间都能放大

▲8.厨卫共用阳台。这种户型非常苦恼，是必须修整的，否则非常尴尬，也不利于健康。把阳台一分为二，厨房阳台作为单独的储藏间，卫生间阳台作为家里的生活阳台使用。

▲9.客厅和卧室共用阳台。客厅与一间卧室共用阳台，这里取决于卧室的功能，如果是隐私卧室当然需要分割；但是上图是作为书房使用，所以对于隐私要求不是很高，所以采用折叠门的形式，分割客厅和书房阳台，平时可以打开，让空气流通，空间更加开放，有孩子的话，活动空间更大更多

▲装修后的实景，采用木质折叠门与旁边的KD板同色定制，这样客厅和书房随时可以互通，也随时可以保证书房隐私，空气流通更好，对于有孩子的家庭来说，空间活动空间更多

▲10.横厅餐客厅共用阳台。如图本来是横厅空间三室户型，但是为了满足多一室的需求，改变横厅，把原来客厅做了分割出一个单独的卧室空间，然后把卧室与阳台采用窗户封闭，保证隐私。原来的阳台与新的客厅打通，从阳台进入卧室阳台，满足生活所需

▲装修后的实景，改变格局，把原来的客厅分割了一个卧室，现有客厅打通阳台，然后从侧面可以进入生活阳台，满足生活所需

▲11.横厅餐客厅共用阳台。如图横厅共用阳台导致餐客厅变小，所以砸掉阳台，拓展客餐厅空间。

▲装修后的实景，砸掉阳台拓展客餐厅，扩大空间，满足更多功能。
▲12.客厅和老人房共用阳台。如图客厅阳台与老人房共用阳台，不做分割处理，老人房本身是窗户不是移门，刚好老人房外面阳台有下水，作为生活阳台使用，这样从客厅进入生活阳台，并不会打扰老人

▲装修后的实景，客厅与阳台打通拓展空间，从客厅阳台可以进入老人房外面的生活阳台，这样不会打扰到老人休息。▲13.横厅共用阳台。如图横厅共用阳台，不做处理，各自共用。

▲装修后的实景，餐厅进入的阳台做了收纳柜用来储物，阳台的中间墙体刚好收纳家里的单车，合理分区和利用空间。客厅进入的阳台作为生活阳台使用，放置洗衣机和烘干机。

▲14.主卧和儿童房共用阳台。如图主卧和儿童房共用阳台，而且儿童房外面还是生活阳台，所以不做处理，分别给主卧和儿童房安装移门分割，一是洗衣服不影响孩子，第二，孩子平时的活动空间更多

▲装修后的实景，主卧和孩子房各自安装移门与阳台分割，洗衣机晾衣服不会打扰到孩子休息，同时孩子随手打开门可以进入阳台，活动空间更多厨房门厅一体共用，80m²两室北欧质感时尚
