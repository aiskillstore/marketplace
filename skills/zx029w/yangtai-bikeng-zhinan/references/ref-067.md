# 没有阳台，人为造一个出来2.19

一般没有阳台是因为没有分割，例如客厅就是一个大开间，没有墙体分割，此时如果需要阳台需要自己划分；还有卧室空间，大卧室像做个休闲阳台，可以利用大空间分割出来。如果不想分割阳台，可以参考这篇《客厅无阳台，怎么装修？》今天看看这些没有分割阳台的格局，是怎么去满足功能的。

▲如上图户型，客厅没有阳台，其实是可以采用缩小客厅划分出来一个休闲阳台出来。

▲如图户型，阳台下水是有，但是没有分割，需要自己分割，如果后期直接砌墙的话非常拥堵，所以采用收纳柜的形式与客厅融为一体，洗烘机位置定制收纳柜，满足功能的同时，视觉上分割空间，同时整体空间拉通布局，也不会让空间缩小
▲没有阳台，可以人为利用客厅空间定制休闲榻榻米，满足一个休闲阳台的功能，也是不错的做法，视觉和空间功能明确划分
▲利用靠近窗户位置，单独分割一块区域做地台，采用木质的装饰，做成一个独立的书房兼顾休闲空间
▲户型本身就是一个落地窗位置，采用定制榻榻米延伸的形式，满足一个阳台休闲空间，同时与旁边窗下卡座链接一体，视觉上更完整。
▲将原有客厅缩小，采用新砌墙中式月亮门的形式，满足一个单独休闲喝茶区域
▲缩小客厅大小，靠窗户位置人为做一个休闲区域，满足休闲阳台的功能，同时两边收纳柜布局，满足收纳
▲利用现有空间，人为做休闲地台，同时木质造型装饰，成就一个单独的阳台空间
▲好多户型是有阳台下水，但是没有单独分割，可以采用单独吊顶的形式，加上玻璃隔断的形式，实现生活阳台的功能
▲客厅角落有下水但是没有分割阳台，可以采用玻璃隔断的形式，满足洗衣机的布局，同时视觉分区，空间也能整体通透
