# 阳台到底该不该封？我需要理由

一、为什么选封闭式阳台
1、扩大居室面积

尤其对于大面积阳台而言，完成封闭后甚至可以多出一个完整的功能空间，从而令室内多出一间卧室或收纳室，令居室内的功能设计更加完善，好用。
2、阻隔外界干扰

封闭阳台之后，一些来自外界的干扰会被更加彻底的阻挡在室外，从而大大提高室内环境的健康度，另外，封闭阳台还具有提升居室内保温能力的作用，冬天的冷，夏天的热对室内温度的影响要比未封闭阳台之前小得多。
3、提高防盗能力

封闭阳台之后，建筑外墙会更加趋于平滑，这无疑会给由外墙攀爬入户增加相当的难度。如果在封闭后的阳台外围再加装一圈铁艺防护栏的话，居室安全当然会更有保障。
二、为什么选不封闭阳台
1、日光浴

阳台是居住者直接承受阳光的场所，人们在阳台上可以进行日光浴，晾晒衣物等。科学实验证明，通过阳光照射，可以增加人体内的维生素D，有利于骨骼的正常发育和健康。阳光的紫外线也可以将衣物，被褥的面的各种细菌，病毒杀死。
2、实用性

开放式阳台有时候会比封闭式阳台更具有实用性，把花花草草钩挂在栏杆上，既节省了地面空间还装饰了原本空落落的栏杆，甚至还利用起了顶部空间，把盆栽悬挂起来，看上去也不错哦。
3、自然风

坐在这里可以感受舒适的自然风，阳台四周各种各种绿树植物和花卉的点缀，一个自然清新的小花园就呈现在眼前。
4、小资

有田园的感觉的座椅设计，中间摆一张简易的同色圆桌，旁边还有绿树陪伴，很有小资味道。
