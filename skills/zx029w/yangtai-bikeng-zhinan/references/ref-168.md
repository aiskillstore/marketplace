# 客厅与阳台彻底打通，区域划分怎么做？2.20

客厅带阳台，北方封闭阳台，肯定是打通布局，放大空间和格局的，但是打通以后怎么去进行区域规划，这里的做法就比较复杂，需要根据实际和功能性去做。

▲客厅与阳台彻底打通，哪怕是生活阳台；原有大梁保留，阳台单独造型吊顶隐藏晾衣架，一面收纳柜与电视墙整体收纳平齐，另一边高柜代替墙体实现洗烘机的镶嵌布局；整体空间变得更加通透，很好的实现了区域划分

▲客厅与阳台彻底打通，电视墙这边也可以借用阳台收纳柜，悬空电视柜定制，满足收纳，视觉更轻盈，而且更有延伸感
▲如果没有办法彻底打通，保留承重墙体，阳台单独的吊顶和收纳柜分区布局，地面通铺，窗帘直接布局阳台，空间也是可以放大和通透的
▲如果能彻底打通布局，电视墙的收纳柜与阳台收纳柜一体延伸统一定制，不同区域吊顶分区，视觉更有延伸感
▲L型休闲阳台与客厅打通一体，采用阳台单独吊顶隐藏大梁，沙发这边收纳柜分割区域，电视墙采用整体书柜定制，视觉空间更通透完整
▲打通以后，不一定非得人为处理大梁，如图大梁裸露，只要搭配和家具协调，颜值也是颇高的
▲也可以采用地台以及单独吊顶的形式，让阳台和客厅区域划分，同时收纳柜延伸定制，让空间既融为一体又能视觉上分离
▲打通空间延伸定制，各自采用不同吊顶划分空间，客厅变得更加通透敞亮。收纳柜局部镂空用来分割两边不同的收纳形式
▲如图空间打通以后，不同吊顶分割区域，一边收纳柜，一边高柜隐藏洗烘机，空间融为一体，功能却不一样，但是整体空间更宽敞明亮
▲也可以采用局部吊顶与阳台平齐，电视墙收纳柜一体延伸阳台，放大整体客厅的布局空间
▲如图同样是与阳台彻底打通，采用不同吊顶的形式与收纳柜进行区域划分，不同的是原有大梁做了弧形造型，让视觉划分上更加柔和
▲如图同样生活阳台打通布局，利用不同区域吊顶以及收纳柜定制的形式进行区域划分，可以让整体空间变得更通畅，更有延伸感
▲彻底打通空间布局，局部吊顶满足收纳柜的延伸，同时阳台位置避免遮挡窗户，布局书桌。满足视觉空间的延伸，同时又能满足功能性
▲如图是一边打通的做法，另一边承重墙保留，电视墙与阳台收纳柜完美结合，阳台单独吊顶处理，视觉上既有区域划分，又能满足空间的一体开阔
▲如图同样是承重墙无法拆除，刚好遮挡洗衣机区域，另外一边彻底砸掉，采用收纳柜形式与电视墙完美一体结合，放大视觉空间
▲如图同样是打掉原有阳台，彻底打通布局，一边收纳柜，另一边满足钢琴的放置；空调吊顶与阳台统一布局，视觉上作为分区设计
▲阳台与客厅彻底打通以后，定制榻榻米满足一个休闲的地方，大梁保留，同时不同吊顶形式满足区域的划分，同时空间上又能融为一体
▲休闲阳台彻底打通以后，单独吊顶划分区域，一边布局钢琴，阳台作为单独的休闲区设计，但是空间可以整体放大
▲阳台打通布局以后，采用收纳柜的延伸满足空间的开阔和功能的提升，另一边书柜书桌布局，让原有阳台作为开放式书房存在。空间既一体放大，同时不同功能又做了区域划分
▲彻底打通，只把收纳柜延伸过去，阳台作为留白区域，让整体空间极简干净
