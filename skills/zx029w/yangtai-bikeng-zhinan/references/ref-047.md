# 阳台不晾衣服，那就尽情养花吧1.29

一、用盆栽点缀阳台
如果有一个空闲的阳台，不知道做什么用，当然可以养些花花草草，除了养眼，还能养心。不需要多么专业的知识，可以在附近花卉市场自己混搭一个与众不同的阳台。

二、还可以用藤蔓植物点缀
盆栽植物相对藤蔓植物显得单薄，可以采用各种形式做藤蔓绿植点缀，一般的藤蔓植物比较好养，甚至还有四季常绿的藤蔓。春夏之际，整个阳台绿植和花卉缠绕，也是一番不可多得的景致。

三、隔板收纳，也放花盆
隔板收纳是家居装修里头常见的做法，所以可以利用起来在阳台做隔板，然后各种花卉点缀，又经济又实惠的养花方法。有铁艺，有木质，可以自己DIY用水管做隔板，好多方法，让布置阳台也成为一种乐趣。

四、成品花架阳台布置
这个就更加简单了，根据自己阳台的格局大小，买各种成品的花架，直接放上喜爱的绿植，这个几乎是大众化做的最多的一种。方便，而且各种花架材质都可以采用网购的形式。

五、绿植上墙，节省空间
绿植上墙可以借用工具，比如防腐木花架直接钉到阳台墙面，或者用铁丝网格固定在墙面，悬挂各种绿植花卉，这样的做法能让绿植面积更多，同时也能节省阳台的地面面积，放置休闲座椅，供人休息。
