# 阳台没有下水却要放洗衣机1.14

房子没有放洗衣机的地方，只能放到卫生间，但是卫生间潮湿，地方又小。有阳台，但是阳台没有下水。

其实如果只能放卫生间的话，就没有其他办法了，除非卫生间做好淋浴地方挡水，用浴帘遮挡，平时防止水溅到洗衣机，然后放置洗衣机的时候一定记得下方垫东西，否则地面潮湿也会腐蚀洗衣机的。同时平时注意保持卫生间干燥，否则严重影响洗衣机寿命。

如果只能放卫生间，能藏到浴柜下方最好，节省空间，也可以最大限度减少水淋。

阳台放洗衣是最好了，但是好多业主嫌开发商位置不适合，把洗衣机下水随意改动，如下图从阳台一头挪动到另一头。

看图上，把洗衣机下水直接挪到另一头了，而且还加了一个下水。阳台地面本身承重就不好，然后为了埋进管子开槽，进一步损伤阳台的承重。更为可怕的是这么长的下水管没有坡度，直接平铺过去，每一个有接头的地方都是直角，后期一旦堵塞，完全没有任何办法。而且平铺过去，只要下水很快基本都会溢出来，此种办法千万不要做，后期堵了就麻烦了。

厨卫放不成洗衣机，阳台如果再没有下水怎么办。如果阳台有雨水管道能不能用呢？

其实楼体都有雨水管道，有的在楼面外，有的就在阳台。有的业主想把洗衣机放阳台，但是阳台没有下水，跟前有雨水管，这个就得和物业工程部协商，如果是因为设计缺陷没有放洗衣机的地方，一般可以统一在雨水管上做一个洗衣机下水的。严格规定是不允许的，除非迫不得已。业主不能随意加的，必须经过物业工程部的同意，否则隐患很大。业主如果私自让工人直接在雨水管开口，一旦破裂就更麻烦了。
