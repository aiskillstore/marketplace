# 北方封闭阳台，给客厅弄个布帘，显得多此一举了4.1

装修真费钱，这是大部人整天喊出的肺腑之言，但是你装修完后有没有发现，有些东西压根就用不上，你还是过去老旧年代的装修理念，家里完全就是建材的堆积，对于装修机构和建材商的建议豪不怀疑和思考。那装修肯定就贵了，因为你把钱都花到了刀背上而已。如北方封闭阳台，给客厅弄个布帘。
▲横厅布局，好不容易把阳台纳入室内，你给阳台弄个布帘，那不多此一举？所以人家不做，好多人喊着客厅不弄布帘显得不温馨，这个是本末倒置了，钱花到家具和配饰上，怎么都会温馨，而不是客厅弄个布帘，然后客餐厅廉价家具搭配，那永远都不会有温馨感的▲人家利用客厅窗帘盒位置满足了一个投影，电视照有，偶尔看大片娱乐完全够了，而你家却给客厅弄个窗帘盒放一个一年四季不用的布帘▲房子要越装越大，所以人家纱帘直接装阳台，钱少还得有价值▲装修有时候缺的不是钱，否则多花了多少冤枉钱，面子充足，而每一件都是廉价品，那就本末倒置了。需要有专业人的建议和审美。其实缺的就是对美和装修的思考，这个就是找专业和人品俱佳专业人的原因所在。▲人家房子显大是有原因的，当然卖窗帘的会很不高兴了▲为什么人家不要哑口套，不要客厅窗帘，这是有原因的，不仅仅是审美，而是务实▲北方封闭阳台，肯定打通纳入室内，纱帘满足隐私，放大空间才是装修的价值▲让空间变大而且少花冤枉钱，为啥不做，莫名其妙建材堆积，刚好中了装修机构和建材商的圈套了▲放大空间少花钱，成就装修结果的价值▲放大空间，阳台梦幻帘，没有你给客厅弄个布帘缩小空间好看吗？所以，装修一定要找专业人士，而且人品得好，否则你这样做，装修机构和建材商都得少赚钱▲看看家具应该就知道，人家并不是嫌客厅布帘贵，是审美和思考决定的装修价值▲如此有品位的装修，不可能是为了省钱不做客厅布帘吧，所以需要有审美，需要明白装修价值所在▲如图本身刚需户型，绝对不能给客厅做布帘，否则让空间更雪上加霜，等于多花钱不讨好了▲这户型都不敢想业主如果给两个阳台洞都做上布帘，空间会缩小到什么样子▲木纹砖通铺，多看看人家怎么装修的，为什么人家不缺钱而且不给客厅做布帘
