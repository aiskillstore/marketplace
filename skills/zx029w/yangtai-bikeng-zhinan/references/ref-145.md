# 非常小的书房，怎么布局合理？5.21

▲小户型利用新作电视墙分割出来一个开放式书房，刚好借用空间L型定制，书柜和展示柜结合，既满足L型的办公，又能有书籍和手办的展示收藏
▲单独小书房，不能太浪费，一侧通顶衣柜兼顾家里衣帽间功能，借用原有飘窗抽屉抬高，然后隔板延伸的方式，满足一个飘窗书桌的功能，空间更开阔，功能也完美
▲也可以一侧书柜定制，中间镂空满足书桌的垂直摆放，腾出足够的过道空间，原有落地窗直接打造飘窗卡座休闲，连沙发都省掉了。办公和休闲两不误，小空间利用到极致
▲非常窄小的书房，一侧书桌书柜靠墙定制，原有飘窗作为休闲功能，木色与白色整体搭配，小空间清爽舒适
▲细长书房，靠向一侧上方吊柜满足收纳柜和书籍收纳；下方书桌卡座一体定制，同时满足办公和休闲，留出足够大空间让整体开阔
▲细长空间，一侧满足了衣柜的收纳，书桌靠墙放置安全感降低，就可以斜放书桌，视觉空间更灵活，让极小空间更有创意和高级感
▲靠窗定制书桌高柜一体，满足办公和书籍的摆放，上方吊柜，吊柜下方休闲沙发布局，对面满足书柜定制
▲空间稍大一点可以兼顾次卧功能了，窗下一米二的榻榻米，侧墙衣柜书柜兼顾，拉通书桌定制，上方隔板展示置物。功能和视觉都满足了
▲细长空间，一侧衣柜，局部镂空满足书籍收纳；落地窗跟前成品书桌满足办公即可
▲空间小也可以一体定制，L型卡座布局，满足休闲和收纳；书桌与卡座一体连接，上方书架布局。功能合理，格局更简洁舒适
▲非常小的空间，一边定制悬空书桌以及吊柜书架，满足一个单独办公空间的需求
▲细长书房，一边衣柜局部镂空满足少量书籍放置，窗下L型悬空书桌定制。同时兼顾书房和衣帽间两种功能
▲细长空间，一侧衣柜另一侧书柜，利用飘窗抬高的形式满足书桌功能，合理利用每一个地方，让小空间发挥最大功能
▲标准的衣帽间兼顾书房布局，靠窗位置高柜与悬空书桌布局，L型的衣柜满足衣帽间功能；衣柜局部镂空满足少量书籍的放置
▲方形书房，一侧定制书柜，靠窗布局书桌，留出过人通道，这种布局安全感更高
▲细长户型，一侧衣柜收纳，和衣柜方向一致书桌布局，留出衣柜打开通道，既保证了安全感又能实现功能
▲门后高柜收纳，窗下L型书桌定制，借用隔壁空间实现局部书架功能，虽小但是功能足够
▲方形书房，两边定制收纳，虚实结合视觉不压抑，靠窗悬空书桌定制，整体连贯，满足基本功能，小空间完美实现功能
▲极小空间，L型布局，一侧书柜定制，悬空书桌，满足一个袖珍书房功能
▲很小的入户花园改造成书房，L型的书柜定制，成品书桌摆放，一个充满书香之气的书房让进门就惊艳
▲方正书房，L型布局收纳柜以后，斜面布局书桌，空间更加合理，而且腾出更多空间
▲极小书房，一侧成品书柜布局，一侧成品书桌摆放，过道通畅，功能齐全
▲也可以一边定制书柜书桌，一边摆放沙发床必要时可以兼顾次卧功能
