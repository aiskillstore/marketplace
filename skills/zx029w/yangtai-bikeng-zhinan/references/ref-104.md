# 新房入住，你家在哪晾衣服？3.6

装修新房必然要有晾衣服的地方，只是各家各户具体情况不一样，今天列出所有可能晾衣服的场所，给大家做参考。

◆阳台晾衣服，这是最常见的场所，几乎家家户户都有。上图用升降式衣架即可，不同的是分手动和电动的区别，好坏看个人使用情况，没有哪种好和哪种坏。

◆高端电动晾衣杆，功能更多，根据自己喜好选择，没有哪个更好

◆不锈钢晾衣杆也是可以的，不同于升降式，这种不能上下升降，相对成本低

◆当然也可以和上图一样的做法，只腾出一定的空间晾衣服

◆如果阳台过小，也可以按照上面做法，斜拉不锈钢晾衣杆

◆移动式晾衣架，没有任何场所限制，用完可以收拾折叠起来的，适合喜欢整洁的家庭。

◆类似于移动式晾衣杆，还有上图的壁挂式，所不同的是一般壁挂式只能挂向户外，一般高层不太适合

◆如果需要节省空间的，这种单杠旋转式更节省空间

◆如果只有露台空间，这种伸缩式直接可以装到墙壁上

◆当然，如果条件允许完全可以装到户外

◆这是最经济实用的，类似于浴帘杆，不需要打眼，直接伸缩顶住两边墙即可

◆如果没有向阳的阳台，那么飘窗也是可以直接安装晾衣杆的

◆落地窗或者平窗也是可以的，顶天立地伸缩型晾衣杆

◆如果嫌飘窗晾衣杆难看，可以提前做好窗帘盒的样式，做成升降晾衣杆，直接隐藏晾衣杆，也可以隐藏窗帘杆，一举两得

◆如果只有一个阳台，嫌晾衣杆露出来难看，可以提前在阳台做暗槽，升上以后，晾衣杆刚好藏到暗槽中，在其他方向是看不到晾衣杆的
