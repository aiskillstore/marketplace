# 阳台下水管3种处理方式，最后一种大部分人做错了1.6

阳台下水管是个特殊存在，因为不像厨卫用的那么频繁，所以一定要有思考着装修，并不是见着下水管跟着别人屁股做，需要根据自己的家的实际情况，做个性化隐藏处理。
第一、不处理，直接裸露。

▲如图所示，精装修的阳台如果不做微改，也不做收纳柜，此时为了视觉更好看一点，可以网购装饰麻绳回来自己缠绕装饰一番，整体看上去也能协调一点，是最实用的做法

▲如图同样是采用麻绳缠绕装饰一下，搭配合适的饰品，看上去更美观

▲也可以不做装饰，直接采用与阳台同色的乳胶漆涂刷，绿色与白色上下两色更有层次感，下水管也很好的融进了整体空间

▲采用麻绳装饰，直接做成猫爬架也不错，下方刚好放置猫砂盆，成了宠物的天堂
第二、后期定制直接隐藏，更节省空间。

▲如图原始下水管不需要任何处理，后期定制柜子刚好隐藏，而且这样收纳柜内部空间更宽敞▲如图收纳高柜隐藏管道以后，侧面做成壁龛，刚好满足收纳，也能避免视觉上的凌乱▲当然也可以利用对称的造型把管道隐藏起来，上方照样可以吊柜收纳
▲如图右边收纳柜隐藏管道以后，管道前方的空余直接做成开放格，可以随手收纳物品，而且视觉上更有层次▲如图左边同样的做法，直接采用收纳柜隐藏下水管，管道前方空间做了开放格，可以满足随手放置物品▲直接采用收纳柜隐藏管道，中间裸露的部分采用与柜门同材质隐藏，不仅满足了视觉的美观，同时收纳柜内部空间更大▲如图所示，阳台下水管如果做收纳柜，是不需要做任何包裹隐藏，直接收纳柜定制的时候，一并做了隐藏，而且还能扩大柜子内部空间▲如图所示，阳台的管道如果后期做定制，是不需要单独付费用红砖或者其他材料包裹的，直接定制隐藏即可，这样后期收纳的空间会更充足▲如图有定制就不要多掏钱隐藏水管导致不仅费钱而且占用空间，采用定制隐藏一举两得▲好看而且不占地方第三种、包完管道再做定制，完全错误的做法。
▲很大一部分人不仅费钱给阳台贴了瓷砖，而且多此一举用红砖包了管道，这样不仅费钱不说，而且导致收纳柜无形中内部空间更小了▲不仅给很小的阳台铺贴了瓷砖，下水管还多此一举用红砖包裹，导致后期定制更小，下方洗衣机更放不进去▲正确的做法应该是客厅与阳台直接通铺过去，阳台即使生活阳台也不需要贴瓷砖的，同色乳胶漆拉伸视觉，并不影响生活阳台的使用，不仅省钱而且可以放大空间。
