# 阁楼天窗秒变阳台，装修黑科技

一种能够变成阳台的窗，它主要针对阁楼坡屋顶设计。

▲一般的阁楼天窗，只能起到采光或者换气的作用。而这种窗户不仅能打开，而且能变成一个阳台，让你走上去欣赏外面的风景。

▲这种窗户叫做敞篷阳台窗，由丹麦的威卢克斯（Velux）公司研发。

▲操作简单方便，窗的侧面有一个开关，只要轻轻扳动一下就好。

▲窗户分成上下两部分打开，上半部变成顶棚，下半部就变成阳台，让你的阁楼多出至少一平方米的空间。

▲而且，还可以根据你的需要量身定制窗户的尺寸大小和样式。

▲更值得一提的是，它的制造者威卢克斯公司，除了这款窗户之外，还有很多其他的创新发明。

▲比如一款叫做太阳能动力窗的窗户，就可以完全由太阳能供电，不需要布线。而且，可使用无线控制开关，可以说是非常节能环保了。

▲还有最新研发的VELUX ACTIVE with Netatmo系统，通过传感器控制，实现完全自动化控制。根据温度，湿度和空气质量，自动打开或关闭。

总之，都是一些集高颜值和高科技于一身的实用性窗户。

虽然他们公司有那么多款黑科技窗户，小编还是最喜欢他们的敞篷阳台窗，简直是阁楼的绝配，窗户秒变阳台，让家多出一平方。
