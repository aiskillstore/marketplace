# 餐厅带阳台，14家都是怎么装修的4.17

好多户型都有餐厅带阳台或者餐厨一体共用阳台，但是有的空间太小，格局不是很合理，需要改动，改动的方法很多，哪种是最好的？今天看看这些户型都是怎么做的。<点击图片可以放大>

▲1.餐厨共用一个阳台空间，导致餐厨都很小，而且家里还有一个客厅阳台可以使用，所以大胆把厨房改到阳台上，原来的餐厨直接打通作为餐厅空间

▲装修后的实景，厨房挪到阳台作为中厨使用，原来的餐厨打通成就超大一体空间，光线也得到提升，同时侧墙定制高柜收纳冰箱和电器，非常完美

▲2.餐厅阳台做书房使用，餐厅带阳台，更换成通透的玻璃移门，同时把阳台改作单独的书房空间，平时可以兼顾休闲，增加功能空间

▲3.餐厅阳台与餐厅打通做西厨，打通空间不仅成就餐厅光线，同时采用岛台形式分割出一个西厨区域，弥补厨房的收纳不足，多了一个功能区

▲4.餐厅阳台打通成就西厨，餐厅小阳台与餐厅打通，把阳台作为西厨使用，拓展一个功能区，弥补中厨的收纳不足

▲装修后的实景，阳台打通以后，成就一个单独的区域，定制地柜做了西厨布局，与中厨功能分开，也能分担一些中厨的收纳压力，同时还多了一个非常实用的功能区

▲5.餐厅带阳台，打通空间做西厨，打通以后不仅光线好了，空间变大，同时成就一个西厨空间
▲装修后实景，打通空间瓷砖通铺，光线和空间都有了延伸感，同时原来的阳台做了西厨布置

▲6.餐厅与阳台打通拓展功能空间，打通阳台以后，光线和空间得到拓展，刚好满足冰箱的位置，解放厨房空间
▲装修后实景，打通阳台，餐厅卡座布局，同时留出足够的通道空间，把冰箱安排阳台放置，解放厨房空间

▲7.餐厅阳台打通拓展空间，不仅成就了餐厅大空间和光线，同时成就厨房的移门增加采光

▲装修后实景，餐厅定制卡座以及餐边柜，满足收纳同时节省空间，打通的阳台刚好放置冰箱，同时厨房实现了移门布局，光线更加通畅

▲8.餐厅阳台作为生活阳台，客厅阳台做了书房，把餐厅阳台保留做了生活阳台使用，把客厅阳台扩大，分割出一个单独书房兼次卧空间

▲装修后实景，餐厅阳台作为生活阳台使用，把客厅阳台扩大，分割出一个书房兼次卧功能

▲9.牺牲餐厅一部分，扩大餐厅阳台改作了书房，把餐厅牺牲一部分和阳台打通，分割了一个单独的书房空间

▲10.餐厅带一个小阳台，改变格局变成书房，阳台打通，餐厅这边新砌墙成就收纳壁龛，同时拓展餐厅空间，阳台朝向客厅作为很小的书房

▲装修后实景，改变阳台格局，成就餐厅大空间，同时成就客厅小书房空间

▲11.餐厅阳台作为餐厅的拓展空间，左侧放置冰箱，右侧斗柜收纳兼顾餐厅柜，拓展了餐厅的空间

▲12.餐厅阳台改作厨房，移动厨房空间到餐厅阳台，餐厅与原来的厨房打通变大空间

▲装修后实景，厨房砸掉融进餐厅，拓展餐厅空间，把中厨移到餐厅阳台，实现空间和光线的双提升

▲13.餐厅阳台与餐厅打通，满足一部分收纳，同时拓展餐厅空间和光线

▲装修后实景，打通的餐厅阳台，一边做了收纳柜满足储物，另一边刚好放置冰箱，解放厨房空间

▲14.打掉餐厅阳台拓展餐厅成就吧台，不仅让光线和空间都得到拓展，同时还实现了吧台功能

▲装修后实景，不仅实现了餐厅的光线，同时餐客厅之间还多了吧台功能
