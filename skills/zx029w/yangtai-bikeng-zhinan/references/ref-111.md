# 这么窄的阳台照样实现洗衣池，太牛了！10.17

一般阳台除过洗衣机或者洗烘机位置以外，都可以满足一个小的洗衣池的功能，这个当然是最好的做法。

如图这是常规阳台，因为有空间，不论是做洗烘机的或者洗衣机，最起码满足一个小的洗衣池的功能

但实际上如上图的阳台，只有非常窄的空间，怎么去实现洗烘机，还要实现洗衣池呢？这个就今天要探讨的细节问题。

如图除过洗衣机以外，刚好剩余10公分左右的空隙，此时可以把竖管下水以及上水电源都放在窄柜子里头，采用台上盆右侧排水的方式，就可以同时实现洗衣机和洗衣池的功能，虽然高度略高，但略胜于无，功能实现了

类似的空间不想要台上盆，也可以定制一体盆满足共存的功能

如图所示，利用下水管的前方空间实现上下水以及电源的布局，直接定制一体盆满足洗衣机上方的洗衣池功能，同样是高度比较高，但是起码实现了功能如图阳台满足洗烘机以后，剩余空间无法满足洗衣池的功能，采用转角定制，另一个方向采用半嵌陶瓷盆的形式，完全延伸了收纳，同时满足了功能《半嵌陶瓷盆，不止颜值，重点是解决空间小的问题》换个思路，转角其实功能更强大，而且满足了更多的收纳储物即使异形很小的阳台，也可以利用转角实现一个洗衣池的功能，而且也能颜值在线如图并排抬高洗烘机更利于后期使用方便，利用转角一体盆也可以实现一个洗衣池的功能如图除过放洗衣机以外，左右都没有任何空间的时候，可以采用加深尺寸，上下水电源都放到后面，此时洗衣机就得朝前放置，采用定制悬空陶瓷盆与洗衣间外沿平齐的做法，也可以满足功能，同时照顾一下颜值，只不过进深比一般洗衣机的60公分进深稍大当然如果阳台一边太窄只能满足洗衣机放置，但是又想实现洗衣池，此时有人如图的做法，直接把洗衣机下水引到阳台另一边，用来满足一个独立的洗衣池的功能。真心不建议这种做法，距离太远容易堵，而且压根不可能留太高的坡度，这样会导致地面整体抬高，而且因为洗衣池后期有太多污渍，更容易堵塞，一旦堵塞无法疏通，下水管基本报废，所以这种做法不推荐。空间小不怕，利用转角位置，采用圆柱陶瓷盆满足一个洗衣池功能，暗装龙头满足功能，不仅仅满足了功能，同时颜值也变得更高级如图利用阳台的转角位置，独立实现一个小的洗衣池，同时并不占用原有洗烘机的位置
