# 厨卫吊顶，没有存在感就是最好的搭配6.7

厨卫吊顶大家都非常熟悉了，一般刚需都是集成吊顶，也好维修；还有的是石膏板吊顶，这里一定注意，你家如果是顶楼随意；如果不是，厨房可以石膏板，卫生间还是谨慎。当然还有木质的吊顶，很少用，第一颜色太厚重，第二防火防水性能较差。

▲左图为石膏板吊顶，整体统一白色，后期可以暗装筒灯，看上去简洁清爽；右图为铝扣板吊顶，同样白色布局，但是带一点小造型，整体还是清爽的；
论造价石膏板要高，因为需要防水而且施工工序多；后期维修比较困难，维修成本也高；铝扣板施工简单，后期维修拆卸非常简单方便
▲左图为石膏板，右图为铝扣板，其实单从大的视觉看，分不出优越，只要搭配正确，都是没有问题的；唯一就是维修成本以及打理的难易程度；
比起厨房，卫生间的隐患更大，楼上漏水或者楼上闭水试验，都会影响楼下的施工，而且成本远远大于铝扣板
不论是石膏板还是铝扣板吊顶，从上面都可以看出来规律：颜色搭配一定要浅色为主，没有存在感最好！
▲以上两图可以看出，颜色过重，最重要的是人为的把吊顶颜色突出来，也就是人为的让吊顶突出存在感，整体空间就显得非常凌乱；
▲再看看上图，就会发现，吊顶统一采用纯色布局，接近白色的配色，也就是最大程度减弱吊顶的存在感，这样空间才能更清爽，配上功能配置以后，才会有清爽的层次感
▲厨房也是一个道理，只要用铝扣板吊顶，一定用浅色，弱化吊顶颜色的存在感，只有这样才能让空间更有层次，而且小空间不会凌乱拥挤。
▲阳台也是一个道理，能用浅色吊顶尽量用浅色，例如石膏板吊顶，这种木色的吊顶或者绿可木视觉太厚重，而且阳台都相对很小，导致空间压抑，后期加上各种定制和晾衣服的话，就更显凌乱了
