# 阳台是否用墙砖，功能决定9.6

家里装修，每一个地方都有每一个地方的特点，像厨房空间，平时油烟最多，我们选购瓷砖和定制橱柜就得朝好打理方面考虑。然后才是兼顾美观和收纳。

卫生间因为长期有潮气，长时间和水打交道，所以卫生间最适合吸水率很低的全瓷砖，而且美缝是必不可少的。瓷砖的搭配和光线基本关系不是很大，看自己喜好，如果你家是暗卫，如论如何都得开灯，用深色瓷砖和浅色瓷砖改变不了什么，可以根据喜好去选择。

阳台作为生活阳台和休闲空间，往往被大家忽略。这里几乎是家里光线最好的，开发商大部分会在朝南的最好地方设计阳台，以北方为例，大多是封闭阳台，即使没有封闭，后期装修都会让封闭使用，一是和气候灰尘大有关，二是北方生活晾衣服有关，也算是合理利用空间了。

阳台的瓷砖就比较麻烦一点，和光线和朝向和用途都有很大关系。

01
客厅与阳台打通

▲刚需房为了拓展空间，往往选择客厅阳台打通的做法，同时把中间的门去掉，一是光线好，二是视觉上拓展空间；北方地区虽然阳台没有地暖，因为大部分都是朝南向，基本冬天无需担心温度因素，因为客厅是活动空间，并不是像卧室一样睡眠空间。
一般做法是客厅大地砖直接通铺阳台，视觉有延伸感，可以放大空间。此时如果阳台不是晾衣服，也不放洗衣机，完全可以不用墙砖，直接和客厅乳胶漆统一涂刷即可。作为单独活动休闲空间，也可以局部做收纳处理。
▲如果阳台作为休闲兼顾生活晾衣服使用，此时除过大地砖通铺，还得考虑墙面瓷砖的铺贴，防止长期晾衣服和洗衣服潮气太大，乳胶漆不耐水汽腐蚀的弊端。所以墙砖是必不可少。
如上图北欧风，阳台选择经典的小白砖铺贴，这里注意一定是哑光或者柔光的小白砖，绝对不能用亮光瓷砖。朝南方向，本身光线过于充足，亮光瓷砖更加刺眼
▲如果客厅阳台是生活阳台，兼顾洗衣和晾衣服的功能，也最好把空间打通设计，除非你是豪宅客厅非常大，否则人为移门分割，不仅浪费钱，而且让空间显得更小
02
卧室阳台

▲北方地区所有阳台都没有地暖，所以如果卧室带阳台，老年人居住，最好安装移门分割，里头厚重窗帘配置，这样冬天的时候不至于卧室太冷。平时可以利用纱帘进行遮挡，也不是很影响光线。如果此阳台是生活阳台同样需要铺贴墙地砖，作为父母房，使用也是比较方便的。
▲如果是年轻人居住的卧室，尽量把卧室与阳台打通设计，阳台有无地暖都不会影响睡眠，这样空间敞亮多了。当然具体还得根据自己的喜好。如果拿不定注意，可以先打通做好哑口套，入住以后可以后做移门分割也是可以的。此时如果阳台是休闲空间就可以不贴瓷砖，如果是生活阳台和客厅做法一样，大瓷砖通铺，墙面单独墙砖铺贴
阳台瓷砖除过不能用亮光以外，其余都可以使用，花色和规格根据风格决定，当然如果阳台是单独分割区域，瓷砖可以根据你的喜好使用，也是没有问题的。阳台不装门，获得更多功能
