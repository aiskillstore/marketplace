# 卧室衣柜是做吊顶压低，还是直接通顶？7.6

这个问题没有什么标准答案，因为和家里装修情况有很大关系。

▲如图有中央空调以及新风的家庭，吊顶必然是和衣柜结合才好看，空间才整洁。此时衣柜只能压低空间定制，节省了好多费用不说，视觉上其实是更美观好看的，只要收纳够用，不在乎多吊顶那点空间。

▲对于追求简单，如图所示的无主灯设计的业主来说，吊顶是少不了的，衣柜也可以同时镶嵌，起到弱化柜体的要求，空间高级感油然而生

▲还有一部分纯粹追求美观的业主，不做中央空调和新风，也给衣柜上头做了假吊顶，同时做了镶嵌隔墙，要的就是弱化衣柜的存在感，压低衣柜高度，让整体更和谐，收纳相对就少这是必须付出的代价，但是定制费用相对也会变低

▲还有一种是房子结构本身就是一个凹陷区，如果没有石膏线和中央空调，直接可以通顶定制，同样柜体存在感降低

▲没有吊顶限制的卧室，当然也可以一柜到顶，上下分开普通板材即可满足定制，费用也低，而且上头专门放置各种被褥不常用的物品，下方压低高度，专门用来悬挂衣物，也非常方便；收纳要比有中央空调的家庭多很多了。

▲还有一种虽然没有中央空调，但是做了喜欢的宽边，这种做法必须在衣柜上方吊顶，让宽边形成完整造型，衣柜也无法通顶定制。

▲这个最常见做法，通顶定制，后期补上石膏线就行；衣柜的收纳空间更大，定制费用也相对高一点。

总结：你家如果没有中央空调和新风，衣柜到底是通顶还是做吊顶压低，完全取决于你的收纳和审美要求，但是各种做法你在装修之前需要知道，否则装修完了发现别人家做法更好，就迟了。

至于哪种更好看，见仁见智；吊顶下压，定制省钱，收纳变少；通顶定制收纳变多，定制费用多；

以上是针对卧室空间而言，如果是公共区域，定制通顶柜强烈建议吊顶压低，一是公共空间大，视觉上会造成非常难看的突兀压抑感；第二会客区域，来个朋友也是自己的审美暴露点。
