# 卧室与客厅共用阳台，别人都是这么做的2.18

通阳台非常常见，例如常见的卧室和客厅共用一个大阳台，因为每家每户的情况不一样，需求也不一样，今天列举大家可以参考，如果有相同需求的可以用到自己家里。
客厅开间比较小，还想要个书房，偶尔家里老人过来住几天。装修时就把客厅次卧打通，做成多功能房，这样老人来了也有地方住，不来时我客厅空间也显得宽敞；通阳台打通作为休闲功能，书房与阳台采用推拉门分割，平时作为次卧使用拉上帘子即可装修前没想过这个6平小阳台，会是家里越住越爱的存在。尺寸虽然只有6米×1.35米，但改造成了三连通的设计，连通次卧和客厅，空间直接翻倍！极简子母门还可以起到临时隔断的作用卧室连通客厅阳台，做了玻璃联动门，在视觉上更加通透显；大阳台处放个衣帽架，挂一些隔夜衣服很方便，还有两个大抽屉可以收纳袜子和贴身衣物等，卧室虽小也不会杂乱。另一边洗烘机布局，平时也很少晾衣服，这样阳台同时满足超大空间，休闲和生活兼顾常见做法，因为卧室外面就是阳台的生活区，所以必须采用推拉门分割，让卧室更有安全感，同时可以保证阳台空间的最大化客厅大阳台连着卧室，中间采用折叠门的方式可以白天共享阳台，晚上关闭后则成为独立空间，比玻璃门分割来说隐私各方面都更好。与客厅共用阳台的卧室空间，为了隐私需求，采用玻璃对开门分割，晚上保证隐私和安全感，白天的时候空间更开阔，同时光线也更好。打通了阳台侧卧这半面墙装了这扇极简子母门，人站在房间内时，母门可以向左平开180度，子门可以用门闩固定在地上，也可以向右平开。由于右边有墙，所以只能开到90度。这个设计给这个房间的空间带来了更多可能性一开始就是冲着双阳台的户型去的，双阳台打通，真的巨显大！书房与生活阳台玻璃推拉门，保证采光，同时还能满足书房的隐私需求阳台做了通铺，客厅与生活阳台推拉门做了隔断，分割单独的洗衣间；同时次卧原有推拉门做了窗户，满足隐私和安全需求《双阳台，怎么分割独立洗衣间？》次卧室外面作为独立生活阳台，采用推拉门分割，平时拉上帘子可以保证隐私；通阳台生活阳台独立开门，也可以独立实用生活阳台，而不影响次卧人的休息双阳台，阳台大概7米多，这个卧室和阳台打通了，虽然打通了，还是用黑色玻璃移门隔断的，既遮挡隐私又可以看风景；平时使用生活阳台也不至于影响到卧室人休息儿童房和客厅共用阳台，但是儿童房实在太小，把一半阳台给了儿童房，不用考虑隔音，为了保证空间的通畅，采用隔断门分割，既保证了儿童房的面积拓展，同时也不至于缩小视觉空间和敞亮客厅与次卧室卧室共用一个双阳台，
父母住在次卧，希望有自己独立的私密空间和阳台，所以做了隔断处理；玻璃砖光影效果很好，照顾私密性的同时，不影响采光，隔断后的两个阳台，依旧可以有很充足的采光条件。把大阳台分成了两块儿，其中一块儿主要是晾衣洗衣为主比较杂乱，另外一个区域只做休闲空间干净整洁。为防止生活阳台不好进入，在柜体中预留了隐藏门，加上层板可当作柜体使用，如果次卧住人不方便进入，可当成通道使用。通阳台空间，但是卧室门刚好在电视墙非常难看，干脆封闭原有电视墙的卧室门，把阳台一半给了卧室，阳台独立开卧室门，解决了电视墙有门的问题，同时卧室空间也得到拓展为了扩大次卧空间，把阳台一半给了次卧，但是又不想牺牲空间的视觉感受，采用对门玻璃门分割，这样晚上可以保证隐私，白天的时候打开门，光线和通风不受影响，也可以满足双阳台的通透8平米小卧室，还连接着客厅的长阳台！把阳台利用起来，1平米都不放过。改成了集睡觉，学习，收纳功能都有的儿童房这样的布局，充分利用了空间，而且整个卧室温馨又活泼。同时儿童房玻璃门分割，随时可以保证独立空间的隐私需求，也不影响光线通透客厅和次卧共长阳台，不想死气沉沉的“硬”隔断，选择在阳台中间做了一扇门，视野更自在，房间更通透卧室宽3.03米，长3.86米，和阳台连通处做了一个折叠门窗，上面贴了整块红橡木当桌板，孩子能在这里写作业，看书，累了抬头也能通过阳台眺望前方。阳台侧面有一整面黑板墙，作为孩子们的休闲区，和客厅联通，也让孩子们的玩乐区更开阔。折叠门窗晚上也能关上锁住，私密性也是OK的。儿童房连接阳台，保留了推拉门，保证采光，做了一组衣柜，一张1.2m小床，活动空间绰绰有余连接客厅的那个房间很小，觉得留那么多房间没啥用，果断砸掉次卧，打通阳台和客厅，得到了一个6米横厅，实际落地效果比想象中还好。《舍弃一间房，实现横厅的空间和通透》作为婚房，不需要保留所有卧室做休息功能，取消一个次卧室做了横厅设计，原有通阳台整体纳入客厅空间，光线和空间的价值发挥到极致首先拆除阳台门，让空间的视线开阔；其次，用抬高地面的做法，区分了游乐区和大人们的世界。阳台和主卧室连接，百叶帘窗户是通道，大人在休息的时候也能守护孩子们的乐园。把主卧门改到了阳台，不仅让主卧室有了更强的隐私性，同时加一组百叶装饰让进门的时候更有了仪式感；原有主卧门移动位置，让格局更加完整统一仪式感；原有主卧门阳台可一分为二，猫咪阳光房放在阳台一角，生活便利也能同时满足。客厅与卧室阳台相通，卧室一侧阳台做阳台的清洁设备功能区，客厅一侧与阳台打通，增加客厅延伸感，空间显通透
