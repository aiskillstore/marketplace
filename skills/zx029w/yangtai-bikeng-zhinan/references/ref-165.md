# 客厅带阳台，肯定通铺不分割3.5

大部分人家都有客厅带阳台，一般除过有的人需要装门分割以外，大部分人通铺瓷砖，但是分开铺贴，导致视觉上分割空间，让空间变得更小

▲阳台与客厅分开地面材料如图，一边是木地板，阳台是瓷砖，这样是可以分开的，阳台不能用木地板，但是也不需要过门石分割，太难看了，直接采用结实的收口条，美观而且结实。如果需要装门也是不需要过门石，甚至不需要收口条，下方地轨刚好压住缝隙即可。
▲如图的收口条非常美观而且结实，过门石就该淘汰了，要不本身两部分颜色材质不一样，中间再加一个难看的过门石，分块操作更难看了。当然有的人想要木地板通铺阳台，也是可以的《阳台能不能用木地板？有什么条件？》
▲阳台无法直接用木地板的可以采用同色或者相近的木纹砖铺，收口条安装，视觉上还能统一开阔，也不会有分块的感觉
▲像这种客厅是瓷砖直接通铺阳台就行，为什么要加个难看的过门石？而且不一样的瓷砖视觉上本身就分块了，缩小了视觉空间，出力不讨好而已
▲像这种休闲阳台，又不大面积养花，客厅木地板都可以通铺，视觉更开阔，空间更显大
▲即使你阳台放置滚筒洗衣机，也可以木地板通铺的，洗衣机只要接好，竖管下水，压根没有一点水，视觉上更好看开阔
▲如果客厅是瓷砖，与阳台打通布局，直接通铺大砖就行，看起来更大更宽敞，千万不要多此一举加个过门石，然后阳台铺其他瓷砖，分块铺贴，房间更小，更难看；客厅能不做窗帘最好，直接做到阳台也能放大空间《放大客厅三大关键，通铺不要门、窗帘装阳台、空调用挂机》
▲即使生活阳台放置洗衣机，洗衣池，瓷砖也是可以通铺的，压根无需担心任何问题，下水竖管三通，可以不要地漏，也可以备用一个地漏以后打扫卫生方便，但是这里的过门石和防水都是多此一举。
