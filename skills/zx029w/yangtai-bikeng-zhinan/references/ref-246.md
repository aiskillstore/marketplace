# 装修新房，不要小看那些格子吊顶3.8

同样是吊顶，你家平淡无奇，别人稍微拼个格子就能与众不同。

◆同样普通顶面用石膏线或者PU线拼成菱形格子档次提高很多

◆简欧风，中间拼大格子，但是中间用了铝扣板，一般人可能接受不了

◆这种也只有别墅空间敢这么做，一般层高的房子做不了这么深的格子造型，不过确实很大气

◆木制假梁格子，一般中式居多，乡村风也有

◆不规则菱形拼格，这个施工比较复杂，前卫时尚的可以尝试一下

◆这个相对简单的多，用石膏线做个大框，中间在原来石膏板基础上刻槽即可

◆卧室同样也适用刻槽的办法，所不同的是原顶一定要有一层石膏板

◆没有超大户型和一定的层高，这种拼格子是做不了

◆中式木格吊顶，根据整体看密集程度

◆镂空花格吊顶，新中式用的较多，简约风也可以

◆用简欧集成镜面吊顶拼格子

◆这个就属于工装常用的铝格栅或者铁格栅吊顶，家装很少用到

◆很典型的做假梁拼格子

◆拼菱形大格子，适合大空间，高层高的居室

◆整个更加复杂，用专用镂空吊顶，一般用于大户型简欧空间或者中式空间

◆中式镂空吊顶
