# 手把手教你布置阳台，努力幸福下去2.11

1.盆栽:盆栽如同一个阳台的灵魂，高颜值的盆栽不仅让阳台充满生气，而且可以净化空气。悬挂式的盆栽既节省空间，又让你家阳台带有不经意的设计感。

动手能力强的话，也可以自己做一个。当然，还可以让家里的男主人来做。一定比送一束快速凋零的玫瑰花要有新意。

只要用装修时留下的油漆桶，就可以实现了。

把螺母拧紧。

串上铁链。

放入泥土与想要种植的植物。然后高高挂起吧。

没有旧油漆桶的话，亦可以买这种现成的。

除了用链子，用绳子缠绕后悬挂起来也有同样的效果。

把废旧灯泡改装一下，插上鲜花，这样挂在阳台，温馨又浪漫。

还可以安装上这样的单杠，不仅可以晾衣服，还可以悬挂盆栽。

对于空间大的阳台，可以把盆栽用架子装起来，视觉效果也很不错。

还可以买这样的木箱装上泥土种菜，自己家种的菜，绝对天然无公害。

2.桌子:给阳台安装上贴壁式的桌子，既可种花，又可以放物品。

翻翻杂志，呼吸一下新鲜空气，面朝大海，春暖花开。

安装一张折叠桌，周末和家人在阳光下享用一顿丰盛的早餐。

放张方便移动的小桌子在阳台。邀上朋友在家中喝下午茶，话家常，或是一个人安静地看书写字，生活恬淡而美好。

在特殊的日子里，与其去高档餐厅，不如与爱人在自家阳台享受浪漫的烛光晚餐来得惬意、有情调。

3.椅子:购置漂亮又舒适的椅子，决定了你会以慵懒的姿势与舒畅的心情享受午后暖阳。这款适合喜欢躺着抱着宠物玩耍的你。

这款适合小时候爱荡秋千，现在放松时喜欢光着脚丫摇晃的你。

当然，只要给椅子装个坐垫，舒适感便会直线上升。

4.床垫:如果你嫌自家房间不够多，完全可以给阳台添置一张床垫，再放几个抱枕，马上就多了一间飘着花香的房间。

当然，如果阳台不是封闭式的，下雨天别忘了要把床垫收进来。

嫌床垫太麻烦的话，索性就铺厚点的床单，照样可以舒舒服服地睡个午觉。

5.书房:如果阳台是封闭式的，无畏日晒雨淋，那你完全可以把它改造成书房。

6.餐吧:装上贴壁式的烧烤炉，阳台就有了餐吧的功能，随时可以在自家阳台开派对。

放置一个架子，饮料和餐具就可以放在上面。
