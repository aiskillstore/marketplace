# 两层石膏板，就成了网红双眼皮吊顶了7.25

以前谈过一篇宽边的文章，大家可以参考一下《宽边石膏线好看，怎么施工？》宽边就分双层单层，双层就是现在所谓的网红双眼皮吊顶。有的人感觉好看，有的人感觉不好看，

但是你家要做宽边双眼皮并不是随心所欲的，条件满足不了是无法实现的，不提前考虑，后期往往会出现遗憾。

▲如图卧室不论做宽边还是双眼皮，你家用挂机吗？如果用，空调挂哪里？尴尬不？挂宽边空调不平，难看；挂到宽边下方空调太低更难看。也就是说你家如果用挂机的话，宽边双眼皮还是谨慎，不要盲目跟风。

▲再看看挂机挂到宽边下方的样子，如果你能接受也是可行的。装修完毕层高如果是2.6米，宽边下放20公分，也就是空调的低端高度在2.1左右，这个高度一定在装修前考虑好，否则空调线路插座位置以及空调孔位会更低，需要有排水需求。

▲当卧室没有挂机的时候，四周双眼皮吊顶，层次感更强，更美观，窗帘盒一体设计布局，衣柜与吊顶配合弱化存在感，减少空间的压抑

▲当空间很小的时候，一定是做贴墙宽边，而不是吊顶，否则空间就会显得更小了

▲所有空间做双眼皮吊顶好看的前提，一定是中央空调吊顶；因为中央空调吊顶下来的深度更能与宽边双眼皮或者单眼皮完美配合

▲当然有单眼皮，就有双眼皮，也有三层的做法，这个看风格以及空间是否适合

▲什么时候做贴墙宽边，什么时候做吊顶宽边双眼皮，这个根据风格以及空间大小，空间大的话，可以吊顶与双眼皮结合，空间小的完全可以宽边贴墙双眼皮就可以搞定

▲如果只是贴墙宽边双眼皮的话，现场做造价高的话，可以选择这种宽边石膏线，宽窄都有，这种成品石膏线造价更低，可以直接刷漆，完全也能满足层次感。
