# 为什么防水怎么做，才是正确的？

防水的核心是防潮。 卫生间防水最核心的是防潮，湿区防水一定是做到吊顶位置，防潮气才是重点。那些为了低价切入连工艺都做不到位的防水，多半是侥幸而已，因为防水做不好后期只能砸掉重做。

防水高度必须做到吊顶。 卫生间一定是四面墙都做到吊顶位置，而非糊弄人只做三十公分或者淋浴只做一米八。红砖墙防水要做到吊顶高度以防潮气蔓延。老房卫生间四面墙都是红砖墙，经过拆除以后受损严重，一旦防水做不对红砖墙最容易透水发霉。

防水材料用彩色。 防水材料最好用彩色比如蓝色，这样工人做完可以看到是否刷到位一目了然。防水与铺砖须由同一工人负责以防责任难辨，一定是谁铺砖谁刷防水，责任明确嫁接责任。

闭水试验别偷懒。 防水做两遍干透以后，在厨卫门口用水泥砂浆围挡5cm左右的挡水，放水至地面2cm左右。放水之前堵塞各个地漏，放水时在龙头水流击打位置铺上塑料纸防止破坏防水层。24或48小时后去楼下确认是否有漏水，一旦有湿气潮气哪怕一丁点水渍就说明防水失败，修补后重做直到完全没有漏水迹象。业主一定要亲自和装修机构人员同时去楼下看。闭水试验不是泡水越长越好，长期泡水可能把防水泡至发软反而起反作用。

防水面积一次算足。 防水单价标高面积少算，卫生间故意少算三分之二面积，等开工刷防水的时候业主要求刷高然后心安理得的加钱。防水按实际面积一次性算足，四面墙直接算到瓷砖铺贴高度。稍微有点思考就可以制约后期加价，而不是前期自欺欺人的低价。

防水是里子工程。 防水涂料是三大里子工程之一，必须优先选用当地经过长期实践验证的靠谱产品。长期广泛使用的本地成熟材料如东方雨虹西卡防水更具可靠性与性价比。不要盲目追求进口品牌，容易被营销利用且缺乏本地实践验证。

防水不能自己刷。 自己刷防水是最冒险的事情，后果严重：一是后期瓷砖脱落成了别人甩锅的借口，二是瓷砖铺完漏水承担责任的只有你自己，这是自己给自己装了一颗定时炸弹。一定是谁铺砖谁刷防水，责任明确。

卫生间防水做对五件事。 防水必须刷到顶，闭水试验至少48小时，美缝必须做瓷砖缝隙是潮气最易渗透的通道，墙排马桶悬空地面减少潮气接触面，浴柜要么彻底落地要么彻底悬空半落地半悬空最藏潮气。

记住。 防水做法一项可以淘汰N家装修公司。样子货防水总价低利于签合同，出问题住几年只能砸了重做。防水做到吊顶位置，彩色材料看得见，闭水试验亲自到场，面积一次算足，里子工程别省钱。
