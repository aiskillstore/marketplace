# 防水闭水试验越久越好，肯定不对6.19

闭水试验大家都知道，装修必须做的。

一般闭水试验时间24小时到48小时之间都是可以的，建议最好48小时，因为时间短了可能无法判断是否合格。但是也不能时间过久，比如有的业主认为既然做闭水试验，那肯定是时间越久越能说明防水没有问题。表面看是这个道理，但是得结合实际需求。

我们实际入住以后，洗澡水再多也只是在地面稍作停留，就顺着下水道流走了，没有人会在洗澡的时候把地漏堵住，然后洗完澡再把水放干？所以实际生活中压根不会存在卫生间直接泡水24或者48小时的现象，所以48小时闭水试验足够了，放再久没有任何意义。

还有如果防水超过48小时，甚至有的业主泡水一个礼拜，这个做法的后果会让防水泡软，失去伸缩性，后期可能任何细小的磕碰会破坏掉原有的防水层，得不偿失。

闭水试验在防水干了之后进行，放水的时候提前确认楼下是否有人。这里有个经验，如果你不确认楼下是否有人，直接放水，万一楼下入住业主出差一时半会回不来，这个水肯定就超过48小时了，长时间浸泡肯定放水会破坏的。所以提前看楼下，确定有人，再做闭水试验。
