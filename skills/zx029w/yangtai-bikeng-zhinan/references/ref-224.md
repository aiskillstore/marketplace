# 年轻人这7个“柜子设计”太惊艳了！一点空间不浪费，房子还越装越大！

定制收纳空间是每家必备的做法，但是缺乏生活经验，没有一定的收纳技巧，虽然做了好多收纳，依然乱，而且还牺牲空间。今天看看年轻人7个收纳柜的做法，简直太惊艳，立马抄作业！01.柜体侧面的利用过去做墙体遮挡柜体侧面的做法，虽然很美观，但是浪费了空间，现今观念改变以后，发现不用遮挡，做成侧面柜更惊艳，而且实用。⑴鞋柜侧面柜。侧面外露不做隔墙，会导致侧面柜板颜色与墙体不一样，反而不好看。此时可以做成镂空，安装玻璃门，可以作为家里的手办展示，实现功能，也满足了装饰。
借用鞋柜侧面实现清洁用具的收纳。家里没有独立家政间，一些清洁用品需要统一收纳存放，此时可以借用鞋柜侧面实现，同时柜门内部满足全身镜功能，拓展功能空间。「侧面柜才是隐藏王者！7个零存在感位置，能收纳杂物还显大」
⑵餐边柜侧面实现鞋柜功能。常见的进门没有门厅的户型，最普遍的做法，利用餐边柜侧面满足鞋柜功能，解决了鞋柜与餐边柜混搭的局面。
餐边柜侧面实现盲盒展示。与鞋柜侧面做法类似，也可以局部开放，实现盲盒的展示，弱化侧面的呆板，也满足功能和颜值的兼顾。
餐边柜侧面实现隐藏化妆台。刚好在门口，可以用来出门化妆的功能，柜门内部贴上小镜子，关闭门以后岁月静好。「把化妆台隐藏起来，不乱！」
⑶满墙柜侧面利用。没有墙体遮挡显得呆板和拥堵，采用镂空开放实现手办展示，加上灯光也能营造氛围。
侧面实现开放书柜。侧面开放满足少量书籍收纳，同时弱化了呆板。
⑷阳台柜侧面利用。客厅与阳台为了利用空间砸掉了墙体，洗衣柜侧面就会外露，客厅视觉不美观，采用拱形镂空开放形式，可以实现展示和书架功能，改善客厅视觉的难看。
侧面满足杂志架功能。跳色隐藏了墙垛，同时多余空间双面利用，一面作为杂志架功能，朝向客厅满足展示和书架功能，视觉上空间更有高级感。

侧面开放书柜。朝向客厅沙发，刚好满足平时沙发上的随手阅读。
隔板展示兼顾书架，刚好利用柜体与墙垛转角，实现展示和书籍收纳。
⑸衣柜侧面利用。不仅满足门口开关布局，同时实现次净衣的收纳。
开放手办展示。进门直对衣柜侧面，开放弱化呆板，同时满足手办的展示。
放书包挂次净衣。儿童房衣柜侧面镂空，实现开关布局，满足书包的进门收纳。
衣柜靠床侧面壁龛代替床头柜。衣柜侧面靠向床，可以舍弃床头柜，衣柜壁龛兼顾，实现收纳的最大化。
衣柜侧面实现书柜功能。可以满足少量书籍的收纳，让衣柜的收纳更多分类。
衣柜侧面隐藏化妆台。实现隐藏化妆台，拓展收纳功能。
02.收纳柜的抽拉利用抽拉隐藏的利用不仅可以解决实际问题，同时可以增加收纳量。⑴鞋柜深柜抽拉。比较深的鞋柜，可以采用抽拉板形式，实现收纳翻倍，而且更好拿取。「鞋柜太深或者太浅，原来这样做就可以解决问题」
下方踢脚抽解决深柜问题，利用踢脚抽解决太深鞋子不好拿取的问题，还能增加收纳量。
利用鞋柜背后的抽拉增加收纳量，进门无厅户型非常适合，让鞋柜收纳翻倍。「为何聪明人都爱抽拉鞋柜？最大化收纳空间」
鞋柜抽拉隐藏换鞋凳，对于换鞋凳不是刚需，但是需要备用的家庭可以采用隐藏做法。「进门空间太小，教你一招把换鞋凳藏起来，实用还好看」
⑵餐边柜低抽屉抽拉满足零食柜。需要零食柜的可以采用这种方式，好挑选，也好拿取。「打造个性化零食收纳区，年轻人的最爱」
利用抽拉功能，实现隐藏餐桌，对于小空间非常实用。
⑶厨房抽拉的利用。常见的电器柜收纳，抽拉板设计满足电器收纳，同时不影响使用功能。「厨房小家电收纳，99%的人看完想学」
厨房冰箱窄柜抽拉，实现调料收纳或者零食收纳，合理利用空间。「冰箱定制镶嵌后，窄缝这样利用，颜值和实用性直接拉满」
橱柜地柜深度抽拉收纳锅具，较深地柜抽拉可以满足更多锅具的分类存放，更好拿取「太厉害了，不花啥钱，家里“锅具”还能收纳整整齐齐！」
抽拉满足随手调料收纳，靠近灶具附近，采用抽拉形式满足随手调料放置，同时避免油烟问题。
厨房抽拉餐桌，可以满足人少的时候就餐，同时可以隐藏不占用厨房空间
厨房抽拉板拓展台面，小户型厨房台面不足，没有切菜位置，可以利用抽拉板延伸切菜功能。
⑷阳台抽拉利用。常见的洗烘机上方的抽拉晾衣架，可以满足小件衣物的晾晒。中间的抽拉板可以方便放置衣服。
阳台窄柜抽拉，也可以兼顾收纳和晾衣服需求。
⑸卧室抽拉利用。小卧室利用抽拉板代替传统床头柜，节省地方，更能放大空间。

榻榻米衣柜重叠下方抽拉设计，可以合理利用死角空间。

床与衣柜冲突，侧面抽拉设计，小空间非常实用，不浪费空间同时满足功能

抬高床铺，下方抽拉利用，小空间抬高床铺，采用抽拉设计，下方满足了收纳功能
榻榻米万向轮大抽屉，解决了榻榻米取物麻烦的痛点「榻榻米取物难？不透气？那是你做错了而已」
03.定制柜无底板设计不做底板可以更好延伸功能，让定制更具价值感
家政柜无底板，没有高度差，透气性好，好清洁，安装洞洞板，收纳工具，运动器材。
橱柜无底板，移动收纳超灵活，哪里需要推哪里，吃火锅必备，增加台面空间，随手放刚买的菜超方便
浴柜无底板，无底板设计可以让机器人自由进出，关上门又很隐形
餐边柜无底板，两侧底部设计为无底柜，一方面收纳凳子方便，另一方面比较重的酒类可以直接推进去，省去了“搬”这个动作。
电视柜无底板，底部并不是适合拿取物品的高度，加了滑轮之后可随意抽拉，一眼看清物品，拿取东西更方便。
镜柜无底板，方便藏匿吹风机/牙刷 保持整体美观。「整理专家推荐：吹风机收纳法，轻松应对家中杂乱」

孩子小可以收纳玩具和书籍，孩子大了全部收纳书籍即可。「家里有小孩，玩具怎么收纳比较好？」

儿童房衣柜下方也可以开放收纳，小时候可以收纳玩具，孩子大了可以收纳书籍。
