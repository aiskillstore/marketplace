# 完美书房，应该这样做1.31

家庭书房的形式不外乎以下几种：1.单独空间书房；2.书房兼顾次卧；3.书房兼顾衣帽间；4.开放式书房；5.其他空间挤出书桌空间即可；

▲标准的新中式书房，更有韵味。搭配新中式的家具，既没有过去传统中式的厚重和压抑，而且还保留了中式的韵味。纯粹书房空间，书柜+书桌的布局，角落休闲单椅满足休闲即可。

m

▲书房兼顾次卧空间，但是又想空间更开阔，就可以采用这种隐藏床的形式，不做次卧时候，随时可以让空间更开阔

▲中式风书房，不大，定制书柜以及书桌布局，剩下的空间还可以满足一架钢琴的布局，合理利用空间

▲美式经典，成品订购美式书柜，美式的书桌椅，一个皮质的休闲沙发布局，来客户可以面对面交流，角落美式地球仪装饰空间

▲阳台有空间的话，定制或者成品书桌，也能成就一个书房的功能

▲利用客厅的角落采用玻璃隔断分割出来一个小的开放式书房，同样可以满足在家办公的需求

▲同样是书房兼顾衣帽间，地方够大，可以定制更多的衣柜，满足更多收纳

▲更大的衣帽间兼顾书房，简直是每个家庭的梦想空间

▲地方够大，可以摆两张书桌，供两人同时办公，还可以利用空余地方摆放休闲沙发或者沙发床，随时也可以兼顾次卧功能

好好围成

▲顶楼斜顶书房，不仅光线好，而且地方超大，采用中式的布局家具摆设，体验感非常好的书房空间了，累了出门就是露台的花花草草，好不惬意

▲超大客厅空间，可以打造一个开放式书房，一面墙书柜定制，隔断分区，让空间互通又能一体融合，也是不错的书房布局

▲小户型不要客厅，直接打造成办公空间的书房，两个人同时办公，也是不错的做法

▲书房兼顾衣帽间的做法，满足衣物的收纳，同时又能成就偶尔办公的书房，一举两得，特别是对于空间小的书房简直是物尽其用
