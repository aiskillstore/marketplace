# 进门玄关翻车，引以为戒8.21

装修翻车有专辑，里头包含装修里头能想到的所有翻车案例，大家可以在装修之前多看看，别人翻车的地方就是自己装修需要注意的地方。今天看看玄关背景翻车案例。

▲进门下沉式玄关，结果没有审美，彻底翻车，就像进门有个坑一样，而且完全没有考虑家里小孩和老人的使用

▲进门口很小不要放很大的成品换鞋凳，突出来占用空间，而且视觉很突兀，直接采用折叠换鞋凳，就可以解决小空间的换鞋凳功能

▲进门处很小的时候，定制鞋柜不要带明装把手，而是拉槽或者反弹器，这样不容易磕碰到，视觉也能极简

▲家里入住人多，鞋柜下方镂空是必须的，否则进门的鞋子都懒得开门放，结果导致进门一地鞋子，整体凌乱

▲门厅一般光线都不好，还好灯光可以救一下，但是你把墙面和定制都做深色，即使再好的灯光也无法挽救昏暗压抑的光线了；而且很窄的过道突兀 的鞋柜把手，视觉凌乱而且容易磕碰
