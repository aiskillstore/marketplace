# 客厅带阳台，窗帘装客厅，感觉多此一举5.6

这个问题如果关注本号的话，属于老生常谈了。不论你是豪宅或者蜗居也好，都不应该这样做，第一没有必要花钱，第二人为缩小空间得不偿失。当然，卖窗帘的绝对反对。续接上篇《北方封闭阳台，给客厅弄个布帘，显得多此一举了》
第一、错误做法

▲如图所示，客厅带封闭阳台，此时阳台本身纱帘已经有了隐私效果，给客厅再加纱帘和布帘，第一会缩小空间，第二会浪费钱财，同时哑口套也是多此一举，视觉上框架会让空间缩小
▲如图所示，同样也是客厅做了布帘，还好没有在做一层纱帘，缩小空间不说，浪费金钱而已，金属套线也并不会显得多么上档次，不如把钱用到买点质量上乘的家具上▲如图即使没有阳台，这里的布帘其实也多此一举，又不做投影，即使阳光暴晒你拉上布帘客厅彻底变黑，没有意义；正确做法是去掉视觉厚重的窗帘，让客厅区域更清爽，视觉空间更能放大▲什么时候客厅需要纱帘遮挡？当阳台布局书桌，偶尔办公需要隐私的时候，此时客厅也是纱帘不是布帘，保证阳台办公空间的隐私需求，同时纱帘不会造成视觉的厚重感。▲大家可以试问一下自己，家里没有投影，客厅窗帘什么时候发挥功能？除过增加视觉上一片厚重的布外，给不懂的人展示一下自己不缺钱以外，意义在哪？▲草绿色窗帘独立存在的话，本身撞色就错了，视觉上更显厚重，就像浓黑的眉毛占据了本来姣好的面容第二、正确做法
▲不要窗帘，不要哑口套，把钱省下来，用到每一件有品味、有档次的家具上，即使你是刷墙铺地也是高级的▲即使家里有投影，客厅也是不需要布帘的，只需要给阳台直接布局遮阳帘即可，放大空间省钱▲客厅不做布帘，放大空间，同时拱形垭口视觉更生动，花每一分钱都带给空间正面的价值▲一样做法，纱帘布局阳台，更能放大空间和光线，同时拱形垭口让空间更生动▲豪宅尚且为了空间的放大，舍弃繁杂，小户型何必浪费金钱缩小空间呢？▲不论你是豪宅还是蜗居，装修的价值并不是看谁多花钱了，看谁家堆积了多少建材，而是看谁花费最少，装修还能放大空间成就档次▲特别是北方封闭阳台，能把客厅砸通尽量砸通，放大空间，这个是装修的最基本的意义所在▲一样的装修不一样的效果，关键是人的观念问题，这个太难改变了。
