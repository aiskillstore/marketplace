# 西安装修课堂每日一讯【地板篇】2.25

一、地砖太冷
缺点：地砖给人的感觉比较冰冷，特别是去看了装好的人家
优点：最好打理，特别是西安的冬天空气干燥，各种加湿器对人健康不利，铺地砖的话可以直接用湿拖把拖一遍地增加湿气；有小孩的话不怕随地小便
二、实木地板
价格太高，不易维护，不适合家里有四岁以下小孩家庭
三、复合地板
1、成本可控。这个最吸引的地方。因为经济上的限制，每一笔钱都要细心、慎重地对待
2、容易维护。装修的目的是什么？好看、档次还是舒适、方便。复合地板相对容易打理，一则价格本身就便宜，不会当一回事，即使坏掉了，最多再换；
4、安装方便，特别是不用打地垄，安装快捷方便
也许想法上比较主观一点，其实各种材料都是可以选择的，并不作为建议或者评判的标准。
