# 阳台中间大梁丑哭，窗帘卡死，原来这样做就能轻松搞定！

阳台中间有大梁，多见于家里有双阳台的格局，不仅大梁丑陋，同时窗帘被大梁分割卡死，解决不好分分钟翻车，不仅颜值丑，同时还影响到窗帘的功能。今天看看这些办法，既弱化了大梁的突兀，同时也满足了窗帘的功能。第一招：三片式窗帘朝中间拉。网友@啡很甜：很多小区房，都是双阳台设计，但是， 中间的这个梁，本打算用过梁神器解决这个问题，但是被商家给打消了这个想法，说过梁神器时间久了，会有下垂现象，容易挂窗帘。为了吊顶能高一点，后来采用三片式的，两边的窗帘都往中间拉，既不遮挡光线，又不影响开窗，这样的效果也还可以。网友@红帽帽：窗帘盒与大梁平齐高度，大梁下放窗帘固定不动，把原有大阳台分割成了两个独立的阳台，窗帘实现各自朝两边拉，只是中间窗帘不能动，无法实现彻底的通透感。
第二招：加宽吊顶，大梁下沿板子，实现窗帘盒。网友@可可蛋奶：很上图大梁非常低，而且窗户是平开窗，想要解决大梁问题，还想要美美的窗帘盒，到底改怎么处理？显然这样做是错误的做法，窗帘盒有了，但是大梁会分割窗帘，导致大梁位置窗帘无法一体拉通。这才是正确做法，人为加宽阳台窗户上翻大梁，在满足不影响平开窗开启的同时，窗帘盒做浅下沿，实现一个窗帘盒的功能，同时窗帘不受大梁分割。最终落地完美的效果，窗帘盒有了，可以一体拉通，同时减少了吊顶牺牲层高的可能。网友@漫漫：阳台长8米，中间有个斜梁，很不喜欢，就想着怎么包起来，方案是顺势做个斜坡，转折处做成木饰面，和家里的风格也很协调。唯一的不完美是窗帘盒很浅，深度大约只有10厘米，也能接受。网友@麦茶：①封阳台的时候阳台断桥铝窗户的最上面往下多做一些，在保证美观实用的基础上尽量往下做，这样窗户开栅也往下移了，从而使梁到开栅顶部的距离更大。②阳台不贴砖，这样梁到窗户开栅顶部的距离保持最大化。③不做罗马杆，直接用窗帘轨道，保证窗帘打开的时候不影响开窗户开闭！以上三种方式同时用了，才勉强做一个深度只有5公分左右的窗帘盒！这样做出来的效果还是很不错的。第三招：大梁下不做窗帘。大梁下不做窗帘，是最不推荐的做法，同时也是翻车的做法。网友@西的家：不能弱化，那就强化吧。先让木工用欧松板做基底 ，量好尺寸后定制木梁，用的松木做旧，而且这个颜色和地板的颜色也很搭配。可以用多层板，更加稳定。 安装，用气钉枪或者螺丝直接拧上去 	 最后落地效果还是很不错的。缺点就是大梁下放没有做窗帘会漏光，不过隐私和遮阳功能实现了。第四招：三片式两边拉，大梁下窗帘固定。单独做一小块窗纱的方法。 这么处理一来考虑到家里私密性可以达到最大的保护，二来考虑到窗纱并不影响室内采光，所以大部分时间它会是闭合状态。 唯一的缺点窗纱收拢状态下，梁下那一小戳纱会有点尴尬。第五招：利用过梁支架实现窗帘两边拉。网友@杨杨：阳台长5米多，中间有根梁把窗帘分成了两部分，安好后整体效果还不错，不过异形位置的窗帘是动不了的，两侧窗帘全部收起来后比较宽，会遮挡一部分窗户。网友@一条人：阳台做的窗帘盒，在梁底下增加轨道，做出来效果很不错，顶部不会漏光，4页窗帘对齐也好看第六招：隐藏大梁，做内嵌轨道。网友@OFFEN：虽然有大梁，但是大梁稍高一点，刚好与窗户上方有个落差，采用石膏板整体拉平吊顶，加宽的石膏板采用预留内嵌轨道的做法，需要提前购买轨道，木工根据尺寸预留即可，这样就可以实现隐藏轨道，同时窗帘可以两边拉的效果。
网友@皮蛋粥：阳台长度有7米，顶上有一根横梁，为了让窗帘能一气呵成不被横梁截断，采用了这种梁下窗帘的做法，既美观又大气。封窗设计时要注意，如果是内开的窗户或纱窗，水平位置上要让开窗户收起来后的宽度，顶部位置打开时要避开窗帘挂珠的高度；网友@花的苏：为了窗外开阔视野，打通客厅和次卧阳台，封了一个5.5米长大落地窗，但是中间横梁不能敲，如何安窗帘好看，差点崩溃。木工阶段，贴着窗框侧用木条与欧松板延展出一定宽度固定窗帘轨道，再贴石膏板上面刷乳胶漆，而顶板吊顶高度与嵌入式晾衣杆持平。最后，为了不压层高，也为了窗帘不在横梁处截断，选择不做窗帘盒，让木工做梁下嵌入式窗帘轨道，亲测效果如图，灰常满意网友@珠的家：满屋大平顶吊顶，吊顶后在斜梁的基础上增加一个弧形设计，弱化斜梁，增加美观度，后期和顶部一样喷的白色漆，和顶部连为一体，根本想不到它原来的样子；同时人为加宽窗户上方吊顶，采用嵌入式轨道，实现整体窗帘的拉通效果。网友@洋杉杉：家里是7米的双阳台，做了大玻璃内开窗，后面木工阶段才发现不好做窗帘盒，因为双阳台普遍中间有横梁，而且这个还是和窗户框架上面的顶齐平，最后的方案是，在横梁是开和隐形窗帘轨道一样宽度的槽，让隐形窗帘轨道嵌入，完美解决，符合我想要的简约设计第七招：不止一根大梁，只能分开吊顶，分开实现窗帘盒。网友@Curiosity：通阳台，一侧有三根大梁，够奇葩吧，注定怎么做都会影响颜值和功能
解决办法：独立弧度吊顶隐藏三个大梁，利用大梁空隙实现电动晾衣架功能，因为有大梁影响，只能独立做窗帘盒，实现局部窗帘功能。另一侧独立吊顶同样实现窗帘盒，唯一的缺点就是两个窗帘盒不在一个高度，但是可以实现独立使用，也能满足隐私需求。第八招：L型独立窗帘盒。网友@oro：中间有大梁没法做窗帘，干脆两个部分做独立窗帘，客厅阳台做L型窗帘盒，刚好平时独立使用，可以遮挡一下生活阳台，也解决了有大梁没法拉通做窗帘的问题。后记：以上是8种常见做法，最推荐的就是第2和第6种，做窗帘盒拉通或者内嵌轨道，实现整体拉通效果。
