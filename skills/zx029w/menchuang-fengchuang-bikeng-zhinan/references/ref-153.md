# 西安装修课堂每日一讯【装修之实木地板】5.4

     西安地区业主大部分都想用实木地板，认为实木地板价格高，质量好，这和人长得漂亮一定是好人一样，没有任何道理的。西安地区气候原因是不适合铺实木地板的，地板使用中的稳定性无法保障，随时可能出现问题。
1、木种名称。不同的木种价格相差很多，这个大家都知道，所以很多奸商给自己的地板冠上珍贵木种类似的商品名。比如，柚木价格很高，所以有商家就取一个巴西柚木、南美柚木之类的名称，有点“傍大款”的意思。所以要区别商品名、别名、俗名和学名，认准学名。
硬度高的实木地板有：摘亚木、相思木、坤甸铁樟木、铁线子、二翅豆及马来甘巴豆。
稳定性比较好的实木地板有：柚木，橡木（白栎或红栎）、圆盘豆、纽墩豆、孪叶苏木、铁苏木、印茄木和铁线子。总之，看见实木地板取得名字你就一笑而过，千万不要当真，否则上当的就是你。
2、颜色。优质的实木地板应该是自然色，清晰木纹，材质肉眼可见。如果地板表面颜色深重，漆层较厚，有可能是为了掩饰地板表面的缺陷而有意为之。
3、级别。虫眼或针孔多的地板做来的是B级板，每平方米和A级板相比至少差几十元，购买时请认准A级板。理论永远都是苍白的，现实中A级板就是一张废纸而已，商家随时都可以做出来
4、色差。在选择实木地板时，色差是一个自然问题。实木地板是天然的材料，哪怕是一棵树上的木材，它的向阳面与背阴面也是有色差的。色差是天然材料的必然因素，它并不影响地板的质量，也不一定影响美观。其实正是色差、天然的纹理、富有变化的肌理结构，才彰显了实木地板的自然风采，当然铺装的时候可以尽量调整色差，或是调均匀，或是把大色差的铺到视线不及的家具底下。有些实木地板色差极小或是没有色差，这些板可能是因为板材本身有问题，用化学药水洗后上漆，表面看不出区别，但一年以后板会发白。理论上是这样的，但是有的人总是不喜欢色差太大，想要没有色差直接用强化地板和打印的一样。
5、长短宽窄。长板对选材要求高、损耗大，故价格高，而小板材料利用率高、价格便宜，且不易变形，经济适用。在安装时，长板裁减的损耗也比短板或窄板高。不过国内基本都喜欢长宽板材。
6、厚薄。实木地板的标准厚度是18mm，如果厚度减少1mm，价格可以减少几十元。所以在购买实木地板的时候一定要看清尺寸，长短宽窄厚薄相差一点点都是每平方几十元的差别。
7、辅料。实木地板除了地板本身以后，铺装还需要用到龙骨、踢脚线、门压条、防潮防虫剂等。随着市场竞争加大，有的商家压低地板价格，从辅料中赚取利润，所以比价的时候也要算上辅料价格。
8、铺装。地板行业有句话叫“三分地板、七分安装”。足以见得安装的重要性。为了避免铺装出现问题，实木地板基本都是地板卖家负责安装。切忌实木地板买来让装修公司铺装，万一以后有问题，卖家和安装工人会相互推诿。
优点：隔音隔热  绿色无害 华丽高贵
缺点：难保养  价格高  稳定性差
