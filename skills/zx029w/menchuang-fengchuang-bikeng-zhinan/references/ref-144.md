# 西安装修小心低价切入

为了能拿下装修单子，很多装修人员都采用先低后高的欺骗手段，让您的装修预算不知不觉就以“万”为单位，偷偷上涨，岂能不防啊？
中计实例：
很多消费者在装修房子时，往往最关心的是造价，游击队及某些不诚信的小家装公司便利用消费者这一心理，采用先报低价揽活，再中途变更设计，增加造价，从而达到谋利的目的。

业主张天打算装修一套110平方米的三室二厅，某正规家装公司方案总造价为95000元，其中各项费用明细清楚，计算也很精确。而“游击队员”李某出具的相似方案，报价却仅为6万元，近4万元的差价让张天毫不犹豫地选择了李某。
签完装修合同，付了35000元订金后，装修队进场施工。经过三天的敲敲打打，李某提出原先设计使用的水电管线质量较差，建议增加1500多元更换某名牌管线，张天爽快答应了；又过了三天，李某又说原先设计的出水口和线口过少，需要增加5条，又要求增加2000多元的材料及工费。就这样，张天事后一算账，竟然不知不觉花了90000多元钱，而效果也差强人意。
破解之法：
仔细对比不同装修公司的报价单，尤其是主材和辅料的报价，一定要对比同一品牌的同一型号。水电改造、包门套、垭口等，材料品牌和单价也要事先详细说清楚，以防事后增项过多。

陈工意见：大公司就是可靠的是扯淡！装修多少年了没有一个人说实话，没有一个切中要害，你们怕什么？心里都有鬼！！！
