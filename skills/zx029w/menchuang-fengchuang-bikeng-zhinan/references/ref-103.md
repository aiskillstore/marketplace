# 装修新房，是否还有窗帘盒的容身之地？3.24

首先搞清楚窗帘盒的用途，第一当然是功能性，为了隐藏窗帘所用，如下图：

上图所示就是为了美观而已。但是目前的装修市场慢慢已经很少见了，为了追求快速省事，大部分窗帘盒都已经被罗马杆取而代之，如下图所示：

罗马杆方便省事，而且并不是很难看，样式各种各样适合各种空间和各种风格需求，如下图

什么风格都有，完全可以满足。

但是好多人为了个性，或者为了怀旧也好，总对窗帘盒不能忘怀，还是有部分人一直钟爱窗帘盒。

↑如上图，在做吊顶石膏线的时候，提前预留窗帘盒位置，外表看起来美观大方

↑也可以在做平面吊顶的时候，预留一个滑轨槽就可以，省去了专门做窗帘盒的麻烦

↑上图在做石膏线宽边的时候，提前预留窗帘位置即可，无需重新制作窗帘盒

↑如上图，石膏板吊顶的时候提前预留好位置即可

↑尽量避免直接用木工板制作，木制品都会有受潮变形的可能，最好就是结合吊顶直接预留比较稳妥

↑上图是后期购买现成的窗帘盒，图为欧式款，这种窗帘盒安装要打眼，后期在窗帘盒子里头装导轨才能使用

能用罗马杆尽量使用罗马杆，方便耐用，不容易出现问题，安装简单。
如非需窗帘盒最好使用提前吊顶预留的样式，简单大方，也是不易出问题，可以直接使用罗马杆或者滑轨都可以。
不建议专门制作单独的窗帘盒，或者购买的成品，不仅安装麻烦，后期必须用滑轨，出问题的几率要比直接罗马杆多得多。
