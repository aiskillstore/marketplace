# 西安装修课堂每日一讯【乳胶漆调色】6.15

       1、选涂料颜色时，一定要在色卡上往淡里走两色阶，因为大面积的墙面通常会显的比色卡上看到的要深。
  2、最好在阳光和灯光下同时进行色卡选择。否则在店内选择完刷好后，你可能觉得在日光下并非你想的那种效果。
  3、一般来说起居室宜选用明快活泼的涂料色彩；卧室的涂料色彩最好偏暖、柔和些；书房宜雅致、庄重、和谐为主色调；餐室应以暖色为主色调。
  4、有色的墙体面积要小，因为点缀效果比较容易被广泛接受。大面积使用彩色的话除非你色彩感觉和美术功底非常好，否则建议谨慎使用。
  5、家里墙体颜色不要过分多和复杂，可以用后期装饰物达到同等效果。
  6、色彩选择要宜淡忌浓，因为淡色对于搭配没有太多限制，在一个空间中进行大面积涂刷都能够比较安全简单。
  7、靠窗户的墙颜色可以略微跳一些。因为阳光会压住色调，看起来比实际淡得多。当然，在实际情况中不能单选墙面颜色，而是要根据整体设计风格搭配适合的墙面涂料颜色。
       8.西晒的房子可以适当变色，防止管线太强
        9.儿童房最忌深颜色乳胶漆，只要颜色深的都不同程度含有各种有毒物质
        10.乳胶漆调色后和刷完的效果会有不同程度的出入，业主在选择的时候一定要谨慎
