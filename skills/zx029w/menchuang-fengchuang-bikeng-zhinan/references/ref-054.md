# 120平四房老房改造，玻璃房通透，躺着就能看电视

▲二手房重装，房子进去最大的感受是采光不行，先来看看改造前

▲原先的入户处没有地方放鞋柜，设计师充分利用墙面空间，在入户处做了洞洞板，这真是一个集美貌和实用于一身的收纳神器啊, 让包包鞋子和杂物都有了去处

▲厨房做了相当大的改动。原来通往厨房只有一扇小门，光线进不来，餐厅很暗，而且厨房和餐厅动线奇怪。我们打掉了餐厅原本入墙柜，成为新的厨房入口，把原来的入口改成了一个小吧台，厨房变成半开放式的，自然光引进来，整个屋子都亮堂了。另外洞洞板旁边的穿衣镜也增加了采光

▲这个小空间，设计师建议做个水吧台，真的是很实用。下面是柜子，放咖啡牛奶零食什么的。我们家人不喝酒，我每天都会在这里泡杯咖啡醒神，朋友们也觉得这个小小的水吧台很赞

▲吧台一边的墙也不能浪费。我俩旅游带回来的明信片，每日菜单留言贴士等等都挂墙上，有烟火气也要有诗情画意

▲厨房用白色墙面，白色吊柜，用浅木色做柜门，显得更加敞亮！地上铺一些花砖，太赞了，厨房就不那么素了，增添了可爱和动感

▲沙发后面的墙面空间也充分利用了，我们做了猫爬架，墙角放了猫树，都不用额外再买，算是给猫宝儿们准备的礼物，宝贝们很喜欢，第一时间就爬上了家中至高点，以后的视野更广阔了，超赞超赞

▲君临天下的大咪

▲榻榻米房除了充当客卧，也是我们的桌游室。经常让朋友来家里聚会，双升降台还蛮适合打牌的
