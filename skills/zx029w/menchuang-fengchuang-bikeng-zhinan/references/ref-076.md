# 阳台窗户与墙面平齐，这瓷砖咋贴？12.8

其实实际装修施工过程中的问题，远比业主想象的艰难多了，如果真的用心这里头是要付出心血的。但现实往往相反，大部分装修不愿意去动这个脑子，业主也不懂，能糊弄就糊弄，反正业主哪天发现了，钱赚到手就行，也无可奈何。

但是装修需要有工匠精神，能做好为什么非得敷衍呢？看似敷衍的是业主，实则是断了自己的口碑之路，从此永远不会有上进，随波逐流，总有一天会被市场淘汰。
1.背景瓷砖没有那么简单。
▲如图是卫生间干区的位置，做法是半截墙瓷砖，上方变色乳胶漆的做法，直接定制浴柜镜柜。有问题吗？仔细看，好像没有什么问题？
▲同样一个地方再仔细看看干区的瓷砖，然后两张图片比较一下，看有什么问题？如果你能看出来，才是行家。
首先第一个问题：背景贴瓷砖不思考，直接铺，导致两边瓷砖大小不一样。当然如果你要求低，这个也能用，不影响使用，但是想要完美，必须保证两块瓷砖是完美对称。
第二个问题：不看瓷砖的排布，注意干区两边分别是厨卫空间，而且都使用的是1.6cm的窄边全景门，而第一张图片采用水泥砂浆直接铺瓷砖，会导致门装上以后，瓷砖高于门套线，非常难看；第二张采用瓷砖粘贴剂铺贴，减少厚度，装完门，瓷砖刚好与门套线完美收口。

▲如上图所示，左边就是细节到位，窄边框直接采用瓷砖胶做法，刚好与门套线严丝合缝；右图就是采用水泥砂浆的做法，导致瓷砖高于门套线，后期必须砸掉重做
第一个问题属于审美问题，同样属于不动脑的问题，而第二个问题属于施工事故了，如果不解决，后期门装了一切就迟了，要解决就得砸掉瓷砖。
大家想一想你们在实际装修中遇到过这种问题没有，遇到以后都是怎么解决的，还是跟着别人屁股将错就错，只要不影响入住就行？

▲再看看同样的户型，我们是怎么去做的。同样一个地方，仔细看看到底哪个好看？
▲来张大图更全面，注意我们为了不会出现难看的收条以及视觉更美观，采用木工板以及水泥压力板做了一个盒子处理，然后贴瓷砖，让窗户边缘整体变得方正美观。最最重要的是我们发现问题到解决问题没有给业主说过，解决问题的费用也是我们自己承担，直到业主互相比较的时候，才发现不一样的地方。
