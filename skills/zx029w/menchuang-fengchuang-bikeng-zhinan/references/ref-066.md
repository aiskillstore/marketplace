# 没有阳台，窗户晾衣服怎么做？11.3

你是否已经想好没有阳台晾衣服的对策了？如上图所示，这样的方式除非是老旧小区可以，而且增加安全隐患，一般小区是绝对不允许你这样做的没有阳台当然分体的独立洗烘机最好，这个是有钱人的做法，但是如果没有烘干机，没有阳台，只有窗户能满足晾衣服，怎么做更好呢？如图如果没有阳台，可以布局洗烘独立机，这样加一个抽拉裤架就可以满足一些无法烘干衣物的晾晒了。但是没有烘干机的时候，家里只有窗户可以利用。如图利用飘窗上方采用窗帘轨道满足平时小件衣物的晾晒，同时拉上布帘以后也可以遮丑伸缩杆就更实惠了，用的时候拿出来两头支撑就行，不用的时候可以取下来，就类似于卫生间浴帘的伸缩杆，都可以满足这个功能利用这种伸缩杆，平窗也是可以满足晾衣服的利用窗户两边型材，支撑伸缩杆，就可以满足晾衣，同时满足通风需求如图利用中间固定窗户位置，安装固定的晾衣架，实现平时的晾衣需求，也不会影响窗户的开启也可以网购这种可以固定在开启扇窗框上的简易晾衣架，可以折叠起来，平时晾小件衣物是可以满足，衣物需要固定起来利用窗户的边缘侧墙安装可以折叠伸缩的晾衣架，当然这个需要打孔安装，注意不要破坏外墙保温等基层，满足室外晾衣服，衣物需要固定，刮风脱落非常麻烦利用飘窗安装一个隐形的晾衣架，不用的时候收起来，用的时候拉出来即可利用飘窗固定扇位置安装固定晾衣杆，就可以满足平时少量衣物的晾晒护栏与晾衣完美结合，平时是作为窗户护栏，也可以起到防护作用，拉起来就可以满足晾衣需求还可以利用窗帘盒满足一个隐形晾衣架的做法，不用的时候可以拆卸隐藏能挂在窗户上的伸缩晾衣架，也可以实现室内窗户的完美晾衣服当然你也可以利用过去的手摇单杆，窗户上头实现一个晾衣需求，只不过有外露的钢丝，而且还需要有手摇装置，看起来繁琐一点还有更简单的免钉折叠晾衣架，直接可以沾到窗户型材或者玻璃上，就可以满足少量的晾衣需求更简单的窗框固定晾衣架，可以满足更多衣物的晾晒折叠伸缩转角的晾衣架，刚好可以隐藏在衣柜的夹角位置，平时不用的时候整洁，用的时候拉出来可以任意角度拉伸也可以利用卧室窗户吊顶，电动单杆晾衣架，还带有光源照明飘窗上头刚好有个凹陷区，安装晾衣架满足晾衣服，下方采用伸缩杆，可以满足晾晒被褥，即使没有阳台也可以满足功能
