# 中央空调、地暖、新风这三大舒适系统怎么搭配和安装，才不花冤枉钱又不好用？

**中央空调：三分产品七分安装。** 中央空调三分产品七分安装，安装比产品更重要。层高不足2.7米不宜安装中央空调，否则应通过局部吊顶并综合考量实际高度。中央空调吊顶下来的深度更能与双眼皮吊顶完美配合。中央空调必须专业清洗一次四五百每年都要洗。

**地暖：水地暖适合大面积，电地暖适合小面积。** 水地暖适合大面积，电地暖适合小面积。北方大部分是地暖，有地暖优先选瓷砖。家有小孩地暖房不建议用木地板，强化复合地板受热污染释放更大。地暖怕污染用实木，变形伸缩无法避免。地暖房子任何非实木地板都只是给装修污染雪上加霜。

**新风：必须是双向换气加过滤网加恒温，前提是家里密封。** 新风系统必须是双向换气加过滤网加恒温，前提是家里密封。单向流没有排风口脏空气排不干净，只能通过门缝窗排出；伪双向流进风和排风都在同一管道，容易风道混流降低通风效果；拥有单独进风口和排风口通风更顺畅换气不干扰。卧室处理噪音采用成本最低的壁挂新风满足换气功能，壁挂新风要选双向流且带热交换功能的，一般卧室空间只要满足一个空间的风量即可，风量越大噪音就相对较大。

**三大系统的搭配原则。** 换窗必须配新风，关闭窗户隔绝噪音的同时保证呼吸顺畅只有一条路：安装新风。中央空调、地暖、新风都是隐蔽工程，一定要在装修初期规划好，水电阶段就要预埋管道和留好电源。中央空调和新风必须在与设计师实地沟通以后确定位置才能施工。

**别被忽悠乱加。** 中央空调不是必高档，水电走顶一定好维修、无主灯必提升档次等认知都是误区。盲目选择走顶、全换水电、无主灯等做法会挤压家具软装预算并拉低整体效果。刚需房优先采用务实做法。

**记住。** 中央空调三分产品七分安装，层高不够别装；地暖水地暖大面积电地暖小面积，有娃地暖房铺瓷砖；新风必须双向换气加过滤加恒温，前提家里密封。三大系统水电阶段就要规划，隐蔽工程别省，功能优先于面子。
