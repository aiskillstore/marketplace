# 飘窗窗帘要会搭配，不要让一片布毁了一个家5.26

大家都喜欢有一个美美的飘窗，然而在装饰的时候，窗帘却不知道如何搭配，有的随意搭配，让飘窗变得不忍目睹。如下图这几个，完全把飘窗给毁了。

▲这么好的飘窗，这窗帘搭配效果，被一片布毁了

▲不是不能用这个窗帘，而是同样花钱，有价格没有价值而已

接下来看看别人是怎么去搭配的。

▲虽然是个普通飘窗，但是忽略人家的造型和垫子，按照形状做了一个梯形窗帘盒，使用滑轨做了浅绿色的素帘，这才是重要的。一般家庭老是陷入了色彩的误区，好像素色就不是颜色了，其实素色有时候比彩色更能体现风格，此图浅绿刚好与窗外景物融合

▲这是飘窗加了纱帘的效果，当然必须是两层窗帘，纱帘取决于窗户对着的楼房距离，对面如果能看进来的，必须用纱帘，白天可以选择用纱帘遮挡，同时可以起到遮挡阳光的作用

▲第一道纱帘为了遮阳和保护隐私，第二道才是真正的窗帘搭配，暖黄色碎花布艺整体墙面拉通，而且做了点缀的帘头，整体空间马上暖意融融

▲飘窗很小而且不居中，房间也很小，就可以选择只在窗户里面做窗帘，这样能看起来房间大一点，而且窗帘颜色与壁纸淡蓝色条纹呼应，整体协调

▲空间比较小，没有外面大窗帘的位置，选择直接在窗户上做，两道窗帘，素色淡蓝，小空间窗户上直接挂窗帘尽量避免花里胡哨

▲沉稳风格，还是两道窗帘，素色为主，让窗帘的点缀装饰性藏于无形，而不是花里胡哨，喧宾夺主，抢了整体装修风格的风头，本末倒置了。上图出彩之处还在于两边的壁灯设置

▲粉色两道窗帘设置，外帘与背景碎花壁纸呼应，整体协调，风格保持一致
