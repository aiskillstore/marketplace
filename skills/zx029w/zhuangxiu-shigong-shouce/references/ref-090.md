# 家里的内保温，需要拆除吗？

保温墙
拆除还是保留?
南方不太清楚，北方地区只要交房的毛坯房，都存在内保温的情况。这些保温存在的意义在哪里，能不能拆除？不拆除会不会对施工带来难度。今天重点看看。
第一、阳台保温，这个几乎北方毛坯房都会有，一般在阳台与客厅相隔的墙面。
▲如图北方毛坯房交付以后阳台都有保温层，厚度有的可达八公分左右。一般北方阳台开发商是不封闭的，后期需要自己定制窗户封闭阳台，此时这里的保温意义不大，而且家家户户都是地暖，冬天公共区域并不会有多少寒意。
▲所以在你准备封闭阳台窗户的时候，阳台的保温墙可以拆除处理，这样空间可以拓展，而且后期施工更好保证质量。
第一：阳台墙面的做法决定，如果你是准备阳台铺墙砖，保温墙必须拆除，否则后期瓷砖百分百或脱落，因为无法粘贴牢固，保温层无法承受瓷砖的重力作用，即使用纯胶也会脱落；如果你家阳台不贴墙砖，做乳胶漆，此时的保温层可拆可不拆，取决于你是否需要拓展空间。
先切线，预留封阳台位置，然后铲除保温层
▲需要注意的是，准备拆除保温墙一定让封阳台的划线界定拆除范围，如图所示，如果前期不规划，后期拆除超过窗户的位置，窗户封掉以后，外面无法修补了
第二，厨卫保温墙。有时候厨卫靠向外墙或者电梯间，有的开发商做了内保温，此时一定注意，厨卫必须铺贴墙砖，这里的保温必须拆除，否则瓷砖必然脱落，而且厨房有吊柜悬挂安装，这些都是隐患，必须拆除。
第三，除过厨卫阳台以外的内保温。
这里一定分情况，如果是西晒的内保温，能保留则保留，特别是卧室区域，这个是能起到隔热的作用，一旦拆除夏季的时候没有任何隔热作用了，这一点西晒的住户应该体验颇深；
除西晒的保温可以保留以外，其他都可以拆除，一是让空间大那么一丢丢，二是施工方便；不过如果其他区域都做乳胶漆的话，也可以保留不拆除。后期直接挂网处理也可以直接乳胶漆施工的，节省一点施工的拆除成本，前提是你家油漆工手艺比较高，否则还是拆了吧，后期裂缝的几率太大了。
