# 75㎡老旧房改造，通铺木纹砖给未来一个家

75㎡老旧房改造，通铺木纹砖给未来一个家
老房购买往往牵扯到太多改造，因为年代太久远，过去的装修压根无法满足新主人的审美。所以需要推倒重来。费用造价一般比新购毛坯房要高很多。
▲原始结构图，进门是厅，客餐厅共用空间；左手分别是厨房阳台以及卫生间，每个空间都小到无法忍受；两间卧室也非常小，几乎没有办法满足基本功能。
▲设计后的布局图。首先为了满足电视墙的功能，利用厨房和阳台空间新砌墙，满足了客厅电视墙，同时把厨房和阳台做了移门处理，节省空间的同时满足基本对称，同时满足功能；
因为卫生间实在太小，为了满足基本的空间，采用移动次卧墙体，扩大卫生间，同时满足了主卧衣柜的收纳；小阳台做了洗衣房使用
▲没有改造之前的样子，因为前主人用来出租，所以比较凌乱
▲利用进门左手做了顶天立地的鞋柜，下部镂空满足放鞋，上部镂空满足进门方便放东西，布局感应灯也非常实用；为了让视觉上不显得压抑，做了局部简单的吊顶处理；厨房采用时下最流行的窄边全景门，价格贵点，但是质量和颜值确实高
▲重新砌墙借用厨房以及阳台的空间，满足了电视墙的布局，同时采用岩板装饰，加上两边全景门的搭配，非常有高级感
▲站门厅看客厅全景，因为有个超大的飘窗，客厅光线非常明亮；四周局部吊顶做了以后，采用实惠的挂机满足了功能，同时为了不压低层高，局部吊顶做了镂空满足挂机的隐藏
▲靠近飘窗位置轻巧的轻奢单椅搭配，大理石圆几和绿植让角落同时满足休闲和视觉的美感
▲阳台和厨房对称的全景门，黑色的质感。中间岩板电视墙，选购同样黑白配的岩板电视柜呼应，简单有档次
▲进门右手很小的角落布局黑白配餐桌，同样的白色岩板与电视柜以及电视墙呼应一体，同样金色丝绒的餐椅搭配，风格统一；简单挂画与跳舞兰点缀氛围
▲进入卧室的过道，能看到直对的主卧空间，平时打开门让光线一览无余；过道右手是次卧，左手是唯一的卫生间
▲主卧空间，空间非常狭窄，只能舍弃传统床头柜，一边是轻巧化妆台，一边是金色落地氛围灯；皮质的床头，一副莫兰迪挂画错开布局，非常有高级感；仅有的大飘窗蓝色垫子定制，这里可以作为平时的阅读空间
▲暖咖色背景变色与皮质床头颜色协调，非常轻巧的化妆台满足女主的爱美需求，不同于传统的挂画布局，让空间有了设计感
▲斜面的拐角飘窗刚好能容纳一个小巧的大理石圆几，平时这里读书休闲非常惬意
▲纱帘透光效果非常好，可以让卧室光线柔和温馨
▲次卧同样非常小，定制了榻榻米书桌一体，满足空间的最大化功能，床尾是定制的衣柜满足收纳；暖色与粉色搭配，蓝色清新点缀。平时兼顾书房和次卧，以后这里就是儿童房空间
▲厨房L型布局，暖色瓷砖搭配统一白色的橱柜定制，简洁干净，满足两人的生活以及收纳
▲卫生间条件受限，无法满足真正的干湿分离，角落定制了淋浴房，两边分别布局马桶和定制浴柜；镜柜满足所有收纳
