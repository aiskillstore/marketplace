# 吊顶和鞋柜不协调，你不出问题谁出问题？

吊顶和鞋柜不协调，你不出问题谁出问题？
吊顶和全屋定制没有绝对的关系，有时候只不过是为了颜值，或者为了省钱。两者侧重点不同，所以各取所需。
▲如图门厅有大梁，本来需要平面吊顶，或者不想平面吊顶最起码需要和大梁平齐，与鞋柜厚度一样的局部吊顶也行，但是害怕吊顶压抑或者费钱，却忽略了基本的定制问题，然后就出问题了，而且鞋柜又高又压抑，还是刀把结构▲没有吊顶就不要做石膏线了，否则石膏线和定制断开真的不好看，不就多此一举了；而且颜色搭配头重脚轻，一定是上方浅色，下方深色的配置▲如图的刀把问题，其实还是吊顶问题，是有吊顶，但是压根和定制无关，这个几乎是自己装修里头常见的问题，每一个工种做法都是业主让做的，而每一个做法都和后面没有关系，结果就是全盘出问题▲要不不要所谓宽边，要不就是整体边吊，这种只给鞋柜上方做个吊顶，非常突兀，那宽边的意义在哪？是要突出丑陋吗？▲吊顶不是为了配合定制，那吊顶的意义在哪？抽拉式直接碰到边吊，而且一部分鞋柜悬空▲不做任何吊顶直接定制通顶鞋柜，而且鞋柜比较窄，就会导致进门非常压抑，鞋柜比例失调，其实吊顶要比定制便宜多了，做了吊顶不仅定制省钱了，而且视觉上比例更协调▲真的不想吊顶，成品鞋柜是最好，也是最美观的做法▲装修之初不考虑定制，吊顶是20公分，鞋柜是35的，咋办？只能看着出问题▲装修只图面子，跟着人家学人家做双眼皮，但是不考虑后期定制，结果就是不伦不类▲如果只图功能，也不知道多花钱了，那就看不出出问题，其实平面吊顶或者边吊，压低鞋柜，定制省钱进门还不压抑▲自己装修走一步看一步，没有整体装修计划和方案，结果是吊顶太窄无法和鞋柜一样厚度，导致鞋柜不通顶，出问题了▲一个工种不考虑另外一个工种，这是政府工程的做法，反正花得不是自己的钱吧▲就差几公分，门厅吊顶与大梁吊平，这个鞋柜颜值以及进门视觉要好看多了
