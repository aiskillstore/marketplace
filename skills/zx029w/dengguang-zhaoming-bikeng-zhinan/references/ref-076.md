# 儿童房窗户，好位置这样利用9.6

几乎每一家儿童房都会有窗户，而窗户的利用不尽相同，今天看看儿童房里头的窗户都有什么样的利用方法。

▲空间小定制榻榻米是不错的选择，这里一定要规划，孩子多大，如果孩子成人没有太大问题，或者孩子还小，也可以提前定制《家里有小孩，怎么做全屋定制更环保？》
如图，利用原来的平窗直接拉通定制书桌满足学习功能，另一边实墙地方定制书柜满足书籍的收纳，窗户的上方同样隔板置物，同时刚好预留空调的空间。小空间极尽利用
▲同样是小空间的布局，采用一面墙衣柜定制，与书桌一体的做法，局部衣柜镂空作为书架使用，角落可以是成品床，也可以是定制榻榻米，空间完美利用的同时，可以让活动空间更大
▲和上一个案例类似，只不过放置的是成品家具，书桌窗下布局，也是可以合理利用空间，而且活动空间更大
▲一个卧室两面窗户比较少见，光线非常好，利用窗下直接定制书桌空间，而且与榻榻米床头一体布局，满足更多收纳，视觉也有延伸感
▲非常小的空间，放上床以后几乎没有空间了，所以只能借用飘窗位置，定制小的书桌，隔板书架，基本满足学习以及床头柜的功能
▲直接利用窗户上方隐藏空调内机，同时利用下方定制书柜以及孩子的玩具收纳架，拉通窗户定制学习书桌，完美利用了窗户空间
▲空间稍大的话，可以利用落地窗直接放置成品书桌，角落还可以放置娱乐设施
▲落地窗直接拉通定制书桌，作为光线最好的学习地方，这是儿童房窗户的标配做法
▲两个孩子，刚好利用窗户下方拉通定制两人位的学习书桌，光线最好的地方留给孩子学习
▲窗下拉通定制木质书桌，一个孩子学习，平时大人也能一块辅导；台灯以及吊灯局部照明
▲上铺睡人，下铺安排衣柜以及学习空间，书桌布局在窗户下方，自然光线最好
▲飘窗可以砸掉或者直接落地窗位置，定制书桌满足基本学习和收纳，旁边如果有角落可以定制成开放格收纳书柜或者展示柜
▲上下铺布局，刚好利用落地窗摆放成品书桌，作为学习空间
▲窗下拉通定制书桌，衣柜局部镂空满足书籍收纳，角落上下铺布局满足睡眠需求，空间小合理利用也能发挥大作用
▲超大落地窗定制两边书柜以及下方开放格收纳，平时的玩具和书籍都可以完美收纳，同时还成就了一个休闲飘窗
▲利用落地窗定制拐角书桌，满足学习功能，同时兼顾床头柜功能
▲狭长空间布置成两孩卧室，窗户下定制两人位书桌学习，书桌侧面因为面对门口，做成了开放格设计，随手放物品方便美观
▲常规做法，直接利用落地窗定制书桌，侧面凹陷区刚好定制隔板满足书籍的放置
▲长条形非常小的儿童房，定制上铺睡人，下方收纳柜，借用飘窗延伸抽屉满足学习功能，空间虽小也能做到非常精致
▲借用阳台拓展卧室空间，书桌当然阳台布置，光线最好的地方
▲两孩家庭，一间卧室，两边各自小床满足睡眠，窗户下布置两人位书桌，孩子小的时候完全满足功能
▲直接利用落地窗书桌，衣柜书柜一体定制，不仅满足功能，同时可以最大化放大空间儿童房装修，用什么家具最环保？
