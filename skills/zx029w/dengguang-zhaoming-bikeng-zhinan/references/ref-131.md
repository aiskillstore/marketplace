# 定制柜子不做见光板？有价格无价值1.29

一般家庭定制柜子除非统一实木，几乎用人造板都会碰到有见光板的地方，这是做全屋定制最最基本的，必须考虑到的。

什么是见光板？因为人造板往往会采用柜体和柜门不同的材质，这样即使颜色再相近也会有误差，所以必须在侧面做上和柜门材质造型一样的板子遮挡柜体，达到整体美观的需要，

▲如上图，就是常见的多层柜体与吸塑柜门的材质色板。下方是多层的色板，上方是吸塑的色板，如果采用多层做柜体，采用吸塑做柜门，不可能有一模一样的颜色，材质完全不同，所以就需要做见光板做以装饰。

▲如上图橱柜，柜体采用多层，柜门采用吸塑浅灰色造型，侧面必须加见光板装饰，否则会露出柜体板，与吸塑形成反差，非常难看。
▲如图假如不做见光板，就会出现这个情况，柜体侧板和柜门颜色不一样露出来非常难看。

▲如图柜体采用橡木指接板，柜门吸塑，完全两个不同的颜色，如果侧板露出来非常难看，需要做见光板处理
▲吊柜侧面露出的侧板需要做见光板处理，除非是一个材质
▲衣柜鞋柜侧面露出柜体板的都要做见光板处理，如上图，采用和柜门同样造型的板子做装饰，视觉要美观很多。

什么时候不用见光板？

▲衣柜镶嵌做了假墙处理的时候，柜体不外露，是不需要见光板的
▲同样橱柜是L型或者U型不外露侧板都可以不做见光板处理。
定制采用同一个材质同样也不需要见光板，例如柜体和柜门采用多层板。

为什么全屋定制有些不做见光板？一是业主嫌有费用，不愿意做，多半是业主不知情。第二就是重点，不给你说，明明需要做得更好，但是故意不说；说了这个是有费用的，总价高了无法竞争，所以索性不给你说，就把柜子做好就行，能赚一点是一点；这就是装修常用的低价切入。这种定制商充其量就是干活，压根没有什么设计可言。或者还有压根不知道要做，从来不思考，这样定制商就是外行，除了价格低以外一无是处。
