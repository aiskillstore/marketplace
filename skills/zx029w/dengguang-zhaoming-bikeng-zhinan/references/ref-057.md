# 为了家居采光，曾做过这些努力7.4

关于采光提升的案例非常多，大家可以自行搜索即可。

家居采光有时候比装修更重要，特别是有些暗厅户型，所以通常在装修的时候通过各种方法来解决采光或者提升采光，今天就列举一下都有哪些具体做法案例，大家可以参考一下。

01牺牲卧室提升客厅采光

▲老格局的房子，客厅居中，完全是暗厅，为了解决这个问题，直接把一间卧室牺牲拓展客餐厅，改变采光的不足；同时还改变了餐厅格局的方正，扩大了厨房空间
▲装修后的实景，打通卧室移位客厅，达到采光的最大化。《100㎡老房暗厅，改变采光，三室变两室黑白灰婚房》

02新开窗户提升客厅采光
《采光不好，新开个窗户就行4.28》

▲如图，为了满足客厅采光的提升，同时达到南北通透的居家环境，把卧室墙体新开窗户，来满足采光和通透的需求，这个也是花费最少，最直接的提升采光的方法。
▲装修后的实景，在卧室墙体新开窗户，来满足客厅的光线，同时达到南北通的通风效果《80㎡老房翻新，储物吧台分割空间，新开窗户提升采光》
▲如上图为了满足餐厅的采光需求，在卧室门口新开窗户，颜值长虹玻璃，不仅让光线通透，同时提升整体颜值《65㎡小两室，无客厅老房新装变清新之家》
▲移动卧室墙体满足餐厅空间，同时墙体新开窗户满足客餐厅的采光需求《90㎡二手学区房，三代人三房暗厅》
03打开干区提升采光

▲这个非常常见，因为干区的光线以及过道都不好，打开干区，或半截墙，或玻璃隔断，都能达到采光和空间开阔的效果，一举两得《干区做个半截墙，通透又有颜值》
04扩大门洞移门玻璃通透

▲如图，餐厅居中格局，采光不足，采用的方法是把厨卫原来的小门，都砸掉，做成了玻璃通透的移门，来提升餐厅的采光以及空间的通透
▲装修后的实景，原来厨卫的门都砸开做了玻璃通透，提升餐厅的光线，同时视觉更通透敞亮《百平三室，小夫妻黑白灰新房，在家办公》
05玻璃代替墙体通透

▲如图，为了拓展儿童房又不至于空间压抑，采用玻璃墙体代替传统墙体，来实现空间的拓展和采光的通透；同时厨房移门也采用通透玻璃来保证整体空间的采光和南北通透
▲装修后的实景，不仅拓展了儿童房成就了收纳，同时采用局部玻璃墙体来提升空间的采光，减少空间的压抑感，让整体空间通透明亮《120㎡三口三室现代家，玻璃房视觉更通透》
06玻璃分割卧室

▲如图不论是公寓房还是其他格局，完全可以砸掉墙体，采用玻璃分割的形式，来满足采光的需求，还可以让小空间视觉更通透；里头布帘遮挡就可以达到隐私需求《装修光线不好？那就做个玻璃房》
07开放厨房提升整体采光

▲如图户型，封闭厨房不仅让光线不好，而且餐厅位置很小，所以砸掉厨房，采用开放式厨房和餐厅一体的方式，不仅提升了采光，同时让空间更开阔
▲装修后的实景，打开厨房开放布局，岛台以及餐厅一体布局，不仅提升采光，而且空间整体开阔《120㎡三室旧房翻新，进门是厅，砸掉厨房开放布局，超级收纳》
▲为了厨房的采光，中厨西厨之间不装门，这样空间更通透，也能提升厨房的采光要求《85㎡两室二手房，增加中西厨和干湿分离，打造日式美宅》

▲如图原始户型封闭厨房，导致空间无餐厅且客厅压根没有任何采光，所有采用开放厨房布局，同时利用岛台隐藏抽拉餐桌，满足了餐厅位置，同时厨房的窗户给整体空间带来采光，光线和空间得到双提升《70㎡小两室暗厅，无餐厅，打造开放厨房，大气岛台，超有范！》
08砸掉多余墙体实现光线通透

▲如图原始户型厨房封闭门口光线无法满足，客厅阳台封闭，采光不足，也没有餐厅的空间；砸掉厨房墙体实现通透开放格局，砸掉阳台多余墙体实现客厅通透，同时餐厅安排到阳台光线最好的地方；最厉害的就是砸掉了卧室的承重墙，然后做了专业加固，实现了书籍的收纳

▲装修后的实景，整体空间豁然开朗，详情移步《50㎡一居室旧房改造，为翻新直接砸掉了承重墙》采光不好，新开个窗户就行
