# 谁分不清射灯和筒灯？？是你吗？那就赶紧看看9.22

什么是筒灯筒灯的发明就是为了和建筑物统一起来，不像吊灯或者吸顶灯那样看起来错乱。可以直接镶嵌在建筑物内部或者吊顶以及各种装饰物内部，其实就是为了美观而已，比如，你家过道装个吊灯层高太低，装个吸顶灯不太好看，那就装个筒灯，美观不占地方，不过筒灯一定要保持吊顶最少在15公分。看下图就是筒灯和射灯

什么是射灯主要是安装在吊顶四周或家具上部，或者置于墙内、墙裙或踢脚线里。用来突出审美作用，突出层次感、制造气氛，既可对整体照明起主导作用，又可以局部采光

下面用人话给大家通俗说一下筒灯和射灯的区别☺
筒灯就是主要是照明作用，也就是你在一个地方装筒灯和其他灯没有什么区别，最大区别就是筒灯可以隐藏而已。

射灯的主要目的就不是照明了，主要用来点缀，衬托某些物件，让你家更有层次感。比如把你的靓照挂在墙上，上面打上射灯，能把你照的美美的。比如大明宫卖瓷砖的，再烂的瓷砖打上射灯就可以高大上，比如服装店的衣服打上射灯都比实际靓丽。

筒灯好比是你穿的衣服，那是必须的，不穿就走光了；射灯好比你身上的装饰品，比如项链，手链，没有的你也照样能活。

注意，筒灯和射灯不止有暗装的，也有明装的，根据需要自己选，一般家里都是暗装的

↓一句话总结筒灯和射灯区别↓
筒灯是用来照明的
射灯是用来点缀的
