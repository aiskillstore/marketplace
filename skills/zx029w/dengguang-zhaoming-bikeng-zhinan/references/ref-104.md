# 你OUT了，装修没有主灯照样精彩6.20

关于客厅灯具以前谈过一次，大家可以直接点击参考阅读《小小一盏灯，那是客厅光芒四射的眼睛》《家有壁灯真美，下一套房一定用壁灯》

今天看一下那些没有主灯是怎么做到精彩的。

▲客厅区域，四周局部吊顶，中间留出间隔，然后中间平面吊顶，设置灯带在中间部位，中间部位四角各两盏筒灯照明，不安排主灯，整体看上去整洁好多

▲卧室空间，同样不设置主灯源，四周局部吊顶结合中间镂空灯带，中间部位四角安置筒灯即可

▲小户型客餐厅一体简约风格，全部使用平面吊顶，在四周靠墙位置点缀灯带，顶面客餐厅都不使用主光源，用筒灯根据功能布局点缀即可

▲白色素雅极简风格，餐客厅虽然分开布局，但是做法根据餐厅，客厅，过道统一做平面吊顶无造型，统一在吊顶的四周靠墙位置保留灯带，然后平面吊顶上面点缀筒灯做照明使用

▲客厅面积比较大，照样可以不做主灯；顶面田字格吊顶，对层高要求很高，保留每一个田字格的灯带，每一个田字格都有筒灯照明即可

▲没有主灯，四周吊顶设置中央空调，吊顶内部设置线条勾勒，中间四周布置筒灯，中间布置斗盏灯装置

▲没有主光源，平面吊顶点缀斗盏灯若干，在电视墙位置靠墙保留灯带装饰

▲平面做吊顶，进门口设置筒灯，靠电视墙整体设置灯带照明，其他用落地灯台灯进行辅助照明即可

▲客厅四周跌级吊顶，中间平面整体吊顶，弱化了中央空调吊顶的压抑，不设置主灯，统一布局筒灯以及沙发背景的灯带点缀

▲没有主灯，四周吊顶，中间平面吊顶，设置零星辅助灯照明，简单简约

▲超大户型照样只设置辅助光源，没有主灯，白色极简风格

▲不设置主光源，只用两排筒灯做照明，以及辅助光台灯壁灯等

▲暖色简约，不做主光源，平面吊顶，宽边石膏板压边，四周顶面设置筒灯照明

▲新中式风格，不设置主光源，平面吊顶，设置斗盏灯即可

▲小户型原木简约风，客厅不设置主灯光，全靠灯带和筒灯照明

▲白色极简风，顶面筒灯和斗盏灯配合照明

▲简约风，平面吊顶，设置斗盏灯和筒灯，只在电视墙靠墙设置灯带点缀

▲混搭风，只用辅助光照明，不设置主光源

▲美式风格，顶面平面吊顶，设置筒灯组合照明

▲新中式，平面整体吊顶，四周保留灯带位置，中间横向开槽设置玻璃装饰，装饰筒灯即可

▲简约风，客餐厅平面吊顶一体，设置筒灯照明

▲简约简洁，平面吊顶，四周宽边压线，设置射灯筒灯点缀装饰照明

▲新中式，客厅同样不设置主灯，四周保留灯带位置，中间四组筒灯照明即可

▲简约客厅，全部平吊，设置筒灯辅助光照明

▲简约时尚，不设置客厅主灯，全靠辅助光照明

▲不设置主灯，四周吊顶和中间木质平面吊顶，然后中间留灯槽设置筒灯或者斗盏灯即可

▲简约风简单吊顶，中间平面吊顶，设置筒灯照明

▲简约风，简单造型吊顶，中间平面吊顶，设置筒灯辅助光照明

▲美式混搭风，平面吊顶，四周宽边石膏板点缀，顶面筒灯排列组合辅助照明

▲简约暖色风，客厅局部吊顶，使用灯带，筒灯点缀，全部辅助光，没有主灯

▲个性小公寓装修，全部平面吊顶，使用辅助光照明

▲素色极简风，全部使用辅助光照明，灯带点缀

▲原木简约，不使用主灯，顶面平面吊顶，使用斗盏灯照明

▲北欧简约风，没有主灯安排，全部使用辅助光源照明
