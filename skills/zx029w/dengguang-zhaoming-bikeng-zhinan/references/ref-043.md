# 儿童房墙面变色，哪种更合适？11.17

儿童房装修除过基本的环保之外，就是墙面的颜色选择了，基于环保考虑，最好的办法就是乳胶漆变色，但是采用什么颜色往往是各有各的爱好。今天通过实景案例看看儿童房刷什么颜色更适合。

▲粉色系儿童房。此时墙面不宜太深的粉色，也可以直接采用白色即可，粉色的软配会又粉色的光线反射；如果需要颜色统一，可以采用极浅的粉色涂刷即可，如果墙面颜色加深就会导致粉色过满，产生压抑感
▲儿童房角落布局床铺，侧墙上下乳胶漆拼色，层次感更强，视觉更活泼，可以采用随意涂刷的形式让空间不那么呆板，色系保持整体色系的一致即可
▲男孩房统一采用木质的家具搭配，墙面部分主次全部灰色系涂刷，素雅干净，适合稍大的孩子居住，不需要过多艳丽色彩，更适合孩子的成长空间；背景最简单的绿色挂画以及壁灯搭配，简单又能温馨
▲冷色系儿童房空间，墙面统一灰色系涂刷，采用后期软配色彩搭配，好处是随着年龄的增长，可以通过软装来改变整体风格
▲蓝白搭配的清新；白色的衣柜以及上下铺布局，墙面采用淡淡的天空蓝涂刷，蓝白对比视觉更清新简洁
▲女孩房，粉色系，大面积白色家具搭配，粉色软配以及单椅点缀，墙面采用脏粉色涂刷，只是背景线条勾勒，清新挂画布局。
▲白色上下铺，大面积墙面采用豆沙绿涂刷，视觉会柔和自然，小空间更清新

▲绿色的黑板漆，为了打造绿意色系的儿童房，背景干脆采用墨绿色的黑板漆，放在儿童房可以当做黑板漆涂鸦使用，同时入住以后也好打理
▲灰色与草绿色上下层次搭配，视觉上有层次感，同时绿色的可以让空间更温馨舒适
▲男孩房蓝色的上下层次布局，床铺同样角落布局，侧墙作为背景蓝色搭配，其他大白墙涂刷，视觉同样清新干净
▲白色的家具搭配草绿色背景，上头灯带点缀，整体清新素雅干净，对于儿童房来说也能整体提升亮度
▲低饱和度颜色搭配，墙面背景采用淡灰色与粉色拼色，提升层次以及视觉亮度
▲千万不要给顶面变色。不论你用多么浅的颜色，都不要试图给顶面也刷上颜色，会让空间无法呼吸，有压迫感的，特别是对于正在成长中的儿童来说，心里的成长尤为重要
▲大白墙加创意拼色。如图大面积大白墙，背景采用半圆形创意拼色，刚好与上下铺衔接，非常契合空间感，同时低饱和度的粉色与蓝色，让空间更活泼清新
▲不同色块撞击，例如采用蓝色与亮黄局部撞色点缀，浓烈的颜色面积放小，否则有压抑感，可以让空间更活泼生动
▲墙面采用灰色与白色层次拼色，刚好与窗帘上下拼色呼应契合，完美提亮空间，增加空间童趣
▲浅紫色变色，比较清新浪漫，但是切忌大面积涂刷，这种浅紫色大面积涂刷有时候会有眩晕感
▲大面积大白墙，四周采用灰色的墙围涂刷，然后粉色腰带，视觉层次感强，同时还能拉伸层高。
▲脏粉色与黑色堪称绝配，脏粉色更适合女孩子的喜好，而黑色采用黑板漆刚好可以给孩子涂鸦的空间，两者对比层次分明，空间更有质感
▲大面积灰色，只在左侧墙面做半截墙的黑板漆，给两个孩子涂鸦使用，同时也能让小空间更有层次感
▲性格好动的男孩房，可以采用蓝色或者蓝灰色，宁静色可以让居室整体清凉安静下方收纳，上铺睡人，再小的房间也可以打造舒适儿童房
