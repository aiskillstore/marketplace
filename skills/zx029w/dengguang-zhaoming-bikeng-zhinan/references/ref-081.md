# 130㎡老房改造，格局大挪移，借光入室，满足三代人居住的简约日式

可能业主真的没有办法，此房型真的太不好了，北向几乎没有任何光线，进门就是厨房，而且购买的时候原房东作为群租房改造，至于格局是否能变化完全未知。业主购买也是因为为了孩子上学，同时家里老人同住，所以必须满足三代人的生活所需，平时白天最多的时候，就是老人独居。
