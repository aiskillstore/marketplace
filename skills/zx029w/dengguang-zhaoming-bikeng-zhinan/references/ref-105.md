# 家里的灯带、灯条，哪些地方可以做？4.27

无主灯的最大要点就是见光不见灯，所以灯带和灯条是最好的做法，能隐藏灯具的地方并不多，所以最好的无主灯其实就是不见灯，只见光。在家庭装修里头，哪些地方可以用灯带，今天看一下实例。
第一、客厅灯带

▲无主灯悬浮吊顶是常见做法，区别于过去侧装灯带，灯槽是朝下的，而且灯带是隐藏式的，见光不见灯，也避免了刺眼，实现了无主灯的灯光均匀。也是无主灯的常见做法，只不过造价过高，对于刚需户型不如把钱用来改变一下家具的档次，一个吸顶灯搞定

▲利用局部吊顶的下方满足下灯槽的设计，也是无主灯的最好做法，可以营造氛围感，同时满足见光不见灯的简洁

▲电视墙上方局部朝下的灯槽设计，暗藏灯带也是无主灯的最好做法，营造氛围也不会吃灰▲沙发墙上方局部下藏灯带的做法，也是常见营造无主灯的做法▲客厅背景利用壁龛满足灯条布局，营造氛围感▲客厅任何造型都可以隐藏灯带，营造氛围感第二、定制灯带营造氛围
