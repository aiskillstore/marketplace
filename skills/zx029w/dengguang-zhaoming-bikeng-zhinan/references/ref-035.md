# 干湿分离光线不好，几种办法解决1.11

干区指的是浴柜外置的做法，不是你做个淋浴隔断，那不是干湿分离，充其量就是保护马桶。为什么要做干湿分离？因为上厕所不排队，解决刚需问题，最最重要的是让牙刷牙杯远离马桶，做品质装修。
好了，这个问题说太多了，如果还有人认为牙刷牙杯和马桶放一块没有问题，那就没有问题吧。
第一、灯光解决。
采用灯光解决是因为干区没有自然光，格局限制同时也无法改造的做法，可以参考昨天的文章。《干区灯光功能第一，氛围次之》
第二、加大玻璃面，门联窗引光入室。

▲如图所示是常规干湿分离的做法，一般就是浴柜外置，浴柜与湿区新砌墙实现。此时如果干区光线不好，只能靠干区灯光以及湿区玻璃门引光入室。
▲打破常规做法，把原有砌墙面积减小，加大玻璃的面积，来满足更大面的引光入室，提升干区的白天采光▲如图所示，门联窗的形式，超白玻的喷砂+长虹的做法，既满足了隐私需求，同时引光入室的面更广，可以满足白天干区的自然光要求▲如图同样是采用门联窗的形式，满足干区引光入室的需求▲如图复古的金属门联窗搭配艺术玻璃，颜值也高，造价也高▲如图门联窗布局，满足采光面更大，可以让空间更通透▲如图门联窗布局，可以让空间更加通透，满足一定的采光需求▲如图白色的门联窗设计，满足空间的采光互通第三、干湿区彻底用玻璃门分割▲如图干湿分离空间小，彻底采用玻璃移门分割，增加采光面，一定要用外部长虹，内部喷砂玻璃两层布局，否则如图的两层长虹就没有隐私了；推拉门还有一个弊端就是密封性差一点，但是与浴柜之间没有卫生死角▲如图同样是地方小采用推拉门分割，满足光线以及视觉的通透▲如图所示干湿区域利用玻璃分割，满足采光和光线需求，对比推拉门，这种平开门的密封性要好很多，但是需要注意，左边是固定玻璃，浴柜定制需要留出距离，否则就有卫生死角。▲利用玻璃隔断实现三分离功能，平开门密封性也好一点，更节省地方。最重要的是这样做法，可以让湿区和干区光线互通，都可以借光入室▲如图推拉门分割干湿分区，同时借用大面积玻璃可以让干湿空间采光互通▲如图所示利用玻璃隔断平开门的做法，引光入室，利用湿区窗户满足干区的采光需求▲干湿区之间玻璃推拉门，与餐厅隔壁采用玻璃砖满足采光的引光入室▲如图干湿分离采用玻璃隔断布局，平开门空间更密闭，但是需要注意浴柜与固定玻璃之间需要留出打扫卫生的空间▲干湿区玻璃移门是空间不够的时候没有办法才做，同时移门的好处是与浴柜之间不会形成卫生死角，但是缺点就是不密封第四、镂空或者局部玻璃满足采光需求▲如图其实和门联窗类似，只不过是采用局部窗洞引光入室，满足光线的通透▲如图所示，利用隔壁卧室开局部窗洞，满足干区的自然采光需求▲利用干区墙体镂空断开的设计，让视觉空间更通透，采光更好▲如图利用干区朝外的墙体窗洞开启，满足视觉的通透，同时满足干区的采光需求▲如上图所示不论是镂空砌墙体还是干区做窗洞，都是为了借光入室第五、砸掉干区朝外墙体▲如图干区朝外不要墙体，同时满足采光以及浴柜的扩大▲不要干区朝外的墙体，同时放大空间以及满足采光需求▲干区与其他区域不要墙体，同时转变方向满足浴柜最大化定制，同时采光更通透▲砸掉干区墙体，扩大干区，让干区与公共区域互通，同时放大空间，提升采光需求▲砸掉干区墙体，让干区空间变大，浴柜变大，空间以及采光都变得通透▲砸掉干区朝外墙体，扩大浴柜的定制以及空间放大，让采光更加通透第六、半截墙与局部玻璃。▲干区半截墙保留，上方玻璃隔断，同时满足采光和视觉的通透▲既满足隐私需求，同时满足光线需求▲光线和空间的视觉更通透，同时半截墙保证与浴柜没有卫生死角▲半截墙+玻璃隔断满足采光和隐私，同时可以满足干区瓷砖的收口▲上图的做法坚决不要做，玻璃落地与浴柜之间会有一个完全没有办法清理的死角缝隙。▲如果浴柜空间小，可以不做半截墙，直接玻璃隔断落到石材上头，同样满足扩大浴柜的需求▲当然也可以利用半截墙，上方L型玻璃隔断布局，采用挂镜满足基本功能和采光▲如果干区靠近过道，不是面向公共区域，可以只做半截墙，不要玻璃隔断，这样视觉以及光线更加通透第七、利用干区对面玻璃门引光入室▲如图干区面向过道，砸掉墙体以后，过道另一边朝南书房砸掉墙体玻璃移门通透设计，这样同时满足过道以及干区的采光，同时空间改变原有的逼仄，变得更加通透▲如图干区在过道，砸掉朝外墙体，让干区与过道整体敞亮，同时朝南的书房玻璃移门布局，引光入室▲干区直对的南向书房，改造成了玻璃移门，引光入室，让过道和干区采光更加通透
