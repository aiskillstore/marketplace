# 收纳底层逻辑与 6 大收纳体系

> 内容均来自会员知识库「从学到装｜装修课堂【会员版】」之「📦家居收纳储物方法」专辑（152 篇原创）。

## 一、核心真相：真正的整洁不靠「收纳好物」，靠前期规划

- **收纳是家的骨架**。没有充足收纳，再豪华的装修入住半年也是仓库；装修的价值不是堆建材，而是把钱花在收纳和家具上。
- **柜子不是越多越好**。柜子做错了，空间塞满盒子，反而变成一堵压抑的墙。小户型乱打柜子，越住越挤。
- **收纳的本质是「藏」**。家里的问题往往不是面积小、不是收纳少，而是乱。东西整齐了，小房子也能清爽。
- **收纳 + 勤快，缺一不可**（去家务化前提）：空谈去家务化没用，第一要充足收纳，第二要人勤快。再多的收纳不愿意收拾，家里还是仓库。
- **入住 5 年才懂**：病急乱投医网购各种「收纳好物」，解决不了问题，反而把家堆成仓库。必须装修前规划。

## 二、6 大收纳体系（全屋必须满足）

大部分人装修收纳没有规划，只是看哪合适做定制就做了。其实至少满足 **6 大收纳体系**：

1. **玄关 / 门厅收纳**——进门不仅是放鞋，还要满足临时收纳、包包衣服、全身镜、次净衣。
2. **厨房收纳**——高柜、电器柜、抽屉、烟道柜、管道柜，是小厨房的最后一道防线。
3. **卫浴收纳**——镜柜延伸、马桶上方、干区高低柜、淋浴壁龛。
4. **衣柜 / 衣帽收纳**——独立衣帽间、床尾衣柜、L 型衣柜、床头前移衣帽间。
5. **阳台收纳**——洗衣柜兼顾收纳、改造衣帽间、定制收纳柜、矮墙书柜。
6. **餐厅收纳**——弥补厨房收纳不足，兼顾客厅电器与西厨功能。

> 只要满足这 6 大体系，收纳的基本功能就得到保障了。

## 三、装修 9 大区域收纳总览（掌握好了装修无遗憾）

| 区域 | 核心做法要点 |
|------|------|
| 门厅 | 利用左右可砸墙体镶嵌鞋柜；尽量通顶；无单独门厅则餐边柜/鞋柜隔断一体 |
| 餐厅 | 拐角砸墙镶嵌通顶餐边柜；太小用墙面隔板；可与鞋柜融合 |
| 客厅 | 电视墙满墙柜是最大收纳；沙发背景可做柜/隔板；拐角用拐角柜 |
| 卧室 | 床头背景做收纳柜；侧墙镶嵌衣柜；床对面做衣柜嵌电视 |
| 书房 | 榻榻米最大收纳；书房+衣帽间一间两用 |
| 阳台 | 侧墙通顶收纳柜；另一边洗衣柜+吊柜 |
| 厨房 | 推拉门墙体做酒柜；高柜嵌电器；烟机位做吊柜；吊柜做到顶；各种置物架 |
| 卫生间 | 定制浴柜；镜柜；镜柜延伸马桶上方；马桶上方收纳；包管壁龛；置物架 |
| 过道 | 牺牲墙体做储物柜，收纳+美观并存 |

## 四、装修前必须想清的 3 件事

1. **家里都有哪些物品要收纳**（见 02 篇 25 种物品清单）——每家生活习惯不同，盲目做柜子后期不适合自己反而更乱。
2. **每个区域用哪种柜型**（通顶/超薄/双面/高低/拐角/壁龛）——见各空间专篇。
3. **收纳是「藏」不是「堆」**——能封闭尽量封闭，外露杂物只会显乱。
