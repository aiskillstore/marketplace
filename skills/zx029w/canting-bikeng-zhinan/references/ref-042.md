# 不要餐桌，有什么办法满足就餐提高颜值？2.18

一般家里如果人少，而且空间小，或者说餐厅作为他用的话，完全可以不要餐桌，但是总得有个吃饭的地方。看看有什么办法实现。

▲如图布局，家里就两人入住，平时也不是经常做饭，直接做成半开放厨房，延伸岛台不仅增加了收纳空间，台面飘空，吧椅放上，就是一个简单的就餐区域，不占地而且提高颜值

▲即使入住人多，也可以实现岛台的延伸，完全代替餐桌功能，甚至还可以作为平时的办公空间，不论从颜值还是整体布局都高级多了

▲当然有人会担心开放式厨房的油烟问题，如图，可以在原有餐厅位置，打造西厨空间，岛台的定制完美实现就餐功能，同时增加了收纳，而且节省更多地方，空间颜值明显高级多了

▲半开放厨房，直接借用橱柜台面延伸出来一个岛台空间，实现就餐功能，而且视觉还有了延伸感，空间更大气

▲特别是小空间，压根没有餐厅空间的户型，打开厨房，采用橱柜的延伸，既作为岛台，又能兼顾就餐功能，一举两得

▲公寓户型，没有餐厅空间，直接打开厨房开放布局，延伸L型橱柜，既满足了收纳，同时满足了就餐功能，空间格局更加合理大气

▲刚需空间，打开厨房，不仅成就了进门右手的鞋柜收纳，同时延伸了橱柜空间，增加收纳，实现了简单的就餐区域

▲公寓户型，开放厨房，延伸岛台兼顾就餐和办公需求，空间更整洁，颜值更高
