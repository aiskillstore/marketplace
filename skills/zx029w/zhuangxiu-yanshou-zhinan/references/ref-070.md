# 买瓷砖小心故意少算，后期再加9.15

更多装修语音，查看小程序：用耳朵听装修

一般家庭如果选择半包，瓷砖就是自己购买。可是有几个客户自己亲自算过自己家的瓷砖数量？是不是拿着你家面积，买瓷砖的时候，完全相信瓷砖商家的计算？如果是，碰到后期瓷砖数量差很多，就不足为奇了。

用事实说话，举个简单例子，大家能更明白。比如一个卫生间墙面是30平方，你买的是300*600的瓷砖，计算方式30/0.18=166.6块。相信上过小学的都会计算。但是，这里的166块是纯面积，是没有加任何损耗的，你家户型不可能没有损耗，门窗洞边缘，风道，烟道，柱子，包括吊顶上头一周如果都是半块等，都会影响瓷砖的数量，所以如果估计的话至少要180块左右。

但是，你到商场买瓷砖，那么多商家，你肯定是转一家又一家，每家几乎都会给你列个清单和总价。这里就得注意了：商家为了和你达成协议，都会在你不知情的情况下，故意少算数量的。比如上头的180块瓷砖，给你只算到120块，你想一想，以此类推，其他区域的瓷砖也按照故意少算，你家要少算多少瓷砖？你家瓷砖总价要少多少？

为什么要这样做？因为你自己不懂行，因为你自己懒得计算，众多商家都想和你成交，就得有欺骗的手段，否则老实的商家就饿死了，没有办法，谁让泱泱大国遍地都是喜欢低价和爱占便宜的人呢？这个商家不欺骗，下一家就会欺骗就会成交。

于是，成交以后，在你施工过程中，瓦工就会告诉你赶紧补砖，数量出来，你会吓一跳：怎么能差这么多？难道是瓦工把瓷砖都拿走了，故意破坏了？有少部分业主一出现这种情况，就会把屎盆子先扣在瓦工或者装修公司身上。等自己数了瓷砖明白是真的少了以后，找瓷砖商家理论，商家会泰然自若：不好意思，当时疏忽，把面积看错了，少算了。好吧，你气愤也罢，什么都没有用了。瓷砖色号是独一无二的，你必须在原来的商家补砖，然后加上后补的瓷砖，加上运费，最后你会发现：其实这家瓷砖的总价比任何一家都高，原因是前期给你低价切入，你上了贼船以后，再慢慢宰你而已。

这就是购买瓷砖业主必须自己算瓷砖的原因。不要把人都想太坏，但是也不要什么都不操心，特别是装修，家是你自己住，你都不操心？那只能让别人宰你，只要你有钱，完全可以不在乎。

以上就是购买瓷砖的猫腻，希望以后业主自己购买瓷砖的时候，多走一步，自己先计算一下数量，哪家瓷砖商和你的数量越接近，说明越诚信，千万别自欺欺人看总价低了。

最后，送各位准备装修业主一句忠告：瓷砖商可以低价切入，装修公司亦然，你装修千万别无知的比较单价和总价了，数量和项目才是重点，否则装修低价更加可怕《装修房子，被低价钓鱼害惨了！》
