# ✅ 原创|业主必看，千万不能这样买瓷砖！！！

装修☞千万不能这样买瓷砖
作者： 陈工 忆雪

好多业主相信一分价钱一分货，也相信所谓的自己道听途说或者被媒体吹嘘的大品牌。比如买瓷砖，业主是想尽办法找各种买瓷砖的技巧，然后死搬硬套用这些技巧周旋于各大建材卖场。殊不知道这些各种购买瓷砖窍门根本都用不上，自己辛苦看来的只不过是商家自己发出来的自欺欺人的营销手段而已。而业主在卖场所做的一切都是徒劳。

相信准备装修的业主对各大卖场都很熟悉，本地的举例如，大明宫或者红星美凯龙，各大店面装饰豪华堪比宫殿，业主只要进去大部分看的已经不是什么实惠和质量了，自己的虚荣心已经输给了人家的店面装饰。店面的各种炫目灯光和奢华装修让自己已经对质量的追究大打折扣。心里肯定认为如此店面怎么可能有质量不好的砖。这个道理很简单，今年各个楼盘老总跑路，哪一家售楼部不是装修豪华的？

道理其实很简单，只是业主作为外行不懂瓷砖的运作模式而已。业主往往会各大卖场瓷砖展区左看右看，掂量分量，甚至摆在地上看平整度，更有甚者不知道在哪看的方法，滴水试验，其实如果你明白了其中隐藏的猫腻会对自己的行为感觉可笑的。

所谓样品砖，何为样品，肯定是没有一点毛病的，任何做建材生意的人都不会把有毛病的产品摆出来让你看，让你挑毛病。何况还给你照着那么亮的灯光，可是你不明白，你还是在样品砖里头看质量。你根本不知道这些砖都是专家千挑万选出来的，外行能挑出毛病？不论你用任何方法这些砖都会满意的，最终你会交钱订货。但是最最残酷的是你费了半天神看的砖和你家铺的砖没有半毛钱关系，这才是业主需要警惕的。你定的砖只是样品而已，只是这个颜色而已，可是你家的砖那是要从库房提出来，然后送到你家的，而且送砖的商家绝对不会打开包装给你验货的，也就是颜色款式能对上就行。所以基本你要的牌子是对的，颜色款式也基本是对的，但是很有可能不是一批次的货，有没有毛病只有天知道。而你前面在人家店面挑来挑去的行为都是徒劳的，没有任何意义的。

所以作为准备装修要买砖的业主，以后不要在金碧辉煌的大卖场，用各种各样的办法看砖的质量了，你看了也白看，你看的不是你家的砖，而是你家砖的样子，送到你家的砖都不知道是哪一窑烧出来的，所以你看砖只看颜色和款式，质量你真决定不了。
