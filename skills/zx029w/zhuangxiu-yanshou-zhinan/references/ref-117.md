# 地暖打压，一定记着装个压力表10.22

今天主要给北方业主说的，一般新房收房，办完手续，需要验房。一般验房当天因为人太多，没法一家一家排队给地暖打压，所以都需要验完房子以后，预约打压时间，然后进行地暖的验收。

像物业打压为了速度一般都是采用气泵打压，一般为7-8个压力，时间在10-15分钟，只要气压表指针不下降，就表示地暖是合格的。
但是好多人忽视了一个问题，现在打压合格，不代表你装修进场不会破坏，怎么能保证装修过程可以随时注意到地暖的好坏呢？
这就需要安装一个压力表，一般小区物业打压都会有个压力表，但是这个只是给你打压用的，打压完毕就卸走了。所以在物业打压的时候，多个心眼，掏点钱，让打压人员把压力表给你留着即可。价格一般二三十都行，有的要五十也行，别嫌贵，嫌贵你自己买表回来自己装吧。
或者在打压之前问一下物业，这个压力表只是用来打压，还是给业主留着，如果只是用来打压，你提前买一个压力表备着，记着需要有配件，否则有的安装不上，这个问五金店的人员都懂；这样打压的时候，你让师傅装上你的表即可，就不要卸了。
地暖合格以后，关闭阀门，始终让地暖管子处于保压状态，然后装修施工进场，隔上一个礼拜，你打开阀门看看每一路地暖管子压力是否正常，不正常的话及时可以维修，不要等装修完了发现有问题就迟了。
这也是安装压力表的好处，时刻可以知道地暖管子是否因为装修过程破坏了，否则盲目装修，完了发现地暖管子有问题，那时候再次砸掉地面费力费时成本就很大了，甚至出现已经没有同色的木地板或者瓷砖，成本更大了。地暖和水电，谁先做？
