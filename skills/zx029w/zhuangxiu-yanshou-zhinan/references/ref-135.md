# 阳台放洗衣机，客厅瓷砖能通铺吗？9.18

首先搞清楚，客厅地砖通铺到阳台的样子，看下图：

▲上图就是客厅地砖通铺到阳台的样子。好处是显而易见，视觉上客厅看起来很大。但是上图阳台没有洗衣机，没有下水，通铺地砖没有任何后顾之忧。所以，就可以这样说，如果阳台放置洗衣机最好用过门石分割，不要通铺。

具体看看，阳台如果放置洗衣机，大地砖是否能通铺。

第一种情况，不通铺，做过门石或者有门。阳台放置洗衣机，有下水，用过门石分割客厅和阳台，此处一定注意防水是必须做的，但是谨记防水一定要做对，参看前面这篇《阳台防水怎么做？或许以前装修都做错了！7.23》

▲上图阳台放置洗衣机，过门石/阳台门分割空间。阳台地面低于客厅地面，这样做的好处是：

一，如果洗衣机在排水过程有溢水发生，阳台有防水，又有过门石阻挡，水不会漫到客厅，从而避免损失。

二，洗衣机上水管万一爆管，水不会漫到客厅，这是阳台做了防水和过门石的两大好处。

上面两个好处能满足的条件是，洗衣机是地漏，而不是竖管。

如果你家阳台放置洗衣机和洗手盆，用的是共同一个竖管，那阳台防水做不做也没有任何意义，真正的做法应该是阳台保持一个竖管和一个地漏。竖管是为了洗衣机和洗手盆共同排水用。地漏是为了防止爆管水能顺地面排出用。参考前面文章《阳台放置洗衣机和洗衣池，这些得明白4.7》

第二种情况，放置洗衣机，不做过门石，照样通铺。

▲上图阳台放置洗衣机，瓷砖通铺，这样做冒一定风险，如果入住时间久了，再好的水件都会出问题，人不在的时候，就会水漫金山。所以显而易见，这样做是不合理的。

总结：阳台如果有洗手盆和洗衣机，最好过门石分割，不要通铺大地砖。
