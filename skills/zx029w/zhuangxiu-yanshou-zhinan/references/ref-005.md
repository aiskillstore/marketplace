# 收房验房有必要请验房师吗？重点看什么？

先说结论：验房师没必要掏钱请，收房也没那么玄乎。 收房其实是一个简单的事情，并没有什么专业性知识。

请验房师有用吗？两字：没用。 掏钱请个专业验房师，拿着各种验房仪器，一通乱测，这个不合格，那个不合格，行为完全属于正常。但是这些在收房以后你反映给开发商以后，就知道这些花里胡哨的仪器测量，充其量是一种滑稽的表演而已，两字：没用！否则如果你的仪器要过关，全中国的房子都得拆掉重盖了。开发商不屌你而已。

更划算的做法： 好多人要不是掏钱请人收房，要不就是参加各种免费的活动。其实大可不必，在快交房的前一段时间去各大装修公司看看，确定装修公司可以免费量房做预算，这样在收房的时候确定让哪一家直接过来量房顺便就可以帮你验房了。免费量房兼验房，一举两得。

重点看什么，按顺序来。 首先看房子的现实户型是否和你合同上有出入，比如朝向，窗户位置，窗户大小，平窗还是飘窗；门的位置大小，阳台的位置大小，从大的方面确定房子是否与合同户型一致。如果不一致就可以直接和开发商交接，就没有收房的必要了。

大的方面一致，接下来从入户门看起，入户门多开启关闭几下，看是否结实，站在门外门内看一下入户门以及门框是否平整。然后把家里所有窗户看一遍，看玻璃是否完好，看密封是否完好，把各个窗户都试一下，看是否开闭顺畅。

电路一定要作为重点试。 开启配电箱所有的开关，一般开发商在验房的时候会有5-10度的电，打开所有灯看电路是否正常，最好能带一个手机充电器试试每一个插座是否通电。电路非常重要，如果不试有可能你家没有布线，当你签字认可时就迟了。再一个很重要，一般交房的时候开发商难免晚上忘记锁门，会有人在晚上去新房偷盗电线，你家运气不好被偷盗，但是看不出来的，所以必须把电路作为重点试一下。

这些都可以忽略。 房子下水是没有办法看的，因为一般验房的时候整栋楼是不通水的，装修的时候自然知道通与不通。开发商防水可以忽略，看也白看，装修的时候都会不同程度的破坏的，毛坯房验收防水不需要看。墙面表皮裂缝也不是问题，你让开发商处理的话，人家随便用刷子水泥刷一下就盖住了。

但这些必须较真。 门窗破损倾斜无法开启，这个才是重点，必须让开发商维修到正常，开发商不会推辞的。墙体倾斜幅度在两三公分，必须较真，因为后期装修处理会产生费用，让开发商处理免费。下水管路漏水，用手触摸下水管接口四周，有水印或者水汽及漏水，就要较真。

记住一句话： 后期装修能解决的你都可以忽略，要较真，你唯一的路就是退房。收房的时候带上装修公司免费量房，重点试电路，门窗看结实，户型对合同，其他睁只眼闭只眼。
