# 烟机与吊柜有缝隙太难看，一招解决12.1

为了厨房视觉更好看，成就更多收纳，更多人选择了镶嵌隐藏烟机的做法。

▲如图所示，镶嵌烟机可以让吊柜更完整，收纳更多，视觉上也更美观
▲镶嵌并不是一无是处，最起码内部空间可以利用起来放一些厨房杂物，让收纳更多一点
▲然而实际上隐藏烟机就会出现上图的问题，烟机安装完毕会和吊柜有个难看的缝隙，这个还算小的，有时候可以忍受，有的缝隙更大更难看
▲如果说小的缝隙无伤大雅可以忍受，上图的缝隙你能忍受吗？显然无对比无伤害，你没有见过好的，当然不知道这个其实是做错了。
为什么会出现这种情况？第一、定制商做定制不管吊顶位置和烟机高度；一般厨房定制需要和吊顶协调，上方需要与吊顶保证严丝合缝，但是上头保证严丝合缝了，你家吊柜只收了你60公分高的钱，当初为了价格低签订的合同，此时就会入坑。当这个高度的吊柜安装完毕，没有装烟机的时候，看起来很好，很美观，但是完全忽视了烟机的高度标准，导致后期安装烟机只能与吊柜有很大的缝隙。吊柜做小了而已，这也是大部分全包装修里头最容易入坑的地方，你以为总价低签订的合同，此时后悔也没用了，要不重新做，要不忍受这个缝隙。
第二、注意了吊柜高低和烟机高度，但是业主不懂，安装烟机不负责任，也会出现这种情况；
▲如图随便找一款烟机的安装图纸，注意红圈里头的高低数字，这个数字没有固定的，而是有一个区间，只要定制商完全按照这个区间保留数据，都是合理正确的，但是后面安装烟机的工人为了自己好干活，业主不懂也没有交代清楚，就会导致这个高度工人随意掌握，谁都没有错，只能留出难看的缝隙了。
▲有人肯定能发现问题，即使你告诉烟机安装工人挨着吊柜安装，最后安装完毕发现，还是有一个很小的缝隙，不能严丝合缝，因为上头吊柜是固定的，烟机需要有挂件固定。
▲当吊柜安装好以后，挂件安装必须预留烟机能挂上的空间，就会导致烟机挂上去会有一个下降挂上的空间，所以会有一个很小的缝隙，能达到这个标准已经够好了，也无伤大雅，只要缝隙不是很宽就行。
怎么能让烟机与吊柜缝隙足够小，足够美观？
▲当注意上图红圈位置，在定制烟机镶嵌吊柜的时候，把烟机位置吊柜柜体缩小两公分左右，然后柜门不缩，在烟机未安装之前这两扇柜门不装，然后烟机根据预留的空间以及柜门高低安装，这样即使烟机挂上去有一个下降的空间，关上门以后刚好严丝合缝，这是烟机与吊柜看上去严丝合缝最完美的办法，而且后期更换烟机也方便拆卸。
有人肯定考虑了另一个办法，就是先装烟机然后装吊柜。其实现实里头这种做法大有人在，风险更大，一是烟机安装以后，位置控制很难，一旦出错要不吊柜报废，要不烟机二次拆卸重新安装；第二烟机安装好了吊柜再次施工，一旦磕碰得不偿失，定制商也担不起这个责任。而且即使先装烟机，固定空间去安装吊柜难度更大。正确的做法是吊柜安装完毕，下方直接根据吊柜预留空间保证严丝合缝即可，因为烟机位置吊柜柜体上缩的话，空间足够了。
