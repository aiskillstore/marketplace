# 水电盲目做，洗衣机压地漏返工难10.6

关于洗衣机以及洗衣机水电怎么走，以前谈了很多，大家可以后台回复“洗衣机”看相关专题。

一、洗衣机的放置位置大部分人还是考虑生活阳台，不占地，晾衣服方便。同时最流行的就是洗手池镶嵌洗衣机，上方吊柜储物，没有比这个更实惠的做法了。如下图：

▲好看美观，而且时尚，再找不到比这个更适合的做法了。

这样做就得提前规划水电，下水位置一定是在洗手盆下方，而不是洗衣机下面，有好多业主不懂规划，找的装修机构也是摸石头过河没有经验，导致装修完了，才发现地漏放在了洗衣机下方，后期洗衣机放了以后无法使用下水。这种镶嵌式的高低都是固定的，是无法抬高地面的，如果地漏做到了洗衣机下方，只能砸掉重做，或者舍弃镶嵌式做法，改用过去的很丑的做法，比如下图：

▲像上图这个做法，不仅不好看，而且很浪费空间。如果像上图这样地漏放到了洗衣机下方，不是问题，你完全可以把柜子与洗衣机调换位置解决，或者舍弃柜子，只放个洗衣机就可以搞定。

▲地漏做到了洗衣机下面，除了更换地方，加个洗衣机专用架子也有搞定，如上图。还有一种解决办法：舍弃洗衣机下方的地漏，从洗手盆下方打眼通向洗手池下方，与洗手池共用竖管下水，但是前提是有足够空间这样做。

需要注意的是，阳台放置洗衣机，下水一定是竖管，而不是地漏，地漏是备用，为了防止生活中爆管出现预留的。洗衣机和洗手池共用竖管下水，这样不会溢水，地漏只作为备用预留，洗衣机最好不用地漏，会溢水的。

二、卫生间放洗衣机如果压住地漏，怎么办？这里分为两种情况，一种是干区放洗衣机，如下图：

▲干区放洗衣机和阳台是一样，一旦出错只能砸掉重新做，几乎没有整改的余地。因为干区一般都是浴柜镶嵌洗衣机，位置几乎是做水电的时候做好的。没有用洗衣机架子的可能，能做要不就是打眼通向洗手盆下方共用竖管下水，把压在洗衣机下方的地漏作为备用就行，防止爆管。

▲卫生间湿区放洗衣机，也没有镶嵌浴柜，地漏压在洗衣机下方就可以用洗衣机架子解决，或者移动位置都是可以的。在湿区放洗衣机为了节省地方，可以直接用地漏下水，因为有坡度，溢水也在卫生间，好打理。如果有空间尽量用竖管

三，洗衣机厨房放置，一般两种情况，一种就是原始房子就没有地漏，共用水槽下水，切记买上排水洗衣机就行。另一种就是原始户型有地漏，但是做的时候洗衣机压到地漏上了，切记，此时没有后悔的余地，洗衣机无法使用。解决办法只能是重新改变橱柜格局，移动洗衣机位置，或者改变地漏位置，但是瓷砖已经铺贴，地漏位置无法移动，只能是改变橱柜格局，洗衣机位置如果无法移动，最终只能砸掉瓷砖重新设置地漏了。造成大量浪费。

总结：家里放洗衣机，不论你放在哪，首先水电这一关必须仔细审查，做完水电，先看做好的水电路是否符合后面的实际需求，不要等到后期安装才发现错误，特别是有防水的地方，后期发现错误都无法整改。一定谨记。装修并不是一帮泥腿子干活，从头至尾是需要经验支撑，并不是你们所说的刷墙铺地那么简单。
