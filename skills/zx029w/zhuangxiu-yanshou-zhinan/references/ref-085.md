# 水电验收不用愁！对照这10个“硬指标”，小白也能轻松避坑

装修水电改造是隐蔽工程，是重中之重，牵扯到后期的功能和使用安全。一旦验收不到位，后期造成功能缺失或者断电漏水，返工还会破坏已做好的硬装，影响正常生活，得不偿失！今天就把装修水电10个验收点一次性说清楚，都是实操干货，每一项都不能漏，确保水电安全以及放心入住。01｜对照交底标记验收是否做到位。
水电交底是干什么？水电交底就是根据装修方案的水电功能规划，现场在每一处需要改造的地方做好标记，方便水电工施工，同时业主与所有施工方都能知悉。水电交底都有哪些人员参加？1.装修机构设计师、2.工地管理人员、3.水电工、4.业主、5.全屋定制商家、6.全屋净水商家，7.全屋智能商家。（6-7一般刚需装修没有）装修方案确定才能签订合同以及确定交底时间，现场做标记，便于水电工施工，同时也便于加深业主的印象。第一步根据标记位置看是否都做到位。这就是水电验收第一步：标记与实际做法相符。现场标记第二个功能：标记完成，水电工根据标记位置，现场估价，然后谈实际出入『装修第一步水电，有多少人估价谈实际出入？』
对于北方装修来说，这一点非常重要，在签订合同的前就得知悉『水电施工不签到合同里，留个后路也行』02｜水电材料进场验收。以西安地区为例电线多用津成，水管日丰冷热管共用热水管。需要注意所有水电料品牌型号是否与合同约定一致。电线需要看品牌认证以及生产日期，真假辨认；水路只要看对品牌以及规格，其他无需多看，因为厂家会上门替你验收质量问题。『水电、防水随便买，花钱走弯路』03｜对照方案图纸看点位是否有遗漏。即使现场标记与实际施工一样，也需要在验收的时候，回头看方案图纸，看是否有遗漏，在没有进行下一步施工之前都可以弥补。04｜按照功能区对照线径是否相符。每家都不一样，需要对照装修方案以及交底具体标记。北方刚需房一般线径回路搭配：需要注意：北方一般开发商回路已经做好，大部分线径都按照常规布局做好，无需改造。具体线径需要根据家庭电器多少以及功率详细计算，每一家都不一样。普通家庭网线少量改造最低六类网线足够，当然如果有条件光纤直接做更好。电线采用BV硬线，更适合暗埋走线。05｜验收开槽工艺。墙面长距离必须是竖槽，严禁长距离横槽。这个在装修谈方案的时候做法就得知悉，验收只是看是否按照国标工艺执行。水电走地严禁长距离开槽，除非有特殊需求，局部小的地方凿低处理。06｜验收水电路走向工艺。北方水电走向推荐横平竖直，验收的时候看是否按照前期沟通走向做法。北方厨卫不是特殊情况遵循水走地电走顶原则，看实际协商做法验收。07｜水路细节验收水管每60-80cm管卡固定，防止水管移位，接头松动爆裂。花洒冷热水间距15cm，水平标准，间距标准，严格左热右冷原则。检查总水阀是否安装到位，是否便于以后全房回路每个区域独立维修。北方水电走地必须留出间距，后期方便水泥砂浆填充，避免瓷砖空鼓。水管热熔处理“双眼皮”标准，合格的“双眼皮”应该是：大小适中、均匀饱满、表面光滑、两眼之间无缝隙。 它不仅是为了好看，更是肉眼可见的“质量合格标记”。PPR水管分冷热，实际使用都用热水管，而不用冷水管；热水管比冷水管质量更过关，后期也不用刻意分开，容易出错。水管大弧弯处理，标配做法，减少水流阻力，流水更顺畅。实际水路过程中，会采用过桥四通代替普通过桥弯，目的是降低高度，不影响后期瓷砖铺贴，不是错误做法，而是更好的工艺代替。水路走顶保温棉处理，防止后期有冷凝水产生。08｜电路细节验收底盒线管必须用锁扣连接，通常是一个塑料小套子，一端连接线管，一端卡在底盒上。工人偷懒不装，导致线管脱落，电线绝缘层被底盒锋利边缘割破。普通家庭插座线路一根16线管不能多于3根线，过多后期不好更换还容易造成挤压变形，甚至短路。电路施工灯线做弹簧弯处理，把电线盘起来打个弯，是怕电线以后被拽断或者自己断掉，留够余量防止拽断。验收检查所有灯位居中，避免后期返工整改。电视墙预埋50管并不是必须，需要根据自家的功能选择『电视墙插座高度装修前不规划，就来不及了』09｜下水细节验收厨房放下水如果带存水弯一定要改成直排下水，否则后期使用下水慢而且容易堵塞。水电验收，下水排水测试，防止堵塞或者流水不畅。除过洗澡位置是地漏以及卫生间备用下水地漏，家里其他下水都是竖管下水，而不是地漏。『下水竖管和地漏，都用在什么地方？』010｜打压测试，拍照留底不论你是找装修机构还是自己装修，水路厂家都会上门免费打压，合格会有一个质保卡，也可以在官网查到自己的照片和售后时间。水电结束最后一步，拍照留底，方便日后正常检查和售后维修。总结：以上10点主要是针对北方水电做法，而且每一家装修理念不一样，验收标准也不完全是标准，需要根据自家方案进行合理验收。💬 你有遇到过哪些水电验收的“奇葩事”？欢迎在评论区留言！
