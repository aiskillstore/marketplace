# 百平三室刚需，12万全包装修竣工

属于刚需房，未来作为婚房使用。房型本身不大，所以满足基本的功能即可。业主也没有太多风格上的预想，干净整洁，满足生活的收纳即可。除过家具家电，包含所有全屋定制，总造价12万。此户型与以前的雅居乐户型非常类似，大家可以参考一下《98㎡三室北欧，美女一个人搞定装修，少吊顶，无石膏线》

▲完工实景拍摄，大家可以点击查看
▲原始图纸，很常见的纯南三室户型，入户是公共客餐厅一直到阳台，因为高层，光线还好；左手是厨房；客餐厅的左边是三个卧室，两个分别朝南，一间作为主卧，一间作为以后儿童房备用；

厨房隔壁是卫生间，但是没有干湿分离，所以这个是必须能改造尽量改造，一是为了以后人多的时候不至于排队，第二重要的是健康问题；
▲第一稿方案，其实这种进门是厅的户型，想要更多收纳，调换电视墙与沙发的位置，真的可以成就超级收纳；餐厅与客厅共用墙体统一定制收纳柜，满墙柜可以满足几乎所有收纳；餐厅采用卡座形式，电视直接镶嵌，甚至上头可以满足投影，而且视觉上并不会压抑，相反，采用平板无把手收纳柜设计的话，更能拉伸空间感
但是，业主考虑到后期定制成本，所以此方案没有采用
▲这是最终的方案图纸，进门餐边柜兼顾鞋柜；传统沙发布局，原有短墙作为电视墙使用，只不过电视墙采用了满墙电视柜的做法，用来满足收纳，同时定制的成本能低一点
卫生间新砌墙实现了干湿分离，马桶做了短距离轻微移位处理；
▲入门视角，没有单独门厅，开门右边餐厅，左边厨房；无法满足鞋柜的布局，只能采用鞋柜与餐边柜一体的形式，满足进门的基本收纳；局部吊顶结合宽边既满足定制要求，又不会让视觉上看上去压抑
▲厨房因为朝北窗户，光线本身不是很好，所以保留了双扇移门，让视觉更通透；黑白灰的干净配色，简单也实用
▲门口看全景，纯南户型，彻底与阳台打通，柔光灰色砖通铺到底；不仅可以拉伸视觉，而且好打理，不会影响光线，同时整体质感上更有内涵
▲客厅全景，电视墙新砌墙实现镶嵌满墙柜，满足电视镶嵌，同时满足公共区域的收纳；统一灰色的墙面变色，窗帘去掉客厅的做法，预留了窗帘盒位置，因为业主怕自己接受不了窗帘在阳台，后期可以客厅弥补
▲局部吊顶和新砌墙实现定制的镶嵌处理，弱化收纳柜的压抑感，采用平板无把手设计，白色与木色清新套色，后期刚好满足电视的镶嵌悬挂
▲阳台看全景空间，通铺柔光瓷砖，非常有质感，防滑耐脏；清爽干净的搭配小空间也不会显得压抑
▲阳台只有一个夹角空间满足洗衣机的镶嵌；这里和业主是有分歧的，我们主张不贴砖不要哑口套，管道采用定制柜直接包裹，但是业主还是接受不了，只能按照业主的意思去满足了。瓷砖和哑口套浪费了，而且红砖包管道太占地方，上方虽然有吊柜，以后拿取东西不踩凳子压根够不着
▲其实阳台我们的最初方案是这样设计的，但是业主接受不了，所以只能按照业主意思去做了
▲阳台全景，一边洗衣机，一边收纳高柜兼顾家里的清洁柜，上方电动晾衣架满足晾衣，采用局部吊顶以及窗帘盒满足颜值
▲进入卧室的过道空间，因为没有软配进场，所以看起来非常干净。简单平面吊顶搭配暗藏筒灯照明；白色木门与踢脚线与灰色既有层次，而且不会让视觉厚重
▲过道看客厅空间，左手与主卧隔壁的是儿童房，因为目前压根无法规划，所以目前空置状态
▲主卧全部乳胶漆，背景清新蓝变色，其他淡灰色涂刷；不要吊顶，不要石膏线，让小空间更简单干净，后期任意添加软配也不会让空间看起来厚重
▲衣柜是原有凹陷区，刚好满足镶嵌定制，满足基本衣物收纳
▲主卧对面的次卧空间稍小，而且北向窗外是连廊，光线不是很好，所以墙面浅色变色满足光线需求
▲次卧衣柜和主卧一样，利用原有凹陷区刚好镶嵌定制，满足基本的收纳需求
▲厨房全景，地面是客厅柔光瓷砖通铺进来，耐脏而且防滑，视觉上还能放大空间；墙面采用仿石材浅色瓷砖铺贴，地柜藏蓝色，吊柜白色，干净有层次
▲厨房右侧刚好容纳冰箱的放置，而且冰箱颜色与地柜相似，统一颜色让整体不凌乱更舒适
▲原有卫生间缩小以后实现了干湿分离，干区白色定制浴柜，镜柜满足收纳
▲干区背景利用灰白花砖提升层次感，上下灯条满足照明以及营造氛围；
▲湿区统一灰色柔光瓷砖铺贴，搭配了大白的增压黑色花洒，简单实用为主

▲卫生间防水的实景，这是标配做法，而非上翻30公分的错误做法《卫生间防水全做错了，被坑还感激人家呢》
