# 中央软水、净水，反渗透or膜，直饮机，管线机，末端净水器，你家需要多少？5.8

关于水质和地域有关，和广大的民生管理者的良心有关，毕竟在遍地事不关己高高挂起的文化熏陶下，防患于未然才是正道。

所以，在每一家装修之际都会面临净水问题，但是面对林林总总的净水设备，大部分人不知道如何选择。所以今天看看这些设备的用途，大家借鉴一下。

第一、150平以下的户型都叫做刚需，一个末端净水搞定一切。

▲如图每家水槽下方必备的净水器，一般分为超过滤和反渗透两种。
超过滤和反渗透净水器的区别：通俗点讲好比筛子，超过滤筛子孔大，反渗透筛子孔小，过滤精度反渗透要高很多。
超过滤对于水质相对好的地区完全够用，可以过滤掉水中的杂质、细菌，家用直接烧开水饮用或者做饭都是没有问题的。
反渗透一般用于水质较差的地区，过滤效果要比超过滤好多了，因为其过滤精度太高，随之过滤掉的也有人体需求各种微量元素；因为其过滤精度高必须采用电源采用加压出水；同样因为其净化能力高，必须产生废水，需要有排水的下水口，一般和水槽共用即可；而超过滤一般不需要电源，靠水的自身压力即可出水，同时也无需废水排放。
至于反渗透的是纯水，没有了微量元素；而超过滤过滤不干净不如反渗透，目前是没有科学依据证明两者到底谁更好，所以大家需要根据当地的水质决定购买；水质差买反渗透，水质好超过滤就行；或者水槽下方忘记留电源的，直接买个超过滤即可。
不论是反渗透还是超过滤千万别信直接可以饮用，一定记着烧开水饮用。
第二、管线机是无胆加热的烧水器而已。
▲管线机是什么东西？其实就是一个无胆的烧水器而已。用来直接接家里末端净水的水，采用电力直接加热，快速喝到热水的电器设备；例如从你家水槽下方的超过滤或者反渗透净水机接软管到管线机，回家打开管线机电源，极短时间就可以喝上热水
管线机一般放在什么地方？没有限制，一般管线机最大距离在10米范围，超过这个范围，净水器供水不足；所以可以放厨房，多数可以放在餐边柜，平时方便饮用热水。需要在装修之初水电之前规划好，提前预埋PPR水管，穿进专用的管线机软管以及预埋电源。
▲如图提前预埋了PPR水管，里头穿管线机专用的软管即可，旁边预留电源即可。至于后期一旦出问题是否能更换，这个取决于距离，如果距离短，后期可以抽动是可以随时更换，如果距离太长而且好多弯头，是无法更换的，所以这一点一定考虑清楚。
三、直饮机就是净水器和管线机的结合体，或者说给超过滤或者反渗透净水器加一个加热装置，省掉了管线机的单独加热而已。
▲看上图就一目了然了。和管线机不同之处就是自身带了过滤装置，烧热即可饮用。购买一定注意：此类直饮机一般都是超过滤效果，烧热即可饮用；如果是反渗透必须排除废水，否则压根不可能是反渗透，那些过滤掉的污渍小小的过滤器能用几天？其实就和你用末端超过滤净水以后自己烧一样的，只不过省去了烧水的麻烦，这机器一次性给你搞定，和超过滤净水一个道理，也得定期更换滤芯的。
第四、中央净水、软水。150平以上或者豪宅可以考虑。
▲中央软水和净水一般是两套设备，供不同家用空间使用，非常占地方，现在好多都是软净水一体机，比较节省空间。但是体积也相当大，必须在全房进水口前端位置有足够的空间放置，而且必须有下水才行。▲如图所示这就是软净水的功能，可以让家里洗衣冲马桶、洗澡用上软水。什么是软水？相对于硬水来说，通俗就是没有水垢，可以保护家里的各种涉水设备，例如保护热水器的零部件等；洗澡可以美容据说，当然天生丽质才行，否则也没用。
净水的作用也好理解，可以直接接到厨房，家里洗菜洗碗，或者接到洗碗机用也行，但其实所有洗碗机都有软水功能，不用单独接这个软水；
说通俗一点就是一个大型的超过滤净水装置，把每家每户水槽下方的末端净水器放大功率，过滤更大水量，供全房使用而已；
中央软水处理的水是无法饮用的，只能用到洗碗机、洗衣机、洗澡、洗菜都行；饮用标准连个普通超过滤都不如；
中央净水器出来的水也是无法饮用的，必须经过超过滤或者反渗透净水器加热才能饮用；
通俗讲中央水处理（软水、净水）只是为了提高生活品质，视你家经济情况决定，唯一的好处就是出来的水比自来水软，比自来水干净而已；做不做，一看财力，二看空间是否允许。
中央水处理前端还需要前置过滤器吗？说实话，就普通高层如果水压本身就不行，不要说中央处理器了，一个前置都会导致你家燃气热水器无法启动。影响水压是必然的常识问题。
为什么别墅都用中央水处理？人家是单独水管，水泵直供的，而高层空间都经过二次加压，水压本身就不行，你在层层过滤，你想水压能大才怪；
如果你家水压没有问题，也有钱，也有空间，就可以做：前置过滤+中央软净水处理+末端净水。
