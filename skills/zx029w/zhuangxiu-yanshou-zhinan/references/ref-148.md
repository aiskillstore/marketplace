# 装修各个工种怎么验收（一）？3.9

这个问题是好多业主想问的问题，网上各种理论答案非常多，只要会搜索都可以找到。但是往往让人看得云里雾里，对于没有经验的业主来说，和天书没有区别。你不懂装修工艺，首先枯燥的理论是看不懂，更不可能用难懂的理论去对照你家装修。所以今天给大家用大白话说一下各个工种的验收方法，其实就是生活经验而已。

01
拆除垃圾运输

不论是新房还是二手房或者老房，都会牵扯到拆除项目。拆除验收其实就是生活经验，主要看拆除交底的时候，该拆的是否拆除到位，是否拆除干净而已。
一般墙体拆除比较简单，该拆的拆掉就行，拆除以后的破损修补是后续工程，这个不用说肯定都在预算里头算着，当然碰到无良机构，拆除以后的修补故意作为漏算项目，业主就倒霉了。
难点在于墙面，大部分业主不知道墙面到什么地步算是铲除干净。或者是压根不知道墙面该不该铲除，这个是普遍的问题。铲墙的可以参考《装修前注意看墙面，不止素灰那么简单》这篇。
▲不论素灰还是白墙，铲除后的效果需要大面积看见原基层。彻底一点没有遗留是不可能的，不论手工还是角磨机也做不到彻底干净。目的就是为了后面好施工，腻子可以与原基层好附着，所以只要大面积铲除干净即可。

02
水电施工验收

水电作为隐蔽工程是重中之重。一是材料验收，二是施工验收。
材料方面就是水电料，这一块水路材料可以忽略，只要和合同签订是一个品牌，剩下的质量业主可以不管。为什么呢？因为现在都是厂家上门打压，也就是你用日丰，日丰厂家上门打压，谁敢用假的水管或者配件？不仅打压不成，没有厂家售后，而且一旦发现假冒材料直接报警处理，这个是要吃官司的。所以装修机构绝对不会在水路材料动手脚。
电路材料一般就是电线和穿线管，电线是有好坏的，除过品牌是合同里头的品牌以外，每一个材料上都有防伪标志，业主可以查看，这个也是很好识别的。
难点在于施工上，水电施工大的分为国标和非标，也就是大家通俗所说的横平竖直还是短距离拉斜线，两者从视觉上是截然不同的。
▲如图所示，左边是短距离斜线，右边是横平竖直做法，视觉上不同。重点是维修不同，一旦后期没有照片或者视频，出问题，斜线做法几乎没有办法维修；而右侧横平竖直做法，即使没有照片也能知道走向，这就是重点区别，至于拉斜线能省多少钱这个可以忽略，几乎相差不是很大。还有斜线电路好抽线也可以忽略，任何走法，只要距离长了几乎都不可能抽线的，除非距离短，不论怎么走，铜线都是可以抽动的。

哪种做法在做之前需要沟通好，剩下的就是视觉上美观程度的区别了。比如开槽是否直线，线管是否横平竖直，底盒安装是否周正，线管与底盒是否有锁母，线头是否预留够长，这些凭生活经验都可以观察到位。
电路即使不美观只要不影响使用，就是合格的；重点在于前期交底的项目是否都做到位，这个才是重点，否则没有做到位，后期一旦装修完成，这个遗憾有时候返工都是没有办法的。所以重点检查自己的要求电位是否一一都实现了，才是电路验收的关键。
水路方面也是一样的，除过美观程度以外，重点是水路是否按照装修方案严格到位，自己的要求是否一一做好，这个才是重点。
03
防水以及瓦工验收

防水一是材料，二是做法。材料可以参考《水电、防水随便买，花钱走弯路》，施工一定注意防水的做法和面积，这个才是重点。防水材料最好用彩色，比如蓝色，这样工人做完可以看到是否刷到位，一目了然。卫生间一定是四面墙都做到吊顶位置，而非糊弄人只做三十公分或者淋浴只做一米八，这才是验收重点；闭水试验48小时或者24小时都是可以的，最好48小时，一定要观察楼下没有任何渗透点，再进行下一步。
瓦工的手艺是基本，重点是项目是否做到位，是否按照标准去做。例如进场的包管道以及烟道，是否红砖笔直，抹灰是否均匀，直角是否标准，这些施工过程都能看到；包括所用红砖是否合格，是否有太多次品空心，这些在施工发现就可以让更换，一旦抹灰完成以后红砖是无法看到好坏的。
贴瓷砖是大头，这个验收绝对不是全部做完的事情，而是瓦工做的过程中，随时发现问题改正问题，千万不能明明看着有问题不说，等全部瓦工再一个一个来指出，此时就迟了，要返工太多，破坏力度太大，会间接破坏掉原来完好的瓷砖，得不偿失，应该是瓦工施工过程，随时有时间去看，直角有没有角度竖直，缝隙是否均匀，平整度是否有问题，及时发现及时更正，损失更小，结果会更趋于完美。
