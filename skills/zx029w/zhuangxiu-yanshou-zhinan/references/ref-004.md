# 瓷砖铺贴工费到底怎么算才不被宰？

瓷砖铺贴工费，被宰的基本都栽在同一个地方：低价签单，后期加钱。把这几条摸清，没人能坑你。

**第一，谈方案的时候就要问清瓷砖规格。** 谈方案不问你用什么瓷砖，等你瓷砖进场，你的瓷砖规格大了，需要加钱，又是一笔恶意增项。谈方案的时候为什么不说清瓷砖规格？每个规格铺贴的价位搞清楚然后再施工。大规格瓷砖、条形木纹砖，铺贴费都是单独另算的，条形木纹砖铺设另加40元/方，其他规格和特殊铺法价格另计，这些都要在签单前问明白。

**第二，地砖铺贴厚度，这是最典型的坑。** 一旦到了瓦工铺贴阶段，装修机构或者工人都会提出来：水泥砂浆厚度太厚，超过了4cm，需要每平方多加人工费。水泥沙施工厚度40mm以内，每增加10mm加8元/平方米。最可恨的是提前不告知，也不直接算到预算里头，偷偷放到预算备注后面，这个就是典型的低价签单，后续加钱的做法。作为新手业主是不可能知道这个细节的，而能专门坑你的人，也不会在签单前告诉你，而是在铺贴的时候才会提出，而预算偷偷备注的东西你已经签过字了。此时你不掏钱也得掏。

**第三，管道烟道漏算。** 瓦工进场，管道烟道漏算，这是低级的增项手段，因为业主看预算白看了，都没有注意少算了几根管道和烟道。碰到好的公司，自己的责任免费做了。但是碰到专门低价切的公司，此时加钱干活，不加钱走人。

**第四，防水加高、拉毛、保护，连环加钱。** 进场就会问你隔壁是卧室，要放衣柜，防水是否需要加高？加高加钱，不加高就这样干。防水刷到吊顶位置已经让你加钱做了，但是没法贴砖，贴砖就得拉毛，当初防水做得低，压根没有拉毛的项目，防水做高了，需要拉毛，同样加钱做。开始贴砖地面需要做保护，这个本来分内的事情，让业主定夺，保护不？不保护直接贴砖可能破坏防水，保护加钱。又是一笔恶意增项。

**第五，马桶下水、烟道排气孔，开孔顺序别错。** 厨房烟道孔以及卫生间的排气孔和燃气热水器的孔，一定要在贴砖之前打好，否则后期打孔很有可能导致瓷砖破裂，顺序错误，要不瓷砖破裂，要不瓷砖空鼓。

**核心应对办法就一条：** 一定要在签约之前明白这些要点，告知装修机构提前测量，有费用提前算进去，而不是低价签单后期再加钱。铺地面瓷砖高于4公分加钱，这个当初看预算只看价格低了，没有想到超出高度需要加钱，给你看的都是超过高度的，没有超过高度的不给看。量房的意义在哪？

**最后说句实话：** 不要盲目找装修机构，否则你把世上所有避坑指南倒背如流也没有用。因为方向是错误的，只有找对人，即使你不懂装修，也不会坑你；而你找的是人渣，你以为避坑指南能治住人渣吗？
