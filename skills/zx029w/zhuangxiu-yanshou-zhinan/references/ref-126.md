# 冰箱旁边有缝隙？难道留着？7.7

冰箱是家家户户不可或缺的电器之一，有时候空间不仅能容纳冰箱而且还有个空余地方，有时候太小，不注意处理，就会造成入住后的卫生死角，所以今天就来解决这一问题。

▲如上图冰箱放置厨房，与橱柜吊柜的缝隙压根没有任何办法，有时候和你购买的冰箱散热有关，必须留出左右的空隙，此时没有办法解决，除非更换冰箱，所以只能日后时间久了移动冰箱进行死角卫生的清理
▲如图人家怎么能实现无缝镶嵌？因为购买的时候是下散热，只需要给下方留有空隙即可。
▲厨房门口刚好有一个凹陷区，放置冰箱完美，但是空间又大一点，采用定制的方式，做满收纳柜，左侧缝隙采用极窄定制，局部封闭或者镂空，实现厨房各种零碎的收纳，合理利用每一寸空间；购买下散热冰箱可以让视觉上更完美整洁
▲如图镶嵌冰箱以后，上方也多了吊柜收纳，与橱柜之间夹角地方做了镂空布局，后期刚好满足一个移动窄边小推车的位置，拿取也方便，合理利用空间；上方与热水器冲突，利用隔板可以满足一部分收纳，避免吊柜与热水器的冲突问题
▲如图冰箱和电器位置镶嵌外，剩余空间太窄，可以改变方向定制一个超薄柜子，开启空间更方便，收纳更多，转换一个方向就可以发挥更大价值
▲如图餐厅窗户下定制餐边柜，一边冰箱放置，剩余空间除过冰箱上方的吊柜放置不常用物品以外，靠近窗户定制窄边开放格，同时可以兼顾酒柜功能
▲如果冰箱必须保留散热的缝隙无法避免的话，可以采用磁吸置物架满足缝隙的收纳
▲剩余窄边如果做成收纳木门，看起来太细窄，但是做成玻璃柜门视觉上就生动灵活很多
▲同样是镶嵌冰箱以后留有空余，可以采用反向空间定制另一边的收纳柜，空间利用率更高
▲如图严丝合缝定制收纳，镶嵌冰箱以后，预留了十几公分的空隙，刚好利用起来做开放格处理，可以作为展示品的放置，同时木色套色视觉上更灵活生动
▲实在不想定制镶嵌冰箱，也可以网购这些窄边的收纳箱，利用缝隙空间进行收纳
▲可以量取尺寸以后，网购合适的收纳盒子，其实完全可以利用好这些缝隙空间
▲也可以利用冰箱缝隙定制这种抽拉拉篮，可以存放各种厨房物品，合理利用空间
▲如图在冰箱的右边套色窄边开放格酒柜，合理利用空间，而且让视觉更有高级感
