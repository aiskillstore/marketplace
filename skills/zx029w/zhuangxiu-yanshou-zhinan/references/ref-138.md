# 130㎡开放餐厨，通铺瓷砖，打造高质量住宅

普通的三室两卫，一家三口居住，没有什么特殊要求，需求房间一定要放大，不能因为装修缩小房间；其二家里没人看电视，所以客厅希望有更新颖的布局；杂物比较多，希望有专门的收纳地。

▲进门是厅，门口空间挺大，但是收纳布局不好做；客卫非常小，而且直对餐厨；餐厨位置倒是合理，但是两个空间都非常狭小，让就餐空间看起来拥挤；主卧因为想要与主卫更通透，所以侧面牺牲衣柜，但是得从别的地方满足收纳

▲布局图纸，利用门口空间打造一个收纳储物式，满足杂物收纳，预留空间实现门口鞋柜收纳；
砸掉厨房，让餐厨 一体开放，放大整体空间和光线；餐厅跟前卧室作为儿童房使用，带生活阳台作为次卧使用；
砸掉原有客卫墙体，改变斜门处理，一是避免棱角直对客厅，二是让公共区域视觉放大；砸掉主次卧墙体，S型布局，同时满足两边衣柜收纳
▲进门视角，左手利用储藏室局部满足鞋柜收纳；右手餐厨开放，让进门口豁然开朗；儿童房为了视觉更加开阔，做成了双扇门布局，平时视觉上更能放大空间
▲利用进门左手位置打造了一个储藏室，采用木质的谷仓门搭配，非常有质感；旁边小推车兼顾装饰品布局；原有客卫斜面处理，让进入卧室的过道不在逼仄
▲开放式餐厨看客厅，砸掉封闭空间，让公共空间连贯一体，视觉和光线都进一步有了提升
▲开放餐厨一体，让空间更开阔，两个窗户采光让进门一览无余
▲地面统一灰色柔光大理石瓷砖铺贴，低调不张扬；橱柜统一白色定制，角落刚好满足双开门冰箱的布局
▲六人位餐桌布局，满足平时一家人就餐，即使人多的时候也可以满足；餐厅窗户下方打造西厨收纳柜，兼顾水吧台以及弥补厨房收纳不足
▲因为不需要电视，还想要有新颖的布局，选择了模块型沙发，这样可以随意拼接，更换不同的位置布局；电视墙采用开放式格矮柜布局，同时满足书柜以及展示品布局
▲沙发背后非承重墙掏了一个壁龛，隔板置物，这里作为客厅的形象墙装饰
▲非常极简干净，满足会客，同时满足一家人的活动空间
▲客厅看过道以及开放餐厨空间，打造的储物间谷仓门搭配移动小推车，过道也有了生动感
▲主卧背景蓝色变色，木质的家具搭配，角落高大绿植点缀温馨
▲床尾是与次卧共用镶嵌收纳衣柜
▲靠近飘窗采用悬空抽屉布局了一个化妆台功能，错落极简，非常有艺术感
▲靠近卫生间斗柜布局，空间更开阔
▲次卧灰地白墙，采用铁艺的床铺搭配，同样是务实极简
▲一边铁艺的极简圆几与吊灯搭配
▲另一边同样采用铁艺的花架兼顾床头柜，同时可以放置少量书籍；极简布局空间显得更高级
▲侧墙一副抽象挂画营造空间的高级感；
▲次卧床尾与主卧共用S墙满足基本的收纳需求；次卧外面是生活阳台
▲儿童房同样蓝色背景搭配原木床，艺术性很强的吊灯满足视觉和功能
▲主卫灰色瓷砖通铺，搭配非常有质感的淋浴隔断，分区布局
▲砸掉主卫墙体，实现玻璃墙的通透，让主卧整体更显高级明亮
