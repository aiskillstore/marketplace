# 好的设计师都有哪些标准？对号入座3.19

装修离不开设计师。撇开质量问题，除非你是出租房，其他再简单的装修都需要专业人员指导，否则总有些地方你想不到。所以专业+经验+人品，才是一个好设计师的标准，缺一不可。

人品，看不见，只能从设计师的行动中去感受。首先，设计师作为服务人员，得从头到尾站到客户的角度去想问题，而不是站在金钱或者公司的角度。从这一点就可以考察设计师的好坏，同样标准也能考察出一个装修公司的好坏。一个好的机构是不会容纳一个品德败坏的设计师存在的，所以设计师的好坏直接决定装修公司的好坏。

1.只看钱，只要效果的设计师要不得。不论你家是豪宅也好，刚需也罢。设计师开始设计的时候，一定要根据你家入住的人口情况去做。比如，家里有小孩，一定杜绝污染源，减少污染的总量。而不是只图自己的设计效果，花里胡哨一大堆，看起来高大上，殊不知，这才是赚你钱要你全家的命而已。
所以以后装修的时候一定注意，你家有小孩，而这个设计师明明知道情况，反而给你设计全房木地板，全房壁纸，各种花里胡哨背景墙大面积制作，或者人造板定制儿童房全部做，碰到这个情况，赶紧换人，这家公司打死都不能找。
为了金钱和效果，从未把业主家人的健康放第一位，这是人渣。关于什么才是装修环保，大家可以后台回复“装修环保”查看专题。
2.多替客户着想，其实也是给自己铺路。装修途中，任何业主的事情，一旦看到有不对的，及时指正，不能明知道错了，反正不是自己责任，任其发展。同样作为业主，在装修过程中，是不是设计师的事情，一定多问多问多问，不要嫌麻烦，你多问专业人士，一定会给你减少一定的损失。如果设计师极其不耐烦，只能说明设计师人品有问题，同时极其短视。倒霉的不仅仅是业主，同样有这样的设计师的公司也得跟着倒霉。
3.好多业主庆幸自己找了公司设计师，做私单，认为这样省钱。其实从人品角度，任何人只要稍有做人的道德，都不会吃谁饭砸谁锅。一个踩着公司平台接私活的设计师，何谈人品？他能为了金钱出卖做人的道德，同样再给你装修的时候，随时可以为了金钱出卖一切道德。所以除非设计师是单干的，否则私活的设计师慎用，这也是考察一个人基本人性的标准。
4.具备以上品行，行动的出发点才是对的。有了强大的人品以后，设计师的做事的出发点才是对的。才能一心替客户着想，替客户的家人着想。装修房子，实际就是考虑房子里头的人与生活的便利。脱离任何一方都是失败的。
5.专业+经验。这个是时间的沉淀，而非学历。好多现实中相信业主都听说，某某公司的设计师都是什么学校毕业，其实这个一点用没有。装修和你在哪毕业一毛钱关系没有，装修是实实在在经年累月一点一滴积累的经验财富。世界上任何学校都教不出来好的装修经验。
实际生活中从年龄就可以分辨，一个二十出头的设计师，自己都没有房子，从未实际有过生活经验，号称金牌设计师，这个纯粹就是骗子而已。如果你家就是刷墙铺地或者出租房，可以一试，否则还是算了，好多专业的经验不具备，甚至连各种下水都搞不懂，怎么去让你舒适入住？这种设计师只能作为设计师助手，绝对不能给你家系统设计和装修。
也不要看花里胡哨的效果图了，一个刚毕业的设计师都可以做漂亮的效果图，至于如何施工却一塌糊涂，房子装修需要落地，而非纸上谈兵。
至于怎么看设计师的经验，关注本号原创里头太多了，多看看，就可以看设计师经验是否有你的经验多，如果设计师都没有你知道的多，要设计师何用？免费设计的设计师没动力？这话很外行
装修找不找设计师？有用吗？
