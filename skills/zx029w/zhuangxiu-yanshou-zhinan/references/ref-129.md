# 前置、净水器、管线机、洗碗机，你都需要吗？10.17

装修之所以复杂，就是因为其个性；看似装修的是房子，实则装修的是每个人的生活，所以每一个大众化产品，需要大家思考一下，并不是大家都在用的东西就适合自己。例如……
第一、前置过滤器。

▲好多年前，哪有这玩意，可是现在装修业主跟风安装，问其原因，别人都装，可以过滤杂质保护电器。
是的，没错可以过滤杂质，但是有没有人问过家里自来水用的是市政水，只要不是突然停水状态，何来杂质？除非你们小区是老旧小区，用的是楼顶储水池。

▲上图的高层储水池大家应该见过，就是高层住宅二次供水用的，自来水压到不了这么高，需要在楼顶设置存水装置，然后给高层供水，此时如果长时间不清理，储水池是非常脏的；而且每次只要停水用干净，重新注水的时候，杂质就是泛起，此时用水就肉眼可变各种杂质。但是此时的杂质也只是停水或者物业清理水池的几天时间会有，至于长久细菌等污染，你安装前置过滤器是一点用都没有的；而真正能起到作用的就是每家水槽下方的末端净水器。▲在注意看一下上图，这个是罐式无负压供水设备，在几乎所有大城市里头，自来水正常不会存在不断停水的区域，这个几乎是住宅高层的必备，而且大部分城市的老旧住宅目前已经大面积改造，这种设备是不需要高层楼顶的储水池的，直接与市政自来水连接，可以让高层住宅用到正常水压的自来水。而此时你家用的其实就是正常自来水，只要不存在水源污染的情况下，压根不会有任何杂质的。
▲在注意看一下上图红圈的Y型过滤器，这个不仅仅是小区水电房的标配，而且在自来水的供水前端也会有，目的就是过滤自来水的大颗粒杂质，防止管路堵塞影响正常供水水压。看了以上的普及，请问你家有必要再安装一个前置过滤器吗？正常的水路本身到小区水压就有影响，然后人为的不断过滤，导致水压更低，如果你家用的是质量不太好的燃气热水器的话，就会发现经常用水高峰期点火不启动，原因就是你人为的加了好多压根没有用的过滤器，导致影响家里整体水压▲更可怕的是大部分人跟风买过滤器，压根不知道怎么去购买，而市面上大部分过滤器都会增加这种隐患--承压远远小于PPR水管承压，压力大，先爆前置过滤器。▲北方地区所有装修公司做水电的时候，都会问你有没有前置过滤器，有的话给你预留空间，等水路做完打压正常，你自己让商家上门安装前置过滤器，你知道原因在哪？你所购买的前置过滤器承压远远低于你家PPR水管的承压，此时一旦你提前安装过滤器，水路打压很有可能直接把过滤器打爆，这是其一；其二一旦后期入住水压不正常前提，你买的前置承压过小，爆管的唯一地方就是前置过滤器。这些后果都得自己承担。▲其实普通刚需家里，除过水槽下末端净水以外，其他压根不需要，这个才是保证水质的前提，不要本末倒置，掏钱买个前置过滤器，家里人却直接喝自来水。总结一下：普通住宅你如果就是居住在大城市，压根不存在不停断水的状态，前置压根不需要，否则一是容易爆管，第二容易影响正常水压；第三并没有改变水质，至于过滤杂质只是你的一厢情愿而已。最后，如果你非得安装，一定要购买承压要远远大于市政供水的压力，前置过滤器的承压如果过小，而自来水压大于前置压力的话，最害怕的事情还是会出现的，那就是水管没事，前置爆管。因为水压都不稳定，谁也无法保证恒压。第二、管线机。▲管线机大家应该不陌生，现在好多家庭都在装，目的就是为了随时能喝上热水，当然家里备一个保温壶，直接用锅烧净水器的水，一样的道理，只是管线机能更节省时间而已。《家里想要管线机，怎么隐藏安装？》▲家里常住人口多，而且老人小孩居多的时候，管线机还是比较方便的，可以调节水温，随时喝热水或者给孩子冲奶粉，都是非常方便的；但是如果家里入住人少，为了节省费用，减少麻烦的话，直接备保温壶就行。▲管线机一定要购买没有储水箱的，一定是即热的管线机，否则过滤后的净水是不能长久放置的，特别是你家用的是反渗透的净水器，已经过滤掉了自来水添加的抗菌剂，此时净水是无法长时间放置，必然滋生更多细菌，一定要注意。▲所以家里经常无人或者入住人少的话，不幸购买储水式的管线机，这个看似生活便利，其实对健康有很大的危害。而且管线机长久不使用必须把水放干，断掉电源；最重要的是你家净水器本身就是储水净水器，长久不使用的时候，先要在净水器龙头多放一会水，然后再次使用管线机。▲还有一定需要注意，如果家里管线机离净水器非常远的情况，此时PE管抽动的概率几乎是不可能的，所以一定要防止人为破坏或者施工不小心磕碰，还有就是时间久了需要更换的问题，所以长距离的话建议穿两根PE管，一根作为备用，不论是后期发现磕碰或者是经年以后需要更换，都是比较方便。一般PE管在使用过程，10年以上应该没有问题，但是长距离预埋，一旦出问题只有一根管的话，几乎无法使用，而如果备有两根PE管的话，就无后顾之忧了。
▲如果家里入住人少的情况下，就没有必要远距离加一个管线机了，你可以算一笔账，如果一个净水器+管线机价格远远高于一个带加热的净水器的话，那何必这么远距离预埋管子，还得分开购买设备呢？直接用可以加热调温的净水器不是更好，只不过接水需要到厨房而已。第三、洗碗机。
▲家里入住人多，一般几代人同时住的话，真心建议买买买，当然前提是厨房空间满足洗碗机的安置。科技就是为人服务的，你如果有这个经济实力，何必累着自己呢？这就好比明明能买得起车非得步行，提高效率，节省出更多享受时间，这才是人生。▲洗碗机需要根据入住人口购买大小，并不是越大越好，如果长期入住就两人，你买镶嵌式13套洗碗机，完全浪费，除非顿顿满汉全席或者每天不洗碗攒到晚上一块洗才行，否则这么大容量的洗碗机太浪费了▲长期就两人入住，用水槽洗碗机或者台式洗碗机，都够了。一大家子一定根据人口来选择洗碗机的大小套数。第四、末端净水器。
▲家里必备的设备，一般在水槽下方，用来提供家里喝水和做饭用的。这里一定注意，现在两种主流净水器，一种是超过滤，可以不用电，不用排废水；一种是反渗透的净水器，需要用电，而且排废水的；如果家里水槽下方没有电源的话，可以直接用超过滤即可其中注意还有带桶和不带桶的区别，过去的净水器几乎都带桶，因为出水量太小，太慢了，所以需要带桶提前出水存储，而现在出水量的提高带桶的就慢慢淘汰掉了；因为带桶提前存水的话，长久不用水会变质，反而有害健康；▲两者的唯一区别就是超过滤膜和反渗透膜而已，因为反渗透过滤的更细，更精准，所以需要用电带水泵才能出水，而超过滤过滤没有那么精细，所以靠水自带压力就可以出水；而且反渗透的净水几乎不含对人体有益的微量元素，而超过滤可以保留对人有益的微量元素，所以一般大城市水质好的建议用超过滤，而水质污染比较大的地区用反渗透。▲超过滤和反渗透哪个更好？其实有不同用途，如果作为喝水和泡茶来说反渗透更好，但是作为熬粥做饭的话超过滤效果更好；像平时煲汤或者蒸米饭两者水质带来的结果是完全不一样的；如果真的要分这么细可以考虑双膜净水器，双龙头，一边是超过滤用来做饭，一边是反渗透用来泡茶喝水，不过成本就更大了
▲购买净水器一定要注意耗材的成本，你以为买净水器只看净水器的价格就大错特错了；现在的好多净水器都把机器价格压低，目的就是为了让你购买后期昂贵的耗材，这个和打印机一样，机器便宜，耗材贵，利润都在耗材上头；
最可恶的是国人商家从来不会把净水器耗材做成通用的，看似一个厂家的滤芯，接口每一家都故意做成不一样，目的就是你低价买了他的机器，后期必须买他的滤芯才能用，价格人家说了算，除非你把机器扔掉不用，但是你换任何净水器，滤芯都是专用的，这就是经商的文化而已，你除过忍受以外，难道还得高喊支持国货吗？
