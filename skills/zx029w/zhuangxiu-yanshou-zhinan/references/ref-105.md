# 隐蔽工程施工，应该把预算放到哪个环节？2.18

装修房子从大的结点分为水电瓦木油，基础施工五大环节。其中又掺杂繁琐的各种细节，每一个细节都需要付出金钱。所以就有了轻重之分。

一般业主并不是装修缺钱，有时候是因为不会规划，导致该花的没有花，不该花的却超支，导致最终钱没少花，但是没有用到刀刃上。

关于水电施工，预算应该放在怎么改造上。而不是看什么名贵的品牌的材料上头。好多业主犯了一个错误是，把资金重点放在了用料上，而忽略实际的功能性。比如，只注重水管电线的好坏，导致在水电改造上这个不动，那个以后用不上。功能都达不到，再好的材料又有何用呢？

比如，动不动就用进口的水电料，这个是犯了一个天大的错误。水电之所以是重中之重，是因为都是地下预埋或者墙面暗埋的。材料用好的是前提，但是什么才是好的材料？这个首先得弄明白。当然是十几年大家都在用，而不出事故的材料了。然而部分业主盲目追求进口，崇洋媚外，不问实质，就以为进口的肯定比国产的好，这个是方向都是错的。

例如在西安地区，用的最多的水管是日丰、金德、伟星。其中金德日丰管，随便打听十年前的业主都用过，这才是经过生活实践，检验出来的货真价实的材料。可是你放着大家十几年检验过没有问题的材料不用，反而用装修公司推荐给你的所谓进口的洋垃圾？是不是本末倒置？而这一切只不过是装修公司自导自演的营销游戏罢了。

因为只有用你没有听过的，大部分装修公司都不使用的材料，这样才好报价，才能让装修公司的利润最大化。即使是国外的垃圾，到了国内也可以天价销售，而业主却认为这是物有所值。殊不知，不仅高价买到可能是洋垃圾，而且这种材料当地几乎没有业主实践过，后果是间接的把自己家当做了试验田。除了徒增风险以外，看不出任何价值。这就是该花钱的地方不花，不该花钱的地方乱花。

电线也是一样，西安地区随便十年前的业主，恐怕都用过津成电线，这就是实践检验的产品。如果你真的想用装修公司推荐的进口材料，先问问当地装修过的人，最好最少五年前使用过这种产品，否则就不要尝试。

把所有迷信进口材料的钱省下来，用到水电的实际改造中，这样经年入住，你才会发现，这些都能用上。而不是家里想要厨宝才发现当初为了省钱没有留插座；想用智能马桶才发现跟前没有电源。诸如此类都会给生活带来不便。

防水只要问西安本地装修过的业主，十年前就用到了东方雨虹和西卡。可是，你放着十几年不出问题的产品不用，却相信进口或者自作聪明用别的品牌，完全是本末倒置的做法。这么重要的施工环节，却让你当做了儿戏。

所以，以后不要问别人隐蔽工程材料到底用什么品牌，你得问当地人这么多年都在用什么品牌，这是大家给你无偿总结的现成经验。

除过材料，防水的重点在于施工，把资金要放到怎么做和做多少上。这个关注本号的业主相信都能背下来，不再赘述，直接参考此篇即可《卫生间防水全做错了，被坑还感激人家呢》
