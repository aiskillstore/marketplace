# 水电改造翻车，装修第一步就入坑6.27

今天看一下水电改造翻车的教训，避免自己犯同样的错误。

▲卧室床两边插座过低，以后放床头柜必然挡住。这个在北方开发商新交的房子里头，几乎百分之九十就是这个高度，所以局部改造需要朝上移动，移动到床头柜以上的高度，但是这个就会产生费用，所以怎么使用，能否使用，需要业主自己做主，后期想挪就迟了
▲记着水电改造淘汰冷水管，全部采用热水管，不要为了几毛钱的费用给自己造成麻烦。如果现在还有人冷热分开用的话，可能是完全没有经验的做法。全部采用热水管完全不需要担心用错水管问题，而且壁厚更厚，承压更好。
▲一眼没有看到，电工长距离开横槽，不仅会破坏墙体的承重结构，而且后期安装东西都会碰到管路产生隐患
▲电路是横平竖直还是点对点，业主需要自己想清楚，如果按照米数计算，点对点你以为能省多钱？后期一旦出现售后问题，你家瓷砖砸得比谁都多，而且每次售后看着照片都不知道具体哪里有水电。横平竖直的做法是为了后期检修都不需要图纸，肉眼都知道哪里有水电，并不是为了多掏钱，那个米数可以忽略不计
▲空调面板放到了风口跟前，这个怎么用？商家说是用遥控器控制，但是要面板干啥？
▲房子肯定不是斜的，那一定是电工的眼睛是斜的
▲自己装修水电当时做完结账就让走人了，没有想到后面单独找到电工安装开关插座，压根找不到线路，家里又是非常复杂的无主灯设计，导致安装工工费居高不下。后悔没有让当时的电工安装。
▲自己不懂行，工人也不懂，阳台一边洗衣机一边水池，结果是地漏放到了右边，插座放到了左边，现在是洗衣机压地漏；而且是没有做竖管留个连个并排地漏，一个进水，一个不会出水？
▲自己不懂以为每一家都用铁管子穿线，比较邻居才知道，这个就是镀锌铁管，但是开发商原有的都是PVC，妥妥的交了智商税，难怪水电费用这么高
▲左图是形象墙的水电工程，真的养眼，右图是自己家做的实景，你说看样板又有何用？自己家确实不是样板。

▲左图是防水的做法，右图是入住两年后的灾难现场。自己不懂，装修机构为了低价切压根就是糊弄做一点防水，这就是后果。

▲这个才是卫生间防水的正确打开方式，可惜大部分业主不知道，防水其实重点是防潮，而不是临时为了低价切，糊弄做防水，后期房子是你住，倒霉的还是业主自己。
▲没有考虑实际，听说所有下水要做存水弯，要不会有异味，结果是马桶用不了，天天堵，其他下水堵了非常难疏通。马桶内部本身就是存水弯，坚决不能给马桶做下水做存水弯；其他地漏后期用深水封地漏就可以解决臭味问题，如果把存水弯埋到地下，以后堵了砸都来不及了
▲下水存水弯是隔层排水的专利，也就是北方常见的下水在楼下吊顶里头，这样的好处是有检修口，以后漏了楼下就可以打开疏通，但是南方都是下沉式卫生间，你把存水弯埋入地下以后堵了咋疏通？
▲不仅长距离开横槽，而且竟然阳角拐弯，就这电工还自卖自夸手艺好？
▲自己装修省钱能省到哪？如图洗衣机咋放？还留了两个地漏？插座在上头打孔接线？这些都是不具备基本常识的做法，你如果不放洗衣机或者把洗衣机拉出来放，自欺欺人认为这是省钱也行

▲横向长距离开槽，随便斜拉线路，如此做法，确实省钱吗？

▲灯具开孔一定是根据灯大小开孔，你提前开孔也不看有柜子，柜子装了才发现孔开错了，又得返工修补

▲水电前期一定要规划好，否则后期想要的东西没有电源，如图前期没有规划电动窗帘，后期想要，只能借用空调插座，难看不说还有隐患
▲电器背后嵌入式插座，感觉有点脱裤子放屁的感觉，既然有电器，何不在规划的时候避开电器去留插座，非得把简单的事情复杂化
▲电源距离没有规划，壁挂炉压住了插座位置，又得敲砖重新移动了
▲智能马桶的需求在装修之初就得想到，最好都预留上，万一以后想用就尴尬了
▲不仅理论改水电，直接把阳台下水更换这么长的位置，右边洗衣池，左边洗衣机，这个洗衣机确定能放进去？
