# 壁挂洗衣机，需要什么安装条件？水电如何预留？

**壁挂洗衣机按图纸详细规划。** 现在大部分家庭都会单独做一个壁挂小洗衣机，可以分开清洗或者给孩子专用，一定要按照施工图纸详细规划去做，否则多半都会翻车。

**常见翻车实例。** 网友@一口泡芙：为了装壁挂洗衣机预留位置预埋线，结果进出管只能进一个，上下水管大小预埋管道粗细必须知道。网友@西瓜：预埋50管结果上水下水和电源线不能同时穿进去，下水管应该预埋63或者75就好了。网友@团子：红砖墙不要装了除非是混凝土，使用半年壁挂洗衣机直接脱落掉地上。网友@eachy：全屋定制一定要复核设备尺寸，硬装95%发现预留尺寸小了将近10公分。网友@废材菌：50管位置留错，机器是要居中留在最下边，想要完全不翻车水电的时候一定要把机器确认好了。

**关键安装条件。** 壁挂洗衣机须装于承重墙且远离马桶，红砖墙空心砖墙不能装除非是混凝土。机器背后管线是固定位置要暗装必须对准洞口，安装时候洗衣机高度是不能调节的。壁挂洗衣机+智能马桶是大冤种组合，洗衣服马桶盖打开了洗完衣服马桶盖又打开衣服会不会掉进马桶。

**水电预留关键点。** 第一下水管必须预埋63或75管而非50管，50管穿不下上水下水和电源线。第二50管位置必须居中在最下边，提前确定产品型号核对机器尺寸管道粗细。第三预留口能隐藏尽量隐藏，整体太丑了。第四水电阶段就要把机器确认好了不要凭想象预留。第五全屋定制要复核设备尺寸避免预留误差10公分。

**水电验收10个硬指标。** 水电阶段提前预埋PVC管，考虑进出管能同时穿过。承重墙是硬性要求，红砖墙脱落危险空心砖墙只能碰运气。壁挂洗衣机高度要合适太高普通人够不到只能踩凳子，太低又害怕碰头。

**安装监督不能省。** 散工没有靠谱的官方安装工图方便和速度直接挂上就走，壁挂洗衣机一定要盯着安装。自装一定要谨慎这些散工没有靠谱的，而且自己没有那么多精力去操心。壁挂洗衣机预留位置完全错误随心所欲导致后期整体砸掉瓷砖重新做，浪费时间增加成本。

**记住。** 壁挂洗衣机体积小但安装要求高，墙体、上水管、下水管、电源线、高度、位置都需要精确预留。施工图纸详细规划，机器提前确认，预留尺寸精确，承重墙硬性要求，散工不靠谱要盯着安装。壁挂洗衣机翻车容易补救难，水电阶段多做一分心思，安装后少十分后悔。
