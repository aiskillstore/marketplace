# 安装踢脚线，盖不住瓷砖缝隙，怪谁？4.21

想必这个事情大家遇到的比较少，除非是自己装修或者半包装修里头遇到最多。因为全包的话，所有材料是装修公司的，后期出现踢脚线盖不住缝隙，已经完美解决了。这些过程业主压根不会经历，所以这就是为什么推荐全包的原因。

▲如图所示，你家是不是在铺完大地砖会出现这种情况？其实很正常，不出现是你没有仔细观察而已。
出现这个说明是瓦工的问题吗？这个不做辩驳，你如果非得说是瓦工的问题，瓷砖和瓦工都比较冤枉。
因为铺瓷砖的时候任何毛坯房的墙面都不可能横平竖直，墙面本身误差太大，瓷砖是直边，瓦工只能按照直边进行铺贴，不可能把瓷砖裁割成“凸字形”铺上吧
所以一般出现这个问题先不要慌张，看一下是局部出现这个踢脚线压不住的问题，还是全部压不住。如果只是局部缝隙大，内行当然知道这是墙面问题，这个可以解决，后期批墙的时候找平就可以解决这个问题。
一般瓦工靠墙留伸缩缝在1公分左右，而市面上最薄的踢脚线厚度是1.5公分，完全可以压住，如果是后期墙面做完压不住，这个不是瓦工问题，是油漆工压根没有找平，而是顺墙做了，这个责任在油漆工而非瓦工。
▲如果你家用实木踢脚线的话，这个3公分都有，所以前期的缝隙不是问题。
关键在于业主不懂，往往瓦工做完发现这个问题，就开始扯皮。完全没有必要，墙面做完看分晓，只要墙面做完能压住就是合格的，如果墙面做完压不住，那就是墙面压根没有找平，顺平的做法，这个需要返工。
