# 瓷砖美缝勾缝到底怎么选怎么做？美缝剂、环氧彩砂、聚脲哪个不翻车？

**勾缝已淘汰，瓷缝才是正解。** 过去都用白水泥勾缝，不耐水固化也不好，会脱落被污渍侵染。成品勾缝剂主要材料还是白水泥，只不过加入固化剂，比白水泥好不到哪去，同样会脱落发黑。瓷缝剂不一样，硬度非常高，强度高于一般水泥，表面有陶瓷质感，不变色硬度好，直接淘汰勾缝剂。预算有限的刚需家庭，环氧彩砂是高性价比选择。

**卫生间必须全做，这是另一道防水。** 不论卫生间大小最好把卫生间全部选择瓷缝剂。瓷缝剂坚硬不怕水，最重要的是长期水流永远不会从瓷砖缝隙进入到瓷砖与防水层之间。普通勾缝剂时间久了发黑脱落，缝隙成空的，水流顺着缝隙进入瓷砖与防水层之间，虽然不会漏到楼下，长此以往卫生间地面永远有积水，这就是为什么没有漏水但是卫生间经常潮湿的原因。卫生间美缝是另外一道防水。

**半填充是坑，别做。** 半填充就是铺完瓷砖先用普通勾缝剂填缝，然后再用瓷缝做一遍，目的为了省材料省人工。表皮那点美缝短时间赢得面子，时间久了必然脱落，露出丑陋的勾缝剂变黑脱落让污渍填满。卫生间一旦表面美缝塌陷或者开裂，下方勾缝剂完全抵挡不住长期水泡侵蚀，水进入瓷砖与防水层之间造成家里潮湿发霉。半填充是工人为了低价切入的特有手段。唯一省钱做法是自己动手DIY。

**颜色搭配三原则。** 深色瓷砖搭配白色瓷缝，强烈对比带来立体感，最普通的颜色搭配法不会出错。浅色瓷砖搭配深色或者灰色瓷缝，同样有立体质感。最好不要用和瓷砖同色的瓷缝，材质不一样几乎找不到同样颜色，做到颜色相近又不一样，效果平庸没有立体感，不如直接用低饱和度的灰色系，低调含蓄还有高级感。木纹砖一定要做同色美缝或者相近颜色美缝，千万别听工人建议做金色。亮面美缝容易显土。

**施工时间别急。** 瓷砖贴完凝固几天以后做地面保护，木工油漆工进场，油漆刷完撤保护膜打扫卫生做美缝，美缝做完衣柜刚好进场木门紧跟其后。千万不要瓷砖凝固两三天就做美缝，水泥砂浆还在不断伸缩，必然出现局部瓷缝拉裂或者塌陷导致无休止返工。美缝时间一定要等瓷砖干燥，卫生间区域一定要保证干燥否则后期也会脱落。冬季气候冷不能做美缝，开春温度提升必然脱落。

**别自己逞能。** 千万不要认为美缝很简单为了省钱自己动手，那需要经验，经验才是做美缝的基础。自己网购材料，颜色做错高低不平，为了省钱最后损失更大，后果只能自己承担。
