# 90平做了美式，除了地板都满意

90平做了美式，除了地板都满意
▲害怕小户型做不了美式，其实还是可以的，除过稍显拥挤以外，还是温馨满满的，就是木地板失误，颜色稍深，还好其他选择比较淡的颜色
▲浅色布艺沙发搭配单椅以及脚凳，家具标配美式深色家具。沙发背景整体石膏线勾勒，统一高级灰乳胶漆涂刷，看起来蛮时尚的。壁灯选择黑色简洁质感的，装饰画也选择黑框的比较有质感
▲电视墙同样简单石膏线勾勒，统一灰色设置。整体实心吊顶，中间石膏线条勾勒点缀
▲沙发区正面图，实际空间确实稍显拥挤，相机拍摄有拉大空间的嫌疑
▲餐厅美式标配深色家具，靠墙成品边柜，挂画以及圆盘装饰
▲餐厅看厨房空间，厨房选择与卧室门统一的玻璃木门，这样家里比较统一。这个角度看木地板确实有点深了
▲客厅背景做了一个壁炉装饰，也算是美式风格的标配吧
▲主卧统一深色变色，美式深色家具搭配，窗帘做了双色撞色设计，整体感觉还算温馨
▲次卧儿童房比较小，只能靠墙放置家具，书桌学习功能布置
▲儿童房的书桌衣柜书柜统一设置，颜色对于儿童房来说深了
▲厨房选择哑光格子瓷砖，白色的模压橱柜，吊柜橱柜之间菱形瓷砖装饰
▲卫生间定制浴柜，蓝色的瓷砖装饰拼花。浴柜侧墙做了收纳壁龛
