# 给客餐厅卧室墙面贴满瓷砖，到底图了个啥？2.17

关于标题的问题，北方从来没有遇到过，可能地域原因吧，南北方气候不同，但是再潮湿的地方也不至于给客餐厅以及卧室里头墙面都贴上瓷砖，这个是无法理解的，让人想起北方几十年给封闭阳台贴满墙砖的做法，其实也是完全没有必要的。假如真的像北方好多人说的，不给阳台贴墙砖容易返潮的话，为啥卧室墙面不贴墙砖呢？恐怕这里头太多的约定俗成或者不愿意有人去说出的真相，你猜猜你把家里所有墙面贴上瓷砖，最高兴的人是谁？退一万步你是南方靠近海边的一楼自建房，就是为了防潮气，那高层空间也这样做，就有点费解了。弊端是不言而喻的：1.非常冰冷，家里毫无温馨感，比仓库更像仓库
2.再怎么做都上不了档次，没有任何内涵的美，就是存放物品和人的空间3.非常危险，一旦出现瓷砖脱落，家人始终处于隐患之中，而且越是潮湿的地方瓷砖空鼓几率更高4.再便宜的瓷砖和人工加起来，是普通乳胶漆的至少三四倍的费用，甚至更高，然而高价换不来好的效果，装修本身就本末倒置了。5.回南天墙面是不会破坏了，但是你得用刮板刮墙面的水了，而且头顶不贴砖，就不怕潮湿了？
你没有看错，客厅除过地面亮光瓷砖以外，你能看到的除过顶面以外，都贴上了瓷砖，第一眼感受就是冰冷和惊讶。包括餐厅墙面，都是瓷砖上墙，这里非常潮湿？还是为了墙面更耐擦洗？如果真的南方这么潮湿的话，为什么南方的酒店没有发现一家这么做？别惊讶，这是一间卧室，所有墙面都是瓷砖，所不同的是用了柔光瓷砖，不知道有多少人能接受，这些真的不用花钱吗？缺钱的人是不会这样装修的，但是缺的是什么呢？包括进入卧室的过道墙面，同样是不灵不灵的亮光瓷砖上墙，感觉豪气的很，但真的没有必要，也没有任何美感，否则地面就不会有那个九十年代最难看的波导线了。入住后的样子，真的亮光闪闪，虽然个人有个人的喜好，但是真心不建议这种该花不花，把钱都糟蹋的行为了；柜机和风管机价格一样了，满墙的瓷砖早都做上了窗帘盒和独立烘干机了。潮湿是气候问题，墙体也不会冒水，贴了瓷砖就可以改变气候了吗？那何不把瓷砖钱做成干湿平衡的新风系统呢？不怕磕碰，不怕刮花，不用担心小孩子涂涂画画。十年如新。这是业主自己认为的优点。真不是缺钱，缺钱就不会做这么突兀难看又花钱的电视墙了，更不会给客餐厅所有墙面贴上瓷砖了，那缺的是什么？把几十年所有装修的缺点放到一起，真的不太容易。几乎所有的翻车都发挥到淋漓尽致。缺钱的话不会全房吊顶采用蜂窝铝大板，豪华的黑色线条，前卫的无主灯做法，奢华的瓷砖上墙，尽显档次。但总感觉有走进澡堂子的错觉。你不能说人家没有装修，但是你可以大声说：这个空间装满了建材！客厅墙面全部瓷砖，而且电视墙配了豪华欧式的电视柜，贴了欧式的线条，你不能说人家没有品味，绝对有，但是不咋地而已。大部分喊着装修缺钱，其实这个是错误的，装修缺的不一定是钱。你以为这是高层住宅？不是，是别墅，所有墙面都贴了瓷砖，一个字形容：你就说有钱不？为什么这样的装修，总给人又穷又有钱的感觉？不缺钱也不缺建材，但是为什么显得这么廉价以及不值钱呢？无法接受这种装修，真的无法接受把钱都花到面子上，家具没有一样是值钱和有档次的，图啥呀？夏天还好一点，冬天这样的冰冷真的受不了满眼的亮光瓷砖，真不是缺钱，但是有一个疑问：如果是为了防潮，为什么卧室墙面不贴瓷砖？为什么头顶不贴瓷砖？所以呀，压根不是这个原因，多半是装修观念的问题。
