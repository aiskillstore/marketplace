# 装修教训：门和地板没协调，露瓷砖的瞬间我懵了

家里铺木地板压根没有考虑与瓷砖接缝位置，导致装门以后，丑陋瓷砖露出来，然而想要改变这个丑陋，已经迟了，除非砸掉瓷砖，实在可惜，装修最后翻车。装修看似简单施工，但是每一个工种都是交叉协调的，哪有那么简单，你除非你懂装修，否则一定要找有经验的团队，否则多半都会翻车！第一种、卧室木地板，外面瓷砖。卧室木地板，外头是瓷砖，装上门以后，木地板露出一大截！丑到快哭了。这种错误非常低级，瓷砖没有按照墙厚对齐铺贴，否则根本不会出现这种问题。只能切割木地板，重新补贴一块瓷砖来解决。大部分卧室木地板，客厅瓷砖，太多人没有注意木门安装位置，就会导致上图的效果，不影响功能，但是非常难看。像上图如果是外平内开木门就可以压住，但是铺设地面难道不考虑木门做法吗？解决：只能切割木地板，然后补一下瓷砖。木地板瓷砖都没有问题，但是都默认是普通木门，结果用的是外平内开的木门，关上门，卧室里头露出难看的瓷砖。只能切割瓷砖，然后补铺木地板解决。上图同样是缺少沟通，地面按照正常木门考虑，结果后期是外平内开卧室门，关上门卧室里头露出难看的瓷砖。家里不是通铺木地板，卧室木地板的时候，一定要问清楚安装什么样的门，否则你按照传统木门做法预留，但是外平内开门，卧室就会露出一截瓷砖，丑陋无比。正常卧室门，里头木地板，外头瓷砖，一定要知道门的厚度以及套线厚度，保证门关上刚好压住两个不同材质的衔接缝，这样关上门才是完美的。第二种、外头木地板，卫生间瓷砖卧室木地板，主卫瓷砖，结果没有考虑门的位置，关上门以后露出一大截瓷砖，丑陋无比。双包套比较好改，因为双包套可以实现内装内开，也可以实现外装内开，终于解决了难看的瓷砖。如图外头木地板或者木纹砖与卫生间瓷砖的接缝位置，不仅仅是金属门的厚度，还得考虑套线压墙的厚度，这样才能满足关上门不露瓷砖的问题。第三种、不同瓷砖衔接需要考虑门的装法。大部分卫生间干湿分离，都是单包套做法，结果你用双包套，而且还是内装内开，干区是花砖就会露出湿区的一节瓷砖。解决办法：双包内装内开，改成双包外装内开即可。外头是木纹砖，卫生间是小花砖，提前要知道门套压墙的厚度以及金属门的厚度，这样就可以保证关上门以后，两个瓷砖的衔接缝隙刚好被压住。卫生间高低台位置错误，关上门里头看到客厅瓷砖。如上图的高低台做法，如果花洒离门很近，高低台压根不防水，水会流到门上，从门缝隙到了客厅，所以这个高低台位置本身错误导致；如图上图就是高低台位置错误，花洒离门很近，结果你关上门以后，花洒水流到门上，流下来全跑到客厅了。注意：如果花洒离门很近，如上图高低台不动，金属门就得内装才行。金属门外装，高低台必须在门的下方，这样花洒离很近，水不会流到客厅如图所示，外头木纹砖与卫生间花砖衔接随意，就会导致关门外头可以，但是天天坐马桶看见里头一节木纹砖，很闹心。各个工种需要有团队协调，否则看似便宜。只不过降低装修价值而已。第四、推拉门以及联动门不注意会更丑。如果地面是一个材质通铺，此时不论做什么形式的门，都是可以的，不需要有特别注意的地面细节问题。如图所示，外头是木地板，厨房是瓷砖，此时如果不注意门的位置，就会出现上图，关上门以后，露出一节瓷砖的问题。如果想要外头视觉完美，就需要让衔接缝刚好在内侧门框下方压住，此时外头是看不到任何瓷砖露出的。上图看似能好一点，但其实里头露出一节木纹砖。如图，外头倒是可以，但是忽视了里头的问题，结果露出太多木纹砖，其实还好，因为是推拉门，两个门不在一条线，再完美都需要有少部分露出的。三联动更麻烦一点，关上门以后，右边露出一节厨房地砖，最好的办法是尺寸卡死，木地板再朝内移动一点，关上门以后视觉更完美。上图就是翻车了，压根没有考虑门的问题，关上门以后真的不好看。当你压根不懂细节的时候，总为自己的最低标准欢呼，但是稍微有点审美的邻居，一眼就能看到问题。这个更无语了，做了传统厚重的地轨，结果没有压住缝隙，要不砸掉重新做，要不忍受。如图所示，只顾着嘚瑟门多么好了，压根没有发现翻车的地方，这个其实就是价格与价值的区别---因为别人比你花得少，还比你更有价值。后记：其实装修说简单也简单，你降低标准什么错误都没有了，但是装修只剩下价格，价值没有了。所以装修一定要找注重细节和良心团队。
