# 少量六边形瓷砖点缀，造价不贵有设计感6.15

六边形瓷砖属于点缀花砖，因为其规格的六边造型，不同于一般瓷砖，视觉比较新颖，而且花色众多，所以在装修中属于比较时尚的元素。

造价不贵，一块才几块钱，但是对于铺贴造价高一点，毕竟瓷砖太小了，工人铺贴耗费的时间相对较长，所以一般少量铺贴，工人都是论堆论项算钱，而不是给你按照平方算，除非面积很大。

01卫生间运用

▲北欧风常见的做法。经典的小白砖地面铺贴，墙面统一采用白色六边形瓷砖，视觉要活泼新颖，同时搭配黑色的极简五金，视觉质感明亮。黑白色可以让空间更简单，更开阔

▲墙面爵士白与地面六边形瓷砖搭配，浅色可以让空间干净清爽，同时六边形又能给空间增添活力

▲淋浴背景，单独采用六边形瓷砖局部点缀，大面积白色，深浅灰色与黄色点缀，视觉更加活泼，让整个卫生间整体提亮

▲马桶背景，很小的卫生间，不要淋浴，只有马桶和洗手盆，可以给马桶背景采用深浅不一的灰色与白色六边形瓷砖搭配，视觉时尚，高级感呼之欲出

▲白色哑光面的六边形瓷砖铺贴，搭配局部防水漆，视觉干净时尚，同时又有质感
▲干区背景灰色六边形瓷砖点缀，与原木对比，让空间生动温馨
▲放到干区背景，能让干区小空间更具设计高级感
▲如果你也想让自己家卫生间与众不同，可以少量采用六边形瓷砖让空间高级起来

02厨房运用

▲北欧黑白厨房极简搭配，墙面经典小白砖铺贴，地面采用大面积六边形瓷砖，局部深灰色与浅灰色点缀，与黑色橱柜颜色呼应，视觉更新颖，活泼清新之余，视觉极简质感

▲小规格墙面砖搭配地面六边形石材瓷砖，带花纹地面更耐脏实用，视觉上清爽简洁
▲也可以只给厨房吊柜与地柜之间做背景装饰，做饭都有好心情了

03门厅运用

▲门厅空间局部采用六边形花砖点缀，而且可以与木地板无缝衔接，视觉上非常时尚新颖

▲单独门厅区域，局部黑白灰三色六边形瓷砖点缀，局部上墙装饰，视觉上有延伸感，也让进门口生动时尚

▲门厅单独空间与木地板的无缝拼接，视觉更灵活时尚，进门眼前一亮

▲轻奢风门厅地面，采用黑白配六边形瓷砖铺贴，合理分区，同时视觉上提升高级感

▲门厅进来纵深的过道空间，单独采用黑色六边形瓷砖，复古有质感，视觉上生动有趣
▲狭小的门厅浅色六边形瓷砖的运用，也能让空间充满活力，时尚高级感呼之欲出

04客餐厅运用

▲也可以利用六边形的花砖，作为餐厅背景使用，颜色由浅及深，视觉层次感更丰富，同时营造温馨的就餐氛围
▲楼梯间采用灰色哑光的六边形瓷砖铺贴，稳重中又有时尚元素，合理分区让空间更生动
▲阳台的休闲空间，也可以采用灰色系六边形瓷砖铺贴，让休闲空间更具活力
▲尽量不要大面积使用，太密集，而且会让视觉有压迫感，容易让人焦虑
▲即使用到卧室角落，彩色的六边形瓷砖也能给空间高级设计感，非常新颖
▲可以让明亮的阳台充满高级感，更时尚生动六边形瓷砖真的很火，只能局部点缀
