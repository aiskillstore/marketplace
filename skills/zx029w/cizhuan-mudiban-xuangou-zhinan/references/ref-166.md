# 卫生间带阳台，不改造就亏大了，这样改才更有价值1.26

前面有一篇厨卫夹阳台的专题，大家可以参考一下《厨房阳台有卫生间窗户，这房咋装？》今天看一下卫生间带阳台的户型怎么装修。…1.卫生间通向唯一的生活阳台/洗衣间
卫生间带家里唯一的生活阳台，没有办法只能安装玻璃门分割起来，其实是有利有弊的做法。洗澡时候采用折叠浴帘分割一下马桶位置，刚好形成独立的淋浴间，避免水到处都是。玻璃门分割的生活阳台，放置洗衣机和洗衣池，平时可以收纳一些清洁用品，每次洗澡换下来的脏衣服刚好可以放生活阳台，这个就是唯一让人欣慰的优点了。缺点也是显而易见，洗澡的时候不是独立空间，而且洗澡时候生活阳台无法使用，家里人多很不方便。如图一样的卫生间外面是家里唯一的生活阳台，只能采用折叠门分割，这样就会导致洗衣和洗澡必须错开时间使用。卫生间带一个家里唯一的洗衣间家政间，没有办法，只能采用玻璃门分割相互独立虽然不是很舒服，但是没有办法，基本功能需要实现，只能用门分割一下，保证各个功能的相对独立好处是都采用玻璃门分割，采光相对通透，同时平时卫生间通风也不受影响，空间大的话弊端会显得弱化一下。…2.卫生间带阳台作为储藏间这个就是典型的厨卫夹阳台的户型，只不过是把阳台与卫生间打通，但是阳台需要放置壁挂炉不让改成淋浴间（各个地方政策不一样）所以，只能作为杂物间使用，淋浴还是和马桶放一起，然后卫生间做了浴柜外置的干湿分开，还好只是杂物间，平时使用频率少一点，只不过进入杂物间需要经过两道玻璃门而已。原有小阳台做了保留与卫生间一体化设计，作为独立的宠物乐园兼顾家里的储藏间…3.打通阳台与卫生间一体化设计原有小的生活阳台与卫生间打通设计，洗衣间兼顾卫生间使用，功能不变，但是空间和光线要通透多了卫生间与阳台打通重新分割，干区洗烘机和浴柜外置，原有阳台位置实现花洒和马桶，让功能和健康并存。原有卫生间带生活阳台规划成了湿区，把生活阳台与干区融为一体，这样的设计才更有价值把洗衣机挪到卫生间干区，打通空间，把阳台改造成了浴缸和花洒共存的浴室独立空间，光线和通风效果更好卫生间与阳台打通拓展空间，实现一个超级高级明亮的卫生间《阳台变浴室，这高级感太难拒绝了》
