# 经验|夏季地板铺设七大罪，绝不能这样做！！！

第一罪：地板堆积
夏季原本就是气温高又干燥的火灾高发季，装修现场材料多、工具多，木地板不放在阴凉的地方就算了，还和其他的材料堆积在一起，还放在插头、电线连接处，一不小心就会因为温度过高而导致材料燃烧，导致火灾的发生。

第二罪：不注意地板环保性
夏季经常会出现雨水下个不停的天气，在这个时候需要注意地板的含水率，标准板材的含水率不能超过12%。此外，甲醛是木地板生产过程中不可避免的添加物，当湿度超过45%、气温达到28℃以上时，地板里的甲醛会成倍释放，所以能闻到强烈刺鼻气味的木地板不能要。

第三罪：高温和雨天施工

一般来说，装修的温度应该在5℃~35℃之间，超过这一温度的话地板容易变轻，且过高的温度也会影响工人的工作状态，不利于最后的铺设效果，一定要避开高温天气。除了高温，不要为了赶工期就在雨天的时候施工，尤其是连绵不断的下雨天，雨天的空气湿度通常会达到70%甚至以上，会影响到地板的铺装效果，日后也可能会出现地板起拱、翘起等问题。

第四罪：不考虑地暖墙暖
南方地区地暖、墙暖比较少见，北方基本都家家户户都有。大夏天的时候虽然不会开暖气，但是也不能忘记它的存在。钉地板钉的时候要注意避开地暖管道，靠近墙暖的地板也要注意一下。

第五罪：地板间隙太大
有的装修工人为了节省时间，铺地板的时候没有将地板拼得紧密一些，这样会导致天气干燥的时候，地板收缩，地板的间隙会变大，导致地板松动或者变形。

第六罪：阳光直射地板
夏天天气热，不少人会开窗通风，这样一来，地板就会被阳光直射暴晒，强烈的紫外线会破坏地板表面的油漆，加速地板干裂和老化。

第七罪：刚铺好就踩上去
刚铺完的地板整齐又美观，脚贱星人迫不及待就要上去踩两脚，再把其他地方的东西都放到地板上，看上去好像很利用空间的样子。事实上，地板在刚铺好的48小时内，尽量避免在地板上走动和放置重物，要给地板胶的黏结留出足够的空间和时间。
