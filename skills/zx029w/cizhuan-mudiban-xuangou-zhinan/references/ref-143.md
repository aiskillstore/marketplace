# 木纹砖没有污染，想好是否做美缝2.14

现今装修，真的是日新月异，和过去的仅仅是个窝不能相提并论了。对品质和环保装修的意识已经慢慢渗透到普通的生活中。

▲比如过去的无知年代的，木地板通铺的做法。认为这样才是高档，才算是有钱人。从来没有思考过，木地板会给家人带来多少祸害。一味的相信洗脑的教育，失去独立思考的能力。

▲现在不同了，随着全球信息化，大家的思想已经意识到，装修环保的重要性，也不再盲目的相信各种洗脑宣传，以品质为重，以家人的健康为主的装修理念已经形成趋势。

所以从喜欢过去的木地板，到如今害怕木地板污染，采用木纹砖的变化，就能看出来大家环保意识的觉醒。

但是关于木纹瓷砖有两个概念：一是和木地板一样规格的木纹砖，二是大规格的木纹瓷砖，如600*600的或者800*800的木纹瓷砖。

虽然都是木纹瓷砖铺贴效果是完全不一样的

一、小规格木纹瓷砖

▲注意，上图就是和木地板一样规格的木纹瓷砖，做完以后做了白色美缝的效果，看上去一点不像木地板，因为木地板是没有白色缝隙的。如果面积大，可以想象满房子的缝隙密密麻麻。

▲注意上图同样是木纹瓷砖，但是没有做美缝处理，做的是勾缝处理。是不是看起来要好一点，密密麻麻的缝隙不是很明显？但是有一个弊端，过不了几个月，只要入住，这些缝隙基本都会变成黑色。因为每天拖地，不干净的拖把污渍就会把原来的白色勾缝污染成黑色。

▲这就是没有做美缝的木纹瓷砖，注意看缝隙，在常年拖把的伺候下，缝隙已经让污渍布满，看不出当初的白色勾缝剂的效果了。

▲木纹砖有一个优势，就是和其他瓷砖无缝衔接，直接对缝就可以，不会像木地板，担心翘边问题

所以，问题就来了。这种小规格的木纹瓷砖到底是做美缝还是不做呢？还是用相同颜色的美缝剂合适？

其实，这个不需要纠结，因为这个问题无法完美。有得必有失。代替木地板没有污染，这才是用它的目的，而其他只不过是它与生俱来的副作用罢了。

其实和药物治病一样道理，是药三分毒，这就是治病带来的副作用，无法解决。所以小规格木纹砖是否美缝，完全取决于你的喜好。

第二、大规格木纹瓷砖

▲注意上图就是600*600的大规格木纹瓷砖的效果，同样做了白色美缝处理，后期缝隙不会变黑。与小规格相比较，大规格的缝隙要少很多，不像小规格显得那么杂乱。是不是更好呢？而且从铺贴工费来比较，大规格的铺贴工费比小规格要低很多。

▲注意上图使用的是大规格800*800的木纹瓷砖，只不过是中间裁割以后，做成了400*800的效果，然后工字型铺贴，这样空间更加生动。同样采用白色美缝处理，与小规格来比较，缝隙要少很多了。

经过实景对比和分析，可以得出一个结论：木纹砖规格越小，成本越大，铺贴工费越高，同时美缝的单价也越贵。所以如果可以接受，普通百姓，用600*600或者800*800的木纹砖最实惠----即使做美缝缝隙少，铺贴工费也相对低，同时美缝以后的缝隙也少，不凌乱。

第三：木纹瓷砖的各种铺法

▲最常见的铺法，也是最简单的铺法，和木地板一样，369铺法，长边和短边错开三分之一，也叫作步步高铺法，非常形象的叫法，有视觉延伸感。当然还有28、五五等铺法，都是工字型铺法的一种延伸。

▲也可以人字铺法，也叫作八字铺法，更灵动，更具有高级感

▲田字方块铺法

▲双人字铺法

▲三人字铺法

▲人字铺法，灰白混搭铺法，多用于工装大厅，很时尚

▲木纹砖鱼骨拼花铺法

木纹砖根据规格不同有不同的铺法，同样因为美缝或者勾缝的原因，铺法越是复杂，美缝处理以后的缝隙越是突出，所以最终效果的接受程度，各位装修业主一定要做到心里有数。
