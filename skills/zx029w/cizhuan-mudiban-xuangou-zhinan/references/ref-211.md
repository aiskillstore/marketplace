# 二手房直接地砖铺木地板，绝对可行12.6

▲二手房或者旧房都存在重新装修的问题，大部分能买二手房或者旧房，对于装修基本能简单就简单，大费周折，浪费大把时间和金钱往往划不来。所以就存在什么该拆什么该留的问题。

▲旧房只要原来的地砖没有破损或者大面积空鼓，其实完全可以使用。后期保洁打扫干净以后，和新的没有什么区别。有可能只是不喜欢颜色而已。但是自己一定要清楚自己的钱包能力，如果不动是要节省一笔费用。不喜欢颜色可以用地板做装饰，改变原来的地面印象，实惠而且好看

▲如果要砸掉地面，一定注意看旧房是地暖还是暖气。如果是暖气管路简单，砸地砖过程可能会破坏管路，这个很简单，后期暖气片可能需要调整或者移动位置，重新布置管路就行。但是如果是地暖就谨慎。工人用的是电锤工具，只要动，必定破坏原来的地暖管路，这个不像暖气管路那么简单，如果破坏多了全是隐患，搞不好还得重新做地暖，费用更多了

▲砸掉地面砖不是像上图一样只拆除瓷砖，而是拆除到开发商的原有砂灰层的。如果只是像上图的拆除方法，一是没有必要拆，二是你家瓷砖不可能和水泥直接分离，出现这个情况是全房瓷砖都大面积空鼓，才能只去掉瓷砖

▲观察旧房瓷砖的缝隙，如果缝隙大于或者等于1.5毫米的时候，就可以不动地面，把所有缝隙打扫干净，后期做美缝处理，和新砖一模一样，完全可以使用

▲在原来的瓷砖上直接做自流平铺PVC地板可行不？其实是可以的，但是前提是原来的瓷砖平整度误差小于两毫米，这一个条件恐怕没有几家能合格。

▲直接铺不带龙骨的木地板是可以的，只要原来地面不存在大面积空鼓，没有损害都是可以直接铺木地板的，如果只有局部有损坏，可以只把局部瓷砖砸掉，修补平整达到铺木地板的要求都是可以的。尽量不使用龙骨铺木地板，因为旧房地面本身平整度如果太差，龙骨铺上以后平整度会更差，后期木地板就会出现不平，长期踩踏肯定会变形

▲旧房瓷砖上直接铺木地板需要注意就是暖气问题，如果是暖气片不受影响，如果是地暖，热量传送肯定受影响，本身下面一层瓷砖，热量需要穿透瓷砖，然后在穿透木地板，热量整体效果肯定受损，这个需要明白。如果原来旧房是木地板就简单多了，旧房木地板如果完好无损，可以保护起来就行

▲原来地面木地板或者瓷砖不动的时候，施工前期一定记住地面一定好好保护起来，否则后期就会大面积损坏

▲如果原来地板是纯实木地板，而且没有损坏，施工完毕可以让进行翻新，直接打磨然后重新刷漆，效果和新的实木地板一样，费用就低很多。当然强化和复合板子是无法翻新的，因为打磨层就会破坏耐磨层
