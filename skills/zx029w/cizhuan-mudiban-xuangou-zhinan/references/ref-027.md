# 过门石必不可少吗？可以不用不？9.17

过门石相信大家都非常熟悉了，但是为什么要用过门石或者过门石哪地方需要，起到什么作用，好多人都搞不明白。装修的时候基本就是跟着别人屁股跑，反正大家做了，自己做了，错了还有个伴。

第一个：阳台过门石

▲如图客厅阳台是生活阳台。

1.此时取决于地面铺设的材质，如果都是瓷砖，你想要分区不同的话，此时是需要用过门石进行分区过渡，否则不同的瓷砖缝隙错乱不美观；

2.取决于你对防水的要求，如果都是瓷砖，你想要阳台做防水，此时阳台与其他区域必须做过门石，进行区域划分，过门石高于阳台，这样防水的才有意义；但是无形中增加了装修成本---因为阳台除过五金件买好一点以外，压根就没有水，防水本身就是一个心理安慰（阳台做防水的条件，必须有过门石，必须有能下水的地漏，而这两个其实都是多此一举）

3.阳台与其他区域瓷砖直接通铺，此时不仅省掉了过门石，同时视觉上可以放大空间；而且省掉了阳台防水的必要，这个才是现代装修的应该去考虑的地方。

4.阳台是瓷砖，其他区域是木地板，阳台不做防水。如图客厅木地板，阳台采用相同颜色的木纹砖用来防潮防晒，此时取决于是否有移门相隔，有移门的话，是不需要过门石的，移门的轨道直接压在不同材质的分界线，起到过渡以及防止木地板翘边的作用。需要注意铺贴的时候就得考虑好移门安装位置，后期移门一定要压在两种不同材质的缝隙上。

5.阳台是瓷砖，其他区域是木地板，阳台做防水。中间没有移门，此时不同材质有的人往往会加一块过门石，如上图，非常不美观，让空间更加零碎了

▲正确的做法是减少过门石的突兀感，直接采用铜条过渡即可，既美观又能让视觉舒服。前提是阳台不做防水，否则此时的防水几乎没有意义。

▲铜条不仅美观而且可以防止木地板翘边，完美解决问题，比难看的过门石要美观多了

▲完全能对缝通铺的何必加过门石？除非你非得给阳台做防水，此时才需要过门石起到作用，否则这个过门石完全多此一举。

总结：如果都是瓷砖，阳台与其他区域是无需过门石的，同时不论是休闲阳台还是生活阳台，都无需做防水，除非你在阳台砌了个鱼池才需要；

如果其他区域是木地板，阳台是瓷砖，阳台也不需要做防水，此时也不需要过门石，直接用铜条过渡即可，如果有移门连铜条都不要，直接移门轨道压住缝隙即可，如果用上轨道移门就必须要铜条了。

第二个：厨房过门石

▲如图公共区域是木地板，厨房是瓷砖，此时厨房也是无需过门石的，和阳台一个道理，不同材质直接用铜条效果要好很多。但是前提是厨房没有地漏，无需做防水；如果有地漏，是必须做防水的，《没有地漏的厨房做防水，就等着破产吧！》此时必须有过门石，否则无法有高低落差，防水就没有意义了。
▲正确做法是厨房没有地漏，不需要做防水，同时采用公共区域的大地砖直接通铺，一般大部分户型都是可以对缝铺贴的。最好采用柔光质感瓷砖，这样通铺以后，厨房也能起到防滑耐脏效果。完全没有必要采用不同瓷砖，导致很小的空间更多分割，更零碎
第三个：卧室过门石
▲卧室如果是木地板，外头是瓷砖，此时是无需过门石的，采用轻巧的金属条直接收口兼顾过渡，视觉效果要美观多了
▲如果内外瓷砖无法对缝的话，此时是需要过门石过渡，但是过门石的突兀感太强的话很难看，所以此时需要找类似颜色的过门石，让两边颜色很好的过渡。《过门石搭配，要不对比，要不相近》
如图不仅用错了了过门石，同时铺砖也是错误的，缝隙只差一点距离，是可以对缝省掉过门石的，只要没有窄条瓷砖出现，完全可以实现通铺
▲还可以采用相同瓷砖进行裁割代替过门石，但是缝隙太多，太乱，不美观。正确的做法卧室门洞一般是85公分左右，你家用800*800的瓷砖肯定就有缝隙了，所以应该找一个规格比门洞大，颜色最好一样的瓷砖代替过门石，视觉上更好看
▲如图通铺800*800瓷砖，但是进入卧室无法对缝，所以必须过渡采用过门石，但是过门石颜色太突兀，所以找到类似颜色1200*600的瓷砖裁割代替过门石的做法
▲注意上图进入卧室的区域，采用的就是大规格瓷砖裁割，颜色上能与地砖更相近，视觉上不会像石材过门石那么突兀
▲卧室瓷砖与外头瓷砖通铺的前提必须有两个，第一缝隙必须能对上，第二也是最重要的，对缝以后卧室不会出现窄条瓷砖.
▲你家能不能卧室通铺客厅瓷砖不是随意想的，是你选择瓷砖以后，瓷砖商家必须出排砖图决定的，否则边铺边看，必然会有翻车可能

第四个：入户过门石

▲几乎家家户户入户都有个过门石，突兀而且不美观，其实完全可以不用
▲如果通铺瓷砖，可以找一块大规格瓷砖裁割，保证是一整块，代替难看的过门石即可，视觉上能更舒服一点
▲还有一种办法，如图所示，直接瓷砖铺过去就行，无需过门石，只不过需要对缝，门口不一定是整块瓷砖而已，但是看上去更能弱化过门石的突兀感，效果更好，而且还省掉了过门石的费用
第五个：干区过门石
▲还有一个干区过门石，有的人给干区做了过门石做了防水，其实这个地方一般很小，防水是多此一举，一旦爆管以后，压根来不及流进地漏的，所以通铺视觉更美观，把五金角阀龙头软管买好一点就行

第六个：卫生间过门石
▲干区和其他区域无需过门石，但是卫生间湿区要不要过门石呢？
如图所示如果做了干湿分离，湿区同样做了淋浴隔断，此时你得问你后期打扫马桶区是否用水，如果用，干湿区必须有过门石。你如果后期马桶区从来不用明水打扫可以不用过门石，干区的大砖都可以通铺，唯一的条件是挡水条预埋，淋浴房里头做好坡度即可
但是一般家庭不可能马桶区不用明水打扫，所以没有人敢冒这个风险，入住后悔就迟了，所以还是选择湿区一定加过门石的做法▲干湿区用过门石的原因一是为了防水，第二因为地面有高低差，石材过门石可以倒弧边处理，不会磕碰，这样可以阻挡潮气以及水的侵蚀，所以全房如果能满足通铺，都可以不用过门石，但是卫生间是必须做的。当然好多人为了美观采用瓷砖甚至用铜条代替过门石，这样的做法风险极大，后果自负了。
