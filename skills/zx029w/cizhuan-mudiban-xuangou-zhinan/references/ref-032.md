# 阳台用大砖还是小砖？装修前就得明白9.23

最近有咨询阳台铺什么样的瓷砖，大规格还是小规格，其实这个要根据家里的实际情况决定的，所以具体分析一下，大家可以对号入座。

一、阳台放洗衣机
阳台放置洗衣机又分为三种情况：
①阳台下水是竖管     ②阳台下水是地漏    ③竖管和地漏都有

①阳台只有竖管，后期要放洗衣机，无地面地漏。如果是这种做法，阳台就可以选择任何规格的瓷砖，因为没有下水，无需考虑水流的坡度，完全可以用大地砖通铺。阳台洗衣机竖管下水切记，购买洗衣机有上下排水的，否则可能买回来洗衣机水排不干净。

②阳台只有地漏，还得放洗衣机，这就得注意了。用大砖还是小砖取决于是否做坡度。如果要做坡度必须用小规格瓷砖，否则大规格瓷砖无法做出水流坡度的。还有一点最最重要的，有地漏洗衣服容易反水，可以参看此篇《阳台放置洗衣机和洗衣池，这些得明白4.7》

如果阳台是地漏，还是坚持大地砖通铺，阳台的防水就失去意义了，这些装修前就得规划好，否则，阳台与其他区域相连，大地砖通铺，你只在阳台做防水没有任何意义，只有当阳台有地漏，而且阳台是个独立的空间时候，阳台防水才会有意义。《阳台防水怎么做？或许以前装修都做错了！7.23》

③竖管和地漏并存。有好多家庭都有这个情况，一般这个情况是阳台放置洗衣机，同时放置洗手盆，同时还要晾衣服，必须满足这三个条件，地漏和竖管并存才有意义-----晾衣服如果有少量的水滴到地面，地面有防水，同时有地漏，就没有后顾之忧了，当然阳台必须是单独空间，而且有过门石分割。

否则如果阳台不晾衣服，完全可以留个地漏或者竖管，洗手盆和竖管共用即可《洗衣池+镶嵌洗衣机，水电路一定走对7.15》如果是两者并存和只有地漏一样，大规格瓷砖无法做坡度，如果坚持通铺，阳台防水就没有意义了，装修前这些都得一次性规划好，绝不是你找游击队或者散工，或者找个不负责任的装修公司，什么都不规划，做一步看一步，然后步步都是错的。

二、阳台不放洗衣机，也没有下水。
当然这种阳台就好办了，可以任何瓷砖铺贴，不存在任何顾虑。通铺可以放大空间，这个在9月18日推送头条有详细分析。
