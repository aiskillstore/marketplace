# 干区不想全贴瓷砖，怎么防止溅水？6.20

首先再次声明，碰到装修里头的干区，一定是洗漱和马桶的分离，可不是把淋浴做个玻璃那种带误区的干湿分离《干湿分离就是把水隔开？别再误导业主了10.8》

▲上图就是彻底干湿分离，全部铺贴瓷砖，因为避免不了有水，所以干区全部做瓷砖是最佳方案。但是事情都是相对的，全部做瓷砖就显得这个区域冷硬，于是就有了如果不想全部铺贴瓷砖，怎么能又防水溅，又能美观的效果呢？

▲可以用瓷砖代替挡水条，加高处理，比如上图用白色瓷砖做挡水条，加高尺寸，然后用弧形收边腰线把瓷砖收边，美观，同时也能起到防止不小心溅水的作用，其他墙面就可以用喜欢的或者与风格相搭配的变色乳胶漆做装饰了

▲与第一幅图不同的是，同样用瓷砖做挡水条设置，上图是整面浴柜都做了瓷砖背景以及挡水。仿马赛克瓷砖装饰，用腰线收口，同样起到防止溅水的作用，同时下方整体铺贴瓷砖，可以防止长时间有水的潮湿，其他区域普通乳胶漆变色即可

▲如果干区一侧没有实墙遮挡，这样的话就无法用瓷砖铺贴加高挡水了，只需要在侧面做一个隔断即可《品质家需要干湿分离，干区隔断更重要6.1》装饰兼顾功能，同时只在干区背景铺贴瓷砖或者马赛克，同样可以起到防止溅水的作用，整体颜值也很高

▲能不能像上图一样，砖砌洗手台，然后瓷砖只贴局部呢？当然可以，不过得注意瓷砖收口无法解决，只能后期用腻子直接收口，仔细看的话确实不美观，但是居家过日子完全不影响使用，当然，还得业主自己能接受，否则装修公司这样干，你不得火冒三丈？

▲只给背景贴瓷砖，其他区域乳胶漆，也是常见做法，防止局部溅水，同时又没有满贴瓷砖的压抑

▲不贴瓷砖直接用乳胶漆还是比较清爽，但是就是有溅水的可能性，后期一旦溅水，不好打理，即使用所谓的防水漆，也是不管用的，防水漆是相对的，不是绝对的

▲如果实在干区不想贴瓷砖，可以全部使用乳胶漆，但是像上图一样，挡水条加高就行。浴柜定制的时候给交代清楚，挡水条需要多高都可以定制加高的，这样就不怕用乳胶漆会有溅水的担忧了
