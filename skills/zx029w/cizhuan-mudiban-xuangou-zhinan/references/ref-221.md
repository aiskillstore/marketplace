# 厨房改造谨慎，小心无法安装燃气热水器9.13

在实际装修改造中，虽然是自己的房子，按照理论来说，只要不破坏承重结构，想要怎么改造，那是业主的喜好问题。但是实际装修中，牵扯到各种电器的安装，有相关标准，在不知情的情况下，随意改造，很有可能造成后期无法安装的问题。

1.开放式厨房。
在北方装修，业主往往都有一定的经验：怎么通天然气？怎么安装燃气热水器？

几乎在北方，所有商品房小区，做开放式厨房都会面临通气问题。装修完毕物业验收倒是其次，天然气公司上门验收以后，合格才可以通气，而开放式厨房不在通气范围，也就是如果是开放式厨房，绝对是不会通气的。

那北方那么多开放式厨房是怎么解决这个问题的？
1.物业不管，验收人疏忽。不小心就可以通气了，但是燃气热水器的安装就是问题，这一关很难过。北方大部分采用的是强排燃气热水器，需要消耗室内氧气燃烧，有的商家是非开放厨房才给安装，厨房必须封闭，这样即使燃气泄漏或者造成缺氧危险，也不会殃及家里其他地方。但是有的商家不管是否开放，你掏钱就可以安装

2.新砌假墙，通气然后拆除。这个是没有办法的办法，曾经在融公馆就是这个问题，导致重新做了石膏板墙体，天然气公司验收了，通气了，回头拆掉了假墙实现了通气和燃气热水器的安装。

3.如果是开放厨房侥幸通气了，燃气热水器无法安装，其实只需要更换成平衡式的热水器就可以。强排的热水器需要消耗室内氧气燃烧，而平衡式热水器是消耗室外氧气燃烧，所以不与室内连同，也不会存在有废气污染或者缺氧的问题。平衡式热水器可以安装在任何室内空间，例如浴室都是可以的。

2.厨房外带阳台，没有打通，阳台与餐厅相通，燃气热水器阳台无法安装。

▲如图户型，厨房外带阳台，但是没有打通，而是把餐厅与阳台整体打通。如果燃气热水器挂到厨房没有问题，但是管路非常长，需要经过外面的阳台，而且会占用地方。所以挂到厨房外阳台最合适。但是因为厨房外阳台与餐厅整体相通，导致北方地区强排燃气热水器几乎不可能安装。
解决办法，因为前期不知道，上门安装才发现无法安装，一是直接给厨房外阳台单独安装玻璃门封闭起来，二是直接更换平衡式热水器就可以不装门安装，但是费用比强排要贵。
综上所述，以后要做开放式厨房需要知道当地或者本小区物业规定，或者直接采用假墙的办法操作，就是成本稍高一点，麻烦一点而已；如果是开放布局装热水器，直接安装平衡式即可；如果对装修费用非常在意的业主，最好前期做好规划，免得后期增加没有必要的费用和麻烦。热水器没选好，洗澡是一件痛苦的事
