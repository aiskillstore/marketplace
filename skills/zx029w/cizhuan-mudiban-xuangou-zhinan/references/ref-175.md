# 除过卫生间，都可以不要过门石，前提是必须能对缝3.16

不要过门石不是什么新奇的做法，这个是个人审美的问题。如果你不知道装修现在已经发展到什么地步，还是固步自封认为装修就是一帮泥腿子干活，那要不出租房，要不你压根对房子入住的品位不高，又或者你不知道能做多好，没有比较刚好碰到一帮看上去专业，其实很业余的团队。

▲入户必须有过门石，甚至还要压铜钱。这是爷爷奶奶辈流传下来的东西。不能叫习俗，免得连累别人。无可厚非，过去人的见识和思想你不能去怪罪，也不能排斥，人家喜欢就行。年轻人要与时俱进，还是算了，压什么铜钱，连过门石都不需要。

▲如果是大规格瓷砖，直接用瓷砖裁割做过门石即可，入门过门石就是一个衔接问题，不要弄个石材难看突兀

▲也可以不用瓷砖裁割，直接瓷砖通铺即可，入户本身小，为什么要分割一个难看的过门石呢？

▲卧室也是一样的道理，只要排砖图出来，能对缝隙，而且保证卧室露出来的没有窄条瓷砖，压根不需要过门石，通铺让视觉更有延伸感，让铺砖的结果多了一个放大空间的价值
▲如果卧室与外头瓷砖排砖无法对缝，如果对缝，卧室就会存在窄条瓷砖，此时就就不能强行对缝，必须有过门石，但是普通石材过门石不可能有和瓷砖一样的颜色，此时就可以采用同色瓷砖裁割做过门石，完美进行视觉过渡，和通铺一个效果
▲厨房也是一个道理，采用柔光瓷砖通铺，放大视觉即可，不论是采用地轨推拉门还是吊轨推拉门，地面肯定是通铺，一般户型，公共区域与厨房都是可以实现对缝通铺的
▲卫生间也是一样的，如果做了浴柜外置的干湿分离，浴柜干区肯定和公共区域一个瓷砖通铺，不要人为的去加过门石，导致本身刚需的空间显得更小气
▲阳台更不要说，即使放洗衣机，客厅肯定和阳台是打通布局，而且通铺不需要任何过门石的，而且阳台压根不需要贴墙砖，哑口套防水都省了，不仅好看而且还能放大空间。你如果还是八十年代的做法，阳台加个过门石，做个哑口套，全部贴瓷砖，然后客厅再弄个布帘，不仅费钱而且难看，最重要的花了钱反而让房子变得更小，更没有品位。
▲家里如果有木地板和瓷砖的衔接部位，也不要用过门石，你用了过门石还得压铜条，直接用铜条不是更好，而且一定选择这种T型的，可以选择直接瓷砖压住，然后木地板也能压住的款式，而且是极窄，做出来效果非常美观
