# 干区与其他区域要不要过门石？6.2

首先谈今天的内容以前，还是老生常谈，普及一下什么才是真的干湿分离《干湿分离就是把水隔开？别再误导业主了》千万不要认为自己家做了淋浴隔断，保护马桶，那叫干湿分离。这是外行的认为，也是装修有史以来最不动脑的结论。

懂了这些再看看，干区应该铺什么样规格的瓷砖，各有什么利弊。

▲干区与过道用过门石分割开来。一般这种做法，湿区与干区肯定也要过门石，就是视觉上在很小的地方有两个过门石，不好看而已。而且上图过道是木地板，必须用过门石分割，否则湿区一旦有水，会殃及木地板的。此时干湿区地面瓷砖都必须用小规格同样的瓷砖了，视觉上还能美观一点。

注意：一般干区如果与其他区域有过门石，最好在干区留一个竖管和地漏，这样干区就可以做防水了。以后一旦出现水漫金山，这个地漏就可以派上用场了

▲上图就不一样，干区在外面，所以直接大地砖通铺，不需要任何过门石分割，也无需做防水了

注意：上图通铺大地砖的做法，无需做防水，也无需留地漏，没有任何用处，一旦爆管是没有办法的。所以需要后期五金、软管、角阀、龙头这些品质好一点，防止水漫金山的风险。

总结一下：干区与其他区域过门石分割，瓷砖就用和湿区一样规格颜色的，视觉上统一。第二种办法就是其他区域大地砖直接通铺干区。

过门石分割的好处是，干区形成一个单独区域，可以留地漏和竖管，这样以后爆管可以防患于未然。否则其他区域通铺干区，只能祈求不要有爆管的可能。
