# 95m²不动柜子和地板，局部翻新老旧宅

老房翻新如果整体翻新，要比新房复杂得多，而且造价高很多。这就成了好多想翻新不敢翻新业主的心病。往往是满腔热忱碰到现实造价而不得不放弃。但是局部翻新，自己又没有主见，不知道哪地方该翻新，哪地方不该翻新，所以往往手足无措。今天看看这套半翻新的改造，也许能给想局部翻新的你带来灵感。
▲户型是典型的纯南三室刚需，因为是局部翻新，原来老旧的暗红色木门以及家具，就是入手点。从颜色以及收纳功能上让空间改头换面。
▲暗红色的木地板，这是过去老房子的标配，经年使用虽然老旧，但是并未有破损，所以木地板保持不动，采用打蜡的方式让其焕然一新。原来老旧的木门以及踢脚线拆除掉，取而代之是时下时尚的高级灰定制， 大大减弱了红色地板的压抑感。进门右手原来同样红色的厨房门拆除，更换了网红窄边框的黑色移门，同时把进门左手红色的鞋柜柜门更换为白色，与厨房门形成视觉对比，让进门视觉层次丰富。
原来的鞋柜虽然是顶天立地制作，但是朝向餐厅没有做隔墙镶嵌处理，为了餐厅完全以及视觉美观，统一采用与木地板类似的KD板做了装饰。不跳跃，但是又区别于木地板的暗红，让整体颜色不至于太突兀
▲改变餐厅背景以后，后期增加了一个电源，装上黑色红色的工业风壁灯，旁边挂钟搭配，视觉极简，增加艺术感。原来旧餐桌丢弃以后，采用大理石现代餐桌，搭配灰色以及黄色跳跃的时尚餐椅，让视觉清新现代
▲沙发与餐厅共用的背景，后期在保证基层完好的基础上，做了高级灰的变色，同时拆除原来的主灯设计，取而代之采用壁灯以及滑轨灯局部照明，增加空间的时尚感。家具采用皮质的灰色沙发，搭配轻巧圆几，亮黄色单椅与餐椅以及抱枕呼应，提亮整个客餐厅的亮度
▲为了解决以前收纳的不足，丢弃了原来传统电视墙的布置，采用新作通顶柜的形式满足收纳，同时上方隐藏投影满足偶尔娱乐的需求。整体收纳柜大面积白色处理，套色采用与餐厅背景KD板相呼应的形式。大面积无把手视觉简洁设计，上部局部镂空作为展示使用，下方镂空采用收纳盒的形式，放置孩子的玩具，视觉上不会凌乱
▲家里所有墙面基层没有做改动，修补了原有的各种污渍以及裂缝，局部改了电路的布置，直接刷漆就可以焕然一新。厨房门口过道旁半截墙做了灰色的黑板漆，贴上各种装饰，作为孩子的涂鸦墙。厨房原来的格局没有改变，只是更换了所有橱柜门的颜色，采用白色的吸塑亮光款式，可以在视觉上让空间明亮清新
▲客厅全景，地板是原来的，墙面基层是原来的，局部主灯改作了辅助光的照明。做了电视收纳柜，在原来吊顶的基础上镶嵌了投影幕布满足娱乐功能。餐厅背景采用KD板做了装饰。更换了客厅家具，局部的更新换代让家里焕然一新
▲主卧地板未动，原来墙面基层未动，局部改动了电路位置，撤掉了原来老土的主灯，取而代之是床头的黑色质感吊线灯。墙面背景采用深蓝色变色，搭配清新的组合挂画提亮视觉感。原来的木床没有更换，只是更换一套床品连同原来的窗帘一起，让整体温馨时尚。为了好看原来的床头柜只保留了里头的一个，更换成比较轻巧颜色相近的小圆几，摆上花瓶，视觉上美感提升很多
▲因为墙面需要翻新，所以新增加了床头的插座，满足两人的基本使用
▲床对面原有的衣柜没有改变，只是把原来红色的老旧柜门更换为平板的白色，采用黑色边框勾勒，与黑色滑轨灯吊线灯统一完整
▲因为不准备大动，所以书房以及次卧几乎没有改变，次卧和书房做了涂刷处理，更换了原来老旧的窗帘。书房唯一改动的就是原来的书桌，采用KD板就行了表面的翻新，新替换了一把时尚的座椅而已。
