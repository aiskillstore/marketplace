# 家有L型飘窗，怎么设计更好？8.23

▲最简单处理，什么都不做，做上布艺垫子，做成平时的休闲空间，但是你会发现，你永远没有时间坐在飘窗上，饿着肚子想着诗和远方。
▲实用做法，可以在L型飘窗上定制抽屉，一边延伸出来，可以作为书桌或者化妆台功能，这才是飘窗的实用价值
▲堆放杂物或者放个小书架，也算是物尽其用
▲房间整个做榻榻米，刚好高低和L型飘窗一致，拓展空间也算是飘窗物尽其用
▲原有L型飘窗如果能砸掉最好，做成收纳地柜，又能收纳，又能有休闲空间，一举两得
▲L型飘窗一边上头做收纳柜，兼顾化妆台，兼顾书桌，另一边铺局部垫子，作为休闲地方
▲长边定制收纳开放格，可以收纳书籍或者化妆品，可以兼顾书桌和化妆台功能
▲牺牲L型飘窗一边定制收纳书柜，成就收纳空间，预留一边休闲空间
▲利用转角飘窗直接定制L型书桌空间，而且还成就更多收纳
▲定制一排抽屉储物，提升飘窗的收纳价值
▲砸掉一字型一边定制书柜，同时成就一个小的书桌空间
▲砸掉飘窗做成收纳抽屉柜，兼顾收纳和休闲
▲定制一排抽屉，长边板材延伸，一个书桌空间就有了卧室有飘窗，可以这样装
