# 24个你不知道的设计，拿来借鉴一下2.19

其实装修设计靠的不是高文凭，靠的就是经验和创新以及对装修事业的执着，所以有些设计看似简单自己就是想不到，此时一定要放开思路和眼界，你能看到的好的设计，都可以拿来使用变为自己家装修的价值。.01衣柜进深太大，做衣帽间
如图所示，衣柜进深比较大，此时可以采用衣帽间的形式，延伸更多收纳；中间两扇门可以开启，两边固定门作为见光板，关上门以后就是一个衣柜样式内部U型设计，利用板材的交叉合理利用每一处收纳，远比一个衣柜的收纳柜量要大.02储物间不用做全屋定制
家里如果有储物间，不用费力费钱做全屋定制，板材不环保而且造价还高，其实根据空间大小，网购铁艺的货架即可，价格便宜，而且不占地，可以自己移动空间隔板，比定制更实用实惠.03入住人多鞋柜不要那么死板
如果入住人多，鞋柜下方镂空不要那么死板，只做一层收纳，其实完全可以两层三层，用来满足家里人多时候，临时鞋子的收纳，更方便实用.04马桶纸盒便利设计
如图如果马桶间旁边有收纳柜的话，可以做夹缝抽纸设计，省去了纸盒的安装也可以利用浴柜侧面柜的做法，满足手纸的收纳，也代替了纸盒子的功能《侧面柜的N种做法，你家是哪种？》.05一大一子母抽
如图所示，化妆台抽屉，抽中抽设计，这样的做法只有爱化妆的女人，才知道实用性，各种零碎都可以分类收纳，而且关闭以后就是一个抽屉的简单样式，空间利用到了极致厨房抽屉设计成抽中抽，也可以完美实现一些小物件的分类收纳，非常实用方便.06直角窗帘与交叉轨道
现实中往往会碰到拐角窗帘，如果做成直角，窗帘在拐角位置容易磕碰，不好拉，而且容易漏光；此时只要把拐角位置做45度斜角处理，同时轨道做弧形处理，就可以解决窗帘难拉和漏光的问题防止漏光还有交叉轨道的设计，原理一样，只不过占用空间以及窗帘间距是不一样的，想要好看一点推荐单向交叉做法《卧室窗帘漏光，觉都睡不好》.07洗碗机踢脚线
大部分洗碗机都不带踢脚板，此时如果是柜门落地的做法，就可以采用同色板做斜面处理，既满足视觉美观同时不影响洗碗机柜门的打开对于黑色的烤漆面板洗碗机，此时量好尺寸，网购亚克力板即可，但是高度需要注意，一定要留出洗碗机柜门的开启空间如果你用的是橱柜原有的踢脚板，此时只需要裁割踢脚板高度即可，视觉也统一，而且因为很低，裁割的地方是看不到的，也不会影响美观度.08燃气管道石英石隐藏弱化
燃气管道隐藏有好多办法《厨房燃气表和管路，3种遮丑办法7.21》，但是如果想要与台面一致的话，还是石英石做法好看，但是需要留出阀门位置，此时告诉石材做法，就可以实现一个隐形的管道装饰.09隐藏难看的晾衣服
肯定有人想到了隐形晾衣架，但是这种只是不晾衣服可以隐藏，一旦晾衣服视觉上还是乱的《隐形晾衣架，颜值和功能都有了》如图侧面晾衣架安装，因为有阳台墙体遮挡，此时即使晾衣服也不会导致整体阳台凌乱，所以这个才是避免晾衣服难看的最佳做法《阳台想要颜值，洗烘机机+侧装晾衣架》当然你也可以侧装隐形晾衣架，不晾衣服的时候看不到突兀的晾衣架，也是可以的如果有独立烘干机，平时就晾小件衣物的话，此时可以利用烘干机缝隙伸缩架的做法，不用的时候隐藏，也是完美的做法.010没有地方，化妆台隐藏实现
实在没有地方做化妆台的话，可以利用衣柜做隐藏式化妆台，其实也可以满足功能《隐藏起来的化妆台，其实也很简单》.011电器的抬高设计
