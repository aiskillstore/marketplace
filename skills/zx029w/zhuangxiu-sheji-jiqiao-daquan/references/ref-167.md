# 去家务化装修成空谈？这11个设计陷阱让你清洁到崩溃！

去家务化的理念不是一天两天了，但理论苍白，实际到现实里头，还有很多人“说一套，做一套”，明明奔着去家务化目的去的，但是装修的做法却增加了很多清洁难度。这期盘点一下这些为了去家务而做的错误的装修行为，大家引以为戒！01.想少擦台面结果做了挡水。明明装修的时候记着以后少点家务，但是橱柜台面却做了后挡水。用最好最环保的玻璃胶自欺欺人，结果撑不了几个月，再好的玻璃胶也是白搭，发黄藏污纳垢。有人错上加错不仅作了后挡水，忽悠你做个前挡水；后挡水是免费的，但是前挡水完全就是为了赚你的钱而已，但嘴上却说这样以后台面有水不会流到地面和柜子里头。当然有大聪明非得给定制加钱做弧形挡水，认为这样不会有脏的缝隙，但是完全无视挡水条与墙体的缝隙只能打玻璃胶的事实，时间久了还得发黄发霉，出钱还不讨好。正确的做法应该是：不要后挡水，极简留出美缝缝隙，后期美缝直接做，永远不会变色和发黄；不要前挡水也不要下挂，更极简，橱柜柜体深度可以做到最深《留还是不留？揭开橱柜台面挡水和下挂的真相！》当然不锈钢台面更好，只不过价格太贵，也有人不喜欢这种冰冷感，但最好打理的就是纯不锈钢台面。02.能用一体盆，非得用石材台面做台上台下盆很长的时间里头，是不是大家都被洗脑，台下盆非常干净，一定要做台下盆？陶瓷盆与石材的缝隙时间久了就是藏污纳垢的地方，特别是长期有水潮湿，暗卫的家庭，夏季这里真会生蛆的，所以陶瓷盆做台下一旦潮湿时间久了，其实是最脏的。《陶瓷盆，首选一体盆，其次台上，台下最脏》洗手池定制台面后挡水一样是藏污纳垢的地方，一旦台上盆没有购买平底，盆子与台面的缝隙无法用美缝处理，时间久了一样是藏污纳垢的场所，无形中都是增加家务的地方。如果地方小，即使你买的平底盆处理了盆子与台面的缝隙问题，但是形成了三面犄角旮旯，这三面缝隙都是藏污纳垢的地方，而且空间小很难清理，一样都是增加家务的做法。正确的做法是：陶瓷一体盆+墙排龙头。如果想实惠，搭配普通台上龙头不锈钢也是可以的；只有一体盆才是没有缝隙，更好打理，减少家务的做法《浴室柜肯定一体盆好，哪种最实惠？》干区固定尺寸也可以采用一体盆，新砌墙的话提前规划尺寸；如果是原有固定位置，也可以盆子买大一点，后期裁割满足一体盆的放置。03.水槽以为台上干净，结果更脏为了好打理千万不要水槽做台上盆，过去的机器槽本身有翻边，做台上盆有个棱角，虽然有时候采用玻璃胶封闭，但是任何玻璃胶时间成了都得藏污纳垢，变黄变脏。台中盆不是不能做，只是手工切割就有问题，必须机器切割台中盆才能达到完美效果台中盆做的时候下沉几毫米，如图所示，这样以后打理台面积水更好打理为啥要做台上台中，第一害怕台下会脱落，这个几率非常低；第二担心台下的缝隙藏污纳垢，这是水槽买错了而已，台下盆不要买机器槽，一定要做边缘平齐的手工槽，否则机器槽边缘不平与石材的缝隙非常大。最好打理的就是纯不锈钢一体水槽的做法，只不过价格太高，不适合大部分刚需装修而已。04.水龙头选不好，也会增加家务黑色龙头花洒自己住都不要选择，除非是出租房为了价格实惠，否则太容易脏了，绝对不要用。白色龙头看似颜值高，但一般白色龙头几乎都会出现上图的问题，所以不要为了一时颜值好看入手鸡肋产品。老百姓想要实惠和好打理，镀铬或者不锈钢拉丝的龙头都是可以的但是普通这种台面龙头遇到懒人也是一样难打理，与台面的缝隙不搭理时间久了照样藏污纳垢当然最好打理的就是这种入墙龙头，就是价格稍高而已，不会存在龙头与台盆缝隙的污垢。05.移门有轨道都会藏污纳垢只要做移门不论任何地轨都不好打理卫生，这是肯定的，特别是过去老旧的地轨更是藏污纳垢的重地。吊轨门才是最好打理，视觉更是极简，最适合懒人的，当然担心质量的话，就得购买质量过硬的产品。《当年被嫌弃的'穷装'厨房推拉门，现在成了全网模仿对象》06.为好打理亮面柜门和瓷砖，更难打理，还廉价网友@木子楠：高光PET照样一擦都是水印 ，很容易留手指印，深色或是在反射光下更加明显。《家里大面积亮光材质，翻车风险太大了》网友@刽子手：别傻傻以为亮光好打理了，一样踩坑，不仅难打理，而且灯光下材质就是没有柔光高级，总有种廉价感
