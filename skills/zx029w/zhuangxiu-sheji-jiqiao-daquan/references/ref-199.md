# 效果图+设计费，不一定有设计感1.17

其实类似的事情以前说过太多了，有好多都是重复的，不知道大家听腻了没有，自己有时候都说腻了；
有可能只是自己心里想着说过，其实大家都没有听过，所以今天就做个专题，系统说一下装修里头，表面看似为你着想，其实只图赚钱，把业主当做傻子的行为--例如认为做了效果图家里就有设计感了，收了设计费家里就上档次了。大家看了可以思考一下是不是这回事，如果是，就多多关注，也可以让别人一块关注，代表我说的是真话，如果不是大家大可开骂，反正骂不骂都得说，也就无所谓了。用不用效果图都得做，设计费也得收
有可能大家作为局外人是无法知道装修里头这些不合理地方，所以这个说法可能遭到反对：人家比较专业才做效果图，而且劳动了当然要收设计费，难道这个不该出效果图和收设计费吗？相信很多人都会有这种想法，这就和“便宜没好货”非常类似。一件同样的商品，你标价10元无人问津，但是你竖个牌子，原价50元，立马有人抢破头。现实就是这么奇怪，不可理喻。---你不推荐做效果图，因为明明业主就是刷墙铺地没有任何设计含量，你说实话了，业主反而感觉尊严受到了打击；相反你谄媚一下，收费给做专业效果图，虽然压根没有什么用，但是人却感觉到你尊重了他，而且心甘情愿给你掏没有任何用处的效果图的钱--现实就是这么怪诞，不可理喻。同样设计费也是一样的，你说实话了，你家就是刷墙铺地，压根没有需要设计的，设计师只是付出了自己的经验给了业主，也没有付出实质性的东西（当然这种付出是无形的，例如经验，例如专业等）但是有人立马就想到便宜没有好货，感觉自尊又一次被打击；相反你管他有没有设计含量，设计费照收，至于是不是真的设计了，对方总感觉挺舒服，现实就是这么不可理解，不可理喻--你以为设计费不收，就没有利润了？当然不是，装修机构的利润在施工，不在设计费，当然前几年很火的公司，就是本末倒置，设计费5万，施工费半包3万，还有人认为人家是高端设计。常常看到同行努力的去做效果图，结果业主家就是刷墙铺地，效果图只不过是一个旗帜的存在---上面好似写着：高级设计。业主有面子，装修公司有票子，这就是生意---现实确实不可理喻，不可理解。常常看到同行做的工地，没有任何设计含量，甚至错误百出。但是业主看不到，最大的不可理解的是设计费一平方收了100元，天啊，现实就是这么光怪陆离，让人无法理解。----因为你不收费，业主感觉你没有水平，能设计出什么样子？虽然你不收费比收费的设计还好，但是业主可能心里不美，总感觉便宜没好货。于是乎，你收一点设计费，不行，业主还是感觉便宜没有好货，于是乎一平方100元，虽然没有任何设计付出。---不对，有劳动付出，把一张图纸复制成N张图纸，然后采用A3纸打印出来，装订成册，而且还要弄个美美的封面，封面上艺术字写着：某某雅居设计图纸。---为什么不用A4纸打印？因为这样面子不够，显得不专业，而且一平方100元，费两张纸也值得。虽然所有装修公司几乎都没有A3打印机，都是A4打印机，但是为了“专业和水平高”也得到打印店掏钱打印，一张1毛钱到5毛钱，真值了。看懂了上面的文字，你也许会明白，为什么好多搞装修和搞设计的不停给业主洗脑，免费设计都是坑的真相了。因为大家不约而同的一致对外，给业主充足的面子，大家赚更多的票子。真的付出劳动了，真的有设计感了，业主也有这个钱变成现实，无可厚非，设计费多少都没有标准--一个敢要，一个敢给，成交。但是现实是太多压根没有设计感，就是做了个刷墙铺地，谁给他说你家不需要效果图，就感觉自尊受到了极大的打击一样---你收点钱吧，你不收心里没底。现实真的非常怪诞和离奇。
就说吧，这样的效果图意义在哪里？不能说毫无关系，最起码有东施和西施的关系。效果图的钱和设计费就是这样被白白赚走的。上图还原了吗？当然还原了，只不过效果图是想象世界，而实景才是现实，虽然一个高大上，一个感觉灰突突有点丑陋，但就是这样子的，现实就是这么灰突突的。所以你完全可以看着他们以前做的手机拍的照片看实景就知道样子了，何必做上头看似美丽实则无用的效果图呢？---更可笑的是现在好多装修机构都是靠着后期单反和修图，用所谓的高级蒙骗业主，但其实现实本身丑陋，好看在于你的内心。不是你后期掏了高级的摄像费用设计就高级了，羊毛还得出在羊身上，后期摄像费用都在设计费里头包含了。现实中太多效果图，就如上图一样，不能说毫无关系，最起码凑成了一桩生意，效果图也收费了，设计费也收钱了。此时业主骂娘已经迟了，这就是这个行业越来越烂的原因之一。几乎很多人的效果图只是为了面子和过程，至于结果压根不重要---你家具不按照效果图买，要效果图干啥？你软装不按照效果图来，要效果图干啥？掏钱做效果图的意义又在哪？这就是现实，就是这么怪诞离奇，明明知道自己不可能按照效果图来还原，但还得掏钱做效果图。以上举例都是压根不需要效果图的，平时装修的手机照片也比这个好看，而且不会有心理落差。因为装修本身如此简约，完全没有必要用高科技体现设计。如上图，如果你感觉自己家能有这种设计品味和档次，这样的效果图才值得掏钱，这样的设计费才叫物有所值。你家卧室如果能达到以上的装修档次，这样的效果图与设计费才完美匹配。对比一下自己家的装修，如果达不到以上的设计效果，基本上如果做效果图没有任何意义，收你设计费更没有任何意义，只不过是又凑成了一桩生意而已总结一下：并不是效果图就无用，并不是不让收设计费；只不过目前因为信息不对称，不要把效果图和设计费当成是约定俗成的事情，有时候效果图和装修毫不相干，不如不做，做过的工地手机拍摄才是最真实的；有时候设计费收了压根没有设计，那就是冤大头了。至于独立设计，这个肯定巴不得你效果图做得非常漂亮，否则怎么靠设计费生活呢？这个以前说过，大家可以参考这个《装修找个独立设计师省钱？坑到哭》
