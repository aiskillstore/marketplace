# 爆火的「去床头」设计，好用吗？4.26

分两种：无床头一种是刚需，一种是装饰；刚需的话对于小户型来说，非常实用，不仅省钱，而且节省空间。.01小空间定制不要床头
对于大户型来说空间不会有问题，但是对于小户型来说，寸土寸金，可能仅仅因为一个床头导致空间功能无法实现，所以舍弃床头成就空间，小户型更有价值。如图所示，就因为一个厚重的床头导致床尾空间非常尴尬，此时寸土寸金对于小户型来说就非常重要了舍弃床头以后，床尾刚好满足过道功能，成就小空间的价值如图为了成就床尾的衣帽架和储物能力，舍弃床头，采用成品的床头靠垫，满足了功能，同时节省了空间传统的榻榻米做法，更不需要床头了，背后衣柜挡板自然就是床头排骨架床代替榻榻米，此时采用成品的床头靠垫，代替传统床头，一样的功能，但是更节省地方嵌入式床头做法，利用定制背板满足床头功能，小空间更节省地方.02成品无床头更简洁
如图无床头实木床，视觉上看上去更极简，小空间视觉更加轻巧对于小户型来说没有床头空间可以节省出来，视觉上也更简洁，唯一需要考虑背后墙体的耐脏问题没有床头对于特定风格搭配，反而颜值更高小户型采用床垫直接使用，不需要传统的床头，空间更宽敞，视觉更简洁.03为了好看不要床头
如图为了视觉更美观，空间更有层次，做了半截定制木质面护墙板，此时购买无床头的床，不做氛围灯带，完全就是为了装饰和耐脏如图同样是木质饰面护墙板，只不过加入了灯带满足一个氛围的营造上图地台床同样是不要床头，放上床垫就可以使用，同样采用木质饰面满足一个床头功能，加入灯带可以满足氛围的营造不做木质护墙板，直接石膏板做，采用微水泥涂刷，可以保证耐用和好打理如图采用石膏板直接做造型处理，不要床头，也是可以的，一般这种卡通造型多用于儿童房空间如图所示，采用实木造型护墙板代替床头，就可以采用无床头的做法，同时满足风格需求也可以做成造型护墙板，满足无床头需求，同时满足风格需求定制硬包背景+壁画装饰，这样也可以实现不要床头的搭配.04舍弃床头成就收纳
如图所示，也可以舍弃床头，采用具有收纳柜功能的做法，小空间的极致利用舍弃床头，利用床头位置实现背景台面以及壁龛床头柜收纳，同时成就上方的超薄吊柜收纳舍弃床头满足背景的收纳柜定制，对于小户型来说能增加收纳储物利用床头实现收纳，舍弃传统的床头，收纳更多，同时两边壁龛满足床头柜收纳也可以舍弃床头，采用收纳柜代替床头，同时满足床头，同时延伸收纳舍弃床头，实现床头的收纳延伸
