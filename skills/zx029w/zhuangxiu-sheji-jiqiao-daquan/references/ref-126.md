# 装修15个独门设计，大部分人都不知道8.2

装修设计一是做工，第二是经验和创新，做工是第一要素，但是经验和创新往往可以解决意想不到的问题，让装修物有所值，所以今天看一下这些不常见的设计，自己装修也可以借鉴一下。

第一、极简窗台石。
窗台石几乎每一家都有，但是做法各异。

▲如图所示，常规的窗台石如图所示，两边出耳朵，边缘翻边倒弧，这种做法没有窗套的话很难看，而且突兀

▲极简窗台石，如图所示，不要耳朵，不要翻边，与窗台大小严丝合缝，看上去更极简高级
第二、厨房台面不翻台大部分厨房的台面做法都是中规中矩，大家都这么做就没错。

▲如图是常规的石英石台面做法，下翻5公分，为了防止台面水渍流到柜内，其实是多虑了，谁也不会让台面水漫金山也不管

▲再比较一下如图的台面，明显要极简高级多了。因为用的是岩板，不需要垫板直接做，视觉更美观，石英石能这样做吗？

▲如图所示橱柜下方为了更结实，一般用石英石的话必须做垫板处理，所以垫板的厚度横截面，石英石翻台刚好挡住也看不到，如果石英石不做翻台这个垫板横截面就露出来，不美观，如果你做隐形把手的话整体柜门就不好看了

▲想要石英石实现不翻台的做法，第一舍弃垫板，第二柜门无把手拉槽设计，柜体和垫板用同一个颜色，就可以实现极简的石英石台面不翻边的做法
第三、圆弧形阳角处理家里的阳角位置很多，一般是拱形门洞的处理，如果做弧形效果会更加柔和

▲如图所示常规拱形门洞的做法，阳角位置是直角处理，也没有不好，而是不出彩

▲其实拱形门如果采用弧形阳角条处理一下，让阳角看起来没有那么锋利，也不会磕碰，同时视觉上整体拱形会更柔和
第四、浴柜上翻石材其实不止浴柜，包括阳台洗衣柜也是同样的道理，改变传统的贴砖的厚重感

▲如图常规的干区做法，统一贴瓷砖，然后干区门洞还得做个哑口套收口，不仅费用高，而且干区如果在公共区域，视觉上也显得很累赘

▲如图所示干区统一变色乳胶漆，只是给浴柜上方采用石材上翻的形式，防止水溅和好打理，不仅功能满足，而且省去了瓷砖和哑口套的费用，同时视觉上更清爽高级

▲如图左图是常规阳台做法，贴满墙砖，而且还做了个视觉累赘的哑口套，费钱并不好看；如右图所示阳台没有水不用铺贴墙砖，采用石材上翻的方式防止水溅满足功能，让整体阳台更清爽与客厅融为统一，而且省钱。

★需要注意，这个石材上翻只要做全套全屋定制的话，一般都是免费的，不会单独收费，所以何乐不为呢？
第五、浴柜石材下翻延伸这个其实都是装修的细节问题，当然也和造价有关，自己如果不懂装修，只是按照常规做法，必然细节会有留有遗憾。

▲如图所示的卫生间很小，花洒一边是马桶一边是浴柜，既做不成淋浴房，也不想用浴帘，此时注意看浴柜的侧面，购买的成品浴柜侧面是木板，经年累月让洗澡水冲刷，你想想这个浴柜能支撑多久板子不会变形？

▲其实正确的做法应该如图所示，浴柜挨着花洒，而且没有任何遮挡，必须采用定制浴柜，同时让石材朝向花洒位置下翻至地面，用来保护浴柜内部的木板，从而延长寿命
第六、双面柜的妙用这个在实际应用中非常多，而且能解决好多实际问题

▲常见的是如图所示开放厨房与鞋柜的双面使用，既满足了两面的收纳，同时也能起到分割空间的作用

▲还有这种转角柜双面利用空间，完美实现格局和收纳两种功能

▲厨房与电视墙砸掉墙体，实现双面柜的做法，既能满足更多收纳，同时又能节省更多空间
第七、灯具移位支架实际装修里头很多都会出现后期灯具位置不合理的时候，如果返工就需要顶面开槽，施工周期长，耽误入住时间

▲简单一个灯具移位器就可以搞定，非常适合有吊灯的区域，或者直接用移位灯也可以解决《装修完了发现灯偏了，咋办？》
第七、抽拉餐桌或者隐藏桌板小户型非常实用，甚至可以增加更多便利性

▲如图所示小户型为了满足就餐可以做一个隐形的移位桌板，其实就是单独购买金属腿与质量好的轨道即可实现

▲如图所示利用橱柜隐藏一个可以抽拉的桌板，用来满足台面的延伸，甚至可以满足一两人的就餐功能

▲如图所示也可以利用衣柜与床距离很近的时候，采用这种隐藏抽拉的做法，满足小空间的床头柜功能
第八、嵌入式移门对于空间小的地方，可以节省更多空间

▲节省空间而且好看，对小空间来说非常实用，唯一需要注意的是必须五金质量过关

▲卧室书房空间也是适用的，颜值方面更高，更节省空间
第九、旋转电视以及折叠支架非常实用的做法，实际装修中也普遍使用

▲利用大角度的旋转支架，在客厅和餐厅都可以方便看电视

▲长距离伸缩支架也可以更好的保证电视机后面空间的合理利用
第十、衣柜内封板这个在做全屋定制的时候非常适用

▲如图所示两个不同衣柜的做法，可以看出来那个更美观好看一点

▲如图所示，其实只是把裸露外部的封板放到了衣柜内部而已，但是需要注意是衣柜上方最好做吊顶，保证横平竖直，对于顶面不平的地方，像好多精装修的房子，这种做法上方缝隙有可能宽窄不一
第十一、有定制的地方可以不用单独包管道看实际情况，如果做定制，背后的管道就没有必要花钱还占地方包裹，完全可以利用定制加以隐藏即可

▲如图所示，阳台区域有下水管，完全没有多此一举包裹这个，直接借用后期定制就可以完美隐藏，而且不用多花一份钱《后期全屋定制，红砖包管道多此一举》
第十二、烟道柜，管道柜包管道不只是包管道和烟道，如果能更好的满足收纳，就可以两全其美

▲如图所示，利用烟道空隙位置，满足超薄的收纳调料空间，不仅实用而且美观《厨房烟道柜，你家没做吧？》

▲利用隐藏热水器位置，实现美观和收纳兼顾

▲利用隐藏天然气表以及管道的收纳，成就小空间的更多收纳《只包管道就浪费了，做成收纳就有价值了》
第十三、柜内洞洞板妙用虽然是小物件，但是可以成就大功能

▲家里的杂物柜可以利用洞洞板悬挂，让家里的清洁用品以及工具摆放收纳更有序美观

▲如上图家家户户必备的清洁柜收纳，就可以利用洞洞板完美实现更多收纳和悬挂
第十四、不要电视柜，电视墙壁龛不要电视柜，但是电视墙位置好多路由器信号盒子要放

▲条件是你家电视墙刚好是非承重墙，提前做壁龛满足路由器以及信号盒子电源的布局

▲这样就可以实现美美的干净空间了，当然如果直接看网络电视，后面留个五孔插座，也可以实现这样的干净以及最大限度的节省地方，连壁龛都不要
第十五、更实用的换鞋凳做法如果要换鞋凳一定要讲究方法，做到空间和功能兼顾

▲如图鞋柜做法，没有空间，勉强利用子门的位置定制鞋柜，但是做了换鞋凳，让门口空间更加拥挤

▲其实完全没有必要，只是一个换鞋凳空间，空间紧张不如留出空间，直接用成品换鞋凳满足功能，这样视觉更宽敞，而且功能一个都不少

▲也可以直接利用折叠隐藏式换鞋凳，在鞋柜对面的墙面实现一个随时可以利用的功能
