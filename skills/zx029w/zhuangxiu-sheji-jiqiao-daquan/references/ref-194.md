# 装修公司设计师与独立设计师有什么区别？8.21

两者还是有很大的区别的，这也就是为什么好多高端大宅设计，明明找了装修公司，还是自己找单独设计师的原因所在。
第一、业主付出的代价不同。装修公司设计师都有工资和提成，施工本身就有利润，一般能收你设计费的，基本是意思一下而已，设计费相对独立设计师要低很多，而且这个设计费并不会都给设计师的。
而独立设计师设计费是刚需收入，是必须满足生活成本的，所以相对价格要高很多。业主找不同设计师，付出的成本是完全不一样的。
第二、设计师付出劳动不一样。首先装修公司设计师面对N个业主，甚至一个人需要兼顾十几家甚至更多工地的设计，这个就注定设计不会很复杂，所需时间就比较零散，所有时间不仅仅要分布给设计，同时需要跟工地协调。
而独立设计师有时候就接一家设计，设计时间两个月甚至更久。所有时间都是分配给设计，而无需操心施工。
但实际上，一个独立师不可能一两个月为了你一个设计付出时间，肯定是接很多家，交叉进行设计的。同时也避免不了独立设计师在外头有自己的工地施工。
但是总体来说，独立设计师在设计的时候，付出的时间和精力要比装修公司设计师多很多。
第三、设计效果的区别。这里是相对来说的，没有绝对的你掏钱多肯定设计效果就好，因为设计效果与造价是两个矛盾体；装修公司设计师需要考虑造价，而独立设计师只负责设计，完全不用考虑造价，否则没法独立设计。
装修公司设计师在做设计的时候，必须根据客户的预算去做，因为需要施工做预算，设计和预算永远都是矛盾体，此时业主制约的就比较多，设计效果往往让设计和施工两重费用挤压，否则设计的高端就预示施工费用节节高，此时业主无法承受，一切都得归零。
而独立设计师完全只看业主需求，至于你多钱能落地，这个独立设计师左右不了，也不愿意左右，否则设计是完全做不下去的《独立设计不是不好，而是有的存心不善》
第四、表面上面对的客户不一样装修公司的设计师面对的客户群体，不仅仅要考虑设计，同时还得考虑施工，此时预算就是两者之间的矛盾体，协调和这些才能达成一致；大概率能找装修公司的往往对预算是有一定要求的，但是也不乏不缺钱的业主，并不想让设计和施工分开。
而独立设计师面对的业主表面上好像都是不缺钱的，其实也只是大部分人不懂而已；因为纯设计费用完全不知道落地费用，此时纯设计上就会投入再多金钱也感觉不到，等到发现施工预算无法落地已经来不及了；但总的来说，只要懂一点常识问题，也不至于刚需房子找纯设计，这是让自己的预算雪上加霜的做法。
第五、对施工影响不同装修公司的设计师设计和施工是紧密衔接的，哪里有问题互相制约，随时做出适当调整；
而独立设计师完全脱离施工实际，施工时候出现问题，协调的时间成本要相对要高，因为设计的数据是不可能一丝不差的落地的，都会有一定的调整空间，此时就需要多方协调，时间成本相对要多，出错的成本独立设计师是不会承担责任的，往往成本只能客户自己承担。但是装修公司的设计和施工是一体的，不论是施工出错，还是设计出错，都是装修公司来承担责任，业主相对就减轻一部分成本输出。
第六、那找装修公司直接设计施工好呢？还是找独立设计师，然后重新分开找施工好？一句话总结：看自己的钱包《装修找个独立设计师省钱？坑到哭》，刚需还是找装修公司设计施工一体吧，这样设计和施工费用是相互制约的，你能知道自己花多钱办多大的事情；否则不差钱，可以找纯设计，至于后期落地费用高到离谱，只不过是钱的问题。
