# 花几千到上万请独立设计师值不值？

花几千到上万请独立设计师值不值？一句话总结：**看自己的钱包。** 刚需还是找装修公司设计施工一体吧，这样设计和施工费用是相互制约的，你能知道自己花多钱办多大的事情；不差钱，可以找纯设计，至于后期落地费用高到离谱，只不过是钱的问题。

**先戳破"独立设计师省钱"的谎言。** 如果有人说你单独找个设计师，然后自己找施工队，设计师全程给你买主材，省去了装修公司的费用，多省钱。请问这房子是怎么装修的？哪一个环节不是装修公司干的？你只是人为把一个机构能完成的事情，拆分成了三个机构，哪来的省事省钱？找独立设计师完全和装修省钱是相悖的，完全不成立。

**第一坑，预算失控。** 找独立设计师，10个人有9个业主不懂规划。拿到房子就找独立设计师设计，压根不告诉设计师自己钱包里头多少钱。心里价位几万搞定，实际设计出来预算都是翻倍增长。要不撕掉设计全当废纸一张，要不减掉好多无用设计，回归刷墙铺地。

**第二坑，设计施工利益绑定。** 设计师给你介绍相熟的施工队，没有利益哪来的起早贪黑？施工队所做的一大部分利润需要再给设计师。这样就会导致设计和施工一块哄抬施工费用，两人才能合作愉快。

**第三坑，主材回扣。** 你的所有主材设计师带着你买，你以为时间都不是钱？主材回扣恐怕最后比施工还赚钱，比设计还赚钱。到头来，一个独立设计师不仅赚了你的设计费，赚了你的施工费，而且还让你愉快的给人家材料的回扣。

**再说设计本身。** 设计是人的生活，而非房子这个躯壳。你是平民，你的生活习惯是平民，再大的房子那也需要平民化。但是大部分人会有一个矛盾点，心里永远住着一个贵族，但是钱包永远都是平民。刚需房刷墙铺地，真没必要掏那个设计费。

**两者本质区别。** 装修公司设计师需要根据客户的预算去做，因为需要施工做预算，设计和预算永远都是矛盾体；而独立设计师完全只看业主需求，至于你多钱能落地，这个独立设计师左右不了，也不愿意左右。还有一点很现实：独立设计师完全脱离施工实际，出错的成本独立设计师是不会承担责任的，往往成本只能客户自己承担。装修公司设计和施工是一体的，不论哪个出错，都是装修公司来承担责任。

**最后送你一句：** 你如果是刚需，谁忽悠你找独立设计师设计，你让他掏钱就行，否则真的能坑到你哭。
