# 20个“鬼才设计”都是谁想出来的？我家装修时刷到该多好！

装修无止境，行业的内卷并非都是坏事，例如一些你想不到的鬼点子，几乎是内卷产生的，不仅可以提升行业的设计感，同时也让大家知道了更多装饰好物。今天就看看这些你可能不知道的装修鬼点子以及一些装饰好物，说不定你可以用到自己家。01.开关装饰，氛围感都有了进门有个开关，刚好利用装饰一下，免布线充电款感应灯，加上小摆件和雨棚，不仅可爱，进门带来意想不到的情绪价值。喜欢不妨一试！02.转角石膏灯，没用但超有氛围感只要家里有非承重墙，找一个合适的转角位置，提前接好电源线。网购石膏灯，可选余地很多，油漆前嵌入墙体，然后油漆工处理仔细即可拥有美美的氛围转角灯了。已经装修完来不及砸墙和布线，可以用这种免布线充电款的转角灯。03.童话拱形门，吸睛之作门厅有个杂物间，为了遮挡一下，也为了进门的亮点，打造了一樘拱形门，没有想到入住以后，这扇门让进门更有了仪式感和氛围感。04.原木转角窗，光线和氛围兼具开放书房做了拱形门洞，为了拓展空间，转角的非承重墙挖洞，定制了转角实木窗户，不仅成了装饰亮点，功能上可以视觉放大，也让整个家有了温馨氛围感。『新作转角窗火出圈，颜值实用双开挂，幸福感直接拉满！』05.过道尽头装饰兼收纳过道尽头背景其他邻居做了收纳定制柜，家里不需要那么多收纳，采用石膏板做了拱形造型，射灯点缀一下，下方斗柜满足收纳，摆上挂画和绿植，氛围感和颜值都有了。『让你的家更有格调！10种过道背景值得借鉴』06.阳台咖啡角，精神家园阳台角落实现了咖啡角，平时办公最佳地方，家终于有了最满意的地方了。『除过晾衣服，阳台9种功能区打造』07.不信风水，不固守传统非常庆幸没有居中放床，也非常庆幸家人比较务实，没有信风水，才有了小空间的大功能，空间更有价值。『床头靠窗，谁说不行？』即使床头靠飘窗，也可以有更高级的做法，空间价值更高『不听劝，小卧室床头靠飘窗，结果效果贼好』08.不加一分钱，衣柜颜值更高侧面其实就是见光板，只不过为了颜值，让断开拉手延伸到了侧面，几何线条一分钱不加，但是衣柜的颜值立马高级，这才是设计的意义。09.洗衣柜超过墙体，设计好了一样美很多户型都会出现洗衣柜太厚，超过了墙体问题，但其实只要设计好了，不影响采光还能继续提升颜值。也可以延伸包裹墙体，拓展台面，而且弱化了墙垛的突兀。010.阳台推拉门改窗户，满足更多功能很常见的做法，不仅满足小卧室布局，还实现了双面柜收纳『阳台推拉门改联动窗，完美落地！』011.成品书桌挡衣柜门成品书桌挡衣柜门，常规设计就得一扇门非常宽，一扇门非常窄。断开设计，采用宽窄交叉设计，实现视觉的平衡，同时也提升了设计感。012.阳台墙体突兀，定制隐藏阳台承重墙垛无法拆除，直接采用定制板材隐藏，做一个包围式水吧台，完美实现视觉的统一和高级感『全屋定制“魔法”揭秘！63%家庭为何钟情围合式外延设计？』定制隐藏墙体，而且朝向客厅实现一个书架功能。013.书桌连衣柜，太厚不好放书书桌连衣柜的话，上头镂空衣柜的厚度，后期放书太深全部乱，采用层板内缩实现书籍的放置，同时还能拓展桌面的空间『没想到层板内缩，能让全屋定制锦上添花』014.洗手池不想贴砖，创意做法石材上翻斜面处理，最大限度防止溅水，几何形状更具设计感。采用包围式做法，阳台洗衣池压根不需要贴瓷砖，一样解决水溅问题，颜值上更具有设计感。015.厨房放不了冰箱，牺牲墙体，转变朝向当厨房空间紧张的时候，可以牺牲墙体，采用柜体代替墙体的办法，占用一部分厨房空间，冰箱朝向餐厅，一样可以满足功能，同时实现了鞋柜和厨房收纳的双面柜收纳。如果厨房隔壁有空间，也可以牺牲墙体，借用隔壁空间，实现冰箱的镶嵌，完美让冰箱放在了厨房。『厨房小到塞不下冰箱？这两种替代方案真香，我家立马抄作业！』016.与众不同的感应小夜灯网购汤姆与杰瑞小木屋，装修之前根据木屋大小预留电源以及尺寸孔洞，后期安装木屋即可；内置感应小夜灯，晚上起夜非常好看，是装饰也是功能。017.百叶隐藏难看柜机嫌柜机太突兀难看，可以借用定制洗衣柜的时候，隐藏柜机，采用百叶门隐藏起来，平时不用的时候完全看不到，使用的时候只需要打开柜门即可，美观也更好维修。『嫌柜机又土又占地？网友神操作，简单搞定颜值』018.床头L型飘窗利用床头靠向L型飘窗，利用角落定制收纳柜，下方镂空代替床头柜收纳，也可以视觉上让床头居中，空间更协调。『床头靠飘窗，床头一半悬空，终于找到解决办法了』019.给家里狗子打造温馨窝利用卧室凹陷区实现收纳柜的定制，下方镂空专门给狗子留个窝，加上帘子，晚上狗子就可以完美入住了。『家有毛孩子，这样设计宠物窝，没有人不羡慕』020.隐藏电视一门两用电视墙满墙书柜，采用移门设计，平时可以隐藏杂乱的书柜，也避免了打理，同时还可以隐藏电视。看电视的时候，打开刚好满足书柜的隐藏。『果然还是年轻人懂装修，看似空无一物，全因会“藏”！』
