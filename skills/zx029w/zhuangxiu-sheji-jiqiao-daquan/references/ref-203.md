# 设计和施工不要分开，不要听人忽悠11.22

家装施工工序繁多，在于衔接和协调。是由两大方面构成，设计和施工。

首先设计，按照自己的想法结合设计师的经验，把家尽量做到合理利用。然后在设计方案探讨没有任何瑕疵，就可以交给施工方进行施工。

在西安地区，一般每个装修公司都有设计和施工人员，属于同一个公司。

好多业主不找装修公司，自己有熟人搞装修，或者自己实在空闲，完全有时间找散工做。施工是没有问题了，可是为了有个整体效果，想找个人来设计一下。

这里就有问题了，大部分人认为找设计人员设计好各种图纸，然后甩给另一个施工机构就大功告成，施工人员就可以根据设计人员的图纸进行施工了。

也就是当设计人员把设计图纸交给业主手上，拿钱走人，再无瓜葛。

你大可以告诉设计人员需要跟工地两三个月，看看设计人员的反应。

难道你让设计人员跟着工地跟两三个月不成？可以，但是那点设计费谁愿意？所以，施工人员拿着图纸自行施工。

纯施工人员拿着设计师的图纸，在没有设计人员的协助下，到底能不能施工？答案是能，绝对能，前提是你的设计和施工压根没有关系，也就是施工人员完全不看设计图纸就可以施工。

如果是真正的一套家装设计，涉及到的数据都是有误差，涉及到的细部非常多，而没有设计人员跟进和施工人员协调施工，压根就不可能做好，即使做了，只是照猫画虎而已。

如果是照猫画虎，那前期所做的设计又有何用？

所以，设计和施工是无法分开的整体，除非你就是刷墙铺地，反过来，如果就是刷墙铺地何必做什么设计？

所以现实中有好多业主在一家做好设计，甚至发一张平面草图让做设计，然后设计机构只为赚钱才不管你能不能施工，业主拿着一套根本没有任何用处的设计，让施工人员施工，施工人员要不压根就不看设计，根据自己的想法施工，要不就是做出来的东西和设计大相径庭，最终导致设计白做，而且还影响最终施工效果。

所以，设计和施工必须是一家而为，只有当设计和施工是一家公司的时候，施工的时候设计人员才能协调，最终达到当初设计的初衷，否则再好的设计与施工分离只能照猫画虎。或者你完全可以找一家能始终跟工地的设计机构，否则不如不找，不过费用一般人接受不了。

当然，这些话，那些专做设计的人员或者机构肯定会嗤之以鼻。

不过业主是清醒的，仔细想想就会明白怎么做了。
