# 免费设计的设计师没动力？这话很外行11.29

今天再次谈一下关于设计费的问题，因为网上对免费设计的误解铺天盖地，其目的不外乎一个：让业主出没有必要的费用而已。

一、首先，什么样的设计师应该收费？这个没有标准答案。有的套餐装修公司连房子都不量，直接套用公司模板即可完成所谓的预算。效果图都是公司提前一年甚至更早提前做好的，主打某小区的。预算+毫无用处、只提供给业主心理安慰效果图，就叫做设计。然后就可以堂而皇之的在预算里头加上设计费了。

二、当然外行看不出什么，认为人家毕竟专业，该收。其实现在的装修公司里头的设计师，年轻一点的，其装修经验连业主都不如，只不过会套个预算，知道公司的营销口诀就行。这设计，你掏钱真的很冤。

三、独立设计师应该收设计费。因为就靠这吃饭呢。比如有的业主找独立设计师设计好，然后找装修公司或者施工队直接施工。这样的设计就是再烂你也得掏钱，否则独立设计师就得饿死。

四、装修公司内部设计师，收设计费跑哪了？当然全西安市有几个公司把设计费全部给设计师的？这就是痴人说梦。公司当然是给设计师一部分，其他还得拿走。也就是说你给再多设计费，并不是设计师都拿走了，在这个前提下，给多给少，设计师给你家操心不操心没有任何关系。

五、业主常犯的错误。就目前大西安的刚需房来说，大家就基本是过日子而已，你家就是刷墙铺地，要什么设计费？如果这个都可以收设计费，只能说对设计有深深的误解，太抬举所谓设计师了。当然，你如果是土豪，你可以掏，有钱难买你情愿，别人再认为你是冤大头，那也左右不了你。但是，咱如果就是普通老百姓，咱买个马桶一千以上的都不考虑，请不要掏所谓设计费了。再好的设计和后期配饰完全搭配不上，这不是糟蹋钱是什么？

六、为什么装修公司大部分都是免费设计？因为你房子就刷墙铺地，收你设计费良心不安呀。只有独立设计师才会喊叫免费设计是陷阱，因为他要吃饭呀。还有所有装修公司都愿意单独收设计费，谁也不会嫌钱多。但是实在看不了那些屁都没有设计的公司，腆着脸收业主的设计费，更可怕的是业主不懂，照给不误。

七、你如果真的想找独立设计师或者好的设计，请找设计经验10年以上的，否则都不要找，找了也设计不了什么东西，恐怕基本的施工经验都不具备，怎么设计？干了两三年设计师，工地加起来都没有超过一百家，连施工工艺都不懂，怎么设计？图纸画的花里胡哨，效果图外面掏钱做得很漂亮，施工的时候全傻眼，全是常识性错误。这设计掏钱太冤了。

八、你如果钱多，八九十平方的刚需房也掏设计费，只能说明你钱多而已。你买苹果手机，人家收你设计费了？同样装修公司施工已经有利润包括设计了，而是分项单独多收费，然后到处散布免费设计是陷阱，让业主多掏钱而已。

设计收费不收费在于你，掏钱不掏钱在于业主，但是请不要说没有设计费，设计师不操心，没有动力的话了。该操心的那是人品，再多钱也是百搭。

装修有利润，免费设计无可厚非；同样你设计费是天价，免费装修也是可行的。一切需要思考并执行。
