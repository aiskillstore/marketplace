# 经验|装修设计和施工能不能分开找人做？

　　1.设计师定稿的方案、选择的材料施工方无权私下更改或者替换。
　　2.设计与施工不是一家公司的情况下，设计师一般会站在客户的立场上对施工方提出建议或者监督。
缺点：
　　1.不同公司的工作方式相差比较大，沟通和合作上会出现问题。一般大项目的周期长，双方也都是行业内比较专业和领先的公司，所以这个问题不明显。楼主的项目小，周期短，若双方又都是半吊子，那问题就更多了。
　　2.责任划分难以确定。除非很专业的公司，双方在项目的任何节点和文件交接，包括项目进行中的设计变更过程都有文书备案或者邮件。否则的话，你推我我推你就再正常不过了。
    3. 如果是家装设计，设计师扔给你一堆图纸就消失了，根本不会跟工地，人家只赚设计费，那你家施工压根和设计就没有关系了，设计和施工是无法分离的，一旦分离，施工只能照猫画虎

不分开的优点：
　　1.设计与施工沟通顺畅、反馈及时，项目比较容易按照进度顺利完工。
　　2.责任明确，不管哪一方出现问题，同一家公司承担。
　　3.一般家装公司会免去设计费。
缺点：
　　1.可能会偷换材料。看起来相似的材料价格未必相同，在利润比较单薄的情况下，也许会出现。
　　2.相互维护。即使发现对方可能违规也不会提出异议，因为要维护公司的整体利益，这个没办法，打工的人都身不由己。
　　3.层层转包，导致费用提高。
　　好了，以上缺点都仅仅只是有可能出现，不代表一定会。对于一般的家庭装修，其实分开比较没必要，要按正规的设计费来收，可能会高于正常装修的费用，这对多数消费者来说，肯定是不愿意看到的，不知道大家怎么看呢？
