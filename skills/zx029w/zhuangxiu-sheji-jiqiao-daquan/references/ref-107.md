# 家里哪些地方「留空」设计更好？1.1

装修每一家都是个性化的做法，所以没有标准程式化，但是在装修设计里头肯定存在共性，大家公认的符合习惯以及刚需的做法，例如留空设计，几乎处处都有，只不过被大家忽略掉了。今天总结一下，看看装修里头的留空设计，是否曾被习惯遗忘了。
第一门厅留空设计。
▲鞋柜中间镂空是为了进门放置随手的物品，非常方便；而下方留空是为了方便放置更换的鞋子。这些都是习惯留空的位置，看似平常，其实用处很大。▲如图即使是矮柜，下方依然留空，留出进门更换鞋子的方便；同时注意进门直对墙体留空，是为了视觉更灵活，方便光线透入，弱化门厅的压抑感，虽然没有实用功能，但是却是点睛之笔▲入户墙体太窄，鞋柜定制专门预留出一部分，这样进门就不会显得很堵，留出进门的迂回空间，同时这个空间不能白白浪费，满足了全身镜的功能▲如图同样家里有老人的话，鞋柜够大，可以留空满足一个换鞋凳功能，同时留空位置挂衣钩布局，可以满足进门挂衣服以及包包，同样是留空并不会浪费价值第二客厅留空设计
▲如图电视墙石材故意留空，左右错位布局，视觉上不会太满，不会让石材的冷硬铺满视觉，反而造型变得更轻巧时尚▲如图电视悬挂位置专门的木色留空设计，视觉上能更有层次，同时可以视觉放大电视区域，虽然是错觉的，但是目的达到，电视墙反而变得大气▲进门鞋柜一直与电视墙满墙柜延伸，所有的留空都有其功能化设计，同时视觉上打破沉闷和呆板▲同样鞋柜定制延伸至电视墙，竖向留空是为了作为视觉分区，同时满足展示品的收纳；电视柜悬空是为了视觉更轻巧，也是为了方便扫地机器人的进入方便▲如图上下留空是为了视觉上显得更轻巧，同时上头的留空可以解决精装修的吊顶太窄与定制冲突问题《精装修微改，全屋定制有窍门》，电视左右的留空，一是为了展示，第二视觉上可以拉伸空间，让视觉上电视墙更大气▲客厅满墙柜下方留空，可以用收纳盒子满足家里孩子玩具的收纳，同时等孩子稍大，这里就是孩子书籍的收纳；同时注意阳台大梁下方的留空是为了作为视觉分区，同时弱化大梁的突兀《定制柜上方有大梁分割，怎么做好看？》▲小空间客厅矮柜留空同样是为了收纳盒子满足孩子玩具收纳，同时以后作为书架使用；而上头大面积留空是为了小空间更有层次，不至于视觉空间压抑▲客厅沙发两边留空，是为了空间轻巧宽松，而且可以拓展不同的的功能▲客厅跨度小，去掉了茶几，同时满墙柜中间留空而且加入了灯光的点缀，为了让小空间布置与视觉压抑，同时空间上更轻巧生动▲如图满墙柜下方整体留空，目的就是造成视觉轻盈感，不至于压抑，同时木色的留空点缀层次，满足功能第三餐厅留空设计。▲餐边柜留空与鞋柜留空类似，但是餐厅是为了满足水吧台功能，平时可以放一些烧水电器、咖啡机、管线机之类，同时满足就餐时候的随手置物，而且视觉上层次感更好，不显得呆板和压抑▲当然矮柜餐边柜的做法，上方大面积留空，可以让空间更显宽敞简洁，颜值以及空间美感更进一步提升▲如图餐边柜靠近进门口，留空隔板是为了进门不至于过于拥堵，同时满足进门随手置物的台面▲如图餐边柜下方留空，是为了更好的布局餐桌，避免小空间的拥挤，同时必要时可以餐桌拉出满足更多人的就餐需求▲如图彻底断开留空是为了避免窄柜的压迫；断开式设计可以弱化这种压迫感，同时让视觉上更有层次▲餐边柜留空为了餐桌的尺寸布局，同时朝向餐厅橱柜留空，可以满足餐厅位置随手置物▲西厨留空满足吧台凳的隐藏，同时留出人坐的施展空间▲岛台下放留空一是放置椅子方便，第二人坐的时候空间更好的舒展第四、卧室留空设计。
▲衣柜离床很近，为了避免柜门与床头柜冲突，采用留空设计的方式，既避免柜门的问题，同时也可以满足随手收纳，视觉上更有层次▲衣柜局部留空设计，不仅让衣柜看起来更有层次，最大的功能是满足了晚上睡觉挂衣服的需求，同时下方留空可以放置行李箱《晚上睡觉，衣服随便扔？那再好的装修也白搭》▲如图衣柜设计留空是为了满足墙面开关的放置，不仅弱化了侧面的呆板，而且还实现了功能化▲衣柜延伸床头柜下方留空，穿插式设计更显高级，视觉更显轻盈，下方留空也能满足更好的清洁打扫▲如图床尾衣柜留空套色设计，一是为了弱化衣柜的压抑感，让空间视觉更生动，第二为了随手置物，可以作为展示功能区▲衣帽间下方留空目的是小空间视觉轻盈，不至于压抑不透气，灯带点缀一是满足照明，二是让整体视觉更轻盈高级▲衣柜留空为了成就床头柜，满足收纳，弱化柜体压抑，避免一门到顶柜门变形问题；更新颖有层次▲飘窗变书桌下方留空为了放置椅子以及人坐的时候腿能很好的舒展▲侧面留空避免进门直对衣柜侧面，同时满足一个展示收纳的空间，让进门直对视觉更好看第五卫生间留空设计▲干湿分离空间极小的时候，悬空下方留空是最好的设计，既满足功能，同时又不会占用太多地方，而且视觉上看起来更高级▲即使干湿分离的浴柜悬空，也是为了好打理，同时下方可以随手放置物品，例如成就一个扫地机器人的藏身之地▲如图浴柜留空不只是为了好看，最重要的是小空间的压抑问题；留空以后不仅满足空间的宽敞，同时可以保证马桶区四周空间的合理性第六、厨房留空设计
