# 横厅怎么装修？有几种布局形式？11.25

现在的户型横厅越来越多，而且大小户型都有，布局方式也各种各样，今天看看这些实例参考，看别人家都是如何布局横厅的。
第一种、打通阳台，沙发居中分割客餐厅

▲最常见的布局形式，不过因为打通了封闭的阳台，不仅仅拓展空间，而且采光更显得通透；沙发居中作为客餐厅的分区布局
▲砸掉阳台墙体拓展整体空间，实现更宽敞明亮的横厅布局▲同样是打通阳台的布局，但是原始横厅空间小，所以利用过道实现了餐厅位置，把原有沙发后面的餐厅满足收纳定制柜，留出通向阳台的合理动线▲正常横厅打通阳台拓展空间和光线，沙发居中背后布局餐厅▲打通阳台成就横厅光线和空间，只不过垭口做了拱形处理，让整体空间更显优雅▲打通阳台的常规横厅布局，沙发居中背后刚好是餐厅空间▲刚需紧凑横厅，一半阳台与客厅打通拓展空间，另一半保留作为生活阳台；沙发背后餐桌布局，刚好在厨房门口▲常规横厅的做法，砸掉阳台拓展空间以及光线；电视墙以及餐厅都做了充足的收纳储物第二、无阳台、沙发居中分割客餐厅
▲也是常见布局，只不过没有带阳台，只有窗户，无法拓展空间；电视墙与餐厅同时做了收纳布局，满足基本的空间储物功能▲如图横厅，只不过窗户是飘窗空间，飘窗就可以兼顾休闲功能；同样是沙发居中分割客餐厅区域▲无阳台只有一扇小的窗户，所以一侧书柜布局，满足家里藏书需求，沙发背后是餐桌岛台，餐边柜满足收纳；中间大梁采用弧形吊顶弱化突兀感▲刚需横厅空间，满足基本的功能布局，沙发居中，超大窗户满足了空间的采光需求第三种、沙发居中，分割书房客厅▲如图横厅，沙发居中，但是分割的不是餐厅，而是背后的开放书房空间，餐厅有独立空间，所以这样的横厅功能要更胜一筹；同样可以打造电视墙满墙柜以及书柜，满足基本的收纳▲小横厅空间，只不过沙发背后刚好布局开放书房功能，餐厅在单独空间，拓展出来另外一个功能区第四种、沙发居中但是反传统布局
▲如图横厅，反传统的沙发布局方式，借用横厅过道满足电视墙布局，另一边是岛台与餐桌的布局；空间上更新颖，而且原有电视墙同样满足纯粹的收纳▲同样横厅，但是跨度有限，所以刚好反传统布局沙发，满足了客厅与餐厅的空间通畅，解决跨度小的问题▲横厅跨度太小，没有办法容纳餐厅，打通阳台以后，把岛台与餐桌布局在了阳台空间
▲横厅空间，为了空间更加通透，动线更合理，沙发反传统布局，利用过道墙面实现电视墙功能第五种、横厅布局打通客餐厅以及厨房
▲原有户型本身就是横厅，但是同时容纳客餐厅空间紧凑，于是砸掉厨房，利用开放厨房实现了岛台和餐桌布局，让客厅更开阔，这样客餐厅以及厨房一体横厅布局，视觉空间以及采光更优秀▲小横厅空间，沙发居中，背后刚好是餐厨空间，只以为空间有限，无法实现餐边柜的收纳▲打通阳台拓展空间，沙发背后餐厅布局，同时开放厨房满足空间的更加开阔▲横厅跨度太小，无法同时满足客餐厅布局，砸掉厨房做了开放式，让客餐厅以及厨房整体开放通透，满足功能布局，同时空间更加开阔
