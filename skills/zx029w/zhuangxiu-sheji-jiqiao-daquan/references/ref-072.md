# 卧室床尾设计，7种布置方式8.7

卧室作为休息的私密空间，一般空间都不大，所以在功能利用上，一定要做到功能与美观的兼顾，今天看看卧室床尾的几种做法，看哪一种才是适合自己的。
第一种：留白，什么都不做。

▲如果不需要任何功能，留白可以让空间更大，动线更合理，当然最好

▲当然对于床尾几乎刚好满足基本动线的时候，也只能留白什么都不做
第二种：满足娱乐功能

▲空间允许，可以满足墙挂电视，满足娱乐功能，特别是小空间老人房，这样刚好合理利用空间实现功能
▲利用床尾墙面直接满足投影的功能，同样满足娱乐功能▲当然想要投影效果好，直接投影幕布安装也是可以的，躺床上看电影爽歪歪▲当然有大空间卧室，甚至给卧室打造电视墙造型，这个仅限大户型卧室，小户型卧室还是算了，空间会更拥挤，更凌乱第三种：做满墙柜▲床尾打造满墙衣柜，可以满足卧室超级收纳，同时利用衣柜可以满足书桌或者化妆台空间《床尾一面墙衣柜，让收纳翻倍》▲利用床尾打造衣柜，还可以解决主卫对床的问题《调换床头解决主卫对床，目前最佳方案》▲满墙衣柜上方也可以满足一个隐藏投影幕布的功能，满足卧室娱乐▲同样利用满墙衣柜，可以满足一个电视的镶嵌，同样可以满足卧室的娱乐▲床尾空间也可以利用开放衣柜设计，拉上帘子即可遮挡隐私，更节省地方第四种：斗柜收纳▲床尾有空间，斗柜兼顾一部分收纳，同时也不会让空间压抑，角落布局衣帽架满足晚上挂衣服，同时兼顾颜值的提升▲也可以不同斗柜高低搭配，满足不同收纳，也满足了不同的视觉层次▲也可以采用定制，根据空间大小满足斗柜的收纳第五种：卧室床尾书柜▲和电视矮柜书柜类似，卧室床尾也可以满足书柜的布局，也不至于太压抑，满足家里藏书的收纳《做满墙书柜怕压抑，矮书柜颜值收纳都有了》▲封闭和开放搭配，同时满足收纳和书籍的收纳，上方还满足了投影的娱乐功能第六、床尾书桌+书柜▲床尾斗柜+书桌+书柜的布局形式，不压抑，可以拓展更多不同的功能▲如图利用床尾定制书桌+书柜，这种做法也可以满足儿童房的学习功能第七、床尾斗柜+化妆台
▲利用床尾空间，满足斗柜+化妆台的功能，不仅拓展功能而且满足收纳▲同样这种成品的斗柜+化妆台，也可以延伸一个书桌的功能《床尾斗柜+化妆台，完美卧室标配》
