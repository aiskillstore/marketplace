# 被年轻人的“墙角设计”折服了！打开思路后，高级感直接翻了一倍

每一家都有转角墙体，不论是阳角还是阴角，有的留白，有的可以发挥创意，装饰一下，给家里添彩。今天看看年轻人的做法，稍作改造，就可以让家里转角更吸睛！墙面夹角，这个思路太有趣了！利用墙面的夹角，做了一个小平台，以灯照亮，有无限想象～书柜做了悬浮设计，没有做满，视觉上就会更轻盈，同时转角延伸一块，不同材质提升视觉层次，吊灯以及摆件的加入，立马有了高级的格调。收纳柜不做满，与墙体留白，利用墙体转角陈设艺术品点缀空氛围感！原有呆板的直角转角弧形设计，花瓶一放上去，瞬间感觉就来了！射灯一装，完美！法式风的家，选了这个角落氛围灯，看到开灯效果太美啦！转角石膏灯 有暖光冷光模式。一个圆弧的空间处理，做一些深入过度，在墙面增加了等量的内嵌石膏灯具，把此处的呆板墙体变成了有开孔光的位置。在顶面做了圆弧的拱顶 让过道的顶面不至于压抑，再加上一组天际线把竖向光变成平光，间接拉伸空间的体量感。墙面转角景观营造视觉引导。墙面转角挖出三角形体，置入景观营造氛围，斜线强化视觉引导，增加行走路线的趣味性。
网友@九月九：玄关转角处的高级感，家属亲手绘制的画挂在墙上，旁边壁龛里的干花在暖光下超有氛围感，每次进门心都瞬间静下来。
网友@小秋天：屋子的原始结构在这里有个500深，1700长的拐角， 如果在这里做一个深500的常规柜子，从侧面看会非常笨重， 我既不想改结构，又不想放弃这块储物空间，所以折中了一下，在拐角处做一个玻璃柜。
原始入户空间毫无隐私性和收纳区，因此设计师增加墙体，改变入户的视觉动线，并且利用极简的低柜增加入户的鞋子收纳，转角圆弧的处理为进门的视觉增加柔美感，底部悬空设计视觉上更加轻盈舒适。
在沙发墙后面的转角处，通过设计这种小色块的方式，从侧面的墙体转折延伸到沙发背景墙，不仅很好的过度了墙体转折的生硬感，同时颜色的跳跃，也是空间中的一个视觉亮点。
经常会碰到一些错层的墙体，会形成生硬的阳角，不仅影响美观，而且特别会对老人小孩造成一定程度的安全隐患。 用了一个圆弧加暗藏灯带的方式，去让这个错层变得自然了，同时也为空间增添了一份氛围感。
家里面同面墙体有高低错落不平，出现生硬的阳角，不小心会出现磕碰情况，可以通过做圆弧的方式，过度墙体的落差感，去弱化它，同时预留灯光槽，既增加了弱化部位的层次感，灯光又增添了空间氛围
在墙体转角处，通过材质变换的方式，弱化墙体尖角带来的突兀感，和原墙体形成对比关系，使空间更有层次感。
墙体转角不同材质的碰撞弱化原有的直角生硬感，同时提升空间的视觉层次。
利用客厅转角的墙面做端景，不仅丰富家里的光源层次感，还让全屋的视觉效果看起来很不错
利用墙面转角空间挖空做内嵌处理，不占地方还美观，镂空柜门既能展示,又能框景，加入洞洞柜门,背景做暖色灯箱，照明手办还贼有空间氛围感。
在墙体转角处的地方，通过包裹的方式，弱化墙体尖角带来的突兀感，在这里包裹的材质及颜色，要和原墙体形成对比关系，其次在包裹的上下要预留出一些距离，营造一种悬挂的感觉，因为这样看起来会更有结构层次感。
书房做了转角窗户，不仅弱化了阳角的生硬，同时视觉也更有层次
