# 经验|赶紧去掉这些不适用的装修设计！！！

◆复杂的背景墙

大部分设计师都喜欢设计好看的背景墙，似乎不这样装饰一下，客厅就会显得单调、不气派。现在，背景墙的材料也非常多，常见的除了壁纸外，大理石、文化石、马赛克、硅藻泥乃至各种石膏板做成的造型，都能上墙，给人非常“宏大”的视觉效果。

费钱：一面复杂的背景墙做下来，人工费加上材料费，几千至上万元不等。

视觉疲劳：背景墙一般都在电视机后的墙面上，有的背景墙一装上电视后，把造型挡住就看不见了。或者看电视机时间长了，复杂的背景墙容易让人眼花缭乱，产生疲劳感。

调整建议：现在的背景墙大多以简洁明亮为主，让空间显得更清爽。整个客厅设计中，顶要清淡地面要稳重，墙面要搭配协调。可以只用简单的背景处理以增加层次感，即使背景墙要增加收纳功能，也要处理得比较隐蔽，简洁明了。

如果已经做了复杂的背景墙不想看，可以用大的电视柜来处理，现在很多电视柜造型美观大方，也是客厅中很好的装饰品。

◆开放式厨房

年轻人一般一天只有一顿饭会在家里做，开放式厨房能很好地增加家人的互动性，比较浪漫。小户型做开放式厨房能使空间在视觉上变大，使空间更好利用。

即使做饭次数不多，中式炒菜油烟也不可避免，开放式厨房会让家具、装饰上都沾上油烟，不好清理。很多厨房电器如微波炉辐射较大，做开放式厨房很难避免辐射。

调整建议：开放式厨房的炉具，应考虑选用不会产生太多油烟的厨房用具，因此大功率抽油烟机是开放式厨房不可少的。最好能有大一些的窗子，这样能确保良好的通风，而且也能让室内的光线更明亮。如果有移动门或隔断的话，会更方便。

◆女性元素

中看大量的花卉图案、镂空的和悬挂的布艺或珠帘以及流苏频繁出现在家中，成为女性元素的象征，深受女主人喜爱。

太浓艳的色彩，时间一长，很容易让人感觉疲倦。而花卉、镂空等装饰太多，也会让房间显得拥挤杂乱。

调整建议：花卉图案可以少量使用，一面墙即可。浓艳的纱或布如果太多，可以换些清淡的色彩。

◆太多镜面

很多小户型，都喜欢采用大面或多面镜子，用来拓宽室内的视觉效果，让空间显得更大，在特定的地方，也有很好的装饰的效果。

大面镜子会让空间有延展效果，但镜子多了产生折射，会让人感觉不自在，给人视觉上带来混乱和反差。玻璃过多，在家里也非常不安全。

调整建议：现在用镜面做装饰，在过道、餐厅较多，或者局部吊顶上也常见到，除注意装修安全外，可以考虑将它分隔成菱形或方形的小块镜面组合起来，增加层次感。也可以用折射不强的烤漆玻璃等做装饰，烤漆玻璃没有镜子那么明亮，又能增加视觉上的通透感。

◆满圈灯带

不少设计师都喜欢用很多灯带来突出房间的层次感，另外，为了使家里的梁不太明显，一般都会做矩形、环形的灯池，五颜六色的灯会让家里更显温馨。

一般有吊顶的地方都有灯带，否则吊顶的作用就显示不出来了。但灯带主要是为营造气氛，照明作用并不明显，若家里装了满圈灯带，开着还费电。

调整建议：目前很多房子不高，做吊顶会让层高更低，所以房间不高的情况下，如果必须吊顶，建议局部吊顶或用简洁石膏线做装饰即可。如果做的吊顶比较多，也可以只在两边或一边使用灯带，灯带一般用暖色灯，会更温馨浪漫。

◆步入式衣帽间

利用一个空间做成衣帽间，不完全封闭，空气流通好，宽敞大气，不但使用起来比较舒适，而且能收纳不同的物品，可以满足一家三口四季衣物和被子的存放，净化了其他房间的视觉效果，非常方便。

步入式衣帽间最大的问题就是灰尘，很多换季的衣物，下次再穿可能要过几个月，如果直接挂在步入式衣柜里，很容易积灰，需要经常清洁。

大部分步入式衣帽间的柜子没有门，进去感觉东西特别多，视觉效果非常杂乱。

调整建议：可以给步入式衣帽间装一扇门或帘子，防止灰尘侵扰。如果还觉得不放心，可以将衣物用袋子或箱子收藏好后，再放进衣帽间里。✪
