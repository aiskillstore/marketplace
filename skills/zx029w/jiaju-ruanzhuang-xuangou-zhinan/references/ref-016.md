# 装修选实木家具，千万要谨慎！1.23

1、木种。不同的木种价格相差巨大，便宜的有松木、柞木，再便宜的杉木主要是用于木工打家具，硬度和稳定性其实都不太好。中端木材有水曲柳、橡木等，高端实木家具以花梨木、酸枝木、黑檀木等名贵木材为主。

2、真假。判断是否是实木家具主要要看结疤、木纹和截面。结疤：看好有疤痕的一面所在位置，再在另一面找是否有相应花纹。木纹：外表看上去是一种花纹，那么相应着这个花纹变化的位置，在木材的背面看相应的花纹，如果对应得很好则是纯实木。截面：截面的颜色要比面板深，而且可以看出是整块木头制作的。

3、产地。实木家具结构的稳定性取决于含水率的变化，会受周围环境湿度的影响。选购时可以留意一下实木家具木材的产地，俗话说"实木不过长江"，就是说在南方生产的实木家具到北方后，会因为气候影响含水率，从而容易出现开裂、变形等问题。

4、纯实木。可以说现在市面上的实木家具，大部分都不是纯实木，很多都是板木结合的，也就是部分是实木部分是人造板材制作。板木结合的家具，一般也叫实木家具，有的商家会跟客户说明，有的黑心商家就直接按纯实木价格销售赚取暴利。纯实木也可以是两种不同木材制作的，比如一张床的骨架用一种木材，床板用另外一种木材，商家以此称为纯实木，大家购买的时候一定问清楚。当然并不是板木结合的家具质量就一定差，但是我们不能花冤枉钱用纯实木的价格去买了非纯实木的家具。

5、做工。实木家具的做工是否细致，油漆面是否平滑，榫卯结构是否严实等也是决定实木家具价格的因素。另外如果是板木结合的家具，可以打开抽屉或者柜门，闻闻是否有刺激性气味，板材环保程度是否达标。
