# 普通家庭，地面铺柔光瓷砖还是亮光瓷砖？

普通家庭地面铺柔光还是亮光？答案很明确：**真心不推荐亮光瓷砖，柔光砖才是普通家庭的稳妥选择。**

**先说为什么不推荐亮光砖。** 关于瓷砖一直都不推荐亮光瓷砖，因为太扎眼，太突兀，太高调，看上去就会失去应有的内涵。很多人认为亮光瓷砖能让空间看起来更亮，其实这个是对光线的认知误区。家里光线靠的是大面积物品的漫反射，而非材质的表面是镜面效果就会变亮。黑色的亮光砖铺到家里，家里还有光线吗？镜面效果和家里光线没有关系，完全取决于瓷砖本身的颜色。

**亮光砖的三个硬伤。** 第一，亮光瓷砖通铺，注意地面的倒影，不仅不美观，而且让整体会凸显出一种说不出来的廉价感。第二，如果用拖把拖地每一次都会留下难看的水渍，永远清理不干净，每次拖完地都没法下脚。第三，如果是家里灯光多或者无主灯设计的时候，整体就翻车现场，地面倒影各种花里胡哨的影子，看起来效果就非常低廉。特别是靠近窗户附近，扭曲的倒影让空间视觉上显得更加凌乱。

**更危险的是卫生间。** 现实装修里头，甚至有人把亮光瓷砖直接通铺到厨卫地面。铺到厨房除过不耐脏稍微不防滑以外，还可以想通，但是把大规格亮光瓷砖直接铺到卫生间，简直是灾难性的，一旦洗澡的时候有洗涤品流到地面，一刻都无法站立，非常危险的做法。

**柔光砖好在哪？** 与亮光瓷砖的反光刺眼比较的话，柔光瓷砖要更有内涵，更低调，而且看上去更有档次。同样无主灯的环境下，亮光砖和柔光砖不同角度对比，效果立马能见分晓。柔光砖不反光、防滑显档次，适配多种风格和空间。如果你是北方地区，家里有地暖，冬季的时候，瓷砖温热，随时席地而坐，家有小孩地上爬行，温润的柔光瓷砖不仅防滑而且更环保。

**还要纠正一个误区。** 瓷砖是柔光还是亮光，决定不了光线，但是可以决定档次。瓷砖光泽度并不决定空间亮度，实际亮度由自然光条件和砖色深浅决定，而柔光砖因更易打理且呈现低调有内涵的档次优于亮光砖。

**最后一句大实话。** 你如果能接受柔光砖通铺，硬装第一步已经完胜百分之八十的人了。当然，如果你把亮光瓷砖的贼亮当成是一种时尚，浮夸的美的话，也无可厚非，人的审美有时候是无法互通的。但普通家庭想过日子，柔光砖，不会错。
