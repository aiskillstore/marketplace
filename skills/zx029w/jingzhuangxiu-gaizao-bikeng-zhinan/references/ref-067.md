# 瓷砖质量差还是工人手艺差？各自表现是什么？1.1

家里装修瓷砖问题，不外乎两个问题，第一人为导致问题，这里包含瓦工手艺以及后期破坏，第二瓷砖本身质量问题。今天看看这两个问题的表现都有哪些，知道这些以后，避免在手艺和质量问题上扯皮。.01瓷砖质量问题
如果你发现瓷砖无法对缝，而且量尺寸几乎每一块瓷砖尺寸都有误差，这个肯定是瓷砖的问题了，误差太大的话再厉害的瓦工也没有办法解决了，只能更换瓷砖。瓷砖有问题需要及时通知，如果瓦工明知道误差这么大还继续施工，那就又加上了人为因素了瓷砖渗污这个现在几乎很少见，必然是瓷砖质量问题，釉面质量太差才会存在这个问题；地面瓷砖如果是半瓷吸水率很高，靠的就是釉面，一旦釉面质量差，必然会出现渗污情况如上图大面积瓷砖裂缝，而不是一两块，几乎所有瓷砖裂缝，这个必然是瓷砖质量问题造成的像上图这种连找平器都没有办法矫正的瓷砖，凹凸严重，就明显属于瓷砖质量问题了，如果凹凸不严重一般找平器是可以解决的，无法解决的就是质量太严重，无法挽救了如图瓷砖误差太大了，密密麻麻的找平器最终还是无法挽救，就会出现右图高低不平的问题，只能大面积更换瓷砖了，这个就属于瓷砖质量问题了；所以谨慎用大规格瓷砖，你家是否有档次用再大规格也没用，瓷砖规格越大，越会出现平整度的问题，都有美缝了，不要跟风用大规格瓷砖了没有铺之前白白净净很好看，铺好了结果颜色全变了，这个完全是瓷砖的问题了，吸水率太大，导致后期深色吸色瓷砖波浪边这个属于重大质量问题，必须退货处理了没有一块是平的，肯定是瓷砖质量问题，但是瓦工也有问题，既然不平刚开始铺必须通知更换瓷砖，结果是不平照样铺，这样导致业主无法退货了不仅渗色而且美缝做了直接缝隙变色，瓷砖太便宜了，这种质量堪忧了如图半瓷砖，吸水率太大只要见水就是这个样子，你还不能说瓷砖质量有问题，吸水率大的半瓷几乎都是这样柔光纯色瓷砖的瑕疵，如果一两块不是问题，但是每一块都有这个问题，就属于质量问题了
.02人为因素问题
如图明显是后期美缝的时候清缝不小心破坏绷瓷了，和瓷砖质量无关，是美缝工人手艺问题，这些工人一般都是图速度，因为赶紧做完下一家等着呢，靠速度赚钱，所以这里给大家普及一个常识问题-----你以为自己做美缝便宜，其实隐藏了一个巨大风险，不论瓷砖是装修公司提供还是你提供，一旦你自己的美缝把瓷砖破坏了，是不是还得装修公司更换，这里多半会收费；指望美缝工人给你掏钱，几乎没戏，散工图速度就是赚钱来了，压根不会管什么口碑不口碑；但是你如果让装修公司做的美缝，导致后期绷瓷，他们自己更换，而且即使你自己买的瓷砖，他们掏钱购买更换，这个就是区别所在，也是价格高的原因。如图的边角窄的瓷砖，想必过去装修的人几乎都遇到过，第一肯定是工人铺贴的问题，因为边角瓷砖太小，用水泥砂浆铺贴覆盖面太小，时间久了容易脱落，碰到这个情况，边角瓷砖一定要加胶铺贴，或者直接用胶粘铺贴，这样不容易出现上图的样子。上图不用说，这个肯定是瓦工手艺的问题，这种瓦工除过工费低以外，早该淘汰掉了大面积空鼓脱落，这个排除水泥砂浆过期等问题，几乎都是工人铺贴手艺的问题上图一看就有问题，哪有铺瓷砖不留缝隙，必然绷瓷，后期有可能瓷砖都会绷瓷脱落瓷砖绷瓷了，这个其实是瓦工问题，除非你都用水刀裁割就不会出现，瓦工现场裁割都会有绷瓷，只不过绷瓷了需要重新裁割，但是瓦工要不就是懒得重新裁，要不就是担心业主嫌浪费瓷砖，或者侥幸心理后期美缝能遮盖，但是绷瓷太大美缝是盖不住的，所以归根到底还是瓦工的问题如图瓷砖铺完了，发现有一块不平整，这个是瓦工责任，因为瓷砖送过来，再好的瓷砖有一两块瑕疵太正常了，铺贴过程需要看平整度，不平整需要用找平器，误差太大是不能铺的，结果不平整照样铺，这个就属于瓦工人为导致了不用说大家都能看懂，瓦工的手艺实在太差了不用说，瓦工瓷砖裁割错误导致离墙缝隙很大，必须更换掉了；碰到这个情况一旦没有同批次同色瓷砖怎么办？只能这面墙用石膏板补，让缝隙满足后期安装踢脚线即可，这个也是能够解决的上图看似瓦工错误，其实不是，你买瓷砖，需要瓷砖商出具铺贴图，瓦工只能按照图纸施工，图纸错了，瓦工也错了；如果是没有图纸必须现场排砖，有缝隙提前发现，瓦工私自铺贴那就是瓦工的问题了这个就得问自己，没有铺贴图纸咋铺砖？如果有图纸是这个那就是图纸错了，如果图纸是正确的瓦工私自这样做，就是瓦工问题了缝隙宽窄不一，这个明显就是瓦工手艺问题了.03非人为也非质量问题
如图所示，过去的瓷砖施工几乎都不留缝隙，有的只是自然缝隙一毫米铺贴，此时北方有地暖或者暖气的话，最容易出现上图的后果，瓷砖热胀冷缩会全部挤压崩开，这个不是瓷砖质量问题，也不是施工问题，是时代工艺的落后问题，只能重新拆除以后重新铺贴了。突然发现已经入住的瓷砖，一两块裂缝了。其实这个既不是瓷砖质量问题，也不是瓦工铺贴问题。一般出现这个现象，是因为瓷砖运输过程内部已经出问题了，但是表面根本看不出来，瓦工直接铺贴，时间久了热胀冷缩必然开裂。如果属于质量问题，应该是大面积开裂，而不是一两块，这个几乎很难避免。只能是尽量让开裂发生在没有入住的时候，此时好更换，一旦入住没有剩余瓷砖，不是同批次更换必然就有色差了亮光瓷砖不亮了，这个是太脏了而已，而且釉面都有磨损，想要亮得和新的一样，除非抛光，再好的亮光瓷砖，你用几年肯定不会和新的一样亮，轻微划痕以及表面不亮太正常了
