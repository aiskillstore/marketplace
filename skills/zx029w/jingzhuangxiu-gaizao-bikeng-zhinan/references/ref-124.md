# 铺完瓷砖记着放水，看坡度和防水2.8

卫生间是装修的重点，入住舒服与否，非常重要。

一、电路方面需要注意
1.照明线路

2.浴霸线路，这个最好前期考察一下，你准备买什么样的浴霸，需要预留几根线。因为现在的浴霸更新换代实在太快了，业主又不知道什么是常规产品和新产品。不协调的话，装修公司预留常规线路，业主购买新产品万一不匹配，后期装修完了非常麻烦。

3.马桶后面插座，这个需要业主自己考虑好，不要入住想装智能马桶连个电源都没有。这些装修公司会给你建议到的，做不做自己决定，不要前期不做，后期埋怨没有给你说到。

4.镜前灯，此处还得注意除雾镜，如果有提前规划电源线路。.

▲如果浴柜在干区，这里注意一般干区是单独吊顶，石膏板吊顶多一些，此处一般不需要单独做镜前灯，头顶干区本身就有灯。如果需要可以在靠近镜子处，放一个筒灯照明即可，这样又美观，就不需要镜前灯了

二、水路方面
卫生间水路一般很简单，花洒上水，马桶上水，以及洗手盆上水。这里的水路重点注意地漏，尽量不要牺牲眼下无用的地漏。好多人把卫生间不用的地漏给牺牲了，除非是有阻碍洁具安装，否则不要牺牲，保留好，后期一旦入住发现需要做淋浴房等，没有地漏是很麻烦的《卫生间多个地漏，尽量保留5.5》

三、重点要注意的
防水，一般做完防水，做完闭水试验不出问题，就开始贴瓷砖了。但是大部分业主不会在瓷砖贴完进行下一步的时候，再放水实验，可能就到入住洗澡才开始检验。这里一定注意铺完瓷砖进行下一步的时候，完全可以没事在瓷砖上面放水，多放水，一是看一下瓷砖坡度到底理想不，是否存在水流缓慢或者存在大量积水现象，如果是因为瓦工疏忽坡度做错了，此时瓦工刚完，整改还来的及，否则入住以后发现就麻烦大了。第二，瓷砖铺完多多放水，勤和楼下沟通，看是否存在漏水，这个一般不会不一定就代表你家没事，万一瓦工在施工的时候不小心破坏防水，此时虽然瓷砖已经铺完，有问题整改还来得及，总比入住以后洗澡发现漏水要好，那时候就影响自己的整体生活了。所以，业主不要嫌麻烦，多考虑一些细节，才能完美入住。
