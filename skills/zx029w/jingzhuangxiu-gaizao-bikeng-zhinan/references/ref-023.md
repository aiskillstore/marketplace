# 瓷砖和地板怎么选？

**不是好不好的问题，是能不能用的问题。** 瓷砖和地板的选择，取决于你家是否有地暖、家里是否有老人小孩。

**地暖房有老人小孩，只能铺瓷砖。** 北方有地暖时优选瓷砖。家里有小孩而且年龄非常小，地暖房子是不敢用强化和复合地板的，受热污染释放更大，而且污染的释放周期很久。实木地板倒是合适，但是昂贵的造价以及难以伺候的本性，让大部分人望而却步。北方有小孩真的不建议用木地板，如果非得用直接纯实木即可，否则不要用廉价和污染来装修。

**亮光砖的禁忌。** 亮光瓷砖反光强、防滑性差、易显廉价，仅适合搭配高档软装的大平层豪宅，普通家庭不建议选用。亮光砖严禁用于厨房、阳台、卫生间地面及无主灯设计，无主灯与亮光瓷砖本身就是两个矛盾的材料无法同时使用。

**柔光砖适合任何空间。** 柔光砖不反光、防滑显档次、适配多种风格和空间，是普通刚需家庭的稳妥选择。柔光砖通铺视觉更有延伸感，放大空间。

**木纹砖替代木地板。** 木纹砖兼具木地板颜值和瓷砖耐用易打理的特性，解决了北方地暖的一切问题，不怕污染视觉上有木地板的温馨感受。造价上一平方一百以下，各种铺法都可以实现。想要木地板效果又怕打理麻烦选木纹砖。

**木地板的弊端。** 使用年限与瓷砖没法比较，瓷砖可以用到房子报废，木地板必然破损和变色。无法通铺，时间久了潮湿起拱变形。不敢见水，越好的木地板越害怕水。地暖怕污染用实木，变形伸缩无法避免。不耐磨，长期拖把拖地木地板能坚持多久。地暖房子任何非实木地板都只是给装修污染雪上加霜。

**记住。** 地暖房有老人小孩只能铺瓷砖，柔光砖是刚需最优解，木纹砖替代木地板。亮光砖只适合豪宅配高档软装。瓷砖比木地板更耐用适配地暖，木地板污染风险高慎用。
