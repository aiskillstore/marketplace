# 瓷砖与乳胶漆过渡，如何做好收口6.5

其实如果舍得花钱的话，这个问题是不存在的，所以最终纠结的还是钱呀。

一般家庭装修，存在乳胶漆与瓷砖收口的情况，有以下几个地方：
1.阳台贴砖，客厅乳胶漆，垭口就可以解决

2.干区贴砖，外头乳胶漆，垭口同样可以解决

3.平面过渡，例如开放式厨房的瓷砖口与外头的乳胶漆收口，垭口照样可以收口

4.除过垭口各种收口线条都可以办到《什么是垭口？家里那么多垭口，知道怎么做吗？》

▲卫生间干区半截瓷砖，采用木条线条收口，也是可以的，一般有配套的瓷砖收口条的，视觉要统一多了

▲卫生间不懂金属门和瓷砖铺贴的关系，瓷砖没有铺贴门洞，导致一部分乳胶漆露出来，做的再好看也是瑕疵《贴砖和门套的关系，搞不清都是麻烦》
▲如上图，两个门洞，两个错误，左边厨房门应该装外头，压住阳角乳胶漆，瓷砖贴到门洞即可；右边卫生间干区，全部贴瓷砖，需要做个哑口套而已。
▲如图厨房半截墙瓷砖与防水漆的收口，这里有人直接用腻子收口，也是可以的，但是后期油烟很难打理，不用收口条，这里采用美缝进行处理，后期要好打理多了
▲如图卫生间半截墙瓷砖，上方黑色的防水漆，为了视觉更完美，采用黑色的瓷砖收口条进行装饰收口；
▲像平时所用的阳角条也是可以收口的，如上图就可以采用黑色带弧度的完美实现

▲如上图就是采用瓷砖专用的收口条做的，视觉更完美

▲如上图的瓷砖专用收口条，各种颜色都有，半截墙瓷砖就可以采用此种进行收口处理
▲如上图的马赛克与瓷砖四周都采用石膏线或者PU线收口，也可以采用镜边线进行收口
▲如上图的半截墙，采用钛金色的金属收口条，与金色的美缝搭配，也能搭配出轻奢的高级感
▲瓷砖与防水漆之间过渡，也可以采用瓷砖本身的腰线进行收口，颜色也统一协调
▲墙面半截墙瓷砖，直接采用上面的腻子收口也是可以的，只要油漆工做细一点，后期一样美感，唯一不足就是这棱一旦积灰尘只能用干抹布或者鸡毛掸子清理，不能用湿毛巾擦拭，否则会越来越脏
▲也可以在瓷砖上头做石膏板基层，直接批腻子刷漆，和瓷砖做成一个平面，也不存在积灰尘的问题了厨房拐角设计，一点空间都不放过
