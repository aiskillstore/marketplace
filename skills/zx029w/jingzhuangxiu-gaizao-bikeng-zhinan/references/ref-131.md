# 土豪，你装修的时候把开发商的水电全换了？3.10

其他地方不太清楚，在西安，只要你买的是正规商品房，一般收房验收的时候，开发商已经根据户型结构把水电路铺设了大概。

如果是要出租，开发商的标准完全可以不动，特别是电路几乎全走到位了，没有的只是个人需求或者爱好，对于出租户肯定不用考虑这么多。只需要把水路走好就行。

西安地区，开发商只是把水路接水口预留在厨卫，没有进一步安排到位，因为这个牵扯到个人爱好，比如花洒位置，个人喜好不同，位置就不同，所以开发商只能预留接水口在厨卫门口。需要注意的是，有的开发商直接预留了厨房到卫生间的热水管，大部分只预留冷水管，热水需要业主后期装修自己铺设。

那么问题来了：开发商铺设的电路和水路，在自己装修的时候需要全部拆掉自己重新换不？

需要全部重换得有个理由，这个理由还得站的住脚。比如，开发商作为奸商一枚，能用好东西吗？这根本不是理由，按照这个逻辑，中国百姓就别活了，因为本国的食品安全没有人重视，难道都不活了？奸商盖的楼房都不防震，你难道不买了？

那么什么是合理理由呢，在西安地区，在你交房的时候，避免不了与物业和开发商人员打交道，比如收房验房，地暖打压，维修工程，如果此开发商知道自己的水电路质量很次，（至于为什么次不用想也知道，肯定是采购的回扣吃太多，必然很次。）会在你收房过程中不断通过各种渠道散布消息：业主装修的时候最好把水电自己重走，都不保险。类似的消息会不断放出，而且在各大业主群里也会不断放出的，如果有物业人员告诉你让你换掉，而且换掉的原因是不可细说的质量问题，此时，应该当机立断整个全部换掉。否则后患无穷。你不会傻到想着开发商当面承认自己以次充好？

一般出现水电路质量次和开发商大小实力有关系，大的开发商是不会为了这点蝇头小利，在水电路材料上动手脚的；但是小的开发商基本采购都是自己家族人在做，明明知道有采购猫腻，只是睁只眼闭只眼而已，反正后期业主家家户户都得装修，后期再放话说质量不行，怂恿你们都换，开发商并不吃亏。而且开发商并不会当面承认水电路有问题的。

到此，可能有人大喊难道没有王法了，这么明目张胆的以次充好。有这想法只能呵呵了，社会主义初级阶段，毛病很多，国人都有忍力，太多的话不便多说，大家想想都懂。

没有让你重换的信息散布，还是用原来的好。一般没有任何消息来源说开发商水电路有问题的，不要惊慌，基本都是到位的，质量绝对比业主自购的要好的多。低价能买真货为什么用次货？

不要充土豪把人家好好的管线全换了，在原来基础上根据自己喜好和需要改动即可，否则你真的是土豪了。
