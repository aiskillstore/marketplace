# 水电改造为什么用硬线，不用软线？9.21

一般装修里头经常用到的电线就是常见的铜线，但是有软线（BVR线）和硬线（BV线）之分，上图左边就是常见的硬线，单根铜线，不同的功率使用电线的负荷不同，就是大家一般所说的2.5平、4平等等，电线的横截面积越大，输送的能力越大。右边同样是铜线，只不过是多股软线组合。一般家用会用到这两类线。今天就看看到底哪种电线用到家庭中好一点。

价格方面，同样的型号，软线要比硬线价格高；软线易老化，抗拉力不如硬线，而且软线的回收率不高；相反硬线的抗氧化性要强，抗拉力好，回收率也高。
用途方面，硬线主要用于隐蔽施工，比如埋墙与地下作为主线使用，而软线多用于连接电源使用。此处两者无好坏，只有位置用途不同。
施工方面，软线相对来说好穿线，硬线太硬不易穿管；但是更换抽线软线抗拉力不行抽线过程容易断；而硬线太硬不容易穿线，抗拉力好，抽线更换线路容易。硬线布线可以做到横平竖直，比较美观，而软线稍差。
软线标准施工需要用烫锡或者压线鼻子，否则软线容易翘起一根与其他导体连接，有安全隐患，但是烫锡的成本相对较高，无形中给业主造成经济负担。从经济考虑，当然硬线首选。
综上所述，到底哪种电线更好？其实从生活实际就能看出来，家里大部分出现电源线烧坏的地方，几乎都是电器自带的软线。因为是多股线，而且细，电力通过每根细线分配是不均匀的，一旦某根损坏就会增加电阻导致整个软线烧坏。所以硬线完胜。价格方面更不要说，硬线要便宜很多。所以实际装修中，避免麻烦，建议全部采用硬线施工。装修完工，你家水电图拿到手了吗
