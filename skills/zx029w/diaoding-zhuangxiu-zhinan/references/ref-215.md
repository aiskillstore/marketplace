# 90㎡不吊顶不要造型，小两口务实新家

属于小两口的新房，但是为了考虑长远，装修的时候就得规划好未来的发展。纯南向空间，三间卧室都非常小，一厨一卫也很紧凑，唯一欣慰的就是公共区域相对宽敞。

▲原始图纸，进门就是客餐厅共用空间。入门右手分别是厨卫空间，很紧凑。主卧和儿童房夹一个窄条生活阳台。次卧准确来说属于客厅的生活阳台，但是没有下水，这里可以兼顾次卧使用。

▲设计布局图，进门右手布局放临时鞋子的空间，兼顾换鞋凳功能；左手利用餐边柜定制，侧面实现超级鞋柜收纳；为了满足主卧的收纳以及布局，移动了主卧入门位置，实现超级收纳以及书桌办公空间；原有客厅的休闲阳台打造榻榻米，采用玻璃移门形式，满足次卧同时尽量不影响空间采光；唯一的儿童房只能在主卧隔壁，空间太小了，暂时采用上下铺满足功能
▲右手空间简易上下柜定制，刚好满足进门放置基本的鞋子，同时镂空处可以满足全身镜以及进门挂衣服包包的需求，上方吊柜满足杂物收纳
▲入门左手刚好利用定制餐边柜侧面满足鞋柜的布局，同时也满足了冰箱的镶嵌；四人位餐桌满足基本就餐需求
▲除过餐厅两盏吊灯搭配以外，其他空间明装筒灯，无主灯设计，让灯光层次更丰富，同时视觉更简洁
▲白色与木色的搭配，整体风格清新，同时又有木质的自然和温润
▲餐客厅全景，打开主卧门，同时次卧做了玻璃移门，满足基本的采光需求。无吊顶也不做任何多余造型，挂机满足功能，同时不占地
▲电视墙定制收纳柜，同时满足收纳和电视墙功能，灰色的轻巧沙发搭配简单的木质三角几，视觉和空间都显得更加宽敞
▲反过来看全景空间，白色与木色的清新自然，同时加入灰色局部色彩点缀，清新小家非常务实干净
▲主卧因为空间太小，为了实现大床以及收纳布局，采用移动入门的形式，满足门后的衣柜定制，改变床铺位置，窗下还实现了办公空间
▲大面积白色与蓝色呼应对比，视觉清新，整体明亮干净
▲床尾定制书桌书柜，满足平时的办公需求
▲移动卧室门以后，成就了超级收纳，同时满足了女主的化妆台功能
▲主卧隔壁的次卧空间，因为空间太窄，打造成了榻榻米，同时满足超级收纳，采用玻璃移门保证公共空间的采光需求。布帘搭配随时满足一间卧室的需求
▲儿童房非常小，而且还带一个小的生活阳台，上下铺以及衣柜，以后这里可以作为儿童房备用
▲厨房本身很小，只能满足L型定制，满足基本的功能需求，水磨石瓷砖与面包砖搭配，整体明亮干净
▲这就是儿童房带的非常小的生活阳台，布局洗烘机以后，侧墙超薄定制了一个小的洗衣盆，电动晾衣架满足晾衣需求；墙面白色乳胶漆，搭配灰色地砖，整体明亮干净
▲卫生间太小无法做干湿分离，只能采用墙排马桶布局，满足淋浴的玻璃隔断设计
