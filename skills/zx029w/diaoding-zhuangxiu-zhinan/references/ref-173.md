# 看了这些案例，以后再也不做多余吊顶了3.24

吊顶其实就两目的，第一压低定制，为了等高设计的审美，同时压低定制的造价；第二隐藏大梁以及难看的家里的结构。剩余其实就是装饰，而且这种装饰不一定有用，有时候反而是一种累赘。如图现代复古风，家里大梁太多，不可能牺牲层高全部用吊顶隐藏，干脆全部裸露，但是你能说人家装修很廉价吗？所以与其用廉价材料堆积提升档次，不如实际一点，用家具和软装来成就品味之家。餐厅有个大梁，家里又不做中央空调，此时并不需要非得用吊顶隐藏大梁，而且即使隐藏也没有办法彻底隐藏，只能是自欺欺人的一种做法而已，还造成了成本提高，后期家具软配跟不上，反而显得不伦不类异形大梁，与其采用吊顶自欺欺人去隐藏，不如直接做灯带处理，满足照明功能，同时弱化大梁的存在感大梁太多太大，没有办法采用吊顶隐藏，此时利用吊顶做灯带无主灯设计，反而是一种简单的做法，而且满足了功能，反而弱化了大梁的存在感即使家里有中央空调，除过必要吊顶以外，剩余大梁没有办法隐藏，完全没有必要非得吊顶处理，直接裸露，把钱用到后期实木家具上，有大梁家里也不会廉价上图餐厅大梁并不妨碍任何事情，除非你把餐厅整体吊顶但是压低层高，此时只需要定制上头吊顶满足等高美观即可，保留大梁并不影响整体的档次上图阳台大梁不去管它，不做吊顶隐藏，难道人家就很廉价吗？不是，钱用到了后期的家具和软配，而不是花里胡哨的吊顶客餐厅之间大梁不管它，并不影响装修的颜值阳台大梁你们认为的丑陋并没有影响人家的颜值和质量，因为问题压根不在于你做多少多余的吊顶，而是审美和是否知道装修的价值中间的大梁并不需要非得处理才有颜值，影响颜值的不是大梁，是自身审美和钱花到刀刃上大梁不是非得吊顶处理，自然裸露并不会影响整体颜值，但是决不能本末倒置，家具软配廉价，却把钱用到无用的吊顶上好的设计绝对不是让你各种建材堆积，各种无用的造型吊顶都做，否则装修的出发点除过金钱就是金钱，必然出来是堆积的廉价感并不是所有的大梁都必须用吊顶处理，无法处理的大梁可以不管它，因为它完全和颜值无关并不是吊顶越多，就有档次，没有必要的吊顶只会更廉价
钱是都花到了好多没用的吊顶上了，而且非常高调，这个就是装修里头的本末倒置，这样做再多也无法改变廉价的宿命没有中央空调却学着别人做吊顶，可是顶面都是波浪不平，后期家具的钱却是能便宜就便宜，结果整体廉价比较一下人家做中央空调的，只做必要吊顶，其他任何吊顶石膏线都不要，问题到底出在哪一目了然--钱花到了不该花的，该花的却舍不得---这个也是大部分装修机构和建材商狼狈为奸引导业主干的事情。再多吊顶也挽救不了廉价感，因为所有东西无一不是建材的堆积，刚好满足市面上大部分装修机构和建材商的圈套了，并不是花钱就有档次，没有审美的支撑，没有替你着想的装修机构的支撑，钱并没有价值为什么不把无用吊顶的钱花到设计和好的家具上？完全是为了面子而装修，而大部分这样审美的人从来不会觉醒再对比一下上图，你就明白吊不吊顶和效果压根没有关系了
