# 入户门直对厨房门，怎么去装修？

进门是厨房的户型非常多，后台有业主咨询进门直对是厨房，该如何来装修。今天来看看这些进门直对厨房的户型，都有哪些做法。

▲进门有单独门厅，但是直对厨房门。一是入门就能看到厨房内部，二是影响门厅的收纳，第三同时长条形厨房格局也不是很好，无法满足冰箱的放置。所以刚好朝向客厅有局部非承重墙，改变厨房的进门方向，同时朝门厅拓展厨房空间，满足了冰箱的布局以及L型橱柜的定制，也不会影响门厅的收纳，进门空间更完整
▲装修后的门厅实景，左手定制入门鞋柜收纳，门厅缩小了刚刚满足，同时解决了进门直对厨房门的尴尬

▲同样是进门直对厨房的户型，改变厨房门方向朝向客厅空间，增加厨房采光，同时满足橱柜的U型布局，还满足了冰箱的放置；原来直对的厨房门刚好定制镶嵌鞋柜，满足了进门的玄关兼鞋柜收纳
▲装修后的实景图，原来厨房门洞刚好定制鞋柜，满足进门的收纳；同时为了进入客厅动线顺畅，直角墙做了斜面处理，动线更顺畅

▲同样是进门直对厨房门的格局，而且厨房墙体都是承重墙，无法做处理，只能按照原来的格局满足功能性，左手定制鞋柜满足入户收纳，为了避免进门直对厨房门的问题，借用餐边柜延伸厨房墙体，满足外挂谷仓门的做法，这样进门视觉能更生动+一点
▲装修后的实景图，左手定制鞋柜满足基本的进门收纳；直对厨房门采用木质的谷仓门做法，进门视觉更灵活，避免进门直对厨房的问题

▲还是进门直对厨房，而且厨房很小，同时家里客餐厅无法布局，采用把厨房移到阳台的做法，成就一个餐厅空间，同时直对做了进门的玄关鞋柜满足基本收纳
▲装修后的实景，进门直对做了L型的收纳鞋柜，遮挡进门的餐厨，同时满足了进门的收纳

▲进门就是过道，同时直对厨房门，没有办法改动，只能砸掉厨房墙体，采用玻璃通透门联窗的形式满足进门过道的光线，同时矮柜鞋柜满足进门的基本收纳，光线和视觉都得到拓展

▲装修后的实景，砸掉进门的厨房墙体，做成门联窗的形式，不仅解决了进门光线问题，视觉也得到拓展，同时下方矮柜满足鞋柜收纳，并未影响采光的良好

▲进门直对厨房，原始厨房门小，不仅影响采光，而且对着入户门，所以直接砸掉原来厨房多余的墙体，做成移门布局，不仅解决进门直对厨房的问题，同时也解决了进门直对厨房门的问题
▲装修后的实景，进门原来直对的厨房门做了移门居中处理，这样不仅拓展视觉，同时原来厨房门洞新砌墙，一副抽象挂画装饰，作为进门的玄关端景

▲入户门直对厨房，采用牺牲一间房子的办法，成就餐厅，同时改变厨房门方向，原来厨房门位置刚好成就进门的直对玄关柜

▲改变厨房入门方向以后，成就了餐厨的动线，同时原来入户直对的厨房门洞摆放玄关柜，黑板墙布局，刚好作为进门直对的玄关
