# 75㎡两室不吊顶简单装修，两人清爽婚房

两室空间，目前作为婚房使用拥有了两个小房间和一个还算宽敞的客餐厅家里居住着两个人一只猫下班一起吸吸猫，打打游戏看看书选择搭配木色和奶色等暖色系的家具和摆件再搭配一些彩色的装饰品和绿色植物让我的家看起来不那么的单调每天下班回到家 看着这个温馨的家没有装吊顶、隔断和电视背景墙。以简约为主，怕收纳空间不够没有隔断，显得通透全屋刷白墙，看着更亮堂不放茶几，给客厅更多的活动空间不做电视背景墙，看着简约不过时铺木纹砖 让空间有延伸感不做背景、吊顶和隔断 显得更宽阔许多家具都以原木色、米白色为主再用地毯、挂画、灯具和好看的摆件来提升氛围感餐边柜和玄关柜都是定制了顶天立地柜，收纳空间足足的去掉吊顶、吊灯和茶几让家里的活动空间更大，看着也跟开阔不压抑在能打柜子的地方都打上了柜子增加衣物的收纳空间次卧定制榻榻米，即使以后有玩具也能有地方收纳厨房也利用了S墙做了小设计，把冰箱塞了进去，利用了隔壁次卧的空间多做了30公分的小台面，冰箱处好多借了25公分，加上台面，刚好和冰箱持平小厨房虽然小但只要好好布置也可以拥有许多东西
