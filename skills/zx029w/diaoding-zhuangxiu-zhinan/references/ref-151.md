# 除了吊顶，屋顶装饰很简单4.23

普通家里装修，没有固定一成不变东西，比如吊顶，除过做中央空调不得不做吊顶以外，经济紧张学别人做吊顶，其实就是自己折磨自己而已。绝对不是说你家吊顶了就有面子了，面子是装修的内涵，无形中散发的高端和艺术。这个不是吊顶给的，是功能、颜色、家具，喜好，整体作用的结果。

NO.01

一般吊顶都有哪些形式

▲中央空调灯带吊顶。一般四周灯带吊顶过去做的多，现在做的话，一般灯光是与过去有区别的，过去灯带五颜六色，和KTV一样，现在几乎多为白色，为的是照明。一般空调出风口位置不做灯带，只做三边，会遮挡风口，否则吊顶会压到更低，这个可以参考《关于中央空调，这些最好提前了解》

▲无主灯平面吊顶结合局部吊顶。很流行的做法，视觉极简，前期走电路也比较方便，就是造价高很多了。
▲无主灯平面吊顶+宽边。同样是潮流做法，不同的是除过平面吊顶以外，四周采用宽边石膏板进行勾勒，和窗帘盒形成一个完整的空间，同样极简时尚
▲四周实心吊顶。区别与过去的灯带吊顶，不至于藏灰难打理，视觉干净，不论是有没有中央空调都是可以做的，搭配上局部通筒射灯氛围布置，效果不错
▲不规则中央空调吊顶。另类做法，因为空间实在太小，大面积吊顶显得压抑，故采用不规则做法，让视觉上更加另类，轻易不要尝试，一旦结果错了后悔来不及了
▲四周实心吊顶+平面灯槽吊顶。大户型专属的做法，大气简洁，同样无主灯，所不同的是多了一些灯槽布局，视觉更时尚有层次而已
▲四周宽边石膏板勾勒。也是非常适合空间小的户型的，像吊顶，但是没有吊顶的压抑感，可以营造出一定的层次感《宽边石膏线好看，怎么施工？》
▲局部实心吊顶+灯带吊顶。虽然有中央空调，不在风口位置做灯带，而是局部点缀，可以让呆板的吊顶视觉更灵活，同时灯光的层次感更丰富
▲悬浮吊顶。不仅大气，层次感无与伦比，但是家里层高需要满足，同时空间需要大。
▲灯带吊顶+顶面线条勾勒。多见于欧美风装修里头，需要有一定的适应，否则时间久了真烦
▲斜面吊顶。多见复式或者阁楼空间，确实新颖好看
▲吊顶+金属线条。也是近年非常流行的做法，多见新中式或者轻奢风
▲九宫格吊顶。同样适用于大户型，多见欧美风格

NO.02

除过吊顶还有什么做法

▲不吊顶，不要石膏线。寒酸吗？当然不是，只不过把钱都用到家具以及后期软配上而已，视觉干净，但是并不失档次。
▲不吊顶，只有石膏线。非常简单温馨。《不做石膏线，装修公司硬要免费送？》
▲宽边石膏线。不同于成品石膏线，这个是工人现场采用石膏板制作的，同样没有吊顶，无主灯明装筒灯，视觉照样极简时尚
