# 不要电视，不要投影，不要造型，背景墙咋做9.17

现在做法基本不会跟风或者是传统做法了，所以就存在一个问题，客厅不看电视，又不要投影，更不可能无聊透顶弄个无用的造型，那电视墙咋办？空着浪费，做功能的话都有哪些既能满足颜值又能满足功能的做法。…1.收纳柜满足储物
做成收纳柜与书柜的结合，大面积封闭满足储物收纳，同时免去打理麻烦；下方局部镂空一排采用收纳盒子满足孩子的玩具收纳，一部分满足少量书籍的放置，高低也可以满足孩子的随手拿取一面墙的收纳柜，同时满足餐边柜以及公共区域的收纳，同时空间也能保持更整洁做成推拉门书柜，这样可以满足视觉整洁，避免开放书柜灰尘的打理，同时局部空间满足了收纳直接一面墙收纳柜即可，采用悬浮设计避免满墙柜空间压抑感进门一面墙收纳柜一直延伸至客厅，满足家里的收纳储物，同时保证空间的整洁和高级感

满墙拱形造型，书柜定制，满足书籍的收纳去客厅化，不要电视，不要投影，电视墙一面墙书柜设计，同时去掉沙发，长条桌布局，满足不同的生活习惯不用电视，又不需要那么多书籍收纳，采用矮款书架布局，满足少量书籍收纳，视觉上也更简洁，空间能更开阔成品的书架置物架，然后搭配挂画绿植，即使没有电视也可以更有颜值，同时兼顾一部分功能矮书柜不会压抑，满足局部书籍收纳，同时挂画装饰，兼顾颜值去客厅化设计，长条桌布局，满墙书架满足书籍收纳不要电视，采用矮书柜满足孩子玩具书籍的收纳即可…4.不要电视但有电视柜
不要电视，但是悬空电视柜以及吊柜满足收纳，采用挂画以及天际线灯满足装饰和营造氛围感什么都不做又感觉单调，落地木质电视柜，上方挂画和摆件装饰，同样提升空间颜值不是没有买电视，而是压根不打算要电视，挂画斜靠，电视柜满足局部收纳即可放一个比较大的电视柜，不要电视，用来满足收纳以及孩子更多的活动空间高低柜满足一部分收纳，各种摆件装饰即可，不需要电视机
