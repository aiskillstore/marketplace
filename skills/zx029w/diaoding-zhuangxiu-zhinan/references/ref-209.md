# 为何餐厅窗户不用布帘？这些材料是绝佳之选2.22

空间越小，布帘越是显得厚重，不仅缩小了面积，而且视觉上更是累赘，所以能不用尽量不用，而且还能节省费用。今天看看餐厅窗户不用布帘的各种做法。

如图根据风格协调，采用木百叶透光，满足餐厅窗户的隐私以及采光需求

餐厅小窗户，采用香格里拉帘，满足隐私同时兼顾采光的通透，不会牺牲空间的视觉简洁

餐厅飘窗同样采用香格里拉帘，满足透光以及视觉空间的简洁

实在没有办法做卷帘，可以采用纱帘满足透光以及隐私需求

也可以用透光的百叶帘，满足视觉的简洁以及透光，氛围感满满

为了满足就餐的氛围感，采用了双层的纱帘，让就餐区氛围以及光线都得到满足

餐厅也可以采用麻制的罗马帘，满足氛围感和透光感，视觉空间也简洁美观

黑白灰的风格里头，餐厅窗户黑百叶满足风格的协调，也超级有氛围感

餐厅特定风格里头，也可以采用木质百叶满足氛围以及透光效果

餐厅窗户木质百叶搭配麻制的纱帘，氛围感绝无仅有
餐厅窗户采用西厨定制柜，采用香格里拉帘满足视觉的极简，满足隐私和采光通透。两个窗户的餐厅光线非常好才，采用极简的铝百叶帘，营造光影效果，视觉极简，同时保证了整体空间的轻盈感极简铝百叶满足餐厅的氛围，保证光线和视觉的通透，但是内开窗用百叶窗户是无法打开的，除非拉起帘子才能打开窗户黑白灰的色系做法，采用黑色的百叶满足餐厅窗户的隐私，同时满足了光影需求，视觉整体统一协调香格里拉帘营造氛围以及光影效果，让就餐更有氛围原木风开放餐厨一体，统一彩色木质的百叶满足隐私以及视觉通透，同时与风格协调统一餐厅落地窗满足光影通透，满足隐私以及视觉空间的更加简洁轻盈餐厅靠窗定制高柜以及吧台空间，采用木质百叶满足光影和隐私，同时满足氛围感餐厅飘窗内开窗，采用纱帘满足光影以及隐私，同时保证空间上的通透轻盈餐厅香格里拉帘颜值和采光都非常好，内开窗也可以，但是必须上头预留安装空间餐厅落地窗而且是内开，采用预留窗帘盒，纱帘的形式满足隐私以及采光的通透即使内开窗也可以用上方的预留空间，实现美美的香格里拉帘
