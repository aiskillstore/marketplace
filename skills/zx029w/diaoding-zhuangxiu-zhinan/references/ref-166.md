# 装修吊顶，大有讲究5.29

吊顶对于装修来说，看起来稀松平常，但其实大有讲究，并不是跟风，并不是随心所欲，有些是必做，有些是故意让你做，所以作为业主来说一定心理有数，为钱也为效果。

第一、厨卫吊顶必做

在知乎上有好多人都在问，厨卫不做吊顶可以不？其实厨房如果条件符合就是可以的。

厨房吊顶需要隐藏的其实就是烟道的止逆阀以及烟机管子，如果烟机管子刚好能藏到吊柜里头，就可以实现隐藏；其次厨房有下水管的弯头，如果弯头也刚好在吊柜隐藏，同样满足条件；剩下的燃气热水器的排气管，能接受外露也是可以的。

需要注意的是，厨房墙砖需要贴到顶部，与顶部乳胶漆（防水漆）收口美观问题；同时顶部做乳胶漆或者防水漆还得不附着油烟，后期好擦洗，否则顶面用不了多久就被油烟熏黑。

以上还不是最主要的，最主要的是层高问题。

▲如上图所示，大部分高层商品房净高是2.7米，铺完地面瓷砖是2.6米左右；如图你家吊柜就需要做到一米高度才能满足隐藏管路的需求；此时吊柜比地柜高很多，难看不说，最上头你也够不到；除非你家厨房净层高本身只有两米三四，层高太低，才有不想吊顶的想法。

▲如果你不吊顶也不做吊柜隐藏管道的话，就成了如上图的效果了，各种管路都得外露
▲探讨卫生间可以不吊顶的问题，首先搞清楚上图南北方的差异；左图是北方常见卫生间的管道，也就是你家管道在楼下，你家头顶的管道是给楼上排水用的；右图是南方常见的下沉式卫生间，所有管道都在自己家里。
如图的话，如果你家是下沉式卫生间，只要解决掉排风管外露问题，你不吊顶直接用防水漆也是可以实现的；但是北方卫生间头顶密密麻麻管道，你不吊顶还真不行。
第二、厨卫集成吊顶弱化存在感
▲厨卫吊顶用集成吊顶，谨记纯色哑光，一定不要选择花里胡哨或者镜面的吊顶，会让空间更有廉价感，而且会让视觉更突出，弱化吊顶的存在感才是厨卫吊顶的最好做法。
第三、蜂窝大板是为了减少缝隙，不要本末倒置
▲还有最近流行的蜂窝大板吊顶，为什么要用大板？因为规格是1.2米乘以2.4米的，目的就是为了减少缝隙，然后好多人本末倒置，没有缝隙了，全部花里胡哨，如左图所示，本身面积很小，这种厚重的做法，失去了减少缝隙的意义了。用蜂窝大板一定是纯色，不要任何累赘的线条，这样一般的厨卫可能两张板子就行，只有一个缝隙而已，这才是蜂窝大板的价值所在。
第四、石膏板除非有钱，刚需算了
▲颜值最好费用还能实惠的当然是石膏板吊顶，但是除非你家是别墅或者有钱不怕麻烦，否则还是算了。
第五、生活阳台局部或者全部吊顶阳台需要吊顶吗？看功能和需求，每家生活习惯使用情况不一样，区别对待。
▲上图卧室阳台，没有洗衣机，没有晾衣架，此时如果只是希望窗帘不漏光的话，是不需要吊顶的，只需要做上窗帘盒即可，也是可以满足功能的
▲如图局部吊顶压低收纳柜的做法，同时窗帘盒布局与局部吊顶高低一致，中间不做任何吊顶，这样能最大限度保证阳台的层高
▲即使放洗衣机阳台，同样可以局部吊顶实现，目的是隐藏上方的下水弯管，同时可以压低吊柜，视觉好看，收纳高低也符合拿取的习惯。
▲整体阳台平面吊顶，刚好隐藏大梁，同时与客厅局部吊顶高低一致，这样延伸定制柜可以保证一体高度，视觉更好看
▲局部吊顶隐藏下水弯管即可，同时压低收纳柜，原有阳台不吊顶，直接安装电动晾衣架，更实惠
▲洗衣机上方吊柜局部吊顶满足隐藏弯管以及压低吊柜的作用，其余都不吊顶，一侧安装小的电动晾衣架，保证层高也满足功能
总结一下：阳台其实并不是非得吊顶或者非得贴墙砖，这个需要根据自己的思考和生活习惯来判断《生活阳台照样乳胶漆，不贴砖，有人这么干》至于弄个手动晾衣架然后吊个木顶还是算了，两个加起来都能买电动晾衣架了《阳台不吊顶，更换电动晾衣架，反而节省一大笔费用》

第六、客餐厅以及弱化大梁的吊顶客餐厅没有中央空调，不做收纳柜，一般不建议做吊顶，你家有没有品位，其实有时候和做不做吊顶没有关系，主要在于后期的家具档次和软配。
▲如上图所示，家里不用中央空调，公共区域又不做通顶的收纳柜，完全没有必要有任何吊顶，但是后期家具全部实木的，同样能有档次和质感
▲比较一下如图的做法，不仅做了吊顶，而且还做了电视墙，效果在哪？问题出在哪？因为内在无法支撑，只能靠这些花里胡哨的造型来填充，适得其反，反而让廉价感雪上加霜了。不如花里胡哨的造型不要，把钱花到后期的家具和软配上
▲有风管机或者中央空调，同时还要定制收纳柜，是必须吊顶的，其次还得考虑与整体配合，如果做全部无主灯暗藏的话，整体平面吊顶也得做
▲至于所谓单双眼皮的话，千万不要跟风了，一定要注意结合实际去做《两层石膏板，就成了网红双眼皮吊顶了》
第七、卧室吊顶卧室需不需要吊顶，看基础施工，如果有中央空调是必须吊顶的，没有中央空调可以局部吊顶，也可以不做任何吊顶。
▲如图所示，卧室没有中央空调，不做任何任何吊顶，甚至连石膏线都不要，衣柜通顶定制，也是可以的，并不会影响什么
▲如图做法几乎是卧室有中央空调的标准做法，除过局部吊顶以外，其他单眼皮四周环绕形成整体感，或者连接窗户下的窗帘盒的做法
▲当然如果不做中央空调的话，也可以衣柜局部吊顶，压低衣柜，让视觉更好看，同时可以采用单眼皮比较低的做法来配合四周装饰，因为要考虑挂机的安装，所以此时的单眼皮吊顶不能太高，否则可能会翻车
▲卧室单双眼皮吊顶还得考虑衣柜的做法，不能东施效颦，自己又不懂装修设计，到后面定制柜子才发现，完全做错了
▲卧室没有中央空调，千万别学着中央空调去做所谓单双眼皮吊顶，高度太高，后面连空调都得翻车
第八、门厅吊顶门厅单独吊顶一般是石膏板造型，根据需求的不同做不同造型，但是也不是非得吊顶不可，不是为了颜值，是为了满足功能
▲单独门厅有大梁，一般为了好做鞋柜以及弱化大梁，必须做吊顶，小空间多以平面吊顶居多
▲如图完全就是为了鞋柜的定制，吊顶下压高度，这样视觉上更好看，同时局部隔墙可以满足镶嵌的处理方式，弱化柜体的存在感
▲门厅不一定非得吊顶，有时候不需要定制通顶鞋柜，也可以不做任何吊顶处理
