# 没有造型，不要吊顶，130m²四室照样清爽

时下最流行的就是清爽极简的北欧风，不论大小空间都能适用，关键是造价还不高。所以本套依旧是极简做法，采用家具和后期软配颜色来做，而且没有造型，不要吊顶，石膏线也不要。

▲原始户型图纸，进门右手依次是客厅、儿童房、主卧。左手依次是餐厨、小书房、次卫，次卧、主卫。

▲平面设计图纸。大格局变化不大，只是做了微调。进门为了定制收纳鞋柜，一边新砌墙体，沙发墙砸掉一部分。客厅和儿童房共用超大阳台，为了儿童房功能更全，隐私更好，把儿童房阳台和客厅阳台做了分割，满足儿童房学习和收纳空间。为了拓展餐厅空间，改变了小卧室的进门方向，移动墙体缩小小卧室做了小书房空间，移门和厨房门直对设计，让餐厅不仅放大空间，视觉更通透。客卫是长条形，所以做了干湿分离的设计处理。
▲门厅空间，左手区域定制鞋柜满足进门的收纳，拐角位置做了L型换鞋凳，可以满足平时拖鞋放置，同时挂衣钩基本满足进门随手挂衣服
▲门厅全景，单独的入户门厅地方挺大，平时就是鞋柜收纳，右侧落地窗光线非常好，摆上几盆绿植就可以让进门口温馨美丽
▲门厅进来右手就是客厅全景，与阳台打通光线非常亮堂，而且为了视觉简洁，把客厅内部的窗帘做到阳台上，客厅视觉更干净，空间做了进一步的放大。很小的细节改变就可以成就大收货。咖色布艺两人位搭配小尺寸薄荷绿的休闲沙发，而且与薄荷绿窗帘呼应，视觉非常清新
▲沙发区域全景，白色家具，墙面局部素雅灰色变色，背景三幅清新挂画单独黑色射灯点缀，空间视觉层次更好，更赏心悦目
▲整体空间硬装非常节省，没有任何多余造型，不要石膏线，墙面变色因为是浅色也是和白色一样价格，硬装上做到了极简。电视墙高低柜收纳，白色与木色经典的清爽搭配。干净的白、温润的木色。清新的薄荷绿，成就不一样的美家
▲客厅看餐厅空间，本身空间的大梁视觉上做了分区处理。原来的小卧室改变进门方向以后，过道上缩进一部分，刚好成就斗柜和挂画的端景布置，一举两得
▲门厅进来左手的单独餐厅位置，原来的餐厅空间比较小，为了拓展空间，移动小卧室墙体，同时小卧室移门处理和厨房统一对称，视觉上餐厅更通透亮堂。原木色餐桌椅黑色的三头吊灯搭配，极简质感
▲餐厅全景，可以满足六人同时就餐，两把白色餐椅撞色配置，让空间更生动。小窗户采用透光百叶配置视觉简洁，可以让小空间看起来更大。薄荷绿的橱柜定制和客厅窗帘沙发呼应统一
▲餐厅局部墙面高级灰变色，与沙发墙呼应，增加空间层次感
▲主卧空间，除过放置基本的原木床铺以外，靠近主卫还可以布置书桌空间，超大飘窗光线非常亮堂
▲主卧床对面通顶衣柜满足收纳，白色极简造型
▲主卧侧墙就是主卫空间，空间不够做衣帽间处理，只能靠书桌空间尽量保持一定距离
▲儿童房空间，与阳台打通，阳台和客厅阳台做了分割处理，这样阳台就可以作为单独的学习游戏区
▲统一木质与白色清新搭配，背景两幅简单卡通挂画，忽视丑陋的空调管道，实在没有办法隐藏
▲儿童房侧墙通顶衣柜满足基本收纳，白色与咖色拼色清新
▲儿童房阳台与客厅阳台隔离以后，定制收纳柜满足收纳，一侧简单学习书桌满足基本功能
▲成品的书桌以及小书柜配置，满足基本的学习功能。平时这里也可以作为孩子的休闲娱乐区
▲次卧空间很小，放置基本的床铺，满足卧室功能
▲次卧因为空间原因，衣柜定制只能采用移门形式，白色家具与蓝色床品搭配，让小空间明亮清新
▲客厅阳台与儿童房分割以后，做了休闲布置，墙面局部仿文化石铺贴，花架布置，轻巧休闲桌椅布置满足平时的休闲功能
▲厨房浅色瓷砖搭配薄荷绿的橱柜定制，角落满足冰箱放置
▲客卫干湿分离设计，因为是客卫缘故，同时家里老人不习惯座便，所以就设计蹲便
▲主卫浅色瓷砖搭配，定制浅色浴柜，淋浴处单独挡水和浴帘配置，简单分区
