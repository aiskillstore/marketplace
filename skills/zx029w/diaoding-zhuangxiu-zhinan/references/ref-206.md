# 干区兼放洗衣机，水路和防水怎么做？

装修如果只是刷墙铺地，不注意细节，那叫做干活；装修公司存在的意义是什么？绝对不是给你施工那么简单，而是给你想好你想不到的细节。而好的装修公司绝对是细节制胜，这就是装修的价格和价值的区别。

01
干区防水做法

想要搞清楚问题之前，你得先知道什么才是干区。绝对不是你用玻璃把淋浴挡着的干区。好了，不懂的可以先普及一下《干湿分离就是把水隔开？别再误导业主了》

清楚了这个问题，以下探讨才有意义。

▲用具体的案例来探讨，如上图。

1.卫生间干湿分离处理，干区地面和客餐厅地面通铺。注意，唯一没有过门石的地方就是干区与客餐厅的通道。既然没有了过门石，也就是这里一旦漏水是会流到客餐厅的。故干区地面防水的意义何在？所以一般为了视觉上美观，这种情况干区地面是没有必要做防水的，做了也没有任何作用，通向客餐厅位置没有任何阻拦。可以只给干区浴柜的三边墙面涂刷防水即可，起到防潮作用，前提是干区墙面都得贴瓷砖，否则如果直接是乳胶漆，防水做了无法做基层处理的。当然也可以干区不做防水，不会有问题的。

那干区不做防水漏水咋办？没有办法，有失就有得，为了视觉上的美观往往必须牺牲一些东西。唯一能做的就是干区的龙头软管以及角阀，购买的时候一定要质量好，而且在使用多年以后及时更换。

▲第二种做法是，干区通向客餐厅区域也做过门石，此时你会发现，干区形成一个独立的空间，此时干区的地面防水才是有意义的，地面墙面都可以做防水，一旦漏水，三个过门石阻拦，水会顺着下水流出去。墙前提是你的下水有地漏和竖管，否则下水做错也是白搭。

总结：干区防水取决于干区是否为独立区域，不是独立区看起来美观，但是无法做挡水处理；做独立区域需要加过门石，不美观，但是可以做防水，能预防水患，怎么做个人决定。

02
干区下水的做法

其实一般如果你家本身开发商就是干区设计，干区一般都是竖管的做法，上图右边就是竖管，顾名思义就是竖在地面上的下水管。

▲还用上图举例，如果干区与客餐厅没有过门石，此时不做防水，记住这里一定是竖管下水，而不是地漏。竖管下水加个三通，就可以让洗手池和洗衣机共用，这样两者都不会存在溢水问题。

▲如上图，一个竖管三通链接，洗衣机和洗手盆就可以共用，而且不会存在溢水情况。

▲第二种，干区是单独区域，放置洗手盆和洗衣机，此时是单独区域，就需要做地面和墙面防水，但是注意这里就不是竖管了，而是竖管和地漏并存。竖管加三通是为了共用下水，地漏是为了漏水避免水漫金山而用。
