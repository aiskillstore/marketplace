# 吊顶做断头，不如不做3.28

碰到太多做断头吊顶的，实在难以理解这种做法的目的，业主不懂，但是好多装修机构以及设计师，竟然也犯这种错误，很难理解在信息不对称的情况下，如此忽悠人，确实过分了。可能太多人不知道什么叫做断头吊顶，今天看看，以后再也不要犯这种错误了。注意看如图所示，有鞋柜的地方是薄厚做法，上头吊顶竟然也就是薄厚处理，而且双眼皮还延伸过去了，省钱吧，为啥延伸，为美观的话吊顶绝对不是这样做法，不如不做吊顶直接通顶正确做法，应该是上图的做法，视觉更完美，吊顶与定制的协调度更好，这才是吊顶的意义。如图吊顶依旧是断头做法，与其这样何必做吊顶？直接通顶更高，否则人为破坏等高审美，不啻是掏钱买翻车如图一样的错误，要不吊顶延伸整体，要不不做吊顶，而不是这种戴帽子的做法，视觉上破坏房屋设计等高的做法如图更奇葩，吊顶下方再做一排吊顶，而且到防盗门直接断开的操作，看似不影响使用，但是同样花钱为啥降低审美标准呢？如图有冰箱和柜子一起，为了满足冰箱柜的厚度，吊顶应该直接到头一样的宽度，而不是像上图一样突兀的直接断头的做法。这审美门口墙面还做格栅装饰，全部是建材堆积，基本的审美都错误了，再多装饰越显的廉价而已你哪怕和上图一样做个斜面过渡也行，也不能直接就停的做法理解不了，这样吊顶能节省多少费用？但是断头的做法彻底打破审美和档次正确做法应该是做到头，满足视觉等高原则，这样才是更美观的做法。还有上图的做法，都做中央空调了，差这点吊顶钱？然后又不定制，买个成品柜放着，花了不少钱，但是廉价如果这个是设计师设计，赶紧转行算了，吊顶直接停，你为省钱，何必双眼皮延伸？这就是赚你钱完全不管你效果的做法，因为信息不对称，在小圈子里头可能没有人看到，一旦稍微有经验的也不会犯这种低级错误真的不相信这些是设计师能干出来的事情，中央空调都有了，就为了节省一平方的吊顶钱，然后让家里呈现一个刀把的样式？正确做法肯定是让吊顶通过去，完美实现空间的方正，而且视觉上也完美达到等高原则真的长见识了，脑洞大开，真的可以这样糊弄业主？降低成本，哪怕把让人笑掉大牙的效果留给业主？为了吊顶而吊顶，难道一点审美都不要呀？又何苦学别人做双眼皮呀害怕吊顶通过去费钱？那何必四周做单眼皮？哪头重哪头轻，完全没有任何审美的做法这也叫做有吊顶？天天刷手机，倒是看看谁掏钱弄个翻车的做法。吊顶就是为吊顶，要停直接就停了？真对不起双眼皮的钱。无法理解，卧室都用中央空调了，金钱不缺了，但是审美还是封建社会的做法，物质和精神如此天地之差。如图对比，稍微有点审美，同样花钱，肯定不会做刀把 处理，肯定要直线更美观没钱咱可以挣，没审美真的就没救了，四周弄双眼皮干啥？用这个钱把吊顶做到头，其他都直角处理，比这个更美呀老天呀，要不不要吊顶还省钱，还能多放点东西，钱真的没有花到刀刃上全房都无主灯吊顶了，应该不差钱吧？门口鞋柜吊顶是个什么鬼？这设计师倒贴钱也不要，把业主的钱当纸了，完全没有价值，典型的东施效颦的做法价格≠价值，花了钱没有价值等于白搭错位地方如果没有柜子，直接用单眼皮或者双眼皮+吊顶的过渡，不会压抑，也不会突兀把翻车做到如此精致的工艺很少见，也就是认认真真，兢兢业业把翻车做成艺术品，佩服，真替业主难过一波又一波把翻车当做艺术去做，以为东施效颦是美，其实是多花钱完全没有价值其实如上图所示，厨房门口宽吊顶配合一下，就可以满足冰箱的厚度，也不用纠结刀把结构了和这个也类似，做不做空调吊顶，做一个冰箱高柜宽度的吊顶即可解决吊顶刀把问题如图这种审美都对不起灯带了，不做灯带，吊顶稍微延伸一下就可以解决这个刀把问题吊顶的意义在哪？同样花钱买翻车？见过牛逼的没有见过如此牛逼的做法，佩服，这定制也是个神人。如图吊顶是断头设计，采用弧度完美与定制结合，让缺点反而成了高级的亮点，这些都需要设计和更多的金钱去支撑最后：家和窝还是有区别的，同样花钱，为什么一个廉价一个高级，并不是细节做到位，而是基本的常识性错误可以避免而已。
