# 卫生间用多大瓷砖，并不是随心所欲3.9

家里用到瓷砖的地方很多，客餐厅的瓷砖需要看实际格局和铺砖图才能决定大小，同样是不可以随心所欲。像卫生间就更复杂，一般默认卫生间地面300*300地砖，为什么不铺大一点的呢？因为卫生间有坡度没法使用大砖，否则坡度出不来，坡度大了瓷砖无法铺平；再一个就是卫生间普遍面积较小，采用大地砖全部裁割，边角可能更多，反而浪费材料不好看。

第一种：没有分区，通铺小砖

▲如图这种没有做任何分区的卫生间，面积又比较小，地面必须用300*300的小规格地砖，需要整体留坡度，客观条件决定；至于墙面则没有那么多限制，只要面积符合，多大瓷砖都是可以的

第二种：干湿分区，外大内小

▲像这种完全浴室柜外置的干湿分离的做法，有所不同了，外头因为与过道公共区域是一体，为了视觉放大，干区与公共区域直接通铺大砖即可。湿区内部就需要采用小规格瓷砖满足坡度需求

第三种：没有预埋挡水条

▲如图做了一字淋浴隔断，因为没有采用预埋挡水的做法，地面必须通铺小规格瓷砖，坡度只能做一个主要坡度，也就是如果地面有好几个地漏，必须以淋浴地漏为主要目标点，进行坡度倾斜

第四种：一字淋浴预埋挡水条

▲如图注意外头地面采用的是长条形的300*600地砖，淋浴是另外一种地面材料，因为预埋挡水条以后，分区以后外头没有明水，所以无需太大坡度，甚至不要坡度，这样就可以预埋挡水条分区，外头实现大规格瓷砖，淋浴采用单独空间去做。如果不预埋挡水条，而是后期在瓷砖上头沾的，做不到彻底分区，就需要一个整体坡度，大规格瓷砖无法实现

▲如图也是同样的做法，采用挡水预埋彻底分区，就可以满足外头大规格瓷砖的铺贴，内部只要满足一个淋浴坡度即可

▲还有一种就是淋浴区域石材的做法，这样挡水必须预埋，淋浴以外的区域不需要坡度，就可以采用大规格瓷砖。但是拉槽酒店做法真心不推荐，贵而且不好打理

第五种：钻石型淋浴房不同区域
▲如图两种不同的做法，左图因为是直接粘贴挡水，所以内外一种瓷砖，必须是一个坡度的做法；右图预埋挡水，淋浴里头单独铺贴材料，单独坡度，此时外头瓷砖规格就没有限制，喜欢多大都可以用。
▲甚至如上图，淋浴挡水预埋分区，外头不要坡度，木纹砖都可以实现。
总结一下，如果你家一个很小的卫生间想要地面不同规格瓷砖，第一做淋浴隔断分区，第二必须预埋挡水条，这样淋浴外头区域就可以采用大规格瓷砖，压根无需坡度，有水的时候其实就是拖地才有，也无需坡度辅助。如果你家卫生间没有任何分区，而且小于4平方，就老老实实用300*300地砖就行，如果大于4平方将就可以用400*400的地砖，其他就不要多想了。
