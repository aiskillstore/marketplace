# 60平顶层复式小房，给个别墅也不换

▲客厅带个阳台，沙发背景灰色壁纸三幅挂画，没有吊顶使用明装射灯点缀。电视墙没有造型，放电视柜，旁边植物点缀。简易白色沙发以及简易圆形茶几，整体干净整洁

▲客厅阳台之间做了简易小吧台，作为休闲之地，也是客厅的装饰

▲进门口简易艺术玻璃玄关，沙发旁分割出一个电脑桌空间

▲拐角楼梯下方做了小储物柜，铁艺栏杆，木质踏步以及马赛克台阶装饰

▲楼上休息平台的装饰墙，各种简易隔架以及照片墙

▲转过来是一个休闲榻榻米，可以作为阅读场所，顶面斜铺白色免漆板吊顶，角落放置休闲椅子以及装饰台灯

▲楼上过道，通铺木地板，能看到卫生间区域铺贴马赛克地面

▲楼上斜顶卧室，背景壁纸，依窗户做了大衣柜储物

▲楼顶的阳光房设置会客区域以及餐桌，顶面全部使用桑拿板装饰，开了好几个采光天窗

▲卫生间坐便器墙排设置，背景使用了仿制报纸的瓷片装饰
