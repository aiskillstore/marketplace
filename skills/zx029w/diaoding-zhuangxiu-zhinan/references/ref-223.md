# 130m²三室美式，不做任何吊顶，把钱花对地方

三房通透户型，本身定位就是美式，但是又不想要太现代的，所以基本方向朝美式乡村方向做。装修预算无底洞，但是只要会规划是可以做到物有所值。我们多余的花里花哨的都不做，客餐厅几乎没有吊顶，也不要中央空调，一年就用一个多月，全部采用挂机，后期家具以及配饰一定要花重金，这才是生活品质。

▲设计布局图纸，南北通透三房空间。不足之处是没有单独门厅，不过在进门右手做了矮鞋柜收纳，同时还兼顾了吧台功能。主卧门直对入户门也没有改变，邻居家好像都改变了方向，我们一致认为这个又不影响入住，为何要讲究这些，所以保持原状。

▲入户门进来左手就是餐厨空间。不做任何吊顶造型，吊扇灯配置，夏天吃饭足够用了。落地窗光线非常好。跨度比较小，所以就采用了卡座和餐边柜一体定制的形式，这样四人位小餐桌放置，空间还能宽敞一点，同时把厨房移门做了内推式，过道空间保持动线合理

▲反过来餐厅看全景，通铺实木地板，墙面浅咖色简单变色。入户门进来右手是矮柜兼顾吧台空间

▲进门右手客厅全景，同样不做任何吊顶造型，简单石膏线勾勒。连空调柜机我们也换成了挂机，能节省点地面空间。皮质美式沙发搭配蓝色单椅和脚凳，空间还是很宽敞的。蓝色的窗帘是为了客厅更清新。

▲沙发区其实不大，三人位，两边边几以及落地灯，空间已经很紧凑了。

▲客厅看全景，电视墙简单的PU线条收框，木地板上墙和地面呼应一体，也是非常简单的造型。能看到门口的鞋柜兼吧台功能

▲铜质落地灯是一眼就看上的单品，平时坐沙发看书还是看电视，非常实用

▲过道镶嵌收纳柜。储物柜再多都不嫌多，有了孩子太多零碎需要收纳了

▲主卧空间同样没有任何造型，甚至飘窗套也没有做，墙面简单变色，干净简洁。美式的高靠背床搭配，家具才要品质

▲床对面斗柜收纳放电视，旁边是化妆台

▲侧墙直接通顶的衣柜收纳，衣服够放了

▲精美花瓶与相框装饰床头，简单温馨

▲另一边非常精致的台灯，蓝色款式非常有颜值。背景简单到一副挂画都不要，干净清爽

▲化妆台一角，同样蓝色花瓶装饰，与台灯以及窗帘呼应

▲主卧全景，蓝色元素让空间更加清新简洁

▲主卧隔壁的老人房，同样非常简洁，给老人用的是比较软的皮质床头，这样能舒服一点。窗帘也选择的是浅色米黄色的，视觉上能清淡一点

▲老人房顶天立地的衣柜满足收纳

▲绿色的花瓶与相框装饰，让老人房安静自然

▲儿童房比较小，床头整面墙蓝色的衣柜收纳，定制的榻榻米储物兼休息，床尾是定制的书桌书柜，这样布局能合理，空间也能利用到极致

▲床尾是定制的书桌书架，蓝色清新

▲因为空间有限，所以儿童房的门采用移门处理，这样不占地方

▲厨房L型橱柜布局，哑光的格子瓷砖搭配白色模压橱柜，台面做了高低台处理，使用上更方便

▲这是客卫干区地方，刚好在儿童房门口。因为过道柜子是蓝色的，所以侧墙延伸也刷了蓝色的黑板漆，一是视觉上有延伸感，二是可以给孩子随便 涂鸦

▲卫生间做了干湿分离处理，因为有水，所以就选择与木地板相近的木纹砖进行铺贴

▲干区浴柜定制，半截墙瓷砖与彩色腰线铺贴，简单干净

▲客卫湿区两色瓷砖，蓝色与米色对比层次，非常舒适。窗户边花砖点缀很好看

▲角落就是淋浴区，简单的三角架置物

▲主卫比较大，同样是两色瓷砖层次铺贴，蓝色与米色营造层次感，彩色腰线点缀
