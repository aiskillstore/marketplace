# 阳台不吊顶，更换电动晾衣架，反而节省一大笔费用6.12

今天的专题同样是关乎装修省钱的话题。更多装修省钱可以后台回复“省钱”看以前的专题。

很简单一笔账，就能算出来，到底阳台怎么做，才是真正的省钱。

▲上图是北方常见的生活阳台做法。左图是桑拿板吊顶，右图是绿可木吊顶。

一般普通的桑拿板吊顶加上各种辅料和人工，普通一点的150元左右一平方；绿可木根据质量不同一百出头一直到三四百都有；
北方地区为了安装手动晾衣架，为了隐藏难看的钢丝，所以几乎每一家都做了这样的吊顶，当然还有的做了石膏板吊顶。好看美观，还能隐藏难看的钢丝，但是其实这样做不仅不省钱反而压低了层高。
1.根据以上做法，算一笔账，假如5个平方的阳台，费用如下：吊顶桑拿板：150*5=750元；手动晾衣架好太太：800元；总计：1550元。但是这个还得牺牲你家阳台的层高。
2.如果我们不做吊顶呢？假如不做吊顶，我们安装电动晾衣架，也没有难看的钢丝，费用如下：腻子和乳胶漆：43*5=215元；电动晾衣架：1500元；总计1500+215=1715元。
从以上对比可以看出来，如果不吊顶做电动晾衣架，仅仅多花了165元。这个还是你家用的桑拿板的多出来的费用，如果你家用好的绿可木一平方二三百元的话，不吊顶做电动晾衣架还能节省一大笔费用，而且还不会牺牲阳台的层高。

▲好太太晾衣机普通的价格，在平时大的活动中，一千二三的都有，要比手动高级多了，而且更好用。
所以，如果你家准备装修的时候，自己对比一下，其实不吊顶，把吊顶的费用节省下来，更换成电动晾衣机，要实惠多了。
如果阳台贴砖，顶面不吊顶，阳台的瓷砖怎么收口？
▲直接用腻子收口，瓷砖与乳胶漆的接缝采用腻子直接收口，下水管难看的弯头局部石膏板包裹即可
▲还有一种做法，直接用石膏线四周收口更方便了。
▲如果阳台不吊顶又不贴墙砖，采用石膏板包管道，上方下水管包住，做吊柜就可以严丝合缝。
以上就是今天的内容，在实际装修生活中，发现不吊顶把费用挪到电动晾衣架上，不仅可以提升层高，而且还能用电动晾衣架，也不会有难看的钢丝，实惠多了。固定式，手摇式和电动晾衣架哪种好？
