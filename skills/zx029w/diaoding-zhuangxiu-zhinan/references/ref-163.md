# 吊顶用木龙骨还是轻钢龙骨？哪个好？4.28

如果你没有装修过房子，只听字眼，肯定认为轻钢龙骨好，硬呗。

这就好比没有吃过好东西，你问窝窝头和王八汤哪个好一样，大部分人认为王八汤大补。

这些认识都忽略了一个事实：东西再好，是否适合？王八汤好喝，你不能天天当饭吃。在合适的地方用合适的材料才是物尽其用。

木龙骨施工方便，不论你做平面吊顶或者复杂造型吊顶，木龙骨都可以满足。这就好比是家常便饭一样，一年四季吃都可以让你活下去。

轻钢龙骨材质硬，只能用到大面积平面吊顶，碰到复杂造型，弧形造型就歇菜了，再硬也用不了。这就是王八汤虽好，不能当饭吃；家常菜虽朴，去能让日子细水长流一样。

防火方面大可以不去考虑，因为一般装修厨卫平面吊顶肯定用的是轻钢龙骨，只有客餐厅造型吊顶用少量的木龙骨，就不信你家里无缘无故天天有火源？再说一般客餐厅基本都是造型吊顶，想用轻钢龙骨也用不了的。

和地域也有关系，如果是潮湿地区能用轻钢龙骨尽量使用，因为木龙骨受潮会变形；北方地区可以忽略此问题。

价格方面的话轻钢龙骨要贵得多，一般家庭又不是娱乐场所，容易发生火灾，还是用便宜又实用的木龙骨比较好。

也就是说一般家庭除过厨卫就用木龙骨比较好，完全够用，祖先用了几千年了，到你这就不行了？

王八汤虽好不能常吃，小米稀饭虽简，但可以活命。
