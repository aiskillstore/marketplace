# 100㎡三室变两室，二手房改造没有吊顶，连石膏线都不要

此套房为二手房改造，业主购置之前一直是出租状态，时间太久，基本已经破旧不堪，接手以后迫不及待需要装修入住。而且二手房工期本身就长，节假日都无法正常施工，所以从设计到施工感觉不算是完美。
户型：三室变两室套间
造价：拆除1万。全包13万含全屋定制
▲原始结构图。入户几乎没有门厅，很小的空间，右手是狭窄厨房空间。门厅进来就是过道和客厅一体空间，餐厅无法布局，只有过道可以容纳餐厅。总共三间卧室，中间卧室以及朝南卧室非常小，而且中间卧室光线不好。
▲设计以后的布局图。首先为了扩展门厅，拆除进门原来的玄关墙体，采用吊顶的形式扩大门厅，然后定制吧台分割出来一个门厅，同时把门厅扩大，与过道餐厅进行合理分区；原来的朝南小卧室门洞做了封堵，打掉两个小卧室之间的墙体，改造成了门联窗形式，这样两个卧室就形成了套间形式，不仅提升了光线，而且拓展了空间，同时两个卧室功能各自独立--儿童房同时有了一个休闲室，必要时候，这里还可以满足老人偶尔的居住
▲装修之前一直处于出租状态，原来的木地板，房客几经更换，已经变形缝隙越来越大，有的已经脱皮了
▲新装修以后更换成了耐用的瓷砖，客厅无吊顶，无石膏线，无主灯，采用明装筒灯以及滑轨灯满足照明以及灯光的层次感；蓝色布艺沙发提亮空间，同时木质的电视柜增加温馨感，为了空间开阔，采用轻巧小方几代替传统笨重茶几，彩色的民族地毯温馨装饰。整体比较简单但是又非常温馨
▲无主灯的布局最重要的是考虑到过道和客厅一体，又没有吊顶分区，如果采用主灯，就会存在不居中的问题，所以干脆无主灯布局，不仅解决了主灯无法居中的问题，同时视觉更简洁，更符合现代装修理念
▲这个方向能看清过道其实和客厅融为一体的，所以主灯布局不吊顶的话必然会出现不居中的问题。而且为了扩大门厅，做了吊顶扩充设计，采用吧台分割了门厅和餐厅空间，只能在过道上布局就餐区，满足基本功能
▲这是改造之前的进门过道空间，有个进门的玄关墙
▲为了扩大门厅空间，拆除原来进门的非承重墙，采用吊顶的形式扩大门厅空间，吊顶下方吧台分割区域，这样门厅也能满足冰箱的镶嵌
▲餐厅与过道收纳柜一体定制，吧台增加功能兼顾分区；白色与木色清新明亮
▲大白墙与木质的协调搭配，不仅空间明亮，温馨有度，不过分冷，也不会产生烦躁之感。
▲进门视角，左手定制鞋柜与收纳柜一体，厨房狭小，刚好冰箱移出来镶嵌。扩大门厅以后，地面六边形花砖点缀，刚好与上方吊顶呼应一致；因为右手厨房狭小，干脆只做了门套，不装门，可以让空间更开阔，减少拥堵感
▲原木的餐桌椅，稳重而且温馨，搭配白色单头吊灯，极简时尚
▲未改造之前的主卧，简陋凌乱，而且阳台的移门遮挡光线
▲装修后的主卧，拆除原有的阳台移门，打通空间，简单木质垭口装饰，采用大面积白色与灰色，木色点缀，让空间更通透素雅简洁
▲角落温馨绿植与轻巧吊线灯点缀一室温馨
▲站阳台看主卧，无吊顶，无石膏线，大白墙，定制顶天立体衣柜满足功能收纳；木色贯穿点缀，提升温馨
▲未改造之前的中间小卧室，很小一个窗户，光线昏暗，而且空间非常狭小
▲改造之后，封掉了原来小卧室的门，打掉中间卧室和儿童房的墙体，做了门联窗套间布局，这样引光入室，同时放大空间，里头是儿童房，外头作为休闲多功能室
▲原来狭小的中间卧室，定制榻榻米满足收纳，同时兼顾家里的多功能室。新开窗户下方开放格兼顾床头柜，同时局部斗柜满足收纳
▲儿童房跨度太小，所以床头改变位置，床尾衣柜定制，原来落地窗做了假飘窗收纳兼顾休闲。侧面定制双人位书桌，上方书柜满足书籍收纳
▲儿童房看套间空间，局部墙面薄荷绿的变色，视觉更清新；原来的门洞封堵以后，利用下半部分做了隔板壁龛，可以放一些小的零碎
▲改造之前的厨房空间，本身空间狭小，放上冰箱以后，更加拥挤，收纳严重不足
▲改造之后，厨房去掉了门，空间更开阔，统一素雅浅灰色瓷砖搭配，浅木色橱柜定制，原来冰箱位置采用高柜收纳，吊柜满做镶嵌烟机，满足更多收纳储物
▲卫生间未改造之前，因为是出租，当初连瓷砖都没有贴
▲新装修的卫生间，干区半截墙布局，可以放大视觉空间，干区对面原来的儿童房门封堵以后，上半部分做了隔板壁龛收纳；定制木质浴柜，镜柜满足收纳，干湿分离提升生活品质
▲湿区空间采用仿大理石的造型瓷砖，简单淋浴区布局，角落塑料置物架满足洗漱用品的随手拿取END
