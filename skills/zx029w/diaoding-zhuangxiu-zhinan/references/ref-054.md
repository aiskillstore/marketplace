# 厨房不能用推拉门，那就用子母门5.23

▲在固有的认识里头，厨房当然是推拉门了，几乎百分之六十以上的家庭都是。但是并不是所有户型厨房都能做推拉门，有的户型只有正常门洞，做不了推拉门的。所以今天就看看如果厨房做不了推拉门，做什么样的门好。

『子母门』
厨房用子母门，是空间门洞无法满足移门的开启空间，同时又想让开启空间最大化。同时密封性要高于移门，有效的隔离油烟。

▲白色的木质子母门，子母门的优点是尽可能让空间通透。选择一边局部木质加玻璃固定，另一边开启空间为普通门洞大小。这样视觉上也能拓展空间，同时保证开启空间的最大化。颜色上如果是木质厨房门尽量与室内其他门材质颜色保持一致。

▲玻璃子母门，一般北欧风最常见，也是比较流行的网红门。窄边框架加上透明玻璃，视觉非常高级简洁。局部玻璃固定，保证开启空间的最大化，时尚通透。这种细边框的玻璃门无法装锁，刚好适合放在厨房空间

▲金属黑色的厨房子母门，一般用到现代北欧风里头，往往搭配白色门套，形成强烈反差，让空间有质感

▲当然也可以搭配白色的金属子母门，需要和风格搭配协调

▲子母门玻璃方面需要考虑到，木质没有什么限制。金属窄边框门有的只能做单层玻璃，必须钢化，为了安全考虑。宽边框的金属门是可以做两层玻璃，也可以钢化的，在制作之前一定知悉。也可以用长虹玻璃，如上图所示

▲纯黑色的细边框子母门，现代质感，非常流行，也深受年轻人的喜爱。搭配透明玻璃让空间通透高级。需要注意的是使用的安全性。

▲子母门除过保证开启空间最大以外，还有一个优点，因为其平开门的结构，密封性要高于任何移门的，这也是子母门的第二大优点。

▲典型的简美装修风格。厨房移门太小，所以采用白色的木质子母门，子门和木门都可以同时打开，保证开启空间的最大，也能保证家电更换的正常出入。否则上图如果做成移门，不美观，开启空间小，甚至冰箱都进不来

▲白色木质子母门搭配黑色的分体锁，颜值稳稳

▲颜色上也可以跳色搭配，颜值更高。这个需要设计师有一定的审美

▲这种老气横秋的子母门还是算了，即使你家是别墅也不要用。基本的审美还是要有的，否则同样花钱，有价格没价值
