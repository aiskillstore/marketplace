# 阳台石膏板吊顶，都有那些形式？4.2

北方封闭阳台做法肯定是与室内打通的做法，此时阳台就存在是否做吊顶的问题，如果要做，肯定是石膏板吊顶，各种形式都有，看看哪种更适合自己家。.01局部吊顶
如图只是在洗衣机上方吊柜之上局部做了吊顶，目的是隐藏上方下水弯管，同时压低吊柜高低，让整体视觉更美观，其他不做吊顶局部吊顶+窗帘盒，局部吊顶位置满足隐藏上方的弯管，同时压低定制美观，单独窗帘盒与局部吊顶等高，其他大面积不吊顶，可以提升层高同样是局部吊顶隐藏上方弯管，同时压低定制，加上窗帘盒既可，大面积保留原顶高度，这样只能明装电动晾衣架，无法做隐藏晾衣架只做局部吊顶隐藏弯管以及压低层高，不要窗帘盒，明装电动晾衣架局部吊顶加边吊，保留原顶高度，满足窗帘盒平面吊顶加四周边吊，满足晾衣架的隐藏，同时满足了窗帘轨道的隐形安装边吊加上平面吊顶，通阳台满足不同功能区平面吊顶加边吊双眼皮做法，窗帘盒压低满足窗帘的相通.02平面吊顶+窗帘盒
最常见的做法，全部吊顶，预留窗帘盒，满足安装隐形晾衣架，同时压低定制，视觉上清爽也高级平面吊顶预留窗帘盒，同时隐藏灯带营造氛围感接近平面吊顶，只不过凹陷造型隐藏明装的晾衣架而已常见平面吊顶+窗帘盒的做法，简单清爽.03创意吊顶
采用拱形设计，同时中间平面吊顶隐藏大梁的突兀，灯带满足了无主灯的照明效果局部吊顶+平面吊顶，所不同的是朝向大梁处做了弧形处理，从阳台看可以弱化一下大梁阳台悬浮吊顶，适合面积大的阳台，可以采用灯带营造氛围感大梁与吊顶同时做了高低斜面处理，加入灯带营造高级感氛围错位斜面吊顶，加入灯带营造氛围悬浮平面吊顶，加入灯带营造氛围局部边吊，两边弧形处理，采用天际线灯满足氛围感平面悬浮吊顶，灯带营造氛围感边吊加两边弧度处理，同时原顶面线条勾勒，采用吊灯满足风格需求波浪弧度吊顶，加入灯带营造氛围弧度吊顶处理，同时弱化大梁，天际线灯营造氛围搭配圆弧吊顶➕天际线灯，增加视觉层高同时，漫反射灯源，柔和不刺眼，极具趣味性和设计感弧形斜面吊顶，天际线灯满足氛围平面吊顶预留了一个凹陷区，专门安装侧装晾衣架，遮挡平时的晾衣服内斜面吊顶，满足灯带的隐藏局部弧度吊顶，同时加入灯带以及天际线灯氛围.04只做窗帘盒
卧室阳台没有下水，采用只做窗帘盒的形式，满足美观和遮光，采用明装筒灯照明即可不做任何吊顶，只是单独做了窗帘盒满足后期纱帘的布局即可定制上方局部吊顶隐藏弯管，单独窗帘盒制作，原顶安装电动晾衣架局部吊顶边吊形式，解决有大梁窗帘无法拉通定制的问题不做吊顶只是单独做了两个独立的窗帘盒
