# 客厅与阳台打通，上方有大梁，怎么吊顶？8.17

客厅带阳台，现在的做法大部分都是打通布局，因为是公共区域，压根不存在什么保温不保温，所以只要是封闭阳台，客厅几乎都选择与之打通布局。但是打通以后之间有个大梁露出来，怎么吊顶才能更美观呢？以前谈过一篇卧室与阳台打通有大梁的专题，可以翻阅『卧室和阳台打通，中间大梁怎么办？』今天就说说客厅这种案例。『不是拆除推拉门那种打通，而是彻底墙体拆除』

▲横厅布局，原始客餐厅阳台是分割开来的，打通以后上方大梁外露，不做任何处理，直接裸露，阳台之间的大梁也不做处理。因为大梁下放太大，如果做吊顶处理，显得压抑，干脆直接裸露不做处理，更自然

▲原来的阳台打通与客厅融为一体，但是大梁依旧在，采用分区吊顶的形式，结合窗帘盒的做法，刚好阳台作为一个单独的休闲区布置

▲彻底打通以后，阳台作为书房空间布局，原来大梁比较小，采用整体平面吊顶的形式，刚好作为空间分区

▲彻底打通以后，原来的大梁上方刚好布局挂机空调，采用整体平面吊顶的形式，作为空间区分，阳台作为开放式书房布局

▲客厅阳台打通以后，采用平面吊顶的形式，弱化大梁的存在，不同高低的吊顶刚好区分空间

▲打通空间客厅阳台之间的大梁采用两边同时吊顶的形式，弱化大梁的存在感

▲打通空间大梁依旧在，阳台刚好借用大梁做了天井造型的吊顶，同时阳台两边木质饰面用来营造一个单独休闲空间

▲借着大梁做阳台的天井造型吊顶，同时成就窗帘盒功能

▲打通空间以后，客厅中央空调吊顶以及阳台的平吊，同时弱化中间大梁的压迫感

▲打通以后大梁依旧在，干脆改变形式，把大梁做成拱形造型，刚好符合美式风格的调调

▲原来的大梁与客厅吊顶统一采用木质装饰，让视觉浑然一体，忽视大梁的存在感
▲客厅做中央空调，同时做灯带处理，高低刚好把阳台大梁隐藏，阳台平面吊顶区域视觉划分
▲如果阳台非常小，打通以后平面吊顶隐藏大梁，同时一边高柜收纳弱化大梁的压迫感，下方可以与阳台大小相同定制卡座休闲，刚好划分一个非常美的休闲区，同时弥补沙发功能的不足『客厅有飘窗，连沙发都省了』
▲根据阳台大梁的大小，阳台做平面吊顶处理，同时客厅吊顶与大梁高低平齐，完全隐藏大梁，而且视觉上还很好的做了区域划分
▲客厅平面吊顶弱化大梁，同时阳台整体木质造型，刚好包裹大梁，做了很好的休闲分区
▲打通以后，大梁采用木质装饰，形成一个木质的大梁，同时阳台做木质假梁呼应，就可以成就一个非常田园自然的休闲区域
▲打通以后的大梁采用木质饰面与旁边承重墙一体造型，不仅可以增加温馨元素，同时视觉上作为分区空间
▲借用大梁作为客厅的造型边，同时阳台木质吊顶，收纳柜定制，单椅与圆几的布局，刚好阳台作为休闲区域使用
▲大梁不做处理，一边下方吧台布局，大梁上吊灯功能，实现一个完美的酒吧区，同时弱化大梁的存在感客厅无阳台，怎么装修？
