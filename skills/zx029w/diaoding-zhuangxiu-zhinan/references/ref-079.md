# 客厅不吊顶，并不是缺钱，而是喜好3.12

太多人都会问：装修需要吊顶不？这个在于你装修的做法，不是你想吊就能做，也不是你不想吊顶就能随心所欲的。
例如你做风管机和中央空调或者管式新风，那家里必须吊顶而且很多；例如你没有以上的做法，你又想水电走顶，那你还得吊顶；你做定制害怕太高，太费钱，你也得吊顶；你做定制有个大梁挡住了，你也得吊顶；综上所述，做不做吊顶不是你决定的，是你家装修的方式和做法决定的。
大家一定不要有误区，认为做吊顶肯定费钱，不做肯定省钱，这个是太大的误区了，如果吊顶下方有定制，其实总花费会变低的，因为《多做吊顶，你家定制就省钱了》，所以吊顶不吊顶要根据实际去考虑，不是钱的问题，看你喜好和对审美的要求。有时候真的不需要用花里胡哨的造型挽救品质的廉价，有这份钱用到家具和软装上，什么都不做也是有档次的。
