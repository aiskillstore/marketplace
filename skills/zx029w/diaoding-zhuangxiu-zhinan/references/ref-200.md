# 厨房装空调，一天能有几毛钱？5.25

在夏季，做过饭都知道蒸桑拿是什么滋味。但是装修的时候，一说给厨房装空调，都非常惊讶，而且严重排斥。
第一总认为厨房是油烟重地，不适合这么好的电器，用不了多久就坏掉，都是钱；第二总认为没有必要，最最重要的是定装修的一大部分是男性同志，而进厨房操作的大部分是女性同志，所以对于厨房空调压根无感。
大家可以看看周边装修的朋友，装修到处比价找低价，但是宁愿做个一万左右的岩板电视墙，都不愿意给厨房装个空调。面子做得很足，哪怕关起门自己受罪都行。
当然有人“聪明”的用了凉霸。可惜这个完全就是智商税，厨房夏季温度能到五六十度，名字叫做凉霸，其实和凉没有半毛钱关系，充其量就是让五六十度的空气流动起来而已，没有任何作用，所以装修坚决不要买所谓凉霸。

▲心疼钱的算一笔账，如上图某宝上的小一匹足够使用，平均下来是1000元一台。即使用一年报废，一天是2.7元；如果能用三年一天是0.91元，一天不到1元钱；如果能用五年，一天是0.54元。请问这个真的是成本问题吗？

▲如果你还是感觉心疼钱的话，可以去拼夕夕逛一逛，价格绝对实惠让你满意。
当然如果有人提出来，你这个计算没有算电费，如果纠结小一匹空调的电费的话，还是在厨房蒸桑拿比较好，没有必要了。

所以准备装修的业主，可以先观察一下厨房外头是否有卧室外机位置可以利用，如果有，就可以给厨房加一个很小的空调，不论是家人谁做饭都不会受罪了。
当然如果厨房实在不满足条件，看看餐厅空间，如果餐厅可以满足一个空调位置，直接吹向厨房的话，也是可以解决问题的；夏季做饭烟机打开，空调打开，冷气是可以直接进入厨房的；

▲如果经济条件允许，直接中央空调也可以满足，也可以采用餐厅中央空调吹向厨房的做法。
当然以上只是一个建议，就看大家对厨房夏季做法的忍受程度了，一看理念，二看经济，但其实还是要实用。
