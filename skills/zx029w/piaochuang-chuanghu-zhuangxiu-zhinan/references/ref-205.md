# 130m²+80m²，破旧顶楼复式，改造惊艳美式新家

今天介绍的这套户型是顶楼复式户型，因为是二手房，一层与二层的楼板原来的房东已经做好，格局上没有什么太大的改变，这一点可以节省后期改造的好多费用。全部下来40万左右。

▲这是房子的原始图纸，物业提供的，右边就是本套户型的格局。一楼建面在130平左右，四室两厅两卫一厨房。看起来格局挺好，房子过多的话格局都小，何况客厅挑空的房子，更显拥挤了

▲房子的一二楼布局图设计图纸。客厅是挑空的，这就是买这个房子的最大理由了。同小区其他家好多把客厅加了楼板，利用起来了，但是显得很压抑，顶楼复式要的就是挑空的感觉。

局部改动还是要做的，一楼餐厅太小，最终牺牲了一间卧室，把右下角的卧室扩大，同时扩大了餐厅空间，同时也能满足做心心念念的餐边柜了。次卧的衣帽间砸掉扩大面积。改变右下角卧室的进门位置，成就了客卫的干湿分离。

▲看一下装修后的实景，客厅是挑空高度，最高点在五米以上了。光线是没有一点问题，所以就采用了深色的木地板。进门右手利用楼梯位置做了收纳柜，鞋柜位置下方镂空方便进门放鞋。进门左手以及头顶都做了白色的模压收纳柜。实木实在太贵，所以全房定制都是多层柜体和模压柜门做的

▲这是进门直对能看到的空间，所以刚好在沙发墙白色护墙板的衬托下，美式斗柜装饰，精美装饰品和镜子摆设，全当是进门的玄关背景了

▲进门左手客厅全景，挑空空间，上下玻璃窗采光通透，光线一点问题没有。电视墙整体收纳柜制作，镶嵌电视，同时大面积收纳柜白色与美式家具深浅协调

▲沙发背景是白色护墙板，局部壁纸的做法，也是美式里头最简单的装饰了。

▲电视墙收纳柜是直接延伸至防盗门上头做的。整体比较简单，充其量就是放了美式的家具和灯具而已

▲进门右手就是餐厅空间，这里比较有感觉，木质的楼梯，蓝色吊扇灯，还有九宫格的吊顶，美式的韵味尽显眼底。砸掉一间卧室餐厅比客厅还要宽敞，侧墙整体收纳柜，中间还有镶嵌钢琴的位置。空间绰绰有余

▲站走廊看一下整体，楼梯下面做了充分的利用。所有墙面乳胶漆采用的是奶咖色，比较柔和，和美式风格协调搭配

▲餐厅阳台看全景，主深次浅的家具搭配，美式的家具韵味。耐看的高级感

▲进入卧室的过道，简单回字形跌级吊顶，尽头的挂画网购。过道左手边收纳柜地方就是拆除原来的衣帽间做的，能让过道不那么单调，同时也能满足杂物的收纳

▲一楼主卧非常简单，背景石膏线勾勒，统一咖色乳胶漆变色即可。美式家具搭配，两边暖色壁灯点缀，最常见的美式做法

▲一张广角镜头，其实没有这么大，空间拉大了。稳重舒适

▲这才是实际的大小，一边床头柜，另一边刚好放置美式化妆台，空间紧紧张张，满足使用

▲没有地方做衣柜，只能在牺牲隔壁衣帽间的时候，移动墙体，成就了主卧门后的衣柜以及收纳储物

▲为了拍照刻意摆了一些水果，有烟火气
