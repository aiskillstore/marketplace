# 家里飘窗太高，怎么处理更合适？5.26

几乎每一家都会有一两个飘窗，或休闲或收纳，都可以合理利用，但是有一种飘窗叫做开发商的飘窗，非常高，既不能砸掉做飘窗柜，铺垫子休闲又太高。今天看看这种飘窗该怎么做。一般普通飘窗高度在40-50公分，属于正常高度，高于这个高度一般都属于比较高的飘窗了。

▲如图，你家如果是这种高度的话，只能是开发商设计的缺陷，智商问题了

▲如图，飘窗太高无法使用休闲，可以采用上头做隔板的形式，朝内延伸出一个书桌兼顾吧台空间，合理利用空间
▲如图，高的飘窗不做处理，朝外延伸做台阶式处理，这样就可以降低原来飘窗的高度，同时布置休闲区，视觉更美观
▲如图，飘窗很高，可以采用延伸层板做书桌的形式，同时为了延伸的层板更美观，旁边整体定制同厚度的书柜满足书籍的放置；但是原来很高的飘窗就更高了，为了解决这个问题，可以地面局部做地台的形式，降低飘窗高度，同时还能满足地台的收纳和休闲功能
▲如图，飘窗太高，刚好在靠窗户定制榻榻米，这样飘窗的高度刚好留出来置物空间，同时也可以铺上垫子作为休闲处理，解决太高的尴尬
▲如图楼梯休息平台有个很高的飘窗，太高不用又比较浪费，可以做成休闲布局，做成统一的木质扶手和梯子，平时完全可以作为单独休闲区，也是非常有新意
▲下方加个台阶，来缓解飘窗的高度，同时侧面还可以做收纳储物搁架
▲飘窗太高，床铺靠角落放置，这样高飘窗可以作为右侧置物，可以代替床头柜功能
▲飘窗太高，下方可以做一排木质抽屉，可以满足收纳，同时解决飘窗太高的尴尬
▲稍高的飘窗可以做成稍高的推拉式书桌，拉出来就是一个书桌空间，可以把非常高的飘窗功能最大化

▲可以直接借用高飘窗定制书桌，满足更多功能
