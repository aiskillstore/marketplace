# 客厅带飘窗，是实用还是鸡肋？8.20

好多户型有个飘窗，但是大部分人感觉这个飘窗除了休闲一无是处；除非能砸掉做收纳柜。今天看看客厅飘窗怎么利用。

▲大平层空间，飘窗预留单独空间，可以作为单独休闲空间，平时阅读或者闲坐欣赏窗外风景都是不错的选择；局部打造书柜，可以收纳常看的书籍。空间大，飘窗哪怕是摆设，也不会显得浪费
▲横厅格局再带一个超级大的飘窗，满足采光的同时，飘窗可以弥补大沙发的功能，就可以满足轻巧沙发的布局，不会让空间显得拥挤，而且功能性满足。
▲横厅有超级大飘窗，相当于与生俱来就多了一个休闲地方，可以让家里的沙发布局更加轻巧，利用飘窗的功能弥补更多沙发功能，不至于让沙发填满空间牺牲美感
▲飘窗自带休闲功能，因为太高，采用下方做地台的形式，满足功能性，同时又能增加另外一种休闲功能
▲横厅布局，沙发反传统布局空间更灵活，同时飘窗兼顾了餐厅的卡座功能
▲小空间客厅如果有个飘窗其实最好不过，完全可以弥补沙发的不足，充当会客区的功能性作用
▲飘窗延续沙发的功能，定制垫子延伸沙发长度，让小空间不仅满足功能，同时视觉上更宽敞
▲原有飘窗砸掉，定制了飘窗柜，同时兼顾休闲区功能。视觉上可以拉伸空间，同时满足收纳以及休闲功能
▲客厅原有飘窗砸掉，定制收纳休闲区域，作为沙发的补充，同时作为休闲最佳角落
▲超级飘窗不仅满足采光需求，同时安排成休闲的喝茶区域，实用和颜值都有了
▲阳台定制飘窗卡座，家里连沙发也不用买了；不仅可以放大空间，更新颖，同时空间利用率更高
▲刚需小空间，砸掉原有飘窗定制收纳柜满足收纳，同时弥补沙发空间的不足，不仅满足功能，同时可以让空间更显宽敞
▲原有飘窗保留作为绿植以及装饰品的摆放区，新作飘窗卡座满足收纳的同时，兼顾沙发功能的延伸，同时与隔板电视柜一体链接，视觉空间更有延伸感
▲刚需空间飘窗本身兼顾的就是沙发功能，这样就可以满足轻巧沙发的购买，让空间更显大
▲利用飘窗柜代替沙发功能，让空间更显大，而非把沙发塞满空间
▲舍弃传统的沙发布局，采用卡座飘窗的形式满足基本的功能，空间更宽敞
▲飘窗可以兼顾一部分沙发功能，千万不要买超级大的沙发把客厅当库房使用了
▲小空间飘窗可以代替一部分沙发的功能，这样沙发可以购买小一点的，让空间更开阔
▲原有飘窗砸掉，采用飘窗柜的形式，满足收纳，同时又能充当沙发功能，可以让小空间沙发更轻巧，空间更显大
▲超大飘窗满足休闲以及弥补沙发的不足，可以让空间购买沙发的时候更轻巧，放大空间
▲客厅有飘窗，完全可以兼顾另一种不同形式的沙发
