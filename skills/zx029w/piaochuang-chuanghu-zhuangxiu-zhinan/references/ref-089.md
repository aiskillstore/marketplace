# 电视墙电路改造，细节超过6.29

水电改造是重中之重，需要了解，后台回复“水电”有专题版块，不定期不断更新中。

而在水电改造中，最麻烦最绕不开的就是电视墙的线路改造，毕竟大部分家庭还没有真的到了不要电视的地步。所以今天重点看看。

『电视墙要不要网线』当然需要，否则你用什么看电视？有的家庭直接用电视的内置WIFI看网络电视，完全可以，不同的是有时候因为网络问题容易卡顿，特别是晚上高峰期。

在西安地区，你家如果是单独电信宽带是没有问题的，如果是电信宽带买一送一的宽带，是百分之百不能用内置WIFI看电视的。同理还有其他很便宜的宽带也是不行的。

所以如果想要安心看电视，大家几乎都会把网线拉到电视墙位置。一般新房毛坯交付，开发商在电视墙位置都有做好的网线，这样你家就无需改动，后期路由器光猫放电视柜，完全可以满足全房的网络需求。

所不同的是你路由和光猫的放置地方选择，一个是进门的弱电箱一个是电视柜，这个做法不同，线路布置是完全迥异的。

1.路由器和光猫放弱电箱。前提是弱电箱够大，能同时容纳路由器和光猫，这样一根网线从弱电箱到电视墙即可。同时弱电箱能有电源口。

2.弱电箱只放光猫，路由器放电视柜。如果弱电箱仅能容纳光猫和电源的话，光猫放弱电箱也是可以的，这样光猫可以直接转换光纤和网线了，电视柜只放路由器就行。

网线的走法有很多问题，大家可以后台回复“网线”看看所有以前说过的专题。

▲上图的电视墙为什么不露出任何线路，这么干净？其实这个很简单，电视墙是后做的，做的时候已经把所有线路线管预埋进去了，这样后期只需要简单穿线就行。下方刚好留有壁龛，可以收纳路由器光猫等设备，里头备用有插座电源即可

▲一般电视墙只要预埋一根50或者40管就可以隐藏所有的线路了，下方插座要不电视柜遮挡，要不后期装饰遮挡都是可以的，这样看起来都很美观。但是前提是你家电视墙是非承重墙才行，否则无法开槽这么深预埋管路的。

如果电视墙是混凝土承重墙的话，可以这样做，把电视的电源放到电视后面遮挡，剩下能露出来的线路就是一根IPTV的信号线，可以在墙面开浅槽埋一根20或者16的线管即可，这样不伤及承重钢筋，后期信号线可以穿进去，这样就可以彻底隐藏了

▲如果电视墙是承重墙还可以这样做，直接做收纳造型的话，线路都可以隐藏在柜子里头，就不存在承重墙无法预埋管路的问题了

▲其他插座想要遮挡起来美观，这个和你家电视柜有关，要不提前看好电视柜，根据电视柜造型做电路，要不常规做电路，后期根据插座高低购买合适的电视柜都是可以的。如上图插座刚好在镂空的置物空间，美观多了

▲类似于上图的错误其实和电路无关，购买电视柜随心所欲导致的，既然插座是先做的，你就得根据插座高低购买电视柜，否则就会出现上图的尴尬

▲万一电视柜买错，导致插座外露你嫌难看，也是可以后期用相框摆放来遮挡，各种装饰品放上不仅好看，而且遮挡了插座
