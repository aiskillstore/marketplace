# 哑口套和窗套，好多年前的事情了2.17

如果大家都不思考做哑口套和窗套，谁最高兴？

答：装修公司和建材商。
属于老生常谈的话题，今天重提，结合实例，大家自己抉择，最大限度说服大家：不要中了建材商的圈套。当然昧良心的话，我们自己做装修，巴不得业主都做窗套、哑口套，利润更高，但是实话总得有人去说，听不听那就是大家的事情了。
装修再也不是做个电视墙就是有钱人，包个窗套哑口套就显得有面子，否则别人看了以为自己是穷装。如果是这种认知层次的话，对装修的认知太肤浅了。
装修不仅仅是要满足室内功能，同时必须考虑每一步的施工结果价值，而不是仅仅就是施工搭一个窝那么简单。能清楚认知到装修更高层次的人，并不是为了省钱而不做窗套或者哑口套，而是人家有钱，知道什么才是价值，什么才是品味，绝对不是仓促促成一个能住人的窝，视线之内全是面子和廉价品的堆积。
有钱能花到刀刃反而成就品味，没钱全部做了无用功，不仅失去品味，而且还给自己的经济雪上加霜。就好比有钱并不是非得脖子上带个金链子一样，如果你不带显得自己穷酸，并不是，有品位的有钱人也不会穿金戴银显得俗气又难看。
▲如图依次是，木质窗套、石材窗套以及金属窗套。虽然材质不同，但是装饰的效果是一样的。防止雨水进家的作用，木质窗套完败，不会有防水功能，但是石材和金属窗套倒是可以防水，但是视觉非常冰冷。不论用什么材质做窗套，缺点是显而易见的：更费钱；视觉更复杂；让本身很小的空间显得更小；
▲哑口套也是同样道理，同样有三个材质，和窗套类似，哑口套唯一可取的地方是，某个区域有瓷砖，需要收口，此时哑口套的作用才是真的发挥了作用，否则和窗套一样，缺点同样是：更费钱；视觉更复杂；让本身很小的空间显得更小；▲家里卧室都是木门，这个门套是自带的，不会单独计费算钱，而且是必须有的，否则门扇没法安装。▲如上左图厨房玻璃移门，才是正确做法，瓷砖贴出门洞，利用移门自带的单套线瓷砖收口，省去了单独木门套的费用，而且更简单；但是右图做法就是多此一举的做法，不仅多了一个单独木质门套，而且视觉上不伦不类，颜色的对比让空间更显得凌乱。▲如上图左一才是正确做法，卫生间瓷砖贴出门洞，利用金属门的自带套线即可满足瓷砖收口；中间很明显是多此一举，做了木套安装金属门，这样做法不仅费钱不好看，而且时间久了木套必然腐烂；最右边是整体金属双包套，等于是门洞没有贴瓷砖，采用金属门的材质做了双包套，还是又费钱又多此一举的做法。▲至于好多人害怕不包窗套，新装窗户与墙体缝隙都是发泡胶无法后期批腻子问题，其实很好解决▲如图用石膏板直接找平即可，满足窗户与石膏板严丝合缝，后期直接批腻子处理即可，至于防止磕碰窗套也大可不必▲因为在家里批腻子的时候，所有阴阳角都有专门的PVC条子预埋，一是为了找平垂直，第二满足后期不会磕碰，与其繁琐多花钱做窗套哑口套，不如买点质量好的阴阳角条，你找装修机构的话，这个是免费包含的▲注意上图阳角位置批腻子的时候，都预埋有阳角条的，防止磕碰和保证垂直都有了▲如果是金属门只是为了分割空间，两边空间都没有贴瓷砖，任何门套都不需要，直接装门即可。▲至于入户门套要不要和格局设计以及鞋柜位置有关，并不是必须做《入户门套需要不？什么时候可以不做？》以上就是关于不推荐做窗套、哑口套的理论，下面看一下人家不做窗套、哑口套的效果实例：第一、不要窗套▲如果说包窗套是为了防止磕碰，如上图客厅带两个落地窗，如果包窗套能难看死，而且中间柱子和大梁不平齐，窗套都没法做，所以干干净净，省钱简洁更显得高级▲如图客厅两个类似落地窗，如果包窗套，客厅视觉就多了两个框架，厚重而且显得空间更小。采用乳胶漆直接做，下方压上极简石材，高级好看实用《窗台石都极简了，你还在做耳朵？》▲飘窗也是一样的，不做窗套卧室更干净，视觉空间更简洁。不铺垫子直接极简石材铺上即可，如果后期做垫子直接瓷砖都可以铺▲飘窗如果后期要铺垫子，都可以直接用瓷砖铺贴即可，后期盖住了谁也看不到，而没有必要用石材，当然土豪除外。▲如图飘窗比较低，延伸做了一个书桌，连飘窗石材也省掉了，不要窗套视觉更简洁干净。这个并不是有钱没钱的问题，而是品味和对装修审美的层次不同。如果你装修的时候感觉不包窗套就是穷装，那对于装修的理解仅仅是个窝，这种认知不在一个层次了。▲如图卧室全部无主灯，飘窗做了弧形造型。不做窗套是为了省钱吗？当然不是，是为了不至于缩小空间和造成视觉复杂的难看而已。▲如图平窗也是一个道理，做了中央空调难道业主没钱做窗套？并不是，而是钱花到刀刃，提升品味放大空间，让装修的价值最大化第二，不要哑口套
▲如图卧室带个超大的落地窗，难道给落地窗做个哑口套？不用想都知道一个木质的框架包起来直接毁掉整个卧室的美感，而且还缩小了空间▲如图200平大平层横厅空间，阳台打通，有个超大的垭口，你包个哑口套试试，不仅丑，甚至毁掉了大平层的空间。如此装修人家并不缺钱，人家知道把钱花到哪里，知道怎么做才能有价值和品位▲如图不做哑口套做了一边弧度造型，而且生活阳台照样乳胶漆涂刷和内部保证统一，如果包套不仅难看，而且失去品味，和有钱没钱的面子压根没有任何关系▲如图客厅与生活阳台打通布局，而且阳台不用难看的贴墙砖，同样哑口套也不做，客厅不要窗帘直接阳台纱帘，空间更大视觉更简洁。这才是品味和装修的价值，和有钱没钱无关，和自己对装修的价值和审美层次有关。▲如果对装修价值和审美层次达不到的话，基本就是上图的做法，虽然地面通铺了，用的却是亮光瓷砖，而且阳台墙面竟然也是大花纹亮光瓷砖，还做了哑口套，而且客厅与阳台之间还做了窗帘盒，阳台吊顶还做了铝扣板吊顶，钱并没有少花，但是装修的价值和品位完全不是一个层次▲看看人家为什么不要哑口套，为什么客厅不要窗帘，为什么阳台不贴墙砖，为什么阳台不做铝扣板吊顶，人家的家具档次并不是没有钱，而是知道钱花到什么地方，才是真正的有面子和内子而已。装修的价值最大化和品位结合才是装修的目的，而非廉价品的堆积。
