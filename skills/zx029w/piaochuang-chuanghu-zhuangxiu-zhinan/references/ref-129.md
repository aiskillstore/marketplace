# 95㎡两室旧房改造，年轻人极简新家

年轻人的装修一般都会随心所欲，有时候跟风潮流，有时候另类自我，因为有资本。

▲没有拆除之前的样子
▲纯南两室，进门口有个储藏室，也可以叫做三室空间；两人生活，也没有什么太大需求，只是喜欢更简单的生活，让家里显得更干净，文艺一点叫做断舍离。大格局没有太大缺点，但是细节处过于零碎，如进门口的储藏间比较鸡肋，没有窗户而且很小；厨房细长，总感觉空间不通畅

▲敲掉进门储藏室，作为开放式衣帽间和西厨共用；同时采用左手鞋柜隐藏砸不掉的承重墙体，同时实现鞋柜的超级收纳；餐厅中规中矩，餐桌以及餐边柜定制；厨房直接与生活阳台打通，同时砸掉客厅与生活阳台的入门，让厨房有了四周迂回的动线，通风也好了，也不会有逼仄感；次卧墙体内移，移动了主卧门洞，实现床尾的收纳
▲客餐厅全景，纯南空间，光线非常充足；餐边柜定制同时入门四周也做了木板延伸，这样视觉更完整，同时弱化一下入门的突兀；进门左手满足超级鞋柜的布局，刚好隐藏了少量的承重墙；鞋柜后面就是砸掉的开放式衣帽间和西厨共用的收纳
▲鞋柜不仅满足了换鞋凳，同时高柜满足进门的衣物收纳；电视墙极简干净，满足实用性，视觉没有累赘；鞋柜背后就是厨房直对的储藏间，砸掉以后更开阔，光线更好，同时满足了衣帽间和西厨的功能
▲公共区域极简干净，两人使用绰绰有余
▲储藏室成就了衣帽间以及西厨共用，镜面玻璃门反射视觉更开阔，同时满足了全身镜的功能
▲客厅一直到阳台打通布局，沙发和电视柜是仅有的摆设，非常的克制极简
▲黑色的皮质沙发，极简壁灯点缀，冷淡但是又有高级感，这就是年轻人想要的生活
▲定制暖气片尽量让其接近电视墙的颜色，视觉上尽量不显得突兀
▲无主灯布局，采用局部磁吸灯以及灯带满足照明需求，视觉上更能极简干净
▲灰色的岩板餐桌极简干练，餐边柜木色与水泥灰套色，同时与岩板呼应，黑色复古吊灯与摆设呼应，非常极简高级
▲进入卧室的过道空间，直对是次卧，主卧与卫生间相对，为了耐用卫生间采用了金属门搭配
▲主卧采用无床头设计，背景护墙板与飘窗一体延伸，视觉更有延伸感
▲床尾空间定制延伸收纳，同时满足书桌兼顾化妆台的功能
▲次卧榻榻米定制拓展更多功能
▲厨房空间与生活阳台打通布局，玻璃门分割避免油烟的蔓延；光线更通透明亮
▲卫生间不大，墙排满足移位以后，进门后浴柜定制，利用角落局部砌墙，实现单独的淋浴区
