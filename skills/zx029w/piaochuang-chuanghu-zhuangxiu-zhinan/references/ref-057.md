# 家里到底做不做淋浴房？安全不？11.20

先回答一下标题问题，做不做看入住人口和实际的格局决定，并不是随心所欲。

家里只有一个卫生间，而且是两位年轻人居住，以后会有小孩，做了淋浴房或者淋浴隔断，卫生间连浴盆的空间都没有，此时压根做不了淋浴隔断和淋浴房。

满足以上条件以后，才可以有做不做的选择，此时做与不做是安全考虑了。

做是因为打理方便，每次淋浴不会出现整个卫生间都是水；不做是因为担心不安全，毕竟所有淋浴房玻璃再好都有自爆几率，运气不好得不偿失。

至于有人说淋浴房或者隔断是为了保温，可能真的是南方人吧，北方家家必备暖风机，保温和淋浴房没有多大关系。

▲首选钢化玻璃 要有3C认证，这个一般玻璃上可以查看到，不是贴纸，是直接印在玻璃上头的，这是安全的第一步。

▲只是钢化玻璃并不能保证安全，而且钢化玻璃并不是不会碎，没有百分百不会自爆的钢化玻璃，所以防患于未然，让淋浴房或者隔断用得更放心。
▲钢化玻璃为了防止自爆，提高其安全性，必须贴上防爆膜，单层或者双面都可以贴；即使自爆也不会碎片乱飞，避免自爆带来的伤害。
▲玻璃大部分家庭用的是透明玻璃，好打理，空间看起来也通透；当然也可以用其他各种有色玻璃和艺术玻璃，这个看个人需求决定
▲淋浴房的门除过移门可以做外开门，坚决不敢做内开门，一旦发生意外，从外面无法推开。
▲淋浴房内部防滑措施必不可少，但是不推荐网红的做法，各种石材或者瓷砖拉槽做法，不好打理，而且天然石材本身容易渗透污渍，最实惠的做法就是网淘好打理的防滑垫，加上防滑的拖鞋，就可以低成本满足功能；而且时间久了，防滑垫可以随便更换，满足颜色和款式的不同需求
▲淋浴房的基石没有必要用各种石材，没有承重作用，所以采用普通的树脂或者PVC都是可以满足的，各种花色都有，需要注意的是不同淋浴房，基石的做法不一样，可以参考这篇《卫生间装修，就不该犯这些错误》，该预埋要提前预埋，这些具体细节操作，最好找一家施工靠谱的，你都不用操心。
淋浴房的价格，这个一分价钱一分货，一平方四五百还是算了，自己命要紧；普通的一平都在一千左右，高端的一平几千都有，这个看自己财力决定。
