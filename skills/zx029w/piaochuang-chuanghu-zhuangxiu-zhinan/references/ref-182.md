# 家里窗户石材，两边必须有耳朵吗？7.15

家里窗户为什么要做石材？一般除过空间有瓷砖的地方不需要窗台石，因为瓷砖直接就铺好了，其他做乳胶漆的地方，有窗台需要铺设石材或者瓷砖，因为不铺贴后期一旦脏了太难打理。

▲上图是窗台收边常见的两种做法，一个是圆弧边一个是直边，这个没有什么影响，还有更复杂的造型，看自己喜好选择就行。
▲重点看上图画圈地方，这就是窗台石材的耳朵。这个到底要不要做？是有讲究的。
▲如果窗户有窗套的话，窗套下方必须收口，石材是必须做耳朵的，如上图所示
▲如图飘窗做了石材，但是没有飘窗套，石材照样做了两边耳朵。其实这里的耳朵也可以不做，视觉也不会那么突兀，或者家有小孩也不会磕碰到
▲如图同样飘窗石材，没有做两边的耳朵，也无需飘窗套，一是视觉不会突兀，家里有小孩也不会担心这个地方磕碰
▲当然不做石材，全部采用木质做套也是可以的，直接休闲使用，比下方石材要温润很多了，不过造价相对要高很多了家里非常低的飘窗，怎么做更好看
