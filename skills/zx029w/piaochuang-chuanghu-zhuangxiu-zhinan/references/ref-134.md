# 空调外机闲置？6种改造让空间价值翻倍，太实用了！

实际装修中，因为做了中央空调的缘故，或者因为其他原因，有闲置的空调外机位置，对于寸土寸金的房子来说，不利用实在浪费！今天盘点一下空调外机的利用做法，这些妙用会让你眼前一亮！第一、晾衣服鞋子。
网友@兔兔emo啦：原本鸡肋的平台被我改成了超级实用的晾衣区！ 顶上可以晒衣服，下面可以晒鞋子养花，铁丝网上也能晒一些小件衣服！ 分分钟薅出1平米的空间，真的太香了！
把原有的空调外机纳入室内，外头百叶不让动，不能改变原有外观，内部采用与封窗材质一样的断桥铝封闭，采用伸缩杆，刚好满足了侧面晾衣区，平时在客厅还能视觉美观，不会看到乱糟糟的衣服。只要窗户能满足人出去，都可以实现的。唯一需要考虑外观美观程度，如果是靠向商业马路的话，可能是不允许的。如果是小区内部，外部采用隐形防护网，下方定制打孔钢板铺上，这里就可以用来晾衣服，完美实现了空调外机位的价值。从外部看是这样的，下方一半满足外机放置，上方利用起来满足晾衣服鞋子非常实用。也可以下方不做不锈钢洞洞板，直接外部隐形防护网，上头衣架，满足晾衣服就可以。如果做了下方板子，会有更多功能，平时可以晾晒鞋子，也可以晾晒干货。下方一半放外机，上方纳入室内，封闭窗户以后，安装固定晾衣架，就可以满足一个侧面晾衣的需求。卧室窗台外头下方放外机，上方就可以利用起来，不锈钢洞洞板搭上，是可以翻盖打开的，也不影响空调外机维修；防护网做上，还做了一个升降晾衣架，朝南空间满足了一个晾衣服的功能。网友@大大的小易：改造前：不美观/空间浪费；改造后：美观/晒衣服 鞋子袜子/ 晒萝卜干、晒辣椒网友@阿闻闻：开发商原计划放空调机位的地方没有放空调外机了，这个地方就被利用起来做了晾晒区。 窗户外开装口袋锁纱窗， 窗台与栏杆处安装不锈钢洞洞板，洞洞板定制可掀开，下方空间还可储物。 顶部安装晾衣杆可晒衣服，洞洞板可晒鞋子。第二、宠物窝。网友@mia：原有空调外机下方放外机，一半空间被浪费掉了，干脆采用不锈钢洞洞板分割起来，外立面铝合金防护网，然后靠房子内部推拉窗封闭，把这里打造成了猫咪的窝，而且通风良好，猫咪非常喜欢呆。原有外机不用了，利用起来，上方作为猫咪活动区，定制猫爬架，下方封闭柜门留出猫洞，作为猫窝使用，让原有浪费的外机空间更有价值。网友@嬛嬛：不锈钢架做的最好的能站人能蹦能跳、因为下面是放的空调外机、方便以后检修做的不锈钢架是活动的，可以掀起来、本来外面已经有那种隐形的防盗网了、为了安全自己又买了钢丝加固了一层更放心了！五只猫四只捡回来的流浪猫！利用空调外机空间，做了拱形门洞，实现了一个狗窝功能做了中央空调以后，腾出一个外机空间，内部窗户封闭，贴了瓷砖好打理，刚好作为狗狗的窝。第三、做收纳定制家里做中央空调以后，这边外机就浪费了，干脆彻底砸掉，朝外的百叶不动，保持外观的统一；内部采用红砖封闭，后期直接定制收纳柜，满足一部分收纳，同时利用原有空调的下水满足一个扫地机器人的放置。空调外机位置比较小，百叶采用亚克力密封住，然后装上了铁艺的支架，这里可以满足一个储藏室的功能，满足一部分家里杂物的收纳。做了中央空调以后，主卧外机空调位就用不上了，直接砸掉满足一个收纳柜的储物，平时专门用来收纳包包。腾出来的外机位置，放上铁艺的架子，满足家里一个储藏间功能，平时可以放一些不常用的杂物，因为朝外封了窗户，也不怕雨水进来了第四、满足洗烘机功能。空出来的空调外机，下方红砖砌墙，上方装了一个固定玻璃窗满足采光，下方刚好满足洗烘机并排布局，还实现了一个台上盆的洗衣池。原来的外机比较大，空间浪费，采用砌墙分割，保留外机位置，同时一半用来满足收纳柜和洗衣机布局；外机下方还实现了一组收纳柜，外机功能保留。原有外机位置很大比较浪费，砸掉以后，上方满足外机放置，下方实现了洗衣池的定制，合理发挥空间价值。原有空调外机比较大，分割出来，上方满足外机布局，下方满足了洗烘机的功能，同时为了上方玻璃窗美观，采用蜂巢帘遮挡，整体要好看多了空调外机位置比较大浪费空间，上下分割，上方满足了外机的放置，下放满足洗衣机布局，为了视觉美观，玻璃窗封闭以后，外面做了同色柜门，看上去像一组收纳柜。中央空调空出来这个机位，砸掉墙体，外头百叶不让动，采用红砖封闭，整体定制收纳柜，同时满足了洗烘机的叠放和一部分储物功能。利用外机位置，上方放外机，下放预留位置，刚好满足了洗衣机的镶嵌，实现功能的最大化。第五、外机位拆除纳入室内原有外机位拆除，空间纳入室内，重新封窗，做了百叶帘，窗下做了一个景观台，刚好满足绿植的装饰拆除外机以后拓展室内空间，保留一部分窗洞用来满足采光和视觉通透，绿植装饰；定制一组书柜，满足读书角的功能。《阳台休闲，完美的读书角》也可以直接纳入室内，作为一个绿植景观设计，满足空间的装饰功能，同时拓展空间。原有空调位一家一半，下方隔壁使用，上方我们使用，做了中央空调以后，这个机位就浪费，做了一个树屋游戏空间，孩子非常喜欢。卧室空调外机位置腾出来以后，定制了一个化妆台功能空间。外机腾出来以后，封闭窗户做了百叶帘，同时实现了一个书架和书桌功能，家里的办公空间有了第六、无法利用的空间，检修口装饰如图如果外机空间无法利用，还得放外机，此时难看的检修口露外头不好看，可以通过洞洞板保留检修口的形式，作为功能装饰，同时保留了检修需求。《别让空调检修口毁了阳台！这些隐形设计让阳台颜值飙升》
