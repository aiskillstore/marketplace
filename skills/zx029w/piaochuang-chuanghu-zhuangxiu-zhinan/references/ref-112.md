# 不做吊顶，也能做美式，而且满足大量收纳

美式风格，也就是我们常说的简美。一般可能认为非常复杂，其实不然，装修风格其实和基础关系不大，和后期家具配饰有很大关系。本套美式在基础上没有吊顶，非常简单，只是地面做了仿古砖而已。后期家具和软配做好了，照样是美美的美式家。

▲入户门厅，简单吊顶，美式吊灯搭配，右手通顶超大鞋柜，下方镂空，鞋柜收纳是足够了。地面仿古砖菱形通铺，这也是美式最经典的做法了。左手全身镜布置满足功能。

▲反过来看一下门厅，进门左手就是厨房，为了让门厅采光更好，同时让空间更加通透，厨房砸掉原来的墙体，做了两扇玻璃移门，平时做饭的时候关上，平时可以打开，空间通透，而且门厅光线也好了

▲门厅进来的餐厅，为了过道更通畅，采用卡座节省地方，过道上做了西厨收纳柜，且镶嵌冰箱，同时也可以兼顾餐边柜的功能

▲看一下进门右手的超级收纳，鞋柜与餐边柜以及电视柜一体定制。西厨区因为要镶嵌冰箱，所以做了镂空隔断分割，电视墙旁边还增加了一个小书房空间，平时可以在这里读书学习，上方局部书架收纳。功能非常强大

▲电视墙挤出来的书房区域，与西厨隔断门分割，同时还能起到玄关遮挡作用

▲客厅全景，没有任何吊顶，石膏线都没有。美式的布艺沙发选了大红色的，这个比较大胆，最后实在没有办法呼应，做窗帘的时候加了红色的帘头呼应，否则感觉有点突兀了

▲沙发墙不大，两边对称边几以及中式的青花瓷台灯装饰，哪怕平时不用，也挺养眼

▲客厅看全景，没有任何吊顶，只靠后期家具和软配来支撑。摆上家具以后能显得空间很大，这应该才是最最实用的装修了。把钱花到了刀刃上

▲主卧也是一样，不吊顶，不要石膏线，蓝色做旧美式床摆放，钱花到了该花的地方。照样可以高大上

▲侧墙通顶衣柜收纳，靠近飘窗的凹陷区同样做了收纳柜。复古的壁灯与吊线灯灵活点缀，非常舒适

▲复古温馨的角落，床品搭配得恰到好处

▲床尾的衣柜角落做了一个黑色的悬空书桌，平时可以兼顾化妆台的功能，黑白对比其实还是很有质感

▲儿童房相对小一点，上下铺设计，床尾是衣柜收纳。利用飘窗做了L型书桌连体，这样利用率超高。过道放置电子琴，小凳子平时刚好放下面不占地方。上方墙面吊柜书架，收纳功能也是非常齐全

▲飘窗改成的转角书桌，收纳更多，活泼的格子窗帘搭配，精致摆设非常温馨

▲客厅的生活阳台，地面复古的瓷砖，侧墙做旧的收纳柜，镂空区域用来养花。平时的休闲地方

▲半开放式的厨房，洗衣机没有地方只能放厨房。一面墙蓝色的格子瓷砖非常亮眼。地面是仿古砖通铺进来，打开门可以拓展空间

▲反过来看一下厨房，因为跨度很窄，所以另一边做了窄的收纳柜，镂空区域平时可以放置小家电

▲卫生间三色瓷砖，蓝色的地面瓷砖，一面墙花砖点缀，在光线非常好的情况下其实很有颜值

▲门口非常小的定制浴柜，因为做了淋浴隔断，所以大胆用了木门，还是比金属门的颜值高。
