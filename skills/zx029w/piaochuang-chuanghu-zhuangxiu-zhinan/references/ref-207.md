# 125三室混搭，飘窗当沙发，家更宽敞

▲建面125平三室空间，原始户型缺点很明显：1.无玄关，进门就是客餐厅，一览无余总感觉不舒服，而且直接对着卫生间。2.客餐厅整体拉通，沙发和电视墙很难布置

▲设计后的布局图纸，进门过道做了衣帽间成就进门玄关，同时也成就了电视墙空间。厨房与洗衣间打通设计，并开放式设计，让空间整体通透

▲进门直对做了衣帽间刚好成就单独的门厅，单独花砖铺贴。直对放置白色成品鞋柜。右手全身镜功能。还有简易鞋架，专门放置进门的鞋子

▲角落做了储物卡座兼换鞋凳，墙上的洞洞板收纳非常强大，而且有颜值

同样卡座上方的莫比挂钩也推荐给大家，好看有颜值，还有功能

▲这是门厅进来以后的客厅，左手厨房与洗衣间打通，做了开放式设计，空间整体更加开阔。做了衣帽间以后，客厅跨度3.5米足够使用了

▲浅色木纹砖非常温馨，搭配原木家具。客厅空间彩色地毯，懒人沙发加上休闲飘窗，显得空间更大。一面墙整体采用灰色的黑板墙，可以随意涂鸦，更有童趣
