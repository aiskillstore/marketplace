# 没钱装修，你给超大飘窗包个套？8.22

关于窗套问题，很早的时候已经说过了，这真的没有必要去做，而且现在装修几乎都是基础极简，把钱用到后期，这样才能提高档次和品质，同时也能把钱真正用到刀刃上。

按照目前市场上的计算方式，一般窗套、哑口套，宽度30公分以内是一米一个价格，如果超出30公分，价格很有可能翻倍，而大部分能称为飘窗的都是超过这个宽度的，算下来一个飘窗套甚至比一樘木门都贵。这就是你们外面买门的时候只问木门，后来发现总价很高的原因。『别只问一樘门多钱，套比门贵多了』

▲即使异形飘窗，除过必要的石材以及设计花点钱以外，飘窗套不做，保证视觉干净简洁。窗帘只在飘窗布局，同样视觉上放大卧室空间
▲极简干净，省下钱可以用到真皮床头和有设计感的定制上，而不是钱花到飘窗套，买个低档的床，然后找个毫无设计感的全屋定制，本末倒置而已
▲这么大的飘窗你如果包窗套，价格百分百高于一樘木门了。钱省下来给飘窗上头加两个明装筒灯比包个窗套更实惠
▲如果有个超大的拐角飘窗，千万不要包窗套了，异形价格更高，钱省下来做个窗帘盒，遮挡一下窗帘才是实惠做法
▲不要无用的石膏线，不要无用的吊顶，不要无用多此一举的飘窗套，省下来的钱，买一张舒适的床，买非常有品位的灯具以及小边几
▲窗套钱节省下来，定制一个可以收纳的抽屉，比无用的窗套实惠多了，而且视觉上房间更干净清爽
▲平窗也是一个道理，最多做一个石材台面后期利于打扫卫生，窗套就省了，做个窗帘盒实惠多了
▲哑口套也是一样的，如果一个空间和阳台打通，而且两边都是乳胶漆，就不要做哑口套了，完全浪费钱，而且视觉上空间更小。
像这种例子太多了，从做不做哑口套也能看出一个装修机构的好坏，使劲让你花没用的钱，然后只替自己赚钱着想，你还以为人家为你好？装修真的需要思考着去做。没有吊顶没有石膏线，全部柔光瓷砖，务实省钱
