# 飘窗能砸不能砸都可以改造，超全4.14

一般飘窗分为三种：一种就是开发商本身有飘窗，而且无法改动的。一种是开发商本身的飘窗可以砸掉，第三种就是落地窗可以做成飘窗。

不论哪一种形式，装修的时候飘窗都值得好好利用。

第一种：可拆除飘窗和落地窗的改造

▲落地窗或者砸掉的飘窗，直接做假飘窗储物，侧墙做了壁橱隔板收纳，小小的窗户物尽其用，同时整体也变得美观。

▲假飘窗储物，侧墙收纳壁橱，布艺垫子装饰兼功能，温馨一角

▲整体做收纳柜，假飘窗储物，同时做了拱形造型，储物的同时更加美观

▲落地窗直接假飘窗储物，布艺垫子功能兼装饰

▲儿童房可以这样做，利用平窗位置两边收纳吊柜，假飘窗和书桌连体，功能更多

▲落地窗比较大，整体假飘窗收纳，侧墙壁橱设置

▲假飘窗与书桌的连体制作，整体美观，空间合理利用

▲假飘窗储物柜，两边假柜门装饰，让整体更协调

▲卧室分割一个小阳台，做了假飘窗储物，同时可以作为儿童活动区域，前提是卧室比较大

▲落地窗假飘窗储物设置，收纳兼装饰

▲平窗下面整体假飘窗储物，两边高柜收纳，功能和装饰兼顾

▲儿童房平窗做假飘窗储物，侧墙收纳书柜与书桌连体，上方书柜设置，收纳做到极致

▲卧室平窗下面整体假飘窗储物，角落高柜连体收纳

▲平窗下方假飘窗储物，旁边书桌书架连体设置，功能和装饰兼顾

▲假飘窗储物，高低错落，抽屉收纳

▲卧室阳台单独书房设置，假飘窗储物，同时侧墙隔板书桌吊柜收纳

第二种：不能拆除飘窗改造

▲原有飘窗布艺垫子设置，侧面空间通顶高柜收纳，增加储物空间

▲原有飘窗石材装饰，侧墙高柜收纳

▲原有飘窗石材装饰，两边收纳壁橱设置

▲儿童房飘窗布艺垫子装饰，侧面收纳壁龛设置

▲原有飘窗上头做了一排收纳抽屉，侧墙吊柜收纳

▲原有飘窗上头做一排收纳抽屉储物

▲原有飘窗布艺垫子配置，侧墙收纳壁龛储物

▲原有飘窗上头做了一排收纳抽屉，功能兼顾装饰

▲原有飘窗上头一排抽屉收纳

▲飘窗侧面收纳柜储物

▲飘窗上头一排抽屉收纳，并不影响飘窗的原有功能

▲飘窗侧墙壁橱收纳与书桌连体设置，比床头柜功能更强大

▲飘窗侧墙收纳隔板壁橱储物
