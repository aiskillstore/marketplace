# 卧室有拐角飘窗，这样设计美哒哒！

1、实用式：对于小空间而言，利用转角飘窗设计成办公学习区，一般长的那边可以做成书桌连接书柜组合，大大提高空间利用率;2、休闲式：在飘窗台上加个一小茶几，搭配软垫，就可以形成一个阅读休闲区;3、小柜体实用式：利用飘窗转角的位置，设计一个小柜体，既能令空间整体协调又独具特色，同时还能增加储物收纳功能，一举多得。

　　飘窗的一边和卧室的主墙处于同一面上，开放性的柜体设计搭配出一个兼具储物和展示功能的书柜、梳妆台组合。不仅填补了墙体，而且令空间整体协调又错落有致。

　　本案利用转角飘窗位置设计成办公学习区，利用矮柜搭配台面板，使柜体到地面的距离正好是常用书桌的高度，搭配高书柜形成整体连贯的设计。窗户的自然采光被充分利用，真正实现了小空间大利用。

　　飘窗的短边用高书柜填补让主背景墙显得整体协调大方，长边处利用三列矮柜增加了飘窗台的深度。飘窗铺上软垫成为休闲区，能供玩耍、阅读或休息。休闲区连接着书桌和床头柜，柜体错落有致，空间也更加灵动。

　　本案属于小型转角飘窗，利用矮柜增加飘窗深度，成为可以盘坐的休闲区，增加开放性矮柜充当书台使用。
