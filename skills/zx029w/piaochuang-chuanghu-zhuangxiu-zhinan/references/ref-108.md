# 窗台石都极简了，你还在做耳朵？1.3

▲上图是普通做法，也是过去一成不变的做法，下挂很多，而且两边耳朵出头，这种做法是为了配合过去的窗套收口用的，而非必须，如果不要窗套，就多此一举了。
▲如图所示，只有需要窗套的时候，这个耳朵的存在才有意义，否则石材出头难看不说，而且还容易磕碰到人。所以舍弃窗套，石材极简做法，才是兼顾实用和美观的最佳方案。▲石材的安装时间一定要在油漆工进场施工一个阶段以后才做，这种毛坯房坑洼不平就直接安装，就会导致石材不平，而且缝隙完全不均匀▲油漆工进场粉刷石膏找平原有坑洼不平的窗台，然后阳角采用阳角条辅助施工收口，这样极简石材安装能更细致，后面的油漆工收口以及修补就更美观。当然，如果你家石材是装修公司提供，前期找平可以免费处理，如果你家石材是自己购买安装，只能单独付费去处理这个了▲如图所示，石材突出来5mm左右即可，为了后期批腻子刚好收口即可，这样做出来就是极简的样式。▲特别是阳台区域，如果有定制衣柜，石材极简安装，完全不会影响收纳柜的定制，否则还是过去出耳朵的做法，必然与定制冲突难看▲还有人如上图的做法，虽然没有窗套，不要耳朵，但是石材还是出头很多，侧面还是一样的突兀，还是和耳朵一样会磕碰到人，而且看起来更丑▲好的做法就是如图的做法，浅色系不要耳朵不出头，干净极简，而且可以让空间看起来更显高级▲是不是要极简美观多了▲如果是后期准备裸露的飘窗也是可以采用极简的石材安装，效果更好看▲如果后期飘窗是直接铺垫子的话，就不要用石材了，直接瓷砖铺贴，更实惠，把石材压到垫子下方，谁也看不到，对于刚需房就是多花冤枉钱而已▲瓷砖铺飘窗一定记着收口，要不裸露的瓷砖横截面一是不美观，第二容易伤人，有安全隐患注意：家里用窗台石的地方是没有墙砖的地方，如果有贴墙砖就不要多此一举弄石材了，像厨卫空间以及阳台有墙砖的窗台，是不需要石材的。
