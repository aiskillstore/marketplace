# 90㎡两室老破小，30万成功改造

非常破旧的两室老房，已经破败不堪，想要入住必须整体翻新，耗费时间和金钱比一般的毛坯房要多很多。但是面对市面上千篇一律的精装修，自己改造才是自己想要的家。

▲房子原始的样子，腾出以后，基础装修时间太久了，整体没有办法使用，只能全部拆除重新装修。
▲原始户型的结构，入门直对卫生间，和风水无关，总感觉不舒服；厨房太小，导致餐厅也过小，空间分割不是很合理，比较浪费
▲设计后的布局图纸，首先解决进门直对卫生间的问题，砸掉卫生间墙体，压缩一部分空间，改变入门朝向客厅，既解决入门对卫生间的问题，同时朝南可以提亮卫生间的光线；
砸掉厨房墙体外移，实现厨房空间的拓展，同时把餐桌布局在原来的卫生间位置，提升家里的空间收纳能力；主卧分割做了一个小的衣帽间，满足更多收纳
▲入门左手有个很大的空间，刚好满足进门的收纳，但是进深很大，直接做高柜显得很压抑，所以采用了里头薄柜收纳，延伸换鞋凳功能，同时新砌墙做了镶嵌处理。一边高柜抽拉储物更多，这种薄厚搭配既不浪费空间，又不会显得压抑
▲薄厚柜的组合，可以抽拉出来，收纳更多进门的鞋子，完全合理利用了门口的空间；白色与木色搭配清新和温馨都有了
▲鞋柜的收纳示意图，既不浪费空间，又能实现不同的收纳，而且旁边顶天立地的抽拉更合理利用空间
▲改变卫生间门位置以后，把次卧做了黑板漆隐形门布局，刚好作为餐厅的背景，餐桌垂直摆放，利用空间，把厨房得以拓展
▲次卧隐形门设计，可以让餐厅空间更加完整
▲客厅看餐厅空间，刚好利用原来的过道实现餐厅功能，而且还实现了餐边柜的布局；卫生间门朝向客厅，南向引光入室，提升卫生间光线
▲客厅全景与阳台打通布局提升空间，同时利用电视墙整体收纳柜定制，满足更多收纳，大面积白色提升空间亮度；阳台位置打造休闲吧台平时可以兼顾办公
▲电视墙全景，收纳柜布局比任何造型都务实，旁边就是卫生间长虹玻璃门，可以南向引光入室，提升卫生间光线
▲主卧空间延续白色与木色的搭配，大面积蓝色色块拼色涂刷，提升空间高级感；原有落地窗定制书桌，作为办公区功能
▲落地窗实现完美的书桌定制，可以满足平时的办公所需
▲因为主卧空间较大，刚好利用角落两边定制衣柜，做了一个小的衣帽间空间，而且延伸定制了一个化妆台功能；衣帽间背景全身镜布局满足功能，布帘简单可以分割，平时可以遮挡一下衣帽间内部以及全身镜
▲次卧因为空间限制，刚好定制榻榻米，满足次卧兼顾书房，同时拓展家里的收纳
▲白色与木色的搭配视觉上永远清新干净
▲客厅阳台与客厅打通布局，同时透光纱帘保证视觉的通透明亮，采用木质的吧台定制，满足功能而且还拓展了功能
▲阳台的另一边刚好满足洗烘机的镶嵌以及洗衣池的定制
▲厨房拓展以后实现了U型布局，同时满足更多收纳，同时延续木色与白色的搭配，清新干净
▲卫生间压缩空间，改变门的方向，提升了整体光线；黑白配的色调显得更干净明亮
