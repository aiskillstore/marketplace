# 老旧房改造，需要有足够的经验和预知风险的能力5.18

关于老旧房改造，陈工是非常有话语权的，从开始接触装修这一行，有幸就没有拒绝过旧房的装修。在过去装修市场如火如荼的时候，老旧房改造几乎是装修机构不愿意去触碰的工程，因为太麻烦，因为赚钱太慢，风险极高。但是那时候，陈工的理念是来者不拒，所以有幸十几年积累了难得的经验。今天给大家分享一下老旧房改造的一些常识，以便于有老旧房需求的业主参考。关于老旧房的知识和改造案例，大家可以点击下面图片，移步专区查看。

什么样的老旧房适合改造

有的人肯定会纳闷：还有不适合改造的老旧房？是的，和新房一样，房子是为人服务，一定要考虑人的因素。
1.老年人入住带孙子的老旧房不能改造。环保是第一入住标准，不论你采用任何手段，只要把原来的老旧房全部改造，污染都比原来大，如果是老人带很小的孩子，千万不要想着为了后代的生活，去改造本身已经很环保的老房，得不偿失。你以为的新房，其实暗藏太多不可预支的环保因素，老人和小孩都是免疫力非常低的群体，这个无形中给生活造成风险。所以不建议，除非孩子到8-10岁左右可以改造。这种事情陈工碰到很多，基本都是苦口婆心劝解了，不能为了赚钱昧着良心干事。
2.备孕期的小年轻老旧房建议不动。好多年轻人要不是购买的二手房，要不是家里的老房，想要改造一新，同时迎接新生命的来临。但是记住，如果是备孕期，千万不要动，表面看是迎接新生命，实际上风险超高，不论你怎么做，新装修的房子污染总比老旧房污染大，不要为了所谓的新房，造成终生悔恨。
2

老旧房改造的风险有哪些

1.安全隐患。这个大家往往会忽视，以为房子装修没有什么区别。其实实际操作风险非常大。老旧房必须有大量的拆除，年代久远，有些覆盖的东西，压根不知道状况，在拆除机械操作的过程中，往往有各种危险防不胜防。

2.地暖房子：这是非常让人头疼的，需要砸掉瓷砖，就必须用电锤，地下是地暖管道，很有可能砸断管道。一般地暖房操作，都会告知业主做好准备：一旦砸断某处，免费维修即可。否则，这个拆除是进行不下去的。
3.各种管道：这个一定要注意，非常老旧的小区，下水上水管都非常脆弱。一旦机械操作稍不留神碰到，就有可能断裂。例如老旧小区的金属下水管，有的已经生锈到薄如纸壳了，稍有不慎碰了就是窟窿，如果维修，会不断延伸破裂风险，搞不好整栋楼都得更换，这个成本不是装修机构和业主能承担起的。
4.上水管：老旧改造，一般上水管都得更换，否则整体拆除就没有必要了，都已经恢复到毛坯房了，保留原来的老旧水管，隐患更多，所以这个可以不用保留。
5.暖气管道：这个有所不同了，如果业主想重新做还好，如果想要保留，拆除瓷砖过程就得小心。
6.所有老旧墙体，看不清结构情况下，不要拆除。好多老旧房物业没有图纸，业主也没有图纸，铲除墙体以后，看到红砖墙，都想拆除，这是非常危险的。老旧小区，大部分红砖墙都可能是称重墙，不能动。这个一定注意。
3

老旧房改造注意点

1.管道风险，老旧保护。拆除一定要有经验的队伍，做好原有老旧设施的保护。

2.冬季施工。注意暖气随时的关闭，防止爆管。
3.所有老旧房墙面铲除以后，后期必须挂网处理。
4.地砖不动的时候，做好保护，也可以后期上头直接铺木地板，无需找平处理。但是所有墙面水电改造就得走顶或者墙面横开槽了。
5.老旧房的改造费用，会多出一个拆除和修补费用，要比毛坯房造价高很多
6.除此剩下的所有施工几乎和新房一样，只是比新房多了更多协调和规划。和新房一样，没有设计和规划经验，装修都做不了，更不要说老旧房改造了拆铲施工，新房和旧房都必须经历
