# 厨房台面置物，有什么好物推荐9.10

上篇谈了一下厨房垂直空间利用，也推荐了一些常用好物《厨房墙面垂直收纳，有哪些好物推荐？》，今天继续，谈一下厨房台面收纳，有什么好用的好物。

01水槽置物收纳

▲水槽置物架，是个让人又爱又恨的物件。确实满足了小空间更多的收纳储物，但是看起来凌乱。所以需要平衡美观和收纳几乎太难，对于小户型厨房来说，只能牺牲美观来满足更多的基本的收纳储物

02台面调料收纳架

▲随手置物架，对于经常做饭的人来说，随手拿取物品的收纳才是合理的收纳。一些常用的东西必须伸手够到，而且能常用的集中放置最好，例如调料、道具，案板等物品，可以随用随取，用完收纳。
03台面刀具案板架

▲小角落刀架案板架，推荐的原因是因为占地小，而且每一家水槽如果靠墙，总有一个空余台面，此时这种收纳架刚好满足充分利用，而且离水槽近，清理拿取都比较方便，最重要的节省地方，不占去台面的切菜区和备菜区
04旋转调料架

▲旋转调料架，算得上是厨房里头的神器了，因为烹饪的调料非常多，没有专用的调料收纳地，或者用所谓调料拉篮，价格贵还放不了多少调料；而这种旋转的调料架，不仅满足更多调料的放置，而且集中放置，旋转设计，想要那个一目了然，拿取更方便，而且不占地，可以放到灶具的墙体角落。分层设计，可以根据自己家烹饪习惯，调料的多少规划层数

05伸缩置物架

▲伸缩置物架，分层设计，可以满足更多收纳的需求；同时可以兼顾台面或者小空间的收纳，因为可以伸缩，多大空间都适用06餐具收纳沥水架

▲家里入住人少，每次用完的碗碟不可能每次擦干然后收拾，也不能只能放台面，有灰尘的话，每次使用都得再次清洗一遍。所以上图的碗碟收纳盒就可以满足需求，带沥水功能，放进去也防尘，下次需求直接拿出来使用即可
07台面置物收纳

▲小角落台面置物架，非常适合灶具角落的空间，可以收纳放置常用的调料收纳，平时烹饪随手拿取也方便。而且这种置物架因为占地很小，可以把灶具旁边的闲置角落充分利用起来
