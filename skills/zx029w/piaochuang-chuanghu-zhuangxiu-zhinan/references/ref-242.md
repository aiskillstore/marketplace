# 85㎡两室老房改造，简约原木

本身空间就是刚需，所以能改造的地方也不多，但是老旧的面貌需要重新恢复重新装修。

▲原始样子，因为格局较小，虽然纯南户型，光线并没有受到影响，只是把原有装修基础推到重来

▲原始结构，入门是个小厅，但是没法做鞋柜；左右分别是次卧和一间暗卫；厨房在两个卧室中间；门厅进来就是纯南的客餐厅一体，带休闲阳台但是没有下水；需要解决洗烘机的放置，以及冰箱的放置，因为厨房实在太小，放冰箱太影响正常收纳

▲设计后的布局图纸，移动右手卫生间门和墙体，实现进门的鞋柜收纳；厨房布局U型，餐厅定制餐边柜满足了冰箱的放置；移动主卧门洞实现门口衣柜的定制，但是电视就无法居中，采用简单的主卧门隐形处理；客餐厅阳台一体打通扩大空间和视觉效果

▲空间整体不大，所以也没有做复杂的累赘造型，大面积白色与木色搭配，显得更温馨和清爽

▲厨房太小，收纳本身就不足，所以横向定制餐边柜满足冰箱镶嵌，改变方向以后收纳更多，刚好避开暖气片位置

▲反过来看全景空间，纯南户型，光线还是不错；整体客餐厅一体与阳台打通，尽量放大空间和提升光线

▲餐边柜定制以后，客厅仅能容纳沙发放置，局部下灯带以及木质背景与原木色呼应；阳台无法拆除的短墙做了弧形处理，视觉更柔和

▲暗藏下灯带更好的提升氛围，满足晚上的灯光层次

▲主卧门做了木质的隐形造型，尽量让电视墙看上去更整洁

▲主卧空间不大，侧面定制衣柜，延伸一个化妆台兼顾书桌，背景做了弧形造型，灯带营造氛围

▲衣柜定制延伸一个简单的书桌，兼顾床头柜和化妆台的作用

▲为了成就更多收纳，移动了主卧门洞，实现一面墙的定制衣柜

▲因为只有两间卧室，所以次卧做了上下铺布局，同时可以满足孩子入住，同时老人偶尔过来也能居住

▲厨房因为空间要满足收纳，所以采用单扇外挂移门，长虹玻璃搭配，满足功能和颜值需要

▲U型布局，地柜木色与白色吊柜搭配，延伸整体风格

▲卫生间因为暗卫，所以在灯光处理上尽量明亮，统一浅色石材瓷砖，整体灯光下更明亮

▲卫生间暗卫而且很小，还得容纳洗烘机的布局，洗澡的地方就很小，无法满足淋浴房布局，只能临时采用浴帘遮挡，满足基本功能
