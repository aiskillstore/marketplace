# 85㎡旧房改造，一抹绿成就北欧新家

老房改造一是过去的装修太陈旧，其实还有一个最重要也是最无法忍受的是，格局不合理，功能好多无法实现。所以在准备改造的时候，先进行设计，能满足功能，格局更好，再决定是否改造

▲原始图纸。进门是厅，而且很小压根没有餐厅的位置；进门直接能看到卫生间门。

业主要求：需要有单独餐厅空间，单独的电视墙客厅空间；主卧希望有个可以休闲的角落；次卧兼顾休闲同时备用后面的儿童房。
▲拆墙砌墙图纸。原来的厨房门移动位置，为了单独餐客厅做准备；原来的卫生间门改动位置，解决入户对门的尴尬；原来的主卧没有门垛，新作门垛便于装门
▲设计后的图纸。除过厨卫墙体改动以外，其他没有做任何变化；厨房移动门位置，为了靠窗户单独布置餐厅，同时为了沙发和电视墙的居中布局；主卧唯一的生活阳台做了榻榻米休闲定制，既满足生活晾衣，又能满足休闲
▲因为进门是厅，只能借用右手的过道墙面布局超薄鞋柜，15公分的深度斜面放鞋，同时悬空布局，下方可以直接放置鞋子，旁边木质衣帽架，可以满足进门衣服和包包的悬挂，成品的换鞋凳满足进门坐下来休息换鞋的需求。地面通铺木纹瓷砖，考虑到有木纹的自然，同时环保健康
▲没有做吊顶，进门客餐厅以及过道统一简单石膏线勾勒，同时因为面积小，挂机更节省地方，更实惠。大面积墙面淡灰色变色，沙发背景采用简单石膏线勾勒，局部豆沙绿的变色，视觉非常清新，同时也能作为进门的端景
▲进门的过道与客餐厅没有做分区处理，视觉上能放大空间；直对的是原来卫生间门，改变卫生间门以后，刚好形成单独背景，一副挂画点缀。客厅进入卧室过道有一道大梁，为了视觉完美，过道吊了平顶，暗藏筒灯，视觉要美观多了
▲进门的一抹绿是最惊艳的，直接通到石膏线，旁边壁灯点缀，可以满足平时阅读和灯光点缀需求
▲看一下近景，木质与布艺结合的沙发，狐狸皮挂毯装饰，高端大气
▲进门左手就是电视墙，移动厨房门就是为了移动电视墙位置，成就窗下的餐厅空间。厨房带阳台，集成灶布局阳台，所以厨房不装门，只做了门套，清新的半截帘，视觉更通透柔和
▲站厨房看客餐厅，灰色淡雅的墙面，木纹砖与木色家具自然温馨，采用黑白灰的软配进行点缀，视觉干净温馨
▲原木灰色的沙发，黑白配格子抱枕提亮整体亮度
▲浅色原木茶几，铺上清新的桌布，客厅更柔和温馨
▲餐桌同样黑白配的桌布搭配，与抱枕呼应，提亮整体视觉空间
▲因为空间太小，害怕视觉繁琐，电视柜采用一块自然的原木隔板，悬空设计，平时上头可以摆放一些装饰品，下方可以放一些绿植，视觉更简单灵动
▲隔板刚好隐藏下方的插座
▲原木的自然纹路，自然的弧边，提升空间的自然温馨度
▲客餐厅全景，窗下很小的位置实现就餐区，同时又能保留沙发和电视墙，功能一样都不少
▲餐桌是宜家的白色折叠餐桌，搭配铁艺的牛角椅，角落白色的斗柜可以收纳杂物，同时摆上装饰花瓶，与窗台的绿植共同点缀温馨
▲客厅进入卧室的过道空间，直对背景一副浮世绘的挂画，与地面彩色地毯呼应，视觉活泼。因为次卧定制了休闲榻榻米，所以暂时没有装门，同样清新的半截帘，让空间开放，空气流通更好
▲次卧整体休闲榻榻米定制，没有装门，半截帘搭配，光线和视觉更开放敞亮
▲掀开半截帘是次卧的全景，采用上翻盖隐形把手设计，平时的被子、换季衣物都可以收纳到这里，储物能力非常强大

▲一副超大的斑马挂画斜靠侧墙，提升空间高级感，顶天立地的吸塑门衣柜同样可以收纳家里的衣物
▲皮毛毯子，舒适的抱枕，以及蒲团布置，平时这里可以作为休闲娱乐空间
▲主卧空间，背景浅色豆沙绿，浅灰色床头，阳台蓝色窗帘，整体清新明亮
▲床头柜是创意复古的床头柜，非常新颖
▲主卧门口看全景，左侧墙面定制收纳衣柜，阳台阳光直接照射进来，光线一览无余。铁艺的衣帽架可以满足晚上挂衣服需求
▲主卧的生活阳台为了兼顾休闲，定制榻榻米收纳，一边还安置了花架，可以养一些绿植，平时不论是看书或者休闲都是不错的地方
▲浅蓝色窗帘与热带雨林的布垫，视觉非常清新，侧面是吸塑柜门的收纳柜
▲很大的休闲抱枕搭配，平时可以在这里睡懒觉，也是最好的享受
▲掀开小碎花的半截帘，迎面是厨房的水绿色瓷砖，与客厅一抹绿完美衔接
▲厨房白色吸塑柜门，水绿色小规格瓷砖，采用黑色的挂件，清新整洁
▲双开门冰箱刚好放置角落，夹角处定制高柜，层板设计刚好满足小家电的放置
▲打通阳台以后，把集成灶安排到阳台，形成中西厨的分区，同样采用半截帘让视觉和光线通透
▲集成灶的好处就是能腾出头顶空间，刚好阳台无法做普通烟机灶具，集成灶完美解决
▲卫生间灰地白墙，石材浅色墙面视觉清新干净。左侧移动门以后刚好定制浴柜，满足洗烘一体机的镶嵌，镜柜拉通定制，不仅满足收纳，同时视觉上拉伸空间，包管道位置局部木色套色镂空，连纸盒子都节省了
▲镶嵌洗衣机与浴柜完美结合，上头牺牲局部吊顶满足电热水器的位置
▲右手角落刚好作为单独淋浴区，黑色的挡水与浴帘杆质感搭配，铺上防滑的防腐木，拉上浴帘，就是一个独立的淋浴空间
