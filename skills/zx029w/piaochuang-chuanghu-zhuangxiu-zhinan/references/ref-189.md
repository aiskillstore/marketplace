# 飘窗不包窗套，直接靠在大白墙上吗？4.3

飘窗不需要包套，省钱，而且对于刚需房来说视觉上不会有累赘感，更清爽干净，可以有放大空间的价值。这个才是重点，木质窗套是没法防止漏水或者潮气发霉的，只不过时间久了窗套就脱落，到时候不如不做，漏水潮气还能最短时间发现并解决。你如果不怕发霉，但是需要有审美，你如果是上图的审美还是算了；掏钱买个视觉累赘，而且导致整体卧室档次降低。是不是很羡慕这个飘窗，人家不一样做了窗套？是的，你得做好心理准备，金钱准备，污染准备。第一种人造板贴实木皮，采用欧松板或者木工板打基层，然后用纯胶把实木板子粘上去；这个就和直接贴人造板一个道理，你绞尽脑汁给卧室减少污染，而一个飘窗成了最大的污染源，图个啥？
第二种你用人造板直接打底，采用KD板饰面，一样的做法，KD板必须用全胶施工，一样的污染
第三种你有钱用纯实木板子去做，可以基层还得用人造板打底，还得用胶去沾。以上三种利弊你能接受，最后你得有足够的金钱，以上三种任何做法要比你家一樘木门贵很多，纯实木的话价格那就更贵了。有人说我用石材包飘窗套，就不怕发霉和潮湿了吧？确实，除过廉价没有毛病甚至有人给厨卫窗户多此一举单独弄个石材套，你以为你是欧式宫廷装修？只不过是显得更加廉价，而且建材商能高兴死而已。所以还是建议你不要包套，更简洁，更清爽，省钱还能放大空间。那么问题来了：飘窗不包窗套，直接靠在大白墙上吗？当然不是了，这个后期靠软装都是有解决办法的。如图所示，不包窗套铺上垫子就可以休闲，同时搭配合适的靠垫，不存在靠大白墙的问题。像上图一边有定制柜子的，放个平时普通的抱枕就可以保证舒适就坐，也不需要考虑靠着大白墙的问题了如图所示，飘窗变沙发，加个靠背而已，更不需要担心靠大白墙的问题，更舒适当然铺上飘窗垫子，买个符合人体工程学的小靠垫一样可以很舒服如图配套垫子和靠垫，也是可以，而且可以搭配出奶油风的颜色如图铺上垫子的飘窗，既可以当做沙发，又可以满足一个床的功能一边一个，飘窗就可以满足两人喝茶聊天看风景了三个抱枕自由组合，想怎么靠就怎么靠，完全不用担心直接靠到乳胶漆墙面不包窗套，后期采用各种软装，都可以满足舒服靠墙的，无需担心靠着乳胶漆也可以直接定制一个棉花糖飘窗沙发，也是可以的
