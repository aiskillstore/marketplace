# 沙发买那么小？客厅有飘窗不怕11.23

关于飘窗的文章很多，大家可以后台回复『飘窗』，或者直接搜索就可以；今天看看客厅如果有大飘窗都可以怎么去做更合适，更美观。

▲横厅的户型，通用一个超级大的飘窗，采光和颜值都能提升；此时取决于客餐厅的布局了，如上图，客厅舍弃传统做法，沙发靠向飘窗放置，剩余空间刚好布局餐桌椅，一部分飘窗充当了座椅功能，刚好满足四人位就餐空间，而且利用飘窗的夹角定制了隔板书柜，平时的餐桌也可以兼顾办公需求
▲如图客厅带一个超级大的飘窗，好处是多了一个观景休闲区，而且空间大，可以布局L型沙发，满足更多人聚会需求；人多的话飘窗也可以兼顾座椅的功能。
▲没有飘窗可以造一个飘窗，如图空间，利用通向阳台的窗户下方，打造收纳式飘窗柜，既满足了书籍的收纳，同时又多了一个卡座空间，此时，沙发可以购买轻巧型的，因为飘窗已经代替了一部分沙发的功能，再多人都可以满足聚会需求

▲横厅空间，共用一个超级飘窗，当然是休闲空间；上图没有做休闲垫子，完全作为一个空置空间，视觉上空间干净整洁。当然也可以放上蒲团垫子，兼顾休闲

▲极小空间，如图这个不是飘窗了，这个是改变方向以后，把阳台与客厅打通，直接在阳台做了卡座设计，然后定制垫子，充当了沙发的功能，非常的有设计感，而且满足了功能性

▲客厅带飘窗，而且还是侧飘窗，这种户型非常多，一般多为休闲布局，如图刚好把暖气片放到窗户下方布局，同时窗帘只在窗户上布局，做了窗帘盒，让整体视觉更明亮通透
▲横厅户型，飘窗石材装饰以后，作为空置地方，后期可以摆放小绿植，或者放上精美的装饰，这里也是一个置物空间而已；因为靠近窗户保持整洁，可以让光线更明亮，视觉更干净
▲同样是客厅带飘窗，一边铺上休闲垫子和抱枕装饰，这里可以作为休闲功能，平时躺着消磨时光，窗外无限风光，也是不错的观景地方。
▲客厅带飘窗的最大好处，其实就是可以沙发选择轻巧款式，而从不担心来人多了没有地方坐，因为飘窗可以随时兼顾一个三人位的沙发功能
▲客厅落地窗造一个飘窗柜，既满足休闲，又满足收纳，同时还弥补了沙发功能的不足
▲碰到这种两个窗户之间有实墙的户型，为了视觉上减少分离感，可以下方做飘窗柜，视觉上让两个窗户统一成一个整体。满足收纳兼顾休闲区域
▲客厅做一个飘窗柜，完美代替沙发功能，而且增加收纳，关键是沙发可以购买轻巧款式，让客厅更显宽敞简洁。
▲利用客厅落地窗的凹陷区，打造一个休闲兼顾收纳的飘窗柜，放上小圆桌，这里可以作为休闲区使用，不论是平时办公还是陪孩子在这里做手工，都非常完美，简直是想要大沙发又怕空间拥挤的最好做法。
▲横厅空间，窗户凹陷区定制假飘窗柜，可以兼顾一个喝茶的区域，光线最好的地方合理利用。
▲极小空间的话，客厅有个飘窗可以弥补很多空间上的不足--可以兼顾沙发功能，也可以兼顾休闲空间。
▲也可以把客厅飘窗单独布局小几和蒲团，作为一个喝茶休息的地方，也是非常完美的
▲落地窗打造假飘窗，让客厅的每一寸空间都发挥价值；既能弥补沙发的不足，同时又能满足收纳。
▲别人家可以这么宽敞，购买这么小的沙发，就是因为有一个可以兼顾沙发的飘窗。
▲你如果书多没有地方收纳，可以把客厅平窗打造成两边书柜，中间休闲飘窗柜的形式，既满足了书籍的布局，同时又弥补沙发的不足，同时增加了阅读空间。
▲沙发那么小够坐吗？当然没有问题，原来超低飘窗加了一排收纳抽屉，不仅满足收纳，而且高低刚好满足沙发功能，铺上垫子，就可以让客厅空间放大。家有L型飘窗，怎么设计更好？
