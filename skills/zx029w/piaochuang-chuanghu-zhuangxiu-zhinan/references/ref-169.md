# 家里窗台石的6种做法，你喜欢哪种8.30

窗台石每家都有，都必须处理，但是处理方式不尽相同，所以今天看看各种窗台石的处理方法，看哪种更适合自己。
第一种：平窗带耳朵做法
▲带耳朵普通平窗做法，石材延伸出来，而且两边会有耳朵突出，此种做法大部分人声称这样可以避免忘记关窗，雨水打湿墙面，其实都是多此一举，这个耳朵和飘出做法并不会避免什么雨水浸湿墙面▲看看上图，你就知道石材耳朵的作用了。在过去传统的窗套做法中，下方石材耳朵是为了给上方窗套收口使用而已，这个是功能性，而现今都没有人做窗套了，你还是传统方法做窗台石，就落伍了▲看上图更直观，能看清石材耳朵与窗套的关系，如果你不做耳朵，窗套无法收口就更难看▲如图现今都没有人做窗套，但是你石材不做改变，不仅视觉难看，而且多出来的耳朵还容易磕碰到人，特别是家里有小孩，这个高度最容易磕碰，所以完全多此一举第二种：没有耳朵但飘出▲如图石材，虽然没有耳朵，但是一样的飘出这么多，同样也是难看，而且容易磕碰到人的第三种，没有耳朵，飘出倒圆弧▲当然如果你非得飘出，还可以如上图的做法，直接倒弧边，也不会担心磕碰了第四种：极简做法，不要耳朵，不飘出▲如图窗台石极简做法，不要耳朵，不飘出，视觉更极简，不论是空间还是功能都是最推荐的做法。需要注意的是这样做肯定是不要窗套的，而且飘出半公分左右，这样后期批腻子刷漆刚好能做平整第五种：极简做法留工艺缝▲如图所示，同样是极简做法，只不过石材朝外留了工艺缝，目的是什么？有人说是为了防止乳胶漆与石材之间的裂缝，这个有点牵强。而且这种做法必须是刷完乳胶漆才安装，更会导致磕碰或者弄脏墙面，感觉老是把简单的事情办复杂了，真的没有必要，也不推荐第六种：飘窗极简石材▲飘窗石材和平窗石材有所区别，取决于后期的用途，如图同样是极简的做法，但是仅限于后期这里纯做休闲或者放一些绿植使用▲如图，如果你家飘窗后期铺的垫子的话，此时是不是铺石材有点多余了？当然不缺钱也是可以这样做的▲如图后期不是为了放绿植，就是为了铺垫子，那其实直接用家里的地砖，瓦工施工就可以搞定飘窗，反正垫子盖住了，谁也看不到
