# 115㎡老房改造婚房，三室只有一卫

三室一卫的老房子，需要改造成小两口的婚房，整体比较老旧所以全部恢复毛墙毛地以后重新规划。

▲因为要做婚房使用，过去装修颜色老旧过深，而且收纳也不足，装修过时，所以必须推倒重来。

▲原始图纸，进门就是餐厅，而且餐厅很小，直对入户门能看到卫生间，而且没有干湿分离；大部分都是承重墙，只有少部分墙体可以拆改；小两口需要各自独立的办公空间，还要备用以后三口之家的入住；卫生间需要干湿分离的布局

▲设计后的布局图纸，首先进门直对卫生间的问题，采用在两个次卧之间实现干区功能，书房门口定制柜延伸餐厅墙体，这样的方式刚好能遮挡一下入户直对卫生间的问题；书房带阳台满足一间单独办公的空间，同时阳台榻榻米满足休闲功能；次卧砸掉原有的飘窗实现一个书桌功能，这里也可以作为单独的办公区域；同时定制收纳柜做了隐藏床体，这里同时兼顾一间单独卧室，以后可以作为儿童房备用；

▲入门视角，利用两个次卧延伸的墙体，实现了收纳柜和干区的布局，同时刚好遮挡一下直对的卫生间；而且卫生间做了隐形门处理，进一步做了弱化处理；进门直线吊顶采用线性灯做了视觉延伸，满足拉伸空间的功能

▲餐厅需要留出进入厨房的空间，刚好侧墙布局，采用复古的椭圆形餐桌搭配两把不同色的复古餐椅；利用新砌墙留出灯槽满足晚上灯光的点缀，同时搭配了极简的伞状吊灯，营造一个简单但是温馨的就餐区域

▲书房以及次卧墙体往外延伸了50公分距离 ，实现了干区的布局，同时还实现了局部收纳柜与干区对称；干区背景采用极窄玻璃砖与书房保持通透点缀

▲入门左手边定制一排收纳柜，同时兼顾了餐边柜水吧台以及进门的鞋子收纳，局部留白搭配背景的木格栅，满足视觉的灵活，同时满足进门坐着换鞋；厨房通透的玻璃门引光入室，让门厅显得格外明亮

▲入门右手客厅全景，与阳台打通布局，窗帘直接布局阳台，不仅放大空间，同时让光线更敞亮；极简搭配和无主灯设计，整体更简洁大气；沙发背景弧形木质背景刚好与阳台垭口完美呼应

▲米色矮款布艺沙发搭配黑色弧形茶几；背景弧形饰面与转角的弧形打磨，空间显得柔和圆润；角落的吊灯与极简圆几配合点缀

▲阳台纳入客厅放大空间以及光线，地台设计又让阳台独立休闲，侧面定制实现洗烘机的布局，视觉上也美观干净

▲透过玻璃移门就是带阳台的书房空间，阳台同样打造榻榻米休闲，一面墙书柜定制满足所有书籍的收纳；

▲深灰色书柜虚实结合，三分之一处格栅造型布局，实现完美的比例美

▲站阳台看书房全景，同样无主灯布局，书柜对面，采用原始一张桌板实现悬空的书桌设计，搭配黑色的复古单椅，分色墙体设计，空间显得简洁又不失高级感

▲主卧空间，原来的飘窗柜拆除以后，实现一个宽大的落地窗，更好的布局窗帘，也能放大整体空间

▲大面积浅色布局，透明轻盈的花瓣灯搭配，空间柔和温馨

▲书房隔壁的次卧空间，定制了更多的收纳柜 ，原有飘窗砸掉以后实现了化妆台兼顾书桌的功能，这里可以兼顾女主的衣帽间以及单独的办公空间

▲砸掉原有飘窗实现书桌兼顾化妆台功能，两侧收纳满足书桌的整洁，同时头顶线性灯与壁灯满足空间的照明；因为是三楼空间，窗户的绿意随时可以映入眼帘

▲厨房U型布局，白色与木色搭配更加清新；墙面采用面包砖与地面花砖呼应，功能和颜值都能满足

▲利用牺牲书房空间实现的干区布局，高低柜搭配，悬空浴柜搭配精致的圆镜；同时延伸木色与白色的清新；高柜满足基本收纳，可以保证干区时刻的整洁
▲推开隐形门以后，原有卫生间因为浴柜外置的原因，显得更宽大；独立的淋浴隔断分区，光线以及功能都完美实现
