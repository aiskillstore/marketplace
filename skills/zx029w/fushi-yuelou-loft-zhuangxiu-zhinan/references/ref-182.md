# loft现代家，150m²一层都是休闲区

loft户型，风格定位现代风，因为户型原始布局的固定，所以只能一层休闲，二楼是睡眠休息区。还好，几乎所有墙体都是非承重，这样就有无限改造的可能。

▲一层的原始结构图。▲砸掉一些墙体，一楼的基本格局就形成了。虽然原始有点乱，但是可以改造的墙体居多▲最终一楼的设计图纸，客餐厅，一厨一卫一阳台，基本一层就作为全家休闲的地方▲二楼的设计布局图纸，三房两卫一阳台，基本是私密的睡眠区域
▲一楼进门的玄关区域。直对通顶鞋柜背后刚好是我们的储藏室空间，右手换鞋凳功能，墙面是六边形的墙贴可以保护墙面，原来枣红色的防盗门毛毡装饰，灯光布局下进门倍感温馨
▲鞋柜的背后就是小的储藏室，以及门口的平板收纳柜，用来放置家里的各种杂物，没有装门，黑色的个性布帘遮挡
▲门厅进来右手就是一览无余的中厨空间，采用做旧的木色橱柜，为了实现彻底开放砸掉墙体以后，采用集成灶实现玻璃隔断的分割，整体平面吊顶简洁辅助光布局
▲门厅以及开放式中厨全景，厨房对面就是楼梯空间
▲门厅进来的楼梯间，楼梯下方做了平板门储藏室，楼梯旁边斗柜收纳兼顾装饰，背景铁艺的搁架装饰
▲下面储藏室超级收纳，可以拉出来，右侧是预留的家里行李箱位置
▲客厅看全景，中西厨一体设计，西厨空间冰箱以及高柜分开，统一颜色做旧的木质收纳柜。岛台以及餐桌的放置。本来西厨的位置应该是电视墙的空间，为了实现超大的西厨以及餐厅空间，把电视墙做了西厨，完美实现餐桌和岛台的大气布置
▲客厅全景，因为牺牲了电视墙空间，在阳台的中间墙面设计大幅壁画，作为简单电视墙，满足基本需求。整体平面无吊顶辅助光源的布置，灯光层次更好，视觉更简洁
▲西厨看客厅全景，能看到旁边客卫的干区。沙发区不大，为了视觉简单，采用轻巧家具配置，地毯增加视觉层次，这样整体空间宽敞敞亮
▲西厨以及餐厅全景，靠近阳台利用卡座分割区域，这样餐厅可以满足8人同时就餐
▲岛台的吊灯与西厨滑轨灯的布局，空间视觉层次感更强
▲岛台以及西厨的细节图，西厨柜局部镂空，隔板简单收纳，可以放置各种小家电
▲楼梯间比较狭窄，所以基本是大白墙，采用灯带壁灯以及吊灯的形式，减弱狭小空间的压抑感

▲楼上主卧空间，统一四周吊顶，背景采用格子灰色质感壁布，局部灯带以及辅助光照明。床对面因为有局部承重墙，作为电视墙使用，两边镶嵌衣柜收纳
▲主卧与阳台之间定制双人位书桌极简布置，隔板代替书柜收纳
▲主卧和干区之间新砌墙体，分割空间，干区独立定制
▲儿童房上下铺布置，衣柜简单书桌布置，墙面采用灰色与绿色点缀，同样四周灯带无主灯布置，视觉干净简洁
▲二楼的多功能房目前作为备用房，可以随时变成卧室使用
▲因为整体是落地窗，为了保温效果，窗户全部更换为三层的。简单绿色沙发与地毯搭配，沙发对面高柜收纳，角落简单书桌布置。设计了投影，平时这里就兼顾影视厅功能
▲沙发背后做了局部木质造型以及旁边的收纳书柜，局部做了壁龛收纳
▲角落高大绿植装饰，两头摇臂灯辅助照明
▲一楼阳台休闲布置，灰地白墙，平时养个绿植装饰，简单的休闲椅配置
▲一楼阳台通过窗户看西厨空间，站西厨也可以看到满眼的绿意
▲二楼生活阳台，一侧灰色的洗手盆，角落拖把池配置
▲另一侧洗衣机和烘干机放置，移动的小推车代替收纳功能
▲二楼主卫灰色瓷砖搭配，黑色的淋浴隔断质感分区，马桶做了花砖背景，同样黑色的五金配置
