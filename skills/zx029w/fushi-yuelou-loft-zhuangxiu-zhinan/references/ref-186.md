# 130㎡复式美宅，打造心爱的小轻奢

两层复式，总面积130平左右，目前只住两个人，需要留出三代人生活的功能。单层面积虽然不大，但是上下分区，刚好能满足不同年龄层次的生活需求。
▲一楼空间，进门是厅，楼梯在餐厅无法更改，唯一缺点就是厨卫门是相对的，而且空间显得凌乱和逼仄，而且进门是厅，门口的收纳难以满足
▲一楼设计布局图纸，砸掉厨房墙体移动入门位置，实现餐厨更合理的布局，而且解决厨卫对门问题，实现干湿分离；借用进门左手打造收纳鞋柜满足入门的收纳；借用楼梯下方满足餐边柜的定制；一楼单独卧室刚好作为父母房备用；客厅生活阳台满足平时洗衣晾衣需求
▲二楼空间，比较小，需要满足主人房以及一间儿童房的需求，一间卫生间满足基本功能，但是楼梯休闲平台占据了太多空间，需要单独分割出来儿童房空间
▲把楼梯平台占用的面积单独分割出来，腾出一间儿童房空间，主卧与阳台打通布局满足小两口的使用
▲入门视角，左手为顶天立地的收纳柜，同时满足进门鞋柜以及杂物收纳的需求；右手楼梯下方打造餐边柜同时与电视墙木质饰面延伸，让空间更舒适有延伸感
▲入门左手的鞋柜定制，采用暖咖色与地板饱和度绿色搭配，舒适而且温馨
▲客厅全景，与阳台打通通铺，延伸空间感，放大视觉；电视墙采用木质饰面与石材的搭配，提升空间的质感，同时搭配橘色皮质沙发，完美实现业主想要的小轻奢
▲入门直对的餐厅看客厅空间，橘色皮质的沙发与大幅挂画，提升空间高级感
▲餐厅与楼梯空间，借用楼梯下方餐边柜定制，黑白灰的搭配，让就餐区素雅简洁，富有艺术感的绿植点缀，温馨高级
▲餐厨全景，改变厨房门位置以后，实现了通透的移门布局，让视觉空间更有延伸感，就餐烹饪区的动线更加合理
▲暖咖色餐边柜与鞋柜呼应一体，同时高级灰的套色宁静自然
▲一楼父母房刚好在电视墙，采用木质饰面延伸，满足隐形门的布局，视觉更干净
▲一楼老人房不大，侧墙高级灰的衣柜满足基本收纳，皮质舒适靠背床铺搭配，颜色上采用比较中性的灰色，让空间更宁静稳重
▲二楼主卧同样与阳台打通布局，背景蓝色突出层次和清新
▲侧墙衣柜满足基本收纳，吊线灯营造氛围
▲床尾是成品的斗柜以及化妆台，拓展空间功能
▲主卧阳台打造休闲布局，一边休闲单椅布局，另一边是全身镜与衣帽间，满足晚上挂衣需求
▲厨房改变入门方向以后，U型布局，同时满足基本操作以及高柜和电器的布局
▲楼上卫生间浅灰色瓷砖，黑色淋浴房单独分区布局，干净素雅
