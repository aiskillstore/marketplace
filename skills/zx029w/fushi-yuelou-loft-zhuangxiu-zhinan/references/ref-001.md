# 老房层高只有2.5米左右，怎么装修显高不压抑？

老房层高只有2.5米左右，怎么装修显高不压抑？记住一句话：**层高不够，靠视觉救。** 几个关键手法，照着做。

**第一，能不吊顶就不吊顶，要做就做四周局部。** 客厅不吊顶视觉上反而很平，墙面再和顶面颜色一样，没有层次感，反而有压顶的感觉；做了四周吊顶加墙面变色形成落差，视觉上反而显得层高很高。空间很小的时候一定做贴墙宽边而不是吊顶，否则空间显得更小。悬浮吊顶尽量避免，普通层高完全无法驾驭。

**第二，灯具选对，别用吊灯。** 尽量避免使用吊灯给人造成视觉上的压抑感。餐厅灯刚好安装在大梁上是装修中的大忌，会显得整体层高很低，这种情况完全可以餐厅不用主灯用点光源照明。不吊顶明装筒灯、射灯、滑轨灯，也能满足照明还增加颜值和层次。

**第三，墙面与顶面分开颜色。** 墙面尽量变色处理，不要与顶面一样是白色，形成落差，突出顶面纯白延伸层高。尽量避免使用深色吊顶。

**第四，家具选低矮的。** 家具选择小而精致甚至比较低矮的，用高的落地灯与家具形成反差拉升空间。低矮家具配高落地灯，一低一高，空间感就出来了。

**第五，窗帘升到最高。** 窗帘高度升到最高也可以视觉上拉伸层高。窗帘杆顶天立地，视觉上天花板就"高"了。

**第六，门洞开到最高，这是法宝。** 人为把门洞开到最高是提升层高的法宝，普通门2.1米提升至两米三甚至更高。门洞一高，整个空间的垂直感立刻不一样。

**第七，窗户顶与天花齐平。** 窗户顶部与天花板高度一致，视觉上拉升层高。

**第八，柜子配合吊顶弱化压抑。** 衣柜与吊顶配合弱化存在感减少压抑。卧室没有挂机的时候，四周双眼皮吊顶层次感更强更美观。如果卧室用挂机，宽边双眼皮谨慎，不要盲目跟风。

**最后提醒：** 门厅不要做吊顶做到与大梁平齐，可以四周实心吊顶做凹陷造型隐藏筒灯，形成错落感，目的就是为了视觉上让层高更高。层高不够不可怕，可怕的是又做吊顶又用吊灯又深色，把2.5米的家装成2.2米的压抑感。所有手法围绕一个目标：让视线往高处走，顶面亮起来，层高就"高"了。
