# LOFT公寓房，真香，也真后悔7.13

LOFT公寓房深受年轻人追捧，因为面积小，掏一层的房价，可以实现两层的面积；对于房价居高不下的城市生活，能有一个家，LOFT是不错的选择。
第一、LOFT公寓的优点

1.翻倍的使用面积，例如一般多见30-50平的面积，层高一般在5米左右，用一层的价格，自己可以分割出来两层空间，面积翻倍。
2.自由分割的优势。可以全部变成两层空间，也可以局部变成两层空间。
▲如图可以钢结构分割局部空间，局部挑空，实现更多空间的可能性。
▲也可以全部分割，增加两层的面积，让功能性更多一点。
3.独特空间造就的优秀设计感。这个是大平层都无法实现的优点，非常适合年轻人的个性喜好。
▲如图的做法，全部分割可以实现完美的动静分离空间；楼下客餐厅厨卫；楼上单独的睡眠空间，动静分离的优势完美体现。
▲也可以局部分割，实现局部挑高的效果，同样可以保证上层的光线以及视觉开阔
4.商业LOFT公寓一般都是不限购的，当然这个优势对于年轻人来说作用不大。对于想要投资的人来说，LOFT公寓的不限购优势就很明显了。
5.年轻人有个稳定的家。在城市里头单身青年想拥有一个稳定的家，这种商用LOFT的投资少的优势就显现出来了，而且可以一层变两层，对于独立男性或者女性来说，是不错的选择。
第二、LOFT公寓的缺点1.商用性质。一般公寓LOFT都会商用性质，这样就会导致商用的水电费用，比一般住宅要高很多；而且还得考虑物业费，比一般住宅都要高，最重要的是基本上这种商用LOFT都不通天然气的，所以如果用来入住过日子，也得打听清楚，否则售楼的有时候会把商用当做住宅欺骗销售。

2.产权40年。几乎市面上大部分的商用LOFT都是40年产权，和普通住宅的70年产权不同，这个在购买的时候一定要打听清楚。
3.空间灵活，安全堪忧。虽然LOFT有空间灵活的一面，但是对于老人小孩，恰恰是这种楼上楼下反而不是很方便，而且因为空间比较小，楼梯设计坡度都比较陡，所以对于有老人和小孩居住的话，LOFT的优点就成了缺点了。
4.隔音问题。因为大部分LOFT都是钢结构分割，所以楼上楼下隔音不如混凝土楼板
5.采光问题。虽然LOFT可以自由分割，但是因为户型原因，大部分户型无法全部隔层，否则采光完全不行，所以如果选择一半分割，一半挑空的话，才能满足一定的采光需求
▲看上图的对比表格，能更清晰看到LOFT的优缺点。
6.购买办公自住可以，投资赚钱算了。LOFT商用公寓因为其商用性质，大部分其实是用来办公的，也可以作为自住来使用，不论是自住还是自己办公使用，都是可以的，相比较写字楼来说成本是低的。但是你如果想靠购买这种房子投资赚钱，还是算了，本身贷款只有十年，而且首付一般都是50%，等到你出租赚钱的时候，你会发现，租到老你都赚不到到钱；除非是地段规划房价突涨，你可以转手，但是税费比一般住宅高很多，转手可能也是比较难的
7.人员混杂，无法落户LOFT商用公寓基本都是小户型，一般是几梯几十户都有，而且大多数是办公，可想而知每天上下楼的人有多少。你如果是自住在这种嘈杂的环境，必然受到影响；无法落户也是商用LOFT的弊端，所以对于想投资少自住，孩子上学就是问题。
