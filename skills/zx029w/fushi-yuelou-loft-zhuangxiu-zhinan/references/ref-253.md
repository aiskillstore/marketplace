# 80㎡三口之家，缩小厨房并开放，砸掉飘窗成就功能

两室三口之家纯南户型，开门见厅常见的格局，好处是所有的房间都是朝南，包括厨卫阳台都是，这是唯一让人欣慰地方。

▲原始的格局看门见厅，左手厨房属于细长区域，进入卧室的过道打破了客餐厅的方正，导致餐厅没有单独区域，显得客厅非常拥挤；两个卧室和卫生间都有飘窗，浪费了很大面积，还好都是室内结构，后期可以拆除。
业主要求：最好有单独餐厅区域，厨房要亮堂，同时格局尽量保持开放，可以放大空间；一间主卧收纳要多，同时一间儿童房也得有收纳和学习空间▲设计后的布局图纸：1.缩小厨房，把朝南作为厨房空间，同时为了保持开放格局，厨房和客厅半截墙设计，上方采用玻璃折叠窗，达到视觉开放效果；为了解决油烟问题，缩小以后的厨房玻璃门随时封闭2.缩小厨房以后，进门左手原来厨房的位置单独设计餐厅空间，同时收纳柜卡座定制，与厨房外面的西厨高柜一体定制，视觉更整齐，同时还能满足冰箱的镶嵌3.进门右手区域小空间刚好定制鞋柜，满足进门的收纳4.砸掉了客厅阳台的空间外机位置，定制休闲卡座，可以拓展功能空间5.砸掉了次卧儿童房以及主卧和卫生间的飘窗，尽可能满足室内功能空间6.主卧砸掉飘窗，为了尽可能多的满足收纳，定制了榻榻米地台床，这样收纳更多，满足更多功能7.儿童房砸掉飘窗以后，定制收纳式床铺，保证了收纳休闲以及学习的空间8.卫生间飘窗砸掉以后成就了更大的淋浴单独区域，一家三口干湿分离，功能和细节做到了最大化9.客厅与厨房之间半截墙分割，为了满足基本的娱乐需求，顶部预留了投影幕布
▲进门右手刚好定制通顶鞋柜，白色与木色清新搭配，视觉简洁同时满足进门的收纳。沙发墙因为有过道很短，为了视觉和空间有延伸感，半截墙蓝色涂刷一直延伸至过道，这样进门视觉就可以无限延伸，同样有放大空间的功能
▲进门客厅的全景，把原来的厨房缩小以后成就餐厅位置，同时厨房与客厅开放布局，用玻璃窗解决油烟问题，达到空间开放放大的布局。
▲非常小的沙发墙，简单的木质与布艺结合的沙发布局，角落的梯形置物架原木色统一，同时可以作为收纳置物需求
▲白色与木色清新，再加上蓝色软配的点缀，视觉上让小空间更清新
▲缩小原来的厨房，成就进门左手单独的餐厅，定制卡座与西厨高柜一体化，同时满足镶嵌冰箱以及电器
▲进门左手的单独餐厅位置，卡座满足更多空间，一家三口足够使用
▲进入卧室的过道，为了视觉延伸，沙发半截墙蓝色一直延伸至过道，视觉上放大空间，增加层次。过道的右手紧挨鞋柜刚好布置全身镜，局部软木背景可以作为家里的旅游留念墙，还做了局部黑板墙，满足孩子涂鸦需求
▲主卧本身就不大，砸掉飘窗以后，剩余空间基本很小了，所以为了增加收纳直接定制榻榻米床，木质的床头背景一体定制，整体与衣柜一体化设计，衣柜采用移门节省空间。背景同样采用清新蓝进行层次化突出
▲放上定制床垫以后，靠近窗户位置还有个休闲的空间，光线直接照射榻榻米，非常亮堂
▲儿童房砸掉飘窗以后定制收纳式床，下方可以收纳储物，上方是床铺以及吊柜收纳，靠近窗户刚好布置书桌以及楼梯和开放书架
▲靠近窗户位置留出楼梯收纳空间，弧形的定制书桌布置，角落开放书架可以放书和收纳玩具
▲靠近窗户刚好定制小的书桌满足孩子的学习，侧墙洞洞板，可以放一些装饰品
▲客厅阳台的一边原来是一个空调外机，砸掉以后，刚好利用起来定制了休闲卡座以及书柜，也是一个收纳和休闲的好地方
▲阳台的另一边定制石材台面，刚好洗衣机烘干机放置，阳台可以平时保持整洁
▲客厅与厨房半截墙分割，上方黑色折叠窗以及玻璃门，可以解决做饭时的油烟问题，同时保证空间的开放性，让客餐厅以及厨房整体放大
▲缩小厨房，靠南分割厨房，保证光线的充足。小白砖与蓝色厨房搭配，视觉更清新
▲卫生间干湿分离，干区半截墙小白砖与蓝色乳胶漆搭配，定制的浴柜白色与木色保持清新感。镜柜能满足收纳，保证干区的整洁干净
▲湿区同样采用黑色边框的长虹玻璃门，与干区隔断统一。墙面小白砖与地面灰色的对比干净整洁
▲砸掉原来的飘窗以后，卫生间淋浴区放大了，做了单独玻璃隔断END
