# 阳台仅能放洗衣机，多余空间做什么？2.3

有一种情况，就是阳台非常窄，空间可以放置洗衣机，但是又不能做洗手盆，剩余的窄缝空间又不好看，有什么好的办法处理，今天具体看看案例。

▲空间太小，索性只放个洗衣机，但是有空余空间，可以采用窄边的木质收纳架，一边可以放一些杂物，比如洗涤用品等，另一边刚好放脏衣篮，平时的脏衣服暂时收纳起来不至于太乱
▲空间小，洗衣机高度很高，如果做洗手池的话，非常小不实用，索性只放洗衣机，夹角刚好放置脏衣篮收纳临时的脏衣服。采用隔板的形式背后墙面做收纳处理，上方的简易晾衣架可以晾晒小件衣服
▲要容纳洗烘两个机器，本身不大的空间就更小了，如果包管道做台面，做一个小的洗手池有点浪费。索性管道不包空间还大一点，采用彩色油漆把管道变个颜色，视觉也好看，同时剩余空间还可以放置置物架，下方分层脏衣篮收纳脏衣服，上方简易的晾衣架，可以挂临时洗衣机拿出来的衣物，非常实用方便
▲阳台太窄，旁边还有下水管道，如果包管道空间所剩无几了，干脆整体定制收纳柜，连同管道一块隐藏柜子里头，只预留洗衣机位置，视觉更好看，储物能力大大提升
▲空间小，仅够放洗衣机，另一边是客厅的移门，而且包了管道以后几乎不可能在做洗手池，所以干脆只放洗衣机，旁边洗衣机与移门夹角网购的小推车，可以分层放置各种洗涤用品，上面墙面简单隔板摆放绿植，也挺温馨实用的
▲这种刚好容纳洗衣机的阳台，也只能这样去做了，上方吊柜尽量利用空间做了收纳，同时平时的洗涤用品也能方便拿取
▲阳台太窄了，只能放置洗衣机，内墙粘上挂钩，可以收纳清洁用具，外侧夹角简单脏衣篮，平时临时脏衣服可以暂时放置，不至于凌乱
▲露台空间无法封闭，只能放洗衣机，为了保护洗衣机，只能采用砖砌的形式去镶嵌，同时朝外顺便做了个拖把池，也不怕雨水进来了，台面上可以养一些绿植养眼
▲这个洗衣机位置利用了空调外机的位置，下方放置洗衣机和脏衣篮，隔板分层进行收纳，最上方直接装个小门，可以收纳平时不用的各种杂物。靠近窗户原木隔板还可以满足小吧台的功能，一举两得
▲空间非常小也可以镶嵌处理，只不过旁边夹角采用镂空隔板的形式，可以收纳各种洗涤用品了，台面可以养些绿植，养眼的同时还能看起来整洁干净
▲凹陷区仅仅容纳洗衣机，上方利用吊柜做了收纳，旁边管道包了以后，很小的空间，购买成品花架装饰兼顾功能，视觉也挺美观
▲空间小的话，可以采用定制柜的形式，把洗衣机镶嵌处理，中间镂空部位可以放置各种绿植或者摆件，整体整洁也美观
▲空间小就放一个洗衣机，旁边角落脏衣篮放置，洗衣机上方放置洗涤用品，简单实用为主
▲花架和洗衣机共存，同时花架兼顾洗涤用品的收纳，如果嫌凌乱，可以采用收纳盒的形式，平时洗涤用品放进收纳盒，视觉上能整洁一点
▲网购的洗衣机架，刚好容纳洗衣机，层板能收纳和摆放绿植，简单也实用
▲空间窄，家里刚好是上翻盖洗衣机，上方吊柜收纳，旁边窄缝刚好塞进折叠式晾衣架，也是不错的做法
▲空间窄，洗烘机叠放，同时定制收纳柜极尽利用空间，视觉上也能保持干净整洁，同时满足储物功能
▲露台空间，砖砌地台镶嵌洗衣机，同时采用防腐木定制收纳吊柜以及下方隔板收纳，满足收纳的同时保证视觉的整齐
▲洗烘机叠放，旁边夹角铁艺的置物架，可以收纳脏衣篮以及洗涤用品
▲客厅与阳台打通了，但是要放置洗衣机，采用定制收纳的形式分割空间，洗衣机夹角窄的收纳盒子放置，分区明确同时保证视觉干净
▲上方吊柜收纳，下方洗衣机放置以后，角落放置旋转拖把，也是不错的做法
