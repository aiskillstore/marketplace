# 90㎡小复式，一家三口的简单家

复式户型楼上楼下这是好多人过去的向往，同时楼上楼下分区明确，如果是两代或者三代人同住，不会被打扰。但是这样的复式除非面积很大，对于小户型的复式来说，不可能这样完美的。例如今天这套复式总面积才九十平，一楼才三十平左右，楼上六十平左右，这样的户型，一楼只能是公共区域，楼上是休息区，只是动静分离了，住一家三口可以，如果好几代人完全不适合了。半包8万。

▲一楼的原始图纸。进门就是一个开间，左手是楼梯和厨房，剩下就是一个开间。很明显这样的格局很难规划。作为一楼的公共区域，首先满足楼梯空间，第二满足餐客厅，第三满足厨房，三大功能要在如此小的空间施展，而且还不能影响收纳和光线，确实不太容易。

▲这是一楼的最终布局图。首先改变楼梯的格局，尽量腾出空间；厨房因为是开放布局，保持原来的样子，为了满足餐客厅的布局，在客厅与厨房之间利用新砌短墙的方式，既成就了电视墙，同时又成就了就餐区域；进门右手原有位置作为会客厅，同时利用拐角位置还摆放了孩子的钢琴。
▲这是二楼的原始图纸，楼梯上来右手分别是一个卫生间以及主卧，楼梯左手是小的儿童房空间，几乎全部是物尽其用，没有任何多余空间。
▲这是二楼的定稿图，为了让过道空间更宽敞，同时提升光线，移动了主卧的门位置，让过道通畅，同时卫生间墙体采用玻璃通透布局，提升采光；儿童房打掉室外机外机位置拓展空间，满足最基本的功能
▲进门右手客厅区域，利用进门口成品鞋柜布局，刚好分割角落的钢琴区；蓝灰色布艺沙发与圆几布局，空间轻巧开阔，角落铁艺的书架满足收纳；一副抽象彩色挂画与抱枕呼应并点亮整个空间
▲客厅的落地窗定制了收纳柜，铺上垫子，壁灯布局，凹陷区定制收纳隔板兼顾书柜，这里成了看书休闲的最佳场所，深得业主喜爱
▲空间小采用轻巧的家具搭配，可以让空间更明亮，极少的色彩点缀，提亮视觉亮度
▲音乐与书籍相伴，钢琴区单独吊线灯照明，简单摆件装饰，旁边铁艺的书架，坐沙发一个人看书，一个人弹琴，音乐和书籍氤氲幸福
▲晚上暖色灯光点缀，钢琴区非常温馨
▲进门左手就是楼梯空间，重新布局节省出更多空间，白色主体与木质的踏板以及扶手搭配，层次分明；新砌的收纳壁龛短墙刚好满足电视的镶嵌，把客厅与餐厨完美分割
▲楼梯的半成品与成品的对比，颜值非常高，虽然每天爬上爬下但是女儿非常喜欢
▲矮墙之后是开放式餐厨空间，采用白色与灰色大面积搭配，可以让小空间敞亮干净
▲电视隔断墙后面刚好镶嵌四人位的餐桌椅，朝向餐厅隔断墙壁龛设计，可以放一些小的零碎，另一面高柜收纳，玻璃柜门可以兼顾水吧台的功能
▲换个方向看餐厅空间，楼梯下方收纳定制，而且与旁边高柜相连，共同满足一楼公共区域的所有收纳
▲二楼楼梯上来右手就是过道，直对进入主卧，右手过道是唯一的卫生间，为了过道采光的通透，砸掉墙体，采用带花纹的喷砂玻璃代替，可以让过道采光提升，同时视觉上更开阔
▲卫生间统一采用浅色的石材瓷砖铺贴，单独的淋浴隔断分区布局，满足一家三口的生活
▲镜柜非常实用，可以收纳所有洗漱用品，让空间更整洁
▲主卧空间整体白色与灰色搭配，通透简洁，金色的吊灯提升质感
▲主卧外面唯一的生活阳台，布局了洗衣机以及晾衣区。背景一副火烈鸟挂画提亮空间视觉
▲白色的家具与灰色的墙面布局，床品与窗帘灰色素雅，鲜花与挂画点缀，让空间陡增温馨
▲儿童房空间非常小，定制了榻榻米床头，床头延伸，旁边书桌满足学习功能，侧墙衣柜布局。整体粉色系刚好满足女孩子的喜好90㎡两室三口之家，两个卧室都有衣帽间
