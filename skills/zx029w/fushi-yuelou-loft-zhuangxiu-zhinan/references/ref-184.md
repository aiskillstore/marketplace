# 90㎡两室两人，巧妙设计让空间通透明亮

两室空间，目前入住两人还有几只宠物猫，未来会是三口之家，偶尔老人也得过来短暂居住；空间上想最大化，收纳上想最大化，所以格局方面需要整体改造。
两室户型，空间上方正，而且实际使用率非常高，空间要显得宽松多了；缺点没有生活阳台，无法满足基本的洗烘机布局；想要更多的收纳和空间的通透也相互矛盾；设计后的布局图，调换原有客餐厅位置，实现了空间的开阔，同时砸掉原有封闭厨房，采用玻璃代替墙体满足封闭油烟的需求，视觉上放大了整体空间；为了实现超级收纳采用一面墙的收纳柜定制，同时利用进门直对空间打造进门收纳，兼顾了进门的玄关；为了解决没有生活阳台的问题，扩大了唯一的卫生间，拓展空间以后，满足了洗烘机的布局；进门直对定制玄关柜，同时满足鞋柜的收纳，局部镂空满足进门视觉空间的通透；大面积白色可以让整体更清新，同时放大空间视觉感受
