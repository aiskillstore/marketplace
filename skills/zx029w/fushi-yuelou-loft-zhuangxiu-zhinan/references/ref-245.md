# 85㎡旧房改造两室变三室，还成就超级收纳

业主购买旧房二手房目的就是现房，而且没有后顾之忧，不用担心开发商跑路，也不用担心期房压根不知道房子长什么样子，而且周边设施资源都可以一清二楚。

▲原始样子，非常破旧，而且光线也昏暗，所以需要重新砸掉，重新根据现有格局进行规划

▲入门就是厅，而且厨卫在一个区域，两室空间，客厅带一个小的阳台满足采光；格局中规中矩，户型本身小，不做改变，整体显得压抑而且完全满足不了业主的入住要求

▲设计后的效果，两室变三室功能，砸掉原有次卧以及厨卫墙体重新规划，让出餐厅空间，同时成就一个小书房空间，还实现了卫生间干湿分离，进门视觉豁然开朗，同时扩大客厅阳台成就一个明亮的次卧功能

▲原有的次卧以及厨卫墙体内退，成就厨卫之间的餐厅空间，同时让进门口豁然开朗

▲厨房墙体内退以后，进门左手刚好实现洗烘机的布局，同时实现了进门的鞋柜收纳

▲腾出餐厅空间，可以让客厅更显宽敞，进门视觉也能豁然开朗，背景局部牛油果绿延伸点缀，搭配暖黄色吊灯，让空间更具时尚活力

▲厨卫地面分别采用六边形瓷砖与木地板无缝衔接，让视觉更生动

▲客厅的小阳台朝向客厅拓展空间，同时为了采光需求，采用玻璃门以及上方玻璃窗的形式，用来保证客厅的采光需求

▲平时打开主卧门同样可以满足通风和采光的需求
▲客厅比较简单，统一雾霾蓝的墙面变色，简单布艺沙发搭配同样木质茶几，满足平时的基本会客即可
▲这个角度可以看到书房空间，缩小了原有的次卧，满足一个小书房的布局，同时采用玻璃移门布局，引光入室，而且书房与卫生间之间还成就了干区的功能
▲书房内部，空间不大，一边书桌一边书柜，满足平时单独的办公需求
▲书房的窗户下原木书桌布局，刚好满足自然光下办公和学习
▲主卧空间比较简单，原木与大白墙的搭配，单独做了窗帘盒布局
▲同样雾霾蓝的窗帘清新搭配，背景简单挂画与壁灯满足功能和装饰
▲原木家具统一搭配，与大白墙对比，简单实用
▲简单吊顶以后，移门衣柜满足基本的收纳
▲正午阳光可以让主卧更亮堂，更温暖
▲客厅阳台扩大以后，榻榻米定制，实现一个次卧功能，而且南向光线非常充足
▲与客厅局部玻璃隔断设计，引光入室，让空间采光更通透
▲厨房缩小以后，刚好满足L型布局，门口满足小冰箱放置，基本的功能需求得到满足
▲改变卫生间入门，利用原有次卧的空间，实现了干区布局，而且书房玻璃移门让光线更加通透
▲湿区空间，淋浴简单隔断分区，更好打理，满足功能性
