# 一楼40平挑高夹层房，瞬间高大上

◆入户门进来右手设置开放式厨房，因为是下沉的，进客厅要上台阶

◆靠厨房一面墙用了白色格子瓷砖，看起来干净简洁

◆这是打开卫生间门的角度

◆上来客厅，通铺浅木色地板，与厨房紧挨放了简易钢木小桌作为餐桌使用

◆一个陈旧的柜子，镶嵌上镜子，然后重新做了清漆处理，就成了电视柜

◆北欧简约的沙发和茶几，能看到夹层的楼梯

◆这是整体空间，做了夹层楼上可以住人

◆楼梯下方作为储藏室使用，百叶木门尽量体现淡色木制

◆这是门厅位置，做了木色假梁处理，地面拼花瓷砖

◆楼上夹层空间，位置很小，所以可以直接打地铺入住

◆卫生间就在厨柜对面，格子瓷砖

◆超高超大窗户，后面带个露天花园

◆这是露天花园的设置，白墙青砖，地面菱形仿古砖
