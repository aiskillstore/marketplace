# 强弱电、全屋WiFi和网线怎么提前规划？为什么入住后到处信号差、智能设备连不上、插座不够用？

路由器放哪，水电阶段就要定。 好多业主装修水电事无巨细，但往往忽略一个重点：路由器放哪。如果路由器放到弱电箱，信号本身就被铁箱屏蔽了一部分，在最远的卧室信号非常弱。正确的做法：网线必须从配电箱到电视位置，电视位置有路由器，从电视位置再引网线到卧室，这样才是合理的线路走法。做水电的时候，记住告诉电工路由器放哪，否则后期入住是无法改变的。

信号差，90%是水电阶段没留网线。 家里总有几个房间WiFi信号弱，网速卡顿、卧室刷视频掉线，大多都是装修前期没规划，水电阶段不留网线、不提前布局，后期再多放大器、信号增强器都是治标不治本。

小户型用单路由就够了：光猫放弱电箱，客厅电视位置放路由器，从光猫到路由器两根网线，一根给路由器一根看IPTV。穿墙能力差，墙体一多距离一远信号直接衰减，不适合大户型。

大户型选AC+AP面板：光猫到AC一体化主路由，再通过预埋网线到各个房间AP面板，网线直供电源不需要单独供电，全屋信号均匀无死角。前提是水电阶段全屋预埋网线，造价偏高一步到位。

Mesh组网最灵活：有线Mesh从主路由到各房间子路由，信号更稳定；无线Mesh子母路由之间无需网线，成本低适合大部分刚需户型；混合组网重要房间用有线，其他用无线。

如果拿不定主意，预算充足的话，水电阶段一定要全屋预留网线，不管后期选哪种方案，有网线就有选择权。拒绝劣质信号放大器，延迟更高。

智能设备连不上，零线和网关是命门。 北方新交毛坯房，几乎所有开发商原有开关都没有零线。单火智能开关价格还贵，后期会不断出现频闪、关灯微亮、失灵甚至影响寿命，想改有的必须重新开槽，返工成本非常高。一定要在水电改造的时候穿上零线，一定告诉电工后面用智能开关，必须零活线都有。网关不要放进金属盒子，非常屏蔽信号；网关最好放置开阔地方，以客厅空间为主，没有任何遮挡物以及密闭空间。网关选支持Zigbee3.0、Matter协议的，断网也能正常用。智能开关优先选离线可手动款，关键区域一定要留物理备份，断网断电也不慌。

插座不够用，是装修前没按电器规划。 开关插座布置应依据房间用途、主要电器家具位置及家人生活习惯来确定数量与位置。电动窗帘、智能马桶、扫地机器人、电动晾衣架一定要在装修时候留好电源。电动窗帘插座位置要确定好窗帘盒大小规格；智能马桶电源位置最好先看好马桶按规格预留；全自动扫地机器人一定要隐藏预留水电位置，保证后面安装不会露出明线。
