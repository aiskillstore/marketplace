# 新中式，新轻奢，80m²跃层轻松演绎

我们对装修其实要求简单，一个喜欢现代北欧风，一个喜欢带点中式的，还好，厉害的设计师直接做成中式轻奢的感觉，满足了一家人的要求。
▲一层原始图纸。没有单独门厅，阳台分割客厅，客厅很小，大卧室的门在电视墙毁了完整性。厨房很小，次卧很小带个阳台格局非常不好。一个客卫虽是干湿分离但是不通畅，功能也得不到满足。
▲我们的要求是一楼是会客厅和一间大卧室，一定客厅通畅，餐厨很大，最起码的格局得让人舒服，还好，我们家几乎所有墙体都可以砸掉改动。设计师非常厉害，彻底改变格局。
1.客厅与阳台打通拓展整体空间，同时改变大卧室的门，让电视墙完整。2.原来的小卧室以及阳台和厨房彻底打通，让空间彻底开放，同时改变客卫格局，实现镶嵌冰箱的功能，把唯一的客卫做成了大卧室的主卫。总之这个设计让人非常惊讶
▲二楼的原始结构。和一楼格局几乎一样，非常混乱，格局让人压抑
▲二楼设计比一楼复杂，但是有了一楼改动的先例，就好办多了，把多余的都砸掉畅通设计，只保留两间卧室满足功能，其他区域几乎都做开放设计
▲一楼进门玄关，利用楼梯下方镶嵌鞋柜，白色与木色生动套色，镂空台面石材装饰，与地面大理石瓷砖呼应。原始直对卫生间的地方改造成了玄关拐角，一副中式字画简单点缀。有中式的稳重，又有现代的时尚与质感
▲这个角度可以看清鞋柜的做法，利用楼梯间，而且在第一个踏步之上，石材延伸，鞋柜最下方高于地面，进门放鞋更加方便。经过过道就是我们砸掉所有墙体的超级大的开放式厨房以及餐厅空间，两扇大窗户光线非常通透，同时更显大气
▲进门右手的客厅全景，通铺大理石暖色瓷砖，打通阳台以后空间得以拓展。线条感极强的简单吊顶，局部钛金条与金属家具的点缀，突出轻奢质感。皮质的橘色沙发以及窗帘的跳色，让空间更生动明朗
▲沙发背景中式山水壁画以及金属线条勾勒，突出中式的时尚现代感。侧墙同样中式现代挂画点缀
▲沙发背景壁画细节，金属线条的勾勒，有中式韵味，又有现代的时尚
▲三人位沙发与轻巧圆几搭配，空间更宽敞时尚。电视墙KD板与石材的冷暖色协调，质感硬朗。落地电视柜延伸视觉，同时石材的装饰延伸增加空间的纵深感
▲皮质休闲单椅阳台放置，延伸客厅的功能区域，旁边拐角收纳柜与墙面平齐，格局保证完整统一
▲另一边的餐厨空间，原来的格局砸掉彻底开放式设计，视觉空间都非常完美
▲中厨西厨整体延伸融为一体，功能视觉更大，餐桌居中放置，侧墙整体餐边柜套色收纳
▲一楼大卧室全景，木地板与窗帘视觉延伸，床品与墙面乳胶漆呼应，背景深灰色硬包金属线条的局部勾勒形成中心点，无主灯视觉的简洁，非常有层次感。改变格局以后原来的客卫成了主卫空间
▲一楼卫生间灰色石材瓷砖搭配，定制浴柜，同时新开窗户与主卧视觉通透，卫生间门局部镜面设计，视觉上拓展狭小空间
▲一楼卫生间全景，灰色瓷砖搭配素雅质感，角落淋浴房设计
▲二楼空间，因为是斜顶格局，所以设计比一楼难多了，把原来多余的隔墙全部砸掉，让公共区域更宽敞，视觉上减弱斜顶的压抑感。金属与玻璃结合的楼梯扶手，北欧分子灯的轻巧时尚，突出现代元素
▲楼梯间墙面冷咖色素雅质感，两幅中式字画点缀出中式韵味
▲二楼全景了，两间卧室一个卫生间，大卧室因为上楼梯直对，索性改作了玻璃墙体直接通透，视觉更宽敞，同时大卧室视觉更通透，平时拉上帘子可以保证隐私
▲楼梯整体采用黑色金属扶手与通透玻璃结合，视觉上更加通透敞亮
▲二楼卧室空间，为了视觉空间通透，局部玻璃墙体可以看到楼梯空间。背景简单中式山水壁画突出中式韵味
▲床对面通顶衣柜镶嵌收纳，白色平板简洁清爽
▲楼上次卧空间兼顾书房功能，因为斜顶格局，所以非常难设计，只能用大白墙减少视觉压抑。榻榻米定制，借用斜边做了收纳柜，旁边简单书桌满足功能
▲二楼卧室带的生活阳台，洗衣机烘干机放置，平时晾衣服也在这里
▲二楼卫生间干湿分离，斜顶空间，所以局部马赛克铺贴，定制浴柜，不规则镜子刚好与不规则格局呼应协调
