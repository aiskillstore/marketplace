# 80㎡二手斜顶复式，成就小夫妻新房

二手斜顶复式，比较破旧，为了满足小两口新房的需求，比如重新拆除装修。
▲没有拆除之前的样子，比较老旧，格局也不是很好，楼梯位置让空间更加拥挤不堪▲原始结构，原有楼梯在餐厅处，导致餐厅空间非常拥挤；厨房狭小，被小阳台分割空间；客厅推拉门也导致光线和空间逼仄；楼上因为是斜顶区域，所以空间比较浪费，而且客厅挑空地方过小，整体光线视觉比较压抑▲设计后的布局图纸，改变楼梯的位置，把楼梯放到了客厅空间更大的位置，砸掉封闭厨房以及小阳台，实现了更加开阔的餐厨一体布局；一楼两间卧室平窗户朝外拓展，增加采光以及面积；砸掉二楼的多余楼板，加大客厅挑空面，提升整体采光▲楼上加大了挑空面积，让客厅挑空面积增大，提升了整体光线；移动楼梯道客厅区域，延伸楼梯让整体上下踏步高低延缓；楼梯下方满足一个杂物间的收纳▲楼梯以及二楼平台整体通透玻璃扶手，可以让空间视觉更开阔；移动楼梯实现了餐厨一体的开放布局，扩大面积的同时让整体采光发挥最佳▲拆除阳台推拉门，与客厅打通空间，让楼梯有了延伸，同时扩大整体公共区域的采光和面积▲客厅全景，借用楼梯成就电视墙，下方木质的地台与踏步一体延伸，可以满足置物；阳台一边洗烘机满足基本的生活所需，放上休闲椅也可以满足平日的休闲▲楼梯下方成就一个储藏空间，隐形门设计，刚好直对入户门，兼顾了玄关作用，进门右手墙面异形全身镜满足功能▲奶咖色柔软沙发可坐可卧，搭配棉麻地毯，整体柔和色彩搭配温馨活动空间▲全景空间，整体浅色系搭配，打通空间，让空间更开阔，同时光线更加通透▲楼梯移动以后，餐厨一体化设计，满足功能空间得到最大化提升；利用次卧的凹陷区实现了卡座的功能定制▲左侧高柜满足冰箱以及蒸烤箱的镶嵌，同时满足更多储物▲一楼主卧素雅咖色乳胶漆变色，简单布局满足功能▲侧墙衣柜定制满足基本收纳▲二楼卫生间干湿分离布局，木质的浴柜满足收纳
