# 120平复式地中海，业主自己设计，设计师哭了

这款地中海风的家装，整个的以黄色为主，加上一些带有做旧色彩的家居，从而营造了温馨舒适感。而多处墙上各式曲线感的设计，有很好的展现了地中海风格特点，很是别致客厅中这边电视背景墙以咖色的带有褶皱感的墙面为装饰，外加淡黄色乳胶漆刷至而成的拱的设计，很是别致。下面则是放置着清晰线条的白色原木橱柜，搭配上咖色原木面，简易而自然。

客厅顶面以白色乳胶漆刷至而成，充满曲线感的顶面设计很是别致，中间则是以带有做旧色彩的黑色铁艺吊灯为设计，自然而充满古典之感。

客厅中放置着清晰线条的米色布面座沙发，看上去简洁而柔软舒适。沙发的背景墙则是以蓝色与暗金花样的壁纸为铺贴，充满着浓浓的古典之感。

这间是楼上的客厅，这边放置着以自然的原木为框，家蓝色条纹的地毯设计的座沙发，浓浓的清新海洋之风。淡黄色乳胶漆刷至的背景墙上有着玄关设计，多面则是书房样式，很是寂静闲适。

餐厅
从这边可以看到，客餐厅是在同一个空间区域中。圆形的餐桌以白色的自然原木为框，搭配上棕色的原木面，多彩的座椅，闲适而多彩感。

餐厅里面的一面墙整个的以多彩小块瓷砖以马赛克的形式为装饰，整个墙面精致而华美。墙上则是镶嵌着黑色镂空雕花的壁镜，整个情面精致。

卧室
卧室中放置着简约的白色原木四柱床，一种贞洁雅致之感。床头的背景墙则是以深蓝为底，加金色花样的精美壁纸为铺贴，很是华贵大气。

卧室的四周墙以米色为底加卡通图样的壁纸为铺贴，加上其他多处的卡通图样，整个充满着浓浓的儿童梦幻世界。

厨房
厨房的顶面以自然的横条原木为装饰，清晰线条的白色整体橱柜，搭配上黑色纹络状的窗台板，简约而自然。墙上则是以复古式瓷砖以斜铺与垂直的两种相结合的方式，是整个墙面因此丰富而多彩。
