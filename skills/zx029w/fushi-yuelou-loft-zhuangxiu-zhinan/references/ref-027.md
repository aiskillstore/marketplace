# 水槽周围空间不浪费，这样做更实用10.14

水槽家家户户都有，而且也是厨房中使用最频繁的地方，对于寸土寸金的厨房来说，能提高空间利用率就是空间的价值，例如水槽四周的随手空间。关于水槽下方收纳，可以参考这篇《厨房储物，挑战一下水槽下方的收纳》
如图水槽上方是吊柜，利用吊柜下方安装一个可以伸缩的拓展板，可以拉上拉下，这样就可以很方便随手放置各种物品。水槽收纳架，这个对于小户型厨房来说非常实用，重在收纳，而且可以分类，刚好在水槽上方也不用担心沥水问题。水槽背后是窗户的话，而且是推拉窗，有窗台空间，这种收纳架可以直接放到窗台上，不占用空间，也不影响窗户开启，同时不影响窗户采光顶部可以放锅具中间可以放碗，碟，筷子🥢杯子底部可以插刀具，✂️，抹布钩子挂旁边可以收纳电线也可挂抹布对于我这样的小户型妥妥多了一个柜子空间万物上墙，对于水槽背后的墙面也适用，一个多功能挂杆就可以实现垂直空间的合理利用如图水槽背后是推拉窗，此时可以采用洞洞板定制，满足窗台的随手挂件置物，也是合理利用空间的做法《家居收纳，厨房洞洞板利用》如图所示水槽背后是实墙，而且无法做吊柜，此时可以采用免钉的洞洞板，实现物品的分类收纳，完美实现了垂直空间的合理利用厨房水槽上方的升降吊柜，下方还带沥水功能，升降方便收纳，也可以隐藏到吊柜里头，但是这个适合大户型厨房，比较喜欢高科技的家庭，因为空间并不合理利用，而是浪费了水槽背后的垂直墙面。更简单的做法，如图所示，直接利用窗户一根挂杆即可满足水槽旁边的随手收纳，简单实用；购买两头可以支撑固定的挂杆，刚好顶到窗户两侧即可，拆卸也非常方便如上图，好多户型水槽上方刚好是燃气热水器，此时吊柜也作不了，旁边还有窗户采光需求，此时采用隔板满足一部分垂直空间的收纳，同时挂杆也可以满足随手的悬挂收纳，隔板下方还可以安装充电感应灯，满足夜晚的操作，同时合理利用了空间实在没有空间，水槽左右只要有空间，就可以采用这种窄的水槽架，带沥水功能，刚清洗的碗碟可以随手放置，不用担心有水了如图左边沥水架，垂直空间都利用上，水槽四周没有一点浪费如果水槽背后墙面太薄无法满足吊柜的定制，此时可以采用开放的金属搁架，满足储物收纳，也方便拿取，也是可以满足大大量厨具收纳，下方紧挨台面位置可以充分利用垂直空间
即使水槽上方有吊柜，也可以给吊柜下方加一层窄的层板，随手物品就可以放置，而且隔板下方空间也可以采用挂杆满足垂直空间的利用精装修厨房窗户非常小，窗台也窄，采用木板加宽窗台可以置物，上方挂杆可以满足更多垂直空间的利用即使水槽在角落靠窗户，也可以采用隔板以及挂杆满足水槽背后垂直空间的利用。而且隔板都是免钉安装，自己都可以动手操作水槽侧墙如果做吊柜碰头而且空间很小，此时一定不要错过免钉的隔板，不用打孔，直接沾上，放上隔板即可满足好多物品的收纳，比吊柜更实惠洞洞板定制安排在水槽上方，颜值在线，实用性在线，可以把小工具们收纳得整齐有序 方便拿取如图利用窗台采用伸缩置物架，可以满足水槽四周的随手收纳
