# 110㎡顶楼LOFT，打造6口之家

顶楼的LOFT结构，一二楼分别各有一间卧室，厨卫在一楼，这样的原始结构，几乎不可能实现6口之家的入住--屋主两人，双方父母过来，以及孩子的独立空间。原始照片，虽然楼上楼下，空间都非常狭小一楼原始结构，进门虽然是厅，但是集合了客餐厅以及楼梯空间，非常拥挤，朝南卧室带阳台；北向分别是厨卫以及一个很小的生活阳台。一楼设计布局图，改动如下：1.砸掉厨房外头生活阳台，厨房北移，腾出一楼餐厅空间；2.砸掉一楼卫生间实现干湿分离，同时实现进门的鞋柜定制收纳3.借用楼梯下方做了进门的隔断柜，一边设计卡座满足客厅使用，采用投影满足偶尔的娱乐功能；实现了整体空间的动线的合理化
二楼的原始结构图，因为是顶楼，顶面有斜面结构，就导致层高非常低，而这样一个空间需要实现三室一卫的布局以及必要的收纳储物。二楼的设计布局图，改动如下：1.原有楼梯挑空处混凝土浇筑，拆除局部墙体，重新布局，满足一个干湿分离的卫生间以及一间小的儿童房空间2.利用北向空间，同时利用斜顶结构，满足了一个储物间，同时这里可以兼顾次卧功能；主卧带阳台满足一个明亮的卧室以及足够的收纳空间一楼进门空间，左手满足了镶嵌鞋柜的收纳，同时满足换鞋凳功能；借用楼梯旁边实现了储物柜，上方镂空满足过道光线的需求客厅楼梯旁边的隔断储物定制，既满足了客厅的隐私，又能拓展收纳，同时镂空的收纳架满足光线的通透一楼通向主卧的过道，镂空的置物架满足采光，同时满足收纳，实现合理动线置物架背后定制卡座，北向采用圆洞隔断满足空间的划分；整体原木色与大白墙的搭配，可以让小空间满足功能的同时，更温馨简洁隔断圆洞的设计，简单，但是可以更有意境，刚好透过圆洞看到客厅楼梯，视觉更通透空间有限，刚好利用楼梯北侧，进门置物架后面，定制卡座，原木茶几布局，就可以满足一个很小的会客空间楼梯下方满足超级收纳，高区开门位于主卧门口，低区收纳面向客厅，互不打扰北边餐厅看客厅，客厅两扇窗户满足基本的采光，百叶帘通透又显得高级，窗户上方明装投影幕布，可以满足晚上偶尔的娱乐客厅看向北边的餐厅以及厨卫；干湿分离以及厨房玻璃门都可以满足采光的均匀，同时动线更加合理，餐桌伸缩款式可以满足更多的人的同时就餐

主卧过道看餐厅，定制白色与木色搭配，又与木地板呼应，简洁清爽伸缩餐桌搭配白色吊灯，又与白色餐椅呼应，拉伸开来可以满足五六人同时就餐，平时收纳起来不会破坏整体空间比例以及合理的动线
餐桌北边刚好满足冰箱的放置，厨房通透玻璃折叠门，保证采光的明亮以及视觉的通透厨房明亮的小白砖搭配同样灰白色的橱柜，L型布局满足基本的烹饪需求鞋柜背后的卫生间干湿分离，干区采用绿色的防水漆涂刷，视觉更有层次，同时满足清新感湿区采用与厨房相同的瓷砖，让空间更简洁，同时黑色的隔断，满足功能分区和好打理楼梯空间太小，采用错步处理，满足小空间同时满足上下楼的舒适；指接板的木质踏板搭配白色简洁扶手，整体色调一致楼梯间非常简洁，一盏双控开关的壁灯满足楼梯间基本照明二楼挑空位置现浇以后，成就的一间榻榻米收纳兼顾的儿童房，玻璃门可以引光入室，同时朝向楼梯间增加了一扇透光窗，可以满足楼梯间的明亮榻榻米满足收纳，靠内升降桌可以满足孩子学习，上方开放书柜满足书籍收纳儿童房玻璃门外就是干湿分离的卫生间，走廊动线非常小但是够用，而且儿童房玻璃门可以满足走廊的正常采光需求二楼主卧带阳台，朝南空间，光线非常充足，左手是主卧的储物间收纳主卧北向很小的空间，斜顶区域，定制收纳开放柜，满足二楼独立的储物间功能，关上门可以让空间显得更整洁主卧利用床尾实现衣柜和双人书桌的布局，阳台玻璃门分割空间衣柜和书桌一体定制，保证空间整洁，同时满足收纳和平时的办公所需背景墨绿色层次做法，提升空间立体感，满足业主需要的复古韵味；床头金色的摇头壁灯营造氛围感主卧阳台两边收纳柜定制，承载更多收纳功能，百叶帘通透，平时也可以满足休闲二楼最北边是斜顶区域，打造收纳区，同时可以满足临时的次卧功能斜顶天窗满足了采光和通风需求，四周地柜开放满足一定的收纳，随时放上床垫，这里可以充当临时的次卧功能一楼主卧相对简单，原木家具搭配，与生活阳台通透玻璃门分割一楼生活阳台满足平时的洗衣服以及晾衣服功能；不贴墙砖，百叶帘视觉空间更通透简洁阳台另一边同样定制柜，满足家里更多的收纳
