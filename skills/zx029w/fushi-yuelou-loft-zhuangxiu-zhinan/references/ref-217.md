# 40㎡小复式功能空间大改造，得服气！3.4

装修信息——面积：40㎡；风格：混搭工业风；装修费用：硬装5W、软装7W；装修时间：3个月 ；

户型再好，空间如果不好好利用，也会变得索然无味！

改造前房子是一个40㎡的小复式，本来非常有意思的户型被不知所云的空间设计搞得乱糟糟的。厚重的楼梯挡住了客厅唯一的采光，搞得室内的有点暗。楼梯下的餐厅用起来也很别扭，站起来的时候容易碰到头。

书柜墙+沙发的书房居然没有桌子，用电脑或者是写点什么都无法实现。室内虽然有窗户，但是整体采光并不理想。

一层卫生间有点杂乱无章

二层的过道有个小衣帽间，地方不够大，结果楼梯变成搭放衣物的地方。穿衣镜的位置也是很不安全，多后退几步就很容易踏空到楼梯下。

加阳台，本来是个很有情调的设计

可惜阳台只是用来晾晒衣物

储藏室也没有什么实际利用价值，阳台这么用真心是浪费！

主卫设计还挺前卫，只是空间小透过玻璃看到的杂乱的画面。洗衣机放在这儿，看着也是不伦不类的。

空间做了重新的规划。重点是合并整合空间，书房的墙被拆掉了，通透的房间不仅显大，采光也会好很多。

拆除了楼梯的外层装饰后，露出的钢骨架超级有型且非常轻盈，省得定制安装了，加上直通二层的文化砖墙工业味儿十足。

改造后的会客区&客房，原来书房的位置改为客厅兼客房，通透的空间非常明亮。餐客厅之间加了一道帘子，如果有客人留宿的话，可以增加私密性。

就餐区&阅读区，一整面书墙收纳了屋主大量的书籍。餐桌也是书桌，一个空间下实现了两个功能。从楼梯处看向餐厅及书房。屋里从地板到家具都是实木，但是用了不同深浅层次的木色加以区分，增强了视觉感。

咖啡角。

楼梯下面有大好的阳光，一圈实木柜打造了一个咖啡空间。晒太阳喝咖啡，多美啊！

楼梯，楼梯的踏步填充了水泥，在没干透之前嵌入了马赛克。女主人是双鱼座哦，每隔一个踏步都会有一对小鱼，这个diy的地方深受女主喜爱。

收纳区，二层楼梯过道被充分利用起来，做了L型的收纳衣柜，挂了厚厚的布帘，不仅防尘，看上去还美观。穿衣镜挂在卧室墙上，一个天然衣帽间就出现了。

卧室，卧室与楼梯之间的墙体拆除了做了通透假窗，卧室及楼梯就更加明亮了。卧室重新吊顶，由于层高有限安装了筒灯照明。房间很小，没有放其他家具，在床头两侧安装了壁灯，由男女主人分别控制，互不影响。

一层卫生间只有2.1m²，并且没有窗户，为了更加明亮选择了白色哑光墙砖，地面铺了好看的花砖，增加了收纳空间。

二层卫生间，把原本放洗衣机的空间合并进来，做了淋浴区。马赛克铺装的挡水台，好看又便宜，虽然没有做到干湿分离，但是洗澡水也不至于流得满屋子都是。

阳台刷了暖暖的橘红色，木质地板超级有感觉。小俩口坐在吧椅上可以晒太阳，也可以看星星。储物箱加了垫子，可以当做躺椅。

木质窗台像一个吧台一样，临窗观景真是美美哒！

之前的储藏室做了洗衣区，墙壁拆除后装了小篱笆栅栏。收纳洗涤用品的柜子台面正好可以用来熨烫衣服。

从卧室望向阳台，房君好喜欢这个小阳台！
