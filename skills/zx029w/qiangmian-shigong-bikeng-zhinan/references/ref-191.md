# 一分钟鉴定乳胶漆好坏，太准了！！9.24

一看看有无沉淀、结块现象。放一段时间后，正品乳胶漆的表面会形成厚厚的、有弹性的氧化膜，不易裂；而次品膜很薄、易碎，具有辛辣气味

二闻闻有无发臭、刺激性气味。真正环保的乳胶漆应是水性、无毒无味的

三擦可将少许乳胶漆刷到水泥墙上，涂层干后用湿抹布擦洗。低档水溶性乳胶漆擦十几次即发生掉粉、露底现象，优质涂料则不会

四摸用木棍将乳胶漆拌匀，再用木棍挑起来，优质乳胶漆往下流时会成扇面形。用手指摸，正品乳胶漆应该手感光滑、细腻

【环保目前那就是屁，得有，但是和屁一样不靠谱】
乳胶漆的环保性能可以忽略不计。只要市面上正规销售的产品，在国内不论你是一百一桶还是一千一桶，乳胶漆的环保标准都是一模一样的。举个例子，如果国家环保标准以0为环保，负数为不环保，当然高于0就更好了，但是要想产品高于0，你的生产成本就会很高，如此高的成本你就得用更高的价格来支撑，请问作为中国商家，还有竞争的优势吗？早都关门大吉了。所以，在国内，乳胶漆都是一个标准，价格不一样，宣传不一样，那只是一个手段而已。退一万步，你侥幸买到了环保产品，但是只是说明你买的乳胶漆单位面积的污染物不至于损害你的健康，但是现实是我们的房子面积不一样，用的多少不一样，想要环保，这是天方夜谭，除非不用，没有任何办法。
