# 不懂行，直接批腻子，全裂了12.21

收房的时候先看看自己家墙面的情况，你如果不懂，可以多叫几家装修公司来量房，反正量房都是免费的。

设计师看到墙面就会给你讲解，然后业主综合几家公司的讲解，大概就能知道自己家墙面的情况了。如果设计师进房压根不谈墙面实际情况，要不不懂，要不故意不说后期加项，这样的公司选不选已经很明显了。

同时，你也知道了哪家设计师是行家，哪家设计师是外行，也能间接的把几家装修公司逐一淘汰了。

这才是比较装修公司、同时也是自己学习的最佳机会。而不是一门心思看哪家价格低，忽视基本常识，尝到苦果以后乱喊乱叫。

房子在中国不仅仅是纯粹住所的功能，某种程度上反应了人在社会中的经济能力，同时也间接体现出一个人的头脑价值。---------在这个前提下，你装修房子只看低价，最后被坑然后歇斯底里，只能说明自身的能力和智慧是有水分的。

第一种情况，墙面是否刷白，如下图：

▲收房以后发现你家新房是上图的模样，不要高兴，你该哭。不要以为你的开发商多好，为你着想把家里弄得干干净净。

开发商刷白的做法只是迎合中国人的虚荣心罢了------只看表面不管内质。你高兴只能说明你不懂行，到时候装修的时候就会有两种可能：

1种可能是你找了个良心公司，给你说这个白墙需要铲除掉，然后涂刷胶或者界面剂，才能批腻子，但是得有费用。你的反应可能是价位过高，不考虑这家公司。

2种可能是你找了家烂公司，直接上门就说这个不需要铲除，直接可以批腻子。你心里一暖：多贴心的公司，这么替我省钱。于是签合同施工了，等你没有入住，或者刚刚入住不久，你家墙面开始出现不同程度的裂纹，甚至顶面墙皮大面积脱落，这下你会被吓傻，然后急匆匆打电话给装修公司，人家说这个当时为给你省钱就没有铲墙必然会掉，不省钱怎么能让你低价签合同呢。于是，你欲哭无泪，可是你并不知道你已经伤害了第一家让你铲墙的装修公司了，你并不知道一个商家的变坏就是这样来的，不多久，第一家装修公司就开始效仿第二家装修公司，于是乎，遍地都是坑人的公司，都是低价钓鱼的公司，烂工程遍地。谁之过？

收房墙面刷白的解决办法，必须铲除以后，涂刷胶水或者界面剂以后再批腻子。你不懂，不铲除，价格低了，后期还得全部铲除，否则后患无穷。

第二种情况，墙面是否光板墙，如下图：

▲一般开发商房子几乎都会有混凝土墙面，收房的时候注意查看，如果是，这种墙面是不能直接批腻子的，必须刷胶或者界面剂，当然这都是费用，替你着想的费用自然高，你必须讲道理，否则只能被坑。

替你想的你说人家宰你，不替你想的直接批腻子给你留后患，你还以为好人替你省钱呢。自己千万不要昏聩，否则既伤害了好人心，自己还得承受严重后果。别人是一箭双雕办好事，你是两败俱伤坑自己。

第三种情况，墙面是否有素灰，如下图：

▲和开发商刷白同理，都不是为了替你着想，而是中国人对房子的重视让人害怕，开发商只能用素灰掩盖本来可以忽略的表面不平整和局部小裂缝。

收房的时候如果发现素灰墙面，建议用钥匙或者坚硬的物件划一下，如果局部掉块或者发现素灰层很容易脱落，这样的墙面在装修的时候就必须铲除掉了，有的素灰太薄人工铲除无法铲除干净，就得使用角磨机打磨，然后刷胶或者界面剂以后，再次进行正常批腻子施工。

第四种情况，墙面是否有施工洞接缝，如下图：

▲施工洞几乎在任何楼盘都存在，开发商前期浇筑混凝土墙体的时候，为了整栋楼施工方面，保留的施工通道口，后期施工完毕会用轻质砖或者红砖封堵。这个就造成砖墙与混凝土之间有缝隙，高层不同程度的沉降以及材料的热胀冷缩，两种材质的墙面始终有裂缝存在。

如果收房发现这个情况，后期施工必须先贴布处理或者用网格布处理，然后再进行施工腻子，否则后期接缝处必然裂缝。
