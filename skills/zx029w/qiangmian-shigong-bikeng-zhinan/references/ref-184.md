# 不想要哑口套，乳胶漆便宜而且好看11.20

垭口套作为过去老时代的产物，现在基本是能不做就不做，除非是需要收口。

▲最常见的就是阳台墙面贴了瓷砖，导致与客厅之间垭口不得不定制哑口套，不仅框架让空间更复杂，而且浪费钱；正确的做法是能不贴砖就不贴砖，压根不需要任何哑口套，乳胶漆直接过渡，空间更大更清爽，也实惠《生活阳台照样乳胶漆，不贴砖，有人这么干》

▲客厅与阳台打通，也不用贴墙砖，更不用红砖包管道，采用定制即可满足管道的隐藏，同时垭口乳胶漆与客厅同色延伸，不仅省钱而且空间更简洁，更宽敞

▲如果嫌乳胶漆过道垭口单调，也可以采用单边弧形的做法，让垭口更生动，同时整体提升空间的丰富性

▲根据空间需求以及整体搭配，垭口拱形可以更加多样化，用最实惠的方式提升空间档次

▲如果感觉乳胶漆没有层次立体感，也可以单独把垭口变色涂刷，如上图所示，视觉上不仅有了层次，同时立体感更强，比累赘又费钱的哑口套要实用多了
▲如图所示垭口采用墨绿色的乳胶漆涂刷不仅有立体感，而且与其他区域呼应延伸，整体空间变得更丰富▲同样如图所示拱形窗户与垭口呼应，同时采用粉色乳胶漆涂刷立体感▲如图的干区垭口，不需要定制垭口，让木工直接用石膏板做出突出造型，类似垭口的做法，然后垭口内部黑色乳胶漆涂刷，简洁而且实惠，同样有立体感▲如图彩色亮光黄色变色，让垭口更有立体感，视觉区域的过渡更有层次▲如图垭口采用彩色乳胶漆涂刷，立体而且好看▲同样过道垭口也可以采用彩色乳胶漆涂刷，简单实惠，而且视觉上整体空间更出彩▲如果没有哑口套嫌方正的门洞不好看，也可以采用把直角弧度处理，让视觉上看起来更柔和
