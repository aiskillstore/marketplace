# 局部壁纸，就可以让家里出彩7.21

▲挑高空间，下半部分护墙板，上部分碎花壁纸，能减少压抑，同时让整体墙面有了层次感

▲粉色女孩房，背景石膏板做拱形造型，粉色乳胶漆涂刷，中间部位粉色碎花壁纸，相同颜色，不同材质的对比

▲背景拱形造型内部壁纸装饰，不在于多，在于精

▲床头背景装饰，简单木质线条或者石膏板线条收框，内部局部碎花壁纸铺贴，装饰点缀常用手段

▲中式最常见的就是中式壁纸或者壁画，通过中式木质线条勾勒，局部铺贴达到以小见大的目的

▲卧室下部分墙体壁纸，利用挂镜线分割，局部彩色乳胶漆，让空间色彩跳跃，更有层次感

▲局部线条收框，壁纸装饰，突出重点，同时进行区域划分

▲客厅墙面下半部分护墙板，上半部分壁纸，或者上半部分乳胶漆变色也是可以的，一是可以增加风格元素，二是减少空间沉闷感，能让空间富有层次

▲背景墙局部壁纸，视觉上引导重心，让背景凸显出来，同时又能打破乳胶漆的单调

▲乳胶漆变色，结合局部壁纸点缀，让空间奢华，此类做法空间要大，否则不啻画蛇添足

▲小空间卧室背景，利用布纹壁纸，能让空间更加柔和温馨，布纹质感的恰到好处

▲电视墙局部壁纸是常见的做法，突出重点，同时增加空间层次感，增加空间风格的元素

▲局部不同风格的壁纸点缀，能让空间眼前一亮，比如常见的美式客厅往往用局部中式壁纸去点亮

▲局部壁纸与别的区域大面积壁纸呼应，让空间有了连贯性

▲线框分区局部壁纸，要比整面墙壁纸更有活力

▲电视墙局部壁纸突出重点，提亮空间

▲电视墙局部线框，壁纸点缀，突出背景墙。另一种反其道的做法，就是电视墙和别的墙面统一设置，因为电视墙很小，所有就融到一块，忽略电视墙的小的问题，下期有机会重点会谈到

▲拱形以及碎花壁纸，都是突出风格元素

▲局部艳丽壁纸结合冷色护墙板，在平衡感中突出亮点
