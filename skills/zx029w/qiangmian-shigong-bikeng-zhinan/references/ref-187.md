# 生活阳台照样乳胶漆，不贴砖，有人这么干8.15

阳台贴瓷砖可能是约定俗成的做法，大部分只要是阳台基本都会墙地面瓷砖。因为长期暴晒，因为要晾衣服，因为要放洗衣机，阳台没有封闭，等等。

但其实，阳台即使放洗衣机或者晾衣服，也可以墙面不做瓷砖，直接做乳胶漆，有时候并不会产生其他影响；洗衣机位置害怕水，可以只贴背景花砖或者上翻石材台面即可；至于晾衣服大件基本都是甩干以后才晾的，小件衣服接个盆子就行。如果有烘干机的话，这一切都不是问题。

排除以上因素，除非你阳台大面积养花，此时墙面必须铺瓷砖，否则长期浇水，墙面必然出问题。

▲像这种本身与室内打通的阳台，又不用晾衣服，纯粹休闲，当然不用铺贴瓷砖，采用和室内一样的乳胶漆，视觉更开阔。地面直接通铺更能放大空间
▲像这种保留了原来开放商推拉门的做法，虽然定制洗衣机柜，做了洗手池，因为窗户比较大，做乳胶漆同样是可以的

▲生活阳台，一边做了高柜，里头隐藏了洗衣机，看起来更整洁一点；另一边休闲的中式座榻横幅挂画，完全休闲布局，而且地面瓷砖通铺，墙面照样乳胶漆涂刷，效果也是非常好
▲像上图这种纯粹休闲的阳台，当然更没有必要去做瓷砖了，肯定是乳胶漆涂刷，视觉效果能做到更柔和，而且更经济实惠
▲像上图封闭的生活阳台，一侧定制高柜镶嵌洗衣机以及烘干机，旁边小的洗衣池布局，只给背景铺贴小白砖，为了防止水溅，其他墙面都是乳胶漆，看起来更清爽，更实用。窗户下方窗台单独做了石材，后期更好打理
▲如图同样是只给放洗衣机的背景铺贴墙砖，上方石膏板吊顶造型处理，瓷砖延伸侧墙，完美收口，其他墙面乳胶漆，窗台石材铺贴
▲这个就是全部乳胶漆，只给洗衣池石材上翻石材挡水的做法，也能防止水溅

▲如果说晾衣服怕水的话，如果有烘干机，当然阳台更没有水患了，直接乳胶漆视觉更宽敞，洗衣机的另一边可以作为休闲角落
▲客厅与阳台打通布局，直接乳胶漆涂刷，阳台高柜隐藏洗衣机与烘干机，视觉更干净，空间更完整
▲不贴砖，不吊顶，砖砌洗衣柜以及洗手台，洗手台木纹砖上翻防水溅即可，其他都是乳胶漆
