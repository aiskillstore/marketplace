# 小区楼上楼下，大部分贴壁纸的都开裂了2.24

一种是不可避免的开裂，有几率存在，太复杂，完全看运气。

壁纸开裂非常的正常，这就像开车的哪有不小刮小蹭的一样，无需大惊小怪。甚而咒骂施工人员或者壁纸销售商，暴露自己素质下限。

同样新车，甲开两年没有任何问题，你开半个月全花脸了，你能骂人家汽车质量不好吗？

同理，好好的壁纸，贴完都好，时间长了，别人家都没有问题，你家裂了，你说到底谁的问题？

壁纸作为一种建材产品不像瓷砖是独立存在的，壁纸的使用前提是基层的处理好坏，但是往往基层处理和壁纸施工完全不是一个工种所为，所以排除壁纸工人故意而为的原因，剩下的就是基层的问题了。

显而易见，你家腻子基层就没有处理好，再好的壁纸也得裂，怪不得壁纸问题。同理，如果地不平，谁走起路来都会跛腿的。

细分起来，壁纸开裂原因复杂，大致如下：工人水平（不能一概而论，但也不能排除）、壁纸软化时间过长、日光曝晒、劲风吹刮。最起码你得知道贴完壁纸多长时间不能让风吹吧。

另一种完全是人为的逼着自己家壁纸开裂

最常见的是毛坯房本身施工方留的施工洞位置，几乎每个楼盘都有，施工洞位置是用红砖后期砌的，和四周混凝土墙面无法衔接，随楼房轻微颤动或者温度变化有胀缩的可能。壁纸施工前，在腻子做之前必须用施工布粘贴，防止后期拉裂。但是入住发现施工洞位置开裂的，有几家在处理基层的时候按照规范来的？？可能有的业主很冤枉，自己钱没有少掏，为什么工人不给贴布呢？这是自以为是。

两种可能，找公司自己没有主见和学识，找的公司不咋样。另一种贪图便宜，公司要干你的活，不低价切入才怪？要赚钱就得给你省掉工序，所以肯定不贴布，你自己以为自己是砍价高手，占了装修公司很大便宜，其实你是真正把自己家质量砍掉了。回头壁纸开裂，怪谁？

注意看上图壁纸脱落地方，卫生间外头靠自己家位置，基本都发霉了。这是什么原因呢？很简单呀，你家防水没有刷到位而已。装修的时候只知道看价格，而不知道该做什么，该做多少。防水给你做多的你认为总价高，防水给你做少糊弄你的，你认为价格低签了合同了。你说该怪给你施工的公司，还是怪你当时逞一时砍价之快，还是该怪自己不懂行不了解仓促装修？

一般壁纸开裂的修补方法（前提确实不是基层问题，否则修补壁纸白搭）：
可以用沾水的湿毛巾将接缝处泡10分钟，用壁纸刀的刀尖挑壁纸，看能否把接缝重新接起来。如果不行，再用水把接缝处泡10分钟，一般都可以接起来。最好请专业人士做吧，这钱你是该掏的。

当然如果是基层本身的问题，铲掉重做，这是代价。

如果是防水没有做好，代价更大，砸掉重装吧
