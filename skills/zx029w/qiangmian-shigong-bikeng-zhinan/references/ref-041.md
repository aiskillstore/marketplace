# 卫生间没有漏水，墙面潮湿？12.13

开始今天话题之前，先让大家看一下，两家防水做完的实景图，看大家能看出什么猫腻。

▲上面两幅图是不同的两家装修，防水做完以后的实景，不知道大家看了以后，能看出问题在哪，如果你能看出来问题，说明已经知道门道了。

防水字面意思看是防水，其实不然，否则你真的不懂装修。

只有不断思考才能明白其中道理。字面意思其实就和肉夹馍是一样的，只是个代号，其实是馍夹肉而已。

干湿分离，字面意思就是把水分开，于是一大拨人把淋浴做个隔断，就以为自己家是干湿分离了，这些都是不懂装修人犯的错误。如果装修公司都搞不懂这些，这种装修公司充其量就是找人干活而已，没有任何专业以及经验，这也是找装修公司的窍门，大家可以记住。再普及一下干湿分离《干湿分离就是把水隔开？别再误导业主了10.8》

好了，回归正题，上面两个图，左图明显是错误的，是不思考，从八十年代装修施工中走出来，一直没有变化，比如卫生间防水地面全做上翻三十，淋浴一米八，这样的做法是防水了，但是恰恰没有防最该防的：潮气。潮气要比水可怕很多。如果是防止水漏完全没有必要做防水，一张便宜的塑料薄膜就可以搞定，只要不是人为破坏，一百年也不会降解。

▲接下来看看上图，凡是过去的旧房，卫生间门口以及隔壁墙面，都有不同程度的发霉或者掉皮现象，这个就能解释最开始的防水做法了。

而且出现这个情况以后，楼下并没有找上门，也就是地面防水是好的。这就能解释通了，因为你家防水只是防止漏水，而并没有考虑防潮。所以必然会出现上图的问题。

▲再看看上图，这是过去的卫生间常见的装修效果，瓷砖铺好以后，直接做勾缝处理，因为地面缝隙全变黑色了。变成黑色这个并不是重点，重点在于，卫生间地面瓷砖如果用勾缝剂，不仅变黑还会在不断洗刷的过程中脱落，时间久了，一般瓷砖缝隙就没有勾缝剂了，全是污渍填满了，也就是说污渍填满的瓷砖缝隙，已经挡不住水了，长久下去，洗澡水会顺着瓷砖缝隙流到瓷砖和防水层之间，因为防水层好着，漏不下去，长期侵泡，潮气蔓延，只能朝干的地方一点点渗透，再加上防水只做了30公分高，迟早潮气会到卫生间四周外面的墙面的，这就是为什么为什么不漏水，但是外面墙掉皮发霉的原因。

接下来看看补救的方法：

第一个，防水没有按照标准做，做低了，这个没有任何补救措施，只能等到以后重新装修砸掉重做了

第二个，地面瓷砖没有做美缝处理，这个好解决。把卫生间的缝隙打扫干净，自己拿着壁纸刀，尽量把缝隙清理出来。注意，除非你家没有留缝，那真的没救了。只要有一毫米的缝隙，都可以清理出来，然后自己买点成品瓷缝剂，顺着瓷砖缝隙全部补一遍，然后把墙面最底下第一排瓷砖也做美缝处理即可。只要做一遍，而且做到位，只要地面瓷砖不破，以后洗澡水永远都不会流到瓷砖和防水层之间，就避免了长期侵泡潮湿的问题了。谨记做的时候，把卫生间门口过门石缝隙以及门与瓷砖之间的缝隙重点做一下。

如果实在不知道买哪种瓷缝，可以找专业人士做，也有成品的，如果需要可以点击下面小程序购买，这个不光是是瓷砖用，安装洁具也可以用，可以避免因为用了玻璃胶发霉的问题

当然如果你家有单独淋浴房的话，第二种问题出现的几率就很低了，因为水流在小范围里头，而且离地漏最近。
