# 客厅不吊顶不要石膏线，难道就很LOW吗？8.14

上一篇有个刚需卧室的极简做法《刚需装修，卧室一分冤枉钱都不花》，给大家省钱打开思路，今天看看客厅极简刚需的做法，或许也能让大家明白装修的意义在哪。
▲不做任何吊顶，也不做任何石膏线装饰；乳胶漆变色是浅色免费调色不单独收费。电视墙高低柜搭配满足功能收纳，同时沙发区斗柜代替边几，同样满足了刚需收纳。进门是厅，放个成品换鞋凳满足进门的基本收纳，几乎没有多余的花钱的地方

▲花钱的吊顶不做，花钱的石膏线不做，变色免费之内，所有布局以刚需使用为主，难道效果很差吗？这才是最务实的实用装修
▲任何吊顶都没有做，任何石膏线条也不做，仅仅基础做了墙面变色而已，剩下的就是刚需配置，把每一分钱都花到该花的地方
▲不要吊顶和石膏线，以及一些没有必要的花费，放到家具和定制上，让刚需房真正做到务实
▲小横厅，所有多余的花里胡哨的造型线条都不要，空间采用挂机满足功能即可；把费用都放到了后期实木家具上，这才是有内涵、有品质的装修
▲大横厅装修，同样不做花里胡哨面子工程，吊顶石膏线统统不要。柔和的色彩搭配，也能把房子装修到有品位有档次
▲所有大梁不做特殊处理，不做没用的造型吊顶，不做没用的石膏线条，柔和配色，刚需布局，同样花钱，把价值发挥到极致
▲没有吊顶和石膏线，难道这样的装修很low?品味绝对不在于面子做得怎么自信，而是后期家具的投入，和对审美的提升
▲家里吊顶做了不少，线条也跟着别人做了好多，但是实际搭配出来却难看无比。看看上图就明白了，并不是基础跟风复杂就能出效果，而是审美和刚需，只做必须的，刚需东西在审美的支撑下照样可以出彩，同时让小空间看起来更宽敞干净
▲横厅户型，在良好的采光环境下，采用淡淡的蓝色变色，没有造型和累赘的线条，仅仅采用自己喜欢的家具刚需搭配，简单但是有层次和内涵
▲如图的刚需户型，有多少人给本来已经很小的空间吊满吊顶，搞一些莫名其妙的背景造型；再看看人家怎么做，多余的繁琐造型没有，利用变色拉伸空间感，把钱都花到后期有品位的家具和软配上，这才是刚需家该有的样子
▲没有复杂造型和累赘费钱的做法，基础装修几乎是极简了；但是把钱花到后面家具和软配上，效果一样清爽
▲没有花一些不必要的费用，但是效果确实非常清爽干净；懂得取舍，懂得给空间留白，花最少的钱达到不一样的效果
▲不做任何多余造型，把钱放到后期实木家具上，不是更好。而且本身刚需何必学豪宅东施效颦呢
▲没有吊顶，没有多余造型，刚需清爽，同样是有内涵和品味

▲你们要的吊顶没有，石膏线没有，就是基础铺砖和刷墙，变色还是免费范围之内，搭配喜欢的清爽家具，非常舒适的家就有了
▲横厅空间，不做任何造型和复杂背景，装饰基本的家具配置，赢在审美和配色
