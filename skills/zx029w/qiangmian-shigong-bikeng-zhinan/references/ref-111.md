# 装修公司让你贴壁纸？还真不是为你好10.10

关于壁纸和乳胶漆，到底哪个好，这个是常识性问题，不用多讲，各位业主如果连这个都分不清，还是再学学三思后装修。

壁纸，不论什么材质，都是经过各种化学工序加工出来的东西，有污染；施工需要基膜有污染，壁纸需要刷胶有污染，三层逃不掉的污染，已经注定你家污染超标。唯一可取的就是你们认为的好看，有档次，有面子。可惜，品位都是错的，这就和过去脖子上带金链子曾经风靡一时一样，现在看看有多LOW。

千万别给人说你家用的是土豆胶，肯定环保，鹤顶红听起来也蛮好吃，你敢吃吗？名字都能忽悠你。

装修不是你掏钱，使劲往家里放东西那么简单。过去装修是需要一个窝，现今社会我们不单单要一个窝，而且要一个安全的窝。所以各位反省一下，你们在装修的时候到底有多少为面子考虑，还是仅仅是一个窝，还是掏钱装出一个“毒室”而不自知，愚蠢的当了一回六亲不认的刽子手而已。

好了，接下来告诉你，为什么装修公司都巴不得你都贴壁纸。

1.如果你做的是全包，都贴壁纸，用的是装修公司的材料，当然巴不得都贴壁纸，再烂的壁纸都比乳胶漆贵，赚的更多。

2.你做的是半包，你自己买壁纸，装修公司只做腻子，该有的利润都有了，刷乳胶漆那点利润可以没有，而且你自己的壁纸自己找人贴，墙面售后当然和装修公司无关。

3.也是最最重要的，你减掉乳胶漆压根动不了装修公司的利润，但是你贴壁纸，墙面售后从此和装修公司无关，出现任何问题都是壁纸的问题，比如壁纸裂了，你能找装修公司吗？不能，你只能找卖壁纸的。装修售后墙面是一个大头，动不动裂缝，装修公司巴不得让你贴壁纸，永无售后。

4.怂恿你贴壁纸，往往会告诉你：壁纸有质感，有档次。却绝对不会给你说壁纸有污染，你这是找死；也从来不告诉你，你贴几十元的工装壁纸充面子有多LOW；用普世的对品位的误解，引导你做出错误的判断，从而达到自己不可告人的目的----污染是你的，房子是你住；效果好不好，那是你自己住，哪怕壁纸LOW出级别来，和装修公司无关，最起码装修公司收你售后的钱，可以稳赚了，以后你再也不会打电话说你家墙面裂缝了。
