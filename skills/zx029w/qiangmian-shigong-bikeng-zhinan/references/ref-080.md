# 还在发愁墙面刷什么颜色吗？看看这个就明白了

首先对于颜色大家要有一定的认知，颜色有冷暖之分，一般来说，红色、橙色、黄色为暖色，蓝色、绿色、紫色为冷色，而黑白灰为中间色。在家居装修中，选择暖色系的墙面漆会给人温馨浪漫温暖的气息，营造欢乐的氛围，而冷色系会使人沉静，使人在感官上觉得房子空间很大，富有想象力，但有时冷色系会让人感觉压抑，所以一般来说墙面选择白色的比较多，而且白色可以反光，室内显得比较明亮。

客厅颜色客厅用于接待客人，朋友聚会，一家人休闲的地方，也是最能体现主人性格和品位的地方。要达到一家人休闲、会客的要求，客厅的布置就尤为重要，既要庄重，又要符合不同年龄层的要求，通常情况下，如果客厅要大面积使用颜色，建议选择中性色，当然这还要看整个居室的装修风格，由客厅装修风格来决定。中色系的客厅墙面漆颜色会比较容易布局搭配，容易布置庄重沉稳、优雅大气的客厅，可以满足不同年龄阶段的人群，而暖色系或冷色系墙面颜色在大面积的使用时都会彰显个性化

卧室颜色卧室是休息睡眠的地方，需要营造宁静悠闲的环境氛围，所以通常是选用纯度相对高一些，明度也较高的色调，大多以暖色调为主，比如米黄，浅橙，粉紫等等。而对于光线好的卧室，局部使用深色更能体现房间的个性，试想慵懒的早晨，阳光照进房间，一睁眼看见的是一片纯度很高的蓝，或者绿，眼前一亮，从睁眼开始就愉悦了这一天的心情，如果是粉粉的颜色，不但刺眼，而且没有生机，所以颜色跟房间的采光有很大的关系，但切忌用大红等过于热情的颜色，休息的地方要安静，累了一天需要休息的时候，如果那种感觉是躺在静静的湖面，微风轻抚，这感觉是何等的宁静惬意。

儿童房颜色对于儿童房，女孩房和男孩房选择的颜色也要有所区别，小孩房的颜色就一定要避开客厅那样沉稳的颜色，色彩不在乎多，不在乎纯度过高，颜色的选择对小孩子的成长有帮助，童年的梦都是多姿多彩的，颜色能使人性格开朗，活泼，所以在选择小孩房颜色的时候可以大胆些，不要用大人的眼光去代替孩子选颜色，平时注意观察他们喜欢什么颜色，喜欢什么动物，有什么爱好，并把这些元素大胆的运用到他们的房间，我相信这样选择出来的房间装饰才是小孩子需要的，才是真正有助于他们成长的

在墙面漆颜色的选择上我们还得整体考虑，不要只考虑在墙面装修上，可以尝试在软装上下功夫，有时候即便墙面是空白的，只要软装色彩等各方面搭配的好，做好软装和硬装的完美结合，也能打造一个完美的家居空间
