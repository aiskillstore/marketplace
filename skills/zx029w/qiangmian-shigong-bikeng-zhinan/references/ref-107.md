# 非常想要壁纸，又害怕污染，咋办？5.19

非常能理解业主的心情，我自己在装修自己的房子时候也是如此纠结：又想要壁纸的质感，但是又害怕壁纸有污染。所以常常想有没有一个完美的办法解决这种苦恼。

先来解释一个误区，壁纸是没有任何污染的，所谓壁纸污染指的是壁纸胶和基膜而已。当然商家一直说他们用的是纯植物胶，是的，让人想起过去时代，好多卖乳胶漆的用养鱼来证实墙漆环保的脑残做法，他们一直声称卖的是牛奶漆一样。

所有装修污染不会一招毙命，而是一个身体损害的一个诱因，比如，我现在可以喝一杯108胶来证实108胶的环保，而且绝对不会在近期突然死亡的，只是假以时日，在某一天突然身体不行了，去医院检查会查出各种疾病，但是没有任何人能证实我就是因为喝了108胶才产生的疾病。

这就像吸烟有害健康一样，小时候劝爷爷戒烟，爷爷常常这样说：不要瞎掰掰，烟是精气神，你看隔壁老王叔不抽烟，五十多都早早走了，我现在不还活得好好的。

所以，装修污染肯定是对人有害的，但是以后毙命无法证实就是装修污染害的。
