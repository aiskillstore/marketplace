# 墙面顺平≠不平整！盲目做垂平反而多花冤枉钱

墙面看似普通但是施工工艺并没有那么简单，例如常规做法的顺平工艺以及高端做法的垂平工艺。1.两者的区别：顾名思义，顺平就是你家墙体是斜的，不做处理斜度，只是填充坑洼不平的地方，这就是大部分装修都在做的工艺，说实话按照西安地区的工艺做法，适合98%的客户。
垂平工艺如图所示，不仅解决墙面的坑洼不平，你家墙面不垂直的地方都可以做到垂直横平竖直。
2.两者的工艺：
>>>顺平工艺，墙固打底 → 石膏补缝挂网 →粉刷石膏找平→阴阳角找直 → 满刮腻子，工艺相对简单，节省用料和人工。顺平的注意点：大部分人只看到了表面的工艺，但是其中最重要的就是挂网和石膏粉找平。
因为很多装修机构这两个是不做的，都得单独付费，这个也是大部分低价切的装修机构惯用的手段，所以一定注意基层处理是否包含必须的挂网和粉刷石膏找平，因为虽然是顺平，但是有的墙面误差过大或者高低不平，不采用粉刷石膏找平是无法直接批腻子的，直接批腻子很薄，压根解决不了高低不平的问题；石膏填缝可以填坑，但是高处打磨不掉，低处就得找平处理，总的工艺还是顺平的做法。
如图第一步就是缝隙石膏填平然后挂网贴纸，一般要求两道网一道牛皮纸，这是我们的做法，如果只是挂一层网后期几乎起不到作用。墙面基层不好容易脱粉，必须全部挂网采用粉刷石膏找平，满足最大限度的平整度。上图是中海学仕里的工地实拍《120㎡全屋同款瓷砖，同色美缝，客厅无主灯设计》如果是旧房翻新墙面铲掉做的话，这个是必须的工艺。>>>垂平工艺，激光定点 → 冲筋造基准线 → 分层填充石膏 → 精细找平。相对于顺平，垂平工艺要复杂繁琐，非常费人工和材料，所以工费是普通顺平的三倍左右。而且每一家墙体误差标准不一样，垂平难度也不一样，相应的工费高低不同，激光找基准点，每一个基准点保证垂直，以后这些点连起来才能保证墙面的垂直度。根据垂直点以及弹线做出筋条，等筋条晾干以后，中间采用轻质石膏找平原有基层很差的情况下，还是大面挂网然后轻质石膏找平，这里一定注意冲筋垂平，如果你家墙面误差2公分，那么垂平工艺就会让房子更小。冲筋找平以后随便靠杆子，这个效果绝绝子，当然价格也是绝绝子
上图是业主晒的他家冲筋找平以后的成绩，如果是这个标准真浪费了冲筋找平了，没有多大价值。上图是建邦华庭我们自己工地的顺平工艺，也可以达到标准。《120㎡三室奶油中古风，软装即将 “上场”！》>>注意点：虽然做顺平工艺，一定给交代有柜子的地方保证横平竖直，尽量做到误差最小化，这才是顺平的价值。这个才是垂平的价值，你做垂平和顺平定制一样，垂平意义都没有了《衣柜不做任何收口，确实好看，定制商哭死》但是实际工艺上，你做垂平了，你要求定制也这样做的话，价格都是节节高的。两者比较肯定垂平的效果要好，但是普通刚需房顺平完全满足标准。上图的效果当然无法交工，虽然是顺平，也不能这么次，这也是顺平验收的最简单的标准，白天站在暗处朝亮面看，只要有太大的不平肉眼可见，如果是这样大面积的波浪，这个必须重修整改。顺平工艺的验收标准就是肉眼观察，看不到不平或者波浪线，定制地方尽可能误差小，这就是刚需房最基本的标准。别用手电筒验收顺平的墙面了，这个除非是垂平工艺，你掏顺平的钱，用的是垂平的验收工具，油漆工也能吐血。这么长的靠杆验收垂直度？这是垂平的验收方法，你家顺平墙体本身误差非常大，只要白天肉眼看不到很大瑕疵，看不到波浪线，晚上灯光打开不翻车，已经是高标准了。你要用杆子这样一点一点靠，你得掏垂平的钱。当顺平工艺完全达到标准，而且更有价值的时候，你愿意掏几倍的价格做垂平吗？上图是君合天玺的工地《100㎡三室一卫硬装实景，包含定制花费13W》最后总结一下：大部分家庭是不需要垂平工艺的，不要被看似专业的做法洗脑，你就是100平房子，20万都想入住，有这钱花到家具家电上，别被忽悠弄个垂平，结果导致后期家具软装没钱，这个就是本末倒置。
