# 模仿装修堆积建材，真不如穷装省钱实用，关键还环保9.8

网红装修其实并没有错，任何行业的流行，其实都是上层人士的引导，底层百姓也只是跟风模仿而已，特别是装修里头，大部分人都是在模仿以及跟风中前进，但是却忘记了，别人的做法是有足够的资金和本身圈层决定。自己所代表的阶层以及生活本身，压根与装修不匹配的时候，就会出现别人是装修，而自己只不过是把建材搬运然后堆积到家里。更可悲的是，当有钱人在刷墙铺地断舍离装修的时候，普通百姓却绞尽脑汁用各种廉价建材堆积来充面子，极端装修体现暴露各自的人生短板。…1.无主灯
黑灯瞎火的家里，一盏落地灯或者台灯就可以实现你要的氛围感；这才是实实在在的结果，不费钱达到目的，更适合刚需一族。高级的设计搭配有钱的业主和不同的圈层，这样的无主灯就是好看，高级。但是你缺了高级的设计，缺了足够的金钱，甚至在温饱边缘挣扎，此时你模仿别人的生活，其实就成了东施效颦，丢面子是小事，还得让自己的经济雪上加霜。装修设计失败，灯光设计失败，这样的使劲模仿高级，反而曝光了自己的综合水平。稍懂审美的人一眼识破你爱面子虚伪的本质。无主灯用亮光砖的做法，输在了审美，不过执意认为这就是美，也没有毛病，这个道理是讲不通的。如果你就不是那个阶层，也不想找所谓高级设计，也不想投入太多资金，就是想模仿一下别人的生活，就是上图的结果。各种廉价的建材堆积到家里。充其量只是搬运工，压根没有搞清楚自己想要的生活和自己生活本身的样子。
舍得花上万元做个电视墙，却全部采用廉价的家具搭配，这就是典型的面子装修，在10年前遍地都是，而今如果还用这种方式装修朋友会越来越少，因为有品位的都不会和你联系了。无主灯的主旨并不是不要主灯，而是见光不见灯，并不是非得复杂的吊顶才可以实现，所以结果才是最重要的，而非形式，整体审美达不到，模仿只能变得不伦不类老百姓装修首先要认清自己的地位和圈层，即使不做任何吊顶，只要你有足够的审美，也是可以很有品味，比较一下模仿无主灯的再比较一下上图，品味和审美是天地之差。如图的品味并不是无主灯给的，压根和你做不做无主灯毫无关系，但是氛围感是落地灯壁灯给的，照样完美实现氛围感，这就是务实的结果，而非廉价模仿堆积建材的做法。即使穷装那也是有品味的，因为懂得审美，不是为了面子堆积建材，多看看多多比较就知道，看似比钱，实则是一个人生活的圈层和趣味而已…2.电视墙造型真的很LOW哪个有钱人会做这种造型呢？除过刚需百姓首套房使劲充面子，真的没有人把钱花到这上头装修稍微有独立思考的话，也不会做电视墙造型，因为明明知道是充面子，有这钱何不买个档次高的家具呢本身自己审美就没有，整体搭配都有问题，模仿烂大街的造型墙，不论怎么做，都逃脱不了廉价和土气的效果同样花钱其实缺的就是品味和审美，内在不提升，只是靠廉价建材去支撑装修效果，必然是失败和翻车的结果。人家电视墙什么都不做，因为知道钱该花到什么地方，因为不做廉价电视墙造型，所以才能有真皮沙发，这才是正确的观念。看上图，有人以上图的做法为荣，这好看吗？收纳是得有，但是颜值价值也得有，这种适合出租房使用的效果，同样花钱全是建材堆积而已电视墙做收纳除过基本的储物功能以外，还得考虑价值，满足弱化存在感，提升颜值的需求，并不是打个盒子那么简单。一样的花钱，价格和价值是两码事。…3.美是独一无二，丑真的千篇一律装修的美其实并不是用金钱堆积，但是装修的丑真的是用廉价建材堆积出来的观念不变，丑陋的哑口套总是与丑陋的阳台瓷砖相伴，这个观念不根除，装修想要价值感几乎不太可能不做哑口套不贴阳台墙砖，是因为这家人没钱吗？不做垭口和难看的阳台瓷砖，你能说人家是没钱吗？人家知道用堆积建材的钱烘干机都买回来了，这才是观念和价值。提升生活品质，而不是堆积廉价建材有钱买大规格瓷砖，有钱给阳台贴瓷砖做哑口套，客厅弄个布帘，钱没有少花，为啥总感觉是出租房的廉价感？因为钱都花到了面子上，而体现品质的家具却廉价十足，这就是普通人的思维模式，装修喜欢跟风模仿，有钱务实，没钱反而充面子装修。《大规格瓷砖就有高级感？错到家了》上图人家是800*800普通瓷砖，为啥人家就不显得廉价呢？因为钱花到了刀刃上，而不是跟风面子充足，这才是装修价值，而非堆积建材。人家全房家具用实木家具，但是人家务实用了挂机，就是个功能而已，如果你的观念还是柜机比挂机上档次，就已经注定你装修肯定会翻车，全是面子作为出发点，一点价值都不考虑，如果真要面子全房就中央空调了，而不是柜机。再看看上图，大规格亮光瓷砖，不嫌钱多，有面；多此一举的吊顶做了那么多，还用了柜机，还做了布帘，有这些钱何不提高一下家具档次，这就是典型的面子装修。《家里大面积亮光材质，翻车风险太大了》
