# 装修公司好坏，全在一张预算7.10

很难想象，一个连预算都给你做不全的装修公司，能替你着想装修。

很难想象，一个专业做装修的人，进入你房子，连产生费用的地方都看不到，这样的人给你装修，和外行有什么区别。

一是这位设计师真的看不到，从进入这个行业以后，混日子而已，不思考，别人怎么做，自己怎么做，从未思考个为什么。这样的人只能说工作就是个过程，没有任何意义。遇到这种人装修，你自己再没有基本的辨别能力，只能坐等倒霉。后果是，虽然低价签了合同，后期不断加钱，最终比任何一家都高，这是你该付出的代价，也是目前互害模式下大家乐于干的事情。《装修房子，被低价钓鱼害惨了！》

二是这位设计师其实很聪明，进房子心知肚明什么东西产生费用，但是不能给你算。

给你算了你家总价高了，你不会签合同，设计师白做了。设计师没有错，错的是人人比价的市场，设计师也得生活，也得吃饭。否则装修公司大部分都会关门大吉。因为在装修大市场中，大部分人装修都是在价位徘徊，从未思考过价位背后的价值问题。《装修，价格重要，价值才是重点！4.20》

装修并不难，难的是人人有颗清澈的心，有一双智慧的眼睛。《害怕装修被坑，首先你得是一个智者8.4》

预算是装修的前提，也是装修的重点。最好的预算是放到眼前，任何不懂装修的人都能看懂。这个是大前提。

装修是为大众服务的，清晰明了的预算能加快彼此间的沟通，让装修意向更快达成一致。

装修预算不是搞花里胡哨的艺术，故意让人看不懂，有的装修公司做的预算纯粹就是故意让人看不懂，只有你看不懂，我才好忽悠。结果好多业主签完合同，面对预算自己都一脸茫然。最终只能任人宰割。

装修预算项目是基本，这个业主得明白；你都不知道你家要做什么，那别人给你做预算，想做什么项目，那就是随心所欲了。这样的话价格多少都是随意的，当然低价迎合你的心里，后期再加不迟。《装修真的没有人坑你，一直都是自己坑自己》

除过基本的项目，最最重要的是项目的做法和面积，否则你看到项目了，却忽视了这个项目的面积，吃亏的还是自己。

最典型的就是防水，你连自己家的防水都不重视，你在寄希望于装修公司，认为店面这么大怎么会坑人？这么有实力的装修公司怎么能有陷阱？你如果还在这个层次，说明你是中国批量复制教育的典型受害者而已。

最基本的道理是看人不看脸，你总认为人模狗样的人都是好人，和找装修公司一样，你总认为店面富丽堂皇的就是大公司，不会坑你。这种辨别是非的方式只是随大流而已。和超市促销排队的大爷大妈没有区别。

总想有种更快捷的方式教给业主装修，但是目前感觉好像失败了。因为你说得再多，只是理论，业主的思维模式是死的，你详细说的太多，业主又嫌文字繁多，根本不屑于去看。要改变除非改变思想，改变眼光，这是很难的。所以，鲁迅弃医从文是有原因的。

预算好坏就是公司好坏，你学会这点，装修应该就不会错了。在微信回复“预算”看预算的门道，希望你认真看，然后避免装修中各种不愉快。
