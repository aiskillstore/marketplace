# 入户就是阳台，是鸡肋还是亮点？

任何房型格局没有绝对的好与坏，例如进门就是阳台的户型，如果家里还有其他阳台的话，这种格局优点太多：入户自然光通透明亮，会显得空间都大；视野好，通风更好。今天看一下这类户型的具体案例做法，有此户型的可以借鉴。没有传统意义上的独立玄关空间，在门口安装了一个半高柜，简单实用也美观；白天的时候进门视野非常开阔，从来没有光线上的困扰，而且视觉上进门会显得空间很大入户即阳台，看似不合理，但其实这才是房子的最大价值；进门不仅满足了合理的收纳，光线明亮，空间宽敞，实现一步一景，独一无二的价值进门就是阳台，采用推拉门分割，让门厅和阳台独立存在，布局成休闲空间，门口满足基本的收纳即可。进门空间不像传统门厅那样局促，明亮而且延伸功能入户就是阳台，半高鞋柜和换鞋凳满足基本收纳不压抑；围绕厨房墙体结构做半墙设计。厨房顶部以实木做檐，向阳台方向延伸，在尽可能开放的同时，进一步关联起两个空间。实现休闲和颜值并存。入户就是阳台，这样的高级处理还鸡肋吗？落地窗采用卡座形式，满足平时的休闲，只对面室内绿植景观，阳光充沛的地方，完全不用担心会缺少绿意入户就是阳台，阳光的充沛满足了室内绿植景观的布局，这个是独一无二的价值，同时门口满足基本的鞋柜收纳2㎡阳台改为入户玄关！两面窗户互相借光，室内光线也非常nice!连接的是个多功能室，整面收纳柜，简直容量大胃王入户有个独立阳台，改成休闲活动区域，超大的窗户可以提供更多采光，进门的光线和视觉空间非常完美入户本来是半赠送的空中花园，为了好收纳鞋子设计成了L型鞋柜，没想到真的实用又好看，而且采光通风非常好。玄关+阳台的结构户型，9米长度通通做成了落地窗，
