# 经验|装修清包真的比全包划算？睁大眼睛看看

在我们的固有印象中，清包是省钱的选择，全包式有钱人的选择，但事情并不是绝对的。

某装修公司做过一次活动，楼上楼下相同户型的两家人，同时用一张设计图纸并且采用大体相同的材料进行装修，楼下的是全包，楼上的是清包，最后算总价，结果惊奇地发现，楼上的清包只比楼下全包省下了2000块钱。这是真的吗？

排除装修公司的自我广告和宣传，客观上来分析，这种情况不是没有可能发生，因为装修公司能够拿到不论是建材，还是人工上的最低价格。比如一款木地板，商场里标价250，你去只能拿这价格或者打个八九折，但是装修公司去能拿到150甚至更低的内部价，因为有合作关系。请一位木工，你去要3000，装修公司只要2000就能拿下，也是有可能，但是这些都是有前提的，绝对不是鼓动你马上去找装修公司搞全包，也不是打击一切清包和半包，事物都不是绝对，小孩才单一做结论，大人会左右权衡，这些事情都是有前提存在的。

前提一：你遇到一家良心装修公司，它赚的钱只有一点点，可能正在打开市场，可能想和你做朋友，所以从你身上的利润微薄，和建材厂商坑你的钱差不多。

前提二：所有建材厂商都不给你打折，全部标价卖给你，你也傻得不会货比三家，说多少给多少，被坑了都不知道。

前提三：你自己懂装修，最起码你知道装修顺序吧，找个找个工人做完该找什么工人，除此你还是不要太自信了

以上三点你都具备了，恭喜，你可以自己找工人做清包工了，只是累，至于您选择累还是选择多费钱这都是您自己的事情。

举个例子，一个书柜，装修公司给的报价是3000块全包，你在相同板材和工艺的情况下，清包能便宜多少呢？一个书柜所用的板材成本大约在1000块钱上下，人工也在1000块钱上下，运费是100元，装修公司拿的成本价可能少100——200元，人工同样如此，所以赚你1400块钱也是争当利润不算坑，这是行情，哪种情况你清包会更贵，第一你遇到了无良厂商，1000块钱的板子卖你1500，第二你遇到了黑心工人，行价1000，收你1500这样算起来，第三你没有车要自己请人所以要出100块运费，这样的花你费时费力的清包确实不如3000元直接全包划算。

清包和全包永远是在体力和金钱之间的质量守恒定律，自己动手省钱，别人动手费钱，就看你在省钱和动手这两者间，砝码更偏重与哪一边了。既然不想自己动手那就不要心疼钱，又心疼钱又不想自己动手，那真的没有治了。
