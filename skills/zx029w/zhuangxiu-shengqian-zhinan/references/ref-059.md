# 客厅装修省钱，都有哪些做法？10.21

第一、过门石去掉。

▲入户门的过门石其实意义不大，装饰作用都算不上，而且颜色不一样，视觉上更难看，所以完全可以直接通铺即可

▲阳台也是一样的，能通铺就通铺，过门石多此一举，通铺视觉放大空间，更好看实用

第二、不要做难看的哑口套以及窗套，门套

▲入户门套可以不要，直接乳胶漆做就行；什么时候需要做《入户门套需要不？什么时候可以不做？》

▲客厅地面与阳台通铺，不要过门石，阳台竖管下水无需防水，同时阳台不需要贴瓷砖，不需要难看的哑口套，踢脚线以及乳胶漆直接做就可以

第三、空间小能用挂机更省钱

▲这个是观念的问题，总认为柜机比挂机好看，做风管机和中央空调的人笑了。刚需务实直接挂机就行，省钱还节省地方；《客厅用挂机就丑？用柜机就好看？》

第四，多余的吊顶石膏线通通不要。

▲不做任何吊顶和俗气的石膏线，钱花在真正体现价值和功能的地方。难看的并不是没有吊顶和石膏线，而是审美太差，廉价感极强的家具而已

第五、不做任何花里胡哨的背景造型

▲东施效颦的背景造型真的很LOW好不好，不要任何多余难看的背景造型，收纳定制要比背景实用好看实用多了。

第六、家具轻巧不占地，而且很有范

▲理解不了，家里只有三个人，非得把客厅做成仓库的感觉，感觉这样才是家？这些家具即使不要钱，但是客厅真不是仓库

▲不论家里多少人，一定要让家具打散布局，视觉上更轻巧灵活；能满足功能即可，千万不能贪心空间，你的贪会失去更多，也更费钱
