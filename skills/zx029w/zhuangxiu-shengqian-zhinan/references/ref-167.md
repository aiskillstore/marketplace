# 这5个家电，别再跟风购买了！后悔没有早知道10.7

如果不是装修过几套房的话，基本大家都是摸着石头过河，好多购买都是盲目的，跟风做法，完全不知道是否适合自己，是否好用，只是一时冲动，让入住新房的憧憬冲昏了头脑而已。今天列举几个不建议购买的家电，大家可以参考一下。.01
零冷水热水器

▲科技的发展是为人服务的，但是这些服务都是建立在金钱的基础上的，这就和汽车是为了代步服务，但是当你压根承受不了汽车的费用的时候，勉强购买，只不过是徒增烦恼而已。▲零冷水做法一个是有回水管，一个是没有回水管；没有回水管严格意义那不叫零冷水，只是一个模仿而已，功能完全达不到。所以想要享受真正的零冷水，当然有回水管是最好的。▲有回水管就需要在装修的时候规划水管，而北方地区一般交房的时候局部水路开发商已经走好了，但是基本都不具备大循环的要求，所以装修水电的时候，水路就得报废重新布局冷热水以及回水管，对于大户型来说，很容易就多出三四千的费用，小户型你用零冷水干啥？只有一个卫生间，而且厨卫隔壁，如果你用零冷水只能是浪费，科技并没有给你带来什么，就是多花钱而已。▲至于好多人好不容易走了零冷水，整天钻研什么模式省钱，用一次水如此烧脑，这个不是科技服务与人，而是人受累于科技，就好比你好不容易买个豪车，整天纠结着怎么省油，怎么省停车费一样，何必如此累呢？
▲好马配好鞍，你零冷水都做了，然后购买一两千元的热水器当然功能不匹配，甚至有的杂牌用不了多久各种问题；所以热水器也是一个花钱的大头，甚至有的一万左右一个机器。▲机器和水电改造费用高了，更高的还是后期的使用，因为零冷水，你需要享受科技的便捷，一定考虑好后期燃气的费用，这个对于刚需用户来说也是一大笔无法逃脱的开销。总结：零冷水到底做不做？家里一个卫生间，而且离厨房很近，不做；如果离厨房很远，用即热厨宝搞定；如果家里大户型有两个卫生间，你看看自己的钱包和自己生活的档次决定，这就和买车一个道理，你想要买豪车，就得承受豪车的油费以及各种保养的费用，否则不做。最后一句：土豪不用看，直接做。
.02
洗烘一体机

▲洗烘一体机不好用，是有针对性的，例如你家就入住一两个人，没有什么毛病，完全可以满足，但是入住人多的话那必然鸡肋，因为洗烘一体，必然牺牲容量，一次洗衣烘干不能放太多衣物，当然就鸡肋了。所以不要在最初的入住选择错误，后面入住人多以后成了鸡肋，不如一次到位，直接购买分体的。▲至于功能上选择，一定要去考察，或者多看看别人的使用测评，最大化满足自己购买的价值。▲如果入住人多，一定不要购买洗烘一体，一定要分开，而且有空间还可以独立给小孩采用独立洗衣机或者内衣专用的洗衣机，这才是享受科技带来的生活便利和舒适。.03
管线机

▲过去年代吧，几乎好多年轻人都会在餐边柜布置一个管线机，为了随时能喝上热水，看似很高端，但其实就是长距离接一个热水器而已▲如图白色的水管，预埋PE管，从管线机到厨房净水器，距离长，而且后期压根无法更换，水压本身就很小，以后每次使用时间长了，都得先放水然后才能饮用，最可怕的就是后期管路有问题，抽都没法抽动，所以奉劝各位这种机器属于完全鸡肋▲其实非常简单，只要配一台净热一体机即可，又能有纯净水，同时可以采用不同温度加热，最重要的是没有管线机预埋管道的烦恼，而且是一个机器两种功能。.04
新风系统

▲全屋新风想必大家并不陌生，但是有多少家庭是需要这种新风的，又有多少家庭开发商的塑钢窗都关闭不严，然后全屋做新风的？然后处理过的新鲜空气没有窗户缝隙进来的浊气多？其他地方不熟悉，就西安的气候来说，目前就是冬季有雾霾的时候，新风可能起点作用，其他时间基本天气晴朗，开窗通风完全满足换气需求，并不需要弄个样子货的新风，窗户舍得不得换，新风的意义在哪里？还有新风时间久了不光是更换滤芯那么简单，管壁长期细菌灰尘，你多久清洗一次管道呢？如果从来没有清洗，你以为换进来的是新鲜空气吗？▲壁挂新风，是和空调挂机一样，外墙打孔，就可以满足小范围区域的换气功能，特别是针对卧室窗外是马路噪音非常大的家庭，这个是必不可少的，因为窗户更换隔绝了噪音，同时也隔绝了通风换气，所以此时的壁挂新风距离短，可以起到换气的作用.05
水槽洗碗机

▲你如果就是单身入住，如果感觉洗碗就是玩，你可以用用。你如果是一大家子过日子的话，还是算了，吃一顿饭，你得分好几次去洗，而且噪音大，甚至洗不干净，稍微大一点的盘子锅别想着能放进去，而且占用了本身很小的水槽空间，不仅自己鸡肋，还导致水槽更小，一旦坏了整体报废。所以奉劝想入手水槽洗碗机的，除非你是单身，除非你后期不嫌麻烦，否则还是直接购买镶嵌的独立洗碗机，越大越好。
