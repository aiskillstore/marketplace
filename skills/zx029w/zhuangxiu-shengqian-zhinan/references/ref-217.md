# 吊柜不挨顶，低价和不懂的必然结果11.11

装修有什么猫腻？一是哄你不识价，二是哄你不懂行。几乎所有猫腻都是围绕这两种可能去延伸的。

▲大家看一下上图厨房有什么问题吗？如果你不懂，当然一眼看上去都是颜值。如果你稍稍懂点装修的审美和过日子清理卫生的细节问题，就会发现：吊柜与吊顶为什么有个缝隙？为什么不能做到严丝合缝？这样会不会后期难打理卫生？
▲再看看同样做吊柜别人家的做法，为什么能严丝合缝，不论从美观或者好打理方面都更胜一筹。
原因在哪：一是你找的是套餐装修公司。套餐装修公司厨房一般是限制米数的，比如地柜三米，吊柜一米五。超出部分单独计费。找过套餐的都知道这个问题，而且地柜肯定是高度85左右，深度60公分左右，而且吊柜同样是高度60公分，厚度35公分，如果你家超出这个范围必然加钱。业主是外行，不懂这些呀，只知道家里有橱柜了，根本不知道橱柜有好多细节问题，而且关乎生活质量和后期整体效果的。套餐公司为了低价签单，更不可能主动告诉你这些，而且套餐公司的设计师纯粹就是签单，压根不会管你效果不效果，甚至有的设计师都不知道这些，只是机械的用模板套出预算而已。这就是你家装修完毕和别人好多细节天地之差的原因了。
如果你找非套餐装修公司：其实道理一样，替人着想在装修上往往会自讨苦吃。举个简单的例子，装修总价10万，业主非得9万做，你又不想失去这个机会，就勉强签单吧，但是你会发现好多细节可以给业主做到更完美，但是你不敢说，因为你说了业主照样把这部分砍掉，你这是自讨苦吃，不如假装不知道。这就是消费者反逼商家的最好例子。比如质量好的东西就是成本高，但是消费者没钱，你再有好的东西也得破产，最终不如做山寨赚的更多。
好多疑问：层高那么高，吊柜做到顶够不着，能用吗？这是多虑了，根据西安地区的商品房一般毛坯房层高就在2.7米左右，减去止逆阀的高度20公分，需要吊顶处理，再减去地面铺贴将近10公分的高度，已经去掉了30公分，也就是厨房吊完顶在2.4米左右，这还是层高比较高的，一般厨房2.3米都不错了，甚至还有2.2米左右的。根据以上的尺寸就可以算出来，地柜一般85公分左右，中间空隙75公分左右，吊柜60公分左右，这就已经2.2米了，如果你家层高多出十几公分，完全可以把吊柜做高来实现严丝合缝的效果。
▲当然有人就会有另一个疑问，吊柜高了会压抑的。当然，你如果找的是好公司，这些都不是问题，你找套餐或者是低价切入的公司，这些也懒的给你想，想多了这个都是钱呀。看上图，吊柜高了做一部分套色的隔板，视觉上就可以解决吊柜太高压抑或者与地柜比例不协调的问题。
最后注意一点：怎么能做好这些细节？需要统一协调，如果你家橱柜是一家做，你家吊顶是另一家做，不好意思，这个几乎不可能实现，各赚各的利润，谁也不会做个中间人给你协调这些，何况不敢说呀，说了你又不掏钱，还得搞价，最终是你以为你找个便宜吊顶，找个便宜橱柜可以用了，其实效果不仅输在实用上，颜值也输掉了。这就是为什么推荐全包的原因，只要碰到好的公司，全包是最好的，这些细节完全不用你操心，吊顶的高度和橱柜的做法一家协调统一，就可以完美实现。
