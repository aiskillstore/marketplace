# ✅ 原创|装修，你是省钱还是抠门？

面对任何和金钱有关系的事情，我们第一时间都会想到怎么省钱，怎么花最少的钱办和别人一样的事情，这是人之常情。但是这块的省钱并不是通常人所理解的抠门。省钱是一种态度，一种有智慧的态度。抠门也是一种态度，但是这种态度不会给自己带来省钱的真实结果，只会带来类似掩耳盗铃式的省钱。例如一件物品原价五元，但是没有人买，把标签一换，原价十元，现价五元，马上购买者趋之若鹜，这些购买者就是掩耳盗铃式的省钱，以为自己占了便宜，其实是自以为是。装修也一样，同样有智慧的省钱和掩耳盗铃式的抠门，只不过作为外行，作为一个普通的只能为活命而打拼的老百姓无法冲破中国式教育的牢笼，无法抹掉眼前的迷雾而看到真实的东西。于是，在想，作为装修的从业者，作为一个有做人基本原则的成人，有义务去做一件有利于业主，也有利用本行业的事情，那就是让装修变得从容，最起码能像正常行业一样看起来正规起来，而不是到处充满猜忌，怨愤，纠结，扯皮，而又不得不面对的无奈。

省钱的字面意思就是节省金钱，但是其实质不是为了省钱，而是为了把事情办好。出发点是通过金钱办事的结果，而不是真的为了省钱。装修里头也是一样，不是给你报价五万，你搞价到四万叫做省钱，而是别人找的高端公司报价六万，而你找的门当户对的公司，适合自己的公司，报价五万，而且你的五万顺利完成，档次并不低于别人的六万，这才叫真正的省钱。事情的结果才是省钱的真实。可是现实中有几个人明白？有几个业主这样做的？大部分人以为省钱就是抠门而已，极尽所能砍价再砍价，最终合同签了，可是你砍价的结果是包不住成本，但是装修不是一个具象的商品，无法整个商品造假，于是乎只能局部造假，就有了以次充好，工艺工序减少，或者直接偷项漏项，最终你的砍价确实是省钱了，也丢了质量，关键是你的装修结果让你不堪入目，而你又不可能砸了重做，于是在你入住新房的时时刻刻你都会为了装修头疼，住在这样的家里，你的脾气能好吗？你的事业生活种种都会受到影响，恐怕此时你后悔自己的无端砍价已经晚矣。

不知道看明白没有。唯有装修如此纷繁复杂，不能以正常市场去衡量，更不能以具象的商品来看待。在价格上根本没有所谓高低，有的其实就是业主心里的承受和业主除过价格以外的对于装修公司的认可。但是，可悲的是，装修市场一拨一拨的老业主上当，一拨一拨的新业主蜂拥而至，还是把装修当成是买衣服一样的看待，扯皮上当轮番上演。以前还侥幸认为市场的制约与竞争会让装修市场趋于正规，但是现实看来，装修的特殊性导致业主和装修公司双方都在暗地战争，这种战争导致市场必定混乱，而且不可能有好的迹象，最起码靠寥寥数个良心企业是很难改变目前的现状。于是，从本质上发现一个问题，不能去奢望改变一个已经腐朽的市场，只能从消费者出发。这就好比你不能奢望坏人和骗子都死绝一样，只能寄希望于人们的醒悟和防范。装修市场不能寄希望于是市场，更不能寄希望于某些腐败的官方，而是我们最直接受害和受益的业主。如果我们业主都是明白事理，都是在社会中运筹帷幄的精英，或者至少是能看透世理的，那这个市场能不好吗。比如装修中我们业主都能切身低下头去学习，去思考，最起码在装修的时候知道什么是该花的钱，什么是不该花的钱；最起码知道天上不掉馅饼的基本社会常识也好。可是据目前观察，遍地装修公司的各种利诱和鱼饵式营销层出不穷，说明大部分业主只是被别人引导而已。看见有装修送东西的就趋之若鹜，看见交定金送礼品的赶紧去占点小便宜，看见先装修后付款的恨不能赶紧去捡个大馅饼。这里绝对没有酸葡萄心里，只是一种恨铁不成钢的无奈。

现实中常常听到客户的各种回答无奈，甚至有种苦楚的心里，辛苦攒钱买房，努力攒钱装修，可是你的肺腑之言却抵不上装修公司一个优惠活动，实在是可叹，可悲。比如咨询房子装修，你报价高了业主说那谁谁才多钱，你报价低了业主说人家谁谁多钱，你这么低能做好吗。其实面对众多咨询业主，有时候只想说一句话：装修没有价，你又在比什么？即使工人一样，工艺一样，可是市场上上万材料品类，商家渠道各异，公司成本悬殊，你比什么？

所以至少目前终于明白，装修不能比价格，更不能比公司规模，比的是良心和做人的水准。做人好了，不论规模和档次，你家都会顺利。做人不好，价格多低和多高有什么用？最终出了问题除了逃避就是扯皮，业主能奈何？这个也许没有多少业主会明白，希望后来者业主真的能看到装修的本质，永记装修里头最最重要的是装修公司的人品而已。
