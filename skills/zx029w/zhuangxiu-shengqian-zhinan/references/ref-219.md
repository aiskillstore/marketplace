# 加块木板当书桌，这届年轻人太会“省钱”了12.11

关于书桌已经有过太多案例专题了，大家可以自行搜索或者在专辑里头查看，今天看看采用木板当书桌的做法。如图常见的书房书桌悬浮做法，视觉上轻巧，空间上不会有压抑感，相反不仅满足桌下空间的最大化，同时视觉上满足设计感和高级感，只不过这样的做法必须提前打好钢架，满足承重的基本功能。一块实木板就实现了阳台的书桌功能，还好两边墙体都是承重墙，分别固定四个角码，榆木板放上去，非常稳固，实现平时一个书桌功能没有任何问题如图采用两层海洋板满足一个书桌的功能，因为是承重墙，采用角铁固定，又怕书桌太长不结实，开槽预埋了方管加固，这样就不用担心时间长了会变形。满足功能视觉空间还能极简。背后是混凝土墙，采用加厚的实木板与三角架固定， 就可以实现一个轻巧高级的书桌，上头隔板采用隐形膨胀螺丝固定隔板，满足一部分收纳，书房空间上不会显得累赘和压抑墙体不是承重，采用网购形式直接满足一个书桌功能，光轴杆以及实木板网购，拼装上以后直接搭上即可，看似简单但是光轴杆的组合对于一般人来说并不轻松。整体定制，采用灵活的桌面上下调节可以满足一个升降桌的功能书房网购一张红橡桌面，然后采用铁艺支架安装，就可以满足一个轻巧高级的书桌功能，墙体一定是混凝土才行，否则时间久了必然脱落；像上图这种悬空的书桌，一般是非承重墙的做法，必须提前打钢架，然后采用木基层处理，后期木板封住即可如图非混凝土墙体想要实现悬浮一字书桌，必须采用钢架的形式来保证后期基本的承重如图做法，背后是非承重墙体，此时采用两张36厚度的板子，直接定制，两头有桌腿，中间有抽屉柜支撑，所以不需要后面的固定，就可以实现轻巧的书桌利用窗户下一张实木板，采用折叠五金满足一个临时的办公空间，不用的时候还可以折叠收起来，不占用太大的地方如图如果是混凝土墙体的话，就可以直接采用铁艺支架满足固定，完全可以满足功能非承重墙提前打钢架，实现悬浮一字书桌，也是可以的，视觉轻巧，空间也显得宽敞，更有设计感千万不要抱有侥幸心理，非承重墙不打钢架，直接用简单的支撑架固定，而且还贪心的做了抽屉，这种做法承重本身就有问题，塌陷只是时间问题。不是承重墙，也不想提前打钢架，其实最好最实惠的办法就是网购亚克力桌腿，一样的实现功能，而且空间上更加灵活，可以随意移动，像成品书桌一样没有局限性，而且亚克力腿没有存在感可以让视觉更轻盈只要满足混凝土承重墙，采用简单的支架，采用非常轻的隔板，就可以实现一个书桌功能
