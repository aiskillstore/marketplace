# 家里飘窗不鸡肋，实用指南5.17

关于飘窗已经有很多专题了，大家可以自行搜索即可，今天继续看一下飘窗的各种空间利用，给自己装修多一点参考和借鉴。
▲利用飘窗延伸定制满足一个书桌兼顾化妆台空间，对于小空间来说，多了一个功能，而且又不占地方▲利用飘窗延伸一个化妆台，同时满足少量储物，这是常见的卧室飘窗利用做法▲原有飘窗太低，采用定制抽屉满足收纳，同时抬高飘窗；借用飘窗延伸化妆台，床头柜也省掉了▲即使飘窗纯粹用来休闲，利用侧面的拐角位置，也可以满足一个小书柜的收纳，平时坐飘窗阅读随手拿取也比较方便▲更高级一点的，做成抽屉抬高飘窗，同时利用伸缩板满足一个书桌的办公空间▲伸缩书桌一定要选择适合的五金才对，否则桌面拉出与原有桌面会有落差，所以选择可以抽拉而且可以上弹的五金才能满足桌面的整体平整▲家里飘窗如果进深非常大，此时一定要利用起来；错位的地方刚好满足书柜的定制，超大的台面可以满足一个喝茶休闲的地方▲飘窗很低的话就坐也不方便，干脆加一层抽屉，延伸拐角连床头柜一体延伸都有了；抽屉可以作为分类收纳，同时飘窗上头继续保持休闲就坐功能，木质的台面连垫子都省了▲木板延伸飘窗，侧面隔板搭配，刚好满足展示和休闲共存▲如果你是手办的爱好者，家里飘窗可以拓展出来，兼顾休闲和手办的展示，同时灯光布局营造氛围感非常漂亮▲小飘窗如果进深过小过低，直接加高延伸台面板，就可以实现小空间独有的书桌功能▲餐厅紧挨的飘窗，采用抽屉抬高空间，满足分类收纳，同时石材台面做法，满足一个西厨电器的布局，兼顾了餐厅水吧台的功能▲如图利用餐厅的飘窗实现了收纳，同时上方极简石材铺贴，满足家里水吧台的功能▲餐厅飘窗利用起来做水吧台，真的再合适不过了，下方抽屉专门满足各种杯子收纳▲不需要额外功能的话，飘窗定制垫子铺上，夹角隔板可以放书或者展示，平时这里就是看书休闲娱乐的地方▲对于喜欢喝茶品茶的人，客厅大飘窗再合适不过了，既利用地方，又能欣赏到美景，一举两得▲对于空间实现不了书桌，又想要办公空间的家庭来说，利用飘窗算是最好的做法了▲利用飘窗延伸书桌或者化妆台，代替床头柜，这个算是常见的做法▲小空间飘窗变书桌，好看又好用▲对于空间小的房间，想要成就空间又要能住人，此时可以利用飘窗作为床铺的一部分延伸，完美成就小空间的功能；不过需要注意平时家里无人记着关窗▲对于想要卧室有沙发的家庭来说，利用飘窗垫飘窗秒变一个舒适的沙发区，真的不错▲最简单的办法就是把休闲区布置得更温馨▲铺上垫子以后，中间定制小几，就可以作为平时喝茶休闲的角落▲飘窗抬高拐角延伸书桌兼顾化妆台，利用了空间，成就了收纳▲最简单的办法就是利用飘窗桌，实现一个书桌空间，但是相对空间也浪费比较大▲原有飘窗能砸掉，然后利用定制拓展飘窗空间，实现了榻榻米和两边的超级收纳，而且开放格还满足了书籍的收纳▲同样利用原有飘窗砸掉以后，实现了休闲榻榻米，同时成就了书柜的收纳，完美实现一个休闲兼顾阅读的角落▲飘窗加抽屉以后，离床位置太小，无法既保证延伸同时容纳椅子，采用床尾局部折叠板的做法，满足一个小书桌，同时刚好能满足一把椅子的放置▲飘窗砸掉以后，实现了飘窗柜的收纳，同时延伸一个床头柜功能，视觉更完整，收纳更多，同时又保留了原有的休闲功能▲飘窗延伸要保证25公分左右的距离，这样后期人腿才是舒适状态；下方抽屉一定要采用加长轨道，才能完全拉开空间；桌板下方一定要提前规划电源，这样方便后期使用▲砸掉飘窗定制两层抽屉，满足分类收纳，同时延伸一个书桌兼顾化妆台，床头柜也省掉了▲当然你也可以直接把飘窗定制加高，做上开放格，采用收纳盒子满足分类收纳的功能，视觉上也能保持整洁▲空间大的时候，可以直接定制满足L型书桌的布局，同时增加收纳，需要注意书桌背后不要伸到玻璃处，预留空间刚好满足窗帘的位置▲儿童房小空间，刚好利用飘窗满足一个书桌学习空间，同时右侧书柜展示定制，不做背板这样不会影响窗户的采光，上方摇臂灯满足局部空间的照明需求▲飘窗成就书桌，利用拐角延伸，隔板书柜布局，成就了一个完美的书房空间▲保留了原有飘窗，定制书桌以及台阶，可以满足休闲，同时保证窗户以及窗帘的开启关闭▲砸掉飘窗以后，靠窗定制超级收纳和书桌，这里满足孩子学习和游戏，桌板伸出20公分，大人也可以使用▲书房空间拓展原有飘窗空间，实现了书柜的定制，满足超级收纳，同时原有飘窗台面得以保留▲当然如果需要，飘窗也可以定制成化妆台空间▲原有鸡肋的飘窗，利用做地台床利用起来，完美拓展空间▲最简单常见的做法就是砸掉飘窗以后定制飘窗柜，既满足了收纳同时又能保留原有飘窗的休闲功能▲原有飘窗保留，延伸定制衣柜与收纳空间，两个台阶采用抽屉方式实现，收纳和休闲并存▲空间小的话，飘窗不做休闲功能，可以加一排抽屉作为收纳功能，台面石材布局以后，这里可以兼顾床头柜置物功能▲砸掉飘窗，成就一组衣柜以及收纳飘窗柜，同时延伸一个书桌兼顾化妆台的功能▲砸掉飘窗，完美定制一个书桌功能，同时满足了书柜的收纳▲砸掉飘窗，同时满足一个书桌和飘窗柜的休闲功能▲书房兼衣帽间空间，利用飘窗柜与原
