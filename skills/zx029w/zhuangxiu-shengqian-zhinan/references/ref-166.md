# 零冷水热水器，值得入手吗10.1

先看看什么是零冷水，就是使用燃气热水器的时候，不需要等待管路里头的冷水放完，即可有热水。这是大部分家庭的痛点。

你们为什么用零冷水？因为冬天上厕所需要洗手，需要放好长时间冷水，才会有热水，一点都不幸福。好吧，下方有五孔插座，安装一个厨宝不就搞定了？上面有插座，安装一个电热水器龙头不就搞定了？你还要什么零冷水的热水器？

洗澡咋办？如果你家有浴缸，必然需要凉水，那就把多余的凉水放进浴缸，后面热水来了，水温不就刚刚好？

淋浴就是最大的问题，衣服脱完了，打开花洒，颤抖着身体拿着手持花洒，半天没有热水；此时要不水放马桶里头，要不水直接流地下，要不放进旁边的拖把池。有的人喜欢用顶喷，颤抖着身体，缩到浴室角落，大冬天享受着顶喷凉水的阵阵凉意，想想浑身都哆嗦。几分钟过后，热水降临，迟来的幸福很难得。

难道你们用零冷水是为了节省浪费掉的凉水吗？如果是，你们就不需要零冷水。所有享受都建立在浪费的基础上的，你买零冷水设备的钱可以供你浪费一辈子了。

▲上图是两个16升的燃气热水器价格对比，零冷水和普通价位相差4999-1198=3801元。如果按照住宅水价一吨3.5元计算，就是3801÷3.5=1086吨水。这个还是普通对比，甚至有比这个更极端的水量，所以如果你是害怕浪费水，归根到底是怕浪费钱的话，其实冬天凉水澡更来得实惠。

所以，你家用不用零冷水取决于你对钱的态度，取决于你对生活品质的态度，要享受就用，反之不用。
零冷水有没有条件？你如果就是一厨一卫，而且厨卫还是隔壁，还是算了吧，要零冷水干啥？你家不用零冷水的热水比其他家用零冷水，热水到的更及时。这就是为什么燃气热水器在厨房，离水槽很近，水槽不需要厨宝，直接接热水器的原因，热水几乎都是秒到。
如果你家是一厨两卫，甚至更多，而且距离比较远，此时为了最远的卫生间洗澡更有品质，那就做零冷水，钱是为品质服务的，此时千万不要省钱，家里有人抽烟，一年轻松抽掉一台最好的零冷水热水器了。
不要用假零冷水。零冷水有两种，一种是不要回水管的，一种是有回水管的，其原理是一样的。但是效果天地之差。
▲上图没有回水管，回水热水与冷水混合进入燃气热水器，本身对热水器就是伤害；而且没有单独回路，内置的循环泵本身就是进水的阻力，导致燃气热水器出水量变小。最大的问题是热水回流会导致凉水出水口有热水现象，比如马桶冲水是热水，哎呦，史珍香，当然有的人担心会损坏家里冷水管，天啊，你们装修谁家还用凉水管？冷热水管价格相差几毛钱，冷水可以过热水管，热水不能过冷水管，何不都买热水管呢？
▲上图有回水管的做法，其实更好，单独回路不会影响到水量的大小。但是这样的零冷水真的是零冷水吗？
不是，你想多了，一是取决于回水的速度，这个和循环泵有很大关系，第二取决与距离的长短，第三取决于你家的水压和水量，第四，取决于你家天然气的气压。四种因素才是零冷水的致命地方。
循环泵其实很好解决，大不了扬程远，功率大，噪音更大一点，这个是必须付出的代价，和烟机噪音和吸力的矛盾一个道理；距离远近也好解决，只要解决循环泵的问题距离就迎刃而解了。但是你家的水量和天然气气压怎么解决？
当然，目前燃气热水器有水气双调和水量伺服的功能。但是这个功能也必须在你家水压足够，进水量足够，气压稳定的基础上实现的。而目前大部分家里零冷水使用不佳的问题，都出在这里。特别是北方地区，冬天天然气严重不足，这个严重影响热水器的各种调节功能，导致高端的水气双调和水量伺服成为摆设。
如果用了零冷水，你家洗澡仍旧忽冷忽热，品质照样下降。你可以看看市面上现在几乎所有热水器都标榜恒温。你真的认为就可以洗澡恒温了？当然不是，大部分产品都是忽悠，压根没有这个效果，最多在出水处有个感应装置，压根反应不过来，感应到温度变化然后传给中央处理器，已经迟了。甚至目前一两千的燃气热水器都标榜恒温，而且还是零冷水的热水器，根据人不识货钱识货的常识，多半是忽悠。
当然，有高端热水器内置各种恒温高科技，是可以做到基本恒温，但是仍旧回到老问题，你家自来水的水压水量和天然气的气压气量，都可以导致恒温是个摆设。这就是不论买低端产品还是高端产品，感觉这个恒温都有不靠谱的时候。其实不怪科技和热水器，高层住宅的自来水以及冬季天然气的极度缺乏，这个不是人为能解决的问题，明白了这个，你应该释然了。最起码偶尔水压正常，天然气正常，你还能享受一下真正的恒温，所以多的钱就看你怎么看待了。
