# 装修课堂每日一讯【装修省钱地方】12.20

西安装修到底能不能省钱？装修是个省钱的差事吗？当然能省钱，就看你有没有省钱的心了；把钱不当钱的不用看了，没有钱充大款的也不用看了。
【开始筹划省钱】收房了准备筹划装修的时候就要想到怎么省钱，首先房子多大面积准备怎么装修，一般老百姓装修适合入住也不需要太多花里胡哨奢侈的东西。风格省钱简约为先，当然简约不是什么都不做，而是只做必须做的，像一般的吊顶造型这些都可以不做，什么背景墙之类的都应该省掉，没有任何实用价值，也没有必要攀比，别人怎么装修那是别人的事情，家是为自己家人准备的又不是朋友聚会的场所，没有必要；而且老百姓你家奢华不奢华没有任何人去注意的。所以风格决定价位的，有的业主不了解这些，装修不考虑造价一开口就是简欧就是中式，根本不考虑欧式和中式后期家具费用。
【找公司省钱】自己的整体筹划决定找什么样的公司，比如小户型简装就找个相当的公司不能不分大小的找，大公司做五十平有可能不接，即使接那价格都是很离谱的
【设计省钱】现在到处都是免费量房免费设计的，多找几家公司就可以了解大概了，至于装修效果图那是不懂装修的人才需要的，也是装修公司糊弄业主的手段；效果图只是参考没有任何意义，可以去问一下装修过的人，有几个人装修完工最后效果和效果图是一样的？网上效果图那么多，而且和自己家相近的也不少，下载下来保存好让装修公司照着做就是了，需要什么样的背景墙自己找图片让装修公司照做就是了
【施工省钱】施工过程中一定要抵住诱惑，比如正在施工装修公司会想方设法得让你做这个做那个，用各种参考案例各种说法说服你该做什么。一旦碰到此种情形自己要有主见，不能别人说什么就是什么，一旦自己没有主见，那后面的钱是省不下来了，都是你自愿掏腰包了
【实用省钱】做任何东西三思实用二字，否则钱绝对是省不下来的。厨卫吊顶铝扣板各种各样价格不一样，不用选那么好，厨卫吊顶没有任何承重作用，你也不可能上到吊顶上去，所以差不多的铝扣板完全可以达到效果，没有必要选择非常昂贵的。洁具国产的足够好，你非得买个所谓的进口的；橱柜任何品牌都是本地厂家生产你非得选择知名品牌，那都是贴上去的，做橱柜生意的谁有橱柜厂？做瓷砖生意的谁有瓷砖厂？借外来资源才能做生意，否则会拖垮自己的。墙面漆：建议选择现在市场上比较大众化的品牌，因为墙面保护的比较好的话，最多在7、8年的时候就该重新刷漆了，多贵的漆面也要铲除，所以在这方面可以省。五金挂件：五金挂件很费钱，别看东西小，加起来也不少花钱，尤其是厨卫挂件，如单双层的玻璃架，可以选择铝合金的框架的，比镀咯和不锈钢的要便宜得多，有些小挂件如皂盒、毛巾架可以选择吸盘式的PVC制品，既方便又经济，更换清洗都方便，还可以选择涨杆用于挂毛巾，这样既省却了打孔安装费，又降低墙砖打坏的几率，可以保持墙面砖的完整。家具都是放着不会大动的，非得买个一百年都不会坏的？红木虽好不是谁都能用的，而且那东西欣赏超过实用
说了这么多，省不省在于自己，你该省的别人可能认为不该省，省钱是相对的自己有主见才是省钱法宝。
