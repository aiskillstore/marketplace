# 别再信‘自装能省钱’了！太多刚需业主咬牙坚持，省下的钱全赔在返工上！

自己装修不是不行，而是你得问自己：你对装修了解多少？如果你连装修先干什么后干什么，连基本顺序都不知道的话，千万不要贸然自装，否则不啻为自己给自己一步步挖了大坑，后悔就来不及了。装修想要省钱、省事，是要嫁接风险，是要推脱责任，而不是包揽风险和责任到自己身上，这就是本末倒置，自欺欺人而已。「装修10招嫁接风险做法，聪明业主早都用上了」
当你对装修不懂的时候，风险是最大化的，此时要化解风险，就是嫁接风险给装修团队，借用外力实现自己顺利的目的，这才是正确的思路。今天盘点一下网友们自装的各种问题，看了之后，如果还是坚持自装，只能自求多福了。网友@迟志强：再给我一次机会，我真的不会选择自装，我真心奉劝想要省钱自装，但是又不懂装修的朋友，一定打消自装的念头。总觉得装修公司都是坑，干活瞎敷衍，抱着我多学习一定也能搞好的心态，直接开始自装，现在每次去房子，真的想哭又想笑，房子都不想要了！（疯了，真的！）起早贪黑的去工地，顶着大太阳采购材料，结果装出来一套差强人意的房子，还超了预算。所以，真的大实话，有时间的/有装修经验的朋友可以考虑半包，如果跟我一样不懂的，还是认真研究下怎么找到一家靠谱的装修公司！「2025年，你找谁装修，结果都在于人」网友@百香果：对于没有装修经验的人来说，想找工人那通常就是找朋友介绍或者在建材市场找介绍。但每个工人报的价格都不一样，技术也参差不齐，好的师傅还要预约施工时间，不仅耽误工期，还打乱了计划上网查了这么多攻略，每个流程都熟悉了但自己找的工人还不一定会。工人只会做自己会做的事，别想着教工人干活工人干完活结完账就撤场了，后续有什么问题，找工人要求返工也只是0人回应，最后也只能自己承担可能会出现的质保问题。网友@剪裁道士：装修涉及水电、泥瓦、木工、油漆等多个工种，每个工种都有专业门道。不懂电路改造，插座位置留错，后期只能用插线板补救；不了解防水工艺，防水层没做好，楼下邻居找上门。就算临时抱佛脚看攻略，实际操作中也会因为缺乏经验状况百出，返工成本高得吓人。自装时很容易陷入各种消费陷阱，看到好看的材料就冲动消费，完全忘了整体预算。而且在材料采购过程中，由于采购量小，很难拿到像装修公司那样的批发价，运输、搬运费用也得自己承担。再加上可能出现的返工费用，超支分分钟的事。考虑自装的业主们： 1.你是否有3-6个月的自由时间？可以随时去办装修的事情，比如盯工地，买材料。 2.你是否有装修工人资源，并且愿意听你指挥，把你的想法落地。3.你是否有齐全的材料商资源？可以买到性价比超高的材料。 4.你是否懂施工流程，施工工艺，施工标准，施工验收？ 5.你是否有很强的抗压承受能力？工人施工过程的风险需要业主你自己承担，质量和效果需要业主你自己去承担，在工地出现各种问题后，还能有个好的心态。网友@雪玲：自装到一半，已经后悔了。后悔自装了，每个步骤都需要自己去操作，其实选择什么也不是很难的事，只是想尽心把每一个步骤都完成的完美一些，怕就怕在尽心找的瓦工、油工师傅，结果却不符合自己的要求，选来选去的产品、颜色却和预期的差别很大，再来一次，不想自装了，太累了。网友@点心西施：装修天崩开局！父母为了省钱找了亲戚装水电。线路混乱、回路设置不合理（全屋大多都是1.5平的电线）、开槽太浅底盒突出后期不好刷白…还有好多多问题！含泪重新买材料请人重新装，奉劝各位，装修真的很专业，并不是随便一个工人能干的，最重要的别图便宜。网友@火龙谷：从拆改到定窗户到水电，我的装修才开了个头，人就快抑郁了。每天遇到的坑都让我能感慨“怎么还能这样，也太离谱了吧？！” 真的装的没有什么信心了。每天到了工地看着一地狼藉真的房子也不想要了。 老公安慰说找装修公司也是坑。 那起码装修公司只有一个人坑我吧，这一天天的每天都在遇坑，都在和工人拉扯，看到的每个师傅都是以最低要求最底线的状态完成工作，你去提要求还觉得你事多，真是何苦来哉？网友@虫蛊：稀里糊涂的自装，想一步做一步。材料都是挑好的来买，成本上去了，做出来效果下降了！真心建议准备装修的亲人们先找个装修团队，按照装修方案一步步来做，这样做出来差不到哪里去！还有师傅最好不要找自己的亲戚，有些工艺不行，理还特别多，还不敢多说几句。网友@铁齿铜牙：装修的每一步都是自己盯着的，预想的肯定会很好看，结果住进来发现自己装了个出租屋。「别再这样做了！7个行为，正在让你的家显得又廉价又邋遢」网友@行侠仗义：经历过绝望吗？在崩溃的边缘。改了又改！拆了又拆！不能只有我一个人吃装修的苦！自己不懂顺序，所有散工都只图自己好干活赚钱，木工做了，墙面做了，没人告诉自己瓷砖得先铺，真疯了，何必自己装修坑自己呢。网友@满墙惆怅：历经81难，最后都到保洁了，顶面脱落了，找的工人打死不承认自己的问题，压根连来看看都不来，后续只能自己再掏钱找别的工人来维修，自装的坑绵绵不绝。
最近有一个业主家的房子选择自装，封窗的时候工人摔下去人没了，家人来索赔，最后这个业主房子也不装了，本来还有一套拆迁房，也卖了赔给人家了，人生直接大跌谷。要知道，自装业主和工人是存在雇佣关系的，所以理论上是要承担工人安全责任的。一定不要忽视这个问题，否则最后钱没省下来，整个身家都搭进去了。网友@千层饼：自装历时四个月，终于结束了，还没有做精细保洁，照片发小区群，大家都说像串串房，太痛苦了！比较了一下，真的非常廉价，不是因为花钱少，而是自装每一步都有利润，自己又没有多少审美，翻车的泪只能自己独自吞了。后记：自装先问自己懂装修不，如果不懂谨慎操作，一意孤行，只能是自己亲手给自己挖坑而已。并不是自己是干装修的才这样说，而是基本常识。>>>你是否有自装的经验？可以文后留言，让大家借鉴一下。
