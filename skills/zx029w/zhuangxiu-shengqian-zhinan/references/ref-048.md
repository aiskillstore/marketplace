# 装修里头看似省钱的做法，其实更费钱7.12

装修作为业主来说几乎都是盲目的，摸不着头绪，任何一家几乎都是在侥幸与祈祷中度过难熬的装修期。

这个怨不得行业不正规，再正规也找不到第二个行业有这么多复杂工序的交叉和衔接了。

不像开发商盖楼，那是规划好，工人每一步有序施工的，而装修的每一步都和业主的需求以及业主自购的东西有千丝万缕的联系，都需要协调操心，不断的调整。如果是大包装修提前规划好还能好一点，如果是装修机构做一部分，业主自己做一部分，各种施工交叉，面临的问题就多如麻了。

今天谈一下装修里头看似省钱，实则费钱的一些做法，大家可以借鉴参考一下。

第一、害怕装修公司坑自己的钱，认为独立设计+施工队更省钱。
先下结论，这种做法是绝对不会省钱的；如果你要省钱装修，这个出发点本身就是错误的做法。《装修找个独立设计师省钱？坑到哭》

一个人能干的事情，人为分开计算，每一个都得有利润，肯定省不了钱；到时候是为了省钱，设计效果出来了，几万的设计费换来的一套需要几十万施工落地的图纸，不仅没有省钱，最重要的是自己压根无法承受这种落地的预算，导致设计废纸一张。然后设计费打水漂，还得回到刷墙铺地的做法，省钱到哪了？

还有最担心的就是独立设计师与外头施工队勾结的做法，你以为你单独设计做好了，设计师还好心介绍了一家施工队，说是做的不做，经常合作，可以很好的还原自己的设计，其实猫腻是设计师作为卖活方，牢牢的把后期施工也一起吞并了而已，看似给你干活的是施工队，实则幕后得利者还是独立设计师。等于是设计师不仅赚取了设计费，后期的施工利润也牢牢把握在自己手里，而且是高价报价，然后低价卖给施工队，自己反手就拿掉了大部分的利润。可想而知，这种又回到套餐卖活的把戏里头，想要质量唯一的出路就是后面不断加钱才可以。

第二、想要省钱，美缝自己找人做。
这里一定要业主自己搞清楚一个问题，你家美缝是做什么地方的？你以为你家美缝只有瓷砖？不是，重点是后期洁具缝隙、浴柜台面，橱柜石材台面。

如果真想美缝省钱，除过卫生间其他地方都可以不做《瓷缝，卫生间施工必须的工艺》

如果家里全部瓷砖做美缝，还想省钱，一定要考虑长远。例如你自己找人做美缝，外面散工很多，小区里头也很多，做完了拍屁股结账走人，你以为你还能有问题找他们处理？几率很小。最重要的是瓷砖美缝是瓷砖铺完做的，你后期洁具安装以及厨房台面安装以后，这些缝隙你打玻璃胶？然后过不了多久全部变黑发黄？

这就是问题所在，你以为你找的外面瓷缝便宜，到了洁具和厨房台面安装以后，想要做美缝，因为活量太少，你必须单独付出昂贵的费用，才有人给你单独去做。此时你如果找装修公司做美缝情况可能就不一样了，大部分装修公司做美缝看似比散工贵，但是有整体售后，而且最重要的是，你家瓷砖全部美缝的话，后期厨房台面以及洁具做完，直接不用玻璃胶，采用美缝给你免费再次处理一遍，你想想到底哪个省钱，哪个费钱？

当然，前提是你家瓷砖美缝都是装修公司做的，否则后期你美缝谁做的，你找谁做后面的台面缝隙了；有人肯定说了，美缝自己做就行，不需要找任何人都可以，最好不要尝试，就好比瓦工贴砖一样，难道自己不会贴？每个人都能贴砖，只不过你贴的不入眼而已；美缝也是一样，网上买美缝都是带工具的，你借一个吸尘器或者自己买个吸尘器即可，做完的效果只是不入眼，也不影响你入住，如果自己能接受，完全可以自己动手做美缝的。

第三、厨卫瓷砖不贴出来，以为省钱
其实这几乎是大部分找散工的业主犯的错误，这个就是装修里头的细节问题；或者说你找的装修公司不含主材，也不给你操心，就会出现这种问题；也有可能是业主认为瓷砖贴多了瓷砖废钱了。

▲如图所示有可能不是不懂，有可能是害怕瓷砖用多了，厨卫贴砖没有贴出门洞，只贴到内侧，后果是后面要掏更多的钱解决这个问题
▲如图只能双包门套来压住难看的瓷砖，但是你如果不知道，还以为这是常规做法，其实不是，金属门的双包门套要比你瓷砖贵多了，而且这种门套里头并不是实心，时间久了以后里头潮气聚集反而更容易滋生细菌
▲正确的做法是瓷砖贴到门洞外侧，后期直接采用自带套线的金属门安装即可，而且瓷砖要比你空心的金属门套更防水；而且没有单独门套的费用。这才是省钱又实用的做法。

第四、自己买辅料，一是放心，二是降低费用其实这个是多虑了，你家水电材料并没有什么利润，利润在人工和服务费上头。而且水路都是厂家上门打压，水管有问题不用你操心，你想如果厂家打压发现水管是次品或者是山寨，不等你发现都报警处理了，所以水管无需你操心，你只需要看自己想要那个品牌而已。
假如你自己买材料，其实一分钱都节省不了，而且成本是居高不下。因为水电报价是根据品牌报价的，人家给你用的是国产的，你自己即使买进口的材料，人家也不会给你减掉进口材料的钱，而是根据报价里头的材料市场价格减钱。这是其次，最重要的是水电材料不可能用多少买多少，剩余的材料你压根没法退货，这样算下来你完全省不了钱，反而更费钱。
类似的还有油漆辅料，腻子石膏等材料，如果你真的自己购买，最后是不仅一分钱节省不了，造成材料大量浪费；乳胶漆你自己购买，剩余材料自己保管，后期乳胶漆变质无法修补，还得你自己购买材料；除此以外最大的风险是，你给后期出问题找了一个完全无法反驳的借口，大可以都说你的材料有问题，推脱一干二净。
辅料自己购买是完全节省不了钱的，你想节省的费用都在人工和服务费上，除非你自己施工，不找任何装修人员，但是这个无法实现。
第五、装修公司防水太贵，自己做辅料自己购买大不了就是浪费材料，费钱而已，但是如果你找装修机构，防水自己做，这个不啻是自己给自己挖坑。后期一旦出现漏水，你找谁都不管用，防水会推给瓦工，瓦工会推给防水，后果只能自己承受。这种高风险的工种千万不要自己插手，除非你找的散工，否则省小钱会吃大亏，后期砸砖重新做的所有成本只能自己承受。
第六、需要安装的五金，同等质量，自己买更费钱因为几乎所有五金并不是买回来就行，需要安装，就会有安装费用。举个例子，你自己买龙头三百，不含安装不含角阀；你拿装修机构的，人家是包含角阀包含安装，你省钱到哪了？你自己买回来然后再买角阀，然后再掏安装费自己找人安装，最后是钱没有少花，售后漏水的风险只能自己承担。
还有同样质量的水槽你自己买能省一百也不要自己买，你以为安装水槽不要钱？都有费用。最怕的是你买水槽，台下安装装修机构单独收费，后期商家自己安装龙头，然后入住漏水泡了，你找谁？找水槽商家？找人家装修机构？你自己把自己放到了尴尬的境地，风险全部转移到了自己身上了。其实最好的做法是价格差不多，直接交给一家做，后期售后风险都让别人承担，而非自己。
第七、学网上理论，止逆阀安装在瓷砖上想必好多人都把这个奉为真理了，但是脱离实际，后期哭都来不及。
▲如图正常做法是，让烟机商家在吊顶之前，提前预埋止逆阀以及烟管即可，因为止逆阀有两种安装方式，第一种是采用螺丝固定在烟道上，四周打胶密封即可；第二种就是免钉做法，但是烟道上无法实现，于是就有人自以为聪明把逆止阀装到了瓷砖上，美其名曰正规密封
▲如图所示就是好多人推荐的，也认为是比较正规的做法。但其实这种做法不推荐。因为这种做法必须采用免钉胶安装，无法采用螺丝固定，因为打眼会让瓷砖裂缝，而且非常麻烦。
但是你考虑没有考虑过，这么大的止逆阀，一旦免钉胶安装以后，后期想要更换止逆阀，唯一的办法是砸掉这块瓷砖，而且不一定能施工，因为那时候烟机安装了，吊顶做了，如果地方狭小，你有可能需要拆除吊顶，腾出更多空间才能砸掉上头的瓷砖，而且即使砸掉很有可能会损坏旁边的瓷砖，因为现在的瓷砖都是全瓷，背后都是背涂胶，如果是纯胶贴砖更结实，后果就是更换一个止逆阀会造成大面积瓷砖破坏，越砸越多。
止逆阀的目的就是固定烟管而已，只要满足固定烟管密封好缝隙即可，但是一定要考虑长远后期更换，不敢只图眼下的表面正规，而忽略了真正的实际操作。

第八、所有套餐项目，都不省钱都会超支例如让人深恶痛绝的套餐装修，这个不用再多说了吧？如果现在还有人装修找套餐的话，只能自己反省一下自己为什么要找套餐，不外乎眼前的低价，但是你以为的是真的低价就想错了。《被低价装修坑，你无力申诉》
还有目前的各种全屋定制套餐，也是一样的套路，你瞌睡了商家给你枕头，你喜欢低价，自然就有人投其所好，所以被坑怪谁？你不能让所有人都是善良的不坑你，而你自己不付出任何思考和辨别的精力，坐享其成吧？《希望装修公司不坑你？希望都是好人不害你？》
第九、防水做少省钱，这个完全是自己坑自己
▲防水的真实隐藏功能是防止潮气，而非防止漏水，漏水是可以解决的，潮气侵入是没有解决办法的。所以你以为防水做少能省钱，这个只能自己坑自己了《卫生间防水全做错了，被坑还感激人家呢》
