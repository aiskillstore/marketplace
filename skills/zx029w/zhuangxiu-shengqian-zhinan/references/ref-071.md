# 装修5个不能省钱的项目，省小钱可能吃大亏

1. 水电工程 → 埋雷必炸⚠️ 致命隐患：
▫️爆管淹地板▫️短路烧厨房▫️赔邻居+砸墙
✅ 保命配置：
▫️水电材料以当地多年实践材料为目标
▫️关键是专业施工，而不是便宜的工人
2. 防水工程 → 漏水即破产
🚫 翻车现场：
▫️返碱发霉▫️楼下水帘洞▫️天价赔偿
📏 硬核标准：
▫️卫生间刷吊顶位置高度▫️闭水试48小时▫️厨房阳台通铺打死不做防水
3. 厨房五金电器 → 省钱买罪受
🔥 爆炸警告：
劣质灶具＝定时炸弹！油烟机吸不动＝满屋致癌物
🔧 必砸重金项：
▫️大吸力油烟机（功能就是吸烟，其他可以忽略）
▫️热水器老品牌（杂牌寿命非常短）
4. 卫浴产品
▫️马桶再次只不过是釉面不耐脏，但是软管和角阀不能便宜，否则用不了多久直接爆管。
▫️花洒可以不用顶喷，但品质绝不降低
▫️水件五金一定要舍得投入
5. 地砖美缝 → 贪便宜反蚀米
🚫 翻车五件套：
崩角+裂纹+鼓包+色差+鱼腥味！
✨ 避坑指南：
▫️瓷砖不一定非得是贵的，太追求低价，必然有问题
▫️环氧彩砂同色美缝，多大规格瓷砖都可以长一样
