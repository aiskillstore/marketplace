# 天啊！装修定制品竟然砍价？醒醒吧

西安装修材料定制成品的不少，比如：门、门套窗套；浴柜，衣柜，橱柜、窗帘等等

业主大部分不懂行，又不相信装修公司的材料，于是只有自己去满世界跑，认为只要价钱能砍下来自己就是占了便宜了。

认为人不识货钱识货，这个误区导致了建材商赚的盆满钵满，业主还在洋洋得意自以为买到了货真价实的建材。

大家都知道大卖场，比如红星美凯龙的建材是值得推荐的，大部分都是中高端，只要有钱就可以购买，但是大部分人购买的时候喜欢砍价，人家明明标价五千的一樘门，不停的往下砍，营业员煞有介事的做出很为难的样子，最后业主死缠硬磨，营业员很不情愿的样子。

最后请示这个领导，请示那个领导，终于让业主以三千元价格买走标价五千元的门，这一切看似很正常，业主心里偷乐，营业员其实快笑喷了。

大家都知道门是订制品，你看上的东西样子款式必须实地测量你家门洞尺寸，然后在厂家定做的。

一樘五千的门被你砍到三千了，业主自认占了两千元的便宜，其实是什么呢，原价五千你要买成本最多四千，这是良心商家做事，因为店面费用实在太高。现在你砍价到了三千了，不用动脑子都知道商家给你那个门绝对赔钱，但是商家能那样做吗？肯定不能，最终结果是用一千元成本做一樘门当三千元卖给你，说到这不知道业主明白不明白，你的所谓砍价热情其实都是你家的成本而已。

门，柜子，浴柜，窗帘，只要存在定制的东西不要在砍价了，你砍多少都可以，定做产品给厂家一个电话就可以降低成本的，所以好多业主聪明反被聪明误，自以为买到好东西，其实是被人涮了。

还是陈工一直强调的那句话，有多钱你买多钱东西，既然没有那么多钱你就买自己买得起的，天上不掉馅饼；你非得掏买菜的钱去买金子，上当必定是你。
