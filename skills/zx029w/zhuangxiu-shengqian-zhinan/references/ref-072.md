# 出租房装修，怎么更省钱？8.14

出租房装修和自己住的做法是完全不一样的，首先搞清楚一点，出租就是为了赚钱，能多赚钱就是出租房存在的唯一意义。

出租房的价值需要结合地段，性质，户型好坏，布局好坏，决定采用毛坯还是装修出租。

1.根据出租年限决定出租方式。如果房子只想出租一两年，然后自己住，不如不装，因为房租压根收不回装修费用。一两年之后租客有可能更换频繁，新装修早都面目全非了，到时候自己住少不了折腾，还是费用。但是一两年如果不出租，又不装修，自己还得掏物业费，取暖费等等费用，等于房子产生了负价值。所以这种情况就可以考虑毛坯出租，只要租金可以抵消这几年的空闲费用就可以，一般可以作为库房使用，好多电商都会需要住宅毛坯作为库房，成本低。一两年以后你想自己住，直接装修即可。
2.如果打算出租五年以上，后面可能自己住。这种年限才是装修的条件，不论什么地段，五年足够收回装修费用了。
这种房子才值得装修，首先水电到位，厨卫瓷砖直接做好，其他地面全部工程木地板，这里注意，可以不用找平，直接通铺工程木地板即可，耐用，即使少量泡水都不会有什么问题。后期自己不论是铺木地板还是瓷砖，都省去了砸地面的费用和风险。
至于洗衣阳台这些地方，统统不要墙砖，只铺地砖，这也是节省成本的办法。橱柜只要满足洗切炒的功能即可，千万不能像自己住一样满做。
所有木门采用耐用的免漆门，踢脚线采用PVC即可，所有墙面采用乳胶漆变色，为什么要变色？因为在同等成本下，墙面的色彩是为了利于出租而已，毕竟租房的都是年轻人，一个大白墙和一个局部彩色的房间，肯定选择彩色的。
洁具以耐用为准，只要能使用即可，且不可讲究什么品牌。
五年之后，直接揭掉地面木地板，就是原始地面了，自己需要铺木地板或者瓷砖都很轻松，不需要牺牲层高了。厨柜拆除新作，洁具拆除新作，墙面可以铲除重新做，所有木门统统换掉即可。
3.长期出租的房子。如果房子就是长期出租，那肯定全部瓷砖，耐用，不论更换多少租客，都不会像木地板那样损耗程度很高。墙面尽量采用可以擦洗的特殊乳胶漆，以便更换租客以后方便清理墙面。
至于一些自住的生活细节完全可以不做，比如各种哑口套，窗套，壁龛，镶嵌洗衣机等等，这些都不需要，租房的人不会在乎房子的这些功能，否则就住酒店了。
4.出租房安全问题不容忽视。在拟定出租协议的时候一定注意各种安全责任划分，特别是家里的电器安全，像热水器一定不能使用电热水器，尽量减少不安全因素的存在。入住人数协议里一定约束清楚，否则以后出事承担的责任太大了装修实在没钱，有什么直接可以不做
