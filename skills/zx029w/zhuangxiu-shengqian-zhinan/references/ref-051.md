# 装修省钱小心踩坑！这8个行为，表面省钱实则更费钱

装修省钱是个永恒话题，一方面是经济原因，必须省钱；第二是堆积建材的冤枉钱的做法。装修的真相：装修房子里头人的生活，而不是房子。你如果一味去以装修房子“躯壳”为目标，往往会南辕北辙方向错误；装修省钱要掌握方法，否则不仅不会省钱，反而更加费钱；今天盘点8个不省钱反而更费钱的行为，大家对号入座，看自己是否也在犯同样的错误。第一、一口价套餐形式。老生常谈了，自从有装修就有套餐装修存在，各个公司不论大小，打一枪换个地方，到目前为止仍然是装修市场里头大多数的做法。因为一口价，业主会认为不用操心什么都包含了，而且价格低还都是品牌。但至于真的包含完了没有，那明显是秃子头上的虱子--明摆着低价切入而已。因为不可能给你包全项目，才能低价切入，才能低价让你签单。同时也因为偷项漏项很多，才符合二道贩子的套路---给包全了后期卖给工长，工长没有给你增项的余地了。都用了品牌还低价，那是因为所有建材都是“特供”--订制品而已，完全就不是你所认为的市场上的大品牌建材；看似价格很划得来，那是因为业主不懂装修项目，有太多项目没有算进去，后期不断给你加钱，总价会比任何装修机构都贵。看似你找了省钱的装修机构，实则是哄骗你上钩，然后慢慢宰割而已，等你醒悟一切都迟了，不信你可以用以下关键词，在搜索引擎搜索一下：……套餐装修坑……套餐装修宰人……套餐装修低价坑……套餐装修陷阱……你就可以看到前人踩出来的一条血路……总结：不要碰套餐装修，碰了绝对省不了费用，会让本身想省钱的业主雪上加霜，土豪可以随意！第二、纯设计+施工队。是不是有人以前人经验的身份告诉你，装修最省钱而且有效果的方法，就是自己找纯设计，然后找个施工队就可以做出高级效果？有一大部分人这样做了，但是几乎百分之九十九都会入坑，不仅不会省钱，反而花了更多费用。纯设计顾名思义就是找独立设计师做整套设计，相当于你找私人秘书、私人保镖一个道理，除非你有钱。因为没钱的人直接都找装修机构了，而且装修施工本身就有利润，设计都是免费的。独立设计很简单，但是你的出发点和目标是矛盾的。你能找独立设计+施工队，本身就是为了省钱，你却去找独立的收费设计师，是不是本末倒置？！你如果装修就是刷墙铺地的预算，压根不可能找纯设计的。因为这样的预算设计没法给你做，给你做了你压根看不上设计，不会付设计费的。你自己就是想省钱必然不会复杂装修，但是独立设计师为了赚设计费，只能给你做复杂的设计，只有这样你才能看上，你才能去掏钱。但是这个效果和你的预算没有半毛钱关系。等到你花了几万拿着施工图去找施工队的时候，会有两种坑等着你：①做一步看一步。这是大部分人看着独立设计师的图纸的做法，只有这样你才感受不到钱如流水，以为是物有所值省钱了，殊不知这个就是独立设计师和施工队给你下的套。做一步付一步钱，你永远感觉不到多，以温水煮青蛙的方式让你装修费用越来越多，到最后你醒悟已经迟了！②施工队报价见光死。拿着独立设计师的设计，让施工队报总体预算，此时你会发现，你找遍当地的施工队，预算高到让你完全无法接受。此时你是否会明白：为什么独立设计师要给你做这么复杂？因为只有这样才能哄骗你的设计费，而你自己其实预算就是刷墙铺地，只不过是钻进一个又一个圈套而已。此时你只有两条路可走：1.设计成废纸，回归自己的刷墙铺地，几万设计费打水漂；2.硬着头皮借钱或者贷款装修一套压根和你生活不匹配的装修。综上所述：你采用独立设计+施工队的方式压根不可能省钱，这个方式本身就是土豪的标配，咋可能省钱？最可悲的是大部分业主太高看装修了，太过于自信，明明自己家就是刷墙铺地，却误认为憧憬中的新家就是豪华美家，结果掏了几万设计费无法落地，几万几万都打水漂，目的是为了省钱，行动却是土豪的做法，本末倒置！第三、为省钱不做吊顶，通顶定制。装修的时候一旦让吊顶，业主就感觉你这个是让多花钱，也不看这个吊顶的目的是什么。吊顶永远离不开目的，缺乏目的支撑的吊顶那就是样子货了。吊顶费钱，不做吊顶，结果客厅收纳柜通顶定制，这个本身就是本末倒置。定制要比石膏板贵太多了，你定制不讲究美观直接通顶，比大梁和风管机吊顶高出很多，不仅仅费钱，而且美观大打折扣，甚至可以说是翻车。同样有风管机，只做有目的吊顶，空调以及定制上头做了吊顶，让视觉上等高，压低定制的高度，其他不做任何多余吊顶，不仅是省钱，同时保证视觉上的美观，这个才是装修的最终目标。卧室也是一个道理，你以为不吊顶是为了省钱，但是定制通顶定制反而更丑，花的钱更多而已。卧室只给衣柜上头做吊顶，目的就是为了压低定制高度，视觉上更美观，其他没有目的性的吊顶都不做，定制压低总体费用反而更低。综上所述：通顶定制上方最好做定制，一是为了压低高度，不至于难看压抑，第二定制要比石膏板贵很多，所以反而更省钱。第四、为省钱自己买水电材料。是不是装修的时候，总感觉自己买材料肯定省钱？其实有些是，但有些并不省钱，反而更费钱。第一、水电改造费用高压根不是材料贵，而是人工贵。第二、水电想要省钱避坑，必须是估价谈实际出入。后者才是最大的用心思的地方，但是好多人以为水电材料购买就可以省钱，完全没有必要。你自己购买材料，那装修公司按照米数计算，你会以为给你减掉多少钱？装修机构的费用计费方式是不会改变的，你自己购买材料，人家减去的是人家包含材料的市场价格而已，到最后你会发现这些和水电总费用比简直是九牛一毛。例如装修公司材料是2000元，你即使购买一万的材料，人家减去的是人家包含的品牌2000材料，可不是你购买的一万的材料。你自己买材料以后，剩余的水电料除过浪费，几乎没有其他用处，反而造成很大的浪费而已。而且大部分业主都没有购买渠道，私人去市场购买，很有可能买到非标产品，反而得不偿失。你这样做装修机构只有省钱的份，是装修机构巴不得的行为。综上所述：装修水电改造，因为水路都是厂家上门打压，完全没有必要考虑水管的问题，而且水电费用那么高，装修机构都是统一配送，划不着在材料商动手脚。而你自己购买材料浪费不说，可能这样后期售后，会让存心不善的机构利用起来，把售后问题归结到你自己的材料上，到时候扯皮更加得不偿失。第五、先装修后付款。装修最怕自己太过于自信，千万不敢想着商家都是傻子，否则真正的傻子可能是自己。市场上所有先装修后付款只是一个叫法，并不是真的装修完了再付款，而是利用阶段付款，把你家活占住，你找谁都迟了。真相是：先装修后付款=边装修边付款。你以为便宜？其实是最贵的。本身就是笑话，但是还真的有人当真，这就是明知山有虎，偏向虎山行了。坑是自己跳进去的，就问你：先结婚生子，然后给彩礼行不？如果正常整体做应该是10元钱，先让你付1元先干着，你以为真少，后期阶段付款，不断增加费用，最终不论付多少次，都会大于原有的10元，可是你不算，以为每次都少，其实总价更高！第六、套餐定制和装修一丘之貉。你以为的套餐定制便宜，实则就是你的爱占便宜心里坑了自己而已。都不用思考，这世上相信天上掉馅饼已经注定你会吃亏！别碰装修套餐，定制套餐更不敢碰，其实就是看上去什么都有了，但是你压根不懂什么不包含，后期任何额外要求，都得加钱，因为不加钱压根实现不了功能，导致前期自欺欺人的便宜，后期总价高于任何人，这就是套路。这世上就没有不劳而获，也没有不动脑子就能顺利的事情。所以弄清楚包含什么，不包含什么，看自己预算决定用什么板材，别抱有任何侥幸心理，你运气好商家给你打半价，只要你没原则，必然是自己找坑了。第七、防水自己做省钱？自己做防水的前提是瓦工也是你做，否则这完全是把自己往坑里头推。你想一想为啥瓦工做防水贵？因为这就是利润呀，你把有利润的自己做，难做的留给瓦工，是人都不会高兴！何况你的防水是瓦工之前，那瓦工完了漏水了，你确定你找人家瓦工能成立？防水人家又没有做。省钱是要讲究方式方法的，不是蛮干，以为表面的省钱就是省钱，完全不是这回事！你自己找人做防水，后期漏水了，你找人的人和瓦工都会推诿，最终砸掉重做的只有你自己，那时候可不是省钱了，你需要付出两倍的价格为自己鲁莽买单了。第八、烟机止逆阀自己买省钱？买烟机的时候总感觉烟机带的止逆阀要贵，或者总感觉人家的不好，非得自己买，后果就是烟机安装止逆阀独立收费，这个是小钱，关键是后期一旦出现止逆阀漏烟，连个售后都没有。开发商止逆阀不能用，一定让烟机商家提供止逆阀，这样烟机和止逆阀都是商家提供的，后期不论那地方漏烟，都是可以享受到售后的，花小钱办大事才是装修省钱的方法。写到最后：装修省钱绝对不是节省眼下的金钱，需要掌握方式方法，看到价值，不仅要节省金钱，同时还要省心省事，达到价值的最大化才是真的省钱装修！
