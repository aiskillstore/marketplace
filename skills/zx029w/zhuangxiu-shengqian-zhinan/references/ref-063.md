# 装修最容易花冤枉钱的33个地方1.20

装修最怕什么？其实最怕被坑，大部分业主都知道，你该赚的明着赚，不要靠蒙骗就好。所以今天把所有装修容易加钱的地方都一一列举，希望各位业主重点考察一下。

1.扛着很高端公司的旗号，做着最烂的设计，实则刚毕业的学生，设计费张口就要。此时业主就得懂什么样的设计才需要付费，什么样的设计不需要付费。傻瓜式判断，设计师给你做的你都想到了，压根没有新意；设计师做的你压根想都没有想到，这才是设计；
2.定金/订金。各种名目，电销用优惠馅饼套路；实体店面送东西吸引业主，反正记住一句话，不和你谈设计和你房子怎么装修，不替你着想，只给你谈活动和优惠，让你交定金享受某某优惠，一定不要交，交了就不要后悔了。
3.样板间。这世上只有一种样板间，就是完全免费的样板间。比如你家房子交房，作为样板间装修，一分钱不收你的，给你装修好，家具家电都放好，然后装修公司使用一年或者两年，然后交付给你。这样的样板间才是真的样板间。而不是嘴上说你家做样板优惠，实则是提价优惠，完了你会发现，别人家10万，你家优惠样板间12万的尴尬。
4.量房需要先交钱。如果装修真的能做到这份上，那就何来竞争？业主叫十家量房，难道得交十份钱不成？所以在你找装修机构的时候一定拿定主意，找公司就找公司，不要公司和工头散工一起比较，这个是无意义的劳动，不是一个概念。
5.开工要红包。这个是少数，但是有，开工的时候让业主发红包。其实一般人也不会开这个口，哪怕是图个吉利也不行。毕竟装修花钱说不定都是节省出来，或者东拼西凑出来的，你好意思把你的快乐建立在业主的痛苦之上？
6.开工拆除故意漏算面积，中途加钱。比如拆除面积故意少算，合同价格低。签了合同活卖给工长，工长现场发现拆除面积大于合同面积，于是工长就各显神通，能加钱则加钱，扯皮就开始了。
7.开工不拆除先搞面子工程。如摆个供桌，放上假红酒，拉上自己都害臊的开工大吉横幅。其实这都是业主的钱，如果可以不搞这些退500行不？
8.开工黄墙绿地面子工程。墙固和108胶和界面剂是一样的作用，这个是在批腻子的时候才刷的，然后现在的装修公司进场先搞面子。你墙固刷也不看墙面需要铲除不，也不管工艺到位不，只要表面把业主糊弄好就行。地固号称防尘，你个装修工地本身就有灰尘，防哪门子的尘？这就完全赚的面子钱，搞形象工程还得业主出费用，还得有利润。你以为你是会所开工？
9.水电开工交底不估价。糊弄业主不会估价，或者估价随便报，不提实际出入，就是一门心思黑到底。不坑业主的都是傻子。业主只有挨打的份。
10.水电打压收费，糊弄业主不懂行。水电打压本来就是厂家免费上门，你用什么品牌的水管，都可以联系上门免费打压，和装修公司无关，然而故意设计门槛，业主掏钱厂家打压售后50年，不掏钱装修公司自己打压，售后五年，然后让业主自己挑。这坑的就是外行，一点都没有防备。利用信息不对称来欺骗业主多花冤枉钱。
11.电路底盒锁母单独收费。好多利用业主不懂，信息不对称，给业主说是否加锁母，加锁母有什么好处，然后你要加一个多钱，你不加就正常施工，可能会有什么隐患等等，逼迫业主主动加钱。
12.电路点位套路。号称水电不单独算，只要不超出不会有单独费用。然后合同里头包含20个点位，业主不懂呀，实际做出来比合同点位多好几倍不止，业主被动被宰。这种方式多为套餐公司所为。
13.水电料剩余材料让业主承担。这个就有点奇葩，你水电施工米数是按照实际做的，剩余的材料你自己拿到别的工地继续使用，然而有的奇葩工长竟然让业主承担材料的损耗：给你家施工，只要裁过的水管，线管、电线都让业主掏钱。
14.瓦工项目不包烟道。这是好多装修公司故意漏项的地方，业主只知道包管道，但是不知道烟道是需要红砖包了才贴瓷砖的，小费用积少成多。到进场的时候，工长就开始说利弊，让加钱再做，常用的套路。
15.防水只提品牌不提颜色。进场开始告诉业主一种是水泥色，一种是蓝色，彩色可以看清刷到什么程度，水泥色刷不刷几乎看不出来，合同里头是水泥色，需要彩色加钱，吓得业主赶紧掏钱。工长的利润有了。
16.防水不提刷多少面积。这是好多业主吃亏上当的地方。为了低价切入，故意把防水做面积很少，施工进场给业主说不刷到顶有什么厉害关系，再次让业主加钱。
17.防水加完钱，连带拉毛也得加钱。防水加钱刷高了，就会有瓷砖无法贴的问题，必须拉毛，又得加钱。这就是典型的低价切入的做法。各位一定看预算注意做法，不要只看价格低。
18.不提瓷砖铺法和费用，进场凭本事工长自行加钱。铺砖不提缝隙宽窄，比如目前都没有一毫米的铺法了，业主瓷砖到场最窄2毫米卡子，不好意思，合同里头是一毫米铺法，缝隙宽了加钱。
19.勾缝剂业主提供本身是免费瓦工勾缝的。但是进场就说合同里头没有勾缝免费一说，让瓦工勾缝加钱。
20.故意漏算铺贴面积。比如装修公司为了低价签合同，故意把铺砖面积算少，进场工长就开始丈量面积，让业主加钱。
21.全包提供瓷砖故意少算数量。装修公司提供瓷砖，故意少算块数，然后进场就不够了，必须让业主加钱才行。和外面卖瓷砖的一个套路。
22.故意漏算瓷砖倒角或者减少米数。同样的低价切入的套路，活卖给工长，就看工长的修行深浅，然后再加钱，加不上工长倒霉，加上了工长有利润了。
26.瓦工铺砖故意因为高低不同加钱。比如合同里头规定高于多少加钱，从来不提低于多少减钱，利用信息不对称后期加钱。
27.木工吊顶故意作为个性要求，不在预算体现。这种套路套餐最多，看似合同价格低，其实是自欺欺人，后期做造型上了贼船就可以随便宰。
28.龙骨不交代，后期变更再加。如大面积石膏平面吊顶，不告诉木龙骨和轻钢龙骨的区别，后期进场忽悠业主更换，再加钱。
29.油漆工进场，工艺材料加钱。例如故意拆项，基层处理不含石膏找平，不含挂网，不含贴布，然后让业主加钱。
30.做墙面借口墙面不平加钱。基层处理本身就包含墙面不平的处理，但是施工的时候借口墙面误差太大，加钱处理。
31.插座安装本身必须做的项目，故意让业主自己装。合同里头不算，合同价格可以低，后期业主自己装发现线路都找不到，还得装修公司安装，然后再让你掏钱。
32.防水属于水电预收，很扯淡的逻辑。这种公司千万不敢用，把防水故意不算，和水电一样按照实测实量，看似合理，其实就是为了低价切入好签合同。
33.未完工就让业主交尾款。像这种公司压根不可能给你售后，比如后面故意有个东西不安装，逼迫业主交尾款再安装。像这种公司一般都不可能有售后的，目的就是收钱就行了。
