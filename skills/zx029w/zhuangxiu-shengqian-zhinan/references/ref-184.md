# 卧室床挨着窗户或阳台，放床头柜就太浪费了2.9

床挨着窗户的户型几乎刚需房都是，因为空间原因，基本放上床以后，基本靠近窗户了，一般就是放个床头柜搞定，但是墨守成规的布局往往让功能仅仅刚需，没有拓展，没有提升。今天看一下不同布局，可以作为自己装修的借鉴。
第一种：床靠近平窗。

▲如图床铺靠近平窗，舍弃床头的床头柜，采用轻便的小几代替，靠着平窗定制收纳柜以及书桌，还延伸了一个休闲卡座，功能得到最大拓展

▲不要床头柜，平窗延伸定制书桌，满足学习功能，同时书桌也可以兼顾床头柜的置物功能
▲如图床靠近平窗，空间足够可以舍弃床头柜，利用床尾衣柜延伸定制一个超级书桌，功能得到拓展，同时书桌也可以代替床头柜功能▲同样做法，空间够大，都可以拐角定制一个床头柜，功能性更丰富▲如图床靠平窗，舍弃原有床头柜，直接放置成品的化妆台，拓展原有的床头柜功能的单一▲利用窗户打造收纳以及休闲，不要床头柜，功能更丰富▲靠近平窗，利用原有床头柜的位置，悬空化妆台布局，功能更强大，而且悬空设计视觉更轻盈第二种：床靠近飘窗▲如图床铺靠近有飘窗，如果非常近，就可以不要床头柜了，飘窗台面本身就可以放置物品，代替床头柜的置物功能▲如图舍弃原有放床头柜的位置，原有飘窗砸掉做了飘窗柜，借用飘窗位置，实现了一个悬空的化妆台功能，同时也兼顾了床头柜的功能，功能性得到拓展▲如果飘窗墙体太宽无法利用，也可以舍弃床头柜，直接满足一个化妆台或者书桌即可，比单一床头柜功能要丰富很多了▲如图靠近飘窗，无法利用飘窗，可以用化妆台代替一个床头柜，功能性得到拓展▲如图如果飘窗很大，直接靠近床头书柜定制，延伸一个书桌兼顾化妆台，比单一的床头柜更实惠▲位置很小，借用飘窗实现一个化妆台的功能，完胜单一床头柜▲床头靠近很低的飘窗，利用飘窗延伸改造成了书桌，同时高柜开放格定制，同时满足书柜以及兼顾床头柜的功能▲床头靠近L型飘窗，不要床头柜，利用飘窗做了书桌，本身飘窗就可以兼顾床头柜，同时抽屉满足分类收纳▲延伸飘窗做了书桌，利用拐角设计，床头柜位置兼顾了化妆台和书桌功能，代替了床头柜的单一功能▲利用飘窗空间悬空化妆台，远比一个成品床头柜要功能强大▲利用飘窗满足收纳，同时拐角设计 ，延伸化妆台功能▲靠近飘窗设计床头柜，满足了一个化妆台兼顾书桌的功能，同时原有床头柜的功能兼顾了▲飘窗延伸满足了书桌，同时利用延伸满足了开放格定制，代替单一的床头柜功能▲同样利用单一床头柜以及飘窗空间，让功能更丰富，更有价值▲原有单调床头柜，利用飘窗满足了一个书柜，同时满足了书桌兼顾化妆台的功能▲即使小空间，利用飘窗也有出其不意的效果▲空间再小，也可以舍弃床头柜，延伸飘窗成就书桌，比单一床头柜要更有价值▲足够小的空间利用飘窗，可以让功能更丰富，更有价值▲利用飘窗不仅视觉更协调，同时功能更有拓展，而悬空的做法视觉也轻盈简洁▲利用飘窗以及原有床头柜的地方，完美实现了化妆台功能以及更多收纳▲空间实在太小，为了满足基本功能，利用飘窗拓展出来一个基本睡眠功能▲空间小刚好靠窗不用床头柜，飘窗本身就满足了置物功能第三种：床靠近阳台▲如图床靠近阳台位置，没有位置放床头柜，刚好借用阳台一侧定制书桌延伸到床头位置，满足书桌以及兼顾了床头柜功能▲如图同样床铺靠近阳台，利用阳台收纳柜延伸隔板代替床头柜的设计，视觉更有延伸感和高级感▲床靠阳台，化妆台代替床头柜，同时阳台布局一个书桌，功能都得到拓展▲床靠小阳台，舍弃床头柜定制▲床靠阳台舍弃床头柜，采用小型置物架满足一个床头柜的功能，随手满足置物需求
