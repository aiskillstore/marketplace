# 装修低价钓鱼那么坏，有人为他叫好10.15

关于装修机构方面的选择，本号已经说了很多，好多都是重复去谈的，每个角落几乎都有谈到。如需翻阅，微信下方菜单“陈工原创”里头就有专门找装修公司的版块。或者你后台直接回复“套餐”有各种专题。

关于套餐装修公司的批判文章也非常多，几乎没有说过这类公司的好话。根子坏了是干不出什么好事的。但是发现和个别业主沟通过程中，发现有人给套餐公司叫好。比如价格就是低，反正装完了没有什么问题，目前已经入住。

但是这种叫好是建立在不知道的基础上。比如套餐没有详单，就是列个笼统的单子，很明显里头橱柜地柜只包含4米，吊柜包含两米，其他多出来的呢？加钱呀，可是业主不以为然，竟然给辩解：不含的当然加钱了实在让人大跌眼镜。

还有卫生间防水只做了30公分高，业主辩解：人家就只包含这么多，你要多高加钱天经地义多好的业主呀，前期怎么给低价钓鱼，后期再加，都感觉是天经地义，如此无知无畏实在是可叹！

类似的项目很多，比如铲墙呀，拆除墙体呀，套餐都不包括，还有生活阳台不贴砖，只包含乳胶漆，业主辩解：是呀，你要贴砖，后期当然给人家加钱呀！严重怀疑业主是不是这个套餐公司的亲戚

签合同三万，一边干，一边加钱，最终加到6万，业主会说：正常呀，加钱的都是人家不含的，应该的呀。你说碰到这样的人，陈工无语辩解，只能瞠目结舌！

如果都是迪拜的土著，装修这点钱真的不是钱，但是现实是大部分都是刚需。房价如此高的当下，有几个装修房子的业主手头宽裕的？谁不是规划了再规划，考察了再考察，小心谨慎的去对待装修。就怕碰到开头低价，后期加钱的坑人公司。

所以，不怕你没钱，就怕你无畏，这就没救了。
