# 装修预算这么多门道，以前都不知道

装修的总价无非是包含以下几项：
1、设计费；2、主材费；3、辅材费；4、人工费；5、管理费。

设计费：西安各大装修公司都是免费设计的，这里业主一定要搞清楚，免费设计只是给你做初步设计方案，是简单装修设计，如果过于豪华或者复杂还是要收费的。关于收费设计和免费设计业主可以参考《原创|装修之设计收费与免费》《装修设计费--【收费】和【免费】互相撕逼的游戏》（直接点击阅读）

西安地区大部分工薪族装修一般很少有复杂的，基本都是刷墙铺地做个简单造型等，像这些完全可以利用装修公司的免费设计来完成。

不要听无良媒体或者某些居心叵测的装修公司说免费设计有陷阱，动脑子想一想如果业主只刷墙铺地你收设计费你脸红不？你设计了什么？认为免费设计是陷阱的只能是免费设计让某些利益集团得不到利益了才说的，比如媒体，比如给媒体掏钱的大公司。

主材费：这是占据装修费用中的大头，如果是半包或者清包装修，一般这部分费用都是不给装修公司的，因为主材由东家自己来购买。主材是装修公司可以从中赚钱的大好机会，你应该也听说过设计师收回扣之说吧。之前我也有写过关于全包、半包和清包的关系，个人是建议半包的。全包的前提是你能看上装修公司的主材，而且人家比你拿的低。业主可以参看《借装修公司优势，买到便宜的材料，这才叫本事！》《看图聊装修之回扣----你自己犯的错而已！》（直接点击阅读）

辅料费：随着半包越来越多，而且主材价格越来越透明，现在装修公司和装修队都要从辅料里面赚钱了，还有一个原因是一般人只关注占据大头的主材，对于辅料可能就忽略了，其实辅料全部加起来价格也不菲。

人工费：各个地区的人工费会略有不同，不同的装修公司不同的师傅也有可能收费不同，不过这个不会相差的很多，基本也可以在网上查到个大概，问问自己城市装修过的网友基本可以了解到人工费的范围。但是一定要明白，西安地区分本地和南方，工费相差很大。

管理费：这个是装修公司才会有的收费项目，如果是清包或者半包的游击队一般不会有这项费用。一般收装修总费用的5%-10%，市面上的一般装修公司收8%的会比较多。人家装修公司也是要生活的，有这费用也是正常的。不过有管理费和没有管理费和总价一点关系都没有，这块业主谨记，不收管理费比收管理费的总价有时更高。不要被表面的形式迷惑，得具体看实质内容。

看报价可以注意以下几点：
1、报价是否详细。所有材料的品牌、系列、型号、数量、单价是否都写清楚了，如果光写一个品牌可以动的幅度是非常大的。比如乳胶漆同一个品牌中，最便宜的系列可能只要100元一桶，最贵的系列可能要上千元一桶。（回复“偷项漏项”查看常规容易漏掉的项目）

2、明确增项。签合同的时候要写清楚每个项目增项是装修公司责任，公司自行承担。否则很有可能遇到刚开始以低价预算来吸引你签订合同，后期不断增项，导致装修费用远超过预算。当然你看报价的时候也要看清楚是否有明显的漏项。（回复“偷项漏项”查看常规容易漏掉的项目）

3、重点关注水电和油漆。这两个版块是装修公司的利润重点，一般如果你想半包，装修公司也不愿意把这两项的主材让你自己来购买。（回复“水电”查看水电注意事项）

4、多多比价。装修中，很多时候金钱和时间是可以相互置换的，你花时间越多就越了解行情，不至于被黑。当然前提是你了解行情，否则你比较N家就是比较总价，没有任何意义。（回复“预算”查看预算注意事项）

好了，说了这么多，总之不用急着签订装修合同，看仔细一点总是好的。该说清楚的都应该白纸黑字写下来。

以上只是理论知识，陈工现在都害怕理论了，现实是残酷的。
