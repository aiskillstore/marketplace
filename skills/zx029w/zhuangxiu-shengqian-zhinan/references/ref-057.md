# 老百姓装修，26个省钱渠道9.24

省钱和装修并不矛盾。有钱装好，没钱装孬，铁定的规律。但是在省钱的基础上，怎么能做到功能完美，而且在看似省钱的做法下，能把价值发挥到极致，这个对于新手业主来说非常难了，最起码不要无故花一些冤枉钱。

省钱绝不是只看总价，而是只做必须的，并非自欺欺人以为总价低自己就省钱了，这样做法刚好中了低价切入装修公司的圈套，完全是自己坑自己而已。
1.吊顶。看预算，如果真的没钱，家里除过厨卫铝扣板以外，没有什么地方需要要吊顶的，你如果非得学着别人装修，感觉没有吊顶不像装修，硬着头皮去做，完全是活受罪而已。
2.厨卫吊顶。这个压根不需要什么品牌，需要的只是能二次拆卸维修。不要傻到问铝扣板什么品牌，你要什么名字提前说好，出厂可以直接给你打上钢印，有什么用呢？不论什么铝扣板，一定是没有存在感就是最好的审美了，也就是纯色系列，千万不要花里胡哨，花钱买丑适得其反。
3.瓷砖能通铺尽量通铺，不要人为分割地面，在有限的费用里头，放大你家空间。
4.电视墙就不要做了。装修入住都是问题，做个充面子的电视墙，真的是活受罪了。没有一个人看你家电视墙花了一万而看得起你，相反，如果知道你没钱，借钱贷款做一个一万元的电视墙，立马和你绝交。
5.水电借用原有的。不要听信装修公司给你说开发商的水电不能用，让你全部更换，你得看看你的钱包，如果有钱，可以更换，至于更换了以后是比开发商的烂还是好，就是掏钱买个安慰而已。但是没钱还是算了，务实要紧。
6.纯设计就不要做了。你得看看自己的钱包是否能支撑纯设计费，同时看看自己巴掌大的地方是否划得来请纯设计，同时你得预想设计好了，是否有足够的金钱去让设计落地。千万不要打肿脸充胖子，装修来不得半点虚的，本来就够累人了，不要自己为难自己。
7.监理就免了，不相信装修公司签什么合同？你以为装修真的有所谓监理，你请的监理也只不过是过去干装修坑人太多做不下去了，转行做监理的。本性是改不了的。不论哪种职业，人的品行才是基础。何况装修监理都是民间组织。
8.在同样价格下，瓷砖可以点缀。例如家里的各种可以做背景的地方，瓷砖价位一样，铺贴工费一样，用个不一样的花砖可以让家里出彩，何乐不为呢？一分钱可以发挥两毛钱的功效，这才是省钱的重点。
9.乳胶漆墙面白色与彩色一个价位，何不多点审美，让家里更好看呢。只要彩色不加钱，完全可以彩色涂刷，同等价位为家里添彩。
10.购买乳胶漆看型号和价位，不要盯着品牌看。否则买回来品牌的垃圾乳胶漆刷到家里，真成了自欺欺人了。
11.地漏看防臭，不是看材质。不锈钢普通的最耐用，别学着酒店做长条形地漏，又不是拍电影，日子以后还得过，中看不中用，还让家里藏污纳垢，多花这个钱干啥
12.客厅带阳台，窗帘做阳台。你家客厅和阳台之间弄个布帘干啥？有投影还是跟着别人屁股跑，不仅费钱让经济雪上加霜，而且让小客厅变得更小。
13.能用挂机不要跟风用柜机。即使价格一样，不占地，而且让你几万元一平的房子看起来更大，这才是务实。
14.同样做水电，洗衣机以及洗手盆下水都是竖管，而非地漏。家里用地漏的地方除了淋浴以及卫生间打扫卫生间用，其他地方几乎用不上地漏。
15.地漏只要一个下水功能。市场上花里胡哨分区域的地漏，只不过让你多买而已，洗衣机地漏本身就是反人类的设计，竖管比地漏更实用，而且还省掉了地漏的费用。
16.从来不关卧室门，木门就要便宜的。木门价位从几百到几万都有，要省钱就用便宜的，只要安装工艺过关，就能用，不要把钱花到完全使用不到的地方。偶尔关门，再烂的门也能满足隐私，你以为你一万的门就能隔音，隔音和门的厚度重量压根没有关系。
17.窗帘能用纱帘不用布帘。特别是需要光线的公共区域以及书房，省钱而且透光，还能视觉上放大空间。
18.能不改格局不改格局，除非为了健康和入住功能。例如增加房间或者收纳以及干湿分离。其他砸墙就为了好看的背景还是算了，看看钱包决定。
19.能不用石膏线就不用石膏线，这个就是装修公司发明用来偷懒的。你以为家家户户用石膏线是为了好看？不是，是装修公司发明你们却不知道，他们懒的把阴角做直而已，否则直接做吊顶，哪怕宽边呢，得看钱包决定。当然，能把石膏线或者PU线上墙的，另当别论。
20.定制不看品牌看实质。不要跟着大众思维只看品牌，有品牌就不是定制了，那就和苹果手机一样是一个具象的商品了。所谓定制就是独一无二，你家唯一，所谓品牌就是你找谁去完成定制而已。这里的品牌和你家质量环保没有一点关系，充其量就是个名字而已。
21.除过厨卫能不用墙砖尽量不用。装修需要思考，不是跟着爷爷奶奶那一辈的思维进行，费钱还难看。
22.能不用门套窗套都不用。没有一点用，而且还让刚需房子看起来更小，更乱，更没有品位。
23.美缝卫生间必须做，其他看钱包。不要为了面子累着自己，完了装修总超支。
24.防水卫生间做到吊顶位置，厨房无地漏不做，阳台通铺竖管不做。该花钱必须花，不该花钱一分都不花，不要糊里糊涂乱花钱。
25.飘窗不养花直接铺瓷砖，后期垫子盖住了。不要跟着别人屁股做石材，哪个便宜哪个务实，再看看钱包决定。
26.玄关以及各种背景就不要了。不要人为给门口做个没有任何功能的障碍，风水是你的务实精神以及进取心，风水不是学着土豪东施效颦。
