# 装修没有无缘无故的低价，迟早得还！11.4

我们一直认为商人是无利不起早。哪有利益那就有商业。可是今天，反过来看看商业场上的消费者，那更是无利不起早。

图为某超市的促销活动，买多钱送多钱券的活动现场
无利不消费好像是现在一个普遍现象。中国人最爱问的一句话就是：还能便宜吗？大到买房，小到买菜，反正都会看是否有优惠，是否有打折，以此作为消费的理由和动机。我们好像从来看不到除自己以外的任何价值所在，除了自己，其他一切都可以廉价甚至不劳而获。一不小心让身边人知道自己买东西不搞价，显得很丢人，显得自己很落伍一样，更有种已经成了冤大头永不翻身的耻辱感。

装修市场，业主问的最多的就是，你们有没有活动？打折吗？送东西吗？

买了房准备装修，一切都不重要，重要的是打开百度，搜索本地所有装修公司的电话，一个一个询问：你们最近有什么优惠活动？好似有优惠活动，哪怕是骗人的活动都行，但是没有任何优惠活动，哪怕是免费的都不考虑。打折，活动，目前是中国人的活法。没有了任何优惠和打折，人活得不知所措，搞价和尽可能的平白获得好处，像国人的黑头发黄皮肤一样，成为了标签。

从最初的打折送礼，到后来的各种五花八门的活动，装修市场是出尽风头，直到后来的免费装修，先装修后付款，装修过的业主请你们摸着良心想一想，你参加的任何一次优惠活动或者不劳而获，真的对你的装修有一点好处吗？翻看网上的投诉帖子，哪一个不是因为前期的活动吸引？哪一个不是拿了什么重大礼品？

可是，再多的惨烈教训也换不回来任何一点的反思和教训。我们已经多年习惯于跟着别人走，习惯于让舆论媒体牵着鼻子走。从来不曾自己真实的思考过一回。

翻看网络上的对装修公司的投诉帖子，百分之九十九都是中期增项的，可是尽管这是现实，业主从来看不到，还是一味甚至执着的寻找各种投机与取巧---哪有低价，哪有活动，哪有优惠，那就有后期不断吃亏投诉业主的影子。前面倒下一大片血淋淋的业主，后面乌压压又一片自己不思考跟着大众盲跑的业主。

如果说你当初根本没有任何优惠，没有任何占便宜的心里，找了装修公司出了问题，你投诉，你谩骂，这是可以理解的。但是，一大部分业主出了问题都是有出处的，当你出问题的时候，没有人给你解决的时候，你是否忘记当初就是为了打折而来？是否忘记当初定装修时候送你的家电礼品？是否忘记砍价再砍价？如今这一切能怪谁呢？
