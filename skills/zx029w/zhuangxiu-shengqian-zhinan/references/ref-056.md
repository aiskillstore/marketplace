# 别花冤枉钱！16个装修省钱“平替”，怒省好几万！

装修是要提前规划的，特别是预算紧张的家庭，否则一边装修一边规划，压根找不到性价比好的产品，结果是预算超支，甚至有的超支效果反而一塌糊涂。今天盘点这些提前规划以后，各种平替的做法，不仅省了好几万，还能成就效果的做法。第一、床垫平替床体。年轻人装修本身资金就不充足，加上各种花钱，就容易出现后期超支问题。例如一间卧室想要功能具备，最起码的三件套：床、衣柜、床尾柜，少不了。一次性买齐资金不充足，除了整体降低品质以外，别无他法。在没有充足预算的情况下，又不想降低品质买张床，此时完全可以不要床。地垫铺上就可以入住，甚至试过以后你都不想要床了，既满足功能，同时又能满足预算不足的问题。网友@小鹿：朋友说：你这是没钱买床吗？对啊，买不起啊买不起，搬家后，我没有着急买家具，包括必不可少的床，而是选择直接把被褥铺到了地板上，就这么一住就是两个月了…总体感受：完全没有必要要床！网友@困眠：装修到最后真的是没有钱了，还得生活，置办了基本的生活用品以后，床又不想买便宜的。网购50元的地垫，1000元的床垫搞定，感觉好像不要床也是可以的。第二、衣柜平替。主卧一面墙衣柜当然最好，收纳量也大，但是一面墙定制下来在一万左右，而且还都是人造板，污染量也加大了。网友@跳咪：因为主卧有小孩，要注重环保，但是实木定制比人造板贵很多，更承受不了费用，干脆网购不锈钢架子，后期拉上布帘，一样满足了一个衣柜的收纳量，但是总费用不到2000元。第三、墙面材料平替有好多人第一次装修，恨不能把建材都搬到自己家，例如墙面各种木饰面，各种大理石，但其实费用昂贵不说，堆积污染才是最可怕的。墙面最好的平替就是乳胶漆通刷，又环保，还节省一大笔费用，不用考虑整体装修的污染叠加问题。第四、床头柜平替传统床头柜又贵又笨重，而且还占地方，空间视觉上也显得呆板。最好的平替就是衣柜自带的隐形抽屉，下方还有两个备用抽屉，不占地，视觉上可以放大空间，而且如果你找到好的全屋定制，这几个抽屉是不会收费的，都在总价里头包括。对于空间小的角落，也可以采用网购这种折叠的换鞋凳，满足一个可以隐藏的悬空床头柜功能，搭配上更显高级第五、吊柜平替传统家庭厨房肯定是做满吊柜的，因为有太多收纳需要满足，但是空间上必然显小，空间压抑。有的家庭经常不做饭，而且不需要那么多收纳，压根不需要吊顶，但是有零碎物品需要随手放置，此时就需要有合理的平替产品。很少做饭而且开放厨房，不想要压抑的吊柜，此时可以采用隔板平替的做法，满足随手物品的放置，空间上更显灵活第六、开放厨房墙面平替开放厨房又不经常做饭，最大的功能其实就是“有个厨房”而已，此时你把难看的瓷砖和吊顶做满，不仅浪费而且视觉空间也难看做开放厨房就是做饭频率很低，为了放大空间以及营造一个更舒适的会客交流场所。所以墙面就可以采用好看的半墙瓷砖铺贴，吊柜可以采用隔板平替，这才是开放厨房的意义。第七、淋浴隔断平替网友@小漫：淋浴房玻璃，好端端的自己炸了，吓死，还好我已经洗完澡出来看电视了。要是我晚半小时洗澡，估计跟去年那个小张一样了，玻璃碎片飞溅了一地，真后悔装修用玻璃隔断。网友@板板漫：淋做淋浴隔断的目的是为了后期好打理，全是错的，实际上入住才知道，每次洗完澡，你得打理一遍玻璃，这压根不是去家务，完全是多此一举，给自己增加生活负担，超级后悔做这个隔断。其实最好的做法，淋浴下沉两公分，什么隔断都不要，特别是小空间，反正洗完澡都得清理，空间还能放大，再也没有清理淋浴隔断和自爆的烦恼了网友@老龚：淋浴区不喜欢玻璃隔断的也可以用浴帘，夹子更换非常方便，成本也低，是个不错的选择。第八、干区垭口平替。浴柜外置的干湿分离，为了瓷砖收口，给干区做个厚重的哑口套，不仅费钱，而且视觉上厚重。其实可以乳胶漆硬收口或者采用极简的收口条，也可以实现功能，而且造价更低，视觉也满足简洁的效果。第九、木地板平替有人喜欢木地板，北方有地暖，没钱买实木，又怕强化复合污染大；南方又有回南天，木地板更难伺候。木地板最好的平替就是木纹砖，不仅比木地板耐用，耐潮，而且完全不用担心售后问题，颜值上也能达到木地板的效果。第十、拱形造型平替一般家里的拱形造型都得让木工做，材料加上人工费用不算低如果考虑预算的话，就可以采用网购成品拱形造型，作为平替非常的实惠。第十一、实木护墙板平替想要实现特定风格，墙面采用实木护墙板，不仅造价高，而且徒增污染。但其实采用PU线一样可以达到墙裙的效果，关键是造价非常低，而且没有污染，也不会让空间有厚重感。第十二、双眼皮平替家里双眼皮吊顶，传统做法又得木工施工，又得购买材料，后期还得油漆工批腻子处理，加起来成本并不低。最好的平替就是网购成品的双眼皮石膏线，尺寸非常多，价格非常实惠，也能完美达到目的，唯一缺点无法实现反光灯槽。第十三、隐形门平替传统隐形门或者无边涂料门，造价昂贵，而且容易出问题。其实采用普通木门，做成外平内开，就可以接近隐形的效果，而且因为是普通木门的做法，结实度以及耐用度要好很多，而且造价要比隐形门和涂料门实惠。第十四、天然石材平替做一个石材背景墙，传统做法就是采用天然石材加工，加上运输安装以后，费用非常贵，而且后期隐患也多其实最好的平替就是PU石皮，不仅造价低很多，施工非常方便，还可以任意裁割，也可以实现天然石材的视觉效果，也不存在安全隐患。第十五、窗户平替客厅与其他房间有窗户相通，有的是为了视觉放大空间，此时传统做法就得砸墙，还得定制窗户，成本肯定不会低。实惠平替的做法假窗户装饰，同样可以达到视觉放大的效果，而且也可以满足装饰作用，造价要实惠很多第十六、普通床平替买个床恨不能床头塞满房子，不仅牺牲空间，而且造价还高，最后还没有效果。小空间无床头床+成品床头才是最好的平替，不仅整体造价要低很多，而且空间利用率更高，实现了放大空间的效果。
