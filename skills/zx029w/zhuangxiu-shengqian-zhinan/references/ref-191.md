# 165平现代大宅禅意，全贴瓷砖预算都得超标

房子小了好装，基本就是住的舒服为主。房子大了反而有了选择困难症，不知道什么风格适合大房。各种风格都有预想，最终实在是太累了，直接现代风就行，不过一直喜欢新中式，所以决定在现代风里头加一点点禅意就行。入住造价想起来就肉疼，五六十万绝对是有了，这一切只不过是父母一手承担而已。

▲原始图纸。基本改动不大，客餐厅是横厅空间，阳台和厨房占了一部分面积，所以统一把阳台墙体移动，图上1位置黄色墙体推至蓝色位置，这样家具摆放就解决了空间紧张的问题。把原来的厨房砸掉融入到餐厅，释放餐厅空间，同时把厨房带的阳台改作了厨房，完美的解决问题。过道的小房间其实是个衣帽间，有点堵，所以干脆砸掉，做了一个开放式的书房。两个次卧之间墙体砸掉用衣柜代替，这样能拓展最里头小房子的空间

▲改变以后的设计布局图。客厅敞亮多了。同时厨房改到阳台，餐厅就豁然开朗。同时增加了好多收纳空间。大房子收纳多了，必然会有很多柜门，视觉上会凌乱，所以基本都做成了隐形柜门，这样看上去整洁，也不会凌乱压抑

▲进门就是惊艳，专门做了门厅的玄关背景，两边对称的弧形造型，而且还隐藏了灯带，这灯带是感应的，只要开门人进来自动亮起，真的方便又新颖。一副现代抽象挂画，搭配一个成品简易换鞋凳，刚好配合右手的鞋柜使用

▲进门看门厅空间，进门右手鞋柜收纳，采用透光的卷帘，简洁还能保证光线的通透。同时为了吊顶采用现代做法，做了嵌入式灯带处理。这样进门的灯光层次以及照明都可以满足

▲鞋柜上方做了石材台面，突出现代元素，同时兼顾进门放置包包或者钥匙之类的小零碎。中式小盆景装饰，有一丝禅意。这就是现代风格中禅意点缀的效果

▲再往进走是狭长的过道，又不是门厅，过道又非常浪费。所以放了黑色的条桌，家里人信佛，这就是以后的佛龛位置了。右手边木色通顶收纳柜，全部采用隐形门处理，不会显得压抑，与爵士白瓷砖呼应搭配，硬朗现代

▲手机拍摄的过道柜子，平时其实就是放杂物的地方，下柜采用折叠门的地方是平时放行李箱的位置，刚好在门口，出行也比较方便

▲最边上做了置物镂空设计，可以摆放精致的装饰品，全当是进入内厅的玄关背景了

▲门厅过道进来客餐厅全景，横厅空间。超级大的阳台玻璃门，采光非常好。整体采用平面吊顶，客厅简洁无主灯设计，局部勾缝点缀。餐客厅之间有大梁，采用吊顶处理以后，能缓解压抑

▲客厅区域，可以看到入户门狭长的过道，一边全做了木质的隐形收纳柜，与浅色大理石瓷砖倒是非常协调。直对的就是原来的小衣帽间，砸掉墙体成了一个开放式的书房，空间也开阔很多

▲电视墙非常简洁高级感十足，中间是石材装饰，两边是隐形收纳柜，边缘为了灵活一点镂空隔板书架，电视柜采用深色石材对比做的壁龛处理，内部灰镜增加高级感。不呆板，不繁琐，虚实结合带来轻盈感

▲电视墙的细节特写，硬朗的石材和灰镜，搭配白色的隐形柜门，现代时尚感十足

▲餐厅位置就是原来的厨房，把厨房移到阳台，餐厅就大了很多。过道的收纳柜直接拐角收纳，弥补了墙体的错落空间，同时兼顾高柜镶嵌电器。侧墙矮柜和吊柜兼顾西厨空间，也可以弥补厨房收纳的不足。大理石台面餐桌搭配木质的餐椅，和整体风格协调，同时可以满足六人就餐

▲餐桌对面的高柜镶嵌电器，同时旁边通柜里头是酒架处理，平时酒就可以收纳到这里，不凌乱，拿取也非常方便

▲所有墙面几乎都是大理石瓷砖装饰，空间现代硬朗，但是造价实在太高，想做的业主还是三思而行。大宅大空间可以，小房间就算了，墙面瓷砖本身会牺牲一部分空间，而且不一定后期不会脱落，后悔已晚

▲原来的厨房移到了阳台，全景玻璃门分割，不影响光线，空间同样通透。注意西厨角的烟道在餐厅，刚好和厨房是隔壁，这就是厨房能移到阳台的决定性因素

▲这是未装修的时候的厨房阳台，门很小，导致光线非常差，所以必须砸掉

▲这就是过道原来的小衣帽间，砸掉以后和客厅一体开阔，做了通顶书柜，一张书桌就是开放式书房了

▲主卧空间，超大落地窗光线没有问题。背景米色硬包处理，镶嵌钛金条勾勒，刚好和吊顶勾缝连贯，视觉上拉伸层高空间。

▲皮质的靠背与米色硬包装饰，黑色钛金条与轻奢台灯质感搭配，圆形的床头柜大理石台面的硬朗，整体都是现代高级感

▲主卧全景，床对面放置了斗柜收纳。家具真的不便宜，这个床都小一万了

▲床对面同样圆形的斗柜收纳，硬朗的大理石台面，搭配黑色同样款式的落地灯，非常有感觉

▲主卧侧墙白色隐形门衣柜，非常简洁。极简线条与几何块状搭配，采用圆弧形床头柜和斗柜呼应，设计确实费了心了

▲最边上的小房间做了多功能房。榻榻米以及书柜一体定制。中间加了升降桌，平时可以休闲读书，来客人这就是临时的客房使用，同时榻榻米下方兼顾一部分的收纳。背景圆形挂画就是禅意的点缀
