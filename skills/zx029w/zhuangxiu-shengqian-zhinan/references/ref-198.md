# 客厅与阳台窗帘别乱装，分清场景按需配，该挂该省不花冤枉钱

很多家庭在客厅和阳台装窗帘时，要么客厅阳台都装，要么阳台厚重布帘，最后要么遮光不够、隐私差，要么多花了钱还显得压抑。其实客厅与阳台的窗帘，真不是越多越贵越好，分清采光、隐私、通风等不同需求，该挂的挂、该省的省，实用又不花冤枉钱。01｜客厅只有窗户（平窗/飘窗）
客厅做法不一样，分为与阳台打通和没有阳台的做法，完全不一样，需要根据实际场景来做。
客厅不带阳台，是一个平窗，此时一定要保证空间的透光功能，不能用布帘❌️，可以采用氛围感的纱帘落地搭配。客厅小平窗，外开或者推拉，横百叶就是最美的搭配，视觉轻盈有氛围感，同时兼顾了隐私和透光要求。
客厅飘窗，搭配中古风，木质百叶更有颜值。
客厅U型飘窗分三部分一样可以用百叶帘，甚至内开窗也不影响百叶帘，前提是收起来上方有足够空间，不影响窗户的内开以及内倒开启。
客厅阳台打通以后，即使内开窗一样可以做木质百叶，开启窗扇与固定扇分开做即可『谁说内开窗没法装百叶帘？操作非常简单』
客厅超大落地窗，采用双层纱帘，氛围感绝了。内层扶风纱加黑边，外层幻影纱，透光、氛围隐私兼顾，适合窗户大的空间。
02｜客厅与阳台打通空间
客厅带阳台打通布局，此时只需要阳台纱帘即可，满足隐私和透光。
客厅与阳台打通，阳台内开窗，采用分开的罗马帘也是可以的，不影响内开窗的开启。
客厅阳台打通，阳台不同窗户采用罗马透光帘+木质百叶的做法，非常有氛围感。
打通阳台，阳台内开窗，采用竖百叶透光隐私氛围都有了。

总结：客厅窗户或者与阳台打通的时候，客厅内部不需要任何帘子，放大空间；阳台和独立窗户适合各种百叶，纱帘落地，或者双层纱帘，透光罗马帘。
03｜❌️客厅窗帘不推荐做法❌️
客厅与阳台只需要隐私和透光，压根不需要彻底遮光，否则一多半人都多花钱反而没用。
错误一：只有窗户，可以用纱帘落地，布帘完全多此一举，客厅是要隐私，但是要求透光，否则拉上布帘以后白天都得开灯。
错误二：客厅与阳台打通以后，窗帘直接做到阳台，是不需要布帘，需要遮光采用遮光好的纱帘即可，视觉空间都轻盈，布帘多此一举，在需要透光场景几乎无法使用。
错误三：客厅窗户小，无法做满墙，纱帘就是累赘和厚重感，还采用罗马杆，整体就显得拖沓廉价。
错误四：客厅阳台打通，阳台纱帘即可，客厅布帘以及窗帘盒都是堆积建材，多此一举，一年四季都用不上。
错误五：客厅只有飘窗，落地纱帘隐私和透光都有，布帘多此一举。
错误六：客厅只有飘窗，布帘完全多此一举，采用一道遮光帘或者百叶帘更好。
错误七：客厅阳台打通，客厅做窗帘本身就多余，还用了撞色翻车到家了。『穷装别玩撞色！翻车率高达90%，真的没救！』
总结：客厅只有窗户，一定不要用布帘，除非有投影必须；平窗落地纱帘也可以，独立窗户百叶罗马帘也可以；客厅与阳台打通，客厅处不要做任何多此一举的窗帘，只在阳台做透光隐私帘子即可。
