# 装修新房，促销+大定，预算+合同，就把你整蒙了

旧文重发，看过略过

西安装修业主最担心什么，当然是各种装修不快，下面谈谈一些常见装修猫腻，不过做好心理准备，对与错不是单方面的。
【促销】常常听到某些业主说上当了，原来看他们宣传装修几点几折就剩最后的席位了，没有考虑就赶紧定了，装修了才知道原来根本没有折扣只是把价格提高再打折

这一点陈工早都说过多少回了，天上不掉陷阱，苍蝇不叮无缝的蛋，自己身正不怕影子斜，不论人家多么诱人的东西你自己不动心怎么可能会上当？美女再美你不动手人家会告你骚扰？

想一想你自己是做哪个行业的，你自己是不是也这样对待你的顾客？陈工曾经给一个做手机生意的顾客装修过，那个顾客说装修行业怎么暴力，当时陈工就问他：你的手机膜八毛钱进的可是你贴个膜30，请问你的利润多少？你的蓝牙五十进的可是你一百五十元以下你卖过没有？所以还是那句话人与人是有区别的，大家都是娘生爹养的，可是我们内在的东西却是天壤之别

【定金】定金是为了确定某项活动才交的款项，目的就是确定有这么回事，业主认可和了解此项活动的意义后才交的款项。

其实陈工一直不愿意也不赞成业主交定金，看市场上能交定金的要不就是耐不了忽悠才交的，要不就是爱占小便宜才交的。你如果真的想让某个公司装修那就直接让他量房做设计然后签合同然后一把付了首付就行了，非得交个定金，最后因为自己没有主见或者自己经不住朋友同事的搅合想退退不了。

【大定】有的业主可能没有听过什么是大定，一般交定金是一两千元，少的可能几百元，而大定比如你的房子装修八万，大定可能就要交三四万元，这个比定金的风险更大，基本相当于签合同了，如果是定金有的公司给你退，可是大定你想都不要想了，交大定肯定和你有一份协议的，要退可以，百分之二十的违约金。

不论定金还是大定那只是一种营销手段而已，一旦交了那是有法律制约的，但是现实是什么，一百个交了定金或者大定的到头来九十几个会埋怨自己上当了，这就是市场，掏了钱的都感觉自己上当了。

【预算】装修扯皮一般都出现在这，预算少算或者多算。其实看预算的时候你要知道自己家要做什么，你给人家设计师交代清楚没有，总共就那么几个房间，每个房间的预算都是分开的，一项一项看，看完看准再签订合同。

至于价格一旦你签字那就是有法律依据了。预算作为合同附件那是严肃的，不是谁想胡说就胡说，谁不认就不认的，该是谁的责任就必须担负起来。有的业主装修完了拿起预算一个个看面积，这个面积好像大了，看到最后没有一个面积小了，都怀疑装修公司故意放大面积了，呵呵，这一点陈工理解，因为毕竟业主没有那么专业，装修面积的误差那是允许的，因为是人工量取，一个人每次量都不一样，何况是不同的人量，所以只要误差不是很离谱就不要较真了。如果真的有出入，那么装修公司给你算大了该退的退，给你算少了你该补的补就是了。双方到实地核实一下就行了，但是现实是只要多而退，少的补业主都不会去核实了。

【合同】说到合同陈工敢保证有好多业主即使现在装修完了的业主都不知道西安市装修合同是什么，拿着装修公司自己打的合同就开始施工了，殊不知道自己签的是一份无效的无法调节的合同，像购房合同一样，那是统一的不是开发商随便打一份你就敢买的。

一旦拿着非建委的合同去打官司那就有罪受了，因为不会给你调节只能找法院，本来你如果是建委合同出了任何问题建委会调节，而且装修公司是建委直接管理的，说话是有一定分量的，但是你签的不是建委的合同，那只能算是民事纠纷了你慢慢打官司吧。所以业主一定要搞清楚装修合同是有规定的，一定要签订正式的统一的合同，截止目前陈工写这个的时候西安市唯一的合同就是2007版的淡蓝色封皮的合同，其他任何自己打印的合同一旦出现问题就不好解决了。《找装修公司千万不要签这些合同2.2》

装修的事情对于不懂装修或者对这一行不了解的人是无法想象的。业主除了恨房价太高以外就是恨装修费用太高了。

现在的装修费用已经远远超出老百姓所能接受的范围了，但是没有办法，人工一天比一天高，业主一方面要求用好的工人一方面要求价格低，这根本不可能。

现实中是业主无法理解一个装修工的费用就那么高，比如一个九十平方房子水电做下来两天完成会产生几千圆的费用，业主无法想象一个人两天就能赚几千元，业主总在惊叹为什么比白领的工资还高，是的，隔行如隔山，人收入的高低和工作没有任何关系，不能因为工人是做苦力的就认为不该赚那么多，这一点陈工以前讲过，不要看不起任何给你干活的工人，正规工人没有一个不比你有钱的，你辛辛苦苦首付买个房子，可是给你贴砖的瓦工早都有好几套房子了，人家的工费那是市场决定的，如果不值那么多就不会有市场了，所以我们不能恨房子太贵只能怪自己赚的太少，不能恨这个社会太黑暗只能怪自己生不逢时了，呵呵，今天就到这了，说得有点多
