# 没有低价和赚钱的矛盾，熟人装修最好6.6

网上好多人哭诉找熟人装修如何不好，如何上当，如何被套。太多了，搞得后面的业主见熟人都害怕，白白把好的资源浪费，舍近求远，明明有熟人做装修，却找个不相干的人，这个到底是为了什么？

其实和家族企业一样，家族企业就不好了？可能大部分认为，如果企业里头有七大姑八大姨就不好管理了，就徇私舞弊了。这个恐怕是大部分人的误区。在真的做事业的企业里头，不乏熟人和亲戚，不论是什么关系，都以制度为准，一视同仁，甚至自己家族比外人更加严格，这样才能让熟人和自己人发挥比外人更好的作用。企业的团队意识要更厉害。

关系社会这是中国特色而已。从上幼儿园开始人人都在关系社会的耳濡目染中长大，这样的环境，能心底无私也难。

比如找熟人装修，第一先想反正认识，好沟通。第二就开始想了，熟人嘛，肯定便宜，价格能低。这就是被洗脑的思想后果，为什么熟人就给你便宜？为什么熟人就需要给你便宜？熟人也是人，也得赚钱吃饭，你如果抱着找熟人想省钱，出发点就决定百分之五十的结果失败了。

第一，如果你的熟人也是被洗脑的思想，也想，反正熟人，能做就做了，能便宜就便宜了，如果碰到这样的熟人不倒霉才怪。两者都被中式关系毁了。

因为熟人之间的装修不像商品，比如买个电器，找熟人，能便宜一点是一点，无可厚非，可以，因为你的熟人不生产电器，只不过是通过渠道给你省钱而已，这样关系更好了。即使出现问题，你也只会怪罪这个电器厂家，不会怪熟人。但是装修是商品吗？

你家装修能看得见摸得着结果吗？当然不能，你家装修是一步一步细节堆积实现的，在这个过程中往往大家都不懂标准，也从来不管什么国家标准，标准就是熟人的标准而已。比如熟人按照国家标准干活，但是国家标准与熟人的要求甚远，这就是矛盾点的出现。

此时，碍于情面，熟人虚伪做人，内心早把你祖宗骂了，表面还客气忍让。这就是熟人最难的地方。于是日积月累，最终整个装修在憋屈中完工，完工了，也就变成仇人了，老死不相往来了。

熟人之间，钱没有赚到，质量没有保证，关系也没了，得不偿失。归咎原因，还是中国式的做人有问题，把私人关系放到做事里头，尤其是装修活动万万要不得。

找熟人装修怎么才能做好？
第一，你的熟人必须是有思想的，而不是社会上的市井人，也就是必须是品行俱佳的，否则人不行，你图便宜不坑你坑谁？

第二，品行达到了，必须丑话提前说，不要考虑价格，一视同仁，给别人什么价格，把熟人当普通消费者对待。当你咨询熟人装修的时候，一定把丑话说前面，找熟人不是为了便宜，只是为了好沟通，该多钱是多钱，该赚的必须赚，千万别指望熟人给你便宜，否则他用什么给你服务？还得偷工减料才能有利润，到头来还得扯皮。

第三，装修是双方的事情，做装修的品行到了，还得看自身，如果业主是个刁钻刻薄不讲理的主，最好别接，再有钱都别做，否则这是引火上身。

陈工很早就说过，装修不是有钱就能做的，如果只看钱不看人去接活，想要口碑，这是做梦。市面上那么多骂装修公司的，有时候敢去调查吗？难道都是装修公司的错？这是不可能的。一个消费活动是双方的事情，怎么可能一抹黑都是装修机构的错？只不过是企业不愿意劳心费神和人扯皮罢了。任何业主只要和装修机构扯皮，所有吃瓜群众都会不分青红皂白的，这和现在的社会戾气有很大关系。

扯远了……找熟人一定记住，该赚必须赚，该保证质量的必须保证，钱是一定要赚的，关系还得保住，这样结果才是圆满的。一个想找熟人低价，一个想给你低价便宜装修接个生意，还是算了，你两都得倒霉。
