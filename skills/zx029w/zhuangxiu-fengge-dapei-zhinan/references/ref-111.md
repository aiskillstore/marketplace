# 原创|装修窗套是包还是不包？难为业主了

赞成包套的：这是很多业主在装修中经常遇到的问题，其实不管是简约、时尚、田园……什么风格，都需要包窗套和哑口，主要是根据装修风格选择合适的颜色。包上窗套哑口会使装修风格整体感觉更强，要是不包的话，拉开窗帘总感觉会有一点不太完整和精细之处，有点别扭。而且包上窗套也便于打理，颜色可以木门一致，不仅美观，对墙角也起到保护作用…

反对包套的：窗套一米几十，如果是飘窗套几百都有，不仅价格高，没有任何实际作用，房子小的话到处都是条条框框，费钱又不美观，真的没有必要。

不论你反对或者赞成，感觉都是对的。家是你住，不是别人住。你买个100平你问人家住别墅的包不包窗套，这个问题人家怎么回答。
窗套的作用不外乎美观和家里阳角保护好打理，对你入住没有任何绝对性的影响。家里缺了座便器不能生活，没有听过缺了窗套这日子就没有办法过的。

建议，想省钱的可以不要，千万不要三百买个座便器然后又把家里窗套都包了。家我们要的是真正的生活质量，不要羊粪蛋蛋表面光。
