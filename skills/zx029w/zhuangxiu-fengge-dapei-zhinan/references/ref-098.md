# 装修墙面该怎么装修？原来是这样！9.25

今天所有墙面做法中不包含乳胶漆和壁纸
【木地板上墙】

◆木地板做墙面，一般人可能接受不了。一是没有这样做过，不知道到底咋样，再一个木地板并不便宜，成本很高。装修就是这样个人有个人爱好，你不试一下怎么知道不行呢。好打理，寿命要比乳胶漆和壁纸耐用得多，而且如果用纯实木污染很小。不过尽量不要在容易受潮的地方使用，比如卫生间隔壁墙面最好不要使用。多用于，电视墙、卧室背景或者餐厅背景。微信回复“木地板上墙”提取更多木地板背景案例，或者回复“背景墙”各种背景墙可以查看

【红砖上墙】

◆红砖直接做墙面还是很多的，比如田园风，地中海风都有。有两种做法，一种是用专用的清水墙红砖，不是普通的红砖，一般小区普通红砖要做清水墙那得从几百块砖里头挑，稍微有破损的都用不了。所以有专门做清水墙的红砖，到处都有卖，网上也有，便宜的也得两三元一块，有的卖到四五元，比普通红砖贵多了。让手艺好的瓦工用专用红砖做好，在勾缝就可以。另一种做法就是直接用仿红砖的瓷片，就像外墙砖那种小规格的瓷片直接贴也可以做出这个效果。比较麻烦，但是效果很好。材料贵，人工更贵，一般瓦工是难以做的。微信回复“红砖”查看更多红砖效果案例。或者回复“背景墙”各种背景墙可以查看

【文化石上墙】

◆这种白色生活中用的很多，有的快餐店也使用，看上去干净又有质感。做电视墙或者餐厅背景都不错。当然文化石各种各样，这只是其中一种，在微信回复“文化石”查看更多文化石背景图。或者回复“背景墙”各种背景墙可以查看

【软包上墙】

◆这个大多数业主都见过，不能说从古到今都在用，最起码家装行业一直在用。有质感，而且各个风格颜色一应俱全，客厅卧室背景都可以使用。材质有真皮，布衣，丝绸的都有，缺点是不耐划，寿命和质量有关，价位便宜的三四百，贵的有几千元的。
在微信回复“软包”查看更多软包背景图。或者回复“背景墙”各种背景墙可以查看

【黑板墙】

◆黑板墙当然是从学校的黑板延伸过来的，大家都很熟悉。但是现在的黑板墙使用特殊黑板墙漆刷出来的，耐潮湿，耐擦洗。可以作为家里的点缀，也可以用于家里小孩的涂鸦。各种颜色都有，不只有黑色，有兴趣的业主可以自己买一桶自己动手DIY都是可以的。

【木板上墙】

◆咳咳，不要光盯美女，说正事。这里的木板当然也包括木地板，在此主要指除过木地板的其他，如，防腐木，杉木板，各种护墙板都可以，还可以纯实木直接刷木蜡油的。做法简单，但是效果各有不同

【手绘（贴纸）上墙】

◆手绘或者贴纸在装修中比较常见，最常见的就是局部手绘或者贴纸，其实有时候可以整个背景墙全部用手绘或者贴纸。手绘要求比较高，专业人士做，贴纸某宝上到处都有卖

【软木上墙】

◆软木上墙比较少见，材料也很少用到。但是和其他木板相比较，软木性格柔和，家装中经常是局部装饰，或者做背景墙，做小块照片墙使用

【镜面上墙】

◆用镜子做墙面很平常了，几乎在简约或者欧式装修里头都有涉及，所不同的只是所用镜子的面积和材质形式不同而已。常用的普通银镜，车边境等。在大户型里头往往是点缀作用，在小户型里头往往起到放大空间的作用。和白墙的单调相比，镜子完胜。

【清水混凝土墙】

◆这个就比较少见了，至少在国内，特别在西安，买个房子再怎么没钱，表面还得和别人一样，整个清水墙，别人还以为因为穷装修不起呢，对于面子比内子重要的中国人，这个可能也只能用到办公场所。比如你开个设计公司，办公室都整成清水墙，不仅没有人说你穷，反而认为你们公司很有内涵，有设计理念呢

【瓷砖或者石材上墙】

◆瓷砖或者石材上墙，这个很常见，但是也只是局部做背景使用。不同的是瓷砖代价低，优势可以代替石材使用
