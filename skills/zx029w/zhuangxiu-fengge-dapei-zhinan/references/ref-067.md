# 阳台都能铺什么？有这么多选择1.25

其实，阳台作为一个功能区，可以做成的功能很多。大致可以分为以下8种功能。

1.▲生活阳台，放置洗衣机兼洗衣服功能，同时还得晾衣服，这是大部分人家的阳台刚需。

2.▲休闲空间，这个针对阳台比较多的家户，很多专门保留一个阳台作为休闲之用

3.▲阳台养花空间，对于爱花人士，阳台养花是最好不过了

4.▲阳台书房使用，这个功能性就很强了，合理利用空间。

5.▲别墅阳台是可以作为单独的卫生间使用的，这个是阳台梦寐以求的功能。

6.▲阳台还可以做榻榻米或者地台休闲使用。

7.▲阳台有的家户也可以作为厨房使用。

8.▲阳台还可以作为单独的西厨区域使用

以上就是阳台的8种功能，各位业主可以根据自家需求适合去做。

今天主要探讨，不论阳台你做什么功能，都可以铺什么。

——木纹砖1，人字形铺贴木纹砖，费用很高，效果不错，必须保留缝隙和后期美缝处理
——仿木纹瓷砖2，生活阳台需要晾衣服，放置洗衣机或者养花，多少都会有水，多少都会潮湿；同时阳台也是阳光充足的地方，免不了阳光长期暴晒，瓷砖是不错的选择。

木纹砖因为有木地板的样式，同时又兼有瓷砖的耐用，所以美观与质量兼备。

需要注意的是，木纹铺贴木纹瓷砖需要保留2毫米甚至更宽的缝隙，这是瓷砖特性决定，当然如果对自己的瓷砖比较自信，你完全可以保留一毫米缝隙直接铺贴，直接普通勾缝就可以。

建议，要铺木纹砖就留宽缝隙，能保证瓷砖的平整度，同时后期做美缝，更美观。你如果舍不得留缝的价钱或者美缝，直接铺普通瓷砖就行。这就好比舍得西装而舍不得买一双好皮鞋一个道理，各位自己斟酌。

木纹砖有各种铺法，上图是顺着阳台方向铺法，你也可以横向铺贴，还有错缝的尺寸，有的错三分之一铺法，也有对半铺法，这些需要看整体协调决定，铺法不同，造价是不同的，想要效果必须付出代价。
————木纹砖3，上图是木纹大规格瓷砖，多见于美式空间，也是可以铺贴到阳台的，防滑耐脏
————仿古砖1，阳台可以铺贴仿古砖，但是仿古砖的类型很多，比如上图彩色仿古砖拼花，菱形铺贴，四周彩色波导线勾勒，是不是很美？价格也很美，铺贴工费也是很高的，同样道理，仿古砖必须保留2毫米甚至更宽的缝隙，后期必须做美缝处理，这就是品质装修。你如果又想有效果，又不想花钱，还是算了，能住就行。
————仿古砖2，同样仿古砖，也可以用素色铺贴，如上图的灰色仿古砖，地面深色，墙面浅色搭配铺贴，相比较彩色素雅很多。同时不需要拼花，工费也能实惠很多，同样需要留缝和做美缝处理
————仿古砖3，也可以使用蓝灰色仿古砖菱形铺贴，相对工费高点，也是需要留缝和后期美缝处理的
————亮光瓷砖1，阳台作为阳光最充足的地方，不建议使用亮光瓷砖，一是不耐脏，二是不防滑，三是阳光充足光线太充足甚至刺眼。上图的使用大规格亮光瓷砖，四周仿石材波导线勾勒。
————亮光瓷砖2，上图阳台与其他区域直接打通，使用了同样的亮光瓷砖拼花，虽然不防滑，但是与整体协调，同样菱形拼花，波导线勾勒
————亮光瓷砖3，上图直接使用大规格全抛釉瓷砖铺贴阳台，勇气可嘉，这个不是合适不适合的问题，是品味问题，实在是太过落后了，房子不仅仅是入住，最起码有点档次和大众品味，各位不要效仿，有用这个瓷砖铺阳台的打算，赶紧收手。
————花砖1，北欧花砖也是可以用到阳台的，与众不同，虽然略显艳丽，只要整体搭配协调，也是不错的选择
————花砖2，不论是单独阳台还是打通阳台，花砖铺贴效果还是惊艳的
————六边形瓷砖，上图的六边形瓷砖并不是只在北欧风多见，随着装修品质意识的提高，各种材质的界限越来越模糊，只要能协调都可以混搭使用。彩色六边形瓷砖拼花，哑光耐磨防滑同时耐脏，但是因为规格小，铺贴麻烦，工费非常高，所以不愿意花钱还是算了
————防腐木地板，需要暖色装修，或者营造田园感的阳台，防腐木地板是不错的选择，拼贴方式各样，不限于上图的形式，造价方面要比普通瓷砖高，但是品质档次有好有坏，各位业主要斟酌
————塑木地板，这个不是防腐木，是类似于防腐木的塑木地板，虽然不是纯实木，但是室内室外都是可以使用的，也是目前大量使用的铺贴材料
————木地板，阳台直接铺木地板是有条件限制的，并不是随心所欲。像卧室阳台打通设置这种是可以通铺木地板的。如果是单独生活阳台还是谨慎
