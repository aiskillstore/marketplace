# 小户型装修，适合做什么风格？1.5

多大户型算大？多小户型算小？几乎没有一个固定的标准，因为大小毕竟是相对来说，但为了能继续阐述，暂且把一百平以下以及左右的面积户型，都称之为小户型吧。风格本身就是一个伪命题，其实没有风格，建材商和装修公司忽悠多了，就有了风格，目的当然除过让你花钱以外，其次就是创造千篇一律的美。回到正题吧，小户型一般是为了省钱或者放大空间，所以笼统来说，极简满足功能，不做累赘造型，其实就是很好的做法了；但是有人当然不愿意平淡，想着好不容易有了家，有点档次或者内涵总是好的。.01简约风格
简约黑白灰，过去烂大街的做法，目前依旧烂大街的做法。没有什么不好。就是太俗，装修没有个性，省钱吧？也不省，各种无用的造型东施效颦做了一大堆；审美吧，也不存在，就是黑白灰叠放而已，颜色上也不会出错；如果说档次吧，一个亮光砖已经毁掉所有了；大部分人认为小空间想要放大空间，就是用亮光瓷砖，殊不知光线和镜面无关，这样做反而让小户型更没有档次可言了
一样的做法，只不过没有那么绝对的黑白灰，但颜色相对较素，这也是小户型需要遵循的颜色搭配，越是浅淡，视觉越是清爽，越是有利于空间的放大；软装和绿植增加一点鲜活的气息，这基本就是普通家庭常见的做法。无主灯的极简黑白，这个风格也算是烂大街的做法了；光一个无主灯就可以让人骄傲很久了，但是造价远远高于普通刚需做法；一旦后期家具软配审美稍欠，廉价感是无法避免的。一样的简约做法，只不过采用了无主灯以及地面柔光瓷砖，视觉上没有那么张扬、高调，其实这个才是小户型应该遵循的法则：低调不张扬。通铺木地板的简约风，其实就是刷墙铺地风，只不过大部分刚需小户型没法这样做。首先需要满足收纳，其次需要满足太多的生活刚需，家必然是乱而温馨，所以能这样断舍离装修的，除非是没有小孩或者单身，当然能这样装那是条件的。木纹砖代替木地板的通铺，耐用是肯定的，而且对于北方地暖来说，既满足了木色的温馨，又能满足耐用防潮，两全其美，这个就是小户型硬装木地板与木纹砖之间的首选。.02奶油风
大面积浅色系搭配，颜色如奶油般治愈，看上去小户型能更温馨自在，这也是奶油风能经久不衰的原因所在。奶油风除过柔光瓷砖以外，木纹砖也是一大亮点，木色的治愈可以让奶油风更有层次，不至于过于轻浮。至于上图的所谓奶油风，还是不要效仿了，很牵强，而且亮光瓷砖搭配奶油风本身就是东施效颦的做法，加上各种不伦不类家具的搭配，就会显得小户型出租风十足，非常的廉价。奶油风一定用低调的地面硬装，最不行也得用柔光瓷砖，色系统一起来，后期的家具以及软配一定要有一点的风格特点，没有审美也是最容易翻车的做法。木地板也是常见于奶油风的做法，可以让空间有大的层次感，不至于过于轻浮，而且无形中增加家里的温馨度.03日式原木
日式原木风，简直就是小户型的专利了，可以提升空间的档次，而且满足空间的内涵，同时可以结合大面积的收纳保证刚需的整洁因为有大面积的木质元素，所以颜色上不会有任何轻浮之感；加上绿植和好看的单品加入，几乎横扫任何小户型的格局。耐看而且木质能提升整体空间的档次。与奶油风的傻白甜对比来说，原木风自带文化气质。原木日式风最忌讳的就是地面灰色瓷砖，这样的搭配会显得木质廉价，而且只要家具款式难看，立马整体垮掉，所以想要日式的原木，最好是木地板或者木纹砖搭配，这个是最基本的遵循原理《原木风好看，但是也容易翻车》日式的原木也需要讲究留白空间，大面积的留白呼吸，能让木质不至于过满，让人产生压抑感.04法式复古
法式复古并不是大户型的专属，对于小户型也可以满足法式的浪漫，复古的质感只不过对于其他风格，法式复古更费钱，造价更高，因为廉价的模仿压根支撑不起这种风格，需要有更多有品质昂贵的单品来满足硬装和软装的搭配，所以造价是唯一需要考虑的因素法式复古切勿东施效颦，这就好比一个人没有任何艺术细胞硬撑艺术家一样，后果只能是廉价的气质和滑稽的效果了，所以一定要有一定审美和金钱的支撑才行.05混搭风格
在众多风格里头，混搭才是最具生命力的，因为无法界定其真正的风格走向，搭配都是根据入住人的品味喜好进行，所以混搭也是最具个性的装修有现代元素，也有复古的韵味，同时又有原木的之感，一切按照自己的喜欢搭配，这才是真正的诠释了不跟风，不从众的做法，无风格才是每个人的独特风格混搭风可以把各个风格的好看的单品集中一起，这样就可以很轻松营造高级感出来，而且也不会落入到千篇一律的俗套里头.06中古风
中古风也是适合小户型的，关键是最好能保持家里整洁，像普通刚需房子，孩子太小的话，最好不要，用不了多久，家里只不过成了中古风的仓库而已想要省钱的话，中古风当然不是首选，和法式复古一样，特定风格的所有单品造价都会高，相应的对设计感的把握也要严格的多，并不是随心所欲的混搭，否则往往会有翻车的风险
