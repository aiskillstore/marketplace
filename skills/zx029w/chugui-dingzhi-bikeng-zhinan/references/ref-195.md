# 橱柜定制常见失误，引以为鉴5.3

橱柜作为家里的必备定制，非常重要。因为普遍厨房比较小，需要精心规划才能满足入住的使用，所以不论从定制还是功能颜值上，都必须得到重视。

第一失误：定制不是一家。
这个关键点贯穿装修始终，并不是所有工种的拼凑，装修公司机构之所以能存活，一大部分是解决了所有工种的协调，利润也是算的整体利润。但是好多业主犯的错误，往往就是人为把各个工种分离去做，甚至把统一工种分开去做。就像家里的橱柜，本应该和家里的所有定制一块定制，但是自己不懂，以为这样分开是正常的，导致不是一家去规划，更不是一个板材，甚至同样颜色都会有色差。而且人为分开导致每一家都得有利润，反而让自己多花钱。所以这一块一定注意，全房定制肯定必须是一家去做，好规划，同时售后也好做。

第二失误：品牌失误。
橱柜属于全屋定制，大部分人还处在对商品认知的初级阶段，一碰到定制就谈所谓品牌，从来不愿意深层次去思考一下。你可以看看遍地的定制品牌，板材是他生产的吗？五金是他生产的吗？没有任何东西是全屋定制商家生产的，那你找全屋定制品牌找的是什么？整体加工设计以及安装服务而已。这里的服务包括对审美的要求，以及对装修风格的全盘把握，从而站在业主的角度，选择最优的板材，根据业主的兴趣爱好设计最合理最能满足功能的格局，把空间发挥到极致，做到完美，这才是全屋定制存在的意义。但是好的全屋定制，得有好的人品，经年的经验积累以及独特的审美，其中缺一不可，除非你就是定个盒子。站在业主角度，好的全屋定制是在最便宜的基础上达到功能和颜值的完美。

第三失误：价格失误
看价位是一方面，但是前提你得知道常识，否则和装修一样，低价切在任何行业都存在，看似低价的背后一定隐藏后期的增项隐患，要不就是诸多设计以及功能的遗憾。

橱柜少碰套餐，市面上套餐盛行，你以为商家是为了你考虑，那你就错了。只不过是为了低价切，让你看起来又便宜而且包含的东西还多。定制是非常个性的需求，需要根据空间的不同做出不同的设计规划，哪能和具象商品一样套餐解决，那所有不符合套餐的内容都得单独计费，到最后你会发现，其实就是用低价吸引你签单而已；而且大部分所谓套餐都会包含一系列烟机灶具，甚至有的还送厨房家电，但是你可以看看，要不是些次品，要不就是时代淘汰的产物，等你用的时候就发现各种问题，甚至压根无法使用，当然你如果认为橱柜就是地柜+吊柜定制盒子，那就无所谓了。

第四失误：细节失误
好的橱柜在于细节，细节是每一家格局和需求决定，这一块是橱柜定制的最有价值部分，否则充其量和定制盒子没有区别了
