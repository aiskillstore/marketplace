# 装修大套路，小公司低价切+大公司重复算10.3

关于装修价格方面的猫腻以前谈过N次，可是，好多业主不愿意听，不喜欢听，甚至反感：没有时间看你那纯文字，或者是几十万房子都买了，装修这点猫腻算什么。

有时候人都有个改不掉的毛病，就是比较自信，听不进去别人的意见，总是很自信，最后只能撞了南墙，吃亏上当自己承受。

好比装修方面，好多新业主自信满满，跑了几家装修公司，就认为是个行家了，仓促开工，实际上这样做完全是对自己家不负责任。----你连自己家都是应付，可想而知给你装修的人，才不管你装修好坏，目的把钱赚到就行。

关于预算各种低价猫腻有专题，微信最下方菜单“陈工原创”里头有个“怎么看预算”，所有关于预算的猫腻大家都可以看到，如果你认真看了，而且按照这个去做了，装修绝对不会出现一些常识性错误。

今天重点看看各大专业大公司的过度装修，陈工多年来一直关注到低价装修和偷项漏项了，竟然忽视了一个过度装修，这个问题是昨天一位业主咨询提出来的。

这里的过度装修不是说业主做的那些无功能性的装饰，而是装修公司预算里头的过度计算。

比如，普通毛坯房一般要看墙面情况决定怎么去做，如果你家是素灰或者白墙需要铲除，或者是混凝土墙需要涂刷墙固/界面剂/108胶，然后才能批腻子。

但是，如果你家这些情况都没有，是不需要额外做这些的。但是有的所谓高端装修公司，从来不看实际情况，不论你家是什么墙面，不该做的都做，完全不需要石膏找平的，故意重复计算，反正实际做的时候业主不懂，这就是纯利润了，表面看比较专业，其实就是以专业的幌子赚钱而已。

奇葩的是有时候发现墙面预算是这样计算的：石膏找平一项，贴布一项，刷界面剂一项，墙衬一项，基层处理再一项，看起来密密麻麻，很是专业，实际全是重复计费，墙面局部需要特殊处理能理解，但是所有墙面需要这样处理明显有问题，看名字好像不一样，其实做法完全相同，但是业主不懂，就只能被坑。

还有一般业主贴壁纸的话，墙面肯定不做乳胶漆，有的预算除过批腻子以外，增加一项贴壁纸基层处理，不知道是怎么处理的。如果有常识的话，肯定知道批腻子打磨平整就可以直接让壁纸刷基膜贴壁纸了，不知道贴壁纸基层处理和批腻子有什么不同。这就是所谓的过度计算，重复收费，用专业幌子增加业主的预算。

此外还有贴砖的墙面，做完防水需要拉毛处理，但是有的预算不仅有拉毛处理，还有抹灰一项，甚至自己发明创造加一项基层处理，这些其实很好判断，业主应该问一句具体是做什么，否则这些莫名其妙的名词只是为了创造更多利润而已，看起来每一项价格不高，但是加起来总价就高多了。

这些重复计算一般都出在所谓高端公司，使劲打广告宣传自己是高端，然后用高端的名义增加自己的利润。这种公司是不屑于低价切入的，否则就不会费劲心思把自己打造那么高端了。业主能找这种公司都是土豪级别，越贵越好，当然在已经无法增加价格的前提下，就可以用各种所谓专业做过度装修，不断创造压根看不懂的项目。
