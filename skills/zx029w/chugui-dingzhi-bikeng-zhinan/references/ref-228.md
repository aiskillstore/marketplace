# 全屋定制太丑，丑在哪里？7.23

全屋定制几乎家家都在做，但是没有对比就没有伤害。为什么有的定制很好看，有的定制非常丑？不外乎以下几点：

第一，丑在造型设计。这个在你不懂全屋定制审美的时候，只能任由他丑了；或者你找的商家完全只图赚钱，而没有一定设计的义务的时候，丑是必然的。

第二，丑在颜色搭配。商家和业主各占一半，因为好多审美业主接受不了，宁愿丑在自己的圈子里头，这就没有办法了。审美不会一两句话就能让人提高的。

第三，丑在实际定制操作里头。例如把手，难看超大的把手，再好的柜子，一个把手毁所有。这就好比一个好看的人，丑在各种饰品上。这就得不偿失了。

▲如果没有基本审美，底子就有问题，后面的面板再好，把手再好，都是白搭，都逃不开如花的“惊艳”。

▲如图各大品牌定制的实景图。而且几乎大部分超大品牌的定制，都是这种样子。不知道业主心里怎么想，看不出问题还是感觉自我良好。同样花钱，别人是功能和颜值都有，而自己充其量就是给家里定制了N个盒子而已。

▲左图是你家的鞋柜+换鞋凳，右图是别人家的。
对比就可以看出来，错误如下：板材选择错误，撇开环保等因素不谈，能做柜体的板材就是那么几种，颗粒板、大芯板、多层板、密度板。因为柜体是挡住了，压根看不到，露出来的可以做见光板处理或者用同色系处理。但是左图显然柜门以及柜体的搭配，导致视觉凌乱，而且选择的这种门板显得非常廉价。至于把手，更是让本身颜值受损的鞋柜雪上加霜了
▲第一左图明显不如右图。柜体板套色没有问题，有问题的是底板以及上头挡板不用柜门同材质，而是偷懒方式直接采用柜体露出来做法，导致视觉非常凌乱，而且美感消失；同时超级大的把手让整体柜子的丑变得更张扬；再看右图，同样是平板柜门，无把手与拉槽把手结合，视觉不仅极简，而且尽量视觉弱化存在感，同样价位完全不同的价值。
▲突出柜子的存在感几乎是审美的一大陋习，千万不要让家里的柜子有各种难看的线条，称之为造型，其实反而让本来颜值不高的柜子更加高调。
▲视觉简洁，套色整齐，视觉上更柔和有档次
▲上图做法，几乎进入家里都是柜子，而且颜色以及镂空非常凌乱
▲上图10米的超长定制，大面积白色，让收纳除过功能以外，低调不张扬，这才是审美，才是定制的精髓要点
▲这种衣柜定制不知道是谁给的勇气，如果业主不懂情有可原，但是这种定制商家这是拉低人审美的操作，压根不负责任，只负责做盒子赚钱
▲不吊顶通顶其实不怕，只要让定制低调一点，不要那么张扬，弱化存在感就不会有问题
总结：全屋定制的美丑，一多半在于商家的责任，一少半在于业主对价位的认可。有的商家你重设计，定制价格就很高，但是所有大品牌是冲着数量去的，不会去为了某一两家给你设计颜值，只要盒子做的多，就能赚钱，可怜老百姓把这种大量做盒子的叫做大品牌。
