# 后期全屋定制，红砖包管道多此一举10.16

在实际装修里头，好多下水管需要用红砖包裹，然后贴砖，起到装饰遮丑隔音保护的作用。

▲常见的地方就是厨卫空间，因为有水有潮气，而且因为都是高层需要起到隔音作用，墙面需要铺贴瓷砖，一般厨卫都选择用红砖包裹然后后面抹灰贴瓷砖。
以上是常规常见的施工做法，但是在实际装修里头有好多地方是无需用红砖包，而且红砖包会占用很大地方，而且造成浪费
▲如图如果家里有中央空调，利用空调外机位置扩充阳台空间以后，阳台无需贴瓷砖，此时外露的两根管道根据情况，就可以采用石膏板隐藏装饰，后期刷同色乳胶漆即可；轻巧不占地，而且也起到隐藏作用
▲如上图，阳台做了休闲书桌办公区域，原有的管道采用石膏板装饰，刷同色乳胶漆，管道的外边做个和管道平齐的储物壁龛，可以满足少量书籍的放置，不仅隐藏了原有管道，而且完全让管道隐藏到无形，整体更好看美观
▲如图，原有管道石膏板包裹刷同色乳胶漆，利用夹角位置刚好定制书桌，满足书架的定制，隐藏管道于无形，而且占地小，整体空间更整洁
▲如果是洗衣阳台与客厅打通布局，不贴砖，直接定制收纳柜，此时不用多此一举用任何东西包裹管道，后期定制柜子直接就可以隐藏，而且管道的前面还可以满足镂空收纳和展示，一举两得。经济还好看
▲对于如图精装修的房子，本身阳台就是真石漆，管道裸露，而且这里又不放洗衣机，此时可以除过花架以外，采用麻绳缠绕装饰的形式，让原有管道变得更美观即可，因为墙面不动的前提下，用任何东西包管道，颜色上无法做到一致，更突兀、更难看
▲阳台比较大的空间，后期如果要定制柜子，管道也无需单独包裹，一是太占地方，二是无形中造成资金浪费；直接如图高柜与地柜形式布局，管道隐藏在高柜里头，利用柜体就可以隐藏，而且还满足了一个清洁柜的收纳
▲如果有下水的阳台与其他区域打通，如图，可以采用直接定制隐藏的形式，而且还可以成就一个小的收纳高柜，延伸做一个书桌，完美隐藏原有的难看的管道
▲如果后期阳台定制如图的样式，在设计之处就定好了，下水管道就无需用任何材质隐藏包裹，直接定制柜子就可以隐藏，省钱而且节省更多地方
▲其实类似的情况有很多，所以在设计之处，规划好以后，这些管道其实压根无需单独掏钱去包裹的，后期直接就可以完美处理，省钱而且还好看。

▲即使阳台是上下断开的设计，也是可以完美实现利用定制隐藏管道的
▲原有管道完美利用定制隐藏，同时管道前方还可以做成书架形式，完美隐藏管道，而且省钱好看
▲看一下简单的示意图，即使阳台不铺砖，吊柜加地柜的做法也是可以的，原有下水管道不用刻意包裹，直接采用定制就可以隐藏，而且可以给后期洗衣盆留下更大空间满足。
