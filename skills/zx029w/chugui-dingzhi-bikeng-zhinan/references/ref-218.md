# 全屋定制不是开盲盒，哪能这么随意11.30

全屋定制说了好多专题，大家还是多多看看，多多比较，这样才能自己做的时候能发挥最大价值，少留点遗憾。今天还是对比说事，当然如果坚持丑就是美，没有什么审美标准，能接受也是可行的，自己喜欢就行。

▲左右图对比一下，左图明显要高级很多。第一隐藏柜体，这样可以弱化立体感和存在感；第二侧面做了柜门的封闭收纳，不论是打开还是关闭，让视觉更统一；右图明显是过去年代的产物，喜欢外露柜体做层板，其实真的过时了，无形中是高调宣示自己的丑了；上方封板错误的露出柜体板，一是审美问题，第二是定制上为了省事而已
▲以上两个大致做法相同的收纳柜，左图明显要好看多了。注意同样是因为柜门无法达到高度问题，右图直接采用柜体板做了难看的封板，而左图采用和柜门一样的颜色做了封板，细节之差，虽然麻烦一点，但是视觉颜值要好看多了。从这一点就可以看出全屋定制商，谁才是替你着想的那个。
▲不论从审美还是功能上，很明显能看出右图，比较张扬高调，这就犯了装修里头的大忌。任何单品太过于豪放，而且没有一定审美的支撑，就是无限放大这种丑陋。
▲过于暴露，问题一目了然，喜欢开放格，但是没有审美支撑，导致厚重的颜色过多，导致收纳书柜太高调，进而整体空间都会显得压抑，还是犯了全屋定制高调的大忌
▲同样是浅色与木色的套色，区别到底在哪？很明显右图不讲究藏与露的比例，随意而为，封边外露柜体，很明显缺乏基本的设计美感，仅有价格但是缺少了居家定制的价值
▲左右对比，右图很好的诠释了什么叫做定制复杂盒子，充其量就是雕花盒子而已，只注重每一处雕花的土豪，而完全忽视整体的美感
▲右图甚至用了无把手反弹器，但是却犯了一个最基本设计错误，柜门超过45公分，导致视觉难看，而左图虽然安装了把手，但是柜门要窄，同时上方去掉了封板，虽然用的是国产的吸塑柜门，也比右图的通柜门要更精致
▲要学别人做满墙收纳柜，求求你别用把手了，真的太丑了，像是满脸的麻子一样。别老想着柜门不好开，反弹器比这种把手好开多了。不能东施效颦，看别人做满墙柜好看，不看别人是怎么变美的，越学越难看，不如不学
▲上两图对比，其实都是很小的满墙柜定制，右图明显是设计失误，毫无比例美感，随意规划尺寸，而且本身很小的空间，过重的颜色点缀导致没有重点，看起来就失去美观性
▲公平起见，都用手机拍照对比，好坏立马有了结果。右图大面积裸露柜体板，而且不讲究比例美观，反正只要完成盒子定制就行，这样的全屋定制即使再便宜又有何用？
▲同样一个位置，同样是入门见厅的鞋柜兼顾餐边柜的做法，右图明显是审美比例有问题，多此一举做这么多无用的背板，反而显得很廉价，设计感和美观以及价值一目了然
▲任何一个定制柜的存在都得多听听专业人的意见，大部分业主因为看到的少，根本没有对比过美丑，所以设计师一再坚持让你做的样式，你得考虑为什么，而不是老是活在自己八十年代对家的记忆里头，最终结果是钱没有少花，效果完全没有，而且最大可悲之处是浪费了设计师的一片苦心，你如果就是喜欢右图的做法，真的没有必要要设计师
▲长得丑算了，还这么高调，那就难看了。这是全屋定制一个最简单的法则，弱化存在感，丑的地方尽量遮盖隐藏，其实和好多女士用头发遮挡脸部的小瑕疵是一个道理，美放在任何地方都是通用的。要不是定制商完全是定制盒子，要不是业主坚持己见浪费了设计
▲同样是鞋柜拐角带餐边柜，审美标准一目了然，并不是你空间大就能有价值，在毫无审美的支撑下，再大的空间也只是打造盒子的堆积而已。弱化存在感是基本常识，但完全分不清美丑的张扬就太高调了
▲不是大品牌还真的做不出来右图如此东西，这个完全称不上定制，妖魔鬼怪呀，颠覆了对设计的认知了。这个方案业主是怎么通过的，没有这套房之前，到底经历过什么艰难困苦才能接受如此审美的定制
▲不讲究任何章法与比例，随心所欲去做，想做什么样子做什么样子，那全屋定制只能是盲盒，出来什么样子算什么样子
▲定制翻车的原因是什么，没有对比没有伤害以为自己的很美，做完了看到更好了，才发现自己家做什么都不是。没法改变，一般定制能给你做成这样，稍微有点审美的业主图纸是没法过关的，所以起决定作用的是业主，而非定制，这设计水平何必去找呢，不是便宜就是图大牌。
总结一下：全屋定制找法和找装修机构一模一样，除了本性能替你着想，把自己的事情当做事业去做的责任心，其次一定要有一定的审美，否则这么丑你能过关，说明你没有把握住而已；或者设计者极力让你变美，但是你就是喜欢八十年代的审美，没有办法，只能放弃了。虽然说房子是自己的，再丑自己喜欢，但是总得有个比例审美和常识审美，底线是不能突破的，毕竟一个专业做设计的比你见过的多，什么好看，什么不好看，百分之九十是对着的。
为什么会出现定制翻车？第一，找对定制商，有设计要求尽量不要找所谓大品牌的百姓品牌定制，那就是批量的工业产品，和设计没有半毛钱关系，充其量就是生产盒子而已，一定要找有设计感的，对设计负责的定制商。这就是为什么我们的定制从来不专门请哪些定制的画图，因为压根不懂设计，我们定制画图必须装修设计师从头到尾把关，全局考虑，细节把关，才能让整体更有价值；第二大部分其实外表已经够好看了，但是压根拉不住业主这里要个层板，这里要个镂空，这里必须装上把手，完了，全毁掉了，毕竟业主说了算，这就是第二种翻车的原因了。
