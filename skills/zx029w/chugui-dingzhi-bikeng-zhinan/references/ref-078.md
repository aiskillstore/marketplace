# 柜门用PET，难道就环保了？10.27

相信了解过全屋定制的人，都听说过PET柜门，好多人有个误区，认为PET柜门就是环保的，但其实这个和环保没有任何关系，否则又进入误区里头了。
.01什么是PET？

PET塑料是由对苯二甲酸和乙二醇通过酯键连接而成的高分子化合物，通常以无定形和半结晶的形式存在，主要用于饮料瓶等包装材料，其透明度高、稳定性强，各种化学药品酒精、输液瓶等都广泛使用，与PBT(聚对苯二甲酸丁二酯)一起统称为热塑性聚酯或饱和聚酯。
.02定制的PET板是什么？

如图常见的PET板，多见于柜门的使用，厚度一般常规的18mm厚，但是你千万不要误会，这么厚都是PET材料制作的，那就误会大了。

看上图就知道了，所谓的PET板只不过是18mm板材上下几毫米的PET而已，和吸塑门类似，就是覆个薄膜而已。

PET板材只是表面几毫米的膜，内部基材还是上图所示的基材，所以你用PET和环保压根没有多大关系。

如上图，左为吸塑柜门，是整面覆膜，正面看是无法看到封边条的；右图就是PET柜门，和所有人造板封边一样，正面是能看到封边条的，只不过采用同色封边条不那么明显，但是如果纯色浅色工艺不到位，胶线就很明显.03PET和吸塑柜门，哪个更有优势？
