# 冰箱放厨房最好，怎么放是个问题2.23

冰箱位置，厨房肯定是最好的首选地，实在没有办法才退而求其次。但是厨房狭小，冰箱放厨房会占据很大空间，怎么能通过设计，让冰箱不仅完美放进厨房，而且各个角落还能最大发挥收纳和操作功能，这个就需要下一番功夫了。

▲侧面镶嵌冰箱，采用高柜的形式满足镶嵌，高柜隐藏角落的烟道；同时高柜与烟道夹角剩余朝外开放格子布局，利用空间满足随手置物需求；吊柜夹角位置内部刚好有烟道，采用一边开放设计，避免柜门冲突，很好的满足平时的使用功能
▲如图U型厨房布局，利用进门右手高柜定制，同时满足冰箱的隐藏以及电器的镶嵌，剩余空间完全满足基本的烹饪操作
▲如图厨房比较大，一边L型高柜，不仅满足冰箱的完美镶嵌，同时满足了电器的布局，收纳容量也进一步提升。最完美的是冰箱颜色与定制颜色浑然一体，细节满分
▲厨房角落有烟道，在前期规划一定要想好烟道的厚度问题，如图，进门左手高柜与烟道平齐，刚好满足冰箱的镶嵌，剩余空间高柜拓展厨房收纳
▲相似的做法，完美利用了凹陷区空间，同时提前考虑烟道贴砖的厚度问题，让视觉和空间都完美无瑕
▲开放式餐厨一体空间比较大，在不遮挡光线的前提下，定制高柜同时满足冰箱和电器的布局，虽然冰箱比较厚，突出来一点，但是视觉上并不影响整体美观，同时还能保证冰箱门的180度开启
▲常见做法，一边高柜镶嵌冰箱，剩余空间要不直接镶嵌电器，要不做成镂空格子，方便置物，同时可以摆放小的家电，也是颜值和功能兼顾
▲侧面正常镶嵌冰箱，旁边地柜满足了洗烘机的镶嵌，同时台面的操作空间变大，上方吊柜还隐藏电器架，视觉也是非常好看，而且保证操作空间的最大化
▲侧面高柜满足冰箱和电器的完美镶嵌，收纳不仅多了，视觉更好看；如果不要电器，这里也可以作为高柜拓展厨房的收纳能力
▲U型厨房，保证最大化的L型操作空间，左手高柜定制，同时满足冰箱以及电器的镶嵌，而且还延伸高柜满足更多收纳需求
▲一般家庭厨房只要满足L性操作台即可，剩余空间都可以考虑收纳的延伸，这个才是科学的布局方式
▲满足足够的操作空间以后，门口位置打造高柜满足冰箱和电器的完美镶嵌，刚好利用移门只开一扇的功能，也不会影响正常的过道进出
▲一侧整体高柜满足冰箱以及电器的隐藏镶嵌，同时地柜上头高柜延伸出开放格布局，可以随手拿去物品；做柜门的话刚好与旁边灶具和烟机冲突
▲空间有限，也可以单独高柜只镶嵌冰箱，视觉更好看，不至于单独冰箱露出来很突兀的感觉
▲如果为了满足更多的台面操作空间，也可以如图所示，只把高柜镶嵌冰箱，剩余空间正常台面吊柜布局，紧挨冰箱地柜镶嵌电器，台面的操作保留了，只不过这样的电器使用起来需要人蹲着操作
▲如图冰箱上头的吊柜很薄，取东西每次都得踩着凳子，这个是没有办法的办法，因为吊柜无法和冰箱厚度一致，否则和旁边的烟机位置冲突，就会导致切菜位置缩小，所以权衡利弊这样做。还有一种做法就是把冰箱单独高柜镶嵌，上方吊柜与冰箱厚度一致，这样视觉更好看，而且拿去东西也方便，但是造价就会高一点，所以这种情况需要多方面考虑
▲左侧镶嵌冰箱以后，宽度刚好不够镶嵌电器，刚好可以借用侧面地柜上方空间，完美实现，同时剩余空间开放格布局，可以方便烹饪时候物品的随手拿取
▲冰箱单独高柜镶嵌不突兀，凹陷区隔板布局，可以放一些随手的厨房零碎；下方太窄刚好镂空，布局一个小推车，合理利用空间
▲哪怕旁边没有高柜，只要冰箱单独完整高柜的镶嵌，就可以避免冰箱的视觉突兀，但是这样做，冰箱下方的柜子就会产生费用，美观与成本成正比，所以看自己考虑和接受，只有上方吊柜，冰箱两边不要侧板，肯定突兀不好看
▲比较一下没有高柜包裹，直接放置冰箱的效果，而且吊柜与冰箱还不齐平，不影响使用，但是影响整体美观而已
▲相当一部分厨房冰箱都是这样放的，一是放置方便，第二也省钱；不美观也浪费空间，这就是低价和品质的区别所在了，不过能接受就行
