# 橱柜柜体采用什么板材去制作？12.29

橱柜其实和衣柜材质是一样的，这个在过去是有区别的，因为衣柜不论采用什么人造板，至少都是足18mm的厚度，但是过去的橱柜根本不是这么厚度的板材，往往会采用15mm的非标厚度，节省成本，所以价位会很低。

▲如上图所示，人造板里头有大概四种厚度规格，做衣柜一般是足18mm的厚度，书架隔板、书桌面采用25mm的厚度，局部桌面可以达到36mm的厚度。如果是稍微正规或者保证质量的橱柜柜体，至少在18mm厚，但是为了低价竞争，好多橱柜都采用15mm的厚度，这样成本就能降低，用降低质量来获取更多订单量。所以一定注意：不论用哪种板材，至少是足18mm的板材做柜体。
▲颗粒板，大家都知道这种板材，现在几乎大部分全屋定制都采用这种板材。做橱柜也是没有问题的，只不过污染稍大而已。各种颜色都有可以满足大部分家庭的使用。
▲生态板，一样是人造板，和颗粒板类似，但是比颗粒板要环保多了。唯一缺陷是木条的填充方向一致，就会导致相反方向结实度稍差。做橱柜柜体足够

▲多层板，同样是人造板，环保与生态板一样，都要好于颗粒板。比生态板的优点任意方向都是结实的，做全屋定制人造板属于好的板材了。橱柜柜体足够了
▲欧松板，也叫作OSB板，同样也是经过压制而成的，只不过这种颜值做衣柜或者橱柜柜体，真的要有一定的勇气，不是另类前卫的人很难接受这种颜色。
▲指接板，再不济那也是实木，像普通做衣柜橱柜柜体采用的橡胶木指接板，要远远好于所有人造板，造价也高，环保性能也好。
▲砖砌橱柜，最结实，最环保的做法，就是比较占地方，过去常用这种方式的做法，随着各种板材的普及，目前很少有人用这种做了。太难适应各种复杂的设计了，比如抽屉，各种镶嵌电器，一旦错了后果非常严重
▲瓷砖橱柜，和砖砌类似，只不过采用双面大规格瓷砖配合铁艺架子做成的，环保没有问题，结实度同样没有问题，但是瓷砖如果造价非常高，做出来比普通板材橱柜价格要高很多。同样普通样式可以，很难适应复杂的设计要求。后期一旦错误，不像普通板材那样容易修改。
▲不锈钢橱柜，可不是普通的做个不锈钢皮的橱柜，而是真正的纯不锈钢柜体，一般人承受不了价位，有兴趣可以去搜索查找一下。
以上就是常用的橱柜柜体材质，砖砌这个用的很少，除非你家设计要求很低，适应普通家庭是可以的；如果考虑到造价，人造板里头推荐多层板。不考虑造价可以用橡木指接板或者白橡柜体，也是可以的。一次性到位，橱柜哪来这么多附加费用？
