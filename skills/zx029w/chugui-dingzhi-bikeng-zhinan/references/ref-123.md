# 定制柜上方有大梁分割，怎么做好看？12.7

定制遇到大梁的事情太多了，不过每一种都有不同的解决办法，今天看看如果定制碰到大梁怎么处理更好。

▲如图进门的鞋柜，想要延伸定制，但是中间有大梁，又不想吊顶太多，可以采用高低柜的形式满足收纳的延伸，也可以弱化一下压抑感，同时增加了台面的置物

▲如图同样是中间有大梁，但是吊顶做了延伸，而且与大梁平齐，此时高柜就可以延伸定制
▲如图所示，一部分有平面吊顶，中间有大梁，吊顶不平齐，此时又需要高柜延伸，只能L型满足功能，就会出现上图的样子，虽然不影响收纳，但是视觉上不太好看▲如图阳台柜定制，刚好有大梁比较低，此时采用局部镂空套色的形式，延伸定制，而且视觉上更有层次，同时还弱化了大梁的突兀感▲如图同样是因为有大梁，不想做吊顶，此时只能L型定制，还好大面积白色弱化了这种瑕疵
▲如图阳台与客厅之间有大梁分割收纳柜，吊顶又无法过低，此时采用镂空的形式弱化大梁，同时也成就了空间的区域划分，视觉上反而更有层次▲如图同样是因为阳台大梁的分割，而且过低，此时一面墙收纳柜定制，就形成了一个小的刀把结构，不过误差小，瑕不掩瑜整体不受影响▲如图阳台大梁太大，阳台随时压低吊顶，但是客厅整体平面吊顶不能过低，此时为了一体定制，就形成了一个刀把一高一低的样子，只不过大面积纯色，小的细节并不影响整体的收纳和效果▲依然是过低的大梁分割了定制柜，采用梁下镂空的形式，弱化大梁的突兀，而且作为空间的视觉分区▲同样是阳台大梁过低分割了收纳柜，采用镂空的形式弱化大梁的突兀，而且视觉做了分区，还满足了不同的收纳形式▲如图电视墙右边有大梁过低，但是定制柜想要延伸，此时为了避免难看的刀把，采用梁下镂空灰色套色的形式，既满足弱化大梁的突兀，又能作为展示作用，而且视觉上同样与收纳柜一体延伸▲如图所示并不是大梁，而是空调的吊顶，但是又不想多做吊顶，此时想要收纳柜延伸，只能采用一高一低的形式满足空间，刀把在所难免▲卧室空间，床尾定制衣柜，为了利用好飘窗的角落，需要延伸定制，此时飘窗上头有突兀的大梁，只能平板延伸，视觉上虽然有刀把结构，但是满足了更多的收纳▲类似的做法，只不过是利用飘窗下方做了镂空的书架布局，这样梁下区域分区不同，视觉上不会有很明显的刀把结构。而且飘窗大梁高可用和吊顶平齐，视觉上就更完整了▲如图大梁分割了收纳柜，此时梁下采用开放格布局，弱化大梁，同时作为视觉分区，一举两得▲如图一样是大梁分割收纳柜，刚好下方布局洗烘机，视觉上大梁不显得突兀▲如图不做吊顶，但是收纳柜被大梁分割，此时大梁下方只要采用镂空的形式，弱化大梁的突兀，视觉上就能美观多了
