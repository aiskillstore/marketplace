# 全屋定制一次性搞定，哪来那么多增项？3.13

前面有一篇橱柜的定制大家可以参考《一次性到位，橱柜哪来这么多附加费用？》今天谈谈全屋定制需要注意的后期增项。

大部分业主如果找所谓大品牌全屋定制，就是都是颗粒板的那种，一般都会根据你家户型拉一套模板，让你看样子。然后根据这个样子只要你能看上，报价是现成的。

▲例如这种丑到家的模板效果图，让业主看，业主没有见过好的，自然不懂审美，而且大品牌，打折各种活动，已经无法分辨好坏。一看报价而且各种优惠活动，经不住诱惑，一大笔定金就交了。此时没法后悔。

但是后期一旦复尺开始具体设计的时候问题就来了，业主当然会有所对比，此时好多费用就莫名其妙的出来了。

一般投影和展开计价方式两种，如果是展开，那你做任何东西都得计算到预算里头，这个费用是根据你的要求节节攀升的。比如给你看的是非常简单的衣柜格局，但是后期设计要根据要求分类布局，这样层板无限制变化，展开面积当然就多了去了，如此这般，你家全屋定制费用能不增加吗？和当初给你看模板时候的总价差很远，除非你不需要个性的设计，按照最简单的去做，但是完全满足不了你的需求。

类似的太多了，给你看的没有边线后期要加，加钱；给你看的吊柜不通顶，后期要加；抽屉要加，层板加厚要加。除非你按照他们模板里头的做法什么都不做，但是基本就是个盒子，完全失去全屋定制的意义了。

所以，你如果找所谓大品牌看模板直接交定金，一定谨记如果是展开计算，这个费用后期设计会无限制增加的，如果你能承受就继续，否则最好不要交大定，除非你能承受后面不断的加钱。

如果是投影面积计算，需要注意是否个性化都得加钱，这里注意：既然是投影了，你要求越多其实商家成本越高，例如层板，如果是投影的话当然商家巴不得你一个层板都不做；抽屉是否单独计算，如果是，那巴不得你一个抽屉都不做；边线是否单独计算，是，巴不得你一个边线都不要；

两种计价方式看，其实投影是业主最划得来的，问清包含的东西，然后你随便根据个性要求设计，都不会产生一分钱额外费用；例如我们现在做的多层全屋定制，除过见光板收取费用外，其他都是包含在内的，抽屉和层板随便做，业主愿意做多少都行；原因在哪？我们赔钱做？当然不是，因为平时的板材量非常大，给任何一家的板材剩余的料都堆积成山了，后面业主的抽屉和边线层板，这些能用上的都可以用上的，只要颜色一致就行，如果不用这些剩料都得扔掉当垃圾处理了。所以这才是敢投影无限制做的原因。

那你们找的为什么各种都得后期加钱呢？一是商家黑心而已，压根不可能做什么口碑或者回头客，这一点跟装修非常相似，得罪一家，后面再用相同的方法宰下一家；二是你们找的是二道贩子，压根不是厂家，那个性要求都得加钱，否则抽屉边线层板无限制做，商家得赔死。厂家就无所谓了，别人剩的相同的料完全可以给下一家使用，所以才敢投影计价无限制去做的。
