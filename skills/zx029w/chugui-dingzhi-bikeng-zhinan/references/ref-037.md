# 做衣柜平开门还是推拉门？这有啥纠结的？5.14

平开门，顾名思义就是可以直接拉开的，好处不言而喻，可以整体打开，展开衣柜的所有内部空间，拿取东西，挂衣服都比较方便。

平开门还有一个好处是推拉门无法比的，就是各种各样美观的造型，可以根据风格做出相应的造型，能最大限度与家里风格搭配。而且因为可以做各种造型，可以在门上镶嵌镜子，省却了穿衣镜的单独位置。

平开门因为不需要轨道，只需要铰链连接，同等材料，造价要比推拉门低，所以在降低整体装修成本上，平开门占优势。

平开门的另一个优势就是密封，这往往是业主需要的重点，特别是北方地区，平时灰尘比较大，衣柜又是放衣服的地方，所以平时密封性要求很高，平开门的关闭状态完全可以做到严丝合缝，这也是推拉门无法企及的优势。

平开门的缺点呢？不言而喻，占地方！如果卧室很小，床和衣柜之间的距离小于门的宽度，那就无法实现平开门，这就是平开门最大的缺点。

平开门不能做太高，影响整体美观，必须有分区，这样就会有缝隙，而且如果过高重量会影响铰链的咬合，容易变形和下沉，这点推拉门就没有后顾之忧了。

所以，你家空间够就做平开，空间不够就做推拉，无需纠结，也不是你该纠结的问题，而是你房子大小的问题。

推拉门顾名思义就是左右推拉的，有上轨或者有上下轨道，这样就会导致，永远只能开启一半空间，在拿取东西的时候，左右推拉很不方便，而且有滑轨就得占用衣柜空间，同样平开门空间要比推拉门空间大很多。

但是正因为是推拉门，左右推拉，在整体空间上，推拉门能节省外部空间，比如卧室很小，离床很近，即使贴近床放，推拉门照样能使用，平开门就不行了。

所以，还是那句话，你家空间小只能用推拉，你家空间大，那就用平开门吧
