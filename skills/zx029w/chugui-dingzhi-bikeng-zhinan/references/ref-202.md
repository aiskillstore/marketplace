# 别被全屋定制 “网红图” 骗了！这5个坑碰一个就后悔

全屋定制与装修一样，都有网红款的设计，但说句良心话，这些错误与网红无关，只不过太多人不愿意独立思考，乐于跟风而已--所以，当你跟风网红设计的时候，你得想好承受的价格，绝对不要模仿，否则必入坑！第一、弧度转角，做的时候就得考虑“弧必裂”别看刚装完没问题，随着热胀冷缩，以及用了软化剂的，填充物的变化，问题就出现了，一旦有了问题也就是翻车的时候了。网友@omo：全屋定制，高价做的弧，裂了几次，重做依旧开裂，历时三个月依旧没有解决办法，真后悔跟风了。网友@胡楚靓：还没入住圆弧就开裂了，全屋定制说是热胀热缩。网友@月兔：安装完才一个多月呀，大几千一块的弧形柜门鼓包了，定制商说是弧度时间长了都是这样的。后记：弧度无罪，有罪的是模仿者而已，你想要这样的效果，就得承受这样效果的后遗症，有些东西太过于追求颜值，就得付出别的代价，除非你用金属弧度，只能说一句：切勿跟风！第二、一门到顶好看，但代价太大跟风一门到顶，结果自己家没有这个条件，定制商是不管这个的，只管做柜子，也没有让定制商验收安装条件，结果是只能自己背锅。网友@盐焗：衣柜跟床距离就这么大，习惯站在这，特别是着急拿东西的时候，每次都被撞，这也是一门到顶的代价。网友@小窝：柜子一门到底吗 你们也是趴下。打开门擦吗 我好恼火。网友@啦拉：终于变形了，做之前就担心一门到顶变形，商家口口声声说没事，结果打脸了
网友@辞旧迎新：最可气的是做一门到顶，然后非得安装拉直器，不装不给售后，一个拉直器收了200元，结果柜门一样的变形，才知道又当了一次冤大头。《装修看着挺厉害的做法，现在用起来真坑》后记：一门到顶和阳角弧形道理一样，你要做以为的“好看”，就得付出难看的代价，除非你做金属门或者玻璃门。第三、电视柜隐藏插座，以为花里胡哨是设计学着邻居做了下翻柜门，也没有想着有问题得趴着检修，简直被自己蠢哭了，一点脑子都不动，结果只能后悔。邻居下翻柜门肯定有问题，应该做上翻柜门，结果是卧龙凤雏，还不如下翻柜门，一样的有问题趴着检修。上下翻柜门都翻车了，来了个大聪明设计师，给你做个抽屉式收纳，不就好了，一个抽屉才200元，于是乎大家高呼：好高级的设计。隔壁老李一看设计师做的嗤之以鼻，一分钱不花让定制直接做个上翻门，简单实用。隔壁老王把大家都看了，更是简单，不就是一个活动盖板搞定的事情，为什么那么多人喜欢脱裤子放屁，甚至愿意掏钱当冤大头呢？后记：任何花里胡哨的做法，看似高级，都是为了收割韭菜，必须思考一下，为什么非得把简单事情搞复杂呢？为了金钱而已。第四、衣柜玻璃柜门，是为了看的网友@ay-：当时做衣帽间的时候有多快乐，现在就有多痛苦。现在每天进去衣帽间我都想把他拆了重做，衣服不能乱放，要不然显得乱糟糟，而且不知道为啥玻璃每天总是很多灰，还擦不干净的那种。玻璃门柜子=杂物羞耻放大镜！玻璃柜的尽头，是P图软件和遮羞布！网友@CC：之前老喜欢玻璃柜了，觉得很有氛围感，很高级，结果昨天去朋友家吃饭，他家刚装好3个月，我看到他家的玻璃衣柜后，和我想象的完全不一样。后记：为了环保衣柜玻璃门是可以做的，但是普通老百姓不要想着氛围感和高级感了，生活档次不匹配，占一个环保即可，否则只能失望。第五、定制盲目跟风极简收口定制极简收口肯定好看，但是你得有自知之明，自己家墙面是否满足条件，完全不管，你让一个只赚钱不管条件的定制商给你施工，必然会出现遗憾你找的定制商只管量尺赚钱，也不管你墙面是否符合定制条件，结果就是上图的样子，吃亏的永远只是业主而已。因为定制商不负责，否则这种墙面必须要求整改到位的。别人家的极简不看付出多少努力，你这个随便施工就想极简高级，是不可能的，所以必须学会嫁接风险，否则担责的都是业主自己《装修10招嫁接风险做法，聪明业主早都用上了》定制想要平整，绝对不是只有让业主做墙面垂平这一条路，只不过是找一个良心的装修人和定制商而已。《墙面顺平≠不平整！盲目做垂平反而多花冤枉钱》后记：全屋定制和装修紧密相关，需要有懂全盘的人去把控，而且要学会规避风险，责任嫁接，否则一步一个坑付出金钱代价结果有时候更不如人意，关键是好的装修人和好的定制商，缺一不可。
