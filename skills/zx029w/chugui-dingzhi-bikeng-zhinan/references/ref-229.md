# 全屋定制，牢记9个不做6.7

全屋定制设计和装修设计一样，甚至要比装修设计更复杂，并不是定制盒子那么简单。
第一、不找套餐，不找所谓百姓品牌。
▲和装修一样，只要是套餐必坑。不要只看到低价，坑了然后骂人，坑你是有原因的，并不是无缘无故的，你越是贪婪，你越找套餐，越会被坑。装修和全屋定制都类似，都是非常个性的定制活动，哪有什么标准？几乎不可能一样的做法，除非你能找到一家良心的投影计价，设计的多少以及做法和价格无关，否则当时的低价，随着你的个性化需求越来越多，价格也就越来越贵。所以不要碰套餐，只不过自欺欺人而已。第二、没有审美不做乱色▲如上图一样的做法，你要那个就看好图纸，而不是自己都不看图纸，定制随意做？肯定不是，而是大部分都没有审美，不知道人家都是怎么做的，低价糊里糊涂做完，才发现别人家比自己更美。--为什么有木色的边线和上头封板露出？因为这样可以节省一张见光板，同时柜门用的更少，简单也降低成本▲衣柜也是一样的做法，除非你提升自己的审美，否则图纸肯定是对的，只不过你压根不知道这样做的后果，或者是做完了才发现别人家怎么好看，自己家怎么好丑，而且价格还高。和装修一样，需要找对人而已，并非只看所谓品牌，这是被商家和媒体合伙洗脑的结果。第三、不要高调张扬，做人也一样
▲全屋定制如果不懂审美，一旦高调就输了；如上图所示一样的花钱，总认为花了钱就得别人能看到，这刚好与审美背道而驰-----突兀的柜体板外露，突兀的把手凌乱，都是太过于张扬了▲如上图所示，第一张明显就是犯了高调的错误，不仅明把手突兀，而且人为把重色块加多，不懂颜色搭配的比例，而且高价做了大面积的玻璃柜门，视觉更乱，更高调了，也就没有品味了▲不追求所谓网红的潮流，但是一定要安静、低调，这样即使普通，也绝对不会廉价和翻车第四、最好不用亮光材质▲亮光材质本身自带廉价感，其实这个是生活常识太多见了，如果用到定制上，气质立马就变得不值钱了，和高调错误是一样的属性第五、能不用把手不用把手▲衣柜要不就用极简把手，两个柜门一个把手，要不就拉槽设计，能不用反弹器尽量不用，没有办法的地方再使用反弹器▲绝对不能用一个柜门一个把手，而且非常突兀的做法《全屋定制，3种把手早该淘汰》▲公共区域的定制绝对不能用把手，否则必然会有廉价感，此时首选免拉手拉槽设计，实在没有办法的个别柜门采用反弹器设计第六、不能做推拉门▲推拉门不仅占用柜内空间，而且再怎么做都自带廉价感第七、不做大面积玻璃柜门
▲不仅贵而且难看，凌乱，你家是过日子，并不是样板间是为了让你买房专门收拾的▲玻璃柜门是放置展示品的，不是做收纳用的，大面积不仅浪费空间，而且显得更乱更廉价第八、不盲目做一门到顶▲毛坯房尚且达不到条件，这个精装修盲目做一门到顶，翻车的地方就太多了，难看而且显得廉价▲不吊顶做一门到顶，第一必须装修基础横平竖直，第二板材高于两米四造价就高，第三变形几率加大，后期有钱更换就可以。这一切都建立在金钱基础上，否则还是正常做法▲装修整体档次上不去，你做了一门到顶也难看廉价；装修档次整体有设计感了，即使你不做一门到顶，那也是有颜值的第九、满嘴百分百环保的，直接淘汰
你选人造板压根就不可能环保，用人造板，谈环保本身就是自欺欺人。更不要相信所谓环保等级，这个是骗普通人的把戏《装修环保是零污染？错到离谱了》你不思考最容易上当。但是作为老百姓又不能不用人造板，此时你要根据自己家里入住人口情况去定制《全屋定制，该不该一次性做好所有柜子？》如果你找全屋定制，商家口口声声，你放心，我们都是E0级或者ENF级，保证环保，这种人赶紧让走，因为你不懂环保概念，明着骗你而已。
