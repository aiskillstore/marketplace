# 衣柜定制打制和买成品，你心里是否有数？3.12

装修新房少不了衣柜，先搞清楚三种做法的含义。

定制：厂家直接量取尺寸，根据空间，做好直接安装。

成品：家具城买现成的。

打制：买好板材各种辅料，工人现场制作。

三种方式各有各的看法，每个业主都有自己的主见。先不说哪一种优胜。三种方法哪一种易于实现？

很显然，买现成的最易于实现。每个地方不论大小都有各种各样的家具城，满足不同人，不同风格房子的需求。但是买现成的，你看不到板材，承诺的东西你根本看不到。如果你看各种证书，那就更不可靠了，谁不知道我们是办zheng大国，很容易就可以弄到各种证件。所以，如果你对板材要求不是很高，经济情况有很大的弹性空间的话，选择买现成的是最明智的。你是土豪也好，是工薪阶层也好，现成家具都有不同档次可以满足需求。所不同的是，你不要执意板材的品种，只要看是否结实，是否能用就行。

买现成家具的弊端一是看不到板材，这个可以忽略，只有能用就行，至于环保和板材没有关系。二是无法和家里的空间严丝合缝，只能将就着放。

于是定制家具就显示出来优势的一面，不论什么空间，不论什么风格，厂家定制是全可以搞定。而且工厂批量生产，工人成本，板材成本都可以降低，而且你可以看到自己选择的板材是否用到自己家。所以综合来看，定制是最省事最经济的做法。

最后一种，现场制作。按照目前西安市场，已经很少有人现场制作了。自己买板材成本肯定很高，而且同样板材质量不同，业主根本分辨不来，只不过自己买是一种安慰而已。再一个现在的木工有几个有真正木匠手艺的？都是用气钉和各种混合胶粘，工艺的细部是不可能和机器比较的。而且单个工人干成本要高的多，而且所有板材和工具在新房里堆积，杂乱，工种之间互相协调免不了磕碰，综合看，工人制作是出力不讨好，是已经被淘汰的做法。

所以，工人现场制作不提倡。家具城买现成和厂家定制其实是相通的，因为商场里头的现成家具也是厂家制作，不同的是各个商家贴上自己的标签而已。所以，柜子的最佳选择还是厂家定制。
