# 没想到层板内缩，能让全屋定制锦上添花1.7

全屋定制的做法非常多，而且必须与时俱进，同时也得创新，大家可以在专辑里头查看，今天看看定制里头层板内缩的做法，这些做法都有什么价值和意义，大家在定制的时候也可以借鉴使用。如图所示，衣柜每一层挂衣服区域都会有衣通，而下方挂衣服的话，比价低，每次取衣服都得弯腰拿取，非常不方便，此时采用把隔板内缩的形式，这样满足了衣柜的结构稳定，同时下方拿取悬挂衣物再也不用弯腰拿取了；而且上层挂衣服本身下方就没有多少预留空间，内缩也不会影响放置少量物品。如图下方衣通上头层板内缩以后，下方衣服就一目了然，更好拿取深柜储物的话，内部进深太大，不好查找拿取物品，此时采用内部层板内缩的做法，把内部空间转移到柜门上，这样不仅不会浪费空间，而且满足物品的更好拿取鞋柜也是一个道理，如果进深足够的情况下，采用层板内缩的形式，刚好满足柜门的收纳拖鞋，提升鞋柜的储物量餐边柜镂空处层板做杯架，采用内缩的形式，满足空间的层次感，而且不至于视觉显得拥堵，同时刚好满足平时的杯架功能橱柜转角空间的利用，同样采用层板内缩的形式，满足物品的收纳和好拿取《橱柜转角利用，发挥空间最大价值》家里的小壁龛，实木隔板采用内缩的形式，视觉上更有层次感，也更加轻巧又比如拱形的展示区域，同样层板内缩更有层次感做满墙书架的时候，采用横向层板内缩两公分的做法，不影响功能，但是视觉上更有层次感，书架也变得更有高级感书架定制，竖板层板内缩也是一样的做法，满足视觉的层次以及空间设计高级感书柜与衣柜转角是常见做法，但是有没有发现一个鸡肋的问题，镂空处60公分的进深，不论你放什么东西，拿取都不方便，而且还非常凌乱。放书的话两排不好取，一排浪费空间如图最好的办法，其实就是内缩隔板，满足放书，而且还拓宽了书桌桌面，一举两得内缩层板才能保证物品的好拿取，同时进一步拓宽了桌面空间。
