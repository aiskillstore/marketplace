# 北欧工业风，不放电视，书柜+钢琴，飘窗当卡座

▲也不算严格意义上的玄关，还是很随意的做一些成品的柜子，入门的地方还是以简单为主，可以说是混搭

▲原木的感觉是一条道走到黑的，很喜欢实木的质感，让我能置身在里面轻松愉快

▲看着有点历史的钢琴和欧洲讨回来的古董音响，还有架子上那些黑胶唱片和有些年头的碟，这些嗾使我们用实际和心情的点滴记录。先把生活过得很有家的气息，我们就堆了很多美好回忆的玩意在这里

▲有时候先生放一张黑胶唱片，我们一起品咖啡；有时候我一段钢琴，家人一起聆听

▲客厅是家里面呆的最多的一个地方，我们都不是很喜欢看电视，所以客厅没有传统的方式做一个电视背景墙，留下一大面积的实木书柜给我们都喜欢的书来做收纳，很喜欢窝在沙发里看一下午的书，品一杯自己现磨的咖啡

▲很多书都是早旅行或者出差的时候偶尔看到然后收集到的，喜欢读书，也算是我们家的一个好习惯了

▲这个小柜子也是机缘巧合淘的，后来没见软装店有出样了

▲这两个柜子也是内心强大，打开柜门里面可以放很多东西

▲餐厅按的陈列柜和飘窗柜组合是我们后期和设计师讨论的时候加入的，有太多小东西没有地方展示了所以做了这样的组合，让餐厅的实用性更加合理以及实用

▲柜类都是纯实木根据尺寸特殊定制的，刚开始没安装的时候也在担心实木的纹理会不会比较乱，杂而有序。还好，成品出来后效果和好，老板的选材确实不错，当然价格也不美丽。餐厅和餐椅是带些工艺风的感觉，虽然有铁艺感觉冰冷但是使用的体验却很好

▲家里的每一个角落都花了很多心思去呈现我们想要的生活气息

▲柜子开放的空间陈列了很多我们收集的咖啡杯，有时候遇到好心情的时候，就会一起来一杯手磨咖啡，满屋的咖啡香味满溢

▲虽然很多时间在国外，但是热爱美食是我们的共同点，厨房我们也是简单干净的，小白砖是性价比最好的装修材料，但是烘托的可以，也会让它有特别的感觉

▲这个柜子也是一时动心买的，很多小抽屉可以很好的分类收纳一些小东西，不至于一个大抽屉里面放各种各样的小东西，最后想要找个东西翻的很乱，然后找不到又生无名火......所以呀，装修的时候一定要考虑实用多于美观，毕竟心情最重要

▲不知道别人怎么看卧室，也许会觉得很重口味吧......最后的最后谢谢材料商，谢谢软装公司靠谱的实木定制和呈现

▲是不是很难看出实木柜体和柜门都是先在工厂做好，现场组装，我还是和佩服软装公司的尺寸把控的，不多不少刚刚好，而且在实木柜体上给我开孔装壁灯都很完美

▲儿童房有两面墙可以给宝宝随意发挥的，其中一面就是这个壁画，到时候宝宝可以发挥想象想有什么色彩都可以，孩子成长中必须要有的就是自我的发挥和动手能力

▲未来学习的地方，简单但是有很多小故事

▲这面很大的黑板墙，可以让我们玩一个下午的时间......建议各位宝妈规划一个给宝宝放开自我的地方

▲回国有时间就会约上闺蜜好友一起在家喝咖啡聊过往，我们都想把生活过的很简单，回归到本质
