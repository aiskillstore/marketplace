# 浴柜定制，各种台面的做法11.28

浴柜定制几乎现在家家户户都有，为什么需要定制？一是家里的空间限制，没有合适的尺寸成品浴柜，一种就是定制更简练，美观。

▲人造石英石台面浴柜▲
▲如上图干区空间限制，必须定制，否则成品浴柜不是大，就是小。只能放小的有难看的缝隙。所以必须定制。柜体可以用人造板比如实木多层，柜门可以用时下流行的模压柜门，可以有各种造型，台面直接石英石就可以，然后单独购买盆子五金镜子等。需要注意的是，定制石英石台面最好和橱柜一块定制，所有做橱柜的都可以制作，这样就可以统一台面颜色，同时一家定制可以降低成本。台上盆或者台下盆看自己喜好了。

人造石英石颜色虽然没有天然那么逼真，但是使用足够了，至于容易渗透污渍，这个看个人生活习惯，如果平时不注意打理，变色渗透是迟早的事情。没有任何东西不需要打理就能长久使用的。

▲天然石材台面浴柜▲
▲上图就是天然石材台面定制，和普通浴柜定制一样，只不过台面用了天然石材波斯灰。纹路比石英石要逼真很多。需要注意的是，天然石材本身材质很脆，空隙更大，所以渗透污渍的几率更大。如果是懒人的话不建议做天然石材。同时如果盆子过大，开孔太大容易出现崩裂。尺寸和石英石是一样的，多大尺寸都可以定制

▲人造石一体台面浴柜▲
▲人造石一体台面，与天然石材不同的是，这种盆子也可以根据大小定制，只是不需要单独购买盆子，台面与盆子一体结合，而且可以根据需要做出搓衣板功能，价格相对于人造石平板台面要贵很多。

▲实木台面浴柜▲
▲木质台面很少见，整体要温暖很多，多见于不常见水，不潮湿的区域使用。台面和柜体使用一种材质，盆子台上台下都可以使用。像上图就是橡胶木的定制

▲人造石一体切角台面▲
▲人造石一体台面切角处理，一般在阳台区域有管道，盆子放置很小，所以这样一体人造石切角台面，可以做到台面和盆子一体，洗手池空间能大一点

▲陶瓷一体台面▲
▲陶瓷平板台面一体设计，一般都是成品居多，如果需要定制，成本有点过高。

▲像平时用的这种一体陶瓷盆，都有围边，造型更复杂一点，与上一图比较这个略显复杂，同样也是成品居多，如果需要定制成本太高

▲玻璃台面浴柜定制，其实和其他材质相比，更小众，虽然打理非常方便，但是其安全性还是值得商榷。

总结一下，浴柜定制台面有以下几种：1.人造石2.天然石材3.实木台面4陶瓷一体盆台面4.人造石切角定制一体盆台面

哪一种更好？取决于你需要什么功能，切记人造石或者天然石材定制，盆子单独购买，洗手盆一般都比较小，不像一体盆那么大，所以自己需要懂常识。要不脑子里全是过去的洗衣盆的印象，做出来大呼上当。只是自己见识太少而已。所以你需要台面和盆子分开的定制款，盆子都小，切记常识。

使用和维护都几乎差不多，价位与柜体材质，台面材质复杂程度，还有五金决定。市面上有最便宜的PVC一共几百元很多，如果你能接受也是可以用的。只不过质量很差。
