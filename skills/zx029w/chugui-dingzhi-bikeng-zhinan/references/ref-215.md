# 全屋定制只要用心，就可以努力做到最好9.29

全屋定制看起来比装修简单，没有那么多复杂的程序，但是也非常重要。一般业主不懂的话，基本也是糊涂认知。

首先，认识全屋定制，全屋定制的内容几乎没有太严格的定义，只要是木制作都可以全屋定制。
一般普通家里的定制包括：鞋柜、玄关柜、餐边柜、橱柜、衣柜、衣帽间，浴室柜、洗衣柜等。需要注意的是，一定找一家去做，千万不要盲目分好几家，工程的协调商家越多，协调的越多，出错的几率越多。更何况全屋定制需要整体设计板材的颜色搭配，不同厂家颜色是不可能一样的。而且全屋定制和装修基础以及水电改造严密衔接，一旦出错就更麻烦，
现实中发现好多业主衣柜找一家，橱柜找一家，浴柜和洗衣柜找一家，问其原因是人家不做这些。如果碰到全屋定制只做衣柜或者只做橱柜，就淘汰吧，百分百你遇到的是二道贩子，不可能有自己的厂子。否则嫌钱烫手？只有一个原因就是厂家嫌麻烦，只给二道贩子做衣柜加工，所以你找的店面压根也做不了。『有什么诀窍，可以找到好的全屋定制？』
其次，全屋定制的规划非常重要，并不是随心所欲，从这点出发也是找到良心商家的诀窍；比如你家有小孩，商家推荐你儿童房人造板定制，甚至颗粒板定制，就凭这一条，要不商家是外行，要不商家只图赚钱，压根不管你全家健康的问题。这样的商家只看钱间接害你的命，你还要找吗？其实和找装修公司相通：人品+经验，才是合格的装修和全屋定制。其中缺一不可，人品是门槛，其次再是经验。
最后，全屋定制的价格和价值是有区别的，这个在全屋定制里头同样重要。否则毫无设计感的定制，充其量就是定制盒子而已，毫无美感可言，有的只是价格，一点价值都没有。这个前面谈过『全屋定制要会设计，无对比无伤害』全屋定制悬空设计，不仅仅是美观
