# 找全屋定制，环保一项露出原形4.7

全屋定制说简单也简单，说复杂其实比装修更复杂，所以需要用心用良心以及充足的经验支撑。在你考察全屋定制的时候，其实也是淘汰的过程，如果有以下情况，就不要考虑了。定制和装修类似，经验是一方面，创新是其中必备，但是这一切必须建立在极好的人品上头，否则这就是流氓不可怕，就怕流氓有文化，玩弄业主的话你压根防不胜防，所以最好在前期考察就把所有的风险避免。人造板没有环保的，你要环保就用实木，这就是真理，但是你先要搞清楚什么是人造板，什么是实木，否则没法谈环保。一切不用刷漆，免漆就可以定制的板材都是人造板，即使你把纯实木贴个三聚氰胺板子，那也是硬生生把实木干成了人造板，徒增污染，这也是人造板了。纯实木就是要不刷清油，要不刷木蜡油，要不纯实木素板定制，是自然的树木伐下来以后经过烘干处理的纯自然木材。搞清楚这个常识，接下来注意，环保并不是一刀切，因为现实是不可能允许人人都能占到优势资源的，所有的原木自然的纯环保，是有钱人的专利，对于刚需老百姓几乎不可能达到。所以，你在找定制商的时候，就有人忽悠你：我们的颗粒板是国际标准，我们是E0级别，甚至我们是ENF级别。注意所有人造板定制，不假思索给你说环保级别，不看你定制多少，都承诺环保的，一定记住：这人是人渣，赶紧跑。因为事实是所有环保级别谈的是单位面积的环保，而非你家做了全屋子的环保；即使这个环保检测是认真履行，那也只是说明这个板材单位面积散发的污染物对你无害，但是你家是全屋定制，叠加污染，此时所有的环保级别就沦为口号了。不要看到环保就以为是零污染。这简直是大部分人的一个致命误区。这就是你喝的所有饮料一个道理，你仔细看看配料成分，你会发现，都有对人体有害的添加剂，但是一瓶饮料一定量的添加剂对你无害，但是你如果短时间喝大量的这种饮料，百分百会出事的。这下明白了吧-------------同理，人造板的环保级别即使检测是真的，也是单位面积对你无害，并不是零污染，而是里头的污染物少量对你无害。但是几乎所有家庭定制都要打破这种环保检测，除非你家就做一平方的人造板柜子。也就是漫天口号的体制，这种检测放到现实的普通老百姓家里，就是一张废纸。你家是把单位面积的少量污染叠加放到一个房子里头，就和一个人一口气喝了大量添加剂饮料一个道理，能环保才怪。这就是为什么你找全屋定制，不管你做多少，他们都说是环保的，这种人是人渣的原因。因为他们为了赚钱，把你全家置于慢性自杀的环境里头了，说是人渣都抬举他们了。这种奇葩的环保检测，也导致所有人造板大品牌有恃无恐，不怕你告，即使真的有污染，你告人家，人家拿出单位面积的样品去检测照样是合乎国家标准的，但是你家做那么多是你自愿的，也不是商家强迫你的，你无法拿出商家强迫你的证据，但是商家可以拿出你定制的合同，此时你哑巴吃黄连。那为什么新闻里头有好多大品牌有污染最后赔偿业主的？这才是问题的关键，因为打官司以后，单位面积的样品拿过去污染远远大于国家标准了，所以必然给你赔偿的。从另一个侧面说明什么？说明环保检测就是口号，你要怎么说都行，不会有人管的，这就是土壤和文化。你真以为环保检测那张废纸有用的话，你真的是被九年义务教育洗脑成功了。因为你自己不敢直视自己脚下的土地和环境，一味的群体自嗨而已。作为老百姓没钱全部做实木，那怎么合理采用人造板？《家里有小孩，怎么做全屋定制更环保？》这篇有详细说明可以看看。人造板是文明的叫法，其实应该叫做高科技，越是人造板，高科技成分越高，木材成分越少，成本越低，越能占领市场，利润越大。没有办法，目前社会只能到这，只能靠自己思考，造孽！
