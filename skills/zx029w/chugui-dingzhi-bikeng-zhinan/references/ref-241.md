# 全屋定制要会设计，无对比无伤害5.17

其实全屋定制重要的不是各种板材和环保的选择，这个是最最基础的。除此剩下的就是设计和细心了，没有一定的经验，可能做出来你见得少，你以为已经很好了，对比之下，你就会发现，你家充其量就是盒子而已。当然为了低价的话，是不可能有细节和完美的。今天给大家对比一下，大家就知道好坏怎么区分了。

▲通顶与不通顶。同样是进门鞋柜，左图有点多此一举，既然复杂的罗马柱都用了，花里胡哨的顶线都用了，这些难道不要钱呀？既然这些都用了，为什么就不通顶定制呢？不要说为了保住头顶的筒灯，那就卸掉灯即可。再对比右图看看，同样做鞋柜，虽然没有左图的花里胡哨，但是最起码知道通顶去做，一是美观，二是不会积灰尘。

▲缝隙问题。注意上两图，撇开颜值之类，看顶上缝隙，左图缝隙都有五公分宽度了，你家做完是这个效果能不难看？再看看右图，严丝合缝，其实每一家都有不同缝隙，缝隙小采用玻璃胶或者腻子修补就可以达到完美。

▲套色细节。套色现在非常流行，但是有的定制不操心，几乎都是画图员而已，压根谈不上设计，跟风套色。如上图有可能是我们太过于要求完美了，左图和右图比较明显就是失误，木色套色一定是点缀，否则不如直接做全白或者全木色。左图明显是定制懒的动脑，直接柜体采用木色，柜门采用吸塑直接做了。而右图柜体和柜门都采用白色，套色是单独定制的，明显要麻烦多了，这就是为了业主的效果麻烦留给自己的做法，如果同样价格当然选择右边的定制了

▲普通细节。注意上图，同样是做假吊顶然后做衣柜，左侧相当于一个盒子而已，再看看右图，三边边线加持，视觉效果立马不一样，如果同样做定制，两个不同定制商，你们选择谁呢？如果只想要低价自欺欺人，不看设计，只看功能，左侧也是能用的，只不过没有对比就不会有伤害

▲橱柜的基本常识。注意上图，左图这种做法直接可以淘汰这种定制商了，很明显是低价切入的做法，而且业主不懂，还做了顶线，顶线是一种装饰，这个就像项链一样，你衣服都搭配错了，再好的项链有何用？再对比右图的做法，一目了然，孰好孰坏一清二楚

▲设计基本的美感常识。全屋定制不是做盒子，最起码的设计美观得有吧，上图第一张虽然也是套色，但是很明显基本的配色都不懂，一个衣柜超过两色搭配，能好看才叫怪，再对比一下下方的两张：左图白色与木色清新，恰到好处，右图人家直接一个颜色也非常清爽。同样的定制的话，第一张不仅不美观，而且让房子整体更压抑，视觉更凌乱

▲不看功能化，看配色。同样是榻榻米，功能是第一，但是颜色不会搭配不仅花钱多而且没有效果。左图壁纸满贴不仅污染，而且花色错误，导致档次整体降低，右图人家全部乳胶漆，不仅环保而且价格低，整体白色与灰色素雅配色，更清爽简单

▲不看表面颜值，看配色和基本功能。第一张舍不得牺牲筒灯上方留那么大缝隙，套色混乱失败，直接回到九十年代，柜门不讲究简洁，都想把造型贴到家，反正掏钱好像做平板就吃亏了一样，没法对比，伤害太深了

▲花了钱没有效果，没有设计感。不要再把衣柜直角做开放式了，又不是要避开开关插座之类，这样做，以后入住放什么高端展示品？最终空间更乱，衣柜还小了，大部分人说直角容易碰人，那家里的直角墙多了，难道就不碰人了？不仅仅是功能，
