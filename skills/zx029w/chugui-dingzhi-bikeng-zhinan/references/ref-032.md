# 嵌入式厨电规划 + 安装全攻略：避开 90% 翻车坑，美观又顺手

嵌入式厨电是厨房装修的“颜值担当”，既能让台面空无一物、整洁利落，又能最大化利用空间，很多业主都想装。但实际操作中，要么规划不当导致电器塞不进去、缝隙难看，要么安装粗心留下安全隐患，翻车案例比比皆是。
今天把嵌入式厨电的「前期规划」「尺寸布局」「安装细节」「避坑指南」一次性讲透，从设计到安装，一步到位不踩雷，帮你装出既美观又顺手的理想厨房。
01｜先定电器，再做定制（记住铁律）
嵌入电器本质就是柜体包裹电器，显而易见肯定是先看电器后做定制，顺序反了，要不小了空间浪费，要不放不进去完全没用。
这顺序一定是装修协调机构或者全屋定制来协调，业主最好不要自作主张，除非你有充足经验，否则翻车几率太大。
正常流程可以参考以下：
装修设计方案的时候，就得确定需要嵌入的电器数量，例如冰箱、洗衣机、蒸烤箱、洗碗机、扫地机器人、烟机、热水器、直饮机等。但最好不要跟风，看自己家需求和钱包决定。装修设计师规划这些要求是否都能满足，然后做决定。
实体店购买或者网购两种方式都可以，一定要得到官方产品的详细尺寸图，包括「开孔尺寸」或「安装尺寸」。
切记一定要把带有尺寸的详细尺寸图或者网购链接发给设计师，一定不能发纯数字尺寸，以免因为自己疏忽错误担责。
满足要求以后，设计师根据空间布局以及水电要求，确保所有嵌入电器都能实现，而且完美适配。
注意：所有嵌入家电，在设计师确认满足条件以后，先不要购买，放入购物车或者先收藏，等设计师具体通知购买时间再买。
02｜关键电器：尺寸规划+布局要点.
1.冰箱首选零嵌款下散热：
过去传统的普通冰箱都是左右散热，导致嵌入三边缝隙非常大，不美观也不好打理，而且容易积累灰尘；下散热可以保证严丝合缝，缝隙完全可以控制到1-2mm，这才是首选，也是产品发展的必然趋势。
冰箱位置首选厨房，动线更短，更方便。『厨房小到塞不下冰箱？这两种替代方案真香，我家立马抄作业！』除非厨房空间小，依次选择的地方为餐厅、客厅。

冰箱插座不要预留冰箱后方，需要查看实际冰箱背后的电源线路走向，选择冰箱左右或者上方预留电源。
2.蒸箱/烤箱/蒸烤箱：
嵌入式蒸烤箱几乎都是前端散热，无需额外散热孔，可以满足严丝合缝的镶嵌，需要注意全镶嵌和半镶嵌，完美与否完全靠定制设计师的经验和水平决定。
蒸烤箱的位置首选高柜中部位置，距地大概1100-1400mm，人站立不弯腰可以操作，符合人体工学。
实在没有办法才选地柜镶嵌，例如灶具下方，需要注意产品说明，是否可以满足灶具下方安装。
如果是开放厨房，可以嵌入餐边柜高柜、地柜或者岛台位置。低处嵌入使用弯腰，老人专用避免。
蒸烤箱电源功率在1500W左右，电源专用的16A插座。避开蒸烤箱正后方，选择左右或者上下有柜体遮盖的地方预留插座。
3.洗碗机：
洗碗机严格按照官方尺寸严丝合缝预留，有官方原装柜门和定制柜门可选，费用不一样。『装修买电器，一些不为人知的省钱窍门』
洗碗机必须靠近水槽，除非有独立上下水布局，最大化避免下水过长堵塞的问题。
最推荐做法：抬高安装，特别是家里老人专用，每天操作频繁弯腰，费力费腰。『年轻人装修坚持7个“省腰设计” ，实用到想安利给所有人』
洗碗机水路电源选择左右相邻柜体内部布置电源和上水，避开正后方位置。
4.烟机灶具：
烟机需要隐藏嵌入，提前确定尺寸型号，不要买自带挡板；除非不嵌入必须购买自带挡板，要不露出来难看。
注意烟机要求安装高度，以台面高度起算，确定高度尺寸，最重要的确定烟机与吊柜的严丝合缝『烟机与吊柜有缝隙太难看，一招解决』
灶具先确定大小尺寸，设计师规划满足动线的合适位置，根据位置大小购买尺寸合适的灶具，安装前提供灶具的开孔尺寸即可。
注意：一般灶具深度小，如果厨房小，就可以缩小台面进深，放大厨房空间。
5.各种小家电：
各种常用的小家电不需要嵌入做法，但是不能在台面凌乱摆放，装修规划的时候，主要小家电就得列出清单，提前看机器，根据尺寸可以做高柜的抽拉板收纳，每一层一个电器，背后布局插座，这样使用的时候方便抽出使用，不用的时候可以收纳更整齐，保证台面无物。『厨房小家电收纳，99%的人看完想学』
03｜科学布局，空间和使用最优化

嵌入做法不仅是好看整齐，同时还得符合自己的使用习惯，使用顺手，动线合理一样重要。
动线严格遵循“取物→清洗→备餐→烹饪→装盘”的动线布局。
例如冰箱是起点，洗碗机紧邻水槽和碗篮，一旦动线错误，就会导致来回拿取，不顺手，增加家务『动线翻车毁厨房！致命错误让做饭变折磨！』
同类电器放一起，例如高柜嵌入冰箱，旁边高柜嵌入蒸烤箱，紧邻高柜小家电的收纳，不仅整齐而且使用顺手。如果有空间冰箱旁可以做抽拉零食柜设计『家里零食没地放？5个被低估的收纳位，轻松变出零食库！』
嵌入式电器要向上要空间，能做高柜是最好的方式。
厨房如果空间不足，次要位置就是餐边柜位置，不论是高柜还是台面放置，都能弥补厨房收纳的不足。『厨房太小别硬塞！这些电器放餐厅才明智，后悔没早知道！』
厨房能满足U型布局，哪怕是窄柜也做，可以延伸收纳，台面满足小家电的放置。
04｜定制安装好复核尺寸
1.电器安装前检查：

定制安装完毕以后，拿出尺子复核所有嵌入式家电空间，看是否与图纸相符，是否满足安装条件，此时发现整改还不晚，一旦等到家电进门安装就迟了，浪费时间不说，二次安装还得独立付费。
检查所有定制安装完以后，电器镶嵌位置后方是否有障碍物，必须保证背后空无一物。同时检查需要打孔地方，电器左右立板是否提前打好孔位，后期电源线以及上下水的穿过。
确认所有电源以及上下水位置，是否避开电器位置，同时检测电源是否正常使用，下水是否有堵塞问题。
2.电器安装中细节：
水电在隔壁柜，定制需要提前打好穿孔，位置以及大小需要确认
避免暴力安装，尺寸稍有偏差避免暴力捶打立板以及柜体，防止后期变形导致电器损伤
注意所有电器的缝隙预留，一定按照官方要求，不要盲目追求严丝合缝，导致后期散热安全隐患。
注意水平和垂直度，洗碗机和冰箱必须水平垂直调平处理，会影响后期使用
注意门板颜色与把手细节，洗碗机如没有成品门板，提前让定制做同色柜门处理；洗碗机自带柜门，注意把手是否突出与旁边抽屉冲突。
洗碗机没有自带踢脚板，需要橱柜踢脚板统一，注意洗碗机柜门是否能完全打开，否则裁割踢脚板满足柜门打开自如。如果洗碗机有自带踢脚板，需要注意橱柜踢脚线与洗碗机踢脚线高低颜色的适配。
电器安装配件尽量使用厂家原装，保证不损失售后服务；例如止逆阀让烟机带，洗衣机龙头让洗衣机商家带；同时注意电器安装增项问题『警惕“电器安装”背后的刺客！我家电器装完，收到账单当场傻眼，太坑了！』
电器安装过程能全程录像最好，安装完毕当场测试功能，看是否有不正常，晃动或者漏水隐患。
洗碗机下水一定要有坡度，测试合格，同时注意容易返水楼层是否安装止逆阀；冰箱安装完毕水平垂直检测，保证柜门能正常打开，内部抽屉盒子能正常打开和取出。
3.电器安装完签字必须满足以下条件：
电器运行正常，无异常噪音、震动；所有门、抽屉开合顺畅，无碰撞、卡顿；
电器四周缝隙均匀，符合散热要求，视觉效果可接受；水电连接处无滴漏、漏电迹象；
安装产生的垃圾已清理干净；索要并保存好安装收费单据、保修卡，与购买凭证放在一起，方便后期维修。
05｜翻车坑以及时间顺序安排
1.避免翻车就是价值：
尺寸传递不口头、不手写，一定给链接或者图片详细尺寸。所有细节与业主无关，尺寸不明让定制商与电器商家沟通，规避业主责任。
检查所有电器把手，是否与相邻抽屉柜门冲突；检查电器背后背板是否影响电器的推进。
装修水电交底，必须装修设计师以及定制商同时在场，现场标记水电位置，避开在电器后方设置水电。
电器商只管安装，所有尺寸必须定制商负责，后期有问题责任分明。
2.顺序步骤不能错：
尺设计方案阶段列出想要的所有电器清单，先列嵌入电器，然后列出小家电，让设计师根据空间，看是否满足条件，然后确定电器数量和位置。
水电改造之前，必须确定所有电器的数量和位置。
瓦工完毕吊顶完毕，定制商家上门精确测量尺寸，腻子一遍二遍继续复尺。『装修10招嫁接风险做法，聪明业主早都用上了』
开关插座安装完毕以后，预约所有电器上门安装。注意烟机止逆阀需要提前预埋。
陈工总结：嵌入式厨电的完美呈现，从来不是“买好电器、做好橱柜”这么简单，而是各方的无缝配合。先定电器，后做定制；尺寸为王，细节为纲。
