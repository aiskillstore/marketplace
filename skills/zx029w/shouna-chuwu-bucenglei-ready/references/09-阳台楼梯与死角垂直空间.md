# 阳台 / 楼梯 / 死角 / 垂直空间（榨干最后一平米）

> 来源：会员库《阳台储物柜必须和生活相关》《家居收纳阳台洞洞板》《别小看壁龛（10处）》《壁龛收纳家里9个地方》《楼梯下方18种》《16个专题楼梯下》《8面墙别浪费》《9个边角收纳》《18个不能浪费的1平米》《承重柱处理》《双面柜》《家里8个地方做薄柜》《过道收纳利用》《窗户侧墙》《窗户下面做收纳和书桌》《被年轻人的防盗门后收纳惊到了》等。

## 一、阳台收纳

- **阳台侧墙通顶柜**：最普通做法放杂物。
- **另一边洗衣柜+吊柜**：满足生活洗衣+上方吊柜储物。
- **阳台洞洞板**：留白墙面用白色铁艺洞洞板装饰+展示收纳。
- **阳台垛子砸掉与客厅一体**：收纳柜侧面套色木色+隔板视觉生动，做展示区不生硬。
- **阳台改造衣帽间**：空闲阳台腾出做衣帽间。
- **阳台矮墙书柜**：半截墙阳台靠墙卡座书柜拓展收纳。
- **阳台柜 15 种**可选（《阳台柜子白做了，原来有15种可以选择》）。
- 露台不要做木柜（会坏），封闭式阳台另论。

## 二、壁龛（家里 9~10 个地方都能做）

门厅 / 过道 / 客厅 / 餐厅 / 厨房 / 卧室书房 / 楼梯间 / 卫生间 / 阳台——非承重墙掏拱形壁龛，颜值+收纳翻倍。注意不能误选承重墙。

## 三、楼梯下（16~18 个专题）

- 18 种创意：进门楼梯下抽拉鞋柜、放钢琴单车、成就卫生间、侧墙书架、电视墙、书房、休闲区、嵌入电器、宠物窝、中西厨房水吧台、景观、酒窖等。
- 16 个专题系统讲楼梯下利用。

## 四、8 面墙别浪费（垂直空间）

门厅 / 过道 / 客厅 / 餐厅 / 卧室书房 / 厨房 / 卫生间 / 阳台——洞洞板、挂衣钩、磁吸挂件、绘本架、壁龛、猫爬架等，墙面全用上收纳翻倍。

## 五、9 个边角收纳（思路一变翻倍）

1. 冰箱缝隙抽拉零食柜（真正边角，非翻车缝隙）
2. 洞洞板装饰兼顾收纳（隐藏天然气管道）
3. 门后边角（嵌入式洞洞板/10cm薄柜）
4. 门边转角（墙角盲盒/烟道包管转角）
5. 厨房窗户（推拉窗下封闭+伸缩杆挂钩）
6. 柜门背面及门上（药/饰品/帽子/杂志门）
7. 飘窗角落（梳妆台+书桌一体/中古风水吧台）
8. 窗户夹缝（敲飘窗多出的窄柜放证件杂物保险柜）
9. 过道墙面（盲盒墙/绘本架/壁龛/收纳柜）

## 六、18 个不能浪费的「1 平米」

床头1平米（去床头柜做书桌化妆台）、门厅、餐厅拐角、厨房转角、卫生间干区、阳台、过道尽头、飘窗、楼梯下、承重柱周边、门后、电视墙侧、沙发旁、床尾、窗下、衣帽间、家政区、书房——每一平米都有价值。

## 七、超薄柜（8 个地方都能做）

门厅 / 过道 / 客餐厅 / 卧室 / 厨房 / 干区 / 阳台 / 防盗门后——12cm 薄柜杂物瞬间隐身；烟道超薄柜、门后超薄柜、客餐厅超薄柜、刚需房过道超薄柜都是极限收纳选手。

## 八、双面柜 / 承重柱 / 窗户

- **双面柜**：40平通间沙发背后双面柜分割客厅厨房；80平砸次卧墙双面柜成就衣柜鞋柜。
- **承重柱**：延伸岛台吧台弱化突兀；阳台承重柱做拱形木隔板展示+隔断家政区。
- **窗户侧墙**：飘窗地柜兼卡座+侧墙书架；平窗飘窗柜+两边收纳书架。
- **窗户下面**：衣帽间窗户下定制化妆台兼顾书桌；假休闲飘窗+对称书柜。

> **结论**：垂直空间+边角+1平米+超薄柜+双面柜，是刚需房收纳翻倍的秘密武器。房子贵，榨干最后一平米。
