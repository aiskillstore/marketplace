# 厨房7大夺命操作！这些习惯正在把你家变成炸弹

厨房里一些看似平常的操作，分分钟能把家变成炸弹。这7条千万别学。

1. 灶台旁倒面粉——粉尘爆炸！面粉颗粒遇明火瞬间爆炸。关火冷灶再操作，撒落面粉立刻湿布清理。
2. 微波炉热鸡蛋——密封食物内部蒸汽膨胀冲破外壳炸裂。带壳/膜食物禁止加热，袋装食品倒出再热。
3. 冻品直下油锅——冰碴变蒸汽油锅沸腾飞溅火焰喷射。彻底解冻+擦干水分，沿锅边轻滑入油。
4. 高压锅超载——食物超2/3、排气阀堵塞、超龄使用都会爆。定期换胶圈，使用前查排气孔，5年强制报废。
5. 燃气泄漏+羽绒服——燃气泄漏遇静电火花爆炸。应急：关阀、开窗、撤离报警；日常装报警器、年换软管、肥皂水测漏。
6. 煲汤无人看管——溢锅灭火焰→燃气堆积→遇明火爆炸。人离灶必关火，调最小火+设闹钟。
7. 油锅浇水灭火——水沉油底汽化油雾爆燃。盖锅盖窒息法，或干粉灭火器对准根部。

厨房安全自查表：面粉远离明火区 / 微波炉禁用密封容器 / 冻品完全解冻 / 高压锅定期检修 / 燃气阀随手关 / 烹饪绝不离人 / 常备灭火毯或灭火器。
