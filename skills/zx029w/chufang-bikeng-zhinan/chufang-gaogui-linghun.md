# ✴️高柜，是厨房收纳的灵魂

厨房好用与否，第一是功能，第二是收纳。金厨银卫，这两个舒适了家就舒适了。

1. 高柜是厨房收纳的灵魂：不仅仅是满足所有电器的嵌入式设计，达到生活和美学统一，同时拓展收纳，让厨房不止满足一日三餐，更体现对生活的热爱。
2. 高柜放常用家电：蒸烤箱、微波炉、小家电竖向收纳进高柜，台面空出来才好操作。
3. 高柜做分格收纳：干货、备用锅具、囤货竖向分区，比地柜好拿取，空间利用率高。
4. 舍不得厨房投入只做面子是本末倒置：装修舍得厨房，功能+收纳都到位，才是真的把钱花在刀刃上。
5. 高柜与地柜衔接是细节：高柜石材突出或衔接不平，找有经验人品好的定制商才能避免，细节决定价值。

小厨房做不了正常高柜，可以做超薄高柜或利用烟道、冰箱落差做窄高柜，收纳灵魂不能丢。
