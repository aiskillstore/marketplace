# 105㎡三室变两室，打造父母舒适养老房

孩子都在外地，此房为两位老人的养老房，所以一切根据老人的意思进行改造。

原始户型为三室空间，本身面积较小，导致整体格局更显局促，而且在老人的观念里头，这种进门没有遮挡的户型一无是处

设计后的布局图，依老人要求做了进门直对的玄关，老人感觉这样才符合生活习惯；小次卧砸掉保留两个卧室，拓展整体空间和光线；拆除厨房墙体开放布局，同时延伸了中西厨的做法，餐桌+岛台让老人乐于接受；唯一卫生间干湿分离，同时满足洗衣机布局，解决没有生活阳台的问题

进门做了直对的玄关，满足基本收纳，同时满足老人的生活习惯，局部长虹玻璃弱化一下拥堵感；砸掉小卧室以后拓展客厅空间，完成了门厅的迂回动线

砸掉小卧室以后客厅拓展空间，两扇落地窗光线更通透

电视墙满墙柜满足收纳和嵌入电视，原有小卧室的拐角做了休闲地台，放上老人喜欢的中式圈椅，平时作为休闲角落

电视墙满墙柜与地台统一浅木色一体设计，满足收纳，让空间更简洁好打理

无主灯设计让空间更加简洁；客卫干湿分离以后，门洞拱形设计，与次卧之间中式花架作为装饰点缀

放大空间以后餐客厅一体放大空间，餐厅窗户位置满足西厨以及冰箱嵌入，岛台+餐桌的布局老人很是满意

原有卧室拐角位置作为休闲的角落，放上老人喜欢的中式家具，作为平时休闲的地方

借用门厅玄关墙体拓展了餐厅空间，实现岛台与餐桌的一体布局

餐客厅全景，光线更加通透，采用大面积浅木色为基调，符合老人对颜色的喜好，同时不会显得那么压抑

厨房在拐角做了开放设计，没有装门，这也是入住不习惯可以加门的条件下，老人同意的做法

主卧软包床头，老人使用更舒适，侧墙木色衣柜定制满足基本收纳，吊灯满足老人起夜使用，空间有限，只能满足一个床头柜的功能

飘窗成了老人养花的地方，阳光非常充足

次卧定制衣柜以及榻榻米收纳，作为临时的卧室，平时可以用来储物

L型橱柜同样是浅木色与白色搭配，因为没有装门，搭配了集成灶

卫生间满足干湿分离，同时满足了洗衣机的放置
湿区局部玻璃隔断分割空间，纯色一体瓷砖可以让空间更干净简洁
