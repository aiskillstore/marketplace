# 浴室要防滑，都有哪些办法？3.1

▲第一种：PVC脚垫，可以随意拼接，成本很低，也能达到防滑的效果，而且各种图案可以增加空间彩色元素

▲而且有防滑脱设计，不用担心整体活动

PVC防滑垫的缺点是害怕有味道，有污染，所以选购的时候一定注意，价格太低肯定大部分都是废塑料回收利用，在本国这是常事。

▲第二种：防腐木地垫，也是可以的

▲细节部分的防滑垫设计

▲可以根据淋浴房形状定做样式

▲第三种：这种是采用TPE和PP材质做的防滑垫

▲第四种：这种是仿马赛克鹅卵石瓷砖，可以起到按摩效果，也可以防滑

▲还有这种仿马赛克瓷砖，也可以铺到淋浴区，起到防滑作用

▲第五种：这种就是仿板岩的文化石防滑瓷砖，表面凹凸不平，所以也可以铺到淋浴区

▲第六种：这就是天然石材拉槽效果，可以根据浴室大小定制铺贴，防滑又美观
