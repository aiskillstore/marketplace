# 70㎡一字型老房变婚房，客厅变卧室，格局改到面目全非

旧房能改造成业主自己都不认识，这个就厉害了。因为小夫妻在外地上班，看好这套二手房以后，回去工作，一切按照方案按部就班施工，等到新房落成，小夫妻还得回来古都上班，所以前后天地之差的对比，让业主自己的不认识了。总花费15万。

▲标准的一字户型。老旧是另一方面，关键是两室空间，客厅没有采光，过道狭窄浪费太大，厨房和小卧室共用阳台，一点隐私也没有；卫生间小到连基本的淋浴都满足不了▲这是修改以后的拆墙砌墙图纸。首先客厅变卧室，把所有方正布局，利用新砌斜墙的方式，满足空间和光线的不同需求，可以说把原来的格局改变到了面目全非。▲最终的布局图纸。斜墙做了可以让原本呆板的户型，极尽利用空间。这个好多业主压根接受不了，国人讲究方正户型，认为这样有违常识。其实还是观念问题，如果斜墙能让你住得更舒适，为什么抱着老观念不放呢？还好，两位90后小夫妻是极力赞成，这就足够了。
1>客厅变主卧，利用斜墙方式，满足一米八大床的放置，同时利用斜角位置拐角衣柜，相当于一个小型衣帽间了；同时把唯一阳台与主卧打通，让空间和光线都得到满足，为了借用主卧这边的采光，采用了局部的玻璃砖隔墙，引光入室
2>狭窄过道与逼仄的小卧室砸掉，作为客厅使用，同时利用斜墙镶嵌定制柜子，满足公共区域的收纳；玻璃墙引光入室也能给客厅加大采光需求
3>卫生间拆掉原墙，新砌斜墙，扩大空间，增加了淋浴空间
4>原来厨房砸掉以后做了开放西厨，满足收纳，同时把卧室和厨房共用阳台一分为二，一半做了中厨使用；缩小小卧室斜墙处理以后，全屋定制，空间小了，布局更合理，收纳更多
▲进门左手原来的客厅砸掉以后改成了主卧空间，斜墙处理，局部玻璃砖隔断为了引光入室
▲进门右手狭长过道与小卧室砸掉，空间拓展作为客厅使用，尽头就是进入厨房和次卧的过道，过道边是卫生间。客厅3米的跨度足够使用了
▲没有拆除之前的样子，进门右手细窄的过道，左手还分割了一个小卧室，非常逼仄昏暗
▲装修以后的进门右手客厅，预留的承重墙与主卧斜墙形成的凹陷区刚好满足定制柜子，满足公共区域的收纳；客厅淡蓝色布艺沙发和小圆几配置，让空间整体清新简洁，角落原木斗柜作为进门端景，同时还能满足一部分收纳
▲站原来进门左手的客厅看狭窄的过道，能想想当时量房对房子的感受了
▲新砌斜墙与玻璃砖引光，成就了光线最好的主卧空间，同时门口定制收纳L型衣柜，相当于一个小的衣帽间了，完全满足主卧的收纳
▲局部玻璃砖墙体，不仅可以保证主卧隐私，同时能引光到客厅区域；金色的床具轻巧质感，圆柱收纳盒子代替床头柜，视觉轻盈，满足收纳
▲站阳台看主卧全景，大面积大白墙搭配木色点缀，整体明亮而且温馨
▲与门口衣柜一墙之隔的床尾，轻巧的化妆台布局，满足基本功能
▲原来的厨房和次卧共用一个阳台，次卧没有一点隐私
▲改变格局以后的次卧，虽然空间变小了，采用定制榻榻米满足基本功能
▲榻榻米旁边小的书桌，放置婚纱照的位置还可以后期放置成品小衣柜
▲没有改造之前的厨房，与次卧共用一个阳台，光线昏暗，空间非常狭小

▲砸掉原来次卧和厨房的墙体，缩小次卧空间，同时次卧墙体局部的玻璃透光设计，可以满足光线的通透；缩小次卧，把中厨移到阳台，原来的中厨作为西厨收纳

▲装修后的样子，缩小次卧，西厨大了很多，中厨移到阳台，光线通透，大面积白色与深色橱柜对比搭配，视觉清新同时又有质感
▲西厨看客厅空间，冰箱放置，深蓝色地柜搭配白色与木色套色的吊柜，大面积白墙的背景，视觉更清新，功能更完美
▲西厨对面与次卧的凹陷区刚好做了吧台布局，可以满足水吧台功能，局部玻璃砖透光设计，视觉敞亮轻盈
▲西厨对面的吧台布局，不仅仅是水吧台功能，同时兼顾平时的就餐需求
▲厨房与次卧共用的阳台一分为二，一半作为生活所需，一边定制收纳柜，满足杂物收纳，一边布局洗衣机烘干机满足生活所需，虽小但是具备功能
▲巴掌大的阳台容纳了所有功能，纱帘透光让光线始终通透；地面六边形瓷砖搭配大白墙，小空间更时尚清新
▲阳台的另一半作为中厨使用，采用集成灶，满足烹饪需求，同时更节省空间
▲原始的卫生间太小，容纳马桶和洗手池以后几乎没有淋浴的空间
▲改变格局斜墙处理以后，与吧台的夹角做了壁龛，可以收纳各种洗漱用品
▲一体灰色瓷砖的素雅，角落成就了很小的淋浴区，用浴帘分割满足基本功能
▲进门左侧定制极窄浴柜，满足基本的洗漱需求，黑色五金质感简洁END
