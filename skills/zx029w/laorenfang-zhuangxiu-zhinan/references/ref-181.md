# 卧室衣柜，门上头要不要做吊柜？11.26

卧室衣柜大家基本都熟悉，各种各样，根据自己家的格局去定制就可以了，最大程度合理利用空间就行。

一、衣柜一般需要注意的是，如果是人造板，千万别让工人现场做。众所周知人造板甲醛释放量大小取决于封边的好坏，工人手工和机器封边，压根不可同日而语。《不让木工现场做柜子的两大理由5.2》

其次工人现场做是不是占用了空间，这个空档完全可以做墙面了，如果是定制刚好利用空档期做墙面，墙面做好刚好可以安装衣柜，合理规划装修时间。

二、想让工人现场做柜子，必须满足唯一条件：实木板材。除非是实木，但是记住了，实木是需要喷漆的，人工喷漆和无尘车间不是一个档次，喷漆表面有颗粒灰尘，现场喷漆是避免不了的。

三、定制衣柜千万别问，哪种板材环保了，这用回答吗？肯定是实木《衣柜用什么材料？有钱疯子才用人造板8.19》

四、如果你只用得起人造板，坚决不要用颗粒板，这东西一到中国人手里就变味了《经验|刨花板和颗粒板你家还在用吗？看看就明白了》

五、更不能无知的认为大品牌就没事《为了娃，衣柜定做大品牌，你是有多无知5.13》

六、衣柜如果通顶一定得注意石膏线，特别是自己装修的业主，这个地方一定注意《衣柜通顶，上头石膏线怎么办？4.18》

七、衣柜使用平开门还是推拉门，这是你买的房子决定，不是随心所欲的《做衣柜平开门还是推拉门？这有啥纠结的？5.14》

八、衣柜定制能镶嵌尽量镶嵌，别问为什么，就是高端大气上档次《衣柜尽量做镶嵌式，这叫品质生活11.7》
