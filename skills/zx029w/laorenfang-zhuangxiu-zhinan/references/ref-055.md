# 卧室墙面蓝色系，好看不？1.2

上一篇有个《卧室乳胶漆刷灰色，好看不？》，大家可以回看一下，今天看看卧室如果用雾霾蓝，是什么效果，怎么搭配更完美。

▲雾霾蓝的流行不是没有原因的，清新又不突兀，宁静又不冷漠，用到卧室背景突出，适合任何年龄阶段人，几乎老少通吃
▲原木与雾霾蓝柔和搭配，极简基础装修，大白墙的衬托下也能干净清爽
▲暗黑系的蓝色与黑色也是重点安利的搭配，稳重质感，而且自带奢华感和高级感
▲背景局部蓝色的拼色撞色设计，可以让整体空间视觉提亮，带来清新时尚感
▲蓝白本身就是经典搭配，永远都是清新，其他大面积墙面采用灰色铺垫，有层次，但是又不突兀
▲雾霾蓝与灰色的搭配，突出中心，同时搭配浅色的软配，让视觉有层次，同时柔和清新
▲这种亮色天蓝属于饱和度非常高，亮度非常高的颜色，相较于雾霾蓝，比较浓烈，这种蓝反而没有宁静感了，稍显突兀
▲饱和度比较低的蓝色系，视觉柔和，能突出层次，但是不会太显突兀
▲饱和度低的雾霾蓝之所有能百搭，其实就是视觉上的柔和不突兀，不论是老人房还是儿童房，都比较适用
▲小空间卧室，背景采用雾霾蓝突出层次，其他墙面浅灰色涂刷，布艺床头以及浅色家具搭配，也可以让小空间清新而且有质感
▲经典雾霾蓝在比较明亮的卧室，非常有层次，搭配黑色与木色的家具，非常有质感，书桌上头挂画与吊线灯是点睛之笔
▲雾霾蓝在美式里头非常经典的搭配，常常会和饱和度低的黄色，橙色进行混搭，提升空间冷暖对比度，可以让优雅的美式凸显现代质感
▲饱和度低的蓝色背景与浅木色家具搭配，整体会显得柔和，同时也不失层次感
▲深蓝色背景搭配千鸟格的的家具，亮黄色跳跃挂画点睛，这种浓烈的对比一般多用于儿童房，提升空间的活泼质感
▲明亮居室，蓝色背景与木色家具对比，可以让空间更有层次感
▲蓝色背景与大面积白色对比，空间层次分明，不论是儿童房还是大人房，都是比较适合的
▲经典蓝色背景与柔和的黄色加上木色的温柔，可以让卧室更有温度，暖色系做到恰到好处
▲天空蓝与黑色的对比，让空间更有奢华感，提升高级感的配色
▲背景深蓝色，大面积浅灰色辅助，皮质的床头对比，干净极简，又有了不同的对比效果
▲局部深蓝色与木质的对比，冷暖协调，突出中心，质感又时尚
▲饱和度低的颜色搭配，背景淡蓝色涂刷，突出层次，也让空间变得清新
▲饱和度极高的蓝色与皮质的床头搭配，大面积浅色对比，一般用到儿童房空间可以让小空间更有活力

▲饱和度低的蓝色局部搭配，与窗帘呼应协调，搭配到男孩房空间稳重宁静
