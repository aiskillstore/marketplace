# 80㎡两室，独居老人的时尚居

大部分人对老人居住的房子，印象中都是老旧，深沉，感觉好像年龄大了就不要时尚和活力了，其实这个是个误区，大部分老人还是希望能追求潮流，入住也要有自己的个性。此套房是一位老人居住，孩子在同一小区单独居住，可以便于照顾。

▲原始图纸，紧凑两室户型，客餐厅较小，几乎没有就餐空间，还好一人居住，功能性只要有就可以；两个卧室其实平时一间就够用，所以满足一个人的最大功能即可▲设计布局图，进门左手布局成品鞋柜，满足一个人进门收纳即可；原来厨房隔壁的小阳台，因为承重墙无法扩充到厨房，只能作为一个杂物间，同时作为门厅的引光作用；
厨房因为一个人住，为了满足就餐需求，做了开放式布局，利用延伸橱柜的方式，满足一个人就餐需求；
为了满足冰箱位置，利用厨卫墙体的错位实现镶嵌；主卧借用次卧空间，实现了衣帽间的超大储物，次卧相对小，成品收纳床以及书桌布局即可，这里平时老人的孙子过来偶尔入住；因为老人有阅读习惯，利用电视墙重新薄墙的处理，满足了主卧的杂物以及书柜的收纳
▲进门是厅，很小的区域，一个人住，利用进门左手黑色简约的成品鞋柜放置，满足收纳，同时视觉对比也有了简单的高级感
▲厨房小阳台看门厅，右侧全身镜落地布局，地方很小，一个人住，采用开放式厨房延伸橱柜的形式，满足简单就餐需求；质感吊灯与蓝色的墙面变色，视觉上更有层次感
▲超薄鞋柜根据阳台墙垛的厚度选购，台面可以放置进门随手物品，预留插座，平时可以作为手机充电使用
▲进门视角，光线非常通透，开放式厨房让光线整体更加明亮，蓝色的质感变色，提升进门的视觉层次
▲开放式全貌以及小阳台，小阳台收纳柜定制，可以弥补一部分厨房收纳的不足，同时燃气热水器满足安装；橱柜深浅对比，提升层次的同时，可以让空间更有质感
▲很小的北阳台与墙垛平齐定制，平板极简，弥补厨房收纳不足的同时，这里也是清洁用品的专用收纳区
▲厨房全景，蓝色地柜与白色对比，优雅质感；高低台面的布局更利于操作
▲老人一人住，又不想全部木地板难以打理，又不想大面积冷硬的瓷砖，采用了客餐厅分区铺法，让分区更明确，也满足了老人的喜好；墙面深蓝色与橙色单椅搭配，空间有了青春活力
▲蓝色背景，橙色单椅，灰色沙发一边边几花瓶装饰，一边简约落地灯，呈现年轻活力
▲冰箱是利用厨卫的墙体错位，预留的凹陷区满足放置，同时凹陷高度与卫生间门高度一致，视觉更好看，没有做吊柜收纳，后期冰箱上头放置收纳盒，收集不常用但是又舍不得扔掉的旧物
▲客厅全景，空间不大，所以挂机空调满足，吸顶灯简约搭配，同时电视墙上方局部吊顶灯带布局，可以让灯光层次更丰富；原来的飘窗砸掉以后做了收纳休闲柜处理；南阳台作为洗衣间使用，采用全景门布局，引光入室，满足光线需求
▲砸掉飘窗定制收纳柜，满足收纳成就休闲；皮质的拉手避免磕碰，而且颜值高
▲客厅南阳台非常小，刚好作为单独的洗衣间使用，定制柜加上镶嵌洗烘机，完全满足一个人使用
▲主卧为了有层次感，同时更符合老人的喜好，背景采用了深咖色涂刷，提升空间层次；利用次卧空间局部实现了小的衣帽间储物，白色谷仓门搭配，黑色五金以及简约吊线灯，简单时尚
▲床头非常舒适的布艺靠背，角落是蓝色的床头柜，咖色背景下，简单雅致
▲主卧右边L型飘窗石材铺贴，平时可以作为置物或者放置绿植的需求；悬空的隔板代替床头柜，视觉更轻巧，旁边预留插座，平时手机充电非常方便
▲飘窗放上抱枕温馨简单
▲衣帽间谷仓门不仅仅是节省地方，同时黑色的线条五金，也可以作为空间的装饰元素
▲主卧全景，为了满足更多收纳以及老人的藏书需求，把原来电视墙砸掉，改作了超薄墙体，满足了局部收纳柜的定制，挂机空调下是玻璃门的成品书柜，刚好满足老人的藏书需求
▲主卧门后的杂物收纳柜以及书柜，满足老人的收纳需求；纯白平板干净极简
▲白色平板与黑色极简把手搭配，视觉干净舒适，同时采用小巧的地吸避免开门与收纳柜的碰撞
▲次卧很小，摆放了成品的收纳床，角落书桌作为老人偶尔使用的书桌，同时这里也可以作为同小区孙子过来休息的地方
▲带收纳功能的床，满足休息同时也满足一部分的收纳需求，不占地，空间更宽敞
