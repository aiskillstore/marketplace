# 给老人装修应该这样做12.27

首先从买房说起，如果是打算给老人独自居住，要不选和你同一个小区越近越好，要不附近也行。注意一点，绝不选择没有电梯的房子，即使是一楼，大部分没有电梯的楼房是没有地下室的，一楼常年潮湿。

老人独居房子尽量远离学校，否则一年四季按时的吵闹声太大。
同样远离城市主干道，灰尘，噪音，老人受不了的

◆进门口一定给老人准备方便换鞋的换鞋凳，还有随手可以取拿的挂衣空间。美观是其次，功能第一

◆老人房禁用木地板，一是大部分都是地暖房，木地板只能用强化复合板子，有污染叠加，二是木地板打理很费事，寿命短，不像地砖老人直接可以拖地就行

◆老人住地面选择哑光防滑的仿古砖或者仿木地板的瓷砖，本身这种瓷砖特性就是防滑，打理也方便，耐脏

◆保持所有地方功能性第一，没有琐碎难打理的装饰品，保持各个通道顺畅

◆禁用所有壁纸粘贴类产品，在污染总量上控制污染

◆公共区域尽量多的有舒适单椅或者其他可供老人休息的功能性座椅

◆给老人选房格局最好餐厅紧挨厨房，方便就餐和打理

◆卧室空间舒适为主，尽量减少任何多余造型，空间允许，舒适的单椅是必备品，供老人随时可以坐下来休息

◆老人房窗帘一定要有浅色和深色互相搭配，可以随时供老人改变光线

◆卧室一定要给老人做双控开关，方便老人起夜

◆老人卧室一定要必备床头柜，空间不足一个也行，方便拿取各种必备品

◆老人房所有家具侧重以实木环保为主，也可以用藤制家具

◆厨房必须选用哑光防滑瓷砖，各个部位功能性要顺畅。冰箱尽量放大点，方便老人存放各种食品

◆卫生间一定要用防滑瓷砖，灯光尽量明亮，减少玻璃在卫生间的使用

◆给老人座便器旁边加上扶手，防止老人时间久了眩晕

◆洗手盆，淋浴位置必须装上扶手，以防老人跌倒

◆老人淋浴处最好能放上淋浴凳，避免老人长时间站立

◆老人淋浴处最好用防滑垫，比如防腐木垫子
