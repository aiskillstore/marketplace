# 90㎡三室二手房改造，砸掉卧室墙提升暗厅幸福感

一家三口，本身资金有限，看重这套二手房，一是交通便利，最重要的是为了孩子上学。可怜中国父母心，为了下一代，一代代人用生命的透支完成生命历程。

户型：三室二手房
造价：拆除1.2万；全包含定制10万；
▲原始户型为小三室，开门是厅是过去老旧房的典型做法，而且客餐厅的窗户都很小，采光很差。
原始户型进门右侧的厨房，与隔壁小卧室空间重叠，导致卧室变小，同时进入厨房的动线不合理；新改造以后，改变厨房门位置，扩大次卧空间，动线更加顺畅，同时利用厨房墙体满足进门的小收纳
原始户型卫生间门朝向客厅，和次卧门紧挨，导致餐厅无法布置，改造以后，同样改变卫生间门到门厅，同时缩小主卧，改变主次卧的进门位置，成就主卧的衣帽间空间；原来次卧的门洞采用餐边柜定制，满足餐厅收纳，同时满足了餐厅的布局以及动线的合理
因为餐客厅空间本身很小，为了拓展视觉空间，厨房隔壁的次卧做了半开式布局，沙发后面的墙体半截墙吧台布局，不装门，采用布帘形式，平时作为开放式的多功能室，以后老人偶尔来住，拉上帘子就可以作为次卧使用。
▲未拆除之前的样子，深色的木地板以及大面积木作，导致空间非常昏暗压抑
▲新装修以后，厨房门改到了门厅右手，同时牺牲局部墙体镶嵌鞋柜，满足了一家三口的进门收纳；原来的木地板更换成了石材柔光瓷砖，更好打理，光线的漫反射更加柔和；因为空间比较小，综合考虑，最终还是做了中央空调，节省空间，同时让一家人的生活品质得到提升。
业主对就餐比较看重，所以唯一的餐厅背景做了重点处理，木质的造型墙布局，大理石餐桌搭配四把复古的餐椅，原来次卧门改变位置以后，做了餐边柜定制。就餐区域成了全家的焦点
▲餐厅全景，虽然餐椅显得有点大，但是颜值颇高，而且半包围的靠背非常舒适。吊灯专门挑选的马卡龙颜色与餐椅呼应，提亮整体空间；造型款的镜子作为背景装饰，可以让空间温馨明亮
▲站门口看餐客厅全景，统一四周吊顶处理，墙面统一烟灰色变色；灰色的布艺沙发搭配大理石茶几与餐桌呼应，孔雀蓝的脚凳与餐椅呼应协调；背景大幅挂画营造一室温馨
▲非常小的客厅，采用轻巧三人位布艺沙发，大理石圆几，两个小脚凳满足会客需求；电视墙细腿电视柜视觉更轻盈现代，小空间不至于拥挤
▲客厅唯一采光的地方就是非常小的窗户，为了解决采光和拓展空间需求，把小卧室的墙体砸掉，做了吧台功能，同时开放式布局可以引光入室，不仅提升公共区域的光线，而且拓展了视觉空间
▲角落的绿植与挂画相得益彰，营造空间的宁静与温馨
▲厨房隔壁的小卧室，作为多功能房使用，平时是书房，是休闲室；偶尔老人过来，这里就是一间次卧；榻榻米以及统一定制的做法，可以把小空间物尽其用；不装门，半截墙吧台布置，不仅满足功能和颜值，同时引光入室，提升空间的亮度以及视觉空间
▲主卧相对素雅一点，咖色的暖色乳胶漆变色，皮质床头搭配，宽边石膏板造型，素雅简洁
▲次卧作为儿童房布局，带一个生活阳台。上下铺的布局，为了以后二胎做准备。橘色窗帘让空间更活泼
▲定制镶嵌衣柜满足衣物收纳，床铺对面白色斗柜可以放置各种杂物，背景绿意挂画清新搭配
▲厨房墙面采用大理石浅色瓷砖，提亮空间，地面大地砖通铺；蓝绿吸塑柜门清新对比，L型布局基本满足三口之家所需90㎡两室老房，空间互换，砸掉厨房，大刀阔斧装出130平的开阔90㎡两室小家，小夫妻非得做心爱的美式90㎡两室二手房，客卧互换，餐厨一体，独立洗衣间，轻奢小家90㎡刚需房，砸掉厨房实现通透小两居90㎡老房20年房龄爆改，休闲露台+开放式厨房+大气岛台
