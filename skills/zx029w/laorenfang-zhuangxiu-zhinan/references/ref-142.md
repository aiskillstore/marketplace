# 85㎡两室三口之家，客厅卧室互换成就光线

刚需两室，需要满足三口人入住，但是户型采光非常差，而且原始户型过道纵深，进门就感觉压抑，所以需要整体改造光线问题。
▲原始格局两室空间，进门直对就是一个纵深的过道，南向被两个卧室和厨房遮挡，北向客厅带阳台，光线昏暗，特别是纵深的过道关上门以后非常压抑昏暗。

▲设计后的布局图纸，首先砸掉主卧空间，重新改变次卧入门，把主卧作为客厅使用，同时砸掉原来封闭厨房，让现有客厅豁然开朗；客餐厅厨房一体化设计，因为平时很少看电视，所以角落采用电视支架满足电视放置，同时布局投影，满足平时的偶尔娱乐
▲砸掉卧室作为客厅，让进门空间豁然开朗，改变原有封闭纵深过道的昏暗；进门右手鞋柜换鞋凳定制，满足基本收纳；鞋柜延伸的角落满足电视支架的布局，同时因为光线的充足，采用橘色提亮视觉空间
▲门厅进来是豁然开朗的客餐厨一体空间，一面橘色的墙提升视觉层次，圆形餐桌角落布局，刚好利用原有过道处收纳柜镶嵌冰箱，兼顾餐边柜功能
▲砸掉厨房墙体做了弧形造型，让空间视觉上更有生趣
▲原来封闭昏暗的厨房与客餐厅融为统一，光线以及空间互通，整体明亮清爽
▲原有过道尽头厨卫夹角的位置，刚好满足定制，镶嵌冰箱，同时局部镂空作为餐边柜，同时弥补厨房收纳的不足
▲沙发刚好布局在原来主卧窗户下，搭配极简茶几，满足平时三口之家使用即可，小空间也能显得更宽敞，实用的挂机空调满足功能
▲天黑的时候，暖色的灯光加上橘色墙面的反射，整体餐厅非常温馨
▲原有客餐厅改造成了主卧空间，唯一的卫生间利用过道实现了干湿分离
▲原来的客餐厅改做了主卧空间，与阳台打通，奶咖色墙面涂刷，营造更温馨的睡眠空间
▲无主灯的布局让夜晚更有温馨氛围
▲衣柜同样选择奶茶色系，平板简洁，自然光下素雅温馨
▲暖色灯光和奶茶色共同营造更温馨的氛围
▲阳台方向看主卧空间，黑色皮质在奶咖色背景衬托下，非常有层次感
▲不对称的灯具搭配也能让视觉更灵活
▲极简白色铁艺圆几搭配一个非常暖心的小台灯，暖光下让床头变得更温馨
▲次卧作为儿童房使用，实木上下铺布局，为了满足老人偶尔过来有个住得地方；墙面是淡淡的粉色，看起来更活泼
▲厨房打通阳台，把灶具安排到阳台，同时移门分割，刚好解决开放厨房的油烟问题
▲干区空间采用橘色的墙漆与背景红色的格子瓷砖，撞色设计，让过道空间视觉上更有活力
▲湿区空间墙排马桶做了移位，刚好满足钻石型淋浴房布局，角落洗烘机放置，利用马桶上方墙挂洗衣机满足
