# 100㎡三室变一室，给老人的治愈系新家

儿女在同一小区给母亲置办的养老房，因为母亲一个人入住，儿女也得随时过来，所以想要更有质感，更有风格感，让母亲住着舒服，功能和收纳也得更完美；最关键问题是儿女几乎每天都要过来一块就餐，所以餐厨空间非常重要。原始结构图，是一个三室一卫的户型，看似三室，但是三个卧室都比较紧凑，而且客餐厅一体，餐厅与进门空间冲突，导致空间非常拥挤；作为给母亲一个人居住的房子，显然三室多余，空间压缩了，需要整体改造设计后的布局图纸，砸掉进门右手两间卧室，实现了餐厅西厨的开阔布局，同时也让南北通透的房子更加敞亮；保留了一间主卧作为母亲的卧室；原有进入主卧的墙体砸掉，实现了干区以及收纳布局，让动线更加合理；同时客厅一面墙定制收纳柜，满足了一个人入住的所有收纳，可以保证空间时常整洁进门视角，因为母亲一个人住，整体色调采用奶油温馨，而且颜色上多考虑母亲的年龄，偏向深色系；进门直对厨房拱形玻璃门搭配，墙面时尚壁灯点缀，提升温馨感；借用过道的干区柜满足一个进门玄关的简单造型入户右手两间小卧室砸掉，布局了餐厅以及西厨，空间非常开阔，而且让餐厅更大，满足平时一大家子就餐需求两间卧室成就了超级餐厅以及西厨的布局，不仅满足了岛台和餐桌的布局，同时满足了收纳储物；南北通透的户型更显敞亮奶油色的定制与木质的餐桌过渡色柔和，餐厅显得干净简洁过道的干区以及收纳柜定制，门口采用一面墙收纳柜延伸，满足了老人进门换鞋凳以及鞋柜收纳电视墙一面墙的收纳柜，通向生活阳台垭口拱形设计，整体南北通，干净清爽电视墙一面墙的收纳柜满足一个人居住的所有收纳，同时无主灯布局，整体空间更显宽敞和高级全景空间，无主灯布局，超级收纳保证空间的整洁柔软布艺沙发搭配小的圆几，素色地毯装饰，阳台垭口拱形布局，无主灯整体素雅高级保留一间主卧，拆除原有过道墙体，拓展干区空间，实现了高柜收纳以及干区的布局主卧依然延续柔和色调，侧墙定制衣柜，黑色的吊线灯营造氛围，高床头对老人更舒适一点阳台一边定制收纳柜，满足洗衣机布局，同时保留一个小的洗衣池，阳台上方隐形晾衣架满足平时晾衣需求厨房依然延续整体柔和色调，L型布局，满足基本的需求，干净素雅过道满足干区布局，悬空浴柜，一边高柜延伸收纳，外侧实现了面向门口的玄关造型湿区空间素雅简洁，淋浴隔断分区
