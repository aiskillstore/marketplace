# 老人房装修，一定记住8不做3.16

每家都有老人，而且人人都会经历老去的那天，所以老人房装修其实非常重要。今天看一下，老人房都有哪些不能做的装修。
第一、不要人为给空间设置障碍。
▲不论什么样的户型老人居住，不要人为设置进门障碍，虽然好多老年人相信所谓风水，但是一定说服去掉，无缘故设置进门障碍，除了影响光线以外，徒增视觉障碍。老人居住动线一定要顺畅，否则如果过小的户型，反而增加“曲径通幽”，这是折磨老人。第二、更不能做下沉式玄关。▲老人房更不能违背常识，学别人做下沉式玄关。这个不是为了让老人好打理，更不是为了老人更方便，这是人为让老人进门摔倒的障碍，千万不要做。第三、不要做不结实的进门换鞋凳。▲如图这种鞋柜隐藏式换鞋凳老人居住最好不要，因为是隐藏，一般都比较小，而且稳固性并不高，给老人心理产生负担不说，安全性极差▲还有如图墙面悬挂的折叠凳，不适合老人使用，结实度放一边，出来进去还得不断让老人弯腰折叠，造成极大不便利性。▲如图老人居住，没有地方放换鞋凳，就可以采用鞋柜定制的做法，保留一个进门换鞋的功能区，而且位置一定在刚进门的位置，宽度大小必须根据老人的身材量身定制，宁愿宽，不能窄，否则非常鸡肋▲如果有空间，最好放一个结实舒适的成品换鞋凳，满足老人进门出门换鞋的便利第四、尽可能不出现玻璃制品。▲比如对于年轻人稀松平常的厨卫玻璃门，如果是老人独居的房间，最好避免，尽可能采用木质门去做。厨房完全可以大面积木头加入少量玻璃，触及不到的局部玻璃去做；卫生间如果害怕潮湿可以选择大面积封闭的复古铁艺门或者直接做木门，哪怕后期使用寿命短，安全第一。▲更不能给老人独居的房子设置各种大面积玻璃隔墙，看似光线好了，但是独居老人身体日渐行动不便，玻璃制品非常危险，宁愿采用布帘或者纱帘遮挡，也不要使用有安全风险的玻璃▲卫生间更不能像年轻人一样，去做任何淋浴玻璃隔断，一定采用浴帘，这是对独居老人最安全的做法《老人独居，卫生间这样做，不要等出事了再看》▲家有老人这种立式或者靠墙的全身镜坚决不能出现，需要一定要固定在合适的角落墙面上。▲更不能不使用玻璃隔断了，但是却做了挡水条，这个对于老年人来说更加危险，毫无防备的时候最容易绊倒，而且卫生间都是坚硬的瓷砖和洁具，后果不堪设想▲也不能做年轻人喜欢的下沉式淋浴间，这个和挡水条是一样的危险第五、避免家里出现尖锐家具或者物品。▲如上图年轻人喜欢的餐桌，四角尖锐，老年人独居绝对不能选择，还有如图轻巧的餐椅，因为太轻，就坐面本身就小，在绊倒老人的同时，更容易第二次伤害▲即使木质餐桌，也尽量避免这种四角棱角分明的家具，老人不小心摔倒，是最容易产生二次伤害的▲四角圆润厚重的餐桌椅，虽然颜值不高，但是最适合老人使用，避免磕碰的同时，家具都比较稳固，老人即使手扶，斜靠都不会发生危险，也没有尖锐的棱角带来二次伤害▲如果可以，尽可能给老人独居搭配圆形的木质餐桌，也是最理想，保持动线通畅的最好做法，平时餐椅可以挪进餐桌下方，防止老人行动不便被餐椅绊倒▲像这种最容易翻车的岩板浴柜，坚决不能给老人使用，尖角外露，而且是非常坚硬的岩板，如果没有做干湿分离，卫生间潮湿容易滑倒，空间又小，非常危险的家具▲能做浴柜外置的干湿分离最好，这样老人不用进入潮湿容易滑倒的卫生间，而且利于健康；如果实在无法实现干湿分离，宁愿采用圆润没有棱角的柱盆，也不要采用有尖锐棱角的浴柜台面。第六、减少复杂危险电器的使用。▲老人独居不要用垃圾处理器，你以为的便利，对于老人来说就是痛苦，操作不便更容易发生危险，反之没有垃圾处理器，每天的生活垃圾，老人下楼锻炼顺便就能倒掉，反而增加了老人适当锻炼的机会。▲超大冰箱严禁给老人独居使用，这样的后果就会导致，老人节俭惯了，一些食品不舍得扔掉，保存冰箱，反而不利于健康，一定采用普通单开门冰箱，够使用就行，这样老人每天出门锻炼就可以购买新鲜的食材，更利于老人的健康▲对于老人独居的房子，洗碗机还是算了，特别是这种镶嵌洗碗机，本身容量很大，而且老人独居，压根用不上，而且老年人也不会使用，怕费电，怕成本高，更麻烦的是这种有水电隐患的电器，完全是给老人生活徒增烦恼。少量的餐具每次老人手动清洗，本身也是饭后适当的活动锻炼。第七、减少超高家具的搭配。▲年轻人喜欢的超高家具定制，最好不要出现在独居老人的家里，最好采用成品的低矮家具，避免老人拿取东西，登高更加危险▲卧室衣柜也是一样，不要做年轻人喜欢的一门到顶，采用成品低矮款成品实木衣柜，环保用材，而且避免了老人登高取物的危险。▲老人房独居喜欢卧室有电视，可以搭配实木的矮柜，用来满足老人的零碎物品的收纳第八、严禁使用地面不防滑的材质。▲老人房独居坚决不要用任何亮光的地面材料，不仅难打理，不防滑，而且老人视力本身不好，这种光污染更是变本加厉。▲更不能选择深色的亮光瓷砖，家里氛围显得压抑难受，更不利于老人的健康▲老人房所有地面以及墙面材料尽量使用柔光哑光材质，没有反光，更防滑，更好打理，例如木纹瓷砖以及柔光瓷砖。
