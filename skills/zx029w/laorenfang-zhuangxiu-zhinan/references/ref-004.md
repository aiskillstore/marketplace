# 家里有老人小孩，装修安全怎么兼顾？

**装修应保障老人孩子的安全与健康。** 孩子的安全与健康是第一优先级，成人的审美喜好需为此让步；老人房装修核心是安全实用。

**儿童房十防记牢。** 防玻璃伤：室内最好不要使用大面积的玻璃和镜子。防磕碰伤：家具的边角和把手应该不留棱角和锐利的边，家具边缘尖角加装圆弧角防护棉垫。防倒压伤：玩具架书架不宜太高，以孩子能自由取放为好，而且要放稳。防门夹伤：对于较小的孩子来说低矮的玻璃门和平开门很危险。防坠落伤：窗口、落地窗和阳台窗口要安装安全栅栏，窗户边不要设置床具和桌子。防滑摔伤：地面材料注意防滑、注意地毯的固定。防缠绕伤：重点是窗帘的选择、窗帘绳的长度。防窒息伤：封闭的衣柜橱柜书柜应该设计通风口。防电击伤：儿童房间的电源插座要选用带有插座罩的插座。防污染伤：有小孩装修时候千万不能以大人的喜好来，小孩子免疫力低下，对装修污染没有抗拒力，大人的喜好为孩子让路。

**老人房八不做。** 不要人为给空间设置障碍，老人居住动线一定要顺畅。更不能做下沉式玄关，这是人为让老人进门摔倒的障碍。不要做不结实的进门换鞋凳，换鞋凳要带扶手，坐得稳起身省力。尽可能不出现玻璃制品，卫生间不能做淋浴玻璃隔断一定采用浴帘，更不能做挡水条和下沉式淋浴间。避免尖锐家具，四角圆润厚重的餐桌椅最适合老人。减少复杂危险电器，垃圾处理器对于老人就是痛苦，超大冰箱严禁给老人独居使用。减少超高家具，最好采用成品的低矮家具，避免老人拿取东西登高危险。严禁使用地面不防滑的材质，老人房所有地面墙面尽量使用柔光哑光材质。

**适老化细节补充。** 推拉门用吊轨，传统地轨绊脚难打扫。卫生间杜绝高低台、蹲便台阶，过门石做斜坡，严禁亮光砖浴缸，装淋浴凳加扶手，热水器选燃气款。智能锁老人难用首选机械锁，全屋智能别装机械开关最实用。厨房吊柜加升降拉篮防爬高，装天然气报警断闸器，灯光明亮。卧室床高45到50cm最合适，床垫偏硬款，床头用传统机械开关。家具全做圆角，沙发茶几别太大留宽敞走道。
