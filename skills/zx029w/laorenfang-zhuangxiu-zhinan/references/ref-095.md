# 浴室防滑，错误做法不要尝试9.28

▲上图是一般普通家庭的做法，做了淋浴房，然后里头和外头一样的做法，简单瓷砖铺上就行。对于年轻人这个做法后可厚非。但是家有老人的话，这种做法一点不防滑，所以大部分人会想出各种各样的防滑做法。

▲狭小的淋浴房，空间本身很小，人洗澡都紧张难受，不知道是从哪个酒店看见这种做法，用石材拉槽铺到本身就很小的空间。看起来高大上是不是？用起来才知道：地方太小，光脚落地，处处和踩到石头上一样，而且本身为了防滑，极小空间坑坑洼洼，实在一不小心磕得慌。空间小就不要做这个了。

▲空间比较大的淋浴房，同样做了石材拉槽，逼格满满，看起来确实高大上。面积大，没有了小淋浴房磕脚的困惑了。但是实际用了才发现，只有一个地漏，坡度必须超一个方向倾斜，坡度大了影响美观，坡度小了水流不尽。找一个合适的坡度，最终使用感受是：拉槽里头的水永远不会干净，每一次洗完澡，槽子里头都是污垢，而且当初是十字开槽，拖把完全无法施展，用喷头每次冲干净，拉槽里的积水永远无法解决，时间久了发现，原来拉槽的颜色变成了黑色，想清理干净真的很难，必须用牙刷爬到地上一点一点清理，实在累人。最终感受：拉槽里头以及石材周边与瓷砖接缝处，永远是藏污纳垢的地方，时间久了就知道了，这个做法简直就是鸡肋。

▲防腐木防滑。不知道从哪知道防腐木不怕水，这个本身就是误解。任何木材只要经过防腐处理，都可以延缓腐烂。和防潮板，防火板一个道理，所有处理只是延缓腐烂的速度，而不是说防腐木就不怕水。但是家里的浴室，如果家里人多，南方地区几乎天天浴室都得使用，长期泡水，没有不烂的防腐木，不烂只说明时间未到，或者表面看到很好，其实下方你看不到的地方已经发霉长毛了而已。

▲浴室如果真的需要用防腐木，建议使用局部的，可以随时拿起来的，经常拿起来通风晾晒，避免发霉滋生细菌，否则直接铺防腐木地板，时间久了，发霉不自知，反而不利于健康

▲其实真正防滑又好清理的就是防滑的瓷砖，比如鹅卵石的瓷砖，造型不要很大，容易磕脚，有造型，脚感舒适就行，又防滑，还容易打理。这里有两种做法，一种就是天然鹅卵石直接铺，不好做坡度，施工麻烦，建议直接使用仿制鹅卵石的瓷砖实惠
