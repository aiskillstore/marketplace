# 哪地方都可以要把手，电视收纳柜不能10.10

前面连续谈了两篇不要把手的专题《鞋柜无把手，咋开门？》《餐边柜无把手，不影响功能还高级》，今天说一下电视收纳柜，这里的收纳柜指的的满墙收纳柜，坚决不要把手；如果是全屋定制给你做的满墙收纳柜把手，只能说明完全没有设计经验和审美经验，虽然钱没有少花，但是效果不是一点难看，可以说是设计灾难了。

▲还是具体对比来看一下，左图为无把手，右图为有把手，不论你采用哪种极简把手，右图都非常怪异。因为有了对比，你才会发现左图最好看，如果没有对比，你不知道还有更好的表现，就会误以为右图才是最好的。公共区域这是人面子的事情，而且把手这样做反而容易磕碰，视觉上也凌乱不堪，所以坚决不要犯这样的错误
▲同样还是左右图对比，看一下有把手和无把手的根本区别，好坏显而易见。

▲不是有把手就不能用，而是相对与无把手的简洁来说，就显得难看。这一点在装修里头的是审美的问题，通过对比你还是要装把手，也不是什么罪过。个人对审美的要求不一样，目的只是好坏对比，自己感受，然后做决定
▲看上图，超大定制柜，同样中间通柜采用了黑色极简把手，大面积看也没有非常难看。因为收纳柜面积大，采用大部分没有把手的做法，零散几个不破坏大局的把手，起到点缀作用，做到恰到好处也是可以的
▲上图对比你会发现一个问题，越是大面积白色收纳柜越不能装把手，显得视觉突兀，但是如果是深色柜子装黑色把手，对比起来要比白色弱化很多，不显得突兀。但是还是没有无把手看起来更高级清爽
▲上图除过吊柜以及右边通柜需要反弹器以外，下方抽屉直接从下方就可以打开的。这种柜子装上把手试试看。
▲什么是设计失误，如上图所示，如果有做全屋定制这样做的话，真的可以淘汰了，毁掉柜子了。
以上举例注意：一般能柜子有设计感的的话，是不会犯以上的把手错误的。但是业主执意要装也没有办法，这个需要个人做决定。
