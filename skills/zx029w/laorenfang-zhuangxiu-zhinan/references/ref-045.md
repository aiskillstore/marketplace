# 小卧室放床，有多少种布局形式？12.4

空间小在北方无一例外做榻榻米，这个是最实惠也最能发挥空间功效的方法，对于刚需房来说，又能解决次卧功能，又能成就一个书房，何乐不为呢？

但是好多人不喜欢榻榻米，不能移动，做好了永远就是这个样式，没有办法改变布局，所以会坚持传统的衣柜、床书桌的布局，但是因为空间小，并不能像传统那样直接布局，否则一张床会占据整个空间，所以小空间想要满足传统布局，是需要思考布局的。打破传统思维，不要老是感觉和客厅必须有沙发和电视一样，小空间床不一定非得居中放置。

▲如图传统布局做法，空间太小，这样传统的布局，瞬间没有了任何空间，想要其他功能几乎不可能

▲如图打破传统思维，把床铺靠角落放置，腾出侧墙衣柜，满足小空间的最大功能
▲如图床铺靠近窗户角落放置，留出侧面定制衣柜的空间，局部镂空悬空定制床头柜延伸功能，满足卧室的前提下，让空间尽可能宽松舒适
▲除过可以延伸床头以外，空间够用的话，也可以延伸一个书桌代替床头柜，功能更多，同时满足衣柜、床以及书桌的完美布局
▲窗户是飘窗的话，床铺就可以紧紧靠近墙体布局，窗帘在飘窗布局即可，腾出很小的空间，满足衣柜以及床头的布局即可
▲如图也可以改变一下床铺位置，入门口定制衣柜，床尾空间可以放置小的书桌，用来满足卧室功能放大空间
▲如图所示进门做衣柜，侧面镂空，床铺角落布局，利用原有飘窗打造收纳，而且衣柜局部镂空满足书桌功能
▲床铺进门左手角落布局，床尾定制衣柜满足收纳，同时窗下打造书桌和飘窗功能，同时延伸一个书柜空间，虽小但是打破传统布局，完全可以满足更多空间需求和功能
▲最里头布局床铺，门口刚好有空间可以定制衣柜，同时延伸一个书桌，上方满足挂机的布局，改变思维就可以让小空间发挥最大功效
▲进门左边角落布局床铺，利用窗下打造书桌和衣柜连体，功能都有了，而且空间利用率更高
▲进门左边放床，利用窗下满足一个飘窗和衣柜的收纳，过道布局小的书桌凳，小空间的儿童房就完美实现
▲小空间左手上下铺，床尾衣柜，延伸窗下定制书桌和矮柜收纳，再小的空间也满足了功能布局
▲入门左手布局床铺，利用门口定制衣柜与书桌连体，同时刚好满足空调风口的布局，小空间改变思维就可以完美实现功能
▲入门左手放床，利用平窗位置打造收纳兼顾休闲飘窗，一边楼空还满足一个小书桌的功能
▲角落放床，床尾窗下打造书桌，空间小无法满足衣柜，可以借用隔壁空间打造镶嵌衣柜满足收纳，空间虽小五脏俱全
▲其实小空间只要改变一下思维，实际上都可以满足入住，例如儿童房或者满足一个人入住的卧室，不要想着非得放大床，满足功能根据现实去做更好
▲不怕空间小，就怕自己的野心不愿意面对现实问题
空间小想要满足功能，一是尽量改变思维模式，第二家具一定要轻巧简洁，满足功能即可，绝对不能使用体积超大或者造型复杂的东西，那样会让本身逼仄的空间雪上加霜的。
