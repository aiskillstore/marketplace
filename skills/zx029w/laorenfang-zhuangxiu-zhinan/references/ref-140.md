# 85㎡两室装修，养老房也时尚

非常中规中矩的两室空间，装修起来是为了父母有个养老房。但是不能像一般简约装修那样看起来比较廉价，所以结合父母的喜欢，让整体空间看起来更时尚大气一点。
▲原始户型，入门是厅，北向是厨卫，而且空间都不大，卫生间没有干湿分离；客厅与餐厅共用空间，但是格局不大；两间卧室都朝南，刚好满足刚需

▲设计后的布局，首先缩小了原有卫生间，实现干湿分离，同时实现入门的鞋柜收纳；缩小卫生间的同时扩大厨房门洞，满足采光和空间的通透；
客厅里头侧墙整体打造收纳柜，刚好满足公共区域的收纳；因为老人居住电视必不可少；餐厅位置刚好是凹陷区，打造卡座和吊柜，小餐桌刚好满足平时的就餐，同时保证动线的合理；主卧带生活阳台；次卧作为备用打造了榻榻米，同时兼顾次卧和收纳布局
▲入门左手缩小原有卫生间以后，实现干区布局同时采用高柜满足入门的鞋柜收纳；客厅不大，侧墙统一收纳柜布局，靠近窗户矮柜以及挂画点缀，同时蓝色的沙发与橙色单椅让空间更有活力
▲客厅全景，侧墙L型收纳柜几乎满足了公共区域的所有收纳，刚好利用窗户位置留空做了挂画点缀，蓝色与橙色与沙发单椅呼应，简单的色彩搭配让空间简练但是又有活力
▲透光百叶视觉简洁，让空间更显清爽干净
▲悬空的电视柜定制视觉更轻巧，而且与卡座木色呼应协调
▲凹陷区刚好满足卡座以及吊柜的定制，轻巧的餐桌布局，同时可以满足四人就餐，橙色皮质餐椅与客厅单椅完美呼应

▲两把橙色皮质餐椅提亮就餐区视觉亮度，同时又与客厅单椅呼应协调
▲主卧老人房带生活阳台，为了保温和隔热需求，全景移门布局，同时内外都布局了布帘；床头背景灰色壁布铺贴，壁灯满足起夜需求

▲次卧定制榻榻米满足收纳的同时，可以兼顾一间卧室的功能

▲厨房L型定制，统一浅色系搭配，视觉更简洁干净

▲缩小卫生间以后实现了干湿分离，定制浅色浴柜，镜柜满足收纳，湿区灰色瓷砖搭配黑色的淋浴隔断分区
