# 老人房装修注意事项？

老人房装修，说来说去就一句话：安全实用，比颜值重要。给老人装房，这几点一定得记住。

**第一，别做下沉式玄关。** 这个不是为了让老人好打理，更不是为了老人更方便，这是人为让老人进门摔倒的障碍，千万不要做。进门换鞋凳要带扶手，坐得稳、起身省力，位置一定在刚进门的位置，宽度大小必须根据老人的身材量身定制，宁愿宽，不能窄。

**第二，尽可能不出现玻璃制品。** 厨卫玻璃门能避免就避免，尽可能采用木质门去做。卫生间更不能像年轻人一样，去做任何淋浴玻璃隔断，一定采用浴帘，这是对独居老人最安全的做法。更不能不使用玻璃隔断了，但是却做了挡水条，这个对于老年人来说更加危险，毫无防备的时候最容易绊倒，而且卫生间都是坚硬的瓷砖和洁具，后果不堪设想。下沉式淋浴间和挡水条一样危险，也不能做。

**第三，避免家里出现尖锐家具。** 四角圆润厚重的餐桌椅，虽然颜值不高，但是最适合老人使用，避免磕碰的同时，家具都比较稳固，老人即使手扶，斜靠都不会发生危险。如果可以，尽可能搭配圆形的木质餐桌，平时餐椅可以挪进餐桌下方，防止老人行动不便被餐椅绊倒。

**第四，减少复杂危险电器。** 超大冰箱严禁给老人独居使用，一定采用普通单开门冰箱，够使用就行。垃圾处理器、洗碗机，对老人来说就是痛苦，操作不便更容易发生危险，少量的餐具每次老人手动清洗，本身也是饭后适当的活动锻炼。

**第五，减少超高家具。** 最好采用成品的低矮家具，避免老人拿取东西，登高更加危险。卧室衣柜也是一样，不要做年轻人喜欢的一门到顶。

**第六，严禁使用地面不防滑的材质。** 老人房坚决不要用任何亮光的地面材料，不仅难打理，不防滑，而且老人视力本身不好，这种光污染更是变本加厉。老人房所有地面以及墙面材料尽量使用柔光哑光材质，没有反光，更防滑，更好打理，例如木纹瓷砖以及柔光瓷砖。预算够就铺纯实木地板，摔倒缓冲更安全。

**第七，门锁开关别玩智能。** 智能锁老人难用、没电更麻烦，首选机械锁。全屋智能别装，坏了难修，机械开关最实用。卧室床头用传统机械开关，别做无主灯，要明亮采光，床高45-50cm最合适，床垫选偏硬款，护腰好起身。

**第八，卫生间是重点防摔区。** 杜绝高低台、蹲便台阶，过门石做斜坡。浴柜、淋浴区做圆弧处理，装淋浴凳加扶手。严禁亮光砖、浴缸。热水器选燃气款，更安全稳定。

推拉门用吊轨，传统地轨、极简地轨都绊脚、难打扫，直接做吊轨，地面无凸起，走路更安全。厨房吊柜高度适配老人，加升降拉篮，防爬高，装天然气报警断闸器，用高低台面，少弯腰，灯光要明亮，加手扫灯、水槽灯。
