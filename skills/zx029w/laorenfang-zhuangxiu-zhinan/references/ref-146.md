# 85㎡一楼带花园，给老人翻新养老房

这是过去非常老旧的小区，一楼带一个天井花园，为了老人居住翻新。但是业主预算有限，基本能保留的尽量保留，以最简单的形式满足老人居住即可。总体全包10万。▲原始户型图。很普通的两室空间，和过去很多旧小区一样，客厅餐厅都比较小，而且进门就是客餐厅和门厅的一体空间，这么小的地方还得容纳客餐厅以及进门的玄关，非常拥挤；过去砖混结构的房子又不敢砸墙改动格局，只能在原来基础上进行微调；房子是一楼难得有一个天井花园，也是老人非常喜欢的，但是花园整体破旧，而且进入花园与室内地面高低相差三个台阶，对于老人来说，生活多有不便。主卧需要进入次卧阳台才能进入花园空间，对于老人来说非常不方便，而且次卧只有窗户无法通向花园。
▲设计后的布置图。首先为了满足进门的客厅功能和进门的收纳，最终只能牺牲餐厅空间，就餐只能用茶几代替餐桌；原有卫生间比较小，为了不占用空间，采用移门布局，节省内部空间；原来进入天井花园只能从主卧进入小阳台，改造之后把主卧窗户做了通向花园的门，原来通向小阳台的门封闭窗户处理；次卧的窗户下方砸掉，也做成了通向花园的门
▲新改造的进门空间，为了满足进门收纳，左手定制收纳鞋柜，满足进门鞋子放置，为了老人换鞋方便，右手专门放置成品换鞋凳，这样老人换鞋比较方便；直对能看到很小的厨房空间。地面是柔光的石材瓷砖
▲新作玄关鞋柜以后，客厅就分割更小了，采用很小的布艺沙发满足功能，同时利用鞋柜的背面做了开放式隔板，可以满足客厅一些小物件的放置，也可以放一些装饰品，视觉上比鞋柜背板好看多了
▲开放式隔板空间以及台面，可以让老人在客厅很方便的放置随手物品，也不会磕碰到人，非常方便
▲很小的区域刚好放置老人原有的一件沙发，旁边多余的地方顺势定制一个扶手柜，满足收纳，也让空间极尽利用
▲扶手柜被沙发挡住了柜门，从侧面做了抽拉式设计，很好利用了收纳空间
▲客厅窗户角落隔板做了收纳空间，同时墙上给老人预留了佛龛的位置
▲客厅朝南光线不错，窗户小而且没有窗台，所以采用木质的隔板，给老人留出一个窗台的位置，同样可以随手放置各种零碎，老人心心念念的佛龛也实现了最佳位置
▲主卧改造之前，左边的门是通向次卧小阳台然后才通向花园的，右手是一个异形窗户
▲主卧改造之后，把原来通向小阳台的门改成了窗户，把原来窗户下方墙体砸掉，做成直接通向花园的门联窗，这样光线更通透，搭配大白墙，可以让卧室更明亮
▲靠近天井花园的墙面定制了收纳高柜，可以收纳换季的各种被褥
▲原来通向次卧小阳台的门下半部分采用定制柜形式封住，刚好成了面向小阳台的收纳柜
▲次卧空间，只有一个窗户，外面是小阳台然后是花园，如果要去花园，还得绕道主卧才行，而且窗户小导致空间昏暗
▲改造之后的次卧空间，整体豁然开朗，砸掉原来窗户下的墙体，变成了通向小阳台的门洞，小阳台与花园玻璃移门封闭，同时小阳台做了生活阳台布局
▲重新定制了移门衣柜，床和电视柜是老人原先有的家具
▲小阳台满足生活阳台的需求，洗衣机以及成品的洗衣池，上方吊柜满足收纳，同样做了和主卧一样的铁艺防盗移门
▲原来的天井花园，从次卧阳台下来花园有三个台阶的高低差，对于老人来说非常不方便
▲改造之前主卧的门是通向阳台，然后下来三个台阶才能到花园，老人多有不便
▲改造之后的花园，不敢想象和原来有天地之差，阳台采用移门封闭做了生活阳台，花园的三个台阶如果回填成本太高了，所以整体采用防腐木龙骨架的形式，把花园地面做了处理，更利于老人的使用
▲原来破败的院墙简单外墙漆处理，就可以焕然一新，搭配中式的庭院灯，简单古韵
▲局部地面采用普通青砖分割，白色的石头点缀，给老人留出养花的地方
▲厨房做了L型布局，采用了容易打理的玻璃柜门，同时高低台操作，让老人使用起来更方便；收纳架的布局满足了收纳不足，平时可以兼顾锅架，放置随手物品
▲卫生间在主卧门口的过道空间，原来的内部空间就很小，所以重新装修以后，采用外挂的两扇移门处理，节省内部空间
▲内部空间非常小，采用砖砌的形式做了浴柜定制，镜柜收纳满足零碎放置
▲砖砌以后铺上瓷砖，也是非常耐用，同时也解决了潮湿问题
