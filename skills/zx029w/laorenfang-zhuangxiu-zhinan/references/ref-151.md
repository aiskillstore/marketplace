# 80m²老屋翻新，给老人一个舒适的家

本套房其实还算不错，旧是旧了点，如果要住，完全满足所需。但是作为儿女感觉老人入住不仅仅是满足居住要求，同时还得有品质，让老人有一个幸福的晚年。所以打算彻底改造。

▲这是未改造之前的实景图，其实要是基本入住是可以满足的。为了让老人住得更舒适一点，所以彻底改造一下。

▲这是改动以后的布局以及收纳储物。

1.餐厅位置做了收纳柜镶嵌冰箱，同时间接延长了鞋柜的收纳。整体L型收纳柜满足收纳，同时视觉上更整洁。

2.因为次卧非常小，所以把电视墙墙体外移，成就了次卧的镶嵌衣柜，同时电视墙也做了收纳柜，且整体木质饰面，整体更简洁。次卧小，床头靠角落放置，这样靠近阳台刚好容纳一张书桌功能。

3.主卧格局没有改动，把床体和衣柜结合增加了收纳。

▲这就是进门的鞋柜，和餐边柜一体L型设计，收纳更多。无把手简洁柜门，简洁清爽。

▲进门右手极简全身镜布置，黑边框和厨房门一致统一。靠近过道的墙面刚好放置老人家的古筝，这也是老人最喜欢的娱乐项目，所以必须有一个合适的位置

▲古筝上方墙面圆形挂画，与古筝共同营造中式古典美。圆形挂画非常有颜值，需要直接点击这里购买

▲进门左手拐角餐厅，餐边柜镶嵌冰箱，木色镂空区域其实是专门为老人做的水吧台，下方抽屉里头是老人常用的药物，上方台面可以随时倒水，餐椅可以随时坐下来休息。为了舒适，专门配置有软垫的餐椅，老人能方便一点。极简的圆形吊灯，犹如一轮明月，这是老人形容的

▲餐边柜镂空吧台功能，为了拍照暂时把老人收集的陶罐摆上。

▲站过道看餐厅，除过功能性布置，几乎就是大面积留白，干净简洁，这是老人极力要求的。

▲换个角度看一下门厅以及餐厅，餐边柜让冰箱有了容身之地，且间接拓展了侧面鞋柜的收纳，一举两得

▲客厅看全景，非常极简，电视墙上方灯带吊顶。电视墙右边是一个隐形收纳柜，左边其实就是木质饰面，看起来统一。灰色布艺沙发搭配木质极简家具，干净清爽

▲电视墙靠近窗户是一个隐形柜，局部镂空简单收纳书籍。

▲沙发墙的做法是局部灰色乳胶漆，几何图案打破大白墙的呆板，四周用黑色钛金勾勒，老人非常喜欢这样的做法。

▲电视墙一半让给了次卧做衣柜，所以整体木质饰面，视觉上统一协调

▲沙发区非常素雅，灰色与木色简单配置，安静简单，很符合老人的要求

▲大卧室也很简单，无主灯简洁布置，为了空间利用，把床头护板与衣柜连体设计，代替床头柜收纳

▲床头柜与衣柜连体设计，合理利用空间。壁灯与吊线灯时尚搭配，整体更加简洁舒服

▲一体设计，收纳更合理，视觉上更加完整

▲定制床头柜和衣柜的镂空区域，可以方便老人放置物品，晚上随手取拿更加方便

▲灰色窗帘与纱帘装饰，空间安静舒适

▲次卧空间是老人给孙子准备的，简单书桌满足学习功能

▲书桌上头极简的隔板满足放书需求

▲看一下全景 ，因为空间太小，床铺只能安放在角落。镶嵌衣柜就是外移电视墙实现的。木质温润与黑色简洁搭配

▲厨房明亮的瓷砖搭配，白色橱柜，满足基本功能即可。白色让空间更明亮

▲卫生间比较简单，素雅灰色瓷砖搭配，做了简单淋浴隔断分区。为了收纳更多，一半镜柜一半收纳柜借用马桶上方收纳
