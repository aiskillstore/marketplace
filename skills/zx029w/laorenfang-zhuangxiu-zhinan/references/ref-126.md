# 一楼90㎡两室带个院子，养老不错

此套房属于单位房子，小两口作为新房使用，因为有单位的学校配套，所以购入以后，可以解决孩子上学问题，而且这种低层的住宅商品房几乎没有的，所以一楼带个小院，在城市里头就是奢侈品。
▲纯南户型，南向带个小院，很紧凑的两室空间，一家三口是没有任何问题。因为格局几乎方正完美，而且一楼这种低层住宅几乎都是承重墙，没有可以拆除改动，所以基本保持原有格局进行装修。

▲布局以后的样子，几乎按照原有格局去做的，唯一就是厨房与洗衣间打通拓展了光线和空间。两室满足小两口居住，次卧作为备用，以后可以作为儿童房
▲进门右手本身留有空间，刚好定制通顶鞋柜，满足进门的基本入住。木色是业主喜欢的颜色，而且一楼空间，木色让整体空间更趋于自然色
▲门厅进来客餐厅一体，刚好利用角落打造卡座以及餐边柜，满足四人位就餐空间，同样是浅色墙面与木色的搭配，视觉清新干净；能看到门厅厨房明黄色的谷仓门，可以让空间更有活力
▲非常素雅极简，木色与淡灰色结合，天生的自然感，让家里视觉更舒适温馨
▲两把木质的餐椅铺上柔光的垫子，就餐或者办公都非常完美
▲局部高柜与卡座结合，可以满足少量酒品的放置
▲客餐厅一体，采用简易斗柜充当边几，满足收纳而且作为餐客厅的合理分区
▲客厅看全景，因为南向空间，天晴的时候自然光还不错；电视墙采用L性定制，满足更多收纳，而且让空间不过于浪费；做了投影幕布，平时偶尔娱乐看大片非常不错
▲窗外就是小院风景，出门是景，住一楼更接近自然
▲灰色的布艺沙发素雅舒适，采用亮黄色抱枕提亮空间，而且与厨房谷仓门遥相呼应，非常简单温馨
▲主卧利用角落新分割的衣帽间，内部简单化妆台布局；玻璃的分割让视觉更加通透明亮
▲背景是浅浅的粉色乳胶漆，一直延伸至生活阳台
▲木质家具素雅床品，白色吊线灯优雅点缀
▲次卧定制了升降床，平时可以收起来，房间更整洁，女主的钢琴刚好角落布局
▲收起床铺以后，次卧就是一个休闲榻榻米，满足基本收纳，同时还可以作为女主的练琴房
▲主卧阳台一边洗衣机布局，另一边收纳书柜
▲入门左手的厨房，采用亮黄色谷仓门提亮进门的空间亮度
▲厨房与洗衣间打通以后，拓展了空间，满足了更多的收纳；浅木色与小白砖的经典搭配，舒适干净
▲卫生间本身门口有空间，刚好实现干湿分离，木质的隔断刚好让进门有了迂回背景
▲墨绿色复古感的六边形瓷砖半截墙铺贴，更有视觉层次，同时搭配木质的浴柜，精致温馨
▲湿区一边放了按摩浴缸，另一边单独布局淋浴区，采用玻璃隔断分割，虽然是暗卫，但是功能完美实现
▲从主卧阳台下个台阶就是一楼的小院，有个可以通到小区的后门；四周铁艺的围栏防护，外面的景色和把小院整体围合
▲留出过道以后，两边分割出来两块菜地，平时的时令蔬菜自给自足。闲时摆张休闲桌，邀三五好友，闲谈野餐都是不错的享受
