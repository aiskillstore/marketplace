# 老人独居，卫生间这样做，不要等出事了再看10.23

关于老人房装修以前都有谈过，大家可以自行搜索《搜索不是后台回复！》，今天看一下老人房卫生间的做法，更利于老年人的使用。
第一、老人房卫生间最好用木门+局部玻璃。

▲老人单独居住的房子，卫生间最好采用木门+局部玻璃；目的是为了防止大面积玻璃磕碰破碎，以及老人平时拄拐杖进入或者拿东西，不小心磕碰危险，这一点和年轻人居住有本质区别；
宁愿让木门寿命短，哪怕下方发霉了更换，也不要用大面积玻璃的门；少量玻璃是为了老人一旦发生意外情况，例如木门突然打不开，此时从外面可以看到情况，及时处理；

▲老人使用卫生间木门门锁最好用非常简单的功能，不要复杂功能，防止出现问题打不开，而无法救援；或者是一个人老人居住卫生间门可以不装锁，防止门锁意外打不开

▲如图的折叠玻璃门、全景玻璃门以及玻璃移门都不要用到老人使用的卫生间，容易磕碰，而且折叠门以及移门时间久了推拉非常费力

▲如果担心平开门老人摔倒刚好推不开门，可以考虑采用质量上乘的木质移门，这样在老人摔倒靠到门以后，可以轻松打开
第二、能做干湿分离尽量满足▲首先是为了健康，第二是为了老人使用更方便，不至于洗漱都得每次进入卫生间，这样干湿分离，在外面就可以搞定，也避免进入卫生间发生其他意外▲老人房浴柜不要设计抽屉，一定要设计成可以方便打开的平开门，而且拿取东西更方便第三、严禁在老人居住的空间出现亮光地砖▲如上图右图，明显干区地面是亮光瓷砖通铺，不仅造成光污染，影响老人视线，同时有水非常危险，不防滑；一定要用防滑的柔光瓷砖或者哑光瓷砖▲不要给浴柜下方为了防水铺任何障碍地垫，不仅不防滑，而且容易让老人摔倒，非常危险第四、卫生间瓷砖严禁亮光以及大规格不防滑瓷砖▲老人卫生间墙面最好使用纯色柔光或者哑光瓷砖，老人在卫生间出现手扶墙壁不至于太过于光滑；地面更不能用亮光瓷砖，一点不防滑，大面积亮光会造成视觉凌乱▲老人专用卫生间瓷砖严禁使用任何花砖或者扰乱视线的各种线条装饰，会让老人本身就不好的视力雪上加霜第五、卫生间内部呼救系统▲如果房间大，或者离老人不是很远，可以给老人配备紧急呼救系统，此时不论老人在浴室或者有紧急情况可以一键呼救▲老人独居的话，可以给卫生间安装防水的按键以及拉绳设计的呼救系统，可以在第一时间发送至子女手机上，以防危险发生▲还有这种自动报警装置，可以设置老人待在卫生间的时间，超过一定时间自动报警，可以传送到子女手机上第六、卫生间内部隐患消除▲玻璃淋浴隔断以及淋浴房，严禁在老人独居卫生间使用。钢化玻璃本身就有自爆几率，而且老人行动不便，磕碰非常危险▲老人卫生间采用简单浴帘就行，严禁地面采用挡水条，一定要保证地面平整无任何障碍；同时如图红圈位置，无法干湿分离的时候，浴柜定制严禁出现锋利的直角边缘，防止老人摔倒磕碰▲老人独居卫生间严禁使用浴缸，在行动不便的时候，非常容易滑倒摔倒▲浴缸对于正常人来说有时候都存在各种安全隐患，何况行动不便的老人▲除非你能给老人配置这种自动升降的浴缸，否则宁愿不要▲老人独居卫生间严禁使用蹲便，特别是北方地区隔层排水，做蹲便必须砌地台，这种地台对于老人行动不便来说非常危险；如果是南方可以不做地台做蹲便，只要老人不是特别反感座便，尽量不做蹲便，即使旁边有扶手，对于长时间蹲着对老人来说太痛苦，容易摔倒，而且起身也比较困难▲严禁在老人使用的淋浴区采用防滑地垫，市面上不论什么地垫都有厚度，落差让行动不便的老人更容易摔倒磕碰，一定给老人配置防滑效果较好的防滑拖鞋即可第七、老人房卫生间安全配置▲老人使用最好采用智能马桶，可以一键自动翻盖，避免老人行动不便频繁弯腰
▲如果没有自动翻盖的马桶，可以设置小便池，并设置扶手支撑，可以方便老人小便使用
▲自动冲洗必备功能，无需老人动手，每次离开马桶自动冲刷▲马桶旁边固定扶手，这个是必备的设施，方便老人起身▲如果无法安装固定扶手的话，可以采用这种专业的马桶助力架，方便老人双手支撑▲有条件的可以给老人配置这种自动缓降以及自动升起的马桶助力架，可以让老人使用座便器也能非常方便安全▲除过马桶必要的支撑以外，还可以配置这种前面坐下来提供支撑的扶手，这样老人前倾支撑非常舒服▲老人独居卫生间严禁使用浴缸，所以必须是淋浴，此时一定要配置淋浴凳，方便老人坐下来淋浴，同时淋浴开关以及花洒拿取位置需要和淋浴凳高低搭配；淋浴凳需要搭配固定扶手，同时花洒旁边也得有站着淋浴的固定扶手▲如果家里老人用轮椅，一定要做这种悬空的洗漱区，高低需要配合轮椅的高度，同时还要有手扶的空间▲悬空可以尽量让老人离盆子近一点，带弧边造型，而且龙头离盆子也近，同时两边有专用的镂空扶手，非常方便▲不使用轮椅的老人，浴室柜旁最好也安置可以随时支撑的扶手，方便老人长久站立以后随时支撑
