# 70㎡老房两室无厅，改造两位老人退休宅1.29

两位老人一直住的老宅，因为过去的装修简陋，而且一直这么多年了，处处都看起来非常陈旧，所以老两口想着现在退休了，就可以安享晚年了，把老宅翻新改造一番，也可以住着舒适一点。
▲没有改造之前的样子，非常简单，两室无厅，所以有一间卧室兼顾了客厅以及卧室空间，因为年龄大了总怕吵闹，所以多时候是分房休息的；整体也没有规划，随便放几件家具满足生活而已。▲这是原始的格局，入门很窄的门厅，右手分别是卫生间以及一个夹角空间，算是餐客厅的空间，但是非常狭窄；两间卧室空间倒是可以，但是整体进门显得昏暗逼仄；厨房狭小而且与主卧对门，导致过道空间浪费，光线也不佳▲设计后的布局图，首先扩大原有的卫生间，利用卫生间实现了进门的收纳储物；砸掉厨房墙体开放布局，这样刚好利用了原有浪费的过道，拓展厨房的收纳；砸掉餐厅紧邻卧室的的多余墙体，引光入室，同时打造一个会客区域，同时采用玻璃门分割靠窗的榻榻米空间，平时可以储物，也可以休闲；主卧满足收纳的同时，还分割了一个小的书房空间▲重新装修以后的门厅空间，利用右手卫生间局部空间，实现了一个镶嵌的鞋柜，两个人使用足够；右手墙面简单挂衣钩以及木质边框的更衣镜布局；地面通铺木纹砖一是环保，二是更好打理▲入门看全景，通铺木纹砖，砸掉次卧多余的墙体改造成客厅，引光入室，让进门以后的光线更明亮，空间更显敞亮▲砸掉次卧多余的墙体以后，改造成了客厅空间，这样客餐厅就融为一体；餐厅的凹陷区刚好满足收纳柜定制，同时满足卡座延伸；餐桌靠向卫生间墙布局，刚好满足平时两人的就餐功能▲次卧改造的客厅空间，靠窗户采用玻璃移门分割一个次卧空间，榻榻米以及衣柜定制，平时可以满足收纳，同时必要时这里兼顾一间次卧功能▲磨砂玻璃移门即使关闭以后，也并不影响客厅的光线▲大面积墙体奶咖色变色，沙发区域白色突出区域层次，草绿色的沙发床配置，拉开也可以满足一张床铺的功能，过年过节的话可以满足儿女回来一块居住▲沙发与玻璃门之间养眼的绿植点缀一室的自然和清雅▲砸掉次卧多余墙体，拓展门洞以后，满足光线需求，同时垭口拱形设计，视觉上更显优雅；电视墙拉通定制悬空的木质电视柜，刚好与地面木纹砖呼应协调▲靠窗户玻璃门分割一间次卧空间，榻榻米以及衣柜满足收纳，同时兼顾一间次卧功能▲榻榻米房延伸木质背景，悬空床头柜定制满足床头收纳；大面积咖色乳胶漆，背景局部白色分开层次，壁灯以及挂机功能性布局▲榻榻米满足收纳，同时满足一间次卧功能，移门轨道采用隐藏式视觉更简洁美观一点▲主卧空间采用一组衣柜分割出来一间小的书房，定制书桌以及吊柜书架，可以满足平时办公所需；左侧的储物间采用隐形门分割，平时可以放一些家里不用的物品▲书房左侧储藏室采用木质的隐形门，让整体更整洁▲主卧空间利用衣柜分割了一个小的书房空间，木质的衣柜定制，搭配浅色高靠背床头，简单并温馨▲主卧与阳台打通拓展空间，同时提亮光线；原有的半截墙无法拆除，采用拱形造型做了门窗造型，让视觉上更显得的优雅美观▲主卧门口定制一面墙的矮柜，用来满足更多杂物的收纳▲厨房去掉门以后半开放布局，满足U型定制，尽量满足更多收纳同时，满足基本的操作；门口利用与主卧的过道空间，满足了冰箱以及洗烘机的布局▲卫生间墙面浅色的奶咖色瓷砖，让视觉更加一体化，地面是灰色的防滑地砖，左边定制悬空浴柜，利用新砌墙实现了壁龛的收纳；右边是花洒以及马桶区域，空间不大但是干净清爽。
