# 买房能不买暗卫最好不买，除非不做淋浴6.6

有明卫谁也不愿意选个暗卫的房子，这个是没有办法的事情。如果有可能，尽量避免购买，或者两卫，一明一暗，只给明卫做淋浴洗澡，暗卫只安排马桶洗手池或者做储物或者放洗衣机即可。

▲卫生间外面墙体发霉、掉皮，如果有壁纸会鼓包脱落。这个几乎是大部分暗卫都会出现的问题。
▲如果你再不懂装修，碰到一个外行给你卫生间防水只做30公分高度，那后果更惨，外墙渗水脱落那是百分百会发生的。
▲美缝放到其他区域是为美观好打理，但是放到卫生间是为了防水，哪地方都可以不做，卫生间美缝必须做。哪地方钱都可以省，这里一定不能省，不敢省。
▲家里只有一个卫生间，而且还是暗卫，能做淋浴房或者淋浴隔断最好，但是需要根据空间大小决定，不能装了淋浴隔断或者淋浴房，家里有小孩洗澡盆都放不进去，那是实现不了的，如果实现不了淋浴隔断或者淋浴房，采用极简的浴帘遮挡一下，尽量让大面积的洗澡水在最短时间流入地漏，避免水汽朝门口蔓延，时间久了就会外墙发霉掉皮。
▲除非家里有两个卫生间，暗卫不做淋浴，可以做收纳储物或者放置洗衣机也行，这样就可以避免暗卫长期使用潮湿问题
那如果家里只有一个卫生间还是暗卫，该怎么避免后期潮湿问题？1.防水做到吊顶位置。2.一定做美缝处理3.能做淋浴房或者淋浴隔断最好，如果不能浴帘也行4.尽量保证空间的时刻干燥，洗完澡赶紧拖地保证短时间潮气不要蔓延
做了以上处理并不能保证肯定管用，最起码会延缓时间，如果你平时使用注意了，完全可以杜绝这种现象。否则没有任何办法解决，只能下次买房打死都不要暗卫洗澡。
