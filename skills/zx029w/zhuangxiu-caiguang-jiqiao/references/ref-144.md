# 80m²两室，无关风格，干净明亮

每个人对家的理解千差万别，但是总有那么一些人，虽然不知道各种风格的定义，却能在最终达到自己想要的感觉。刚需房，首要是简单，入户的收纳是主要，其次才是颜值。

▲不算是好户型，南北各一间卧室，中间分别夹着厨卫以及客餐厅。对于这样的刚需，我们的业主是非常清醒的，唯一要求就是实用，并没有要求颜值，而是更注重整体颜色的搭配。所以全包的做法更能系统规划。
▲3D草图就能看出来其实整体格局非常小，而且光线并不好，特别是阴天的时候，甚至于客餐厅需要开灯照明，所以颜色绝对不能采用深色。
▲进门直对的就是厨房空间，为了满足收纳，牺牲一部分墙体做了镶嵌鞋柜，下方镂空便于进门放鞋，中部镂空木色套色清新，便于进门放置包包或者进门钥匙。镂空区域感应灯细节布置，晚上进门自动亮起非常方便。旁边是厨房黑色的全景门，视觉和光线都能保持通透
▲站门口看另一边的客厅空间，过道门厅单独采用水磨石灰色瓷砖，视觉更柔和。黑白灰与木色的清爽对比。
▲过道进来的客餐厅全景，直对就是主卧空间以及一个休闲飘窗。大面积留白，局部木色点缀，视觉非常干净。为了满足收纳，电视墙整体采用收纳柜的形式定制，大面积白色无把手以及木色套色设计，满足收纳的同时保证视觉的清新
▲电视墙的整面墙定制柜，大面积白色无把手设计，视觉干净，空间不压抑。局部套色区域展示柜书架设计，视觉更灵活。电视墙预留电视位置，目前上方做了隐藏投影幕布
▲电视墙满做柜子利用了卫生间门上的空间，收纳更多。卫生间定制浴柜镜柜满足更多收纳
▲大面积白色与木色搭配，客厅整体无主灯，采用白色滑轨灯辅助照明，层次感更强，视觉更简练
▲空间小，采用灰色布艺沙发简单配置，背景木质隔板，精品摆件以及挂画装饰，简单干净
▲非常简单的原木餐桌椅搭配，与木地板融为一体，极简的吊灯简练，营造高级感的就餐空间
▲客厅角落休闲阳台，采光能好一点，因为空间原因，没有布置茶几，这样整体客餐厅更宽敞，视觉更简单高级
▲朝南的飘窗虽小，但是中午的时候阳光可以直接照进客厅，某一时刻光线非常好
▲餐厅以及门厅全景，大面积白色，门厅单独灰色水磨石瓷砖，局部木色搭配，视觉干净清爽，这就是业主想要的感觉
▲主卧空间实拍，颜色大面积白色，床头半截墙护墙板造型，淡紫色变色清雅。床头极简吊灯与壁灯辅助照明，视觉上非常干净舒适
▲主卧全景，主卧带一个异形阳台，打通设计，侧面定制收纳柜，靠近窗户异形卡座，布艺淡紫色布艺垫子定制，与背景护墙板以及窗帘一体呼应，阳台可以作为休闲的角落，整体颜值也是非常耐看
▲主卧对面有个很小的衣帽间，衣帽间与床之间同样定制顶天立地的衣柜，满足更多的收纳。因为空间小，满足业主的视觉干净，整体没有石膏线，干净极简
▲次卧更小所以定制榻榻米满足功能性，同样大面积白色。空调位置预留位置刚好满足空间需求
▲空间限制，榻榻米床头定制超薄收纳，上头镂空兼顾书籍的放置，视觉也能更加灵活。平时的书籍以及精美摆件都可以放上
▲厨房地面水磨石瓷砖灰色清雅，墙面大面积小白砖铺贴，搭配白色橱柜。为了空间过道更宽敞，右边拐角橱柜做了斜边处理，比直角视觉柔和，更能保证过道的通畅，左侧刚好放置冰箱。拐弯延伸过去是小的洗衣间
▲卫生间进门空间定制干区浴柜以及镜柜，旁边高柜镶嵌洗衣机以及烘干机，满足功能性
▲卫生间另一边单独淋浴区域，采用简单浴帘遮挡，黑色五金质感搭配
