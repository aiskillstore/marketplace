# 亮光PK柔光瓷砖，业主都撕起来了！到底谁更胜一筹？

如果以装修是别人生活为前提的话，装修里头的正确以及审美从此就不存在了！这就好比万事都有人回你一句：管你屁事，那就无解了。但装修绝对不可能是这样的，否则就没有那么多人去到处寻求避坑“秘籍”了。总归装修是以人的生活为主，以自己的审美为主，就会存在同样装修，不同做法存在，而且各自都有各自的道理！今天结合网友们的做法，看看到底哪种是好，哪种不好，结合自身需求，也可以借用别人的经验成就自己家的装修。亮光瓷砖还是柔光瓷砖？①认为亮光砖好的，自然还是考虑光线和好打理。网友@朱大馋：装修前反复纠结一个月，在瓷砖铺反复仰卧起坐，差点把瓷砖老板气坏，最后还是放弃了所谓的“高级感”选了亮光砖！真香！跪谢当初的自己！网友@哈哈哈：选择亮光砖的原因：因为它太太太容易打理了。有点脏的时候用扫把就能清理干净。显亮堂显空间大显层高，更清爽，让人忽视了它的不足。网友常说亮光砖拍照不好看实际好看，目前觉得还可以，不是很影响照片质感。网友@小青蛙：80×80浅灰色亮光砖，做的同色美缝， 墙面也是浅灰色，顶面是白色， 柜子和门也都是做的白色， 入住后真的很百搭， 而且敞亮显干净！②认为亮光砖不好的，如弃敝屣！网友@麟麟格：才装好不到一年的家，就是妥妥的大冤种，花了近四万贴的瓷砖，无论如何都无法与亮光瓷砖廉价和解 犹豫了很久还是决定改铺木地板，浅浅期待一下吧网友@小糯米：这个瓷砖说温馨也不温馨，说亮吧也有点反光 反正就是感觉家里很土，没人家的洋气网友@小王的米：好好的原木奶油风被亮光砖毁了，好后悔当初没有坚定的选择奶白柔光砖，这亮光砖真的太难看了网友@橘爱：当初一心想要铺柔光砖，被家人劝退了，说柔光砖不好打理，但是现在我真的好后悔啊，亮光砖没有质感，冷冰冰的，稍有不慎就会变成出租屋，原本家里的装修挺好看的，就是被这个亮光砖给毁了，现在好后悔个人见解：亮光瓷砖让空间变亮不假，但是也正是这个致命点，让其有了遇强则强的属性，反而对刚需房不友好，越是装修预算不足的装修，亮光瓷砖越是让结果看起来更廉价，这一点毋庸置疑。③喜欢柔光瓷砖的，挡也挡不住网友@悠然：最不后悔的装修决定之一，入住这几个月，每当天气晴好，当推开家门看到阳光洒落在柔光砖上时，满屋子的温柔似乎融化了一整天的疲惫，柔软了内心…真的，每次都特别想光脚进去，张开双臂，轻闭双眼，让这温柔拥抱入怀…	 庆幸当初的选择，柔光砖真的是最不后悔的装修决定之一！
网友@棕子：爱干净的话，柔光砖非常好用，永远可以相信柔光砖的质感，光脚踩上的感觉是多舒服。没有光污染，这也是一开始就选择柔光砖的原因，不喜欢亮光一开灯那种反射倒影，很不高级，简约通透还显空间大，这是直观感受，没有复杂的花纹，全屋通铺出来的效果。网友@姐姐：柔光砖手感很细腻，平时是一天一拖，很好打理也很干净；入住半年多了，最不后悔的就是通铺了柔光砖，通透又好打理，奶油风真的好温馨~品质和花色都蛮不错网友@莫言：面积比较小，装修的时候就想整洁显大为主，亮面砖反光太厉害看起来不够温馨，所以选择了柔光砖通铺＋同色美缝，卫生间也是一样，做完之后效果非常满意，看起来简洁又高级，而且还非常显大，朋友以为有一百多平！④不喜欢柔光瓷砖的，厌恶到家了网友@搬砖：柔光砖表面虽然看起来很细腻，但是特别容易显脏。一些细小的灰尘、脚印，在光线下看得清清楚楚，而且还很难清理。每次看到地上的污渍，我这心里就像有小蚂蚁在爬，不擦干净就浑身难受。网友@傻狍子：入住半年后，才发现：柔光砖打扫起来比较费劲，有些污渍不能一下用拖把拖干净，需要二次刷才能打扫干净，地面上掉头发也比较明显。所以柔光砖适合勤动手的人，我这懒的拖地的人就想换亮光砖了，拖把一次就搞干净了，不要再二次清洁。个人见解：柔光瓷砖百分百有质感，有档次，这个毋庸置疑。不好打理的原因并不是真的不好打理，而是本身柔光就显得干净，稍微脏了就想打理，导致感受上浪费很多时间。要用柔光瓷砖需要与自己生活水平匹配，如果家里不配扫地机器人，还是慎选，靠传统拖把肯定会越拖越脏的。
