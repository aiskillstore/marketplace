# 70㎡两室暗厅改造，老破小变身三口温馨居

原始的一字型格局像是狭窄的走道，暗客厅只有6平左右，又小光线又差80年代典型的南北一字户型，南北两卧室，中间暗厅，卫生间和厨房在入户玄关两侧；拆除8千含外运；半包基础3.6万；主材3.2万；定制2万；利用厨房空间嵌入到顶高鞋柜，不占玄关空间，储物强大
没有地方做鞋柜，只能砸掉厨房墙体满足一个小的鞋柜内嵌，勉强满足常穿鞋子的收纳一字户型就像是条狭窄的走廊！入户左右两侧是厨房和卫生间；安装整墙洞洞板，垂直收纳增加利用率，美观又实用入户直对就是餐厅空间，三人居住，原木餐桌搭配两把椅子和条凳，虽小但是满足平时的就餐把客厅与南卧打通，整个家都变得通透明亮！全屋通铺木地板，大白墙，客厅做了简单的吊顶，突出空间层次感。透明推拉门将客厅开间隔断为两个独立空间，明亮又显大主卧在隔断处安装透光不透人的白纱帘，保证了卧室的私密性；床头衣柜和箱体床，则足够收纳家人的衣物和生活杂物。主卧宽度不够，定做床头衣柜，不遮挡客厅采光；4米整墙衣柜+1.8米箱体床，储物空间强大书房区域L型布局，低柜储物+1.6米大书桌
书桌上方利用墙面置物架和洞洞板纵向收纳
客餐厅书房集一体，无主灯设计更显空间
布局简单，休闲与收纳兼并，实现一房多用墨绿色沙发和温柔干净的大地毯都是让空间看起来显大的加分项。家具主要都是白橡木和榉木的，虽然这个小房子没有装修得非常豪华，但整洁温馨，住起来很舒服打通南卧室，以白色极窄透明推拉门做隔断，原先昏暗的客厅变的通透明亮拆掉与南卧的墙体，以透明折叠门重新隔断空间，提升客厅采光
隔断后的客厅空间变大，原本属于卧室的区域改为书房
客厅开间仅有2.4米，没有做电视墙也没有茶几，作为休闲区与书房融为一体5平儿童房没有做传统榻榻米，却满足了睡眠、收纳和娱乐，还拥有独立的学习区，功能丰富，温馨又实用！学习区的书桌没有像传统榻榻米那样延伸出来，而是选择了更为灵活实用的升降桌椅。上方顶柜开放格，可以满足少量书籍以及杂物的收纳。侧面还贴了整面墙的大白板，既能辅助学习又充满童趣！当季常用的衣物则放在床尾的小衣架上，下面还有两个储物抽屉用来收纳内衣袜。床尾还放置了带抽屉的小衣架，用来收纳隔夜衣和当季的内衣袜。书桌上方的洞洞板和顶柜开放格用于收纳零碎小物品。小房子造型的白板墙，不仅充满童趣，还可以辅助学习，磁吸收纳。烟灶的区域原本是北阳台的一部分，打通后融入厨房面积。厨房长4m宽1.9m，选择了高效率强收纳的一字型布局。在橱柜对面定制了窄边柜来增加收纳，双边橱柜+过道的设计也不会拥挤，白色柜体、亮面地砖让厨房明亮显大，清爽整洁！家里的洗衣机和冰箱都放在厨房，选择嵌入式的不占空间。橱柜60cm，过道90cm，窄边橱柜40cm。做菜动线合理顺手，收纳强大卫生间面积太小，做不了干湿分离，安排铝合金浴室柜防水耐用卫生间长宽距离都很勉强，只能做成卫浴一体，处处都要防水。长方形的卫浴两头安装浴室柜和马桶，中间安装花洒。虽然洗澡时两边都会淋到，但这样洗澡和如厕的空间都大。卫浴门选择了长虹磨砂折叠门，简单方便，折叠省空间。
