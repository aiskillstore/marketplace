# 新风和空气净化器，哪个好？8.18

今天应该比较枯燥，不过尽量用通俗话语来说，大家有个了解，心里有底就行。

新风和空气净化器有什么不同？
新风相当于换气扇，就是房子做了新风，可以把室内空气与室外互换。空气净化器只能将室内空气回收净化然后放出。相当于汽车空调的内外循环一样。

新风到底对健康有没有用？
当然有用，否则早就不生产了。关键点在于你用什么样的新风。

比如大家经常逛商场超市，这些地方如果没有新风，恐怕是活物都能憋死。但是你真以为这些地方用新风家里能用吗？可以用，只是名字叫做新风系统，实则就是一个大型的廉价的换气扇而已。这就是为什么说新风看你用什么样的。你如果给家里装一个叫做新风的换气扇，不如不装，和开窗户没有什么区别。

新风系统的主要功能以及购买要点：
新风主要是空气交换，这是字面理解的意思。大部分人都是这样理解的，所以大部分人抱着新风的概念，都买回来一个大型换气扇而已。

第一：单向新风，只进不出，即只有一个送风口，把室外空气加入室内，通过气压，让污浊空气通过窗户门缝隙排除。其实就和厕所排气扇一个道理。如果你买新风如果是这样的，要它何用？外面是雾霾还把雾霾吸入室内？

第二：双向新风，有进有出，即有送风有排风，送风口负责把室外空气送入室内，排风口负责把室内污浊空气排出。这才是新风的基本意义，不过只有进出还是相当于一个换气扇，和开窗有和不同？

什么样的配置才是真正的新风系统呢？上面提到的双向新风加上过滤网才是它的意义。一般市面上有简易新风就是双向的，但是好多根本没有过滤网，所以购买时一定注意，可以加上前置过滤网，这样才能让室外污浊的空气过滤以后进入室内，才起到新风的作用。

普通过滤网都不贵，但是记住，这个过滤网其实和防霾口罩有点像，你想空气过滤质量好，过滤网就得密实，这样会导致风量不够。风量够了，过滤质量就得下降，这个本身就是一个无法解决的矛盾，所以在购买新风的时候，一定把握两点，过滤质量过关，风量要足。

高效过滤网，可以直接过滤PM2.5
还有一点非常重要，过滤网要不停更换，像西安地区冬天雾霾的话，半个月就得更换一次，绝不是新风装好不拆迁都不维护，那你提高的只是面子，糟蹋的还是全家的性命。

普通过滤网两道过滤
一般的过滤网是无法过滤PM2.5的，所以有一种静电过滤器，可以办到。不需要每次更换，可以清洗，和更换过滤网一样，定时清洗即可，清洗一两次再次更换新的，这样就可以解决雾霾的侵害。但是静电过滤器一旦饱和会产生臭氧，会危害人的健康，这就是为什么大部分人不敢使用的原因。

静电过滤器可以水洗

目前最先进的除过双向排送，过滤外，还有恒温风机。也就是能保持室内室外进出风的温度一致，一般的只是换气过滤，恒温就解决掉了冬夏室内外温差很大的问题。举个简单例子，冬天有暖气室内温度十八度，室外温度是零度，新风系统开始工作，如果没有恒温功能，你试想一下，一秒钟零度空气进入室内十八度，恐怕用不了几分钟，你家暖气就成了摆设了，而放在西安冬天就是害怕雾霾，你不懂这些，你家新风冬天就是个摆设而已。

新风和净化器到底哪个适合？
这个一定要考虑清楚，如果面积小，人员少，当然净化器实惠；如果面积大，人员多，你不可能每个房子都放净化器，所以新风实惠。再一个新风的噪音肯定大于净化器。当然如果你非得购买新风，可以考虑国产的壁挂新风，就是个换气扇而已，远远不如净化器功能好。

购买新风系统要根据自家面积选择适合的风量风机，这个每一个产品都有说明，不再赘述。

新风的安装形式：
这里不谈柜机和壁挂，这个一听都知道怎么安装。主要说吊顶式新风的安装。

和中央空调一样，都得隐藏在吊顶里头，一般在三十公分左右。谨记一点，如果你家要装中央空调和新风，一定是新风先做，后做中央空调，因为新风的管路直径在十公分左右，而且不能有九十度弯度；中央空调的铜管要细得多，所以如果你先装中央空调，新风管路可能会因为空调管路互相冲突。这就是顶送顶回，好处是不影响层高，只需要和中央空调一起局部吊顶即可。

▲注意上图就是新风地面排管法，采用高度三公分的扁管连接，一般不建议使用，一是影响层高，不好维修，最重要的是扁管极大影响风量，很有可能失去新风的意义了

▲进风口尽量避免在邻居家厨卫附近，否则 +污浊空气又被吸进自己家里了。进出风口保持距离，如果太近，排除的废气很有可能又被回收利用了。注意上图的管路都是九十度做法，此做法极大的影响风量

▲这才是新风管路的正确做法，拐弯处永远保持45度弯管，否则会影响风量

▲如果有承重梁的位置，一定采用过梁器，否则房屋会有安全隐患

好了，相信看了上面的介绍，大家应该对新风有一个大概的了解了。但是为什么每每有客户问需要安装不，陈工都不推荐，其实也是有苦衷的。

第一、新风的前提是你家是密封的，这是最最基本的前提，否则新风何用？但是各位入住的业主自己想一想，你们家的塑钢窗或者断桥铝，真的能达到密封的效果吗？不可能的，所以你如果想要密封，最好自己动手做一下。

自己购买密封条把所有窗户缝隙修补一下，否则你家新风换气的量都不如窗户缝隙多，还是个换气扇而已。

第二、大部分人即使购买到真正的新风，从不维护，从不清洗，这是现实，好多做新风坦言，客户从来没有维护或者清洗过。这才是可怕的，这样的新风相当于掏钱买了个生产细菌的机器，整天给家里输送细菌，这样的做法你要新风何用？不要说麻烦，一个售后电话就可以搞定，关键在于舍不得那份钱而已。这才是不推荐新风的原因。
