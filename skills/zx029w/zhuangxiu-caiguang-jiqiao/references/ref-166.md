# 后悔没早看！8个全屋定制技巧，小户型越住越大！

小户型收纳怎么做才不会显得空间更拥挤？相信是大部分刚需业主最关心的问题。为啥家里明明做了好多收纳，却越住越乱，而且空间拥挤？归根到底是把收纳做成了“盒子”，完全忽视了定制的“隐藏术”和“消失术”，甚至有的定制完全是高调宣示存在感，认为只有这样才能体现花钱的“价值感”，但其实是本末倒置。今天看看真正可以让小户型收纳不拥挤，不繁琐的做法，大家可以借鉴使用。01.隐藏柜体厚度像这种房子结构本身就是凹陷区的定制，只露柜门的做法，就是最大限度的隐藏了柜体厚度，视觉上更极简，弱化了定制的厚重感的做法。像这种无法隐藏柜体厚度的做法，相对来说定制就比较突兀，而且侧面颜色与墙体不一致，就会导致小空间更显拥挤。衣柜无法嵌入隐藏侧面柜体厚度的时候，也可以采用侧面开放的形式，实现功能的拓展，弱化柜体视觉的突兀。《侧面柜才是隐藏王者！7个零存在感位置，能收纳杂物还显大》如果不隐藏厚度只是视觉突兀，那不做见光板简直就是翻车做法了一样的鞋柜不一样的做法，就会有不一样的视觉感受；隐藏柜体相对来说空间不显得拥挤，视觉更简洁。餐边柜也是一样道理，对比起来，嵌入做法只露柜门，视觉空间更轻盈极简，让空间更整洁。道餐边柜两边不靠墙不内嵌与内嵌弱化柜体厚度，两种做法是截然不同的，对于空间的影响也是不一样的。柜体越是弱化存在感，空间越是简洁，越能放大空间。《餐边柜选色难？其实纯色就能美翻天！》满墙柜做法如果可以嵌入设计，就可以弱化柜体的厚度，满足空间的简洁，小空间更不会有拥挤感。一整面墙的收纳柜，两边都有墙体，只露出柜门，最大化的隐藏了柜体的厚度，弱化突兀感，满足收纳，而且不会导致空间拥堵。相对来说满墙柜侧面露出柜体厚度以后，视觉上就显得厚重，小空间就更有拥堵感。如果满墙柜无法嵌入，可以采用悬浮以及侧面开放的形式，也可以弱化柜体的厚重感，也是一种解决办法。《电视墙不做满墙柜，那就做悬空柜吧》满墙柜无法弱化侧面柜体厚度，可以采用局部开放作为手办展示的做法，第一弱化柜体厚重，第二拓展另一种收纳展示功能。《各种手办展示，拯救空白墙》02.隐藏突兀拉手公共区域满墙柜做把手，无一例外都会翻车，视觉非常凌乱，导致空间更乱。公共区域满墙柜因为面积比较大，此时一定要低调，采用隐藏拉手设计，满足视觉空间的极简清爽，否则全是定制“盒子”。鞋柜有无拉手视觉效果是天地之差，如果审美不行，简直就是翻车结果《鞋柜定制翻车集锦，原因在哪？》一样花钱，一个是价格，一个是价值；一个是盒子，一个是设计。突兀的把手以及不懂审美的玻璃门简直是定制的天灾人祸《无缘无故，收纳柜少做玻璃门，真的很廉价》一个是断开设计全部把手，一个是分段设计，价格一样但是价值天地之差。03.造型纵向，弱化越极简约高级鞋柜的横向镂空太常见了，现在看多了索然无味，更不能让空间显得更高级。相反纵向的开放造型，可以拉伸空间，视觉空间不会显得拥堵，更有高级感纵向造型镂空结合夹吊的手法，可以让视觉上更轻盈，拉伸空间感收纳柜分段式设计，局部纵向的开放以及夹吊手法，拉伸空间感，灯光点缀，让空间上更有高级感满墙柜纵向开放不仅可以提升颜色层次，同时可以作为分区界限，空间灵动而不显乱。收纳柜局部纵向跳色和镂空搭配，可以打破空间的呆板，同时也能满足风格色彩的延伸。04.藏八露二原则网友@将军：能劝一个是一个，没想好别做满墙书柜，不要以为你能把它做得多好看 装饰的多好看，尤其是家里有小孩的，你放心，他不可能整齐，他不可能好看，他很有可能变成你娃玩具的堆放地家里没有那么多书，就不要做大面积开放书柜，如果有小孩，采用下方局部镂空，兼顾玩具和书籍的收纳，孩子也方便拿取，最重要的是好收拾，空间上也不会显得非常凌乱《刷到这条的家长有福了！适童化改造方案被网友玩出花》少量开放满足空间层次，加入灯光的轻盈点缀，反而会更高级更出彩。收纳柜少量镂空满足层次和灵动感，也满足空间色彩的视觉平衡。05.善用“隐形”嵌入收纳技巧满满墙柜开放格玻璃门毫无章法，视觉本身很乱，电视没有内嵌平齐，跳色与电视分裂感，整体就会导致空间凌乱常见满墙柜极简设计，局部跳色与电视融为一体，嵌入齐平设计，可以让空间更加整洁餐边柜定制高调张扬必然翻车，而且后期摆放物品以后，整体会更乱餐边柜如果面积小，尽量纯色极简，因为后期有物品要摆放，首先让餐边柜低调极简，不至于后期摆放东西更显乱。闲置的客房兼顾书房，但是由不得不准备卧室功能，可以采用隐形床的形式，也可以采用沙发床的形式，既满足功能，同时还可以让小空间更加整洁《只是办公就亏大了，7个功能让书房成为家里的明星》如果空间小，也可以采用隐形设计，满足空间的最大化，同时可以让空间保持整洁《户型如果实在太小，就用折叠神器满足》阳台空间小但是有需要书桌功能，可以采用隐形设计，用来保证平时空间的放大通透《当阳台装上‘变形金刚桌’！白天喝茶晚上办公，网友：早该火了》餐边柜有电器采用严丝合缝镶嵌做法，一定要让视觉极简，弱化存在感，小空间才能不拥挤，放大空间。想要厨房空间整洁，所有电器采用严丝合缝镶嵌做法，不仅让空间整洁放大，同时平时也更好打理。《厨房装修，定制橱柜要考虑多少电器的镶嵌？》小空间床头柜采用隐形设计，可以最大化空间，小空间不至于繁琐厚重06.颜色多用浅色，不要超过两种没有审美颜色格局混乱，一样掏钱就会导致视觉空间凌乱繁琐，对于小空间来说就是雪上加霜了极简干净，颜色控制最多两色，小空间弱化柜子的存在感，其实就是低调，更有价值。同样鞋柜，颜色极简干净，低调弱化存在感，才能让空间整洁，放大视觉空间。没有审美的话不要高调做法，也不要无缘无故用什么玻璃门，颜色最好不要超过两个，哪怕就是一个颜色极简做法，也是低调有价值的。好的定制价值在设计，而烂的定制甚至连定制盒子都不好看，一个没有审美，没有设计经验的商家，你直接找以为的便宜是肯定的，因为压根没有任何审美和设计。一样的价格，一个丑到极点，一个美到惊心，这就是审美和独立思考的价值不一样。07.悬浮可以让空间轻盈空间小，鞋柜悬浮设计，可以视觉更轻盈，放大视觉空间，小空间更通透过道收纳柜悬空设计，丰富空间的同时，作为展示装饰，空间上也不会更拥堵。电视墙收纳柜悬空设计，加上灯光点缀，对于小空间来说更能视觉轻盈，通透，空间上不至于厚重拥堵小空间书房书桌采用悬浮设计可以放大空间，不会导致空间拥挤狭小《悬浮书桌，释放更多空间，享受更自由的生活》小空间衣柜悬浮设计，也可以弱化厚重感，让小卧室空间更显轻盈。08.定制局部镜面放大空间小空间门厅，鞋柜局部镜面柜门设计，满足全身镜功能，同时放大视觉空间《装修中，镜面柜门都用到什么地方？》狭小的衣帽间，采用镜面柜门的做法，可以充当全身镜，更能视觉上放大空间阳台收纳柜镜面柜门代替全身镜，视觉上可以放大小阳台的空间。书房兼顾衣帽间，局部柜门采用镜面设计，满足全身镜功能，同时有放大空间的功效。写在最后：其实定制是要比装修更复杂，更需要技巧和审美的专业学科，如果一味只看价格低，舍弃的只不过是设计，丢弃的不仅仅是审美，同时还影响了空间的价值。
