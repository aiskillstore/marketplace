# 有些户型便宜也不能买，后期成本更高8.25

买房其实住是基本，所附属的各种功能其实比住本身更重要。例如年轻人买房肯定是学区了，现在房户一致的政策其实就是为了刺激房地产，所以学校是首选；至于不考虑学区的改善型购房，必然考虑是生活的方便以及宜居，远离嘈杂的声污染，空气污染等等不利因素。今天主要谈一下什么户型最好不买，一旦前期不考虑，后期如果能改造徒增成本，如果无法改造，那全是入住烦恼。…1.不规则户型
各种异形户型能不买尽量不买，除非你买房前已经全面了解房子结构，而且保证百分百可以缺点变优点，否则买回来发现没有救了，就迟了因为一般购房业主都不是做装修设计的，也不可能买房的时候带一个资深设计师，能化腐朽为神奇。即使后期能缺点变优点，付出那么多金钱代价，何不直接购买好户型呢？
再好的设计师也无法挽救空间极度浪费的户型，像有纵深过道的户型，完全无法利用，导致房子的利用率极低，看似购房单价低，其实无形中已经付出了昂贵的生活成本，何不直接躲开，直接把浪费的成本加到房价里头挑选好的户型现实装修里头，总有人会嘚瑟自己家奇葩户型，怎么经过设计师鬼斧神工的改造，满足了不一样的价值。但其实就是吃饱撑的，就是有好路你不走，专门翻山越岭，你付出的成本代价完全可以买到更好的户型有些异形户型即使后期付出更多设计成本满足了功能，暂时的新颖时间久了各种不适应，始终在家里都找不到北，毫无方向感的空间会让人产生恍惚感，时间久了这种恍惚感会一直持续，甚至到最后连家都不想回了，到那时候你明白为啥房子要方正，已经迟了…2.没有干湿分离或者无法改造干湿分离的户型如上图卫生间不仅是明卫，而且本身就是浴柜外置的干湿分离的格局，这才是好的户型，否则后期不注意生活习惯，只能是隔空吃翔了如图毛坯房本身没有干湿分离格局，但是经过后期可以改造成干湿分离，这种户型就是可以入手的户型，特别是家里只有一个卫生间的情况下。不排队不让全家隔空吃翔，这个是判断户型以及装修好坏最最基本的因素之一。《浴柜外置干湿分离，8种做法》如果你不看户型，买个暗卫而且极小，也无法做任何改造，这个就太难受了；后期如果不把牙刷牙杯拿出去，这就是最不健康的生活方式…3.北向客厅户型当然不好
这个不是重点，如果为了省钱不是不可以买，有的纯南户型一年四季不见阳光太多了，为了省钱的话，不是不可以，如果不是为了省钱，那就尽量避开。能买北向客厅并不是买房不知道，而是当时压根拿不出更多钱而已，所以这个是没有办法的办法，努力赚钱重新买一套就是了…4.大部分卧室都朝北的户型
虽然横厅布局，但是四室空间，三室都朝北，相对来说不算最佳户型，这样的卧室永远见不到阳光，即使高层同样四室，虽不是横厅户型，但是所有三室都朝南，要好很多，而且客厅紧邻的卧室墙体都可以拆除，入住人少完全可以实现横厅格局《舍弃一间房，实现横厅的空间和通透》…5.没有独立门厅的户型
这里的独立门厅并不是进门的障碍，而是门厅独立空间，可以满足更多收纳，进门换鞋区域可以与公共区域独立分开，有个空间迂回的功能如图就是独立门厅，进门有个独立的迂回空间，右手刚好是鞋柜，对面墙可以作为装饰，进门的玄关背景也有了，这种户型当然是最好的户型
上图就是没有独立门厅的户型，后期装修诸多问题，结果是各种定制，把一个完整的空间切割零碎，降低了装修价值，这个就是不好的户型的弊端所在像这种南向的户型，进门是厅的话，甚至有的后期不懂设计，连个鞋柜都实现不了没有单独门厅，不仅鞋柜很难布局，而且没有迂回空间，甚至进门有的直对餐桌《入户直对餐厅，除非有迂回空间，否则无解》
