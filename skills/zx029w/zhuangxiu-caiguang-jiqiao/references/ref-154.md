# 55m²一居室暗卫暗厨，居住工作娱乐都有了

只有一居室的公寓，需要满足居住，工作，娱乐，最大的要求还要超级收纳，难度是有，但是一一满足。
▲原始户型就是一个大开间，一厨一卫，需要满足一间单独卧室，还得有客餐厅，还得有单独的工作台和收纳的衣帽间。其实乍看户型感觉不可能，其实只要合理规划还是能实现的。进门的厨房有点小，牺牲了卫生间空间拓展厨房，同时做了开放式设计，视觉更通透开阔。卫生间同时借用一点卧室的空间拓展空间。单独的卧室角落位置单独分割出一个单独衣帽间满足收纳。同时卧室和餐厅隔断分割保障隐私。客厅角落刚好有餐桌的功能
▲入户空间，因为右手拓展厨房，刚好形成一个凹陷区，定制开放隔板柜，进门可以随手放置包包和钥匙，同时还能兼顾书籍的收纳。进门左手空间超薄鞋柜定制满足鞋子的收纳
▲门厅进来紧挨就是原来的厨房，借用卫生间空间进行了拓展，同时做了开放式设计，解决了暗厨光线不足的问题。经典小白砖铺贴，采用黑白对比的颜色搭配，空间更有质感，简洁实用
▲进门左手超薄鞋柜布置，角落还能放置双开门的冰箱。为了分割一个单独工作台，新砌墙体，工业风的红砖效果，刚好设计异形工作台以及书架收纳
▲原来的大开间利用玻璃以及墙体隔断，分割出三个不同的区域，而且还能保持空间的通透
▲为了单独分割卧室，同时保持空间光线的通透，采用黑色玻璃隔断分割，布帘遮挡随时可以保证隐私。客厅深灰色布艺沙发搭配轻巧小圆几，空间更宽敞灵活
▲整体颜色黑白灰素雅，视觉质感极简。主灯北欧经典分子灯，局部黑色滑轨灯营造层次感
▲工业风的墙体分割，加上工业风的壁灯组合，非常惊喜的效果
▲L型的布艺沙发搭配，利用彩色圆几，抱枕以及挂画提升空间
▲卧室内部空间，为了收纳在床头上方定制吊柜收纳，靠窗户很大的隔板书桌满足工作需求。上方黑色滑轨灯满足书桌的局部照明
▲卧室看全景，空间真的不大，但是区域明确，功能齐全
▲卧室的床对面角落木色衣柜布置，满足部分收纳
▲利用卧室的角落分割出一个很小的衣帽间，无门开放设计
▲很小的衣帽架L型布局，白色平板，满足所有衣物的收纳，侧墙还有功能性的全身镜
▲拓展卫生间以后，满足了超大的定制浴柜以及镜柜，旁边角落还满足了洗衣机的放置
▲卫生间还满足了钻石形淋浴房的布局
▲定制木质浴柜，镜柜满足收纳，上下灯光布局增加层次感本期装修好物推荐
