# 装修铺瓷砖，真心不推荐亮光瓷砖7.4

关于瓷砖一直都不推荐亮光瓷砖，因为太扎眼，太突兀，太高调，看上去就会失去应有的内涵。
但是总有人，不是，总有一大部分人还是喜欢用亮光瓷砖，认为亮光瓷砖能让空间看起来更亮；其实这个是对光线的认知误区；家里光线靠的是大面积物品的漫反射，而非材质的表面是镜面效果就会变亮。
▲如图黑色的亮光砖，铺到家里，家里还有光线吗？镜面效果和家里光线没有关系，完全取决于瓷砖本身的颜色。
▲如图亮光瓷砖通铺，注意地面的倒影，不仅不美观，而且让整体会凸显出一种说不出来的廉价感
▲如果用拖把拖地每一次都会留下难看的水渍，永远清理不干净
▲如果是家里灯光多或者无主灯设计的时候，整体就翻车现场，地面倒影各种花里胡哨的影子，看起来效果就非常低廉
▲与亮光瓷砖的反光刺眼比较的话，柔光瓷砖要更有内涵，更低调，而且看上去更有档次
▲特别是靠近窗户附近，扭曲的倒影让空间视觉上显得更加凌乱
▲其实在现实生活中，大部分人接触到的都是亮光瓷砖，特别是开发商的样板间更甚，看上去亮光闪闪，浮夸的背后其实是一种审美的缺失，但是大众习惯了就很难做出改变
▲再仔细比较一下柔光瓷砖通铺的质感和内涵，不论是用什么灯具以及无主灯，不会有任何浮夸的倒影，看上去更内敛更有品位
▲同样无主灯的环境下，亮光砖和柔光砖不同角度对比，效果立马能见分晓。如果你把浮夸叫做时尚或者叫做美的话，这种比较毫无意义了
▲你如果能接受柔光砖通铺，硬装第一步已经完胜百分之八十的人了。如果你是北方地区，家里有地暖，冬季的时候，瓷砖温热，随时席地而坐，家有小孩地上爬行，温润的柔光瓷砖不仅防滑而且更环保
▲亮光砖不仅仅是光污染无内涵，拖地的水渍简直就是噩梦一般，每次拖完地都没法下脚
▲如果你把亮光瓷砖的贼亮当成是一种时尚，浮夸的美的话，也无可厚非，人的审美有时候是无法互通的；
▲现实装修里头，甚至有人把亮光瓷砖直接通铺得到厨卫地面。铺到厨房除过不耐脏稍微不防滑以外，还可以想通，但是把大规格亮光瓷砖直接铺到卫生间，简直是灾难性的，一旦洗澡的时候有洗涤品流到地面，一刻都无法站立，非常危险的做法
