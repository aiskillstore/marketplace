# 户型光线暗，怎么装修好？8.16

买房都知道，有的户型确实光线本身就暗，有的是买了房，才发现旁边高楼拔地而起，完全挡住了家里的光线。今天就光线比较暗的家庭装修方法举例说明。

▲如果光线本身暗，白天不开灯的前提下，再亮的地板也提升不了光线。所以可以从硬件和心里两方面着手解决。一给暗客厅铺上浅色亮丽的地毯，范围不要太大，目的就是用不同的色彩和质感视觉上提亮空间，二明亮艳丽的地毯让人心里敞亮，用心里暗示的方法提亮空间亮度

▲镜子是让光线明亮的法宝。并不是只有浴室才需要镜子，各种装饰镜子家里的各个地方都适合

▲客厅如果有阳台，尽量打通设计，窗帘设置到阳台，客厅尽量简洁，能引光的地方尽量不要有 遮挡物

▲房间光线不好，不要选择用深色的家具，不要选择用深色的窗帘，切勿使用无用的深色造型。墙面宜采用亮色乳胶漆，搭配局部镜面处理

▲局部镜面装饰，有反射光线的功能，合理利用效果非常好

▲卧室背景局部镜面和壁灯搭配，提升整体空间的光线

▲光线不好的区域，尽量选用透光帘或者浅色窗帘遮挡。窗户外没有其他楼体的话，完全可以用透光纱帘进行装饰

▲灯光一定要多，比如吊顶的四周射灯或者装饰用的滑轨灯，落地灯、壁灯，一切能想到的带电光源都可以提升整体居室的亮度

▲如上图，仅用主灯是照亮空间，但是台灯壁灯可以给你温馨之感，心理上提升居室亮度

▲家具木门衣柜尽量以白色浅色为主，这样视觉上整体光线会提升不少

▲局部软装色彩点缀，不仅能增加家里童趣，同时也能让人心里上为之一亮

▲能做开放式设计最好，所有和入住功能不冲突的实墙都可以拆掉，再暗的房子都可以变亮

硬件方面这些是必须的：
比如不能用木地板，不反光有污染，选用亮光瓷砖，更利用采光。

不要用壁纸，更不会反光，选用光泽度比较好的乳胶漆，不要做多余造型，尽量简单达到功能就行。

不要让家里显得很拥挤，否则再大的房子也黯然失色。
