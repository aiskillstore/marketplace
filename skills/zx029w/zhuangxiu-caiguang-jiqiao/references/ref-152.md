# 60㎡两室变一室，让家更明亮通透

再小的房子那也是家，特别是对于年轻人来说，不仅仅是有了归属，同时也是一种社会价值的体现。
▲60平有多大？除过公摊以后，仅仅是大平层的客厅大小。原有格局本来划分的就是两室户型，但是客餐厅狭小，没法满足更多功能；金厨银卫，厨房小到可怜无法施展，还是暗卫。除过满足基本功能以外，还需要在颜值上给户型做出一定的弥补，这样小户型才有自己的精彩

▲蜗居虽小也得好好设计，首先进门卧室墙体砸掉重新做了规划，满足了门口尽量多的收纳定制；
厨房窗户与卧室相通，干脆做了封堵，让卧室变得更完整。封闭厨房直接砸掉做了开放布局，同时橱柜延伸，满足洗烘机以及就餐功能；
因为不知道以后多久能更换房子，所以砸掉原有带阳台卧室以后，采用玻璃移门进行分割，平时可以是敞开式大厅以及书房，以后万一换不了房子，这里可以随时变成一间独立卧室
▲入门左手定制鞋柜满足基本收纳，白色肤感定制与木色套色，刚好与地面鱼骨地板呼应协调
▲砸掉封闭厨房，让空间豁然开朗，满足基本的烹饪需求以外，厨房敞亮很多，同时打造橱柜延伸，满足洗烘机的镶嵌，延伸吧台刚好满足两人平时的就餐
▲厨房全景布局，开放式让功能得到延伸，满足洗烘机的镶嵌，同时延伸的吧台完全满足了两人的就餐；功能和空间都变得更高级，更敞亮；原有通向卧室的窗户封闭以后，当做壁龛使用
▲浅木色定制与地板呼应一体，厨房单独采用灰色瓷砖地面防滑，同时好打理，黑色金属条让地面无缝衔接，而且与吧台以及吧凳颜色一体呼应；吧台上方颜值满满的吊灯同时满足功能和颜值
▲靠近阳台的卧室砸掉以后，采用玻璃移门分割，平时空间融为一体，让公共区域明亮放大；必要时这里可以拉上帘子单独布局卧室功能，所以隐藏床的布局就很有必要
▲玻璃移门分割，里头布帘保证隐私，右边其实是一个隐藏床，随时可以作为单独卧室使用
▲放下隐藏床，拉上帘子，这里就是一间独立的卧室；白天可以收起来，让公共区域更敞亮开阔
▲客厅很小的窗户满足采光需求，轻巧家具搭配，满足功能尽量让空间开阔
▲原木书桌可以满足平时偶尔的办公需求，刚好隐藏背后的暖气片
▲与阳台打通，纱帘让视觉更明亮开阔；阳台成品斗柜同时满足一定的收纳
▲门口卧室空间，大白墙与鱼骨地板的素雅干净，床尾定制衣柜满足基本收纳
▲空间实在太小，刚好容纳基本的双人床，舍弃一个床头柜，布置了女主的化妆台，同时可以兼顾办公；吊灯与壁灯灵活点缀，满足功能和颜值
▲非常小的飘窗满足基本功能，原有通向厨房的窗户做了封闭处理
▲很小的暗卫，采用木纹瓷砖与哑光瓷砖搭配，木质的定制浴柜，简单挡水浴帘遮挡一下
▲全景，很小，没法满足淋浴房功能，只能采用简单挡水和浴帘的形式满足功能
