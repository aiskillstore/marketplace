# 经验|把飘窗设计成书桌，漂亮又实用！

飘窗改书桌是时下流行的设计手法，更能为居室带来意想不到的效果，另外在视觉上还能增加室内空间面积。不但合理利用了飘台节省了空间，又增添时尚感。下面一起来看一下飘窗改书桌的装修参考方案吧:

这款长行的书房设计，考虑到光线的问题，把书桌设立在飘窗前，白天不用开灯阅读，晚上还可以欣赏夜空的美景，无疑是一个不错的选择哦!

很多人都喜欢躺在床上看书，但是毕竟坐在床上不能写字，各方面的不方便，如果在你的床旁有这么一个飘窗，那么可以改造成书桌的形式，在睡觉前还可以舒舒服服的进行阅读。

房间的转角是最麻烦的了，凹进去，买的成品家具又合位置，不放东西又觉得这个空间浪费了，其实可以在转角飘窗前定制一个书桌，或者是梳妆台什么的。将桌子嵌入到墙中与飘窗像融合在一起，再做些储物吊柜，可以收纳展示东西的同时还可以减少凹位的突兀感。

利用飘窗的光线，结合飘窗的凹进去的位置做个书桌的台面，再在飘窗旁边设计个半通透的书柜设计，一方面可以展示自己的收藏品，一方面掩门的书柜还可以收纳一些凌乱的物品，书柜门板采用黑色米兰千腾设计，飘窗改成书桌就是这么轻而易举和美观时尚。
