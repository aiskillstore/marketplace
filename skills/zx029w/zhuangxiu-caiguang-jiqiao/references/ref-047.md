# 没有电视墙的户型，怎么装修？7.6

有的户型格局没有电视墙，所以想要实现娱乐功能比较难，今天看看没有电视墙的户型怎么装修。

▲如图所示为了满足一个开放书房以及提升整体光线，电视墙新开门洞，此时为了满足娱乐功能，采用支架电视角落布局，虽然牺牲了电视墙但是功能没有减少

▲原有电视墙满足书柜收纳以后，同样可以采用支架电视，满足娱乐功能，而且电视墙还实现了超级收纳

▲如图没有电视墙，采用钢架悬空设计，满足一个悬空电视墙，既实现了功能同时保证空间的通透《悬浮电视墙除过高级，还有什么功能？如何施工？》
