# 75㎡两室冷感婚房，解决了无餐厅和客厅光线，还成就一个衣帽间收纳

两室婚房，想到婚房大家印象中肯定是温馨、浪漫，暖意融融，但是本套房两位年轻人不这么认为，而是根据自己的喜好去装修，并不是只为别人着想，为别人看的婚房。所以就有了这套性冷淡的黑白灰婚房。
户型：两室造价：水电7千；半包3.9万；定制3.2万
▲原始结构图。首先进门就是客厅，无餐厅空间。左手厨卫一个是刀把结构不规则，而且很小。仅有的客厅只有一个很小的窗户，虽然朝南，但是光线非常不好。对于婚房来说，这种缺点业主是无法忍受。

业主要求：
1.进门需要有足够收纳；
2.厨房需要足够操作空间；
3.卫生间希望扩大空间；
4.还得有合理的就餐空间；
5.解决客厅采光不足问题
6.要有一个休闲吧台
7.要有独立书房和衣帽间收纳

回头看看原始图纸，再看看业主的要求，完全无从下手。

▲平面设计图，经过一个月的苦思冥想，最终的设计方案终于定稿。

1.客厅与主卧互换空间，成就了客厅的超级采光；
2.砸掉原来主卧的墙体，让进门视觉光线得到完美提升，同时定制客厅书柜延伸一个吧台休闲空间
3.厨卫统一后移墙体，卫生间利用了阳台空间打通拓展空间，厨房后移墙体，成就门口的鞋柜收纳；
4.厨卫后移墙体实现餐厅的单独空间；
5.原来右手的客厅改作主卧以后，进门右手专门预留空间，镶嵌冰箱以及定制高柜收纳，弥补厨房收纳的不足；
6.原来次卧缩小以后，划分出一个书房和单独衣帽间空间，实现业主想要衣帽间的梦想

▲厨卫后移以后，留出的空间，刚好在厨卫门之间墙体垂直布局餐桌，满足全家就餐需求；厨房门口新砌墙镶嵌鞋柜，满足了进门的收纳；靠近入户门的通柜门其实是原来的烟道，采用假柜门装饰起来，视觉更完美。

▲因为餐桌刚好布局在厨卫之间，所以厨卫都采用木门的形式，关上门餐厅是一个完整的地方，避免打开卫生间门，感觉坐在卫生间门口吃饭一样，非常不舒适和尴尬

▲黑白灰简洁素雅，婚房少有的做法。黑色的餐桌，两把灰色和黑色铁艺的餐椅搭配，同时头顶黑色的吊灯时尚点缀

▲餐桌对面过道利用局部凹陷区做了黑板墙装饰，同时一个黑色细腿玄关柜与挂钟，布置一个进门的端景空间；过道上能看到衣帽间和缩小以后的书房空间

▲采用轻巧的家具布局，最大化留出合理的过道动线

▲餐厅与客厅过道处，极简黑色的吧台搭配两把同样黑色的吧椅，黑色的摇臂灯点缀照明，不仅视觉分割空间，而且成就了业主想要的休闲品酒区

▲进门过道看客厅全景，地面是柔光的大理石瓷砖，视觉柔和，而且比亮光的瓷砖更有质感，好打理；客厅是原来的主卧改造过来的，因为朝南，打开以后光线豁然开朗，整体效果远远胜于原始的结构

▲门口的全景，灰色的漫发射让空间更具质感，卧室变客厅让整体光线明亮

▲入户门右手牺牲了次卧空间，刚好布局冰箱以及高柜镶嵌电器，弥补对面厨房收纳的不足；沙发的拐角位置同样定制书柜，局部开放格展示，更生动灵活，颜色与整体协调一致

▲沙发区，采用轻巧深灰色布艺沙发，黑白配的抱枕装饰，茶几铁艺黑色与金色搭配，镂空造型视觉更轻盈，一把同样镂空的单椅，小空间弱化物体的厚重感；背景一副极简黑白画与摇臂灯时尚简练

▲卧室与客厅互换是最满意的地方，让原来昏暗的门厅以及餐厅瞬间明亮

▲全景视角，客厅无主灯布局更符合整体效果。黑白灰以及过渡色的完美呈现，局部金色元素提升空间质感以及轻奢之感

▲户型小，懂得舍得，才能让小空间发挥自身价值。缩小家具体量，满足功能的同时，让小户型也能有高大上的一面

▲原先的次卧空间，缩小以后，分割成了一个多功能房和一个小的衣帽间。多功能房整体榻榻米定制，可休闲，可储物，可作为次卧使用；靠窗户开放格和书桌兼顾；侧墙是整排的定制衣柜，满足作为次卧时的衣物收纳；局部开放格满足少量书籍的放置，同时视觉更生动；玻璃移门的配置，可以引光入室，提亮室内光线

▲原先的客厅改造成了主卧，因为只有一个朝南很小的窗户，光线不足；不过作为卧室空间，晚上使用灯光居多，缺点倒是可以忽略；主卧增加了温馨元素，采用原木色进行搭配，整体偏向暖色调

▲因为有了衣帽间，为了主卧更宽敞，采用原木的斗柜满足零碎收纳，视觉更宽敞一点

▲厨房本身就小，后移以后更小了，刚好满足洗切炒的基本功能，同样采用黑白灰色调，经典小白砖搭配白色橱柜，灰色的台面耐脏而且增加视觉层次；把原来拐角地方给了卫生间，同时新作了一个窗户，作为厨房的采光通道
