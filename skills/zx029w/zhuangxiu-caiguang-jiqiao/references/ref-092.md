# 多做一扇窗，还你一室明亮12.7

1.以前关于厨房光线暗的问题，专门有一篇勇于砸墙做窗户或者玻璃的文章，大家可以看一下《厨房光线不好？舍不得砸墙而已4.13》

2.如果房子光线不好，可以考虑多做鲜艳的颜色搭配，同时多做玻璃装饰《再小的房，玻璃成就通透大家11.9》

▲其实对于暗黑逼仄的户型，完全可以多多开窗，只要是非承重墙，都可以执行。不仅视觉上拓展空间，同时光线更充足，何乐而不为呢？

对于大多数装修讲究品质的家庭来说，这个不是太难；但是对于广大刚需房，经济紧张的前提下，往往望而却步：一是压根欣赏或者接收不了这种窗户，同时也是心疼钱大于审美的欲望

▲厨房小，虽然有窗户光线好，但是还是坚持开了另一扇窗户通向客厅，厨房里头木质台面设计，做了吧台的功能

▲再看看客厅区域，不仅空间更加灵活，空间更加开放，也符合现代家居的需求，这样才是时下的品位

▲当然厨房开窗户，木质台面制作，还可以把吧台放到外头，也是可以的，不仅光线好了，还增加了功能，更时尚了
