# 卫生间干湿分离，不是指淋浴隔断？

干湿分离不是淋浴隔断，是分离座便器和洗漱区。 干湿分离就是把座便器和洗漱区分开，而不是淋浴隔断。多少人以为干湿分离就是淋浴房玻璃隔断，这是大错特错。干湿分离的核心是把马桶和牙刷牙杯隔离，才叫干湿分离。你以为马桶冲水的瞬间没有细菌吗？长期以往所有卫生间内部都布满有害健康的细菌，但是又有多少人能做浴柜外置干湿分离而不作，借口是把空间缩小了，买房是为了生活品质，连基本健康都达不到的房子又有何用呢？首先房子是为人服务，而非房子是人的一个面子。

浴柜外置是最低标准。 客卫浴柜外置或者只有一个卫生间最好做浴柜外置，才是装修的基本价值，能做而不作，为了空间大，属于本末倒置。能做浴柜外置的干湿分离最好，这样老人不用进入潮湿容易滑倒的卫生间，而且利于健康。

三分离是洗漱马桶淋浴完全独立。 三分离是洗漱、马桶、淋浴三个空间完全独立，各自独立使用互不干扰。两个卫生间不嫌多，一个卫生间做三分离最好。

为什么必须干湿分离。 一家三口早上抢卫生间是最常见的矛盾，干湿分离后洗漱和上厕所互不干扰。卫生间潮湿，马桶细菌多，洗漱用品放里面天天被细菌包围。浴柜外置让牙刷远离马桶，这是健康底线。

干湿分离的常见误区。 第一以为淋浴房就是干湿分离，错。第二以为干区不用防水，错，干区墙面也要防潮处理。第三以为干湿分离就是加个挡水条，错，要真正隔开空间。干区灯光功能第一氛围次之，头顶主光源和镜柜上下灯条为刚需。

记住。 干湿分离分离的是马桶和洗漱区，不是淋浴隔断。浴柜外置是最低标准，三分离是最高标准。买房是为了生活品质，连基本健康都达不到的房子又有何用呢？能做浴柜外置而不作，属于本末倒置。
