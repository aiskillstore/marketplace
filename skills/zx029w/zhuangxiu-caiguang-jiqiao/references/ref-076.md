# 经验|暗卫应该这样来装修，业主必看

1、用比较亮的瓷砖
如果您的卫生间是暗卫的话，如果用比较深的瓷砖，那么，必然显得室内色调暗淡，此刻，建议您买白色的，或者比较亮的瓷砖，从视觉上先改善暗卫的不足。此处暗色砖指的的棕色，黑色等，不是彩色砖，暗卫完全可以用带色砖，让本来色暗的卫生间在开灯情况下充满活力

2、还可以做成敞开式的，彻底改善采光问题材料为钢化玻璃。这样还可以增加洗澡的情趣。不过大部分人应该不喜欢吧，主人房用用还可以，年轻人可能更加容易接受。

3、装换气扇
因为没有窗户，所以通风不是很好。那么如果任由它发展，早晚会变得很臭，又潮湿。所以通风扇是必不可少的，多少钱也要装。和吊顶的人说下就可以了，还有肯定要装浴霸，也可以帮助换气。好多业主把装修房子当成一个任务，几十万的房子都买了，卫生间图便宜装一个一百多的山寨货浴霸，呵呵，这种人，我想说一句：不要为了买房充面子了，内子都丢完了。裸身穿西装买不起裤衩，充哪门子绅士

4、买最好的坐便器
卫生间之所以臭味这么大，相当一部分原因是因为马桶盖的不严实，以及地漏做的不好。地漏就不说了，就算是明卫的家庭对地漏质量也要抓的吧。那么既然房子是暗卫了，就要吹毛求疵，从源头上断绝味道的来源。二三百一个马桶大有人在，只为了一句：我在某某城市有一套房，哈哈

5、装修不留死角，要尽量使任何地方都保持干燥。
比如说装浴霸，就要费心思了，尽量不要让浴霸有照不到的死角。这些都是潮湿的来源，而潮湿会让卫生间味道大，或者多装几盏灯。

6、如果卫暗是主人房，可以考虑改装，最理想的就是衣帽间，或者储藏室。但是千万不要改成书房，毕竟楼上人家没有改装，管道还是从你这边走的。

后记：中国人穷怕了，这几年才刚刚学会怎么去吃饱饭，可是我们顶着生存的各种压力。但是骨子里我们爱面子的性情根深蒂固。既然几十万的房子都买了，就是为了提高生活质量，而不是为了让不相干的人知道你挺有本事都买房了。而不是几十万的房子里头放一个二三百元的马桶，何必呢，小区拿两块红砖卫生间一放照样拉屎。
