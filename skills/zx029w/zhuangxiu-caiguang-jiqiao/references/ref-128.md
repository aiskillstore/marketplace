# 100㎡老房暗厅，改变采光，三室变两室黑白灰婚房

此套为小夫妻购买的二手房，做婚房使用，钟情于黑白灰色调，但是此房是暗厅，导致想要的色调和实际光线是有冲突的。
▲原始结构图。进门是厅，餐客厅一体细长条，而且餐厅客厅没有一个窗户，一旦关上所有室内门，客餐厅只能靠灯光，否则真的是暗无天日；客餐厅右边分别餐厅和厨房。客卫以及一间小卧室；客餐厅左边依次是带阳台卧室以及次卧。厨房很小，而且厨房门口就是餐厅，导致公共区域浪费很大
▲设计布局图。1.首先满足进门收纳，敲掉进门左手卧室的墙体，满足进门的收纳功能2.原来餐厅和厨房之间墙体砸掉，拓展成一个大厨房，新砌墙装上移门，满足厨房U型收纳布局3.卫生间与小卧室墙体移动拓展原有卫生间，实现单独淋浴房4.砸掉小卧室墙体与原有客厅融为一体，不仅拓展了空间，同时满足采光需求
▲未拆除之前的门口图。原来老旧装修，而且是两道门，一道老旧的铁艺焊接防盗门，朝内开还有一扇很久的木门，原始的左手墙面木门占一半，剩下就是成品鞋柜，收纳不足，导致鞋子满地堆放
▲改造之后的门口图。更换原来防盗门外开以后，腾出地方，砸掉左手卧室墙体，镶嵌鞋柜，满足进门的收纳，旁边与卧室门之间刚好布置黑边全身镜，与黑色的把手呼应，视觉极简有质感
▲未拆除之前的客厅以及小卧室。客餐厅没有任何窗户，如果不打开卧室门的话，完全没有自然光，而且原始装修采用木柱子把客餐厅分开，本身昏暗的客餐厅更加拥堵
▲新装修以后。客餐厅进门公共空间作为新的餐厅布局，客卫扩大以后网红窄边框的全景门时尚质感；砸掉小卧室以后，与原来客厅融为一体，采光得到最大化满足，地面灰色大理石瓷砖，深灰色布艺沙发搭配黑色小圆几，一副极简挂画装饰，大面积大白墙，视觉干净极简
▲新改造的客厅全景，大面积大白墙处理，砸掉厨房墙体以后大梁外露，客厅采用整体平面吊顶，减弱大梁的压抑感，无主灯视觉极简干净
▲原来客厅定制了收纳柜，平板柜门隐形把手，局部黑色套色作为展示作用，刚好直对入户门，作为进门的端景使用。为了避免视觉压抑，柜子没有通顶，局部灯带点缀，增加层次感以及温馨度
▲自然光下的客厅，虽然黑白灰基调，自然光完全满足。深灰色布艺沙发搭配黑色双圆几，黑白格子提升层次感，一副视觉纵深的挂画点缀，极简质感
▲电视墙是外移墙体以后，做了镶嵌处理，下方整体石材落地电视柜，凹陷区收纳地柜与隔板收纳，可以放一些展示饰品。窗户采用透光百叶装饰，时刻保证光线的通透
▲餐厅拆除前后对比，把原来餐厅扩进厨房放大厨房空间，把公共区域做暗厅处理，空间更大
▲新改造的餐厅全景，原来餐厅融进厨房扩大厨房空间，全景门布局，视觉更通透；黑白大理石餐桌搭配，而且空间刚好布置一个很小的岛台，进门视觉更大气
▲空调风口拉通设计，内部涂刷黑色，整体黑白灰色调极简干净
▲四把灰色的皮质餐椅与大理石岛台与餐桌非常匹配，满足全家人就餐
▲餐厅跟前的带阳台卧室，背景淡绿色突出，局部拐角涂刷，悬空的化妆台定制兼顾床头柜功能，视觉清新极简不做多余装饰
▲客厅跟前的主卧空间，背景简单灰咖色变色，木质极简的床具，清新格局床品，角落成品书桌布局
▲厨房扩大以后，统一灰色瓷砖，深色木质橱柜，因为空间大，做了一部分吊柜，采用茶色玻璃吊柜门，同样风格统一极简质感
▲未拆除之前的卫生间。空间本身小，还得容纳洗衣机，老旧的装修更显得陈旧凌乱
▲未拆除之前的卫生间。改变卫生间以后，成就了浴柜的定制，花砖背景提升视觉质感，单独的淋浴区，玻璃隔断分割，大面积灰色瓷砖，同样是极简干净，时尚现代范END
