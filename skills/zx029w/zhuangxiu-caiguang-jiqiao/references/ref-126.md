# 160㎡顶楼复式，用极致白色与木色打造简单家

让家的居住功能回到本来的状态，整体采用白色与木色完成一个极致的家，是一次尝试，也算是一种回归。
▲户型改动并不大，所以对于基本功能的设计都非常简单。一楼属于公共区域，带一间卧室，卫生间较小，就没有设计洗澡功能，满足基本使用即可；一楼的好处是有独立的电梯门厅，就省去了在室内布置鞋柜的功能；餐厨一体与客厅开放设计，来解决一层建面只有80平的尴尬，而且公摊太大，这样才能最大化放大空间▲楼上是两间卧室，而且顶楼带露台，楼梯直接通向楼顶阳光房，这样阳光可以直接倾泻而下，散射室内，这也是唯一惊艳的地方；而且楼上有休闲露台，所以平时几乎很多时候都在楼上▲有独立电梯间，省去了室内布局鞋柜的问题，门口藤编伞架布置，直对的就是进门的餐厅空间；黑色质感的防盗门与室内白木碰撞，简单直白▲开放餐厨可以让户型放大，实现光线和空间的双重完美▲入门进来直对餐厅空间，木质的长条桌满足六人同时就餐，中厨白色定制与餐厅的收纳柜一体连接，延伸空间感，同时让空间时刻保持整洁▲客厅看全景，白色与木色极致搭配，没有多余杂色，回归到最本真的状态▲餐厅看全景空间，客厅跨度太小，舍弃了传统的电视柜，直接墙挂电视满足功能即可，最简单的功能满足空间价值的最大化▲客厅极简，米色L型沙发搭配原木茶几，同样米色地毯提升层次，一副简单挂画以及木质落地灯点缀视觉空间，靠近沙发收纳柜镂空，可以满足随手书籍的收纳▲楼梯间下方储藏室满足杂物收纳，预留空间落地灯营造氛围；一楼卧室门口很小的客卫，不做淋浴满足功能即可▲一楼卧室作为老人房备用，同样简单极致，藤编椅子代替床头柜满足功能▲藤编椅子代替床头柜，可坐可收纳，侧墙衣柜满足基本收纳▲开放厨房U型，同时岛台延伸收纳，不论是功能还是视觉空间都做到极致简单▲U型布局，中间岛台延伸收纳，同时满足一个休闲吧台功能▲一楼卫生间空间非常小，舍弃了淋浴功能，定制浴柜以及马桶布局，满足最基本的功能使用▲楼梯空间，同样做到白色与木色的极致搭配，最大化满足功能放大视觉空间▲二楼楼梯直接通往露台阳光房，平时阳光倾泻而下，光影斑驳满足光线氛围▲楼上主卧同样延续纯白色，床尾木质的衣帽架满足极简功能▲床头原木化妆台满足功能，壁灯营造氛围▲主卧衣帽间，两边高柜满足收纳，通向主卫，同样白色与木色的极简干净▲次卧蓝白清新，作为儿童房备用，床头一角书桌布局，原有飘窗砸掉做了收纳柜，床尾书柜满足书籍的收纳▲二楼楼梯直接通向露台阳光房，平时阳光明媚，能照亮整个二楼休息平台▲露台空间整体防腐木铺设，作为平时绿植以及休闲场所
