# 推拉门只能开一半，11个办法让门洞开启最大化7.27

厨房门洞是恒定的，但是门做法不一样，开启空间就会不一样，今天看看哪种更合理，更能让开启空间最大化。
▲如果普通厨房推拉门，很明显再怎么努力，推拉门只能开启一扇门的事实，无法改变，此时为了让开启空间更大有什么办法？第一、三联动门解决，同样一米六的门洞的话，推拉门最大开启为八十公分，但是如果做三联动的话，可以开启空间就可以达到一米左右，就可以解决开启空间太小的问题。但是三联动门造价高，而且对门洞墙体的厚度有要求，一般在18公分左右的厚度，才能满足三联动门以及轨道的安装第二、2+0联动门解决，如图如果推拉门左右有定制柜，可以采用联动形式满足门洞的最大化开启。第三、折叠门解决。如图所示门洞尺寸固定，想要开启更大，此时采用折叠门，根据空间选择折叠方向，满足门洞空间的最大开启第四、推拉门墙体隐藏。如图所示门洞尺寸固定，一边有墙体，此时把推拉门利用墙体隐藏起来，这样就可以满足门洞的最大化开启空间第五、推拉门利用外部墙体隐藏，如图所示，采用外挂形式，让推拉门利用外部墙体隐藏，此时可以满足门洞的最大化开启第六、利用两边墙体隐藏门解决，如图门洞两边都有墙体，此时需要考虑朝内还是朝外，以不影响视觉感受和功能为准，同样可以满足厨房门洞的最大化开启▲如图利用厨房内部墙体满足移门的遮挡，此时满足开启空间的最大化，需要注意这样做会影响内部橱柜的定制第七、利用口袋门解决，同样是利用墙体满足门洞的最大化开启，只不过口袋门视觉上更美观，但是必须质量过关，否则后期维修售后非常麻烦，这个一定要慎重考虑清楚。第八、利用幽灵门解决，其实和外挂移门一个道理，只不过幽灵门可以隐藏轨道，看上去更简洁一点，需要做一定要考虑质量和造价问题第九、利用PD门解决，又能推拉又能平开就是PD门的最大特长，就可以满足门洞过小开启空间小的问题，同样需要考虑产品质量和造价问题第十、利用单扇隐藏解决，和双扇推拉隐藏一个道理，比平开门节省地方，隐藏墙体后面或者做成口袋门形式，都是可以满足门洞的最大化开启
第十一、玻璃代替墙体，实在没有办法就采用终极办法，砸掉墙体，统一采用玻璃多联动移门，此时厨房开启空间几乎可以和开放厨房媲美《开放厨房怕油烟，怕噪音，直接做玻璃房就行》
