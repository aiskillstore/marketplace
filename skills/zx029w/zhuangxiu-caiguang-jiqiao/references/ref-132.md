# 90㎡两室黑白灰装修设计，打造宽敞明亮的三口之家

‍
‍硬装简单，家越显大软装还好搭❗️小户型，🏠建面90平，套内65平，因为没有做多少定制，硬装下来12万两室一厅，客餐厅一体，开放式厨房原本的户型是一个大阳台，隔成了两个独立小阳台在客厅的阳台被利用起来做成了办公学习区另一半的阳台在卧室内，做成了一个单独洗衣房合理布局，加上简单硬装，不仅实用，还显大！从入户到阳台用了80*80cm的中灰色地砖通铺，用瓷砖同色美缝，没有过门石，地面无切割感会很显宽阔。原开发商自带的是猪肝色的入户门，但我家装修风格是黑白灰的简约风，所以装修阶段就把门换成了黑灰色。当时做了很多功课选了这款智能门锁门锁是家里的重要保障，不仅仅要安全，还要能让生活更舒心便捷。阳台垭口不是承重墙的也建议扩大、加高，把阳台内包进来，整体空间就会显大、显亮开间3.4m，客餐厅总长6.1m沙发长2.8m，地毯尺寸2*2.9m茶几直径60cm，餐桌尺寸1.4*0.8m电视墙长3.9m，幕布110寸，电视柜长2.8m双眼皮吊顶高30cm，宽25cm，吊灯60+80cm想要空间显大，砸掉一些不必要的墙体。砸掉了入户一侧的厨房墙体，做成了开放式厨房色彩要和谐，黑白灰为主色调，所有大件软装的颜色都在这三个主色中挑选，整体就清爽耐看，款式也尽量选择简约款，好搭配又不易过时。细腿造型的岩板餐桌，搭配低饱合度的橙色西皮餐椅，再加上一点点绿植点缀，可以让整体黑白灰的空间增添一点活泼的色彩~
从入户开始，用80*80cm以上规格的瓷砖通铺到阳台，不要做波导线和过门石。搭配与瓷砖同色的美缝剂，尽量让缝隙隐形。视觉上地面不被分割，空间就更显宽阔
客厅主灯选用黑色方块双层吊灯，同一空间内的餐厅搭配同系列的一字吊灯，都是可以调节高度的，好打理又不压层高

不做任何造型，不做背景墙，一个颜色的乳胶漆通刷，沙发墙挂几幅装饰画，电视墙直接一块110寸幕布上墙，简约耐看又显高级

没有任何背景墙，浅色乳胶漆通刷墙面，沙发墙挂了一幅1.2*1.8m的装饰画，餐厅墙挂画尺寸是60*80cm，整体简约耐看

更换了餐厅灯以及餐桌椅，空间更显高级了；一家人整整齐齐坐在餐桌前吃饭是一天中最美好的时光，精心烹饪的佳肴用赏心悦目的餐具呈上

小户型不要选转角沙发，直排沙发足够日常使用，我选的米白色，提升空间明亮度，让黑白灰装修也可以显得温馨柔和。铺一块地毯摆上一个茶几，客厅的氛围感就出来了

天气热的热的时候入手了无叶循环风扇对于这个颜值控来说，很容易被这种时尚简约的造型打动形似一个麦克风，摆在家里任何地方都很好看。

餐厅不大，放一张1.4*0.8米的餐桌，正好足够一家三四口使用

之前的方形吊灯有一点看腻了，最近换了这款有设计感的铬色天秤魔豆灯

新入手的洗地机，和家里的风格非常搭

厨房很小，只有4个平方显大最主要的原因是因为做了开放式厨房我喜欢“断舍离”的生活态度
整体是U型设计，做了导台，隔开了厨房和餐厅台面是白色石英石，墙面是鱼肚白瓷砖吊柜门颜色是哑光纯白，地柜门是深灰色上浅下深的搭配清爽又耐脏好打理

精简的环境会觉得人都变得清爽通透。也正因如此，最后能在我的小厨房占有一席之地的物品，一定是经过我严苛筛选的。比如使用频率很高的菜板刀具，三刀三板套组，不仅颜值高，而且轻巧实用不占空间。

厨房的懒人大神器除了洗碗机以外，还有深得我心的垃圾处理器了，平时备菜整理出来的菜渣果皮，用餐结束后的剩菜剩饭等等，如果没有及时处理掉，特别是夏天，第二天就会产生异味，甚至招来蟑螂小飞虫😨，偶尔还会漏一地菜汤，地上油腻腻的，清理起来也麻烦，所以厨房水槽安排垃圾处理器真的方便又省心，不要再用手去抠水槽里的湿垃圾，做家务真的愉快太多

大阳台一分为二一，客厅阳台一边书桌定制，满足一个办公学习的地方

阳台的另一边升降桌放置，可以满足孩子平时做作业，光线最好的地方

阳台升降桌换了方向，加了一个马路灯；它形似一个路灯，灯罩超大，光照范围广，显色指数大于97，太阳光显指100，所以光感类太阳光一样，明亮自然。

卧室面积只有10个平方，不是常规的卧室格局，原来的窗户砸掉做成了推拉门，外面是一个洗晾小阳台，做了推拉门，保证光线明亮的同时又非常实用
装修其实也很简单，面积虽然不大，但该有的都有，住着温馨又舒适

窗帘是浅棕色+白纱，做了窗帘盒，不露光也不怕压灰主灯是13头的月球灯，有点太大了，但是这个造型真的好看

纯白色衣柜，做了上下分段设计，可以收纳很多衣物，非常实用地面是铺的木纹砖，有木地板的柔和感，又耐磨抗造好打理。

墙面是通刷的乳胶漆，颜色是奶咖色调浅了一度，特别温柔恬静的调调吊顶是双眼皮，一边预留了射灯，小山丘的光打下来很有氛围感
床的另一侧放了八斗柜，上面摆点装饰画和氛围感小灯，简单又温馨

床边过道上放一个投影仪📽在我的纯白衣柜门投射画面，也还蛮不错躺在床上追剧的感觉简直太惬意了

家里最不满意就是这个9平米小卧室😣面积小，采光差，为了改善花了不少心思传统榻榻米不透气孩子长时间睡在上面不利于生长发育用无床头床架代替了榻榻米，舒适才是王道房间小但又想要收纳多，毕竟家有小儿初长成杂七杂八的东西还是蛮多的，书桌也是必需品所以做了衣柜书桌一体，实用性是大大提高了

灯光护眼效果达到教室用光标准，无频闪，而且防蓝光光线柔和舒适，长时间看书也不会累眼显色指数达到Ra98，色彩还原度高，清晰明亮太阳光的显指是Ra100，所以这样的显指相当优秀了

卫生间非常小，依旧黑白灰搭配，淋浴只能采用浴帘分割‍
