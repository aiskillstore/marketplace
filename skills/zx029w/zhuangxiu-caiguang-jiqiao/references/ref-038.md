# 越来越多的年轻人放弃淋浴隔断，背后原因很现实：省钱、安全、好打理！

现在业主只要说要做玻璃隔断，我们断然不给推荐，特别是家里有小孩的坚决建议舍弃玻璃隔断和淋浴房。如果业主不听执意而为，只好让业主自己定制，绝对不敢再碰淋浴玻璃隔断了，原因可以查看这篇《突然爆裂！致人伤……这“物品”你家也有……》所以现在年轻人也更加务实了，再也不会跟风从众了，因为不做玻璃隔断，更省钱、安全，重要的还好打理。4平方的小卫生间，不要用玻璃做隔断，用伸缩门，这样既不会让卫生间拥挤，也做到了干湿分离。2.9平小卫生间，真的是太小了，还是正方形的，没做干湿分离是很棒的决定，为了防水浴室柜用了不锈钢的，非常有质感卫生间只有4㎡，当初为了视觉上增大空间，主卫设计成了极简奶油风，整体白色调，没做隔断，看起来简洁又敞亮。入住快一年啦，依然觉得当初没做淋浴隔断是正确的选择！完全没有之前担心的发霉或者智能马桶被水浇湿坏掉的情况！事实证明，不做隔断打扫起来真的很方便，刮板一刮水就完事，不用擦玻璃不用打扫淋浴房！还是决定淋浴区不做隔断，一是卫生间做了浴柜外置湿区本来就不大，二是玻璃隔断容易留下水痕，清理卫生也麻烦相比较玻璃隔断和钻石淋浴房，浴帘更能释放空间，尤其是对小卫生间来说，浴帘➕下沉，既能隔断水花四溅，又能完全收在一边不占空间，简直是一举两得。 从美观上来看，浴帘更有一种松弛和温馨感，让家里更显自在更有人情味儿，真是非常满意了。浴室整体采用奶油微水泥瓷砖通铺，小浴室做开放式淋浴房，不做隔断整个浴室通透明亮～又显大空间一直纠结小卫生间要不要做淋浴隔断，最后决定打破常规——不做隔断，没想到真香了！4㎡的空间反而更显大，清洁也没想象中麻烦，关键颜值还超高由于面积小就没有做淋浴房，选择安装浴帘，有一说一，用了一段时间，浴帘是真香，浴帘布料高温处理过，垂感很好，洗澡不会粘在身上，收起来也完全不占地方不碍事淋浴区做一个小小的下沉，水也完全不会溅出来。 打扫卫生也很方便。再也不用为了浴房玻璃门的水渍而烦恼啦。没有做下沉时淋浴房，空间太小转不开身，准备后期安装一个淋浴折叠帘，这样给孩子洗澡也能放下她的浴盆大人也方便操作！淋浴区地面做了下沉下水很快，会稍微溅出来一些，马桶基本不会淋湿，反倒清理马桶很方便，直接高压喷枪扫射~地面的水用魔术扫把一刮就干净了，拖把己闲置。替你们试过了，卫生间不装玻璃隔断真的很香，非常好打理！但几个细节需要满足：独立下沉淋浴区，花洒位置要远一些，壁龛可以厚一点没有做淋浴隔断， 用的75*150的大砖通铺，整体浅色系看起来简单干净，做了一整面的镜柜视觉上会更显大有空间感。做了无淋浴房的淋浴区下沉，如今使用一年多，没做淋浴房，空间更通透，使用了不同瓷砖做功能分区，好看还特别。写在后面：其实普通卫生间空间小，真的没有必要人为分割，不仅难打理，而且有安全隐患，真不如做个下沉淋浴，不要任何隔断，或者最多浴帘分割，这样可以保证空间的最大化，使用起来也更好打理。
