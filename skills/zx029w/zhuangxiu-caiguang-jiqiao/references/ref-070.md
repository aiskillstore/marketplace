# 小户型必学！7种“大白墙高级用法”，不挂画也能出片！

大白墙本没有错，现在的大白墙指的绝对不是「本质白」，而是指空白墙面。小面积留白可以让空间更有呼吸空间，但是太大面积留白就会让空间单调，甚至有廉价感。所以居家环境就需要解决空白墙的问题。过去挂画的做法虽然简单，但是烂大街，千篇一律工业画风，也显得更俗气。今天看看这7种做法，不用挂画，一样可以让家里颜值高，更出片。01.斗柜+软装斗柜用来增加功能性收纳，同时加上局部软装配合，可以让大白墙更出彩。横厅常见的过道浪费，采用超薄斗柜悬空安装，视觉上更轻盈；上方做上业主喜欢的唱片架。兴趣和收纳都满足，同时解决了过道大白墙的单调。「从杂乱到高效！我是如何把横厅的长过道变成‘黄金区’的，超实用改造全分享」不要电视的电视墙，空着难看，采用黑色斗柜满足收纳，局部软装搭配，实现空间的丰满。过道大白墙复古斗柜，1米6的长度刚好，复古色调搭配精致骨骼线，单调的墙面瞬间丰富多了，台面放上爱看的书和摆件，不仅客厅颜值提升了不少，超大的收纳空间还很能装。进门有个长长的过道，装饰布置感觉乱，最后选择了一个同色系的斗柜，柜门是上翻门设计，关上可以放些杂志，打开秒变开放格，内部收纳空间也足够大，杂物、书籍、茶具都能收纳进去。不要电视的大白墙，放上九斗柜，搭配精致靠画台灯，落地灯与绿植，没有想到一下子氛围就提升了。沙发与餐桌之间的大白墙，采用中古斗柜搭配，足足有九个大抽屉的储物空间，巨能放，抽屉还带阻尼轨道，尺寸后面放咖啡机小家电也很合适。因为卧室很小，没有像传统装修一样做衣柜或者榻榻米，衣柜做在阳台外面。摆放一个六斗柜，39cm的宽度很适合小卧室。黄杨木的材质很温润，配上实木拉手，很有复古的韵味。02.照片墙/黑板墙/涂鸦墙不论是家里有小孩与否，都可以采用这种方式解决大面积大白墙的单调。毛毡板改造大白墙，价格还比柜子便宜了不少，100+成功拿下！背面自带背胶再贴上美纹纸还不伤墙面！用图钉挂上海报或者一些小装饰就很好看了，丑丑的大白墙立马变得有趣起来。网购软木板自带背胶，唯一的难点就是上墙需要把开关面板的尺寸切出来，贴完需要每个位置都用力拍一拍让他更加牢固，用一些拍立得的照片，或者打印3寸的照片用图钉固定在墙上，或者把出去玩的机票门票固定上去，觉得特别有纪念意义，整个家显的更加温馨黑板墙与软木板共同组合一个照片墙，既可以磁吸照片，还能写写画画。手机里的海量照片终于可以都安排出来啦，搞了一个照片打印机，全都给打印贴出来。鸡肋的长走廊改造成了孩子的休闲学习区！洞洞板➕全身镜：尺寸1.09m*2.12m，两块各宽54，镜子选超白银镜。玻璃白板涂鸦墙：尺寸是2m*2.12m，底部压一层镀锌板，有轻微磁力，可擦洗重复涂写。照片墙➕绘本角：尺寸2m*2.12m，高度和门套线齐平，整体不显乱。照片墙记录孩子的成长，绘本角增加阅读量，孩子非常喜欢。03.洞洞板洞洞板在新家里头使用的频率非常高，几乎很多区域都可以利用起来，兼顾收纳和装饰。「家居收纳，洞洞板收纳定制妙用」儿童房的一面墙采用洞洞板利用起来，规划成了几个区域： ①次净衣区：挂衣服、包包、帽子都方便； ②玩具展示区：儿子喜欢各种小车车，装了几个隔板，刚好用来摆他的车队；
③绘本区：买了三个带膨胀铁粒的洞洞板专用书架，放书特别牢固。 另外还能配些小夹子，夹便签纸或装饰画，孩子随手画的画都可以。玄关洞洞板+全身镜，显大又实用，全身镜上墙后，真的有空间显大，也减少了低层高的压抑感～洞洞板可以兼顾进门的挂衣和包包，实现功能，空白墙的问题也迎刃而解。「家居收纳，门厅洞洞板利用」空白墙采用洞洞板满足一个骑行墙。选择原木色，干净清爽不压抑。整面墙尺寸3.2*2.6，定制三块尺寸洞洞板，螺丝+膨胀管吃进墙体，非常牢靠。洞洞板配件和骑行装备的的摆放自由发挥，每天一进门就能看到骑行墙，真的很绝免打孔的顶天立地洞洞板，不用打孔真的很香，安装都变得简单很多，不管是装饰还是收纳都好棒！ 看腻了也可以换位置，真的很实用04.全身镜几乎每家每户都需要全身镜，既满足功能，同时又解决了家里的大白墙的单调。还在苦恼家里的大白墙，定制全身镜真香，不仅实现功能，还能放大空间。「想放全身镜，这5种办法绝了，省空间到离谱，颜值直接飙升，安利给所有人」电视墙空白墙，采用异形镜子装饰，光影效果绝了，而且满足了功能。超级移门杂志门，后面一大面全身镜，不仅解决了大白墙的单调，同时视觉上可以放大空间好几倍。05.杂志架/书架/绘本架大白墙想要功能性的话，杂志架和书架其实是最好的做法，既满足了功能收纳，同时也是一种解决大白墙的方法。家里的大白墙有救了！！ 100➕买了墙上杂志架 可以定期换专辑、版画、相框等装饰 好看又实用！根本看不腻治愈系樱桃木杂志墙完工啦， 两组90cm的温润原木架，让大白墙瞬间有了呼吸感，搭配上罗马帘真的很不错，从此家里多了个温柔的阅读角落。两个绘本架实在是“真香”，大大提高了孩子自主看书的频次，而且解决了过道空白墙的单调。大白墙改造成梦寐以求的书墙，每天窝在沙发上看书喝咖啡听黑胶，是不爱社交星人最简单的快乐。悬空书架打孔安装，实现了局部书籍的收纳，同时视觉非常轻盈，也可以作为大白墙的装饰。06.墙面收纳系统墙面收纳系统可以满足功能性，也可以兼顾装饰，对于空间足够大的墙面非常适合。家里过道这面长度近3米的空白墙，因为装了这套置物架而有了“新的生命”。配了斜隔板，可以展示好看的贴画、杂志，也可以用作照片墙，因为是金属材质，还可以贴磁吸的小物件，每层都是可以灵活调节的，由摆放的物品决定觉得白墙太单调，可以来套精巧置物架点缀一下白墙，为自己精致生活加上一块拼图07.手办墙很多人喜欢收藏手办，此时可以采用手办墙解决大白墙单调，同时得到展示功能。走廊尽头不是只能挂画，喜欢收集盲盒手办的朋友，可以考虑设计一面悬浮展示墙，搭配内嵌灯光，收纳展示两不误。网购亚克力手办收纳盒，采用免钉形式既可以悬挂，手办都非常轻，搭配了一个壁灯，空白墙解决了，也满足了收藏喜好。长过道墙面，在24非承重墙体内凹10公分，长度3米的手办柜，为小手办找到了栖息之所，收纳展示两不误。
