# 22平层高3.3米，小户型经典改造

房价这么高，而我们能买得起的房子真是越来越小了，之前50㎡就说是小户型了，可是这个数字还在下降，几年前见过一个房子，只有8㎡~房子再小也是家，生活的基本需求还要满足，所谓设计的智慧就是这么给逼出来的！

改造前平面图

▲房子是一个开间的户型，只有22㎡，好在层高有3.3m，搭出一个睡眠区和用于收纳的衣柜。进门就是厨房和卫生间，一张小餐桌搭在灶台边，看着可怜兮兮的，然后就是客厅，靠窗户做了张书桌。房子除了装饰陈旧以外，设计上也没有特别明显的缺陷。只是舒适度还是不够，就看那张小得可怜的餐桌，就没有什么生活可言。

▲改造后平面图

▲改造方案是在原设计上做了些优化，遵循的原则是：让生活更便利，空间整洁、通透，明亮。按照生活习惯把衣柜放在下面，上面做了书架；靠窗做了榻榻米；靠墙放了可以移动的餐桌，这样就可以腾出一块比较宽敞的空间供屋主做运动使用。改造后的家基本上只有白色和橡木色，简单的色调看上去整齐很多。靠窗的凹型空间正好嵌进去一个榻榻米，不仅可以当沙发使用，下面的箱体兼顾收纳，还能当客房使用。两侧的空间也没有浪费都做了收纳。

▲靠墙放了两张一模一样的长条桌，平常可以作为书桌使用，吃放的时候只要把两张桌子并在一起就变成一张完美的餐桌了，即使来了客人也不怕，能满足6~8人用餐。能有张正经餐桌吃饭，生活才算有个样子。

▲楼梯使用了钢制扶手，看起来通透多了。楼梯下面的空间也\"藏\"进去两个鞋柜和一个电视机。

▲所有的家具都靠边，就能腾出一块空地出来，看着真敞亮一点也不憋屈，屋主平常就在这儿做健身。

▲从夹层向下看，是不是很整齐，很宽阔的样子~

▲睡眠&工作区。二楼的夹层空间比较低但比较安静，所以设计了睡眠区和工作区。

▲可以坐着工作的书桌适合上面空间的高度。

▲厨房在入口处，做了I字型橱柜，与衣柜书架形成整齐的一排。

▲洗衣机和冰箱也塞到操作台下面

▲从卫生间看向厨房

▲原来的淋浴间放了浴缸，每天泡个热水澡是件多幸福的事~

▲全白的卫生间本来就很显大，镜面推拉门让空间又大了一倍~白色、镜面，小户型法宝啊！
