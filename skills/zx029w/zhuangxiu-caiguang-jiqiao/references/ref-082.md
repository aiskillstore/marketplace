# 家有暗厨，还有救吗？7.22

暗卫前面谈过，今天谈一下暗厨，其实这在现实里头属于少数，一般家里暗卫很常见，但是很少有暗厨空间，因为有天然气，暗厨不通风，怎么能保证没有安全隐患呢？一旦碰到暗厨户型，到底该怎么操作？今天详解

▲砸掉做开放式。这是暗厨最直接的解决办法，但是有的地方奇葩的是：做开放厨房不给通天然气，说是有安全隐患。够奇葩，天然气如果漏气，空间开放才能更利于浓度的稀释，才是最安全的。如果你说为了防火，就家里的普通门也没法防火呀。

如上图，因为做了开放式，如果后期真的不给通气，非常简单，做假墙，通气了再拆掉就行；上图为了瓷砖好收口做了木质的哑口套装饰

▲浅色搭配。如果不能开放布局，只能采用浅色系进行搭配，同时注意灯光的亮度《品质厨房三盏灯，你家做了几个？》

▲开窗引光入室。如图通过移动卫生间，做了明卫处理，同时采用玻璃引光入室，满足暗厨的光线

▲砸掉做开放式。小户型没有办法的办法，砸掉做成开放式，成就全屋光线
▲新开窗户。这个是不想做开放式布局的第二个选择，可以朝向光线处新开窗户，来满足厨房光线，同时可以让视觉空间更通透《采光不好，新开个窗户就行》
▲砸掉多余墙体扩大门洞。无法做开放式，也没有办法开窗户，可以把厨房门尽可能放大，做成玻璃通透的移门，尽可能引光入室，满足厨房的光线需求
▲砸掉墙体玻璃代替。如图暗厨，砸掉所有墙体，但是又不想做开放式。采用玻璃墙体分隔，解决油烟和光线问题。对于想做开放式又怕油烟，这个也是最好的办法《想做开放式厨房，又怕油烟咋办？》
▲统一浅色搭配。这个也是没有办法的办法，暗厨不敢随心所欲的装修了
▲局部引光入室。如果开大窗户影响收纳的话，可以借用吊柜和地柜之间，朝向公共区域新开很小的玻璃引光洞，满足暗厨的采光
▲灯光布局。暗厨空间如果能满足三盏灯的需求，最好全做。一是主照明灯，二是水槽上方照明，三是吊柜下方手扫灯。《厨房灯光越亮越好，你家重视了吗？》厨房窗户不闲置，直接用来收纳也不错
