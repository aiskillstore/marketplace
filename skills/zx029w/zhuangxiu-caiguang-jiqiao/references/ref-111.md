# 80㎡两室暗厨暗卫暗厅，打造童心之家

装修风格只是一个名号，怎么装取决于自己的喜好。当自己喜欢的东西都放在家里的时候，这才是自己想要的家。比如这一对年轻人，非常有童心，对卡通漫画非常喜爱，于是决定让自己的小窝也充满童趣。

▲两室刚需，进门就是客餐厅的公共区域，直对就是两个卧室空间，主卧带一个小阳台，但是无下水，没法满足洗衣机的布局；厨卫是隔壁空间，没有窗户，暗卫暗厨，而且空间极其狭小。所以需要改造空间让各个区域都能得到质的提升。

▲设计后的完成图，为了满足金厨银卫的需求，砸掉了原有厨房空间，拓展了卫生间，实现干湿分离的同时满足洗烘机的放置；同时原有墙体后推让出开放式厨房空间，满足开放式餐厨以及客厅一体化设计；主卧与阳台打通拓展整体空间，次卧作为儿童房备用，提前布局做好，以后孩子居住的话保证环保
▲为了满足收纳，利用子母门位置，从门口开始定制收纳柜一直延伸至电视墙。进门采用卡通地垫，第一眼就奠定了整体空间的风格
▲鞋柜位置镂空满足随手置物，卡通挂画充满童心
▲餐厨全景空间，整体移动原有的厨卫墙体，拓展卫生间，同时外面拓展空间以后，实现开放式餐厨一体空间。整体浅色系搭配，彩色餐椅提亮视觉空间
▲原有客厅空间受到挤压，采用很小的卡通沙发满足基本的功能，背景同样一副卡通挂画点缀
▲拓展卫生间以后实现了干湿分离，局部小白砖铺贴，侧墙同样卡通挂画点缀
▲沙发区域离开放式厨房水槽很近，采用黑色边框长虹玻璃隔断分离，防止水溅问题，同时作为空间的分区处理
▲收纳柜从门口开始一直延伸到电视墙，满足镶嵌电视以及公共区域收纳，同时双开门冰箱得以镶嵌放置
▲餐厨一体空间，墙面经典的小白砖处理，地面局部黑白花砖分区铺贴，餐桌靠近入户门位置，满足就餐同时可以作为操作台使用
▲全景空间，虽然是暗厨暗卫暗厅，通过灯光的处理，可以让空间更宜居住
▲两间卧室门关闭以后，公共区域完全是暗厅，只能依靠灯光处理，所以采用无主灯布局，视觉更简洁，灯光更匀称
▲厨房L型定制，白色简洁，满足简单的烹饪需求
▲主卧移门衣柜定制，背景粉色涂刷，搭配蜡笔小新的卡通挂画，延续童心的打造
▲主卧与阳台打通，拓展更多空间
▲原有阳台一边衣柜打造，同样满足收纳，剩余空间作为休闲角落
▲主卧阳台一边衣柜定制拓展收纳空间，剩余空间作为休闲角落，同时兼顾家里的晾衣功能
▲儿童房因为很小，靠窗两边衣柜和书柜收纳，中间简单的书桌满足学习功能，卡通床头搭配
▲实木架子床布局，下方镂空可以放置各种玩具
▲拓展卫生间以后，实现了干湿分离布局，干区白色浴柜定制，镜柜满足收纳，局部小白砖与花砖搭配，背景采用卡通花砖延续整体风格
▲湿区占用一部分厨房空间，实现了单独的淋浴区，地面黑白卡通人像花砖铺贴，右手满足洗烘机以及马桶的布局
▲黑白简洁搭配满足基本的功能性
