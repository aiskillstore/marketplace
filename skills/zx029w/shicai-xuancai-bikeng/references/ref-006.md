# 橱柜台面舍去5公分，获得更多便利12.10

台面变窄：有舍才有得

厨房舒服与否往往取决于一些小的细节设计，特别是小空间厨房，有时候一个小的细节就能成就生活的便利，让别人羡慕，让自己庆幸。

▲注意上图空间，厨房是长方形的，当时看上的双开门冰箱，按照橱柜正常60公分进深，刚好放不进去。上下楼邻居没有办法只能都放置单开门冰箱，冰箱无法严丝合缝，两边空隙很难看，唯独我们家小小的改变成就了双开门冰箱，同时做到了严丝合缝。

现在告诉你到底怎么做才成就美观的。一般的橱柜台面都是60公分，当时问了做橱柜的，几乎都说这个宽度，而我们掏了60公分的钱，只让做了55公分，仅仅牺牲5公分的宽度，所有问题迎刃而解，冰箱刚好放置，而且严丝合缝，上下邻居看了都非常惊讶---同样买房，同样的面积，为什么你家这么大呢？这就是有舍有得的结果。各位业主如果你们在装修中也碰到这个情况，千万别舍不得，认为同样掏钱，绝对不能少做橱柜，你不舍得这个怎么能得到自己想要的呢？

▲像上图的厨房格局，本来很小，L型布置，用了集成灶就是为了节省地方，这种厨房在做橱柜的时候，没有必要死搬硬套非得做60公分橱柜，完全可以做成55公分，水槽灶具完全不影响安装，而仅仅5公分的牺牲能换来比别人家更大的空间，上下邻居比较，你家空间明显要大很多。所以还是得注意小细节，有舍才有得。
