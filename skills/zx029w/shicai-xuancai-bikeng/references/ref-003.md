# 7种橱柜台面，取决于颜值和钱包8.25

都有哪七种？1.石英石 2.亚克力 3.天然石材 4.人造板木质台面 5.实木台面 6.不锈钢 7.岩板

▲石英石。这是目前市场最普及的材料，几乎大部分家庭都用这种材料。

一分价钱一分货，太多次品山寨石英石了，为了满足喜欢低价的消费者；市面上除过厚度以外，价位相差大部分在于花色上，不同工艺可以做不同花色，价位就会有高低，也成为了商家的卖点，这个需要自己权衡，颜值也是需要付费的；

厚度当然越厚越好，市面上主流是1.5公分，有2.0公分，价位是不一样的；如果经济情况不允许，推荐1.5的足够，但是切记一定要有背板『橱柜台面，石英石下垫板够结实了』

石英石优点：耐高温，耐磨；缺点：抗污能力相对比亚克力要好，但是有临界点，如果酱油辣酱倒上去，好几天都不清理，再好的石英石也渗透了。

颜色选择需要和瓷砖已经橱柜颜色整体搭配，最好不要用纯白色，太不耐脏了，刚装修完是颜值高，做饭不到两礼拜就受不了了，太不耐脏了。

▲亚克力。不是主流台面，唯一的优点就是好加工，很容易做出来各种造型，比石英石好加工；接缝处理比石英石美观；价位比石英石便宜；不耐脏，不耐划，除非你不做饭，否则亚克力台面不推荐使用。当然如果是顶级亚克力是比石英石贵多了。

▲天然石材。颜值高，非常高，价位高，土豪值得拥有；严重缺陷：辐射，不耐划，不耐高温，不耐渗透，随时可能开裂；天然石材本身就具有天然的空隙，所以开裂几率非常大，而且还得定期养护，所以一般不经常做饭的豪宅可以用，普通百姓还是算了；

▲木质台面。分人造和天然木材两种，人造板都可以用，价位不是很高，而且比天然木材更耐磨，但是厨房空间偶尔做法是可以的，普通百姓一日三餐还是算了，撑不了多久，木皮就会磨损甚至变形；天然实木价位太高，比人造板更不耐水，不防潮，更容易变形甚至开裂；如果是做吧台台面的话，可以用，厨房尽量不用，除非你不做饭。

▲不锈钢台面。只要颜值你能接受，真的不错，否则外面餐馆食堂不可能都用不锈钢台面，还是最耐用的。厚度当然越厚越好，你直接用钢板更好，只不过价位高而已。普通的不锈钢台面差不多5mm左右的，价位和石英石相差不大。越薄越不耐高温，这是不锈钢的弊端，下方大面积胶水粘接，高温会导致脱壳，局部鼓起；一定选择304的，食品安全容不得马虎。

▲岩板台面。这是目前最最理想的台面材料了，几乎没有任何台面的缺点，全身透出贵气和完美。推荐，极力推荐。但是价位非常高，产品分国产和进口，一般国产的比石英石好上百倍。

你家用什么？推荐宁愿先不买沙发，厨房做岩板台面，绝对不后悔。
