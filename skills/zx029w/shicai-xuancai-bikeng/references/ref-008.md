# 橱柜台面高低不同，不用弯腰了

比较常见的厨房台面是这样的:

表面是挺好看的，但是实用性，你看图就知道，炒菜和洗菜要求高度是不一样的，用起来就让人没那么方便了，就像下图一样。弯腰洗菜切菜，架着胳膊炒菜，用起来并不方便。

所以按照人体工程学来说，做橱柜台面的时候应该有高低之分才对，今天小编就给大家说说具体是按照哪三方面来决定。

第一:洗菜区要高于炒菜的区域
根据人体工程学的要求，洗菜区域设置得高一点，这样站立着洗菜就舒服很多了，洗多几次都不怕，相反炒菜区域低一点，就不用举着锅炒菜了，使用起来也更方便。

就好像下图一样，一般的厨房会从高到低这样划分区域，分别是洗菜、切菜、炒菜。轻松洗菜切菜，轻松炒菜。

2操作区和电器台面要分开。
在日常厨房使用时候，我们会用到一些电器，这个时候我们就有把电器区域和洗切炒区域分开了，这样便于使用，也避免小孩子出入造成的一些隐形安全隐患。
如果房子是小户型的话，不妨把洗衣机和洗碗机做成嵌入式的方式，嵌入到橱柜里面，这样会省下很多空间。

3根据身高来体验决定台面高度
其实橱柜的高度没有固定的标准，决定橱柜的高度多少，最主要是自己亲身按照自己的身高去体验一下，再来决定橱柜的高度，高低台面计算差2或3厘米，使用起来的体验而已。

不过高低台面也存在很多缺点,例如高低台面很难做成整体橱柜,美观度就没有这么好,而且高低台面缝隙之间会有渗水的风险,所以在挑选商家的时候选好一点的是必修的。
