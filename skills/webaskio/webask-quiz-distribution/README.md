# Раздача опроса

**Готовит опрос к раздаче так, чтобы потом было видно, из какого канала пришли ответы**

| Навык | Версия | Инструментов | Скачать |
|---|---|---|---|
| `webask-quiz-distribution` | 1.0.0 | 5 | [ZIP](https://github.com/WebAskio/webask-mcp/releases/download/skills-latest/webask-quiz-distribution.zip) · [страница навыка](https://webask.io/skills/quiz-distribution) |

## Что делает

1. **Начинает с меток источников.** Ссылка одна, а мест раздачи несколько. Без меток ответы сольются в кучу, и задним числом их не разделить — метки предлагаются до рассылки, а не после.
2. **Даёт по ссылке на канал.** Письмо, соцсети, мессенджер, баннер — у каждого свой адрес с понятной меткой, а не utm1 и utm2, которые через месяц никто не расшифрует.
3. **Собирает офлайн-выход.** QR-код с выбором формата, размера и логотипа — для наклейки, слайда или листовки. Проверяется до печати тиража, а не после.
4. **Закрывает доступ, если нужно.** Пароли пачками до пятидесяти штук: разным группам разные. И печатная версия в PDF или Word, когда анкету согласовывают на бумаге.

## Что на выходе

| Адрес | Меток | Паролей | Печать |
|:-:|:-:|:-:|:-:|
| **свой** | **4** | **50** | **PDF** |
| <sub>короткий и читаемый</sub> | <sub>по числу каналов</sub> | <sub>если опрос закрытый</sub> | <sub>ещё Word, HTML, текст</sub> |

| | | |
|---|---|---|
| **Рассылка по базе** | метка email-sep | ссылка |
| **Телеграм-канал** | метка tg-channel | ссылка |
| **Баннер на сайте** | метка site-banner | ссылка |
| **Стойка в зале** | метка offline-qr · QR 600 px, логотип в центре | QR-код |

> **Адрес уже разосланного опроса не меняем**  
> Прежние ссылки перестанут открываться, а рассылка уже ушла. Если адрес всё же нужно сменить, ассистент предупредит об этом до правки.

<sub>Метки на схеме — пример. Названия подбираются под ваши каналы.</sub>

## Какие инструменты вызывает

| Инструмент | Что делает | Тип |
|---|---|---|
| `export_quiz_print` | Печатная версия опроса | чтение |
| `get_answer_extra_field_values` | Значения меток ссылки | чтение |
| `manage_quiz_passwords` | Пароли к закрытому опросу | необратимо |
| `manage_quiz_qr_code` | QR-код опроса | запись |
| `set_quiz_link` | Адрес ссылки на опрос | запись |
