# Сколько ответов нужно

Два вопроса, которые задают постоянно: «уже можно делать выводы?» и «сколько ещё
собирать?». Оба решаются одним разговором.

Отвечай человеку на том языке, на котором он пишет.

## Что спросить

1. **Насколько большая аудитория**, о которой делаем вывод: сто клиентов или сто
   тысяч. Если аудитория маленькая, нужная выборка тоже маленькая.
2. **Что решаем по результатам.** «Прикинуть настроение» и «выбрать между двумя
   вариантами» требуют разной точности.
3. **Нужны ли выводы по группам.** Разрез по городам или сегментам умножает
   требования: на каждую группу нужен свой объём.

## Оценить

`get_quiz_summary` — сколько собрано сейчас, в том числе по нужным разрезам.

Практические ориентиры для ответа человеку:

| Задача | Порядок нужного числа ответов |
|---|---|
| Понять общее настроение | 30–50 |
| Назвать доли с точностью около 10% | ~100 |
| Точность около 5% | ~400 |
| Сравнить две группы между собой | по 100+ в каждой |
| Разрез по пяти сегментам | по 100 на сегмент, то есть 500+ |

Это ориентиры для разговора, а не строгий расчёт. Если человеку нужна формальная
оценка, сказать, что цифры приблизительные и от чего они зависят.

## Как отвечать

- **Если собрано достаточно** — сказать прямо: данных хватает, можно
  останавливаться.
- **Если мало** — назвать, сколько ещё нужно, и предупредить, что выводы сейчас
  могут развернуться.
- **Если по общей картине хватает, а по разрезам нет** — это самый частый случай.
  Сказать, какие выводы уже надёжны, а какие пока нет.

## Чего не делать

- **Не требовать «репрезентативности» там, где решают быстро** — опрос для
  внутреннего решения не обязан быть исследованием.
- **Не молчать про малую выборку**, если человек уже строит на ней планы.
- **Не считать брошенные прохождения** в объёме собранного.
- **Не предлагать смену тарифа и не вести на оплату.** Если упёрлись в лимит —
  назвать факт и остановиться.
