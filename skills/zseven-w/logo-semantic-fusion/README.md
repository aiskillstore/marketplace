# logo-semantic-fusion

[简体中文](README.md) | [English](README.en.md)

面向 AI Agent 的语义共形 Logo 设计与评审 Skill：让两个或更多品牌含义真正共享
同一条轮廓、笔画、负空间、字形骨架或模块系统，而不是把完整图标简单叠放。

适合设计、改版、评审和候选比较；不适合通用 Logo 生成、完整 VI、包装、插画或
没有语义共形要求的任务。工作流会先判断这条路线是否成立，并允许明确退出。
