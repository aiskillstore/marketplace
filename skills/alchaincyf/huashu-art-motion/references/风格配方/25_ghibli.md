# 25_ghibli · 吉卜力视觉家族：整体语言＋既有背景实做


## 2026-10-15 · 整体语言研究（尚待跨场景验证）

先读[跨场景风格提炼](../15-跨场景风格提炼.md)。本卡下半部是一个既有房间场景的工程经验；它证明部分水彩/赛璐璐手法可运行，不代表整个吉卜力体系，也不是新片的构图模板。

**先定范围。**《龙猫》《魔女宅急便》《千与千寻》可用于研究不同环境中的人物、手绘背景与生活动作；《辉夜姬物语》有明显不同的线条与留白组织，不能把它强塞进同一水彩背景配方。制作时选与本次内容相符的影片/作者范围，比较不同场所、光照和动作的片段，不只挑森林远景。官方[作品与场面写真](https://www.ghibli.jp/works/)可定位参考；[场面写真发布说明](https://www.ghibli.jp/info/013344/)不等于所有素材取得无限使用许可。

**可迁移的研究维度。**①角色剪影、表情与关键动作清楚，背景有自身的观察和材料细节；②角色与环境在透视、光向、接触阴影和色彩上相容，不要求二者涂成同样的水彩纹理；③生活动作有身体重心、使用器物的次序和反应；④环境运动有风、重力、接触等原因；⑤场景同时具有可居住的结构与叙事用途。以上是初始研究归纳，具体影片中不成立的部分要改范围。

**内容可变。**绿色森林、乡间住宅、少女、猫、扫帚、美食和巨大云朵都不是必备。题材可以是城市维修间、夜班交通站或虚构设备舱。不能把「生活感」等同固定慢节奏；紧张段落也需要准确行动。

**制作假设。**从本次场景的空间与光开始，角色设定独立校比例、轮廓和表情，按10号制作帧库或导入素材，再用代码合成与编排。背景的洗染只是可选材料手段，不把整张人物图乘上纸纹当作完成。现有`scenes/25_ghibli.js`可参考局部背景手法，角色与新空间必须重新设计；复杂转身或交互不能靠同一张图平移代替。

**迁移压力测试（待做）。**城市自助洗衣房里找回遗失物；无人物的自动灌溉设施启动；两位成年维修员在太空舱完成紧急修补。三者不是新模板，仅用于检验不依赖森林、少女和慢动作的迁移能力。

**回流。**每次记录影片范围、场景、采用路线、图像/动画证据、角色环境一致性与接触问题；旧结论失效先改原句。单场景通过不能替整个工作室评级。当前状态：既有背景实做保持原质量，整体视觉与表演方向仍为研究。

## 既有水彩背景示例（历史实现，不是风格定义）

> 来源：迁移测试 B（只读 skill 的独立 agent 实做，2026-10-04）。场景代码由整合后移植到 `scripts/engine/scenes/25_ghibli.js`。

实验时的文件名：`scenes/c4_ghibli.js`（约 270 行）。每帧中位 17ms，**首帧 619ms**（水彩底版缓存）；帧差 5.1%。

**水彩渲染器**
- `deform(pts, depth, amp, r)`：中点位移。每轮在每条边中点沿法向推一个近似高斯量（3 个均匀数相加），幅度和边长成比例（min(1, len/80)），每轮 amp×0.6。
- `wash(g, pts, color, {layers, alpha, amp, seed, edge, blend, fill})`：先 deform 3 轮得到基形；每层再 deform 2 轮，用 `multiply` 低 α 填充（透明颜料叠色），并以 α=edge 描一圈 1.6px 同色边。描边逐层叠加，就是颜料在边缘沉积的**水痕边**。fill 可以传渐变（天空、墙）。
- 常用参数：大面积墙 layers 5、α 0.4、amp 12；色晕 layers 3、α 0.045、amp 40（大幅变形）；木板 layers 3、α 0.5、amp 3、edge 0.14；不透明的白（窗框、桌布、云）用 `blend:'source-over'`、α 0.9–0.95。
- 墙 = 径向渐变洗染（窗边亮 `#fbf3e0` → 角落 `#dcc49a`）＋ 28 块大幅变形的透明色晕（暖黄、粉、蓝灰、浅绿交替）＋ 两角暗晕。护墙板和地板**逐块**换色调洗染。最后 `multiply` α 0.3 叠一层高频纸纹颗粒。
- 云：白色不透明圆团（16 个 puff，用 wash 画边）＋ `source-atop` 叠底部蓝灰渐变，缓存成精灵。大樟树也是精灵，绕树根转 ±0.025rad。

**赛璐璐角色 `cel(c, p, base, shade, dx, dy)`**：先整块填阴影色，再在 clip(p) 里把自身朝光平移 (−dx, −dy) 后填基色，只剩背光侧一道月牙阴影。最后描 2.4px 暖褐线 `#4a3428`。一个函数就是吉卜力式的两色赛璐璐。

**母题动画**
- 白纱窗帘：两幅，下摆鼓起 `q²·(90 + 70·gust)`，gust = 0.55 + 0.45·sin(3.2lt + 相位)，再叠 `sin(7lt + 6q)` 小波纹；3 层半透明 wash，固定种子，所以边缘不沸腾。
- 窗外 360 根草叶：风是一阵一阵的，`wind = 0.5 + 0.5·sin(3.1t − 0.018x)`，相位沿 x 推进，看得出一道风浪扫过草坡。
- 云飘 22–30px/s；树冠轻摇；墙上 34 个 komorebi 光斑（`screen` 暖黄径向渐变，位置用 noise 漂，亮度 `sin(5t + 1.7i)` 闪）；桌上雏菊点头；少女长发被风吹向右后（7 点 smooth，wind 推动）；红蝴蝶结飘带抖动；桌布垂边摆动。

**角色**：长金发＋大红蝴蝶结（致敬魔女宅急便，不复制角色）、青色长裙＋白围裙＋白袖口；猫是暖橙＋米白赛璐璐。背景里靠墙的扫帚是彩蛋。
**角色的水彩填色**：审片说「背景像，人物不像（扁平矢量）」。把角色先画进离屏 L，另起纹理层 M（纸纹颗粒 α 0.8 ＋ 40 块透明色晕 `charBloom`，α 0.1、amp 16），M 用 `destination-in` 按 L 的剪影裁掉，再以 `multiply` 叠回画面。线色从 `#4a3428` 调软到 `#6a4a38`。
**窗帘**：审片说不飘。gust 频率 3.2 → 5.4，鼓起 `q²·(60 + 150·gust)`。

**坑**
- 色晕 α 0.07×4 层、颗粒 multiply 0.5 时，墙面像发霉的旧羊皮纸。吉卜力的房间是亮的：色晕 α 降到 0.045×3 层，渐变整体提亮一档。
- 第一版用两个矩形 wash 拼墙（右侧更暗），x≈1100 出现硬接缝。暗部要用大幅变形的多边形（amp 60），不能用矩形。

**仍可改进**：人物还是平面，可以加吉卜力式的发丝高光块；地上的光斑里可以加窗帘影子的流动。
