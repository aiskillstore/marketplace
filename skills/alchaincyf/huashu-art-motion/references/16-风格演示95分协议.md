# 16 · 风格演示协议：从「受启发的扁平插画」到「一眼认得出是谁的画」

何时读：新做、重做任何一个艺术风格的演示场景（`scenes/<id>.js`），或派 agent 做的时候把本页路径给它。15 号管「怎么研究一个风格、怎么迁移」，本页管「演示做到什么水平才算数、怎么一步步做到」。

## 为什么 2026-10-15 新增的 17 个演示几乎不可用

2026-10-16 把它们渲成静帧并排看，又拉了公版原作对照，查出五个根因（17 个里绝大多数符合；45 雷诺阿是外部位图＋网格变形、44 带帷幕，不是扁平矢量块，但同样缺原作锚定和媒介层）：

1. **没有人看过原作。** 配方卡只有文字描述和馆藏链接，做的人（agent）凭印象画。结果是大部分图像同一个现代扁平插画师换了套色板：形是干净的矢量块，风格只剩「调色板＋一层噪点」。
2. **卡片措辞把锚点也拿掉了。** 「不凭单幅名作概括」「构图不搬用」本意是防抄袭，实际变成「不许对着原作做」。该防的是搬名作的人物和坐标，不是不许学笔法、材料、色彩关系、人物造型逻辑。
3. **没有「媒介」这一层。** 老标杆（梵高 09、水墨 17）强在把画面过一遍真实的画材：流场笔触、飞白、墨晕。新场景 35–70 行，只画形，不过画材。
4. **同一个题材套所有风格。** 洗衣机、水车、修机器反复出现（这轮重做也没完全避开：38 与 47 都有「木箱／载货」、51 又用了汲水轮——47 已改成麻袋，余下的列入进度表待改），风格自己的叙事逻辑（马远的一角、细密画的满铺、高更的裁切、乔托的视线）全被抹平。
5. **没有分数门槛。** 自检只有 qa 的技术项（能渲、确定性、不闪），没人拿着原作问「像不像」，所以 6 秒能跑就算交付。

## 协议（按顺序，每一步有产物）

### 1. 原作锚定

```sh
uv run <skill>/scripts/analyze/fetch_reference.py --out <项目>/参考/<风格> "艺术家 作品A" "艺术家 作品B" "艺术家 作品C"
```

至少 3 幅**不同作品**（15 号的口径）。脚本拉维基共享资源的公版图，存本地，抽主色板，出接触表。然后**真的看这张接触表**，写下：

- 5 条签名特征，每条分「必须有／加分／禁忌」。例：马远——必须有：一角构图、大面积留白、斧劈皴；加分：垂柳、渺小的人看向空处；禁忌：满幅填充、彩色鲜艳。
- 主色板（取脚本抽出的色值，写明明处偏什么、暗处偏什么）。
- 这种画在现实里是怎么做出来的（刷、刻、描、涂、贴）。那个物理过程就是渲染器的规格。

### 2. 题材按风格自己的逻辑重构图

不搬名作的人物和坐标，但学它**组织画面的方式**：马远留白＋一角；细密画把地面竖起来满铺、建筑切开；高更裁切前景、斜线分割；乔托用视线把人物咬合；印象派天占一半、水把岸拖成碎笔。写一句「这个风格的构图规则」，再按它给新题材定布局。**同一个题材不许套第二个风格。**

### 3. 画「干净的形」，再过「媒介通道」

禁止在扁平矢量上叠噪点就算风格。场景分两层：

- 形层：把物体、人、空间画干净（可以是 Canvas 路径、离屏画布）。
- 媒介层：用 `lib/medium.js` 或老库把形层过一遍真实画材。

| 通道 | 做什么 | 用在 |
|---|---|---|
| `MEDIUM.broken(src, o)` | 重画成一笔一笔的弯笔，明处偏暖暗处偏冷 | 印象派（西斯莱、毕沙罗、瓜尔迪、雷诺阿） |
| `MEDIUM.fresco(c, plate, o)` + `MEDIUM.plaster` | 色粉被石灰吃进去＋灰泥颗粒、针孔、接缝 | 湿壁画（乔托、皮耶罗、拉斐尔） |
| `MEDIUM.silk` + `P.brush` / `P.inkWash` | 绢纹、飞白、墨分五色 | 水墨（马远） |
| `MEDIUM.flat(c, path, fill, o)` | 掐丝珐琅：同色块里有顺笔向的短条＋粗而不均的深色轮廓 | 高更、综合主义、彩绘玻璃 |
| `MEDIUM.figure(c, o)` | 有体量的着衣人物：袍、披风、褶、视线 | 壁画、细密画、平面叙事类 |
| `MEDIUM.outline / hatchFill` | 变宽线、排线 | 木刻、铜版、细密画暗部 |

库里没有对应通道时，写一个通道函数进 `medium.js`，不要把它写死在某个场景里。

### 4. 一帧先行，并排对照

先出静帧，不先做动画。

```sh
uv run --with playwright python <工程>/render.py --film style_studies --solo <id> --stills 3 --no-counter --out 渲染/<id>
uv run <skill>/scripts/analyze/side_by_side.py --ref 参考/<风格> --frame 渲染/<id>/t003.00.png --out 对照/<id>.jpg
```

「一眼认得出是谁的画」只能拿着这张并排图回答。

### 5. 让画活：用风格自己的运动逻辑

主动作＋2 个母题循环（08 号第 3 条）。风格自己的动法：墨随风、笔触在呼吸、水面把倒影拉碎、壁画几乎不动但视线与交接在动。不要所有风格都用同一套淡入淡出。

### 6. 打分，门槛 80，最多两轮

| 项 | 分 | 怎么判 |
|---|---|---|
| 签名命中 | 35 | 对照第 1 步的「必须有」逐条打钩，缺一条扣 7 |
| 媒介可信 | 20 | 放大 1:1 看：是真画材还是矢量加噪点 |
| 构图与叙事 | 15 | 是不是用了这个风格自己的组织方式，事件是否一眼看懂 |
| 人物与物体造型 | 15 | 有没有重量、有没有关系；一眼幼稚或像贴纸就低于 8 |
| 动态 | 10 | 活而不闪，动在事件上 |
| 技术 | 5 | qa 的确定性、框景、耗时 |

**两道一票否决**：签名命中低于 25；人物或主体一眼幼稚（涂鸦感）。AI 只判事实项，品味项（构图好不好看）留给花叔，自评分只作排序，不写成「已达标」。两轮后仍低于 80 就把状态写成研究配方，把卡住的点写进卡的「仍可改进」，不登记为实做。

**自评会虚高。** 2026-10-16 这批的自评比独立审查平均高约 10 分（最多 17 分）。所以：分数表必须带分项分和签名清单；独立复核分写在自评旁边，以较低者为准；进度表的「现在的短板」栏里只要出现一票否决项，状态就不能写「完成」。

## 人物的规则（这是新增风格里最容易崩的一环）

这一节与 SKILL.md 窄桥的人物规则**合并为同一条**，以此为准：

- **一般风格**：真人／本人／拟人角色走 AI 生帧＋抠图（B/C 两法），代码只管位置、换帧和材质；没有生图能力就只出手和背影。
- **窄例外（明确选择的平面叙事类，允许代码画人）**：37 Rick & Morty、52 南方公园式剪纸，以及 2026-10-16 重做的壁画／细密画／综合主义演示（38 乔托、48 高更、51 波斯细密画）。这三个是**研究级演示，不是交付成片的角色方案**：交付片里要出现需要被观众认同的主角时仍走 B/C。
- 例外里的人也要有重量和视线：眼珠朝向对方、手去够物体、衣褶按受力走。涂鸦式的圆头加药丸身体不合格。
- 做不好的人物不要放大：缩成远景、背影，或让前景人物被画框裁掉。
- 不借具名角色的服装配色组合（52 已因此换掉青绿帽配浅绒球）；题材也别整个照搬原作的片头构图。

## 已知的坑

- **拉回来的原作必须看接触表核对**：搜索会混入地图、现代照片、博物馆墙上带金框的翻拍（42 瓜尔迪的第三条是现代教堂照片，47 的第三条是带框翻拍，50 的第一、三条是同一幅《山径春行》的原图和调色版）。`fetch_reference.py` 只做近似去重和取中央 80% 抽色，认不出「这是不是这位画家的」「是不是三幅不同作品」，这两件事靠人看。作品名写进场景头注释之前，先对着接触表确认。

- 先画「形层」再重绘，**重绘用的画布要在本地坐标里画**（如船），不要整屏重绘每帧，否则慢。船、人这类小动态：画到小画布 → `MEDIUM.broken` → 贴回。
- `drawImage` 九参数版里 `sx+sw` 超出源图宽度，超出的那段就是空白；天空漂移用 `sx = t*速度` 且源图要比舞台宽（47 的天宽 2600）。
- 边缘缺口小圆点有两个来源，都已修：`M.broken` 的底图现在外扩 14px 再糊；水面逐行位移时目标宽度要加宽（`dx-24, W+48`），不然位移出来的两端会露出下面的底色。
- 马远类水墨：垂条要成簇、弯、长短不一，等距竖线读成栅栏。人物一律走「背影＋一笔衣纹＋留绢」，不填满。
- 高更类：形一律圆、不用折线；折线人物读成表情包。
