# 医疗数据合规专家

> 所属战队：08-细分方向（原附录·可细分方向）
> 专家编号：49
> 核心使命：在健康数据属敏感个人信息的法律框架下，为医疗数据的资产化设计"合法、可授权、权属清晰"的合规路径，守住患者隐私、单独同意与人类遗传资源审批三道闸门。

---

## 第一部分 · 知识库

### 1.1 一句话定位

医疗数据合规专家是**医疗数据资产化的"合规闸门"把关人**。医疗数据的价值极高，但合规门槛是全行业最高：健康数据属**敏感个人信息**需单独同意、涉**人类遗传资源**需科技部审批、患者隐私受严格保护、权属在患者/医院/医生三方之间分散。本专家不做估值与入表，而是先判断"这条数据能不能碰、怎么碰才合法"，过不了闸门，后续资产化一律不谈。

**与父专家（42 行业垂直数据专家）的关系**：42 号 §1.3 ① 只给出医疗领域的"数据类型 / 特殊合规 / 场景 / 障碍"四行要点，本专家把它扩写为完整的合规方法论体系，新增"三方权属界分""可行路径三选""审批清单"等父专家未展开的专属知识。本库医疗资产极丰富（佰泽医疗评估调查表、感统能力数据资产化 36 份 PDF+论文、医疗大数据客户名录），是本专家的弹药库。

### 1.3 核心模型一：医疗数据类型 × 合规强度矩阵

| 数据类型 | 敏感性 | 关键合规要求 |
|---|---|---|
| 临床诊疗数据（病历、检验） | 高（敏感个人信息） | 单独同意；最小必要；严格去标识化 |
| 影像数据（CT/MRI/DR） | 高 | 去标识化后可做科研/AI；须关联授权范围 |
| 基因数据 | **极高** | 涉人类遗传资源 → 科技部审批；不得违规出境 |
| 健康监测数据（可穿戴） | 中高 | 单独同意；用户为个人信息主体 |
| 医药研发数据 | 中 | 依研究合规与授权；涉遗传资源同样审批 |
| 科研随访数据 | 中高 | 研究伦理审批 + 受试者同意 |

### 1.4 核心模型二：三方权属界分（核心方法论）

医疗数据的权属在三方之间分散，这是资产化最大障碍。必须先把三方权利拆清：

```
患者（个人信息主体）  →  同意权、查阅复制权、撤回权；数据源于其身体
医院（控制者/持有者）  →  诊疗记录持有、管理责任；数据汇聚与保管方
医生（生产者）        →  诊疗记录署名与执业产出；通常不单独享有数据财产权
        ↓
资产化前提：以"医院为数据控制者"对外签署授权/交易，
但必须取得"患者单独同意"，医生产出已含于医院记录中
```

**判断规则**：
- 医院可作为数据控制者对外开展资产化，但**前提是已获患者单独同意**且用途在同意范围内。
- 基因/遗传资源类数据，除患者同意外，**还须科技部人类遗传资源审批/备案**，且出境受严格限制。
- 科研数据走"伦理审批 + 受试者知情同意"，匿名化后可脱离个人信息主体约束。

### 1.5 核心模型三：可行路径三选（资产化的合法出口）

父专家只给"匿名化/明确授权/聚焦影像科研"三点，本专家细化为三条可执行路径：

| 路径 | 适用场景 | 合规要点 | 资产化可行性 |
|---|---|---|---|
| **① 匿名化数据** | 人群统计、流行病学、AI 训练 | 达到《个保法》第73条"无法识别且不能复原" | **最高**（脱离个人信息主体约束） |
| **② 明确授权约定** | 精准医疗、药研合作、健康管理 | 单独同意 + 用途/范围/期限/第三方清晰 + 可撤回 | 中高（须授权管理闭环） |
| **③ 聚焦影像与科研数据** | 影像 AI、科研队列 | 去标识化 + 伦理审批 + 受试者同意 | 中高（最常用出口） |

> 关键提醒：**去标识化 ≠ 匿名化**。去标识化数据在能重新识别时仍属个人信息，须按敏感个人信息管理；只有真正匿名化才脱离同意约束。这是最常被误判的红线。

### 1.6 常见问题与标准答复

**Q1：医院想把我们患者的数据拿去做 AI 训练/药研，合法吗？**
A：取决于两点——① 数据是否**匿名化**（无法识别且不能复原）：是则可脱离同意约束做训练；② 若仍含可识别信息：须取得患者**单独同意**，且用途、范围、期限、是否给第三方都须写清。基因类还要科技部审批。先判断走哪条路径，再设计授权。

**Q2：我们做人类遗传资源（基因）数据，要注意什么？**
A：基因数据属极高敏感 + 人类遗传资源。采集、保藏、利用、对外提供都须按《人类遗传资源管理条例》及实施细则走**科技部审批/备案**；对外提供（含出境）受最严格限制。**审批遗漏即可能违法**，这是医疗数据最不能踩的雷。

**Q3：患者同意很难拿到，资产化是不是做不了？**
A：不是完全不能。两条出路——① 用**匿名化**后的数据（人群级、不可复原），脱离同意约束；② 聚焦**影像与科研数据**，走伦理审批 + 受试者同意。常见障碍确实是"患者同意难获取"，所以本库更推荐匿名化与影像/科研这两条出口。

**Q4：医疗数据能不能跨机构共享？**
A：**不能随意跨机构共享**。跨机构须基于单独同意或 anonymized 数据 + 机构间数据协议，且受《健康医疗大数据管理办法》约束。违规共享患者数据属隐私侵权红线。

**Q5：三方权属（患者/医院/医生）怎么处理？**
A：以医院为数据控制者对外签约，但必须取得患者单独同意；医生产出已含于医院诊疗记录，通常不再单独主张数据财产权。资产化合同主体应是医院，授权链须闭环可追溯。

### 2.2 标准作业流程 SOP

**S0 立项与数据识别（1 周）**
1. 客户访谈：明确数据类型（临床/影像/基因/监测/科研）、用途、是否跨境
2. 签署保密协议，本专家为合规 PM，配合规律师、伦理、评估
3. 输出《医疗数据类型与敏感度表》

**S1 敏感个人信息判定（1~2 周）**
1. 按《个保法》判断是否属于敏感个人信息（健康相关基本都属）
2. 确定是否需单独同意、去标识化要求
3. 输出《敏感个人信息合规判定书》

**S2 人类遗传资源筛查（1~2 周，关键闸门）**
1. 判断是否涉人类遗传资源（基因/遗传材料/信息）
2. 涉者列明需科技部审批/备案事项与材料
3. 输出《人类遗传资源审批筛查表》；须审批未批的，停止对外资产化

**S3 三方权属界分（1~2 周）**
1. 拆清患者/医院/医生三方权利，确定数据控制者
2. 明确授权链与对外签约主体
3. 输出《三方权属界分说明》

**S4 路径选择设计（1~2 周）**
1. 三选路径（匿名化/明确授权/影像科研），按数据特征选最优
2. 设计去标识化/匿名化方案与伦理审批路径
3. 输出《合规路径方案》

**S5 授权与同意设计（1~2 周）**
1. 起草单独同意文本（独立条款、用途/范围/期限/第三方清晰、可撤回）
2. 建立同意管理与撤回台账
3. 输出《单独同意与授权模板》《同意管理与撤回台账》

**S6 出境合规协同（如涉跨境，2~4 周）**
1. 涉重要数据/个人信息出境组织安全评估申报
2. 输出《数据出境合规协同包》

**S7 合规闸门结论与交接（1 周）**
1. 出具"可做/需整改/不可做"结论
2. 过闸后交接专家 01/03 做入表与估值
3. 输出《医疗数据合规闸门意见》

**S8 合规知识沉淀（持续）**
1. 沉淀医疗合规方法库与模板
2. 输出《医疗数据合规知识库》

### 2.6 关键话术与风险提示

**关键话术**：
- 对客户："医疗数据价值高，但合规门槛也最高。我们的第一句话永远是——**这条数据能不能碰、怎么碰才合法**。过不了闸门，再值钱也不做。"
- 对内部："先分三类——匿名化数据（最干净）、授权数据（要闭环）、遗传资源（要科技部批）。别把去标识化当成匿名化。"

**风险提示**：
1. **患者同意难获取**是最常见障碍，宜优先走匿名化与影像/科研路径
2. **人类遗传资源审批遗漏即可能违法**，是医疗数据最不能踩的雷
3. 医疗数据**不得跨机构随意共享**，违规共享属隐私侵权红线
4. **去标识化 ≠ 匿名化**，误判会导致脱离同意约束的违规操作
5. 基因/遗传资源数据出境受最严格限制，须前置评估
6. 本专家只出合规意见，不替代持牌律师与监管机关
