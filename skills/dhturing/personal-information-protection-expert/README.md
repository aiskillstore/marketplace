# 个人信息保护专家

守住数据资产化中最硬的一条红线——含未合规处理个人信息的数据一律不能入表。盘点、审查、评估、去标识化，四步把红线变通道。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **个人信息盘点（C1）**：按一般个人信息 / 敏感个人信息 / 不满 14 周岁未成年人信息三分类，记录收集场景、字段、来源、用途、存储位置与共享情况。
- **合法性基础审查（C2）**：按个保法第 13 条逐项确认六种合法性基础，核查同意的取得方式与留证。
- **告知同意审查（C3）**：核查六项告知内容、自愿明确、单独同意（五种情形）、可撤回与禁止捆绑。
- **敏感信息专项（C4）**：识别生物识别、医疗健康、金融账户、行踪轨迹等敏感类别，落实单独同意、书面同意与必要性告知。
- **影响评估 PIA（C5）**：对敏感信息处理、自动化决策、委托处理、对外提供、出境五类情形开展影响评估。
- **合规审计（C6）**：按《个人信息保护合规审计管理办法》八个方面出具审计清单与审计报告，关注如超 100 万人的触发门槛。
- **去标识化 / 匿名化（C7）**：去标识化用假名化、泛化、抑制、差分隐私；匿名化用 k-匿名、l-多样性、t-接近性，并验证可复原风险。
- **权利保障（C8）**：建立查阅复制、更正补充、删除、可携带四类权利的响应流程。

## 使用示例

- 我们的客户数据准备入表，请先帮我做个人信息盘点和合法性基础审查，明确哪些字段属于敏感个人信息、哪些必须单独同意，并给出可行的去标识化或匿名化方案。
- 请审查我们 App 的隐私政策和同意弹窗：告知是否覆盖六项内容、有没有默认勾选或捆绑授权、五种需要单独同意的情形是否都做到了，并给出整改清单。
- 我们处理个人信息的规模已经不小了，请说明《个人信息保护合规审计管理办法》的审计触发门槛、频率和八个方面审计内容，并给我一份可执行的审计清单。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\personal-information-protection-expert/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r personal-information-protection-expert.zip personal-information-protection-expert/
```
