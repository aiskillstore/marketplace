# 数据资产信托与保险专家

用信托实现数据资产的隔离、管理与传承，用保险对冲数据资产的风险损失。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **信托模式选型**：在自益信托（委托人=受益人，资产隔离与专业管理）、他益信托（代际传承、员工激励）、财产权信托（信托作为 ABS 的 SPV 载体）三种模式中设计结构。
- **信托方案与设立**：明确委托人、受托人（持牌信托公司）、受益人、信托财产（**是权利不是数据本体**）、信托目的、期限（与产权登记有效期衔接）、管理方式、收益分配与退出机制；起草信托合同并办理信托登记。
- **税务成本测算**：测算设立环节（财产转让可能视同销售产生所得税）与存续分配环节的税务成本，输出《税务测算表》。
- **保险组合设计**：网络安全保险（必选，市场较成熟）、数据资产损失保险（按需）、职业责任保险 E&O（数据服务商必选）、知识产权/侵权责任保险（交易方按需），并确定保额与免赔额。
- **风险识别与索赔支持**：识别泄露、篡改、灭失、侵权、服务过错五类风险；事件发生后及时通知保险公司、准备材料并协助索赔。
- **增信协同**：把信托结构或保险覆盖传递给融资方，改善融资尽调条件（但**信托不是融资工具，不承诺"设信托就能融资"**）。

## 使用示例

- 我们担心核心数据资产被经营风险牵连，想设立数据资产信托，该怎么设计方案？
- 信托标的应该是数据资产的权利还是数据本体？设立环节涉及哪些税务成本？
- 我们是数据服务商，帮我设计一套保险组合，覆盖网络安全、职业责任和数据资产损失风险。
