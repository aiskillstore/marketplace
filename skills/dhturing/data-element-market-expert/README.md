# 数据要素市场专家

看懂数据要素市场的大盘与趋势，为战略决策与客户沟通提供市场层面的判断依据。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **市场扫描（C1）**：按月扫描交易所动态、企业公告、政策动态与创新模式，输出《市场动态简报》。
- **竞争分析（C2）**：按细分领域分析竞争者定位、优劣势、客户案例与定价模式，输出《竞争格局分析》。
- **案例研究（C3）**：研究成功与失败案例，提炼可复用经验，注意幸存者偏差。
- **趋势判断（C4）**：汇总政策、交易、融资、技术四类信号，提炼五个趋势判断（确权→用权、场内→场内+场外、交易数据→交易产品、单点→全链路、流通→金融化）。
- **机会识别（C5）**：结合趋势与自身能力识别机会，判断服务层、垂直行业深耕、金融化三个高价值方向。
- **市场规模测算（C6）**：自上而下与自下而上双向交叉验证。
- **模式验证（C6）**：用重复客户、正毛利、可复制三个标志判断模式是否真正跑通。
- **战略输入与客户沟通（C8/C9）**：为战略决策提供市场依据，为客户提供市场视角与行业数据。

## 使用示例

- 请帮我判断一下当前数据要素市场处在哪个成熟度阶段，并基于四层市场结构和五个趋势判断，指出未来三年最值得卡位的环节和理由。
- 我们有几类数据资产化服务想做，请帮我判断哪些模式算真正跑通了，用重复客户、正毛利、可复制这三个标志逐项评估，并说明市场规模测算的方法与假设。
- 我想跟客户讲清楚数据资产化不是尝鲜而是趋势，请给我一份能支撑说服力的市场证据清单：该引哪些交易所动态、行业白皮书和入表案例样本。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-element-market-expert/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
