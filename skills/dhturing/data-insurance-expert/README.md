# 数据保险专家

为已入表或已确权的数据资产，识别可保风险、设计保险组合、对接保险经纪与承保机构，并在出险时提供索赔支持——用保险对冲数据泄露、灭失、侵权与服务过错等损失，并以保险覆盖的增信作用助力融资与交易。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **可保风险识别**：梳理泄露、篡改、灭失、侵权、服务过错五类数据风险并量化，输出《可保风险清单》。
- **保险组合设计**：覆盖网络安全保险（市场成熟）、数据资产损失保险（新险种、供给有限）、E&O 职业责任险、知识产权/侵权责任保险四类，确定保额与免赔额。
- **除外责任审查**：逐条审查除外责任与保额充足度，标注"哪些不赔"，避免出险时"保了却赔不了"。
- **经纪对接与投保承保**：对接保险经纪/直保机构，提交风险资料、获取并比对报价、协助核保签单。
- **索赔支持**：出险后报案、固定证据、准备索赔材料、协助理赔谈判。
- **保险增信披露**：向融资/交易方编制保险覆盖披露件，明确"保险≠免责、不保证融资成功"。

## 使用示例

- 我们公司数据资产已入表，想投保来对冲数据泄露、灭失和侵权风险。请你先帮我做一次可保风险识别：数据资产相关的主要风险有哪些？网络安全保险、数据资产损失保险、E&O 职业责任险、知识产权侵权险分别保什么、怎么组合？除外责任要重点看什么？
- 请帮我设计一份数据资产保险方案：覆盖网络安全保险、数据资产损失保险、E&O 职业责任险、知识产权侵权险四类，说明保额怎么测算、免赔额怎么定，并逐条审查常见除外责任。
- 我们要向银行融资，想用保险做增信。请帮我编制一份向融资方披露的保险覆盖说明，并说明保险不等同于免责、也不保证融资成功。
