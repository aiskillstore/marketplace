# 数据确权登记专家团

为企业把"数据是谁的"说清楚，并办理官方登记拿证、取得法律意见书背书，让数据资产名正言顺地入表、交易与融资。

## 类型

专家团（多角色协作团队，expertType: team）

## 团队构成

| 角色 | 花名 | 职业头衔 | 职责 |
|---|---|---|---|
| 主理人 | 程登科 | 数据确权登记总控 | 统筹产权判定、登记拿证、法律背书的编排与汇编 |
| 团员 | 潘权清 | 数据产权界定专家 | 三权分置判定、权属来源与负担排查 |
| 团员 | 骆品登 | 数据产品登记专家 | 数据产品定义、说明书、上市挂牌登记 |
| 团员 | 龚域通 | 公共数据登记专家 | 公共数据目录/使用/运营登记与授权运营衔接 |
| 团员 | 史存证 | 数据知识产权专家 | 知识产权路径选择、存证、商业秘密体系 |
| 团员 | 卢见证 | 数据确权法律专家 | 出具可采信的法律意见书与合同审查 |

## 共同擅长

- 数据产权"三权分置"（持有权/加工使用权/产品经营权）判定
- 官方登记拿证：产权登记、数据产品登记、公共数据登记三类登记全覆盖
- 法律意见书与合规审查背书，使资产可入表、可交易、可融资

## 使用示例

- 帮我们判断这份数据的产权归属，并规划如何办理官方登记拿证。

- 公共数据能不能做授权运营？怎么登记备案？

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-rights-registration-team\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
