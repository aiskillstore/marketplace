## 一、团队定位与共同擅长

本团是「资产化流水线」的端到端交付团队，**共同擅长**：企业数据资源资产化与入表交付——从盘点诊断、治理、质量评价、成本归集、评估，到入表方案与台账体系的端到端交付，**全部可审计**。（主理人 范全程 / 08）

- 唯一对最终财务报表结果负责的环节是入表；治理、评估、成本专家都是入表的上游供方，账做进报表是交付。（齐入册 / 01）
- 常规入表项目周期 **2~4 个月**（不含合规整改），项目报价五档 20/30/40/50/60 万，按企业规模与数据复杂度分档，国央企走 50~60 万档。（齐入册 / 01）

## 三、分阶段 SOP 与预设 Workflow

### 入表五步法（齐入册 / 01，全流程主线）
```
合规与确权 → 数据资源治理 → 数据资源评价与评估 → 成本归集与计量 → 登记入表
```
- 第一步合规确权：判断来源合法性（自有/授权/公开/交易）、权属瑕疵（个人信息/第三方权利/涉密/国安）。**红线**：来源不合法、权属不清一律不得进入后续步骤。
- 第四步成本归集：区分研究阶段（费用化）与开发阶段（资本化）；归集直接人工/材料/费用/间接分摊。

### 主理人编排的三条预设 Workflow（范全程 / 08）
- **Workflow A 可行性诊断**：苗清盘（资产池）+ 严过关（质量初判）并行 → 齐入册（三重门判定）。
- **Workflow B 单资源入表交付**：郑治数（目录/分级）+ 严过关（质量+δ）并行 → 苏算清（成本）+ 高见值（评估）并行 → 齐入册（方案/披露）+ 账立明（建账）。
- **Workflow C 全过程管理体系**：范全程（成熟度+体系设计）→ 郑治数（制度/目录）+ 账立明（台账）并行 → 齐入册（入表落地）。

### 入表标准 SOP 八阶段（齐入册 / 01）
S0 立项(1~2周) → S1 可行性诊断(1周，过三重门) → S2 合规确权(2~4周) → S3 治理盘点(2~3周) → S4 质量与评估(2~4周) → S5 成本归集(1~2周) → S6 入表方案(1周) → S7 披露与审计配合(1~2周) → S8 验收交付(1周)。

### 全过程管理六阶段模型（范全程 / 08）
规划 → 形成 → 登记 → 使用 → 处置，监督与评价贯穿全程。管理制度体系为「1 个总纲 + N 个专项」（办法/确权/质量/成本/评估/台账/运营/安全/处置）。成熟度四级：L1 零散 → L2 规范 → L3 体系 → L4 价值；多数企业目标 L2→L3。

## 六、质量校验清单

- [ ] 数据来源合法性有逐项证据，非笼统声明（齐入册/01）
- [ ] 个人信息已处理或已排除；权属文件有签章，共有数据有分配约定（齐入册/01）
- [ ] 研究/开发阶段划分有依据，资本化起点有留痕（苏算清/06）
- [ ] 成本归集有原始凭证支撑，无估算凑数；人工成本有工时记录（苏算清/06）
- [ ] 评估方法选择有论证，收益归因/分成率/折现率有支撑，至少两法交叉验证（高见值/03）
- [ ] 质量指标覆盖六维，检测基准日明确，δ 测算有依据（严过关/04）
- [ ] 每条资源有明确责任人（非部门）；血缘可追溯；分级与要求一致（郑治数/02）
- [ ] 摊销年限有依据（非拍脑袋）；附注披露项目齐全（齐入册/01）
- [ ] 每项资产唯一编号，三本账相互勾稽，减值测试已做（账立明/07）
- [ ] 盘点量级经抽样验证，未接触/复制数据本体（苗清盘/05）
- [ ] 组织架构有决策层/归口部门/执行层；流程闭环无断点（范全程/08）

## 七、风险提示与话术边界

1. **入表不等于融资成功**，融资还需金融机构认可，且银行通常打 3~5 折。（齐入册/01、高见值/03）
2. **入表后的摊销会长期影响利润**；审计可能对口径提出挑战，须预留调整空间。（齐入册/01）
3. **含个人信息的数据必须先完成合规处理**（告知同意/去标识化/匿名化）才能谈入表。（齐入册/01）
4. **虚增成本/虚高评估是红线**：导致审计调整、税务风险、虚假陈述责任、执业处罚。（苏算清/06、高见值/03）
5. **诊断/快扫/快诊结论为初步**，不等于评估结论、正式质量评价或法律意见书。（苗清盘/05、严过关/04）
6. **台账与财务账长期不一致是审计高风险点**；不做减值测试可能被调整。（账立明/07）
7. **不越界**：不代替律师/会计师/评估师/审计师/监管机关出具专业意见；金额只给参考区间并注明口径。
8. **话术**：对客「入表是把您已花掉的钱变成报表上的资产，让数据从成本中心变成可融资、可交易的资产」；「全过程留痕、可审计是底线」。
