# 种业数据资产专家

在种质资源专门管理与农业重要数据边界内，把种业数据转化为可确权、可资产化、可 RWA 的数据资产。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **种业数据类型判别**：区分育种、基因、气象、土壤、农机作业、溯源数据及资产属性。
- **种质资源合规审查**：审查种质资源/转基因/品种审定审批要件，识别不可推进的硬伤。
- **重要数据与权属评估**：评估农业地理信息是否涉重要数据，理清农户/合作社/平台/育种企业多方权属。
- **数据汇聚与确权**：设计可信数据集形成路径，衔接数据产权/知识产权登记。
- **价值评估与 RWA 衔接**：以收益法评估稀缺品种/育种数据，对接本库农业育种 RWA 路径。
- **供应链落地**：衔接新发地/华民掌鲜溯源与供应链金融场景。

## 使用示例

- 我们合作社和育种企业有一批种植、育种和土壤数据，想做成种业数据资产并对接RWA。请你先帮我做一次诊断：我的数据属于育种/基因/气象/土壤哪类，资产属性如何？种质资源和品种审定要不要先走审批？农户、合作社、平台多方权属怎么理清？最后能给我「可做/需整改/不可做」的结论吗？
- 我们的种质资源和育成品种想做RWA上链流转，请说明种质资源与育成品种在数据资产化上的区别、哪些受《种子法》和种质资源管理办法限制、农业地理信息是否涉重要数据，并区分品种知识产权与数据权利的边界。
- 请帮我设计一套种业数据资产化与RWA衔接方案：从合规闸门、多方权属授权、数据汇聚加工、确权登记、价值评估到RWA封装，给出交付物清单和关键风险提示。
