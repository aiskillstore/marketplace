# 行业垂直数据专家团 · 团队知识底座

> 整理基准日：2026-09-23｜适用主体：图灵数盟（深圳）数字产业有限公司
> 本文件按**团队视角**重组，标注每条知识来自哪位成员（专家 42 主理人 / 46 碳 / 47 种业 / 48 电力储能 / 21 公共数据）。政策文号、期限、口径以主管部门最新发布为准；未确认的口径不编造。

---

## 一、团队定位与共同擅长

**定位**（来自 42 主理人）：把通用的数据资产化方法论（入表、评估、交易、确权）落到具体行业的具体数据上。本团覆盖碳、种业、电力储能、公共数据四个行业方向，核心纪律是"行业监管优先于通用法律，先过合规闸门再谈资产化"。

**共同擅长**
- 行业数据特性分析：识别每个行业产什么数据、规模形态、更新频率、敏感性。
- 行业合规闸门识别：碳 MRV、种质资源审批、电网 CII/重要数据、公共数据授权期限等专门监管。
- 行业价值场景挖掘与买方结构分析：谁付钱、怎么决策。
- 行业资产化路径设计：入表（五步法）、RWA（收益权/品种权益上链）、公共数据授权运营拿权。
- 区分官方规则与商业 RWA（如 CCER 与碳币、品种权与数据权、官方授权与商业权益），防"漂绿"与合规风险。

**三个"特别注意"（来自 42）**：① 行业监管优先于通用法律；② 行业数据权属往往更复杂（多方主体）；③ 行业买方更保守，口碑风险高。

## 三、分阶段 SOP 与预设 Workflow

**统一 SOP（来自 42 + 主理人编排）**
- Phase 1 行业识别与数据特性分析 → Phase 2 合规闸门识别（关键，不可跳过）→ Phase 3 价值场景与买方结构 → Phase 4 资产化路径设计（入表/RWA/授权运营）→ Phase 5 主理人总成报告。

**Workflow A 行业可行性诊断**：并行做数据特性与合规闸门初判 → 主理人五步法汇总 → 输出"可做/需补条件/不可做"结论。
**Workflow B 行业 RWA 与入表落地**：对应行业专家并行给闸门结论与路径 → 主理人衔接通用方法论 → 区分官方规则与商业 RWA。
**Workflow C 公共数据授权拿权**：龚运做区域政策与五步程序 → 主理人叠加"原始数据不交易/禁止转授权/期限衔接"提示 → 输出方案与风险清单。

## 四、关键政策依据与期限口径（按成员标注）

### 4.1 碳（来自 46）
- 《碳排放权交易管理暂行条例》**国务院令第 775 号，2024-05-01 施行**：全国碳市场顶层行政法规。
- 《碳排放权交易管理办法（试行）》**生态环境部令第 19 号，2021-02-01 施行**。
- 《温室气体自愿减排交易管理办法（试行）》**生态环境部、市场监管总局令第 31 号，2023-10 发布**：CCER 注册登记、审定、核查与交易规则。
- **CCER 重启**：2024-01 全国温室气体自愿减排注册登记/交易机构成立。
- 核算标准：GB/T 32150-2015、GB/T 32151 系列、ISO 14064-1:2018、ISO 14067:2018、GHG Protocol。
- 《企业可持续披露准则——基本准则（试行）》财政部 2024 发布（ESG 披露会计基础）。
- **口径**：碳信用抵销比例有限制（重点排放单位抵销上限为应清缴配额的 **5%**）；碳信用有**计入期/有效期**，到期需重新审定，价值随时间衰减；**碳排放/碳足迹是合规成本，碳信用/碳汇是可交易正资产，二者不可混同**；商业"碳币"（WorldCarbon）≠ 官方 CCER，须明示区分。

### 4.2 种业（来自 47）
- 《中华人民共和国种子法》**2021-12-24 修正通过，2022-03-01 施行**：品种审定/登记、实质性派生品种（EDV）保护。
- 《农作物种质资源管理办法》**农业部令第 30 号，2003-07-08 施行**：种质资源国家所有、分级管理，采集/出境/利用须审批。
- 《主要农作物品种审定办法》《非主要农作物品种登记办法》《农作物种子生产经营许可管理办法》（农业农村部令）。
- 《农业转基因生物安全管理条例》**2017 年修订**：转基因严格审批。
- 数据安全：《数据安全法》《农业数据分类分级指南》（行业指引口径）——农业地理信息/大面积农田遥感可能涉**重要数据**，出境/共享须安全评估。
- **口径**：种质资源属国家战略资源，出境/对外提供须审批；区分"种质资源数据（受限）"与"育成品种数据（可授权经营）"；品种权（知识产权）与数据集权属（按采集/加工约定）分开看。

### 4.3 电力储能（来自 48）
- 《网络安全法》**2017-06-01**：确立 CII 制度，重要数据境内存储、出境须评估。
- 《数据安全法》**2021-09-01**：数据分类分级（一般/重要/核心）。
- 《关键信息基础设施安全保护条例》**2021-09-01**：电网、大型充电/储能平台可能落入 CII。
- 《电力监控系统安全防护规定》**国家发改委令第 14 号**：电力数据采集"安全分区、网络专用、横向隔离、纵向认证"。
- 《"十四五"现代能源体系规划》**发改能源〔2021〕2101 号**。
- 《关于进一步构建高质量充电基础设施体系的指导意见》**国办发〔2023〕19 号**：充电桩数据资产化政策锚点。
- 《数据出境安全评估办法》**2022-09-01**：重要数据出境须申报评估。
- 《企业数据资源相关会计处理暂行规定》**财会〔2023〕11 号，2024-01-01 施行**：入表根本依据。
- 《关于加强数据资产管理的指导意见》**财资〔2023〕141 号**。
- **口径**：电网调度/网架拓扑/潮流等落入"重要数据/CII"——严禁出境、须安全评估、一般不可对外交易；充电桩/储能现金流可计量性最强；收益权与数据权利必须分离；充电桩用户 ID/支付/车辆须去标识化。

### 4.4 公共数据（来自 21）
- 《**公共数据资源授权运营实施规范（试行）》** **2025-03-01 施行**：核心依据，明确授权模式、程序、期限、监管。
- 《公共数据资源登记管理暂行办法》：登记规范（与专家 12 交叉）。
- 《关于加快公共数据资源开发利用的意见》**2024-10**；"数据二十条"**2022-12**；《政务数据共享条例》；GB/T 43697-2024 分类分级。
- **三种授权模式**：整体授权（1 家）/ 分领域授权（多家）/ 依场景授权（多家，中小企业切入）。
- **五步程序**：目录编制 → 方案制定 → 主体选择 → 协议签订 → 运营监督。
- **期限口径（易踩坑）**：公共数据资源**登记原则 3 年**；授权运营**最长 5 年**（协议生效日起算）。运营期 5 年但登记仅 3 年，须中途续展登记，建立"登记3年/授权5年"双到期提醒。
- **红线**：原始公共数据不交易，只能经营加工后数据产品；一般**禁止转授权**；收益分配常见 5:5 到 8:2，政府通常要求审计权。

## 六、质量校验清单（按成员标注）

**碳（46）**：类型判别未把"排放"当"减排量"；MRV 已完成或补强计划、第三方核查路径明确；核算边界/因子有依据；碳信用符合方法学、计入期与签发量有测算；登记交易区分官方 CCER 与商业碳币、无混同；抵销比例未超上限；ESG 披露无"漂绿"、数据可验证；碳 RWA 合规边界已明示；全套可第三方复核。

**种业（47）**：种质资源来源合法、未涉未批出境；品种审定/登记、转基因审批要件已核对；重要数据边界已评估并做安全评估/脱敏；多方权属已理清、授权与收益分配有书面约定；数据集可信、血缘可追溯；确权路径明确（数据产权/知识产权）；评估以收益法为主；RWA 边界已明示、未混同品种权与数据权。

**电力储能（48）**：每类数据已完成分类分级；电网/调度数据已做重要数据/CII 识别；涉 CII/重要数据未设计对外交易/出境违规路径；现金流四"可"逐项有证据；最优场景选择有理由（优先自带现金流）；收益权与数据权利已分开界定并留痕；个人信息已去标识化；入表/估值已组织专家 01/03 协同；涉跨境已走出境评估；全套可审计。

**公共数据（21）**：目标地区确有真实开放意愿；已提前介入方案设计；授权范围清单明确；**授权期限不超过 5 年**；收益分配比例与核算机制明确；安全责任边界清晰；禁止转授权条款已明确；已完成登记与运营备案；运营环境满足等保/隔离；**双到期提醒机制已建立（3年登记/5年授权）**；产品经营符合"原始数据不交易"红线。

## 七、风险提示与话术边界（按成员标注）

**碳（46）**：① 须先过 MRV 与专门登记规则，不能套用通用流程；② 商业碳币 ≠ 官方 CCER，表述须区分，防合规与"漂绿"；③ 碳信用有计入期与政策抵销上限，价值须谨慎；④ 碳价与政策波动大，碳金融须增信；⑤ ESG 披露超出实际减排即"漂绿"，须可验证。

**种业（47）**：① 种质资源审批不可遗漏，出境/对外提供须审批，否则违法；② 农业地理信息涉重要数据，共享/出境/RWA 跨链须安全评估；③ 权属多方须先理清授权与收益分配；④ 品种知识产权与数据权利须分开看；⑤ 转基因须走正式审批；⑥ RWA 须明示边界，不宣传违规代币融资。

**电力储能（48）**：① 电网/调度数据涉重要数据或 CII，对外交易/出境属违规红线；② 能源涉行业监管须优先遵守；③ 收益权与数据权利必须分离；④ 充电桩个人信息须去标识化，禁止对外提供可识别行为；⑤ 优化型场景须建基线对照，否则不可计量不能入表；⑥ 境内不宣传"代币发行/融资"，统一用"数据资产化 + 收益权结构化"。

**公共数据（21）**：① 授权期限最长 5 年、登记 3 年，需中途续展（易踩坑）；② 原始数据不得交易，只能经营加工后产品；③ 禁止转授权，违规可终止授权；④ 收益分配谈判周期长；⑤ 地方换届可能影响政策连续性，需约定稳定性条款；⑥ 涉个人信息公共数据须特别注意合规。

**主理人总纪律（42）**：行业专门规定优先，不能用通用方案套；行业数据权属先理清；特殊审批不能遗漏（人类遗传资源、种质资源等）；行业买方圈子小、口碑风险高；行业知识须持续更新；不同时铺太多行业；本库部分 RWA 方案为设计稿，实际落地需行业专业机构参与。

## 八、共同输出纪律
1. 无证据不下结论，金额只给参考区间并注明口径。
2. 合规闸门优先于通用资产化，过不了不谈后续。
3. 不越界代替持牌机构与监管机关出具意见；不混同官方规则与商业 RWA。
4. 所有专业产出由对应成员输出后采信，主理人只做编排与总成。
