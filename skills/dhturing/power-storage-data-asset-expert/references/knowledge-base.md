# 电力储能数据资产专家

> 所属战队：08-细分方向（原附录·可细分方向）
> 专家编号：48
> 核心使命：把电力、充电桩、储能、电网、水务等能源类数据，转化为可计量现金流的数据资产，并在涉 CII / 重要数据的合规闸门下设计入表与 RWA 路径。

## 第一部分 · 知识库

### 1.1 一句话定位

电力储能数据资产专家是**能源行业数据资产化的落地执行者**。能源数据的独特性在于：① 数据天然伴随物理资产（电厂、电网、充电桩、储能站、水厂）与实时现金流；② 电网侧数据高度敏感，可能触及**重要数据与关键信息基础设施（CII）**；③ 价值兑现依赖"数据 + 收益权"打包。本专家的核心判断只有一条——**数据必须能产生可计量的现金流**，否则它只是成本，不是资产。

**与父专家（42 行业垂直数据专家）的关系**：42 号 §1.3 ③ 只给出能源领域的"数据类型 / 合规 / 场景 / 机会"四行要点，本专家把其扩写为完整方法论，并新增"现金流可计量性"这一父专家未单列的核心闸门。本库在能源方向的资产极丰富（充电-储能项目清单、水链 H2O Global Network），是本专家的独特弹药。

### 1.3 核心模型一：能源数据类型与敏感度分层

进入任何能源数据项目，先用下表做"数据分类分级 + 敏感度"判断，这是后续一切合规与资产化的前置：

| 数据类型 | 典型字段 | 敏感度 | 是否含个人信息 | 资产化闸门 |
|---|---|---|---|---|
| **电力运行数据** | 发电出力、负荷曲线、机组状态、线损 | 一般 ~ 重要 | 否 | 涉电网拓扑/调度则升为重要数据 |
| **充电桩数据** | 充电量、充电时长、站点/枪位、用户ID、支付、车辆 | 重要 | **是**（用户ID/支付/车辆） | 须个人信息合规 + 收益权清晰 |
| **储能数据** | SOC、SOH、充放电曲线、PCS 状态、健康度 | 一般 ~ 重要 | 否 | 涉电网调度指令则升为重要数据 |
| **电网数据** | 调度指令、网架拓扑、潮流、保护定值 | **重要数据 / CII** | 否 | 严禁出境、须安全评估、一般不可对外交易 |
| **用水数据** | 供水量、管网压力、水质、户表、漏损 | 重要（民生） | 户表=是 | 水务数据（水链）须民生安全优先 |

**关键判断**：电网数据一旦落入"重要数据 / CII"，其资产化路径被严格限制——通常只能做"内部优化增值"与"受控的脱敏统计对外服务"，**不能直接对外交易或出境**。充电桩与储能数据的资产化空间最大，因为它们天然绑定用户付费产生的现金流。

### 1.4 核心模型二：现金流可计量性判断矩阵（核心闸门）

本专家区别于父专家的关键方法论。**数据资产化的前提不是"有数据"，而是"数据能产生可计量的现金流"**。用四维度判断：

```
可计量性 = 可计量 × 可持续 × 可归因 × 可验证
                ↓
   四个"可"都过  →  可资产化
   任一不过      →  先整改或放弃，不得硬做
```

| 判断维度 | 通过标准 | 典型反例（不得做） |
|---|---|---|
| **可计量** | 收益能用金额/度数/次数明确计量 | "提升品牌"等无法计量 |
| **可持续** | 现金流有稳定周期（月/季/年） | 一次性活动数据 |
| **可归因** | 现金流可归到具体数据产品 | 说不清"是这数据带来的" |
| **可验证** | 有合同/账单/系统日志佐证 | 仅靠乐观假设 |

**五类价值场景的现金流属性**：

| 价值场景 | 现金流形态 | 可计量性 |
|---|---|---|
| 能源调度优化 | 节约的燃料/损耗成本 | 中（需基线对照） |
| 设备运维（预测性维护） | 减少的停机/维修费 | 中 |
| 需求预测 | 削峰填谷收益、偏差考核减免 | 中高 |
| 碳核算 | 碳资产/碳交易收益 | 中（引用专家 46） |
| **充电网络运营** | **充电服务费分成、广告、数据服务订阅** | **高（最优选）** |

> 结论：做能源数据资产化，**优先选"充电网络运营"这类自带实时付费现金流的场景**；纯"优化节约型"场景须先建立基线对照，否则现金流不可计量。

### 1.5 核心模型三：充电桩 RWA / 水务数据（水链）路径

**充电桩 RWA 路径**（本库 `充电-储能-项目介绍清单.xlsx` 含项目清单）：

```
底层资产：充电桩硬件 + 充电运营数据（量/费/用户/位置）
     ↓ 收益权剥离
充电服务费现金流（可计量、可持续、可归因、可验证）
     ↓ 结构化
RWA 载体：受益权/收益权凭证（非代币融资表述，须合规）
```
- **收益权与数据权利分离**：资产化的是"充电服务费收益权"，数据只是现金流的佐证与运营优化输入，二者在法律上须分开界定。
- **合规要点**：用户个人信息（ID/支付/车辆）须去标识化；不得对外提供可识别个人用户的充电行为。
- 表述纪律：境内不宣传"代币发行/融资"，统一表述为"数据资产化 + 收益权结构化"。

**水务数据（水链）路径**（本库 `RWA\水链\`，H2O Global Network）：

| 要素 | 内容 |
|---|---|
| 数据底座 | 供水/管网/水质/户表/漏损的运营数据 |
| 价值锚点 | 水务运营效率提升 + 水权/水费收益 |
| 路径 | 水务数据资产化 → 水币（Web3 估值模型）生态 |
| 红线 | 民生安全优先；户表数据含个人信息须脱敏；涉跨境须评估 |

> 水链属本库"能源/新能源"大类的延伸（用水数据），与充电桩同为本专家"自带现金流"型场景。

### 1.6 常见问题与标准答复

**Q1：我们电网公司有一堆调度和运行数据，能不能直接做成数据资产卖出去？**
A：**不能**。电网调度、网架拓扑、潮流等数据极可能落入"重要数据 / CII"，按《数据安全法》《关基条例》须境内存储、出境评估，且一般不得对外直接交易。可行路径是：内部做调度优化与降本（节约即现金流），或对脱敏后的统计级数据提供受控对外服务。先做"重要数据识别"再谈资产化。

**Q2：充电桩运营数据能做资产化吗？**
A：**能，且是最优选之一**。充电桩天然绑定用户充电付费，现金流可计量、可持续、可归因、可验证。关键是：① 把"充电服务费收益权"与"数据权利"分开；② 用户个人信息去标识化；③ 用本库充电桩 RWA 结构做收益权打包。

**Q3：储能数据有什么资产化价值？**
A：储能的 SOC/SOH/充放电曲线可用于设备健康评估、保险定价、电网辅助服务（调频/调峰）收益分成。价值偏"优化节约型"，须先建立基线对照让现金流可计量，优于纯对外交易。

**Q4：你们说的"现金流可计量"到底怎么落地？**
A：四步——先确定现金流形态（服务费/节约/分成），再用合同+账单+系统日志做"可验证"证据链，再设基线对照做"可归因"，最后按月/季出具计量报表。四"可"不全，就不建议入表或做 RWA。

**Q5：水务（水链）数据和充电桩一样做吗？**
A：结构类似（底层运营数据 + 收益权），但水务必把"民生安全"放第一位，户表含个人信息须脱敏，跨境部分须走数据出境评估。水币生态属 Web3 估值范畴，境内表述严格遵守合规纪律。

### 2.2 标准作业流程 SOP

**S0 立项与数据普查（1~2 周）**
1. 客户访谈：明确能源数据类型（电力/充电桩/储能/电网/用水）、业务范围、目的（入表/RWA/优化）
2. 签署保密协议，组建项目组（本专家为 PM，配合规、评估、财务）
3. 输出《能源数据资产清单》

**S1 分类分级与敏感度判定（1~2 周）**
1. 按 1.3 表对每类数据定级（一般/重要/核心）
2. 标注是否含个人信息、是否涉 CII
3. 输出《数据分类分级与敏感度表》

**S2 重要数据/CII 合规筛查（2~4 周，关键闸门）**
1. 对照主管部门重要数据目录与 CII 认定标准
2. 涉 CII/重要数据的，明确"不得对外交易/出境"红线，设计受控使用方案
3. 输出《涉重要数据/CII 合规筛查意见》；硬伤项停止对外资产化

**S3 现金流可计量性诊断（1~2 周，核心闸门）**
1. 按 1.4 四"可"逐场景判断
2. 选定最优场景（优先"充电网络运营"等自带现金流场景）
3. 输出《现金流可计量性诊断书》；四"可"不全则建议整改或放弃

**S4 价值场景与路径设计（2~3 周）**
1. 设计价值场景与变现方式
2. 充电桩/水链走 RWA 收益权结构；优化型场景建基线对照
3. 输出《能源数据价值场景方案》《充电桩RWA/水链路径方案》

**S5 入表与评估协同（2~4 周）**
1. 组织专家 01 做入表可行性、专家 03 做估值（收益法优先）
2. 收益权与数据权利分开界定并留痕
3. 输出《入表/评估协同方案》

**S6 出境评估协同（如涉跨境，2~4 周）**
1. 涉重要数据/个人信息出境的，组织出境安全评估申报
2. 输出《数据出境评估协同包》

**S7 交付与验收（1~2 周）**
1. 交付件核对，客户培训（运营方维护计量报表）
2. 进入运营期（转专家 26 数据资产运营专家）

**S8 案例沉淀（持续）**
1. 沉淀能源标杆案例与可复制材料
2. 输出《能源数据资产化知识库》

### 2.6 关键话术与风险提示

**关键话术**：
- 对客户："能源数据能不能资产化，不看你有多少数据，看它能不能产生**可计量的现金流**。电网数据再大，涉 CII 也不能随便卖；充电桩数据虽小，但每度电都有服务费，最干净。"
- 对内部："先做分类分级和 CII 筛查这两个闸门，过不了就不谈后续。能源项目最怕把重要数据当普通数据往外交易。"

**风险提示**：
1. 电网/调度数据可能涉**重要数据或 CII**，对外交易或出境属违规红线
2. 能源数据涉行业监管（电力、水务），须优先遵守行业主管部门规定
3. **收益权与数据权利必须分离**，混同会导致权属与合规双重风险
4. 充电桩用户个人信息（ID/支付/车辆）须去标识化，禁止对外提供可识别行为
5. 优化型场景现金流须建基线对照，否则"不可计量"不能入表
6. 境内不宣传"代币发行/融资"，统一用"数据资产化 + 收益权结构化"表述
