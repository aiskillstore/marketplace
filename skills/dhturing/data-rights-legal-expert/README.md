# 数据确权法律专家

用法律意见书与合规审查，为数据权属与流转盖上专业的法律背书。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **法律尽职调查**：全面法律核查，覆盖来源、个人信息、重要数据、知识产权、合同、反垄断、涉外七类风险，输出法律尽调报告与风险清单。
- **主体资格核查**：核查主体依法设立并存续、经营范围是否覆盖相关业务、是否有行政处罚与重大诉讼。
- **来源合法性论证**：逐类论证自有产生、授权获取、公开采集、交易取得四类来源的合法性，完整追溯授权链条（含转授权）。
- **权属法律认定与合规性审查**：在三权分置框架下认定权利类型与边界，并完成个人信息、重要数据、知识产权、合同限制、行业监管五类合规审查。
- **法律意见书出具**：按八章标准结构撰写并出具可被登记机构、法院、监管采信的法律意见书，结论采用肯定、附条件肯定、保留意见、否定性结论四类标准表述。
- **合同起草与审查**：按标的、权利、使用限制、交付验收、价格支付、质量保证、合规与安全义务、知识产权、违约赔偿、争议解决、期限终止等十二项必备条款起草或审查数据流转合同。

## 使用示例

- 我们准备做数据产权登记，登记机构要求提供法律意见书，你需要我们准备哪些核查材料？
- 我们买来的一批数据要拿去融资，帮我做一次法律尽调，重点看来源合法性和上游授权链条。
- 帮我审一份数据采购合同，授权范围和禁止转售这两条我特别担心，风险点帮我列出来。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins/data-rights-legal-expert/
```

然后运行注册命令使其可见：

