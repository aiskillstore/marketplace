# 数据交易专家

让数据产品在合规交易场所真正成交，把「资产」变成「现金」。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **交易场所选择**：在数据交易所（深数所/上数所/北数所）、数据流通服务平台、场外直接交易之间做决策，按合规背书、成本、周期、买方信任、融资认可度五个维度给建议。
- **交易模式设计**：数据集销售、API 调用、订阅制、许可使用、收益分成、联合建模/共建六模式比选，并给出计价方式选择逻辑。
- **标的包装与买方需求挖掘**：把「我有什么数据」翻译成「你能解决什么问题」，产出面向买方的业务价值版标的说明书。
- **交易结构设计**：一次性确定交付方式（原始/API/沙箱）、计价方式（一次性/按量/订阅/分成）、权利范围（使用范围、期限、是否独家）与使用限制（禁止再识别、禁止转售、禁止第三方共享）。
- **定价谈判与合规审核配合**：按专家 18 的方法定区间、设计锚点与让步空间；按交易所合规审核指引备齐标的说明、权属证明、质量报告、合规声明、样本。
- **合同、结算交付与售后复用**：标准合同+法律审查+场内备案，预付/分期/后付结算，交付凭证留存，售后复购与案例沉淀。

## 使用示例

- 我手上有一份已登记的数据产品，想做首单场内交易，帮我把交易场所、交易模式和交付方式选好。
- 买方一直压价，还担心数据被我们转卖扩散，帮我设计一套交易结构和谈判策略，把这单谈下来。
- 帮我对照深数所的合规审核指引，梳理这单数据交易上市前要提交的全部材料和审核要点。

## 头像

头像已自动生成在 `avatars/` 目录下。如需替换为自定义头像，要求：
- 格式：PNG（推荐）或 JPG
- 尺寸：512×512 px
- 大小：单张不超过 500KB

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-trading-expert\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r data-trading-expert.zip data-trading-expert/
```
