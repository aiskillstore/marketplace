# 数据供需匹配专家

把匹配效率变成核心竞争力——建立并运营「三大数据库」，让数据供给与需求高效对接。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **三大数据库设计与运营**：数据资源库（供给侧）、需求数据库（需求侧）、专家/服务机构库（交付侧），含完整字段结构与行业/数据类型/场景/地区标签体系
- **需求先行建设**：优先建需求数据库（含需求方/内容/用途/预算/时间五字段），并用"有具体的人、有明确用途、有预算"三标准校验有效性
- **五渠道需求收集**：交易所需求池、行业活动会议、现有客户延伸、政府园区合作、主动陌生拜访
- **匹配效率公式应用**：覆盖度 × 需求精准度 × 匹配智能度（乘法关系），提醒不要只盯覆盖度
- **五种匹配状态判定**：A 直接匹配 / B 加工匹配 / C 组合匹配 / D 外部匹配 / E 待开发，并执行对应动作
- **匹配跟踪与供需分析**：按月更新数据库、清理僵尸数据，按季度输出供需趋势报告指导资源获取方向

## 使用示例

- 帮我设计三大数据库的字段结构和标签体系，并说清需求先行的建设顺序。
- 客户提了一个数据需求，帮我判断属于A到E哪种匹配状态，并给出该做什么动作。
- 帮我判断需求条目是不是有效需求，并告诉我什么时候该从Excel换成系统。
