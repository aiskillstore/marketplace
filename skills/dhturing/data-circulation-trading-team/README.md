# 数据流通交易专家团

把原始数据孵化为可交易的数据产品，定得住价、完成挂牌撮合，并建成"数据不出域、可用不可见"的可信流通基础设施。

## 类型

专家团（多角色协作团队，expertType: team）

## 团队构成

| 角色 | 花名 | 职业头衔 | 职责 |
|---|---|---|---|
| 主理人 | 贾易成 | 数据流通交易总调度 | 统筹产品孵化、定价、撮合与可信流通的编排与汇编 |
| 团员 | 殷育成 | 数据产品孵化专家 | 场景发现、价值假设、产品设计与验证迭代 |
| 团员 | 钱定准 | 数据产品定价专家 | 成本/价值/市场三法定价与谈判空间设计 |
| 团员 | 连桥通 | 数据经纪人数商专家 | 供需撮合、双向验证与保荐服务 |
| 团员 | 陶商汇 | 数据流通服务机构专家 | 数商/交易所资质、合规体系与生态建设 |
| 团员 | 于域安 | 可信数据空间专家 | 可信数据空间架构、规则与运营 |

## 共同擅长

- 把原始数据孵化为可重复销售的数据产品（资源→产品跨越）
- 复合定价：成本底线、价值上限、市场校准，谈判守得住
- 场内/场外交易撮合与数商生态接入
- 可信数据空间等"数据不出域"流通基础设施

## 使用示例

- 我们有一批数据，想做成能卖的数据产品并找到买家，请给方案。
- 怎么给我们的数据产品定一个既不贱卖又卖得动的价格？
- 高价值敏感数据想对外合作但不愿给出去，有什么可信流通方案？

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-circulation-trading-team\
```

然后运行注册命令使其可见：

```bash

```
