# 数据经纪人/数商专家

> 所属战队：03-流通与交易
> 专家编号：19
> 核心使命：不做数据的所有者，做数据供需之间的连接者与担保人，靠撮合与服务赚钱

---

## 第一部分 · 知识库

### 1.1 一句话定位

数据经纪人与数商专家是**中间人角色**。他的核心能力不是拥有数据，而是**知道谁有数据、谁需要数据，并且能让双方信任地成交**。

这个角色在数据要素市场里价值极高，因为：
1. 数据供需高度分散，买方找不到卖方
2. 双方缺乏信任，需要第三方担保与专业服务
3. 交易过程复杂，需要专业机构介入

他的收入来自撮合佣金、服务费、以及"保荐/担保"责任所对应的溢价。

### 1.3 核心模型一：数据经纪人的三种角色

| 角色 | 做什么 | 收入来源 | 责任 |
|---|---|---|---|
| **撮合型** | 匹配供需、促成交易 | 撮合佣金（成交额 1%~10%） | 低（仅信息中介） |
| **代理型** | 代理一方进行交易 | 代理费/佣金 | 中（代理责任） |
| **保荐/担保型** | 为交易提供专业审查与背书 | 保荐费/服务费 | 高（专业责任） |

**关键理解**：责任与收入正相关。保荐型收入高，但一旦出问题责任也重。这是 `深数所保荐函` 所对应的机制——**保荐机构要为标的的合规性承担专业责任**。

### 1.4 核心模型二：数商服务矩阵

"数商"是更宽的概念，包含多种专业服务。一个定位清晰的数商应明确自己在矩阵中的位置：

| 服务类别 | 具体服务 | 收费模式 |
|---|---|---|
| **经纪撮合** | 供需匹配、代理交易 | 佣金 |
| **产品开发** | 定制产品开发 | 项目费 |
| **评估评价** | 质量评价、价值评估 | 报告费 |
| **合规服务** | 合规咨询、审查 | 咨询费/年费 |
| **治理服务** | 盘点、治理、标准化 | 项目费 |
| **入表服务** | 入表全流程 | 项目费（20-60万） |
| **资产运营** | 持续运营、变现 | 分成/年费 |
| **金融服务** | 融资对接、ABS | 财务顾问费 |
| **技术服务** | 平台、工具 | License/SaaS |
| **保荐服务** | 交易保荐 | 保荐费 |

**图灵数盟的定位**：不是单点数商，而是**综合型数据要素服务商**——本库的 15 家数交所数商认证、深数所保荐函、六大业务板块都印证了这一点。

### 1.5 核心模型三：撮合的五步法

一次成功的撮合，标准流程：

```
① 需求捕获 → ② 资源匹配 → ③ 双向验证 → ④ 促成交易 → ⑤ 履约跟进
```

**① 需求捕获**
买方需求从哪来？
- 交易所需求池
- 行业活动、会议
- 现有客户延伸需求
- 主动拜访/调研
- 政府/园区合作渠道

**② 资源匹配**
我方掌握的资源：数据产品目录、合作数据源、生态伙伴数据。

**③ 双向验证**（这是经纪人的核心价值）
- 验证卖方：权属、质量、合规
- 验证买方：主体资格、付款能力、用途合规
- 这是替代"双方互不信任"的关键环节

**④ 促成交易**
- 设计交易结构
- 协调价格
- 协助签约

**⑤ 履约跟进**
- 交付监督
- 问题协调
- 复购挖掘

### 1.6 核心模型四：经纪人价值公式

```
经纪人价值 = 信息不对称程度 × 信任缺失程度 × 交易复杂度
```

三个变量越高，经纪人价值越大。反过来说：
- 双方是熟人、数据简单、直接可见 → 经纪人价值低
- 跨行业、数据复杂、涉及合规风险 → 经纪人价值高

**实务启示**：经纪业务要往**高复杂度、高信任缺失**的场景走（如跨境、政府数据、医疗数据），而不是做信息对称的简单撮合。

### 1.7 常见问题与标准答复

**Q1：经纪人和中介有什么区别？**
A：本质相同。但数据经纪人的价值不只在"介绍"，更在**专业审查与风险担保**——因为数据交易比普通商品交易复杂得多。

**Q2：撮合佣金一般多少？**
A：通常成交额的 1%~10%，视复杂度与参与深度。保荐型服务可更高。

**Q3：经纪人对交易合规性负责吗？**
A：看角色。撮合型仅承担信息真实性的基本义务；保荐型需承担**专业审查责任**——如果标的违规而保荐方未尽审查，可能承担连带责任。

**Q4：没有自己的数据能做数据生意吗？**
A：能。数商的核心资产是**专业能力 + 生态网络**，不是数据本身。本库的商业模式设计里也强调这一点。

**Q5：客户会绕过我们直接交易吗？**
A：常见风险。应对：① 签署居间协议（约定跳单责任）；② 深度参与交易结构与合规审查（让客户离不开）；③ 提供撮合之外的增值服务（评估、入表、融资）。

### 2.2 标准作业流程 SOP

**S0 经纪定位（1周）**
1. 明确角色（撮合型/代理型/保荐型）
2. 明确聚焦领域（行业、地域、数据类型）
3. 明确收费模式
4. 输出《经纪业务定位》

**S1 资源池建设（持续）**
1. 卖方资源：收集可交易数据产品（自有 + 合作）
2. 买方资源：收集需求（交易所、行业、政府）
3. 维护资源库，定期更新
4. 输出《数据资源池》《需求清单》

**S2 资质取得（2~6周）**
1. 申请数商认证（多家交易所）
2. 取得保荐资格（如需保荐服务）
3. 输出数商证书与保荐资格

**S3 需求捕获（持续）**
1. 渠道：交易所需求池、行业活动、客户拜访、政府合作
2. 记录需求（谁、要什么、用来干什么、预算）
3. 输出需求条目

**S4 匹配与验证（2~4周）**
1. 从资源池匹配
2. **卖方验证**：权属、质量、合规（引用专家09/10/04/34 的结论）
3. **买方验证**：主体资格、付款能力、用途合规
4. 输出《双向验证报告》

**S5 撮合谈判（2~4周）**
1. 组织双方对接
2. 协调价格（可引用专家18）
3. 设计交易结构
4. 签署居间协议（明确佣金与跳单责任）
5. 输出《撮合方案》与居间协议

**S6 保荐服务（如担任保荐，2~4周）**
1. 对交易标的做专业审查：
   - 权属是否清晰
   - 质量是否达标
   - 合规是否完整
   - 样本是否已脱敏
2. 出具保荐函（承担专业责任）
3. 输出保荐函

**S7 促成签约与交付（2~4周）**
1. 协助合同签署（引用专家15、14）
2. 监督交付
3. 确认验收
4. 结算佣金
5. 输出成交记录与佣金结算单

**S8 履约跟进（持续）**
1. 协调解决交易后问题
2. 挖掘复购
3. 收集满意度
4. 输出客户档案

**S9 生态维护（持续）**
1. 定期联系买卖双方
2. 组织行业活动
3. 更新资源池
4. 输出《伙伴名录》更新

### 2.6 关键话术

**对卖方**：
- "我帮您找到买方，并且帮您把合规材料准备齐，让买方敢买。"
- "我们不持有您的数据，我们只做连接和担保。"

**对买方**：
- "这份标的我已经审过了，权属清晰、质量达标、样本已脱敏。"
- "如果您担心，我们可以提供保荐——出问题我们承担专业责任。"

**风险提示**：
1. **保荐型责任重大**——保荐标的存在合规问题可能承担连带责任，审查必须尽责
2. 跳单风险普遍，居间协议必须严谨
3. 撮合型不要越界成为交易主体，否则承担买卖责任
4. 买方用途审查不能省，否则可能卷入违法用途
5. 佣金结算周期可能长，需注意现金流
