# 数据合规安全专家团 · 团队知识底座

> 本底座由团 7 七位成员（34/35/36/49/38/39/40）的《知识与技能.md》按团队视角重组而成。
> 整理基准日：2026-09-23。

## 一、团队定位与共同擅长

**共同擅长**：数据全生命周期合规与安全底线，叠加政策解读、标准化与市场研判。

**团队心智模型**：合规安全是数据资产化的**守法底座**——其他团做的入表、交易、金融化，全部建立在本团把住的闸门之上。
```
合规体检（34，总闸门）──┬── 安全技术防线（35 等保/加密/脱敏）
                        ├── 个人信息处理（36 告知同意/PIA/去标识化）
                        ├── 行业专项合规（49 医疗：单独同意/人类遗传资源审批）
                        ├── 政策红利（38 解读/试点与资金申报）
                        ├── 标准话语权（39 国标落地/团标参编）
                        └── 市场研判（40 结构/趋势/机会）
```

**分层铁律**：行业专门规定**优先于**通用法律（做医疗先看卫健委规定，做金融先看金融监管）。

## 三、分阶段 SOP 与预设 Workflow

**三个预设 Workflow**（详见主理人 MD）：
- **Workflow A 数据资产化前全链路合规体检**（最高频）
- **Workflow B 敏感数据（个人信息/重要数据/医疗）资产化前处理**
- **Workflow C 政策红利申报 + 标准布局**

**SOP 主线**：
- **Phase 1 合规体检**：34 牵头，35/36 协同，输出《合规风险清单（四色分级）》。
- **Phase 2 专项处理**：按体检结论分流——安全技术措施（35）、个人信息处理（36）、行业专项（49）。
- **Phase 3 红利与布局**：38 出政策机会清单，39 出标准落地与参编方案，40 出市场研判。
- **Phase 4 汇编**：主理人出《合规体系建设方案 + 整改计划》。

## 七、风险提示与话术边界

1. **《网络数据安全管理条例》2025-01-01 施行**——此前做的合规体系需按新条例复检，不能沿用旧结论。
2. **重要数据识别不是企业自己说了算**——需对照行业主管部门的重要数据目录；未识别到位的处罚风险高。
3. **"单独同意"不能用一揽子隐私政策覆盖**（【49】口径，务必原样传达）。
4. **人类遗传资源审批遗漏可能违法**（【49】）——涉及基因、样本的必须先筛查。
5. **去标识化 ≠ 匿名化**（【36】）——去标识化数据仍属个人信息，只有匿名化（不可复原、不可复指向）才脱离个保法。
6. **等保不是越高越好**——按定级指南客观定级，盲目高定级会带来不成比例的投入。
7. **行业专门规定优先于通用法律**（本团铁律）——先看行业主管部门规定，再看通用法。
8. **不越界**：合规结论中涉及法律意见的部分，仍须由执业律师出具正式文件。
9. **话术**："合规不是让你不敢用数据，而是让你敢用、能用、经得起查。"
