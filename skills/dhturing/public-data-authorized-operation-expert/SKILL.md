## 内容索引

- **1.1 一句话定位**：政府数据与企业能力之间的对接；政府侧设计授权方案与选主体，企业侧申请资格、设计模式、合规运营
- **1.2 政策与标准依据**：《公共数据资源授权运营实施规范（试行）》（2025-03-01 施行，核心依据）、《公共数据资源登记管理暂行办法》、《关于加快公共数据资源开发利用的意见》（2024-10）、数据二十条（2022-12）、《政务数据共享条例》、《数据安全法》《个人信息保护法》、GB/T 43697-2024、各地公共数据管理办法
- **1.3 核心模型一**：三种授权模式（整体授权/分领域授权/依场景授权）与模式选择逻辑树、对企业的启示
- **1.4 核心模型二**：授权运营五步程序（目录编制→方案制定→主体选择→协议签订→运营监督）与协议核心条款
- **1.5 核心模型三**：授权运营期限（最长 5 年）与登记期限（原则 3 年）的衔接要点（双到期提醒、续展责任方）
- **1.6 核心模型四**：收益分配机制四种模式（固定费用/收入分成/保底+分成/利润分成）与实务建议
- **1.7 常见问题与标准答复**：Q1 怎么拿到授权 / Q2 能否直接卖数据（制度红线）/ Q3 期限到了怎么办 / Q4 收益怎么分（常见 5:5 到 8:2）/ Q5 谁承担安全责任 / Q6 能否转授权
- **1.8 源材料索引**：公共数据资源授权运营实施规范、公共数据资源登记管理暂行办法、政务数据共享条例、国家公共数据登记系统、数据要素公共服务基地、邯郸数据、资质材料
- **2.1 能力清单**：C1-C10（政策环境分析、目录梳理协助、授权方案设计、主体申报、遴选答辩、协议谈判、运营模式设计、收益分配设计、合规运营体系、续期与续约）
- **2.2 SOP**：S0 区域选择与政策分析 / S1 政府对接与早期介入（关键）/ S2 目录梳理协助 / S3 授权方案设计 / S4 主体申报 / S5 遴选与答辩 / S6 协议谈判与签订 / S7 登记与备案 / S8 运营体系搭建 / S9 产品开发与变现 / S10 期限与续约管理
- **2.3 交付物**：12 项（区域政策与机会分析、对接纪要与合作意向、可授权数据目录建议、授权运营方案、主体申报材料、遴选答辩材料、授权运营协议、登记与备案凭证、合规运营手册、收益分配方案与核算机制、授权数据产品、续期/续约材料）
- **2.4 质量校验**：11 条勾选项（含授权期限不超过 5 年、禁止转授权、原始数据不交易红线）
- **2.5 协作接口**：上游 12/38/35/34，下游 17/11/15/26，平行 20/25
- **2.6 话术与风险**：对地方政府 2 句、对政府部门内部 2 句、风险提示 6 条
