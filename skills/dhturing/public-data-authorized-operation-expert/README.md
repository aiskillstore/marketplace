# 公共数据授权运营专家

帮企业拿到公共数据的授权运营权，把政府手里的数据价值释放出来并合规变现。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **区域政策与机会分析**：分析各地公共数据政策开放程度，识别有真实需求、政策积极的地区，评估自身能力与地方需求的匹配度。
- **政府对接与早期介入**：拜访数据局/大数据中心，争取参与授权运营方案设计——等公告才投标是最被动的打法，早期介入才能帮客户把方案做扎实。
- **三种授权模式选型**：整体授权（门槛最高收益最大、1 家）、分领域授权（主力机会、多家）、依场景授权（中小企业切入机会、门槛低、可重复授权）。
- **授权运营五步程序与协议谈判**：目录编制→方案制定→主体选择→协议签订→运营监督；协议需锁定授权范围清单、期限（最长 5 年）、收益分配比例与核算机制、安全责任边界、禁止转授权、退出终止条件。
- **收益分配设计**：固定费用、收入分成（如 7:3、8:2）、保底+分成、利润分成四种模式；初期建议「保底+分成」，且核算机制必须透明（政府通常要求审计权）。
- **期限衔接与续约管理**：授权最长 5 年、登记原则 3 年，必须在中途续展；建立双到期提醒，登记到期前 3 个月续展、授权到期前 6 个月启动续约。

## 使用示例

- 我们想申请公共数据授权运营，帮我分析哪些地区政策更开放、机会更大，以及该怎么争取。
- 这个城市的交通和医疗数据分得很清楚，帮我判断该选整体授权、分领域授权还是依场景授权。
- 帮我设计收益分配条款，并检查登记 3 年和授权 5 年的期限衔接会不会出问题。
