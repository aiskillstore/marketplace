# 行业垂直数据专家

把通用的数据资产化方法论，落到具体行业的具体数据上——医疗、农业、能源、教育、碳、贸易金融、黄金大宗、IP 消费，负责行业"最后一公里"的适配。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **行业选择**：从数据资源丰富度、政策支持度、客户预算、自身资源匹配度、竞争程度五维度评估，选定 1~2 个聚焦行业（对应本库六大首批市场）。
- **行业数据特性分析**：调研行业产哪些数据、规模形态更新频率、质量状况与分散程度。
- **行业合规识别（关键）**：贯彻"行业监管优先于通用法律"，识别数据敏感性与特殊审批（人类遗传资源、种质资源、未成年人信息 14 周岁以下监护人同意等）。
- **行业场景与买方分析**：挖掘行业专属价值场景，并回答"谁付钱、预算从哪来、决策链怎么走"。
- **行业方案设计**：输出行业化的入表方案、产品设计与合规方案。
- **标杆打造与复制**：先做一个行业的标杆案例，再提炼复制手册横向覆盖同行业客户。
- **行业知识沉淀与生态建设**：建立行业知识库（政策/数据特性/场景/买方/案例）与行业合作伙伴网络。

## 使用示例

- 我们想聚焦医疗健康数据做资产化，先帮我分析这个行业的数据特性、特殊合规要求和买方结构。
- 种业数据为什么适合做 RWA？帮我分析它的资产特性、可量化收益和权属清晰度。
- 我们在新能源行业已经做出了一个标杆项目，怎么提炼成能复制给同行业其他客户的复制手册？
