# 数据资产ABS/REITs专家

把数据资产未来产生的现金流打包成证券卖给投资人，实现一次融资、多方受益的规模化资本运作。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **ABS 适格性判断**：逐项核查五个硬条件——有稳定现金流、现金流可归集、权属清晰可转让、持续性至少 3 年可预测、规模通常 > 5000 万；不满足时明确建议改走质押融资。
- **现金流分析与压力测试**：分析波动性、客户集中度与可持续性，预测未来 3~5 年现金流；设计基准、-20%、-50% 情景，测算覆盖倍数（通常要求 > 1.2 倍）与敏感性。
- **交易结构设计**：设计 SPV（专项计划/信托）、优先/次级分层、现金流分配顺序、期限与还本付息方式，确保真实破产隔离。
- **双重增信方案**：内部增信（优先/劣后分层、超额抵押、现金流超额覆盖）+ 外部增信（差额支付承诺、第三方担保、其他资产质押），并测算增信成本。
- **中介组织与发行申报**：组织券商、评级、律所、会所、评估机构；编制募集说明书，应对多轮监管反馈，完成路演、询价定价与发行。
- **存续期管理**：按期分配本息、定期信息披露、跟踪基础资产表现、应对风险事件。

## 使用示例

- 我们有一批数据产品，年收入大约 6000 万，想做成数据资产 ABS，先帮我判断够不够格？
- 帮我按基准、-20%、-50% 三种情景做现金流压力测试，测算覆盖倍数和敏感性。
- 我们的数据服务收入还没有稳定下来，客户也担心做不了 ABS。该怎么向客户说明，并给出替代路径？

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-asset-abs-reits-expert\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
