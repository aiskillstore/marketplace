# 数据资源成本归集专家

把企业花在数据上的钱，一笔一笔找出来、分清楚、算明白，形成可入表的成本底数——入表金额的唯一合法来源。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **成本四分类识别**：直接人工、直接材料、直接费用、间接费用逐项排查，并排除易错项（研究阶段探索性支出、日常维护、培训费/广告费/一般管理费、已费用化沉没成本）。
- **研究/开发阶段划分**：判断资本化起点（常见以立项批准日为界，更严谨用技术可行性论证通过日），并逐条对照开发阶段可资本化的五个条件。
- **归集口径设计**：直接归集（首选）/ 分摊归集 / 参照估算三口径；分摊基础比较人工工时、数据量、使用频次、收益比例四种，形成《成本归集办法》。
- **成本计算**：直接人工 = Σ(人员月薪 × 投入工时比例 × 期间)，材料与费用按实际发生额，间接费用按比例分摊，输出逐项可追溯的《成本归集明细表》。
- **证据链构建**：为每笔成本建立凭证索引（工资表页码、发票号、合同编号），确保可经受审计抽凭。
- **资本化金额确认与制度建设**：出具《资本化金额确认书》，并协助建立《数据资源成本核算办法》与常态化归集机制。

## 使用示例

- 我们想把数据库团队近两年的投入归集出来做入表。请你告诉我怎么按四分类识别成本、资本化起点该以哪个文件为准，以及需要我向财务和 HR 要哪些原始资料。
- 请帮我判断哪些支出属于研究阶段、哪些属于开发阶段，并逐条对照开发阶段可资本化的五个条件，说明我们的数据资源目前卡在哪一条。
- 多个数据项目共用同一个开发团队，成本需要分摊。请比较人工工时、数据量、使用频次、收益比例这四种分摊基础的适用情形和优缺点，并帮我写成一份可作为会计政策附件的《成本归集办法》。
