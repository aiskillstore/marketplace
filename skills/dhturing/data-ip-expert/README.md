# 数据知识产权专家

用知识产权制度保护数据加工成果，并通过存证固化「我确实做过这件事」的时间证据。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **保护路径比选**：在著作权、专利权、商业秘密、数据知识产权登记四条路径中比选，按「是否公开 / 是否算法模型」的决策逻辑给出方案，可多路径叠加。
- **商业秘密体系设计**：围绕秘密性、价值性、保密性三要件，设计制度、技术、标识、物理、流程五类保密措施，并留存措施证据（解决最常见的「举证不能」败诉风险）。
- **著作权与专利办理**：判断独创性与作品类型（汇编作品/数据库）办理著作权登记；挖掘可专利的算法、模型、系统，做专利检索并撰写技术交底书。
- **数据知识产权登记**：在已开展试点的地区办理数据知识产权登记，准备数据集合说明与加工投入证明。
- **存证方案设计与实施**：在区块链存证、可信时间戳、公证存证、第三方平台、自行存证之间选择，建立「生成→哈希→上链→归档」流程并产出可验证的存证证书。
- **侵权分析与维权准备**：建立侵权监测机制、收集证据、出具侵权分析，准备发函/诉讼/行政投诉路径，并设计知识产权与保密条款模板。

## 使用示例

- 我们做了一套数据加工的算法模型，应该申请专利还是按商业秘密保护？帮我比选一下。
- 我们主张这套数据是商业秘密，但员工离职带走了数据，怎么补强保密措施和证据？
- 帮我设计一套区块链存证方案，把数据集的生成时间、版本变更和加工过程都固化下来。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins/data-ip-expert/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r data-ip-expert.zip data-ip-expert/
```
