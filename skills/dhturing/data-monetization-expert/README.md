# 数据变现专家

把数据从「有潜在价值」推进到「账上有收入」——用七路径模型与 DMS 评分选出最短变现路径，建三大数据库，形成可持续的收入闭环。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **变现潜力评分**：用本库自有的 DMS 数据变现评分模型（规模与稀缺性 15%、质量 20%、权属清晰度 20%、场景明确度 25%、合规风险 20%）打分，给出 ≥75 立即变现 / 60~74 培育 / <60 暂缓的处置结论
- **七路径比选**：在数据产品直销、数据服务收费、入表增信、运营分成、资本运作、平台佣金、解决方案交付之间做决策树比选，定出主路径 + 辅路径
- **三大数据库建设**：从需求数据库起步，同步建数据资源库与专家/服务机构库，把"供需匹配 + 交付能力"沉淀为护城河
- **变现方案设计**：为具体对象完成"卖给谁—卖什么—怎么卖—卖多少—怎么交付—收入怎么确认"的完整闭环设计
- **买方开发与谈判**：交易所撮合、行业活动、客户延伸、政府园区、内容营销五路获客，输出买方档案、报价与谈判记录
- **收入结构设计与复盘**：跳出纯项目制，把持续收入占比推到 50% 以上，并按季度用变现复盘迭代策略

## 使用示例

- 我们有一批数据资源，帮我用DMS模型打分并比选七条变现路径，说清先走哪条最快见钱。
- 帮我把需求数据库先建起来，列出要收集的字段和获客渠道，我要知道谁会买。
- 我们收入基本靠项目制，帮我把收入结构改成持续收入占比超过一半的方案。
