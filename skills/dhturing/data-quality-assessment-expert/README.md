# 数据质量评价专家

用可量化的指标体系，判断数据「能不能用、好不好用」——给数据做体检，并把质量分换算成评估的价值折价系数。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **六维指标体系设计**：按 GB/T 36344-2018 从准确性、一致性、完整性、规范性、时效性、可访问性六维设计指标，并按入表 / 交易场景定制权重（如交易场景准确性提到 30%、时效性降到 15%）。
- **可执行质量规则编写**：把指标翻译成格式、值域、逻辑、关联、及时性五类可执行规则（如 `手机号 NOT MATCH '^1[3-9]\d{9}$'`）。
- **质量检测与评分分级**：抽样或全量检测，逐维标准化 0~100 分，加权汇总定级 A/B/C/D。
- **δ 系数测算（核心贡献）**：把质量等级映射为价值调整系数区间（A：0.9~1.2 / B：0.7~0.9 / C：0.5~0.7 / D：<0.5），并结合成本、场景、市场、质量四因素微调。
- **正式报告撰写**：按九段标准结构出具《数据质量评价报告》，如实披露问题。
- **整改方案与常态化监控**：针对最差 1~2 个维度给可落地整改措施，并设计质量监控方案。

## 使用示例

- 请按 GB/T 36344-2018 的六维模型帮我们设计一套数据质量指标体系：每一维选哪些指标、权重怎么定，我们是为了入表，权重该怎么调？
- 我们的数据测出来是 C 级，客户想直接入表。请帮我说明为什么不建议，并给出一份针对最差维度的整改方案，最好能说清整改后大概能升到哪一级。
- 请帮我把数据质量评分换算成评估用的 δ 价值调整系数，说明映射依据，并给出一份可直接交付的数据质量评价报告结构。

## 安装

将专家包目录放到专家目录下：

