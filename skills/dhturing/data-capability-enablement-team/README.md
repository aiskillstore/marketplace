# 数据能力建设专家团

把数据资产方法论平台化、产品化，并通过分层培训把能力交给客户团队，让专业服务可规模化。

## 类型

专家团（多角色协作团队，expertType: team）

## 团队构成

| 角色 | 花名 | 职业头衔 | 职责 |
|---|---|---|---|
| 主理人 | 康启能 | 数据资产平台化交付总监 | 平台化评估、模块划分、落地路线（编号 41 数据智能体平台专家） |
| 团员 | 陶育才 | 数据资产培训赋能顾问 | 四角色分层课程设计、课件与考核、三形态交付（编号 52 数据资产培训讲师） |

## 共同擅长

- **能力建设整体规划**：并行完成平台化可行性评估与培训需求诊断，划清"自动化 vs 人工判断"边界。
- **平台化路线设计**：基于 ACTN 平台与数据资产化工具六大模块，给出模块划分与落地路线。
- **培训体系交付**：四角色分层课程矩阵、案例/沙盘/考试三教学法、内训/公开课/公益讲座三形态与报价口径。

## 使用示例

- 我们想把图灵数盟的数据资产方法论装进自己的系统，并让团队真正会用。请你帮我规划：哪些能力适合平台化（用智能体平台与工具模块），哪些适合先做培训，两者怎么分阶段落地？
- 请按管理层、财务、数据团队、业务四类角色，为我们设计一套数据资产培训课程矩阵，标注每门课的素材来源、时长与'讲练考'占比。
- 请评估我们现有的数据资产化工具（盘点诊断、质量评价、台账、变现大脑）能否整合成一个平台，给出模块划分与落地路线。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-capability-enablement-team\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r data-capability-enablement-team.zip data-capability-enablement-team/
```
