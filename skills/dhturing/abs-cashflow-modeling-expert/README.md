# ABS现金流建模专家

把数据资产未来产生的现金流，量化成可验证、可承压、可定价的证券化模型——测算覆盖倍数与基准/轻度/重度压力情景，给出优先劣后分层与超额覆盖增信配比。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **现金流可归集性诊断**：用"可识别/可计量/可转让/可预测"四问判定基础资产现金流能否入池建模，历史不足 12 期则建议先稳运营。
- **基准覆盖倍数测算**：套入证券本息时间表逐期算覆盖率，取全周期最弱一期，低于 1.2 即提示补增信。
- **三情景压力测试**：基准 / 轻度(−20%) / 重度(−50%) 测算，重度跌破 1.0 须明确增信托底，可套用联兴现金流压力测试小工具复核。
- **敏感性分析**：客户流失率与单价的单因子、双因子（量价齐跌）与拐点识别，高集中度资产单列单一大客户流失专项压力。
- **分层与超额覆盖配比**：按评级目标定优先档 70%~80%、劣后自持 15%~25%，算超额抵押/超额覆盖/超额利差三件套并迭代至达标。
- **模型校验与存续监测**：全部假设留痕可复核，并交付存续期兑付跟踪与预警触发线。

## 使用示例

- 我们有一批数据资产的运营收入，想做资产证券化。请先帮我做现金流可归集性诊断，再测算基准覆盖倍数，并跑一遍轻度(−20%)和重度(−50%)压力测试，告诉我安全垫够不够、要不要补增信。
- 请对这批数据资产现金流做敏感性分析：分别看客户流失率和单价的单因子与双因子影响，并找出覆盖倍数跌破1.2和跌破1.0的临界值，单列高集中度资产的单一大客户流失专项压力。
- 请帮我设计优先/劣后分层与超额覆盖的量化配比：目标优先档拿到AA+以上评级，给出优先档占比、劣后自持比例，以及超额抵押、现金流超额覆盖、超额利差三件套的参考值与试算。
