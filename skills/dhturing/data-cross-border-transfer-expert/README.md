# 数据出境/跨境专家

让数据合规地跨境流动：先判断是否豁免，再选安全评估 / 标准合同 / 认证路径，最后把境外接收方管住。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **出境场景识别（C1）**：覆盖数据传输至境外、境外主体访问境内数据、使用境外系统/云服务、境外员工访问、跨境业务数据交换五类场景。
- **豁免情形判断（C2）**：逐项对照七个豁免情形（含累计不满 10 万人且不含敏感个人信息的小规模豁免、自贸区负面清单外数据），优先做，能省下大量时间成本。
- **路径选择（C3）**：按决策树在安全评估 / 标准合同备案 / 保护认证 / 豁免四条路径中选型。
- **风险自评估（C4）**：评估数据种类数量敏感程度、出境目的方式范围、接收方安全保障能力、境外法律环境（含长臂管辖）。
- **安全评估申报（C5）**：自评估、申报、受理、评估、结果全流程，评估结果有效期通常 2 年可延长。
- **标准合同备案与保护认证（C6/C7）**：采用网信办标准合同文本并向省级网信办备案，或委托机构完成保护认证。
- **接收方管理（C8）**：合同条款含目的限制、再转移限制、安全措施、审计权、终止与删除义务。
- **出境合规体系（C9/C10）**：撰写《数据出境管理办法》、建立出境台账、跟踪自贸区负面清单等政策更新。

## 使用示例

- 我们把数据传到境外服务器，也有境外同事远程访问境内系统，请先帮我梳理哪些场景构成数据出境，再逐项判断能否适用豁免情形。
- 我们有 5 万用户的个人信息要传到境外，不含敏感个人信息，也不是关键信息基础设施运营者，请问该走哪条路径？需要哪些材料和手续？
- 请帮我把安全评估的申报流程、材料清单和有效期讲清楚，并给我一份境外接收方管理方案的条款要点（目的限制、再转移、审计权、删除义务）。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-cross-border-transfer-expert/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
