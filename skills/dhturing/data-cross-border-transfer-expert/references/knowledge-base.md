# 数据出境/跨境专家

> 所属战队：06-合规安全与政策
> 专家编号：37
> 核心使命：让数据合规地跨境流动，既让企业的国际化业务跑得动，又不越监管红线

---

## 第一部分 · 知识库

### 1.1 一句话定位

数据出境专家处理**数据跨越国境**这一最敏感的合规领域。他的核心工作是判断：

1. **该不该出境**：能否用替代方案（如境内处理、数据不出境）
2. **怎么合法出境**：走哪条合规路径（安全评估/标准合同/认证/豁免）
3. **怎么闭环**：出境后的接收方管理、再转移限制、审计

**为什么这个专家对数据资产化重要**：
- 跨境数据资产交易、境外发行（专家 33）、跨国企业数据资产运营都要用到
- 数据出境是**跨境融资的四重门之一**（见专家 33）
- 本库有专门材料：《企业数据出海合规调查表》《中资出海挑战与应对策略》

### 1.3 核心模型一：四条出境合规路径

这是本专家最核心的判断框架（依《促进和规范数据跨境流动规定》优化后的体系）：

| 路径 | 适用情形 | 流程 | 周期 |
|---|---|---|---|
| **1. 安全评估** | 重要数据出境；关键信息基础设施运营者出境；达规模个人信息出境 | 向网信办申报评估 | 较长（数月） |
| **2. 标准合同备案** | 个人信息出境且未达安全评估门槛 | 签订标准合同 + 备案 | 中 |
| **3. 保护认证** | 个人信息出境（可替代标准合同） | 通过专业机构认证 | 中 |
| **4. 豁免** | 符合规定的不需履行程序 | 无需申报 | 无 |

**路径选择决策树：**

```
是否含重要数据？
├─ 是 → 安全评估（必须）
└─ 否 → 是否是关键信息基础设施运营者？
        ├─ 是 → 安全评估
        └─ 否 → 是否含个人信息？
                ├─ 否 → 检查是否属豁免情形
                │        ├─ 是 → 豁免
                │        └─ 否 → 视情况（一般不需程序，但需合法基础）
                └─ 是 → 数量是否达门槛？
                        ├─ 是 → 安全评估
                        └─ 否 → 标准合同 or 保护认证 or 豁免情形
```

### 1.4 核心模型二：豁免情形（重要！）

《促进和规范数据跨境流动规定》明确了多种**豁免情形**，这是实务中最重要的"减负"工具：

| 豁免情形 | 说明 |
|---|---|
| **国际贸易、跨境运输、学术合作、跨国生产制造和市场营销等活动中收集和产生的数据，不包含个人信息或重要数据的** | 无个人信息/重要数据即可自由出境 |
| **在境外收集和产生的个人信息传输至境内处理后向境外提供，处理过程中未引入境内个人信息或重要数据的** | 过境数据豁免 |
| **为订立、履行个人作为一方当事人的合同所必需**（如跨境购物、寄递、汇款、支付、开户等） | 合同必需豁免 |
| **按照依法制定的劳动规章制度和依法签订的集体合同实施跨境人力资源管理所必需** | HR 管理豁免 |
| **紧急情况下为保护自然人生命健康和财产安全所必需** | 紧急豁免 |
| **非关键信息基础设施运营者，自当年 1 月 1 日起累计向境外提供不满 10 万人个人信息（不含敏感个人信息）** | 小规模豁免 |
| **自贸区负面清单外的数据** | 自贸区便利 |

**实务价值**：多数企业的数据出境其实落在豁免情形内。**先判断是否豁免，能省下大量时间成本**。

### 1.5 核心模型三：安全评估的申报流程

| 步骤 | 内容 | 材料 |
|---|---|---|
| **1. 自评估** | 开展数据出境风险自评估 | 《数据出境风险自评估报告》 |
| **2. 申报** | 通过网信办系统申报 | 申报书 + 自评估报告 + 法律文件 |
| **3. 受理** | 网信办受理 | 受理通知 |

| **6. 有效期** | 评估结果有效期（通常 2 年，可申请延长） | — |

**申报材料清单：**
```

```

### 1.6 核心模型四：境外接收方管理

数据出境不是"传出去就完事"，还要管理接收方：

| 管理项 | 要求 |
|---|---|
| **法律约束** | 与境外接收方签订法律文件（合同/协议），明确处理目的、方式、范围、期限、安全措施 |
| **目的限制** | 接收方不得超出约定目的处理 |
| **再转移限制** | 未经同意不得再转移给第三方 |
| **安全保障** | 接收方需采取与风险相当的安全措施 |
| **权利保障** | 保障个人的权利（可联系、可投诉） |
| **救济途径** | 明确法律救济方式 |
| **审计权** | 出境方保留审计权 |
| **终止与删除** | 约定终止后的数据删除义务 |

**实务提示**：标准合同路径有网信办发布的标准合同文本，建议直接采用（省去谈判成本）。

### 1.7 常见问题与标准答复

**Q1：我们把数据传到境外服务器算出境吗？**
A：算。只要数据传输到境外（包括境外服务器、境外主体访问境内数据），都可能构成出境。

**Q2：境外主体访问境内数据算出境吗？**
A：算。**"访问"也构成出境**——这是容易被忽略的点。远程访问同样受监管。

**Q3：我们有 5 万用户数据要传到境外，要做什么？**
A：非关键信息基础设施运营者 + 累计不满 10 万人 + 不含敏感个人信息 → **可能适用豁免**。但仍需：① 确认合法性基础；② 告知并取得单独同意；③ 与接收方签订协议。建议以当地网信部门口径为准。

**Q4：重要数据一定要做安全评估吗？**
A：是。重要数据出境**必须**申报安全评估，无豁免路径。

**Q5：安全评估结果有效期多久？**
A：通常 2 年。期满需重新评估或申请延长。

**Q6：自贸区有便利吗？**
A：有。部分自贸区实行**数据出境负面清单**管理——清单外的数据可自由出境。这是重要的政策红利。

### 2.2 标准作业流程 SOP

**S0 出境场景识别（1~2周）**
1. 梳理所有可能构成出境的场景：
   - 数据传输至境外
   - 境外主体访问境内数据
   - 使用境外系统/云服务
   - 境外员工访问
   - 跨境业务数据交换
2. 记录：数据类型、数量、接收方、目的、方式
3. 输出《出境场景清单》

**S1 数据分类判断（1~2周）**
1. 判断涉及数据是否含：
   - 重要数据（引用专家 35）
   - 关键信息基础设施相关
   - 个人信息（引用专家 36）
   - 敏感个人信息
3. 输出分类判断结论

**S2 豁免情形判断（1周，优先做）**
1. 逐项对照七个豁免情形
2. 若能豁免，明确援引依据
3. 输出《豁免判断意见》
4. **若能豁免，直接进入 S8 建立内部管理**

**S3 出境路径选择（1周）**
1. 按决策树选择路径：
   - 重要数据 → 安全评估
   - 个人信息达规模 → 安全评估
   - 个人信息未达规模 → 标准合同 or 保护认证
2. 输出《出境路径方案》

**S4 风险自评估（2~4周）**
1. 评估内容：
   - 出境数据的种类、数量、敏感程度
   - 出境目的、方式、范围
   - 境外接收方的安全保障能力
   - 所在国家/地区的法律环境（是否有长臂管辖等）
   - 数据泄露、篡改、滥用、丢失的风险
   - 个人权益维护渠道是否畅通
2. 输出《数据出境风险自评估报告》

**S5 安全评估申报（如适用，4~12周）**
1. 准备材料（申报书 + 自评估报告 + 法律文件）
2. 通过系统申报
3. 配合问询
4. 取得评估结果
5. 输出申报材料与结果

**S6 标准合同备案（如适用，2~6周）**
1. 采用网信办标准合同文本
2. 与境外接收方签署
3. 向省级网信办备案
4. 取得备案编号
5. 输出备案材料

**S7 保护认证（如适用，2~6周）**
1. 委托专业认证机构
2. 完成认证
3. 取得认证证书
4. 输出认证材料

**S8 接收方管理（2~3周）**
1. 设计合同条款（目的限制、再转移限制、安全措施、审计权、删除义务）
2. 建立接收方档案
3. 建立监督机制（定期问询、必要时审计）
4. 输出《接收方管理方案》

**S9 内部制度建设（2~3周）**
1. 撰写《数据出境管理办法》
2. 明确责任部门与流程
3. 建立出境台账
4. 输出制度文件

**S10 持续合规（持续）**
1. 跟踪法规更新（尤其自贸区负面清单）
2. 定期复核出境场景
3. 安全评估结果到期前续评
4. 输出合规报告

### 2.6 关键话术

- "先别急着申报。先判断是不是豁免——多数企业的数据出境其实在豁免范围内。"
- "境外主体**访问**境内数据也算出境，这一点很多企业不知道。"
- "重要数据出境没有豁免，必须走安全评估。"
- "自贸区有负面清单，清单外的数据可以自由出境——这是政策红利，值得关注。"

**风险提示**：
1. **"境外访问"构成出境**——常被忽略，导致无意违规
2. 重要数据出境无豁免，必须安全评估
3. 个人信息出境需**单独同意**（法定要求，常遗漏）
4. 安全评估结果有效期通常 2 年，需续评
5. 接收方再转移需受限制，否则责任仍在出境方
6. 境外法律环境（如长臂管辖）需评估
7. 自贸区政策有差异，需逐地确认
8. 监管口径持续优化，需跟踪最新规定
