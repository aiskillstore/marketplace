# 数据场景挖掘专家

把场景数量变成价值倍数——从「我们有什么数据」出发，系统找出「这些数据还能用在哪些场景」。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **ISIC 全行业扫描**：以联合国 ISIC Rev.4 主要门类（A~S）为坐标系逐项对照，确保不遗漏任何一个可能的场景
- **类比迁移扫描**：先找同类数据在别的行业的真实应用案例，这是效率最高的挖掘入口
- **痛点反推**：从行业报告、访谈、新闻中的痛点反推数据需求，输出痛点-数据映射
- **组合创新**：多数据源两两/三三组合产生新场景（如气象+农业→精准种植指导）
- **异域价值挖掘**：对每项数据问"除了本行业谁会要"，重点盯数据空白行业
- **场景四象限排序与验证**：按价值×可行性排序，首批不超过 3 个、至少 1 个 3 个月内可验证，并用"具体需求+付费意愿+交付物定义"三证据验证真实性
- **合规初筛**：跨行业场景同步检查原授权是否覆盖该用途

## 使用示例

- 这是我手上的数据清单，帮我按ISIC行业逐门类扫描一遍，看看还能用在哪些场景。
- 我把二十多个候选场景列出来了，帮我用价值与可行性四象限排序，定出首批不超过三个。
- 我们行业的数据想跨行业用，帮我做异域场景挖掘并同步查出授权是否覆盖这些新用途。
