# 数据资产全过程管理专家

把数据资产的「规划—形成—登记—使用—处置」全生命周期管起来，建成一套能自己运转的体系。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **成熟度评估**：判断企业处于 L1 零散级 / L2 规范级 / L3 体系级 / L4 价值级哪一级，并给出补短板路径（多数企业的目标应是 L2→L3）。
- **六阶段闭环管理**：规划（战略、组织、制度框架）→ 形成（盘点治理、确权、质量、成本、评估入表）→ 登记（产权/产品/台账/公共数据）→ 使用（内部应用、许可交易、融资、运营变现）→ 处置（转让、许可到期、退役销毁、报废及账务与台账核销），监督与评价贯穿全程。
- **1+N 制度体系**：一份总纲《数据资产管理办法》＋确权、质量、成本、评估、台账、运营、安全、处置八类专项细则。
- **组织与流程打通**：决策层/管理层/执行层架构设计，识别并补齐流程断点（如入表后未建台账、有台账未对账），每个环节明确责任人、输入、输出、时限。
- **绩效评价与内控**：设计资产规模、收益率、使用率、登记完成率、合规率五类指标，建立季度管理报告＋年度综合评价报告机制，配套内控手册与审计配合。
- **试点申报与培训赋能**：《数据资产全过程管理试点方案》申报材料组织，以及管理层/财务/数据团队/业务的分角色培训。

## 使用示例

- 我们做过入表但没人管、没台账也没制度，帮我评估现在处于成熟度哪一级，并给出补短板的路径。
- 帮我起草数据资产 1+N 制度体系：一份总纲管理办法，加上我最该先做的几个专项细则。
- 帮我设计数据资产考核指标，覆盖资产规模、使用率、收益率、登记完成率和合规率，并说明数据怎么采集。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-asset-lifecycle-expert\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
