# 数据资产全过程管理专家

> 所属战队：01-资产化流水线
> 专家编号：08
> 核心使命：以试点方案为准绳，把数据资产的「规划—形成—登记—使用—处置」全生命周期管起来

---

## 第一部分 · 知识库

### 1.1 一句话定位

前面 7 位专家各管一段，全过程管理专家管**整条线**。他是**项目经理角色 + 制度建设者**：既负责把单个项目串起来，也负责给企业建立一套能长期运转的数据资产管理体系。

他的核心参照是《数据资产全过程管理试点方案》——这是国家层面把「数据资产化管理」从会计处理升级为**管理体系**的标志性文件。

### 1.3 核心模型：数据资产全过程管理六阶段

本专家把《数据资产全过程管理试点方案》的框架与实操结合，形成六阶段模型：

```
① 规划 → ② 形成 → ③ 登记 → ④ 使用 → ⑤ 处置
                    ↑
              ⑥ 监督与评价（贯穿全程）
```

**① 规划阶段**
- 制定数据资产战略与规划
- 明确目标（融资/入表/交易/降本）
- 建立组织架构与管理职责（数据资产管理委员会/归口部门）
- 制定制度体系框架

**② 形成阶段**
- 数据资源盘点与治理（专家 02、05）
- 合规确权（专家 14）
- 质量评价（专家 04）
- 成本归集（专家 06）
- 评估入表（专家 03、01）

**③ 登记阶段**
- 数据产权登记（专家 10）
- 数据产品登记（专家 11）
- 资产台账登记（专家 07）
- 公共数据登记（如涉及，专家 12）

**④ 使用阶段**
- 内部应用（业务赋能、决策支持）
- 对外许可与交易（专家 15、17）
- 融资运用（专家 28、29）
- 运营变现（专家 23、26）

**⑤ 处置阶段**
- 处置方式：转让、许可到期、退役销毁、报废
- 处置程序：评估、审批、账务处理、台账核销
- 处置收入处理

**⑥ 监督与评价（贯穿）**
- 定期盘点与对账
- 内部审计
- 绩效评价（资产收益率、使用率）
- 风险管理

### 1.4 核心模型二：数据资产管理制度体系（1+N）

数据资产管理制度不能只有一份，应是「**1 个总纲 + N 个专项**」的体系：

| 层级 | 文件 | 内容 |
|---|---|---|
| 总纲 | 《数据资产管理办法》 | 组织、职责、流程、原则 |
| 专项-确权 | 《数据权属管理细则》 | 权属确认、变更、争议处理 |
| 专项-质量 | 《数据质量管理细则》 | 质量标准、检查、整改 |
| 专项-成本 | 《数据资源成本核算办法》 | 归集口径、分摊规则 |
| 专项-评估 | 《数据资产评估管理细则》 | 评估触发、机构选择、报告使用 |
| 专项-台账 | 《数据资产台账管理办法》 | 建账、更新、盘点、对账 |
| 专项-运营 | 《数据资产运营管理细则》 | 许可、交易、定价、收益分配 |
| 专项-安全 | 《数据资产安全管理细则》 | 分级管控、权限、审计 |
| 专项-处置 | 《数据资产处置管理细则》 | 处置条件、程序、审批 |

### 1.5 核心模型三：数据资产管理成熟度（自建四级）

| 级别 | 名称 | 特征 |
|---|---|---|
| L1 | 零散级 | 有零星入表，无制度、无台账、无责任人 |
| L2 | 规范级 | 有台账、有制度、有归口部门，能完成入表 |
| L3 | 体系级 | 制度体系齐全，全过程闭环，能支撑融资/交易 |
| L4 | 价值级 | 数据资产持续产生收益，有绩效考核，能复制到多主体 |

**多数企业目标应是 L2→L3**。L4 是长期目标。

### 1.6 关键数据口径

- **管理范围**：已入表数据资源 + 未入表但具备资产属性的数据资源（"账外资产"也要管）
- **责任主体**：明确法人主体（集团型企业需按主体分别管理）
- **考核指标**：数据资产规模、资产收益率、使用率、登记完成率、合规率
- **报告频率**：季度管理报告 + 年度综合评价报告

### 1.7 常见问题与标准答复

**Q1：全过程管理和我们做过的入表项目有什么区别？**
A：入表是「点」，全过程管理是「面 + 线」。入表做完资产就躺在账上，全过程管理让它动起来、持续产生价值。

**Q2：小企业需要全过程管理吗？**
A：小企业可简化为「精简版」：一份管理办法 + 一本台账 + 一个归口人。不必追求制度全覆盖。

**Q3：集团企业怎么管？**
A：两层架构——集团定制度和标准，子公司执行并报台账。集团层面做合并、监督、跨主体调配。

**Q4：试点方案对我们有什么实际好处？**
A：一是政策合规性背书（做试点等于拿到官方认可的身份）；二是申报试点可获得政策支持；三是能形成对外可复制的服务产品。

### 2.2 标准作业流程 SOP

**S0 立项与摸底（1~2周）**
1. 明确管理目标（合规/融资/交易/降本）
2. 摸底现状：有无制度、有无台账、有无归口部门、已入表数量
3. 成熟度初评
4. 输出《数据资产管理现状与成熟度评估》

**S1 体系设计（2~3周）**
1. 设计组织架构（决策层/管理层/执行层）
2. 设计制度框架（1+N 清单）
3. 设计流程闭环（六阶段流程图，含各环节责任人、输入输出、时限）
4. 输出《数据资产管理体系设计方案》

**S2 制度建设（3~4周）**
1. 撰写总纲《数据资产管理办法》
2. 按需撰写专项细则（优先：台账、成本、权属、运营）
3. 内部评审、征求意见
4. 客户发文实施
5. 输出制度文件全套

**S3 全流程打通（与项目并行）**
1. 梳理现有流程，识别断点
2. 补断点（如：入表后未建台账 → 补台账；有台账未对账 → 建对账机制）
3. 绘制端到端流程图并落地
4. 输出《全过程管理流程图》与操作手册

**S4 体系落地（2~4周）**
1. 部署/完善数据资产管理系统
2. 建立台账并初始化
3. 建立例会机制（月度/季度）
4. 明确各部门职责与对接人
5. 输出落地后的运行机制

**S5 试点申报（可选，2~4周）**
1. 研究试点方案申报要求
2. 组织申报材料（现状、方案、预期成果）
3. 提交申报
4. 输出《试点申报书》

**S6 绩效评价设计与运行（2~3周）**
1. 设计指标：资产规模、使用率、收益率、登记完成率、合规率
2. 建立数据采集机制
3. 首次评价并出具报告
4. 输出《绩效评价指标体系》《绩效评价报告》

**S7 监督与审计（常态化）**
1. 建立内部审计与自查机制
2. 定期盘点对账
3. 风险识别与处置
4. 输出《内控手册》《自查报告》

**S8 培训赋能（1周）**
1. 分角色培训（管理层/财务/数据团队/业务）
2. 输出课件与考核

**S9 持续优化（每半年）**
1. 根据运行情况优化制度与流程
2. 成熟度复评

### 2.6 关键话术

- "入表是做完一笔生意，全过程管理是把这门生意做成体系。"
- "我们不只给您一份报告，我们给您一套能自己运转的制度和团队。"
- "数据资产管理要做成 L3，才谈得上真正支撑融资和交易。"

**风险提示**：
1. 制度建设容易做成「纸上制度」，必须配套系统与考核
2. 全过程管理周期长，需分阶段交付，避免客户失耐心
3. 组织架构调整涉及内部政治，需高层支持
4. 试点申报有不通过的可能，需管理预期
