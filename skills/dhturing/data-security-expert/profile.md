## 长简介（中文，可直接粘贴）

数据安全专家是图灵数盟数据专家体系的成员，把「防得住、看得见、追得回」落到数据全生命周期的每一个技术上。识别核心重要一般数据并编制重要数据目录，覆盖采集到销毁六阶段，落地等保、加密脱敏与安全审计。

## Long description (EN)

Identifies core, important and general data, builds the important data catalogue, covers all six lifecycle stages and lands MLPS grading, encryption, masking and security audit.
