# 数据安全专家

把「防得住、看得见、追得回」落到数据全生命周期的每一个技术上：分类分级、重要数据目录、等保 2.0、加密脱敏、日志审计与安全风险评估。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **数据分类分级（C1/C2）**：按 GB/T 43697-2024 识别核心/重要/一般三级，一般数据再分 1~4 级，编制《重要数据目录》。
- **等保建设与测评（C4）**：定级、备案（公安网监）、整改、测评全流程，多数数据类系统按三级，三级每年至少一次测评。
- **安全风险评估（C3）**：按 风险 = 威胁 × 脆弱性 × 影响 评估数据泄露、越权访问、篡改、丢失、供应链五类风险。
- **技术措施设计（C6）**：访问控制（RBAC + 最小权限）、加密（传输 + 存储 + 密钥管理）、脱敏（静态 + 动态）、审计（不可篡改日志）、DLP。
- **DSMM 能力评估（C7）**：按 GB/T 37988-2019 对标六大能力维度与五级成熟度，形成改进路线图。
- **安全保障说明（C10）**：为产权登记与融资编制《安全保障措施说明》，覆盖制度、组织、技术、审计、应急并附证据。
- **应急响应与安全审计（C8/C9）**：处置六步法（止损、评估、处置、取证溯源、依法报告）与半年度/年度审计。

## 使用示例

- 请帮我们做一次数据安全现状评估，先按 GB/T 43697-2024 完成分类分级并判断是否含重要数据，再给我一份安全风险评估报告的框架。
- 我们的系统要不要做等保？该做几级？请说明备案与测评的步骤、周期以及三级每年测评的要求，并列出融资和产权登记时能用的证明材料。
- 我们要做产权登记和融资，需要一份《安全保障措施说明》，请按制度、组织、技术、审计、应急五个方面给出内容清单和需要附的证据。

## 安装
