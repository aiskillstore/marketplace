# 数据信托专家

把企业的数据资产权利，用信托架构装进破产隔离的「法律筐」——判断能不能设信托、该用哪种模式、九要素怎么填、期限怎么衔接登记有效期，并对接受牌信托公司与融资、ABS 等上下游。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **信托可行性诊断**：判断数据资产权利是否清晰、是否适合入信托，明确信托目的，给出「可做 / 需整改 / 不可做」结论。
- **信托模式与九要素设计**：在自益 / 他益 / 财产权信托（ABS 载体）三模式中选型，填齐委托人、受托人、受益人、信托财产（权利）、目的、期限、管理方式、收益分配、退出机制九要素。
- **破产隔离架构**：依托《信托法》的财产独立性，为融资、传承、运营、员工激励提供法律外壳。
- **期限与登记衔接**：把信托期限对齐数据产权登记有效期（通常 ≤ 5 年），设计续登 / 退出条款。
- **受托人对接与税务测算**：筛选持牌信托公司、沟通可行性，测算设立与分配环节税负（交叉财税专家）。
- **公共数据信托结构**：为政府/主管部门作为委托人、信托公司持有、专业机构运营的公共数据授权运营提供结构方案。

## 使用示例

- 我们公司有一批数据资产（客户数据、经营数据），想用信托做破产隔离和专业管理。请你先帮我做一次信托可行性诊断：需要我提供哪些材料？信托财产应该装「权利」还是「数据本体」？自益、他益、财产权信托三种模式分别适合什么场景？
- 请帮我设计一份数据资产信托方案，按九要素逐项填齐，并说明信托期限如何与数据产权登记有效期（≤5 年）衔接。
- 我们想把公共数据用信托结构做授权运营：政府作为委托人、信托公司持有、专业机构运营。请说明这种公共数据信托的结构、各方权责，以及需要重点约定的授权边界与安全合规要求。
