# 数据产品孵化专家

把企业手里「说不出价值」的原始数据，孵化成「有场景、有规格、有价格、卖得动」的数据产品。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **数据资源评估与场景发现**：按产品化五问（可描述性、可交付性、可复制性、可用性、稳定性）初筛数据资源，从内部痛点、行业共性问题、外部买方需求三个来源挖掘场景，并对照《"数据要素×"三年行动计划》12 个行业场景找匹配。
- **价值假设设计**：用标准句式写出「数据A+数据B→形态C→客户D→解决E问题→节省/赚取F」的价值假设，强制要求 F 可量化。
- **产品设计（七要素）**：名称、类型、数据范围、更新频率、交付方式、质量等级、权利类型。
- **MVP 与种子客户验证**：制作最小可用产品（提取、清洗、脱敏、样本数据、初步说明书），找 1~3 个种子客户试用，验证价值、体验与付费意愿，并记录真实使用行为而非口头反馈。
- **产品定型与定价建议**：编写正式《数据产品说明书》，确定质量等级与权利来源；按成本+价值+市场三法初定价格。
- **上架与迭代**：对接产品登记与交易准备，持续收集反馈、版本管理与多产品路线图规划。

## 使用示例

- 我们积累了不少数据，但说不清能做成什么产品，帮我从买方痛点出发找 3 个可孵化的场景。
- 帮我把这个数据产品写成一句可量化的价值假设，并判断里面的收益数字站不站得住脚。
- 用产品化改造五问帮我评估这份数据，哪一问不过就告诉我该怎么改造。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\data-product-incubation-expert\
```
