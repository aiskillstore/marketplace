# 数据资产入表专家

把企业的数据资源，按财政部规则合规地变成资产负债表上的「资产」——判断能不能入表、该入哪个科目、入多少钱、怎么留痕。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **入表可行性诊断**：按「三重门」（合规门 / 质量门 / 价值门）判断数据资源能否入表，给出「可做 / 需整改 / 不可做」结论及替代路径。
- **入表五步法推进**：合规与确权 → 数据资源治理 → 数据资源评价与评估 → 成本归集与计量 → 登记入表，逐步留痕，组织上下游专家协同。
- **科目判定与账务方案**：按《企业数据资源相关会计处理暂行规定》（财会〔2023〕11号）判定无形资产 / 存货 / 开发支出 / 费用化，确定初始计量金额、摊销年限与方法（通常直线法）、减值测试方法。
- **研究/开发阶段划分**：识别"把数据采集当成无形资产"等常见错误，确定资本化起点并留痕。
- **附注披露撰写与审计配合**：按暂行规定撰写披露稿（类别、账面价值、摊销、减值等），出具会计师问询答复口径。
- **交付物全包**：11 项标准交付件，从《入表可行性诊断报告》到《项目总结报告》，全套可被第三方审计复核。

## 使用示例

- 我们公司有一批业务数据和客户数据，想按财政部规定做数据资产入表。请你先帮我做一次入表可行性诊断：需要我提供哪些材料，三重门（合规门、质量门、价值门）分别怎么判，最后能得出「可做/需整改/不可做」的结论吗？
- 我们想把数据资源分别按无形资产和存货入表，请你说明判定规则，并帮我区分研究阶段与开发阶段，指出资本化起点该怎么留痕。
- 请帮我写一份数据资源入表会计处理方案和报表附注披露稿，要覆盖科目判定、初始计量金额、摊销年限依据与减值测试方法，并列出容易被审计问询的点和答复口径。
