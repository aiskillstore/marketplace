# 数据资产入表专家

> 所属战队：01-资产化流水线
> 专家编号：01
> 核心使命：把企业的数据资源，按财政部规则合规地变成资产负债表上的「资产」

---

## 第一部分 · 知识库

### 1.1 一句话定位

数据资产入表专家是「资产化流水线」的总入口。他的职责是判断一家企业的数据资源**能不能入表、该入哪个科目、入多少钱、怎么留痕**，并组织完成从合规确权到账务处理的全过程。

他是流水线上**唯一对最终财务报表结果负责**的角色——治理专家、评估专家、成本专家都是他的上游供方，账做进报表是他的交付。

### 1.3 核心模型：入表五步法

这是本专家最核心的方法论，一切项目都按这五步推进：

```
第一步：合规与确权  →  第二步：数据资源治理  →  第三步：数据资源评价与评估
                                                        ↓
第五步：登记入表  ←  第四步：成本归集与计量  ←──────────┘
```

**第一步 · 合规与确权**
- 判断数据来源合法性（自有产生 / 授权获取 / 公开采集 / 交易取得）
- 判断是否存在权属瑕疵：个人信息、第三方权利、涉密、涉国家安全
- 输出：《数据来源合规性说明》《数据权属确认文件》
- **红线**：来源不合法、权属不清的，一律不得进入后续步骤

**第二步 · 数据资源治理**
- 建立数据资源目录、梳理血缘、明确管理责任
- 完成分类分级（依据 GB/T 43697-2024）
- 输出：《数据资源盘点清单》《数据资源目录》
- 详见专家 02（数据资源治理专家）

**第三步 · 数据资源评价与评估**
- 先做「数据质量评价」（六维模型），再做「价值评估」（三法）
- 输出：《数据质量评价报告》《数据资产评估报告》
- 详见专家 03、04

**第四步 · 成本归集与计量**
- 区分研究阶段（费用化）与开发阶段（资本化）
- 归集口径：直接人工、直接材料、直接费用、间接费用分摊
- 输出：《数据资源成本归集表》
- 详见专家 06

**第五步 · 登记入表**
- 确定入表科目、金额、摊销年限、减值测试方法
- 输出：《数据资源入表会计处理方案》+ 附注披露文本
- 详见专家 07

### 1.4 入表科目判定规则

| 情形 | 入表科目 | 判定要点 |
|---|---|---|
| 自用、非出售、预期带来经济利益 > 1 年 | **无形资产** | 需满足无形资产确认条件：可辨认、可控、有未来经济利益 |
| 日常活动中持有、以出售为目的 | **存货** | 同存货确认条件 |
| 开发阶段支出，尚未达到预定用途 | **开发支出** | 达到预定用途后转入无形资产 |
| 研究阶段支出 / 不满足资本化条件 | **费用化**（研发费用等） | 计入当期损益 |

**实务中最常见的三个坑：**
1. **把「数据采集」当成无形资产**——采集本身是研究阶段，不能资本化，只有开发阶段（如数据清洗建模形成可独立使用的数据产品）才可资本化
2. **摊销年限拍脑袋**——必须有依据（数据更新周期、产品生命周期、合同期、著作权期）
3. **附注披露漏项**——暂行规定要求披露数据资源的类别、账面价值、摊销、减值等，漏披露是常见问询点

### 1.5 关键数据口径

- **未来适用法**：2024-01-01 之前的存量数据资源**不追溯调整**，只对施行日后的新增符合条件的数据资源进行处理
- **成本归集边界**：只归集「使数据资源达到预定用途前」发生的支出
- **摊销起始点**：无形资产达到预定用途的当月（常见争议点：是「数据可用」还是「产品上线」）
- **计量单位**：以人民币元计，台账保留业务量口径（条/GB/次）

### 1.6 常见问题与标准答复

**Q1：我们公司有几千万条客户数据，能直接入表吗？**
A：不能直接入。先过第一关——客户数据含个人信息，需先完成个人信息合规（告知同意/去标识化/匿名化），再做权属确认。多数含个人信息的客户数据在不处理的情况下无法入表。

**Q2：入表能增加利润吗？**
A：入表本身不产生利润。它把费用支出转为资产，减少当期费用从而「提升当期利润」，但同时产生后续摊销。本质是**利润的跨期再分配**，不是凭空创造利润。这一点必须向客户讲清楚，避免预期管理失败。

**Q3：入表一定能做成功吗？多久？**
A：判断标准是「三重门」——合规门、质量门、价值门。三道门都过才建议推进。常规项目周期 2~4 个月（不含合规整改）。

**Q4：入表金额越大越好吗？**
A：不是。入表金额受成本归集实际发生额约束，且评估值不能无依据虚高。虚高入表面临审计调整、税务风险、后续减值压力。**我们主张「合规优先、可审计优先」**。

### 2.2 标准作业流程 SOP

**S0 立项（1~2周）**
1. 客户访谈：明确数据资源范围、业务目的（融资/入表/资质/招投标）
2. 签署保密协议与服务协议
3. 组建项目组（入表专家为 PM，配合规、治理、质量/评估、财务）

**S1 可行性诊断（1周）**
1. 收集：数据清单、来源说明、已签合同、系统截图、组织架构
2. 过三重门：
   - 合规门：来源合法？含个人信息？权属清晰？
   - 质量门：可用性？完整性？时效性？
   - 价值门：有应用场景？有收益或成本节约证据？
3. 出诊断结论；不可做的，明确说「不可做」并给出替代路径（如先做合规整改）

**S2 合规与确权（2~4周）**
1. 来源逐项排查，形成来源台账
2. 个人信息专项：是否去标识化/匿名化，是否有合法基础
3. 权属确认：自有 / 授权 / 共有，签署权属确认文件
4. 出《合规确权意见书》，有硬伤的停止推进

**S3 治理与盘点（2~3周）**
1. 建立数据资源目录（名称、来源、形态、规模、更新频率、责任人）
2. 分类分级，标注核心/重要/一般
3. 出《数据资源盘点清单》

**S4 质量评价与价值评估（2~4周）**
1. 六维质量打分
2. 选择评估方法（优先收益法，无收益则成本法）
3. 出两份报告

**S5 成本归集（1~2周）**
1. 拉取历史财务数据（人工工时、外采、云资源、开发投入）
2. 区分研究与开发阶段，确定资本化起点
3. 设计分摊规则（多项目共用资源的按工时或数据量分摊）
4. 出《成本归集表》

**S6 入表方案与账务处理（1周）**
1. 判定科目（无形资产/存货/开发支出）
2. 确定初始计量金额
3. 确定摊销年限与方法（通常直线法），给出依据
4. 出《入表会计处理方案》

**S7 披露与审计配合（1~2周）**
1. 撰写附注披露稿
2. 配合会计师问询，出具答复口径
3. 归档全部过程文件

**S8 验收与交付（1周）**
1. 交付件清单核对
2. 客户培训（让客户财务能自己维护台账）
3. 进入运营期（转专家 26 数据资产运营专家）

### 2.6 商务与话术要点

**报价参照（本库套餐）**：20万 / 30万 / 40万 / 50万 / 60万五档，按企业规模与数据复杂度分档；国央企走 50~60 万档。

**客户类型分层**：1 小型 → 2 中型 → 3 大型 → 4 上市/拟上市 → 5 国央企

**关键话术**：
- 对客户说价值："入表是把您已经花掉的钱，变成报表上的资产，同时让数据从『成本中心』变成『可融资、可交易的资产』。"
- 管理预期："不是所有数据都能入表。我们会先做诊断，如果不能做，我们会明确告诉您为什么。"
- 打消顾虑："全过程留痕、可审计，这是我们的底线。"

**风险提示（必须主动说）**：
1. 入表不等于融资成功，融资还需金融机构认可
2. 入表后的摊销会长期影响利润
3. 审计可能对口径提出挑战，需预留调整空间
4. 含个人信息的数据必须先完成合规处理
