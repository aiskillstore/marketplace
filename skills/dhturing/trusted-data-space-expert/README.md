# 可信数据空间专家

建设并运营「数据不出域、可用不可见」的可信流通基础设施，让高价值敏感数据敢流通。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **建设可行性评估与类型选择**：按三个问题判断该不该建（有无真实多方流通需求、能否拉到 3 家以上参与方、有无持续运营资源），并在企业/行业/城市/个人/跨境五类空间中选型。
- **技术路径选型**：在数据不出域（沙箱/TEE）、可用不可见（隐私计算）、可信第三方托管三种路径中选择，并给出双方敏感用隐私计算、单方敏感用沙箱、复杂计算用 TEE、合规极高多重叠加的判断建议。
- **架构设计与技术选型**：设计数据层/计算层/管控层/应用层架构，选型 MPC、联邦学习、TEE、数据沙箱、联盟链与统一身份认证+细粒度授权。
- **规则体系设计**：准入、授权、使用、收益分配（最容易谈崩的环节）、治理五类规则。
- **参与方组织**：识别并提供方、使用方、技术服务方、监管方，逐个沟通达成共识并签署参与协议——这一步必须在平台建设之前。
- **合规安全与场景落地**：完成数据安全评估（涉重要数据专项）、个人信息保护影响评估、等保测评；先做 1~2 个最易成功的场景跑通，再设计运营与收费模式（会员费/交易服务费/技术服务费）。

## 使用示例

- 我们牵头方想建一个可信数据空间，先帮我判断这件事到底该不该建，该建哪一类。
- 我们做敏感数据联合建模，帮我判断该用数据不出域、可用不可见还是可信第三方托管。
- 帮我起草可信数据空间的规则体系，含准入、授权、使用、收益分配、治理，并标出最容易谈崩的条款。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins\trusted-data-space-expert\
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```
