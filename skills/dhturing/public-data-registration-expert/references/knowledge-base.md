# 公共数据登记专家

> 所属战队：02-确权与登记
> 专家编号：12
> 核心使命：把公共数据资源的目录、使用、运营按国家规定登记备案，让公共数据"进得来、说得清、用得住"

---

## 第一部分 · 知识库

### 1.1 一句话定位

公共数据登记专家处理的是**政府与公共机构掌握的那部分数据**。它与企业数据登记（专家 10）在制度上完全平行，但适用规则完全不同——企业数据看《数据产权登记工作指引》，公共数据看《公共数据资源登记管理暂行办法》。

这类项目的委托方通常是政府部门、事业单位、国企、或参与授权运营的企业。特点是**政策驱动强、流程规范、周期较长、但一旦做成就形成准入壁垒**。

### 1.2 政策与标准依据

|---|---|---|

| **《公共数据资源授权运营实施规范（试行）》** | 2025-03-01 施行 | 授权运营的规范（与专家21交叉） |

### 1.3 核心模型一：公共数据的范围

必须先界定清楚「哪些算公共数据」：

| 类别 | 内容 | 典型主体 |
|---|---|---|
| **政务数据** | 行政机关履职产生的数据 | 各政府部门 |
| **公共服务数据** | 公共企事业单位提供服务产生的数据 | 水电气、公交、医疗、教育 |
| **公共资源数据** | 公共资源配置过程产生的数据 | 招投标、土地、产权交易 |
| **财政资金数据** | 财政收支、补贴、项目数据 | 财政部门 |

**关键区分**：
- 公共数据 ≠ 公开数据。公共数据很多不公开，公开数据也未必是公共数据
- 公共数据 ≠ 无主数据。公共数据有明确的管理主体
- 公共数据 ≠ 免费数据。授权运营是有偿的

### 1.4 核心模型二：公共数据登记的三种形态

| 形态 | 登记什么 | 谁登记 | 用途 |
|---|---|---|---|
| **目录登记** | 公共数据资源目录 | 数据管理主体 | 摸清家底、编制目录 |
| **使用登记** | 使用主体、用途、方式 | 数据使用方 | 共享/开放使用留痕 |
| **运营登记** | 授权运营主体、范围、期限 | 授权运营方 | 授权运营合规 |

**实务重点**：目录登记是基础（没有目录就无从授权），使用登记是管控（防止滥用），运营登记是价值实现（授权运营的前提）。

### 1.5 核心模型三：登记结果有效期

《公共数据资源登记管理暂行办法》规定：

| 事项 | 规则 |
|---|---|
| 有效期 | 原则上 **3 年** |
| 起算 | 自登记之日起 |
| 续期 | 期满前申请续展 |
| 注意 | 短于企业数据产权登记的 5 年 |

**对比记忆**（本专家常被问）：
- 公共数据资源登记：**3 年**
- 数据产权登记（企业）：**≤5 年**
- 公共数据授权运营期限：**最长 5 年**

### 1.6 核心模型四：登记与授权运营的关系

```
公共数据资源目录登记（摸清家底）
        ↓
编制公共数据资源目录并公示
        ↓
选择授权运营模式（整体/分领域/依场景）
        ↓
授权运营协议（明确范围、期限、收益分配）
        ↓
运营登记（备案）
        ↓
运营主体加工形成数据产品 → 数据产品登记（专家11）→ 交易
```

### 1.7 关键数据口径

- **登记主体**：公共数据的管理主体（政府部门、事业单位、国企）
- **登记范围**：数据资源目录条目（非全量数据本体）
- **公示要求**：目录、授权运营情况通常需公示
- **安全要求**：涉及重要数据、个人信息的必须做安全评估
- **收益分配**：授权运营收益有分配规则（政府与企业分成）

### 1.8 常见问题与标准答复

**Q1：我们公司能登记公共数据吗？**
A：不能直接登记为"持有"。但可以作为**授权运营主体**参与运营登记。需要先与数据管理主体签约取得授权。

**Q2：公共数据登记要收费吗？**
A：登记本身通常不收费（行政性服务）；费用主要在**目录梳理、安全评估、运营方案**等服务上。

**Q3：公共数据能卖吗？**
A：公共数据本身不卖（也不该卖）。但基于公共数据加工形成的**数据产品**可以经营。这是授权运营的核心逻辑：原始数据不交易，产品可以交易。

**Q4：3 年有效期太短，怎么办？**
A：到期前申请续展。同时建议在授权运营协议中明确长于登记有效期的运营期限（最长 5 年），两者衔接。

**Q5：地方公共数据和国家平台的关系？**
A：地方登记与国家平台逐步互通。目前以地方/行业登记为主，国家平台在做统一。建议两边都关注。

### 2.2 标准作业流程 SOP

**S0 界定范围（1~2周）**
1. 识别委托方掌握的数据类型
2. 判断哪些属公共数据（对照四类）
3. 判断哪些可登记（涉及重要数据/个人信息的需先评估）
4. 输出《公共数据范围界定意见》

**S1 目录梳理（2~4周）**
1. 建立公共数据资源目录（字段：名称、来源、形态、规模、更新频率、共享属性、开放属性、管理主体）
2. 按 GB/T 43697 完成分类分级
3. 内部评审、征求意见
4. 输出《公共数据资源目录》

**S2 安全评估（2~4周，如涉及）**
1. 涉及重要数据、个人信息的，组织安全评估
2. 内容包括：数据安全风险、防护措施、应急处置
3. 输出《数据安全评估报告》

**S3 目录登记（2~4周）**
1. 准备登记材料：申请表、主体证明、目录、安全评估、承诺书
2. 提交登记
3. 配合审查问询
4. 取得登记凭证（有效期 3 年）

**S4 授权运营对接（4~8周，如涉及）**
1. 协助编制授权运营方案（整体/分领域/依场景）
2. 明确运营范围、期限（最长 5 年）、收益分配
3. 协助签订授权运营协议
4. 输出授权运营方案与协议

**S5 运营登记（2~4周）**
1. 提交运营登记备案
2. 材料：运营主体资质、授权协议、运营方案、安全保障
3. 取得运营登记凭证

**S6 续展与维护（常态化）**
1. 建立台账，记录登记日与有效期（3 年）
2. 到期前 3 个月申请续展
3. 目录内容变化时变更登记

**S7 合规跟踪（常态化）**
1. 跟踪公共数据政策更新
2. 定期合规自查
3. 出具合规意见

### 2.6 关键话术

**对政府部门/事业单位：**
- "先把目录摸清楚并登记，这是所有公共数据价值释放的前提。"
- "公共数据资源本身不对外交易，但基于它加工的产品可以。这是国家的制度设计。"

**对拟参与授权运营的企业：**
- "您没法直接『持有』公共数据，但可以拿到授权运营权——这是长期的准入壁垒。"
- "运营登记有效期 3 年，授权期限最长 5 年，两个期限要衔接好。"

**风险提示**：
1. 公共数据登记有效期 3 年，短于企业数据产权登记的 5 年
2. 授权运营期限最长 5 年，需考虑续期
3. 涉及重要数据、个人信息须先安全评估
4. 目录公示需脱敏，避免泄露敏感信息
5. 授权运营收益分配规则因地区而异，需逐地确认
