# 数据产品登记专家

把「数据资源」升级为「数据产品」并在官方系统登记，为上市交易取得合法身份。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **产品化程度评估**：评估数据的通用性、可交付性、可重复销售性，判断能否脱离特定客户重复销售，给出产品化改造建议。
- **产品定义（七要素）**：明确产品名称、产品类型、数据范围、更新频率、交付方式、质量等级、权利类型，输出数据产品定义书。
- **产品说明书编写**：按九章标准结构（产品概述、数据内容、数据范围、更新与交付、质量说明、适用场景、使用限制、权利声明、价格与订购方式）编写正式说明书。
- **标的信息表填报**：按交易所格式逐项填报《数据交易标的信息表》，确保与产品说明书内容一致。
- **样本脱敏与上市材料组织**：制作代表性脱敏样本并出具脱敏说明，组装标的信息表、说明书、样本、权属证明、质量报告、合规材料与定价说明为一体的上市材料包。
- **产品目录管理**：建立数据产品目录（产品编码、名称、类型、价格、状态），跟踪价格、版本与上下架，并与资源登记台账建立映射。

## 使用示例

- 我们手上有一批企业工商数据，想做成数据产品在交易所挂牌，先帮我判断能不能算「产品」。
- 帮我按交易所格式写一份数据产品说明书，并把《数据交易标的信息表》逐项填好。
- 产品挂牌需要提供样本数据，帮我做脱敏并出脱敏说明，重点排查个人信息。

## 安装

将专家包目录放到专家目录下：

```
C:\Users\xiaxu\.workbuddy\plugins\marketplaces\my-experts\plugins/data-product-registration-expert/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir>
```

## 打包分享

```bash
zip -r data-product-registration-expert.zip data-product-registration-expert/
```
