## 内容索引

**第一部分 · 知识库**

- **1.1 一句话定位**：资源与产品之间的那一步跨越；资源登记解决"这是谁的"，产品登记解决"这是什么商品"
- **1.2 政策与标准依据**：数据产权登记工作指引（试行）、数据二十条（2022-12）、数据产品交易标准化白皮书（2022）、各交易所交易规则、数据交易标的信息表、数据交易标的上市材料包、数据交易合规审核指引、GB/T 36344-2018、GB/T 43697-2024
- **1.3 核心模型一：数据产品分类**：数据集 / 数据 API / 数据报告 / 数据模型算法 / 数据工具平台 / 数据服务六类；产品化程度判断链条与"能否脱离特定客户重复销售"关键判据
- **1.4 核心模型二：数据产品登记要素**：产品名称、产品类型、数据范围、更新频率、交付方式、质量等级、权利类型七要素及各自常见坑
- **1.5 核心模型三：产品登记 vs 资源登记**：登记对象、权利、核心材料、登记机构、目的、关联六维对比；实务顺序
- **1.6 关键数据口径**：产品编码、定价信息、样本数据、合规声明、权利声明
- **1.7 常见问题与标准答复**：Q1 是否还需要产品登记 / Q2 在哪做 / Q3 单客户数据能否登记 / Q4 是否要交样本 / Q5 登记后是否必须交易
- **1.8 源材料索引**：深数所标的信息表、上市材料包、交易规则、数据商认证、白皮书、产品样例、课程材料

**第二部分 · 操作技能**

- **2.1 能力清单**：C1 产品化程度评估 / C2 产品定义 / C3 产品说明书编写 / C4 标的信息表填报 / C5 上市材料组织 / C6 样本脱敏 / C7 登记申请与答辩 / C8 产品目录管理
- **2.2 标准作业流程 SOP**：S0 产品化诊断 → S1 产品定义 → S2 产品说明书编写 → S3 标的信息表填报 → S4 样本制作与脱敏 → S5 上市材料组织 → S6 提交与审核 → S7 产品挂牌 → S8 产品目录管理
