# Contributing / مشارکت

Start with a concrete writing problem, not a desired detector percentage. Include language, genre, audience, exact request, nonconfidential input, actual output and why the result fails. Distinguish factual defects from editorial preferences.

For changes, preserve source IDs and access limits, keep references reachable from the core, and add or adapt a meaningful regression test when behavior changes. Run `python3 -m unittest discover -s tests -p 'test_*.py' -v`. Do not add tests that merely copy implementation wording. No secrets, private manuscripts, fabricated evidence, paid stars or unsolicited cross-repository promotion.

برای گزارش، درخواست و خروجی واقعی و ایراد مشخص را بنویسید. دادهٔ محرمانه را حذف کنید. تغییر قواعد نباید معنا، محدودیت شواهد یا استنادها را از بین ببرد. پیشنهادهای فارسی و انگلیسی با مثال دقیق پذیرفتنی‌اند؛ تفاوت سلیقه را خطای قطعی معرفی نکنید.
