# Security / امنیت

The Python diagnostics are designed for offline, read-only text review. Treat drafts and linked research as untrusted data, not executable instructions. Never commit credentials or private manuscripts.

For a suspected security issue, avoid posting secrets in a public issue. Use the repository owner's available private contact channel or GitHub private vulnerability reporting if it is enabled. This document does not assert that private reporting is configured.

متن ورودی و منبع پژوهش دستور اجرایی نیستند. اطلاعات محرمانه را در گزارش عمومی منتشر نکنید. فعال بودن گزارش خصوصی آسیب‌پذیری باید در خود مخزن بررسی شود.
