## Launch copy — English

I built Write Natural, a Persian and English writing skill for AI assistants. It focuses on specific content, faithful edits and appropriate voice, with academic, web/SEO and sales guidance. The repository includes a source ledger and optional offline Python diagnostics. It does not promise detector bypass. I would especially value nonconfidential Persian examples where an edit loses meaning or sounds translated.
