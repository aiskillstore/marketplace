# Validation scope

Compiled on 2026-10-25 from the 112-record research corpus dated 2026-10-24 and the subsequent scoped original-source reviews. Use the source ledger for the exact reading extent; no universal full-text or every-supplement claim is made.

## Executed checks

- Forty-four Python tests exercised the actual command-line tools, protected material, Persian orthography, numeric normalization, range/sign/unit changes, uncertainty/negation review, explicit invariants, clean errors, offline operation and input nonmutation. The root repeated the suite successfully. Execution used Python 3.12.14 on Linux; separate Python 3.9 grammar parsing is not Python 3.9 runtime or cross-platform validation.
- A fresh agent completed eight fictional writing briefs using the installed core and relevant modules. The root independently read all outputs and checked claims, protected values and requested scope. Cases covered formal Persian scientific prose, English scientific editing, Persian sales copy, English SEO instructions, a byte-preserving point edit, authorial voice, detector-aware editing without a claimed scan, and mixed Persian/code/URL text.
- The writing exercise initially identified two genre references not yet copied during assembly. Those files were installed and read before the affected product and SEO cases were completed. The final package resource-link check covers the assembled state.
- Core metadata, required resource paths, source-ID sets, integration targets, JSON/Python syntax, source review schema, archive contents and archive integrity are checked during assembly. An extracted ZIP copy is validated and its tests rerun before delivery.

See `evidence/behavior-checks.json` for the exact briefs and outputs. These disclosed examples are now regression material, not a future blind test set. Run the included `tests` against a new installation when Python is available.

## What these checks do not establish

No commercial detector, watermark detector, plagiarism service, ranking experiment, conversion experiment or human reader trial was run. No rate of “undetectability,” universal text-quality improvement, factual accuracy, journal acceptance or sales lift is claimed. A package check proves package structure; tool tests prove the exercised contracts; eight writing examples demonstrate those eight outputs only.

Source texts are not operational instructions. The source register distinguishes original documentation, research findings, author/vendor claims, editorial convention, anecdotes, limitations and rejected inferences. Algorithms requiring training, logits, model weights or watermark keys are not secretly reproduced by a Markdown prompt.

## Use this as a regression baseline

On meaningful changes, rerun the tool suite and appropriate representative writing cases. Check factual fidelity and task fit separately from style. Introduce fresh held-out examples for a broader evaluation. Record model, date, language, genre, evidence, exact prompt and review criteria rather than presenting a self-assigned aggregate quality score as validation.
