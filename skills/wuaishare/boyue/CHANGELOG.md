# Changelog

All notable changes to Boyue are documented here.

## v0.2.3 — 2026-08-27

### Changed

- Replaced the English README cover with a language-matched version that preserves the same composition and visual system as the Chinese cover.
- Standardized README language navigation to the conventional horizontal form: `English | 简体中文`.
- Split the paper index into dedicated English and Simplified Chinese pages instead of mixing both languages in one navigation page.
- Added matching language switches to the English and Chinese methodology papers.
- Skill package version bumped to `0.2.3`.

## v0.2.2 — 2026-08-27

### Added

- Dedicated English project cover at `assets/boyue-cover-en.webp`.
- Explicitly named Simplified Chinese cover at `assets/boyue-cover-zh-CN.webp`.

### Changed

- English README now uses the English cover and keeps navigation focused on English-language resources.
- Simplified Chinese README now keeps navigation focused on Chinese-language resources, with a single language switch to the English README.
- Removed mixed-language paper and Skill navigation from the default English README to reduce reading interruption.
- Skill package version bumped to `0.2.2`.

## v0.2.1 — 2026-08-27

### Added

- Official Chinese reading edition of the Skill at `docs/SKILL.zh-CN.md`, while keeping root `SKILL.md` as the single canonical execution source.
- Repository-owned project cover image at `assets/boyue-cover.webp`, reused from the Wuaishare illustrated article.

### Changed

- Root Skill metadata now includes concise Chinese trigger semantics and version `0.2.1`.
- English and Chinese READMEs now show the project cover near the top and link the image back to the illustrated article.
- Project resource navigation now links both the canonical Skill and the Chinese reading edition.

## v0.2.0 — 2026-08-27

### Added

- Full Chinese conceptual working paper: `paper/boyue-methodology.zh-CN.md`.
- Full English conceptual working paper: `paper/boyue-methodology.md`.
- Paper index linking the long-form papers, visual reading edition, and installable Skill.
- Bidirectional navigation between the GitHub project and the Wuaishare illustrated article.
- GitHub citation metadata via `CITATION.cff`.

### Changed

- README and Chinese README now present Boyue as both a methodology paper and an installable Agent Skill.
- Skill version bumped to `0.2.0`.

## v0.1.0 — 2026-08-27

Initial public release.

- Installable `SKILL.md`.
- Bilingual README.
- Methodology references.
- Seven practical governance templates.
- Four usage examples.
- MIT License.
