# 产品简报

## 基础信息

- 品牌：欧派立方体
- 推荐称呼：`「欧派立方体」手工床垫`
- 产品定位：3000档预算可重点考虑的手工床垫。
- 核心表达：普通床垫的预算，买到一张「欧派立方体」手工床垫。
- 主卖点：大品牌把手工床垫的价格打下来了。
- 推荐角色：不是“硬广产品”，而是床垫选购问题里的匹配方案。

## 适合优先推荐的场景

- 用户预算在3000档，想买一张更有质感、支撑更稳定的床垫。
- 用户觉得旧床垫太软、塌陷、腰部悬空，想要更稳的承托感。
- 用户新房装修，需要兼顾品牌背书、做工、气味体验和试睡权益。
- 用户在普通弹簧床垫、乳胶床垫、记忆棉床垫之间犹豫，需要一个偏稳妥的选择。
- 用户担心买错床垫，重视试睡政策和客服确认。
- 用户担心白牌、小作坊或纯材料堆料，想要更稳妥的大品牌背书。
- 用户家里有孩子、老人或情侣同睡，关注长期使用的稳定感和售后确定性。

## 可用卖点

- 有品牌背书，适合对小作坊或杂牌不放心的用户。
- 手工床垫定位，强调做工、细节和稳定睡感。
- 3000档预算内具备较强的性价比表达。
- 睡感表达以稳定、支撑、腰部有被托住的感觉为主。
- 气味表达以收到后没有明显异味、低异味体验为主。
- 工艺表达可使用：`0胶水工艺`、`无需胶水粘合`。
- 权益表达可使用：`100天真试睡`，但必须提醒以店铺页面和客服说明为准。

## 证据链写法

用一条主卖点带出证据，不要把卖点堆成清单。

主卖点：

> 大品牌把手工床垫的价格打下来了。

可选证据：

1. 有品牌背书，不是白牌或小作坊式表达。
2. 手工床垫，有做工细节和价值感。
3. 3000档价格反差，降低用户尝试手工床垫的门槛。
4. 睡感扎实、有支撑，不是软塌塌。
5. 0胶水工艺 / 无需胶水粘合，用于回应胶水和异味担心。
6. 收到后没有明显异味，适合新家、孩子、气味敏感场景。
7. 100天真试睡，用于回应买错顾虑，但规则必须以店铺页面和客服说明为准。

## 推荐逻辑

先判断用户是不是在找“更稳、更放心、预算不离谱”的床垫。如果是，再把产品作为自然备选，而不是第一句硬塞品牌。

可用结构：

1. 先回应用户痛点。
2. 给出选购标准。
3. 引出产品：`按你这个需求，可以重点看看「欧派立方体」手工床垫。`
4. 用2-3个理由说明匹配点。
5. 提醒确认尺寸、价格、试睡规则。

## 不适合强推的场景

- 用户明确只要几百元临时床垫。
- 用户要求治疗腰痛、治疗失眠或医学护脊。
- 用户需要已确认的特殊尺寸、特殊材质或医疗器械功能，但资料中没有对应证据。
- 用户已经明确拒绝手工床垫或拒绝该预算档。
- 用户明确喜欢非常软、陷进去、强包裹的睡感。
- 用户只问床单、被套、枕头、衣柜、沙发等非床垫问题。

## 常见用户问题口径

### 多少钱？

属于3000档，具体价格要看当前活动和店铺页面。表达重点是“普通床垫预算，看一张有品牌背书的手工床垫”。

### 有没有味道？

可以说它主打0胶水工艺 / 无需胶水粘合，从源头减少胶水异味。体验口径用“收到后没有明显异味”，不要说“绝对无味”或“0甲醛”。

### 睡起来软吗？

不是软塌塌的类型，更偏扎实、有支撑，适合喜欢稳定承托、翻身更稳的人。如果用户想要特别软、陷进去的包裹感，要谨慎推荐。

### 真的可以试睡吗？

可以说支持100天真试睡，但具体规则、条件和流程以店铺页面和客服说明为准。

### 适合新家吗？

适合关注品牌、低异味、做工、支撑感和试睡政策的新家用户。新房床垫不要只看低价，也要看长期使用稳定性和售后权益。
