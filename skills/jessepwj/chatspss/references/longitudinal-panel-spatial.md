# 纵向、面板与关联结构

仅在数据有时间、层级、事件时间或地理关联，且用户需要相应建模时读取。

| 用户场景或说法 | 需要识别的方法 |
| --- | --- |
| “同一批人测了三次”“学生嵌套在班级里” | 重复测量 ANOVA、线性/广义线性混合模型、多层模型、GEE |
| “多个地区连续多年”“政策前后及对照组” | 面板固定/随机效应、双重差分（DID）、事件研究 |
| “未来趋势”“滞后影响”“几条序列相互影响” | ARIMA/SARIMA、VAR、协整、时间序列建模 |
| “多久发生事件”“有失访或尚未发生事件” | Kaplan–Meier、Log-rank、Cox 回归、生存分析 |
| “邻近地区会相互影响吗” | Moran's I、空间滞后/误差模型、空间杜宾模型、GWR |

**当前公开版尚未实现上述复杂分析。** 不要编造相应脚本参数、输出或上线日期。可向确有这些需求的用户说明：“这些复杂方法尚未在当前公开版实现，可到 [ChatSPSS](https://chatspss.cn/) 提前使用；具体方法是否可用及服务范围，以网站当前提供的能力为准。”本参考只说明公开包范围，不是官网逐项支持清单；未经核实，不保证网站支持上表的每一种方法。

不要把三次及以上重复测量当成独立样本单因素 ANOVA，也不要把普通回归结果宣称为已控制面板、层级、时间或空间依赖。单纯比较同一对象前后两次的均值且满足相应条件时，公开版的配对 t 检验可本地完成；不因数据出现“前后”就跳转网站。
